# 《诡异药剂师：血锯药剂店》v0.2

这是一个面向 SillyTavern 1.17.0 与酒馆助手 4.8.19 的 MVU Zod 角色卡工程。

v0.2 在 v0.1 的稳定运行协议上扩写人物世界书：

- 七名核心角色均具备基础信息、性格调色盘和二次解释
- 左左、血衣女士、人偶夫人、黑弦月具备三面性条目
- 第1至21章的白日病患、街坊和不眠夜异常以两条配角群像收录
- 主线从系统觉醒推进到小小的夜间牙科与命名，同时允许玩家改变事件顺序和结果

核心角色仍为：

- 左左
- 血锯
- 血衣女士
- 小小
- 人偶夫人
- 爱丽丝
- 黑弦月

配角群像不进入 MVU 关系表，不获得隐藏好感或跨事件角色变量。

## 运行依赖

- 宿主：SillyTavern 1.17.0
- 必需扩展：酒馆助手 / JS-Slash-Runner 4.8.19
- 卡内脚本：MVU 加载器、Zod Schema
- 远程运行时：
  - `MagicalAstrogy/MagVarUpdate@b42817925d0391c15fa242a8238d2bbe28eb6319/artifact/bundle.js`
  - `StageDog/tavern_resource@7f29257de3ffbd83d63bc37ca09f4d4ecad6ca0f/dist/util/mvu_zod.js`
- CDN 策略：`cdn.jsdelivr.net` 主源，`testingcf.jsdelivr.net` 备用源

卡片无需玩家单独安装 Zod。Zod 由酒馆助手提供；卡内 Schema 复用同一个全局实例。

## 构建与校验

在本目录运行：

```powershell
npm run check
```

生成物：

`dist/诡异药剂师_血锯药剂店_v0.2.json`

离线检查会验证：

- `chara_card_v3` 结构与版本镜像
- 七名核心角色组件矩阵
- 两条早期配角群像
- 世界书、MVU、Schema、正则和状态栏源码一致性
- 禁止战斗与经济字段、禁止接管林恩、固定关系边界
- 负向夹具可以拒绝旧世界书、缺失依赖、缺失人物组件和战斗字段

生成物通过离线检查后仍是候选版。导入真实 SillyTavern 后，需要新开聊天确认初始变量、同轮 JSON Patch、状态栏切换、变量块隐藏与远程加载器均正常工作。

## 设计边界

- 玩家扮演20岁的林恩；AI不替林恩说话、行动、选择或书写内心。
- 玩家对林恩的声明、动作、判断和治疗方案是当前叙事的最高事实。
- 七名角色按剧情自然登场，不在开局同时解锁。
- 恋爱可以并行发展，NPC保留自主、边界和拒绝权。
- 成人内容只在明确成年、双方清晰同意、情境自然成立时出现。
- 小小固定为非性伙伴；爱丽丝固定为非性家人；血锯固定为师徒。
- 左左只有形成独立且明确成年的人格与形态后，才可能进入成人关系。
- 黑弦月明确为成年外形、成年心智和自主意志的人偶。
- 本版本不包含战斗、等级、阶位、装备、库存、货币或经营模拟。
