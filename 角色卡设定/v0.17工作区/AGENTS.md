# v0.17 设定精修工作区

本轮用户已授权继续精修并召唤子代理。只在本目录写入；原文、旧切片、v0.16 设定与卡体只读。不集成、注册运行世界书、打包、提交、推送或运行真实酒馆。

先读创作规划.yaml、来源台账.json、事件蓝图.json。原文.txt 是唯一事实来源。阅读脚本一次最多读一个冻结包，不越过 1767 章。

- 用户最新要求：涉及 NSFW 内容直接跳过、留空；不写占位、叠甲、回避话术、解释性声明或替代内容。整条只有此类内容时文件保持零字节，在核对记录登记；留白优先于字数。
- 林恩对白、主动动作、决定、判断、内心和记忆由玩家独占。默认走向只给条件因果、NPC行为和外部变化，停在可回应处；对原作玩家行为的记录只放核对报告。
- 事件沿用 EJS 隐藏/展开格式和14字段、下一事件4字段。普通默认走向目标500—1000字；重要战斗/机制展开可约2000字，事实不足或留白不凑字。
- 人物与概念以具体可核事实为准，无字数上限；不凑组件。概念在事件核对后编写，先查当前v0.16编号，新增逻辑编号由主代理统一分配。
- 正文来源仅用 E/C 编号；章节、行号、原文引句、编制判断放核对记录。知识不能提前开放，不把他人证词或猜测写成全知事实。
- 子代理只写获分配文件，其他代理也在工作，禁止回退或覆盖他人修改。主代理拥有共享台账、规划、摘要、衔接、校验与最终交付。

修改后运行 npm run check；最终运行 npm run check -- --complete。结构通过不等于事实复核，也不等于宿主验收。
