# 概念·生物／灵魂机制·寄生兽脑部灵肉绑定机制（事件["E213","E217","E218"]）

- 类别：生物／灵魂机制；描述幼虫进入脑部后一端接入神经、一端钩连灵魂并替代部分身心桥梁的重症状态，为治疗禁忌和休眠窗口提供依据。
- 事实门槛：E213由实验记录、脑部检查与灵魂稳定度共同确认绑定结构；E217在未成年患者王麟身上观察到意识暂存与虫群活性波动；E218确认医院内存在大批脑部寄生患者，但没有第二个可稳定复制王麟状态的病例。只有神经影像与灵魂指标相互支持时，才可认定灵肉绑定，不能只凭攻击行为或阵营标签判断。
- 定义：灵肉绑定是寄生幼虫成为宿主神经系统与灵魂之间的异常中介。它既窃取控制权，也承担了部分信号传递，因此直接杀死或强拔虫体可能连带切断宿主的灵魂稳定，使肉体修复与意识存续同时失败。该结构不同于外周寄生、普通附着和纯精神控制，治疗必须保留宿主原有桥梁或建立安全替代。
- 来源：E213明确区分体表、四肢、脏器幼虫与脑内残留，并记录恢复性药物会同时滋养虫群、高剂量麻痹可暂时压低活性。E217的王麟病例提示强烈目标可能短时影响虫群，却在家属病情缓解后反向升高，证明该效应脆弱。E218的批量患者说明问题可扩展为医疗灾区，但未提供根治或长期预后。
- 机制：诊疗先稳定呼吸循环，再逐层移除外周幼虫，脑内部分保持原位并进行神经、灵魂、虫群三线监测。深度麻痹只能作为桥接方案，需记录剂量、生命阈值、最长观察窗和唤醒预案。任何新疗法先在非活体模型和密封样本验证，再由独立会诊评估是否能逐步替代虫体桥梁。患者清醒时由本人决定，未成年人需同时保留本人意愿、监护与伦理审查。
- 限制与代价：麻痹会把机能压到接近停止，最多约一个月只是现场估计，不是安全保证；恢复药物可能加速虫群。搬运、精神刺激和不当净化都可能扰动绑定。等待研究会增加苏醒与占据风险，贸然移除则可能立即致命，因此不存在无代价选择。患者数量上升还会消耗监护设备、隔离床位和专业人员。
- 未知项：虫体替代了哪些具体桥梁、能否逐步逆转、休眠后的唤醒成功率、不同患者的占据速度、灵魂损伤是否可修复、神圣力量与特殊血液能否安全区分宿主和虫体、王麟效应的真实因果及批量患者长期人格状态均未知。
- 禁止外推：不得把脑部绑定等同于患者已死亡、完全无人格或可任意拘押，也不得把王麟单病例推广成“制造执念即可治疗”。不得用虚假家属死亡、疼痛、恐惧或暴力维持意识。王麟是未成年人，只允许医疗、家属支持和经审查的非性研究；18岁的林恩是否介入治疗或研究由玩家独占。
