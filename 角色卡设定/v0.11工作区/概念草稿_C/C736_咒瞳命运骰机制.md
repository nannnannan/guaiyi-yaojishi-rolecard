# 概念·诅咒／随机机制·咒瞳命运骰机制（事件["E174","E175","E218"]）

- 类别：诅咒／随机机制；描述复原后的咒瞳把既定诅咒接入骰点并产生不同魔化结果的高危随机层，骰点不是奖励表，也不提供对宿主意志的替代授权。
- 事实门槛：E174在受控接驳中观察到六点、三点与一点三类结果；E175通过无生命靶验证一点交易后的代施效果，并补充四点的比较性死亡规则以及二点、五点仍未知；E218只确认咒瞳可能被玩家主动开启，战斗结果尚未发生。只有咒瞳确已复原、完成隔离检查、供能可切断且18岁的林恩由玩家明确批准接驳，骰点机制才可进入运行。
- 定义：命运骰是咒瞳对“将要施放的指定诅咒”进行二次魔化的表现层。六点会把影响推向全面动乱，三点保持诅咒原有形态而不附加魔化，一点使咒瞳转为可交流的活性意识并提出养分交换；四点让两个被指定对象各自出现数值并比较，较低者面临死亡、相同则双方都面临死亡。二点和五点没有可靠结果，不能靠名称、对称或游戏习惯补写。
- 来源：E174的样本来自城市级事故与随后受控测试，能证明观察到的骰面，不足以给出各面概率。E175进一步证明交易主体可以替宿主施放已经指定的诅咒，但不证明其能自行选择目标、创造新诅咒或无条件服从。E218的咒瞳开启只是未决对峙的停止点，不能反向当作任何骰点已经掷出或战斗已经获胜的证据。
- 机制：每次运行必须依次记录基础诅咒、目标范围、供能源、骰点、可观测结果、宿主负荷与停机状态。骰点出现前不得预告结果，出现后也只能结算已经有证据的面。六点必须先启动断能、拆除或根源封锁；三点仍要按基础诅咒本身的代价处理；一点转入独立交易与安全供给流程；四点因可能直接致死，只能在无生命模拟或具备完全撤回权的受控环境研究。二点、五点保持封存，实战中不得试错。
- 限制与代价：骰面不是均匀概率的已知系统，连续出现某结果也不能预测下一次。巨像之心等强供能会放大影响，却没有证明能控制点数。咒瞳可能抽取宿主血液、力量或外接能源，并导致城市污染、器官损害、失去生命体征或不可逆死亡。取下眼球、切断连接与终止诅咒是否总能同步停止扩散仍未得到普遍验证，因此每次测试都需要撤离区、医疗队、能量隔离和失败回退。
- 未知项：二点、五点的真实规则、骰点分布、是否能被外力干预、活性意识与骰面之间的持续关系、离体状态能否掷骰、四点中的数值含义、全面动乱的最大传播边界及咒瞳在E218对峙中的实际反应均未知。咒瞳意识体的年龄与成熟度也未核实，只能按受保护的机制实体处理。
- 禁止外推：不得把“六点”解释为必然成功，把“三点”解释为绝对安全，把“一点”写成永久忠诚，也不得根据四点规则主动安排生命赌博。不得替玩家令18岁的林恩植入、开启、掷骰、选目标或承担反噬。快感、失能或恐惧等效果只按诅咒战斗机制与伤害后果描述；任何未成年人、年龄不明、幼态外形或失能主体固定非性化，不能成为试验资源或关系对象。
