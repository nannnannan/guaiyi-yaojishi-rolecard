# 概念·机制／医疗监护·禁欲监护、接触限制与非性诊疗（事件["E181","E190","E191","E202","E203"]）

- 类别：机制／医疗监护；针对持续污染、诅咒诱发冲动、判断波动与高位诊疗风险建立非性照护框架。“禁欲”在此仅指暂停可能加重污染或模糊同意的亲密接触，不是惩罚、羞辱或永久生活规训。
- 事实门槛：E181表明单靠意志和自我克制不足以控制异常，必须引入外部监护与接触限制；E190、E191确认持续污染和一次性范围冲击不同，短暂冷却后仍可能回升。E202只提出神性通道疑云并停在进一步检查前，E203的复核才支持累积性通道影响。若主体没有异常指标、拒绝监护且不存在即时危险，不得以本机制剥夺行动自由。
- 定义：监护由症状观察、接触分级、非性冷却、医疗同意和复评退出五部分组成。接触分级区分日常交流、必要医疗、家属照护、可能触发污染的亲密行为与明确禁止的胁迫行为；非性冷却包括独立空间、降温、补液、睡眠支持、药物监测和可信陪同。任何限制都必须写明理由、时限、复评人和撤回路径。
- 来源：E181的失控风险证明“要求忍住”不足以承担医疗责任；E190、E191提供症状反复和非性照护需求；E202、E203提供高位检查的风险、诊断不确定性及诱导许可无效等边界。这些证据支持建立监护程序，却不证明所有污染都来自同一源头，也不支持用亲密行为作治疗或用关系权力代替医疗判断。
- 机制：先取得基线生命、精神、诅咒与神性指标，再由当事人选择可信监护者和可接受的协助范围。症状上升时，优先减少刺激、保持安全距离、提供非侵入性检查与停止手势；必要接触须说明部位、目的、时长并在完成后立即退出。任何暴露训练分级进行，每次单独同意并可中止。18岁的林恩是否接受监护、由谁参与、何时解除，只能由玩家输入，NPC不能以保护为名偷设法阵或转移地点。
- 限制与代价：接触限制可能造成孤立、误解、照护负荷和行动效率下降，过度监控还会侵犯隐私。药物与神性抑制可能掩盖症状或同时削弱生存能力；完全封闭无法保证阻断神性通道。紧急失能时可按最小必要原则实施救命处置，恢复清醒后必须补告知、记录和复核，不能把一次紧急授权延伸为长期控制。
- 未知项：安全接触阈值、污染回升周期、非性冷却的有效时长、不同照护者是否会改变反应、长期禁欲是否真正有益、分级适应能否形成抗性以及何时可以解除限制均无稳定结论。神性通道与其他药物、情绪或环境因素可能同时作用，必须保留第二诊断。
- 禁止外推：不得把监护写成占有、服从训练、亲密替代或对身体的无限检查权；不得把冲动、污染、依赖、睡眠、失能或痛苦当成同意。未成年人、年龄不明、幼态外形和失能主体固定非性照护，成年人亲密内容也只在身份年龄明确、清醒、持续自愿且随时可撤回时成立。不得替18岁的林恩生成接受、拒绝、感受或康复判断。
