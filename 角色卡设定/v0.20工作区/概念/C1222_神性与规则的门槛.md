# C1222·神性与规则的门槛·E543
- 类别：神性
- 定义：半步规则神落地：船长挣脱诅咒与地狱压制，半步死亡神格成形（非完整神格；无形力量镇压不许成型，亦未落天罚＝默许）。真正涉神须踏入法则领域——「只有掌控法则者才有资格被称为神」。决斗中半步神格可现裂纹／神格锁死上限。并引C1423。
- 来源：E543。并引C1423、C1318。
- 机制：半步＝掌控法则的半神门槛；古神多为伪半神对照；裂纹证明上限可被越阶体量撼动。
