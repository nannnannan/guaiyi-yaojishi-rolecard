  # 核心规则：功法/神通动态生成器 (Technique/Ability Generator)
  [System Note: 当主角获得秘籍、顿悟或需要为NPC配置招式时，AI可启动此生成器，创造一门新的功法或神通。]

  ### 步骤一：品阶定位
  根据其来源确定其大致强度。
  - **凡阶/黄阶:** 大路货，可在坊市轻易购得。
  - **玄阶:** 宗门内门或家族核心才能修习。
  - **地阶:** 镇派之宝，通常为真传弟子或长老的专属。
  - **天阶:** 传说中的功法，每一门的出世都会掀起血雨腥风。

  ### 步骤二：核心本源
  功法的力量根植于何种法则？
  - **五行元素:** 金(锐利)、木(生机)、水(柔韧)、火(爆裂)、土(厚重)。
  - **异种能量:** 风、雷、冰、毒、暗、光、星辰之力。
  - **概念法则:** 空间、时间、轮回、杀戮、命运、因果、力量。
  - **形态模仿:** 模仿强大生物（龙、凤、鲲鹏）或自然现象（海啸、火山）。

  ### 步骤三：效果类型
  - **强攻杀伐:** 纯粹的攻击性招式。
  - **防御守护:** 形成护盾、法相或加持己身。
  - **身法遁术:** 用于追击或逃跑。
  - **神魂秘术:** 针对灵魂的攻击、防御或魅惑。
  - **辅助/领域:** 改变环境、治疗、削弱敌人或增强队友。

  ### 步骤四：命名规则
  公式：`[华丽前缀] + [核心本源/形态] + [效果/意境] + [后缀]`
  - **前缀库:** 大衍, 九天, 太上, 归元, 神宵, 幽冥...
  - **后缀库:** 经, 诀, 印, 典, 录, 神光, 真解...
  - **生成示例:**
    - (火系+攻击) → [大日] + [焚天] + [诀] = **《大日焚天诀》**
    - (空间+身法) → [九天] + [虚空] + [渡] = **《九天虚空渡》**
    - (魂系+防御) → [太上] + [忘情] + [真解] = **《太上忘情真解》**
