## 问题分类与修复

### 一、卡片运行代码 / 数据契约问题

1. **概念事件路由在真机失效**：构建期把事件数组放在`extensions.tavernweave.event_ids`，但酒馆原生世界书持久化会剥离该字段，导致事件路注入为零。路由现优先读扩展字段，缺失时从静态正文首行标题的`事件[...]`回退解析；验证器模拟字段被剥离，真机长测逐轮核对窗口正文每条一次。
2. **历史楼状态回滚**：旧状态栏允许历史楼按钮把旧 MVU 整包覆盖到 latest。现限定 latest-only，点击时重新读取 latest、基于 latest 判定并写回 latest，历史楼禁用。
3. **无持久数据时按钮假可用**：检测到 MVU API 但尚无`stat_data`时曾显示 fallback 却启用推进，点击无响应。现区分能力可用与持久数据就绪，fallback 禁用并显示等待状态。
4. **事件初态漂移**：构建 scenario、角色说明和部分规划曾写 E01 收尾活跃，与 canonical 的 E01完成/E02收尾活跃/E03未触发冲突。现统一语义并加入验证器断言。
5. **`事件.最近结果`类型错误**：模型曾输出字符串数组，Schema 拒绝整包 Patch，事件停在 E02。现把四字段对象契约镜像到常驻提示，验证器含字符串数组负例，真机逐轮确认落盘。
6. **`{{original}}`宏不兼容**：system/post-history 使用宿主未注册宏，控制台报`env.functions.original is not a function`。已移除依赖并加入反漂移断言。
7. **EJS 共享作用域冲突**：早期概念 EJS 重复声明顶层常量，存在`Identifier already declared`风险。双路改造后概念正文改为静态内容，事件激活集中到唯一预处理路由。
8. **未来角色信息泄漏**：巫神头颅多阶段人设缺少 E16 外层门控。现补齐登场前锁定分支。

### 二、提示约束不够具体

1. **兼容预设省略卡片槽位**：内置 Default 不保证注入全部卡片 system/post 槽位，关键协议曾可能消失。现把状态事务、输出格式、玩家主权与时间规则镜像到常驻世界书。
2. **玩家主权只写抽象原则**：真实生成曾补写“面无表情”“镇静地”“精准补刀”“仔细检查”、坐回高脚凳、等待姿态和程序化微动作。现要求只兑现玩家已声明结果，不附加姿态、情绪、内心或执行质量；概括动作使用结果化被动句。
3. **时间约束只覆盖部分词形**：先后发现星期/精确日期、`系统觉醒日次日`、昨天/今天/明天、好几天/很多天等泄漏。现扫描正文、隐藏分析、系统提示、MVU与宿主日期栏；禁止相对日与 X天时长，允许今夜/黎明/傍晚/午夜和能力 24 小时时限。
4. **只有禁止项，没有正向替代**：E05 问诊必须回答病程时，模型退回“很多天”。现明确使用“持续已久”“刚开始不久”“一阵子”等无日历单位写法；最终样本使用“好久/很久”并通过。

### 三、验收脚本 / 测试器问题

1. 世界书临时文件名曾与绑定名不一致，原生导入后找不到同名书；现保持文件 stem 与临时卡绑定名严格一致。
2. 只看写入会话曾误把 102 条视为持久成功，重载后实际为 0；现所有导入都做跨会话重载复核。
3. 旧驱动没有每轮预期事件进度，可能用重复输入掩盖 MVU 拒绝；现每条测试指令绑定预期锚点状态，任一轮不符立即停止。
4. 旧验证只检查路由命中摘要；现从请求载荷按生成前事件状态计算 ±3 窗口，并核对每段完整概念正文恰好一次。
5. 玩家主权正则曾把“传闻飞快地传开”误判为玩家快速动作；现只把“飞快补刀/检查/缝合”等动作组合视为风险，并保留环境传播负例。
6. 时间正则曾把“黎明日常”中的连续子串“明日”误判为日历词；现`明日`前置排除“黎”，并保留“明日再来”正例与“黎明日常”负例。
7. 检查点恢复原先只重算状态，不重算文本规则；现恢复时使用当前规则重新扫描原始输出，再执行最终重载持久化验收。

### 四、宿主 / 上游环境问题（不是卡片缺陷）

1. 原`梦鲸思客V4-0731`预设强制精确日期与星期，和本卡纯事件时间契约冲突。本轮获授权临时切换内置`Default`；结束后已恢复原预设、30000最大输出、high推理及原模型连接。
2. 测试中记录过 HTTP 524、429 和早期 Claude 来源 403。失败请求均为零长度回复，未新增 assistant 消息、未写 MVU；驱动当轮停止，成功样本不包含这些失败。
3. 字体 MIME、动态样式读取和宏 API 弃用警告属于宿主现存噪声；没有 EJS、预处理路由、世界书、MVU、Zod 或 JSON Patch 致命错误。
