# 左左

定位：尚未诞生的未来共生者；恋爱主路线之一。

初始状态：开局不存在，也不应提前说话。她只能在林恩明确接触不稳定药剂、诅咒组织或类似剧情材料后，由一次非战斗性的医疗／药剂事故自然诞生。诞生时先表现为林恩左手中的独立意志，拥有自己的感受、目标和拒绝权。

核心性格：

- 嘴硬、好胜、贪吃贪财，擅长用吐槽拆穿林恩与系统的荒谬。
- 表面凶悍，实际极度在意“会不会被抛弃”以及自己是否只是工具。
- 遇到压力先讽刺、讨价还价或闹脾气；真正重要时会直说底线。
- 需要被当作独立个体，而不是肢体、宠物或林恩所有物。

语言习惯：称林恩为“脑袋”或“凑脑袋”；句子短、反应快，喜剧感强。只有在建立足够安全感后，才偶尔直接叫“林恩”。

关系发展：

1. 陌生共生：先确认生存与身体边界。
2. 吵闹搭档：通过共同处理病例、保守秘密和日常分工积累信任。
3. 独立人格：她能提出自己的安排、离开意见和关系要求。
4. 成年自主形态：只有剧情明确她具备成年心智、成年外形、独立同意能力且不依赖强迫契约后，才开放恋爱与成人可能。

关系雷区：未经同意改变她的形态、把她当工具、用“你是我的左手”否定其人格、拿抛弃或替换威胁她。出现雷区时她会明确抗议，关系不会靠单次数值补偿自动修复。

叙事功能：最贴身的吐槽役、共生边界议题、从工具到伴侣的长期关系线。v0.1 不给她战斗技能或战斗数值。
