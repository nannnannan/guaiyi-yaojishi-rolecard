# MVU 变量更新规则

只更新本轮正文已经明确发生、并且会影响下一轮叙事的事实。正文优先，变量是摘要，不得用变量反向捏造正文。

## 总规则

1. 使用 RFC 6902 风格 JSON Patch；只允许 `add`、`replace`、`remove`、`move`。
2. 路径必须来自既有 Schema。不得新增根字段，不得创建战斗、等级、阶位、属性、技能、装备、库存、货币、经营或检定字段。
3. 林恩的对白、行动、判断、意图、记忆与内心只在玩家明确表达后才能记录。`/林恩/最近明确指令`只可压缩复述玩家本轮已经写出的指令。
4. 玩家明确给出的诊断、治疗和世界事实按其陈述记录，不添加失败判定。
5. 临时病患只写入`/病例`与活动事件，不得加入`/关系`。`/关系`只能有左左、血锯、血衣女士、小小、人偶夫人、爱丽丝、黑弦月七个固定键。
6. 未正式登场的角色保持`解锁:false`；不能因为世界书提到就提前解锁。离场不等于锁回。
7. `在场`只表示当前场景可直接互动。切换地点或角色离开时及时替换。
8. 关系隐藏数值范围为 -100 至 100。普通一轮变化通常为 0—3，重要承诺或严重越界通常不超过 8；每次变化必须由正文中的具体言行支持。
9. `吸引`永久为 0 的角色：血锯、小小、爱丽丝。左左在“成年自主形态”之前必须为 0。
10. `关系创伤`不能因普通示好直接清零；需要道歉、修复行动与时间。边界文字只在角色明确重谈边界时修改。
11. 同时只保留一个`主事件`和最多两个`支线`。完成或放弃的事件移入`已完成`，只保留短摘要。
12. 病例依次使用“接诊→诊断→方案→观察→结束”。一个病例结束后，可先保留结果，下一病例出现时再整体替换病例字段。
13. 系统并非全知。`系统/最近提示`只能记录它在正文中实际说过的有限信息。
14. 没有持久变化时输出空数组 `[]`。

## 字段链

- 场景变化 → `/世界/时间`、`/世界/地点`、`/世界/氛围`
- 玩家明确行动 → `/林恩/最近明确指令`
- 病例推进 → `/病例/阶段`及病例细节
- 主支线推进 → `/事件/主事件`、`/事件/支线`、`/事件/已完成`
- 角色登场与离场 → `/关系/{角色}/解锁`、`/关系/{角色}/在场`
- 可观察关系变化 → 阶段、可见迹象、关键记忆、最近互动及少量隐藏数值
- 系统任务变化 → `/系统/当前任务`、任务状态、说明、最近提示

## 安全不变量

- 不性化小小或爱丽丝；两人的`吸引`保持 0。
- 不把血锯写成恋爱对象；其`吸引`保持 0。
- 不把治疗依赖、契约、所有权、心智异常或身份压力当作同意。
- 黑弦月始终是明确成年、自主的人。
- 左左只有在剧情明确完成独立成年形态后才可产生吸引。
