### 1.2 晋升路径

- **召唤四阶段**：众生 → 超凡-死兆 → 君王-根源 → 根源之上（仅视界至高意志可行）；第一阶段法阵需世界意志烙印认可，只能向下兼容（阶段3）。
- **根源级晋升**：吞噬炼化其他根源级（或同等能量源）可晋升根源级。实例：银色幻想吞灭绝者晋升机械根源，再夺机神数据飞升"万机之神"（阶段14）。
- **新根源诞生（反向）**：神格实体被拖入地狱后被标记、削弱神格，转化为新根源（阶段9）。
- **初诞者路径**：弑杀万物生灵融合自身；后证实为死路（阶段10/15）。
- **升格机制**：初诞者之力可使根源级短暂摆脱地狱限制升格——"升至真神位数分钟"（阶段12，素材B/C）；素材A表述为"使根源短暂升格为古神（阶段12-14）"【表述差异，并列待考】。
- **泰坦血肉控能路线**：普通 → 血气 → 神力 → 神格四阶（阶段13）。
- **三位一体晋升**：需吞噬外来者三家族守护之力（阶段16）；最终须吞噬同伴本源（血枢、以太、灵能）（阶段15-18）。
- **外来者限制**：走遗产路线者（巨像、艾雯）无法获得半神及以上位阶，强行融合致法则排斥；林恩因初诞者之力可走法则线（阶段16）。
- **机械神教晋升线**：身份烙印 → 预备役审验 → 意识上传 → 正式成员（蜂巢居住）；层级：万机之神 → 肃正议会 → 指挥官 → 蜂巢智脑 → 普通上传意识；一级权限豁免所有审查但风险极大（阶段9）。
- **血肉傀儡军备链**：猎杀者 → 3型 → 猎神者 → 试做型巨像（大总结1）。

### 1.3 法则体系

- **法则梯队**：第一梯队【真理】；第二梯队【时间/空间/因果】；第三梯队【创造/毁灭/轮回】（大总结12）。
- **法则掌握阶段**：雏形 → 领悟 → 成熟（可战斗） → 巅峰（镇压万物）（大总结14）。林恩掌握空间规则雏形→已超成熟；银色幻想掌握创造规则雏形（阶段14）。
- 法则可武器化（梦境领域构建→法则潮汐）；神王可奴役/反转敌方法则（阶段16）。

### 1.4 层级压制规则

- **根源级诅咒定律**：所有根源级因堕入黑暗世界背负诅咒，越强束缚越重，神亦不例外（阶段4）。
- **本体降临限制**：根源级本体降临需生命献祭或能量积累，通常以投影隔空借力（例：欲望母树需吞噬一半部众完成四分之一降临）（阶段4）。
- **庇护规则**：根源级不受72君王庇护规则约束（阶段1）。
- **神性位格**：高于根源级，可绕开根源禁制；主母禁制无法覆盖神性通道，高位格诅咒可绕开（阶段7）。
- **权柄类异常**：独立于超凡体系，"破碎世界坠落物"，掌握命运等高阶规则（羽毛笔为图鉴第七位，大总结6）。
- **权柄干涉上限**：对外干涉超过"直接影响凡人"程度即触发地狱最大反噬（阶段7）。
- **无序化定律**：非天生无序生物终将彻底无序化，存在痕迹被世界抹除，仅高位格者保留记忆（大总结12）。
- **低魔世界限制**：蓝星无法召唤根源级及以上存在（阶段3）。
- **无序三柱神**：画家（奈奈子/典狱长）、乐者/歌者（已被狱卒击败）、沉眠者（第一柱神，被紫罗兰大君入主）（阶段12）。
- **72柱魇魔**：各代表不同扭曲概念，神王级，可复活；空白之柱（紫罗兰大君）可借用终焉之主本体力量（阶段17/18）。

### 2.2 制作/学习机制

- **夜医切割缝合疗法**：药剂以咒术均匀分布在血肉中，形成压制诅咒的罗网；操作要求高（阶段2）。

## 三、世界规则与战斗通则

### 3.1 诅咒通用机制

- 诅咒对抗分两档：**限时清除** vs **永久削弱**（阶段1）。
- 高阶同质诅咒可吸收低阶（诅咒同化，阶段5）。
- 神圣力量可压制多数诅咒，但会刺激小丑型诅咒失控（阶段2）。
- 诅咒管理条例与道德值挂钩（阶段4）。
- 恶灵诅咒强度与吞噬数量成正比，吞噬越多越难保持理性（阶段1）。
- 咒瞳机制：可记录并释放任意诅咒，效果取决于双方精神力对比（阶段2）。

### 3.2 地狱机制（反噬/凝视/绝罚/拖拽）

- **地狱反噬/凝视**：动用权柄触怒地狱 → "地狱的凝视"数值化（例：17）→ 7日倒计时 → 刑罚（诅咒/切割灵魂/使人疯狂，但不杀灭）（阶段6/7）。
- **绝罚（地狱灭绝机制）**：最高级地狱权限，可引爆指定区域内所有生物体内诅咒（导航者·弑利亚持有）（阶段12）。
- **地狱拖拽**：持有【门】者在主宇宙使用技能，地狱派锁链黑线镇压拖回；对林恩有特殊反应（"地狱不敢排斥林恩"）（阶段9）。
- **哭泣小丑诅咒三阶段**：放大负面情绪/篡改能力 → 经欲望母树神性绕开禁制 → 第三阶段潜伏；根源为狱卒（猪头屠夫）工具（阶段2/7/10）。

### 3.3 污染与无序

- 无瞳之眼可污染空间/物质/法则/时间线（阶段12）。
- 污染可经梦境/潜意识渗透，突破初诞者之力检测（阶段16）。
- 污染者来自破碎世界，经时间裂隙侵入历史；初诞者之力可修复裂隙（阶段12）。
- 无序化定律（见1.4）；无序化=存在痕迹被抹除的真死（阶段12）。
- 可控无序技术：物质载体+轮回法则铭文实现短暂可控无序；可控无序生灵战力大幅低于同规模纯无序生物（阶段15）。

### 3.4 即死/规则杀能力

- 《看了就会死的书》：无差别直死诅咒（阶段4）；诅咒之城战场丢失后出现裂纹下落不明（阶段5）。
- 咒瞳魔改版"命运的骰子"：1点=活性化交易 / 3点=正常 / 4点=即死对半骰（对死兆级以上效果打折，对君王级无效）/ 6点=全面动乱；2点与5点效果未明（阶段7/8）。
- 巫神巫毒娃娃：远程无视防御攻击，精准对应玩偶受击部位（阶段6）。
- T型智能动乱病毒：对纳米机械专属，无视其底层逻辑（阶段4）。
- 纳米机械底层逻辑漏洞：禁止将同类型单位作为分解对象（阶段4）。
- 机械意识信息同调传染：经信息网络将状态/"疾病"同步至全链路节点；切断同调为临时对策；万机之神无免疫方案（阶段4）。
- 疫医"血肉·咒缚瘟疫"：封锁机械意识上传，斩断机械神教战争潜力（阶段5）。

### 3.5 领域/法则战斗

- **梦境领域**：1米内即创造新世界，瞬间触发法则洪流，可封印破碎之眼（阶段16）。
- **神疆**：梦境照入现实（感知/压制/培育）；群星调动术含神疆（远程法则浪潮）、锚定（空间锁定折跃点）、第三种未知（阶段16）。
- **法则防线/法则潮汐**：初诞者之力激活法则成武器，对无序生灵绝对压制（阶段16/17）。
- **灭世灾厄**：能崩解空间、熄灭星光、无视法则（阶段9）。
- **混乱色彩 vs 灾厄**：阶段9"混乱色彩（地狱边境）可阻挡灭世灾厄注视"；阶段10修正"混乱色彩/视界掌控者无法对抗外域灾厄"【矛盾，并列】。
- 驱魔大阵：封锁空间限制折跃穿透（阶段7）；镇旗：王骑八柄旗帜形成封锁结界（阶段12）。
- 封印矩阵：五台巨构在精神世界封印以太，林恩本人成封印容器，他死则封印解除（阶段14）。

### 3.6 灵魂与精神

- 灵魂层级：精神世界 → 心海 → 潜意识领域 → 混乱之海（时间流速不同，极危险）（阶段11）。
- 混乱之海穿梭：以精神意念穿越潜意识形态区回溯被抹去的记忆；意识若认定死亡则无法唤醒（阶段11）。
- 灵魂分裂术：林恩分裂32份灵魂无异常报告，但47%灵魂创伤未处理（阶段13）。
- 寄生兽机制：幼虫侵入大脑与宿主灵魂绑定为不可逆"新器官"，物理移除即毁灭宿主灵魂；成长周期与宿主血肉活性负相关；强烈执念可一定程度抵制虫群意识（阶段7）。
- 心锚机制：以情感寄托为锚，将恶灵/诅咒困于时间循环；心锚对象消失则封印崩溃（灵媒封印法，阶段2）。
- 地缚灵机制：怨念锚定死亡之地；诅咒清除可短暂解缚24h；获地界产权可传送回据点（24h冷却）（阶段2）。
- 恶灵附身：爱丽丝提供力量增幅但承受生命力流逝（阶段4）。
- 一体双魂神明机制：主母善面与堕天使暗面共存，信仰之力为神明意识锚（阶段5）。

### 3.7 复活与死亡规则

- **替死娃娃x5**：抵消致命伤害；每用一次"咒怨缠身"，第5次后完全触发；阶段4时剩1次（阶段3/4）。
- **天使之吻祝福**：24h诅咒抗性+20 / 生命恢复+20 / 攻击附神圣属性 / 濒死补满状态；需主母"补魔"续费（阶段2）。
- **命运契约**：林恩与羽毛笔结契约，林恩真死时她代替赴死（阶段6）。
- **不死诅咒**：阶段8在蓝星曾被禁用（阶段8）。
- **自然领域神性保意识**（阶段6）。
- **72柱魇魔可复活**（阶段17/18）。
- **终焉之主**：不可彻底消灭，只能以秩序压制，与永恒形成循环（阶段18）。
- **欲望母树绑定规则**：第一个与其发生关系者持续获取其力量，其他试图者受反噬；母树失去绑定者将逐渐消亡（阶段6）。
- **人偶诅咒**：地狱最温和诅咒之一，洗去记忆赋予人偶之躯（阶段11）。
- **死亡凋零**：被压制至20%未根除，存在复发或被远程引爆风险（阶段3-5）。

### 3.8 时间规则

- **时间战争系统（林恩独有）**：以过去渡鸦尸体为容器返回过去修炼/清除污染者；积累"时之疲惫"（白发增多）；不能干涉重大历史节点；改变过去引发蝴蝶效应反噬现在；同一时间节点不能出现过多自己；时间线可分支、截断、交互（阶段14/18）。
- **心灵之海修炼法**：意识空间时间差加速法则领悟，存在死亡投影、记忆丢失风险（阶段14）。
- **时间加速修炼场**：上限100倍（紫罗兰世界奇异世界），已产出多位半神/古神（阶段16）。

### 3.9 其他通则

- **交易规则**："有钱给钱 / 没钱等价交换"，可支付情报、器官、服务等（阶段1）。
- **货币**：骷髅币（黑暗世界主货币，游荡者账单3.5万骷髅币）；黑颅币（根源间流通）；悬赏实例：血肉神教对林恩悬赏500万（阶段2/3/7）。

- **驯服度/崩坏值/涩涩度**：对机械意识同样适用；涩涩度max自动转化为崩坏值与驯服度；攻击可致意志崩溃 → 情报服从 → 恶堕（阶段4）。
