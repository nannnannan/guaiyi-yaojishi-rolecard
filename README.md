## 核心特性（V1.0 / v0.23.0）

- **全书封箱沙盒世界观**：完整收录《诡异药剂师》全书 **798 个事件锚点（E01–E798）**、**102 篇阶段总结（S0–S101）** 与 **1830 条世界书词条**，并从传统「线性剧情卡」升级为「沙盒世界观卡」（含偏离账本、时空锚点、五条沙盒铁律、三级信息可见性、事件信号与近期事务）。
- **核心角色与全员 IF 线**：覆盖 **28 名核心角色**（完整六组件 + `if_line` 偏离支线 + 关系网/里程碑/专属互动）与 **66 名可选登场 NPC**。
- **双轨存储与零冲突协同**：原生适配 **MVU（MagVarUpdate）Zod Schema** 与 **龙血玄黄·数据库（AutoCardUpdater / shujuku）**，明确职责边界、静默降级、`<UpdateVariable>` / `<tableEdit>` 互不干扰及 `[AMxxxx]` 纪事协议。
- **全屏魔导书状态栏（Grimoire UI）**：内置楼层紧凑摘要条（含专属封面徽记）与全屏五视图魔导书（总览 / 羁绊 / 世界 / 纪事 / 敕令），支持双通道指令队列与一键复制兜底。
- **双格式发行产物**：同时提供 JSON 卡体（`角色卡本体/诡异药剂师_MVU_v0.23/dist/诡异药剂师_v0.23.json`）与内嵌 `tEXt.chara` 数据的 PNG 封面角色卡（`角色卡本体/诡异药剂师_MVU_v0.23/dist/诡异药剂师_v0.23.png`）。
