## ✨ V1.0 全书封箱正式版核心特性与精修亮点

### 1. 全书封箱沙盒规模（Full-Book Sandbox Scale）
- **798 个事件锚点全覆盖（`E01–E798`）**：完整囊括原著全部 **2,710 章**、七大时期（游魂巷药店篇 `E001–E032`、黑夜城夜医篇 `E033–E133`、蓝星返乡篇 `E134–E254`、机械神教篇 `E255–E348`、渡鸦真相与地狱扩展篇 `E349–E506`、地狱统一与主宇宙神战篇 `E507–E681`、终焉决战篇 `E682–E798`）与 **102 篇阶段总结（`S0–S101`）**，止于「本书完」雪谷婚礼大团圆。
- **1,830 条世界书词条与双路去重路由**：内置 1,561 项核心概念（含事件门控动态变体与增量演进）、798 份事件素材与 798 份专属 `if线` 分支，依托 `@@preprocessing` 概念/人物事件窗口（`±1`）与酒馆原生关键词双路去重激活。
- **28 名核心角色 + 66 名动态登场 NPC（前端 98 份图鉴卷宗）**：
  - **28 名核心角色**：完整配备「角色速览 / 基础信息 / 性格调色盘 / 三面性 / 多阶段人设 / 二次解释」六组件立体档案，随事件推进动态解锁阶段人设。
  - **66 名可选动态 NPC + 4 份特殊卷宗**：按事件窗口与关键词动态投送，前端图鉴完整收录 98 份高清设定与亲密档案。
- **16,296 条 `if-lines` 条件分支精修**：全量通过深度审计，实现 **0 语法错误、0 元数据泄底词、0 林恩玩家主权越界**（玩家绝对独占林恩的对白、主动动作、决断、判断、记忆与内心）。

### 2. 前端「诡秘解剖羊皮卷」状态栏与专职状态官独立 API
- **楼层轻量摘要条 + 全屏四大核心视图**：
  - **楼层紧凑摘要条**：每轮回复底部展示哥特羊皮卷摘要，集成时期/地点坐标、林恩生理与权柄微章、在场角色速览、当前活跃事件与 `@module` 动态场景专属模块。
  - **全屏四大核心视图（`灵肉场域` / `深渊情缘` / `诡异图鉴` / `沙盒星图`）**：支持全维检视林恩状态、角色好感/信赖/戒备/恶堕/涩涩度及专属调教维度、98 份角色与世界图鉴、798 事件星图与蝴蝶效应偏离账本。
  - **按阶段防剧透保护（`spoilerSafe`）与窄屏自适应**：默认隐藏尚未解锁的后期人物与高阶事件，支持一键显影切换；针对手机端与窄气泡完成深度适配，低至 `375px` 视口保持 `0px` 水平溢出。
- **正态分离 · 专职状态官独立 API（`#gyp-agent-console-v023` & `<GypDSL>` v1.0）**：
  - 主 AI 专注正文叙事，回复结束后由内嵌状态官引擎自动审计正文并输出 `<GypDSL>` 指令块与 `@module` 动态场景专属模块，实时编译为 MVU JSON Patch（同时兼容单通道 `<UpdateVariable>` 回退）。
  - 内置独立 API 配置面板（`#gyp-agent-console-v023`），既支持配置任意 **OpenAI 兼容副模型（自定义 Base URL / API Key / Model）** 分担状态结算，也支持 **零配置自动回退酒馆当前主 API（`TavernHelper.generateRaw`）**。

### 3. MVU × 龙血玄黄·数据库（Shujuku）双轨零冲突协同
- **沙盒变量层**：`schema.js` 系统对象完整维护 `偏离`（蝴蝶效应账本）、`近期事务`（滚动时空轨迹）与 `信号`（一次性事件防重锁），支持结果等价判定与变形收束。
- **双层纪年与零冲突降级**：原生适配 **MVU（MagVarUpdate）Zod Schema** 与 **龙血玄黄·数据库（AutoCardUpdater / shujuku）**，通过 E 锚点世界观层与 `[AMxxxx]` 个人纪事层双轨协同，`<UpdateVariable>` 与 `<tableEdit>` 互不干扰，未安装数据库时自动静默降级。
