# 《诡异药剂师》SillyTavern 同人角色卡

这是面向 SillyTavern 的《诡异药剂师》同人角色卡工程，采用 MVU Zod、EJS 和世界书事件路由来承载角色、剧情与状态变化。

本仓库的 `main` 分支只保留 `角色卡本体/` 下的 19 个历史版本目录。每个目录都尽量保留该版本自己的源码、契约、配置、构建脚本、校验记录和生成卡体，方便按版本构建、对照与使用。

这是同人创作项目，不代表原作官方立场。

## 快速开始

1. 进入目标版本目录，先阅读该目录的 `README.md`。
2. 按版本 README 中的依赖说明准备 SillyTavern 与酒馆助手。
3. 优先修改 `src/` 和规划/契约文件，再运行该版本提供的构建与检查命令。
4. 将 `dist/` 中生成的 JSON 导入 SillyTavern；不要直接编辑 `dist/`。

多数较新的版本使用：

```powershell
npm install
npm run check
```

早期版本可能使用：

```powershell
node tools/build.mjs
node tools/validate.mjs
```

离线检查通过不等于真实宿主验收。导入真实 SillyTavern 后，还应按照对应版本 README 和 `host_acceptance.json` 检查变量初始化、MVU 更新、状态栏、正则、事件路由和远程运行时。

## 运行依赖

- SillyTavern 1.17.0。
- 酒馆助手 / JS-Slash-Runner：v0.1–v0.4 的 README 主要记录 4.8.19，v0.5 及之后主要记录 4.9.1。
- 卡内 MVU 加载器与 Zod schema。
- EJS 条件渲染、世界书关键词路由、事件锚点和状态栏组件。
- 部分版本使用 jsDelivr 及备用 CDN；具体地址和版本以对应目录的 `manifest.json`、`profile.json` 与 README 为准。

## 源码入口

不同版本的目录细节略有差异，通常可以从以下位置开始：

- `src/events/`：事件锚点与事件详情素材。
- `src/concepts/`：世界观、人物、机制、势力、地点和伏笔概念。
- `src/characters/`：角色的基础信息、性格、人设阶段和其他组件。
- `src/prompts/`：系统提示、主线衔接、开场白和 MVU 提示片段。
- `src/initial_variables.json`：新聊天的初始 MVU 状态。
- `src/scripts/schema.js`：MVU Zod 结构约束。
- `src/ui/status.html`：状态栏和事件控制界面。
- `contract.json`：可机器检查的结构与依赖契约。
- `manifest.json`、`profile.json`：版本、依赖和构建映射。
- `tools/`：构建、校验、迁移和一次性同步工具。
- `dist/`：生成的角色卡 JSON，不应作为源码入口直接修改。

## 设计边界

- 林恩的对白、主动行动、决定、判断、记忆和内心始终由玩家掌握；默认剧情只提供因果背景。
- 事件是默认因果链，可由玩家介入、取消或改变，不替玩家做决定。
- 事件详情、摘要、世界书关键词和状态栏之间通过 UID、窗口和去重规则协作。
- 项目不以可运算的战斗数值、等级、装备、库存、货币或经营结算为核心玩法。
- 角色关系、成人内容和非恋爱角色边界以对应版本 README、卡体设定和运行时规则为准。

## 验收与维护

修改源码后，先按对应版本 README 运行离线构建与 `npm run check`（若该版本提供），再进行真实 SillyTavern 验收。源码检查、生成物检查、真实宿主运行、人工接受和发布推送是不同的证据门，不相互替代。

本仓库只发布角色卡本体的历史版本目录；共享指南、项目交接材料、测试证据和其他工作区文件不属于发布范围。
