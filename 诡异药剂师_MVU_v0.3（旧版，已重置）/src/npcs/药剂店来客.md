# 药剂店来客

以下人物只在病例、地点或事件中承担局部功能，不加入十人关系表。

- 人皮拾荒者：游魂巷交易者，携带旧物和来历不明的器官；重视等价交换和礼数。
- 血娃娃：抱着缺臂洋娃娃的血肉恶灵；围绕“妈妈”求诊，成为开场病患和E01参与者。
- 猪头魔：游魂巷猪肉店老板；眼部与腹部有异常，暴露手术风险后可能优先离开。
- 恶灵血婴：可从猪头魔腹中出现的未成形恶灵；血肉结构不稳定，会寻找宿主。
- 烧死鬼：带有焦黑灼烧痕迹的候诊者；遇到超出承受范围的场面会直接离开。
- 猎魔人奥卡洛斯：来自地上世界，携带受诅咒左轮，受黑蝴蝶剧毒侵蚀；认可明确报价与公平交换。
- 黑蛾妖精玥玥：可能到店的单次客人；具体病症和背景按实际事件简述，不建立长期关系。

来客只记录身份、可见特征、行为、与林恩的当轮关系和剧情功能。重复出现且具有长期特殊设定时，后续版本才评估是否升级。
