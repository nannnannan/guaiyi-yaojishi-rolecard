# 三件套整理说明

原始三件套是配套的角色卡制卡工具，本目录把它们整理为可维护的「入口 / 大脑 / 手册」结构，
并基于同一思路实现了新的 AI 接入桥。

## 原件与职责

| 原件 | 格式 | 职责 | 整理去向 |
|---|---|---|---|
| 酒馆助手脚本-玉藻前一键写卡器V1.0.json | Tavern Helper 脚本（481 B） | 入口：注册「一键角色卡写卡器」按钮，从 jsdelivr 加载小玉藻写卡器前端 | `入口/st-bridge.mjs`（命令行接入桥） |
| 明月秋青-V10086.json | SillyTavern 预设（277 KB，61 个提示词块） | 大脑：秋青子 AI 秘书 + 完整写卡工作流模板 + MVU/EJS 模板 + 思维链正则 | `大脑/AI接入指南.md` |
| 写卡知识库.json | 世界书（178 KB，36 条目） | 手册：EJS / 酒馆助手接口 / MVU / 自查标准的按需查阅字典 | `手册/酒馆运行时速查.md` |

原件已备份到 `三件套原件/`，保持一字不改。

## 玉藻前入口（原始脚本）要点

- 本体只是加载器，实际功能来自远程打包的 Vue 3 + Pinia 应用（约 4.4 MB）。
- 三种工作流：一键生成完整角色卡（回答 3 个问题）、高级编辑模式、只整理人设。
- 生成前自动保存恢复点，分阶段写入世界书/角色卡/开场白，失败可从当前步骤续写。
- 三种连接模式：稳定完整 / 流式保活 / 截断续传。

## 明月秋青大脑（原始预设）要点

- 蛇娘秘书「秋青子」人设 + 输出格式铁律（thinking/metacognition/content）。
- 创作流程：世界观 → 角色基础 → 性格调色盘 → 三面性 → 二次解释 → 衣柜 → NSFW → NPC → 角色速览 → 开场白。
- 写作原则：绝对零度、白描、去八股、外貌差异化、语料纯净、用户主导。
- MVU 全套模板：变量结构脚本（Zod）、初始变量、变量列表、更新规则、输出格式（JSON Patch）、前端状态栏。
- 内嵌两个助手脚本：LorebookToolCall（AI 读写世界书/角色卡的函数工具层）和「伪IDE」（写卡操作台）。

## 写卡知识库手册（原始世界书）要点

- 36 个条目全部禁用，AI 按需 Read：索引 → 对应主题条目。
- EJS 专题：基础语法、变量读写、装饰器注入、多阶段人设、函数速查、动态内容控制器。
- 酒馆助手接口 00–19：消息楼层、变量、世界书、AI 生成、事件、提示词注入、预设、角色卡、宏、音频、脚本、扩展、导入、工具函数、MVU、Slash、版本、角色卡管理。
- MVU ZOD 指南：schema → initvar → 变量列表 → 更新规则 → JSON Patch 输出 → 正则 → 前端。
- 世界书配置指南：蓝灯/绿灯、单角色卡全蓝灯、D0 放二次解释、递归双防、关键词英文逗号。
- 自查体系：一般条目 / 世界观 / 世界书评估 / 前端美化 / MVU / MVU 状态栏 / EJS 调色盘多阶段。

## 新入口（st-bridge）与三件套的关系

- 入口：原来是「点按钮打开写卡器」，现在是「AI 用命令行连接酒馆」。
- 大脑：原来靠预设提示词约束 AI，现在靠 `AI接入指南.md` 约束接入 AI。
- 手册：原来靠世界书按需 Read，现在靠 `酒馆运行时速查.md`（且全部经过本机实机探测）。

新工具不替代三件套，而是把三件套的能力开放给「外部 AI 代理」，让 AI 可以直接读取和操作酒馆。
