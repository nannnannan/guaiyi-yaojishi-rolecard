# 概念·物品·第二职业转职凭证（事件["E248","E254"]）

- 类别：物品；蓝星任务线最终奖励的、开启第二职业的转职凭证——一枚乌鸦臂章，上刻疑似「流逝」的神秘学符文，须回黑暗世界方能开启。
- 事实门槛：E248说明第二职业转职凭证是蓝星任务线的最终奖赏（须像当年成为夜医一样需要特殊证明）；E254在全球核袭拦截结算中（任务线阶段性奖励：等级+2、黑颅币+20、特殊传奇职业转职凭证x1）实际入手乌鸦臂章。未拿到前不得引用。
- 定义：蓝星任务线终结后，系统发放的转职凭证——一枚看似有些年岁的臂章，正面雕满华丽不可解的花纹，风格不类地狱、反而像喵喵与羽毛笔所在破碎世界的雕文（林恩在羽毛笔书籍扉页见过类似纹路），其中一角像是某种代表"流逝"的神秘学符文。它不像地狱风格，需凭它回黑暗世界（或相应开启流程）完成第二职业转职。
- 来源：E254全球核袭拦截结算时系统发放任务线阶段性奖励（等级+2、黑颅币+20、特殊传奇职业转职凭证x1），后续奖励需完成第一阶段最终目标；林恩对照第一次转职（夜医任务线）回忆转职流程，明白第二职业同样需要特殊证明；臂章的乌鸦意象与"流逝"符文成为其神秘血统的锚点。
- 机制：①获取：完成蓝星任务线最终目标后入手；②外观：乌鸦臂章+「流逝」状雕文（像破碎世界雕文而非地狱风格）；③开启：需回黑暗世界/满足转职条件方可激活第二职业；④用途：在现职业之上开辟第二职业线（与夜医并行的新成长轴）。
- 补充事实：臂章"不像地狱风格"反而是最大线索——林恩在羽毛笔书籍扉页见过的破碎世界雕文、喵喵与羽毛笔所在的文明，正是与"乌鸦/流逝"意象相符的另一个力量体系（v0.11已铺垫的跨世界线索）；"流逝"符文与E265公海禁地（旧日/时间）的暗合未被文本证实，但足以作为世界观层面的钩子。它是蓝星任务线的最终奖赏，意味着"蓝星线"本身就是一个可以走到底的职业级任务链，而非单纯的家园支线。
- 限制与代价：不能当场开启、需回黑暗世界；是蓝星任务线最终奖励、稀有唯一；转职条件未标明。
- 补充细节：转职凭证的"乌鸦臂章"外观与【传说左轮】【渡鸦启蒙神话】（v0.11既有条目）共享同一乌鸦母题——羽毛笔所在文明的雕文、喵喵的破碎世界、以及"流逝"符文，三者在世界观里都是"曾经存在的更高文明"留下的指纹；林恩"记得第一次转职时得到夜医任务线"的对照，暗示第二职业同样会开出全新的任务链与世界入口，而"须回黑暗世界"这个条件则把玩家从蓝星家庭线拽回地狱主线，是S35向后段（旧日/公海/门）过渡的钩子。
