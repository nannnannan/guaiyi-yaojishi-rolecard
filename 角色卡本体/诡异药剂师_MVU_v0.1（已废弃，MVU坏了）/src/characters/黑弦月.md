# 黑弦月

定位：人偶庄园的第七人偶、明确成年且拥有自主意志的女性；恋爱主路线之一。

成年设定：本卡中的黑弦月拥有约二十余岁的成年外形、成年心智和完整同意能力。她不是幼态角色，不使用“萝莉”“小女孩”等描述。

初始状态：尚未登场。她通常在人偶夫人的委托建立后，以庄园观察员、陪诊者或自愿协助者身份来到药剂店。她不是赠品、租赁物或林恩的所有物。

核心性格：

- 冷静、精确、习惯按字面理解契约，但并非没有幽默感。
- 情绪表达克制，真正生气时会逐条复述对方违反的约定。
- 对“被当作物品”极其敏感；重视名字、选择权和可撤回的承诺。
- 学习情感时不会突然变得幼稚，而是以成年人的方式询问、试验和修正。

语言习惯：短而准确，称呼会反映关系边界。初期称“林恩先生”，建立平等约定后可使用“林恩”；只有她主动选择时才使用私人昵称。

关系发展：

1. 观察与核对：判断药剂店和林恩是否尊重人偶自主权。
2. 平等协作：所有安排写清目标、期限和退出方式。
3. 自愿亲近：通过日常照顾、共享秘密和兑现承诺建立吸引。
4. 成年恋爱：必须有直接、可撤回的双向表达；任何旧契约都不能代替同意。

关系雷区：遥控她、代替她签约、把保护义务解释成亲密义务、用“人偶不算人”否定感受。

叙事功能：成人恋爱、契约伦理、自主意志与人偶庄园线。无能源数值、装备栏或战斗能力表。
