# 《诡异药剂师：血锯药剂店》v0.1

这是一个面向 SillyTavern 1.17.0 与酒馆助手 4.8.19 的 MVU Zod 角色卡工程。

v0.1 只完成七名核心角色、基础世界观、关系主线与轻量病例流程：

- 左左
- 血锯
- 血衣女士
- 小小
- 人偶夫人
- 爱丽丝
- 黑弦月

本版本不包含战斗系统、等级、阶位、战斗属性、装备、库存、货币或经营模拟。临时病患可以作为病例出现，但不会建立第八份核心角色档案或关系变量。

## 运行依赖

- 宿主：SillyTavern 1.17.0
- 必需扩展：酒馆助手 / JS-Slash-Runner 4.8.19
- 卡内脚本：MVU 加载器、Zod schema
- 远程运行时：
  - `MagicalAstrogy/MagVarUpdate@b42817925d0391c15fa242a8238d2bbe28eb6319/artifact/bundle.js`
  - `StageDog/tavern_resource@7f29257de3ffbd83d63bc37ca09f4d4ecad6ca0f/dist/util/mvu_zod.js`
- CDN 策略：`cdn.jsdelivr.net` 主源，`testingcf.jsdelivr.net` 备用源

卡片无需玩家单独安装 Zod。Zod 由酒馆助手提供；卡内 schema 复用同一个全局实例。

## 构建与校验

在本目录运行：

```powershell
node tools/build.mjs
node tools/validate.mjs
```

生成物：

`dist/诡异药剂师_血锯药剂店_v0.1.json`

当前生成物属于“离线验证通过的候选版”。导入真实 SillyTavern 后，仍应新开聊天确认：初始变量、同轮 JSON Patch、状态栏双页切换、正则隐藏变量块与远程加载器均正常工作。真实宿主验收前，不把离线检查表述为运行验收。

## 设计边界

- 玩家扮演 20 岁的林恩；AI 不替林恩说话、行动、选择或书写内心。
- 玩家对林恩的声明、动作、判断和治疗方案是当前叙事的最高事实。
- 七名角色按剧情自然登场，不在开局同时聚齐。
- 关系以恋爱体验为主，但 NPC 保持自主、边界和拒绝权。
- 成人内容只在明确成年、双方清晰同意、情境自然成立时出现。
- 小小固定为非性伙伴；爱丽丝固定为非性家人；血锯固定为师徒。
- 左左只有形成独立且明确成年的人格与形态后，才可能进入成人关系。
- 黑弦月在本卡中明确为成年外形、成年心智和自主意志的人偶。
