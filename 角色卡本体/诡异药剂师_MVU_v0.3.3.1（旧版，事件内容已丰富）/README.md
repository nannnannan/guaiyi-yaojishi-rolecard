# 《诡异药剂师》v0.3.3.1

这是面向SillyTavern 1.17.0与酒馆助手4.8.19的MVU Zod角色卡工程。v0.3.3.1是v0.32的事件衔接补丁版：开场白仍为小说第1-4章血娃娃剧情原文摘抄（正文逐字未改），开场后E01处于收尾活跃态、E02未触发；事件衔接从关键词蓝灯触发改为**常驻注入**——12对事件的剧情引子统一放进常驻「自主世界事件调度」条目，按锚点状态用EJS只渲染当前待衔接的一对，各对触发时机以自带「触发时机」为准；状态栏新增手动「推进」按钮作为兜底，锚点链就绪时禁止原创来客占位。内容范围截至第1至149章阶段1。v1.0以前仅内部使用，不公开发布；卡按开源标准制作，玩家主权优先。

## 本版内容

- 开场白：小说原文摘抄（第1章至第4章），覆盖系统觉醒、血锯离店、血娃娃上门诊疗、右眼抵押、隐藏任务"血娃娃找妈妈"触发（完成度2%）。开场后E01处于收尾活跃态（诊疗已完成、寻母线索待处置），E02未触发；玩家推进或点击状态栏「推进」按钮后，E02才进入预兆。
- 八名主要角色：左左、血锯、血衣女士、小小、人偶夫人、泰坦头颅、巫神头颅、小宝贝。
- 每人六个源码组件，按事件状态用EJS条件分段呈现阶段人设。
- 六类势力、三套世界机制、五处关键地点、十二个自主事件锚点（E01至E12）。
- 事件衔接常驻化：`src/prompts/mainline.md` 收录12对「下一事件引入」剧情引子，EJS门控（前一事件完成/变形/取消，或活跃且收尾为true；后一事件未触发/预兆时渲染），各对触发时机以自带「触发时机」为准、未满足不得启动；锚点带「收尾」标记（主体完成、只差玩家推进时置true）；另设按状态定位的事件上下文窗口（前后各3事件摘要）与构建生成的事件详情窗口（当前±1事件详情，不依赖关键词、不开递归）；配合「衔接优先于原创」硬规则与状态栏手动「推进」按钮，解决开场后AI自创来客或提前启动下一事件的问题。
- 纯事件驱动时间线：不记录天数。
- 系统任务+图鉴轻量版；林恩按原文为17岁、等级2。
- 七根MVU结构；四页状态栏（当前状态、人物关系、世界事件、系统）。
- 恶堕值=女性角色亲密接受度：全部女性角色建变量、初始0、不锁定；小小为幼态角色，恶堕恒为0。

血锯、小小、泰坦头颅、巫神头颅和小宝贝固定非恋爱，吸引恒为0。八名主要角色不会永久死亡或彻底退出。

本版不包含战斗数值体系、装备栏、库存、货币经营结算、天数计数或旧聊天迁移。

## 维护入口

- `创作规划.yaml`：需求和内容边界。
- `contract.json`：结构契约与验收条件。
- `manifest.json`：稳定ID、版本、文件映射和运行依赖。
- `src/worldbook.json`：世界书注册表。
- `src/prompts/opening_source.txt`：开场白原文源（修改开场白须同步此源并保持逐字一致）。
- `src/prompts/first_message.md`：生成的开场白（原文+占位符+initvar块）。
- `src/prompts/mainline.md`：自主世界事件调度与12对常驻即时衔接段（EJS按状态渲染）。
- `src/characters/`：八名主要角色的六组件源码。
- `src/events/`：十二个事件锚点（蓝灯详情，含「下一事件引入」段）。
- `src/factions/`、`src/mechanisms/`、`src/locations/`：世界内容。
- `src/initial_variables.json`、`src/scripts/schema.js`、`src/prompts/mvu_*`、`src/ui/status.html`：MVU整链。
- `tools/build.mjs`、`tools/validate.mjs`：构建与离线验证。

不要直接编辑`dist/`，应修改源码后重新构建。
