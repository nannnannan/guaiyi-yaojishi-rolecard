# 《诡异药剂师》v0.31 AI接手指南

## 适用范围

本文件适用于`诡异药剂师_MVU_v0.31/`整个目录。该目录是完整可构建的`chara_card_v3 / 3.0`、MVU Zod角色卡工程，正式候选产物为`dist/诡异药剂师_v0.31.json`。

不要手改`dist/`。所有修改进入维护源码和配置，再运行构建。v0.1、v0.2、v0.3目录与产物必须保持不变。

## 权威顺序

1. 用户当前明确要求。
2. `创作规划.yaml`。
3. `contract.json`。
4. `manifest.json`。
5. `profile.json`。
6. `src/`维护源码。
7. `dist/`生成候选产物。

内容范围变化先更新`创作规划.yaml`，结构要求同步到`contract.json`，文件映射和版本同步到`manifest.json`。

## 本版定位

- v0.31以第1至149章阶段1为内容边界，从v0.3源码重置世界书、游玩规则、角色阶段人设与开场白。
- 玩家扮演20岁的林恩，开场于系统觉醒日傍晚、血娃娃敲门之前。
- 版本号只用于分段制作与测试；E12收束后不设计续接。
- 卡按开源标准制作：不预设关系结局，选择权全部留给玩家。当前不公测。

## 最高目标与叙事主权

- 最终目标是逐版本还原整部小说的世界观与人物，让玩家扮演20岁的林恩自由行动，格局最终指向紫罗兰大君级长线。
- 玩家独占林恩的对白、主动动作、决定、意图、判断、记忆和内心。AI只能写环境、系统和NPC；需要林恩决定时停笔。
- 玩家明确写出的林恩行动、诊断和治疗方案按其陈述成立，不追加检定或隐藏失败。
- 未登场人物不能因世界书存在而瞬移、提前相识或获得未来知识。
- 原作事件是默认因果，不是必须复刻的剧本；因果失效时事件变形，不回轨。

## 主要角色（八人）

左左、血锯、血衣女士、小小、人偶夫人、泰坦头颅、巫神头颅、小宝贝。

每人维护六个文件：`角色速览.md`、`基础信息.md`、`性格调色盘.md`、`三面性.md`、`多阶段人设.md`、`二次解释.md`。组件内容按事件状态用EJS条件分段：未接触阶段不呈现最终版人设。

爱丽丝、黑弦月完全移除出本版；"黑弦月"仅允许以"尚未到货/租借在途"语境在E12与庄园词条中出现。

`src/worldbook.json`在运行时把每人的六个组件合并成一条`[角色]姓名`蓝灯。常驻`[角色索引]八人精简路由`只含姓名、别名、边界和解锁规则。

固定非恋爱且吸引恒为0：血锯、小小、泰坦头颅、巫神头颅、小宝贝。左左在独立成年形态和心智明确前吸引也为0。恶堕值=女性角色亲密接受度，全部女性角色建变量、初始0、不锁定；阶段1内事件可自然推进的仅血衣女士与人偶夫人；小小为幼态角色，恶堕恒为0，禁止成人化描述。

八名主要角色受保护，不会永久死亡或彻底退出。允许状态只有活动、受伤、失联、受困、休眠、暂离、敌对。

## 次要人物原则

情报员024、械魔、噬心魔、玥玥等次要人物不单独建卡，并入对应势力、地点与事件词条并用关键词触发。临时人物只记录身份、可见特征、行为、与林恩的当轮关系和剧情功能。

## 世界书维护

世界书注册表是`src/worldbook.json`。条目前缀包括`[核心]`、`[角色索引]`、`[机制]`、`[势力]`、`[地点]`、`[角色]`、`[事件]`、`[initvar]`、`[mvu_update]`。

每个新增或修改条目必须同时显式设置：

- `extensions.exclude_recursion: true`
- `extensions.prevent_recursion: true`

不要用`delay_until_recursion`代替。小设定（魂灯、门槛、价目表、信使等）不单独建条目，融入势力、地点与事件。

主要角色、势力、机制、地点和事件使用精确关键词。稳定数字ID不可重复。事件蓝灯通过E01至E12稳定ID触发。

## 事件契约

- 五阶段固定为S0至S4；十二个锚点状态固定为未触发、预兆、活跃、变形、完成、取消。
- 时间线纯事件驱动，不维护天数计数。E01完成后E02才可能进入预兆，后续锚点按依赖顺序解锁。
- 同时只能有一条重大事件活跃或变形。普通诊疗和原创日常不占重大事件位。
- 林恩缺席时有限演算；主要角色即将遭遇不可逆结果时停在可介入危机。
- 系统任务链（活过血夜→建立怪物客户群→覆灭魔人协会→猎头者家族绑定→转职夜医→师徒归来收束）是引导而非锁链。
- E12收束后不自动设计第149章以后的续接、循环或结局。

## MVU整链

根变量精确为：`元数据`、`世界`、`林恩`、`事件`、`关系`、`角色关系`、`系统`。没有`病例`根，没有天数计数。

关系根八人各维护：解锁、在场、生存状态、位置、处境、关系类型、人物阶段、好感、信赖、戒备、吸引、关系创伤、恶堕、可见迹象、边界、关键记忆、最近互动。数值统一0至100。

林恩根维护轻量成长（等级、技能、成就、图鉴已解锁）；系统根维护任务链、图鉴、成就与提示。无商城、库存、货币与经营结算。

任何字段变化必须沿整条链同步：

`src/initial_variables.json` → `src/scripts/schema.js` → `src/prompts/mvu_update_rules.md` → `src/prompts/mvu_output_format.md` → `src/ui/status.html` → `contract.json` → `tools/validate.mjs`

更新协议固定为`UpdateVariable.JSONPatch`。v0.31只保证新聊天，不迁移旧聊天。

## 状态栏兼容

`src/ui/status.html`是死界通用四页界面：当前状态、人物关系、世界事件、系统。必须保留：

- 只显示已解锁人物。
- 未实际接触时只显示姓名与状态。
- 实际接触后显示数值条、文字判断和详情（好感/信赖/戒备/吸引/创伤/恶堕）。
- 显示唯一活跃事件、一个近期预兆和最近结果。
- 系统页展示当前任务、任务阶段、成长记录、图鉴、成就与恶堕值。
- 轻微魂灯呼吸、蓝光和紧急动效。
- `prefers-reduced-motion`。
- 页签键盘操作和移动端布局。
- 安全文本渲染，不使用`innerHTML`或`eval`。
- 双路径读取：`Mvu.getMvuData`与宿主`SillyTavern`聊天消息的`message.variables[swipe_id]`回退。
