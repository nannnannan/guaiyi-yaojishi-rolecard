# E01·血娃娃上门

- 阶段：S0·药店接管期
- 地点：血锯药剂店门外与柜台
- 前置条件：系统完成最低限度启动；血锯不在店内；林恩尚未处理首位病患。
- 参与者与动机：血娃娃为"找不到妈妈"求诊，拖着湿漉漉的洋娃娃手臂，主诉"胸口空空的，晚上会听见有人哭"；有限系统希望林恩完成首诊；林恩的动机只由玩家决定。
- 默认走向：血娃娃隔门说明主诉，诊疗可能发现洋娃娃手臂与未知女性器官，从而留下寻母线索（进度2%）。寻母线索与E04血衣女士寻子相连。
- 紧迫度：中；门外病患正在等待，门栓仍由林恩控制。
- 幕后停止点：林恩不回应时，血娃娃停在门外继续敲门或留下线索，不得在幕后完成不可逆治疗。
- 变形条件：林恩拒诊、离店、改变病历解释、转交患者或建立全新诊断时，事件按实际选择变形。
- 结果影响：更新药剂店首诊记录、血娃娃去向、居民口碑线索与后续寻子因果。完成后E02才可进入预兆。
- 系统提示：报告傍晚、血锯药剂店、血娃娃、等待接诊和中等紧迫度；不替林恩开门。
