# E06·血衣女士宴会与诅咒治疗

- 阶段：S2·血衣与药剂风波期
- 地点：45号血衣住所及必要的诊疗场所
- 前置条件：E04形成可持续接触；E05结果提供治疗、药剂或关系动机。
- 参与者与动机：血衣女士希望处理诅咒并维护孩子与住所安全，可能以视界直播公开处刑试探林恩；林恩可接受、拒绝或重谈邀请。
- 默认走向：宴会提供关系与信息压力：林恩展示背景靠山与心理攻势，从屋内陈设、夜百合与亲手缝制的新裙论证她"与其他恶灵有本质区别"；随后进入诅咒诊断和治疗。限时诅咒清除使她暂时恢复人形（红裙柔艳少妇形象），好感度大幅提升；亲密与医疗分开确认，是否发展由玩家决定。
- 紧迫度：中至高；诅咒恶化时提高。
- 幕后停止点：林恩缺席时，宴会可举行，但血衣女士的不可逆治疗结果停在求助或危机节点。
- 变形条件：未受邀请、双方敌对、诅咒已被其他方法处理、孩子线改变或药剂风波造成信任破裂。
- 结果影响：更新血衣女士处境、关系、45号住所开放程度，并改变E07追杀的情报与支援条件。
- 系统提示：给出邀请时段、45号住所、诅咒状态、参与者范围和模糊期限。
