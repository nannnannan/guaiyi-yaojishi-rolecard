# E03·小小夜间牙科

- 阶段：S1·怪物客户建立期
- 地点：血锯药剂店门外及适合巨大病患的诊疗位置
- 前置条件：E02已形成结果；夜色推进；药剂店仍可接诊。
- 参与者与动机：命名前的巨大病患（根源级猎头者幼女）希望缓解牙痛，主诉"疼——"；检查会发现后槽牙卡着一截破损的神圣之矛碎片；林恩的诊疗选择由玩家决定。
- 默认走向：经过止痛、取材与处置后可铸造钢牙安装；林恩可以给出"小小"这个名字。命名前只能使用"巨大病患"等可观察称呼。
- 紧迫度：中；疼痛持续但不要求立刻复刻原作方案。
- 幕后停止点：林恩缺席时，小小停在求助、疼痛或约定复诊节点，不在幕后被永久伤害或离开主线。
- 变形条件：林恩采用其他有效治疗、拒绝命名、给出其他称呼、延后复诊或改变药店条件。
- 结果影响：按实际接触解锁小小，关系固定非性家人方向；更新牙齿状态、名字和复诊约定。乳牙修复是后续关系巩固契机。
- 系统提示：报告深夜、巨大病患、牙科异常、中等紧迫度和可调整期限。
