# 《诡异药剂师》v0.31

这是面向SillyTavern 1.17.0与酒馆助手4.8.19的MVU Zod角色卡工程。v0.31从v0.3非破坏性复制并重置世界书、游玩规则、角色阶段人设与开场白，内容范围截至第1至149章阶段1。v1.0以前仅内部使用，不公开发布；卡按开源标准制作，玩家主权优先。

## 本版内容

- 八名主要角色：左左、血锯、血衣女士、小小、人偶夫人、泰坦头颅、巫神头颅、小宝贝。
- 每人六个源码组件，按事件状态用EJS条件分段呈现阶段人设，未接触阶段不展示最终版资料。
- 六类势力、三套世界机制、五处关键地点、十二个自主事件锚点（E01至E12）。
- 纯事件驱动时间线：不记录天数，E01完成后E02才可能进入预兆。
- 系统任务+图鉴轻量版：任务发布、成就、图鉴与吐槽；等级/技能仅作轻量成长记录。
- 七根MVU结构：元数据、世界、林恩、事件、关系、角色关系、系统。
- 四页状态栏：当前状态、人物关系、世界事件、系统。
- 开场白从系统觉醒写到血娃娃敲门，按文风提示词重写；文风规范不写入世界书（由所有者做成酒馆预设）。
- 恶堕值=女性角色亲密接受度：全部女性角色建变量、初始0、不锁定；阶段1内事件可自然推进的仅血衣女士与人偶夫人；小小为幼态角色，恶堕恒为0。

血锯、小小、泰坦头颅、巫神头颅和小宝贝固定非恋爱，吸引恒为0。八名主要角色不会永久死亡或彻底退出，但可以受伤、失联、受困、休眠、暂离或敌对。

本版不包含战斗数值、等级体系、装备、库存、货币、经营模拟、天数计数或v0.2/v0.3聊天迁移。

## 维护入口

- `创作规划.yaml`：需求和内容边界。
- `contract.json`：结构契约与验收条件。
- `manifest.json`：稳定ID、版本、文件映射和运行依赖。
- `src/worldbook.json`：世界书注册表。
- `src/characters/`：八名主要角色的六组件源码。
- `src/events/`：十二个事件锚点。
- `src/factions/`、`src/mechanisms/`、`src/locations/`：世界内容（配角并入词条）。
- `src/initial_variables.json`、`src/scripts/schema.js`、`src/prompts/mvu_*`、`src/ui/status.html`：MVU整链。
- `tools/build.mjs`、`tools/validate.mjs`：构建与离线验证。

不要直接编辑`dist/`，应修改源码后重新构建。
