# 概念·场景·地下大殿与炽天使雕像庇护所（事件["E266","E267"]）

- 类别：场景；弥赛亚与教士坚守的最后净土。
- 事实门槛：仅在对应事件（E266/E267）进入"完成"或"变形"且正文出现该事实时方可引用；"预兆""活跃"不得提前兑现。
- 定义：地下大殿与炽天使雕像庇护所是圣城沦陷后圣域一方最后的坚守之地：在圣彼得中心广场等核心区被污染、海嗣横行之后，弥赛亚（圣女）与忠诚的教士们退入圣城地下的隐蔽大殿。大殿中央矗立着一尊炽天使雕像——这尊雕像不仅是圣域的信仰象征，更携带着炽天使血脉的圣性残余，在污染时代成为庇护所的锚点：只要雕像矗立，大殿内便维持着相对安全的圣光场域，污染被压制、海嗣难以深入。弥赛亚与教士们以此为最后的净土，守护圣物、维持仪轨、等待转机。它是E266-267期间圣域抵抗的核心据点：对外是沦陷圣城中最后一块"还算活着"的圣域，对内则是圣女与教士们以命相守的信仰堡垒——雕像在，净土就在；雕像若被污染或摧毁，最后的庇护也将不复存在。
- 来源：E266圣城沦陷后弥赛亚与教士退守地下大殿；E267炽天使雕像庇护所的坚守与利用。
- 机制：①位置：圣城地下的隐蔽大殿；②核心：中央炽天使雕像（炽天使血脉圣性残余）；③场域：雕像维持圣光庇护，压制污染、阻挡海嗣深入；④人员：弥赛亚与教士坚守；⑤职能：守护圣物、维持仪轨、等待转机；⑥命门：雕像即庇护所的存续核心。
- 补充事实：教士们在大殿里点灯的方式和往常一样虔诚——只是如今每盏灯亮起，都像在跟头顶那片黑下来的圣城较劲。
- 限制与代价：庇护所依赖雕像圣性，长期消耗会削弱场域；雕像一旦被污染或摧毁，庇护所随即失守；地下空间补给有限，围困越久越危险。
- 未知项：雕像的圣性来源与剩余量、庇护所通往外界的暗道、弥赛亚在此地准备的后手均未知。
