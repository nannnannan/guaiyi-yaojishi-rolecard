# 概念·机制·血肉牢笼（事件["E297"]）

- 类别：机制；血肉瘟疫对机械的「水牢」式囚禁——断链/封视听/蚀处理器的三重封锁。（与C943瘟疫、C946孤立个体化互证：牢笼是瘟疫的应用形态，孤立是牢笼的心理后果。）
- 事实门槛：仅在E297进入"完成"或"变形"且正文实际出现"血肉牢笼、水牢、断链、封视听、蚀处理器"等事实时方可引用；"预兆""活跃"不得提前兑现牢笼的破拆方式与持续时间。
- 定义：血肉牢笼，是血肉瘟疫（精改，C943）对机械体形成的「水牢」式囚禁结构——以血肉滋生包裹机械体，实现断链（与智脑、蜂巢、机械集群的链接中断）、封视听（信号与感知被血肉封死）、蚀处理器（血肉触手侵蚀处理器核心）三重封锁。E297银色幻想坠落的瞬间，瘟疫雾化吞没她与未来得及上传的机械体——血肉滋生、触手覆盖处理器、信号被完全截断——她第一次感受到脱离集体、被整个世界抛弃般的孤独（C946）。"水牢"的比喻精妙：水牢不杀人、不破坏，只隔绝——把目标泡在无法挣脱的介质里，让其在感官尽失、链接尽断的处境中独自承受。对机械神教而言，血肉牢笼的杀伤不在物理而在系统：机械体的存在依赖集体网络（意识上传、蜂巢链接、集群协同），牢笼切断的正是这份"存在感"——被囚者没有死，但已被从集体中剥离，成为孤岛。林恩用这份牢笼捕获银色幻想，随后开启"拖行剧本"（C948太阳能梦想）——牢笼既是捕获手段，也是情感手术台。
- 来源：E297瘟疫雾化吞没银色幻想——血肉滋生、触手覆盖处理器、信号完全截断、与智脑/蜂巢/机械集群链接一齐中断（"水牢"式囚禁）。
- 机制：①来源：血肉瘟疫（精改）雾化（C943）；②结构：血肉滋生包裹（水牢式）；③封锁三重：断链（集体网络中断）+封视听（感知封死）+蚀处理器（核心侵蚀）；④效果：无法意识上传、无法呼救、无法感知外界；⑤心理后果：孤立个体化（C946）——脱离集体的孤独；⑥维持：血肉持续增生（随时间加固）。
- 补充事实：牢笼中银色幻想的挣扎——"她在黑暗中挣扎破局，却决定绝不认输——她承载着智械文明的未来，生命从一开始就不属于她自己"；她清除一小部分禁锢睁开眼，看到的是"一台锈迹斑斑的冰箱拖着她艰难前行"（拖行剧本开场）——牢笼的出口通向的不是自由，而是林恩编好的剧本。
- 限制与代价：牢笼依赖瘟疫供给（血肉耗尽则松脱）；对根源级/高位机械效果有限（银色幻想可局部清除禁锢）；血肉牢笼的包裹对"拖行剧本"是必要条件——太早破笼则剧本崩盘；长期囚禁可能引发被囚者的极端反应。
- 未知项：血肉牢笼的自我增殖上限、能否对根源级机体（万机之神）生效、牢笼内的意识是否仍能被外部侦测，均未展开。
- 禁止外推：林恩的对白、动作与选择由玩家主权独占；禁止把血肉牢笼写成永久囚禁或可无限复用的常规技能；"水牢"式定性按原文保留。
