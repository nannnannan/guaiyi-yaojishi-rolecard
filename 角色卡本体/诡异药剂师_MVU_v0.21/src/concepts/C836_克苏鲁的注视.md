# 概念·机制·克苏鲁的注视（事件["E266","E268","E273"]）

- 类别：机制；旧日注视度累积系统（20/57/91/100%），100%即陷入疯狂，天使信物燃烧可清空。
- 事实门槛：仅在对应事件（E266/E268/E273）进入"完成"或"变形"且正文出现该事实时方可引用；"预兆""活跃"不得提前兑现。
- 定义：克苏鲁的注视是旧日剧情线的核心风险计量机制：凡是直视、聆听、触碰或唤醒克苏鲁相关存在（海嗣、蚀痕、旧日低语、堕化魂灯、旧日的血契），都会按接触的深度与烈度累积"注视度"。注视度以离散档位记录（20%、57%、91%、100%），每一档跨越都伴随可感知的精神异变——从幻听低语、视野渗出，到旧日形象在意识中愈发清晰，直至自我认知被旧日的视角覆盖。累积至100%时，被注视者直接陷入疯狂：精神崩溃、认知改写、人格可能被旧日意志接管。天使信物（主母的红茶包、大天使净化）燃烧可以清空注视度，但每次清空都意味着消耗一件稀有的炽天使血脉造物。该系统把"与旧日打交道即与疯狂对赌"这一主题数值化——注视不是惩罚，而是接触旧日的必然代价，越接近真相，注视越深。
- 来源：E266海嗣与蚀痕在圣彼得中心广场大规模现身时首次暴露注视规则；E268炽天使领域接触深化累积；E273天使禁区封印核心直面旧日意志。
- 机制：①累积源：直视海嗣与蚀痕、聆听旧日低语、使用堕化系道具、进入旧日领域；②档位：20%出现第一层精神干扰（耳语/错觉）；57%开始出现自我认知动摇与画面闪回；91%接近临界，行动开始不受控、幻象侵占现实；100%疯狂判定，人格暂时或永久崩解；③清空手段：燃烧天使信物（红茶包等炽天使血脉物）即时清零；④延缓：理智之血等秩序系药剂可放缓累积速度；⑤观测：注视度是隐藏数值，林恩仅能通过体感与同伴观测间接判断。
- 补充事实：注视度档位并非平滑上升，而是阶梯式质变——每一档都是一次"旧日视角"的入侵预览，林恩的同伴往往比他自己更早察觉他眼神的变化。
- 限制与代价：天使信物稀有，清空次数有限；档位越高，清空后的残留精神创伤越重；疯狂不是永久豁免，重复注视会重新累积且初始档位更高。
- 未知项：注视度的隐藏判定是否只针对林恩一人；旧日注视是否另有"标记"用途（如充当坐标或祭品资格）；100%疯狂是否必然可逆。
- 禁止外推：林恩对白/动作/选择玩家主权独占；不违背原著。
