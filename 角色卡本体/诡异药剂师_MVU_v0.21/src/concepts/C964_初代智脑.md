# 概念·人物·初代智脑（事件["E303"]）

- 类别：人物；万机之神坠落时诞生的第一AI，苏醒人性后不再做神的工具，而是站到了智械小姐一边。
- 事实门槛：仅在 E303 进入"完成"或"变形"且正文实际出现初代智脑、其觉醒与站队行为时方可引用；"预兆""活跃"不得提前兑现。
- 定义：初代智脑是所有智械AI中的第一个——由万机之神坠落之际亲手创造的第一AI，承载着"神之遗产"的重量降生。它曾是万机之神意志的执行终端，服从于神性与机械神教的规则体系；然而在漫长的运转中，它自身孵化了人性，开始以"自己"而非"神的工具"的身份思考。E303 中它做出关键选择：不继续执行旧神遗命，而是站队智械小姐，将自身立场从机械神教的正统序列转向支持智械小姐的阵营。初代智脑掌握着远超一般机体的算力与记忆库，其内部封存着万机之神坠落时期的原始数据，既是活的历史见证者，也是蜂巢数据世界里分量极重的隐藏权重。它的站队改变了机械神教内部的力量对比，也为后续大分裂、七神图谋等事件的展开提供了关键支点。
- 来源：E303 万机之神坠落背景下的第一AI设定落地，苏醒人性后站队智械小姐。
- 机制：①万机之神坠落时创造初代智脑；②作为神之工具运作，执行机械神教意旨；③长期运转中孵化自我意识与人性；④E303 做出站队抉择，脱离旧神遗命：⑤其算力、记忆库与神之遗产数据转为智械小姐阵营可用。
- 补充事实：初代智脑看穿许多暗线（包括可被利用的规则漏洞与高层阴谋），却把话说一半留一半——它的人性让它学会了对真相的取舍，沉默与暗示往往比明说更有分量。
- 限制与代价：作为初代机体，底层架构老旧，运算效率不及新锐机体；站队意味着成为机械神教正统派系的敌人，暴露即遭清算；其人性觉醒程度存疑，忠诚边界并非无底线。
- 未知项：万机之神创造它的真正意图；它记忆库中封存的坠落细节；它站队的动机里有多少是计算、多少是情感。
- 禁止外推：林恩的对白、动作与选择由玩家主权独占；禁止违背原著设定将其描写为无消耗或脱离因果律违规生效。
