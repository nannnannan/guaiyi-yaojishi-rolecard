# 概念·物品·旧日的血契（事件["E270","E272","E274"]）

- 类别：物品；骨制火炬：记载旧日大起义；安抚/激怒旧日情绪、唤醒克苏鲁信物。
- 事实门槛：仅在对应事件（E270/E272/E274）进入"完成"或"变形"且正文出现该事实时方可引用；"预兆""活跃"不得提前兑现。
- 定义：旧日的血契是一柄以骨制成的火炬形器物，是旧日（克苏鲁）侧最核心的遗物之一。其表面以某种血契铭文记载着旧日大起义的历史（与E274旧日时代幻象呼应：那段被镇压前的反抗史被刻在这柄骨制火炬上）。血契的功能面向旧日情绪与意志：其一，安抚/激怒——血契可以抚慰旧日的情绪（平息暴怒、延缓苏醒、压制污染冲动），也可以反向激怒旧日（挑衅、催醒、放大其意志暴动），是一柄双向的情绪闸门；其二，唤醒克苏鲁信物——血契本身即唤醒克苏鲁的关键信物，当唤醒仪式或条件满足时，血契可被用作召唤/唤醒旧日本体意志的媒介。这使它成为旧日阵营与封印方都在争夺的战略级物品：持有它，既能安抚旧日争取时间，也能在必要时以它为钥匙掀起旧日的觉醒。血契的"契约"之名，暗示唤醒行为本身即与旧日立约。
- 来源：E270血契记载旧日大起义；E272安抚/激怒旧日情绪的功能展开；E274作为唤醒克苏鲁信物登场。
- 机制：①形态：骨制火炬，刻血契铭文；②记载：铭文录有旧日大起义史；③安抚：抚慰旧日情绪、延缓苏醒、压制污染；④激怒：挑衅放大旧日意志、加速暴动；⑤信物：作为唤醒克苏鲁的关键媒介；⑥争夺：旧日与封印双方皆欲得之。
- 补充事实：骨制火炬安静时像根枯骨，只有在旧日的情绪翻涌时才会亮——火苗的朝向永远指着克苏鲁沉睡的方向。
- 限制与代价：安抚与激怒皆不可控风险，用错方向即引火烧身；唤醒功能不可逆，动用即涉旧日命运；血契本身携带重度旧日污染与注视累积。
- 未知项：血契的制作年代与制作者、铭文是否还有未解读内容、是否存在多柄血契均未知。
