# 概念·人物·恶面堕天使与疫医信仰源头（事件["E111","E112","E351","E357","E358"]）

- 类别：人物
- 事实门槛：仅在对应事件（E111/E112）进入“完成”或“变形”，且聊天正文明确出现该事实时方可引用；“预兆”“活跃”“取消”不得提前兑现。 本版新增事件（E351/E357/E358）按相同门槛生效。
- 定义：血肉神教疫医阵营背后真正供奉的母神，主母坠入地狱后的混乱邪恶暗面人格。
- 来源：E111虚空黑羽降临拯救315灵魂容器，至E112被林恩以M狂灌后被善面锁回裂隙。 E351确认疫医因白衣撤离而陷入混乱并遭追剿；E357疫医将林恩诱入旧神埋骨地陷阱并试图剥离其神性与灵魂，恶面堕天使意识短暂压过林恩；E358恶面堕天使现身向疫医索取全部生命，疫医面临反噬濒临崩溃。
- 机制：十二翼黑羽遮天蔽日，周身散发至高无上的深渊神威。为主母坠入地狱被诅咒侵蚀分裂出的混乱邪恶人格，亲手开创并庇护疫医教派。被林恩不死巨头死咬手腕狂灌以M快感冲击后娇喘痉挛，最终被主母善面夺权镇压回神魂裂隙。 恶面堕天使不仅是疫医的信仰图腾，更是其无法掌控的残酷吞噬者。在埋骨地陷阱中，疫医企图通过活化病变与阵法抽离林恩的一切，却引来恶面堕天使对疫医自身的无情索命与威慑；疫医狂热神学在绝对残暴面前转化为本能恐惧与内部分崩离析。
- 限制与代价：与主母善面同源同体，在主母善面本尊被强烈唤醒暴走时会被强行剥夺主导权锁回裂隙。 恶面堕天使的意识显现伴随狂乱与吞噬本能，无法受疫医意志或凡俗契约驱使；疫医的盲信不能消除自身被当作食粮反噬的致命代价。
- 未知项：堕天使与深渊意志达成的万年密约具体内容不详。 疫医在埋骨地外的剩余据点规模，恶面堕天使最终索命后的去向与信仰断绝程度。
- 禁止外推：林恩的对白、动作与选择由玩家主权独占；禁止违背原著设定将其描写为无消耗或脱离因果律违规生效。 不得把恶面堕天使写成听命于疫医的傀儡，不得把疫医恐惧误写为坚定信仰，恶堕与意识交替不得越权替林恩定论。
