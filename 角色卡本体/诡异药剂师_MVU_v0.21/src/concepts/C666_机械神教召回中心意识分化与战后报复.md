# 概念·势力·机械神教召回中心、意识分化与战后报复（事件["E132","E133","E134","E141","E319","E331","E332","E340"]）

- 类别：势力
- 事实门槛：对应事件完成或变形且正文实际出现后，才引用其事实；事件中的参考经过不代替玩家选择。

- 既往定义：机械神教在根源会战失利后建立的重组与报复体系。核心不再只是万机之神聚合大量文明意识形成的单一神躯，而是重建数据召回中心、开放意识上传，把聚合意识重新分化为多个相对独立智械，使每个个体分别逼近地狱诅咒允许的力量上限，并以此筹造新的根源级机械。
- 既往来源：E132确认万机之神解除自我镇压后可从文明数据中分化陨星级舰船与灭绝者战甲，本体处于虚化空间；E133确认其能在远端分化舰群、主动切断链接并尝试重连；E134确认万机撤退，银色幻想用两次根源射击转移泰坦仇恨后机体被毁，而意识仍可能上传，机械征服转为长期任务；E141确认受创万机强行重建召回中心，任命银色幻想为临时统领并发布上传、采矿和造神命令。
- 既往机制：聚合意识曾依靠统一压制保持绝对理性，分化则把力量上限、任务和人格风险拆给多个个体。银色幻想是早期试作与万机本源子集，而非完整复制；她负责开放更多意识上传、开采地狱深层材料、建立新的机械躯体与组织秩序。那些曾被强制吞噬的意识一旦脱离压制，可能恢复独立诉求甚至反叛，因此“分化”同时是扩军方案和内战种子。万机还为银色幻想设置最高优先级的紧急折跃／意识上传限制，以阻止她接近林恩并维持控制。
- 战后报复：目标是绕过单一根源受诅咒上限、恢复机械文明军势并继续征服，而非立即返回诅咒之城决战。虚化、分化、上传、深层采矿和根源机械是同一长期链条的不同环节。当前战场曾限制其无法分化歼星级以上军势，已见舰船也非真正无限；新中心能否突破这一限制尚未得到结果。
- 既往运行边界：林恩；是否拆解缴获舰、研究上传或接触银色幻想由玩家决定。不得替玩家建立情感、赦免或处置方案。
