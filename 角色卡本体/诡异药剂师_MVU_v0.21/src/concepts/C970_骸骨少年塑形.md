# 概念·机制·骸骨少年塑形（事件["E304"]）

- 类别：机制；"这也许就是代价吧"——她画像里的少年模样，被永久维持在这具数字躯体上。
- 事实门槛：仅在 E304 进入"完成"或"变形"且正文实际出现少年形象被永久固化、代价表述等事实时方可引用；"预兆""活跃"不得提前兑现。
- 定义：骸骨少年塑形是林恩在蜂巢数据世界中形象定制的最终归宿：她以塑形机制化为梦中描绘的少年模样，而当剧情推进至 E304，这一塑形不再是随时可换的临时外衣，而是被永久锁定——"这也许就是代价吧"，她以这句话接受了：从此她在数据世界里将一直以那个少年形象存在，无法再自由切换回原来的形态。塑形的永久化意味着形象与身份权限的深度绑定：系统不再允许她修改形体参数，少年的骨骼、轮廓、气质被固化进她的数据底层，像一具由代价铸成的骸骨支撑起这具形体。它兼具双重含义：一方面是她对银色幻想梦中形象的回应与践行，让那个画像里的少年真正"活"在了数据世界；另一方面是规则层面的代价结算——越界的形象定制必须以失去自由换形权来偿还。此后林恩以少年之姿行走于蜂巢，这一形态成为她身份的一部分。
- 来源：E304 塑形永久化，林恩以"这也许就是代价吧"接受少年形态被固化。
- 机制：①林恩以塑形机制化为梦中少年形象；②触发永久化条件（如代价协议、系统结算、特殊事件）；③形象参数被锁定，写入数据底层；④换形功能对该形象失效，无法自由切换回原形；⑤少年形态与身份权限绑定，此后在数据世界以该形象行动；⑥"这也许就是代价吧"完成自我接受，塑形尘埃落定。
- 补充事实：最戳人的细节是——画像里的少年是银色幻想梦里的影子，如今影子有了骨头；永久化的那一刻，数据世界里的"他"与画像里那个少年分毫不差，仿佛她把自己的愿望铸成了固定模具。
- 限制与代价：永久失去自由换形能力；该形象无法适应部分需要原形身份的场景；若数据底层被破坏，固化形象将连带受损；代价是否仅限于换形权尚不明朗。
- 未知项：永久化的触发条件与结算标准；能否通过特殊手段解封换形权；固化形象对意识底层人格是否存在反噬。
- 禁止外推：林恩的对白、动作与选择由玩家主权独占；禁止违背原著设定将其描写为无消耗或脱离因果律违规生效。
