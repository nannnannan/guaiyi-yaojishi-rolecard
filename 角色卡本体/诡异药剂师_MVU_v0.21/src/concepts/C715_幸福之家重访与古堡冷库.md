# 概念·地点／古堡·幸福之家重访与古堡冷库（事件["E177","E178"]）

- 类别：地点／古堡
- 事实门槛：只有玩家批准地狱侧核验并实际抵达幸福之家，才可调用古堡重访事实；爱丽丝只能提供无法离堡期间观察到的间接情报，高能波动、外乡人增多和冷库活口必须与现场痕迹交叉核验。冷库中无面俘虏关于赏金、第二项任务与跨界产业的说法属于分层口供：五百万首项任务可登记为已述报酬，后续任务内容、委托方和产业规模仍待查，不能提前当成组织全貌。
- 定义：幸福之家位于离魂街尽头，是一座被地缚诅咒、家族记忆与异常生活规则共同占据的古堡。可确认区域包括庭院、会面与治疗空间、通往冷库的入口及用于拘束潜入者的低温区域。古堡既是爱丽丝无法离开的住所，也是周边召唤异常的长期观察点；冷库则把“收容敌人”与“把生物当作作物、食材”混在一起，必须按高风险拘束现场而非家庭仓储处理。
- 来源：E177确认林恩此前长期昏迷令诅咒清除供应中断，爱丽丝的地缚复发；她报告游魂巷方向数日前出现高能召唤、近期外乡人增多，多名潜入者被捕且仍有活口。E178打开冷库后确认其中存在不同形态的受拘束者和一名无面血肉人形，问询可获得针对林恩的已知任务、赏金与更大行动疑云；然而“第二项任务”和完整跨界产业没有在现场得到独立文件支持。两事件也明确古堡把生命当作可收割资源的习惯必须进入救助与问责。
- 机制：重访流程应先处理爱丽丝的地缚强度、治疗同意和替代照护，再建立冷库的双人开门、生命体征扫描、温度回调、束缚解除与证物编号。俘虏先按患者和证人分流，提供翻译、医疗、拒绝酷刑和中立记录；敌对身份不能取消基本保护。古堡空间余波可用于比对召唤方向，却不能单凭爱丽丝的感应定位蓝星。玩家可以选择不进入、让第三方救援组先行，或只封存冷库并远程问询；每条路线都要避免爱丽丝和尹依被迫承担危险角色。
- 限制与代价：地缚使爱丽丝的行动和证词范围受限，长期依赖治疗又可能形成权力不对等；家人称谓、拥抱、求助与照护均不产生亲密同意。冷库低温、束缚与古堡捕食规则可能继续伤害活口，贸然放人也可能释放敌对渗透者，因此需要隔离而非私刑。爱丽丝年龄与成人身份未核实，只能进入家人、患者与情报提供者路线。
- 未知项：古堡精确结构、冷库受拘束者总数与身份、谁下达首项任务、五百万报酬是否已经支付、第二项任务内容、无面俘虏是否故意隐瞒、古堡对潜入者造成的伤害、地缚长期治疗方案，以及爱丽丝能否在不依赖单一供给者的情况下离堡均未知。
- 禁止外推：林恩的对白、动作与选择由玩家主权独占；禁止违背原著设定将其描写为无消耗或脱离因果律违规生效。
