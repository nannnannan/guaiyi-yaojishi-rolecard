# 概念·物品·灾厄魂灯系列（事件["E267","E272","E343","E344","E345","E346"]）

- 类别：物品
- 事实门槛：对应事件完成或变形且正文实际出现后，才引用其事实；事件中的参考经过不代替玩家选择。

- 既往定义：灾厄魂灯系列是炽天使魂灯被神的方程式堕化后衍生的一整类"堕化魂灯"。它们保留魂灯的外形与供能结构，但内核已被替换为灾厄系异常属性。其核心机制是"灾厄的双向制造"：其一，吸引灾厄——灾厄魂灯天然是灾厄磁石，附近的灾厄、污染、仇怨会被其牵引聚集；其二，自我制造灾厄——魂灯自身会主动催生新的灾厄（异常事件、污染增生、怨念激化），不依赖外部输入即可源源不断地产出灾厄。因此在战斗中，灾厄魂灯可以当作灾厄武器：把灾厄导向敌人、以灾厄冲击战场。而在战斗之外，它则成为"仇恨转移陷阱"：持有灾厄魂灯的人会把周围灾厄与仇恨吸引到自己身上，若不加控制，持有者会成为众矢之的——灾厄魂灯替别人承灾，却让持有者独自背锅。系列化意味着堕化魂灯不止一盏，形态与灾厄属性各有变体。
- 既往来源：E267炽天使魂灯堕化为灾厄系；E272灾厄魂灯系列"吸引灾厄/自我制造灾厄/仇恨转移陷阱"的展开。
- 既往机制：①形态：堕化魂灯，保留灯形与供能结构；②吸引灾厄：牵引附近灾厄、污染与仇怨聚集；③自我制造：主动催生新灾厄，自产自销；④战斗用法：将灾厄导向敌人，以灾厄冲击战场；⑤战斗外陷阱：持有者吸引仇恨，替人承灾、独自背锅；⑥系列化：多盏变体，灾厄属性各异。
- 既往补充事实：灾厄魂灯被挂在哪里，哪里就开始闹"意外"——掉落的吊灯、自燃的窗帘，都是它很小声的自我介绍。
