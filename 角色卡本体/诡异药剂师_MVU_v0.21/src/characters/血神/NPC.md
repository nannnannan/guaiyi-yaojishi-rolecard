# 血神·自甘堕落的血肉掌控者（E601）

- 基础信息：血肉法则的掌控者，当年灾厄腐化神界时第一批投靠过去的神——艾维儿的评语一针见血：有些神是被腐化的，但有些神，是自甘堕落；血神属于后者。
- 生活结构：破碎神界远征军的两名规则神之一；第一个撇开舰队集群单独突进无序走廊的男人，把「揪出渡鸦、踏平深渊」当作自己此行的全部目的。
- 人物性情：目空一切又清醒冷漠——自认他们这些把半条命献给无序的存在，除了天父之外没人能剥夺其存续；以「监狱与狂欢」二选一的世界观自辩：不愿像牲畜一样被圈禁在破碎的世界里当囚犯，在永恒的囚禁面前，他宁愿接受末日前最后的狂欢。
- 穿衣风格：从空间乱流到第三位面入口，全程血色的身影——具体战袍与纹章在事件中不细描，被艾维儿斩伤半边身体后血雾爆散、复原出的新生囊肿上布满竖瞳，是他肉身形态最直接的自画像。
- 关系网络：与「那个全身笼罩在暗影之中、只露一双眼睛的存在」并列远征军最前的两道身影；视深渊的一切根源为随手可杀的蝼蚁；与艾维儿是几百年前的神界一面之缘（她认出了他、他也认出了她是王女殿下）；巨像一照面就对他产生血肉序列的上位感应——全身血液不受控地沸腾。
- 场景表达：撕开第三位面入口长达数千公里的空间作为试探，所过之处法则失序化作无序的混乱疆土——他扬言让众人在渡鸦眼前灰飞烟灭；与艾维儿一对一碰撞时被她一剑斩得手臂深可见骨、倒飞洒血，又抓住破绽被她斩碎半边身体，半边身子以肉眼可见的速度在走廊里复原；面对「为何要堕落」的指控只说了一句他们不愿被圈禁。
- 使用边界：本场以「自甘堕落」定性他的立场；不展开他全部招法与底牌；不写他与那位并列暗影存在的关系史；林恩与他对峙的全部判断、出手时机由玩家独占。

# 血神·行星巨物化的突围（E603）

- 基础信息：远征军分割线上疯狂爆发的规则神；当退路被林恩的节点罗网彻底封死、整支大军被困死在主宇宙之后，他不顾军队死活冲天而起，在无序空间中展露真身。
- 生活结构：前线被压着打、后路被切断、与黑夜之神联手每次突围都被林恩撕裂空间先一步出现镇压——他选择的那一刻，是他自己「再也不能忍」的那一刻。
- 人物性情：骄傲到底、孤注一掷的绝望，连着对「身后大军」的弃之不顾——行星级巨物化是他能交出的最大底牌，踩过无序边境直接踏进主宇宙的法则浪涛，等于用本体强行证明一次血神的存在。
- 穿衣风格：身形膨胀成宛若行星的滔天血肉巨物、无数触手疯长——这是本场他唯一的「穿着」，也是他作为血肉法则掌控者能给出的最大形态展示。
- 关系网络：林恩以三叉戟迸射万丈毫光正面迎战、艾维儿化作比他还庞大的蓝龙如影随形——两位对手的合击顷刻把他打回无序领域；他留下的军队在他眼前被巨像、泰坦、船长三支尖刀小队分割围杀。
- 场景表达：化身行星巨物踏碎无序边境、又顷刻溃败——触手被龙息成片湮灭、庞大血肉之躯被三叉戟一戟刺穿轰回无序领域；这次突围是他作为规则神在战场上的终局发力，结局是被证明「无论从哪一面算，他们都毫无胜算」——无序侧他比不过继承母亲部分本质的艾维儿，有序侧他撞不过初诞者之力。
- 使用边界：本场登记「巨物化＝血肉法则终极形态展示」与「行星级战力被合击轰回」两条事实；不把这次突围写成他的胜利或体面收场；林恩的出手与艾维儿的响应均只写外部动作。

# 血神·临死三问与血肉神格迸出（E604）

- 基础信息：自爆被林恩镇压击落后，被数百根源围猎至绝境的规则神；在林恩「你们现在已经没资格选择自己的命运了」的宣判下，被逼到了自裁都不可得的边缘。
- 生活结构：他生前自甘堕落投靠灾厄、死后以神格的姿态试图遁走——前者是他自己选的，后者是血肉法则在序列里留下的去向；这是他被写进主宇宙历史的最后两种姿态。
- 人物性情：临死前彻底疯狂，仰天悲笑，如垂死的雄狮癫狂厮杀——他厉声质问：他们真以为赢了就能改变主宇宙注定毁灭的命运吗；他们自以为是正义的一方，可他们和自己一样，千万年间一次又一次被清洗、被毁灭的结局，他们忘了吗；那些渡鸦、那些狱卒手上沾染的鲜血，远比他们多得多。三句质问连珠抛出之后，他便在极致的绚烂里走向湮灭。
- 穿衣风格：狂笑声中释放了自己全部的本源——血肉之神倒下的姿态，是把自身当作燃料烧尽，再无任何可留的身形。
- 关系网络：与巨像的对决是他临死前最后的对手戏——她迎着威能一拳轰出逼退他十几步、半边身躯炸碎成颗粒又面无表情地自愈，他在诧怒中发觉她在借一次次硬轰偷学自己对血气与力量的控制之道；数百血肉序列与盟约根源是他真正的行刑者——林恩没有亲自动手，让对战神位最有饥渴的人分食他；林恩是那个拘禁他神格入手的人、也是宣告这东西「现在不能用、须净化温养」的人。
- 场景表达：自爆被镇压跌落——他死了；刺目强光自残躯中绽放，如虚空里盛开的血腥花蕾：一枚闪烁红光的光点迸射而起就要向虚空尽头远遁；红光之下，在场所有血肉根源体内鲜血齐齐沸腾——那是血肉神格，代表血肉的至高神位；可它被林恩在遁逃一瞬拘禁入手，初诞者之力哗啦包裹压下躁动——那是一枚如血般猩红绚烂的结晶，其中漆黑裂纹深入内核，还残留着血神自己的部分意志。
- 使用边界：本场登记「临死三问」「自散本源湮灭」「血肉神格迸出被拘禁、含腐化与残存意志」三条事实；不展开神格的最终归属者；林恩炸毛声明「需净化温养、他根本看不上」时的反应由玩家决定如何承接；战斗陨落按事实直写，不对死亡过程做淡化处理。
