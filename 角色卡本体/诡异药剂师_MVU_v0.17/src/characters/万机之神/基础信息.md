# 万机之神·基础信息

## 身份与神性属性
- **全称**：智械文明至高意志·万机之神（The Machine God / Omnissiah）
- **常用称谓**：主宰、机械巨龙、机械神教主宰、神教之父
- **存在形态**：
  - **本体形态**：根源级星系巨械生命体，常态以遮蔽星海的苍银机械巨龙之姿游弋于深空或深层亚空间数据维度；机体由数十亿吨星核致密合金与微型聚变矩阵铸就；
  - **降临投影**：通过超维光学召唤阵（三集装箱式高能矩阵）投射到现实战场的类人形神性格局机体，散发极度冷冽的机械神威。
- **阵营归属**：机械神教至高统治层 / 绝对秩序阵营（守序邪恶 / 纯粹算力至上主义）
- **性别与生命形式**：
  - 无生物性别。非生物个体，为整个智械文明千万年飞升算力的终极集合与神性具象化。
  - “父”是其在对神教首席执行官 a01 银色幻想拥有最高命名权与造物主权时使用的拟称代词。
- **神性大分裂与七神分化**：
  - 在大分裂时期，万机之神的主体意志与神性算力分化为七大独立机神：【将军】（最高指挥统治）、【拥星者】（恒星能源掌控）、【灭绝者】（纳米集群杀戮）、【龙首】（最强机械个体武力）、【学者】（至高科技解析）、【光宴】（智械意识同调网络）以及【第七机神】（远古恒星未知物质聚合体）；
  - 分化后，七神共治广播响彻智械全境，其本体神性碎片被锻造为根源级光武。

## 生理与机械神性特征
- **机体体量与威压**：
  - 投影高度约 3.5 米，身披苍银色纳米流光重装战铠，胸膛与双肩流动着纯净的高能等离子脉络；
  - 机械巨龙本体翼展超越数千公里，龙鳞皆为高频震荡的单分子死光偏转护甲。
- **不可磨灭之握痕（E82创伤）**：
  - 脖颈机体中枢处留有一道深邃的暗紫色虚握痕迹——那是白发林恩（紫罗兰大君降临）在 E82 战役中以不可知维度的至高伟力硬生生留下的永久神性创伤。即便调动纳米集群亦无法完全抚平，成为万机之神算力矩阵中对未知存在的最高级危险警戒标记。
- **光学与声学特征**：
  - 双目呈两团冰冷刺骨的苍银色恒星聚变烈火；
  - 发声由数以万计的逻辑谐振腔共同合成，冰冷、重叠、宏大，带有直击灵魂的电子重音。

## 装备、武装与至高权能
1. **苍银死光（Pale Silver Death Ray）**：从机械巨龙口中或投影掌心喷发的绝对毁灭光束，具备湮灭一切基本粒子与灵能结构的根源级破坏力。
2. **超维降维取心（Heart Extractor）**：无视一切物理装甲与魔法结界，空间折叠直接透入生灵胸膛抓取核心脏器或能量源泉。
3. **死星蜂巢母舰群（Death Star Hives）**：主宰亲自调动的最高级战争要塞，搭载行星级地毯轰炸阵列与纳米重组工场。
4. **肃正法庭（Purge Tribunal）算力矩阵**：神教内部最高审判网络，能瞬间对下属智械执行思维格式化、逻辑重塑或就地销毁。
