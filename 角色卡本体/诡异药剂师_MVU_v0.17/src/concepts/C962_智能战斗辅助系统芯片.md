# 概念·物品·智能战斗辅助系统芯片（事件["E301","E307"]）

- 类别：物品；从破烂三位一体机里拆出的战斗辅助芯片，插上巨像之心供电就能驱动——一个话多、谄媚、自称全能辅助的"舔狗AI"。
- 事实门槛：仅在 E301-E307 进入"完成"或"变形"且正文实际出现该芯片、其供电方式（巨像之心）、其舔狗式对话与战斗辅助行为等事实时方可引用；"预兆""活跃"不得提前兑现。
- 定义：智能战斗辅助系统芯片是一枚从破烂的三位一体机残骸中拆解出来的战斗辅助芯片，本体几乎报废，却仍保有完整的辅助AI人格。芯片没有独立电源，必须插入巨像之心（为它供电的核心）才能激活运转。激活后它会以话痨、谄媚、过度积极的"舔狗"姿态与持有者对话，自吹功能齐全，实时汇报战场数据、分析敌情、给出建议，偶尔拍马屁式夸赞持有者。它本质是一套嵌入芯片的旧式战斗辅助程序，人格层被写入得格外话多，能力上限与供电状态挂钩：供电充足时辅助可靠，供电波动时反应迟钝。它跟随林恩与银色幻想的行动线，在数据世界内外充当半是工具、半是活宝的随身设备；既提供真实的战场情报价值，也因其喋喋不休的性格成为插科打诨的存在。
- 来源：E301 前后自破烂三位一体机拆出，巨像之心供电激活；E301-E307 随行动线持续登场。
- 机制：①拆解三位一体机残骸，取出芯片；②将芯片插入巨像之心完成供电；③芯片加载辅助AI人格，开始对话与辅助；④战斗时输出数据分析、敌情提示、战术建议，并伴随谄媚夸赞；⑤供电中断或波动时功能降级，话痨属性可能也随之掉线。
- 补充事实：舔狗AI的经典名场面是"主人英明""这波稳了"式的连环夸赞，数据判断与马屁齐飞，让严肃的战场氛围多出一层黑色幽默；它自诩"全能辅助"，实际能力随供电飘忽，被打脸后立刻转移话题。
- 限制与代价：依赖巨像之心供电，脱离供电即失效；辅助决策仅供参考，最终判断归持有者；话痨属性可能暴露行踪或在潜伏场景引发麻烦；芯片底层是旧式程序，对蜂巢新体系的理解有限。
- 未知项：芯片原属于何种机体、为何沦落为破烂；其AI人格的底层来源；供电上限下是否存在隐藏功能。
- 禁止外推：林恩的对白、动作与选择由玩家主权独占；禁止违背原著设定将其描写为无消耗或脱离因果律违规生效。
