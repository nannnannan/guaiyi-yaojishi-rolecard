# 概念·机制·地狱凝视十七、七日通牒与约剩三日的倒计时口径（事件["E147","E153","E154","E157","E199","E200","E201","E202","E203","E204","E205","E206"]）

- 类别：机制；统一管理【地狱凝视（17）】显示、完整反噬转移后的七日通牒、数日流逝后的约剩三日、后续十二小时与最后两小时等时序证据，同时禁止把不同口径互相换算或当成已解决状态。
- 事实门槛：E147只能确认面板出现【地狱凝视（17）】；七日倒计时须以E153完整反噬转移和地狱明确回应为前提，部分转移、撤销或取消不能继承；E154在可靠倒计时已成立且确有数日流逝后才可记约剩三日；E157只提出跨界暂避。E199至E206的保护性转移、十二小时、最后两小时、最后分钟和归零，只在对应事件形成结果后按时序记录，不能用方案提出时间代替实际经过。
- 定义：十七是特殊异常名称后的可见数值，维度未知；七日是古老狱规在完整命运转移后给出的应对期限；约剩三日是昏迷、复苏和会诊消耗数日后的粗略估计；十二小时来自E202临近截止的记录；两小时是E205根源阵营在002室外同意的最后等待窗口；E206的秒级归零描述本次召唤争夺时点。它们属于同一危机的不同观察口径，却没有已知公式。
- 来源：E147的面板同时警告命运不可任意书写、不要相信影子或回应低语，当时没有明确肉体症状。E153把羽毛笔反噬与注视转给林恩后留下七日降临倒计时；E154会诊指出地狱无需杀死，也可持续折磨、加深诅咒和摧毁心智。E157提出跨界候选。E199、E200使五根源以截止压力推动保护性转移，E201在通讯试验时危机继续，E202记为只余十二小时，E203、E204暴露欺骗许可与强制方案，E205形成最后两小时停战，E206归零前接受蓝星召唤后只确认地狱本次暂失目标。
- 机制：凝视标记表示规则冒犯进入地狱观测，通牒提供有限应对期。家人用巨像之脑日常诅咒作短时可中止模拟，只能证明活着也可能受刑，不是提前处刑或消耗倒计时。跨世界召唤可尝试离开锁定环境，不能预设计时暂停。运行账应记录观测来源、时间精度、是否完整转移、所处地点和本次目标状态；从约三日到十二小时可按事件流逝更新，但不能凭叙事感觉补精确小时。
- 限制与代价：十七不能解释为十七日、阶位、伤害或次数；约三日不是精确钟表。五名根源联合没有被证明能正面抵挡地狱，保护性转移又可能侵犯玩家主权。羽毛笔和002室只能暂时降低定位，E206跨界只使本次凝视失去目标，不证明标记清除。完整与部分反噬转移路径不同，若只出现部分病变，倒计时是否成立必须以状态证据为准。
- 未知项：十七真实维度、惩罚形式、七日起算点、跨界期间是否继续计时、部分降临如何影响锁定、地狱能否提前或延后、猪头屠夫可调整多少规则、一次归零后是否产生新期限、地狱何时重新定位蓝星以及羽毛笔警告的外部追索者与凝视是否相关均未知。
- 禁止外推：林恩的对白、动作与选择由玩家主权独占；禁止违背原著设定将其描写为无消耗或脱离因果律违规生效。
