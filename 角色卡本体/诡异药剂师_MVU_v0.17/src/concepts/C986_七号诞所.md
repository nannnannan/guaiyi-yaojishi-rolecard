# 概念·地点·七号诞所（事件["E308"]）

- 类别：地点；机械神教地下负135层的锻造场——七神分化之根源机体的工坊，神教的子宫与坟场。
- 事实门槛：仅在 E308 进入"完成"或"变形"且正文实际出现七号诞所、负135层、锻造场、七神分化根源机体等事实时方可引用；"预兆""活跃"不得提前兑现。
- 定义：七号诞所是机械神教地下的隐秘锻造场，位于地下负135层——一处深到主流档案几乎不记录的底层空间。它的职能是锻造：专为分化与铸造"根源级机体"而设，是机械神教最核心、最神秘的生产环节所在。所谓"七神分化之根源机体"，指向机械神教的七神体系（万机大分裂后形成的神格序列）——七神的根源机体正是在此类诞所中被锻造/分化出来，每一台根源机体都是七神存在的物质底座与权柄载体。七号诞所因此兼具"子宫"与"坟场"的双重属性：它诞生了七神的根源机体，也封存着分化失败的残次品与弃置的失败机体。诞所内部是层层叠叠的锻造工位、神金熔池与机体孵化结构，由机械神教最忠诚的工匠序列守护；其锻造流程以原初神金为原料（见 C987 七神光宴），成品直接决定七神体系的根基稳固与否。任何窥探七号诞所的企图，都会被机械神教视为对神格的亵渎。
- 来源：E308 七号诞所作为地下负135层的锻造场被揭示，系七神分化根源机体的工坊。
- 机制：①七号诞所位于机械神教地下负135层；②专司根源级机体锻造/分化；③以原初神金等顶级材料投入熔池；④历经锻造工序，分化出七神根源机体；⑤完成体移交神格序列，失败体封存于诞所深处；⑥诞所持续运作，为七神体系供应根基。
- 补充事实：诞所的地层编号本身是禁忌——档案里负134层与负136层直接相连，负135层被整个抹去，只有拿到专属权限的人才能看见"七号诞所"四个字；据说锻造工位上的工匠序列终其一生不离开诞所，他们自称"模具"，不与外界通信。
- 限制与代价：诞所的锻造消耗天量的原初神金与算力；分化过程极其危险，失败体会在诞所内滋生畸变；诞所的秘密一旦泄露，七神体系的根基将被动摇；其深度与封闭性也使内部成为阴谋的温床。
- 未知项：七号诞所是否存在"一号"到"六号"的姊妹诞所；锻造流程的完整仪式细节；那些封存的失败体是否仍在活动。
- 禁止外推：林恩的对白、动作与选择由玩家主权独占；禁止违背原著设定将其描写为无消耗或脱离因果律违规生效。
