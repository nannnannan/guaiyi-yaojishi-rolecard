# 《诡异药剂师》MVU v0.8

这是面向 SillyTavern 1.17.0 与酒馆助手 4.9.1 的 `chara_card_v3 / MVU Zod` 内部候选工程。v0.8 从 v0.7（已由所有者指示转 accepted-release）独立复制，在不修改 v0.7 的前提下扩写阶段四：新增 E65–E95 共 31 个六态锚点与 E96 阶段待续钩子。

## v0.8 内容规划（建设中）

- 96 个事件锚点：保留 E01–E64，新增 E65–E95（G01–G31 一对一映射）；E65–E95 含下一事件引入；E96 只写阶段待续钩子（无六态、无推进按钮）。
- 14 个宽阶段 S0–S13：新增 S11 疫医潜入与纳米风暴期（E65–E72）、S12 万机之神降临与根源混战期（E73–E84）、S13 战后修复与机械总攻期（E85–E95）。
- 27 名核心人物：24 名既有 + 万机之神（UID295，登场锁 E77，固定非恋爱）、巨像之脑（UID296，登场锁 E78，恋爱/恶堕开放，只写骨架+不详）、血肉支配者（UID297，登场锁 E96 恒锁，固定非恋爱，只写最低限度）；9 份候选二次解释已批准注册。
- 概念 UID 551 起、数量不设上限、删除字数上限（保留下限与结构断言）；世界书条数随实际派生。
- 世界书路由与 v0.7 一致：事件详情±1 强启 / 原生关键词绿灯，同 UID 去重，双递归保护；UID1 唯一事件运行时源；事件素材 UID300–395 统一禁用。
- 95 对常驻事件桥（E01→E02 … E95→E96）；E96 无推进按钮；E64→E65 桥前件判断挂 E63。
- 初始变量、Schema、开场 initvar 与状态栏 FALLBACK_STATE 保持深一致；事件身份迁移只允许单条 `replace /事件`。
- 色色口径：原文色色暗语翻译成明语写入（含性过程）；以M=快感冲击（媚药）、性行为=解咒、恶堕=性调教；涩涩度=恋爱角色通用，情感开发度=黑弦月专属，驯服度/崩坏值/恨意值=银色幻想专属；固定非恋爱角色锁0。
- 卡内与世界书正文禁止出现"第X章/小总结/阶段几"等元数据词汇，来源与门控一律用 E 编号。

林恩的对白、主动行动、决定、判断、记忆与内心始终由玩家独占；默认走向只供因果推演。

本卡不建立战斗数值、可运算等级成长、技能树、装备栏、库存、货币、经营结算、回合制或日历/天数系统。

## 维护入口

- `创作规划.yaml`：内容边界与连续性决策，修改前先同步（项目级事实来源）。
- `contract.json`：事件/人物/概念结构与局部依赖契约。
- `manifest.json`、`profile.json`：版本、稳定 ID、依赖与构建映射。
- `src/worldbook.json`：世界书注册表；所有条目双递归保护。
- `src/events/`：E01–E96 事件素材；构建时嵌入 UID1，素材 UID300–395 不参与运行时扫描。
- `src/characters/`：27 人六组件 EJS；9 份候选二次解释已并入官方组件。
- `src/concepts/`：概念正文（静态或 EJS 状态变体两种形态）。
- `src/prompts/mainline.md`：事件摘要±3、完整详情±1 与 95 对按状态工作的常驻桥。
- `src/initial_variables.json`、`src/scripts/schema.js`、`src/prompts/mvu_*`、`src/ui/status.html`：MVU 整链。
- `tools/build.mjs`、`tools/validate.mjs`：构建与离线验收。
- `tools/` 下 sync/fix 脚本为一次性过程记录，不进入运行时。

不要直接编辑`dist/`。修改源码后重新运行`npm run check`。
