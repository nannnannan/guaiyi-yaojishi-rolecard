# 概念·势力·人皮拾荒者（事件["E01"]）

- 事实门槛：只有E01进入“完成”或“变形”，且正文实际形成相应接触时，交易与关系变化才成为事实；“预兆”“活跃”或“取消”不会自动兑现默认走向，后续再访也以聊天事实为准。
- 定义：人皮拾荒者是游魂巷中独自行走的以物易物者，收取其认定为“垃圾”的残肢、器官和异常材料，再用别的物品交换。其外表、种族、所属组织与力量层级均未公开，不能因“拾荒者”称呼将其写成普通清道夫。
- 来源：若E01形成首次交易，拾荒者会用林恩交出的垃圾换来裁缝店老板与猪肉店老板的眼球，并以自身存在说明游魂巷的生存准则：不要随意得罪黑暗中的行走者。眼球的取得过程、原主人是否自愿均没有现场证据。
- 事件演进：首次接触只建立交易渠道。若后续正文实际发生二次上门，林恩可把从根源猎头者牙中清出的残肢交给它；拾荒者识别根源气息后，才可能透露深渊猎头者吃空周围三巷、游魂巷独存的消息，并以无面魔心脏回礼。该段未发生前不得主动预告。
- 机制：交易价值由拾荒者自行判断，不遵循骷髅币定价；器官、尸块和根源残留都可能成为交换物。它能辨认根源气息，也曾取得其他店主的眼球，但这些表现不足以证明其拥有摘取器官、空间移动或根源级战斗能力。
- 限制与代价：它明确表示直接帮忙次数有限，友善交易不等于受雇、结盟或接受召唤。接收来源不明的回礼可能附带诅咒与饲养代价；无面魔心脏需要鲜血，不能因拾荒者赠予就视为安全物品。
- 当前状态：若相关交易已发生，拾荒者可对林恩形成好感与敬畏；若交易被拒绝或改写，则只保留实际交换与态度。它是否仍在游魂巷活动需由场景确认。
- 人物关联：林恩是潜在交易对象；血锯药剂店是其上门地点；裁缝店老板与猪肉店老板只通过眼球来源相关。
- 未知项：真实姓名、种族、力量上限、眼球取得方式、与血锯及游魂巷居民的旧关系均未知。
- 禁止外推：不得揭示其为根源级遗褪或其他确定身份；不得让它无条件救场、传送、监视全巷或替林恩解决敌人；不得把游魂巷幸存直接判定为林恩庇护的客观因果。
