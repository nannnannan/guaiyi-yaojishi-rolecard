# E456·尖端对抗与七神宣战·if线

- 若林恩在黑袍机械的同脸揭开那一秒抬手把它另一张侧脸颊按凹，则机体失去对称美型，艾雯在战报栏加一条「同脸误差 4mm」，后续士兵在走廊谈心把它叫成「左脸的林哥」。
- 若林恩在直拳对轰中主动不后退、任凭臂骨"咔"地响一声再用反震震开对手,则他尺骨裂一道细纹,但那台苍蓝机体的肩关节被反向震开——艾雯备注「平局算赢」。
- 若林恩在君王栏「×」写下前主动对艾雯说「我还没用真力」，则她放下笔扫他一眼、补一句「那就再让我看」，战斗又被强制续上三分钟。
- 若林恩在死星结界匕首被打飞瞬间用脚后跟踢回舱壁、故意让匕首插在会议纪要牌上，则那把刀成为整场会议唯一的实质道具，艾雯离场时把它拔下随身带走。
- 若林恩在尖刺化鸦时让乌鸦群掠过艾雯帽沿、故意啄掉她那副单片眼镜，则她罕见地眯眼低头让镜片滚落，事后左左嗅到「第一次有人敢碰她装备」的甜味。
- 若林恩在碾盘压碎第三台机体后静静蹲下去，用食指抹开它反应炉的蓝焰,则他那枚指尖被灼伤成永久的淡蓝,事后万机之神甲板上讲起「良医的蓝戒」。
- 若林恩在爱丽丝爬出机体的第一秒脱下夜医外袍盖在她肩头，则她那一整天被碎袍碎成布条也不愿还——绑定值隐藏+5。
- 若林恩在艾雯坦白「开战已一月」时反问「什么时候开始统计」，则她罕见地露出半天没表情、最后回了句「从第一节课起」，夜里远征军出征名单就被替换了三处将领名。
- 若林恩在爱丽丝手心道歉时主动双手握住她的手指再压向自己胸口，则小女孩愣住七秒，咒纹在她指尖与他胸口同步亮了一线。
- 若林恩对追问的左左说「他们不是要赢，是想看看我能打多远」，则她一整天没再顶嘴，绑定日志多一行「妹妹开始学会沉默」。
- 若林恩在被掐颈砸地时主动放弃硬化脖颈、让它真的咔嚓一声，则他昏迷中死星结界匕首从袍内自行弹开，机体在半秒沉默后开始笨拙地剥皮自救，君王栏「×」被艾雯改成「？」再改回「×」。
- 若林恩在听到「巨像已切断联系」时当场给巨像之脑打一道初诞者之力脉冲，则远在前线的银瞳少女胸口裂开一道细纹又迅速愈合,她在心悸里记下「有人在找我」。
- 若林恩在穿梭入场前搜光三台超凡机甲的废核，则背包多出三颗未用过的能源核心,后续在火山战车走廊被当作应急起爆。
- 若林恩在爱丽丝归还机体时偷偷在她的连衣裙口袋里塞一枚小兵人，则这件小布偶在 E457 隐身舰被她当作压兜物，完整保存到开战第三日。
- 若林恩对艾雯提出「同脸靶标为何如此逼真」而不再评「熟」，则她罕见地合本文件资料转身就走，五秒后步兵鸣笛「机械基地区域 B 封」。
- 若林恩在火花碎裂的瞬间强行让左手变成增生血肉，则他被机械溅射割伤的手腕跟不上纠生速度，后续对灵能弧控制的精度明显下降，连左萝都在意识里倒吸凉气。
- 若林恩在七神宣战那一秒直接打量艾雯问「能不能先把我编入作战家眷」，则艾雯怔住两秒,把他名字黑笔涂入「家族遗产」栏——后几月里他远征军用这枚头衔调用了不止的一处夜医停车。
- 若林恩在广场中央打开空间传送门瞬间强行把左左从意识里拉出「你自己看」，则她在门口愣住,被远征军的「良医先生」吼声吓得腿发软,事后「又被吓到」统计数字 +1。
- 若林恩在三维一体机报出「三位一体」时当场表示「我不背这个框」,则三位一体机露出罕见不理解的停顿、把这三个字从硬盘中划除，后续君王栏的对策被强制改为「对抗根源」。
- 若林恩在询问银色幻想下落时主动对艾雯承认「我决定参战是因为她不是输不起」,则她罕见地抿嘴,在日志边栏写下「受试者动机理性不纯」，后续指挥官没有把侦查信息全交给他。
- 若林恩把黑袍靶标的苍蓝衣角拽回身后，交给夜医纪律官当作「同脸穿戴证」，则机械基地在下一周的远征通行中被授权了一条「林恩同款机械也能登列」的伪约定。
- 若林恩在黑袍退场时强行与它并肩走了三步，则它为他让出半步,艾雯登记「非程序化协同可能 +3%」，后续「同源机体」精度模型被加一格。
