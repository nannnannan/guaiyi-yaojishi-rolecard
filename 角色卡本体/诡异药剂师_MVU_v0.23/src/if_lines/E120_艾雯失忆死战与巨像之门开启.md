# E120·艾雯失忆死战与巨像之门开启·if线

- 若林恩在艾雯爵士答出"你不是巨像之——"那一瞬改口换上第二道暗号，则艾雯爵士眉峰一颤断档被强行续上三秒，安全密码升级成双层，但接续瞬间灵能输出矮了半阶。
- 若林恩在递记忆芯片前先拆成两半把半截藏进系统空间，则艾雯爵士接过那半片只唤起"赛博文明星火"唤不起林恩姓名，战友关系挂牌生效但"挚友"两字没被他亲口念出来。
- 若林恩坚持现在就恢复艾雯全部记忆宁可他跌落位阶，则艾雯爵士沉默地盯着芯片三秒后推回，额头贴上林恩额头低语一句赛博母语才退回战线，此战位阶高出整整一阶，但战后他再也无法维持根源实权。
- 若林恩对艾雯爵士那句"我可能忘记了你的名字"点头回"那就重新认识一次"并主动伸手报出全名，则艾雯爵士握紧那只手时灵能频率重新校准，记忆断档处被这枚握手盖上临时锚，诅咒侵蚀速率按下约半小时。
- 若林恩在万机之神开条件那一刻抢话回怼"先把你在我心口留下的洞补上再说"，则机械巨龙红芒一闪扭头锁定林恩，艾雯爵士趁这三息把左翼灵能幕墙拉到极限，林恩多争取到一段无弹幕冲锋窗口。
- 若林恩任由万机之神把"机械神教与黑夜城结盟"那根胡萝卜完整挂出来不反驳不揭穿，则艾雯爵士冷笑时没当场戳破三位一体，万机之神多讲了四句承诺细节，血肉支配者的眼球压到阶梯中段上空才开炮，林恩冲锋节奏整体后移。
- 若林恩在艾雯变身心灵巨人时伸手搭上那道灵能巨人脚踝共享刚觉醒的那丝自然神性，则巨人体表浮起淡金色纹路，龙炎落在金纹上散成细雾而非炸开，艾雯爵士续航被拉长但也立刻识别出这丝神性混着母树本源。
- 若林恩在台阶冲锋途中召唤小宝贝变身铠甲状挡住龙炎而不是硬顶，则小宝贝发出一声介于警戒与兴奋之间的嘶鸣，蛇鳞立起血肉骨板整段阶梯被照成赤色，林恩步伐没减速但左左被他箍得更紧。
- 若林恩在艾雯爵士第二次转移束缚光流时脱口喊出"大哥我自己来接这一发"，则光流落点半途被林恩用疫医斗篷兜头罩下，斗篷被融出三个焦洞但他未被锁定，艾雯爵士那句"林恩——"喊到一半咽回去改成一声短促龙啸。
- 若林恩在与左左按门之前先抽出一滴血抹在巨像之心表面，则巨像之心权限激活瞬间白光里多出一缕血红细丝缠上两人手腕，门缝弹开速度快了近一倍，但巨像之脑在E121苏醒时第一时间认出的不是左左而是这缕血。
- 若林恩在按上门的那一刻刻意把左左的十指掰开改成自己单手按门，则巨像之心权限只识别林恩一人，白光只吞没他一个，左左被气浪掀退三步跌坐在台阶上，等门内禁库入口再次稳定时她手指还保持按门形状悬在半空。
- 若林恩在按门瞬间反手把左左拽进怀里替她挡掉第一束迸射的白光，则左左被埋在他胸口没看清门开细节，但那三秒里她听见林恩心脏与巨像之心合拍共振，E121开场巨像之脑直接对林恩说出"你的心跳里有我们的频率"。
- 若林恩在白光淹没之前回头对艾雯爵士喊"回来我给你讲你今天做过什么"，则心灵巨人在龙炎与死光中侧头深深看了林恩一眼，那一眼里没有回忆只有当下，艾雯爵士把这一眼压进最后一缕未剥落意识里当作护命锚点。
- 若林恩在门开瞬间没有立刻踏入而是先把小宝贝从怀里放到艾雯爵士脚边，则小宝贝嘶嘶一声缠上心灵巨人脚踝，蛇身被灵能灼得冒青烟仍不松口，巨人在战场上多了一条会咬根源的尾巴，而林恩真正踏入禁库时怀里只剩左左。
- 若林恩带着左左在门内第一步就主动伸手触碰最近的那本流动金色典籍而非等待巨像之脑苏醒，则典籍在他指尖碎成漫天光点，整座禁库响起一声古老叹息，巨像之脑苏醒时间被提前半个呼吸，E121开场的"欢迎你们"变成"……是你先碰了我们的书。"
- 若林恩在踏入禁库前一刻突然把巨像之心从胸口摘下来握在掌心而非任由它共振，则巨像之心权限短暂脱锚门内的无尽典籍同时翻页，禁库的空气里多了一层检测意味的沙沙声，巨像之脑对林恩的"王后护送人"初始评价从"合格"上调到"受监视的合格"。
- 若林恩在进入禁库的瞬间放开左左的手让她自己悬空飘浮，则左左在失重的金色光尘里翻半个圈最后抓住一根书架横档稳住，林恩落地时她已先一步站在一堆古册上面，眼神里"原来这里是为我准备的"了然被她自己先看见。
- 若林恩在门后第一秒就把血婴渡鸦梦境里那句"渡鸦守望着我们的岁月"默念出声，则禁库书架最深处一只金色渡鸦浮雕的眼睛忽然亮起，E121里左左诵读神话被一句无声的"嗯"提前应和，林恩面板多出一条只有他看得到的古渡鸦侧写。
- 若林恩在踏入禁库后立刻打开系统面板把巨像之门全程录像回放，则系统在第三十七秒自动暂停并圈出左左按门瞬间指尖渗出的一缕金线，林恩第一次看到"王后血脉"这条隐藏标签，巨像之脑还没开口他已收到半张底牌。
- 若林恩在艾雯爵士死战期间悄悄从系统空间放出一缕预备好的封灵药剂雾盖住台阶，则万机之神与血肉支配者的探测蒙上湿疹般错觉，对门内锁定延迟十几秒，林恩与左左在禁库入口多出一段静默喘息，代价是这支药剂在E121谈判时已成空瓶。
