# E707·数年过去与新神·if线

- 若自缚天使在登神前把那枚林恩留下的神格让给同僚先试，则她错失第一时间窗口，心灵之神位落在人偶家头上，她的至高神位被推迟一年，边疆布防次序全改。
- 若人偶家改以梦境映照而非心灵之海研究冲神位，则她的神格名称从心灵之神偏成织梦一系，后续心灵丝线战法的源头改写。
- 若母树不放弃毁灭一面，则她保留紫罗兰旧部的杀戮性，自然神位空缺，她从主宇宙寻回的「曾经支离的家」以另一姿态复苏，神界多一尊主战派神灵。
- 若泰坦在不告而别前先向主母报备去处，则他的下落从一开始就有记录，后续「全身燃火的战神」目击线索被替换为定期情报回传，悬念强度大幅降低。
- 若泰坦未冲向边陲无序深空而是回黑夜城述职，则他在第二轮全面战争时已出现在城墙之上，黑夜城多一柱顶级战力。
- 若白骨兽王被林恩斩杀那次就彻底湮灭而非标记可降，则它在第二个年头无法重降，四大魇魔少一柱，边疆第一次压制力量均分倾斜。
- 若镜魔与白骨兽王分批而非同步重降，则边疆防线获七天预警窗口，狱卒集团得以多布置一道轮换阵。
- 若「第四个魇魔」按原文起名被点名公开，则画家对它的来源判定提早，神界学者得以在战后先建档案。
- 若画家在第一轮全面战争中选择「吞四杀零」而非杀一吞一伤二，则她体量再涨一档，但「越来越多像魇王一样的存在」的隐忧强度同步加剧。
- 若画家选择避战保存力量，则边疆第一轮不被她压回，魇王一行直推内环，整个第二次战争的时间表被提前数年。
- 若狱卒集团在对画家的描述里保留老一輩「女主人当年」的证词不外传，则新神一代对画家体量的认知断档扩大，内部恐慌在战后翻倍。
- 若神疆在对抗四大巅峰魇时发挥出对所有魇都通用的新法则，则「挡得住寻藏挡不住巅峰」的局限被改写，防线的物质基础整体升级。
- 若黑夜城在战争收尾时立即向主宇宙边缘世界派遣重建队，则第二轮魇潮来袭时他们已失守一半外环，灾厄的蓄力期被动拉长。
- 若「越来越多像魇王一样的存在」的判断被压下不上报，则黑夜城的下一轮修行规划失去方向，三年后的危机被「外部记录缺档」的形式延迟炸开。
- 若人偶家在成神当夜把戒指留在心灵之海不回神界，则她在下一轮战争开幕时已失联，无法参与神疆献祭的调度。
- 若自缚天使在至高神位登临时对林恩的闭关发出正式的「牵挂宣告」，则神界内部的「林恩回归期」议题被提前推上桌，内部派系提早分裂。
