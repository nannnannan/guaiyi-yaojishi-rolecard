# E378·劫后流浪与远洋航行·if线

- 若林恩在沙滩爬行画面开场瞬间主动拿出疫医记录器件把这一幕的方位与海岸线记下，则「逃上海岸」地点坐标被锚定，疫医档案里多一条旧世边缘之城落点。
- 若林恩在她觉得「像极了坠入地狱那一幕」那瞬间主动对比两个画面细节，则「地狱坠岸与旧世登岸」身体行为第一次被写成对照档案。
- 若林恩在她决定白天不出那晚出时主动评估她判断的依据，则她发现这是一份「光照体型识别」策略，疫医档案里多一份异世生存策略副本。
- 若林恩主动凑近她在垃圾箱里翻出的第一口食物辨认它的成分，则档案多一条「旧世城市下层食源清单」示例。
- 若林恩记住雪莉塞给她的那一枚硬币此刻被藏在布偶某条缝里，则疫医档案里第一次确认布偶还是储物功能，后续修补布偶意义重大。
- 若林恩在小狗渡河而来那一秒主动扫描它伤口的深度与感染程度，则他第一次量化发现她的「裹伤救治」具备基础水准、是长期训练才能习得的手法。
- 若林恩在她相依小狗画面里试图用疫医气息包一层保暖空气罩外面，则疫医气息消散，他第一次体会到「历史里没有我」的物理含义。
- 若林恩在她每天观察货轮班次时主动陪她做一轮表格记录，则「码头班次表」被手抄进疫医档案，地下世界线索被再次汇集。
- 若林恩在她的硬币只剩下最后那一枚瞬间主动用灵能识别币种，则结果发现这枚硬币面值很低、根本买不起一张船票，「被迫偷渡」的背景逻辑被证明。
- 若林恩在她冲入码头货物夹层瞬间主动跟她一起进入箱体夹层视角，则视角改为低光的箱中世界，他能客观量化「躲藏体积」对孩子体型的决定性。
- 若林恩决定留在码头而不随记忆上船，则船上部分全部失去，档案里多一个「求上岸」的待定空位，需要后续用其他渠道补齐。
- 若林恩在货轮中途改航瞬间主动记忆新航线方向，则他能直觉判断「不是她原定方向」，地下世界线索得到进一步确认。
- 若林恩在大量被囚者接入底舱瞬间主动数人数与性别比例，则档案里多一次旧世奴隶贸易规模的小样本记录，疫医档案多一行「旧世罕见度」评分。
- 若林恩在那名黑皮肤男孩跌到箱边恰与她对视瞬间主动记录两人目光持续时长，则他发现对视只有一秒但锚定「识别」的动作已经完成。
- 若林恩试图在男孩告发前用心声提示女孩挪位置，则历史原样推进，他被记忆边界警告一次，疫医档案里多一条「干预尝试对告发事件无效」。
- 若林恩在女孩被拖上甲板挂进鸟笼瞬间主动测笼子的粗径与海水的浪差，则他发现这是一种纯粹的凌虐装置，疫医档案里多一行「旧世虐待器具」分类。
- 若林恩在女孩被白鲨围绕笼子时主动记忆每种鱼种的体型与进食习性，则档案里多一条旧世海洋生物样本清单。
- 若林恩在小狗貌似遗忘前主动观察它尾巴摆动频率，则他看出「讨好水手」主要是生存策略，旧主锚点未断。
- 若林恩在女孩分食下层被囚者的瞬间主动记录其他同层被囚者的反应，则档案里多一段「底层互助链条」首次量化。
- 若林恩决定不休地看完全程航程，则疫医档案里多出一夜的旧世航程全记录，但疫医气息耗费比平时高、他需要在现实里补养。
- 若林恩当场选择结束观察退回现实向人偶家汇报，则「航程经历」与「小狗的行为真相」已被写入档案，黑弦月深层执念里「无人再见」一项被首次纠正为「互助但分别」。
