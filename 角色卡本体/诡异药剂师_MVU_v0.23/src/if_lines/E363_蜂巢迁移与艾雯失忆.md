# E363·蜂巢迁移与艾雯失忆·if线

- 若林恩在智脑交付人偶家档案时主动弥补一句「银色幻想她还好吗」，则智脑停顿三秒后淡淡回一句「她的事你不该问我」，但档案里多了一条隐藏索引标记。
- 若林恩主动询问智脑蜂巢迁移的目的地，则她以一句「我不会告诉你」回绝，但临别时蜂巢黑雾中留下一枚灰色坐标残片，需日后林恩亲自反向解码。
- 若林恩主动提出以十年或百年为期的互相支援协议代替附庸框架，则智脑在意识节点里停顿一拍回应「让我与她自己谈」，蜂巢势力未来向盟友路径开放。
- 若林恩主动为蜂巢的撤离路径铺一道初诞者防护衣，则蜂巢智脑会意外停下撤离一拍，林恩首次感知她意识里一闪而过的「这不是必要的」。
- 若林恩在主母解释这枚芯片实质不是艾雯自创产物时主动追问「那艾雯究竟是谁」，则她会望向荒野沉默很久答「他一半是传承一半是新我」，林恩首次领悟这项界分。
- 若林恩在备份解封时主动用灵能波纹替艾雯的躯壳做一次前置稳定，则传输时间缩短半小时，但林恩自己被反哺到的一小段赛博记忆需事后深夜咀嚼。
- 若林恩在艾雯苏醒瞬间主动以「大哥」二字唤他一声，则艾雯灵能回路在那一瞬剧烈震颤，备份之外的某缕残存让他在茫然中流出一滴不存在的灵能泪水。
- 若林恩主动朝艾雯虚影张开双臂给他一个兄弟拥抱，则艾雯虚影下意识地向后退半寸，但随后抓住他肩头用力收紧，「一定会想起来」成为他主动的自我承诺。
- 若林恩在艾雯询问「这段时间之内究竟发生过什么」时主动选择从头细叙，则对方接受一半理解一半迷茫，但他灵能核心边缘的多余空白会默默填入第一笔。
- 若林恩主动把从艾雯丢失的某一件共同经历（比如最早兄弟一战的细节）口述成一小段独白，则艾雯在灵能深处产生一种「似曾相识」的共振，将这次唤醒标记为最深的一笔。
- 若林恩在艾雯第一次抓住他的手腕表明同源共振时主动加一句「我们是生死之交」，则艾雯盯住他的眼睛数秒后点头，灵魂深处多出一条「原谅过去的迷途」责任标注。
- 若林恩主动问主母「那枚芯片可以在哪里再做冷备份」，则她愿意带他去一次远古时代的内空间位置，路径与「主母的内空间」秘密相关。
- 若林恩主动为艾雯备份芯片失败后留下一份旧档案的镜像存储到蜂巢智脑侧，则智脑接过不会致谢也不会拒绝，但蜂巢未来多块共享节点。
- 若林恩主动在艾雯清醒后再次自我介绍「我是林恩，疫医、机械之神、卡牌人偶的持有者」，则艾雯在数秒内陷入沉默之后点头并补一句「你是我认识过的最有威胁的朋友」。
- 若林恩在蜂巢离开前主动把一小瓶药剂附赠档案里作为临别礼，则智脑收下药剂不置一词，但蜂巢最终撤离时在黑雾中多停留了三息以示认可。
- 若林恩主动朝艾雯虚影凭初诞者气息叠加一道共鸣强心剂，则他的灵能躯干在数分钟内能短暂实体化两小时，艾雯得以首次脚踏实地与众人回应重逢的拥抱。
