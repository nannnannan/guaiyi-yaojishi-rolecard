# E383·失却之海与梦境新生·if线

- 若林恩在幼小身影定格油污海岸瞬间主动记录她脸上皮带抽疤痕的方向与深浅，则疫医档案里多一张「旧世虐待遗留线谱」详图。
- 若林恩顺着小拇指丝线往下看那一秒主动确认这条丝线与现实黑弦月小拇指上那一条是同一条，则他在疫医档案里多一笔「灵魂最深锚点同源」备忘。
- 若林恩在艾雯郑重说「你是想对她的整个过去开枪」那一秒主动用疫医气息柔化成纯白为这句话加一层亮度，则疫医气息首次成为「疫医心底拒绝该方案」的象征物。
- 若林恩当场决定先不对幼小身影出手而是再观察一段，则他多了一段「谨慎期」的记录，下一轮决策被玩家主动压后，档案里多一条「玩家考虑期」备忘。
- 若林恩决定直接向幼小身影出手消灭她，则画面立即被疫医档案记下一条「疫医对历史整体开枪」的罕见记录，黑弦月的过去被宣告流产。
- 若林恩主动找艾雯询问现实时间差距，则他知道现实只过了不到一小时、深层体验可能远比想象漫长，「深层时间代差」首次由疫医视角亲自确认。
- 若林恩主动请艾雯把「越是往下、代差越大」这一规则详细描述一遍，则疫医档案里多一页「深层时间曲率」样稿，下次下潜有心理预期。
- 若林恩主动用疫医气息在深层意识海测一秒钟对应的现实秒数，则他发现气息本身也被减速，「疫医气息被失却之海消解」首次量化。
- 若林恩决定不再深入失却之海并向上撤离，则疫医档案里多一笔「玩家选择退」备忘，但深层执念里的「活着即折磨」仍以她现状未被清理。
- 若林恩当场决定在失却之海利用初诞者之力构筑新生活，则他被记忆边界认可进入「梦境重构」分支，深层意识海首次允许他干预。
- 若林恩主动用灵能构筑污染海岸边界并让浪涛击打礁石，则疫医档案里多一笔「梦境构造细节初稿」副本。
- 若林恩在把自己虚化形成高脚帽绅士向孩子伸手那一秒主动控制阳光角度让她确实睁不开眼，则「疫医在梦中成为救援者」档案首次落定。
- 若林恩决定让小女孩在梦里只有自己勾一个小拇指就知道对方想法，则「疫医在梦境中为小拇指联系做省事处理」被记入档案。
- 若林恩当场决定雪莉在梦境中作为裁缝复活，则档案里多一条「梦境雪莉职业」新规则，与旧世苦难相距一层。
- 若林恩决定让小狗在梦境中健康生存甚至生了一只幼崽，则档案里多一条「疫医为小狗开梦境命运」新备忘，与旧世苦难相距一层。
- 若林恩拒绝让小女孩在梦中交新朋友，则「疫医选择护航」档案首次落定，梦境被默认隔离陌生人。
- 若林恩在女孩夜里惊醒紧抱被子喘气的瞬间主动用疫医气息柔化成纯白包裹她周围空气，则梦境疫医气息成为合法物品，档案里多一条「梦中疫医气息」。
- 若林恩决定让女孩醒来后寻找可以确认的联系，则档案里多一条「疫医为梦境提供最轻联系方式」。
- 若林恩当场决定让女孩梦境里化开被失色过去的七分之一，则「疫医对历史坏事减速」被记入档案。
- 若林恩在失却之海对一个人精神和意志的瓦解反应开始加快那一秒主动监控疫医气息的存留指数，则「疫医气息在深层海里折损」首次量化。
- 若林恩在艾雯说「我必须让他收手了在他彻底让自己迷失之前」那一秒主动用疫医气息留下一枚「归来锚」，则「疫医在自己意识里埋锚」首次实现。
- 若林恩当场决定撤离梦境退回现实把接力交给艾雯，则疫医档案里多一笔「疫医同道见面」备忘，下一段救治由艾雯主导。
