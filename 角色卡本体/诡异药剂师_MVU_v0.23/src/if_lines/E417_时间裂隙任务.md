# E417·时间裂隙任务·if线

- 若林恩在改造锈链锯时为神的方程式多垫一层原初之力垫底，则核动力链锯的辐射风险会被压低半档，他挥锯时不再每五秒灼手一次，但中频档位的输出上限也会跟着降一档。
- 若林恩决定不改造整条链锯、改把地下室收集到的剔骨刀和锈骨钻临时熔成一把「简易原初短刀」，则这把刀轻巧便携但耐久度只有链锯三分之一，他全程都得边打边找补刀的时机。
- 若林恩选择穿原初斗篷再出门作战，则游魂巷黑雾下的路人不会立刻认出这位是外人，但黑雾人形会嗅到斗篷上的原初气息、朝他发出齐声尖啸追猎整整十分钟不停息。
- 若林恩坚持赤身裸体、仅以破布蒙面的方式冲出旧店，则他在游魂巷擦过血娃娃母女身边时血娃娃会忽然亮出一声「好大」的惊呼，母亲头颅皱眉训斥，留下事后巷内孩童的一段都市传说。
- 若林恩走游魂巷时主动用原初之力在脚底塑一层薄金护板行走，则赤身扫街的他由裸奔变成金身狂奔，被远处信标有意截屏记录成「裸金冲魔」词条发去黑堡夜医进行嘲笑。
- 若林恩进钟塔后先用拟化把整条破木梯填平为一块斜面，则三个四肢着地的污染者的俯冲优势被破坏，他可以集中精神应对上方的飞行个体——代价是他无法用斜面往上急退。
- 若林恩在缠斗中先用爆炸药剂把钟廊洞口暂时轰塌，则他赢得五秒的真空窗口集中处理下方局势，但坍缩的碎石也顺带压伤他的脚背，他只能就地指挥旧躯在原地哀嚎数秒。
- 若林恩在塔内以高于污染者的速度连斩下两只四肢着地的污染者，则余下一只会见到同类被毁后学习拉开距离避开横扫，林恩以故意露背诱敌才诱出它再一次冲刺。
- 若林恩在塔尖触到伤疤状裂隙时突然放手、改为不间断维持原初之力输出整整十秒，则裂隙会在强制牵引下收缩成一枚黑珠，但林恩的旧躯右臂三个指尖被震成永久的紫黑色。
- 若林恩在钟塔遭遇飞行个体时以链锯之高热档逼其降落，则该飞行个体的翅膜会被高热灼伤、只能在地面扑腾，林恩得以用爆炸药剂精确点名控制它的反击。
- 若林恩在缠斗间隙废弃面具暴露自己的脸，则黑雾中某人形残魂顺着他的气味认出「是血锯家的小林」，它下来与林恩短暂接触——这具人形亡者生前是血锯的学徒。
- 若林恩决定先绕过钟塔、直奔荒野寻找第二污染源，则他会与刚袭来的殉难者哨兵正面遭遇，紫黑甲胄上的秩序王国徽记会让他提前明确敌方阵营归属，但也失去钟塔充足备战的资源。
- 若林恩在与殉难者哨兵缠斗时硬是用骨钻撬开对方甲缝的螺栓一穿二，则破重甲的骨灰会在哨兵身周像蝴蝶飞舞一样焚烧，林恩以光焰包裹整条右臂被迫弃甲逃生。
- 若林恩穿戴火龙动力甲迎向亵渎骑士的冲锋，则甲面被骑士长枪贯穿、林恩本人被冲击力撞飞几十米外因体温上升而晕眩，他借爆炸药剂逃至一处侧巷才避开第二段冲锋。
- 若林恩耐心地等到亵渎骑士冲锋完毕、马匹放缓时施用原初之力对其长枪尖端进行重熔，则长枪会在下一次刺击时被那股力量直接熔断，骑士本人被惯性甩下马跌落、被林恩快速击杀。
- 若林恩在封锁最后裂隙前选择拖延时间应对援军增长、而非立即闭缝，则黑雾递送援军的速率会持续升级，他在封缝的前十秒里将被逼退两次、狼狈之程度创下此役最高纪录。
