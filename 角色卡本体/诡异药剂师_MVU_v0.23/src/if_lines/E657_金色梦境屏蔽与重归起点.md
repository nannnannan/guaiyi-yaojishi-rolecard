# E657·金色梦境屏蔽与重归起点·if线

- 若林恩不用金色梦境屏蔽因果而改用其他方式对抗封锁，则变形：被拉回的节点会改变，因果裁剪会以另一个形式发生。
- 若林恩让涟漪自眉心缓慢覆盖全身而非瞬间，则遮蔽能更彻底，但梦境的消耗会同时翻倍。
- 若林恩在感到异样的第一瞬间立刻强行解除梦境，则他能避免被裁剪拉回，但他会被扯出半截因果、当场脱力。
- 若林恩让涟漪只遮蔽四肢而露出眉心，则他被拉回时意识仍然清醒、能立刻反抗，但代价是核心因果链更容易被剪中段。
- 若林恩在被拉回深渊第一位面后先按住胸口不动，则围攻的神灵会在数秒内完成合围，他再想起身反攻就迟了一拍。
- 若林恩在被拉回后立刻点燃罪火强突包围，则他能撕开一条血路，但因果神王会立刻追加一道裁剪、把他重新拉回起点。
- 若林恩在被拉回后立刻拔三叉戟指向魇王，则他能迫使魇王先退场，但因果神王会立刻接管对他因果链的实操。
- 若林恩在被拉回后朝因果神王方向投出金色长矛，则他能立刻撕开一条路径进入主宇宙深处，但他会失去揭穿因果神王位置的关键一击。
- 若林恩在被拉回后用心去突破魇王的包围圈，则他可以在金色领域范围内虚拟地脱离因果封锁。
- 若林恩接受被裁剪回来的事实、虚心求教因果神王，则他能获得一线生机、飞向因果神王的一侧，但他也会冒犯因果神王的耐心和意思。
- 若林恩立刻发动金色梦境把自己封在金茧里不让因果接触，则他能以「无因无果」撑住两拍，但因果神王会立刻识破金茧的存在并对它进行拆解。
- 若林恩在被拉回后立刻朝织梦斩出的大裂隙方向而逃，则他能脱离这块被团团围住的空间，但他会被因果原则推向离织梦更远的地方。
- 若林恩在被拉回时朝因果神王问「你们剪了我哪一段」，则他能立刻得知敌方想要让他相信的因果片段，他能以此推算几招棋的走法。
- 若林恩在被拉回时全力以赴防守而不是突围，则他能在第一波捍卫之后保住一命，但他无法突破因果神王和魇王双重防线的压迫。
- 若林恩在被拉回时立刻点亮罪火和星寂，则他能同时攻击多位神灵与卷入他们中间的魇，但他会承受远超自身极限的因果断链后果。
