# E450·天空城搬空与黑夜城坠落·if线

- 若林恩在王骑口谕落下后再多追一句「一言为定」,则后续广场地面陷落与地板砖失踪在众狱卒眼里多一层「他自己答应的」合法字样,王骑眼角抽搐段会晚一拍才出现。
- 若林恩登船前先把圣殿门前的大君雕像用粗绳打两道死结再挂上船尾,则无尽海上空那缕彩带式飘荡的画面更富威胁性,黑夜城众根源从天边认船时会先认出雕像轮廓而不是木船本体。
- 若林恩卸船前反手把圣殿门槛下面一条青石板路面也整排铲走,则天空之城广场地面陷落的深度会再多两寸,狱卒暴怒的台词里多一句「他把我们垫脚的路都扒走了」。
- 若林恩把大君雕像改绑在船身侧面而不是挂在船尾,则飞空航态更颠簸,小小扑船的抛物线会被迫再偏一枚舰尖,后续撞城落点偏移到城外荒野。
- 若林恩在装货途中先对康斯坦丁提醒「你别挪脚」,则孽主踩脸段会被转嫁为孽主蹬骷髅眼眶的笑话,船上的争吵剧本会换了主角。
- 若林恩强行催孽主再用内空间多装一座钟楼,则孽主「塞不下了」的台词声调会再拔高一截,但小丑「掌好舵要翻了」的呼喊仍准时到达。
- 若林恩在冲黑夜城警报瞬间先以心声喊一声「我是林恩,别打了」,则五大根源备战姿态会滞一拍再认人,小小一路抛物线冲船的时机延后半秒,夏娃扑粘窗口仍准点打开。
- 若林恩在小小头碰到舷缘时反手递上一枚备用血包招待,则她舔脸段会被她先原地咀嚼替代,亲昵开口被推后半秒,后续撞城轨迹仍走原线。
- 若林恩主动让小小先用触手勾住船尾而不是一头砸上舷面,则她上舷的姿态会更稳,夏娃的血管触手也得挪到船身中段,但撞城蘑菇云仍准时升起。
- 若林恩抢先对夏娃敲响心灵警讯「现在不能上来」,则她那庞大身躯扑粘船壳的动作会被迫慢一拍,蘑菇云改在城外荒野开启,黑夜城二次重建区不会被砸伤。
- 若林恩在撞城前一秒把怀里的喵喵逆风甩到船外荒野,则她被气浪推到城边不被蘑菇云卷入,后续她被小小一起抱进广场时充当两人之间的亲昵缓冲。
- 若林恩在被艾雯训斥时主动在小板凳上多压一本《灵能导论》垫坐,则他坐姿被误认为是在顶撞,十五分钟被拉长为二十分钟,训斥中途被迫多问一句「你怎么坐得这么高」。
- 若林恩在被训斥瞬间主动吐血扮重伤,则艾雯会被迫中断训斥先叫夜医抬担架救场,十五分钟被压缩为七分钟,但「最恶劣调教」商议仍会准时召开。
- 若林恩主动把船上那具大君雕像先丢上广场作为「见面礼」,则艾雯训斥会在雕像落地的轰隆声中被打断一拍,「拐来船长」一事在他的震怒之前被先一步泄出。
- 若林恩在被训斥期间真诚提议「让我赔偿黑夜城损失」,则艾雯的怒气会滞一拍,他多出一缕「他居然赔得出」的惊讶,后续灵能课宣告被直接立为赔偿条款的一部分。
- 若林恩在小小舔脸瞬间顺手吞下一支镇定剂,则他表面平静,系统面板上会多爬一行「黏腻同志」的标签,后续训斥期间小小会选择蹲在他脚边守护。
- 若林恩在被训斥末尾自发从系统空间抽出一营罐头砸在广场上作为「谢罪礼」,则艾雯的怒气反而再多一道上扬,训斥又被追加十分钟,「max收获」自白在他眼里被压为废话。
- 若林恩让左左从怀里飞跃出来在被训斥期间故意卖萌,则训斥会被迫再断一拍,小小也会起身跑过来保护他,训斥基调由「暴怒」改为「无脾气长谈」。
- 若林恩以「船长是我拐来的,可别赶他走」开场先自贬后抬康斯坦丁,则康斯坦丁会以「被拐来的受害者」身份落定,后续他与黑夜城结盟的切口被提前打开。
