# E455·死兆级评定与战争宣告·if线

- 若林恩在艾雯亮出品前便把左萝从意识里拽出来压在肩头观礼，则小丫头全程咧嘴旁观重型机甲升台，事后在左左面前连续三天炫耀「比主机里那些玩具结实」。
- 若林恩在链锯机炮标记红光锁定瞬间抬手把最左那台的链锯扭成死结再下压，则那台机甲右臂在自旋中把自己肩甲削开，艾雯在评定页边栏用红笔写下「零件回收率下降三成」。
- 若林恩全程不开泰坦压细胞，纯以夜医手术刀的精细走位避开弹幕，则三台超凡机甲弹头全部嵌进他脚后半步的钢板上，监控补拍的弹坑被艾雯当作七年期训练教材。
- 若林恩被一道微型炸弹攀上肩头的瞬间反手把它摁进自己衣领、用体温引爆，则血气冲散火光的同一秒他锁骨留一块鸡蛋形烟痕，后续整整一月笑纹都挂在那里。
- 若林恩在三台赛博灵能者虚化束缚时主动往精神力网心注入一缕以M气息，则三台领主级机体的自我意识殖装同时跳帧，艾雯现场记下「意识殖装对标剩 86%」。
- 若林恩接死星结界匕首那一秒没偏颈，反把颈侧迎上去让匕首尽数没入再一把攥住，则拔出的刀尖上串着他自己的血珠，艾雯罕见地沉默两秒才把「作弊」口径咽回去。
- 若林恩拔出匕首回掷、故意擦过最近一台机体的反应炉外壳，则那台赛博灵能者在接下来七秒内全程僵直，被剩余两台误以为是自己人打了一炮。
- 若林恩把事后颈伤留给左左舔而不当场愈合，则她在意识里小声嘀咕「不许扔掉」，绑定层 +1，但他在后续第二场对拳时被打得退步多两步。
- 若林恩以血肉把整条手臂锻成半透结晶状再接对拳，则轰飞那台机体的同时碎屑在他小臂内侧划出三道白印，事后左左坚持要用咒纹把它们补成纹身。
- 若林恩在手掌碾盘扭空间时故意把其中一台捏成球形，则球化废铁被艾雯刻上编号「MECH-E455-03」放进战利品室，一月后远征军出发它被作为仪式炮弹出膛。
- 若林恩在三台领主级合围时反向弹出十根指骨钉进自己掌心，则血雾爆开冲垮虚化，他的双手战后足足三天握不紧拳。
- 若林恩对艾雯提出「死兆级靶标能不能让我挑形态」，则她答应让他等十分钟，升降台多停一档，士兵在走廊里看见有人推着一具未熟机体往回走。
- 若林恩在黑袍靶标出场瞬间脱口报出那台机体记忆里某个旧编号，则它淡蓝双瞳短暂闪烁半拍，艾雯在事后把它从死兆榜降级标黄。
- 若林恩在阶梯评定中段抽空给巨像之脑打一道通讯请求并在得到应答时挂断，则那台银瞳女孩愣在原地五秒后才想起自己也在等他的回话。
- 若林恩在君王栏「×」落下前主动一拳击退黑袍并蹲下摸它掌心，则机体握住他的手指不松，被机械关节压出一圈白痕——后续爱丽丝爬出时第一眼便是这道白痕。
- 若林恩在艾雯喊「不留情」时反问「要不要真杀我说的算」，则她郑重地点头并在评定栏顶划出「主控交还玩家」，之后所有王牌机甲听令动作灵敏上调整整一档。
- 若林恩把超凡三机残骸各摘一块链锯碎片贴身收藏，则他背包多一组「评定回执」，后续战火打响时管理员会给夜医部队优先出一份「良医的战利品凭证」介绍信。
- 若林恩在多机夹攻时主动让自己鼻子中一拳鼻血直流反笑出声，则他整张脸被血涂鸦，艾雯备注「受试者可能享受此过程」，后续言辞多加一句「别太惯着他」。
- 若林恩在万花筒现身最后一拳前停半秒让那台机体把匕首完全抽出，则它反手把匕首横在自己反应炉前，被林恩贯穿时是一张「自己找死」的姿势，艾雯判定「自我意识已具生死决策」，档案 +1。
- 若林恩在听说「死兆才能横着走」的瞬间笑着打断说「那我偏竖着」，则三台赛博灵能者同步后退半步，艾雯罕见地抿嘴、之后整整一周没再用「横着走」这种口吻。
- 若林恩在黑袍靶标无声站立时大声点出袍下那条苍蓝脉搏，则它第一次动——一只根节指骨轻轻碰袍缘，像是对「被察觉」环境的本能回应。
- 若林恩全程不动用任何外置殖装纯以基础血气与灵能拆解，则战后他在面板里多一项隐藏称号「裸装破格者」，但 Titan 法与巨像循殖的同步率在该日下滑三个百分点。
- 若林恩在评定尾声牵着爱丽丝的手在全场机械面前走一圈再还回机体，则小女孩的裙摆在远端监控里被夜医技术员截成壁纸，三月后仍糊在萨克森蜂巢新兵训练舱内壁。
- 若林恩在黑袍靶标退场瞬间朝它背影比了个中指，则机体停顿反身回礼（半抬手又落下），艾雯在日志末尾用铅笔写一笔「被试者的挑衅已开始有回报」。
- 若林恩全程不用三甲医院级灵能感知、只让眼球拟形贴在墙缝里读取蓝光，则他在出战时坐拥整张评定场的全息图，但那一日左萝在意识里被压得连话都讲不出一句。
