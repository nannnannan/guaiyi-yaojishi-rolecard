# E164·部分降临与恶灵聚合体镇压·if线

- 若林恩把拍回的子弹一颗颗签上编号再弹回亡魂眉心，则受控躯壳倒下的顺序呈一种病态几何美感，总局猎魔人在远处望远镜里看得后颈发凉。
- 若林恩触手横扫时主动绕过白逸身边三尺、留下一个干净的扇形安全环，则白逸首次感受到「被自家人标记保护」的踏实，E165 求援意愿 +1。
- 若林恩故意让七八只亡魂逃进迷雾再追，则聚合体产生「还有残部可调度」的错觉，误入林恩触手预设的回形阵。
- 若林恩在聚合体翻墙瞬间顺手把墙垛血肉化、长出尖刺朝它膝盖插，则「我知道路！！」变成「我不知——啊——」，逃跑喜剧效果拉满。
- 若林恩让触手末端那只眼闭嘴不讥笑，则聚合体在死胡同里多琢磨三秒、才被吊起，羞辱等级略降但猎魔人误以为「此怪有教养」。
- 若林恩抽屁股教育的话改成「问你话就砍我一刀？那你妈妈有没有教过你，打完人要自己擦血？」，则「妈妈」一词在聚合体意识里第一次产生近似恐惧的回响。
- 若林恩聚合体卷起后不摔打、改把它倒吊在裂隙正上方当诱饵，则尚未合拢的裂隙被它恐惧的阴气滋养，垂落时间反而再延一拍。
- 若林恩让亡魂被摔出时一个个嘴上贴了林恩血肉小标签，则这些亡魂脱困后无一敢逃回超自然总局档案，全部变成「未知疫医实验过样本」。
- 若林恩在吊抽过程中故意给每名被吓住的士兵安一根视觉共享神经，则总局事后回看视频时全员同步感受半秒眩晕，档案上对林恩处置等级上调一档。
- 若林恩主动朝白逸传一条心声「下一步你去抱住你姐，别站太近我这边容易溅血」，则白逸急转身扑向尹琴，急救窗口的亲情加成落地。
- 若林恩在总局增援翻进村前先用触手把村委会的喇叭线接起来、放了一段类似乡村大喇叭的电流杂音，则增援队以为「此村村民已疏散且民兵组织在线」，战术分歧多两条。
- 若林恩把「跑吧，你越跑我越兴奋」改成「跑吧，你跑得越喘我越下得了手」，则话音里那分大叔式嫌弃让总局猎魔人档案多一行吐槽批注。
- 若林恩故意把聚合体的摔打节奏调成「咚、咚咚」三拍一首当 BGM，则后来深夜林恩自己哼这段旋律被左左质疑品味。
- 若林恩施压同时用一缕触手抵住尹依残魂可能逸出的位置不压、只是顶住，则尹依在聚合体体内首次感到「外面有人等我」，配合度提升。
- 若林恩施放血肉灾变时反向压缩体表、把部分存在削得更薄，则他更显「只是一段触手」，总局误判权重下降、部分降临机制的秘密续保一期。
- 若林恩把聚合体卷起来后故意不立刻摔、就让它吊在半空任凭所有雾气从它身上掠过，则聚合体的逃跑剧本被「挂半空当路标」一招彻底封掉。
- 若林恩决定不交总局审讯、直接一口闷下整只聚合体回地狱慢慢拷问，则 E165 尹依分离路径当场改写，白逸强行留下帮她剥离，裂隙稳定性告急。
- 若林恩施虐过程中忽然收手、改用「疫医式检查」指法给聚合体做了一套全身体检，则聚合体在意识里首次困惑：这玩意儿到底是敌人还是医师？
- 若林恩主动留一名清醒猎魔人头目不吊起，则此人事后成为总局内部「不要把林恩列为必须歼灭」路线的第一代关键证人。
- 若林恩在追击聚合体时顺路把村里被附身的狗、鸡鸭也一并剥离，则村史档案留下一条「嘉靖年间古井异闻」级别的野史条目。
