# E286·泰坦暴走与欲望母树之战·if线

- 若林恩看到暴走影像时拒绝「不认识泰坦」的玩笑、当场哽咽，则艾雯爵士把他揪起来继续看，左左感动地为他擦屏幕，氛围由滑稽转为沉重。
- 若林恩主动用「救人 = 高道德」的论述说服左左，则她半推半就接受伏特加，道德账簿开始一份长期负债记录。
- 若林恩提议帮泰坦成立一个「泰坦康复基金」，则黑夜城生意继续顺着荒唐逻辑盘剥病人，但基金名义落在左左名下、她心情复杂。
- 若林恩在备战期间先把克苏鲁之眼强行外显 30 分钟作为威吓，则黑夜城上空起了乌云，血肉神教得知信号加紧蛰伏，但视界之眼的注视可能霎时加深。
- 若林恩决定独自前往血肉神教根据地探风，则他被血肉支配者的残识提前察觉，立下一笔同盟或对立的新账目。
- 若林恩向艾雯爵士提议把 ICU 账单打三折，则艾雯爵士终于勉强默许，但作为代价他要签下一份终生廉勤合约。
- 若林恩在备战前向左左承诺「我让你当副指挥」，则左左精神大振，但实际功勋账簿会算成左左多林恩少。
- 若林恩用克苏鲁之眼吸收周围的旧日残念修补巨像之心，则机体损耗下降，但他会被注入一缕属于旧日不死之灵的邪异。
- 若林恩向羽毛笔求问机械神教死星结晶的情报，则羽毛笔以命运权能透露一缕隐秘，但「被观察」的感觉被钉在他颈后。
- 若林恩提议把备战模拟改成真人实景射击训练，则夜医一众都爽到，但左左和艾雯就他「上班不端疮」的作风开炮。
- 若林恩主动把 ICU 重绘为「冰箱样式」装饰，则病房病人会感受到黑色幽默式安慰、复原率 +5%。
- 若林恩接到切景信号就立刻用自己的方式广播提醒黑夜城戒备，则黑夜城全体感受到被关照，但切景战报被稍推迟。
- 若林恩在切景前主动用心声呼喊视界之主「你可以放他们一马吗」，则视界之主没有回应，但心底记下一桩。
- 若林恩决定把「冰箱加披风」当作战备制服，则黑夜城观感一时哗然，但间离效果被削弱。
- 若林恩主动整理一份针对性备战会议名单，则会议效率 +20%，但沉闷等级直接拉满。
- 若林恩在备战准备中特意摘了左左私下送的小物件作为护身符，则左左心里暖暖的、力量 +5。
