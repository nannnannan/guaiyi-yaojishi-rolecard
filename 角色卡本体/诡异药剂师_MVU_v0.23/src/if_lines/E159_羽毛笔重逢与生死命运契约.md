# E159·羽毛笔重逢与生死命运契约·if线

- 若林恩主动在羽毛笔写字批注绘本时不出声干扰、等她写完再回话，则她的「你知道现在抓着的是什么吗」被改成「你还是一如既往喜欢这种东西」，事件以不变形收束但语气冷度下降一级。
- 若林恩主动在羽毛笔跃上窗台一瞬伸手攥住羊皮纸角落，则她被拽得回头竖瞳冒火，事件以变形（羊皮纸当场撕裂）收束，「命运的契约」字条暂存于残片盒里。
- 若林恩主动念出全句【命运的契约】原文给她听，则羽毛笔瞳孔剧烈一缩，事件以不变形收束但她甩出一支墨羽毛写着「你还能读到我自己也不知道的内容」。
- 若林恩主动在羽毛笔冷笑离开时从五楼追出去反而同样被石头砸下，则他在夜空跌进一片叠羽之网，事件以变形（双双坠楼）收束，出手者首次露出半张遮脸。
- 若林恩主动用咒瞳在她「我要走了」后捕捉她暗中留步的脚步声，则咒瞳记录到窗外月光下一支羽毛悬浮三秒犹豫回去还是不回去，事件以不变形收束但「她还留过一秒」证据存于咒术档案。
- 若林恩主动让步「我不问你交付了什么代价，只问你有没有退路」，则她沉默良久、在羊皮纸上留下一行反转承诺「契约成立即我不悔」，事件以不变形收束但情感纠葛加重一格。
- 若林恩主动当场抽出束缚在书柜下的唯一咒术原型试问「如果我签一份对等契约换你解绑，你接受吗」，则她从窗台才能朝下冲来，事件以变形（对等契约被启动）收束，但对等条款需要玩家与玩家主权协议才可成立。
- 若林恩在状态栏显示契约条目时主动呼叫系统以咒瞳进行【限时鉴定】，则契约读数跳出一句额外信息「契约对象为第一恶魔级羽毛系造物」，事件以不变形收束但羽毛笔真实身份档案多一条隐晦线索。
- 若林恩主动掏出羽毛笔过去落在床底的一片旧羽，则她对旧羽产生微弱共振、留下一句「你留着它做什么」，事件以不变形收束但羽毛笔旧羽成为后续剧情道具。
- 若林恩在她要离开前主动说「如果死亡后我会忘记你，那我现在就记下你所有的羽毛颜色」，则她眼神迷茫三秒、然后甩出一张速写画像，事件以不变形收束但画像嵌入玩家档案代替遗忘后果。
- 若林恩主动让左左挡在窗台前不让她走，则左左与羽毛笔对视 5 秒后双方都冷哼一声回头不理对方，事件以不变形收束但三位妹子阵营互相建立「唧嚷」非正式关系。
- 若林恩主动把契约条款读给左左并要求协商是否接受，则左左从手套里倒竖着拨出来怒吼「我不同意任何替死方案」，事件以变形（左左当面反对）收束，契约变成接下来主线争议点。
- 若林恩在她准备跃下前主动扔出一件外套盖着她全身轰轰轰「遮遮羞」，则她被衣服盖得闷声轻哼、反手把外套叠成一本小册子，事件以不变形收束但反手外套成为冀巾系存证。
- 若林恩主动在家门被石头砸下之前对左左说「推我一下试试」，则左左真的推了他一下、石头砸的位置变成门外天棚，事件以变形（石头曲线闪开）收束，出手者身份依旧不明。
- 若林恩主动追问「你脑子里是否认为死亡后我会恨你」，则羽毛笔沉默不语随后跃下、在窗口留言「我怕你恨我」，事件以不变形收束但羽毛笔的担忧成为后续反省线索。
- 若林恩主动回应「我同意努力活不再叫你替」，则羽毛笔跃上窗台时静默一刻、回头看了一眼，事件以不变形收束但契约情感基调被温柔改写。
- 若林恩全程沉默不语、置身事外读完整卷事件，则默认走向收束，羽毛笔契约作为潜伏合约进入淡水水。
