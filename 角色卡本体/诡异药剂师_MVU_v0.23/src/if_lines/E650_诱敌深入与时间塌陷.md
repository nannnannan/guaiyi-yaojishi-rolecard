# E650·诱敌深入与时间塌陷·if线

- 若林恩没有掷出三叉戟就先暴露自己，则会立刻被十多名神灵集火，他没有时间引敌到高塔海域，事件以他取消收束。
- 若林恩没有闭上双眼而是睁眼定位高塔，则那缕与高塔的联系不会被激活，他会找不到那座孤岛的坐标，只能在幽冥海洪流里盲逃。
- 若林恩掷出三叉戟之后立刻折跃离开，则追兵会锁到中位神尸体旁的残影，神王会在三十秒内接管该区域，诱敌节奏被打破。
- 若林恩撞上那五位神灵时只用星寂不开白烬而是骤然熄灭，则他们会以为猎物濒死、掉以轻心冲到近身，林恩能借以初诞者之力瞬杀两人。
- 若林恩在盲遁幽冥海的时候主动放出一缕疫医气息，则几支追兵队伍会在洪流尾端嗅到这场假气味，多绕出十分钟，但疫医气息会被金色少年一眼识破是诱饵。
- 若林恩在洪流中反向逆流，则他能甩开半秒，但众多追兵会凭着身体对流向的直觉在另一边设伏。
- 若林恩在进入高塔所在海域前回头戮杀一位掉队的中位神，则他的位置会第一时间被金丝记录，诱敌成功但自身被锁得更紧。
- 若林恩让左左独立从另一端冲向高塔、两人分两线引敌，则追兵兵力一度被分薄到一半，但左左没有他身边作为一环就会被无止境地追下去。
- 若林恩先对孤岛发动一次冲击去测试高塔是否有禁制，则他能探到那道抵消无序冲击的隐约阻力，但金色少年会趁乱加快收网令。
- 若林恩只催动白烬不带二档就冲击时间涡流两次，则他被反噬得更轻，但那次「时间之外」的旁观画面会更模糊，白发身影的轮廓不明。
- 若林恩在探入时间涡流时特意保留一段自身意识写下的回溯锚点，则他在第二次尝试撞入时能更快解开涡流层状，但锚点一旦丢失就回不去肉身。
- 若林恩让左左握住白发身影画面里绿伞的手柄拓印下来，则她能在 E651 之前多一条对那支伞的认知证据，但那一刻她的意识会被那道画面拉住半秒。
- 若林恩在自己被压到孤岛上时不放出棺椁，则变形：棺椁不出现龟裂，时间塌陷改由高塔禁制主导，他本人会在涟漪定格外被压得更久。
- 若林恩单纯倚靠高塔禁制挡下一百道无序冲击而不动用自己的初诞者之力屏障，则他的本源燃烧不会发生、蜃影周期延至第三秒才被压上，但禁制会因此提前崩溃、塌陷更早落下。
- 若林恩在空中把棺椁往上抛让它先挨第一波，则棺椁会立刻出现第一道大龟裂，但林恩仍能借棺椁残余的护体多撑一秒，代价是它一开始就咬掉两根钉。
- 若林恩引动棺椁在时间涡流里主动撕开一角让他们能通过那道缺口，则他可以避免被时间塌陷抛出，但同时会感受到白发身影的目光在那一瞬落到他身上。
- 若林恩让左左代替自己在棺椁中凝聚二档罪火，则她能在最终冲击里撑起一堵比本体更大的绯红护障，她会承受比原定多出三倍的反噬、陷入一段时间的失聪。
- 若林恩在孤岛上让白烬顺着黑发少女的方向引燃，则他不会得到任何回应，但那缕火光会在无序的湮灭顶点上多钉一秒。
- 若林恩在时间涡流里尝试向白发身影高喊「是你在等我吗」，则不会得到答复，但他的声音会在塌陷里被记住，下一次他在时间尽头再度听见那声音时它将认得他。
- 若林恩在心中重复默念棺椁的旧世大君姓名并加一份恳请，则棺椁不会在冲击里彻底崩散，而是留下一块指甲盖大小的铁皮。
- 若林恩在自己被抛出时间长河的前一刻死死攥住左左的手腕，则她不会被立刻定格在时间长河之外，她会随他一同被抛到时间之外，E651 的金色茧会因此扩出更多的涟漪。
- 若林恩不喊名字而在心里默默推衍这整座孤岛的因果走向，则他能在时间塌陷落下前的最后半秒意识到一切，落地后他对孤岛的禁制有更清晰的直觉绘图。
