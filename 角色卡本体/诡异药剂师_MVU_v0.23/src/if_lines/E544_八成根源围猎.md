# E544·八成根源围猎·if线

- 若林恩在观战根源触手轰击时直接以死亡法则反击而非躲避，则突袭方当场减员，人偶家代理通牒的台词由「统一或死」改为「血债血偿」。
- 若林恩躲开触手后立即朝船长靠拢而非原地站稳，则两人未被拆散，船长被拉回心灵之海的环节缺席。
- 若林恩在切法则视角发现丝线后立刻斩断最近的数条，则被控根源醒得几位，但人偶家暗门激活的时点提前。
- 若林恩在「人偶家」名字出口前先用心灵法则扫描全战场，则代言的根源被预先识别，「统一或死」通牒的突袭力下降。
- 若林恩拒绝念出「人偶家」而选择沉默对峙，则通牒改由其他被控根源开口，但内奸指控的焦点会更早指向银幻巨像。
- 若林恩当众宣称「一人之力即可破阵」而未发动力量法则，则城内外对其战力的预期被吊高，泰坦冲锋时的情绪反差更大。
- 若林恩把死亡法则转化空间洪流的速度再快半拍，则人偶家的「泰坦！」召唤略迟，砸散空间洪流的戏法不一定能成。
- 若林恩未拒左左的催逃，则他退回内空间暂避风头，「真战场无准备」宣言被搁置，围猎的压迫感化为冷却期。
- 若林恩主动用空间法则先把已聚拢的根源打乱传送而非逐步切割，则战团重列的速度赶不上下一波冲锋。
- 若林恩对泰坦族的感知在泰坦未到之前即启动，则他能先以力量法则与后辈接头，族长赴援的剧本被部分改写。
- 若林恩让左左控身拔刀刺地后立刻让她协助布置心灵印记防线，则他不再单纯靠硬撑，丝线钉十字架式的画面不现。
- 若林恩当泰坦逼近时选择以毁灭法则而非力量法则正面对拳，则极高位的对撞产生新等级的毁伤，「不愧是大哥」台词的对象反转。
- 若林恩在泰坦冲锋路径上短距折跃失效反被锁定后改投心灵之海暂避，则战场被转移到梦境，公开层见证中断。
- 若林恩未举掌欲聚空间洪流，则人偶家无需立刻唤泰坦，战神上场时机被推迟到林恩酝酿第二套路。
- 若林恩封神级声明「举目皆敌我愿陪到底」而非「你要战那便战」，则台词风格由狂放转为沉郁，围观根源的情绪链偏移。
- 若林恩选择先以力量法则斩断身后数条心灵丝线而非直接战斗，则解开部分被控根源，但人偶家立刻升级更深暗门。
- 若林恩任由被控根源以伤换伤以命换命对自己贴身围攻，则他要么硬吃一击要么破例退避，画面张力更高。
- 若林恩让人偶家的代言根源改用冰冷女声而非沙哑根源口，则「人偶家操控」画面感更浓，围观者对其身份的破译速率提升。
- 若林恩在主母或艾雯以心声称他为林恩随口回应，则身份暴露的窗口被围猎压力强行提前，人偶家代理剧本破产。
- 若林恩让巨像和银幻通过心声反向证明自己不是「内奸」，则人偶家指控链条动摇，暗门激活的可信度被破坏。
- 若林恩在力量对拳落于下风时立刻涌现左左提醒「大哥比船长还强」，则他能提前准备放逐工具而非被动挨打。
- 若林恩不称「不愧是大哥」而称「太可怕了」，则台词情绪从敬佩转为战栗，围观的求战心态被打压。
- 若林恩私下把「为何不逃」的逻辑提前讲给左左，则她催逃的叫声更弱，林恩的孤胆画面更完整。
- 若林恩让原子机械在战场周围投下录音石，则整场围猎被黑夜城档案化，后续身份暴露时的对照素材更丰富。
- 若林恩在代言人偶家开口前先呼唤「想要我的命，请发到心灵之海直接联系」，则通牒的对等性下降，人偶家公开度被压缩。
