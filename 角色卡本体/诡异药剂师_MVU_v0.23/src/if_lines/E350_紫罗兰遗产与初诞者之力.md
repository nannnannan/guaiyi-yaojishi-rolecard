# E350·紫罗兰遗产与初诞者之力·if线

- 若林恩在白夜与几名持刀鸟嘴夜医推门那一刻主动盖住自己与左左的姿势不让被撞见，则白夜不会停步道歉、他看到的是一幅得体的场面，探病流程会按既定问诊路线直接展开。
- 若林恩在鸟嘴夜医说「刀到病除」时主动询问具体刀法与可能的副作用，则白夜会第一次对他解释夜医与手术刀的关联，这一段询问被记入诊断前的首发问答中。
- 若林恩推开夜医要走动前往大厅，则鸟嘴夜医会跟着他一路步观，室内身体对话被下地这件事替代，这一临时移位让林恩自己有机会一路观察黑夜城的复生现状。
- 若林恩在巫神头颅还没开口提醒「灵魂在分裂」之前主动把「我还没准备好接受大君那一世的力量」说出口，则巫神头颅不会重复警告，小小的触手也会自然绕到他的手腕更少力气。
- 若林恩听到「变成白痴」那种警告时只是笑一声说「我不会让自己变成白痴」，则巫神头颅会首次正眼打量林恩作为主位的态度，关于灌注的口头协议在他这里直接被改写。
- 若林恩在小小提醒他小心时主动握住她的手、别让她只缠手腕，则小小会感到身体一震，整个看护的氛围从她单方面警戒转成复杂情愫的接触。
- 若林恩询问尝试这种力量具体会让白发人回来的几率为多少，则巫神头颅会给出大君孤身过往记忆合并湮灭的否定答案，过去的复苏路径在他这里不会再主动重现。
- 若林恩在法阵盘坐的那段时间里主动把肢体姿势调整成大君曾用过的那种，则半个时辰后他的躯体开始透出未曾形容过的古老威压，巫神头颅首次在面谈中露出惊异的表情。
- 若林恩持续试验一段时间仍看不到那缕黄沙，则法阵上的无瞳之眼会有一段时间没有亮起，黑暗海域记忆里大君白发背影的画面反过来流入林恩的体感。
- 若林恩在满头白发开始一寸寸退散的时候仍保持深呼吸全程不动一根手指，则退散速度被他的身体控制显著延缓一半，巫神头颅首次赞他身心协调度超出想象。
- 若林恩在那缕黄沙真正浮现的那一刻只是微微一笑，则左左原本已经准备哇哇大叫的惊呼被他的表情截停，珍贵的火苗就在他的指缝里烧得安然。
- 若林恩第一次驱动黄沙成功后主动把那一缕黄沙引到左左手心让她接触，则她的小手会在黄沙接近的瞬间缩回、伸出不只一点不自觉的警惕，黄沙在她皮肤附近会被识别为位格过高的外物。
- 若林恩在驱动后主动开口说「黄沙现在就只是一缕霞光」，则巫神头颅的表情首次从震惊落入稳定，他会承认林恩的评估符合现实：目前的强度与当年大君相比连零头都谈不上。
- 若林恩在巫神头颅提到同行的赛博恢复过程时主动提出亲自去看望她，则随行队伍的目标会从「伤处援护」切成「疫医主宇宙同伴关系把握」，巫神头颅对此的响应更加复杂。
- 若林恩听到小小的自责时主动把她整个人从轮椅上搀起、背到自己背上让她贴着他爬行一路，则小小会感到眼眶一热，她背着双手把脸贴在他后肩上伤心抽泣着说「我不想她救过一次反倒连累你」。
- 若林恩在主宇宙调查报告里发现某位曾被大君所救的疫医系统合作者记录，则他会当着巫神头颅和同行者的面把这段档案念出，现场气氛从追忆切入互相尊重。
- 若林恩在巅实际发出一缕黄沙试图催动医疗级别的治疗，则黄沙会反射出拒绝性质的光芒，病灶不会真正消退，巫神头颅会指出黄沙本身位面高于纯医疗它有自己的边界。
- 若林恩询问「初诞者之力到底在哪里存在」，则巫神头颅不会给出明确答案，他会指着林恩的手心说「它就在你体内，你要寻找的是在哪里可以打通它的通道」。
- 若林恩尝试驱动黄沙的过程反过来感到龙背血脉的刺痛，则他首次清楚地感应到与大君同源的黄沙之力并非无偿获取，这种压力会在他体内逐渐累积。
- 若林恩在仪式完成后只留下一枚外界根本感应不到的符文留作为大君痕迹，则巫神头颅不会注意到、但流浪中的疫医们会在修行途中远远感到这股隐隐的能量波动。
