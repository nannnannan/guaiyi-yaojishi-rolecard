# E153·古老狱规回应与生死反转·if线

- 若林恩只将羽毛笔的部分病变转移到自身、留下一半仍由羽毛笔承受，则双方各保留一段可见纹路，倒计时按实际比例被地狱记录，E154 的剩余期限相应减半但折磨层级同步加重。
- 若林恩在书写进行到一半时按下笔尖撤销授权，则权柄未完整生效，狱规未触发回应，羽毛笔继续背反噬，左左当场崩溃、拖行求救段落改写为持续照护。
- 若林恩在动用羽毛笔权柄前先把左左托付给艾雯爵士或人偶小姐看护，则拖行求救不由左左独自承担，左左只负责守夜与信物传递，失态戏份转移到闻讯赶来的家人群身上。
- 若林恩在书写前向羽毛笔本人提一个交换条件（如仍以自身名义担责但要求局外探视权、信物或一句谎言），则羽毛笔在沉睡中留下额外微表情掉落物，E154 真相核对多一道旁证。
- 若林恩主动署上「血肉支配者」之外的另一重身份抬头（如血肉锯药剂店主理人、黑夜城疗养区合作药剂师）再动用权柄，则猪头屠夫裁定对象更换档案编号，地狱观测条目里的对立名号临时改写，但其主人层面的定性仍然成立。
- 若林恩在写下承诺时刻意留白一部分文句给羽毛笔本人补笔，则权柄双向接通，诺言内容不止「你永远不会死」一条，地狱回应强度同步抬升，复苏节点延后但保命加成扩大。
- 若林恩拒绝当场动用转移、改口要求羽毛笔先偿还「幸福的抵押」，则狱规未启，事件变形为「权柄议价与反噬拖延」，倒计时替代为分阶段偿付排期。
- 若林恩在主母与泰坦争吵升级时立即让人偶小姐或黑弦月出面仲裁，则「全城陪葬」口头宣言被压制，主母辖域未画押，疗养区秩序保住，但泰坦一家对林恩的亏欠账再次加码。
- 若林恩的临床死亡节点恰好撞上替死娃娃随身挂载，则替死道具未如原著那样沉睡，反而即刻强制结算一次，复苏度数字下调、135% 极限窗口不再出现，复活路径改写为替死结算+自然领域神性残存。
- 若林恩失去自愈与灾变维系后仍硬撑意识、让巫神以幻手深度介入心脉，则复苏拉长为数日，左左与小小轮值守夜细节延长，护士「诈尸」惊吓戏份后移。
- 若林恩让小小在自己濒危前就挤到疗养区床头，则小小的冲撞路径与泰坦的陪葬言论撞车，冲突提前爆发，事后疗养区多出一道「不许父亲乱说话」的家规式默契。
- 若林恩在次日直挺挺坐起的瞬间选择沉默而非应声，则「诈尸」尖叫升级为整层报警，巫神与艾雯爵士必须亲自下场做身份确认，复生消息在黑夜城圈层内更早扩散。
- 若林恩在疗养期间对外只宣告「还是死了」，则外来求诊与盟友吊唁同时涌入，局外势力（银色幻想、疫医残部、万机之神信众）各自解读，主宇宙资讯面出现多日误导窗口。
- 若林恩以濒死身躯仍坚持把「未明效力的诺言」用录音笔或左左手写稿记下，则后续核对羽毛笔许诺效力时多一份铁证，E154 的语言漏洞陷阱被提前封死大半。
- 若林恩在猪头屠夫的「答应他」裁定传回前主动向八音盒小丑隔空致意或开嘲讽，则小丑观测到的扰动做大，其主人对林恩的关注等级上调，E154 之后的试探升级。
- 若林恩让巨像之脑在抢救期同步调用主宇宙记忆库比对「自然不会死」语源，则「欲望母树嫌疑」与「其他候选」并列建档，为后续揭谜保留多线并行选项，违反「严禁锁定母树」的提示依旧成立。
- 若林恩不在乎公开泄密、让血锯药剂店临时营业挂出「店主恢复期」告示，则游魂巷熟客、血衣旧识与黑弦月探子轮番上门，疗养区治安与人情账双重重排。
- 若林恩以M路径应对复苏后的空虚疲惫、主动向已解禁成年同伴（人偶小姐或主母）索取抚慰，则以M成立，身体反应与解咒式亲密并入疗养段落，但「复活主因」秘密仍未被抚慰过程触碰。
- 若林恩在疗养区提前宣布「剩余期限一定会再来、不如先演练一次地狱折磨」，则巨像之脑受控模拟的时点从 E154 提前到本事件尾声，事件边界变长但 E154 开篇压力减小。
- 若林恩在羽毛笔留下诺言离去的瞬间试图把对方留下继续对谈，则羽毛笔仍可退场，但留下一段可被左左听到的低语残句，疗养期梦境侧多一条可供追踪的线索。
