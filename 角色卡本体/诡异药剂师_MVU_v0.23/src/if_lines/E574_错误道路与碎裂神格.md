# E574·错误道路与碎裂神格·if线

- 若林恩在挖出枯骨前主动用三位一体机打个小型土钻而非亲手掘沙，则土钻触及骨瞬间就停，「与死者直接手触对话」这条通道被系统机能替代抽走。
- 若林恩手握单片眼镜前主动先感受一下它的重量感与光泽在掌心的接触，则那滑动让他感受到某种「高端文明」的温度差异心。
- 若林恩在听到「另一个林恩」残识自述时主动请求三位一体机全段录音而非任由自己聆听，则那根「第二个初诞者」的宣言在他面板中落成一条独立音频档案。
- 若林恩在摸神格碎片时主动先捡一片瞧并不触摸，则碎片的光芒未有赋予他，他偶然注意到这些碎片上一些有血迹。
- 若林恩主动在残识传递过程中提问「被称为第二个初诞者具体会导致什么的时候」，則那个第二初诞者接过残识意志的画面被他重新解读为一份「为创世被献世之上」的悲壮。
- 若林恩在破碎的神格旁主动让系统记录碎片并反神识，則系统中伪神识关于他们脚下这些神格背景数据首次实打开。
- 若林恩在接触巨石中残识前主动询问「你是已经死透了只留意念，还是还有生命气息」，则模糊的残识没有答复，林恩也得不到答案。
- 若林恩在巨石石刻前主动将自己的手心对准石刻笔画的起笔点，则按着那股「这是我的笔迹」的认知，那种孪生笔锋辨认之快感被取代。
- 若林恩主动理解「初诞者」这逻辑时先调出系统面板让其辅助判断，则系统报错，因这个概念超越其运算，残识自弃的孤独感来自他自身。
- 若林恩在听「这个世界只会有一个初诞者」时主动让三位一体机默认录下「这个世界只会有一个初诞者」这段话移到最终结论以设置后手，則他的明白动作加入更多变量。
- 若林恩在理解「我的路错了」时主动追问「错在那一开始」，则残识回以终直而是在他成初诞者的那一刻就天地同契沦陷，林恩情资质感到一丝残存。
- 若林恩摸到神格碎片上血渍时主动用三位一体机扫见来他怎么留下的碎片，則那个血渍在面板里呈现异样的痕迹，与他身上熟知的灵魂中血痕相似。
- 若林恩在摸巨石残识前主动把自己的意识调整到「接受一切真相」的宽松状态，则他感受到残识中那些深邃的苦闷沉郁相对短暂，心痛减轻半分。
- 若林恩主动在离开遗址把巨石中残识最后一点意识灵光再捕获了一瞬上口的神格碎片，則那道残识中口中断定他「原本想成」已描住他心感但神格碎片早已碎技。
