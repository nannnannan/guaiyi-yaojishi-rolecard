# E168·双生关系危机与共同过夜·if线

- 若林恩在巨像之脑捶倒他之后装死三分钟不动，则她抱着左左走远又回头一看、这混蛋还躺在地上，最终她叹了口气让侍卫把他抬进偏殿，同床剧本被降级成「同屋分床」。
- 若林恩在集市上主动当着满街路人跪在左左脚边磕头认错，则「我不跟那个混蛋了」的底气瞬间被一根软钉子戳破，她只好扭头勉为其难说「回家再说」，离家路径临时收回。
- 若林恩在左左「挖出来就变成没用的废物」的嘟囔后接一句「你看你还是心疼我」，则她当场炸毛、但又反驳不出，巨像之脑趁机在旁补刀「那你还要不要重新做我的王后」，归属谈判卡点更剧烈。
- 若林恩故意在烤肉街给左左点了一打果汁而不是烈酒，则她醉意戏全无、哭诉粮食全线崩溃，巨像之脑目睹一个清醒的左左比醉酒的左左更难哄。
- 若林恩让尹依随行进殿端茶，则巨像之脑首次见到「蓝星灵魂候选学徒」，王后纠葛里多一层新变量，E169 的剧本视野增加一双眼睛。
- 若林恩在同床前主动用触手把整张床加宽一尺，则「你为什么挤上来」的质问无法成立，巨像之脑只能默认他作为「左手家具」加入，剧本进入被动折叠模式。
- 若林恩在挤上床时主动用咒语把自己的体温降至接近室温，则背贴背睡再也不会被巨像之脑察觉到他，恶堕成就触发条件被动作废、纯共眠版本成立。
- 若林恩在同床半途主动溜到地面打地铺，则事件以变形（客厅独睡）收束，背德成就锁定，但左左第二天早上会发现床边地上蜷缩着一个熟悉的黑团，心软值 +5。
- 若林恩让触手在半梦半醒之间偷偷替左左掖好被角，则这是同床阶段他唯一做的、无可指摘的亲昵动作，驯服度与恶堕度同时小幅前进而非暴涨。
- 若林恩拒绝巨像之脑「我现在就把他的心脏挖出来」时给整个房间静音一秒，则所有玩家与 NPC 都意识到「挖心」其实是她护短的最大声，剧本张力反向推到峰值。
- 若林恩把「总之就是不对劲」当成起床闹铃反复在梦里回放，则第二天清晨他向巨像之脑汇报「你昨晚说的，我全程记得」，信任危机提前到 E169 开场引爆。
- 若林恩故意在床沿打个响指点燃一根蜡烛、给三人同床加一层「读书会氛围」，则场景从「暗流涌动」滑向「荒诞室内剧」，左左被迫承认这客厅风三人组她其实也享受。
- 若林恩主动提出自己要去抓警备队追捕聚合体的进度，则他以「我有正经事」为借口主动掀被下床，同床剧本在第一小时内被他自己报废，【背德的欲擒故纵】成就变体作废。
- 若林恩在巨像之脑翻身瞬间用血肉把她背后的被子捏一个猫耳形状给她戴，则半梦半醒的她无意识戴着猫耳被天明，画面被左左次日清晨吐槽「姐姐你昨晚到底干了什么」。
- 若林恩在入睡前主动握住左左的小拳头让她枕在自己肩上，则这是同床场景里唯一无争议的亲密，恶堕成就 +0、友谊羁绊 +3，剧本向纯和解线偏航。
- 若林恩让左左中途在自己臂弯里先醒过来，则她第一反应是又咬他手腕、第二反应是发现巨像之脑也在——惊吓值与安全感同时拉满，E169 拟化剧本必须绕开她的清醒期。
- 若林恩主动在睡前说清「我什么都不会做、我只想你们俩都在我边上睡着」，则剧本完全切换为「三人共眠纯爱版」，驯服与恶堕数值结算走向另一条支线。
- 若林恩让系统在结算【背德的欲擒故纵】成就时附加一条「道德-2 但良心+3」的恶搞好笑 tag，则道德数值结算体系首次出现双向拉扯，玩家与左左事后查看面板时同步想笑。
