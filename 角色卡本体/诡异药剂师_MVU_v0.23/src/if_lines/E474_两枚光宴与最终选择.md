# E474·两枚光宴与最终选择·if线

- 若林恩催促合体前先让小光宴群自己排出一圈站着看他，则九十八份自我同步「钉死」这一句时会形成环状合唱效果，她未来对「仪式感」的记忆会被临时升格。
- 若林恩在催合体时附加一句「不管出来的是谁，我都不会让她后悔」，则九十八份自我里会有约四十份在互吞前就先把这句话记入「合作者可信度」的交汇底账。
- 若林恩在体型稍大者自称主体时直接表态支持她，则其余九十七反过来会先瓜分林恩指定的这枚，「株连式反向操作」首次被证实可行，体型稍大者消失得更快。
- 若林恩在旁观械斗时喊「击败体型最大者应获得额外数据加成」，则械斗逻辑被这一条外部规则影响，最后两名的身体型态会比默认线更靠近。
- 若林恩在两枚终局竞价时沉默不选、只把拇指停在半空，则近侧和远侧会同时陷入僵持，竞价会再加码一轮，「可以和你操一次」远侧也会跟风说出，最后两枚少女的承诺档次都高于默认线。
- 若林恩在竞价时直接闭上眼睛不听，则两枚会立刻意识到他在拒绝被驱动，她们会同时收声，合并谈判的语气从性挑逗转回纯利益谈。
- 若林恩故意用拇指偏向远侧，则近侧会在远侧松懈瞬间反向出锁链，背刺路径从「林恩指哪边」完全镜像翻转，刺中者和被刺中者对调。
- 若林恩在背刺发生瞬间发出短促惊呼，则归来完整体会以为他在心疼被吞的那枚，她会冷哼一声、把这点多余情绪记成「他不可全信」。
- 若林恩在完整体归来后立刻提前预警「你可能刚吞了一个我提前埋的标记」，则她会在意识层三秒自扫、发现确有灵能微粒被她一起吞下，她对林恩的警觉升起但「他也防我」这一现实使双方距离反而更近。
- 若林恩在她捏碎锁链那一刹那用三叉戟挡一下，则她捏碎的会是三叉戟投出的虚化残影而非真实锁链，他对她行动节奏的「允许」边界首次被实物化。
- 若林恩提醒协议一后她收刀、用咒瞳扫她瞳孔，则她眼底那一缕真正压住的杀意会完整在他咒瞳视野里显形，「她想杀他但有约束」被他的硬证登记。
- 若林恩在她冷收刀之后伸一只空手摊开给她看，则她会用指尖轻触他掌心一秒再收回，这个动作不属于任何类别，被她日后无数次单独回放。
- 若林恩在她被打断的那句「帮你找巨像之后……」接话说「之后你由我分配」，则她会把头转向他眼中燃烧一缕几乎可见的金火，她没接下、也没否定。
- 若林恩选择不共享视野的集会场景，则灭绝者的虚影、模因立方体的三秒特写、更高阶的三名光宴的剪影全都不会进他面板，他的情报等级比默认线低一截。
- 若林恩在灭绝者亮出模因立方体时反向释放一道他自己的初诞者之力扰动立方体边角，则立方体的裂射路径会在分射瞬间产生三毫秒偏移，未来在林恩侧光宴体内的模因分布将不规则。
- 若林恩立刻询问光宴「你打算什么时候执行与我的协议二解除」，则她会安静说「等我集齐十块区块权限」，承诺的时间锚点被她自己钉死。
- 若林恩在集会中选一件高阶姐妹的中级光宴，用三叉戟把她标记为「不要碰」类别，则光宴会皱眉、问为什么，他不说，她把这次不明所以的标记记成「他有别的算盘」。
