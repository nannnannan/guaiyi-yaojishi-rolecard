# E478·第七机神以太狂潮·if线

- 若林恩在数据滞涩迹象初现时立刻让深潜侧光宴停止前行三十秒，则猩红狂流横断时她会在他身后而非身前，「他拦她」的动作被她视为主动保护而非被动反应。
- 若林恩在猩红狂流横断瞬间用三叉戟划开一道临时屏障，则光宴不会被摄走、但他自己的三叉戟会被当场污染三寸，他要花两小时清理这柄神器上的以太痕迹。
- 若林恩在捂嘴镇压她体内动乱时让她听见他心声一句「我在」，则她瞳孔里那阵战栗会先平一拍，然后她意识到「他不是为了任务是为了我」并把这层含义装进她口袋。
- 若林恩在她镇压后用指背替她擦去额角的数据汗珠，则她会有半秒忘了七神以太狂潮就在三丈之外，这一秒空白会被她自己日后回放时认出为「那时我不怕」。
- 若林恩让面板浮现时主动把【七神：以太狂潮】这一行在她面前举起让她看清，则她对「他并没有想在情报上单吃我的恐惧」这一事实的体认升一档。
- 若林恩问她「你怕它吗」而不是任她自己掩饰，则她会在第三次窒息般的沉默里点头，七神辈分的意识第一次在她身上露出「可以承认怕」的缝隙。
- 若林恩主动说「那你不准一个人面对它」，则她会安静几秒、说「我没打算一个人」，她在这一刻把「我们」这个词重新装进她自己字典。
- 若林恩在光宴口述「想赢吗」契约细节时反问她「你当年投过票吗」，则她会说没投票、但任性参与了复仇之战，她对当年决定的悔色在那一刻露出来。
- 若林恩在她说到「眷养契约续数万年」时回头朝血色狂潮方向看了一眼，则她会抓住他手腕、说「不要看」，她对他也即将成为它食物的可能性产生的反射被她自己承认。
- 若林恩在她口述以太狂潮曾吞噬千亿亿计生命资料时主动握住她的手，则她会停顿两秒继续说、不再颤抖，她在数据层面上感到一种不该存在的「温度」。
- 若林恩用咒瞳反向扫描血色狂潮流向，则他能识别祂走的路径其实有空窗带，未来若要让她过那条路径去田园会合，存在逃生缝隙。
- 若林恩在她口述完后立刻追问「它能被切割吗」，则她会摇头、但她眼底有犹豫，她自己都不知道这个答案的真实度。
- 若林恩让守巢都分身不撤、反向在她所在的位置布置三层初诞者之力屏障，则该分身能被血潮笼罩时不立刻被吞、但屏障消耗速率提升，他在她的生存时间上多花资源。
- 若林恩直接把光宴与自己绑定到三叉戟共享空间，则血色狂潮一旦摄走她他也会跟着被拖，「同生共死」这件事被她无声承认是他在安装。
- 若林恩在她口述过程中同步把她所述敌机神弱点拓片复制到巫神侧情报网，则巫神将在四小时后就「非本土飞升种」发出跨界警报，林恩侧第一次承受「信息扩散责任」。
- 若林恩在她已说完所有的状况下再问她「还有什么是你没说的吗」，则她会沉默很久、说「它曾经想留我们做宠物」，这一句被她本能地压到今天的最深处。
