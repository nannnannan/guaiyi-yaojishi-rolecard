# E524·渡鸦墓地与神王相遇·if线

- 若林恩在罪孽城出发前选择不让孽主随同而是让银幻陪同，则载飞速度从「速度灵巧型」变成「机械飞行」，但氛围从姐妹淘变成同事结伴。
- 若林恩决定让孽主载飞时她故意留一手速度不发挥，则抵达时间延后，但她的自尊保留一种「我没尽全力」的余地。
- 若林恩选择在飞行途中给孽主讲笑话活跃气氛，则荒芜废墟的沉重感被分散，她对节点之行的戒备心减弱。
- 若林恩决定不主动抓沙判断节点性质而是让孽主先察觉，则她的「节点认知」由他提示变成她发现，主动感增加。
- 若林恩在穿地而下时选择化作完全不同的形态（如银幻的机械体），则虚化跟随机制失效，他们可能无法同步下潜。
- 若林恩决定让咒文巨墙上的明灯一次性全部点亮而不是一盏盏，则视野开阔但可能触发某种禁忌机制，情节走另一条支线。
- 若林恩在下潜十万米过程中选择停留一刻欣赏深渊图景，则孽主可能对此不耐烦或者同样被震撼，节奏改变。
- 若林恩决定佩戴面具时间比约定短，则他对时间涟漪的感知减少，入侵示警慢一拍。
- 若林恩在异常啸叫出现时不立刻戴面具而是先听听来源，则他可能识别出更具体的污染类型，但暴露风险上升。
- 若林恩选择在他率先俯冲时让孽主先探路，则她承担第一风险，她的反应可能从「震惊」变成「被指派」。
- 若林恩决定不让怀中的面具微热提示而是直接靠自己的初诞者之力感应，则面具不被使用，他的宝物账目不变。
- 若林恩在节点定性时故意让孽主露出相似把握的表情，则两人有一种「同阶者心照」的默契氛围。
- 若林恩在听到时间外敌人入侵时选择立刻掉头逃跑，则 E525 大场面不成立，被迫改写为边退边打。
- 若林恩决定尝试与污染者对话而不是直接清剿，则可能获得某些情报，但风险极大。
- 若林恩选择在抵达凸出平台前主动停下来调整呼吸，则他错过关键时刻的画面第一眼冲击，所见「怎么会」的惊讶程度减弱。
- 若林恩决定让下潜的路径偏离直线下行而是螺旋形，则时间消耗更多但安全性更高，某些躲藏的污染者可能错过去。
- 若林恩在黑堡相似节点定性时不告诉她未来对手的真实身份，则她的戒备心不完全，遭遇时可能被吓到。
- 若林恩选择让渡鸦第三尸体在他下面三尺处被他察觉，则他的俯冲目标更明确，但 platform 上的惊讶不再成立。
- 若林恩决定在俯冲时不锁定孽主的视线保持她在后面跟随，则她可能因速度差异而掉队，二人分离。
- 若林恩在进入深渊前主动咒术把自己和孽主连接，则他们之间的感知同步，下潜协作度上升。
- 若林恩决定不让左左在此行出现，则她被排除在 E524-E525 大场面之外，参与感不足，E527 的留在过去剧情她的角色缩小。
- 若林恩选择在看到异常啸叫时用心声告诉孽主，则她主动意识到危险，共同决策下潜节奏改变。
- 若林恩决定在凸出平台前用咒感瞳探视时间涟漪，则他可能提前见到神王的身影，「怎么会」的惊讶被预先准备所稀释。
- 若林恩在停止时说「先别过去，看看再说」，则平台惊停变成理性判断而不是被动惊讶，剧情气息不同。
- 若林恩决定让载飞时的行李适量加固，则他在下潜过程中可能保留更多补给，后续战斗备用资源更充足。
- 若林恩在选择目的地时挑战孽主选定更远的渡鸦而不是「附近」，则她接受或拒绝的挑战完全不同。
- 若林恩决定用三叉戟作为侦测导向而不是靠面具，则面具不被使用，但三叉戟可能因为暴露而承担额外压力。
- 若林恩在咒文巨墙前主动试图解读墙体上的咒文，则他可能读取到关于这座节点的历史情报，情节多一条知识支线。
- 若林恩决定让佩戴时间面具时孽主也能看到一部分涟漪，则她成为这个特殊视觉的分享者之一，情感账目改写。
- 若林恩在事件结尾决定停止前某一句话不是「这是……怎么会」而是「那是……神王吗」，则 E525 开场场景从这个名字起跳，气氛从惊讶变成直面。
