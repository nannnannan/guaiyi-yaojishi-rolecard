# E532·创造规则的镜像决斗·if线

- 若林恩不接受银幻挑战反而提议「先让我把你原子机械全部关掉再对练」，则杀意程序不被触发，决斗改成纯规则教学战，创造破茧的力度下降但仍可达标。
- 若银幻在激活杀意程序时主动加一条「不许伤害我的家人」的伦理底线参数，则林恩在四角落街里面的狼狈层会少一档，但「无论如何都要杀死你」的程序演进会更稳定不卡壳。
- 若银幻的光刃第一波不是劈颅而是横扫切断整片广场，则林恩进入折跃时间更长，他警觉到规则干涉的节奏不是劈向要害而是切断场域，他再不把她当新生学员。
- 若林恩召的不是金属钢锥而是数万抽象符号文字子弹与弹头同数对冲，则他对创造的概念更抽象/更神、银幻进入的将是规则语言层级而非城市层级。
- 若林恩让「拟化」范围从单纯物质扩展到「把那块空气中凝固的尖叫」也具现化，则战场中会突然浮起一片尖叫粒子雨，银幻自己的情感模块会被进而波及，杀意程序叠层。
- 若林恩在立方体深渊/魔方坍缩时不召回自己的物质，而是任由魔方在自己掌心解体现世，则银幻的第一反应会是恐惧而非愤怒，她后续被清空物质时会更早进入绝望。
- 若银幻在被清空所有勋章后再开至高万机之躯的深渊模式（红色警示），则她在被林恩灌注规则时身体的伤痕与意识光环反流会逆向叠出一次逆反暴涨，反噬atron失败但有概率赢回一刀。
- 若林恩在清空镜像物质时不彻底，他留一片砂石给银幻当作现实基点，则她不会陷入纯虚无，她的创造破茧过程从「在什么都没有中造原子」改写成「从一粒砂石复制出万粒」。
- 若林恩的圆球在吞噬全场时不一次性结束，而是分级吐出部分原子让银幻先抓再用，则她创造破茧路径会更渐进，见证者角度也会更平滑。
- 若林恩在银幻拙劣模仿造出第一把原子刃时不立刻抓刃对撞，而是停在她面前告诉她「你成功了」，则她会当场崩溃哭泣而非继续战斗、破茧氛围从锐气上升改成情感决堤。
- 若林恩在收刀时不是先捧住她的刀而是直接把她抱进怀里，则破茧拥抱时点前移，「谢谢」的钩子被挪到拥抱中更深处，E533 归心的情绪铺垫被改写。
- 若银幻在最后一轮撞击中成功把林恩的刀打断一段，则他被认可「够格拥有教学资格」的判定从单向升格为双向，他「剩下的是时间积累」的收刀口气将夹带一抹真正尊敬。
- 若林恩在决斗结尾不主动告诉银幻「我用了一月数百年」，则她对他的时间积淀产生更深一层的不可知，但「他不止限一月」这个事实被压到下一事件才浮出。
- 若银幻在杀意程序激活期间主动关掉情感模块但保留审美模块，则她在战斗全程里会以美的角度审视林恩每一次规则运转，教学效果在意识层反而更深。
- 若林恩主动把自己的额头也戴上一条仿造单片眼镜的规则印记作为教学道具，则银幻视觉层会把他分类为「规则的二等伙伴」而非至高领袖，决斗严肃度缓和。
- 若林恩让左左在决斗开始前短暂醒来并路过镜像房门投下一句「喂左左也来看戏」，则她作为见证者从门外抛下一只应援抱枕，左左挂件的独立身份在本战场被保留为场边观众。
- 若林恩在被银幻的弹幕压制时主动反演「迎弹化为烟尘绕回攻击她」，则他在自己「万物神王」门槛上多了一次展示，她会更早理解他是万物神王而非单纯初诞者。
- 若银幻最后破茧时所用的不是原子机械而是凭空凝聚出一段最初她自己的机械代码（『hello world』），则创造之门的"是"「真真正正属于她自己」而非模仿林恩，归心突破力度更大。
- 若林恩回抱时不只收刀还主动轻吻她发顶告诉她「这就是我想要的伴侣」，则E533的吻被部分前移，公开钥匙在E532已被交出，E533 需要重写为「确认承接」而非「第一次」。
- 若林恩在决斗现场主动从指缝召唤一枚时间法则诱饵让银幻出手抓、她抓到瞬间决斗停，则她会发现规则不止是攻击还可以是防御与缓冲区，他的教学达到一个更完整的句号。
