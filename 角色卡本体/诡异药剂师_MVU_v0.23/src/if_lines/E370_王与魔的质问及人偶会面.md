# E370·王与魔的质问及人偶会面·if线

- 若林恩在人偶夫人首问「你是怎么找到这里来的」时回答「用一个多月前托付的朋友换来的档案」，则她能记下这一份「不藏牌」的诚意，结界门开的速度比原约定再快半拍。
- 若林恩在被问及「不会回来的到底是王还是魔」时直接坦白「是我在上一战里留下的那一面」，则人偶夫人震撼静默三秒，但她旗下高阶人偶小队当场围拢半圈，戒备程度短时上涨一档。
- 若林恩在同一问里改答「那是已经过去的事，回来的是我自己」，则人偶夫人会在沉默里给出一个「且看你站到她面前时再说」的临时边界，后续走廊的岗哨减少一道。
- 若林恩选择用灵魂丝线作为答话的物证让它在小拇指尖轻轻颤动一下，则人偶夫人亲眼见到这条脆弱但仍未断的链接，眼眶里泛起一缕压抑已久的湿意，戒备反向下降一大档。
- 若林恩主动把八音盒的神印复制品作为见面礼递出，则苍玄月第一时间接过并请人偶夫人代为转交给女主人，整条交涉路径多获得一位非口头的中介者。
- 若林恩在主母提议让巨像同行时主动点头采纳，则他被多一双血红瞳眸伴随走过戒备走廊，人偶家会暗自把他判定为「被另一个根源同时看住的可控对象」。
- 若林恩在主母提议后反而孤身深入，则人偶夫人在他手触及大门前的那一刻主动额外叮嘱一句「请别让她受第二次伤害」，他知道她这次只对林恩一人说。
- 若林恩在戒备走廊上主动朝那位背着不成比例巨大镰刀的红发人偶点头致意，则她因被承认而愣了一秒，下意识小声多补一句「上次不是，是她已经有了心了」。
- 若林恩当面反问红发人偶「上一次是哪一次」，则她眨了眨眼陷入纠结，最终在人偶夫人走近后红着脸快进大门去不再回答，但走廊气氛随之松了一度。
- 若林恩在推开咒术大门前主动先把外衣脱下来交给人偶夫人，则她能摸到那件衣物上残留的黑弦月哥特长裙丝线香，沉默半秒后允许他径直入内不再设防。
- 若林恩推开咒术大门前先稳稳手按在门上对门里的法阵轻声说一句「是我，林恩」，则紫色法阵内细细垂落的丝线会先停顿一拍再缓缓散开，人偶姐妹们集体往后站半步。
- 若林恩在见到黑弦月悬浮那一刻主动先张开小拇指而非直接靠近她，则那一缕断续的灵魂丝线会在数秒内自行接得更紧，他体内那股久违的扣回感从指端蔓延到胸口。
- 若林恩主动配合人偶夫人把「不会回来的王/魔」一段记忆挑着讲出来而不是全盘托出，则人偶家得知一半真相也稳住一半戒心，灰色空间内仍保留某些隐而未表的禁区。
- 若林恩主动对黑弦月悬浮的身影俯身深深一礼，则法阵中心那道贯穿她胸口的大洞在数息里轻微缩小一丝，人偶姐妹们发出一阵难以置信的低呼。
- 若林恩主动让巨像之脑从网络远端只看他不动他的视野以避免刺激，则她能在不亲身擅自带入黑堡的前提下既能陪伴又保持边界，巨像之脑后续处理「黑堡关系」的状态朝良性方向浮动一档。
- 若林恩主动伸手进法阵但仅停留在法阵外圈触碰一根丝线，则那根丝线会在他指尖被染上一抹属于他本人的初诞者黄沙色，黑弦月本体随之轻颤一次。
- 若林恩主动把头顶那根从意识深海里带出来的金羽插在法阵边缘示意主母的参与，则紫色法阵会泛起一片淡淡金光对方阵内的生死轮转节奏减缓一成。
- 若林恩在法阵前主动告诉人偶夫人「下次我来，会带着让她醒过来的方案」，则她会握紧双手压抑着不哭出来，苍玄月主动在背后悄悄拭去一滴眼泪。
- 若林恩主动提出「让我带一件属于她的东西离开作为契约」，则人偶夫人会犹豫后同意取出她某位随身的八音盒传来，作为「他会回来」的白色信物。
- 若林恩主动把自己的食指留在法阵外圈上交出一滴血作契约引，则法阵在那一滴血落地瞬间发出一道轰鸣，但人偶夫人第一时间喝止咒术师们继续运转，「他的血有不可承载的东西」。
- 若林恩在报告「她确实活着」时主动补一句「但她现在比我想象的还要痛」，则人偶夫人脊背一僵第二次询问「那你的方案是什么」，交涉被推进到实际操作协议层面。
- 若林恩主动对法阵说出一句黑弦月过去最喜欢哼的小调，则法阵内她的银发会在只有他能感知的角度轻轻飘起一缕，他知道她在里面听见了。
