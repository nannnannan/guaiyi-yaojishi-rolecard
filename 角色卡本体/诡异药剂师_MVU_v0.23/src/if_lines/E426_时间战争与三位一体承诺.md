# E426·时间战争与三位一体承诺·if线

- 若林恩在苏醒后主动先开口告诉家人自己才有穿越时间的经历，则「经历了时间裂隙、见过另一个世界」的前置条件齐全，会议提前起动、孽主闭门不见的警告被推迟。
- 若林恩先拒绝分享个人穿越时空的经历，仅以「我看见过未来」带过，则艾雯、巨像之脑、人偶家只能凭借有限情报拼图，会议推理深度被矮化一半。
- 若林恩在巨像之脑以银眸「核实是不是本人」时主动反抓她手腕发问「你信不信我」，则她的X光停顿一拍、由被动验证转化为主动选择相信，「信任转向」首次落到她自己手里。
- 若林恩在卧室里没用突如其来的强吻验证身份，改以一句坦白的「我没事、我回来了」宣告，则巨像之脑解除戒备的节奏放慢十倍，她首次用谨慎的眼神仔细观察他每一个微表情。
- 若林恩先拒绝主动公开那次亲吻，则巨像之脑把他当作「可能是冒充者」继续观察半小时，会议延后起动。
- 若林恩在巨像之脑说明三位一体时主动插问「机械部份是谁」，则她把「机械神教的本源」概念首次详细提到桌面，「拼图缺一块」的实体画像首次被众人人格化。
- 若林恩在三一任务浮现后当场按「拒绝」，则系统的任务面板到他手部震动一秒就消失，「未拒绝与未接受同时成立」的边界首次迂到。
- 若林恩在三一任务浮现后按「接受」，则面板入场「未来客人集结」的提示窗，但家人集体瞳孔骤缩，「他疯了」与「他有计划」两种解读在同一拍里并存。
- 若林恩在三一任务浮现后拒绝明确表态、只说「先记下」，则三一提议被挂起，会议的发酵期最长、后续林恩需要亲自整理答应或回绝的依据。
- 若林恩在艾雯爵士追问「敌人针对谁」时主动把咒瞳切换成未来客人的视角输出，则她首次实眼看见「未来的林恩」的一切，「敌人不分彼此」的结论被她本人采信一次。
- 若林恩让自缚天使在会议上以她自己擅长的「看守边界」身份发出警示，则「地狱是牢狱、也是堡垒」的逻辑由她本人实眼作证，会议结论被一位「城堡内号」的实手加持。
- 若林恩在巨像之脑离开会场时主动冲到窗外高喝一声「胆敢有这想法我就今晚吃了你」，则她精准掷石砸中他额头后回头时银眸里面呈现罕见的明亮，「把『吃了』听成两情相悦的粗暴调情」首次被她身体力行地确认。
- 若林恩没冲到窗外、仅以一句沉默告别送她，则她离开前三秒回头时真正想说什么但没说，「家庭里没人开口的瞬间」首次被纪念。
- 若林恩在会议尾声主动呼叫孽主的眷者把她从旅社接来，则「孽主闭门不见人」的警告提前兑现，她的拒绝在「他被人召但仍拒见」的画面首次成型。
- 若林恩拒绝呼叫孽主、专心与家人讨论，则「孽主被安排旅社且闭门不见人」在会议结束后仍未处理，「她的事被搁置」首次成为一种选项。
- 若林恩让喵喵以猫形态溜到会议桌底做尾巴毯子，则家人们会谈时无意识抚摸她，「家庭温暖的破坏」首次被一只猫自然稀释。
- 若林恩在巨像之脑强力提三一承诺时主动反问她「你真的愿意被吸收吗」，则她银眸颤动一秒、「愿意不愿意」的真实首次被现场议论。
- 若林恩拒绝三一承诺但不质问，则她把话题沉寂一秒后离开，「她没得到想要的回应」成为她个人秘密的下一座塔。
- 若林恩在会议中途主动盯自缚天使发问「你怎么看待你自己的恶魔本质」，则她首次长时观察林恩，「她与他首次以『本质』连接」被记进她的祖先脑海。
- 若林恩让喵喵在会议间爬到桌顶上做瑜珈，则家人们开场笑话温度熄火后重新点燃，「家庭温暖会受到机械影响难以消灭」首次实手证明。
