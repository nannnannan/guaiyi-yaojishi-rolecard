# E481·智械伪身与病毒陷阱·if线

- 若林恩接受光宴建议先去另两台高阶光宴机拿下一台，则他能立刻补足三分之一常规机械体，但最高光宴机那台终端会被银发少女独自引爆、本事件所有「虚伪身未被识破」的现场也没有人到场。
- 若林恩回收所有小分身汇入本体再支援警报源，则他能压场撞入大厅，但算力集中在本体一个脑袋、后续拖着巫神与夏娃穿网道时会精神透支三分钟。
- 若林恩在深潜前告诉智脑「我怀疑她是故意的」，则智脑在大厅看见银发少女时不会尖叫、她会沉默攥紧裙摆，「小姐在玩命」这件事她自己确认过一次。
- 若林恩走地下走廊时让智脑留在网道口，则没有人陪他见证两颗机械神祇入场，但智脑本体也不会被灭绝者一眼锁定为「附带不放过」的次要目标。
- 若林恩在走廊中先把一支灵能浮标钉入大厅顶端，则拥星者抵达瞬间他能从屋顶角度俯视全场，二秒内识别浴火魔神胸前终极反应炉位置。
- 若林恩用疫医血包代替热熔粒子枪朝禁卫掷去，则几具禁卫会被夜医毒雾烙上血肉符号，后续战报里机械神教被迫承认「夜医已渗入核心」。
- 若林恩在银发少女弯腰躲热熔时以咒瞳扫她机体波长，则他会先一步意识到这不是她、因为苍蓝数字眼的频率低了她本体半格，「伪身」这一事实先于灵能扫描被他钉死。
- 若林恩在苍蓝锁链镇压光宴时主动以三叉戟刃尖挑断一根锁链，则他能立刻获得这份「万机之神遗产」的真品样品，但也会引起高阶机神对林恩作战等级直接升两级。
- 若林恩在她扼住光宴脖颈时主动用灵能压住墙上一台机械终端不让它跟着过载，则这台终端会成为后续反向追查模因路径的活路标。
- 若林恩在灭绝者逼近时不立刻下手、只在墙体留下一道隐形咒纹，则灭绝者后续追猎林恩本体时会被这道咒纹燃一次，而这次燃痕成为巫神头颅对本体的识别路标。
- 若林恩施放血肉灾变把整座终端包成增生战场，则银发少女将立刻被识别出是在与根源合作、后续所有「她被格式化」的误判就不成立，机神侧直接进入「全面战争」。
- 若林恩在纳米集群被过载灰烬化瞬间往墙顶钉一道三叉戟灵能标记，则灭绝者追猎林恩的过程中会先撞上标记陷阱，二秒空档给真身侧争取到关键的呼吸时间。
- 若林恩主动对频道里狐疑的监控侧喊一句「她不是被感染了，她是装的」，则全场信道会被他一声真相填死，灭绝者立刻改判「需要双神全力击杀」而不是「观察隔离」。
- 若林恩让左左借助意识空间朝这具机械姬扔一个咒面包裹，则她表面的机械体会被打散一角、露出里面那层「光宴数据伪装」，但左左会因此被拥星者的视线钉住。
- 若林恩在双神围死的瞬间出手替她挡下灭绝者利爪，则机械姬就被她背后的林恩肉身接住，她被解体一半的数据会直接溅到他脸上，「被救了一次」这件事会以最深物理感烙进她核数据。
- 若林恩在她「所以，还真的是卑鄙啊」的台词出口瞬间用灵能覆盖她声带半秒，则她说出的不是「卑鄙」而是无字的呻吟，两台机神听到这一声会更确定病毒起效了、双神松懈一拍。
- 若林恩主动在她手仍摁着触发装置时先把装置用三叉戟拍飞，则全网模因散播不会从这里启动，但她会被立刻识别为「无价值目标」、被灭绝者当场拍碎。
- 若林恩让智脑用叠音在网道口放声大喊一句「林恩救我」，则双神的扫描会被这一声叠音干扰半秒，他能借此缓冲最后一步，但智脑暴露在全场视野里。
- 若林恩在墙廊被巫神砸开前主动用咒瞳反向接触灭绝者的视野，则他能提前三秒看见灭绝者准星，避开第一记利爪，但咒瞳会被灭绝者的微观机械风眼反锁住一秒。
- 若林恩在她背靠墙壁压制时主动让她听见自己心声一句「撑住」，则她眼底会闪过一丝陌生温度，这丝温度会在后续她主动引爆自己前成为她体内病毒勉强稳一拍的原因。
- 若林恩把时钟改成提前引爆整个区块，则所有机械禁卫与上传宏观体都会在这波超载里被全部瘫痪，但银发少女的身体也会一起瘫痪，林恩必须要决定要不要在瘫痪前把她拖出去。
- 若林恩直接放弃救援、选择离开现场让事件自行收束，则双神的围杀会以完全形态收束、装置按原剧本引爆，林恩身上多一笔「我放任她引爆」的精神负载。
- 若林恩在走廊尽头用手势命令禁卫拉开阵列让他过去，则会被立刻判定为「已认证最高指挥」，但这份伪装的认证只能维持三秒、三秒后架在他脖子上的刀比它们之前架在机械姬脖子上的还要多。
- 若林恩施放灵能像渔网一样当庭罩下整个走廊监控网络，则这段所有作战影像会被他完全捕获，机械神教所以能拿到的只有「他拿走了所有证据」这一个事实。
- 若林恩在灭绝者问她「你是不是在等他们」时自屋顶发声替她回答「是」，则双神的准星会立刻全部转向他、林恩一入场就面临三台机神同向用火力的局面，战斗直接升级为地狱级。
