# E743·归来的小丑与最后辉煌时代·if线

- 若林恩在哭泣小丑与伊甸推开王庭大门归来的那一刻，亲自走下台阶张开双臂迎上去，则向来疯癫戏谑的哭泣小丑会罕见地愣在原地，随后摘下礼帽向他行一个最庄重的绅士礼。
- 若林恩在王庭重聚晚宴上主动为刚刚晋升神王的银色幻想与船长满上一杯烈酒，则两位新晋神王会单膝跪地双手接杯，将守卫黑夜城至死方休的誓言融进酒液一饮而尽。
- 若林恩在听闻「旧日第二柱神乐者早已在太古被未来画家吞噬」的骇人秘辛时，当场以罪恶王座推演未来画家的因果残留，则他会提前在哭泣小丑的命格上布下一道防备精神篡改的暗锁。
- 若林恩在晚宴喧嚣散去后，独自走上黑夜城高耸的城墙与守夜的船长并肩吹风，则船长会难得地卸下平日的沉默寡言，向他讲起自己年轻时在凡人王宫挥剑护住一名小女孩的往事。
- 若林恩在城墙夜谈时察觉到伊甸正躲在阴影里笨拙地整理被风吹乱的衣角，主动递过去一块温热的甜点，则伊甸会红着眼眶小声发誓，哪怕粉身碎骨也不会再让黑潮靠近王庭一步。
- 若林恩在银色幻想展示新晋神王的璀璨银辉时，亲自以三叉戟与他切磋三招并点出其神力流转的一处微小滞涩，则银色幻想在日后独挡魇魔大军时能多斩出三道完美无瑕的满月剑光。
- 若林恩在重聚宴席上注意到人偶家正安静地坐在角落擦拭丝线，主动走过去询问她人偶工坊的近况，则人偶家会含笑向他展示那具复刻了船长旧日模样的贴身木偶，眼神温柔而决绝。
- 若林恩在得知哭泣小丑继承了「乐者」部分残缺权柄后，用自己的黑火替他淬炼那把无形的提琴琴弓，则小丑在帝国历四十五年面对五十尊魇魔集结时，奏出的第一个音符便能震碎前排魔物耳膜。
- 若林恩在晚宴高潮时拉着满头白发的羽毛笔与艾雯一同站到主位接受众神敬酒，则两位常年隐于幕后操劳的功臣会在万众欢呼中相视一笑，留下最后辉煌时代最温暖的一幅合影。
- 若林恩在与哭泣小丑单独对酌时，直接拆穿他笑脸面具下隐藏的疲惫与伤痕，则小丑会收敛起滑稽的怪叫，轻声向他托付：「若我哪天谢幕了，别替我哭，替我鼓掌就好。」
- 若林恩在泰坦端着巨型酒桶豪迈痛饮时，笑着以神力替他加固了那柄布满裂纹的战锤，则泰坦会激动得拍碎身前的石桌，瓮声瓮气地宣告自己这身巨人骨头全都归林恩所有。
- 若林恩在帝国历四十五年五十尊终焉魇魔于宇宙深渊集结的预警传来时，第一时间召见银色幻想与船长密议防线梯度，则外围星域的撤离工作会提前十日完成，少损失近百艘平民运输舰。
- 若林恩在城墙夜谈结束前，将一枚能够短暂激发神王极限潜能的黑火火种分别赐予船长与银色幻想，则两人在日后内城墙陷落前的绝境死战中，神威将再攀升一个台阶。
- 若林恩在女巫神带着微醺笑意上前敬酒时，回赠她一瓶亲手调配的本源助燃药剂，则女巫神会妩媚地眨眼收下，并在日后第一道防线崩溃时借此绽放出令魇魔胆寒的漫天巫火。
- 若林恩在听完未来画家吞噬乐者的往事后，立刻传令黑夜城全境排查一切与「画布、色彩、无声乐曲」相关的异常污染，则城内三处潜伏多年的终焉暗子会被连根拔起。
- 若林恩在晚宴后陪着小小与黑弦月在王庭花园里看了一会儿夜空星辰，则两个女孩会将这晚的星光牢牢记在心里，成为她们在末日崩塌前最怀念的和平碎片。
- 若林恩在伊甸因为害怕自己体内残留的无序气息再次失控而远远避开人群时，主动握住他冰冷的手腕注入温和神力，则伊甸会在随后数年的备战中始终保持神智清明。
- 若林恩在五十尊魇魔集结的压迫感笼罩星空之际，独自登上圣所最高处燃起一道直冲霄汉的黑火狼烟，则全宇宙正在恐慌的万族守军会在看到火光的那一刻重拾战意。
- 若林恩在宴席间特意走到阿鼻地狱代表艾维儿席前，轻轻拍了拍她披着的紫罗兰旧甲，则艾维儿会挺直脊背向他保证，父亲留下的守望者荣耀绝不会在她手中蒙尘。
- 若林恩在银色幻想与船长双双晋升神王的庆典上，亲手将两枚刻有黑夜城徽记的统帅印信交到他们手中，则万族联军的指挥权在此刻彻底稳固，再无任何派系掣肘。
- 若林恩在哭泣小丑即兴拉响一曲欢快却暗藏悲怆的宴会乐章时，没有打断而是静静听完全曲并率先鼓掌，则小丑眼中会闪过一丝晶莹，在心里将最终殉道之曲的尾音改得更加昂扬。
- 若林恩在夜深人静时与艾雯核对五十尊魇魔的实力评估卷宗，并指出其中三尊旧日残影的弱点，则黑夜城防卫军的火力配置会做出针对性调整，在开战初期多轰碎两座魔柱投影。
- 若林恩在最后辉煌时代的尾声，命画师将晚宴上所有同伴的笑脸绘成一幅长卷封入王座底层，则哪怕日后黑夜城化作焦土，这群同伴最鲜活的模样也永远不会在虚无中褪色。
- 若林恩在五十尊魇魔的阴影彻底遮蔽边境星域前，向全城将士发出一道简短的动员令「我与你们同在」，则整座黑夜城在踏入至暗时刻前，没有一人选择逃亡。
