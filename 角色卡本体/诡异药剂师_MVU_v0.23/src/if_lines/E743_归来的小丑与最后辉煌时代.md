# E743·归来的小丑与最后辉煌时代·if线

- 若林恩在小丑穿过完美世界光幕那一刻主动起身迎接、而不是坐在王座上等他入殿，则小丑首次被「王」亲自在阶下接住，八音盒旋律短暂跑调，后续他对林恩的同伴叙事降级为「兄弟直话」。
- 若林恩在小丑开口说明无序自解前抢先问「乐者呢」，则小丑的沉默拉长到三秒，他没立刻回答，把「乐者缺席」这一事实压成更沉的一块石头，黑夜城王庭的空气先于因果网络提前凉一层。
- 若林恩主动伸手按住小丑肩上沾着的无序残屑、用罪火替他烧掉，则小丑没有拒绝，但他低声一句「我不再是你的小丑了」，旧同伴的身份从这一刻松脱一线，黑火中多一缕「自愿放逐」味道。
- 若林恩当场命羽毛笔把小丑带回的每一段无序自解画面在信仰殿公开展示，则信徒阶层首次在黄金时代里看到辉煌之外的真相，三大圣堂的祷告声当晚压低一半，王座黑火反而更稳。
- 若林恩让主母以最高规格为小丑设接风宴、并亲自出席坐到他对面，则小丑握杯的手在桌下抖了一下，他没有喝那杯酒，只把它放回桌面，后续他把这件事记成「她最后一次以家人身份看我」。
- 若林恩主动追问小丑「你在无序里还见到谁」，则小丑说起几个已消解的旧控制者名字，林恩首次在黄金时代听见「死者名录」，后续 E749 因果燃烧时这些名字会以反向方式回响。
- 若林恩要求小丑把八音盒暂时交给他保管，则小丑会愣很久才把它递过去,指尖在盒盖上多停一秒，后续林恩持有八音盒期间，所有「乐者残响」场景他都能比旁人多听一小节。
- 若林恩在王座上直接宣布「无序自解就是胜利的前奏」,则小丑的脸第一次在王庭上沉下来,他不再说话离开大殿，后续他与林恩之间多一段「公开分歧」，银色幻想会私下找小丑对表。
- 若林恩让银色幻想立刻带小丑去兵工厂检修他残破机体,则她首次以「同伴」而非「战力」视角摸到他肩上的裂纹，后续她在 E754 中下令毁传送门那一刻会想起小丑当时的眼神。
- 若林恩让船长带小丑去喝一场旧时代的烈酒,则船长喝到一半把杯子摔在地上,他没有劝小丑留下,只说一句「你想走就走」，后续小丑在 E751 赶来时脑子里重放这句话。
- 若林恩让艾雯此刻就告诉小丑「乐者可能永远回不来」,则小丑不再去找乐者的执念会从这一刻松掉一半,他后续愿意把八音盒按下最后一曲的时点提前,这是反向改写 E752 的入口。
- 若林恩主动把完美世界光幕掀开一角让小丑看见王座上方的黑色裂纹,则小丑沉默很久只说一句「这哪里是黄金时代」,此后他看林恩的眼神从「看弟弟」变成「看将要烧尽的人」。
- 若林恩让小丑在王庭当众演奏一曲、不计代价,则八音盒里混进了一丝不属于乐者的沙哑,所有听到的人当晚都做了「终焉」之梦,信仰帝国多一层未被言说的预感。
- 若林恩决定不让小丑再踏入无序深空一步、把他软留在黑夜城,则小丑第一次对王发火,他还是走了,事件以变形收束。
- 若林恩在小丑离开前以心声对他说「如果你回不来,我会怪你一辈子」,则小丑在跨出光幕那一秒停了一下,他把八音盒第二把钥匙隔空丢给林恩。
- 若林恩让小丑把他见到的「无序自解」画面以灵能刻进自己左眼,则林恩整夜没有睡,后续他登临王座时眼里会多一层那种自解的火。
- 若林恩在主母面前公开感谢小丑「带回最后的消息」,则主母首次以最高礼待他,这一幕被艾维儿远远看见,她会对自己的权柄产生更重的疑问。
- 若林恩让小丑直接住进主母寝宫附近的旧屋,则他半夜被主母敲门送被子,后续 E753 船长与人偶家守城时小丑在废墟上回想起这一幕。
- 若林恩对艾雯说「小丑回来了,但乐者没有」,则艾雯眼底最深的那层阴霾会突然清晰,他对林恩的隐瞒从这一刻又增加一层。
- 若林恩让小丑把「无序生物正在自我拆解」这一消息捂住不告诉黑夜城同伴,则只有少数高层知道黄金时代尽头将至,后续 E747 噩梦柱落下时信徒的绝望会更深一层。
- 若林恩在王座上对小丑伸出手说「你是我兄弟,不必是任何人」,则小丑没有立刻握,但他在离开前回过头看林恩一眼,那一眼里第一次只有一个普通疲惫的同伴。
- 若林恩让小丑在离开前给黑夜城的孩子们讲一次无序深空的故事,则所有孩子听完后安静了一夜,后续 E754 撤离时这些孩子最先服从「不许回头」指令。
- 若林恩没有在王庭见小丑,而是独自去无序深空边缘和他私下会谈,则小丑会告诉他一些主线未公开的真相,包括织梦生前最后的灵能残响曾在无序出现过。
- 若林恩让左左在此刻现身和小丑打招呼,则小丑第一次伸手揉了揉左左的头,左左没躲,后续她会在林恩登临王座时把这段记忆拿出来压在他手上。
- 若林恩在小丑离开前主动把一小瓶灵能药剂塞进他口袋,则小丑后来在 E751 杀入噩梦潮时把这瓶药剂当最后一击砸出去,那一击的火光是王座能看见最亮的一缕。
