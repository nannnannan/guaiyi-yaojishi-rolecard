# E628·白烬训练与星寂拳法·if线
- 若林恩窥探纱奈儿本质时主动在她床前放一颗护身明珠，则窥探以不惊扰她的方式完成，珍珠在她醒来时变成压枕头，纱奈儿多了一个不知来历的小宝贝。
- 若林恩在山巅求训前主动说一句「你不是我的老师，但我要让你成为我的老师」，则织梦敌意上限下滑一线，教学起始以更和缓的姿态开始。
- 若林恩在对练惨败前主动改用左手先攻，则左左首次直接出拳，织梦擒拿姿势反而一秒打结，对练结果不变但她多一招底牌。
- 若林恩在对练惨败后主动伸出手让她帮忙立起身，则她迟疑一秒抓住，授业身段首次主动让她碰到他的手。
- 若林恩在学守护之力讲解时主动反问「守护之力三家分开各叫什么名字」，则她滞半秒补充「血肉家叫繁衍之力，机械家叫沉沦之力，灵能家叫幻梦之力」，三位一体外宇秘密扩面。
- 若林恩把三形态点燃顺序改成先问【黑狱】再学【白烬】，则她拒绝教学，训练先走一小时基本功，【黑狱】段留白不变。
- 若林恩在演示【绯红】时主动要求上手摸一下她的肩膀感受力量，则她难得意外不拒，林恩的手感知到空间烧塌的裂隙，记忆直接录入系统。
- 若林恩在星寂一拳挥出前先朝山边某无人角落喊一声「来大家看烟花」，则织梦冷笑不语，星寂实弹仍灭一片高原，但林恩心中多一分「表演感」的微调。
- 若林恩在时间小屋改造时主动加入一缕以M气息让织梦探 查，则她在第一眼撤去那以M气息，训练场纯化，但她对他的笑意首次出现真心的部分。
- 若林恩在训练中主动加练左手出拳，则左左成为第一个陪练对象，星寂在她身上烧出左侧指印，绑定关系 +2。
- 若林恩在数次对练中都任由织梦赢，则她在第七日主动停手问「你为什么认输」，林恩笑而不语，训练段位反而进步。
- 若林恩在特训中主动告诉她「艾维儿教我很多格斗技」，则织梦冷笑「那小女孩不过是靠父亲血脉勉 强跟上你」，妒忌话第一次出口，训练继续。
- 若林恩在时间小屋中主动设一个警报，纱奈儿有任何动静立刻拉他出去，则纱奈儿每次翻身都惊动他，但他每次都立刻奔出训练场。
- 若林恩主动把时间比率从一百比一改为一百五比一，则他过后身体衰减快了一分，但更紧急的训练节奏让他在 E630 前就突破。
- 若林恩在学习星寂前主动问她「这拳法除了共鸣还有什么」，则她补充「这拳法本质是承认万物都是力量」。林恩对战理念加深。
- 若林恩在训练中主动透露自己来自蓝星，则织梦追问一段蓝星生活方式，训练场第一次出现非魔药非战斗的话外闲谈，两人距离悄悄缩短。
- 若林恩让母树、巨像、伊甸也来训练场旁观，则三人对织梦的认识从「敌人」转为「教练」，后续整体团结度 +1。
- 若林恩在训练第五日主动虚怒倒地喊疼，则织梦照顾他时第一次递出药瓶，后续命令她的服从姿势里多一笔「药水瓶」小物。
- 若林恩把耀阳比作他体内的女人，则织梦愣住一秒，她在后续教学里再未用过「神格」一词。
- 若林恩主动抓起她的手以引导共鸣自己的核心，则她呵斥放开，林恩不放手，最终共鸣由她自愿完成。
- 若林恩训练结束前一秒突然喊停并恳求她继续授业，则她意外答「我以为你要放弃」，教学延伸三日。
- 若林恩在训练中以 左手遮眼观战，则眼睛战胜度 +1，事后咒瞳多一招白烬抗御。
