# E666·三重里世界与空间神格·if线

- 若林恩在撕开系统空间外壁之前先在意识深处冷冷地对自己喊一声「左左、巨像、织梦看着他」，则他胸口那道蛇鳞焦痕和耀阳同频一震，空间撕开时他稳住意志的能力比默认强一线。
- 若林恩撕开外壁时不是用手而是借三叉戟直接劈开，则破口更整齐、曲率乱流的侵入更稀薄，他跨出第一步时不用承受那扑面而来的眩晕。
- 若林恩在先做瞬移实验之前先在系统空间最深处用初诞者之力凝出一枚「自身印记」，则他瞬移后那枚印记会跟过来作为对照坐标，他在后续研究中保留一枚不会消失的锚点。
- 若林恩施放瞬移指令时故意在低语里带上「带我去一个没危险的地方」的修饰语，则系统空间依旧出现在他所在位置但出口方向略略调了一线，「它听懂了我」这一事实超越他自己的推测。
- 若林恩在乱流中伸手探向远方试图抓到某块漂流的残骸，则他指尖刚好触到一片属于以太战争时期的碎片，那场他以为过去的战役以一片实体形式在他指尖重新浮出。
- 若林恩进入乱流后立刻反向进入系统空间再出来，则他实测「入口=出口」的假设并发现其实不成立，系统空间在他离开那一刻默默换了坐标、他回程时落在偏离原地三米的位置。
- 若林恩在实验途中让左左的蛇鳞焦痕以一缕残识外放探知周围，则那片空间乱流中浮现出一个极淡的龙的轮廓，他自此确定「这地方与她已经发生过的事关系密切」。
- 若林恩试图用记忆倒推他第一次得到系统空间那一刻的画面，则他识海里浮出画家苍蓝的身影手持笔在虚空画过一道光弧，「是她给的」在此刻成为全部答案的最后一笔。
- 若林恩故意在系统空间内留下一个侮辱性书写比如「画家是笨蛋」，则他下次进来那行字会消失而地面会留下一条极细的「你也是」的回话痕，「她在监听」第一次是实证。
- 若林恩出系统空间后长时间屹立在乱流中不返回试图寻找画家本人，则一缕苍蓝的幻影会在远处朝他淡淡一点头又消失，「她知道、但不见」的边界被他亲自摸到。
- 若林恩在瞬移实验后抽出一次万物神格感应画中第三格的共鸣距离，则他发现画中与他的距离并不随他瞬移而改变，画家所在坐标是绝对的、不随他的「地」而浮动，「她不是这个梦里的人」在他心中翻涌。
- 若林恩从乱流退回系统空间时把一缕金色初诞者之力留在外壁破口处再用意志封口，则那道破口被他亲手烙下私人印记，往后除了他没有任何人能再以同样方式撕开。
- 若林恩在实验中尝试以极慢的语速向系统空间「请求」而不是指令式召唤，则响应速度反而更快，他以亲身体验到「它对我与对它对别的不一样」的诡异亲密。
- 若林恩将整个实验完整记入一张羊皮纸并密封保存进另一个独立小空间（比如项链坠子里），则他为自己留下一份「如果有一天我再次怀疑自己」的应急对照物，此后怀疑的链条不再纯粹靠记忆。
- 若林恩从乱流出来时狠狠一拳砸在自己的系统空间入口上以测定它的坚固性，则入口只漾起一圈涟漪又恢复原状，他由此判断「如果我消失，这个系统也不会消失」，「画家不在、它还在」的层级被他自己区分。
- 若林恩施放瞬移时主动闭上眼不去看光门的显现过程，则他被指挥「凭空瞬移」时的眩晕感少一半，这个不为外人所知的心得替他后续高速穿梭动作节省一线宝贵的精神损耗。
- 若林恩在撕开外壁时听到极遥远处传来画家轻轻的一声哼笑，则他下意识反手把破口封回去而不再往外走，他决定不在她的耳边深究、把探索留给下一次更私密的时机。
