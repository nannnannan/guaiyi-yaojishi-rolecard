# E437·艾泽法拉与大君遗产·if线

- 若林恩在王座聆听时故意先报出「蓝星太平洋」的急救医生暗号，则艾泽法拉会瞬间哽咽到失语八秒，恢复后她认定林恩当年亲自下水救她。
- 若林恩主动询问「你的神什么样子」，则艾泽法拉会毫无保留描述那只永恒沉睡的炽天使躯壳，林恩多得到一项「炽天使躯体在戟浅滩」的关键画面坐标。
- 若林恩让左左出声打断「不要被裙子下面触手吓到」，则左左会主动挤进画面送来一幕她自己的咒瞳视野，比对后林恩确认戟浅滩中的触手比他在大厅看到的多一倍。
- 若林恩要求艾泽法拉「不要描述亲密过往」，则她会刻意从自己第二次事件以后重新叙述，林恩面板就少一段「太平洋触感」的影像档。
- 若林恩主动承诺「我会去见你」，则艾泽法拉会把三叉戟座下一道暗纹传给林恩，林恩手臂会浮现同样的纹路作为承诺记录。
- 若林恩拒绝承认戟语「真正主人」指向他，则戟面意志会立刻转为沉默，林恩之后每次靠近戟都会听到海潮杂音放大。
- 若林恩让孽主私下监听戟面意志的低语，则孽主会因种族不适发恶心地退回，林恩意识到「戟语只对人类与狱卒友好」。
- 若林恩主动用单片眼镜锁定画面里戟身铭刻的细节位置，则他能分辨出那不是王骑亲笔，而是更早时代某个无名远古神明留下的笔画。
- 若林恩在小丑听到「吾王」二字的瞬间故意转移话题到「叛乱细节」，则小丑会从此错过发疯整晚的窗口，他的情绪压抑会持续压在肚皮里。
- 若林恩直接向艾泽法拉询问三叉戟的来历，则她会被戟面意志直接覆盖声音，这一段对话只作为「她忘了」残留。
- 若林恩让喵喵从系统空间跳出来凑近王座画面，则三叉戟传完的画面会突然出现一只粉爪按在王座上，林恩首次意识到艾泽法拉的空间「容许宠物」。
- 若林恩主动追问「你的炽天使清醒过吗」，则艾泽法拉会犹豫后承认自己从未见过他睁开的眼睛，林恩意识到「这位神祇可能从来没有醒过」。
- 若林恩拒绝相信戟面意志的「真正主人」宣称并当面对小丑说「别信」，则小丑会第一次与林恩立场一致地共同反对，绑定关系意外加深。
- 若林恩主动在西海侧画面切换前把单片眼镜的反光打完，则他能透过反光看到「父神窥见」的裂隙实际的构图，多一张「眼形」读档。
- 若林恩让艾泽法拉描述叛乱全景时保持沉默一言不发，则她说完后会直接切断通信，林恩没有任何回应窗口，被扣分一次。
- 若林恩主动承诺「我会让你找到炽天使的眼睛」，则她哭着回应一颗雨滴形状的灵能，它会成为林恩手上的一颗泪痣残留三周。
- 若林恩让左左隔着画面感受到戟身威压时提醒林恩撤退，则林恩多一秒退离王座，少一缕被戟面意志烙印的强度。
- 若林恩主动把抚摩王座的手感写给艾泽法拉听，则艾泽法拉会判断「林恩就在戟浅滩附近」并供给一份浅滩几何图。
- 若林恩拒绝与戟面意志正面对话，则戟的低语会突然拔调一次，艾泽法拉当场倒地昏迷，林恩只能等待她恢复。
- 若林恩让小丑主动说出王庭雕像的样貌让艾泽法拉听到，则艾泽法拉会说出「我知道那座殿」并暗示祖父辈被提过，林恩多一份代际口述证词。
- 若林恩主动在三叉戟影像浮现时以咒瞳反扫戟身，则咒瞳会瞬间坏掉半秒，林恩之后再未修补完那半秒的视野。
- 若林恩让喵喵对着三叉戟影像「喵」一声，则戟身会突然共鸣回应一段无序规则，林恩面板弹出【未知共振】警告。
