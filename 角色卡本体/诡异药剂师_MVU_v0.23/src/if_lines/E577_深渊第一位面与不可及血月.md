# E577·深渊第一位面与不可及血月·if线

- 若林恩拒绝折返强行继续单飞耗竭，仍不得写成已破障入战场；不可及血月事实与丘陵重复仍立，但蓝龙体力消耗提前压缩至危险线。
- 若林恩放弃血月改探荒原，以变形收束：不可及血月事实仍立，魔君城堡目标被无限期搁置，自缚天使的信仰缅怀线在焦土上多绕一夜。
- 若林恩在踏出迷雾时先对主宇宙基准刻度进行一次独立计时，则「不足十分钟」口径由他亲测，后续对时间异常的主动判断多一手数据。
- 若林恩在艾维儿化蓝龙后没有调侃而是直接跃上后颈抓紧鳞片，则龙骑士情结被压回心底，艾维儿少一次空中翻滚，但林恩在狂风中仍被吹得心神不宁。
- 若林恩在讨要缰绳时说「父亲留下的遗产是不是也包括骑乘权」，则艾维儿愠怒转为被戳中软肋，她不再翻滚但依旧加速，龙翼气流理着他头发往后拉。
- 若林恩在蓝龙升空时主动打开系统空间让左左也探出头，则左左趴在龙颈边缘大喊大叫，平稳飞行重新变成左左高空惊魂喜剧。
- 若林恩对自缚天使的信仰缅怀直接补一句「路西法也未必光环全保」，则主母信仰崩塌提前，但在不可及血月面前她少了一道「至少此处象征仍存」的缓冲。
- 若林恩在艾维儿补刀「包浆脚趾板」传说时忍住笑而是追问「父亲真的如此随性」，则艾维儿罕见地沉默几秒，后续王女威严在林恩面前出现一条微裂缝。
- 若林恩催促进度时改为「先确认血月到底挂多高再加速」，则丘陵地貌重复在更早节点被发现，不可及性质被更早锁定。
- 若林恩在发现空间法则无扭曲后立刻反问「如果不是迷宫，那就是锁定坐标」，则「非空间困局」判断被他所主导，撤退决定从指令变成推论共识。
- 若林恩对主母说「你一定也很想回去」，则自缚天使数万年思念被点燃，她在蓝龙背上的站姿从凝重变成紧握枪尖的决意。
- 若林恩对艾维儿说「真正的城堡一定在血月后面」，则艾维儿先犹豫继而被他笃定带动，二次冲月的决心由她来立而非由他来催。
- 若林恩下令撤退时没有说「回去」而是说「先拉开看看范围」，则折返验证窗口扩大，迷雾边缘脚印确认被延后，但不可及性质更加无可辩驳。
- 若林恩在蓝龙巡航时主动放出咒瞳扫描整片次位面边界，则空间回路无折叠的确认更早，但咒瞳同步被血月的异常折射干扰，额外心悸一层。
- 若林恩在折返前主动对主母和艾维儿说「我保证一定回来拿下这座城堡」，则两个女人对他的判断从「谨慎」升级为「毫不犹豫」，后续破障时信任成本降低。
