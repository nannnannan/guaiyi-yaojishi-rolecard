# E587·以太机械星云·if线

- 若林恩在伸手抚上装甲外壳前先放出一缕咒瞳视野扫过整片星云，则银河系尺度的机械葬场全景被提前录入面板，后续接 E588 时多一笔「苍银舰队沉没阵型」档案。
- 若林恩先调动空间法则朝最远处那艘被劈成两半的旗舰劈一记试刀，则碎屑飞溅带起的金属尘埃会在虚空中悬浮数小时不散，成为左左之后抱怨「呛鼻」的来源。
- 若林恩把首块裂片递给左左前先放在掌心掂一掂分量，则左左会先一步扑上来抢走，夜魔刀试劈那一场变成她独自炫技的舞台。
- 若林恩拒绝收下左左私藏的合金碎片、坚持全部入库，则左左鼓着腮帮在系统空间角落生闷气，E588 苏醒段她收钱袋的动作会多一分赌气。
- 若林恩敞开系统空间时让光门直接罩住一整座反应堆连根拔起，则反应堆底部残存的高维能量残渣会顺势洒落虚空，小丑在系统内尖叫「浪费」的台词被改写。
- 若林恩只搜刮稀有合金而放过完整战舰，则入库存单偏向材料学分支，事后万机之神日志里多一行「渴望拆解而非囤积」的备注。
- 若林恩把搜刮清单公开给小丑过目，则小丑会主动报出三种他只在古籍见过的动力炉型号，并警告勿碰其中一件，为后续事件埋一条「禁忌造物」支线。
- 若林恩在死物难担屏蔽的判断出来前先尝试对一艘战舰灌注初诞者之力唤活，则舰体短暂亮起又熄灭，反而坐实「生命火种已熄」的判断，并让以太在林恩意识里沉默数秒。
- 若林恩干脆什么都没收，空手穿过整片星云，则仓库为空、衣衫干净，但 E588 苍白耀阳灼烧段会因少一层机械防护联想而更凶险。
- 若林恩对小丑坦承「这些死物挡不了灾厄」并征求他意见，则小丑主动说出一句他对无序渗透的独门看法，直接替换原文中小丑被动提醒的走位。
- 若林恩走得太急没等左左，把她落在某条战舰甲板上，则她会自己抱着碎片一路小跑追来，E588「肉身交付左左」改成她追上来后被一把抱住。
- 若林恩在决定转向灵能前先回头再看一眼整片苍银星河，则那一眼会被录进后来的「白发人」记忆拼图，E588 渡鸦联想的画面多一层色彩。
- 若林恩公开说出「以太是技术力决定上限」，则以太会在意识深处发出一声几不可闻的叹息，这条因果可挂入后续以太个人线。
- 若林恩让小丑挑出三件最有价值的机械造物单独封存，则小丑拿走珍藏权，E596 银幻改造段小丑会主动开口索回一件作交换。
- 若林恩对星云中心逆推当年战场轨迹，则可提前看见那道把整支舰队劈成两半的「紫罗兰大君一道剑痕」联想，为 E588 映像段埋一笔先入为主的认知。
