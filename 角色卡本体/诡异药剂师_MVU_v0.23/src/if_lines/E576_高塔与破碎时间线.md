# E576·高塔与破碎时间线·if线

- 若林恩在左左话语余波中先切入法则视角再说话，则「时间亦细微紊乱」的观测轮廓提前，但左左因他骤然沉默而直接凑到眼前伸手摇晃。
- 若林恩坚持返回高塔消失处死盯背影，以变形收束：背影与塔均不可复现，来路化雾后他不再有幸存旁观者视角。
- 若林恩拒绝与主母艾维儿汇合，则双河破碎与汇合时间差仍可立，但迷雾上游行程改写为孤身深入，主母膝盖验真戏延后至下一次偶遇。
- 若林恩在高塔顶端不触碰壁画而是直接以初诞者之力轰击蓝图，则跨新旧世界的草图纹丝不动，反而触发记忆层大君驻塔时的短暂回响，视界闪回三秒。
- 若林恩试开系统空间时强行撑住错位光门并踏一只脚进去，则空间坐标紊乱直接把他短暂弹到奇异世界边缘，左左在迷雾中抓到他脚踝拽回。
- 若林恩点选时间战争「八千年前」而非「三千前」，则渡鸦层照样陷入，但交汇观测窗口同样不可复现，他只在洪流中捕捉到一缕与塔下背影无关的鸦鸣。
- 若林恩反复尝试逆流至被震荡掀回后仍不收手，则时间法则反噬升至面具层，他被迫提前吐出的不只是血，还有一缕被烧掉的时间本源。
- 若林恩在双河交汇观测后立刻向左左口述「两条时间流碰撞」画面，则左左听完罕见没有插科打诨，而是盯着自己的手低声说「我也觉得我的时间不太对」。
- 若林恩在塔下回望时选择走近背影而非回塔，则一切消失规则同样生效，但他在消失前一瞬捕捉到背影肩头一根极细的银白发丝。
- 若林恩与主母对答「才离开几个小时」时改口为「我度过了一段很长很长的时间」，则时间差确认仍立，但主母自缚天使的愧疚线被拉长，「找了好几天」的重量直接压到她肩头。
- 若林恩对自缚天使详细复述双河交汇与抹除推断，则「未全盘托出」被打破，艾维儿听完后的催促从「快走」升级为「我们不走就一起被抹掉」，急迫度跳档。
- 若林恩主动对弑莉叶之立在地上的弑莉叶控诉台词表示「我理解你的恨意」，则恨意非针对离开之辨被拉近，但主母「未背叛」自辩的孤独感被削弱。
- 若林恩询问左左是否看到塔下背影前先反问「你宁可看不见吗」，则左左摇头后补充「看不见但总觉得有人坐在那儿」，她未获双河详述同步，却有模糊体感。
- 若林恩离开时没把高塔消失记录进系统，则后续事件里他对时间异常的主动追踪失去塔体坐标锚，E577蓝龙航线多绕半圈。
- 若林恩在被主母膝盖顶中下体时顺势闷哼一声抓住她肩膀，则验真结果不变，但主母察觉他气息深度已不同于数日前，她在心里给他记上一笔「已不可同日而语」。
