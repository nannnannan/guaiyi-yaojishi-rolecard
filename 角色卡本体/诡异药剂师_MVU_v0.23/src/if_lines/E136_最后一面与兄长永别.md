# E136·最后一面与兄长永别·if线

- 若林恩在残魂碎片分离前先加固往日遗念媒介，则清醒期限延长数息，兄长能多说完一句嘱托再消散
- 若林恩让喵喵独自进入安置区见兄长、自己与巫神在外围警戒，则兄妹对话更私密，但林恩失去当面接下「照顾好傻猫咪」嘱托的机会
- 若林恩当面接下兄长伸出的拳头并以拳相抵，则记录为「承诺成立」，后续林恩对喵喵的守护行为会被赋予契约级分量
- 若林恩沉默不答只点头，则嘱托不被视为口头承诺，喵喵事后会自己把石子举到林恩面前再问一次
- 若林恩在兄长掷出石子的瞬间用鬼力拦下石子不让它飞远，则喵喵不必化猫追去，但兄长「不告而别」的旧日缺口没被填上，执念残留得更久
- 若林恩跟着喵喵一起追那枚石子，则追上时能看到她攥着石子回头的瞬间，此处留白由玩家决定是否开口
- 若林恩在兄长即将消散时递上一份止痛或凝神药剂，则药剂无法改变死亡结局，只能让最后几息的表情更松弛，兄长会轻声道谢
- 若林恩尝试用血肉支配者的权能挽留残魂，则权能判定失败并如实呈现反噬，兄长会摇头：「哥哥其实早就已经是一个死人了」原句落地
- 若林恩在消散前告诉兄长喵喵这些时日如何找他，则兄长记忆碎片被点亮，消散时带着完整的笑而非仅是松手
- 若林恩把小鱼形石子要走替喵喵「先保管」，则石子会被喵喵死死盯着，关系账目上记一笔「信任测试」
- 若林恩在场地外围布防拦截其余恶灵逃散，则四散的恶灵被收束在临时囚笼，队伍免于追击战但需处置一批囚徒
- 若林恩放任其余恶灵四散不追，则按原著路径恶灵逃入荒原，后续巡夜时可能再遇零散恶灵
- 若林恩提出为兄长立冢并把石子一起下葬，则喵喵会拒绝把石子埋掉，冢只立衣冠，石子留在她掌心
- 若林恩主动提议保留石子作为纪念物、绝不再尝试复活，则事件按完成路径收束，兄长线正式闭合
- 若林恩暗中保留兄长残魂的一缕作为研究样本，则被巫神头颅当场识破，乌鸦瞳孔警告而非动手，偏离账本记入发酵中
- 若林恩转身离开不陪伴追石子的喵喵，则回到营地时她已经自己回来，但当晚她不会主动蹭到林恩身边
- 若林恩蹲在原地等她回来、什么都不说只张开手，则喵喵化作人形撞进怀里，姐妹级依赖关系确立
- 若林恩在喵喵哭喊「骗子！大骗子！」时上前捂她的嘴让她保留体力，则她会咬林恩的手，痛感如实呈现不回避
- 若林恩把外袍披在她头上替她挡住黑雾余烬，则她在外袍底下哭到力气耗尽，事后把外袍叠好还回来
- 若林恩此前在E134或E135对喵喵承诺过「带她见家人」，则此处兄长会主动提到「小店长没有食言」，承诺账目兑现
- 若林恩对巫神头颅咨询「放下执念能否通用」，则巫神只回「个案，勿外推」，事件规则按原著口径锁定
- 若林恩本事件全程不在场，只在事后听喵喵转述，则事件仍成立但林恩与兄长之间无任何交集，立冢位置由喵喵独自选定
- 若林恩带着血锯或小小一同前往见证，则见证者增加，喵噬事后会被血锯默默多塞一份口粮
