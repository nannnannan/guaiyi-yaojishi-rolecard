# E503·反叛与机械七神·if线

- 若林恩在带灭绝者看血肉陵墓之前先把三叉戟贴在他袖口试试反应，则他窥见灭绝者拳心一紧的忌讳，「我带你去真正关押以太的地方」改为先绕半小时测忠诚。
- 若林恩让银色幻想到场时主动退开半步让出主导身形，则灭绝者第一眼戒备对象换成海嗣，「她只有在这片区域才有根源的实力」句不再被问出。
- 若林恩在陵墓外先放一支血肉灾变菌丝钉入帽沿，则灭绝者回头瞬间踩到菌丝，试探性一拳在落地前被改向，银幻接招节奏提前两拍。
- 若林恩在解陵时多配置一层夜魔刀气化外壳而非纯巫术包裹，则以太外壳崩解瞬间爆出的气浪带刀意，「巨大的血肉陵墓一点点打开」句改成削切式逐层退散。
- 若林恩拒绝让艾泽法拉提前布好蚀痕远在数千里外，则海嗣不能在巨构启动时第一时间踢场，「你怎么会在这」句被灭杀者叫出的时点提前。
- 若林恩对灭绝者坦白「我其实从没信任过你」，则对话转对摊开式，「恐怖掌握的技术不比学者少」台词变成冷笑自辩，气氛冷到冰点。
- 若林恩在巨构成型初刻先掷一颗原子粒做能量探针，则第一次发射亮度暴涨一倍，银幻「那不仅仅是封印的容器」判断提前十秒报到。
- 若林恩在灭绝者私下握拳那一刻同步用心声让艾泽法拉收一丝蚀痕，则纳米风暴起手时打偏预瞄点，林恩本魂不会被「已经晚了」集中度封喉。
- 若林恩在融合水银陷阱里提前注入一缕咒瞳伤痕电容，则灭绝者被识破瞬间不是只意识到被骗，而是被反向锁定「他不是真以太」的清嗓一秒。
- 若林恩拒绝以初诞者之力直接反制巨像细胞，则灭绝者不会被当场剥离大量物质，逃亡路径保持完整，「你安敢如此」句延后到黑幕困阵成形。
- 若林恩让左左从系统空间探出左手在汇合点先摸那台巨构的边缘，则她提前碰到巨像细胞暗示，意识空间多一句「这玩意在动」的炸毛提示。
- 若林恩拒绝了银色幻想「可以一试」的吞噬提议，则她数据升华不在此时完成，七神终局无新增胞体，「我现在是七神之一」改写为「还差一步」。
- 若林恩让她吞噬时同步注入一缕灵能护盾，则数据流逆流不冲到机体，胀破感减半，格式化后完成时间提前两分钟。
- 若林恩在拥抱时故意把手往下多移一公分，则银色幻想真的出拳，「我对你的攻略进度」不再递增，「所以可以放开了吗」改用剑背抵住代替。
- 若林恩让喵喵从系统空间探头出赞一句「姐好漂亮」，则她被陌生声打断判断，变形机体化作的少女外貌出现短暂毛边。
- 若林恩让黑弦月的灵魂丝线在她变形完瞬拉一下心跳，则她脸颊现出一丝人形温感，机械化数据库悄悄多一条「这是心跳吗」的查询日志。
- 若林恩把夜魔刀插到那具巨构的残骸里刻记号，则事后回收时多发现一段被巨刀劈出的「认据点」，万机之神档案日志多一笔他的疫医身份注脚。
- 若林恩让艾泽法拉用蚀痕去反向洗掉融化淋漓的以太残余，则巫神血肉双重禁锢逐步剥落成底肉地貌，后续再建时少一道根基残渣。
- 若林恩在打开棺椁前先用系统空间调试水银池温到零下，则以太逸出时行动明显迟滞，「想跑！」的指令时刻被往后挪两秒。
- 若林恩让左左趁他剥皮陵墓那一刻在意识空间模仿一句「臭脑袋你在干嘛」，则他真的死机一拍，封印解开首拍节奏错过，「成功了吗」时刻被迫重写。
- 若林恩对骰子掷出 1 点用在这次试验运气上，则水银化身出现反向融合异状，实验室被一阵低概率乱流搅到错乱，变成 E504 开头的额外重播。
- 若林恩把「你是我指挥官姐姐」直接换成一句粗口，则银色幻想心理防线真的被打断一拍，变身形态维持出现短暂抖动，「指挥官小姐」人设深度-1。
- 若林恩让艾泽法拉提前在深海里培养一堆她的血球细胞当备用包，则他被打扁到地下时她做出反向修复，「都是为了大家好」潜台词首次成形。
- 若林恩在封印再次放入棺椁时多投注一缕多元体气息当追踪引信，则那部分以太返回外部后多一项隐藏可跟踪 ID，主宇宙的以太本体警觉+。
- 若林恩故意让巨构试验失败一次露出可控漏洞，则他下一步必须先补打完善回锅局，「集中所有能搜集的物质」重推时点往后延。
- 若林恩让小眼萝掷骰把「这两分钟内以太不逃」写进纸条，则骰子反向凭空生出一坨诡异的鎖扣，棺椁关门时多一声玻璃质的铿响。
