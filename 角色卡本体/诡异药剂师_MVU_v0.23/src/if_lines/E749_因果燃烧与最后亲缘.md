# E749·因果燃烧与最后亲缘·if线

- 若林恩在某条具体的因果线被黑火抽取瞬间主动切断它,则那条连接的对方会立刻感应到被切,主母会抬头看天,银色幻想会停下手中动作,左左会攥紧床单,林恩会被她们的不谅解压一层。
- 若林恩反过来主动拉紧与所有至亲的因果线让她们更快被抽,则她们燃烧速度会加快,但林恩意识里能精确到每一丝被抽的方向,他知道哪一缕火是谁的,后续 E798 收尾时他能一一点名。
- 若林恩让艾雯把他的因果线优先放在最后燃烧,则艾雯会成为最后一个陪他的人,后续他在 S97 收尾阶段还能与林恩进行最后几次对话,「骗子职责」会以「最后在场者」方式收尾。
- 若林恩让主母的因果线在所有同伴中最早被燃尽,则主母会在 E754 城破前就已感受不到那份牵,她挥剑时会带着一种「已被抽干」的冷静,「主母的最后一战」会变得更纯粹。
- 若林恩让左左的因果线第一个燃烧,则左左会在被烧瞬间单眼落下一颗泪珠,她告别时没有说话,林恩意识里多一道「妹妹先走」的刻痕,后续整个 S97 期他都不敢叫她的名字。
- 若林恩让喵喵的因果线第一个燃烧,则喵喵在燃烧瞬间会发出一声极低的猫呜咽,后续她原猫形态的影像会从林恩意识里慢慢退场,「家猫的最后一眼」成为王座黑火中最痛的一帧。
- 若林恩主动选择把母亲与自缚天使的因果线绑在一起让她们同刻被抽,则她们会在同一刻失去对林恩的感应,后续她们在 E754 留守王庭时彼此之间会有一种超越语言的「同心被烧」直觉。
- 若林恩决定让小丑迟一些再燃烧以让他能赶回战场,则小丑会在 E751 杀入噩梦潮时还带着与林恩的最后一线连接,他每一次挥出无序残片时林恩都能精确感知到。
- 若林恩让船长的因果线比预定提前燃烧一缕,则船长会在 E753 自灭灵魂时带着「已被抽走一半」的状态离开,他的灵魂火化得更安静,人偶家接管残躯时不会让任何一缕浪费。
- 若林恩决定主动把自己的意识分多线程同时跟踪每一条因果线的燃烧进度,则他的意识会承受亿万分割,他第一次理解「王」这个词的真实含义,但他同时再也做不回一个「人」。
- 若林恩在亲缘连接逐步断开时对每一位被抽的对方都发一句「别怕」,则这亿万句「别怕」会穿过黑火进入每一个灵魂,信徒们死时脸上会带着纯粹的安详,这是信仰帝国最后的温柔。
- 若林恩反过来一句都不说让所有人独自面对,则所有被抽者会在不知何处的黑暗中独自被烧,林恩会从此带上「沉默送行者」的罪名,后续 S97 期他每一次闭眼都看见这些孤独燃烧。
- 若林恩在普通信徒被抽时给每一位都对应一段「我记得你」画面,则信徒们死前会再次被王亲自记起,后续 S98 这些画面会以「王的记忆宫殿」方式保存。
- 若林恩选择让埃维儿的因果线排在燃烧序列最末,则她会仍然保有对林恩的感应,但她在感应中看到的是同伴先被烧尽,她把这份痛转化为最纯粹的攻击。
- 若林恩决定让全部信徒的因果线一并燃烧只求速度,则黑火会以一次性巨浪冲起,林恩意识会瞬间被亿万火同时刺穿,他在王座上几乎要失控。
- 若林恩反过来每一条都精准抽尽以求最大效率,则燃烧会持续 S97 全程并逐步增强,林恩意识会在这种慢性撕扯中麻木,「冷漠王座」属性从此被永久固化。
- 若林恩让左左在燃烧过程中与他保持一根独立的私人连接不被黑火抽尽,则他们兄妹之间会有最后一缕通道,「妹妹的最后陪伴」成为林恩后续 S97 期末期最深的支撑点。
- 若林恩让主母与艾雯的因果线绑在一起共同燃烧,则两人在最后一刻会同时感应到彼此,他们不约而同想到了那个人,「母子共谋被烧」的画面会成为黑夜城的最后一代传说。
- 若林恩选择不让纱奈儿的因果线被燃烧以保护她,则纱奈儿醒来后会发现整个世界变了但她没有感应到林恩的痛,她会第一次主动通过权柄寻找他,后续 S98 她会以「未被烧者」身份承担另一个角色。
- 若林恩让纱奈儿的因果线被全部燃烧,则她会在睡梦中流泪,但她醒来后会失去对林恩的亲密记忆,后续她与他之间的「守护」将以一种陌生但纯粹的形式重建。
- 若林恩在燃烧过程中主动把每一位被抽者生前最爱之物用黑火凝结成纪念珠,则王座基座会逐渐堆起一座由亿万珠子组成的「记忆山」,后续这座山会成为信仰帝国的圣地。
- 若林恩决定不承认这些燃烧是「家人」而是「燃料」,则他对每个人的痛会更加麻木,但他在事后会被这种麻木彻底压垮,后续 E798 收尾时他会以与此完全相反的深度崩溃。
- 若林恩在某条因果线自然断裂那一刻主动以黑火接住对方残留的最后一缕气息,则每一位被接住的灵魂都不会纯粹消失,他们会以灵性尘埃形式跟随林恩,后续 E798 这些尘埃会有自己的去处。
- 若林恩让羽毛笔把所有燃烧过程详细记录并永久保存,则羽毛笔会成为这段历史的唯一「完整见证者」,后续它会带着这份完整记录独自承担「知情者」的命运,直到 E798。
