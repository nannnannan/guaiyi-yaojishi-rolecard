# E749·因果燃烧与最后亲缘·if线

- 若林恩在第三阶段晋升反噬即将顺着因果线波及所有亲友的刹那，果断以王座黑火率先斩断自己与黑夜城众人的表面因果羁绊，则正在外城血战的同伴们不会因他的狂暴晋升而遭到法则同调撕裂。
- 若林恩在燃烧自身与主母（自缚天使）之间的亲缘因果、于心底痛声宣告「从今日起你们不再是我的家人」时，将最后一缕纯白母子温情封入王座最底层的暗格，则主母在王庭外握戟的手会微微一颤，随即露出懂得他苦心的微笑。
- 若林恩在斩断与羽毛笔的因果联系前，特意让黑火在「下辈子再见」那五个字上多停留三息，则远在命运之境的羽毛笔会在因果断裂的剧痛中听清这句约定，含泪将手按在心口。
- 若林恩在剥离与苗苗的亲缘丝线时，故意将所有剥离产生的灵魂反噬全部拉回自己胸膛承受，则苗苗只会感到手腕上的契约印记化作一缕暖风散去，免受神魂割裂之苦。
- 若林恩在当着跪在阶前的艾雯面主动焚烧两人之间的兄弟因果时，看着艾雯惊愕抬头的眼睛哑声说出一句「下辈子再见」，则艾雯会在泪水中大笑着点头，彻底放开所有顾虑。
- 若林恩在因果燃烧的熊熊黑火中，坚持将每一个被他抹去羁绊的同伴名字在心底默背百遍，则即便宇宙法则不再承认他们是他的亲人，他的记忆却将这份亲缘焊死在了灵魂本源上。
- 若林恩在切断与船长、银色幻想的君臣因果契约时，顺势将契约燃烧产生的纯粹神力全部反哺回两人体内，则正在内城墙浴血死战的两位神王会突然感到神力暴涨，联手逼退三尊压境魇魔。
- 若林恩在剥离与小小的兄妹因果线时动作放到最轻、如同替熟睡的孩子掖好被角一般温柔，则正在废墟间寻找他的小小不会感到心慌，依然怀揣着「哥哥一定会回来」的纯粹信念。
- 若林恩在将黑夜城全城守军的信仰因果一并投入黑火焚烧、免除他们死后灵魂被终焉污染同化的厄运时，独自吞下万民信仰断绝带来的刺骨严寒，则他的黑火会由狂暴转为深不见底的幽暗。
- 若林恩在燃烧与黑弦月（人偶小姐）的主仆因果时，留下一根没有任何法则气息的普通记忆丝线系在她指尖，则黑弦月在随后独守圣所结界时，依然能凭着这根凡间丝线感受到他的存在。
- 若林恩在切断与艾维儿、哭泣小丑及伊甸的因果牵连时，将三人昔日体内残留的最后一丝无序隐患一并抽走焚毁，则三人在最后的殉道之战中流出的每一滴血都属于纯粹而骄傲的人类与神明。
- 若林恩在因果大火烧至最旺、自身几乎彻底沦为宇宙间无父无母无友的孤神之际，咬破舌尖以一口心头血在王座靠背写下「林恩」二字，则他永远不会在无边的孤寂中忘记自己是谁。
- 若林恩在斩断与夏娃及幸福之家孤儿院的庇护因果时，将燃烧化作的灰烬凝聚成一层无形的隔音壁障笼罩孤儿院地窖，则躲在最深处的年幼孩童们在城破之时听不见外面凄厉的惨叫。
- 若林恩在剥离与泰坦、女巫神等老部下的同袍因果时，于黑火中向他们每个人行了一记庄严的军礼，则正在第一道防线赴死的女巫神与泰坦会在恍惚中看见王的披风在城头一闪而过。
- 若林恩在艾雯试图阻止他独自承担因果断裂的反噬、伸手去抓那团黑火时，以王座威压轻轻震开艾雯的手并斥道「连你也不听我的话了吗」，则艾雯会怔怔地收回手，像幼时一样顺从地低下头。
- 若林恩在所有亲缘与羁绊全部付之一炬、神格彻底摆脱法则软肋的瞬间，没有感到轻松反而发出一声压抑到极致的呜咽，则这座冰冷的罪恶王座会第一次为它的主人铭刻下名为「孤独」的权柄。
- 若林恩在因果燃烧殆尽的余烬里，偷偷拾起一枚尚未完全化灰的旧日全家福记忆碎片藏进左眼瞳孔深处，则当他日后以黑火焚尽五十九尊魇魔时，左眼深处始终映着昔日王庭的万家灯火。
- 若林恩在向全宇宙宣告「林恩从此孤身一人，一切罪孽与终焉因果尽归吾身」时，七十一座终焉之柱原本分散轰击黑夜城的法则诅咒会有半数被强行吸引至圣所穹顶，替外城守军分担了灭顶之灾。
- 若林恩在切断与人偶家的因果丝线时，顺手替她将那根连接着船长旧剑的宿命红线系得更紧，则人偶家在城门缺口扶住船长无意识躯壳的那一刻，两人心中皆无半分遗憾。
- 若林恩在亲缘尽断的剧痛中迎向第三阶段神格的最终锻造，不再借助任何外力缓冲而是以纯粹的肉身与意志硬扛法则重锤，则他蜕变出的终焉之躯比轮回神王预想的还要强大三成。
- 若林恩在说出「下辈子再见」后，将这五个字的声波封印在圣所石门内侧，则当E757黑弦月守在门外战死前夕，石门上会轻轻回荡起这句温柔的诀别。
- 若林恩在看着自己双手上所有代表羁绊的命运红线尽数化为黑灰飘散时，用力握紧双拳将黑灰揉进掌纹，则那些被斩断的亲缘从此化作了他人无法窥探、也无法斩断的掌心骨血。
- 若林恩在彻底完成因果切割的最后一秒，对着空荡荡的虚空轻声补了一句「骗你们的，你们永远是我的家人」，则这句不被法则记录的私语，成为了他日后在E761重塑世界时最核心的火种。
