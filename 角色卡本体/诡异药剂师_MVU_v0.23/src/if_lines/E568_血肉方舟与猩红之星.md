# E568·血肉方舟与猩红之星·if线

- 若林恩在她落悬浮岩石时主动先把恶鬼面具夺过来扣在自己脸上而非任由她拿起，则她盯着那张面具愣了一秒，随即伸手夺回，「别碰我的东西」的冷语落下。
- 若林恩在「定位到了污染者位置」这句话出口后主动追问「我能帮你省多少力气」，则她瞥他一眼说「六成」，但他得到的这份「六成」数字带着她对他能力边界的现场评估。
- 若林恩在被左左拆穿「顺便打包」时主动压住左手不让她继续说下去，则左左红瞳圆睁怒视，「你在帮她瞒什么」的疑问成为瞬间之后以M注视两人的隐忧种子。
- 若林恩在分成比例讨价还价时主动把比例改成「我七你三」而非接受「我六你四」，则她笑容一展说「你很大方」，但她眼里那份对他谋略的隐形评分略微下调，林恩认出她笑容里的测试味。
- 若林恩在无序化屏障覆体瞬间主动伸手顺了一下她的长发而非任由她一手抓胳膊，则她手微微一顿，反手握住他的手腕加重了一分力度，「别以为我不会恼」。
- 若林恩在被她闪电迸射带离瞬间就主动用三位一体机记录此刻无序视野里全部诡异色彩，则他面板中关于「王女体内无序本质」的那段数据成为日后研究无序生物的稀缺参考资料。
- 若林恩在她说「我跟狱卒不一样」时主动追问她处理无序化改造的跳步原理，则她坦言不是改造而是继承，但「继承的无序本质」带来的寿命问题以一笔带过，留下一层悬未深谈的暗涌。
- 若林恩在被问「你要看吗」时主动反问「你变成那样子时能控制住自己吗」，则她先楞再笑说「几百年才能醒过来」，但笑里带着她此生第一次有人敢当面追问她自我失控的边界。
- 若林恩拒绝看她转化时又主动补「我不是怕你，我是怕我没法把你拉回来」，则她瞥他的目光变得不苟言笑，她第一次用正经而非戏谑的方式回应他「你也不会拉得动」。
- 若林恩在幽冥海支流出现时先伸手抚了一把支流边缘溅起的「光」介质，则他指尖传来的不是温度而是一种极悠远的信息感，关于主宇宙在何处有了重创的另一种验证。
- 若林恩在五艘血肉方舟远观时主动让三位一体机分别记录每艘面板的細节差异，则除「半无序的神级造物」这一统一定位外，五艘方舟各自的小型配置差异在他面板落成档案。
- 若林恩在她讲述噩运引擎那段时主动打断问「引擎的硬件产自哪里」，则她答「被打碎的神界那段世界树残肢」，神界与物质世界"如何对接"的秘闻首次以这一具体词落地。
- 若林恩在她讲述污染者起源「最初来自灾厄对物质宇宙生命的腐化影响」时主动问「那物质宇宙里最初的生命是怎么来的」，则她沉默几秒说「这个我已经忘了」，记忆里某种旧神界的葬礼隐含背后。
- 若林恩在孢子瘤爆炸喷出污染者时主动让三位一体机拍下了那一段影像，则「污染者批量生成」的恐怖画面第一次被林恩收集到原始资料库，后续反哺战策可被引用。
- 若林恩在她冲向猩红之星前主动朝她的背影喊一声「别死在那边」而非任由她冲过去，则她身影微一顿，回头朝他露出一抹他读不懂的笑，但下一瞬已无影无踪。
- 若林恩在口头计划顺舟时主动让小丑现场演示一次开启通道的能力边界，则小丑在无序深空里捏出的仅是一个米粒大裂缝，「通道无法稳定打开」的现实让他的口头计划添了一个限制条件。
- 若林恩在她「你不要走太远」的命令下主动原地不动并让小丑为自己建一个简易法则隐身泡，则气泡折射把两位王级存在最后的身影隔绝开来，他的隐匿层级升了一档。
- 若林恩主动提出他可以在她与指挥官交战时趁乱溜进另一艘方舟偷取情报而非顺舟，则她展出对他「随时想着收益最大化」的精神风貌的又一次讥诮。
