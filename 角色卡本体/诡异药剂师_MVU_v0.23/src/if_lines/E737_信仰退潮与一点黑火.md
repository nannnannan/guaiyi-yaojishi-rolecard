# E737·信仰退潮与一点黑火·if线

- 若林恩在三十尊魇魔同时发难、自己逆势硬撼被震飞的瞬间强行展开磅礴大梦，却被魇魔们发现大梦内早已没有储备分毫罪火、陷入真正干涸，则他会干脆放弃以火海平推的旧战法，仅凭手中夜魔刀与肉身在干涸的大梦中与群魔贴身搏杀。
- 若林恩在数尊魇魔于大梦内部直接引爆自身炸开缺口、并将漆黑的「终焉之柱」如铆钉般狠狠钉入大梦核心时，拼着胸膛被两尊魇魔利爪贯穿也死死抓紧刀柄不退半步，则他惨烈浴血的身影会通过信仰链接深深刺痛全宇宙每一个旁观者的眼睛。
- 若三大圣堂上空的信仰之力因亿万信徒目睹「神明流血濒危」而陷入雪崩般的大退潮时，林恩在战场上没有流露出半分对众生背弃的怨怼，则这份孤身赴死的纯粹反而印证了艾雯爵士在圣堂前对自缚天使所说的「神与王的区别」。
- 若自缚天使（主母）在看着圣堂信仰光辉急速黯淡、颤抖着询问艾雯该怎么办时，听完艾雯关于「把林恩当神去盲从必然崩溃，真正的信仰是让普通人明白自己能与王并肩作战」的剖析，立刻下令将战场画面继续向全宇宙毫无保留地转播，则那场绝境中的呼唤才得以传遍万界。
- 若边疆破败街道上那个衣衫褴褛的小女孩含泪对天嘶喊出「不能输啊！！就算王要身先士卒！！那也要让我们这些羸弱的家伙先死掉才可以！！王不就应该和他的子民一起冲锋陷阵吗！！」的那一刻，林恩在漫天血雨中恰好侧耳听见了这声微弱却炽热的呐喊，则他原本布满裂纹的金色双眸会瞬间亮起璀璨的光芒。
- 若全主宇宙的生灵在小女孩的呐喊中如梦初醒、领悟到「从来都没有什么救世主，因为我们每个人都能成为救世主」并让纯粹坚韧的真信仰逆流而上时，林恩主动敞开千疮百孔的心灵之海接纳这股洪流，则原本束缚他意志的尖啸面孔与锁链会在瞬间化作纯粹的金色柴薪。
- 若三大圣堂的信仰光柱止住颓势直刺苍穹、汇入林恩体内即将熄灭的罪火最深处时，林恩将两年王座枯坐积淀的所有痛苦、守护执念与众生「与王同行」的信念彻底熔为一炉，则那一点纯粹深邃的第三阶段「漆黑之火」将在他眼底轰然点燃！
- 若林恩在第一点黑火点燃的刹那轻轻握紧夜魔刀，感受着体内从未有过的、仿佛能烧穿一切无序腐化的寂灭伟力，则围攻他的十余尊魇魔会在本能的战栗中骇然暴退，但一切都已经太迟了。
