# E61·突围反杀与夺萃之镰·if线

- 若林恩在白夜被恐惧尖啸钉在原地时不踹那一脚，则白夜的恶灵之躯仍被尖啸拖住，林恩只能先靠肾上腺素注射与话术唤醒，反杀之志的清明度被延后一轮，腐蚀毒雾在龙吸水完成前先漫过前排夜医的长袍下摆。
- 若林恩没拽左左放龙吸水、而是把史莱姆最终形态药剂直接泼向绿雾本身，则毒雾被胶质软体包裹成团块沉降地面，左左的深渊巨口绝活在本事件中不再展示，血肉人形潮从雾底提前分娩涌出。
- 若林恩在黑弦月丝线捆住圣徒时抢先打出以M三连而不等左左咬肩，则疼痛转以M的通道由林恩拳头直接完成，左左肩头咬合空缺，黑弦月小手发烫的震颤被林恩的头顶汗珠替代。
- 若林恩在圣徒引爆畸变迷雾前先把小宝贝从腰间放出当移动肉盾，则血肉人形前排被小宝贝缠住拖慢半轮，阿姆斯特朗回旋巨炮的命中目标里夹杂了小宝贝自身，骑兵形态在本事件中无法完成。
- 若林恩把涩涩药剂的配比调成"只作用于疫医不作用于夜医"的定向版本再掷出，则夜医队伍里没有"杰哥不要"的推搡场面，但疫医追兵的侧翼阵列在粉红烟雾扫过后同步变形，敌我两阵营同时陷入同一种压迫感。
- 若林恩在圣徒悬赏50万骷髅币时不竖国际手势、而是当众报出自己夜医实习生编号，则疫医与血肉人形追击前先互相推搡抢功，林恩的仇恨拉动效果因身份暴露打折，分兵策略在第七个岔路前就被识破。
- 若林恩在圣徒瞬移至身侧时不用触手长索弹射、而是激活系统空间取出备用手术挡板硬接巨镰，则镰刃在挡板上砍出深痕但林恩未被轰碎半边身，"亮个相吧"未发生，夺萃之镰的顺走时机必须改到圣徒猫娘化空白期尾巴上。
- 若林恩在圣徒被猫娘药剂命中后不立刻折跃离场、而是站在原地补足"猫娘化全程观察记录"的诊断记录，则死亡凋零的黑斑从林恩指尖开始蔓延的速度加快一倍，左左手上的黑斑同步提前浮现，折跃前林恩必须额外承受"凋亡视觉"的幻象冲击。
- 若林恩在突围时把兽医专用肾上腺素全部留给自己而不分给夜医，则夜医队伍在分兵七八次后掉队超过三成，白夜的双剑因体力透支从白焰转为暗红，圣徒的追兵在接近诅咒之城时不再只咬林恩一人。
- 若林恩在以M充能max时不是一拳砸地而是把天女散花之拳对准天空轰出，则冲击波向上撕开山谷雾锁，血肉人形与疫医被气浪掀翻而非瘫软，左左、黑弦月因提前被林恩护在身后而保留行动力，突围时在场夜医能同步跟上提箱狂奔节奏。
- 若林恩在黑弦月能量耗尽停机前不按下关机键、而是把她留在战场上当固定丝线路标，则丝线网在追兵冲过时自动收束成陷阱网，但黑弦月的人偶之躯承受圣徒残余凋零气息的侵蚀，E62的黑弦月验伪环节需改写为"丝网回收与充能修复"。
- 若林恩在圣徒投掷死亡凋零前先把猫娘药剂手雷捏在手里不扔出去，则圣徒的左臂萎缩动作没有被猫娘化打断，死亡凋零的释放速度加快一轮，林恩的凋零侵蚀从皮肤层深入肌肉层，但保留了猫娘药剂作为E62入城的额外筹码。
- 若林恩在以M三连放倒圣徒后不趁机顺走夺萃之镰、而是让白夜在圣徒倒地时补上"杀疫医不算破戒"的正式处决，则圣徒在猫娘化与凋零释放前被斩杀，夺萃之镰作为无主之物落在战场中央，林恩必须在追兵包围下做一次"战场拾取"的高风险动作，E62的疫医伪装线因"击杀圣徒"名声起点难度上升。
- 若林恩在左左龙吸水解围后顺手把吸进腹中的毒雾样本挤出收集进试剂瓶，则他多一瓶"腐蚀毒雾浓缩液"的私人存货，左左的口腔内残留毒素让她的嘴唇在接下来几个时辰内呈现青紫色。
- 若林恩在以M三连放倒圣徒的那一刻同时启动夺萃之镰的诅咒折跃、把镰与人一并拽出战场，则小宝贝未被"亮个相吧"叫出，圣徒的死亡凋零只追到一半失去目标，但夺萃之镰每日杀生的诅咒在当晚就需要立刻兑现一次。
- 若林恩在骑小宝贝蛇皮走位时让她把腐蚀液从"镰臂灼烧"改成"地面铺洒"，则血肉人形与疫医追兵在追赶路径上持续踩入腐蚀区，小宝贝的舌头因长时间暴露在外干燥起皮，追兵整体追击速度被拖慢。
- 若林恩在圣徒瞬移偷袭时不靠黑弦月挡刀、而是用触手在脖颈处编织"外科手术缝合网"硬接巨镰，则镰刃切触手网时被缝合线缠住，触手被斩断数条但圣徒拔刀动作被延迟，白夜与左左获得一次连击窗口。
- 若林恩全程不主动使用以M之力、全部依赖药剂与物理操作，则以M充能槽保持低位，系统刷屏的"踹回现实"不再出现，白夜的意志唤醒只能由肾上腺素注射与话术完成，恶灵们被拉回现实的方式从"精神震荡"改写为"肉体痛觉回神"。
- 若林恩在圣徒释放死亡凋零后立刻用夺萃之镰短距离连续折跃、而非长程直接离场，则他在凋零黑液的地面上留下一串断续的血雾残影，追兵与圣徒视线被多重残影干扰，到达诅咒之城的时间点比原案推迟半轮但凋零侵蚀浅一层。
