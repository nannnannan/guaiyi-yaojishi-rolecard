# E781·如果我必须杀了你·if线

- 若林恩在古神战场废墟上没有拔剑而是先向那只远古渡鸦展示自己体内的深渊黑火，则那只渡鸦会收起敌意凝视火焰良久，在承认同源之前先问他「未来的我们赢了吗」。
- 若林恩在说出「如果我必须杀了你」之前先向那只渡鸦坦白时间线已被未来黑手锁死，则对方不会做任何无谓闪避，而是主动挺胸迎向他的剑锋说「那就用我的死替你开路」。
- 若林恩在捏造假尸时不仅动用【黄金梦境】，还分出一缕黑夜城的真实烟火气息裹住那只渡鸦的灵魂，则被藏入梦境深处的渡鸦们会在睡梦中闻到故乡的药香，不再因漫长囚禁而躁动。
- 若林恩在十万渡鸦的时代长河中每一次挥剑斩断因果前都默念一次对方的编号与存在痕迹，则他的【黄金梦境】里会立起一座无名碑林，每块石碑下都安睡着一道完整的渡鸦魂魄。
- 若林恩允许左左在每次假死剥离瞬间用她的黑火帮渡鸦灵魂抚平剑伤痛觉，则左左的精力消耗会翻倍，但所有被收入黄金梦境的渡鸦都会记住这只温柔的左手。
- 若林恩在古神残骸堆积的荒原上遇到一名尚未咽气的旧时代凡人信徒并随手递出一瓶止痛药剂，则那名信徒在临终前会把「戴单片眼镜的黑衣渡鸦」刻在石壁上，成为后世幽魂巷传说的一角。
- 若林恩在峡谷篝火旁没有立刻盘问来自未来的画家，而是先往火堆里添了一把干柴并递给她一杯热饮，则那道蓝色光晕笼罩的身影会微微颤抖，用几乎听不见的声音道出一句「很久没人请我喝东西了」。
- 若林恩在未来画家承认自己来自幽魂巷与诊所时期后，主动追问「那时的我有没有好好保护你」，则画家的蓝色光影会剧烈波动一瞬，偏过头避开他的视线只答「现在说这些已经太迟了」。
- 若林恩要求未来画家在地图上先标出她曾插手抹除过的所有历史节点，则画家会在灰烬上画出一张密密麻麻的星图，让他第一次直观看到两人在时间长河里交错的次数。
- 若林恩在得知过去的自己早已被清洗却仍本能执行计划时，主动伸手触摸地上那具远古渡鸦留下的骸骨，则骸骨中残留的一丝不屈执念会顺着指尖融入他的黑火，让他的剑锋重上一分。
- 若林恩选择把黄金梦境中收容的第一批渡鸦灵魂安置在复刻的幽魂巷药剂店阁楼里，则那些一辈子只在血火中厮杀的远古渡鸦会第一次笨拙地学着坐在椅子上打量和平的街道。
- 若林恩在与未来画家对坐时主动摘下单片眼镜擦拭并亮出自己眼底的疲惫，则画家不会再维持冷漠的神性腔调，而是叹息着提醒他「在去时间之末前，先让你的左手歇一歇」。
- 若林恩在斩断某处历史节点的渡鸦因果后故意留下一枚小小的黑火余烬作为假象，则潜伏在幕后的黑手会在那枚余烬上浪费一次窥探算力，为他的下一步争取到喘息之机。
- 若林恩让左左在峡谷外围布下隔绝因果窥探的梦境帷幕再与未来画家深谈，则画家会多透露一条关于时间之末黑夜城废墟的地形细节，帮助他在下一战少走一段弯路。
- 若林恩在听完未来画家关于「斩断过去」的警告后主动反问「那你自己的过去呢，你也打算一起斩掉吗」，则画家会沉默整整十息，脚下的枯骨在她的灵能溢散中化作细碎的白沙。
- 若林恩选择在黄金梦境里为每一只假死脱离的渡鸦保留他们原本的记忆而不做封存，则他在后续战斗中随时能听到十万道同源声音在心底为他呐喊助威，但精神负荷也会成倍增长。
- 若林恩在离开远古峡谷前主动将一朵用黑火凝成的紫罗兰留在渡鸦枯骨旁作为祭奠，则那朵黑火紫罗兰会在历史尘埃中静静燃烧万年而不熄。
- 若林恩在起身赶赴下一处时间节点前主动与未来画家击掌立下临时盟约，则那道蓝色身影在消散前会笨拙地回击一下，指尖传来的温度冰凉却真实。
