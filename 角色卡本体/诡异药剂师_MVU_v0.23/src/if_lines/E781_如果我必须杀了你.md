# E781·如果我必须杀了你·if线

- 若林恩在历史终点主动以一根黑火之剑走向过去自我，则过去自我会先看穿他的来意,两人对打十数回合而胜负不分,左左被迫介入把二人扯开。
- 若林恩允许画家残影完整抽离过去渡鸦的「关联记忆」而不是部分，则渡鸦群体忘了林恩本人，却仍记得「有个值得为之战斗的未来」,反抗意志更纯但更孤独。
- 若林恩主动朝画家提出「我先杀了自己你再动手」，则画家残影在那一刻会停顿一秒——那一秒里她第一次不像工具而像一个会犹豫的人。
- 若林恩选择让过去渡鸦保留全部记忆并承担未来因果负担，则 E782 中七十一噩梦数量会临时增加到八十，但他从渡鸦群体获得一支「知情同盟」。
- 若林恩先去找那个版本的远古渡鸦单独谈话而不是面对画家，则远古渡鸦会给他一个完全不同的解决方案——用她自己当代价而不是用记忆。
- 若林恩主动把自身被抽离的那段关联记忆切碎二十四份撒在不同时间点，则空白实体需要逐一收集，他在 E782-E789 多获得一层时间冗余。
- 若林恩让左左在记忆抽离瞬间把自己钉在当前而不是跟着林恩进入过去，则她成为唯一一个「没看过修改」的见证者，她在日后会成为校验林恩的锚点。
- 若林恩主动把自己的咒瞳借给过去渡鸦看一段未来影像，则那些渡鸦在 E782 会以「知情者」姿态重新加入时间战争。
- 若林恩把自身某段痛苦回忆替换给过去渡鸦作为交换，则他失去那段痛苦，但过去渡鸦的灵魂上会留有一道属于他的疤痕。
- 若林恩在画家抽离瞬间反向把一根手指伸进她的残影里，则他会被她拖进她的本源记忆，看见紫罗兰大君第一次教她握笔的画面。
- 若林恩选择把远古渡鸦从历史终点藏起来而不让她面对决定，则她会在 E782 主动寻到他质问「你凭什么替我们选择」。
- 若林恩主动用完整黑火为自己烙一道「不得自杀」印记，则这条印记在 E789 会被空白实体反向利用，空白可以借印记让林恩无法以同归于尽收场。
- 若林恩让喵喵舔一口画家残影的颜料，则喵喵三日里会不断咳出带彩色的毛球，那些毛球里藏有被抽离的记忆碎屑。
- 若林恩主动把过去自我的某段战斗技能当场吞噬，则他能掌握那套技能,但林恩会短暂忘记一段属于他与某位红颜的温情瞬间作为替代。
- 若林恩动手把自己的过去自我从根系彻底抹除，则过去自我的渡鸦同伴会全部成为「无主孤魂」,E782 中他会面对一支由孤儿组成的复仇者军团。
- 若林恩选择不杀过去自我而是把自己封进一颗因果琥珀，则他在 E786 苏醒时会面对一个被改变但不受他预期的世界。
- 若林恩在画家残影抽离记忆时主动抓住她的手腕说「停一下」，则她会看他一眼,那一眼里有他在其他地方从未在她的残影里见过的活气。
- 若林恩主动把抽离的记忆暂时存放在自己心脏而不是交给画家，则他必须每天承受一次那段记忆的真实重量,E786 时那段重量足以压垮他的肋骨。
- 若林恩把喵喵作为历史见证放到过去渡鸦身边，则喵喵会在 E786 带回一段「未被抽离的渡鸦日常」,这段日常比任何战斗都更令林恩动摇。
- 若林恩选择放任画家按她自己判断抽离多少就抽多少，则抽离后残留的记忆不再规则，E783 林恩会在时间长河中看到一组「不连贯的渡鸦面孔」。
- 若林恩主动朝过去自我扔一瓶理代制的「记忆锁」,则过去自我在被画家抽离时会保留一段加密封底，那段封底在 E790 会作为最后的反转钥匙。
