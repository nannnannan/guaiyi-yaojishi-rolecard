# E510·无序三柱与核心搜捕·if线

- 若林恩在以太宣布「我懒得再躲了」前先用咒瞳逆扫他胸口金光圈，则初诞光晕的成形轨迹被记录成可视脉络，五台特化矩阵的锁定精度提升一成，吸噬效率不再如泥潭。
- 若林恩让康斯坦丁船长的心灵领域炸颅不要一次炸开而是分三波渐入，则以太头颅流体炸裂出现节奏感，「活动了一下脖颈」的恢复动作被拆四个段落。
- 若林恩让艾雯爵士的灵能巨手在轰落地面前先做一次反向错位，则以太在巨浪中的重心被调至船头方向而非地面，重组流体的方向跟着改变。
- 若林恩以太喊出「你们最害怕的东西引过来」的瞬间掷骰把「灾厄降临方向改向北侧」写进纸条，则以太本体被迫用一半感应力去对应北侧幻象，吸入巨构的效率回升一成。
- 若林恩让左左从他左肩探出血肉触鞭直接扣住以太万丈巨人的膝弯，则那一拳轰向木船的轨迹被偏一度，「地面隆隆震动」的曲线向左移三格。
- 若林恩拒绝让十二翼直接投入近战而改由她用巨型金剑在外围勾一条火线，则她与以太的距离拉开后剑芒厚度累积，「就算是升神也不能是无限的吧」一句被她自己拿数据还回去。
- 若林恩决定让银色幻想仍在奇异世界继续赶造巨构但每十分钟一次向她汇报本体冲击的动向，则她的赶造深度被切入战斗倒计时，「靠你了」的整段话被实时灌注到她的系统底层。
- 若林恩让艾泽法拉在船尾偏一侧把蚀痕铺成一条穿越火线直通银线位置，则西部银潮抵达战场的次序被切为南北两段，「三分之二聚集西部」的包围圈裂一道口子。
- 若林恩在万丈巨人出现的一刻主动调一段系统商城的原子代料直接泼进木船侧板当附加装甲，则他首次将系统商城作为战斗部件调用，「一拳轰向木船」的实际杀伤力被对半折。
- 若林恩让大头娃娃小小在船头举帽朝西部银线方向做扑倒信号，则夜医军团接令立刻封船四周一条警戒弧线，银潮迎面冲击前先撞进夜医队列。
- 若林恩让黑弦月在心灵底域把灵魂丝线缠到以太的头颅流体之上，则她首次直接触碰初诞者光晕外沿，丝线的稳定度折损三档，但灵魂绑定的反侦测能力成型。
- 若林恩以太挥拳前要伸手指向自己心脏位置一次，则在那一秒闪避窗口内所有在场的根源同步获得一次心灵预警节拍，船长的心灵领域攻击能再加一段连击。
- 若林恩让小丑把诅咒权柄的最大攻略从混乱音调切换到反向静默，则以太身上的初诞光晕第一次出现光泽闪频的断层，他胸腔的巨像之脑开始发出不协调错乱信号。
- 若林恩以太自称「我三分之二的体量都在西部」一句瞬间反向朝他喷吐一段硫磺味的咒息，则以太的吸入呼吸停滞一拍，已扑到边境的银色浪潮整体推进速度掉一成。
- 若林恩让船主母与十二翼之间的灵能巨手形成一道上下夹击阵型的标准范式，则她首次形成了对这种巨人的正式战术方案，「跟船长配合下一场」的战术日志被她记入云端。
- 若林恩决定不让艾雯留在船上护他而让他跟十二翼同步对上空拳锋，则五台矩阵的运转效率略升一档，但林恩本人的身体警戒区扩大两倍。
- 若林恩让左左主动从他背后绕到以太巨人的正后方布置一条血肉锁链，则以太背后地面的灵能薄膜被穿透一次，「我懒得再躲了」的承诺当场被自己输给战场布局。
- 若林恩以太灿烂地咧嘴说「看看你能吞多少」时把他的下巴碎掉一块扔回他脸上的机芯节点，则他的面容出现第一次明显噪痕，「天不亡我」的浮躁气息被他自己吞回去一口气。
- 若林恩在三台巨构达到极限的时刻直接把其中一台的运作功率反向抽到另两台，则两台过满变成三台中平饱和，特化封印整体效率从泥潭升到水面但仍低于峰值。
- 若林恩让艾泽法拉把蚀痕从船底上翘曲线引向西部银线的缓冲区，则银潮抵达场地的密度被切成几段都不是完整潮涌，「东方鱼肚白」比喻的失败写进以太自己的意识流。
- 若林恩以太扬身化万丈之时主动用三叉戟朝自己脚下的船板划一道拒界结锚，则船体不被巨人推离则在甲板上的整体防御等级升一格，但林恩本人的机动范围也减少一半。
