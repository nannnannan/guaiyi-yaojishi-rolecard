# E776·新世界的记忆·if线

- 若林恩在过去渡鸦的身体里选择先看远处而不是睁眼细查,则他能保持一份模糊的体面,但也会错过大君旧记忆中那些最锋利的细节。
- 若林恩让左左在记忆海表面不要同步下潜而是闭眼放哨,则她能充当他在数据洪流中的锚,但漏读的画面会由她口头转述一份过滤版本,失真风险 ↑。
- 若林恩把「渡鸦无心」这段旧事的每帧都让黑火烙标记以便日后查证,则他能建立可检索档案,但每枚烙印都会让他旧忆体多一层不舒服的灼感。
- 若林恩在「女主人带他们重归紫罗兰」那段画面里主动慢放三秒,则他能看见渡鸦集群首飞时大君的掌温,但温情加载时长会让他在现世多停留一秒的错频。
- 若林恩让左左在渡鸦集群机械化加剧那段主动记录图片而不是文字,则她能建立可比对的状态图谱,但左左的眼睛会对应每帧画面在她说不出来的位置感到酸痛。
- 若林恩在他自己作为渡鸦追杀真理之神的段落里刻意让自己看不完整结局,则他能省略那场最后通牒,但缺失会在后续给他一段空白,逼他在下一次再回来穷追到位。
- 若林恩把「那个人第一次笑」那一帧单独截出来存进系统空间,则他保留了一份能够让他未来沉默的钥匙,但这份沉默也会成为他在画作面前真正的弱点之一。
- 若林恩让黑火在查看「他的第一缕情绪是愤怒」段落时反向记录那股愤怒生成瞬间的温度,则他能建立与自己愤怒起源的对照表,但黑火会在数据落点处产生一次不顺手的回流。
- 若林恩在新世界初叶的画面上主动把左左拉近画面中央而不是只让她在背景,则他能让她共享那段历史的触感,但左左自己的渡鸦人格边界会被轻微推扰。
- 若林恩在大君潜意识消失那一帧选择追看紫罗兰旧部的反应而不是渡鸦集群,则他能提前理解狱卒集团立场,但渡鸦本身在那一刻的共感会从他的记忆里淡出。
- 若林恩让左左在看到人被处理成机制场景时在意识里替他叫一声,则他能用她声音压住自己,但左左那声叫会成为她后续无法解释的多余情绪。
- 若林恩把「他不是真理」三段记忆做成一张书签夹在他意识里的某本书上,则他能在下次动摇时翻到它,但印章本身会带出那份「说得多痛」的回音。
- 若林恩在信仰建立白热阶段选择直接跳过二十年再看结果,则他能节省共情损耗,但帝国那二十年里具体的伤害面孔将被他让渡给「时代」这个抽象词。
- 若林恩让左左在看到那对母女相拥画面时主动用左手叩一下自己胸口,则她能建立与那对母女的共感连接,但她的左手会永久记住那种近距离的揪心温度。
- 若林恩把渡鸦「流泪」这个属性记录为「渡鸦可以流泪」而不是「那只渡鸦发生异常」,则他能修正种族认知,但修正会让他在后续面对每一次渡鸦目光时多一丝无法描述的失重。
- 若林恩在反抗开始阶段主动把自己拉离现场几米再回看而不是站在原地,则他能获得更广全景,但几米距离也会被录进记忆里成为「他站在了多远的地方」的一个数字。
- 若林恩让黑火在感知到王庭镇压时主动停止记录,则他能跳过这段血腥,但那段被刻意丢掉的内容会在他日后再度变成需要翻找的断章。
- 若林恩把「他赢了」这一概念限缩在个体革命层面而不扩展到全面胜利,则他能更准确呈现那段历史,但林恩心底的希望火焰会因此更微弱。
- 若林恩让左左在僭越者排位前列的画面里同步轻声念出那人的名字,则名字与场面都会被更稳固保存,但左左对那个名字的熟悉度会超过她从未见过的他。
- 若林恩在见到画家进入画面时主动让自己的视线不落在她半面而是落在她脚下的土地,则他能跳过与她直视那一刻的冲击,但「他没看完她出现的那部分」会成为他后续难以准确复述她登场的记忆。
- 若林恩把大清洗机制的画面用慢放看完而不是用意识略过,则他能真正理解机制的冷酷,但慢放的痛感会让他在现世的主宇宙里多一段失神。
- 若林恩让左左在每次林恩看完一段后主动握一下他的手腕,则他能在每段之间保持心理温度,但左左会成为他在每段记忆中的必经站,没有她的时候会额外产生空。
- 若林恩把那位母亲的眼泪形成一个独立事件标签「哭过却没得救」,则他能把它从混合的记忆里分离出来单独追念,但这份单独存放会让那个标签在系统中显得形影孤单。
- 若林恩让黑火在紫罗兰七王怒火的画面上烧一道线,则他能意识到自己何时走过界,但那道线会成为他在后续处理与旧部关系时的心理界碑。
- 若林恩在渡鸦集群回归那段主动只看不参与,则他能保有距离感,但那段灵魂交融的画面会让他意识到自己作为一只渡鸦永远不可能完全融入。
- 若林恩让左左在他发现过去自己时主动拉开他手说「我们走」,则他能免于更深卷入,但那只会是左左而不是他自己做出的决定。
- 若林恩把「大哥」这个称呼翻译成「一份责任」而不是「一位应该回应的声音」,则他能解除情感义务,但那种翻译会带给他长久的隐痛。
- 若林恩让左左在他记忆最深处感受到了自己微弱存在的画面里主动插入她自己的视角,则她能帮助林恩完成自我确认,但左左的位置将成为他在那画面中唯一稳定的光。
