# E184·警戒线教学与腔室反伏击·if线

- 若林恩不在墙缝偷窥瞬间开枪崩眼、而是先以咒瞳记录其神经结构再示警，则摘除警报延后十秒，「歼灭模式」改由血肉人形远程手动宣告，腔室收缩定调为「围猎」而非「灭绝」。
- 若林恩开枪替换成假意放下猎魔左轮、把怀表竖在眼睛位置以示「成交继续」，则眼球群集体愣神两秒，首领谈判冲动被勾起，腔室先锁外不锁内，林恩获得一道先手撤离缝。
- 若林恩在「歼灭模式已触发」广播前主动把尹依塞进系统空间，则她被豁免此轮监控记录，但后续「警戒线教学」整段名场面不发生，师生磨合线整体后移。
- 若林恩让左左从手背拟化成第二支猎魔左轮加入弹幕，则双轮齐发把墙面眼球殖装撕成横贯裂纹，燕尾服虚无锁链得以空出全程斩切消化脏器，反击节奏比原作提前一轮完成。
- 若林恩直接以燕尾服锁链破墙撤离而非充能反击，则事件以变形（破壁撤离）收束，E185 快感冲击清场路径不成立，需另起等价突围叙事。
- 若林恩抱起寄生兽时顺手以咒瞳检查其神经接口而非塞入怀内，则他发现该批寄生兽已被远程写死自毁时钟，后续封存缴获环节整体失效。
- 若林恩当面挑衅时把「欲望母树直系子嗣」改口为「我干翻过你们两个老大」，则首领恐惧层级从「嫡系血脉」改写为「来头不明的重灾区」，「绝户判断」不变但腔室收缩速度再加一档。
- 若林恩让尹依自己接一发炎灼弹并示范警戒线原理，则她右臂灼伤见骨、警戒教学落点从「听」改为「亲身体验」，后续她对林恩的师生定位多出一条「他真的敢伤我」。
- 若林恩挨脓液腐蚀的瞬间把尹依也纳入燕尾服内衬同受，则两人并肩被蚀出焦痕，「带她再学一课」被改写成「让她也吃一刀」，尹依警戒阈值反向暴涨。
- 若左左主动从手背探出触手接下脓液腐蚀替林恩挡伤，则她首次实质分担燕尾服反伤，绑定参数 +1，但她整个反击期都留在意识空间干呕到虚脱。
- 若林恩在充能反击时主动压低以M输出功率、只针对神经网而非消化脏器，则反击只瓦解控制环，血肉墙壁依旧收缩，林恩需要在半失能状态下额外锁链斩壁，难度硬上一档。
- 若林恩做到一半放弃充能反击、改口谈判要「拿五百万换通行」，则首领短暂犹豫——但「绝户」定性已立，谈判只是拖延，腔室收缩继续、上级请示同步触发。
- 若尹依在监控注视下立刻撕裂灵表跪地求饶「我只是个见习」，则她被监控记录为「低价值伴随体」，警戒解除最低但潜伏烙印形成，林恩面子在腔室层面被刮去一层。
- 若林恩以夜医官衔名义宣告「例行检查」，则腔室警觉短暂拉低至「核实真伪」，但首领在能级报告对比下立刻撕破伪装，歼灭模式照常触发，只是延迟三轮。
- 若林恩提前以咒瞳扫过腔壁上所有监控眼球、趁歼灭广播前先一枪穿脑两颗关键节点，则监控远程断连，首领被迫进入「瞎指挥」状态，腔室收缩向量紊乱一线。
- 若林恩借脓液充能时主动朝那枚「谈判」眼球传递一句扭曲低语「我孩子饿」，则以M恶意外泄触发该眼球自检短路，消化腔短暂漏气，林恩获得一道低成本出气口。
- 若林恩在反击前主动摘下高脚帽向四周鞠一躬致意「献给各位的节目」，则以M受众被全面预告，神经网尚未起反应就已经有外围复制体体表紊乱，充能效率反向抬升。
- 若林恩把充能后的第一发反击对准腔室顶端而非神经深处，则顶盖崩出裂口，黑雾涌入形成天然排气阀，腔室收缩由「闷死」改写成「缺氧窒息」，林恩节奏得以缓一口气。
- 若林恩坚持全程护着尹依不让她看监控眼球也不让她出枪，则她彻底失去「第二课」教学机会，师生线在该事件上没有推进，事件以变形（教学未发生）收束。
- 若林恩当着血肉人形首领的面当着腔室把左左拟化成完整萝莉形态亮出来打招呼，则她首次在敌方监视下以人形露头，警惕等级 +1，但首领判断被打断一秒，能级报告多出一行「三名异形」。
- 若林恩主动让血肉灾变从指尖渗出与腔室消化液对接试探，则他短暂获得腔体表层视野，但血肉人形首领立刻识别出「深渊畸变信号」，警觉等级封顶。
- 若林恩在反击最后一击前主动留首领一口气以便逼供，则首领神经核心被神经冲击削穿后仍存活，E186 逼供门槛得以保留；否则首领当场失能致死，「五百万兑换点」线被斩断，需另走等价情报搜证。
