# E116·荒原漫步心智交锋与耍赖骑乘·if线

- 若林恩把「像一坨睡着了的屎」换成向艾雯心魔庄重致哀，则投影强度上浮、夜海推进加快，沙漏被压缩，但欲望母树会把他当成难得正经的同路人，态度出现一丝软化。
- 若林恩绕开艾雯心魔不当面评点，拉着母树走向另一片荒原，则心智交锋不被点燃，投影威压维持现状，但失去共同话题，舌战窗口关闭。
- 若林恩以巨像之心共鸣放慢步伐、给血雾描出地形供母树辨认，则空间戒备下降，她愿提前透露一丝生命树时代记忆碎片，等价把「共情杀招」部分情报前置交出，但暴露他窥探她过去的目的。
- 若林恩不开「树也能操吗」，改问「欲望本身会不会厌倦」，则她不会立刻僵直，对话直接进入核心思辨，双方都亮底牌，事件从耍宝互怼切换为冷峻哲学对赌。
- 若林恩在「树也能操吗」后立刻补刀「那您要不要试试用枝条」，则怒火冲顶，她放弃小板凳改用精神压制把他扔出数丈，挨揍层级上调为意识受创，事件时间被压缩。
- 若林恩顺着自己的「女孩们容易被攻略」话术直接拆穿「所以你还是在诱惑我」，则共情陷阱被正面戳穿，她不进记忆，但把他列入更高戒备，后续全程蛮力束缚，交谈几乎中断，心智交锋半路收束。
- 若林恩在她耳边说「我宁愿舍弃全部力量也要回家」时没有反制而是承认自己也有过同类念头，则会出现一段危险的真实共情，枝叶从猩红短暂退回本绿，但她会把他视作「知道最多秘密的人」，事件结束后处置偏向「收编或永久封锁」二选一。
- 若林恩在「扒开意识」威胁前主动敞开表层无害记忆给她看，则她会读出一段林恩刻意构造的「同路人」设定，态度短暂动摇，但巨像意识空间会把自我切割判定为权限滥用，叠加一层抑制。
- 若林恩真的放行让她进深层记忆，则她会看到左左、血衣、白银之手、疫医战争全部真相，陷入久久沉默，此路径把事件升级为「欲望母树主动临时结盟」变形，林恩失去玩笑与耍赖的缓冲层。
- 若林恩不脱靴耍赖而是陪她正常走完全程，则心智交锋拖长，沙漏需要更久归零，但投影爆发时位置更逼近艾雯心魔，E117带上双重压迫。
- 若林恩脱靴时不是耍赖而是脚真已走出血，则她会先高傲拒绝，再冷脸丢下藤条让他包扎，情感泪点成立：她不承认这次心软，但对他的敌意上限出现微小裂缝。
- 若林恩以巨像之心身份要求「背我，这是祭品的权利」而非撒娇，则她拒绝得更冷硬，扯着藤蔓把他拖走，事件切换为冷酷雇佣模板，物理束缚照旧，但没有骑乘或小板凳插曲。
- 若林恩骑上她背后规矩坐好不作乱，则三十分钟小板凳环节不发生，她仍全程低气压但少一层羞辱记忆，事件结束后态度比原作少一分真要杀他的决心。
- 若林恩骑上去后双手环上她的腰以接近拥抱的姿态依靠，则她数秒僵直后仍把他甩出去，但出手分寸下意识收敛，小板凳数量与力道都比原作低一档。
- 若林恩在被掀飞后偷偷往她背上拍下一枚欲望诱导剂，则她暴打过程中心律体温短暂失调，出现三秒成人向裸途错位；她反应过来后以更狠的力道把他砸进土里，但情感账簿记下「他敢碰她的本能」，调教路径打开一扇隐藏门。
- 若林恩在小板凳连打中不躲不闪反而认真点评力度与角度，则她半分钟内破防，从想杀他转为更像训他，深层投影爆发时位置偏向荒原中段，不再落在远方边界线上。
- 若林恩反过来张开双臂「那换我背你」，则她先愣住再彻底激怒一藤条抽下，事件变成「母树把林恩倒吊在身后拖行」，羞辱主体互换，深层投影爆发时机不受影响。
- 若林恩在藤蔓捆腕时主动要求缠在手臂内侧并护住结点，则他承担更明显的勒伤，但保留单手挣脱余地，等价把「安全距离+物理束缚」改为「合作式束缚」，E117被迫并行作战时反应更快。
- 若林恩在被牵牛式拉行中以咒瞳扫描荒原并逐句报告空间结构，则她意识到他把整段行走当成正式勘探，关系升级为冷峻「专业雇佣」，心智交锋被压进更少对白，报酬与情报互换上限抬高一档。
- 若林恩在沙漏最后一粒沙落下前主动点破「你的恐惧投影马上来了」，则她对他全面拔高警惕，事件仍收束于深层心魔降临，但爆发瞬间她先把目标锁定他，E117进入「母树先杀林恩再自心魔」双重危机。
- 若林恩提前以巨像之心权限反向压制投影多支撑一两分钟，则以自身意识负担换取套出她回家之路的一句真话，压制崩解后恐惧投影加倍降临，事件升级为「林恩承担一段反噬伤害」变形。
- 若林恩全程不脱靴、不骑乘、不点评心魔，维持疫医的冷面职业态度，则事件仍以深层恐惧投影爆发收尾，但她对他的人格评价彻底改写：列入「有资格谈判的对手」序列，雇佣、欲望引导与调教路径全部改写。
