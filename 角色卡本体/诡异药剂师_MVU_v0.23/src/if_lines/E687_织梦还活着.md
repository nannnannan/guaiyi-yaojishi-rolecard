# E687·织梦还活着·if线

- 若林恩先以空间法则封锁整层警报的发声管道再冲杀到织梦牢房，则监狱的警铃声会延后三十秒，但他在轰碎最后一道牢门时不再需要面对同时从三面包抄的魇群。
- 若林恩在清剿第一层守卫时把某位高阶魇的尸体完整保存一具拖挂在身后，则越往深处行走时，走廊里的其余魇会在半米外自动退开半步——他们第一次以尸首为律，打开了最深处的大门。
- 若林恩没立刻一拳轰开四层监狱之门，而是沿外墙爬上三层穹顶、从高位眺望后再找最薄弱点切入，则整层监狱的全貌会在五息内显形，他提前知道了织梦被关押的最深方向，但错过了龙卫澜亲手放下姊妹遗体的时机。
- 若林恩把那位龙卫女子的遗体小心裹上白布收进三叉戟世界，则不得以位阶为名的人不会再来搜刮遗体，但系统空间里的龙卫澜从此再不说话，她的愤怒将被压缩到下一次原地处爆发。
- 若林恩不顾周遭清剿、直接拆开织梦身上所有金属倒刺，则她的伤势会在灵能散开时变得更重，哀鸣中她的指尖会在林恩手背上抓出八道血线，但那具本就走向死亡的身躯比之前更剧烈地抽搐了一次——她还活着。
- 若林恩在紫罗兰纹章落入手心瞬间故意将自己的精血滴在纹章背面，则那具枯骨残留的意志会化作一缕极淡的光晕缠上纹章，他亲手把一段忠魂钉进了永恒，日后以M之力一旦触碰这纹章便会触发一场反向的誓约保护。
- 若林恩在织梦昏迷时先用一撮疫医止血膏涂抹她的心口裂口，则腐化不会像原先那样在他渡入灵能时剧烈反弹，她第一次不再因痛楚扭曲面容，睫毛会在他的额头温度下极轻地颤了三次。
- 若林恩把三枚触手分别刺入织梦双肩与后腰直接中和腐化，则她的痛苦会在三息内消退，但他双手虎口、肘窝与胯骨内侧的三处将被烧穿三个深孔，他必须缄口不提此伤直到自己恢复初诞者之力。
- 若林恩没让真理残魂的手指再靠近织梦眉心，而是亲手把圣水抹在她额头缝合裂口，则她会短暂苏醒一瞬，用嘶哑至极的声音叫出他的名字——然后再次昏死，那一瞬间足够她半伸出的一根手指，在林恩手背上虚虚按了一下。
- 若林恩在抱起织梦前先将两手放在自己颈侧让极光体覆盖全身，则腐化不会顺着他的手臂二度传导，但他怀中的人会先感受到一寸极寒，寒到她的唇色恢复了三分。
- 若林恩在清剿整层时没去拽那些已经悬在锁链上的狱卒遗体，则他们会在他离开后无声自燃，千百具死者在不惊动任何人的情况下化作飞灰，而他日后站在第四层最深处的梦魇群里，会第一次不被认出。
- 若林恩顺手在这座监狱最深处画下一个极小的定位阵，则在第五层、第六层的所有追兵后来围着整座行宫搜索时，他们无法准确念出这座监狱的最深囚室，织梦所在的那一格从此在魇王的地图上消失。
- 若林恩在背起织梦前先用一根疫医处理过的布条把她两眼蒙上，则她醒来时不会被外界突然涌入的光刺激到，林恩第一次见到她的目光时也不会看到那双眼睛——而是先看到她干裂嘴角那半抹几乎不存在、却还努力上扬的微小弧度。
- 若林恩没把转身交给真理残魂、而是强行让他与自己同行的同时让织梦挂在自己背后，则三叉戟世界不会替他承担腐化，他必须在抱起她就走的同时用一半的初诞者之力维持她的生命体征，余下力量只够一次主动出手。
- 若林恩在事后给龙卫澜留出十里之外的一座幻象囚室让她与姊妹的遗容安静道别，则她会用一整天时间守着那道遗容，然后在太阳第二十七次沉入虚空时走过来，轻轻把手放在林恩肩头：「下一个……该轮到她了。」
