# E07·血衣寻子与鬼婴萌化化解·if线

- 若林恩在触手探入瞬间抱娃后撤摆出药剂阵，则危机度拉满进入战斗硬解，伤亡按实战发挥结算。
- 若林恩把萌娃藏在身后只用言语拖延，则触手绕过他直取柜台，隐匿无效被迫当场交代。
- 若林恩不演讲、只把孩子高举充当唯一筹码，则话术加成清空，血衣态度全由鬼婴本能萌化支撑。
- 若林恩愣神间隙改口"我可长期为她调药恢复气息"，则以医师身份换缓冲，血衣留下孩子登记为长期病号。
- 若林恩追加医疗类药剂缓场并提出盟约，则成年恶灵被药物与本能撕开裂缝，可演化为以医换命的临时解咒途径按住杀意。
- 若林恩摆利害"您吃了我孩子就再没人能把她变回来"，则以医师不可替代性强挂钩换她压下食欲。
- 若林恩反问"您要的是女儿还是能下口的怨念容器"，则情感硬顶，血衣反应由残存人性与自尊衡量支撑。
- 若林恩主动提做她专属药剂师定期复诊，则寻子线改造为长期治疗契约，与一次性化解等价但延展更深。
- 若林恩要孩子留下只让血衣随时探望，则触发监护权僵持，进入与恶灵妈妈背道而驰的背离路线。
- 若林恩要血衣搬来本街接受复诊作为交接条件，则44号灯依旧亮起但性质转为被监视的长期病号。
- 若林恩抱娃从后门逃店，则追逐分支启动，药剂店短期失守，游魂巷口扩散新一轮传说。
- 若林恩演讲失败血衣再度发难时以身体挡在孩子前面承受一击，则以人类脆弱直撞她残存人性，可能扭转也可能当场殒命。
- 若林恩目送她离开不作追加，则与原作"路上小心"等价但更冷，44号血灯是否亮起由局势判定。
- 若林恩接住"再大晚上潜进来吃了你"的威胁反顶"那我每晚备好药等您"，则威胁转成暧昧约定，夜访线翻为猎奇调情。
- 若林恩递上现场配制的稳魂安气药剂作见面礼，则开启药剂师-病号家属双重身份，血衣杀意下降一档。
- 若林恩在她颤抖鼓掌时追加对红裙与夜百合的具体恭维，则舞台感更浓，可能再拉好感也可能因显油腻扣分。
- 若林恩关闭感染性气场纯以话术应对，则无被动加持的纯交涉版本，结局由她当下心态与已有信息支撑。
- 若林恩在她抱走孩子后立刻在柜台血痕处取样分析，则开启血系药剂与血衣相关炼金支线。
- 若林恩放任她抱走孩子且不设任何复诊/邻居/契约约定，则达成最低完成线，母子重逢血衣退场后续温度任其自演。
- 若林恩让在场常驻角色插手劝架，则多方介入分支启动，危机度按全员站位与血衣当下焦点结算。
