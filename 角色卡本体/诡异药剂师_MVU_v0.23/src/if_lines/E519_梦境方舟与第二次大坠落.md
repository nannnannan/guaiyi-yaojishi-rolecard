# E519·梦境方舟与第二次大坠落·if线

- 若林恩在释初诞者之力前先私下分配一缕给左左傍身，则左左在大坠落期间有一缕护体，但主力输出少一分，拖神规模略减。
- 若林恩选择不集中释力而是分散到多个时间节点，则当下坠落者减少，但未来可能有零星第二波，机制账本不同。
- 若林恩在北方天空之城法阵启动时让自己的面具充当增幅器，则法阵功率+一成，但面具承受意外压力损耗。
- 若林恩在看到战争之王·努斯第一斧投出时主动以心声助威，则努斯被拖入前最后听到一缕回声，心中仇恨值略减。
- 若林恩选择在铸造者／核子之神被拖入瞬间同步喊一句「联盟记得你」，则铸造者绝望长啸中多一缕被记住的慰藉，降临地狱后投靠意愿上升。
- 若林恩在元素之神目睹母星陷落时选择让她看完再拖，则她带完整怨恨入地狱，后续拉拢难度+，但她对家园的记忆完整保留。
- 若林恩在「足够了」之前先一次性拖完剩余三神再停，则坠落者名单扩大到更多，地狱第二次收割规模更甚。
- 若林恩选择不休息反而继续输出，则他在释力窗口后期过度消耗，回城时虚弱数日，「开始吧」状态拖长但身体付出代价。
- 若林恩在询问引灾厄是否计划时换成「你本来就要吃它」，则奈奈子回答可能从「渗透加深」变成「我本来就饿了」，对话气质根本改变。
- 若林恩在大坠落过程中突然心生一念回头去看望小小／泰坦，则他错过看主宇宙坠落全景的窗口，但多一笔小人物视角的当时记载。
- 若林恩选择不问「面对的是何时的你」，则奈奈子在消失前不给「当世的我」答案，他失去确认她这一世身份的关键句。
- 若林恩决定不回船而是在意识域继续追问奈奈子更多，则他可能多问出三两条情报，但错过康斯坦丁船舱时间静止的窗口，回归难度上升。
- 若林恩在「开始吧」释力窗口喊出的不是「开始吧」而是「让我们开始」，则奈奈子在 procedural 上多一拍，抵达漩涡兑现的时间点稍延后。
- 若林恩选择在大坠落中主动标记某几位神灵优先被拖，则后续地狱的权力格局被他的意志影响，盟友名单由林恩参与塑造。
- 若林恩在拖神行进中看到熟悉名字时主动放过一两位，则那几位神灵留在主宇宙灰飞烟灭，Karma账双面。
- 若林恩决定在「我不在意」对谈时反驳奈奈子「你应该在意」，则她可能愣一拍但不改变行为，林恩心里多一道「她其实在意」的预设。
- 若林恩在地狱侧坠落者如雨坠下时选择闭眼不看，则他不被仇恨与痛苦淹没，但失去「守护主宇宙延续」的重量感，E520 时间战争动机减弱。
- 若林恩在奈奈子「这就是我们的不同」出口时反讽「你的监护像极了冷漠」，则她可能回一记冷眸，关系从「合作」向「对峙」偏移。
- 若林恩选择在漩涡兑现前直接用三叉戟切断某条锁链救一位神，则锁链断裂，那一位神被卷入无序深空而非坠落，命运改写。
- 若林恩决定不让左左看到大坠落而是将她先安置在安全处，则左左对地狱格局破没有第一手感性记忆，E520 的问剑术场景少一分沉重。
- 若林恩在「当世的我」回答落地后立刻追进，则他可能在未来某个时刻重新遇到「未来的奈奈子」，得到另一条情报线。
- 若林恩选择在回归船舱时故意呛一口血让船长担心，则船长的「大军压境」叙事多一份共情，后续合作的凝聚力上升。
- 若林恩在事件尾声主动落在主母／艾雯／银幻三人中间而不是单独站立，则甲板画面从「独对苍天」变成「四人并立」，归心合照意义不同。
- 若林恩决定在「当世无序化」瞬间试图伸手拉住奈奈子，则他可能被卷入无序化波动，承受一段意识混乱，留下「曾触碰画家」的烙印。
- 若林恩在回归现实中先写一封信留给未来的自己说明今天所见，则未来某个时刻这封信作为伏笔被翻出，叙事链延展。
- 若林恩选择不观看努斯／铸造者／元素之神被拖而是专注于奈奈子对话，则他对大坠落惨状的感性认知减弱，后续劝服盟友时少一分直观弹药。
- 若林恩在「没多余的初诞者之力」证词落地时反问「那我的力量能否分你」，则奈奈子可能拒绝或考虑，借力窗口的边界重新谈判。
- 若林恩决定让巨像之王／巨像之脑也参与观测坠落者坠落，则巨像后来苏醒时多一段「我看到他们掉下来」的共同记忆。
- 若林恩在事件结束时不回房而是直接走向黑夜城某处高地凝视，则他错过艾雯灵能通讯「醒了？会议厅等你」，E520 会议节奏改写。
- 若林恩选择把这一幕的影像用灵能印在某个玻璃珠上，则他获得一枚可以随时回放的证据珠，未来对他人说服时有实证支援。
