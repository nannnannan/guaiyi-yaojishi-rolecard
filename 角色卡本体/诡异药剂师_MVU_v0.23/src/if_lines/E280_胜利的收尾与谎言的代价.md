# E280·胜利的收尾与谎言的代价·if线

- 若林恩当场接受血衣的吻别而非伸手推开,则左左指尖猛地插进他左肩血肉,她「小姑娘不要看」的音量炸分,但系统好感度盘中左左侧的数值首次没动。
- 若林恩把左左拟化成娇小萝莉时顺带到她额前轻吻一记,则她指节没拍开他,反而当场跳起来抱住他不撒手,「本手要暂停仇恨了」成为她的迟来告白标记。
- 若林恩答应血衣支托托奸女儿的所有请求,则血衣离去前那步「大步上前吻住他的嘴唇」被他一动不动地接下来,左左没跳脚,但林恩四海之内多一道血衣烙印。
- 若林恩拒绝让左左跑腿拿死星结晶,改把趴她去给血衣女儿送夜医牛皮纸袋,则左左走了但事前来句「我不要被埋在你旁边」,林恩她问出一句恶的没答。
- 若林恩把托血衣女儿安顿的救世主形象从「从林恩接待」换成「托付给白逸加整队看护」,则血衣受用得当场拍他肩膀,但左左吵着「她也不会回来」。
- 若林恩不带左左去魔都,转让她带王麟去孤儿院,则少年有一对金色狐眼终于等来了爹闭嘴的平安符,王麟一生长谈里多一段「某个不是黄大人的女孩带我去看了蓝天」。
- 若林恩在左左抓挠时反手把她搂进怀里用上层视线瞪着她,则她首次被在晴空下放倒但反抗某场,系统强制弹出【左左脸红到送命】,E281 她出发时间推迟一周。
- 若林恩不让她飞走而是跟血衣一起留下半月,则左右够了比如「我要留着修折跃引擎」的不正当蜂拥,血衣告别时首次发现他没站在屋檐下被吸走空气。
- 若林恩答应让血衣把女儿留给她自己,则血衣拒绝时把手里的东西塞进他怀里,来自左手的安慰成就没触发,他今后在血衣心里的形象向纯棉软硕倾斜。
- 若林恩把「我一定会去接到你」换成手刻小字条藏在血衣女儿领口内侧,则血衣走时兜里多一张没刻意密封的纸薄信,她出界门时首次忍住没回头。
- 若林恩把血衣大名告诉左左,则左左首次喊血衣「外面的姐」,血衣杀气骤降数据,黑夜城登门时首次把她这把正步补上「请多指教」。
- 若林恩特意等左左飞远了才允许血衣转头向他吐一口气,则血衣那一个小时都没走,林恩在黑线消失的几秒里首次感到自己右侧肩膀空了一块。
- 若林恩决定当场把谎言刺破并向血衣坦白,则血衣转身不叫走,首次以「队员」身份蹲在原地看他发呆,后续星空调查之门首次在她的言身下被无偿提前拉开。
- 若林恩当场向血衣坦白随后又问「你敢不敢欠我一次」，则血衣首次暴走踹飞他三米,怒别氛围中事情转向「她欠他一笔不需要偿还的债」的未知档案。
- 若林恩施放随时监看泰坦的通信灵磁,改在一百天内只在凌晨让它发光两到三次,则林恩此后每次抬头都会怀疑自己是不是在看不见的地方散步,泰坦禁区多一段「其画像深夜曾闪现」的隔空记号。
- 若林恩把那阵子星光广播一直播到事件尾声,则左左走的八天中黑暗世界什么事都没发生,八天后他收到一封来自机构的结案报告,相接的只有「两人再度重逢」的冷淡结尾。
