# E611·修炼狂潮与根源反噬·if线

- 若林恩在宴会名单上加一笔「伊甸娜与血枢旧识名分」,则她主动放弃接风敬酒改以静默侧座,千年前见林恩的台词换成「这次我不会再抬错杯子」。
- 若林恩特意为艾泽法拉安排与伊甸娜单独对面的桌位,则那一声「姐……姐姐」的拖延会更久,伊甸娜当众替她擦眼泪,姐妹排位在宴桌上正式坐实。
- 若林恩不忍母树当众起舞的时间过长,私下递上「克制一点」的眼色,则她只跳半支便翩然落座,生机洒满的场景压缩,但唇边「谢谢」的私语溢出更轻的颤音。
- 若林恩在母树深吻瞬间主动侧脸让开唇齿之印,则吻会落在下颌与耳畔,「谢谢」二字不变,但自缚天使与艾泽法拉的怒视改为错愕。
- 若林恩在宴桌上直接为弑利叶与自缚天使主持和谈,则两人不喝酒而以茶代酒互相敬长辈礼,「过去的就让他过去」台词改由她说给自缚天使听。
- 若林恩让军团长老携家属入席共同见证,则羽林军迟疑的表情被家属看到的目光压下,落座更早,自缚天使的拥抱也更短促。
- 若林恩主动为老大精灵王斟茶送行而不饮酒,则他改走暗影之路的告白推迟到宴后的私下会谈,星轨的出现只在私下场景落地。
- 若林恩借家宴公开为新晋半神人偶家致辞,则人偶家起身回敬时流泪,宴会焦点短暂从亲情转向标尺,军团潮涌随之提速。
- 若林恩为避开母女冲突让星轨那一晚不入席,则她与父亲的对面一瞬延后至次日凌晨,彼此目光再未对接,护道誓言依然成立。
- 若林恩把宴上表演禁令用玩笑缓和而非严令喝止,则母树的蛊惑会再多撑一轮,被欲望母树当众点名后才不甘地坐回席位。
- 若林恩在宴后仍关闭时间小屋调用以让众人休息,则冲击失败的地狱古老根源便不再在本事件暴走,护法严令的代价转嫁至下一个加班夜。
- 若林恩选择在冲阶失败前夜与那位古老根源单独约谈,则他冲击时会带上林恩的点拨,失败时林恩可在更早期介入保住部分灵魂,但民初仍折损。
- 若林恩允许艾泽法拉代替自己第一时间镇压失败的根源,则她会果断出手保存灵魂但错过动脉微创,护法严令措辞会多一句「不可代替主帅护法」。
- 若林恩把护法严令写成族规刻上黑夜城,则更早抬上桌面,艾雯的「法则焰铸失败」首次在族规生效前被记录,压力线转移一半至他头上。
- 若林恩当众认下老大精灵王的跪祉并亲扶他起立,则护道誓言在公开场合烙下,星轨在门口的多疑加速,冲突爆发点提前。
- 若林恩让母树继续在那晚发挥自己的蛊惑手段返还各军团,则宴会气氛会更高涨但护法严令公布后反差更大,失败案例的痛苦更刺骨。
- 若林恩拒绝帮助冲阶失败的古老根源镇压暴动法则,而改为旁观记录,则根源彻底湮灭,护法严令更冷,巨像的警惕更深,但所有人记忆里的代价更重。
- 若林恩决定允许洲狱成为人们冲击半神的门径,则失败案例会从深渊尾随一段,巨像的半神执念转化为本能的逃避,冲阶失利案例在深夜被推向她。
- 若林恩亲自带母树前往宴后巡视冲阶失败者的遗体,则她起舞谢意的诚意加深,但在下一场菜单上会提前提出「不可急于求半神」的慰留话。
- 若林恩为巨像安排频繁的冲半神计时提醒,则她在四十个月的僻修结束后会向林恩申请跨越时间小屋外冲阶,巨像的执念被推向更极琉下的形式。
- 若林恩让艾雯从宴桌重头戏中下场另攸后勤调度,则他与护法严令的遵途被划分,之后巨像失败时能第一时间赶到废墟。
- 若林恩安排母树当众起舞但不严肃告饶,则她会误以为谢意已被接受,深吻持续更久,让自缚天使与艾泽法拉更添一股苦决。
- 若林恩提前通报羽林军「一切尽护之下惊喜下北」的护法严令样式,则军团会默认坚持后勤责任,但作为成本,失败的根源依然本会暴走,代价之外多了一层世界观以来循环往复另一层环铸。
- 若林恩把巨像的上方护法严令下转为不再冲半神的区,则她从本源中另我之前,但原路冲阶的记忆仍在深处尘泥中。
- 若林恩在宴后主权客人房中陈述护法严令形象,则严令以「林恩族规」性质生效,但同样会让巨像与艾雯暗中设漫诺另辟一路。
