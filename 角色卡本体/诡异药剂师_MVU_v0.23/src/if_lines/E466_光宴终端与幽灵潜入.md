# E466·光宴终端与幽灵潜入·if线

- 若林恩在穿上渡鸦甲胄那一秒主动让面具内壁贴上他自己血气一缕，则甲胄在风暴中收紧半度，他被识别为「小型异物」的概率下降三成。
- 若林恩在钻壁垒静默缝时主动让左萝先在他意识里演示一遍钻法，则她的小手在他视角里画出一个完美的弧线，绑定值 +1。
- 若林恩在蜂巢数据世界中主动让左萝替他记一个数据节点的坐标，则她的小手在他意识里标出一枚亮点，绑定值 +1。
- 若林恩在与光宴脸终端少女擦肩时主动把自己呼吸压停三秒，则她背后的管线没有出现异常的共振。
- 若林恩在数字林恩掐喉时主动让手上的力道收至七分，则少女瞳孔急缩，但她没在第一时间触发警报。
- 若林恩在少女自称「我也是七神之一」时主动回应一个冷淡点头，则她的炽金双瞳在那一秒收紧，绑定值稳。
- 若林恩在被她问「你是来救我的吗」时主动拒绝先答，则她的数据流在那一刻反转向他敞开了三成。
- 若林恩在掠过光宴脸的瞬间主动让左萝在意识里把她画一遍，则她在事后把那张脸刻成「最可爱的姐姐」草稿，绑定值 +2。
- 若林恩在感应到「其他的我」时主动用自己的意志把那道感应按回，则「其他的我」的察觉窗口被推迟了约两分钟。
- 若林恩在离开蜂巢数据世界时主动在王戟的刃面上留一道未名的刻痕，则后续他在战区多次重新潜入时能借这道痕迹定位同一台终端。
