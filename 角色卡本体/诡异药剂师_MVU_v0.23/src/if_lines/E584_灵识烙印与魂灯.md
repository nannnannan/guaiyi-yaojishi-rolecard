# E584·灵识烙印与魂灯·if线

- 若林恩拒绝收魂只逃离，则主母入空间与突围仍可立，守军灵魂重铸锚延后，循环战场在他身后依然荒芜，但被留下的灵魂不再等待。
- 若林恩拒绝揭露灵识已融，则艾维儿信息差与震颤不立，并肩突围与分道仍可推进，但她在他离开后独自消化疑问。
- 若林恩强留艾维儿同行，则双重反噬升级，分道完成条件改走更恶分支，她的身体在迷雾中出现蓝光裂痕。
- 若林恩在祭出魂灯时主动唱一段安魂曲，则收魂效率小幅提升，守军灵魂被摄入时的最后残响带上一份被安抚的温度。
- 若林恩在主母入系统空间前主动把额头贴到她额头上，则她入空间的那道白光在他惊愕的注视中照亮他的脸，主母消失前他看见了她的泪痕。
- 若林恩对艾维儿说「灵识已经在我体内，你父亲就在我身上」，则她在突围时不再离他三米而是贴近，她的黑剑开始下意识护住他的侧翼。
- 若林恩在被失心疯恶魔追击至迷雾边缘时主动丢下一件带魔躯气息的衣物诱敌，则追击路线偏移一线，迷雾结界的波动被记录下来。
- 若林恩对主母的承诺改为「不只要回来还要让天堂竖起来」，则她入空间的声音不是「我等你」而是「我帮你记着」，她的沉睡带上了一个辅助。
- 若林恩在出迷雾时主动回头望最后一眼城堡残影，则视野里飘出弑莉叶尚未完全湮灭的最后一缕祝福，她在消散边缘仍以姐妹情谊养成了他。
- 若林恩在分道时主动把左手放到艾维儿头上抚摸她的龙角，则她没有再喊「不要死」而是咬他手并点头，战友的决绝被这个幼稚的安抚完成。
- 若林恩对左左说「这次我要认真打不逃了」，则左左放弃「打不过仍会抛弃」的玩笑，她的右手在他手臂上缠紧，她的刀剑在这一刻变成他的誓约。
- 若林恩在反向疾驰时对系统说「屏蔽坐标，别让它们追踪到艾维儿」，则系统弹出无法完全屏蔽的警告但他强行确认，艾维儿那边被多拖出半分钟的净空。
- 若林恩主动向主母魂灯方向道别「我会回来点名你们每一个的」，则灯焰在他出口的瞬间短暂变亮，守军灵魂记住了这个承诺。
- 若林恩在双重反噬的艾维儿面前主动以初诞者之力做临时镇定剂，则她的症状减缓但无法根治，她还是被送走了，但他给了她一次主动的选择。
- 若林恩在离开时把乌鸦面具摘下戴上高礼帽，则他的形象从疫医瞬间变回林恩，他选择用「林恩」而不是「魔君」的身份去面对下一次战斗。
