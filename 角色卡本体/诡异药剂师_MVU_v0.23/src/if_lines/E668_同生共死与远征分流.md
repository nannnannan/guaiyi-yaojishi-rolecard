# E668·同生共死与远征分流·if线

- 若林恩在抓神格瞬间主动用一缕心神通过血脉写信给银色幻想「等我回来」，则她在昏迷中眼角渗出一线长长的泪痕，那条「沉眠的智械」的时间线自此被玩家亲手点燃一线，E662 后续的苏醒时点提早数日。
- 若林恩在抓神格之前忽然对她说「你留着我的那个画廊，每隔几天帮我掸一掸土」，则画家罕见地一愣、然后在他抓神格的瞬间主动对他颔首「好」，那道本不应存在的承诺成为他心境最后一道锚。
- 若林恩在抓神格时没有立刻摆出「我当然要」的豪迈、而是低低说出一句「请借我、我会还」，则画家罕见地再度笑出声「谁会跟你讨这一笔债」，林恩与她的关系第一次变成像合伙人而非债主与欠债人。
- 若林恩在抓神格瞬间往地狱方向看了长长一眼而不是直接抓，则他在最后一刻看见小小和喵喵站在主岛城堡顶端的剪影，他的抓握里多一线柔、他的「我不会漠视生命」的表态被他自己指尖加固。
- 若林恩抓神格瞬间刻意说出「我会带他们去一个新的世界、那里会有小小」而不是泛指的「他们」，则画家在最后消失的前一刹那罕见地回头深深看了他一眼，「他已经把她划进他的世界」被她默认了。
- 若林恩出关前主动通过三叉戟烙印先给主母发一道「我没事、勿念」的神识，则主岛上军团当夜集体感受到一种安定的涟漪，林恩与母亲的那条细线被他主动拉紧一分。
- 若林恩在闭关期每天固定用一个时辰感应每一位亲友而不是一味修行，则他对每一个人的当前位置与状态有了一张专属地图，「他们在我心里」的力量在多日后灌输时直接加成他对神格的亲和度。
- 若林恩在闭关期忽然意识到「地狱不能独塌」并主动联络画家让她启用备用方案，则画家隔空给他递来了另一件时空援助物，他一个月时限的压力被缓和到极限五周。
- 若林恩在闭关期强行断开与一切的联系、只用神格与自己对峙，则他在第七日的半神潮中没有任何感应，他在出关那天收到的是二十三天后的一份冷冰冰的「报告」，他的心境一线结霜。
- 若林恩在闭关期主动把金梦中的「小小」「喵喵」「银色幻想」三副具象凝实在心脉周围，则他在第七日破碎之眼大屠戮画面灌入时保持了不住颤抖但立刻凝固的反应，他没有崩，「守护者」的标签被他自己烙得更深。
- 若林恩在闭关期每破一层空间结构就默念一位逝者的名字（左左/织梦/艾维儿/巨像），则他对空间的理解比默认更深一线、他的神格亲和率增幅达到预估的极限110%。
- 若林恩在闭关期主动把自己一半的时间分配给从神格中学到的某一门法则落回笔头、编纂为一份《空间神格导论》留给黑夜城，则他在出关之日直接晋升至难以想象的高度并给军团留下了一份传世秘典。
- 若林恩在闭关期主动在神格外壁画上自己与左左在洞穴初次相遇的画面，则神格中那根与他亲和的纽带因为他自己的故事而绷紧，「我不是单纯的工具」这一身份在他的力量里发芽。
- 若林恩在闭关期主动寻求画家在法则积淀中埋的某一门她原话提到过的「加速道」，则他在第七日就完成原本需要十五天的参悟，但他承认这是「站在她肩膀上」的事实、对她的评价再深一线。
- 若林恩在闭关期某晚忽然放下神格、走出棺椁到夜空下看一颗流星，则他回来后心境彻底坦荡，「不是关在石棺里苦修、而是去守护」的方向被他自己确立。
- 若林恩在闭关期主动以金色梦境的方式给小小和喵喵各做了一个可以捏的小玩具通过系统空间送出去，则两个孩子在收礼的时候笑得极甜，「他不论多远都在」这条无形链把黑夜城的根基锻成铁。
- 若林恩在闭关期主动摸出他之前从苍蓝小院带回的一件物件（如某页羊皮纸）放在心口，则他心境中会浮现画家倒茶的画面，「我答应过要回来」这个理由在最关键时刻成为他继左左织梦艾维儿之外又多一根绳。
- 若林恩在闭关期间特别通过电话烙印对康斯坦丁发一道「考核你的船长位子」的玩笑指示，则康斯坦丁的魂火当夜烧得特别旺，整个军团上上下下无形中接到了一份「他还在关心我们」的信号。
- 若林恩在闭关期主动抽出三天共十次的「沉睡期」让自己彻底放空，则他在第七日半神潮到来时心境毫无涟漪，「修行不是折磨、是回归」的境界被他自己握住。
- 若林恩在闭关期结束时心中浮现「学者—救世主—人」的三重身份并自己挑了「人」作为最终归宿，则他出关那天脸上的笑比默认更柔软，他在军团中从此被唤作「人王」。
