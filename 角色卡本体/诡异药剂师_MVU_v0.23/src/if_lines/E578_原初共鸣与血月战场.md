# E578·原初共鸣与血月战场·if线

- 若林恩拒绝二次冲月并阻止艾维儿，则破障不立，事件不得写成已入战场；折返验证仍立，但血月后真相被无限期封印。
- 若林恩破障后拒绝援城只外围观察，则王女确认与尸骸战场仍可立，艾维儿被呼「王女殿下」的确认在远处完成，支援线改写为远距离观测。
- 若林恩在艾维儿第一次无序黑炎后立刻喝停「共鸣不够，省着点」，则三次黑炎的间隔被拉长，原初共鸣的校正窗口出现频率变化。
- 若林恩在破障瞬间主动把三叉戟而非初诞者之力顶在最前，则金焰与黑甲交融改成圣蓝与漆黑，穿透阻力的震荡差异让三人反噬程度重排。
- 若林恩在感受反噬时主动扶住自缚天使肩膀让她靠着自己，则主母金色神血染到他袖口，她在恢复说「死不了」前先低声道谢。
- 若林恩在望见王庭尸骸时对系统说「这数量太离谱，全部战力的集合体也不够」，则系统印证他的疑窦，但无法给出任何关于时间循环的额外数据。
- 若林恩沟通外界时同时试系统商店订购一份外卖，则订单无法下达，系统面板提示「该位面不存在配送路径」，他确认坐标封死的另外一条实证。
- 若林恩在艾维儿秒杀骸骨和血肉双巨龙后主动让她停手先观敌阵，则城门缺口处的守军压力陡增，王女降临的士气峰值被推后。
- 若林恩在守军单膝跪地时主动「王女殿下别杀我是友军」式自嘲，则守军天使凝重里出现首次被逗乐的瞬间，但艾维儿用尾巴扫他一下打断不合时宜。
- 若林恩在艾维儿长啸黑炎时同步释放初诞者之力作第二波过载，则半个前线焦黑化加倍，但他与艾维儿同时进入短暂过载倦怠。
- 若林恩在系统空间可开后立刻把主母先塞进去，则自缚天使拒绝「我在战你的战」，并肩战的信任线提前拉满，但林恩失去一手安全牌。
- 若林恩在战场上空把左左从自己怀里递给艾维儿让她抱着飞，则左左在蓝龙背上尖叫，王女殿下的光芒被左左的喜剧尖叫混色。
- 若林恩主动对战死尸骸群鞠躬致意，则艾维儿在俯冲时体感诧异但仍照做，主母在落地前亲眼目睹，她的恨意与哀悼在一瞬间被同步放大。
- 若林恩在被守军呼喊王女时主动纠正「我是林恩，你们的王女是我朋友」，则守军的敬畏并不减少，他们眼中的林恩被标为「王女的召唤者」。
- 若林恩在冲入战场前对主母说「你来压阵，我开路」，则两人的战法分划从默认父女协同改成战友分工，她的金色血不再仅仅因反噬而流。
