# E685·又一个真理神王·if线

- 若林恩未现身而在原处等那十分钟自然耗尽，则真理残魂会起身、亲手把三位最先回来的助手先行杀死后坐回原位，林恩的隐匿能延续到下一班换岗，但他会错过「入梦者」这条信息的当场出口。
- 若林恩现身后先把一枚疫医镇静剂悄悄抹在自己颈侧才与金色身影对话，则对方半透明的灵体波动第二次靠近他时会被硬生生压回，真理残魂的「无神格」自述在灵觉层面被反向佐证一次。
- 若林恩没接过那枚金光晶魄的真理契约碎片，而是反问「你拿什么证明你最古老的秩序不是无序」，则真理残魂会把碎片收回、换成一柄由他自己肋骨磨成的金色小刀递出，契约依旧成立但约束力从律令改为血肉。
- 若林恩当场撕开一道空间口把同伴从三叉戟世界里请出来作陪，则真理残魂在看到龙卫澜的同一瞬间瞳孔会极快地凝一下——他记得这张脸，千年前的王下第三军团，他凝视的方向第一次变得不那么镇定。
- 若林恩为真理残魂制造假象时把假象做成一个抱着书卷的站姿而不是端坐，则归来的助手们会在进门的第三秒就识破，因为那位从未在他们面前站立阅读过；陷阱的启动提前，十几枚神格落入林恩手中但对面大门立刻封锁。
- 若林恩在助手们被金色锁链禁锢时主动伸手扯断最末尾一位工匠之神的锁链，则那位神灵会木然地站起身，向林恩深深鞠了一躬——这一躬里有压抑了数千年的求生欲——然后转身，用他自己的方式打开了通往更深处的隐秘通路。
- 若林恩在真理残魂提及「织梦还活着」的瞬间没稳住手、让一撮流沙从指缝间漏下，则金粒落地即化为一线细细的白烬，他第一次在「入梦者」这个名字前确认，她真的在他所能及的范围内。
- 若林恩追问「入梦者被法则审讯失败是不是因为她根本不是这个世界的存在」，则真理残魂会点头，并用一句几乎听不见的音量告诉他：她也问过他，要不要和她一起离开这里，当时他说「在这里只有一种真理」。
- 若林恩在银色太阳开口警告之前先对真理残魂说「你旧身那场死我至今不道歉」，则对方合上手掌间金色书页的动作会停顿一拍，千百年的两种神情在他脸上一闪而过，但他没有动怒，只是把食指竖在唇边：「到第三层再谈。」
- 若林恩在与真理残魂走向第三层甬道时主动让左左从神识上探出半只爪子轻叩那道结界，则结界另一端一声极轻极轻的断裂音先发出来，真理残魂脸色一变，带着他偏离原定路线数十步才重新踏入——他们绕过了魇王布下的第一道杀阵。
- 若林恩把那十几枚腐化智者神灵的神格中的一枚悄然抹上一缕自己的初诞者之力，则那枚神格会短暂地亮起一瞬的纯金色，随即恢复暗红，但它从此不再受魇王指令驱动，一具失去了「监听」功能的眼睛落进林恩掌中。
- 若林恩在甬道尽头与真理残魂各退一步分头走，则第四层监狱的火炬在他这一侧先熄一半，真理残魂那一侧全熄——林恩先抵，但门口一队黑骑已被提前调动，他必须在没有带路人的情况下自行清剿。
- 若林恩当场把契约碎片按在自己的三叉戟戟柄上作烙印而不是收入系统空间，则真理律令与戟身融合一瞬，他的罪火第一次染上一缕极淡的金纹；但当他日后以三叉戟对真理残魂出手时，戟柄会突然迸出一道反向攻击——契约与背叛同时具现。
- 若林恩在真理残魂说「这些书籍是我这几千年的陪伴」时伸手抽出一卷翻开，则扉页右下角有一个极小的、用旧式中文连笔写的「致艾维儿」，真理残魂不会主动解释，只是把书轻轻抽回，那一页从此烙进林恩的记忆。
- 若林恩没立刻动手杀那些归来的助手，而是用一缕黑雾裹住自己贴上墙壁，则在金色锁链闪现的瞬间他能看清锁链的真实来路——它并非来自地面纹路，而是从真理残魂脚下那片半透明影子里生长出来的，这位残魂用几千年时间把自己铺成了这张陷阱。
