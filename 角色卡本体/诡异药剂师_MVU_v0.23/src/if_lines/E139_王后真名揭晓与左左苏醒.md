# E139·王后真名揭晓与左左苏醒·if线

- 若林恩在左左睁眼瞬间先伸手按住她的拳头、把她与巨像之脑的视线隔开，则左左那一记上勾拳落空，连接重建仍在发生，但「王后」两字未被她当场听见，真名揭晓推迟到下一次巨像之心跳动。
- 若林恩抢在巨像之脑开口之前说出「她是左左，不是任何人」，则巨像之脑把「王后」二字咽回，连接仍在但身份公开被冻结，事件变形为「同源确认、真名未揭」。
- 若林恩在巨像之心高频跳动时提前把左左从神殿带离，则苏醒未发生，巨像之脑主动呼唤失败，E139 标记取消并记入偏离账本，E140 改走「强制唤醒或第三方调停」分支。
- 若林恩站在原地不出声、让那一记上勾拳结结实实落在自己下巴上，则左左的怒火与羞意在巨像之脑面前先烧尽，真名揭晓瞬间她的情绪波动被压到最低，质问句更冷更短。
- 若林恩当着巨像之脑的面把左左护到身后并宣布「她的主权归她自己与归我」，则他与巨像之脑之间当场挂上对左左归属的对立账，E140 谈判多一条「凑脑袋占位」的前置挑战。
- 若林恩在左左僵住的那一刻用手覆上她的五指、把「凑脑袋」这个词顶回去，则左左的注意力被拉回二人既有关系，「王后」称呼在她的意识里被压成「某个很久以前的熟人」，归属感偏向林恩一侧。
- 若林恩直接对巨像之脑说出「你认错人了，你的王后早就碎在三千年前」，则巨像之脑默认走向中的「见到我的王后」一击被打断，祂的悲伤与矛盾当场公开，事件变形为「身份揭晓但归属失败」。
- 若林恩把早已知晓的巨像之心寄生事实先一步摊牌，则左左在认亲的同时得知林恩体内也藏着一块巨像血肉，她的质问范围从「你是不是我的王」扩展到「你是不是我身体的一部分」，张力抬升一档。
- 若林恩趁僵住瞬间用超维连接直接检查左左意识是否被巨像之脑拉扯，则左左察觉被检查而炸毛，「凑脑袋你居然偷看我」与「王后」两件事叠在一起，愤怒与归属感被同时点燃。
- 若林恩在左左欲挥第二拳时把她整个人捞到怀里扣住，则巨像之脑注视下二人身体接触被成像，祂对「王后已属他人」的判断当场成形，E140 谈判中祂对林恩的态度从「感谢送回」转为克制敌意。
- 若林恩在巨像之脑报出真名之前先叫出祂的隐藏代号称谓，则巨像之脑主动公开身份的节拍被打乱，揭示权被林恩夺走，左左接收到的信息变成「凑脑袋早就知道且瞒着我」，对林恩的信任账本受损。
- 若林恩静观其变、只在左左震惊过度时稳她的肩，则默认走向基本兑现，但林恩「关键时刻不抢镜」的姿态被左左记下，后续她对归属问题的答案里多一层「脑袋没有替我做主」的正面账。
- 若林恩借苏醒瞬间向巨像之脑提出某种交换（庇护/收容/合作换取左左自由），则事件从「家庭重逢」向「政治谈判」切换，左左在旁全程听见自己被当作议题，她对林恩与巨像之脑两边同时留下复杂观感。
- 若林恩在左左手指下意识呢喃「王后」的那一秒打断并纠正「叫她左左」，则巨像之脑的视线与左左的自我定位同时被拉向林恩的命名，称谓归属前置归到林恩这一侧，事件变形。
- 若林恩完全不介入，让纳米血肉集群先一步误判并介入冲突，则左左要面对的是集群而不是巨像之脑本人，身份揭晓延至混战之后，E139 完成条件中的「双方进入可继续谈判」被集群敌意所破坏，事件变形。
- 若林恩当场把此前从艾雯爵士处得到的巨像之心收容方案直接递给巨像之脑看，则谈判筹码前置公开，巨像之脑对林恩的算计等级重新评估，E140 中的收容条款谈判起点被改写。
- 若林恩在左左抓住他衣领质问「你早就知道对不对」时选择沉默一秒以上，则沉默本身被左左视为默认，她对林恩的隐瞒等级评定升级，后续羁绊线多一道「被瞒真名」的裂口。
- 若林恩在巨像之脑开口「是我，你的王」之后立刻补一句「你的王早就死了，你只是祂留下的意识」，则巨像之脑被迫当场承认自身也是残片，左左与巨像之脑的「父母-女儿」框架被同时拆散，双双降格为「前代遗留」，归属权重新悬置。
- 若林恩在苏醒完成后立刻带左左走、不让巨像之脑说完第一句挽留，则E139完成条件中的「双方进入可继续谈判」未成立，事件变形为「揭晓后立刻断联」，E140 需要在第三方介入或远程连接下才能重新开启。
- 若林恩在左左质问「你到底是谁」时抢先替她反问巨像之脑「你想要她做什么」，则谈判议程提前曝光，巨像之脑被推着当场亮出真实意图，E140 的「归属谈判」前置压缩进本事件。
