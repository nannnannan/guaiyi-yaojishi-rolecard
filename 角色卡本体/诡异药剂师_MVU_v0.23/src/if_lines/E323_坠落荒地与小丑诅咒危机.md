# E323·坠落荒地与小丑诅咒危机·if线

- 若林恩在界门吸噬瞬间先把左左从枝干上扯下来塞进自己的蚀痕里贴身固定，则她不被母树枝条和风压甩飞、保留完整指挥权，但也错失她挂在枝上远眺蜂巢方向的最后一个观察位。
- 若林恩在肩扛银色幻想飞越断裂区时刻意朝躯干的瘟疫囊肿掷一支镇静药剂，则瘟疫蔓延节奏放缓一拍，银色幻想后续储存能源损耗降低 8%，但疫医黑粉样本落到地面的密度同步减少。
- 若林恩在放松控制之前先朝蜂巢智脑方向留下一句心声承诺「我会回来收尸」，则她在被瘟疫吞没前多撑三秒发出一条残缺加密讯号，血肉神教解码组后期多一条追蹟线索。
- 若林恩在坠落地面的瞬间优先用蚀痕护住左左而不是银色幻想，则左左零撞击无伤落地、立刻进入寻母树状态，但银色幻想失去一层血肉缓冲，破损度 +10%。
- 若林恩在发现左左欲呕吐时主动把一根触手伸过去让她咬着稳定,则她胃酸没吐出来、保留所有体力,但事后她追着要拔掉那根触手整整十分钟。
- 若林恩在左左准备拔树枝前先脱口而出「你踩我脸上拔不出来」,则她脸红心神一乱、改踩树干为施力点,树枝一次脱落、他脸上不留鞋印。
- 若林恩在左左做图灵测试时故意把答案报成错误数字,则她惊呼「脑袋疯了」立刻改投镇静针,他被强制麻痹三小时、错过撕离诅咒的黄金窗口。
- 若林恩在见到被血肉包裹的银色幻想时不使用夜魔刀、改以灵能震碎瘟疫连结,则剥离速度快一倍但刀刃不沾血,左左无法从伤口判断他的真实心境。
- 若林恩在捧起银色幻想那刻默数那断成两截的根源战刃并冷笑一声「收力收得漂亮」,则左左首次听出他语气里那层带哭的自嘲,护送期间主动贴紧他三步范围。
- 若林恩在跨上她身上那秒改用膝盖压住她的腰而非直接撕扯血肉,则接触面积缩小、瘟疫传染路径减少,但他必须在后续撕魂前多承受一波小丑诅咒反噬。
- 若林恩在喊出「我就是他」之前先把左左指使去找母树的具体方位,则「我就是他」台词保留自爆冲击,左左不会目击这一刻、关系揭示延后至 E324 苏醒期。
- 若林恩在吻下去前一秒用最后一格理智把咒瞳贴上自己太阳穴锁住部分记忆,则他事后能完整复盘这一段失控过程,但咒瞳留下一道隐蚀、未来一周无法全力扫描。
- 若林恩在撕扯血肉瘟疫的瞬间朝自己肩膀咬一口制造伴生剧痛,则剧痛把诅咒反噬短暂压制回第一阶,他多争取到十秒坦白时间,但伤口成为后续母树检查时的明显新伤。
- 若林恩决定不爆出「我就是他」、改以行动直接开始撕离诅咒,则银色幻想只听到撕扯声、没听到身份承认,E324 苏醒时她对他身份的判断分歧多一层。
- 若林恩在以M光晕浮现瞬间把光流引向自己手腕作为泄压口，则自己手腕瞬间爬满猩红荆棘纹路里，左左后期护理时多一项专门清洗工序。
- 若林恩在吻上她那刻同步把胸口的树枝断口推向她的伤口方向,则尖锐断口在他唇边划出血痕,银色幻想恢复后能在他唇上看见那道缺口作为证物。
- 若林恩在狂乱中抓破自己胸口留下三道血痕作为「自我惩罚标记」,则小丑诅咒被剧痛反向压制一档,但他在 E324 苏醒时胸前多三道无法消去的疤。
- 若林恩在扑倒前先朝树干一拍把自己的指纹印在瘟疫脉络上,则疫医回收队事后清理时多采到一枚「林恩参与」的物证样本,视界黑市命名价格 +3000 黑颅币。
- 若林恩全程让左左先离开十米再回到现场,则他在失控强吻时没有目击者,E324 中左左对「他病理状态」的评估完全依赖母树的转述。
- 若林恩把「我现在可以告诉你了我就是他」这句话拆成三句分次说完,则每说一句就被小丑诅咒打断一次,他必须在三秒内完成三段发音,否则完整身份永远断裂成残缺讯息。
- 若林恩在出现小丑虚影的瞬间把它当作靶子命令以M向自己心口反向刺去,则以M执念反向撕碎虚影一角,诅咒第二阶持续时间被强行缩短两小时。
