# E364·黑夜城复起与神印绑定·if线

- 若林恩在艾雯爵士「大哥」的呼唤后主动反问「先生这二字你敢再叫一次吗」，则艾雯先是一愣，然后掩面大笑，拳头亲密地碰在他胸膛上，那段遗失的兄弟情感第一次被新记忆补一笔。
- 若林恩在黑夜城倾城狂欢时主动为艾雯从系统空间抓出一份他失踪前最爱喝的灵能配方咖啡，则艾雯在愣神三秒后接过喝一口，灵能虚影深处多一份微弱却逼真的回忆印记。
- 若林恩在欲望母树树洞里主动替药剂师们额外摘取一块初诞者力量精华，则药剂调配成功率提升三成，但林恩本体的初诞者储量被抽空到必须休养一周。
- 若林恩在药剂师们面前主动掏出那枚「疫医瘟疫资料」与「初诞之力」样本，则实验室全场静默三秒，黑夜城皇家药剂协会会长亲自提笔将林恩记入「当代首席药剂师」馆档。
- 若林恩在监测屏幕上看到母树灵魂读数死水时主动拍一下屏幕，则屏幕木然回馈波纹但毫无变化，他得到「非药剂范围」最直接的证据。
- 若林恩在否决「巨像血肉滋养」方案时主动提议「那她需要怎样的灵魂肉质」，则智囊储备中记下一行可能的狩猎目标，未来清单避无可避地指向血肉支配者。
- 若林恩在讨论「牺牲一位根源作为养料」时主动问「那具体是谁呢」，则众人同时沉默，视线一致落到智脑的网络投影中血肉支配者那一栏。
- 若林恩主动对神印做逆向解析，则他会在神印深层感受到「制造者已逝、其位曾经身处地狱与旧神为敌」的怒吼回响，他首次得知这枚神印曾属于一段失落战争纪元。
- 若林恩主动把神印绑定到右手而非左手，则右手手背浮现黑色印记，左左在意识空间破口大骂「你竟然把我晾在一边」，涩涩度-1，绑定关系出现一段奇特冷场。
- 若林恩主动让左左从掌心探出轻轻触碰那枚神印同时绑定，则她会瞬间被神性震荡得后退三步，绑定关系追加一道「神与咒的共栖」标注。
- 若林恩直接把神印插入夜魔刀柄而不绑定任何人，则刀身在数日内隐隐散发强制追魂气息，但林恩自身的灵魂也会随着每次挥刀持续被磨耗一个不可见的点。
- 若林恩主动问左左「你愿意做我神印的灵吗」，则左左红着脸把头别过去，「你做梦」三个字从牙缝里挤出来，但她的咒纹深处多出一道悄悄愿意的暗光。
- 若林恩主动尝试将初诞者力量直接灌入神印试用，则神印瞬间爆出刺目黑金光芒，他的灵魂被拉入一段古老的「旧神战争」记忆残影，必须靠巨像网络拽回。
- 若林恩在绑定完成瞬间主动把左手伸到母树树洞脉络中轻拍一下，则母树庞大主干沿着这一拍渗出极其微弱的绿色气泡，监测屏幕上她的神魂读数首次出现一条细微起伏。
- 若林恩主动将神印既有力量通过巨像网络调一份给黑夜城防御炮塔试用，则防御炮塔的弹药伤害额外+40%，智慧智脑在网络里记下「这家伙是收不住的宝库」。
- 若林恩主动对神印施一段腼腆祈愿「愿养母树神魂苏醒」，则神印响应他的意愿浮现一缕极淡的黑光，他自身灵魂在那一霎被轻轻叩击出一声「是」。
- 若林恩主动把那枚芯片与神印一并收入怀中做平行存放，则主母摇头「那样会让两枚神器共振冲突」，林恩不得不择一先放系统空间备份。
