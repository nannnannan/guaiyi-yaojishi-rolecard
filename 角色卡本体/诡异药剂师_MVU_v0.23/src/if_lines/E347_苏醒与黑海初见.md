# E347·苏醒与黑海初见·if线

- 若林恩在推开房门之前先抬手确认右手衔尾是否仍附着，则他对自身仍是当前人格这件事的最快核验落在那条黑色衔尾上，窗台街景的恍惚感被他用自己的方式压下去一拍。
- 若林恩在左萝那记飞扑头槌落下的瞬间主动侧身而不是被撞飞，则她扑空翻倒在地板上打两个滚，闯进来的夜医看到的不是团圆动色而是左萝摔成大字型，尖叫声和笑声在同一帧炸开。
- 若林恩把屁股上的三下拍打换成揪住左萝两只脚踝把她整个人倒吊起来，则「废柴回来了」的认证画面被改写成她被倒挂在他手上的现场，巫神头颅远远笑出第一声，小小扑过来时先抱左萝再抱他。
- 若林恩在周围夜医围拢上来前就把眼眶里的热泪压回去，用一种过分冷静的口吻一句一句问「我不在这段时间里城市出了多少事」，则团圆氛围被他自己生生打断成灾后报告会，左左当场皱眉把触手搭上他手腕。
- 若林恩在夜医们涌入时主动一个一个把人背后的面具与编号都扫一遍，则他在第一分钟就清点出缺席名单，艾雯与主母的悬念在他自己嘴里先被念出，不必等传讯来打破。
- 若林恩在左萝嚎啕的喜悦里抬手替她把乱发拨回耳后，则她第一次没被「凑脑袋」的外号盖过、被一句没说出口的温柔击中，拍打的喜剧节奏瞬间反转成她脸红到耳根。
- 若林恩在白夜按肩问身体状况时主动先把右手那条衔尾抬给他看，则对话焦点直接从身体创伤移到「复苏度去哪了」，白夜会沉默一秒才说出「你终于肯给我们看了」。
- 若林恩把对「眼睛进砖头」的咆哮改成沉默半晌后用胳膊勒住左左和小小两人，则「废柴回来」的戏码被他自己用一次不吭声的抱紧替代，整个现场哭成一片但没人敢先开口打趣。
- 若林恩在众人讲述那一月神迹时主动插问「白发大君删除自己记忆的具体边界在哪」，则调查方向从「复活后状态」提前切入「视界之主与我的记忆分割点」，佝偻老人尚未出现时他就先锁定了黑海这条线。
- 若林恩拒绝立刻随老人进入黑海、要先去见艾雯和主母下落，则老人枯拐一顿收回海面，告别变成「下一处阴影再见」的预告，黑海推迟到下一事件窗口作为入口。
- 若林恩随老人踏入黑海时先把左左的触手缠得更紧，则她没有被留在小巷、整段黑海初见都有她的意识挂在心口催问，老人的每一句叙述都同时被她监听。
- 若林恩在黑海边缘先蹲下用手指触碰那片镜面水，则指尖被一把不属于任何人的悲意钝咬，水面在他面前一瞬间卷起无数陌生面孔的倒影，老人第一次食欲停顿。
- 若林恩黑海里抬手想把自身血肉探进海面，则海水在他皮肤附近自动退开一指困难地，留下一圈微微隆起的水泡，老人轻声说出「它认出你了」。
- 若林恩在老人说出「更希望他回来」那句话后保持沉默过半分钟才开口，则老人误以为被默认同意、下一句话会更重，整条引路叙述节奏被拖慢一拍。
- 若林恩直接打断老人「别绕圈，告诉我紫罗兰大君到底是谁」、不给对方铺陈空间，则老人在潭水边第一次正眼打量他好几秒，这一段段节奏从闲话切换成开门见山。
- 若林恩在老人转身沿着水面走时突然问出「你就是那个引路人对吗」，则老人脚下一顿、水面泛起一圈波纹，他承认的话语不再只是旁白、而是正面应下这句质疑。
- 若林恩主动从背包里翻出那条古梦中反复出现过的渡鸦羽毛举在黑海上，则水面会自发把羽毛圈进去拖向深处，老人的目光跟着羽毛暗下去一秒才继续往下讲。
- 若林恩在黑海领域主动打开咒瞳扫过整片水面，则视野是无数道环状波纹堆叠出的深邃，他被迫立刻收回咒瞳、眉心多一道为窥见深广而烙下的灰线。
- 若林恩黑海初见全程都保持一种对死亡的冷静不在状态、只把听当记录，则老人在告别之前会多看林恩一眼，他会说出「你不像上一个来这里的人」。
- 若林恩拒绝被彻底引入深海、选择只在黑海边缘水面踏半步，则他能听到引路人全部故事、但老人把关于「紫罗兰大君」后面更深一段保留在下一处别面时机。
- 若林恩在老人说出「第一次相见」之前就主动俯身叩倒三次作为对难尊对手的礼节，则引路人的眼里会闪过一丝陌生，轮回的叙述从那一刻起被改成「上一位引路者」同样的礼遇。
- 若林恩在老人临别那一句话落点后隔十几秒才回「我不打算让位」，则黑海水面霎时间竖起一道水枪后倒塌回镜平，引路人背后的衇尾黑蛇自动朝林恩身后浮起虚影。
- 若林恩把黑海之行全程伪装成只是病愈后一次散步、不愿承认自己在调查，则老人眼中的他只是「某个面上不慌的病人」，告别会被他回避出黑海深处重要节点。
- 若林恩主动要求黑海只是一次单方面观察调查，则他离开时背后多一条由他自己设下的隔离线，老人在下一次现身时会明确指出那道忘置的防线跟他的来历不一致。
- 若林恩在黑海领域里主动释放以M气息环绕在自身一旁，则水面会如同活物般同频呼吸一圈，引路人看透但不说破，关于「衔尾后来」那一句会多一笔诡异的潜台词。
