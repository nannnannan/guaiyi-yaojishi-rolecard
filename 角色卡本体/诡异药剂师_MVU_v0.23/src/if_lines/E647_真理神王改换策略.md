# E647·真理神王改换策略·if线

- 若林恩不去高塔而继续在外围猎杀落单神灵，则变形：猎杀窗口因献祭加速而急速收窄，他必须赶在四大无序生灵合围前剪光最后的下位神。
- 若林恩当场折返追查震荡源头，则他会在出口一带先撞上驻守的腐化上位神，迷雾之海入口战提前爆发，金色少年接报会立刻改道正面拦截。
- 若林恩按住初诞者之力的躁动不动声色地继续潜伏，则体内敌视反应不断累积，精神持续被无序气息撩拨，左左会先一步撑不住出手稳住他。
- 若林恩借迷雾做假尸抛给追兵，则搜捕部队短暂相信猎物已死、献祭节奏放缓一刻，但金色少年一眼看穿，献祭规模反向翻倍。
- 若林恩主动向汇聚的被污染者营地发射一支疫医镇静剂远程索敌，则部分腐化神灵痉挛滞后，献祭队列出现一道真空缝隙，但他本体的位置第一时间被金丝定位。
- 若林恩借助与高塔的联系直接闭眼入幽冥海洪流，则脱离追兵搜索圈，但离开期间迷雾之海被四大无序生灵蚕食得更快，最后能周旋的海域更小。
- 若林恩让左左先回左手、纯以人形只身游荡，则她能省下护体消耗，但失去她的初诞者之力共鸣，他对无序生灵躁动的耐受时间大打折扣。
- 若林恩主动向被召集的污染者队列混入一具疫医伪装，则能渗到献祭中心附近，但每多呆一秒，体表的疫医法则就会被无序气息一寸寸啃噬。
- 若林恩在初诞者之力躁动顶点时主动宣泄一缕罪火，则周边无序生灵集体回望他方位一秒，但他能借此扰乱半拍集结，挣得片刻腾挪。
- 若林恩用心声对左左说「先去高塔等我」，则她咬牙默认，孤身被洪流推向高塔，他留在迷雾之海独自面对追兵，汇合节点被动后移。
- 若林恩朝金色少年的方位反向释放一缕初诞者之力气息，则少年立刻识破诱饵但不得不分一缕法则金丝锁定假信号，献祭中央指挥出现短暂空白。
- 若林恩此刻强行催动白烬扰动边境空间陷阱，则几处死地瞬间激活、追兵误入空间涡流，但金色少年会立刻判断猎物仍在这一带、加派上位神封边。
- 若林恩在献祭召令传遍前狙击一名传令的中位神，则召令晚一拍到达两翼营地，集结时的秩序多一层乱，但他会在金丝反向追溯里暴露自己曾踏足的节点。
- 若林恩不对无序气息做任何处置、潜心修整伤势，则体内敌视反应被他压到初诞者之力深处，左左会盯着他暗沉的眼睛发一整夜的呆、不敢睡。
- 若林恩以眼角余光记录金色少年捏爆腐化神灵的全貌并刻意让这一幕被远处哨兵看见，则追兵内部的神灵对神王的恐惧更上一层，忠诚度反而出现极细微的裂纹。
- 若林恩在异响出现瞬间让左左握住夜魔刀做最坏准备，则夜魔刀会提前养起一缕初诞者的战意，E648 的开天一刀会更快凝形，但她战后裂纹也更多一道。
- 若林恩决定冒险将自身一丁点意识沉入幽冥海洪流深处探底，则能隐隐触到「时间在这里不对劲」的粗糙轮廓，但意识回体后眉心会渗出一滴血、短期内不能再用咒瞳远视。
- 若林恩反过来利用猎物的身份诱少年误判，则金色少年虽不会被牵走，却在心里把猎物的位阶再上调一档，日后出手会更狠。
- 若林恩拒绝在这一刻作出任何选择、只在原地保持不动，则四大无序生灵的扩张不停，他被迫在 E648 的开局从更小的活动圈内突围。
- 若林恩朝高塔方位投出一支药剂作为记号，则药剂会在幽冥海洪流里被卷走、标不出固定坐标，但左左会把这一支视为他「决定活下去」的信号。
- 若林恩在震荡里对系统商城下一份特殊订单换取一份边境地形图，则商城会以一次扭曲的时空差交付，万机之神侧档多一道诡异的「献祭中交易」备注。
- 若林恩主动向追兵的边缘小队挑明自己研习过无序学理，则小队无神敢应，只把这句话层层上报，金色少年会卡在两个判断上：猎物精通无序，或猎物在拖延时间。
