# E625·命运游戏与七日离场·if线
- 若林恩醒来第一时间冲到艾维儿面前抱住她道歉「刚才差点伤到你」，则她红着眼眶不肯站住不肯原谅，主动要求他「别再这样危险地让我担心」，两人关系 +1 但保护伞枷锁议题被正面摆出。
- 若林恩不说罢工宣言、只平静收戟掉头就走，则织梦仍抛出「军团、朋友、家人」的威胁，他的「死吧」宣言以无声姿态成立，监视之眼继续。
- 若林恩在宣言中加入「如果你们终焉之主能赢，那我也跟他们同归于尽」，则织梦笑而不答，「莫比乌斯环」概念在 E627 揭示时她多一句「你早说过」。
- 若林恩叫左左出来后多说一句「死去你跟我一起死」，则左左疯狂嚷嚷「我早说过要跟你一起死」，两人在月儿兰城夜色中荒唐共立一场不那么庄严的死誓。
- 若林恩在第一天的闲逛中主动与那双灵能注视回眼，则远方高楼上一个幻影的「她」出现在窗边对他招手，距离一公里仍笑得云淡风轻。
- 若林恩带左左去吃面时坚持把面碗摞更高、打破餐馆纪录，则老板激动到收拾送他们一张终身优惠券，左左反而对他态度软下来一瞬间。
- 若林恩在两天中去冬泉谷找纱奈儿道别，则他在她沉睡床铺前站足一夜，告别由沉默完成，纱奈儿醒来后听到「林恩哥哥走了」的消息号啕大哭一小时。
- 若林恩在两天中往天堂世界轻轻折跃一次试图去探视大君，则他刚接近就被一缕渡鸦震退回来，「不能去」的信号以最深姿势送达，他选择收回步子。
- 若林恩把监视之眼的细节逐条记录到系统里归档成「入梦者灵能注视数据库」，则 E628 之后他能用这些注记反推她的灵能频率，训练首日就多一分先手。
- 若林恩离场的七天中从未浪费时间发呆，则他实际上每分每秒都在意识空间重复演练星寂模拟，E628 训练首日织梦评价「你怎么已经开始走样了」。
- 若林恩在酒店对峙瞬间主动先把房间炸了再尝试谈判，则织梦冷笑「他还是在赌」，舰队画面被灵能退散，博弈等级上升。
- 若林恩拒绝拖过椅子、选择直接坐到床上摊开躺着，则织梦鹰眼直视他三秒，「想杀我」一句被她以更缓的语气反问成「你以为我会吗」。
- 若林恩拖延到第九天才回酒店，则织梦主动找上他住的地方出现，对峙地点不变，提前两日发生。
- 若林恩带到酒店房间的包里多塞一颗他为纱奈儿买的糖果，则织梦视线落到那颗糖上一秒，「原来你还是舍不得她」的心事被她以沉默收取。
- 若林恩在酒店对峙时点燃烟、把烟雾平静吐到她那张平静的脸上，则她不退反笑，后续切割眼中碎片救他的决定坚定得更早一分钟。
- 若林恩选择屏蔽联系到刻意连血枢的残念也拒绝存在，则血枢在他意识空间独守七日，「超维链接」被他主动断出，E628 历史揭示段首次以织梦的独白替代血枢佐证。
- 若林恩在左左骑他背上时当场把她抱起转三圈，则她惊叫怒骂，月儿兰城街景一段被她两人以纯纯真的打闹画面立档。
- 若林恩在两天中主动找到月儿兰城某家药店老板，买票订购一整年口罩预防感冒，则月儿兰城对他而言有了「还有下一段」的坐标，他在离开后仍会记得这里。
- 若林恩主动告知巨像、母树、伊甸他去哪，则三人陪同不缺席，织梦监视之眼对象由两人变五人，舰队画面压力更大。
- 若林恩在酒店开局先说「客随主便，你请坐，我跪」，则织梦微愣三秒，后 续「你死我活」策略需要她重新评估，服从测试段位被推迟到 E626 后段。
- 若林恩在离场期间把月儿兰城逛遍，则他在脑海记住这座城市每一处细节，E628 之后若回月儿兰城，他将能像老朋友一样回来看爷爷。
- 若林恩在酒店开局前主动给艾维儿发一道心声「明早我回来」，则她在第二日清晨全城搜寻的力度稍减，泛起的愤怒被压回一层，E627 汇合段她主动伸拳而非主动抱怨。
- 若林恩在七天中用系统商城封印自己原初之力作战能力，则织梦探查到他成为「凡人」，后续服从测试她更不敢掉以轻心。
