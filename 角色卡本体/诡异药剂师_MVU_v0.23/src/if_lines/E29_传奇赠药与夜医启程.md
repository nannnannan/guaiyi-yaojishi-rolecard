# E29·传奇赠药与夜医启程·if线

- 若林恩婉拒收下两瓶药剂，则血锯改口「暂存店内」，临行无增益，荒野开局按无药结算。
- 若林恩只收精神药剂退回体质药剂，则抵荒野后药效不均衡偏差由环境与狼群表现呈现。
- 若林恩表态留作伤患备用而非自用，则血锯补一句「夜医的手术刀不等病人」，何时启用由玩家后续声明。
- 若林恩反向提条件（情报/回报/信物），则血锯开价还价，药剂与嘱托分量随谈判浮动，师徒情分记一笔带账。
- 若林恩临行改道先去游魂巷置办，则启程顺延、道具暂不捏碎，狼群时点不提前。
- 若林恩当夜不睡做药剂或写笔记到凌晨，则次日精神欠佳如实呈现；血锯晨间皱眉但不越俎代庖。
- 若林恩翻歇业招牌留字条，则店内事务按既有 NPC 关系自行延续，不强造来客。
- 若林恩捏碎道具前先拆开查看构造，则系统只报外观与位阶，机制不剧透；捏碎仍由玩家主动触发。
- 若林恩捏碎道具后暂缓踏入法阵，则六芒星开放片刻后自行合拢；道具已耗，再次开启需玩家自寻等价路径。
- 若林恩两瓶同时立刻嗑下，则 24 小时双增益记为既立状态，虚弱副作用届时由系统结算。
- 若林恩只嗑精神药剂留体质作后手，则抵荒野时五感清明但耐受一般，差距由环境与狼群呈现。
- 若林恩两瓶都不嗑裸装进荒野，则以凡躯落入红月狼群包围，精神/体质增幅均缺位，不自动加护。
- 若林恩带黑弦月之外的随身物件（夜魔刀/电锯/医疗箱/多余药剂）入阵，则行囊照常同行；黑弦月封装仍不可解。
- 若林恩落地后不朝寂静镇路牌方向走，则进入诅咒之领其他区域，夜医知名度积累起点随之地形改写。
- 若林恩落地第一时间尝试杀生攻击狼群，则「禁止杀生」提示立刻反馈，夜医阵营反感按事实记账，不预先宽恕。
- 若林恩落地先出声示好或举医疗箱白褂示医，则狼群与远处目击者按各自动机反应。
- 若林恩落地想隐藏外观（脱白褂/摘镜片/收电锯），则夜医或遗民初见按新形象认知，不保留原作孤身良医预设。
- 若林恩试图寻找避开寂静镇的其他路径，则诅咒之领按既立设定展开，不虚构安全捷径。
- 若林恩临场向系统询问夜医更多资料，则系统只报可观察与已公开层级，三千年内情、倒吊天使本体、疫医暗面仍锁绝对隐藏层。
- 若林恩试图当场改写转职任务目标，则系统不直接否决，面板原始口径仍按机制存在；等价路径由后续事实判定。
- 若林恩在荒野遭遇首位夜医前主动表露血锯学徒身份，则对方反应按 npc 动机处理，不预设好感或敌意。
- 若林恩隐瞒血锯学徒身份以无名药剂师自荐，则夜医考察从头记录；后续再想亮身份需玩家声明并接受对方既成印象。
- 若林恩落地即受伤，则自救或等待外力由玩家声明；环境不自动安排恰好路过的夜医。
- 若林恩试图直接越过荒野进入寂静镇而不与狼群周旋，则狼群追击与镇内反应同步展开，不预设镇长立场。
- 若林恩落地先记录环境画地图做药剂标本，则狼群红月与镇内动静继续流动；首次照面时点由双方空间轨迹决定。
