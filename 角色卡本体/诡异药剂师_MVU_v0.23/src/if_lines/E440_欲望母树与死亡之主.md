# E440·欲望母树与死亡之主·if线

- 若林恩在出口袋阵前主动留下一支满充能碎片作为后手，则口袋王兽在吞噬碎片时会突然错乱，林恩多一拍突围窗口，但碎片将无法回收。
- 若林恩让左左以血族身份在大军冲锋前先制造血雾，则血雾会让王兽在短暂失明中无法精准锁定目标，林恩得以保留三分之一血量进入殿堂。
- 若林恩主动让克拉肯从半兽形态重塑为更完整的战斗体，则其触手会在变形时发出一种类似共鸣的歌声，系统会弹出【自然共鸣已激活】提示。
- 若林恩拒绝解放芬里斯让巨兽硬闯，则巨兽的触手会因硬碰硬而断裂两支，未来三天不能开展战斗，但它会以成熟的血族身份主动对敌军做出安抚。
- 若林恩对「猩红之影」王兽进行破防时主动以初诞者之力加持，则她原本八只王兽们的攻势会出现一个大熔点，他为巨兽换来了一个生生相息的机会。
- 若林恩主动让左左以咒血中咒喷出守在门口的守护精灵，则守护会受到咒术的持续破坏。
- 若林恩主动对孵化出来的子体王兽许愿「不许杀幼猴」，则新生的男子从此会永远以「父母」的身份保护孽主的孩子。
- 若林恩亲自以破魔箭为王兽破开胸肌，则他就成为王兽心中「重生救命恩」的头号位次，王兽会用全命都归顺于他。
- 若林恩让小丑陪林恩一起进入死亡领域，则小丑的玩偶身比血肉更能抵抗死亡气息，林恩多一位在死亡领域中的掮客。
- 若林恩主动让喵喵在该战役中携带药剂与补给跑动，则她将在途中被发现并被弑利亚征用做弩储存位置——狈从此会以储存这个身份存入对方档案。
- 若林恩让巨兽自愿继续用「树形」摧残敌军直到力竭后再让他现身模式，则林恩除了简单过渡还能亲身诞生在自然法域中给刚力的巨兽当伴侣。
- 若林恩主动让母树在树界中被种子渡给他，则林恩背包里会多一颗「生命之种」，未来它可以在任意地点生根成新的母树。
- 若林恩拒让孽主诗歌化为平常行径而主动让其暴露在王兽面前，则她会光彩夺目地受到王兽的敬仰，林恩可能会在杀戮中苦苦失去平常心的真意。
- 若林恩让左左假扮成王兽来掩护小丑逃进死界，则队员的身份潜伏会让小丑在死界内更加恐慌出门。
- 若林恩主动在入城前就把与血族利瘩的传送药品互传，则队伍从此能在死界自愿互换两个空间来额外逃开伤亡事件。
- 若林恩让母树在入城前更彻底地完善树界部队的灵台架，则其将以「自然亡主」的身份直接拖任后退。
- 若林恩主动让大腿王兽当场联手林恩，则林恩会在破城战后立刻叛逃并遭队强力歼灭。
- 若林恩触毛捕捉力亦渴望女宿继续出城，则她因此会爆成自然亡主而灵智与斯人一同毁灭，林恩将留下一种永远无法与该军团会合的遗憾。
- 若林恩让喵喵在死界放声尖叫，则她的「喵」会因二度死去而保留在死界——林恩日后可在死界听听她的声音。
- 若林恩与小丑离开便让他们无忧送还，则小丑身后断然给他一个看淡的困境——他会随意一个爆骂永不原谅林恩的告别。
- 若林恩让左左在死亡领域中心祭出最强的血族咒术爆炸，则王兽们的整个大队伍会同步被爆炸冲散，一片深厚血色的领域会从此变成死界王域。
- 若林恩主动让孽主干脆假扮林恩被敌王兽杀害，则后果会有一片无人受伤的事件场画布，孽主的真实身份永远成秘密。
