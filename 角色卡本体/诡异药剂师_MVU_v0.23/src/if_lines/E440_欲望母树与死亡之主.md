# E440·欲望母树与死亡之主·if线

- 若林恩在克拉肯全身触手绽放刀刃冲入口袋阵时高举王戟撑开初诞者屏障，则漫天无序轰击被金光接连挡下，克拉肯得以毫无保留地向三千米外的古老殿堂突进。
- 若林恩在冲至九百米处趁城墙鲛人射出破魔长矢的瞬间让克拉肯将自己掷向敌方王兽，则他能借碎矢涡流一戟刺入撕裂者·芬里斯胸膛，以雷霆万钧之势完成第三只王兽的解放。
- 若林恩拒绝冒险净化第三只王兽而令克拉肯孤身硬闯最后九百米，则两人在密集火力下伤痕累累，突入城门前的防线压力骤增数倍。
- 若林恩在解放芬里斯后因灵魂超负荷而七窍流血、几乎握不住王戟，则刚恢复清明的灵魂之狼会立刻与克拉肯并肩燃烧灵魂之火，死死挡住涌来的万千敌军。
- 若林恩在城门前打开系统空间放出小丑与孽主协助断后，则孽主会咬牙亮出光刃逞强宣称「骄傲的血族才不会弱水」，与小丑一同背对林恩迎向大军。
- 若林恩在系统空间闭合前试图阻止新生的欲望母树走出空间参战，则柳叶长发的小女孩会笑着拒绝被当成宠物保护，扎根海底化作参天诅咒巨树展开树界。
- 若林恩任由欲望母树展开树界吞噬冲锋的污染骑士，则海底蔓延的畸变藤蔓会同时为克拉肯与芬里斯持续愈合创伤，将四大根源与狱卒战力牢牢钉在城门外线。
- 若林恩冲至结界前高举深海罗盘大喝开门，则罗盘光束直刺殿堂深处的古老符文大门，城墙上的鲛人军队齐声高呼「是主人要等的人」并立刻开启钢铁城门。
- 若林恩在入城摇晃欲坠时接受鲛人将军的搀扶并追问船长现状，则将军会边引路边沉痛告知无尽海已被狱卒封锁、康斯坦丁的本体在地下墓船内只剩不到两月的寿数。
- 若林恩穿过死兆级亡灵禁军把守的甬道踏上地下巨船时未以初诞者之力护体，则墓船外溢的腐败幻境会令皮肤瞬间生出剥离幻痛，逼得他立刻激发黄沙屏障。
- 若林恩登上破败巨船甲板后出示深海罗盘高呼履行约定，则覆盖船舱的漆黑病变组织纷纷退散让路，船舱深处传来康斯坦丁沙哑苍老的回应。
- 若林恩顶着死亡领域的尖啸幻象冲至如山王座前，则他能亲眼目睹湮灭与失控均达极限的死亡之主神骸，并确认所求的第二具渡鸦尸体就在王座之下。
- 若林恩察觉康斯坦丁每说一句话神骸便多裂开一道缝隙、当即喝止他继续开口，则骷髅眼眶中的蓝焰会温和闪烁，只以一句「那本就属于你」完成交易允诺。
- 若林恩跃上王座将双手按在森然魂骨上全力倾注最后的初诞者黄沙，则金色火焰会顺着王戟与掌心迅速攀满整具庞大骷髅，在透支灵魂的极限边缘启动神骸复苏。
