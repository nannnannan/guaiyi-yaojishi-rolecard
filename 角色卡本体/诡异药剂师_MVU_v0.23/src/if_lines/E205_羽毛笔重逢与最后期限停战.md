# E205·羽毛笔重逢与最后期限停战·if线

- 若林恩进002先做一件事是把大门用主母的加护再次反锁,再回头招呼羽毛笔,则她那句开场白「你看上去很着急」被推到三秒后才落笔,事件以不变形收束但纸面先多了一道额外线。
- 若林恩忍住伸手rua确认她真身的冲动,改成站在桌前恭敬地打招呼,则羽毛笔没机会写下把自己扯出门的那段字,事件以不变形收束但「不要每次问候的方式都这么特别」的吐槽未被留下。
- 若林恩坐下先表态「我听你说完」,则羽毛笔笔尖一顿、临场更改书写顺序,先列出那四条外部警戒,再补一行【不必现在答应什么,但请记牢】。
- 若林恩把那句「我爱你,羽毛笔」说得更慢更重、并顺手把她的手背握住不放,则她划掉的前一行不是【思维可不可以不要这么跳】而是【凑巧我也想听到这句】,事件以变形(告白生效)收束,后续警戒改由她闷闷地亲口念出。
- 若林恩到场之前先在门外把巨像之心输出耗到过半,则他推门时脚步发虚差点跌到她书桌上,事件以变形(虚弱入场)收束,羽毛笔不得不暂停警戒先递上一杯温水。
- 若林恩听完四条警戒后主动复述一遍作为承诺,则她被这份尊重安抚,事件以变形(应允且尽量遵守)收束,她在纸页落下「若违反,代价自负」的补充款。
- 若林恩坦白跨界通讯那一夜把白逸按进了全功率镇静,则她没有生气,事件以不变形收束但她在纸上写【那不是你的错,是兄弟的命】。
- 若林恩在「还有两个小时」响起后回头先去安抚小呀哒和尹依,则羽毛笔目送他出门时多留了一段柔软目光,事件以不变形收束但她心中「家人」的边界被悄悄扩大一寸。
- 若林恩与羽毛笔对视时把她递来的那杯水喝完并持续握住她那只看不见的手,则002之外五根源的灵能共振全数静止一拍,事件以变形(誓约共振)收束。
- 若林恩在两小时守夜里因彻夜疲惫睡着,则她悄悄在他梦中落笔,事件以变形(梦话共鸣)收束,他醒来后手里握着一段关于她的关于「保护你」与「寻找你」的细碎记忆。
- 若林恩干坐着不吃不喝直到倒计时最后五分钟,则她主动在纸上写【你先喝口水,不能让自己垮了】,事件以不变形收束但她的脸色比林恩先白下来。
- 若林恩中途离开002去敲主母殿堂门解释白逸家世,则五根源在半路全数拦下他,事件以变形(摊牌提前)收束,主母听完「那个世界有他的父母」一句话后独自在殿堂中深吸一口气。
- 若林恩顺嘴问她一句「你心里是不是有过我」,则她笔尖一抖、翻页速度比平时快了一倍,事件以变形(尺度突破)收束,她在最后一小时主动把手背放上他的掌心。
- 若林恩在五根源破门之前主动应允「到零点就走,无论召唤来不来」,则羽毛笔在最后一小时落在纸页上的不是警戒而是【条约女友转正条款】,事件以变形(条约新章)收束。
- 若林恩完全不理窗外召唤波动、只是陪她看她桌上那张羊皮纸,则她守夜状态比原作饱满一倍,事件以不变形收束但午夜零点之前她多出一段关于他的完整笔录。
- 若林恩在【我爱你,羽毛笔】之后,被羽毛笔停笔追问「你是不是只爱我一个」,则她的翅膀气压绷出一线裂缝,事件以变形(独宠质疑)收束。
- 若林恩当众对着殿堂外喊主母一声「姐」,则主母投影立刻浮现在002门口,事件以变形(主母探访)收束。
- 若林恩在半途主动收回刚才那句「我不去蓝星了」改口「刚才那句不算」,则羽毛笔的笔尖缓慢拉直,事件以变形(情绪彩排)收束。
- 若林恩想开窗透气被羽毛笔的咒权强行压下,则她暗暗把002的结界加了一层,事件以不变形收束但五根源在门外灵能感应突然增强。
- 若林恩与羽毛笔短暂沉默,则她主动在纸上写【其实你不用说,我都知道】,事件以变形(被识破)收束。
- 若林恩倒数期间开始情绪夸张哀嚎闹情绪,则她用一缕咒权纸带堵住他嘴,事件以变形(强制镇静)收束。
- 若林恩透露「羽毛笔你其实偷偷复制了一份窥探我的记忆给我」,则她的咒权剧烈波动,事件以变形(记忆交易)收束,她主动作废关于过去那段被删内容的复审许可。
