# E662·腐化刺杀与林恩苏醒·if线

- 若林恩在黑剑入胸瞬间主动把意识压回体内最深处让初诞者之力自动守门，则他睁眼时气色更冷峻，那双布满血丝的眼睛里倒映的不止是刺客，还有半个战场，第一句话里多一道铁意。
- 若林恩在银色幻想中剑那一瞬心脏部位的无形细线被因果神王再次拽紧，则他苏醒的时点被硬生往后推三息，她背上血花渗透得更深，「谁也休想害他」之后还多一道撕裂的颤抖。
- 若林恩在第二波刺杀折返时指尖无声按到怀中一枚画卷残页，则空间法则在他胸口隐约亮了一线，黑剑停在胸膛前一寸而非两厘米，全场看见的是一幅更瘦的差距。
- 若林恩苏醒瞬间第一反应是抬手把胸前黑剑往外拔，则拔剑的刹那整把黑剑崩解成无序齑粉随风而散，那名腐化狱卒的「视死如归的笑」直接凝固在脸上。
- 若林恩苏醒瞬间先低头吻了一下银色幻想的额头再抬眼，则全场无人敢言，连天顶上的林蒙都在滞空一瞬，「躺在腿上的银发少女」首次被公开承认为他的私有领域。
- 若林恩苏醒瞬间先用被血染的手指轻轻合上她仍睁着的眼睛，则她的身体在他指尖下第一次真正完全放松，全场根源的「林恩！！」长啸里多一拍他低沉的「睡吧」。
- 若林恩苏醒时不急着处置黑剑、先用左手按住银色幻想背上的贯穿伤口替她分担余火，则她呼吸回来的速度更快但她醒后会更加抗拒他的靠近，「她挡不住下一次」的因果埋下。
- 若林恩苏醒瞬间先抬手掌心对上天空那一线破碎的蓝天再放下，则封闭世界破口的法则恢复过来一角，给黑夜城众人一个明确的「他可以撑住这个世界」的信号。
- 若林恩苏醒瞬间直接用三叉戟从自身系统空间里召出、钉在地上发出锵然一声，则林蒙与康斯坦丁首次同时定住，「暗影神格挡南王」的必要性当场作废，事件走向谈判轨道。
- 若林恩苏醒瞬间只抱紧银色幻想、对周围一切刺杀者都不看一眼，则根源们自发展开撕碎腐化者的清算战，「他没有命令我们却动了」的认知在最深一层扎根。
- 若林恩苏醒时直接发出一声濒死的兽吼，则整个封闭世界的蓝天彻底崩解，狱卒的黑雾多一线惊慌，南王林蒙即刻下令「全部停手、否则视为背叛」。
- 若林恩苏醒瞬间用指尖蘸了一下指缝里流的银色幻想的血放在唇边，则他的眼底再燃一缕罪火，那双本来布满血丝的眼睛里多一圈猩红，腐化者中已有两人当场意志崩溃自爆。
- 若林恩苏醒瞬间把银色幻想放倒在地上、自己摇摇晃晃站起来拔剑，则「大病初醒的少年」形象被替换成「仍能战斗的少年」，全场退避的距离从两边扩展成整圈。
- 若林恩苏醒瞬间先朝康斯坦丁风中那个背刺副官的位置投去一眼，则背刺者周围空间直接塌陷，「副官身份」在他还没来得及自爆前就被剥离。
- 若林恩苏醒瞬间低声念出左左的名字而不是银色幻想，则左腕蛇鳞焦痕在他识海里一颤，那份承诺在意识底处由玩家交付出来，银色幻想的指缝里滑落的血多一层意味。
- 若林恩苏醒时刻意把气息完全收敛、让人以为他仍未醒，则第二批腐化者中最后潜伏的一人也跟着出手暴露，「全部暴露」的实现比默认的更彻底。
- 若林恩苏醒瞬间拖身上的血站起来把银色幻想抱进怀里再转头，则他从此在黑夜城全员心中的地位从「王」升格为「他们的神」，E664 跪迎时多一线伏线。
- 若林恩苏醒瞬间只对那位背刺副官说一句「你也配提大君」，则康斯坦丁的魂火跟着晃了一下，「家人中也有鬼」的恐惧首次在他心中具体化，同生共死之约的土壤更厚。
- 若林恩苏醒时先以一根食指建立一个金色小屏障把银色幻想完整罩住再应对外界，则「保护她」的优先级在所有参战者面前被明示，林蒙随后再不敢拿她作筹码。
- 若林恩苏醒瞬间用三叉戟的烙印远程向整个黑夜城发出一声「我回来了」的无声宣告，则主岛上巨船未到时已有大半根源涕泪跪迎，E664 的场面提前成熟。
- 若林恩苏醒瞬间抬头直视林蒙的方位、轻笑一声「这就是你们的诚意」，则林蒙自认理亏单膝而跪道歉，「女主人的治疗」提议从他口中消失，事件转入由画家主导的治疗轨道。
- 若林恩苏醒瞬间将身上那股反噬的余火向四周散作点点星屑而非压回体内，则根源们首次看见「他替你烧了半条命，又为她再烧半条」的画面，「赴汤蹈火」的誓言从这一句开始彻底锚定。
- 若林恩苏醒瞬间短暂失忆、用戒惧的眼神扫过在场所有人一次后又松开，则主母第一个跪下大哭「吾儿」，其余根源跟着跪，林蒙不得不公开承诺狱卒不再靠近林恩。
- 若林恩苏醒瞬间主动把自己的血珠弹向怀中的万物神格备用碎片（如已取得），则神格与mái伏在他体内的因果细线共鸣一道，因果神王在天顶远望时眉头微蹙，多一笔观测日志。
