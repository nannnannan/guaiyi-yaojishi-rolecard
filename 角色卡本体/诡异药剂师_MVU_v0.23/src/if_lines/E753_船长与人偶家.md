# E753·船长与人偶家·if线

- 若林恩在船长于内城墙血战至灵魂彻底燃尽自灭、仅凭无意识的肉身本能挥剑死守城门缺口时，以王座引力替他稳住脚下碎裂的城砖，则那具不屈的躯壳在狂风暴雨般的魔潮冲击下未曾后退半寸。
- 若林恩在人偶家流着泪以本命丝线扶住船长摇摇欲坠的无意识躯壳、轻声说出「我就是当年凡人王宫里被你护在身后的那个小姑娘」时，让圣所微光穿透硝烟照亮她手中的同款银剑，则这段跨越漫长岁月的宿命重逢在战火中熠熠生辉。
- 若林恩在人偶家亮出那柄珍藏一生的同款银剑、以丝线将自己的手腕与船长持剑的右手死死绑在一起并肩迎敌时，将一缕初诞者锋芒注入双剑之中，则每一记挥斩都能同时绽放出属于神王与人偶师的双重剑华。
- 若林恩在银色幻想如一轮璀璨银月般从天而降、一剑斩杀闯入幸福之家孤儿院的堕落士兵救下夏娃时，顺着那道银色剑光送去一圈安抚波动，则被夏娃护在身后的孤儿院孩童们会止住惊恐的哭声。
- 若林恩在孽主浑身是伤地退守至孤儿院门前、与拿着简陋武器的孤儿院大孩子们站在一起立誓「我会守到最后一刻」时，让王座底层的黑火在她脚下燃起一道不灭的火线，则越过火线的低阶魔物尽数化为焦炭。
- 若林恩在感知到船长的灵魂早已在连续数日的不眠死战中化作点点金光散去、如今挥剑的只是刻在骨子里的守城执念时，于被锁禁的王座上对着城门方向深深低头，向这位最沉默忠诚的统帅致敬。
- 若林恩在人偶家一边操控丝线带动船长躯壳挥剑、一边微笑着向身边这个已经听不见她说话的男人讲述自己这些年如何追随他脚步时，以神念替她挡下侧面袭来的精神尖啸，则她能毫无遗憾地把藏了一辈子的话全部说完。
- 若林恩在银色幻想救下夏娃后没有片刻停留、转身对夏娃留下一句「带孩子们去内城最深处」便再度冲向城头死地时，分出一缕温和药力替银色幻想封住左肋的崩裂伤口，则他的银月剑光在随后的巷战中依旧快若惊雷。
- 若林恩在幸福之家孤儿院里那名年纪最大的少年握紧铁管站在孽主身侧、大声喊出「我们也是林恩大人的孩子，我们不怕死」时，以神魂牢牢记住这群少年的面庞，不让他们的勇气被黑潮吞没。
- 若林恩在船长手中那柄陪伴他征战一生的古旧银剑终于承受不住高阶魇魔重击而出现裂纹时，让人偶家手中的同款银剑与之产生共鸣交叠，则两柄凡铁旧剑竟硬生生架住了魇魔劈下的巨爪。
- 若林恩在人偶家十指因过度拉扯神王级躯壳而寸寸断裂、鲜血顺着透明丝线染红船长战甲时，送去一缕止痛的温和气息，则人偶家脸上的笑容始终如同当年王宫里那个仰望英雄的小女孩般纯净。
- 若林恩在孽主为了替孤儿院撤退队伍争取时间、独自一人迎面撞向三头冲入街巷的深渊魔狼时，引动空气中残留的药香助她激发血脉潜能，则她能以重伤之躯将三头魔狼全部撕碎在街角。
- 若林恩在夏娃带着年幼孩子们向内城中心圣所外围转移、沿途黑夜城伤兵纷纷用残躯替她们垫平弹坑与火海时，将每一名垫路伤兵的灵魂金光温柔接引回王座，不让任何一缕忠魂迷失在废墟中。
- 若林恩在船长的无意识躯壳哪怕被魔矛刺穿胸膛、右手依然机械而精准地挥出守护黑夜城的标准剑式时，于潜意识中与他同步挥出一记黑火斩击，则城门缺口前堆积的魔物尸骸如同山岳般无人能越。
- 若林恩在人偶家将全城散落的残破木偶尽数召回城门缺口、组成最后一道木偶剑阵护在船长身周时，偷偷将自己的一缕微弱神念附在最角落的一具独臂木偶身上，则这具木偶得以在战后留存下来替船长奉还断剑。
- 若林恩在银色幻想重返内城墙、看到船长早已魂灭却仍与人偶家并肩屹立在血泊中的一幕而眼眶通红时，借三叉戟的共鸣向银色幻想传递「替他守下去」的意志，则银色幻想挥出的剑意愈发凌厉决绝。
- 若林恩在人偶家轻声对船长的躯壳说「这一次，换我来保护你了」并主动用自己的后背替他挡下一道致命黑雷时，用王座黑火瞬间焚灭那头偷袭的魇魔眷属，替她报了这一击之仇。
- 若林恩在喵喵穿梭于孤儿院与内城防线之间、拼命将最后一批止血绷带送到孽主手中时，让沿途坍塌的钟楼向侧面偏斜三尺，则喵喵与撤退的孩童们险之又险地避开了飞溅的巨石。
- 若林恩在感知到内城墙的防御阵纹正在一寸寸崩碎、船长与人偶家的鲜血已经将整扇城门染成暗红色时，在王座上拼命压榨自身潜能加速融合灵魂金光，只求能早一秒破封而出。
- 若林恩在孽主擦去脸上血水、回头对躲在掩体后的孤儿院孩子们露出一个笨拙而温柔的微笑时，让掩体上方飘落几片带着暖意的金色光屑，则孩子们会在心里永远记住这位高挑少女最美的样子。
- 若林恩在船长与人偶家的双剑同时斩入一头统领级堕落者胸膛、两人身影在漫天火光中重叠为一具永不倒下的雕塑时，将这一幕永恒镌刻在罪恶王座的正面浮雕之上。
- 若林恩在船长与人偶家共同谱写的这段凡人王宫旧梦即将走向终局之际，于黑暗圣所内流下滚烫的血泪，则那两柄交错的银剑在彻底折断前，发出了响彻云霄的龙吟。
