# E460·纳米工厂与巨像细胞·if线

- 若林恩在无人机掠过时故意划破指头让血珠冒出，则被扫描仪标记为「新伤员」，他在半小时建厂录像里被当成临时伤患推动流程。
- 若林恩在被机械风暴压住脚步时主动抬手背伸出一段血桥让左萝踏上去，则她顺着他护甲骨线上到他肩头，绑定值 +2。
- 若林恩在天罗地网启动瞬间主动把自己的身影在监控前停一整秒，则指挥官反复重放那一秒，多写了一条「受试者形态稳定对称」的报告。
- 若林恩在告知「我也并不是没有」时主动张开掌心让左左捏一捏他用血气凝出的微缩纳米球，则她默默把这一招命名为「孩子的玩具」，绑定值 +2。
- 若林恩在调教工厂失序时主动让左萝做一次小规模联动测试，则她被调动的情绪在事后被夜医形容为「原来小丫头也能这一招」。
- 若林恩在被恒星火球击中前主动开系统空间让大量凡物先行被烧尽，则他的背包少了两箱家具，但人体烧伤面积减少了近三成。
- 若林恩在热灰散开时主动剪下一块自己的发烫外壳递给左左，则她愣了一愣后把它收进意识空间作纪念，绑定值 +4，但后续每逢高温都会缩一阵。
- 若林恩在向巨像之脑传输「我们进场了」的脉冲时主动让她听见自己的心跳节奏，则她在前线血伤中辨认出他「一切安好」的信号，绑定值稳但她在他回应时沉默了半秒。
- 若林恩在让反控纳米染体成熟的当口主动把目标规划为「去帮巨像」，则被锁定「良医出场调研」标签在机械神教总台弹出，前线指挥系统回馈延迟多一秒。
- 若林恩利用超维感应的脑音主动在黑暗长夜里孤单喊了一声「脑子」，则她在数千公里外的巨像创伤中突然听出了他的声音，绑定值隐式 +2。
- 若林恩在被左萝肘腹时主动把那块她撞击的位置微微外推，则她笑了一声又一愣，绑定值 +1，日后她在追他时悄悄收敛了力道。
- 若林恩在思考智神考验时主动写下一句「如果我被迫选择，我会跟大家说」，则那句被左左保存进意识空间的某一段，等了很久后仍能被翻出来读。
- 若林恩在目视上千公里工厂时主动吐出一口气，则他的神经表层在那一刻共振出一道苦味信息波，但事后左左形容他「就像被吓到的小孩子一样」。
- 若林恩在数位神祇询问时主动披上黑袍给自己遮上，则他在最后一刻没有进入「同脸」的标准问答，让机械设计出来后续更多的数据交换。
- 若林恩在意识到「细胞反控」时主动标记一个更细的归属系统让左左和左萝也可扫描，则他们在星空中多了一份「如果真的走散也能联络」的内心守望。
- 若林恩在火山艳影下主动化出一对灵能羽翼为自己折跃，则他离开了整场比赛的焦点区域，但机械神教在后续半日对他这副「鸟之疾走」留下深刻烙印。
- 若林恩在敌机神教即将失控时主动演一出「我是来帮忙」的戏码，则他成功混进指挥圈，但后续被指两次「这几轮他太热情」，后续灼热导航的作者热度被下调。
- 若林恩在工业盆地解析信息时主动藏三枚夜医药膏回背包，则后续在火山战车区他用其中一枚救治了左左的右手。
