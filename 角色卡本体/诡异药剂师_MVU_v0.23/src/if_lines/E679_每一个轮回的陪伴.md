# E679·每一个轮回的陪伴·if线

- 若林恩在时间神王挥手展示画面前主动将自己指尖的罪火点亮一寸,则画面中苗苗所在的林地第一次被绯红色染色,时间神王会多看林恩一眼而不是只顾自己的叙事。
- 若林恩在看到画面初段时主动开口询问「这是哪一世的轮回」,则时间神王会屈指一弹把画面翻到更早的某世,林恩额外看到一段轮回神王尚且会笑的时年。
- 若林恩在苗苗说出「我就是这里的老大」那句画面时嘴角动一下,则时间神王会立刻捕捉到那一缕笑意,他后续所有厌倦论都会绕开这个细节。
- 若林恩主动问时间神王「你自己有没有像苗苗这样的存在」,则时间会罕见地陷入一段真正的长沉默,然后摇头,沉默的长度本身就是答案。
- 若林恩在画面中主动数出苗苗出现在第几世轮回的频次,则他会发现苗苗不在每一世都出现——有那么十几世,林地空着,而轮回神王仍坐在那块巨石上。
- 若林恩主动把三叉戟放到时间神王颈前时先压低一寸,则时间神王会把它解读为「犹豫」而非「威胁」,他提出交易时的措辞会第一次变得更诚恳。
- 若林恩主动选择完全不架起三叉戟、只静观画面,则时间神王会跳过战斗姿态直接摊牌,但他会在交易条件里额外加一条「你要替我看一眼林地的现状」。
- 若林恩在听到「你们三个从来都是一个人」时主动打断,则时间神王会罕见地收起笑容,后续所有解释都会绕开「你们三个」的措辞改用「你们两位」。
- 若林恩主动告诉时间神王「我不会为了一幅画面改变对这场交易的判断」,则交易仍被提出,但时间神王眼底的光会第一次出现一丝真正的失望。
- 若林恩在画面散去后主动追问苗苗如今在哪,则时间神王会告诉他们已经「永远留在过去」,但他会在说出这句话时把目光第一次从林恩脸上移开。
- 若林恩主动询问时间神王想带回的那个人是谁,则他不会直接给出名字,而是伸指在虚空写下一笔——笔迹与轮回神王画面的留白完全一致。
- 若林恩主动提出要在交易里加一条「你也要告诉我那场争夺的真相」,则时间神王会沉默片刻后点头,但他会在点头同时把绯红罪火的画面再现一次。
- 若林恩主动拒绝交易并转身离开时间长河之外,则时间神王不会拦他,但会在他踏出第一步时在后面淡淡说一句「你会再回来」,这一句将作为 E680 的悬念。
- 若林恩在时间神王重新化作银色太阳瞬间主动伸手触碰那层光,则光面会泛起一圈极细的涟漪,时间神王会在意识里对他说一句无声的「多谢」。
- 若林恩主动告诉时间神王自己曾在过去见过轮回神王,则时间神王会立刻反问是哪世,林恩的回答将成为他愿意把交易条件再加一条的依据。
- 若林恩主动把苗苗在画面里说过的某句话在时间长河之外低声复述一次,则画面会因此乍然复现一秒钟,那一秒里苗苗的眼睛首次朝林恩的方向望过来。
- 若林恩主动选择不立刻答应也不立刻拒绝,只提出「让我看一眼那个你想要我带回来的人的轮廓」,则时间神王会把虚空剖开一线,剖口深处立着一个披着绯红罪火的背影。
- 若林恩主动要求自己也不进入时间长河而是只在河外递话,则时间神王会指出这相当于让交易变成单向赌注,他会要求林恩额外押上一件信物。
- 若林恩主动告诉时间神王「如果你说的理由只是想见他一面,我可以考虑」,则时间神王眼底第一次出现真正的松动,交易条件会当场减少一条。
- 若林恩在画面里的苗苗与轮回神王并肩坐着那一幕停更久一拍,则时间神王会主动把那一幕的画面单独切出来递给林恩,这将成为林恩日后回想时手里唯一的实物。
- 若林恩主动提及自己也想知道「这到底是不是爱」,则时间神王会转头正视他一秒——那一秒里时间第一次把林恩视作对话者而不是工具。
- 若林恩在离开时间之外前主动朝那座虚空深鞠一躬,则时间神王会罕见地站立回礼,这是他漫长寿命里对林恩唯一一次的等位致敬。
