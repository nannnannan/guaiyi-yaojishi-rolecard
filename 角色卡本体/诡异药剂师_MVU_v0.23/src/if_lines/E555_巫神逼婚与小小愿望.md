# E555·巫神逼婚与小小愿望·if线

- 若林恩在巫神当众高喊「贤婿」时立刻逃离广场，则广场围观舆论把逃席解读为默认，契约符文的曝光在林恩缺席下继续发酵，巫神那边的声势更稳。
- 若林恩在巫神激活契约符文前就私下与巫神谈判，则符文没机会在广场曝光，小小愿望独立于外界把柄生效，逼婚喜剧被抽成家庭议事。
- 若林恩在符文亮起时立刻封印自己的眉心压住符文，则咒术神芒被林恩本人斩断，「泰坦灵魂契约」在众人面前只是一枚被主人按住的刺青，巫神把柄的物理权能被削一半。
- 若林恩在左左暴跳如雷时让左左先去陪小小而不与巨像之脑结成心脑同盟，则「反对」的分量变弱，巫神把柄的阻力少一层缓冲。
- 若林恩在跟巨像之脑击掌时多补一句「无论中文英文同盟就是同盟」，则心脑同盟的戏谑口吻被固化成双方字面协议，左左在后续起哄的余音更沉。
- 若林恩在巫神抛出「你敢当众大喊讨厌小小就作废」之前主动承认自己无法说出口，则杀招被提前按下，巫神的绝杀圈套无从显形，符文也被顺势搁下。
- 若林恩在巫神设局前提下当场站在城墙上喊出「我特别讨厌小小」，则符文作废条件被触发，但小小当天被哨声召回面对已作废的婚约，小女孩愿望窗口被结构性关闭。
- 若林恩在小小被砸到广场前主动传声「不要出来」，则小小缺席整场，独留林恩和巫神两人对峙，「不讨厌、一点都不讨厌」的起手没有接收人。
- 若林恩在小小坠地时当场用双手捂住自己的眼睛不看，则他没有被小小那双纯净大眼睛盯防线的机会，「讨厌」二字在物理层面无法被说出，巫神把柄击不破。
- 若林恩在小小问「什么是结婚」时主动改答「那是两个互相讨厌的人去做的仪式」，则误读方向被引导，小小当场皱眉拒绝，但长大后对此事的记忆更混乱。
- 若林恩在诱导推迟时只说「推迟一百年」而不用提议方式问小小，则小小丧失自主做出选择的位置，她的「好呀好呀」变成被动追随，先拒后要的弧光断裂。
- 若林恩在诱导推迟时不明确表态，仅含糊「以后再说」，则巫神不会和林恩扭打，她当场扬长而去，扭打喜剧消失但把柄未被服用。
- 若林恩在与巫神扭打时反过来赢她一局、将她按在地砖上，则完全没有被诱骗的定调，权责倒转，广场对林恩的观感从「渣男」变成「凶狠男人」。
- 若林恩在扭打中发出难堪的破音或怪叫，则围观的自缚天使和艾雯听到的不再是双雄争霸而是喜剧连场，公众观感倒向更明朗的幽默一方。
- 若林恩在小小拉住衣角时主动装作没听见小小要说话，则「医生哥哥……小小现在……想要结婚了」的开口时机被林恩本人错过，小小愿望延后到日落。
- 若林恩在小小主动要结婚时立刻关掉城门渐次检索小小说话的现实性，则他从「听清小女孩说话」转到「评估这份愿望的后果」，郑重度上升但喜剧质感下降。
- 若林恩在小小主动要结婚后向她提出条件「我们先经历一些共同的事再决定」，则林恩从根本不可能的人变成可能的人，小小不是拒绝或接受而是接受另一种委托。
- 若林恩主动在小小口中听到「只要我活着哥哥就永远都不会死掉」时刻意加固这份约定，则小小不再是「永远和哥哥在一起」的负担，而是「哥哥你活着的保护力」，共死语义被前置压缩成共生支持。
- 若林恩在小小主动要结婚后向巫神提议「我们两个先替小小决定一个未来仪式的日子」，则两个大人合谋跨过小女孩本人，小小愿望被当成可代理的家庭事务，她的主导权被去掉。
- 若林恩让自缚天使、艾雯在场起哄达成一致，则小小当众要结婚之后还遭遇熟人起哄，小女孩反而尴尬，主动或被动地把成婚诺言打上更沉的印记。
- 若林恩在小小主动要结婚时让左左和巨像之脑立刻一起发声共同反对，则心脑同盟成为一条新的协力线，小小愿望被共同的反对姿态压在外圈。
- 若林恩在小小主动要结婚时不当场承认也不拒绝、只是含糊说一句「我再想想」，则小女孩愿望挂起，巫神也不知下一步能不能下手，压力被推到双方。
- 若林恩在这个庄严的场合当众撒谎说自己不喜欢小小，则他在自身的罪恶感里藏下伪证，小小愿望在他的谎言内反向定格，婚约作废表面成立。
- 若林恩在小小主动要结婚后把巫神头颅紧紧抓牢不让她继续起哄，则起哄的终止取决于巫神的意愿，他从场面中撤离，小小愿望进一步被旁落。
