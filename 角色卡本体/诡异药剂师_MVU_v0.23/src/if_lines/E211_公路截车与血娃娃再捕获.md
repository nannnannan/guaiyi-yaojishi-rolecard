# E211·公路截车与血娃娃再捕获·if线

- 若林恩在大巴进入拦截区前先以白雾沿树林覆盖半公里路肩，则司机视线被压住、车速自动降到三十码，事件以不变形收束但截停瞬间的平民惊叫声少了一半。
- 若林恩改以触手从路面下拉断大巴油管而非手雷炸前轮，则车体不会翻滚、乘客无一跌落擦伤，事件以不变形收束但五名教徒失去混乱突围窗口被原地活捉。
- 若林恩让左左先一步缠上为首的教徒不让他举枪扫射车顶，则车顶那一排窟窿眼被避免，事件以不变形收束但左左首次在平民乘客面前显形。
- 若林恩在拖出最近一名教徒后改以触手封喉麻痹而非当场拽断四肢，则他留下第一个可审活口，事件以变形（先捕后审）收束，运输路线情报提前落地。
- 若林恩沿用原作一枪爆头一名教徒震慑其余，则剩下的四人立刻叠声供出"很大的房子"四个字，事件以不变形收束但林恩耳边留下那名教徒死前的咒骂回响。
- 若林恩不让任何一人当场被枪决、全部触手捆成一排留作活口，则五份口供相互校核、误差被压到最低，事件以变形（全捕审讯）收束，但后续押运人力必须现编。
- 若林恩在拖出最后一名教徒时顺手把一名被吓晕的平民扶回座椅打一针镇定剂，则平民心理创伤被压一档，事件以不变形收束但林恩的"疫医"身份首次在乘客眼中建立。
- 若林恩不亲自追血娃娃改派左左循骷髅币残响翻掘荒坟，则林恩能先行处理教徒与乘客，事件以不变形收束但血娃娃被拖回时抓伤挣扎更凶。
- 若林恩在掀棺那一秒先用燕尾服下摆把正午阳光挡住再把她拎出来晒三秒，则灼烧只停在她裙摆、不伤她本体，事件以不变形收束但林恩手中多一枚"她欠我一次"的筹码。
- 若林恩在她蜷进长棺之前先贴一枚咒纹在棺盖内侧，则她一合眼就被压得神志模糊、自己先开口招供，事件以变形（提前撬情报）收束，逼供戏份被压缩为零。
- 若林恩在血娃娃破口大骂"跟踪狂""无良医生"时冷静回一句"骂我就多晒十秒"，则她学会在嘴硬之前先算账，事件以恶堕调教收束，调教节奏停在口头威胁未上身。
- 若林恩把她从棺里提出后让她背对光沿公路走三十秒蚂蚁步才许进树林，则她在路人视野里被迫挂着焦黑裙摆沿街行进，事件以恶堕调教收束，她的自尊被压到第一次求他让她蹲下。
- 若林恩在她供出"很大的房子"后额外要求她画出沿途三个路标，则后续突入路线误差被压到一百米内，事件以不变形收束但她首次意识到自己真的可以带路。
- 若林恩把她脚踝的铃铛摘下暂存自己口袋作为"担保信物"，则她的悬浮逃生能力下降一档，事件以不变形收束但铃铛后续可被作为追踪道具复用。
- 若林恩赐给她一支啤酒口味药剂让她在供出情报后当场喝完，则她的怒气被她自己呛到，事件以不变形收束但"无良医生"标签在她心中多一层"还舍得给酒"的复杂。
- 若林恩在教徒尸体未被处理前让血娃娃亲手把祭品骷髅堆到公路旁作路障，则她以"劳动换不被暴晒",事件以恶堕调教收束，她首次触碰血肉神教的残骸层。
- 若林恩让左左抓起她怀里的洋娃娃单独审讯三分钟，则洋娃娃被动供出未参与教徒的名单，事件以不变形收束但血娃娃首次意识到她的玩具会背主。
- 若林恩顺着她"很大的房子"三个字直接冲向近郊的高塔，则她在被拖行中急喊方向错了，事件以变形（地理误读）收束，资源浪费十分钟。
- 若林恩在她指向废水处理厂方位后仍让她带路而不是扛在肩上，则她以悬浮姿态贴在他侧的飞线被沿途监控完整拍摄，事件以变形（公开同行）收束。
- 若林恩当场把她按在棺材盖上、以触手在她后颈写下一个临时咒纹作为合作誓约，则她无法不告而别、每离他一公里就被咒纹灼痛一次，事件以恶堕调教收束但调教清晰停在契约级而非身体级。
- 若林恩决定不带走她而是让她先去附近藏身等天黑再对接，则她首次拥有"被信任的喘息窗口"，事件以变形（延迟合作）收束，但教徒尸体与泄气路口必须由林恩先清理。
- 若林恩让她指认"运输线的下一波交接点"再出发，则情报链延伸到下级教徒，事件以变形（情报延伸）收束，但她撤回带路承诺拒绝配合突入。
- 若林恩把她按在燕尾服内袋里带走、让她全程紧贴他肋骨听他的心跳，则她在飞行途中被迫承受他胸腔内那枚恶魔核的低频震动，事件以恶堕调教收束但调教止于体感压制、未触性器。
- 若林恩让她在教徒供出的路线图上亲自按一枚血手印确认情报真实性，则她被卷入责任链，事件以不变形收束但血娃娃的事后掩护难度上升。
- 若林恩在五名教徒被制服后回到车旁向幸存乘客说一句"刚才是地狱里的恶魔内讧，不是袭击你们",则平民叙事被掰离"恐怖袭击"维度，事件以变形（公方沟通）收束。
- 若林恩当场把教徒枪械收集起来交给最先反应过来的乘客让他暂时看管，则乘客从"受害者"被掰向"协作者",事件以不变形收束但后续军方清点会多问一句这真的是乘客主动的吗。
