# E618·织梦现身与艾雯被带走·if线

- 若林恩在迎战织梦前先掷出一缕初诞者之力作为试探,则她会更早地识破他的实力,但「非本尊」的评价会更中立。
- 若林恩决定让血枢残魂全程记录这场战斗,则它会从中获得宝贵的强化数据,但吞噬欲望会更强烈。
- 若林恩在灵能爆炸中使用三叉戟直接冲向织梦,则她会以更精准的技巧反击,但「杀光整个文明」的指控会更极端。
- 若林恩让巨像在战斗外围布置一层「血肉祭坛」辅助,则她的存在会给织梦带来额外压力,艾雯被带走的时点会延后。
- 若林恩在织梦揭露「灵魂植入后门」时当场反驳,则她会以更多的证据佐证,艾雯的旧史会更彻底地被曝光。
- 若林恩选择撤退而非硬拼,则织梦会认为林恩示弱,后续对艾雯的处置会更残忍。
- 若林恩让银色幻想提前介入战斗并以战争机器封锁虚空,则织梦会动用「三位一体最终主导」的力量突破封锁。
- 若林恩在幻境中加入一段「初诞者记忆」作为干扰,则织梦会因旧识的情分而迟疑,魔法的威力降低。
- 若林恩把「未来的林恩」身份作为底牌透露给织梦,则她会露出更复杂的表情,「只有你才配当那位大君」。
- 若林恩决定让左左陪同自己进入幻境,则她会因灵能的干扰而受伤,但「左左之墓」的场景会被重新演绎。
- 若林恩在战斗中刻意让织梦看到「三位一体」的真实形态,则她会震惊,但「接受我为你的主宰」的要求会更苛刻。
- 若林恩选择在织梦挟持艾雯前先自爆一部分力量作诱饵,则她会因贪婪而多停留片刻,给林恩更多救援时间。
- 若林恩让血枢残魂见证他如何被织梦压制,则它会产生「我不如他」的自卑,后续合作意愿降低。
- 若林恩在幻境中使用「万物希望符」作为防御,则织梦会因它的神圣而迟疑,但灵能爆炸的威力更强。
- 若林恩决定让织梦看到他眼中的「未来」,则她会因命运的「无可改变」而放弃执念,「那边有你」的暗示会变淡。
- 若林恩让血枢残魂在关键时刻提醒织梦「你不是终焉之主的对手」,则它会更加警惕。
- 若林恩选择在杀死艾雯前先说服众人,则织梦会因林恩的决心而犹豫,「献祭」的场景会被改写。
- 若林恩在灵能爆炸后故意留下一个假信号误导织梦,则她会追捕一段错误的方向,但艾雯的安危更有保障。
- 若林恩决定让织梦了解到他对巨像的真正感情,则她会因嫉妒而加快挟持艾雯的速度。
- 若林恩把「紫罗兰之约」的地点改为另一处,则织梦会因不满而加速行动,后续冬泉谷事件的时点会提前。
- 若林恩让织梦看到自己与巨像的亲密场景作为干扰,则她会因嫉妒而失控,艾雯被救下的机会更大。
- 若林恩选择在战斗结束后向织梦索要艾雯,则她会条件回:「只要你放弃反抗」。
- 若林恩决定让渡鸦在夜晚为织梦唱安魂曲,则她会因「温柔」而心软,挟持艾雯的时间会缩短。
- 若林恩把「三位一体最终主导」的名号让给织梦,则她会欣然接受,「你的棋子」会变得更忠诚。
