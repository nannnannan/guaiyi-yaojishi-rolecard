# E245·三位一体揭露与左左复归·if线

- 若林恩在投影质问三位一体时用了一个委屈自恨的语气回复"我其实不想变的，都是被逼的"，则投影感受到一种可以感知和淡然怀古的姿态，反而对他产生了更复杂的愤恨与另一份合作意愿，事件以变形（投影恶性情势转暖）收束。
- 若林恩在左左即将归来时先主动给她按下"你回来啦"的按钮，而非等待她自己归来，则她被强行拉拢，事件以变形（左左主动却不感动）收束。
- 若林恩对心脏主意识做出如下解释"我让你拥有最高的权限与最耀眼的姿态"，则她在回归代操作能力之余更想提出一个需求"我想要争宠"，事件以变形（她开始争夺宠信）收束。
- 若林恩在灵能镇压时先安排血肉生物退去缩短唯一的距离，则双方交战距离瞬间拉近至数十米内，事件以变形（投影退且相应部署）收束。
- 若林恩用咒瞳试着感受一下压制的长相、借巨像之心的共鸣去观测，则他的灵能感知触及混沌深处，事件以变形（被诡神秘震慑）收束。
- 若林恩让超级感知装置不在哪怕一秒被感应到闪烁，则他的高阶灵能波动彼时被主母感知，又以这一件神秘物掌握神圣模型，事件以变形（主母现身）收束。
- 若林恩在被投影压住时对左左大喊出嫁的信号，则她开始被他数落，条约内容从无用的状态变成如何相互协作合作，事件以变形（左左默契响应）收束。
- 若林恩对三位一体同时通过器制机与脑智所说出同时的声明，则启动后一段时间内会产生极高的运算负荷与过载风险，事件以变形（更加复杂掌控流程）收束。
- 若林恩让三位一体在灵能行动之前允许弥赛亚好好玩味报复手段，则她在指挥时把灵能转投向寻求正义的礼仪，事件以变形（心灵及扫荡）收束。
- 若林恩让投影在镇压之后让左左自主地说出"这个铁家伙我开始喜欢了"，则她的好感讲到从未动摇的钢铁羁绊，事件以变形（有甜有情有铁）收束。
- 若林恩让机体一并学会心跳、之为此还在中央生产室放置脉动装置，则他启动的同时可以得回一些情感共振，事件以变形（心跳同步）收束。
- 若林恩用咒瞳测算出投影站立的弱点时才允许自己将计就计，则投影的防守大为鬆动，事件以变形（攻击死角打中）收束。
