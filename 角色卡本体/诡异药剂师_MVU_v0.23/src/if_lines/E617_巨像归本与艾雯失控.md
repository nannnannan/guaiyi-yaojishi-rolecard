# E617·巨像归本与艾雯失控·if线

- 若林恩在三个月重修期内多给巨像一轮「血柠炼骨」,则她的重组效率更高,但血枢会更频繁地呵斥「还不够狠」。
- 若林恩在血枢怒评巨像幼女形态时追加一句「那就换回巨人本体」,则巨像会当场变形,但这会让艾雯对她的好感度下降。
- 若林恩决定把巨像体内残留的悸动法则彻底抽离,则她会更早地开始偷修,恶化速度更快。
- 若林恩在血枢警告时安排巨像与左左同场,则两人会因争夺林恩的关注而争抢表现,山河幻境的修炼进度被拖慢。
- 若林恩把「三个月」期限写进山规并让巨像签字,则她会主动加速修炼,但「如触刀刃」的刺痛会更强烈。
- 若林恩让血枢在重修过程中多次否定巨像的进步,则她的自信心会倍受打击,突破界限的时刻会更艰难。
- 若林恩决定先帮巨像压下暴动的血肉神格再开始重修,则她的根基会更稳,但「血枢最残酷」的评价会降低。
- 若林恩在巨像突破界限瞬间再给予一次「三位一体」的冲击,则她的升华会更彻底,与玩家的共鸣更深。
- 若林恩让银色幻想提前介入重修并铸造一座血肉祭坛,则巨像的重组会更精准,但银色幻想与血枢的合作会有些摩擦。
- 若林恩在血枢责骂巨像时出面调解,则她会半怒地回应「你护着她,她早晚被你惯坏」,重修进度被延迟。
- 若林恩决定把艾雯也拉进山河幻境的观摩团,则他会因灵能的陌生而倍感压力,失控的伏笔更早埋下。
- 若林恩在巨像突破后禁止她再接触任何外来物质,则她的血肉之道会更精纯,但战斗时的变通能力会降低。
- 若林恩让血枢在深夜独自面对巨像的修炼,则他会忍不住感叹「你是我见过最特殊的」,师徒关系出现微妙变化。
- 若林恩决定把巨像的晋升仪式公开给全盟约,则士气会高涨,但「麻木自尊」的担忧会更重。
- 若林恩让左左在重修期代替血枢的角色,则她会以更温柔的方式指导巨像,效果等同于半神指导。
- 若林恩在血枢警告后立即给巨像服用一枚镇定初诞者精粹,则她能更快地平复,但依赖感会增加。
- 若林恩决定让巨像在山河幻境外先体验一次现实的战斗,则她的实战经验会更丰富,但突破界限的时刻会更晚。
- 若林恩把「血肉回归」的结果告知巨像本人,则她会当场落泪,「如触刀刃」的伤口会更深。
- 若林恩让血枢在重修中发现巨像体内有织梦的灵能痕迹,则他会立刻调整教学,防止被织梦察觉。
- 若林恩决定把「血肉之躯」化为林恩的私人图腾,则巨像身上的「三位一体」印记会更鲜明,但与玩家的同化风险更大。
