# E229·巨像之心灾变与灭魇魔投影·if线

- 若林恩在爆衣瞬间把燕尾服贴上自己胸腔而非丢地，则巨物膨胀时燕尾服被包进血肉内部，事件以不变形收束，但战后回收需切腹取出，死兆级咒器被血气浸染三日。
- 若林恩给左左灾变出的阀门从三五个改成七八个，则她在黑夜城那一端短时间内能量溢出打转，事件以不变形收束，但她的「工资」首次超发，守阵法力反哺到他身上额外 +10%。
- 若林恩在听到「诅咒」二字的瞬间当场放声大笑并就此停下折跃，则他正面接下扑来的九重梦魇，事件以不变形收束，但诅咒结算链路被整段压前。
- 若林恩让殖装鬼面尖啸者停在71而不到897，则血肉负荷维持低档，事件以不变形收束，但白雾不被尖啸吹散，魇魔的精神力扩展只是放缓没被切断。
- 若林恩在「动乱」命令落下之前改口「收声」，则数千鬼面尖啸者憋住一声不发，事件以变形（哑炮尖啸者）收束，魇魔察觉他底牌不实、狂笑着挣扎出锁链半秒。
- 若林恩在巨像之心轰鸣时同步引爆埋在蜀都市区的一台中型抑制器，则市内夜医集体昏厥换来巨象之力短暂翻倍，事件以变形（引爆保险）收束，蜀都市区后续三日被列为临时禁区。
- 若林恩在血肉暴动触发前夺下巨镰让触手缠成护腕，则他的裸身拳拳自带镰刃弧光，事件以不变形收束，但战后镰刀上的血气需三日调养才能正常净化。
- 若林恩把埋在废土下的心灵抑制器激活时机提前十秒，则魇魔投影在尖啸者齐鸣前被压向地面，事件以不变形收束，但他没时间从胸腔掏出触手缠绕，千台鬼面尖啸者的殖装环节被压缩一轮。
- 若林恩在轰出「血肉暴动——殖装！」时改念成「血肉暴动——见敌！」，则殖装成形态出现偏差：鬼面尖啸者全部集结成一张巨脸而非分布千台，事件以变形（一面千眼）收束，魇魔被一张脸吓懵一秒后即刻反击。
- 若林恩在战斗中让小眼萝持续吸吮不停止，则他在殖装完成瞬间持续被呲溜声包围，事件以不变形收束，但小眼萝吸收过多阀门养分短暂醉养，饲主需扛着她走半日。
- 若林恩顺脚把远处魇魔交战的最高峰踹碎一半，则山体滚石掩埋了他自己埋的一台小型震荡器，事件以不变形收束，但装置清单从70台减到69台，战后核对时多一笔「自伤一台」。
- 若林恩在「九重梦魇」黑兆扑来时掏出乌鸦臂章贴到额头，则臂章内的机械心跳与诅咒当场共鸣，事件以变形（乌鸦试诅咒）收束，他首次见识诅咒被乌鸦臂章短暂吸收的奇景。
- 若林恩在巨像之心轰鸣时把最后一支暴击药剂塞进自己嘴里，则「变秃变强」效果再次被触发，事件以不变形收束，但秃头形象+胸毛一并掉光，他此番亮相成一具「全秃血肉魔人」的荒诞画面。
- 若林恩在殖装间隙让左左对阀门远程供一波，则她隔着空间倒吸一口凉气，事件以不变形收束，但她对「饲主敬业」评价再 +5。
- 若林恩在尖啸者齐鸣前先安排左左从意识空间喂一块糖，则她的电流短暂掉进饲主胸腔拌入血气节奏，事件以不变形收束，但诅咒反扑前他首次心跳失序一拍。
- 若林恩用主动笔记往系统小窗里发一句「我帮白夜大叔报仇了」便暂存对话框，则日记在巨象震动下未发送成功，事件以不变形收束，但白夜大叔祭扫场面多添一行离奇未送出的草稿。
- 若林恩让殖装成的「巨脸鬼群」对着光柱方向做一次口型「白夜」，则万机之神探针远端抓到一段不符合物理常识的声形档案，事件以不变形收束，但被记录为「泣鬼咆哮」永久备注。
- 若林恩在坍缩一瞬让左左把阀门扭转出火花，则她的指尖被电得娇哼，事件以不变形收束，但她的血浆里多一笔高负荷带给她的轻微蛀痕。
- 若林恩在千台鬼面尖啸者齐鸣时主动朝它们做手势「不许偏五十米」，则声浪扇形收拢一线，事件以不变形收束，但数十公里外飞鸟少崩碎一片，蜀都市区玻璃完好率上升 30%。
- 若林恩主动在殖装前喝一支镇痛药，则他在爆衣全过程保持一个冷静的微笑，事件以不变形收束，但隐修会远端把「冷血魔人」标签打上更深一层。
- 若林恩在爆衣之后没有朝空中喊声，就只用肉身诉说，则事件以不变形收束，但观战的几十台探针无声把林恩的「沉默压迫」評级再次上调。
