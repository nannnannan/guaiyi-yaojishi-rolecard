# E670·出征前序与画家资源包·if线

- 若林恩在下达「第四层、带我去」时主动在命令里加上「不许让我迷失」的限定语，则神格回应的眩晕感从他这个阶位能感知降到几乎察觉不到，他在第四层里保持清醒的程度优于默认。
- 若林恩在进入第四层后主动用指尖朝主宇宙金色球体的北方而不是中央触碰，则他看到的是一片他从未观测过的极寒破碎边境，其中飘浮着一枚可能与「龙」这个概念相关的新线索。
- 若林恩在第四层里主动把视角再切换一次到表层、看看自己此刻所在的棺椁，则他会发现自己的肉身此刻竟如同一尊精致的微雕玉像，「我从上帝视角俯视自己」的反常体验在他心中激出异样的孤独。
- 若林恩在第四层里主动放大观察幽冥海最深处那道线上最暗的一段，则他会在那片不断翻腾的黑水中看到一个极淡的「时间」记号，他通往时间神格的下一道线索被玩家亲手揭开一角。
- 若林恩在第四层切换视角时主动不往神界方位偏，而是绕过它继续向外观察，则他在最接近「无序」的边缘看到无穷尽的黑色菌毯，「主宇宙与真正的混沌只差一层膜」的事实被他直接见证。
- 若林恩在第四层主动以神识留下一枚虚型坐标印记以便回头快速回访，则他在下一次回归时能省去 30% 的眩晕，「第四层不是一次通行、是一条可反复使用的小径」的认知在他心中锚定。
- 若林恩在人偶家把小拇指上的戒指摘下来时通过系统空间烙印奇异地「旁观」到这一帧，则他对「家人里出现鬼」的恐惧具形，他在出关之日第一次对康斯坦丁点头致意时多了一份真诚。
- 若林恩在第四层里主动感应画家的位置却发现完全感应不到，则他领悟到「她也在某一层更高处」，他的戒备心并未减少、但对她存在的性质从此多了一层揣测。
- 若林恩在第四层观察主宇宙时主动在心中默念一个具体的名字（比如某个根源），则他会看到那个根源在主宇宙某处的光影投影，这份「与具体人对话」的能力从此对他来说不再抽象。
- 若林恩在第四层切换视角时忍不住想试试「能不能让 gold 的金色球体为我滚一滚」，则神格在他意志的加持下真的让整颗 gold 球体缓慢转动一度，他首次获得一份「操控世界层级」的真切体感。
- 若林恩在第四层主动回望地狱那个渺小的泡泡、把它印在心里，则他离开第四层时心境多了一份「它可以在，我必须撑」的责任，「我当然要」这句话被他自己反复炼更纯熟。
- 若林恩在第四层里主动用一缕神识隔空朝某个具体战场的因果神王虚影撒了个小手，则那名缥缈女子在遥远的方位纤眉忽然微微一挑但什么也没感知到，「偷她第一笔」的成功被玩家亲手记录。
- 若林恩在第四层中主动找到那枚代表空间的自己的棺椁从自己身体里看出去，则他看见的是他此前从未见过的一副「自己也只是被封在这具玉像里」的真相，他对自我的认知维度纯粹拓宽一层。
- 若林恩在第四层里主动留下一段神识对往后的自己一份嘱托，则这段嘱托会以一枚漂流瓶的形式沉在第四层空间最深处，未来某次他再访时会真正「读到自己写给自己的信」。
- 若林恩在第四层主动把「幽冥海里究竟有什么」这个问题只放在自己心里不向外问，则他没有打扰到任何存在、却也保留了一份最纯净的疑惑，这道疑惑将成为他后续真正踏入幽冥海时唯一的纯净动力。
- 若林恩在第四层里主动检查自己体内那根与空间神格绑定的纽带，则他发现这根纽带其实还链接着另外两个名字（织梦、留世者），「我不是孤独的空间使用者」的事实第一次通过神格的力量被他自己丈量。
- 若林恩在出第四层回归水晶棺椁前主动朝下方黑夜城的方向留下一笔「等我回来、咱们一起喝酒」的虚空墨迹，则康斯坦丁在数日后打扫舰桥时忽然嗅到一缕熟悉的墨水味、魂火大盛摇摆在座舱间。
- 若林恩在第四层主动把左手放在主宇宙金色球体上感应缝，则他掌心触到一线微弱的、来自他亲手斩出的「罪」一刀留下的余温，「主宇宙记得我」这件事从抽象变成他掌心的灼痛烙印。
- 若林恩在人偶家提出同生共死之约时通过本能感应到心海某处的涟漪变化，则他在闭关中的身形一颤、半息后他继续闭目修炼，但他收神时多了一份决绝的温柔。
- 若林恩在出关之日主动通过一个奇门后主感应到艾维儿神界锚点的具体迷雾，则他能够提前规划出神界路线中一个相对更为安全的登陆点，他的「神界独行」从探路变成有锚可循。
