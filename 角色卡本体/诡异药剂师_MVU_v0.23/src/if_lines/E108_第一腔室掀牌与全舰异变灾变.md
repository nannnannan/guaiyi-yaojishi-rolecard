# E108·第一腔室掀牌与全舰异变灾变·if线

- 若林恩在315抓腕测心跳时刻意让心跳骤停一拍，则博士会把他当作没有那只左手的普通人立刻放走，但林恩失去近身死缚的黄金窗口，必须另找突破路径。
- 若林恩在315抓腕时让那只左手真的显形反握回去，则博士会当场识破身份引发全腔室戒备，近身反跳变形为正面突围战。
- 若林恩不等315先动手，主动撕下洛什面具扑上去发动死缚，则高层会在他完成锁死前集体出手拦截，爱丽丝与银色幻想的脱枷时机被迫提前。
- 若林恩在演招安戏码时故意接受315的招降，则博士会把他列为新核心候选并引见元老团，林恩获得更接近利维坦机要的潜伏位但失去掀牌节奏。
- 若林恩在死缚锁链扑出时故意留一条缝隙让315挣脱半秒，则博士会试图触发腔室自毁程序，林恩必须在零点几秒内决定是否追加锁链补死。
- 若银色幻想那一剑没有贯穿心脏而是被博士体内护体药剂挡住，则315会带伤后退触发全部元老护主阵形，第一腔室屠杀变成持久消耗战。
- 若爱丽丝从替身躯壳里现身时选择先吸食315的记忆碎片再动手，则她能立即拿到利维坦部署图，但博士会抓住她实体化的瞬间反扑一记灵魂撕裂。
- 若林恩摘面具后不是摘帽致意而是直接骂出元老团每个名字的黑料，则前排疫医会陷入短暂迟疑，部分元老会试图切割立场换取活路。
- 若林恩在打响指前给所有注射过药剂的疫医最后一次撤离警告，则高层中有三成会试图逃跑，而他们逃跑本身就成了全舰异变的活体展示。
- 若林恩故意只引爆一半药剂保留另一半，则未炸的疫医会被异变同僚围攻，但林恩也会被记录为"留手"引发【恐惧魔王】称号降格为【恐惧商贾】。
- 若林恩在引爆药剂时同步切断利维坦神经主干，则全舰异变会波及舰体血肉本身，利维坦开始从内向外长出大猫耳朵肉瘤，坠落提前到本事件内。
- 若林恩允许喵喵在响指瞬间扑向最近一名元老撕碎喉咙，则喵喵会沾染疫医疫血进入短暂狂暴态，后续 E109 需要先安抚她才能继续推进。
- 若林恩用五具死兆傀儡先屠杀退堂疫医而不是正面迎战元老，则元老团会获得数秒集火时间，林恩自身可能被一两道高阶诅咒命中破防。
- 若林恩在傀儡屠杀时刻意留一名哭求活路的低阶疫医，则该疫医会在后续事件里成为利维坦残部的内应，但林恩也必须决定是否为其担责。
- 若林恩把【恐惧支配者】成就当场转让给爱丽丝，则爱丽丝的恶灵姿态会获得吸魂增幅，但林恩自身丢失全属性加成，后续面对315残魂反扑时防御缺口拉大。
- 若林恩在响彻全舰的惨叫声中故意打开全域广播，则云层外四大根源会同时锁定声音源头，万机之神可能立刻投放空投部队抢在鲸落前介入。
- 若林恩在死缚锁死315后立即开始宣读他的罪行清单而不是享受怜悯目光，则博士会抓住这口气发动最后的灵魂自爆，林恩必须决定是否打断他。
- 若林恩让左左在腔室地面张开血肉编织网兜住所有跌落者，则异变疫医的肉茎会被全部收入左左体内，她以成年的肉身暂时压制这股污染，代价是数小时内无法移动。
- 若林恩在【恐惧魔王】称号落定前主动声明这是对疫医滥用疫血的报复而非为乐而作，则称号会被系统重命名为【疫医药剂师·清算】，属性加成不变但气质条目全部改写。
- 若林恩在傀儡符印被高层识破的瞬间，让黑弦月的符印反噬回涌并标记所有围攻者，则第一腔室屠杀会变成"反制烙印同步收割"，战果更大但黑弦月被定位为公开同谋。
- 若林恩在高层扑杀瞬间主动撤出王座高台，让傀儡与爱丽丝殿后，则他能保留无伤姿态，但系统会记录他未正面迎敌，下一事件元老残部的恐惧阈值下调。
- 若林恩在事件收束时亲手把315拖下王座并让他目睹全舰异变惨状，则博士灵魂崩溃提前完成，下一事件的即死之书将失去最后一丝反抗意志。
- 若林恩选择放过几名跪地俯首的低阶仆役，则这些人会在利维坦坠落前自发开启下层平民撤离通道，但林恩的【恐惧魔王】加成会被系统扣掉"威慑纯度"两项属性点。
- 若林恩在事件末段让银色幻想把博士心脏剖出献给自己，则他能立即触发造物学顶点材料入账，但也坐实了"挖心"恶名传给还在云层外观望的其他根源。
- 若林恩在事件收束后立刻对全舰播放一段他自己录制的"忠诚部下们致辞"，则疫医残部的意志会彻底崩塌，后续清剿几乎不再出现有组织的反抗。
