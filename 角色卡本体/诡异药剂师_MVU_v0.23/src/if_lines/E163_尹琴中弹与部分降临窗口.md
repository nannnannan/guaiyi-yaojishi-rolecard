# E163·尹琴中弹与部分降临窗口·if线

- 若林恩隔着裂隙先把一缕信标血肉精准呼在白逸脸上再扣腕，则白逸被糊得瞬间呛咳、本能认出那根熟悉的烂肉，献祭咒语被呛断一半。
- 若林恩不扇大逼斗、直接把白逸整只腕骨捏得咯咯响拖近裂隙，则「电影看多了是吗」金句被换成一声钝响，白逸哭喊对象从「大哥」降级成「哥我错了」。
- 若林恩从裂隙中探出的不是手而是一根顶端带眼球的细长触须、先在白逸面前晃一圈，则白逸险些把它当成聚合体新一波攻击、几乎断腕自斩。
- 若林恩响应召唤但刻意只送出声音、不送血肉，则地狱那侧补足能级的机制被中断，裂隙边缘塌缩，尹依刚刚被绞吞的魂尾又多碎一分。
- 若林恩在扇完大逼斗之后顺手把白逸脸上血浆抹匀当战术迷彩，则他从「绝望献祭者」变成「被自家大哥糊了一脸血的小子」，聚合体的亡魂队列短暂被这滑稽一幕干扰。
- 若林恩的深渊巨口吞聚合体分身时故意留一颗魂珠在齿缝里嚼，则「我的祭品呢」台词变成含糊的口齿不清版，白逸愣在原地忘了下一句。
- 若林恩没有回答「刚刚被他吃了」，直接操控白逸的下巴替他指向聚合体，则合作默契标志首次打上，白逸的下颌骨在林恩掌心微微发烫。
- 若林恩主动用触手接住第一波「亡魂齐射」的子弹搓成一颗铁丸子反手弹回去，则受控调查员亡魂队列首次出现逃兵，聚合体咆哮声里第一波阵型破口。
- 若林恩把嵌入眉心的子弹抠出来时不嫌脏地嚼碎吞下去、倒吸一口凉气感慨「蓝星的火药口感比地狱差远了」，则亡魂军团控制链路集体多一段颤波。
- 若林恩只让一只眼的视界切入裂隙看清尹琴血泊位置，则他第一时间知道尹琴的真实伤程，急救窗口时钟在他意识里先一步开始走。
- 若林恩让部分降临体的眉心、脸颊、脖颈三处枪眼不抠子弹、留着它们嘚瑟，则聚合体误判林恩「能被物理伤害」，后续指挥方向整体偏错。
- 若林恩从喉咙里抠子弹时顺手把卡在声带的一枚递到白逸眼前，则白逸沉默接住、首次亲身体会「蓝星亡魂武器对高等夜医只是异物」的落差。
- 若林恩部分降临体的下半身始终不出裂隙、只把触手扎根当成固定点，则他可以执行「锚定信标」姿态，裂隙关闭速度被硬生生拖慢一拍。
- 若林恩在夺取亡魂控制权前先反向咳一声、用气音唤一句尹依的乳名，则被吞的尹依残魂在聚合体腹中反应性一缩，分离难度后续略降。
- 若林恩决定先把聚合体叼进嘴里不吞、含着跟白逸摆龙门阵，则聚合体在他齿间惨嚎三分钟，亡魂指挥链路全程瘫痪到 E164 开场。
- 若林恩没有选择大逼斗而是直接弹白逸额头一记脆响，则屈辱程度+10、白逸鼻血长流，但「黑化路线」被砸醒速度反而更快。
- 若林恩在聚合体嘶吼「他出不来的」瞬间故意又挤了半只肩进来，则画面从「部分降临」滑向「你再吼我就真的越爬越出来」，亡魂集体后退一米。
- 若林恩的部分降临体在裂隙边缘故意多卡三秒、用骨节把裂隙撑得咯吱响，则后续「触手延展村庄」活动半径扩大，但裂隙稳定性下降、必须在 E164 早起内收兵。
- 若林恩在撕吞聚合体分鬼时刻意避开那只曾吞噬尹依的主魂刺，则主魂刺得以保留，后续可被交易作为「分离尹依的素材」。
- 若林恩放任聚合体指挥残余亡魂朝自己齐射一整轮不闪，则所有弹着点愈合为死肉瘢痕，视觉恐怖先到顶、白逸战意大幅提升。
