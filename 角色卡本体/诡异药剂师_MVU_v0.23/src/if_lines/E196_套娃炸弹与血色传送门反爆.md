# E196·套娃炸弹与血色传送门反爆·if线

- 若林恩在切开第一层铁箱后停手用咒瞳先扫一遍内部，则第二十九层的血浆波动提前暴露，套娃整层被林恩改用夜魔刀沿缝撬开而不触雷。
- 若林恩让左左从自己肩头探出脑袋陪他一起开箱，则她每剥一层就咬一口箱板吐掉，几十层箱壳被啃出一圈牙印，套娃骨灰级怨气分散成儿童餐。
- 若林恩剥到第十层时把箱子整体倒过来狠抖，则最内层礼盒连带着投影仪哗啦掉出来，倒计时在落地前已被他脚尖踮住。
- 若林恩在按下投影仪按钮前先把镜头对准白夜，则全息画面里第一个特写是白夜的死鱼眼，公开处刑变成双人同框。
- 若林恩在投影仪播放录音途中强行抢镜清嗓重述，则全息演变为「林恩解说版」，根源大殿里巫神咯咯笑地把这版录下来存档。
- 若林恩在「卧倒」口令响起瞬间没卧反而向前踏一步，则夜医全部扑地只剩他一人原地站立，270 度全垒打的挥镰弧线被他自己调高两度。
- 若林恩改用左手直接攥住炸弹血肉囊体而非挥镰，则以M 在掌心炸开被他自己强行吸收，教堂正厅毫发无损，林恩的涩涩度直接冲过红线。
- 若林恩让左左张嘴把炸弹囫囵吞下，则左左肚皮像气球一样鼓起来三秒又被她一声嗝打回去，爆炸冲击反过来震碎她一颗牙。
- 若林恩把炸弹用咒线吊在头顶三米高处不挥棒，则倒计时结束时炸弹在半空开花，教堂外墙被气浪掀下半面但传送门正好错过。
- 若林恩改从教堂侧窗把炸弹丢进地下室走廊，则爆炸点偏离正厅三米，血色怪物探头时被气浪掀飞但没把炸弹咽进嗓子。
- 若林恩在挥镰前对罗斯特方向喊一句「开门你接好」，则罗斯特在咒阵边本能抬头，血色大门的开门节奏被那一嗓子打乱半拍。
- 若林恩不挥镰反把炸弹高举过头顶，则白夜从地面飞扑上来抱住他的腰往下压，全垒打变成保龄球滚入教堂门口门槛。
- 若林恩挥镰命中炸弹的同时让左左伸出触手拉了一把弹道，则囊体拐了个弯从教堂正门斜飞进地下室，正门怪物探头与炸弹错身而过。
- 若林恩在挥镰空隙给弹幕一个特写投射回自己，则全息画面里他以挥棒姿势定格，事后巨像之脑在大殿里反复回放这一帧咬牙。
- 若林恩在爆炸冲击波前先把左左藏回体内独自硬抗气浪，则林恩被掀飞三米砸进黑雾，左左完好无损却被禁言半分钟。
- 若林恩在血色大门开启瞬间用地狱视角反向窥视门内，则血肉指挥官先看到他那张特写，咒骂词从「你背叛」临时换成「你是谁」。
- 若林恩在罗斯特辩解「这是意外」时命令夜医同步公放求援录音，则罗斯特的辩解与林恩的讨要经费全息混剪，血色指挥官彻底断线。
- 若林恩在血色军团集火罗斯特时抓住断臂落点就把那截手臂抬走，则断手在战利品袋里抽搐半宿，罗斯特返回结界的时间被拖后十秒。
- 若林恩走到传送门废墟中央叉腰夸耀「我打的」，则血色世界另一侧的眷属在其视野里给他建档一个新的代号「球场恶魔」。
- 若林恩当场折跃一颗新的牧师咒钉进传送门余烬，则余烬被钉成一面静止画面，后续拆解有余地，但传送门崩塌延迟三十秒。
- 若林恩在夜医收集爆炸残肢时让左左先咬一口再封袋，则证物整体减少三成但左左的暴食记录在古堡档案里加一条「战场就地取材」。
- 若林恩把整场反爆的功劳在战后简报里全推给「艾雯大哥的大礼」，则艾雯爵士收到感谢信附带投影回放，苦笑回信只写一句「下次别搞这么大的」。
- 若林恩在血色军团误判罗斯特叛变后朝罗斯特喊一句「感谢配合」，则罗斯特情绪彻底崩坏，残躯撞向结界内壁多了一道裂纹。
- 若林恩在罗斯特断臂退守瞬间不去追击反倒递给白夜一支肾上腺素，则白夜愣神一秒接过来扎进自己胳膊，夜医总攻的节奏整段后延。
- 若林恩在爆炸扬起的血雾里顺手以M 反向吸收飘散的生命力，则系统啃出一行【涩涩度-50】的提示，他吸完转身才发现裤链崩了。
- 若林恩让崩塌的血色裂隙保留最后一道缝而非彻底粉碎，则一枚小型传讯符从血雾里飘出落在他掌心，血肉支配者的注视在那头的眼底亮了一瞬。
