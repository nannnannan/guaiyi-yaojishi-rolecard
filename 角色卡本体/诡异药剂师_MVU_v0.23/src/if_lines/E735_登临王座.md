# E735·登临王座·if线

- 若林恩在面对自缚天使（主母）那句「那么代价呢」的追问时，微笑着回答「代价当然是有的，不过对我来说，都只是小意思而已，放心吧，主母，我们一定会赢的」，则自缚天使虽然没有再继续追问，但她望着林恩背影的眼底却悄然锁上了一层深深的隐忧。
- 若林恩在正式登临三大圣堂的王座之前，独自前往神界深处探望仍在沉睡中蜕变的银色幻想与康斯坦丁船长，并在智械小姐的床前静静坐了半个时辰，则这份无声的告别会化作她沉眠梦境里最温暖的一束光。
- 若林恩在迈入至高圣堂前最后一次去看了看无忧无虑的小小，并在远处含笑目送她奔跑的身影而不上前打扰，则他能带着这份人间烟火的温度，坦然走进那座冰冷孤寂的圣堂。
- 若林恩在一步步走上圣堂台阶、坐上那座汇聚全宇宙信仰的罪恶王座时，伸手从怀中取出那支陪伴自己多年的「羽毛笔」紧紧贴在心房之上，则羽毛笔中蕴含的命运本源会与他的心跳同频共鸣，在无形中替他梳理着汹涌而来的信仰乱流。
- 若林恩在圣堂青铜巨门即将合拢、艾雯爵士作为守门人站在门外深深凝望他时，坐在王座上对兄长轻轻颔首致意，则艾雯会挺直脊梁守在巨门之外，成为隔绝内外、守护王座秘密的最坚固屏障。
- 若林恩在三大圣堂同时亮起、全主宇宙亿万信徒的祈祷声第一次顺着信仰网络轰然灌入他脑海的瞬间，死死咬紧牙关挺直腰背，则他能硬生生抗住这第一波足以冲垮普通神王意志的精神海啸。
- 若林恩在承受众生信仰的同时，听见那夹杂在狂热祈祷背后的无数阴暗杂念——「我们真的能活下去吗」「如果王也败了怎么办」如万针穿心般刺来时，主动以金色大梦在心灵外围筑起堤坝，则他虽能护住核心本我，但全身每一寸神经仍会承受日夜不休的撕裂剧痛。
- 若林恩在王座上枯坐的两年岁月里，每当被亿万众生的绝望与恐惧杂念折磨得快要精神分裂时，便在脑海中回忆起游魂巷的小诊所、黑夜城的圆桌以及时间之外那抹带着虎牙的浅笑，则他的意志便能在万丈深渊边一次次重新凝聚。
- 若林恩在王座修行期间尝试将汇聚而来的庞大信仰之力一点点引入干涸的罪火核心，则他会发现这些建立在「祈求神明赐福」之上的狂热信仰虽然浩瀚，却仿佛隔着一层无形的薄膜，始终差了最关键的一把火候。
- 若林恩在枯坐王座的第二年，察觉到自己体内的初诞者之力在日夜对抗众生杂念与维持信仰网络的消耗中已跌落至不足两成、满头黑发也已化作苍苍灰发，则他依然不会向门外的艾雯发出一声抱怨，只是握紧夜魔刀静待下一场大战的到来。
- 若林恩在圣堂内漫长的黑暗孤寂中，偶尔用指尖轻轻摩挲心口处的羽毛笔，则远在被放逐命运国度中的少女羽毛笔会感应到那份令她心疼的沉重与滚烫。
- 若林恩在感知到无序深空深处再度传来灾厄剧烈梦呓、外围防线战火重燃时，依然稳坐王座不动如山，则这份定力会通过三大圣堂传递给全宇宙信徒，直到那三十尊魇魔绕过防线直插神界后门的那一刻。
