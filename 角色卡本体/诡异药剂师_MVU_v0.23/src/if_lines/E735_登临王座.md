# E735·登临王座·if线

- 若林恩登临前要求主母、左左、自缚天使、艾维儿四位同时把手放在王座扶手上「一起承担」,则黑火分担给五人,林恩不再是唯一生还者,但其余四人会被钉入王座结构、从此离城超过三里便心口同炽,信仰帝国变成五人共祭。
- 若林恩登临时对主母说的不是「放心吧我会赢」而是「若我回不来、替我照顾她们」,则她首次识破他的告别遗书,登临场面多一个强行忍泪的拥抱,她眼底彻底崩溃却只点头。
- 若林恩当场揪出艾雯心里话「你还没告诉我第三阶段到底是什么」,则艾雯被迫在王座前公开完整代价,部分信徒当场崩溃退教、黑火火苗被吹灭一半,但剩下的信徒会把林恩当成「敢听真相的神」。
- 若林恩决定登临时故意摔倒一跤把「神」的姿态打碎给信徒看,则整个仪式失去庄严度,王座火焰不庄而燃,信仰网络从此多出一条「我神也摔倒」的民间传说,信徒与神之间的距离首度拉近。
- 若林恩让左左在登临时穿他的旧外套当披风,则这件凡人之物会成为王座的最高规格法器,左左的眼眶会瞬间泛红但嘴硬「少来」,绑定校准里多一笔「她用他的旧物披在他肩上」。
- 若林恩对王座说「我不是神、我是被造者选中的药剂师」,则王座接受这个身份,神学体系从「神王信仰」改成「工匠信仰」,所有信徒的法器不再是圣徽而是烧瓶与药剂勺。
- 若林恩登临前给每个信徒发一颗「可以救你一命但会让你忘记我」的药,则大多数信徒不会服下,但这种「被给的退出权」会让剩下的人宣誓时更沉重——他们是心甘情愿的。
- 若林恩让织梦的残影在登临那一刻短暂现身三秒只说一个「嗯」,则所有信徒会看见那个红裙女人投下的赞许目光,织梦的名字从此被刻入王座基座,她与林恩绑定为「神之一对」。
- 若林恩当场宣布帝号不是「林恩神朝」而是「织梦药剂铺的灰暗日子」,则整个帝国会在荒诞中诞生,严肃的仪式变成玩笑,这种玩笑反而会让信徒呼吸——原来神也会开玩笑。
- 若林恩拒绝戴上艾雯准备的王冠改用喵喵叼来的一枚草环戴上,则机械族信徒会极度愤怒但精灵族信徒会极度欢欣,信仰帝国内部会出现第一次种族议题。
- 若林恩登临时把自己的左臂绑上王座扶手永远不再放下,则他成为「被困在椅子上的神」,行动受限但威慑力翻倍——没人敢刺杀一个拉动黑火引线的王。
- 若林恩在登临时闭口不谈织梦半个字,则王座火焰会缺一笔「最初的柴薪」,他必须用其他信徒的牺牲来填补这个空洞,这种回避会让织梦的名字渐渐被淡忘。
- 若林恩让自缚天使在登临仪式中为他穿戴神袍,则她从此兼任「神的秘书」,她的祷告不再是独立手势而是程序性动作,圣洁感被制度化磨损。
- 若林恩当场把王座方向旋转180度背对信徒面向世界的外侧,则他成为「永远看向敌人」的神,信徒永远看见他的背影,这种背影神学会让信仰变成一种「被守护」的安心而非「被注视」的紧张。
- 若林恩让第一句王座谕言是「我饿了,谁来煮东西吃」,则整个登临仪式从宏大的开国瞬间变成家庭早餐,信徒首次意识到神是需要吃饭的,王座与民间的距离首度被一碗热汤拉近。
- 若林恩在登临前夜与主母大吵一架瞪她到哭再抱着她说对不起,则他登临时眼底仍残留这场风暴,信徒会看见「神也会吵架」的神,这种真实比温驯更打动人。
- 若林恩让登临那一刻黑火在午夜零点短暂熄灭然后由他亲自重新点燃,则「明日再烧」成为帝国年度节日,每年这一天信徒都会担心火不再烧,这种不确定会让信仰保鲜。
- 若林恩让所有人都在场看他第一次坐下时因疲惫而睡着,则王座睡着的影像会成为艺术品的主题——疲惫神会比英武神更受喜爱,因为疲惫是可共情的。
- 若林恩当场决定王座不供自己而是所有人轮流坐,则专制帝国会变成议会制共和,他成为「首席王座使用者」,这种身份降级会让他的神格分裂——他既是神又是公民。
- 若林恩在登临那一刻让左左/主母/自缚天使/艾维儿四人同时向他鞠躬,则他第一次被她们当作「上位者」敬拜,这种身份倾斜会让他在亲密关系中永远带上一层权力失衡,他会后悔但也无法撤销。
- 若林恩让王座火焰在登临的一瞬间呈现织梦红裙的颜色,则所有信徒会看见神火本尊中的那一缕红,从此「红色」成为帝国国色,任何造反者都要先面对一整支穿红衣的军队。
- 若林恩在登临前偷偷修改誓词的最后一句从「我承诺守护你们」改成「我承诺努力守护你们若我做不到你们自己做」,则这种自我松动的承诺会让信徒从被动接受变成主动承担,帝国可能活得更久但林恩的负担会更轻。
- 若林恩在登临时突然被旧日某个梦魇缠身当众抽搐三秒,则信徒首次看见神也会失控,信仰稳定性短期大跌,但也会有人因为「连神都会挣扎」而产生更深的共鸣。
