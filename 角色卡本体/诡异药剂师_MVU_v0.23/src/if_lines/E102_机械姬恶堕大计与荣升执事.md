# E102·机械姬恶堕大计与荣升执事·if线

- 若林恩把恶堕计划主讲重点放在欲望教派那批重器而省略精神殖装环节，则315博士会追问他如何突破机械姬的意识防御，林恩必须现场补一段方案否则授权等级降半级。
- 若林恩没有把「策反夜医」作为收尾卖点而只强调当众处刑，则315博士给的奖励会缩水为基础执事头衔，不会附加黑颅币与经验加成。
- 若林恩当着第一腔室全员主动请缨出演那个精壮大汉，则疫医们的退避会变成狂热掌声，他被直接锁定为出镜人选，事后无法反悔改派。
- 若林恩把出演人选推给某位特定队长而这位队长拒绝，则315博士会顺势让林恩「以执事身份强制调度此人」，埋下一条内部仇怨支线。
- 若林恩在演讲时刻意淡化羞辱万机之神的部分、只强调镇压机械姬，则计划会被定性为「军事方案」而非「宣传战」，外层空间直播环节会被砍掉。
- 若林恩提出直播收益分成的具体比例而不是笼双说「赚外快」，则315博士会额外批一条物资通道给他，执事经费池扩容。
- 若林恩在委任状到达前就向部下许诺心腹位置，则这段对话会被血肉墙壁记录传给315博士，好感度加成变成猜忌度起步。
- 若林恩拒绝在委任状上签「洛什」而坚持签真名，则系统会立刻提示身份冲突，执事头衔被冻结，事件走向必须在伪装与暴露之间二选一。
- 若林恩主动要求把一级授权期限写成「直到机械姬伏法为止」而非默认的开放式授权，则在计划失败之前他无法动用执事资源做任何私事。
- 若林恩在恶堕方案中要求加入以M连续灌注的调教日程表，则系统会额外生成一张「执事私密实验室」解锁卡，机械姬的意识崩溃倒计时被缩短三分之一。
- 若林恩把「让机械姬欲死欲仙」的执行人限定为自己亲手操办而非外包，则他获得对机械姬身体数据的完整读写权限，每晚必须亲自到场一次否则进度倒退。
- 若林恩提出让多名疫医轮班执行调教以加速崩溃，则机械姬会对「夜医」面孔失去唯一锚点，恶堕后的认主对象变成随机，后续策反剧本失效。
- 若林恩在计划中安排机械姬保持一丝神志全程清醒观看自己恶堕，则万机之神会在直播瞬间强冲利维坦外层防线，事件急转为正面遭遇战。
- 若林恩要求把直播镜头做成分段付费、按恶堕进度解锁，则黑暗世界黑市会涌出大量山寨剪辑，机械神教的社死范围被放大但利维坦版权收益被稀释。
- 若林恩在向315博士述职时额外提交一份对艾雯爵士的连带羞辱方案，则博士会要求他同时兼任两条战线的宣传负责人，林恩的时间被强制切碎。
- 若林恩接受执事头衔但婉拒一级授权芯片的植入，则他保留随时抽身的退路，代价是每次调度资源都要当面找315博士盖章。
- 若林恩把授权芯片植入后立即用权限调阅左左与喵喵的入利维坦检疫记录，则他会发现两人已被打上「执事私产」烙印，短期内无法移交他人。
- 若林恩把上任第一件事定为视察机械姬囚室并要求单独会面，则他在正式调教开始前就能与她建立一段不为外人所知的对口供词。
- 若林恩上任后先办公开仓、给底层疫医发抚恤，则「洛什执事」的名声从狠毒转为恩威并施，后续查抄殖装工厂时部下愿意替他挡枪的比例显著上升。
- 若林恩上任第一天就点名某个第一腔室元老当面对质旧账，则该元老的派系会在计划推进期间暗中给他的执行队穿小鞋。
- 若林恩把315博士的「提头来见」回赠一句「博士的头我先存着」，则现场哄笑中好感度再涨，但系统会标记一条「以下犯上」隐性记录。
- 若林恩切断链接后没有立刻签字而是先与左左密议半夜，则左左会给出一份「执事特权滥用清单」，翌日签字的委任状自动附加几条灰色操作空间。
- 若林恩在签约笔尖一落就顺手把身边的呆滞下属改名为「大狗腿子一二三」，则这些疫医的系统标识被强制改写，他们在利维坦内网再无以原名登记的渠道。
- 若林恩掌事当晚就用一级权限调来一瓶高浓度以M试作型放进自己私柜，则系统会记录一次「物资挪用」，额度虽小但触发后续审计支线。
