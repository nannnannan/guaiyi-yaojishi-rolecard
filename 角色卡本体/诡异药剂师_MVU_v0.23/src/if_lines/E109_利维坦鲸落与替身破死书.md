# E109·利维坦鲸落与替身破死书·if线

- 若林恩在诅咒清除前先通知黑弦月与人偶小姐撤离坠落轨迹，则银白净化沿利维坦血肉纹路照常崩解，但友方规避了鲸落末日压砸，事后与利维坦残骸物资回收通道更顺畅。
- 若林恩放弃"听死灵说话"演讲、直接沉默净化，则利维坦的长啸仍在血肉深处回荡，但古神残魂对林恩的悲悯回应减弱，后续拒魂之路不一次性开放。
- 若林恩用咒瞳透视利维坦神经根须、锁定缝合主轴后定向净化，则血肉崩坏顺序精准，坠落轨迹被引导至预设无人海沟而非随机地面。
- 若林恩选择在利维坦坠落前先破开主控室外壁让疫医高层目睹净化全程，则疫医阵营当场陷入指挥断层，但万机之神远端信仰标记提前确立。
- 若林恩保留旧怀表不合上、改用倒计时声作掩护，则315博士无法读出净化发动的瞬间征兆，替身破死书节奏更可控，但系统提示出现的时机需要林恩即时口播。
- 若林恩在被死书死亡红光笼罩前主动服下缓解生命参数衰减的解毒剂，则"洛什"躯壳不瘫倒、可继续演戏，但315博士识破替身的概率上升。
- 若林恩拒绝让替身赴死、执意以真身接死书红光，则死书死亡改写作用于真身，需消耗替死娃娃一次复活才渡劫，鲸落完成的因果不变但代价沉重。
- 若林恩声明在斩首一瞬刻意破碎熔断灵智、让替身头颅不再"回光返照"，则315博士安然以为成功，触发"博士狂喜后被反杀"的分支通道。
- 若林恩在替身脱口而出"博士，这不礼貌"台词前提早收回神经链接，则回光返照只到半个语气词，场面更显诡异，但博士反扑节奏放慢。
- 若林恩改让替身躯体被斩首后立刻自燃毁尸灭迹，则315博士无头颅可验，疑心在事后慢慢发酵，最终识破时点延后。
- 若林恩决定真身从培养槽破出时未披夜医装备、以赤裸姿态直面博士，则压迫感与羞辱度更切近博士审美与恐惧，但夜医科技感视觉伏笔削弱。
- 若林恩不从利维坦内部培养槽钻出、改由外壁破口破海而入，则真身抵达时间延后，博士有自爆或找援军的窗口。
- 若林恩选择让利维坦血肉尸体完全崩塌露出古神骨架真容，则疫医高层在坠落深渊前已能看见他们所倚仗的巨物是尸身上挂上形态的改造物，疫医信仰根基动摇。
- 若林恩把《看了就会死的书》在死亡红光中由替身躯体强行合拢，则死书副本反噬到博士本人，博士当场枯朽一半，事件变形为"博士重伤与替身合体破书"。
- 若林恩选择在博士扑向替身头颅那一刻声明用束缚缠纹锁死博士手腕，则斩首动作被打断，替身不必熔断，但博士反攻爆发更猛。
- 若林恩决定死书死亡红光仅作用于在场某一具死兆傀儡而非替身本尊，则傀儡当场溃解但替身保全，鲸落与破书因果链不变。
- 若林恩在利维坦坠落时主动拉着博士一同坠地，则深渊塑造后博士需坠落重力反噬一次，但林恩也承担坠落对冲伤损。
- 若林恩声明以情欲反向干扰死亡红光的视线聚焦，则替身在红光中保形，但夜医性调剂与灾变现场氛围产生冲突，需要林恩自行承担节奏差异。
- 若林恩不审问博士、选择在利维坦解体前便用夜魔刀斩首，则E110刑讯前置姜南条件变形，主宇宙剧情转为和黑弦月有关的开颅回溯。
- 若林恩把鲸落坠落轨迹引导至地下新城隐藏集市之上，则疫医老巢一次性受创，利维坦血肉物资砸向疫医高层，主母双魂附近防御体系出现裂口。
- 若林恩在真身破水时让喵喵同乘，则喵喵即将到来的单分子剑钻孔戏份由本人亲自上场，但需承担与博士正面交锋时的三连反击。
- 若林恩把"洛什"替身设计为可在死亡红光中反复复生的血肉组件，则博士斩首动作连续失败三次以上才识破替身，剧本嘲讽度大幅上升。
- 若林恩让利维坦残存血肉主动爬回第二腔室报信，则主母与269博士提前掌握死书失效情报，E110刑讯口供质量直接下降。
- 若林恩选择不刮开古神骨架、不净化利维坦真身，仅以诅咒清除封印利维坦行进，则鲸落因果未成立，事件变形为"利维坦囚禁与博士反扑"。
- 若林恩在破水走出的真身姿态保留了部分"洛什"形象，则博士识破与失败叠加产生精神崩溃级认知错乱，后续审问接触门槛低得多。
