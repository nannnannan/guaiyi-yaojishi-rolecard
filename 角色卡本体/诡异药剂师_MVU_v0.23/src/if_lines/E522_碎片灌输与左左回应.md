# E522·碎片灌输与左左回应·if线

- 若林恩在左左扯袖口时主动牵她手而不是并肩走，则走廊气氛从「会后严肃」变成「伙伴关系」，灌注法提议的接受度略升。
- 若林恩决定不说「一体双魂不需要珠」的反话，则左左可能抢先要求一颗玻璃珠并开始尝试，灌注法窗口延后。
- 若林恩在抛出「灌注法」措辞时换成「渡灵法」或「融合功」，则左左的联想路径改变，理解过程出现别的误会。
- 若林恩选择让左左不要变成人形而是在左手形态下尝试灌输，则方法可能失败或者部分生效，但表面尺度降低。
- 若林恩在响指转场时选择不变回房间而是带她去某处空旷地，则「黑夜城房间床榻」的氛围隐私度下降，后续羞愤场景无法展开。
- 若林恩决定让左左看见珠圈排列再决定是否接受灌注法，则她的判断过程更慎重，但「被诱导」的叙事逻辑弱化。
- 若林恩在左左意识到「被绕进去」时主动坦白「对就是诱导你要成神的话听我的」，则她从被动转主动参与，道德账目重新划分。
- 若林恩选择在「没有错我就是要测试机型」时让她严肃反问而不是玩笑，则气氛从轻快转向沉重，「主人」称呼的暗示消失。
- 若林恩决定让房内灌输窗口过程更短，则事后左左的疲惫反应减弱，「吐沫」与「咬人」的羞愤戏份压缩。
- 若林恩在事后用「我们的关系不一样了」代替「你要当挂件」，则左左的反应可能从愤怒变成不安，关系定义改写。
- 若林恩选择不让左左在飞向罪孽城时「呸呸呸」吐沫，则她的羞耻发泄渠道换成沉默或者其他肢体语言，事后复盘内容不同。
- 若林恩决定不在她耳边轻声提「亲爱的脑袋」的可爱称呼，则左左的羞耻意识觉醒推迟，账单记账方式改变。
- 若林恩选择让她在房间内保持沉默不准说话，则她不能立刻用语言羞愤，只能在「事后」通过别的方式爆发。
- 若林恩在左左羞愤咬人时不笑而是低头让她咬，则可能使她产生愧疚，关系通道开启不同的发展方向。
- 若林恩决定把「测试机型」换成「交一个朋友」的说辞，则诱导的性质完全改变，左左答应的意愿或许上升。
- 若林恩选择在左左炸毛时立刻道歉并停止，则灌输实施可能中断，机制因果不落地，E523 的禁术突破前史重塑。
- 若林恩决定把「准许称为亲爱的脑袋」改成「准许称为倒脑袋」，则她的羞耻底线改变，后续羞愤台词的语域不同。
- 若林恩选择在「可贵的营养」上强调某种仪式感，则左左的联想路径变化，她的愤怒点重新定位。
- 若林恩在飞向罪孽城的途中选择掏出一瓶药剂献给左左作为安抚，则她的羞耻愤怒暂时被物质化安抚，关系账目改写。
