# E117·往昔恐惧投影生命树与幼稚园·if线

- 若林恩在沙漏最后一粒沙落下前主动松开左左并保持完整巨像之心权限，则投射领域对他的意志压制翻倍，他能在母树坠入心魔的同时反向拉动领域边缘，把战斗拖入自己选定的街道布景。
- 若林恩在母树伸手扒意识的瞬间不闪不避、反而贴上她掌心提交一段属于自己的记忆碎片，则母树被迫在幻象里同时消化两段痛苦起源，藤蔓破地节奏被打乱。
- 若林恩在生命树燃烧幻象中对着母树的方向走上去而不是逃开，则他的心像投影本体同步坠入那片火海，两人在同一段毁灭记忆里第一次以平局对视。
- 若林恩选择在母树狂奔时化作一艘方舟的外形立在航道尽头，则她撞上来的刹那幻象表层破裂，露出下方更深的巨像潜意识底层，双方同步坠落。
- 若林恩在初恋小女孩宣判蛀牙归属时不石化也不挥拳，只是蹲下来笑出声说"谢谢"，则走马灯失去下一段的接力点，幻象链条在第一环就松动脱轨。
- 若林恩在富家千金退还触手公仔时伸手按住她的手背而非任由她塞回，则该段投影被强行停留，母树的领域替他多保留一份可重新读取的细节片段。
- 若林恩在大姐姐老师说完"等不了你十年"时直接追上去而非留在原地滴眼药水，则投影被迫生成下一段原本未预设的延伸镜头，领域算力被进一步消耗。
- 若林恩在黑丝黑发小萝莉幻象拒绝"假林恩"时不打飞两人、只把假林恩拉到自己身边重叠，则挑拨机制失效，投影塌缩为一个只剩他自己的空街角。
- 若林恩在幼稚园走马灯完整走完全部十几次情伤后仍不哭不吼、只低头数糖纸，则快乐值扣减的系统提示被持续刷新直到溢出，幻象对他失去软刀子意义。
- 若林恩借巨像之心次级权限把整个幼稚园布景反相成「告白成功」版本逐段重播，则领域核心出现逻辑矛盾，母树在挣脱心魔的同时被强制拉入对立记忆的对照组。
- 若林恩在情伤走马灯中识别出某一帧并非自己的记忆而是母树悄悄植入的伪段，则该帧失去伪装被反向放大，母树的神格坠落史被强制拖进同一条播放轨，两段痛苦起源同时公开。
- 若林恩在血色藤蔓合围至巷口时不迎战、反向顺着藤蔓爬回母树扎根处，则双方进入近身肉搏距离，挣脱心魔的母树第一次拿不到地毯式远程优势。
- 若林恩在幼年初恋现场蹲下替"小林恩"挡住那句蛀牙宣判，则投影规则判定「过去被改写」，走马灯当场出现裂纹，他获得一次从内部撕开领域的出口坐标。
- 若林恩借幼稚园布景对左左广播自己的坐标与状态，则失联数小时的左左循信号切入领域边缘，巨像之心权限短暂双线程，母子藤被迫分火。
- 若林恩在母树咆哮"林恩，你真的惹怒我了"时不接话也不逃，只把那一句原样念回去，则她的杀意锁定出现一瞬的目标识别紊乱，藤蔓破地方向偏出原定包围圈。
- 若林恩主动让自己完整坠入生命树燃烧幻象并放弃挣脱，则幻象在他彻底沉没前耗尽了预设长度，母树先一步被弹回现实扭点，领域归他短暂接管。
- 若林恩在情伤投影中大哭出声而非滴眼药水硬扛，则领域错误解读为「心防已溃」，把他直接弹出幻境边界送回现实巷道，恰好错开血腥合围。
- 若林恩对幻象里的每一位小女孩都拒绝出手也拒绝解释、只是递上一支新棒棒糖，则整个连锁情伤布景被推离原本的剧本节奏，母爱树种与情欲权限在底层第一次彼此触碰。
