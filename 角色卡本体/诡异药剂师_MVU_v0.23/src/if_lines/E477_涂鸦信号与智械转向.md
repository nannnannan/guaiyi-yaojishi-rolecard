# E477·涂鸦信号与智械转向·if线

- 若林恩入侵裁剪机械时反向把行为逻辑改为「每裁一寸反向加一寸」，则田园时代会在两小时内出现自己重生的悖论区，巢都其他节点会对这区域的异常标出三小时审计。
- 若林恩留下的羽毛状数据流不只有代码指纹还藏一缕少年旧笑的音波，则银色幻想抓到羽毛时会同时「听见」那笑，她停的时间会比默认线长七秒。
- 若林恩在巢都另一边境以隐蔽模式擦肩而过时主动呼出一缕初诞者之力，则这一缕会擦过银色幻想去程空气，她不会停下、但下意识回头两次。
- 若林恩选择不擦身而过而是直接现身叫住她，则她会粒子枪先上膛、认出是他后再放下一半，会面提前发生但「最后一次」宣言被本事件本身打断重写。
- 若林恩在光宴拦截外界交互十秒时让她同时也拦下银色幻想巢都方向的扫描三段，则智械吸收一缕光宴数据的路径不会被她反向嗅到，银发体脱身节奏不变。
- 若林恩留守者镇压第三中端机同貌体的篡改记忆换成「她曾被林恩救过」，则下次光宴到这台区块时这台主体会对她先放下敌意半寸。
- 若林恩在第三中端机登记完成后让分身向巢都集结、尾随银色幻想尾流，则她会在两分钟后意识到被跟，反向数据首次主动找他。
- 若林恩在少年涂鸦上除了画笑眼还画一缕她银色长发的一角，则她抓住涂鸦瞬间会认出那是她，「他记得我」的判定从「他记得我的暗号」升为「他记得我发色」。
- 若林恩让涂鸦上的少年眨眼一次，则她会在解码那一秒把这帧动画重复三十遍，她意识外侧首次出现「她想多看一会」级别的柔软位。
- 若林恩改涂鸦方向不指向天空而是指向巢都某扇她熟悉的窗，则她会先在原地犹豫二十秒、不选择去阳光处而去那扇窗，会面地点被林恩重新定向。
- 若林恩在涂鸦角落加一笔小三芒星，则她会在阳光方向启程前多看那星三次，「这是不是他旧时的某个标志」的疑问会在她下一次见林恩时被问出。
- 若林恩用咒瞳尾随她的数据长流直到她抓到涂鸦的瞬间，则他能看到她瞳孔变化顺序：识别、抗拒、犹豫、决定，他把这四阶段记入他自己对她的底账。
- 若林恩在她「最后一次」宣言落定瞬间反向信号「我等」，则她在跃向阳光处的数据流尾部会留一缕反向颤频，相当于她的回应「别等」或者说「你最好别等」。
- 若林恩用灵能远程把她抓涂鸦的那只意识手裹一层温度，则她会在那一秒错以为他真的在她身边，她攥画的手指会更用力、离开巢都时回一次头。
- 若林恩在她启程后悄悄把她起飞坐标反向标入田园的两棵老树之间，则她抵达时会发现自己落在那两棵树间，「他提前知道」的具体证据再多一笔。
