# E299·一家人之诺意识上传·if线

- 若林恩在广场上望着三座蜂巢时先手贱指认其中一座说成「那是你们的食堂吗」，则全场机械意识猛转头，她的笑容僵在脸上一拍之后终于笑出声，后续擦屏的柔意多了一分「原来你也会怕生」的体谅。
- 若林恩想逃时先用扳手轻轻拨正她的披风角而非被抓住，则她原本就要屈下的身躯顺势微蹲，擦屏的动作从蹲姿展开变成平视，那句「你在风雨中保我护我的时候」多了一份并肩意味。
- 若林恩被她提溜住后顺势反手把机械臂勾上她的指尖而非挣扎，则她的语气从关怀变成惊愕，一级权限的申请在她心底从「勉强替他盖过疖子」变成「早晚我自己想留他」。
- 若林恩在她说「你是这里最干净的那一个」之前抢先自己呛一句「我知道我是最脏的那个」，则她没有回「不」而是久久沉默，让那句赞美就此埋进数据里，从公开肯定变成私密默认。
- 若林恩在 rbq牌大冰箱试做型报名时把 rbq 掐哑成低声，则她写下名字没意识到谐音笑话，左左错过杀意提示，关系评分表的唯一提醒滞后两条目。
- 若林恩在上传大厅里被驳回四项原因中最爱提「战舰部件相似」一段而非认知溯源，则她动用一级权限时首要把驳回焦点片面化处理，议会首次纪录里出现同类归档，事后再处理就难了。
- 若林恩在申请被驳回时发出一段泄气的电子嗡鸣，则她表情没变，数据底层却留了「为他心疼」的备份，人格重塑时此段免检。
- 若林恩把「保证他从来没有说过谎」的保证换成「保证我在你身边每一刻都没有撒谎」，则她的指尖微微一颤，E301 塑形大厅的逃离不再带有任何背叛色彩，只剩下一场被迫的惜别。
- 若林恩在审核通过语言中主动补上一句「愿万机之神的钟磬为我而鸣过之后再为别人鸣」，则系统播报多了一句额外的祝祷词，她被记入异常数据，但被她的权限亲手封档。
- 若林恩在上传成功成就面板弹出时对成就内容报以一声低哼，则系统把「精神力+5」临时折算成薄荷糖味的心理安慰品，事后他发现无论怎么丢也丢不掉这个异样。
- 若林恩领取任务【机械神教的命运】时先翻到最后「关系走向」一栏而非直接接取，则他提前看到一条「判断与银色幻想的关系」的明文，从此他无法再骗自己说的是「无关个人」。
- 若林恩在母星模拟世界里先伸手触碰她肩头而非任由她以数据投影靠近，则她蓝眸微抬，第一次主动将数据体真实密度提升到 100%，那份拥抱真实到让她在事后回忆时称它为「第一次活过」。
- 若林恩摘下路边小花时花突然变成一段加密数据流当面消散，则她接不住这个梗，只能继续笑着解释这是他们数据化的一个小弱点，反而暴露一个能被他利用的代码口。
- 若林恩在她问他「是不是和你想的完全不一样」时没有点头也没摇头，只轻声答一句「和我想的一模一样」，则她愣住，原本清澈的苍蓝深处浮现出一层他自己看不懂的迷雾。
- 若林恩在大本营广场把「我们出发吧」的台词换成「指挥官，请允许我从此跟随您」，则她的矜持第一次出现裂缝，E300 的文明史开场白从讲述变成叮嘱。
- 若林恩在她说「以后我们是一家人了」之后立刻回一声仿佛自嘲的短笑，则她笑容渐敛，一级权限的记录里多了一条「他有迟疑」的注脚，后续听证少被引用他的抗拒案例。
- 若林恩刻意把上传大厅的监控角标记下来而非装作不懂，则他在 E300 的文明史环节里时时提醒自己对话还有另一组见证者，因此后来的松动变得更稀有也更沉重。
- 若林恩在她带走他入教时用她的原名呼唤她而非「指挥官姐姐」，则她瞳孔一缩像是被电到，事后把这个名字查出来认真记住，最后变成陪审团时她不愿提交的那个秘密。
- 若林恩在成就面板弹出时大声说一句「谢谢机械神教」，则她当他是亲人，E302 双线毁约的口气提前消耗一半。
- 若林恩私下跟左左承诺「拿到结晶我就下船」，则 E301 的逃离场景里他实际使用的话术与这句话完全相反，后果是他自己也没能卸下那个惭色。
- 若林恩在意识上传成功后立即回复一朵用程序自动生成的小花递给她，则她把这份数据封存为「他是真的在意」，议会此后想用这段数据指控他都翻不出有用的情绪。
- 若林恩把「rbq牌大冰箱」那串难记又出格的名称也输入机械神教的人员档案，则高层点名时全场不住发笑，银色幻想第一次当着所有人维护他的名字，权威值因此损失一格。
- 若林恩在她带他游母星模拟时率先表达「这里的天空像我见过的蓝天」，则她首次主动讲述自己从前看过多少蓝天，话题从冷冰冰的文明史变成共情的记忆分享。
- 若林恩在上传时接受一级权限那一刻起就开始策划反水而非日复一日地犹豫，则 E301 逃离塑形大厅的动作从容得多，反而让她后来的受伤多了一分措手不及。
- 若林恩把「rbq牌大冰箱试做型」申请信息去掉一半只让小智脑看一半，则小智脑首次发现申请不完整，主动补全程序的情况下，它被议会注意到成为日后监控焦点。
