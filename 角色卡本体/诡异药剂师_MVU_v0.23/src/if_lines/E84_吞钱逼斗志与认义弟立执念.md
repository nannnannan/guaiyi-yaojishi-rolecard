# E84·吞钱逼斗志与认义弟立执念·if线

- 若林恩在左左吞第二枚黑颅币时催动咒术「胃囊倒灌」，则她被逼吐回钱币、斗志未被刺激，林恩改用咒瞳自刺解除斗志丧失，事件以斗志解除成立收束。
- 若林恩在左左吞钱前已凭意志挣脱「斗志丧失」，则吞币刺激落空、他反手收缴她私房钱，事件以变形（自醒型解除）收束。
- 若林恩拒用【限时诅咒清除能力】、改用合成配方配出「抑志灵散」，则斗志丧失被临时压制而非清除收录，诅咒收录字段缺失，事件未达标，后续诅咒遗留为隐患。

- 若林恩选择不追缴左左私房钱、只把已吞下去的币让她慢慢消化，则左左怒意+0、好感反而涨，但她保留「欺主杀手锏」经验，事件仍以原作收束但左左性格锚点偏向「能再度胁迫」。
- 若林恩追缴金库时顺便勒索左左继续做苦力抵债，则她大怒扯他左手纹、人偶身份险些泄露，事件仍以原作收束但多一道「私密勒索」伏笔。
- 若艾雯爵士幻境只造死水池塘不造双路锦鲤，则林恩只看见白骨、没看清救世分歧，他以怀念哥哥台词硬过场，事件仍以认义弟成立但爵士真实意图未传达。
- 若林恩面对幻境直接说出「我选逆流跃山巅那条」并阐述理由，则艾雯爵士把他归为潜力战路而非温和亲缘、轮椅不再赠送，事件以变形（战路结缘而非义弟）收束。
- 若林恩在面对艾雯爵士时不演怀念哥哥、只以落寞神情低声陈述「我已没有故乡家人可回」，则艾雯爵士出于孤狼共鸣仍主动认义弟但好感度仅+5而非+10×2，事件以变形（降级版义亲）收束。
- 若林恩在认义弟现场拒绝轮椅赠品、表示自己不需要代步，则轮椅回归艾雯爵士密室，E85前往病房探望黑弦月的链路改为徒步慢挪，左左无可拍按钮，事件以变形（收义弟不轮椅）收束。
- 若林恩接受轮椅但要求换成普通木制轮椅不要单兵辅助装置，则艾雯爵士只给15倍音速之外的简版，后续冲撞黑弦月病房链路速度来源消失，事件仍以认义弟成立但轮椅伏笔廓线偏移。
- 若银色幻想在意识空间选择接受思维重塑，则「用一生亲手杀死林恩」执念未写入底层、她醒来对林恩冷漠中立，事件以变形（解除恩怨型）收束，后续她不再伺机追杀。
- 若银色幻想假意应承但执念目标不是杀林恩而是「让他尝到同样屈辱」，则她醒来后选择接近、伪装服从，事件以变形（执念偏移型）收束，E85之后她主动出击链路提前。
- 若银色幻想当场取出意识核心在万机之神面前删除那段记忆，则万机之神判定她「可控」，蜂巢虚拟空间链路改写为她被送上前线听调，事件以变形（银幻脱离执念）收束。
- 若万机之神在发现银色幻想已写底层执念时不再建议思维重塑、改为直接湮灭意识，则蜂巢链路中断、银色幻想本体当场报废，事件以变形（银幻消散）收束。

- 若林恩拿左左的私房钱去买给艾雯爵士的谢礼再认义弟，则感激链路被货币稀释，艾雯爵士主动好感度仅+5、轮椅附赠，事件仍以原作收束但认义弟成色略减。
- 若林恩收缴左左金库时发现叠钱的衣服被扯乱，则他要求她熬夜把衣物叠回原样，左左大哭升级、好感多+1，事件仍以原作收束但左左关系偏「被训奴化」。
- 若林恩苏醒时先看见的不是左左而是艾雯爵士，则他跳过吞钱刺激直接请求解除斗志丧失，事件以变形（被动治愈）收束，左左私房钱未被触动、欺主戏码整体消失。
