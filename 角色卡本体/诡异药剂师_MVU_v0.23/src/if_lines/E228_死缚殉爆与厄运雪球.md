# E228·死缚殉爆与厄运雪球·if线

- 若林恩在第一次死缚掷出「3」的瞬间补一根咒血指刺再投一次，则第二次骰子停在「6」，事件以不变形收束但「镇压到死」路径直接走通，魇魔在本事件就被钉死、E229/E230连锁整段取消。
- 若林恩在脑袋爆成血雾前先把小眼萝从眼眶掏出塞进左臂傀儡之印里，则印记触发时由小眼萝代他掷骰，事件以不变形收束但小眼萝后续一日内被魇魔残余精神灼烧、沉睡五日。
- 若林恩让弥赛亚在城外远远释放一轮炽天使恩泽扫过机械猎场，则心灵抑制器被误判为「敌对机械」、数台被她光流并爆，事件以变形（误伤装置）收束，整场战斗改为白刃战。
- 若林恩不让小眼萝加钱、选择自己硬抗精神疼痛的呲溜感，则「愉悦度抵消」机制未触发，事件以不变形收束但战斗持续一小时他精神条归零一次，恢复后多一层「精神创伤」debuff。
- 若林恩在小眼萝吸吮到一半时反手把她从脖颈里扯出来，则她发出一声被强行断奶般的尖叫，事件以不变形收束但小眼萝之后一周不再理林恩，咒瞳停用。
- 若林恩在随机诊断术连续失败十次时改用「咒瞳扫一眼」直接读魇魔弱点，则他被魇魔的精神扫描当场反定位，事件以变形（互探失败）收束，战斗改为「双方都知道对方位置」的明牌对决。
- 若林恩在第二次死缚掷出「1」时当场折断咒瞳原型，则咒瞳活性化失败、小眼萝回到普通眼球模式，事件以变形（咒瞳退化）收束，他必须用纯武力+机械装置完成猎杀。
- 若林恩让燕尾服傀儡在被魇魔切开后仍然保持移动、临时充当第二诱饵，则魇魔在分解傀儡时回头迟一线，事件以不变形收束但燕尾服死兆级咒器被撕裂一道口子，从此失去「气息遮蔽」一档。
- 若林恩在脱裤加码时顺脚把裤子踢到远处数十公里外的弥赛亚面前，则她惊叫一声背过身去，事件以不变形收束但「裸奔少年」画面被她记入隐修会档案。
- 若林恩在诊断术「精神迟钝/意志衰弱」叠满二十层时改用【以M】主动切断，则魇魔的debuff雪球停在半途，事件以变形（半途收尾）收束，他需要单挑一遍剩余debuff未叠的部分。
- 若林恩在战斗中允许左左通过守阵远距离给他投放一瓶暴击药剂，则他在战局最紧张时再次猎杀强化，事件以不变形收束但左左守阵法力消耗+50%。
- 若林恩在小眼萝爬到他脖颈吸吸时反向以触手扣住她腰间，则她被迫用最快速度吸吮完阀门养分，事件以不变形收束但小眼萝事后被养得圆滚滚浮在他肩膀上动弹不得。
- 若林恩在精神冲击波-90%的瞬间反向以巨像之心把所有血气灌到头部，则他的新脑袋在原地直接长出三颗备用头颅，事件以不变形收束但战后他必须处理三颗脑袋共享意识的尴尬。
- 若林恩让一台中型心灵抑制器在信号消失前事先反向轰向自己，则他在战斗中以「心灵闭塞失真」状态换取免被读取，事件以变形（自我封闭）收束，诊断术对魇魔的命中率反而下降一档。
- 若林恩把死缚的目标换成自己而非魇魔，则他以身作诱、被锁链拉向魇魔近身，事件以变形（自缚近身）收束，「血肉暴动」发动面积直接贴身爆破。
- 若林恩在加码爆衣时同步撕裂自己一层胸腔露出巨像之心的外露脉络，则巨像心跳在战场上轰鸣被所有人听到，事件以不变形收束但血肉支配者在远端立刻识别出「巨像之心外露」特征。
- 若林恩在小眼萝「老规矩」时多加一句「给你顺便加一份咒血芝士」，则她首次接受到远超以往的待遇，事件以不变形收束但小眼萝后续三天消化期内无法上场。
- 若林恩在梦魇殉爆的瞬间让巨镰先替自己承受一击，则镰刀刃口当场被撕裂、耐久度-40%，事件以不变形收束但他在后续战斗中必须改用巨镰的「收割模式」原本的「战斗模式」一档缺失。
- 若林恩在锁定魇魔本体的瞬间临时把自己切换成白雾形态，则他化作雾状掠过数百米，事件以不变形收束但梦魇殉爆的范围冲击仍命中他一半。
- 若林恩让远处蜀都内的隐修会特务看到巨镰跃迁轨迹，则一枚红色紧急信号弹在半空炸响，事件以不变形收束但魇魔投影识别出「林恩得到隐修会支援」误判，梦魇殉爆延迟一轮。
- 若林恩在双锁成立时顺手给小眼萝记一份「战后天地会自助大餐」的欠条，则她吸吮养分的力量增大一倍，事件以不变形收束但林恩接下来三天必须兑现承诺否则小眼萝会用执行咒术罢工报复。
