# E652·时间尽头与唯一道路·if线

- 若林恩没有轰开壁垒而在漩涡里慢慢绕行，则他不会触到时间之外，本事件以他继续在原地盘旋收束，时间长河崩坏的进程后移。
- 若林恩任由悲恸主导、在时间之外一直寻觅左左而始终不向长河内回望，则他和她之间的距离会随每一次寻找越来越远，最终两人都化作黑暗中的一对雕塑。
- 若林恩在浑噩里先开口问「你是谁」，则长河内的平静声音会在消失前多停一秒，那张脸上会浮起一次像是对自己家人的惋惜。
- 若林恩以心声反问那位声音「你也要拦我」，则声音会留下一句「我没有要拦你，我只是放过你一次」，然后如泡影散去。
- 若林恩在时间之外试图大叫左左的名字而不是先听那位声音，则她会远在任何一滴涟漪里，他不会得到任何回应，但那只黑伞女孩会提前出现在他肩头替他遮雨。
- 若林恩冲向时间长河终点的那一拳没有挥出而是停在半空，则那位声音会再补一句「在你挥出那一拳之前，我都会在那里」，然后河流开始黯淡。
- 若林恩踏上孤岛之后率先扑向白发身影而非听撑伞女孩把话说完，则他会被时间法则直接弹开、跌回时间之外，这场交谈会失去最后一丝线索。
- 若林恩朝撑伞女孩伸出手却被时间锁链挡住，则她会苦笑着主动把伞举过来，她会用另一只手抚摸他的脸颊作最后告别，告诉他她等了太久，手心会出现一道无法擦除的涟漪。
- 若林恩问她「你是左左吗」，则她会本能地应答一声「不是」，时间法则立刻将她吞没在涟漪里，只剩一把绿伞留在原地。
- 若林恩问她「你叫什么」，则她会犹豫很久才说一句「就叫林左吧，改主意了下一轮再讲」，然后在第三次涟漪波动里被时间吞没。
- 若林恩在她为他撑伞的时候故意把她按进雨水里、强行与她共享一场寒冷，则她会把他推进河中回到现世，但锁链会多一环，下一次他们再见面时，她的容貌会更多一分左左的影子。
- 若林恩朝白发身影恭敬一拜并默默告别，则撑伞女孩不会拦他，她只会目送他回到时间长河，然后在塔的背影里再独自撑了一整夜伞。
- 若林恩面向白发身影说出一句「我会带左左回来，哪怕只剩她一个人留」，则撑伞女孩会先替他掉眼泪，然后把这一句话背在自己唇上、直到时间尽头。
- 若林恩在雨中边走向白发身影边对撑伞女孩说出自己的名字「林恩」，则那句话会在第一次涟漪中扩展成惊天动地的轰鸣，时间法则会把她从原地抹掉又复凝，她会被涟漪撞得短暂崩溃后重新微笑。
- 若林恩在走向塔的途中主动把手伸向那件仿佛随时会破碎的白发身影，则他会被时间锁链直接烙出五道痕迹，撑伞女孩会冲上来替他按息伤口，她会在离开前替他留下一道保护伞。
- 若林恩把折翼天使的事说给她听，则她会一直沉默地守着白发身影，只说一句「他看过太多这样的事」，这句话会让他走出孤岛之后肩上多了一层掌心般的重量。
- 若林恩先向她询问未来而非回望，则她会说出「未来曾给过许多人一条活路，现在只剩这一条」，但在她说出这一句的时候时间长河已经开始崩坏。
- 若林恩不合眼让自己跌回时间长河而试图硬闯，则涟漪的涟漪会变成浪，他被迫回到出发之地，结束时候他什么都不记得，只剩左手心里一个新的个纹。
- 若林恩带一场梦境进入时间长河、让她瞥到他对「未来的她」的期待，则她会一路哭到孤岛边缘，时间的锁链会随她的泪珠变成一层繁密的罗网。
- 若林恩在临走前把一滴指尖的罪火留在塔的背影里，则白发身影会在他的焰迹中闪了闪，撑伞女孩会代替他作最后的目送。
- 若林恩用力吻别撑伞女孩然后转身，则她会停在原地站着不动，他离开孤岛时她会自己带着那道吻走向时间长河边缘，化成涟漪融进河里。
