# E404·狱卒尸骸核爆与血肉世界崩坏·if线

- 若林恩在旧战场取尸前先对棺椁外层加贴一层原初始护符，则进入内部承受的消耗减一成，但护符因接触混乱而迅速焦蚀。
- 若林恩不带棺椁、直接以血肉躯体潜入旧战场，则行进更轻，但空间无序腐蚀会直侵肉体，事后需在黑夜城复原。
- 若林恩把「卸光装备、赤条条上阵」的轻装偏好告诉左左，则她会吐槽「反正都要进那口棺材，穿不穿一样恶心」，棺椁要求按原样生效。
- 若林恩主动用自己的血肉包裹棺椁里的残骸，则取尸量可多三两，但他的身体会因接触混乱而需要额外清理。
- 若林恩让艾雯爵士在坐标节点预埋一道灵能折射网，则炸开第一瞬间她能把核心法阵圈层完整测绘成三维模型，但折射网本身会被无序污染。
- 若林恩让前两次爆破都把爆炸波偏向同一处表层，则壁垒缺口变大但核心法阵不被贯通，进入近距作战前敌人警觉度抬高。
- 若林恩按原节奏走——前两次撕壁、第三次送弹入缺口、第四次核心引爆——则核心法阵被击穿，事件按原作走向收束。
- 若林恩在第三次送弹时点错节拍让爆炸波偏向表层，则缺口扩大但核心法阵不毁，支配者获得反向调整跃迁时刻的时间。
- 若林恩让艾雯爵士在第四次爆破前加一道「维度回卷」保险，则她能在核心击穿瞬间立刻把他拉回，但行动窗口被压得更紧。
- 若林恩让支配者在最后关头察觉同源共振并成功取消跃迁，则核心不会按时抵达伏击点，爆破计划落空，事件变形为「追击与重磨节拍」。
- 若林恩让血肉支配者在失衡后派出大量触手撑住地层，则他撑住地层的同时反向暴露核心法阵方位，进入近距作战的危险机会被放大。
- 若林恩接受艾雯的维度投送靠近核心圈，则他会被数百万吨蠕动血肉包围，任何防护失效都会被活体吞没，但近距引爆精度最高。
- 若林恩改用远程引爆器不靠近核心，则他不必承担被血肉吞没的风险，但引爆精度可能不足，核心只受创不毁，支配者得以残存。
- 若林恩在核心被击穿后仍让艾雯继续在原地测绘残余结构，则她能带出更详尽的法阵数据，但撤离窗口被拉长，机械四神反应时间被换来。
- 若林恩在壁垒剥离后立刻让艾雯撤回，则他失去对内部逃难的持续测绘机会，但他的安全指数显著上升，机械四神没有追击目标。
- 若林恩在核心被击穿后忽略了孽主的临阵观望，则孽主可能在观察得出支配者已奄奄一息后立刻重新计算阵营，她留下的可能反而升高。
- 若林恩主动让艾雯把灵能印记留在核心法阵内深处，则后续测绘能追溯法阵本体，但印记本身可能成为敌方反向定位的凭据。
- 若林恩让巨像之脑在敌核溃败后同步用血气探测支配者残躯的活力，则她能比他更准确地读出「支配者已奄奄一息」还是「仍然活着」，决策方向被改写。
- 若林恩让机械四神在壁垒崩坏时反向注意到伏击谋划者，则他们的蜂巢提前升空，伏击后的下一轮防线会因为他们反向锁定而更紧张。
- 若林恩让小小在敌核溃败瞬间陪同侦察核心圈，则她的速度能闪入破口，但她的体量无法承受核心残余血肉碾压，事件变形为「小小惊险逃脱」。
- 若林恩在事件中让爱丽丝在幸福之家静候爆破战果，则她能在他回归时用一杯热茶接住他，但她若未迁城，这条便利不存在。
- 若林恩让大舌头在爆破期间负责下水道的尾部防线，则他能以劣魔提供的血食维持警戒，但他的下水道贵族阵地会被无序污染。
- 若林恩让巨像之脑在爆破结束后亲自前往敌核区域核查血肉支配者生死，则她的判断会揭示残躯是否仍在缓慢繁殖，但她本人有被卷入吞噬的风险。
- 若林恩让爱丽丝在爆破结束后立刻到幸福之家探望他，则她带来的安魂茶能在无序残响中让他更快清醒，但她本人会因短暂暴露来吸引机械侦察。
- 若林恩让银瞳萝莉在爆破结束后立刻进行回归镇压，则她的巨像力量会压制支配者残躯的反扑，但也会让她的王后身份进一步暴露给敌方侦察。
