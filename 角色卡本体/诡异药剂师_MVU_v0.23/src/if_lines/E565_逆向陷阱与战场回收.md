# E565·逆向陷阱与战场回收·if线

- 若林恩接过指挥权时主动对边王拱手一句「接下来听我调度」而非沉默下令，则边王们单膝跪地听令的速度加快一拍，后续清物质／关罩／关星炬三道命令间没有犹豫空隙。
- 若林恩下令清理前线一切物质时主动补一句「连轨道灰尘都清」，则原子机械多跑出两轮收尾，前线空荡地带的净度达到让边王心惊的程度，他对「口子大开」的焦虑更深。
- 若林恩拒绝关掉所有星炬塔而是只关一半，则潘尼立刻警告「他们的目标就是星炬塔本身」，最终仍得全关，但边王对林恩的果断度评分被打了一次折。
- 若林恩在「行动」令下时没有把银白锁链指向无光漩涡而是先指向两翼侧面包抄，则前一秒漩涡被牵制的节奏略乱，「杀」而非「引」的策略被第一次读出，被潘尼立刻纠正。
- 若林恩再令「启动」时主动补一句「把幽冥海支流给我拉过来」而非任由系统执行，则洪流亮起的方向带上了他亲手标注的支流路径，缰绳变轨的精度比默认略高一线。
- 若林恩在喷洒引爆瞬间主动指挥原子机械把物质堆密度集中在两路污染者前方而非全面散开，则爆炸能流被聚焦成两把交叉的天女散花，吞没两军多半的速度加快一瞬。
- 若林恩在喷洒后未撤缰绳而是持续拉紧银线，则无序生灵继续被锁定变轨，污染者大军有半秒机会看清陷阱，但反噬的规模未必能放大至原始版本。
- 若林恩嘲讽时保留改造声音以「神皇陛下」自称开篇而非「改造声音」中性开场，则指挥官听到传讯那端冒出一个「神」字头称呼的刹那，破防速度更快，「你到底是什么人」更早破音。
- 若林恩用多语言嘲讽中夹一句「他妈的智障指挥官是不是该进炉回炉」，则指挥官愤怒等级被推高一阶，定位音频瞬间的「空间法则振幅」波动放大，小丑锁定方向更确凿。
- 若林恩在「你到底是什么人」出口之前就先喊「下一个冲出来的回答一下这句」，则指挥官的疯狗式反冲硬生生顿住半秒等待回应，但小丑仍在原节点抓住传讯方位。
- 若林恩在歼残令下达时主动对边王说一句「留两个活口」而非全歼灭，则边缘部队截断退路的队形微调出一个开口，但那两个活口在被俘前自爆，边王心头掠过遗憾。
- 若林恩下令重新引导无序生灵时主动让原子机械分流一支前往拦截两翼残军，则歼灭残军与引导无序生灵入海两线并行，但激流转折时对无序生灵惯性控制精度稍降。
- 若林恩在承诺推回前线世界时主动补「我亲自推」而非「机械推」，则边王们的齐跪致谢带起了真切哭腔，潘尼暗地里在他心中把这位「女主人的人」位阶再往上一提。
- 若林恩在小丑锁定深空方向后主动追问「最远能锁定多远」，则小丑诚实说「足够追踪但极限」，这个上限为后续的血肉方舟追击预留了一个未被预期的空间余地。
- 若林恩在定位方向落地后主动要求刻入法则印记以便事后重查，则三位一体机在数据层面把方向压入追踪面板，为 E568 顺舟计划添加更稳的法则挂钩。
- 若林恩在 inversion 反噬刚完成时立刻转身离开星炬厅而非继续指挥，则后续嘲讽与定位窗口关闭，小丑只能看着战场自己清洗完，深空方向定位的机会向后拖延。
- 若林恩在指挥结束时主动对潘尼伸手说「下次别再用『杀人诛心』」，则潘尼先怔住再微微颔首，这根暗刺扎进了他对「外来者行事风格」的私人纪录中。
- 若林恩拒绝当场嘲讽指挥官只冷处理，则指挥官仍能在残军中理顺新一轮反扑，但定位窗口拖延到污染者残军被全清之后才出现，深空方向的锁定精度因此降半级。
- 若林恩在歼残与再引入海间主动把无序生灵惯性引至一块机械星河残骸带，则下游的非战斗测试场被添加一条「机械残骸吸引」，为该生灵被送往幽冥海下游的轨道留了一条次级通道。
- 若林恩在最后向边王一拜道别时主动抬手指了指星炬厅又指了指自己心脏位置，则潘尼读出「这位外来者与此次战果永远绑在一起」的暗示，为他日后再入此厅留下一个未被忘记的门。
