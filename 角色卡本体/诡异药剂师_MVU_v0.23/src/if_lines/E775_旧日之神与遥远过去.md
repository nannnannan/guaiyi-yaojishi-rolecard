# E775·旧日之神与遥远过去·if线

- 若林恩附身活体渡鸦跟随帝国狱卒穿过地狱之门、亲眼目睹整整七十二位半神与数百名世界级职业者被漫天猩红锁链拖入地狱化作「根源」的「大坠落」惨状时，他死死克制住出手的冲动，才未惊动远古地狱的最高法则。
- 若林恩在俯瞰大坠落现场时注意到地狱海边有一群气息渊渟岳峙的「旧日之神」正死死攥紧拳头冷眼旁观，则他立刻将观察重心锁定在这群隐忍的反抗者身上。
- 若林恩在旧日之神们几乎按捺不住怒火的刹那，截获了天空中另一只渡鸦向众神传去的那道低沉传音——「忍耐」，且听出那道声音竟与自己的声线一模一样时，他与左左同时在意识中掀起惊涛骇浪。
- 若林恩在锁定那只发出自己声音的神秘渡鸦后没有贸然惊动对方，而是耐着性子顺着因果线暗中追踪了整整数月，则他成功跟随对方来到了地狱北海深处的一座隐秘孤岛。
- 若林恩在北海孤岛的夜幕下亲眼看见那只渡鸦降落、黑羽褪去后化作一名与自己容貌完全相同的黑袍青年时，他瞬间确认了这就是远古时期作为渡鸦首领的过去自己。
- 若林恩在看到岛上等候的众多旧日之神齐刷刷向黑袍青年单膝跪地、声音哽咽地唤他「大哥」并泣不成声地禀报「老七死了，被地狱同化了」时，他从那一声声“大哥”中感受到了跨越万古的悲壮情义。
- 若林恩在目睹黑袍青年眼底掠过深沉悲恸、挨个扶起跪地的旧日之神并郑重起誓「无论如何都会带所有人回家，哪怕只剩下森森白骨」时，他内心深处涌起一股强烈的震动与酸楚。
- 若林恩在左左震惊地小声嘀咕「这家伙不就是你吗」时用意识轻轻回应「先看下去」，则两人保持着绝对隐蔽，没有打断这场决定旧日之神战争走向的秘密集会。
- 若林恩在大坠落的哀嚎声中仔细观察那七十二位半神被猩红锁链同化为根源的过程，则他对地狱根源体系的残酷本质有了前所未有的透彻认知。
- 若林恩在听到旧日之神哭诉「老七被地狱同化」时留意到在场某几位旧日之神的面容，则他能将他们与后世在地狱深处见过的那些古老残魂一一对应起来。
- 若林恩在黑袍青年说出「带你们回家」时敏锐察觉到这位过去的自己虽然顶着渡鸦之躯，却早已觉醒了比凡人更炽热的感情与担当，心底不禁生出由衷的敬意。
- 若林恩在北海孤岛外围用时间神格悄然抹去自己附身渡鸦的呼吸波纹，则岛上感知敏锐的旧日之神们自始至终都未察觉有第二只“林恩”在旁注视。
- 若林恩在观察黑袍青年安抚众神的手势与语气时，发现对方连蹙眉与握拳的小习惯都与现在的自己如出一辙，则那种“跨时空照镜子”的宿命感愈发强烈。
- 若林恩在集会进行期间顺便扫视整片远古地狱的苍穹，则他能感受到这一时期的未来画家尚处于清醒镇压地狱的状态，旧日之神们唯有蛰伏待机。
- 若林恩在听完黑袍青年的誓言后于心底暗暗叹息，则他深知后世的历史里旧日之神战争最终以惨烈失败告终，眼前这位意气风发的“大哥”注定将走向悲剧结局。
- 若林恩让左左将北海集会上每一位旧日之神的气息特征逐一记下，则这份远古名单让两人在理解旧日神国与紫罗兰帝国的恩怨时不再偏听偏信。
- 若林恩在黑袍青年提及“哪怕只剩白骨也要带兄弟们离开地狱”时联想到后来地狱里堆积如山的骸骨，则他对那场远古起义的悲壮底色有了切肤之痛。
- 若林恩在集会接近尾声、众神各自散去蛰伏时提前选定黑袍青年飞离孤岛的航线，则他为下一刻直接将意识附身到这位远古渡鸦首领体内做好了万全准备。
- 若林恩在决定附身读取黑袍青年记忆前先与左左做好精神锚定，则他即便坠入那段横跨无数纪元的浩瀚记忆洪流，也绝不会被过去自己的激烈情绪反向吞没。
- 若林恩在黑袍青年重新化作黑羽渡鸦振翅飞出北海海面的瞬间悄然将意识贴合上去，则新世界初创以来的漫长记忆画卷当即在他脑海中轰然展开。
