# E453·黄金泰坦训练·if线

- 若林恩在房屋被掀开瞬间主动用心声叫小小「来陪我一起睡」,则小小会直接从触手那头用头一卷把他拦下,泰坦头颅见到他的镜头多一分错愕,「立正」命令晚一拍落下。
- 若林恩被触手拍成血水之后主动用心声喊「岳父大人我有苦衷」,则他被抽起时泰坦的下一次出手会滞一秒,「给你小子融了」的台词不变。
- 若林恩在「给我脱」命令落下后先把四角内裤反着丢出迎风摇摆,则左左「脑袋!」呼救被压低一拍,泰坦头颅瞪眼凶恶的训斥从「血统」改口为「炫耀」。
- 若林恩接连亲手挖出克苏鲁之瞳、咒瞳、巨像之心、血肉之核之后,把咒瞳顺手掷入泰坦嘴里,则岳父被迫先咀嚼再把眼球吐回,「我能有老夫的大吗」的训斥被压一拍。
- 若林恩自评阶位之前先盘腿蹲下半闭一只眼估算,则他最后回答的台词从「君王以下杀不死」变成「我提个保守数」,泰坦「你能坚持多久」的追问被加重一拍。
- 若林恩在木桶和榔头的笑话之后主动把榔头往自己脑袋上敲一记表忠心,则岳父喝令「没了你小子」的台词更快被吐出,他被再次拍渣的窗口被压一拍。
- 若林恩在「系统组织的发力教程」回答之外自己补一句「主母给我上文化课」,则泰坦沉默两秒再吐槽,「我以前为什么会被追着跑」的疑问被多添了一拍。
- 若林恩在百公里测速之前用心声主动征求泰坦同意「我能否跳一下」,则他被回驳的理由改成「那你就更远」,他被触手弹弓弹出的出发点被再踩半米。
- 若林恩故意提前抢跑再上触手弹弓,则他被罚的弹起点被偏到半空,他撞烂草坪的画面多一道谐声,但抵达旗子的时间仍超三十分钟不变。
- 若林恩在跑回程时主动把旗子当枪使一边狂奔一边挥舞,则岳父训斥「拿个姿势拿不直」的台词提前,「以后怎么宇宙巡航」的疑问不变。
- 若林恩被泰坦示范黄金巨人之姿之后主动问「您还能再缩吗」,则岳父低头瞪眼骂「你再看个什么呢」的台词提前,他被允许观摩的窗口反而多一拍。
- 若林恩在泰坦愤怒到达巅峰之前主动把自己的咒瞳反转引他视线,则岳父愤怒的膨胀台词被压缩一半,他被推向课程的推背手势反而更直接。
- 若林恩在被印记灌知识之前先用心声说「我要全部懂」,则初控失败时分顶爆出的触手数量更多,他被泰坦斥责喝令摁回的声音拖长一拍。
- 若林恩在把大腿踢出上千米之后主动跑出院尝试自己把腿捡回来,则他返回时「身体是整体」的教育台词被提前一拍,岳父暴怒的骂声被压一拍。
- 若林恩直接请求泰坦先教一拳完整循环再学压缩,则他被回驳的理由是「没压就没有爆」,他那一拳的破坏力不变,但泰坦示范序列不变。
- 若林恩在一拳砸出大坑之后主动报出「他终于有资格学灵能」的自评,则泰坦会回驳「你现在只配跑了」,他被多抽一记痛处但课程推进不变。
- 若林恩在被裁决为「更适合血肉支配者式阴险」之后主动反问「我能改改性格吗」,则岳父会闭眼再补一句「你心血来潮就是这样子」,他被聆听的位置从听众变成被斥者。
- 若林恩被勒令背山跑二百公里之后主动申请「我先跑一次五十公里再补一杯酒」,则他被驳回的画面不变,他被遣去荒野的身影不变。
- 若林恩跑两百公里的途中主动让左左在掌心拖着小小,则小小会一个抛物线头砸上他的肩膀,他被计算出的总时间再多三分钟。
- 若林恩被左左拖往居所的路上主动用心声给她讲今天的故事,则她拖他行进门口的姿势更轻,「死兆级」展望的台词被左左提前替他讲给艾雯爵士。
- 若林恩在艾雯爵士出现的瞬间主动闭气装死,则他被识破的画面不变,「猜对了!还真有灵能的课程」的台词被提前一拍。
- 若林恩主动提议「能不能连着一晚灵能一晚血肉」,则艾雯爵士笑眯眯回应的台词再多一句,「最恶劣调教」的清单在他脸上被压一拍。
- 若林恩在被宣布整晚课时主动用心声示意「我们去外面」,则艾雯爵士被温柔移到原地,「今晚的课定在原地」的决定不变,但他仍会被拖去上课。
- 若林恩在被上灵能课之前主动询问还缺什么学科,则艾雯爵士给他透露的课程名单会更长,「魔法、咒术、傀儡术」的清单被他自己点亮。
