# E792·终焉倒计时与轮回·if线

- 若林恩在循环蛇影于瞳孔里浮现瞬间主动承认它是自己的一部分而非外来窥视，则他能完整读出时间王的攻击路径，但他从此再也不能假装只是「一名药剂师」。
- 若林恩在时间王揭示身份时先转身问轮回「你是不是也是这样被留下的」而非指责背叛，则轮回首次把脸从桥接中抬起来看了他一眼，那一眼成为后面一切交付的根据。
- 若林恩让左左在权柄剥离瞬间主动把黑火换成暖火而非继续燃火，则权柄接住的是「温度」而非「燃烧」，她今后所有付出都不再是消耗。
- 若林恩在轮回接手遗志前主动喊它一声「梦主的伙伴」而非「工具」，则轮回第一次用名字回应他而非职责，后面每一次牺牲都变得有人情可分。
- 若林恩在时间王时代影像被一层层拆开时主动伸手接住其中一片属于自己的过去，则他多了一份私藏的旧日，但所有权柄法则里会自动记载「他欠过时间王」。
- 若林恩在紫罗兰大君尚未发动攻击前主动问一句「你到底想要什么」而非直接格挡，则大君的攻击迟了半拍，而所有人的命运因这半拍出现一次「本可以」的可能。
- 若林恩让左左权柄转移瞬间主动把自己抽出来只护住她而非护住整个桥接，则她成了唯一被保住的点，但也成为权柄下次再转移时第一个被翻动的坐标。
- 若林恩在倒计时推进到关键节点前主动让自己的左手从桥接中抽出一次替轮回挡一秒，则轮回多了一份残余喘息，但林恩的左手从此觉醒一项会让他偶尔失重的能力。
- 若林恩在轮回承认只能争取片刻时主动对它说「这片刻我记一辈子」而非「我还有很多要做」，则轮回嘴角的黑火最后闪了一下，那一下成为他此后每个低谷里能想起的光。
- 若林恩在权柄交给左左那一刻主动按上自己心口的梦主记忆作担保，则左左成了权柄合法共有人，但她也从此背上了他每一寸记忆碎裂的责任。
- 若林恩让轮回把剥离后的一瞬间里唯一一次自由留给左左而非自己，则左左尝到梦主那一代从未尝过的轻盈，但她今后再也没办法假装什么都不在意。
- 若林恩在空白实体截杀路径显现瞬间主动用自己的心脏为桥接打一次节拍，则桥接规律节律化，权柄此后每次转移都会按他心跳走。
- 若林恩把时间王的所有影像逐一编号而非任由其重叠，则他在后面所有战斗中都能精确认出哪一段是哪一段，但他也永远不能再说「我已经忘了」。
- 若林恩让轮回在承认「只有一个碎片」时主动握住它最后一缕火苗而非让它自动熄灭，则那缕火苗被他塞进左手，此后他一生都揣着那一小段温度。
- 若林恩在倒计时归零前主动对左左说「无论结局怎样，我先谢谢你」，则那句道谢被写进权柄法则，他今后所有险胜都自带一层她的影子。
- 若林恩主动让黑火不再向攻击、而是向记忆渗透，则他此后所有面对的敌人都先看到「他记得他们」而非「他要他们消失」，整个战场节奏因此改了。
- 若林恩在时间王背叛的事实完全展开时主动开口说「我不会因为被背叛过就放弃相信」，则时间王的影像真正静止了一拍，那一拍成为他此后仍能守住自己的路标。
- 若林恩在权柄空门即将关闭时主动把它撕开一个永久性的细缝而非任由其封死，则他此后所有时代都能从那条细缝里得到一点点风声，但那风也偶尔会把他自己的过去吹回来。
