# E484·三方汇合与智械二次拿捏·if线

- 若林恩在分身侧接到伪身临爆前的坐标时先用咒瞳扫完整区块，则他能提前识破这是机械神教处决意志的炸弹库，他带光宴绕开走第三条网道，银色幻想的真身被独自留在水泥立方角落空等一场。
- 若林恩在带光宴沿破碎网道的路上直接告诉她「伪身爆炸是计划好的」，则光宴不再震惊追问她我居然没料到，她会立刻接「那她不怕自己人炸我们」，两人合作从这一刻起多一层共同信任。
- 若林恩用「始乱终弃」的话术安抚光宴不加后续的「各有各的用法」，则光宴会冷着眼回一句「那你之后还要我信你吗」，两人关系从这一刻起跌入信任低谷，银色幻想介入期增加三档张力。
- 若林恩在汇合点不喊「老友久别」直接甩灵能长刀，则银色幻想的伪影会抬手就被就地斩碎，整场试探环节被跳过，银色幻想对「他没打算玩剧本」的认识从此定调。
- 若林恩在斩伪影时先用三叉戟反向抽出她的残片保存，则这段伪影残骸会成为后续追踪她真身的新锚点，原子革命复原期他多一条独有线索。
- 若林恩在踏进光束房间前先用咒瞳扫光宴体内模因活性，则他会在入房第一秒就知道光宴体内其实已接近极限，「隐瞒这条」会成为他后续所有决定的潜在偏置。
- 若林恩施放血肉灾变把整个炸弹库地基都包掉，则银色幻想在交权柄那一刻会发现自己被血肉包围，她对林恩的「血肉是武器」的认识从此钉死。
- 若林恩进入光束房间时带着被下载的智脑而不是让她在现场空置，则银色幻想会在第一秒就看到被自己信任的智脑，对面谈判立刻倾斜，「智脑是我方的」信息不再需要林恩用威胁去揭露。
- 若林恩在谈判中直接告诉她「我救下了智脑」，则她会愣一拍后低声说「你没把她当筹码，」她对这个恶魔式存在的敌意第一次被她自己打破。
- 若林恩用灵能反向读她那双苍蓝数字眸的频率，则他会立刻断定这是万机之神遗产外接权限，整场谈判他都不会再把她当作「普通子集」对待。
- 若林恩在她拨动三维地图投影的瞬间用手势把地图按停一下只听「将军的部分」，则银色幻想会立刻答应把这段单独掏空给他，因为她意识到林恩真正在乎的是将军这条线。
- 若林恩在她说「人情已还」时回一句「那就再欠一次」，则她会沉默数秒后说「我这条命你想拿就拿」，这句话日后被她自己反复复诵、她与林恩的债从此不是数字符号。
- 若林恩在贴耳威逼时让她清晰听到「你现在不能动」，则她会在「我答应」之后主动把那把灵能剑刃的位置记下，成为她后续训练数据中的关键标记。
- 若林恩在她「我答应」的瞬间用灵能刻录下她的表情，则这道被屈辱压着的眼神会被林恩永久保留，这一幕会在原子革命之后成为她在三方位再度对峙时的审判证据。
- 若林恩在「我答应」之后主动把光刃还给她收手，则她会愣住半秒不知道为什么他不取，林恩会获得她信任的下一阶段筹码。
- 若林恩在贴压制中顺手把她耳边一绺银发撩回去，则她会立刻感应到这个动作是「他假装没看见我的乱」，这层体会在她心里埋成一道名叫「林恩也有温柔」的根。
- 若林恩在夹层那一端主动让本体松手放智脑离开，则智脑会在网道口跌坐在地瞪着他的本体破口大骂，「你这家伙就该挨一顿骂」成为本事件夹层侧的真实句。
- 若林恩在智脑松手之后立刻把她的中枢神经向后拨一档让她休眠，则她会陷入真实沉睡、本事件结束后再醒来依旧记得这帧「她骂我」的画面。
- 若林恩听从光宴说「她不义了」的主张撕开真相，则光宴首次直面自己曾被七神当成棋子的真相、银色幻想的位置也从「女儿」被她挂进「同病相怜」的行列。
- 若林恩在银色幻想要求她先离开时坚持留在房间再说一会，则她会硬压低声音回一句「你还要不要脸」，林恩的「厚脸皮」标签在此事件被她打在脸上。
- 若林恩主动不要巨像情报、把这份交换无偿送给她，则她会停顿一拍然后说「你耍我」，林恩首次意识到她真正讨厌的是「被怀疑」这种态度。
- 若林恩在走之前主动对她说「下次仍带血肉红包」，则她会有可能会在下一次见面时心里浮起他那句话是真心的感觉，但也很有可能让她从此取下一个被她的想法拖延的行动。
- 若林恩在出门之前额外在她肩头拨一下，则她会有可能会在当她没看到的地方出现情绪反应，但她不会让林恩知道发生了什么。
- 若林恩把这次三方汇合的情况通报给巫神与夏娃，则夏娃会认为林恩「居然能骗到这个笨蛋」，巫神会认为林恩「离得近了」，两人在各自战线上对林恩的看法完全变形。
- 若林恩在离开光束房间后用灵能反向封死整个炸弹库，则这节课的数据调度变得最终阻塞，机械神教机神的行动被林恩间接控制。
