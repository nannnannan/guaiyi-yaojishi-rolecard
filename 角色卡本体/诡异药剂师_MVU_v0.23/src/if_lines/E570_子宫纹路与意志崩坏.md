# E570·子宫纹路与意志崩坏·if线

- 若林恩阻止小丑「提遗书找死」时主动用一记爆栗代替口头警告，则小丑额头多一枚红印，立刻老实记起自己作为随行帮手的本分。
- 若林恩在「等一下！让我再想一想！」出口前主动先按住艾维儿的手背，则她注意到他掌心温度比平时更冷，「让我再想想」变成了她默许之下的数息停顿。
- 若林恩主动提议用「棺椁」或者「周期引擎」入核前先做小规模法则测试，则这段临场试验能多一分把握，但时间紧迫，她会冷声提醒他「没时间测试」。
- 若林恩在决定用小丑投掷棺椁前主动问小丑「你投掷重物最远能扔多远」，则小丑认真比划半天终于回答「不知道」，林恩这才意识到小丑以前根本没干过投掷棺材这种活计。
- 若林恩主动在她释放全部无序构筑屏障时以咒瞳记录屏障的法则密度，则她屏蔽信息外泄的手法被他熟记于心，成为日后布置隐匿结界的重要参考。
- 若林恩主动让小丑投掷棺椁前用法则再接一层稳定尾翼，则棺材穿行尘埃风暴中心时的轨迹更加笔直，只是切入核心时的朝向会略微偏转半寸。
- 若林恩在「那边是棺材」出口前主动让小丑在棺匣表面刻下一道挑衅符文，则棺椁砸入前线战场时的威慑感大增，敌方指挥官心中多了一层「暗处究竟是谁在布局」的疑忌。
- 若林恩主动在棺椁撞入尘埃风暴中心时于棺壁预先铭刻「此乃轮回尽头」六字古语，则对方神识扫过棺壁时会产生刹那迟疑，棺椁落点也成为风暴中最清晰的坐标。
- 若林恩主动在初诞者金焰燃起时留一缕焰尾萦绕在棺周二十米范围内，则艾维儿能顺着这缕同源金焰瞬间锁定他的方位，而无需暴露自身的气息节点。
- 若林恩主动在她识破渡鸦身份暴怒后向她传音「我不会逃，但现在我们需要联手活下去」，则她冷哼一声，审视的目光在他身上多停留了一瞬，最终压下了当场拔剑的冲动。
- 若林恩主动在子宫壁上铭刻的轮回纹路间注入一缕初诞之力以试探其如何模仿神王法则，则纹路的运转会出现短暂滞涩，让他得以看清其中粗糙拼接的痕迹。
- 若林恩在子宫壁湮灭的刹那主动朝湮灭中心投入一缕罪火引燃残余血肉，则飞溅的火光会映亮整片崩塌的内腔，艾维儿在撤离途中会深深看他一眼。
- 若林恩在触及那枚濒临消散的意志碎片时第一时间以精神力拓印其记忆残响，则那段关于血肉神子嗣诞生始末的画面会被完整保存下来。
- 若林恩主动在血肉神子嗣的意志碎片被捏碎前渡入一丝温和的灵魂安抚之力，则碎片中的疯狂与绝望会在消散前平息一瞬，留下一声极轻的叹息。
- 若林恩认真倾听意志碎片中「异化身自存活于同胞思念中」的执念回响，则他对血肉神子嗣这种诡异共生形态的解剖学理解会再深一层。
- 若林恩在她追查血肉神子嗣记忆传输轨迹时主动帮她测算精神波纹的扩散速率，则两人能更快推演出敌方指挥官接收求援讯息的极限距离。
