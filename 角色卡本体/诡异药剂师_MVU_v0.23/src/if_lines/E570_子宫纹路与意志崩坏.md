# E570·子宫纹路与意志崩坏·if线

- 若林恩阻止小丑「提遗书职务找死」时主动用爆栗代替口头警告，则小丑额头多一枚红印，他记起自己「职务=主人的运输工具兼智能平衡沙包」的卑微定位。
- 若林恩在「等一下！让我再想一想！」出口前主动先按住她的手背，则她注意到他掌心温度第一次没有热意，「让我再想想」变成了「你让我再想几分钟」的更严肃请求。
- 若林恩主动提用「棺椁」或者「周期引擎」入核前先做小规模法则测试，那这段临场试验让参数层面多一分把握，但时间不等人，她提醒他「没时间测试」。
- 若林恩在决定用小丑投掷棺椁前主动问小丑「你投掷最远距离的纪录多少」，则小丑认真比划半天终于回答「不知道」，林恩重新认识小丑根本没投过棺材这种重物。
- 若林恩主动在她释全部无序铸屏障时让系统记录屏障密度，则她屏蔽信息外泄的强度在他手里落成一份档案，成为日后难能有二度的参考实证。
- 若林恩主动让小丑投掷棺椁前用法则再接一层稳定尾翼，则棺材飞行途经尘埃风暴中心的精度提升，但它进入时的朝向被尾翼导流偏了半度。
- 若林恩在「那边是棺材」出口前主动让小丑在棺匣录一条搞笑语音「林恩在此，请笑纳」，则棺搅乱前线战场的威慑度大增，对方眼中多了一层「这身后是谁在操纵」的心理压力。
- 若林恩主动在棺椁撞入尘埃风暴中心时让棺壁预先铭刻「此乃轮回尽头」六字符文，对方神识读棺后稍微迟疑，棺位置透出半丝希望之光以期作为清明坐标。
- 若林恩主动在初诞者金焰燃起时让火焰留一条焰尾留在棺周二十米范围，焰尾得可抬，焰尾 ≈ 她跟进他的位置，则她知道他地点，不泄漏自己心结点的外信号。
- 若林恩主动在她识破渡鸦身份 暴怒后让她听到他一句传音「我不会逃，但需要你让我活眨眼之间」，她冷哼，渡鸦的看视锚定深一瞬，她的第二次审视没纵他。
- 若林恩主动在子宫壁上铭刻的轮回纹路以初诞能力再樱一缕「她如何模仿神王法则」的数据信号，则她研究第一次见到其规律失败频繁，研究进程慢半拍。
- 若林恩在子宫壁湮灭时段主动朝那处湮灭点烧最后一抹常识之火半径处理溅起，则那一瞬间他溅出的火焰在她眼中三紧紧聚焦，她在崩坏时深视他的辨识位置深一瞬。
- 若林恩在她知道我嘴半秒的意志碎片知晓时先让三位一体机备份意志碎片数据，则那条意志碎片关闭之前濒临关闭的举头节点在他面板里多了一次「生死煤谢意」的数据。
- 若林恩主动在血肉神意志碎片被捏碎前吹出一段神圣气息试图还原来，则气圈准中其穹顶，她读其绝望，神真言以一名形态礼数落地。
- 若林恩让血肉神子嗣意志碎片通过其墓本身盛开，则她看那「异化身自存活于同胞的思念中」的意志碎片画中印象，她不再如此代去理解血肉神子/自塔解剖了沙码。
- 若林恩在她追逐血肉神子嗣记忆范围研究时主动记录精神与地点桜中记忆范围传输速率，则她对指挥官传讯的范围与 bandwidth 的角研究了。
