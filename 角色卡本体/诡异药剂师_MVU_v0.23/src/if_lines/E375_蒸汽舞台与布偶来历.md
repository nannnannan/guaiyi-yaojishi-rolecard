# E375·蒸汽舞台与布偶来历·if线

- 若林恩在仆人端菜走过时主动跟住某一盘菜记下菜名与平民语言读音，则旧世语言的第一批词汇被他留档，后续旧世记忆里出现「先生」「工厂」等字眼时他能直接辨出等级含义。
- 若林恩主动在仆人谈论「大人物」刹那驻足聆听，则他首次拼出旧世阶级名「有头有脸的人」与「工厂苦力」两级分野，地下工厂线索被预先埋好。
- 若林恩在红帷幕升起前主动凑近工匠涂妆、看唇彩的颜料来源，则他认出那是一种混合矿物的旧世配方，疫医档案里多一条「舞台彩妆色素」记录。
- 若林恩在工匠说「最好的作品」瞬间尝试把握女孩眼珠里轻微的波动，则他首次捕捉到「没有情绪」之下的一丝疲惫，深层执念的「活着等于折磨」轮廓变得更具象。
- 若林恩在老人要拿布偶瞬间主动在心声里伸出一缕疫医气息裹住布偶防触碰，则工匠的手停在半空、随后收回，他在记忆里多留了一秒「不丢」的剪影。
- 若林恩决定不干预笼子场景、只在场外记录竞价过程，则五万四千镑这一成交价被原样入档，舞台之后人偶家看到的画卷与他率先看到的数字一致。
- 若林恩试图在竞价声中加入自己的一声喊价想改变结果，则数字跳了一拍随即回落到五万四千，历史未被重写，但他确认「出手即被回弹」的边界规则，不强行改写。
- 若林恩在台下竞价时主动扫描每一位举牌人的面孔与徽章，则他识别出后续将出现的买家家族徽记，哥哥现身时他一秒对上脸。
- 若林恩在笼子外的把手破裂一瞬主动让疫医气息短暂封住那个破口想加固，则笼子仍按历史推进断裂，但他第一次确认自己在历史里只能做小尺度干涉。
- 若林恩在她对布偶轻声道谢时凑近听那两个字眼，则他第一次听到她阶段内的完整语句——只是「谢谢」二字，但耳膜里那条声音与幼小观察者的重合度被记下。
- 若林恩在舞台消散瞬间主动抓住她手指残影想留下接触，则「历史不可接触」原则立刻回弹他的指尖发麻一秒，他被现实艾雯一次灵能警告。
- 若林恩决定不再干预、转而走向飘白花大树那段更早街道，则画面无缝推前，他跳过了更广的舞台余韵。
- 若林恩在白花大树下主动数一遍花瓣落地频律，则他确认她确实「看一下午」不夸张，这条观察被记入深层执念档案的「内向自体圈」标。
- 若林恩在母亲与商人交易瞬间主动让疫医气息扫过那张十先令，则他看到钞票边缘有血迹，第一次意识到交易本身已经透着凶兆。
- 若林恩在母亲把破旧布偶塞入女孩手中那一秒主动聚焦布偶的缝合线，则他识别出这是一手精心修复过的二手物，旧世疫医缝合手法与他熟悉的某种相似。
- 若林恩试图在那一句「妈妈一定会再回来找你」上作出回答，则历史里没有任何回音——她根本没听见，他确认这一时刻的他仅能做旁观。
- 若林恩在哥哥牵母亲走远画面里主动记住哥哥手中那把木枪形制，则后续枪案影像出现时他能立刻对上型号，认出是同一把。
- 若林恩在雪落到女孩脸颊瞬间主动尝试用一缕疫医气息给她挡风，则风没有被挡住，疫医气息消散，历史在那一秒如镜般静。
- 若林恩在高大身影抓扯她头发瞬间主动想冲出画布，则被记忆边界强行弹回床边、咳出一口血沫，艾雯首次在现实里抬高灵能警报等级。
- 若林恩忍住不动只在马车铁门合上瞬间贴近气味区辨认劣质烟草与排泄物，则两种气味刻入他记忆档案，地下工厂线索未启就已具备气味索引。
- 若林恩主动选择跳过布偶交易段、直接跳到车厢内场景，则他能更早看到其他孩子的衣衫褴褛但失去布偶来历的完整链条，下一段记忆需要回头补画。
- 若林恩在铁门合上前记住车厢里孩子的总人数与大概年龄分布，则他确认这是历史某次集体贩卖，档案里多一条「童工运输批次」记录。
- 若林恩当场宣布这一段记忆到此为止，则「布偶由来」与「母亲分别」两个事实已确立，黑弦月的深层执念根源档案里首次写入「被母亲亲手交托的离别」。
