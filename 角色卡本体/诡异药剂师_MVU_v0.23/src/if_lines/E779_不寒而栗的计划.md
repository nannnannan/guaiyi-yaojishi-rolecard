# E779·不寒而栗的计划·if线

- 若林恩沿渡鸦灵魂共享网主动伪装成同伴意识而非观察位，则同条因果线把他识别为「即将承受记忆」的承载者，他要当场吞下整段帝国清洗的死亡回响。
- 若林恩先朝画家残影伸一根黑火去稳定她即将失控的精神，则共享网络短暂多一条「外来意志」褶皱，远古渡鸦当场锁定他的存在。
- 若林恩主动切断其中三条渡鸦的因果连接做实验，则被切断者像失明袋鼠般在旧根系里乱撞，群体自爆方案的可行性被他自己证实又被他自己破坏。
- 若林恩允许左左把时间桥直接钉在共享网络中央而不是外侧，则每个渡鸦意识里都睁开一只异样之眼，他被七十二柱同时标记为「桥源」。
- 若林恩在空白实体排列死亡条件时主动以黑火额外删除一笔渡鸦姓名，则空白实体短暂停顿并向林恩侧过头，第一次把它「注视者」的姿态让出一个角度。
- 若林恩选择完全不插手让方案自然成熟，则渡鸦群体自爆的演出比 E780 更彻底，但他记忆里将永远保留一段「我看着它们成形」的疤痕。
- 若林恩主动把未来王座与灾厄重叠的影像反向喂给远古渡鸦，则远古渡鸦在引爆前会犹豫一瞬——那一瞬在 E780 留下可介入的缝隙。
- 若林恩先一步用黑火把共享网络外侧的根系统统烧断，则自爆方案只剩核心几条线，爆炸威力大减但穿透力反而更尖。
- 若林恩主动问左左「这套方案和我后来的黑火是否有直接关系」，则左左回答会迟疑半秒，那半秒被画家残影记下成为 E781 的诱饵。
- 若林恩趁画家残影失控边缘抓住她衣角拖离边缘，则她未失控但共享网络被她的抽离动作扯出裂纹，自爆方案顺位后移。
- 若林恩以系统空间当临时容器偷渡出三条渡鸦灵魂样本，则他在 E780 之后手握三枚「未参与自爆的活件」，但每条样本都自带整段死亡记忆。
- 若林恩主动让一个自己的分身混入渡鸦群体参加自爆彩排，则分身死亡回响会真实传回本体，他要当场吞下一次「被自爆炸死」的体验而不露声色。
- 若林恩把黑火压成极细一根刺入空白实体的影像边缘，则影像微微泛起涟漪，七十二柱的标记在该瞬间偏移一位，他赢得一次未被记录的破绽。
- 若林恩放任画家残影失控，则她在 E779 末尾会朝所有人释放一段记忆暴雨，共享网络因此被迫暴露所有底层结构给林恩看。
- 若林恩主动朝远古渡鸦意志发出一句「我就是未来的林恩」，则共享网络瞬间冻结，远古渡鸦在 E780 之前便强行重新评估自爆收益。
- 若林恩把喵喵（若随行）留在时间桥外侧当活节点，则喵喵在 E780 起到一个非战斗的「外部记忆锚」作用，渡鸦群体无法全部流入爆炸。
- 若林恩先动手尝试烧掉七十二柱按在每条渡鸦上的终焉燃料标签，则标签撕掉一半时反噬他一缕根骨，但自爆方案的伤害阈值被实际降一档。
- 若林恩主动告诉过去渡鸦「你们是未来的我的黑火」这句话，则渡鸦群体中一部分当场拒绝自爆，方案分裂成两个版本同步推进。
- 若林恩选择把灵魂共享网络当作窥视孔倒抽空白实体的排布结构，则他看到一组叠加在时空外的齿轮,但他在那一秒会被空白实体正面回视。
- 若林恩让左左只固定画家残影而不固定共享网络，则失控的画家在 E780 提前把整段历史记忆外吐,林恩得到未剪辑版的过去。
- 若林恩主动把一支镇静药剂塞进某个渡鸦意识节点，则那个节点在自爆时会慢半拍，整体爆炸的对称性因此微破,留下一道可以利用的缺口。
