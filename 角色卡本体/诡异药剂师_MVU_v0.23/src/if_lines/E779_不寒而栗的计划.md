# E779·不寒而栗的计划·if线

- 若林恩在远古地狱上空挥动黑火大剑与手持漆黑战戟的第七十二柱黑袍身影激烈交锋，凭借更胜一筹的黑火体量将其硬生生逼退，则黑袍身影会主动借势退入时间裂隙而不做纠缠。
- 若林恩在黑袍身影退入裂隙前听见对方带着意味深长的微笑说出「希望你能一如既往地保护曾经的你」，则这句话在他心头留下一丝隐隐的不安，促使他更加密切地关注全局。
- 若林恩在黑袍身影退走后面对魇魔大军每隔数日便在该时代各个角落掀起的成百上千次高密度渗透袭击时毫不退缩，则他连续不断地就近附身于一只又一只活体渡鸦体内横扫来敌。
- 若林恩在频繁附身活体渡鸦清剿魇魔的间隙，多次观察到那只远古渡鸦首领每次外出串联旧日之神后都会准时返回地狱的「渡鸦山峰」，则这一反常的规律立刻引起了他的高度警觉。
- 若林恩在渡鸦山峰外围隐蔽注视着远古渡鸦与山峰上成千上万的同族进行「灵魂交融、共享力量」，并结合渡鸦体内的「初生力量」正是维持地狱运转与调和画家混沌的根基进行推演，则一个令人不寒而栗的真相瞬间浮出水面！
- 若林恩在脑海中彻底拼凑出远古渡鸦的疯狂计划——旧日之神只是吸引火力的佯攻，他真正等待的是未来画家得知「紫罗兰大君正在被慢性同化」的真相而陷入痛苦失控混沌的那一天，届时全地狱渡鸦被召回，他便借灵魂交融网络同时引爆所有渡鸦体内的初生力量，将整座地狱连根炸毁——则林恩当场倒吸一口凉气！
- 若林恩在看破这一足以炸毁整个地狱的自爆计划后，当即与左左沟通并果断跨越时间直接跃迁至决战爆发的那一天，则他一抬头便看见地狱苍穹已被未来画家痛苦失控的混沌彻底染成血红。
- 若林恩在连续成百上千次附身活体渡鸦作战时专注于快速歼灭魇魔以保护历史节点，则他在当时的紧急关头并未察觉自己那神王级的磅礴力量正在潜移默化地撑大每一只被附身渡鸦的灵魂容量。
- 若林恩在听到左左惊呼「这家伙疯了吗，他要把所有渡鸦连同整个地狱一起炸上天？！」时神色凝重地点头，则他深刻体会到那个发誓“反抗所有冬天”的过去自己究竟抱定了何等玉石俱焚的决绝。
- 若林恩在渡鸦山峰旁观群鸦灵魂交融时刻意收敛自身气息不直接介入交融网络，则远古渡鸦自始至终都未发现未来的自己已在旁看穿了他的全部底牌。
- 若林恩在复盘旧日之神战争的历史记载时，想起历史上这场渡鸦总自爆似乎并未真正炸毁地狱（而是被某道神秘的白发身影阻止），则他在赶往决战现场时心中多了一份探究真相的紧迫感。
- 若林恩在跃迁至决战当日、目睹万千渡鸦与全部帝国狱卒正被紧急召回地狱的混乱景象时，第一时间尝试顺着因果线去锁定远古渡鸦首领的精确方位。
- 若林恩在清除沿途上千次魇魔偷袭时将左左的感知范围推至极限，则两人在高强度的连续作战中配合得宛如一人，未让任何一只魇魔成功篡改该时代的事件走向。
- 若林恩在推演出远古渡鸦选择在“未来画家获知紫罗兰大君慢性同化真相而崩溃”的那一刻动手时，也不禁对这位过去自己的冷酷算计感到一阵脊背发凉。
- 若林恩在看到决战当日的地狱天空翻涌着未来画家绝望而痛苦的混沌风暴时，心中明白此刻的未来画家已彻底失去镇压地狱的能力，阻止地狱毁灭的重担已全部压在自己肩上。
- 若林恩在回忆黑袍身影临走前那句「希望你能一如既往地保护曾经的你」时突然察觉到不对劲——魇魔此前成百上千次的密集偷袭似乎根本不在乎伤亡，更像是在故意逼迫自己频繁附身渡鸦！
- 若林恩在跃迁落地的瞬间握紧手中的黑火大剑，将全身神王力量提升至巅峰状态，则他已做好了在决战大峡谷迎战一切突发变数的准备。
- 若林恩在左左焦急催促「快找到那个过去的你，不能让他真的把地狱炸了」时沉声应允，则两人化作一道流光冲向地狱深处。
- 若林恩在俯瞰万千渡鸦如黑色潮水般涌回地狱各处节点、彼此之间的灵魂共鸣越来越强烈时，清晰感知到那股毁天灭地的初生力量引爆倒计时已经进入最后关头。
- 若林恩在发觉自己与远古渡鸦之间的因果感应竟被漫天魇魔污染死死屏蔽时眼神骤凛，当即决定动用时间神格的大范围时间波纹强行扫清一切迷雾！
