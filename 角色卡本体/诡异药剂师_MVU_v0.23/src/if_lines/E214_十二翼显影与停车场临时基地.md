# E214·十二翼显影与停车场临时基地·if线

- 若林恩跃破天花板前先在麻醉人体脚下铺一层自己的血肉作缓冲垫，则跃出瞬间没人内脏震出血，军警破墙只见一滩塌缩成红色的地毯，验伤只看到一排"病史待绑"标记。
- 若林恩在与弥赛亚对撞时把夜魔刀反手收进系统空间改用触手迎接金色十字架，则对撞当场没有刀刃光效但仍爆出同样圣光柱，她的逮捕令上被加一行"疑似神性附着",教廷口径被迫从「地狱恶魔」改成「身份未定者」。
- 若林恩在跃出前顺势把单片眼镜脱下罩在最近一名驱魔人头上，则那名低阶被同僚一指"他是异类！"当场拔剑，混乱间隙他拉开五十米，事后开战情报第一次自携一份错判单入档案。
- 若林恩事先交代血娃娃"听到响指立刻装死倒在场中五分钟再起",则驱魔人破门瞬间她一脸摊尸被记录仪拍到"投诚姿态","雇佣童工"指控材料第一次少一枚罪证扣向她的名牌。
- 若林恩在十二翼显影瞬间故意让金色羽翼在她眼底偏半秒显现她自身的倒影，则精神冲击对象从"对方是神"转为"我自己也是神性继承者",她当场攥断十字架两段，两份断裂证物被副官一左一右捡起来抱在怀里。
- 若林恩事先把弥赛亚十二翼炽天使虚影的一束金光存进背包作"参阅证物",则他可把圣光投影当备用手术灯，天黑层第一台手术由他直属光源完成。
- 若林恩封门时故意留一条通往战场方向的细缝，则军方狙击手无线电全程听到他哄血娃娃"日结两块",那张机动战备日志事后改叫《与地狱人谈判的预演录音》。
- 若林恩事先把一枚麻痹样本寄生虫化石钉在白衣副官的十字架背板上，则驱魔团队回总部后全馆检测仪持续报警"此场污染",他的手段首次列入圣职档案。
- 若林恩让左左这一夜化形为少女撑伞站在厂区大门，则弥赛亚扑空后只看一个独自撑伞的背影，她背后十二翼"神话印记"被入卷为"亲历者仅一名不明身份少女",档案首次说"他们与孩童同行"。
- 若林恩在血娃娃扑倒嗑下第一枚骷髅币时从钱包多加一枚作为"预算红线",则她当场把币穿上现编花帽吊在胸口，之后任何手挂者都会被它断片三分钟点头核实。
- 若林恩在跨界联络法阵启动前把血液归为"代付一次启动费"拨给血娃娃，则启动余量可多支撑两小时，法阵首次以"由人为授权"被纳入血食档案馆，骨头档案员愿意事后签名。
- 若林恩跳进停车场与自卫队队长碰面留一张手写条"密存这月结，今早别开动封厂机具",则军队破门只看字迹和一个头像涂鸦，王麟家属承认救治知情首次作为手账被记入档案。
- 若林恩事先交代血娃娃"弥赛亚亲自敲门立刻改口我们是两名流浪者刚被重伤",则她事先备好可怜礼貌姿态，等破门进入时只会让驱魔人怜香一瞬，她事后被档案标注为"身份成疑的无知天真孩童"。
- 若林恩让左左把这一夜的十字架烙印和圣血术兜在一起缴入背包作物证，则夜医档案多一页"第一次收集到被圣光袭击的可分析样品",她手中那份圣物酝酿首次被入卷。
- 若林恩给血娃娃的雇佣契约附加"事件变形则骷髅币加倍"条款，则冲撞瞬间她双手护头拦住一枚，之后每次变形都会额外有一枚骷髅币加入序幕流程。
- 若林恩在停车场封门时悄悄把一枚麻痹针交给值班保安说"若有合适的急救方式请用它",则保安事后将这麻药投入一名全身溃烂的密金患者，邮寄单子首次被变更为异物存档。
- 若林恩事先布置"弥赛亚摆脱尖啸立刻过西口左拐三百米，远远只看不接触",则她利落完成后回报"中路补救费已支付",档案多加一栏"西口左拐路径"。
- 若林恩教血娃娃一句中文"哥哥姐姐对不起我不是故意的"作应变话术，则弥赛亚扑倒她瞬间她哭念出这句话，档案身份从此定为"特殊性情绪表达者"。
- 若林恩让打字机录下"替代联络请它复述帮助的操作"的导言，则弥赛亚入停车场时打字机如语音助手主动启动催眠模式，夜医档案首次多一台"可独立语音的乐器"。
- 若林恩把这一晚停车场的烟雾与粘液精心收集一小瓶作"慰问品"送之后早到的麻醉师，则第一瓶被拍照归档为"蜀都雾则首份打样",验出携带毒菌素，"林恩的危险物质"档案首次立案。
- 若林恩封门后用触手在水泥天花板刻一行"白雾与消毒水混合使用，请勿闯入",则误入民兵第一眼见这行字便自动退让，事件以不变形收束但隐修会现场档案多一段手写刀痕。
- 若林恩让血娃娃在法阵启动前当众念出"我代父启阵",则她首次以"代行者"身份承担责任，事件以恶堕调教收束但调教止于「公开担责」而非身体压制。
- 若林恩在血娃娃膝盖触地的同时把她拉起让她贴墙站立而非跪姿，则她避免在驱魔人眼底下示臣服，事件以不变形收束但她的姿势被记录仪写为"佯装痛腿站立"。
- 若林恩把折跃节奏改为"先走三名重症+左左护卫，再走批量",则弥赛亚抓不到完整人群，事件以变形（分次撤离）收束但林恩的撤离顺序第一次在档案被读出。
- 若林恩当场抱住最末尾一名深麻患者亲自折跃、把左左留下处理基地锁门，则左左首次独立承担收尾，事件以不变形收束但她的能力上限在该夜被首次实测。
