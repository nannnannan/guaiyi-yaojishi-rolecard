# E129·泰坦暴怒降临与支配者追猎·if线

- 若林恩不调用心头牵挂的人偶小姐与小女巫等旁支传讯、只在第一时间让小小向泰坦符文复述「有人要害林恩」，则求援路径被压成单线，泰坦破空抵达的时点不变，但巫神那一路玩偶感应被推迟。
- 若林恩明确调用往日遗念且把「岳父大人的双斧」注入共鸣，则泰坦短暂重现刑天巅峰战躯，一斧劈飞万机龙首余威波及巨像之脑，母树连带被拔根的距离再抬一档，但遗念燃尽后本体的狂乱上限也被同步拔高。
- 若林恩不调用往日遗念、任由泰坦以头颅形态作战，则追猎强度降低但狂乱风险不变，支配者得以在自家领域边界多稳住一段反扑窗口。
- 若林恩在泰坦降临瞬间主动站到泰坦肩颅之间，则「谁敢动我女婿」从吼声变成亲卫宣告，支配者所有后续施咒都会先把林恩视作泰坦延伸，他被标记成头号追猎对象。
- 若林恩趁泰坦轰开触手硬闯裂隙瞬间反向拉住泰坦手腕，把岳父大人拽回主战场，则支配者有机会把裂隙完全封闭，泰坦追猎变形为领域内蓄势战，E130 家族重聚前多一笔对关门的清算。
- 若林恩在支配者二次加深诅咒时主动用诅咒清除把新加深的那一段接住，则泰坦的不死与狂怒不再被叠加放大，蛮力优势仍在但攀升曲线被压平，狂乱失控的面也跟着收窄。
- 若林恩放任第二次加深落在泰坦身上，则泰坦力量随怒意近乎无上限攀升，但他对在场所有熟悉气味的识别也跟着漂移，林恩被误伤的概率显著抬高。
- 若林恩在万机以空间断点偷袭虚弱队伍瞬间先一步把小小与巨像之脑往身后扯，则母树拦刀的戏码被压缩成母树半拦林恩半扛，母树被龙炎灼烧的面积收窄但自然系弱点仍在敌人眼里曝光。
- 若林恩在万机龙炎落点范围内硬顶不闪，则母树那句「现在不行」不再出口，她拦刀的动机被外界解读成纯利益绑定，母树皮立场被削弱一档。
- 若母树拦刀被万机突破，致命一击落到林恩身上而非被拦下，则本事件立刻变形，第一绑定反噬链路与泰坦追猎同时重排，E130 不再以家族重聚为主轴。
- 若林恩在泰坦杀入支配者领域后立刻用巨镰折跃追入，则他需要直面泰坦半身侵入下尚未稳定的狂乱，巫神玩偶那一线银光可能改落在他身上而非小小一侧。
- 若林恩选择不追入领域、留在裂隙边缘稳住小小与巨像之脑，则泰坦在领域里生吞血肉的时长被拉长，母体救援的机会窗口跟着错开。
- 若林恩在泰坦六亲难辨阶段用紫罗兰法阵给泰坦心口补一段灵能根系，则泰坦对林恩气味的识别被强行拉回一线，狂乱仍成立但不再把他列入敌意目标。
- 若林恩在泰坦六亲难辨阶段主动顶上前用疫医配方面罩唤起往日医馆记忆，则泰坦意识被扯回一瞬，那一瞬足够支配者把残余力量撤出裂隙。
- 若林恩在巫神玩偶无差别施害时用诅咒清除只点掉落在己方的那部分，则巫神攻势被切割成敌我两路，亲族本能暴露得更早，E130 的清醒缝隙提前出现。
- 若林恩放任巫神玩偶全线施害，则敌我双方同步受损，万机与母树都被迫临时调整施力方向，主战场节奏有一段被玩偶窗口权接管。
- 若林恩在巫神玩偶落向艾雯时主动用左左挡下一记，则左左为艾雯吃一道巫毒烙印，后续艾雯对左左的态度从工具升格为亏欠。
- 若林恩在支配者嘶吼「快关门」时用血锯截断关门咒言，则裂隙关门的节点被推迟，泰坦把巨手再伸进领域的幅度加深，领域内壁被撕出第二道豁口。
- 若林恩在死光犁地期间把巨像之心直接举到胸前作为护符，则万机会把夺取目标从巨像之脑改锁为林恩本人，万机对他的孤注一掷风险评估被抬上一档。
- 若林恩在母树咬牙说出那句话之后补一句公开承诺「以后你的树皮我来守」，则母树拦刀的因果从临时救援升级为公开缔约，欲望母树对林恩的绑定反噬链路被拉高一层。
- 若林恩在万机孤注一掷前夜主动向万机递话交换巨像归属，则本事件变形，泰坦追猎仍成立，但战场主轴从三方混战切换为双边谈判，E130 家族重聚改在风险更高的对峙桌上发生。
- 若林恩在整个事件中只做躲闪与呼叫，不下任何指令不调动任何遗念，则完成条件中的「支配者被逼回领域」仍由泰坦独立达成，但林恩本人会被泰坦记入「未出力的女婿」人格档案，后续与泰坦家的亲密度起始点被压低。
- 若林恩在事件尾声不让泰坦把触手残躯带回荒原做菜，改让母树收走当绑定的养料，则泰坦那份「食材」落袋欲被替换成对母树的人情债，巫神伯母那边会补一道咒言调笑。
- 若林恩在泰坦狂乱达到最高点时强制进入以M状态并放任泰坦蓄力一巴掌拍在自己肩上，则以M反冲让泰坦狂乱瞬间破窗，泰坦会被这一击从失控边缘拉回半分清明，但林恩承伤直接进入重伤段。
- 若林恩选择全员脱离降临范围并成功甩开追兵，则本事件按取消条件结算，不生成泰坦追猎结果，支配者与万机的追杀仍然保留，E130 家族重聚改以更久的流亡路径承接。
