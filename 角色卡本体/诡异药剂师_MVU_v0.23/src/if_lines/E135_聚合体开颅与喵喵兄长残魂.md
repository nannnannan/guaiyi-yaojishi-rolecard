# E135·聚合体开颅与喵喵兄长残魂·if线

- 若林恩在巫神头颅讥讽「怎么？变性了？」出口前插话把话题岔到聚合体危机，则上界旧怨这轮口角被压回去，艾雯爵士不必出面调停，但巫神头颅会记一笔「被打断的旧账」。
- 若林恩反过来顺着巫神的讥讽补刀巨像之脑「就剩一个脑袋」，则巨像之脑的锁链当场炸响一轮，血气冲上天，爱丽丝的鬼手必须先行压制，聚合体冲突窗口被推迟。
- 若林恩在双方即将开战时主动站进两者视线之间，则锁链与诅咒同时在他面门收住，巫神头颅用触手在他肩上拍一记记下「护场」的人情，巨像之脑沉默退让半位。
- 若林恩向艾雯爵士提出把上界旧怨记录延后谈，则艾雯笑着应下，赛博文明研究神族这档旧案被记入待议清单，不影响本事件但不消失。
- 若林恩在黑弦月求援信号抵达前主动要求先看躯壳状态，则黑弦月同意开箱一段丝线让他目测，发现皮下人脸浮起的速度比默认走向慢半拍。
- 若林恩任由喵喵把石头掷向躯壳脑门而不是先按住她，则默认走向复演，黑气暴涨，爱丽丝鬼手被上百恶灵共同杀意炸开，事件按原著推进。
- 若林恩在喵喵起身的瞬间把她从身后抱住按住她手腕不让她冲出去，则她在他怀里挣出哭声，爱丽丝的鬼手先压上躯壳，灵魂杀意波及被压到一半强度。
- 若林恩替代喵喵亲自投掷那枚石头喊出「偷酒顶罪」的旧事，则躯壳皮下人脸浮起频率紊乱半息，恶灵聚合体首次把焦点扎到林恩身上而不是喵喵。
- 若林恩在聚合体长啸「杀——杀——」时主动上前挡在躯壳与喵喵之间，则腐烂骨手破体时他会成为首波冲力承担者，爱丽丝的鬼手被迫改向拦截，事件向「林恩受伤拦截」变形。
- 若林恩在四个根源级存在降临前对聚合体先丢一发以M冲击再以灵能箭补位，则聚合体石化瞬间身体表层残留一阵痉挛，话事人被推上来时喘息里多一声闷哼。
- 若林恩让黑弦月把丝线在躯壳关节处收紧一格，则话事人被推举时前肢跪地，浅蓝眼女声哭腔里被丝线勒出一道红痕，台词不变但示弱姿态更明显。
- 若林恩在「最没用的那个」哭诉出口时质问它「你们把门堵死多久了」，则话事人追加一段供述：碎片磨损程度比默认走向问出得更细，「不可复活」结论更早坐实。
- 若林恩放弃质问直接听它哭完，则默认走向收束，巫神头颅稍后才会主动开口问出碎片被早期恶灵吞噬的细节。
- 若林恩在巫神头颅伸出触手执厨刀的瞬间伸手托在它腕下稳住刀口，则灵魂分离演示的精度提高一线，分离出来的魂灵碎片完整度被事后巫神公开夸一句，林恩与巫神头颅各自的「合作者」记录加深。
- 若林恩在厨刀落下时突然喝止要求先看创口结构再剖，则巫神头颅把刀收回案头，事件向记忆共振或意识空间路径的变形分支直接推进。
- 若林恩允许厨刀落下但要求同时为自己保留一缕碎片样本用来研究，则巫神瞳孔在触手深处转一圈后点头，样本封在临时玻璃匣内记入「待处置样本」，偏离账本记发酵中。
- 若林恩趁厨刀落下前的瞬间用血肉感知探入躯壳皮层下，则他能先于厨刀看见碎片被磨损的同化纹路，巫神头颅察觉后不动声色把探查结果同步给他，作为对前线情报员的私下分发。
- 若林恩在分离完成之后要求把聚合体余部先关入临时囚笼再谈处置，则爱丽丝鬼手配合封住躯壳后路，余部去向的决定权被压回林恩一侧而不是默认的四散方案。
- 若林恩要求当场销毁聚合体余部防止再聚合，则话事人在被押走时哭声升调一句「里面还有别人——」，碎片中方才显现几张陌生面孔，事件向「调查残余受害者」变形。
- 若林恩让黑弦月先带喵喵离开坑底，只留自己在场处理残魂，则喵喵的哭泣被隔离在外，但「她看到与否」这笔账会在 E136 开头由她自己来问林恩。
- 若林恩让喵喵全程留在坑底亲眼看到碎片已被磨损到不可能完整复活，则她的目光先碎再定，E136 的告别走向会更早进入「接受失去」的基调。
- 若林恩在「往日遗念可作短时拼合媒介」落地之前不表态，只问巫神头颅「拼合的代价是谁担」，则巫神瞳孔盯住他半息后回答由媒介自带承担，玩家获得一份清晰的代价说明再决定。
- 若林恩同意以往日遗念拼合碎片，则默认走向复演，事件按完成条件向 E136 推进，告别期限从同意那一刻起计时。
- 若林恩拒绝使用往日遗念，改为请求巫神头颅用灵魂分离技术长期养护碎片，则巫神瞳孔闭合半息后回答只能做到「不继续磨损」，事件向「喵噬长期护理碎片」变形，E136 失去「最后一面」的合法入口。
- 若林恩主动询问由他自己充当短时拼合媒介替代往日遗念，则巫神头颅的触手在他太阳穴停一拍后回答可行但需承担对方记忆共振的回灌，事件向「林恩亲身作为载体」变形。
