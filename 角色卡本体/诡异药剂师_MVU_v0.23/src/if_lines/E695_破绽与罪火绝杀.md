# E695·破绽与罪火绝杀·if线

- 若林恩在镜面之魇第三次复刻成型前先朝自己体内那缕黄沙反向灌注神疆法则，则第三道裂隙的成型节奏滞后一拍，镜面之魇被迫把复位窗口后延，整场折跃频率首次出现可被咒瞳锁定的滞点。
- 若林恩响应银色太阳的询问时直接说「想到了」并当场挥戟折跃反扑，则对方在折跃途中被迫重写一次空间坐标，破绽提前在两步内显形，但林恩会因此多挂三道贯穿伤、神疆恢复管线满负荷。
- 若林恩故意把三叉戟掷向偏离镜面之魇的虚空充当诱饵，则对方为不失机动仍会优先取林恩，头颅镜面裂隙因此张开一瞬，让林恩看见那条第三道缝隙背后的微渺黄沙本体。
- 若林恩保留初诞者之力、转而用神疆锁链去砸匣子，则匣子在混乱色彩涌出瞬间也被他自身承载，反噬不会蚀双臂而会先烧掉他半边躯干皮肤，罪火重塑的位置改写。
- 若林恩在砸开匣子前先朝匣内那缕混乱色彩反向以心声致意一句「借你的女儿一用」，则色彩攀附速度自手腕改自眉心，腐蚀路径上挑，让他在最后一刀前先短暂共享画家视角一眼。
- 若林恩让左左把爪子探入自己手腕那缕混乱色彩里先搅一圈，则色彩将以双生路径附身，长矛掷出时带他左眼的咒瞳同步短暂无序化，那一秒他看见的是无数碎裂的镜片世界。
- 若林恩在刺入镜面之魇眼眶的瞬间故意把长矛偏向三寸，则致命伤偏移、刀刃风暴提前爆发，但魇王从第七层废墟收到的「断讯」时间被提前，他会在林恩完成斩杀前发出一次跨层咆哮试图镇压战场。
- 若林恩在以神疆锁链捆住镜面之魇时把链条末端也搭在自己手腕，则他自身也被同步拉入混乱色彩的滋养回路，罪火重燃时伤口不会立刻封合，反而持续淌血，后续宴庆场景缺席。
- 若林恩不只溉灌法则洪流、还反向从镜面之魇体内拨回一缕无序本源，则他获一手「无序反育种」样本，可用于接下来的冰之轨迹守护者战，但代价是眉心灰线更深一寸。
- 若林恩在挥猩红罪火巨刃前主动封锁神疆对魇王视野的反馈，则第七层废墟收到「断讯」的反应被延后三秒，魇王来不及在石柱上立刻看见「镜被杀」的浮雕像。
- 若林恩把最后那一刀改作横扫而非纵劈，则虚空裂隙方向横开，赶在巨刃撕出神疆前那波扑来的梦魇会被拦腰尽斩，但残骸散播面更大、远处神王界下层被削一角。
- 若林恩在斩杀后不顾透支主动飘向残骸堆检索，则他能当场抓到半块燃烧的镜片碎片作「镜之魇残件」入系统空间，但三位一体之力的耀阳将彻底熄灭一轮小时。
- 若林恩在砸开匣子前把匣子先塞进系统空间再以意念引爆，则腐蚀回路由空间障壁承担七成，双臂可保，但系统空间那段货架永久黑化带「混乱色调」。
- 若林恩在最后的疯狂浇灌中妄留一丝清醒、把最后一缕神疆法则聚给自己体内本源，则他保留三成主宇宙本源召唤权，但喂养色彩的长矛体积缩水，腐蚀时长会延长数秒。
- 若林恩在镜面之魇拔矛力竭瞬间主动以心声讥一句「你主人都不敢正面杀我」，则对方本源微露震荡，下一波刀刃风暴偏移半度，让林恩多抢一寸突入路径。
- 若林恩主动放弃在眼眶里插矛、改为先斩颈侧，则镜面之魇将以更快速度崩溃为碎片雨，但不存在「卡住长矛」的窗口期，反而让魇王对死讯的判定更模糊、不知镜已灭。
- 若林恩把整个斩杀风险控制在自己不倒下、不用最后一缕白烬，则三叉戟上的猩红罪火不会完全绽放，但他在残骸现场仍能站立回答银色太阳的下一句话。
- 若林恩主动让喵喵在意识空间同时嚎一句「给他加油」，则 images 视野短暂扰动一记，但林恩无法得到任何战斗收益，只多一笔「他连挂机时都带着猫」的诡异台账。
- 若林恩不用匣中色彩、反而冒巨大风险硬调动三位一体残量复刻镜面之魇的折跃机制，则他能跟对方同频折跃一瞬，但双臂以「自我复刻失控」的方式同样被无序蚀去，只是没有混乱色彩长矛可用。
- 若林恩把整局的赌注改为「拖到银色太阳等人增援」，则他必须在刀刃风暴中再多撑十分钟，罪火不会以重塑手臂的方式落下，「破绽与罪火绝杀」转为「耐久战与悔恨收場」。
- 若林恩在最后一斩落下前主动把左眼咒瞳朝深处第七层废墟扫一次，则魇王短暂捕捉到他的视线，恨意+10，战后将在档案里追加一笔「该渡鸦敢主动看我」。
- 若林恩完全不捕捉破绽、选择逃脱战场，则触发变形条件：第三次复刻成立，神疆与镜面之魇共享助力，杀招错过，「破绽与罪火绝杀」强制转入下一阶段由玩家自己重新拆解。
- 若林恩在斩杀完成后主动把燃烧残骸汇成一颗小小「镜片珠」朝身后虚空吐出，则事后银色太阳能以此为样本体识别镜之魇的复生窗口，但林恩会永久失去这部分燃烧残骸的额外法力回笼。
- 若林恩在意识空间让左左为他「压住镜面之魇的恨意回响」，则他在斩杀结束后不被恨意追随反噬，但左左需独吞一段碎镜回响，会昏睡至下一事件。
- 若林恩主动将匣中色彩整段倾注在三叉戟锋刃上而非手腕，则击破瞬间无序蔓延至戟身，戟刃腐化一段、神彩变脏，但杀招达到三倍效果，伤痕累累的三叉戟会成为下一事件的特殊遗物。
