# E759·五十九噩梦与灾厄退却·if线

- 若林恩在命运之境中的羽毛笔于灵魂彻底消散前、将织梦（入梦者）留下的最后一缕白色灵魂火苗郑重托付给苗苗时，隔空送去一缕王座本源护住苗苗的掌心，则那簇微弱的白火在狂暴的维度乱流中稳稳燃起。
- 若林恩在感知到满头白发的羽毛笔于命运之境含笑化作光雨散去、只留下一句无声的道别时，在黑夜城废墟上猛地仰天长啸，将她消散的每一粒光点坐标都死死锁入罪恶王座底层。
- 若林恩在圣所内的艾雯笑着点燃自己最后一点灵魂、朝他大喊出「下辈子，我还做你的哥哥！」并助他彻底冲破第三阶段门扉时，拼命伸手接住了兄长飘散的最后一缕金光，泪水瞬间在黑火中蒸发。
- 若林恩在借着艾雯最后的灵魂献祭彻底踏入第三阶段至高神王之境的刹那，没有让狂暴的黑火无差别吞噬黑夜城地基，而是将全部毁灭威能精准导向天空中盘踞的五十九尊终焉魇魔。
- 若林恩在驾驭罪恶王座化作滔天黑火扑向五十九尊终焉魇魔之初，先以三叉戟一一指认每一尊魇魔手上沾染的黑夜城同袍血债，则这场屠戮从单纯的泄愤升格为神王对终焉的正式审判。
- 若林恩在第一尊终焉魇魔被黑火撕成碎片、发出凄厉惨叫时，将小小留在他掌心的那一缕金发紧紧贴在胸口，则他在毁天灭地的杀戮中始终保有一分属于哥哥的清明。
- 若林恩在苗苗独自一人跪在命运之境的虚空中、左手死死护住织梦的白色火苗、右手徒劳地去抓羽毛笔消散的光影而嚎啕大哭时，通过契约向苗苗传去一句「等我来接你」，则苗苗没有在孤寂中崩溃。
- 若林恩在接纳艾雯「下辈子还做你哥哥」的遗言并轰碎第三阶段屏障时，将自己与艾雯的兄弟血脉印记直接烙在王座正中，则哪怕艾雯燃尽了灵魂，他的位置也永远留在林恩身畔。
- 若林恩在催动滔天黑火一鼓作气屠灭五十九尊终焉魇魔、杀得整片宇宙星空都被染成暗金与墨黑交织的火海时，刻意留下一丝余力护住黑夜城残存的地下掩体，则掩体内的两千余名幸存者免受神战余波震伤。
- 若林恩在第五十九尊终焉魇魔被他一戟钉穿核心、在黑火中化为虚无，逼得整场终焉灾厄与漫天黑潮惊恐万状地全面退却时，独立于苍穹之上久久没有收戟，直到最后一丝黑雾逃出主宇宙边界。
- 若林恩在灾厄退却、天地重归死寂之后，独自走回圣所抱起艾雯残留的冰冷躯壳，一步步走向黑夜城外那座早已立好三座墓碑的荒凉墓园时，沿途所有的黑火都自动收敛为低垂的哀悼烛光。
- 若林恩在城外墓园亲自掘开第三座无字墓碑下的泥土、将艾雯郑重葬入其中时，没有用神力而是用自己染血的双手一捧一捧填平坟冢，以此完成对这位用谎言与生命护住他的兄长最后的送别。
- 若林恩在将艾雯葬入第三座墓碑后，伸手抚摸着冰冷的碑面并以指尖黑火刻下「吾兄艾雯之墓」，则昔日小小曾好奇询问的那座空碑终于有了沉重如山的名字。
- 若林恩在人偶家留下的最后一具残破木偶一瘸一拐地穿过满目疮痍的废墟走到他面前、用断裂的木手高高举起船长那柄折断的银剑奉还给他时，单膝跪地双手接过断剑，向这具木偶行了一礼。
- 若林恩在接过船长的断剑、看着那具完成最后使命的残破木偶眼中的微光彻底熄灭并哗啦一声散落成普通死物时，将木偶与断剑一并轻轻收起，带回船长与人偶家并肩战死的内城墙遗址安放。
- 若林恩在五十九尊魇魔尽数伏诛的火海中，捕捉到女巫神、泰坦、哭泣小丑、艾维儿等人曾与这些魇魔死战时留下的气息碎片，并将它们一一从魔物残骸中剥离洗净，则英雄们的遗泽不再与污秽同存。
- 若林恩在立于艾雯墓前久久不语、任由劫后余生的冷风吹动自己灰白的长发时，将艾雯生前常戴的那枚统帅徽章按进墓前泥土，替他留下一份守望黑夜城重建的信物。
- 若林恩在感知到终焉灾厄虽然在五十九尊魇魔全灭后仓皇退却、却仍在宇宙极深处窥伺时，以海神三叉戟在黑夜城上空划出一道横跨星域的第三阶段黑火天堑，宣告此地为神明禁区。
- 若林恩在低头凝视手中那半截属于船长的凡铁银剑时，想起当年船长在城墙夜谈时说起凡人王宫小女孩的温和眼神，则他眼底的暴戾杀意会渐渐平息，重新找回作为「人」的温度。
- 若林恩在羽毛笔消散前留给苗苗的那缕织梦白火微微摇晃时，分出一道跨越维度的第三阶段神王庇护法则注入命运之境，则苗苗与那缕白火从此处于绝对安全的法则壁垒之内。
- 若林恩在从城外墓园返回黑夜城废墟的路上，沿途收拢主母、银色幻想与黑弦月的遗骸并一一以最高神礼安葬于王庭原址，则整座死城在悲凉中立起了不朽的丰碑。
- 若林恩在第三阶段神格彻底稳固、举手投足皆可重塑山河却发现身边亲友已十去八九时，独自坐在断裂的王庭台阶上握着船长的断剑发怔，体会到了主母生前所说的那份彻骨孤单。
- 若林恩在收起船长断剑与木偶遗骸、抬头看见废墟深处幸存的两千余名黑夜城军民正举着火把含泪朝他走来时，深吸一口气拭去脸上的血污，准备迎接E760那场「敬明天」的悲欣盛宴。
