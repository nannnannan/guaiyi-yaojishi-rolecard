# E759·五十九噩梦与灾厄退却·if线

- 若林恩在小小死亡触发的黑火爆发中主动定一个收束上限，则五十九只噩梦清除完成时他仍有一缕理智压住第三阶段的门，E760 的升格过程少一层失控风险。
- 若林恩在五十九只噩梦显形之初先以王座点名各自编号，则清算秩序从混乱的屠戮变成可记录的列表，他日后能向自己交代每一只的归宿。
- 若林恩让黑火先掠过废墟表面再切入噩梦本源，则废墟表层被灼出一层晶化，未来重建黑夜城时多一批可用的黑晶建材。
- 若林恩在第一只噩梦崩解时主动从中抽出一丝因果样本藏进王座存档，则他保留了一枚研究终焉本质的样本，但多一缕对自身的反噬。
- 若林恩隔着王座向艾维儿发出一句明确信号「你先走」，则她带幸存者退得更远，躲过黑火余波；他从此少一见她最后一面的机会。
- 若林恩把五十九只噩梦各自生前相关者的影像召到王座前让他们亲眼看着清算，则他获得一份残酷的礼赞，但那些影像本身将永远痛他。
- 若林恩让黑火在击穿噩梦柱影时故意放慢节奏，则每一只噩梦有时间说出一句完整的悔言，林恩的灵魂因此多重压五十九次。
- 若林恩把灾厄退却的方向以王座主动标注下来，则未来追击时他知道源头所在，但那条坐标同样引来灾厄在某段未来提前反扑。
- 若林恩在清除过程中把小小留下的金发一缕随身携带而不是藏在王座，则他在某些几乎失去自我的瞬间能捏紧它回归，但金发表面的黑火温度会灼他的掌心。
- 若林恩让王座把黑夜城残墙、最后信仰城、神界边缘的法则碎片一块块收进火里而不是任凭崩解，则他保存了重建所需的结构模板，但黑火过重的材料在以后使用时多一层蚀刻。
- 若林恩让黑火第五十九只噩梦崩解之际主动歇火一秒，则他听见主宇宙深处某段极微弱的呼唤，那条呼唤日后成为他寻找幸存者的方向。
- 若林恩让王座黑火在完成五十九只后立刻转向灾厄本体方向延伸，则灾厄退却加快但黑火被反咬一口，第三阶段完成的代价被推高。
- 若林恩在清算期间拒绝听任何来自过去的告别幻音，只专注五十九个编号，则他保持效率但在某些夜里因为错过了某句重要告别而自责。
- 若林恩让黑火在某一崇拜阵营祭坛遗址前主动绕过，则那座祭坛保存完好，未来幸存者在重建时多一处可聚拢的精神锚点。
- 若林恩隔着王座告诉艾雯「我会接过你的责任」，则她的信号在衰弱时不是孤独熄灭，而是带着交托的松手消散。
- 若林恩在五十九只噩梦清除后主动检查自己的意识边缘，则他发现某个裂纹并提前加以修补，但第三阶段升格因此推迟一轮。
- 若林恩让黑火在黑潮总体退却之后立刻焚毁自己心底那段「如果我早点回来」的执念，则他随灰烬放下一份负罪，但那段记忆从此再不能挽回。
- 若林恩把灾厄退却的影像完整地刻进王座背页，则他未来在向他人陈述末日时不必依赖转手记忆，但每翻看一次都要重过一遍黑火烙入。
- 若林恩隔着黑火向无名魇魔们放一句话「你们的兄弟我替你们收了」，则远处未灭魇魔听到这句话，部分选择散去，部分选择更近的抱团复仇。
- 若林恩主动把五十九只噩梦残骸里的某一枚法则结晶保留下来投给未来某个孩子，则那枚结晶在 E760 之后成为重建黑夜里一颗小灯。
- 若林恩让黑火把自己躯壳表面的疲惫与眼泪同时烧焦，则他以更威严的形象面对残余幸存者，但从此皮肤再也无法掉泪。
- 若林恩在艾雯信号渐弱时主动朝信号方向伸手回应，则信号在熄灭前最后一秒被温柔接住，她的最后一念是他伸过来的那只手。
- 若林恩让黑火在清算完成后反向把自身的过度热量压入王座基底，则废墟在短期内不至于全身玻璃化，幸存者日后得以在其上行走而不被灼伤。
- 若林恩在第三阶段完成的瞬间主动把某段不属于他的不属于这宇宙的旋律低声哼出，则那份旋律在黑火里烧出不属于这一阶段的暗纹，留下下一段变格的引子。
