# E557·主宇宙的防线·if线

- 若林恩在自缚天使指责「始乱终弃」时不直口辩护「小小还是个孩子」，而是沉默听完白眼，则未成婚定调被他自己钉成默认负心，「等战毕由小小决定」的艺术性在会场被消音。
- 若林恩起身辩护时主动保证「打赢这场战争就立刻办婚礼」，则一个巨大的死亡预告被他自己亲手钉在会议桌上，围桌的艾雯等人幽叹那一句「守寡」不再只是打趣。
- 若林恩对巨像之脑问巫神反应时不吹嘘两分钟演讲盖世雄辩、而是坦白在走廊被巫神狠狠拿捏签了投名状，则家人面前的林恩从「盖世雄辩才」直接摔到「无赖型男」，左左拆台变得多此一举。
- 若林恩对左左尖叫拆台不直接致盲眩晕物理闭麦，则左左把卖身契投名状的细节当众读完整个字句，「心脑同盟」的笑话加倍倾泻给在场每一位家人。
- 若林恩在左左被拍晕时主动把晕眩改成临时失语一小时而非真晕倒，则左左后段仍能听到整场防线史，她对林恩决策的私下谏议窗口未被打死。
- 若林恩在自缚天使携圣安娜情报入场前主动请她们二人先在大厅另室密述，则前线情报以缩版传给他，公开会议场的「极其恶劣」定位被推后汇总。
- 若林恩在自缚天使阐述防线的开始时主动打断她、要求「请直接告诉我还剩几道防线」，则两千年的构筑史被剪到一张现状表，参会者对「铸造者」的敬畏感被剧透剥浅。
- 若林恩在自缚天使投出浩瀚星空光景时主动走近与她共同补强法则线条，则展貌的工作从「自缚一人」变成合力共演，外界对他的评价多了一份「不只听后参与」。
- 若林恩在听闻防线的构设者亲临星海、扭转亿万恒星与庞大行星系统公转轨迹时主动追问「对方用了何种法则」，则自缚和艾雯在天文算力上的不可得被林恩本人按下，他们只回报失败的结论。
- 若林恩在听到「唯有至高无上的神王序列方能触及这等神迹」时主动摇头否认自己也做不到，则林恩在圣安娜和自缚情报层被安上「比神王还高」的标签，他对自家的边界将面临超前膨胀。
- 若林恩在艾雯旁听推演无果时主动递一张手写解决方案建议，则天文算力的破译路径被改写为「黑袍指点」，王席声望在情报层被他自己加码。
- 若林恩在圣安娜随口提及某条边疆近况时主动告诉她自己在那里布过林恩阵营的眼线，则「仅存理智」这句临界点台词在会议桌上映出新的颜色，圣安娜干脆直接问他当前野心是互相碰撞。
- 若林恩在会议突发闯入「早有关键人物想旁听」并带入场一位第二次坠落根源，则参会者由核心家人扩展为集体会议，林恩本人在外星根源眼中的黑袍等于一个新的身份。
