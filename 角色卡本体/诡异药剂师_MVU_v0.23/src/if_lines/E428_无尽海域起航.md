# E428·无尽海域起航·if线

- 若林恩在远征前主动为孽主准备防水斗篷与湿衣替换装，并明言不会强迫她下水，则她的抵触从「我会被玩」降级为「装备顺手吗」的专业反问，磨合摩擦被物质准备提前消化。
- 若林恩拒绝带孽主同行、令她留城辅助艾雯加固城防，则「磨合训练入口」整段钩子被熄灭，她对林恩的调教曲线被放回后台保留。
- 若林恩让小丑心脏的新玩偶躯体额外喷一层边界红霆伪装，则他通过海面的辨识被驻守狱卒自动归类为「同僚」，通关对话直接跳过「身份盘查」一节。
- 若林恩在界门落雷一刻主动用蚀痕把队伍围成空中球体，则外界血红雷光被多层蚀痕盘面反射回去，球内无人淋到一滴海水，「界门安全穿越」首次成型。
- 若林恩拒绝躲入系统空间避险、命令全员在甲板上顶雷过去，则孽主被迫抓着桅杆接受一次「恶堕体质压雷」的洗礼，水母形态的粘液与她的鸡翅在雷光里冻在同一幕。
- 若林恩在她被湿衣贴身时主动脱下自己斗篷包她上身，则她第一反应从「要被玩」切换到「他没打算玩」的错愕，恶堕防备首次被一次反向善意打破一拍。
- 若林恩接受她提出的「留城帮忙」、当众认可她的责任承担能力，则她「被迫跟船」的借口破灭，她反而以陪伴者身份自请同行，「反向邀请」首次由她开口。
- 若林恩拒绝游戏化的「战骑接客赚钱」玩笑入口，当场把它打回系统记录，则「深海战骑营业」话题在队伍内被禁绝，小丑稍后在外面自言自语没人捧场。
- 若林恩拒绝小丑的「边境禁忌」证词、以咒瞳单人探查海面扰动，则信息从二手变成一手，「红霆来自女主人混乱力量」的论断由「她猜的」变成「我看到的」。
- 若林恩让喵喵化成尾鳍贴在船尾充当雷达，则队伍在红霆落点之间穿行被她用直觉导航，「猫的罗盘」首次被实战写入航行装备。
- 若林恩让通讯蚀痕贴上远处蒸汽帆船甲板先做英语手势跟那位章鱼头船长搭话，则船只避开红霆航线前提前与林恩建立一面之缘，「陌生船员躲避红霆」的桥段被双向接管。
- 若林恩拒绝对那位章鱼头船长的身份做任何追问，则他在林恩感知中只是一个外貌锚点，「不是康斯坦丁」的防御性确认首次被这一眼锁定。
- 若林恩让归小丑自动讲解四境狱卒分工与深海之王的骑士，则罪孽城降落一行人的「功课度」首次被小丑肉身录音，王骑情报被小丑亲口献上。
- 若林恩把深海罗盘挂在孽主脖子上作为「供奉信物+实用器」组合交付，则她成为队伍内对照王骑出场的合法旗手，「王骑出来先认她」的暗示被她自己穿着在场。
