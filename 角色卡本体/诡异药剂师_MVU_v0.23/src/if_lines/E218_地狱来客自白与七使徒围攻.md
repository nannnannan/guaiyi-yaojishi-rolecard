# E218·地狱来客自白与七使徒围攻·if线

- 若林恩把三句慢性病式自白浓缩成一句「我不是蓝星人这话你别再问了」,则王麟世界观只弹出一根毛而没有后续冲击,他跟着走的理由从此少一条情义债。
- 若林恩在小护士自荐跟随时反递她一支写有「纵欲流程表」的小册子,则她捏着册子愣了三秒再转身跑回病区,事后每晚都把那本金边册子摆在床下枕底。
- 若林恩拒绝让弥赛亚接下柔情,改在她每说一句教义后补一句「这也是虫子教的?」,则她的十字架首次没全场燃烧,七使徒围着她的怒焰气势塾住一堵苦墙。
- 若林恩在七道气息未锁定他之前先反向释放一缕以M气息撞向其中一位使徒的「心脏」,则那人瞬间颤抖一下没能出手,随队审讯里首次出现「该使徒对他有奇怪感情」档案。
- 若林恩把空中过山车那段改成默默把四百具人体装入巨像之心大块头货舱,则落地点改在医院屋顶停机坪,林恩走出电梯时正对着一对看夕阳的中年老夫妇点头致意。
- 若林恩在弥赛亚抛问那一秒改向她行一个标准的蜀都作揖,则她火焰口中烧出的「革恶生善」台词硬生生被压回,七使徒首次看她在公众面前窘迫阖嘴。
- 若林恩故意把对林恩的判断题换成「若你们是虫子,你们会怎么处理同族?」,则弥赛亚首次没得到发言机会,被身后使徒级瞬时抢答,「围观自身制度漏洞」档案生成。
- 若林恩事先让左左在王麟肩上趴着并授意她「七使徒来了吐泡」,则那位戴燃烧之剑的女性第一次见到鸟嘴医头顶一只乌鸦对他吐泡泡,她的进攻窗口整体后移一拍。
- 若林恩把射向弥赛亚十字架那发子弹替换成消失术,则她手中圣物首次脱手又飞回,她怔住的三秒里已足够七使徒围他形成钳形,B 类型收束方案被现场登记。
- 若林恩朝广场雕像落座时反手朝王麟挥了一下,则少年高空落下时先把手中两叶黑肺扣住,他落地瞬间跟父亲再次十指相握,「父子执」支线首次被强化。
- 若林恩对阵七使徒时刻意只开启咒瞳的一支,则他的威胁强度被误判为「单眼观测型」,他今后每次出现在敌档案里都写着「弱点:疑似右眼」,诱使后续他每次出奇制胜。
- 若林恩在最后那发开战信号前回头对王麟唠叨「记得你爹还能活三天再醒来」,则少年首次在七使徒包围现场无精打采地嘀咕「我爸还没吃饭」,包围氛围瞬间降一档。
- 若林恩以咒瞳反向往七道气息里其中一位刺入半秒针刺,则那人瞬间倒地前被同事拽住头套,七使徒首次无法在公众面前保持神圣队形,事件以变形停在「林恩主动挑衅」新线索。
- 若林恩事先把左轮顶上王麟额头那个动作改成揉他头发,则少年后一首恐惧线彻底断裂,他不再是「害怕人型怪物的幸存者」,而是「被怪医生宠溺过的幸存者」,人设锚点转向。
- 若林恩在弥赛亚开口提问之前先向她提出一个问题:「若我叫你一声姐姐,你会否认吗?」,则她首次失去自白节奏,台词被挑到尾声才来一段难以平衡的静默。
