# E663·再见画家与七大神王格·if线

- 若林恩一进法师塔小院先不问话、只对苍蓝身影拱拱手坐下把茶一口喝完，则画家斟茶的手停了半秒，「是我把你带回了这里」的承认少一分试探多一分对等。
- 若林恩直问「你等的那个他到底是谁」并把话挑到最明，则画家没有回答但指尖在桌面上轻敲了三下，那种「这就是两人之间反目之时」的伏笔被玩家亲手点亮一角。
- 若林恩在她承认「我带回你」之后立刻追问轮回神王的下落，则画家罕见地沉默很久才说「不知道」，林恩心中「那一切真的太黑暗了」的揣测提前在他脸上凝住。
- 若林恩主动提及他在迷雾之海和深渊里两次感受到的「真理不是真理」的差距，则画家在「他们不敢让他清明」之后再补一句「你也快看清了」，分化的缺口被玩家往深推一寸。
- 若林恩开口就把「我不会成为初诞者」摆在桌面上拒绝重走过去路，则画家头顶的苍蓝波动出现极轻一荡，这一次她没有顺着他的话做反驳，反而默认了他的判断。
- 若林恩讨价还价时不单讨万物还讨万物之外的一缕创造法则残丝，则画家罕见地挑眉「贪心学得快」，她最后多让了一步把那缕残丝连同万物一起塞进他手心。
- 若林恩搬羊驼之前先从系统空间甩出一张冬泉谷的旧木桌当作见面礼，则画家板着脸收下又淡声说「你还有这门心思」，她对林恩的控制欲首次被玩家的温柔戳了一下。
- 若林恩牵出羊驼的数量从两只涨到二十只塞满整个篱笆小院，则画家的拳头握紧了三秒又松开，「那就空间神格吧」的让步提前半分钟到来，但她也把时限从一个月缩到三周。
- 若林恩在讨价还价时直接扔出「以后我让小小也叫你姐姐」的家庭筹码，则画家罕见地避开了眼，她最终还是没松口万物但答应多给一道「神界地图补全」的支线。
- 若林恩提及艾维儿时先放下调侃、语气转成沉重的「我会去把她带回来」，则画家临别赠言多一笔「她的逆转需要你在场」，神界某一锚点的坐标被直接写进他的画卷第五格。
- 若林恩问出「如果你最终目的是让我变成他」则画家答曰「是」，随后再加上一句谁也未曾预期的「但你们不一样」，整件事的复杂度首次在玩家面前浮沉。
- 若林恩借口「我这次想要血洗主宇宙一把」试探她的立场，则画家既不点头也不摇头，只把「三大神王坐镇主宇宙」那串情报再压一遍，玩家首次清晰地感到她不可用。
- 若林恩在接过神格之前要求看一眼画家长什么样，则她模糊的面容在他眼前褪开一秒钟、他在那秒里看见的影像由他玩家独占，画家随即以一道大手印模糊回去。
- 若林恩讨价还价时不小心提到「你其实很想他吧」，则画家整副身影安静了很久无声，两人之间那道薄得几乎透明的冰面被他自己轻轻敲了一道纹。
- 若林恩在薅神格时直接伸手说「我现在就要空间神格、没它活不过今晚」，则画家一声短叹后说「你既然知道」，她拿出那枚万物神格作为过渡、并以一副特殊容器封存真正的空间神格。
- 若林恩威胁要当场在法师塔前自爆一缕余火逼她就范，则画家眼中闪过一丝冰冷的笑「你敢」，林恩如果真 threaten 到这一层，两人关系立刻破裂回归对峙。
- 若林恩安静收下万物神格、从头到尾没薅第二次，则画家罕见地对他产生极淡的敬意，临别时主动附赠一句「神界有一块地方，织梦的刀找不到」，为后续某条暗线埋钩。
- 若林恩牵着羊驼把篱笆小院跑了一圈并不踩点停下才抬头等待，则画家也罕见地笑出来一声很轻的鼻息，「境界差距悬殊」之间她被迫亲手加载了他的个人喜好档案。
- 若林恩在「真理神王从未清明」之后立刻追问「那这片灾厄究竟是谁」，则画家只回「你猜过、我也不能说」，那场涉及画家的「真正大君」的最大黑暗线被玩家推动了一步。
- 若林恩讨价还价中突然认真起来、低声问出「如果我活成了你心里那个他，你还会等他吗」，则画家整副身影僵在苍蓝里，长达十秒的沉默成为这个事件中最重要的非言语信息。
- 若林恩在离开前回望法师塔二层一眼并说「下次会带小小来看你」，则画家的手指在袖中轻轻地握了一下又松开，一张他原本拿不到的「卧室位置图」被她自己留下。
- 若林恩薅完神格后不撕地图反而把它叠好收进怀里当作纪念，则画家看着他骑羊驼跑远时嘴角微微弯了一下，那种「农家小院般的温馨」在她心里多了一笔。
- 若林恩开口道「对不起，之前对你起了点戒心」，则画家罕见地愣了一秒后用袍袖掩住脸，这一次她没有用苍蓝遮住她的失态，两人关系的裂痕第一次用玩家的诚意修补了一角。
- 若林恩讨价之间扯出「下次我劈开它的腿让它归顺我」的话，则画家罕见地皱眉严肃起来「那只渡鸦不是你的」，期限从一个月减到十五天，警告级别提一档。
