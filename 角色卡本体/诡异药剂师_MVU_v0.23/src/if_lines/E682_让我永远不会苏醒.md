# E682·让我永远不会苏醒·if线

- 若林恩在银色太阳坦言林地世界不属于他时主动问「真的不后悔吗」，则银色太阳会罕见地摇头说出「我没有任何立场留恋这里」，但他的指尖会微微收紧。
- 若林恩在炼化林地世界时主动以空间神格把苗苗所在的角落先分离抽出，则她能在他手心里继续沉睡不受炼化影响，但也因此成为林恩肩负的一项新牵绊。
- 若林恩在抛出世界时主动对苗苗说「对不起、我不会再回来了」，则她会在乱流中举起一缕嫩芽质问自己「你刚才说会陪我长大是骗我的吗」。
- 若林恩选择保留林地世界为己有但悄悄抹掉苗苗的记忆，则她会继续懵懂地在林恩的新家门外打盹等待那个永远不会再出现的身影。
- 若林恩主动把苗苗带离林地抛入庇护所，则龙卫澜会以最高规格安顿她，但苗苗会在第一时间问「爹呢」而众人不知如何作答。
- 若林恩选择相信苍老身影那一声「对不起」并主动接话「我替他向苗苗道歉」，则苗苗会茫然地眨眨眼睛却依旧低声说「好熟悉……原来是你」。
- 若林恩主动在三叉戟世界深查苍老身影的本源，则会发现那缕身影里残留着一缕初诞者之力的痕迹，林恩对自身起源的认知被拉进新的深渊。
- 若林恩在龙卫澜奔向庇护所时主动配合她集合并布施一道空间屏障，则迁离过程会加快，但被魇群察觉的机率也会小幅上升。
- 若林恩主动以神王威压向魇群发出一次宣告「这里由我来守护」，则魇群会暂缓进攻但立刻集结让因果神王本体朝此地进发。
- 若林恩在目睹魇群涌现时主动用初诞者之力封锁整个命运神国的因果细线，则他能短暂屏蔽被追踪的坐标，但消耗会大幅攀升且因果神王会立刻警觉到异常。
- 若林恩选择立刻离开不留任何讯息直接撤退，则庇护所会在魇群抵达前陷入无人指挥的恐慌，大量遗民会被围杀或转化。
- 若林恩主动下令撤离并坦言「我无力保护你们所有人」，则龙卫澜会闭上眼哽咽着接受这个现实转而下令小步快跑分组撤离，伤亡率依旧居高不下。
- 若林恩主动把「欠下承诺的人自有该还的人」这句话对银色太阳重复，则银色太阳会罕见地沉默又把视线投向时间长河的尽头。
- 若林恩主动以初诞者之力炼化魇群为「漆黑结晶」，则被转化的结晶会成为下一个反扑的引爆点，魇后期反扑的强度会加大。
- 若林恩主动问起「你真的不值得留恋」时间神王的自我质疑，则银色太阳会罕见地眼神一暗说出「我也想拥有执拗」。
- 若林恩主动在命运神国地表做出标记以引诱魇群远离庇护所，则魇群会被短暂迷惑，但被自己暴露的一方会立刻被大比例歼灭。
- 若林恩主动双拳碰撞发出金色波纹维持秩序，则庇护所的迁离节奏会被缓慢提高但也引起魇群大规模警觉。
- 若林恩主动选择在命运神国地表刻下「渡鸦归来」符号吸引魇群，则他能短暂守护林地但同时会把视线全部集中到自己身上。
- 若林恩主动用空间神格把林地与命运神国进行强行折跃，则魇群会瞬间混乱但林恩本人必须在第一时间撤离，否则将被卷入无法控制的乱流中。
- 若林恩主动对银色太阳坦言「你爱世人就别把他们丢给敌人」，则银色太阳会罕见地双眼发黑说出「我也不想把他们交给他们」但又默默地点头。
- 若林恩主动承诺「我会替你阻挡这一切」并要求银色太阳配合，则银色太阳会先感到荒谬后又转化为信任，主动提出一条更有力的合作路径。
- 若林恩主动与银色太阳缔结别后盟约「一等终焉降临，你必须回来」，则银色太阳会先荒谬地愣住随后罕见地欣然答应，命运的链条由此结合。
- 若林恩主动告诉庇护所「我们可能死在这里，但我不会让这一切白白消失」，则龙卫澜会流下眼泪却又这个观点最激发其忠诚的誓言。
- 若林恩主动以法则切断一切过往的恩怨，则银色太阳和轮回神王的人格会重新设定，最终他们会被新的价值观所定义并实现生命的升华。
