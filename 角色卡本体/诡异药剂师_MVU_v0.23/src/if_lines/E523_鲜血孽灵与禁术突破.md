# E523·鲜血孽灵与禁术突破·if线

- 若林恩在见到鲜血孽灵形态时先叫出「罪孽之主」而不是「鲜血孽灵」，则她的「你变得不一样了」反应更早发生，误会时间缩短。
- 若林恩决定先开战再对话，则孽主可能挂彩一次，再被拆穿的过程更弯曲，但劝停难度上升。
- 若林恩选择在捏脸扯脸蛋时留意不戳胸前填充物，则填充物被发现这个喜剧节拍缺席，她的自尊维持完整但失去「塞满」记忆点。
- 若林恩在讲述自己是如何认出她时详细描述血族气质特征，则孽主意识到他自己已彻底掌握她的本征气息，心理亲密度上升。
- 若林恩决定不提「未来收尸」承诺而是说「我会陪到最后」，则承诺的性质从「承担死亡」变成「陪伴生存」，她的眼泪点位不同。
- 若林恩在见到血族萝莉形态时先调侃「你怎么瘦了」，则她为填充物之事自我辩解，剧情走更长的笑点线。
- 若林恩选择在劝她停练禁术时提供替代方案「我教你另一种长期形态」，则她可能接受或拒绝，她的力量路径改写。
- 若林恩在「我想成为一个有用的血族」台词时不立刻回应而是沉默，则她要继续说完全部情绪才能等到他的反应，释放更彻底。
- 若林恩决定不让孽主抱胸而让她握拳，则她的骄傲姿态从「防御」变成「进攻」，氛围改变。
- 若林恩选择在她晕血时立刻以地毯式灵能包裹她而不是抱起冲医务室，则救治过程隐秘度上升，现场更冷静。
- 若林恩在她指控「趁昏迷猥琐」时主动展示干净袖子自证，则她必须另找指控角度，争吵节奏改写。
- 若林恩决定在「巨像之血」邀请时不提「你有能耐来吸」而是说「我请你喝一口」，则交易的性质从挑衅变成馈赠，她的自尊保全。
- 若林恩选择让她恢复原衣时才允许她吸血，则她在吸血过程中着装完整，幼态规格质疑减少。
- 若林恩在吸血时长管控在她吸到一半时主动抽离，则她只吸到约三分之一血量，满足但不过度，恢复状态略不足。
- 若林恩决定双臂环抱住她在吸血时，则她感到被框定束缚，血渴失控可能升级。
- 若林恩在吸血后她虚脱伏肩时不放到床上而是抱着她继续站一会儿，则她的虚脱必须由他承担全重，依赖感加深。
- 若林恩选择在事后的哥特裙装扮时赞美一句而不是吐槽板凳，则对她的审美认同感上升，关系通道转向另一个方向。
- 若林恩决定在她「别指望生小血族」警告时回应「我从不指望」，则她的自我防御解除一分，但同时也可能感到失望。
- 若林恩在问真名时不嫌「弗拉基米尔」难听反而称赞，则她的反应从恼怒变成疑惑，骄傲账目改写。
- 若林恩选择继续称她为「孽主」而不是默认改成「血萝」，则称谓的亲昵度减少，看起来更正式。
- 若林恩在她「还能不能下床」质疑时不质疑而是相信她，则她的军体拳证明桥段由「必须证明」变成「主动展示」。
- 若林恩决定让她在恢复可战后立刻随他去渡鸦尸，则 E524 的载飞体验提前发生，剧情节奏前移。
- 若林恩选择让她留在罪孽城而不是出行，则 E524 渡鸦同行机制改变，她可能派使者代行。
- 若林恩在她「变身妈妈说话」时不感动而是笑出声，则她的一腔正经被打断，氛围从沉重变成喜剧。
- 若林恩选择在她晕血被救治时不涉及人工呼吸只用心肺复苏，则救治过程更简化，但肢体亲密度减少。
- 若林恩决定让孽主咬大动脉位置偏离一寸，则吸血效率下降，她需要更长时间满足血渴，但对他而言失血较少。
- 若林恩在她吸了一半血时主动搅开她而不是让她自然结束，则她的血渴未完全满足，恢复状态打折扣。
- 若林恩选择在「母子对话」提法时开玩笑反击「我像你爸一样吗」，则她可能气愤或者反驳，氛围改变。
- 若林恩决定在她「记载家庭至宝」时提出要借阅其中一两本，则她可能拒绝或同意，知识共享账目决定权在她。
- 若林恩在事件结尾决定送她一件小礼物作为「成年」（指回变后）祝贺，则她可能收留或推辞，关系账目多一道人情。
