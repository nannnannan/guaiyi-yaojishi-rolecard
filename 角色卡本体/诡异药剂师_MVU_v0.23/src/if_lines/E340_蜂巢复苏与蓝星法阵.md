# E340·蜂巢复苏与蓝星法阵·if线

- 若林恩在智脑救治时主动要求「给我看看我的灵魂损伤报告」，则透明容器内壁浮现裂纹状的数据流，他第一次看清自己被撑裂的形状。
- 若林恩把051机体漆成白色并画上红十字，则机械人形在战场上被误认为医疗兵，敌方火力在最初三秒出现人道主义迟疑。
- 若林恩在银发指挥官说「让他走吧」时突然回头，则监控影像里的目光与他隔空相撞，她的瞳孔在数据屏幕前停顿了整整一秒。
- 若林恩用往日遗念回溯人偶庄园时主动触碰那张恶劣便签，则影像里的黑弦月突然抬头，她的视线穿透时空与他对视了一瞬。
- 若林恩在蓝星法阵图纸上故意画错一笔再修正，则修正后的阵纹多出一条隐藏回路，召唤信号被加密成只有他能解读的频段。
- 若林恩把血肉增生药剂的配方加入自己的血液作为引子，则水缸里长出的躯体在成形时多了一道不属于他的咒纹。
- 若林恩在血锯药剂店地下室布置法阵时先点燃一支蜡烛，则烛光在密闭空间摇曳，阵纹的绘制轨迹被光影扭曲成另一种图形。
- 若林恩让左左在图纸上用她的咒纹代替签名，则她的咒体在纸面上留下灼痕，接收者打开图纸时会听到一声极轻的抽泣。
- 若林恩在发送图纸前把其中一份折成纸飞机扔向窗外，则纸飞机在夜风中消失，但某个捡到它的人从此开始追踪他的坐标。
- 若林恩在蜂巢数据世界里主动留下一段加密留言，则智脑在解析时发现留言被写成了只有「那个人」才能看懂的格式。
- 若林恩在旧战场影像里主动走进画面拥抱那个白发意志，则影像中的身影第一次停顿，但停顿后的冷漠中止更加决绝。
- 若林恩把血肉躯体重建后立刻用一支麻醉剂让自己昏迷，则他在无意识状态下被送往蓝星，醒来时发现自己躺在隐修会的海底禁地。
- 若林恩在蓝星法阵启动前给白逸、弥赛亚、尹琴各写一封亲笔信，则他们在打开信纸时看到的内容各不相同，但每一封都指向同一个坐标。
- 若林恩在系统空间里对智脑说「敌人的敌人就是朋友，但朋友的朋友不一定」，则智脑在数据世界里沉默，蜂巢的救治程序出现一次伦理判定延迟。
- 若林恩在人偶庄园空置的花丛前放下自己的乌鸦面具，则面具在花丛中被夜风吹动，某个路过的机械侦察兵把这一幕传回了蜂巢。
- 若林恩在旧战场影像回溯时主动对那个白发意志喊话，则影像中的身影第一次转身，但转身的动作让画面出现了无法修复的失真。
- 若林恩把蓝星法阵的二十一份图纸分别藏在不同的药剂瓶里，则接收者必须凑齐所有瓶子才能拼出完整阵纹，召唤被延迟了整整两天。
- 若林恩在血肉躯体成形后拥抱那具身体说「欢迎回来」，则躯体的心跳与他的意识频率出现一次偏差，他需要重新学习如何控制自己的手指。
- 若林恩在蜂巢里主动要求与银色幻想进行数据直连，则她的意识流在接入瞬间出现一次无法解释的波动，波动中浮现出某个被删除的名字。
- 若林恩在血锯药剂店的地下室里发现一张未寄出的明信片，则明信片上的字迹让他认出那是某个已经死去的人的手笔，但收信地址写的是他现在的坐标。
- 若林恩在蓝星法阵图纸上用血画出自己的指纹，则阵纹在启动时多了一道生物识别锁，只有他的血能开启召唤。
- 若林恩在旧战场影像里主动拿走那个白发意志留下的某件物品，则影像在那一刻冻结，冻结后的画面里出现了另一个正在注视着他的人。
- 若林恩在蜂巢数据世界里主动请求智脑删除他的救治记录，则智脑在删除前备份了一份，备份文件被加密成「给未来的他」。
- 若林恩在血肉躯体成形后立刻用咒纹在胸口刻下自己的名字，则咒纹在愈合时多了一道不属于他的古老符号，符号的来源无法被任何数据库识别。
- 若林恩在蓝星法阵启动前给左左留下一张便条「等我回来」，则便条在传送时被系统空间吞噬，但咒体在沉睡前感受到了一阵极轻的风。
- 若林恩在蜂巢里主动对智脑说「如果我变成怪物，请销毁我」，则智脑在数据世界里记录这条指令，指令被加密成最高优先级但执行条件未知。
- 若林恩在人偶庄园的花丛前用血画出一个简笔笑脸，则笑脸在夜雨中模糊，但某个路过的夜医把这一幕告诉了残余营地的所有人。
- 若林恩在旧战场影像回溯时主动对画面中的自己说话，则影像中的身影第一次抬头，但抬头的动作让画面出现了无法修复的裂痕。
- 若林恩把蓝星法阵的启动按钮设计成只有自己能按下的形状，则他在按下时感受到一阵不属于这个世界的阻力，阻力来自某个正在注视着他的存在。
- 若林恩在血肉躯体成形后立刻用一支解毒剂注射进心脏，则剧痛让他在成形瞬间陷入昏迷，但昏迷前的最后一秒他看到了某个不属于他的记忆画面。
