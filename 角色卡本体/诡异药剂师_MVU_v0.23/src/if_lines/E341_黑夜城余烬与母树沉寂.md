# E341·黑夜城余烬与母树沉寂·if线

- 若残余夜医在良医先生出现时集体跪地磕头，则那圈碎裂哨塔重新亮起灯火，「只剩您」的颤抖被换成「愿为您死」的誓言。
- 若玩家拿出小血瓶递给崩溃的夜医，则「不许哭」的队列当场决堤，有人跪在地上用整张脸蹭他的鞋尖。
- 若玩家用往日遗念把母树的抉择回放给残余夜医看，则观众们的哭声与嘶吼把营地撕裂成两派——一派要她苏醒道歉，一派要她触犯禁地。
- 若玩家直接对外声明「我就是继承了她的意志」，则里面的人为他握拳又为他落泪，外面世界把他的身份再次钉上十字。
- 若玩家把自然之泉的储备全部灌进水潭后主动停止解咒，则母树的焦黑躯体永远停在半复苏状态，龟裂的下颌被他亲手封在不被看见的地方。
- 若玩家在性解咒过程中叫到「醒醒啊母树」，则作为回应她的喉咙里发出一声含混的呜咽，那不是回应，而是连回来的灵魂残片都无法拼合成的悲哭。
- 若玩家把羽毛笔的笔身当作临时术杖插进母树的心脏部位，则书写领域的主母被强行唤醒，她在半昏迷中咬了他的肩膀一口以示惩罚。
- 若玩家带着守殿夜医的白夜遗物俯身倒进水潭，则金剑的守诺灼痕与母树的焦黑躯体重合，遗物被淬成可以滋养她肌肤的药膏。
- 若玩家用心灵分流把自己的意识送进母树的躯壳里沉睡一夜，则他第二天醒来时她的手指能微微勾住他的大拇指，但整张脸庞依然干枯如树皮。
- 若玩家把艾雯爵士的失控心灵巨人的潮汐阵眼暂时转移到母树树冠上，则两颗根源级的哀伤彼此碰撞，吱呀作响并震裂大地将两人逼至绝境。
- 若玩家把系统空间的安全屋彻底开放给残余夜医，则他们刚开始感激涕零，后来发现里面只剩一屋子的机械兵器，又集体怀疑主人对待生命的态度。
- 若玩家在母树体内以M结晶直接注入她最深的存在根基，则结晶权柄让她的身体直接复活成莱斯不分阶段伸长增大的少女形态，却依然失去一句话。
- 若玩家把主母大殿的黑羽撒进母树根系，则枯枝顿然染上银光，她在深眠中第一次皱眉，但眉心的病变鳞片随之剥落一片。
- 若玩家在小丑观察的荒野坐标上新建一个坟茔，则坟土在黎明前被某种力量翻掘，里面埋着的不是尸体而是他亲手写下的道歉信。
- 若玩家让左左留在母树树干上要她打完这把结界，则咒体快活地钻进病变最浓的裂缝里，跟树根呼吸一起鼓胀，她的咒纹与母树的叶脉第一次同频。
- 若玩家亲手把腐烂的种子喂给母树，则树皮上一道旧伤崩开，崩开处流出的不是脓液而是带着花香的黑色泉水。
- 若玩家最终放弃拯救并完全逃回城里，则母树守护着整体废墟，以及那永远无法唤醒的、属于某个名字的寂静。
- 若玩家选择拥抱母树直到死去，则岸边的野草缠绕在一起，温柔地陪伴着两个人留下的心跳，直到病变在相拥的躯体间彻底冰封。
- 若玩家用一支解毒剂代替性行为进行解咒，则药剂在注入瞬间被她的身体转化为催情毒素，毒素顺着血管爬进他的心脏。
