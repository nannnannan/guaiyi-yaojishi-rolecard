# E710·更高的境界·if线

- 若林恩在梦境中映照罪火第一次就成功而非「红色的火而非罪火」，则他的三位一体与罪火融合速度跳级，但同时也失去了一次理解「必须了解」的机会。
- 若林恩选择映照灵能而非法则，则他不会发现「必须了解它才能创造它」的底层逻辑，所有映照都停留在失败层级。
- 若林恩把映照实验的第一目标初定为「三位一体融合神火」而非基础罪火，则他动不了半分进度，三年后仍在原地空转。
- 若林恩在「想创造它必须先了解它」顿悟之后就立刻尝试在梦境中重构万物神格，则他被银色幻想的所知所坌。
- 若林恩拒绝承认自己太急功近利，继续用填鸭式法修习，则他的体量继续爆涨，但基础与理解继续脱节，罪火踏入第三阶段的门槛永远在咫尺之遥。
- 若他把罪火退回白烬的决定拖延至第六年，则他错失同步两位新神的黄金期，银色幻想与船长的成长曲线被扭曲。
- 若他把白烬常态化的决定告诉任何一位神（包括母树或人偶家），则「他始终保持罪火」成为公开秘密，他失去主动权独立准备。
- 若林恩在心境转变上以「急切寻找第二位梦境铸造者」作为解决方案，则轮回神王对他的评价再次降低，「你依赖外物」的标签永久打上。
- 若林恩把回到现实中的行为（心态的转变）作为新神抄写版传给其他新神，则他开创了「以稳为先」的神系修练流派，成为神界隐世长老的气质被提前锁定。
- 若他在白烬退火的同时放弃肉身，把全部心力投入梦境修炼，则他的肉身将不会被罪火破坏，但失去了三位一体融合的真正关键。
- 若轮回神王看到他退回白烬后赞许一句「你终于懂了」，则林恩的自信暴涨，在白烬状态下反而会加快对黑火冲击的速度。
- 若林恩在整个顿悟过程中向银色幻想发出过信号，则她会即刻从主宇宙赶到天堂之战遗址看他一眼，由于对林恩的感情错综复杂，看到白发与苍老的她会更加接受他后来的选择。
- 若林恩在第五年年关选择不重新回到现实，继续停留在时间长河的过去，则他的现实存在感会减弱，与身边众人之间那缕「他是我们认识的林恩」的认同感进一步褪色。
- 若他在达到白烬常态化之后主动起身对黑夜城发动远程探问，则他首次表明「我记得你们」的姿态，但同时他也担负起对外公开的责任。
- 若他把这一期间最深的心境转变写成诗句或日记留在时间长河的过去，则后来的他（或别的人）会在未来的岁月里读到，从而让其心态的演变史留下可追溯的痕迹。
