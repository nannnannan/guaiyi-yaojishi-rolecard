# E01·系统觉醒与开店·if线

- 若林恩在挂灯前在阁楼对系统面板进行更深入的提问与翻查，则挂灯与拾荒者相遇顺延至更晚的黑暗时段，巷内更浓的雾气让老太婆的灯笼先一步出现在门口，交易场景仍在但报酬议价空间被压缩。
- 若林恩在老师催促挂灯时主动开口与老师交谈（提问规则、追问上任学徒），则老师会以沙哑声给出更详尽的游魂巷行规矩与"只做不问"训诫，本事件信息层增厚，但老师外出时间点不变。
- 若林恩在拿油灯时先回到阁楼带上日记本或羽毛笔再下楼，则他到达前厅时老师已开始将尸体拖入手术室，手术室门已半掩，林恩无法观察老师切割画面，手术电锯声仍作背景音。
- 若林恩在挂灯后向黑暗中的嬉笑、雾气方向驻足凝视片刻，则巷内更深处的存在会留意他，记下他的面孔，E02—E04 来客中可能多一位未登记在默认列表的"路过者"敲店门。
- 若林恩将垃圾递给拾荒者时与老太婆多寒暄几句、问其对街裁缝店与猪肉店的近况，则系统追加一次"游魂巷传闻"微任务，老太婆额外松口一两条关于裁缝店与猪肉店的零碎口风，不影响眼球数量。
- 若林恩在收眼球时只接一颗并把另一颗退回，则拾荒者好感仍正向但低于原案，留下的那颗眼球落到柜台上不会消失，可被林恩作为原材料或议价物在后续接诊中使用。
- 若林恩在收眼球后抬头目送老太婆离开并记下她拉车离开的方向，则"拾荒者的去向"作为一条潜在情报记入系统任务残渣，C 阶段的拾荒者相关相遇事件触发位置可由门口换到她消失的方向。
- 若林恩在投喂小宝贝时倾倒速度快、未避开地窖喷出的血气，则血腥气沾在他脸与领口，接下来几个时辰内他身上带"小宝贝腥气"标记，上门的高阶来客会先于对话留意到这层气息。
- 若林恩投喂前后院小宝贝时顺手对地窖口说一句安抚或递多喝一瓶药剂，则小宝贝嘶吼不会减弱，但封门后地窖口的怒气噪声变轻，小宝贝好感度仍降但降速放缓，E44 解封前的预兆修辞略为缓和。
- 若林恩投喂后没有立即封门、站在地窖口忍耐恶臭多听几息，则黑暗里会回递一句话语般的含糊音节或一段肢体摩擦声，记为一条小宝贝声音样本，但"提前探查地窖"的识别仍按变形条件处理。
- 若林恩在血锯拖着麻袋出门前主动追问麻袋里的东西或外出的目的，则老师不会停下给答案，只多丢一两句含混带过；麻袋仍在蠕动，血锯作为"幕后"留下的补课台词省略，铁律三条仍原字交代。
- 若林恩在血锯出门前请求一把比剔骨刀更轻的随刀或一枚老师的暗记护身符，则老师不会答应其他护身物，只以眼睛示意柜台上那把染血剔骨刀已足够；本事件完工物列表不变。
- 若林恩在老师离开后没立即进柜台，而是在门口以魂灯灯光核对招牌与店内外陈设，则他会在魂灯光照半径边缘发现一两处走位异常的影子，可作为开场白之外的尾巴，引出一条非 E02 默认来客的轻度后续。
- 若林恩独自看店时主动调试或粉碎一到两瓶昨天没过期但林恩不卖给患者的药剂，则柜台上会出现一两种未在原案清单内的"自留药剂"，可在 E02—E04 的议价与治具步骤中充当替代物。
- 若林恩在系统觉醒后回到阁楼把"金手指"三个字写进日记本并标注自己在死界两年的生存准则仍在更新，则系统记录此页为"准则追加"信号，老师归来后若被翻阅，老师的反应按守序邪恶人设落定，但不干预该写的存在。
- 若林恩在第一晚听到店外呜咽或嬉笑却没立刻起身守望，则魂灯光焰会轻闪一次示意来客的强度，但来客不进门就不会发生接诊；本晚接待推迟或被 E02 默认来客顶上的情况进行等价占位。
