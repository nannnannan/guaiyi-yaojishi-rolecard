# E709·创造你的力量·if线

- 若林恩在被轮回神王三招内轰飞时就喊出「我回去提升肉身再战」，则他退回现实专注闭关肉身，「心境三年契机」被推迟，时间线拉长。
- 若林恩在问「我为什么碰不到你」之前先主动提及紫罗兰大君体内那位复苏者，则轮回神王直接把谜底翻开，林恩获得的是确定答案而非方法论钥匙。
- 若林恩把「渡鸦尸体无法发挥真实实力」的借口咽回去，则轮回神王不会点出「门槛两关」的话，点拨顺延到下一次失败。
- 若林恩在气急败坏咆哮时选择当场退出时间长河，则他与轮回神王之间的师生关系第一次出现裂痕，轮回神王对下一次点拨会更谨慎。
- 若林恩对「身体、灵魂、意志」那一串答错顺序——先答「灵魂」而非「意志」，则他得不到「在梦境中造物」的钥匙，只得到一记无声的拍飞。
- 若林恩早就自己在过去的岁月里悟到「梦境造力」之法，则轮回神王的点拨改写成印证，他在同一时段里直接踏入罪火第二阶段。
- 若轮回神王把「为什么带不来你的火」的顺序换成「为什么带不来你的以太」，则林恩的顿悟方向偏向机械一系，罪火的常规化路径改写。
- 若林恩在听到「梦境中创造你掌握的力量」时立刻尝试造初诞者之力，则他当场领悟到了「三位一体本为一体」的深层秘密，但肉身即刻被反噬摧毁一角。
- 若林恩长年拜轮回神王为师而非单纯把他当陪练，则他在心境上先一步站稳，但金羊毛钥匙的揭示反而推迟，积淀缓慢而更稳。
- 若轮回神王在点拨时多补一句「你师父是那头紫罗兰大君」，则林恩的身份真相提早被抛出来，他对「自己是谁」的恐惧紧随而来。
- 若林恩在那一刹那对轮回神王出手而非只是对空气破骂，则大概率的被拍飞结局会带来更长一段的心理落差，他的信心受到打击。
- 若林恩当场对轮回神王下跪拜师，则他失去了和林恩一样「我行我素」的修为风格，但获得更完整的轮回修炼之法。
- 若林恩未向轮回神王发出任何询问而安静离开，则点拨的那一句话不会被说出，他必须等到下一次更狼狈的失败再回来。
- 若时间泡破碎后林恩被外力召回时间长河，则他失去了递交「为什么总是碰不到你」问题的机会，整个梦境造力的启迪被长时间悬置。
