# E716·神疆献祭与红魔幻想·if线

- 若林恩当年构筑神疆时在核心回路里预留了一道「本源回护」底线，则在黑夜城主母下令点燃亿万生灵金火时，凡人献出力量后仍能保住最后一丝性命本源而不至于当场枯竭。
- 若黑夜城主母在下达「交出力量、若生一起生若死一起死」的命令前先带头献出自身半数神力，则全城新神与狱卒的响应会毫无迟疑，金色火海在瞬息间冲天而起。
- 若神疆汇聚的璀璨金火在将银色幻想与船长推上「一念神王」之境时多偏向银色幻想一分，则她在第四层迎战红魔时的机械神国威能会更早压制住红魔的初轮狂攻。
- 若船长康斯坦丁在承接神疆献祭登临一念神王后，第一剑便以毁灭与死亡的极致锋芒将兽王死死钉在外围战区，则兽王直到战斗尾声都无法提前闯入第四层增援红魔。
- 若艾维儿在独力拦下镜魔时采取以伤换伤的凌厉剑路，则镜魔会被迫将全部算力用于复刻与招架艾维儿的剑光，无暇分心窥探其他战场的虚实。
- 若银色幻想在破碎神界第四层与红魔交锋之初便果断舍弃外围机械舰队、将全部神疆加持凝于万机神躯一身，则她与红魔的近身搏杀会更加惨烈，但也为后方多争取了数息缓冲。
- 若红魔在第四层狂笑着试图以血色狂潮污染银色幻想的万物神格时，触发了林恩昔日亲手设下的神格禁制，则那缕残留的罪火印记会灼伤红魔的指尖，令其攻势一滞。
- 若主宇宙各生命世界的凡人在看到头顶燃起神疆金火时没有哭泣，而是朝着战场方向虔诚祈愿，则这股纯粹的众生愿力会让「一念神王」的持续时间再延长片刻。
- 若自缚天使与母树、人偶家在献出自身力量后仍咬牙结成辅助战阵守在内环入口，则随七魔一同涌入的底层梦魇潮水会被死死挡在第四层之外。
- 若林恩在赶往第四层的途中远远感应到神疆燃起的悲壮金火与银色幻想的险境，则他撕裂空间赶赴战场的速度会再快上一线。
