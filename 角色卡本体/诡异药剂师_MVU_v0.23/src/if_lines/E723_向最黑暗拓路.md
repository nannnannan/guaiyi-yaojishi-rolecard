# E723·向最黑暗拓路·if线

- 若林恩在无数渡鸦齐鸣的瞬间停下刀势回头望，则他会看见整片主宇宙夜空上密密麻麻的渡鸦光点，那一幕会作为「紫罗兰最后全盛」的画面被永远滞留在他记忆里。
- 若林恩在女孩喊「走」时没有立刻冲，而是先朝她看了一眼，则他能最后一次捕捉到她的笑容，那一笑被嵌入他后续的每一次梦境。
- 若林恩在冲击黑墙时主动挣脱她的手腕、把她反压在背后，则她会被保护得更彻底，但林恩的身体会多承受三成黑潮腐蚀，后续黑夜城睡眠期延长。
- 若林恩在拓路途中朝那无垠黑墙发出一声从喉底挤出的嘶吼，则嘶吼会被黑墙吸收转化为更深一层的注视感，但也会唤醒几只沉睡已久的旧日堕天使虚影替他挡下一波。
- 若林恩让左左的印记在他心口剧烈发烫以维持清醒，则他能以「我还不能死」的执念熬过最黑的一段，但左左的印记在这一程中会受到深空腐蚀折损。
- 若林恩在冲入核心阶段主动把三叉戟丢在她手里让她拿着，则三叉戟内的主宇宙本源会在她消化过程中反而维系她意识最后一丝清明，为后续埋下意想不到的伏笔。
- 若林恩选择以最省力步调前进、不挥刀只用梦境推开梦魇，则他能保留更多体力走到最深处，但也失去了在梦魇尸体堆里吸收样本的机会。
- 若林恩在刀光斩断梦魇时主动让苍蓝色的尾光跟在身后排成路线，则他能在外部留下一条「烧穿黑潮」的标记住，但在主宇宙观测者眼里那一刀会被刻成一段史诗。
- 若林恩一路上把注意力全放在她身上而不看战场，则他会错过身后万千狱卒跪地的画面，回神界后只能从别人的叙述里听说那一刻。
- 若林恩在她气息彻底消失之前主动在意识里喊她一句「笨师傅」而不是默默承受，则她消散前的最后意识会真正落到这句话上，往后任何幻境中她都可能用这话回应。
- 若林恩在梦魇大爆发点选择将刀势集中全力一击、不留后路，则他能瞬间打穿一面黑墙但自身会被裂缝反噬，疲劳度翻倍，必须靠意志力硬撑到出口。
- 若林恩把喵喵从怀里放出来让她替他嗅路，则她能更早一步嗅出安全节点，但喵喵整个身躯会沾满无序腐蚀的黑色细线，回神界后需要长时间净化。
- 若林恩在几乎窒息时主动放弃金色梦境的护体只保留呼吸用的一层薄壳，则他能以更低消耗越过大段黑潮，但代价是接下来 E724 醒来时会有一段视觉缺失期。
- 若林恩在最深处的黑暗中主动把眼睛闭上完全靠罪火感知前进，则他会躲过最终那只「注视感」的直接精神冲击，但也永远不会知道那只注视「具体是什么样子」。
- 若林恩把手伸进怀中抓住兜帽下卡罗牌中那张她画过的自己的肖像，则那张纸会在这一程的温度里彻底焦化，他会把焦残一角永远藏在心口。
- 若林恩在退出黑瞳范畴的最后一刻回头一望，则他能捕捉到她消散光晕中最后那句无声的口型——「对不起，谢谢你」。
- 若林恩在被弹出灾厄内部时主动让痛觉全部麻木，则他能维持姿态直到被艾维儿接住，但体内更深处的伤势会被掩盖一天。
