# E203·适应方案与极端疗法争议·if线

- 若林恩听完第一方案「适应它战胜它」直接拍胸脯表态「给我一个月,我亲自压住它」,则主母第二第三方案不再被抛出来,事件以变形(应允回避)收束,隐蔽结界未撤,四根源继续藏在暗处。
- 若林恩听到第二方案「切掉不健全」瞬间就跳起来喊停,则主母手指一撩的撤结界术式在半秒前被收回,事件以变形(拒绝到底)收束,她所期望激活的法阵口令并未出口。
- 若林恩在第三方案「1v3000魅魔世界」刚一脱口时面无表情问出「主母今天是不是换了个人」,则主母嘴角圣洁微笑瞬间僵住,四根源在暗处齐齐屏住呼吸,事件以变形(察觉异常)收束。
- 若林恩听到三方案之后先绕殿一圈检查隐匿结界,则艾雯爵士他们在符光屏上映出他自己的轮廓,事件以变形(识破局)收束,五根源切换为明面劝说,更难拒绝。
- 若林恩回应之前先转身一把抓住左左压在桌子底下问了句「你也觉得这事太好了对吧」,则左左把「主母从来不会提这种话」的警告直接喊出口,事件以变形(左左抢先)收束。
- 若林恩应允关头临场把主母的话原样复述一遍「1v3000堂堂正正克服诅咒」,则他的回应力量加倍纯粹,主母嘴角的柔和微笑弧度上扬一分,事件以不变形收束,根源计划在心头多加一笔「拿捏到位」。
- 若林恩在拍胸脯应允后立刻补一句「那么我可以先回家收拾两天行李吗」,则主母当场拒绝当场捏碎结界,事件以不变形收束但林恩当面看到四位根源庞大身影的怒火比原作多一秒。
- 若林恩应允时顺嘴补一句「不过我还是先想去蓝星」,则主母手指撤结界的同时,巨像之脑在法阵中央主动压下一道「预言式许可」,事件以变形(条件性应允)收束,跨界传送坐标追加一个蓝星预备项。
- 若林恩故意装傻、应允时刻意把1v3000说成「1v三万名根源」,则巫神头颅在暗处挑起眉头把那句当玩笑,事件以不变形收束但现场氛围冷场一秒,锁定口令提前触发。
- 若林恩应允后主动转头对左左说「你也去,我不想一个人在被子里哭」,则左左吓得冲上前狂拍他脸,事件以不变形收束但主母殿堂里那四道视线第一次有了「临场弃婴」的迟疑。
- 若林恩应允之前先把当日剩余的巨像之心力量调高一格作为底气,则他被隐藏结界包围时仍能清晰感觉到四位根源庞大身影的压迫,事件以变形(察觉到围困)收束,但他仍未改变应允决定。
- 若林恩拍胸脯同意后主动要求先与小呀哒道别,则主母面露一丝迟疑,巫神在暗处念出「贤婿亲情根深」,事件以变形(契约延期)收束,跨界传送启动被推迟半小时。
- 若林恩应允关头临场装晕倒敲到地板,则主母手指撩起的撤结界术式自动断裂,事件以变形(昏迷避阵)收束,艾雯爵士不得不主动显形救治那位病人。
- 若林恩到现场之前提前给左左塞一枚反向情绪诅咒,则主母殿堂里的圣洁微笑不能让左左闭嘴,左左出场骂翻主母是个「道貌岸然的主」,事件以变形(左左爆破)收束,结界强行拉起。
- 若林恩在第一方案被表达完就主动抢答「那我选一,给我三个月适应」,则主母第三方案那句「1v3000」根本没有被说出,事件以变形(适应方案)收束,跨界召唤整段未启动。
