# E123·巨像重组与破宇冲向地狱边界·if线

- 若林恩在苍银之塔崩裂前就提前抱着左左撤到塔外安全高度观礼，则他仍能借血脉悸动感应王之号角，但失去禁库大殿的第一门槛视角，巨像之脑踏出通道的画面只留背影供他远眺。
- 若林恩把左左暂时交给艾雯爵士照看、单独钻进巨像意识空间见证号角，则左左会被留在塔外残骸下被艾雯爵士拎着后领远离红芒，祂重组后第一次回眸的对象从「抱着左左的送行者」变成「孤身立在顶端的林恩」。
- 若林恩把号角直播切成500骷髅币/人的更大入口，则直播间在线数爆炸、入账跳到三百万以上，但他会被巨像之脑在意识空间里当场抓包一次「你也拿来卖」的白眼。
- 若林恩选择不开直播、只做文字级转播，则入账缩到十几万，但边界冲锋的画面会被十几家二级渠道转载，他事后照样被艾雯爵士用「你这算什么版权意识」的眼神追讨。
- 若林恩把直播收益名目伪造成「地狱边界观测费」而非巨像冲锋实况，则视界内的坠落者会把它归类成谍报而非神迹，「双木」马甲同时进入数大势力的潜在情报商名单。
- 若林恩在巨像挥矛自断双腿的那一刻仍硬生生留在意识空间没退，则断腿血雾会顺超维链接反呛他胸腔，他得立刻靠左左权能稳住，不然要在重组的意识空间里咳血到直播破音。
- 若林恩在巨像冲过第一段黑雾锁链时抢先退出链接保住肉身，则他会错过第一层支援窗口，巨像之脑在边界冲锋里替他记下一笔「第一行人过半退场」的账。
- 若林恩在重组号角响起时强行插话「先理一遍坐标再上」，则巨像会罕见半息停顿再跃出，那半息让祂调矛头绕过一段血色锁链，但王的威仪首次在子民面前被外人打断。
- 若爱丽丝、小小、黑弦月在号角前已抵达诅咒之城外围，则她们会被超维链接号召震得跪倒，爱丽丝借与林恩的灵魂丝线分享出第一视角冲锋画面，事后被他骂「你们偷看直播，得另付入场费」。
- 若血肉支配者没静观冲锋、而是趁号角吹响抛出大批血肉触手拦截，则巨像之脑会先把祂的遮天巨瞳扇碎再出发，重组的第一波远程拦截让边界冲锋延迟一次心跳。
- 若万机之神在号角响起后破口大骂但忍住没出手，则祂会原地被巨像亮相的余波压住，给艾雯爵士在诅咒之城外围留下一段「连万机之神都只敢看戏」的逸话。
- 若林恩在号角响起时向巨像之脑递交自己调制好的稳定灵魂药剂作为壮行，则祂会在冲锋途中把它吞进心脏内腔，重组后的巨像意识崩解速率会因此被压低约三成。
- 若林恩在巨像第一次跃出黑雾云层时用血脉权能反向把某段被地狱诅咒侵蚀的锁链烧出一个空洞，则巨像会通过超维链接回敬一句「在我亡命的时候你还有余力护我？」并在后续冲锋里避开那个方向。
- 若林恩在直播里任由观众实时下注巨像能否破宇而出，则直播间整体骨架币流水会爆炸成天价，他事后会被艾雯爵士用锁喉+「你就用天国巨像当赌盘」的组合拳收回一半盈利。
- 若林恩在冲锋途中偷偷把直播画面切成付费回放、只对最忠实的几十名老主顾保留实时流，则普通坠落者只会看到黑雾合拢的转播剪辑，他进入地狱的权力格局也被重新洗牌。
- 若左左在巨像冲锋时主动把权能外放替他强化直播信号，则她会在林恩的直播频道里留下一段可被识别的巨像铭文水印，事件结束后这个水印会被某些根源当成「林恩已正式寄生巨像之心」的证据。
- 若林恩把两百万入账先分出一定比例暗中塞给欲望母树作为替她解缚旧账的还礼，则欲望母树在地狱边界冲锋后会罕见地替林恩挡下一次血肉支配者的探测，但直播间会留下一段「某主播被神树单独约谈」的悬案。
- 若林恩在巨像冲锋时把艾雯爵士也请进意识空间共同观战，则两百万入账会被当场对半斩，艾雯爵士会顺手从林恩的直播间里拎出一笔「入场费也要谈判」的额外加价。
- 若林恩选择中途退出直播、只保留最后一跳的高潮实况，则回放收入仍破百万，但「双木」会被冠以「地狱第一猎奇主播」的称号，再想伪装成普通viewer就难了。
- 若林恩在巨像冲锋期间发现某段锁链上烙着能对应原著知识库的旧印记并离线抄录下来，则他能获得一段「地狱之上古神残片」的隐性笔记，留给后续翻阅上界资料时比对。
- 若林恩在冲锋尾声提前从系统里掏出应急方案（一座小型的血肉回生阵），则他能在巨像第一次负伤面上黑雾时暂时灌入血气，让巨像之脑多撑住一段锁链绞杀，但对应的大段血肉债务得由他出面偿还。
- 若林恩选择不讨价还价、把两百万全数充公给艾雯爵士，则艾雯爵士会收下并沉默良久，事后在黑弦月面前替林恩记一笔「这小子老老实实把钱给了我」的人情账。
- 若林恩主动通过血脉权能对巨像之脑喊出「你要走就连我一起带上」，则祂会在冲锋短停的那一瞬把他直接烙印进意识空间最深处，从此祂每次破宇冲锋都要带上这个胆大包天的送行者。
