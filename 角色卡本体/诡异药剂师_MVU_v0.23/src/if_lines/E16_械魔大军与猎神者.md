# E16·械魔大军与猎神者·if线

- 若林恩在械魔大军压境前索性让血锯药剂店门户大开挂出"休息"牌，则械魔的判断从"硬碰"转为"这是圈套"，他过半兵力先停在巷口，倒吊塔那头对林恩的威胁评级在战斗开始前就下调半级
- 若林恩在小小拍扁3型那一瞬不退身反而跃到她背上当场唱号指挥追猎，则每一发猎魔左轮的弹痕都记入成就系统计数，小小的"听医生的"反射链路更深一层，但巫神头颅落在战场时对她的出手分量暗加一道"她不该被当马骑"的烙印
- 若林恩在追杀逃兵时只点射械魔直系部队而放任其他散兵逃向区外，则上游逃回倒吊塔的幸存口供少一档"灭绝"，噬心魔接管通讯时的决断速度被延缓半轮，但下游猎神者折跃时携带的压制阵列密度反而更厚
- 若林恩在两颗巨型头颅落地前先一步掷出备用药剂为小小止血固乳牙，则巫神舔唇动作顿半拍，泰坦鼻孔的热气改吹向别处，E17过审难度下降一档，但小小把"还疼吗？"的目光写在脸上
- 若林恩在械魔身份被怀疑时不补刀，而是好整以暇在视界里刷一张"乖，回去好好养伤"的回执图，则械魔当夜的死机时长拉长三倍，但噬心魔对那台325通讯器的永久封印判定反向加速
- 若林恩在两颗头颅与猎神者之间主动站出"我是她契约方"以根源骑士身份认领小小，则畸变协议不再仅按血肉骨架判定，他被记入协会档案的"非常规眷属"名单，E17后协会对游魂巷的情报工作改挂另一档
- 若林恩在猎神者出折跃前一刻唤起自己体内的疫医信号伪装宣称是"疫区联合处置权"，则噬心魔那边必须先三秒判别真伪，猎神者落地的瞬间条件被微微改写，但林恩"疫医"身份在主宇宙侧的曝光指数同步抬升一档
- 若林恩在小小挨打哭喊的瞬间直接借械魔身份二次喊话"老子的眷属也敢动"，则倒吊塔那边对这次覆灭的归因从"根源冲突"修正为"械魔失控暴走"，械魔本人日后即使醒来也再无法回巢，林恩把械魔这个空身份整只手到擒来
- 若林恩在画饼授勋时把"械魔位"许给那名联络员而非"械魔近卫"，则此人战后真的在倒吊塔内部挂机自封，E18接管时替林恩端了一份"械魔许可令"的伪造底层权限，代价是E20起他必须对"那位械魔大人到底去哪了"持续给答案
- 若林恩在巫神头颅舔唇时主动递一份"牙医纪念小物件"让她带回去，则她对小小的占有欲火气分数当场转半成好奇，后续婚恋线的某个关键节点自动解锁一段私语
- 若林恩在两颗头颅围殴猎神者时不旁观而是携左近旁以血肉灾变同步监视猎神者的机体核心，则他体内多一段"猎神者机体蓝图"的污序备份，E18倒吊塔预案时他能局部拼装反向单位，代价是左手左左对这段信息的消化难度让两人当晚都睡不好
- 若林恩在战斗尾声才亮出"夜医"身份当前宣告收治病患与战场尸体分离，则倒吊塔残部的撤离队列按他的医疗名单重新编组，噬心魔预案的"清剿对象"被人为挪出几名高位参谋，事后协会对游魂巷的报复节奏被错位
- 若林恩在收编那只最后未死的猎杀者时不是收作样板而是当场以疫医身份做加班手术让它"活着但归属于我"，则他多了一个"带编号的魔人眷属"实证在手，械魔醒来后对自己身份被双重抢走的认知失调宣发顶点
- 若林恩在噬心魔抽离瞬间以"恶堕者"口吻笑着回敬"小朋友回家受训乖乖哦"，则噬心魔对他的定性从"地头蛇骑士"秒升级为"仇邪同列"，下一阶段针对他的"讨伐排班表"先列一档，但黑暗世界里另一条"他家人"的传说不胫而走
- 若林恩在战后没有立刻拥抱小小而是蹲下听她把那颗乳牙的故事复述完，则她对"医生疼我"的认知刻到根骨，巫神头颅对他的定性加入一道"亲缘分"微亮标签
- 若林恩在两颗头颅离开前主动提出"您们闺女那边缺一道换牙期的特殊膳食方"并附一贴处方，则泰坦当场眼泪鼻涕一起流，女婿地位被默认成立，小小事后对此的解读却挂在颊边那一抹白月光里多日不褪
- 若林恩在战斗里刻意让小小多咬碎一只械魔心口残留的谐振核心，则那块残片在她嘴里炸出一道同频协调波，她个人的"根源共振"技能树多一条支线，但泰坦巫神对这行为的反应两极——一方满意一方生疑
- 若林恩在两颗头颅到场后立即主动让出对战猎神者的"代理权"并以疫医身份承担后续处置善后，则他与泰坦巫神的"家长"关系正式和平落地，代价是自己名字被两位头颅同时写入"闺女史上第一位责任承担者"卷宗
- 若林恩在战后没有立刻休息而是连夜把猎神者的残片分批冲洗并写好死亡鉴定书，则他多一位对"未知造物的克制"清晰度加分，倒吊塔事后清算战损时他们家的"损失公式"被林恩对照自己的库存记账
- 若林恩在与巫神头颅作别时故意喊一声"母亲大人"而不是"巫神大人"，则巫神当场破防淌下两行粘液把泰坦拎到旁边旁听，林恩与小小的婚约进度被她在心里提前盖章落定
