# E684·艾维儿行宫潜入·if线

- 若林恩没让渡鸦分身先行冲天，而是带着它一同潜入外层梦魇包围圈边缘才下令闹动静，则渡鸦能在他三米之内就引爆第一次骚动，但凝视之眼会同时锁定两道目标而非一道。
- 若林恩攀附噩运方舟前先把一缕初诞者之力浸透方舟船尾的铁环，则他能在整段闸门关闭过程中悄然感知船队调度的优先级，跃迁落点选得更靠近立方体工厂边界。
- 若林恩在渡鸦分身引爆第一颗目标后立刻切回系统空间询问龙卫澜对凝视之眼的旧记录，则她会补一句「它扫描时先扫高位阶，再扫无名位阶」，他据此把自身气息压低一层才继续前行。
- 若林恩没选择隐匿魅影，而是直接以疫医护士形态混入被污染者劳工队伍，则他会被一头精锐黑骑拽去搬一座方舟零件，期间头顶的凝视之眼扫过三次都没停顿，但左手小指会被一只高阶魇无声烙上一个「劳工合格」的黑印。
- 若林恩对二十余座立方体一口气同时施加一丝干涉，则停运的立方体数量加倍，但金色主事者与十几位腐化智者神灵抵达现场时间比单独干涉早了近两分钟，戒严令落下的闸门距林恩当前位置只剩三条走廊。
- 若林恩没等金色主事者把整片区域扫完就提前潜入立方体工厂后方探查，则他不会正面看到那道扫过来的目光，但他会在第七座立方体的金属内壁里发现一行极小的、用手指甲刻出的中文连笔字：「致手持渡鸦者」。
- 若林恩在金色主事者喊出「戒严」一瞬反身扑向闸门坠落的方向，用三叉戟刃尖顶住正在合拢的金属接缝，则闸门停落三寸，留下一条半人高的缝隙，魇群与林恩之间出现一道肉眼可见的破口。
- 若林恩在攀爬噩运方舟时被人发现他伪装的劳工身份可疑，则那头巡逻黑骑会先把他拖去角落里盘问，他必须在十秒内决定是否当场灭口，灭口会让附近巡逻路线短暂空缺一段。
- 若林恩允许左左从系统空间探出一缕神识附在他的眼球内侧，则凝视之眼的扫描在他眼里会化作一圈圈淡蓝色波纹，他能凭借波纹厚度读出这座行宫此刻有几处被藏起的「非公开闸门」。
- 若林恩在行宫大门开启瞬间主动向一只扭曲魇伸出一根触手，则那只魇会先怔一下、然后向他伸出三根畸形指骨，像在做一个不标准的王下军团礼，他没有被认出，但那一瞬的「识别错位」留在了门侧监控眼底。
- 若林恩在戒严令落下前就撕碎第二只渡鸦尸体、把所获初诞者之力凝成一根金色短针别在发梢，则在闸门砸落前他能以一次极小的爆发瞬间移动三十米，刚好避开主事者那道回眸扫过的最后一线光弧。
- 若林恩在立方体工厂干涉法则时故意留下一道反向律令痕迹，则金色主事者在收回探查时会多停一息，「奇怪」这两个字会让他眉心的金光出现一瞬深色的裂痕，这位主事者的身份第一次在他自己心里动摇。
- 若林恩没攀附噩运方舟而是从巨门侧面攀爬那面看不到尽头的高墙，则他会先触到墙体里肉眼看不见的一层骨质酸液，左肩被腐蚀出一道慢速溃烂，但他能赶在闸门关闭前落在立方体工厂的另一侧，避开主事者出现的那段视野。
- 若林恩在十几位腐化智者神灵中主动盯上工匠之神多看三秒，则对方会毫无所觉地从他身边掠过，但在他腰侧的工具匣里，林恩会瞥见一枚熟悉的紫罗兰徽记正被复刻成战时制式，与他后来拿到的那枚纹章是同一套模具。
- 若林恩在闸门落下瞬间撕开一个微型空间门把龙卫澜从里面接出来一线，则能在金光大盛中看清主事者略微侧过来的那张脸的轮廓——除了肤色更深、轮廓更冷，它几乎与那位遥远孤岛上的身影一致。
