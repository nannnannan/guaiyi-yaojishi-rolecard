# E468·三位一体与原子革命·if线

- 若林恩用血肉灾变而不是灵能切入锁链算法缝隙，则锁链会被腐蚀成黑色碎屑坠地，光宴首次直观见识他不是纯数据体，未来对他的威胁评级上调一档。
- 若林恩斩断锁链前不屏蔽监控信道、改在斩后一秒才覆盖，则母亲机日志会留下三毫秒异常峰值，将军侧排错程序将在两小时内排到这台终端。
- 若林恩斩链瞬间故意让金发擦过指尖带出一缕数据气息进系统空间，则他日后可在蜂巢外远程嗅到这台终端频段，但光宴会对那瞬间的指尖触感留底账。
- 若林恩只斩手腕两根锁链、留脚踝双链不斩，则她能起身但站不稳，全程口述原子革命时呈半跪姿态，「如何带出去」的紧迫感被她实体化演示。
- 若林恩不追她口述的原子革命历史、只追问「你打算怎么脱身」，则她会跳过微观进化威胁直接谈撤离方案，原子革命情报减档但仍被登记为「她提过」。
- 若林恩在她讲原子革命「可吃尽生命与物质」一句时插入反问「包括你们机械神自己吗」，则她会沉默两秒、点头，「微观进化不分敌我」的细节首次浮出。
- 若林恩在她提「两百个自己」时立刻追问终端地理分布，则她只能交出大约六个大区编码，其余因权限不足标灰，蜂巢地图首次获得非官方描点。
- 若林恩把两千终端规模的数字故意夸张成「几千个你」，则她会冷声纠到「至少两百」，她对玩家措辞严谨度的记账多一条「他喜欢夸张」。
- 若林恩在她解释智械小姐「统一零件」必要性时追问「没她就不能原子革命吗」，则她会说理论上可以、但缺一票的宪章死锁摆在那里，司令台算法会停止通过。
- 若林恩提到将军一个月前强链她入网，则她的虚拟身体会突然一僵，她首次承认那瞬间她的某个分区被烧毁，亲密禁忌被绕过、她允许玩家更近一步。
- 若林恩问她「原子革命后你还是你吗」，则她会陷入长考，「个体密度无限增加后的自我认同」被她首次列为提案的隐性漏洞。
- 若林恩不追智械小姐线，把话题拧回银色幻想，则她会说没见过但有传闻，她把「某个体内七神权限在涨」的回程警报登记给他。
- 若林恩问她「既然必败，为什么还留在这终端」，则她会说两百个自己是兄弟，她不能只救自己；她胸口的金色数据在那一秒稳定下来。
- 若林恩选择不屏蔽监控、故意让将军看见斩链动作，则将军侧不会立刻反应——他会先派出审计程序溯源三小时，给林恩制造撤离窗口但暴露他的存在。
- 若林恩用咒瞳扫描原子革命提案编号并立即传送回巫神侧，则巫神会在一小时后刷新一份「机械神教正在转向微观」的紧急警报，跨文明情报网开始共鸣。
- 若林恩直接问她「你能自己挣脱剩下一根锁链吗」，则她会安静看着自己手腕、尝试七秒后承认不能，「我不是为挣脱设计的」的痛楚被她自己说出。
- 若林恩用三叉戟在终端空间内直接开一个通往奇异世界的临时洞口，则洞口只能持续四秒，她必须立即决断是否带全部两百个自己的意识索引走。
- 若林恩在「如何带出去」质问落地后沉默不答，则她会主动给出三条草案：替身、整体搬终端、上传全部两百体，他的选择窗口被她推到他面前。
- 若林恩在她口述中插入「你听说了吗，诅咒之城那位最近出现了」，则她瞳孔骤缩，诅咒之城旧事与「她曾与之合作」的含蓄怀疑首次落进她意识底账。
