# E382·旧日终点与现实联络·if线

- 若林恩在买家认出柜台上人偶的那一抖瞬间主动记录那一抖的幅度与持续秒数，则疫医档案里多一条「成年男子认亲力度」样本。
- 若林恩在买家说出兄妹最初称呼那一秒主动记录这一称呼的语音细节，则档案里多一笔「兄妹暗号」样本，与黑弦月深层执念里的「兄妹亲密」呼应。
- 若林恩在买家拿出旧棉袄与摇篮曲那一秒主动把疫医气息柔化成纯白试图共享温暖，则疫医气息被历史反弹，他再次确认自己不能干预一个兄长的安慰举止。
- 若林恩在老屏幕浮现成年雪莉瞬间主动对她容貌做细致素描，则旧世疫医档案里多一份「活过排污管的雪莉」岁月图鉴。
- 若林恩在这一刻主动记录所有童年遇难依然解释为「死」的角色的「方便解释」被打破，则档案里多一条「方便解释证伪」备忘，深层执念里的「无人再见」一项首次被证伪。
- 若林恩在雪莉被从大厦边缘推下去那一秒主动记录高度、风力与坠落路径，则疫医档案里多一份「旧世连环事件全记录」样本。
- 若林恩决定只在黑弦月得知消息后冲到房间那一秒与她同框出现，则他出现在她与姐姐最后擦肩的画面里、但疫医气息不能改历史。
- 若林恩在画面大幅面无表情一片空白的流逝瞬间主动记下流质与风格，则疫医档案里多一条「失去记忆摄化档案」样本。
- 若林恩在画面停在燃烧大厦与黑暗坠入地狱影像上瞬间主动用疫医气息压住心跳，则疫医档案里多一条「坠地前夕记忆终点」样本。
- 若林恩决定这段历史里不再强行干预任何人物，则疫医档案里多一笔「玩家选择停观」备忘，「观看者不被允许改写」规则被重申。
- 若林恩在等待已经在房间外持续太久那一秒主动听到巨像网络的现实警报，则他意识到现实同伴的担忧同样真实，决定权向现实倾斜。
- 若林恩主动监看艾雯抽离庞大心灵巨人躯体穿过屏障来结界边缘全过程，则档案里多一笔「现实协助抵达方式」样本。
- 若林恩在艾雯请求放行那一秒主动评估人偶家是否会答应，则他发现艾雯用「与他陪伴多年的家人」自称胜过任何证据，通道被打通。
- 若林恩在艾雯推门而入那一秒主动记录他如何建立比以往更强的灵能联系通道，则档案里多一条「疫医旧世界的灵能通道参数」副本。
- 若林恩在艾雯与人偶夫人对视那一秒主动记录人偶夫人好奇皱起的眉形，则档案里多一条「疫医间初次相认」样本。
- 若林恩在艾雯说「我是他哥哥」那一秒主动用疫医气息柔化成纯白为这句话加一层亮度，则疫医气息首次成为「兄长认同」的原质。
- 若林恩决定不回答艾雯「你找到执念的源头了吗」、先带他走完历史各关键点位，则疫医档案里多一条「疫医帮旧世同道存证」线路。
- 若林恩在艾雯说「你必须保持你自己作为观察者的认知、你陷在一个人的过去里太久可能就再也走不出来了」那一秒主动决定遵循兄长提醒，则他决定留下、不走，未来接应由艾雯承担。
- 若林恩主动告诉艾雯他见到的画面但拒绝立即撤出，则疫医档案里多一条「玩家选择看久一点」备忘，下一段记忆继续直至决定离开。
- 若林恩在与艾雯讨论救治方式时主动提出「保留历史、扭曲未来」的分方向，则疫医档案里多一条「疫医双向救治路线」草稿。
- 若林恩现场决定清楚幼小身影不能当成普通敌方清除，则疫医档案里多一条「疫医历史上不可清除项」样本。
- 若林恩当场决定结束旧世接触退回现实，则疫医档案里多一笔「现实同道见面临时收场」备忘，「疫医同道见面」档案被初始落定。
