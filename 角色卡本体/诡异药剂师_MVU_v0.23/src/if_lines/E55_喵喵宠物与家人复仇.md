# E55·喵喵宠物与家人复仇·if线

- 若林恩在窗户刚被拉开一线时就醒了、握着左轮没出声，则喵喵蹑手蹑脚走到床边时被一只温热手掌按住猫耳，"恶作剧"开局反写成"医生守株待兔"。
- 若林恩的梦呓说成"黑弦月，发条再拧半圈"，则房梁上那道注视立刻凝住，被子里的小身影僵直三分钟，气氛换成两个成年听众各自的微妙。
- 若林恩清醒后先把喵喵从被子里拎出来放在椅子上坐好再核对瞳孔，则"瞎扒人床"被医生坐姿盘问开局，撒娇的余地降到谷底，她改从凳子上伸手拉他袖口。
- 若林恩当场把脉把出猫娘药剂残余灵能，则他对她的"变态"反应从惊吓切换为医者复诊，确认无副作用后再听她开"想做宠物"的口。
- 若林恩在她说出"只想做哥哥的宠物"之前先开口问"你还有什么愿望",则告白顺序倒转，她直白请求认主，三个选项任务照常弹落但谈判由她主导。
- 若林恩把三条规则里的"在外人面前必须穿衣服"换成"在我诊所以外的场合要穿衣服"，则她曲解方向同步收窄成"哥哥诊所里可以不穿",次日她真的怀里只裹毛巾钻进病院后门。
- 若林恩拒绝认主但答应收留为"家人"且坚持叫妹妹，则她沉默片刻摇头回应"那喵喵再等",系统任务挂在未完成栏，好感度+15代替+30,驯服度一栏空缺。
- 若林恩在三选项时任选"拒绝并劝解"，则特殊道具落袋,喵喵穿回旧衣跳窗离开,次日她把一份写满疫医博士坐标的猫爪信压在病院门缝下，任务以无主身份开启。
- 若林恩选"严厉拒绝"，则回归流浪按事件取消路径标记,但喵喵走时留下一句"哥哥是我最后一次求人，下次再见面喵喵自己也可以",复仇线被她单独撕出走向后期事件。
- 若林恩在"主人哥哥"定称呼之前改定"良医哥哥"为唯一对内外叫法，则驯服度-5、信赖度+10交换结算，她的撒娇模式从跪膝蹭胸换成递药送饭，主宠壳外仍是医患底。
- 若林恩把镇魂铃当场挂上她的猫尾作契约凭证，则铃在她每次贴在他胸口撒娇时低响一声，黑弦月就寝隐匿路径因此每晚多绕开半米距离。
- 若林恩在系统提示"擦枪走火"顾虑窗口主动声明"控住",则玩家主权落笔，背德感页由他本人翻过去，那天晚上喵喵蜷在他怀里蹭到睡着的画面被允许原样保留。
- 若林恩拒绝声明、把是否留她过夜的决定按下不写，则事件停在未触发边界，喵喵套着他的旧衣在床尾蜷到天明，清晨才收到他没落笔的"再商量"。
- 若收主夜里黑弦月主动现身把《亲爱的女婿》与王妃条款译给喵喵听，则她俩对话结成同盟,平等契约与人偶夫人伏笔从这两条看似琐碎的枕边对话里同时被点亮。
- 若林恩在结算前把小逗猫棒收进抽屉改用医用手套装实验用猫薄荷正试剂引，则她整晚主仆间的追逐换成药理学实验，好感度照涨但驯服度曲线少一段"追棒运动"。
- 若林恩答应后补充一条"受控期间不准偷吃我的灵魂碎片储备"，则她乖乖点头但次日到他兜里翻出一枚小锅碎片碎片在他眼前来回晃，确认他改口"这半枚给你"才开心收手。
- 若林恩早就在E48为她拆过疫医博士傀儡材料并写进档案，则"家人与复仇"任务的koala直接贴上这页档案，特殊传奇奖励在任务接取时同时上浮一档。
- 若林恩在喵喵倾诉家人下落前就提出"先用三份小猫分泌物做逆向溯源血检"，则疫医博士代号315的坐标定位提前半年，博士的复仇主线被他拉到主动局。
- 若林恩在认主后问她想要什么嫁妆式的见面礼，则她吭哧半晌回答"想回疫医博士曾经住过的旧实验室看一眼",一条隐藏探索任务挂进系统面板后静默。
- 若林恩拒绝立刻答应复仇并反问她"想清楚杀人那个场景的样子了吗",则她瞳孔缩细三分钟再点头,系统任务开启但附一行"已问过她本心"备注，复仇路径后段她不会再被惊吓到颤抖。
- 若林恩在认主后立刻加签"哪一天你想解除关系不用先问我",则驯服度曲线走上极缓的平坡，她的依恋从宠物式逐步过渡到家人式，后续亲密度触发点移向她主动亲吻额头那一夜。
- 若林恩在给博士定位后自己背着她率先潜入疫医旧部藏点，则她追到现场时他已被人绑上实验台，主宠关系第一次反向换位为守护者把主人拖回黑暗城。
- 若林恩答应收养但给疫医博士复仇开出条件"先为她做一整季驯化课在动手",则训练路线被拖拽延展，她复仇之路中途多出一条由林恩主导的厨艺/追猎/急救四项兼修任务线。
- 若林恩派黑弦月暗中贴身记录喵喵的血统与疫医博士句柄，则黑弦月每晚隐匿时段多一项记录任务，人偶夫人远程监控端首次出现"人类临床报告"这种类别。
