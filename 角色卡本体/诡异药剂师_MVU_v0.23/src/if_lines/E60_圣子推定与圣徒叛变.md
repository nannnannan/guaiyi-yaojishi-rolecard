# E60·圣子推定与圣徒叛变·if线

- 若林恩回营第一眼先扑向担架抢救难民而非立刻扫场，则猜忌氛围多蔓延半刻，真名显示器启动推迟，左左急得揪他衣领把他拽回人群中央。
- 若林恩扫场时漏掉一两个严重血肉化的外派夜医遗骸没确认面板，则营地里仍残留一两处怀疑火星，羽毛拔出来之前已经有人攥刀站到他背后。
- 若林恩换一件信物压阵——抽出倒吊天使授勋时的旧徽章而非拔主母头顶的金羽毛，则说服力立刻打折，左左嘴快戳穿徽章来源，『圣子』推定不成立，知名度停在小涨一格。
- 若林恩被追问信物来历时闭口不答、只把羽毛竖在掌心让众人自己看，则面板权能自行显形，『圣子』之名以更玄的方式流传，系统结算的知名度照旧跳档。
- 若林恩拔羽毛那一下没压住疼、倒吸凉气被左左当众点破，则形象多出一段人间气，『圣子』推定改写成『跟我们一样会痛的圣子』，夜医齐声应答里多一层死心塌地。
- 若主母远程察觉羽毛被拔、借他背后虚影投来又一根递到手边，则『圣子』推定升级为实锤，主母宠溺痕迹留在场每个人都看见，等级结算里附带主母亲和度也跳一档。
- 若白夜抵达西陲丘陵后先一步起疑、不肯去握那只手，则圣徒被迫提前扯下伪装，包围圈从雾里直接升起，林恩这一枪的狙击点从相握改为林间埋伏，子弹路径更险。
- 若白夜在相握瞬间愿赌一把旧情、把手握到底，则林恩子弹擦着两人交叠的指缝钉进圣徒眉心，附加擦伤白夜掌背，白夜对林恩的信任里从此压一根刺。
- 若林恩第一枪故意只打穿圣徒肩骨留活口审，则379号面板照常弹出，但圣徒借肩伤血雾遮蔽念出引路人那句话，白夜意志击穿的瞬间手里还攥着林恩的枪管。
- 若林恩出手慢了半拍、让圣徒先扣住白夜脉门，则包围圈合拢时白夜已成第一波人质，突围主线改写为夺人，林恩『杀出重围』的判定条件多一条『抢回白夜』。
- 若圣徒的『深度恐惧』把林恩拖进的不是幼儿园幻境而是更具象的私伤，则玩家在输入里自己声明幻境内容，未声明前文字只停在他瞳孔失焦、冷汗顺着下颌滴在扳机上。
- 若林恩童年幻境里那十几份婚契被某个小女友当场火漆封回、递还给他，则幻境崩塌的路径偏一寸，他自残清醒的第一枪改打向心口侧而非肩膀，san值掉得更狠但醒得更透。
- 若林恩不用自残换清醒，而是咬破舌尖借血气硬挣脱，则清醒路径成立，但以M分摊的前摇拉长一秒，前排两名夜医被噩梦拖进血肉化边缘才被拽回，身上各留一块触手咬痕。
- 若以M洪流分摊到白夜身上时林恩刻意把他那一股压到最低，则白夜涩涩度只+2，意志线回稳稍慢，林恩那一脚踹得更重，白夜领口纽扣崩飞两颗才站稳。
- 若白夜被噩梦拖进的是『我救了你你为什么不救我』之后更长的一段独白，则他在幻境里先听见林恩踹骨声才听见那句『你对不起良心吗』，决意里掺一丝愧，『杀』字出口更哑。
- 若林恩那一针肾上腺素改抹在白夜后颈皮肉上而非肌注，则药剂通过诅咒回路渗入，白夜站直时眼底多一线金红，夜里那一战他的杀意带着药劲、斩断第一根章鱼触手时血管微凸。
- 若林恩拒绝接受『圣子』这顶帽子、当众把羽毛插回主母送来的虚影里，则推定作废、知名度停在原档，『白夜率军会合圣徒』这一条替代链成为本事件唯一收束，事件仍可完成但因果锚点少一笔。
- 若林恩反口承认圣子身份并顺势向圣徒喊话招降，则圣徒长笑不答，包围圈起雾时多一段『圣子 vs 圣徒』的阵营宣言，突围战里疫医对林恩的集火密度翻倍。
- 若林恩在营地扫场阶段就点到三号营区『已易主』这条线，则白夜会合前有所戒备、相握那一下留了后手，圣徒揭破时没有那句『我说的对吗』，子弹代替台词先到。
- 若林恩带伤回营途中顺手把一名被利维坦扭曲的难民压制住，则他进营时羽毛上还沾着别人血，举起来那一下『天使之毛』四个字自带战场味，『圣子』推定之外多一段『染血圣子』的口耳相传。
- 若林恩从噩梦里第一个挣脱后先救的不是左左而是离他最近的无名夜医，则左左多吐半刻、被他第二把捞起时整条前襟湿透，左左涩涩度+20之外多一段濡湿贴着他的温度。
- 若林恩在以M分摊时把那股洪流有意压向战场边缘，则几名靠谷口的夜医被爽醒瞬间反扑最近一只苍白乌鸦，包围圈在第一息被撕开一道口子，突围路径提前现形。
- 若白夜被击穿后林恩没踹那一脚、改蹲下身跟他平视说一句玩家声明的话，则白夜回神路径更慢但更稳，『杀疫医不算破戒』的应和里多一滴未落的泪，杀意底色从狂怒换成清醒。
