# E14·瘦长鬼影手术与024诊断·if线

- 若林恩不签收信使卷轴，则024头发无法触发被动诊断；瘦长鬼影线仍可按手术完成，但024闭环剥削支线不启动。
- 若林恩签收时戴手套或以衣物隔指，则不触发024头发的被动诊断；事件以瘦长鬼影线单独完成，024线整体不启动。
- 若林恩只开药方不动刀，则囊肿未切；瘦长鬼影成为长期复诊病人，E15接到复发上门时等价续疗完成。
- 若林恩只做囊肿切除不扶正腰子，则腰部留根；E20前后必然以并发症上门等价回访。
- 若林恩自费配出麻药真正麻醉，则物理麻醉不发生；击晕经验与头缠绷带段消失，等价承接为更稳医患关系。
- 若林恩不击晕而让他忍痛，且瘦长鬼影自愿按手术台，则手术照常完成；但病患san值暴跌，邮递圈散播本店凶名。
- 若林恩动刀前签下正式医疗契约，则契约成立；瘦长鬼影成为林恩第一个人形生物医疗契约样本。
- 若林恩改用寒毒拔除药方慢慢治，则疗程拖延；瘦长鬼影被绑定为长期客户，事件等价完成。
- 若林恩让瘦长鬼影赊账立字据，则医疗债入账；E15催债支线等价激活。
- 若林恩免费医治仅收部分诊金，则邮递圈与视界底层快速扩散善名，等价替换三枚黑颅币的收入收益。
- 若林恩以物易物（工作、情报、邮递代送），则收益等价结算；瘦长鬼影可能绑定为本店跑腿渠道。
- 若林恩当场在瘦长鬼影面前说出四病，则信息提前流入邮递圈；024可能提早起疑，试探通道收紧。
- 若林恩在回执卡上署名"林恩"而非"双木"，则身份切换公开给024；后续以真名通道展开，双木摊位声誉通道不再生效。
- 若林恩将头发留作研究样本，则E20前后可深挖毒蛾毒素配方线索；但024察觉后立场由求助变向戒备。
- 若林恩在回执内夹带秘术追踪印记或占卜索引，则024身份坐标可提前定位；后续直接以上门诊断或角色面谈切入。
- 若林恩亲笔写信直指024而非依赖回执卡，则通过医疗行会提前建立通信；E20时024防备降低。
- 若林恩术后让瘦长鬼影留在店内静养，则店内多出一位客户；影响E15信使作业节奏。
- 若林恩术后附送补药或免费调养包，则该病人立场被锚定为本店善意源；邮递圈宣传扩散等价放大。
- 若林恩不收下四个卷轴中的某个，则对应E15召唤链不建立；须以替代信使或等价路径补齐外援来源。
- 若林恩拆开卷轴立即焚烧或毁坏其一，则对应召唤源被永久切断；E15求援链等价失效。
- 若林恩动刀前出来与围观游魂巷居民解释要开刀，则名声立即本地化扩散；E15前街头巷尾生效。
- 若林恩决定不收诊金或大幅降价，则瘦长鬼影可能当场逃跑或转求其他医师；事件按未完成手术标记。
- 若林恩把囊肿样本、毒蛾毒素残留或血液样本留作底稿，则后续配方/视界鉴价可提前扩项；但一旦检出对己身份识别风险，需另设封条或销毁通道。
