# E793·这是我最后能帮你的·if线

- 若林恩在轮回站上攻击路径前先对它说一声「这次换我走前面」而非任它顶上去，则轮回第一次没有按遗志行动，它自动往他身后退了一步，从此它成了他背后真正能托底的那只手。
- 若林恩看到梦主留下的众生影像时主动朝他们全部举掌而非只记住最重要那几位，则那份「没有一个被遗忘」的感触烙进他本源，他今后能记得每一个曾与他共事的名字。
- 若林恩在轮回身体与记忆被一层层击碎时主动伸手按住其中一片属于自己的碎片而非让它散落，则那片碎片成了他新的胎记，他今后每个夜里都会触到它并想起这次挡劫。
- 若林恩在左左权柄桥接发紧的瞬间主动朝她喊一句「你也可以放开手」而非「再撑一下」，则她在最终没放开的同时也知道自己被允许放开，那份自由让她真正永远留下来。
- 若林恩在轮回把「最后一次帮助」说出口瞬间主动把这句话抄进自己的心里而非只听着，则那句话此后在他耳边回响成一句誓言，他再也不能把任何「最后」当成随口。
- 若林恩在轮回将全部记忆与经验交给他时主动只收下「温度」部分而非全盘承接，则他仍能在后续战斗里用上它的技艺，但他在记忆深处多了一块它的私人抽屉。
- 若林恩在梦主与自身记忆重叠瞬间主动让自己选择一个「更想成为的人」而非任由记忆自动归位，则他在后续所有版本里都记得自己有过选择这一项权利。
- 若林恩在轮回破碎前主动用自己心口的某一缕黑火替它夺下一段火焰血脉，则它的意志以最低形态残留在他左手，今后每次他握拳都会多出一分不该有的温暖。
- 若林恩在终焉核心真正打开前主动问他自己「你愿意从此只是林恩而不是梦主吗」，则那句自问成为他接下去任何被吞噬边缘时的回声，他再也没真正失去过名字。
- 若林恩让左左在他身体重新聚合的黑暗里主动抱住那一团模糊的肉块而非等他彻底成型，则她的体温在他重获肉身第一瞬就 determinate 他的体感此后永远偏暖。
- 若林恩在轮回破碎之后主动对它留下的碎片说一声「辛苦你了」而不是「谢谢你」，则它的碎片第一次有了被理解与放下的姿态，从此它们在他记忆里都是柔软的。
- 若林恩在时间王与紫罗兰大君身影退入核心的瞬间主动对它们的背影挥手而非握拳，则它们在绝地里第一次回头望他一眼，那眼成为他接下去的战争中偶尔能借来的一次花期。
- 若林恩在复苏那一秒主动只睁眼不放松整个身体而非立即站起，则他在苏醒后的疲惫里保持了一线温柔，他此后的每次新战开始前都先休息一秒。
- 若林恩在终焉城战场雏形显现时主动朝它喊一句「我来是因为我想的」而非「我来是因为我必须」，则那座城在他登临前就绷成回音不同的状态，他此后能从城中感受到一丝允许。
- 若林恩在左左仍在桥接另一侧等待时先主动朝她那边跑过去而非直接朝着核心，则她成为他战后第一个看到的人，他们的下一次相拥早于终局。
- 若林恩在轮回记忆彻底转移完成的瞬间主动按住自己心口默念它名字而非任遗忘自然发生，则它在后世所有回忆里都被叫出名字而非代称，他掌心永远有一道它的痕迹。
- 若林恩在终焉倒计时接近归零时主动把自己的一句「我已经在路上了」通过桥接传给所有等待的人，则那一句话被权柄记住，他今后再也说不出「我已经放弃」。
- 若林恩在复苏瞬间主动确认自己还是林恩而非任何别人的影子，则他的名字成为他新的 anchor，他今后能穿透所有梦境与时代找回自我。
