# E731·罪恶王座·if线

- 若林恩在从无序深空浴血杀回黑夜城殿堂、看见家人们通红的双眼与沉默低头的艾雯爵士时，一句话都没问便直接发疯般冲向奇异世界织梦的房间，则那一路洒落的血滴与飘扬的花瓣会成为黑夜城众人心中最痛的凯旋画面。
- 若林恩在冲入空荡荡的房间、发现最后一个活着的外来者织梦已经永远不告而别时，跪在床前死死攥住她残留着一丝余温的红裙衣角，则他会在死寂的房间里独自枯坐整整一夜，谁也不敢上前打扰。
- 若林恩在确认织梦死讯后走出房门、第一眼看向阔别二十余年归来的艾雯爵士并哑声问「她在走之前，去见过你了对吗」，则艾雯爵士会身体剧震、紧咬嘴唇沉重点头，为后续城墙风雪中的坦白埋下伏笔。
- 若林恩在面对满脸悲痛与自责的自缚天使时，主动伸手扶住她颤抖的肩膀说「主母，不怪你们，是我把三叉戟抽走的」，则自缚天使会当场泣不成声，打消了以死谢罪的念头，更加拼命地替他维持黑夜城大局。
- 若林恩在房间角落里发现织梦溯源先主传承时震碎的灵能结界残痕，并将其小心翼翼地收拢进掌心，则那缕纯粹的灵能本源会自动融入他的三位一体之中，让他清晰地感受到织梦用死亡为他推开的那扇「唯一性」大门。
- 若林恩当场抓住艾雯的衣领将他抵在廊柱上、双目赤红地低吼「她到底为什么非死不可？！她跟你说什么了？！」，则艾雯首次被林恩肢体冲撞后哑口无言，会在当晚的风雪城墙上提前将一切真相和盘托出。
- 若林恩在得知织梦临终前曾对艾雯说「有人会为你流泪的感觉似乎也不赖，那个家伙肯定会记得我的」时，仰起头闭上眼睛任由两行清泪滑落脸颊，则织梦人生中最后一次关于「被他铭记与悼念」的期盼便在这一刻得到了真正的圆满。
- 若林恩选择在这一夜不让自缚天使、艾维儿或任何家人靠近，独自一人提着夜魔刀走上黑夜城外狂风暴雪呼啸的高墙，则自缚天使会在城墙台阶下默默守候三个时辰，而艾雯爵士将在安抚母亲后独自走上城墙陪他。
- 若林恩在将前线新防线交接给艾维儿时声音沙哑却异常平静地下令「全军休整，没有我的命令谁也不准擅自出击」，则所有狱卒与新神都会从他平静的语气里听出山雨欲来的压抑。
- 若林恩在走过黑夜城王庭大厅、望见台阶之上那座空荡而冰冷的至高王座时停下脚步驻足凝视，则他会隐约预感到：织梦用性命为他换来的这份三位一体唯一性遗产，终将把他推向那座背负一切罪责的「罪恶王座」。
- 若林恩在凯旋归来的当晚下令撤去城中所有庆祝胜利的旗帜、改挂哀悼织梦的素旗，则整个黑夜城与主宇宙各星区都会得知那位曾铸造群星防线的古老外来者已为人类流尽最后一滴血。
- 若林恩在看到艾雯爵士摘下兜帽后脸上那道狰狞的利爪疤痕时，伸手轻轻触碰兄长的脸庞并轻声说「欢迎回家，艾雯大哥」，则一直紧绷着准备独自背负「骗子」地狱的艾雯会瞬间眼眶泛红，彻底坚定了生死相随的决心。
