# E731·罪恶王座·if线

- 若林恩在织梦残躯消散前强行把她从艾雯身边拉开,则她没能说完「三位一体与引路人」的除名交接,罪恶王座钥匙只剩半截传承,后续登临时多一道「未授权继承」裂痕。
- 若林恩当场质问艾雯「你为什么不早告诉我她还活着」,则隐瞒被提前撕开、信任裂痕先于王座成立,后续「骗子职责」换成林恩主动共谋。
- 若林恩把涌动着灵能的本源直接按进自己胸口而非收进系统空间,则她的最后礼物即刻生效,林恩多一缕「她残响守护」印记,王座反噬时她会替他先流一次血。
- 若林恩抓住艾雯衣领把他推到墙上吼「你到底还瞒了什么」,则艾雯首次被林恩肢体冲撞后说不出话,他从「沉默的执行者」变成「被林恩压出来的共谋者」。
- 若林恩对织梦说「你滚吧,我不需要你救」,则她体面地消散但无法完成「有人会为你流泪」的自我交付,王座诞生时多一道「未收到告别」空缺,黑火起步温度偏低。
- 若林恩把自己的王座残片掰下来塞进织梦掌心,则她最后一刻不是受赐者而是持有者,临终笑话变成「这次换她丢下他」,后续王座多一缕「主动归还」属性。
- 若林恩拒绝立刻接手王座残片、转头冲进雨里找织梦的残躯,则他在废墟上找到的不是尸体而是她落在墙角的半段红布,后续他把那截红布当作王座基座的旗。
- 若林恩让左左此刻强行现身去握织梦的手,则她首次接触灵能飞升者残留,单眼流泪却没说话,绑定校准多一笔「她陪你哭过第二次」。
- 若林恩当场决定把「织梦之死」对主母与艾维儿全线隐瞒,则她们在他登临时仍以为织梦只是沉睡,后续真相撕开时黑夜城会爆发一场小规模崩溃。
- 若林恩凝视王座残片时主动用刀划开掌心把血滴上去,则以血触发的王座从那一刻就记住他的咸腥,后续每次供能黑火默认从他血里抽,他升级更快但血亏。
- 若林恩对艾雯说「从今天起我不问你任何事,但你也别骗我第二次」,则艾雯的「骗子」从单向隐瞒变成双向协议——他仍然得骗世人,但每次说谎前必须先在心里给林恩一念发票。
- 若林恩让喵喵以猫形态叼走王座残片,则她首次接触这种位格之物后尾巴从七根烧剩五根,但她也成为「王座共管」之一,林恩失控时她能按紧急制动。
- 若林恩在王座残片上看见自己的命运轨迹时主动把「成神结局」那一栏撕下来烧掉,则命运之笔首次被凡人撕稿、羽毛笔远程心跳漏一拍,后续它对林恩多一分纵容。
- 若林恩选择这一夜不去见任何主母或其他人,独自站在雨里淋到天亮,则艾雯不会跟上去,主母在宫殿门口站了三个时辰也没等到他,温柔眼底那簇阴霾多锁一层。
- 若林恩当场问织梦「你曾经后悔创造我吗」,则她被迫回答造物主问题——她沉默很久说「我没有把你当过我的孩子,所以我才会这么痛苦」,这句话会成为他日后梦里反复回响的钝刀。
- 若林恩把织梦消散那一幕让主母亲眼看见,则她整夜跪在雨里不动,她对林恩的担忧升级为「我必须替他死一次」,后续 E735 主母会形成提前赴死的隐秘信念。
- 若林恩当场宣布「我不会为任何人流泪」,则织梦消散前反而笑得更深——因为她赢了,「被悼念」作为人生最后一次胜利被她收下,王座记录:「造物主以笑换泪之契」。
- 若林恩决定今夜不让左左/主母/自缚天使/艾维儿任何人靠近,只身与织梦残躯并肩坐到天亮,则所有其他人对他的担心都被推迟十二时辰,主母首次在城墙上站到摔倒。
- 若林恩临走时回头对织梦的影说「我不会忘记你的傲慢」,则她怒笑一句「你也好不到哪里去」,这种互相承认成为他们最后一次对话,后续林恩以M 调教时「傲慢对位」成为一种私密玩法。
- 若林恩当场把王座残片摔碎要逼艾雯说出所有真相,则残片不会碎、反而把整片废墟的灵能抽干,艾雯脸色苍白、林恩首次亲眼看见「王座会吃人」。
- 若林恩选择当晚直接睡在织梦消散的废墟上到天亮,则他醒来时怀里多一缕她遗留的灵能飞灰,后续所有以M 高潮瞬间都会伴随她一声淡淡叹息。
- 若林恩当场决定把王座命名为「织梦座」,则信仰殿铭牌全体重写、黑火点燃时首现一抹暗红,艾雯首次在章程里被林恩压一头。
