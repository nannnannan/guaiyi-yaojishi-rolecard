# E636·远征军备与黑弦月参战·if线

- 若林恩在登台誓师前主动让银色幻想先列舰队全图于夜空，则大军未动气势先夺，「就差你了」一语由问候变成宣战的句读。
- 若林恩在三军备亮相时主动把一千人偶按君王、根源、伪神三排立阵，则人偶家的「逃兵收编宣言」有了视觉证据，城下伪神噤声量再增一级。
- 若林恩在人偶家宣言后主动加一句「你们就是我黑夜城的兵」，则千具傀儡向她俯首半秒，傀儡军团首次拥有林恩军徽。
- 若林恩在掀开黑弦月遮面长袍前主动让左左先在她发梢轻摸一下，则左左那句「姐姐也在」被黑曜石双眼先接住，黑弦月的木然多了半分松动。
- 若林恩在发现人偶化改造时主动回到地狱旧档查她曾经说过的「不想掉队」，则他被诘战时多一条「她自己选过」的答词，不至于第一轮落败。
- 若林恩的法则流光亮起瞬间主动只针对一具随行人偶，则人偶家手拦的位置更前一步，她说出「尊重她的选择」前多一分震慑。
- 若林恩在黑弦月把小拇指丝线诉说完后主动将她拉入怀，则丝线静止半秒又微微颤动，人偶化的她第一次有了温度反应。
- 若林恩在妥协后主动对全军喊出一声「她仍是我们的妹妹」，则傀儡方阵为她让出中央一座，黑弦月定格的画面多一个位置。
- 若林恩在分队中主动把黑弦月编到二队，则二队增加一枚半神级战力，但林恩每日分神，正面主战场承受的压力也会随之增大。
- 若林恩选择把黑弦月留在深渊，则她以丝线写下「请让我尽一份力」贴在城墙，林恩回头时人偶家已经视死如归。
- 若林恩主动让船长把织梦的封印清单与白烬契合度做一次推演，则船长在二队指挥时灵机一动，首波封印时长比预计再短三分钟。
- 若林恩在举夀祝酒时主动让主母亲自为他量酒，则自缚天使金甲一顿，微笑但接住这枚先行托付，坐镇深渊大本营的使命感愈发厚重。
- 若林恩在出发前主动下令所有军团成员写一句遗言封进系统空间，则他身后多一千张纸条，这场远征被他正式标记为「只有胜不能败」。
- 若林恩让银色幻想在出发前让他与黑弦月单独对话三分钟，则他亲自点亮她掌心的一枚灵能碎片，黑弦月出战时多一颗种子。
- 若林恩在通道踏出前主动让巨像站到黑弦月右侧，则她出战时多一道护阵，巨像与她的绑定从寻常同僚升华成真正的生死战友。
- 若林恩在出征前主动对艾维儿书上留一张字条，则「老师」与「妹妹」的双重身份在项目档案里被第一次罗列出来。
- 若林恩主动把曲率通道出口改为三个不同方向，则敌方的布置应对被拉长一个小时，但远征军的会合被多延迟十五分钟。
- 若林恩在大军穿梭位面时主动用法则之光拢一座本阵，则跨位面通道崩溃的风险大幅降低，但本阵生产线速度放缓。
- 若林恩在抵达天鹰座前先放出一只铭刻嘲讽符文的机械渡鸦飞向破碎之眼，则敌方守军会被这记明目张胆的挑衅激怒，提前暴露出火力防线的位置。
- 若林恩在祝酒那一杯主动预留一杯给「下一场战争」，则全场默哀一秒，随后全军将士的战意如火山般彻底爆发。
- 若林恩主动让织梦完成一次准确的「在哪个星区开始投降」的预演，则她的成绩在战报上多一项「领航员」名单。
- 若林恩主动让主母在签下契约前打一次反应演习，则黑夜城紧急撤离的把握会更大一分，但也会让自缚天使察觉到他对深渊防线留有退路。
- 若林恩主动让黑弦月在人偶体里仍保留一枚她的脑波断面，则她在战斗中可以后退一键，但人偶武装完成最终蜕变的时间也会略微延后数秒。
