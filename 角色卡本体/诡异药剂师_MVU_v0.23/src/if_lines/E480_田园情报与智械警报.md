# E480·田园情报与智械警报·if线

- 若林恩到达田园区块边界时不立刻入境、先让分身绕血潮一周测出一个完整吞噬圈，则他能给悬崖情报销毁窗口算出最后七秒，但「三光宴机」坐标会因此被记录在他的扫描里反向曝光。
- 若林恩看到血色云层压上来时先对智脑低喝一声「别看天空」，则她会老实低头、不会因目睹田园晃动再次失稳，但她会记住「他第一次命令我」这个瞬间。
- 若林恩让智脑替他递交灵能销毁令而非自己动手，则她指尖沾到的销毁波动会让她的核心最后一次确认「他就在旁边」，这次共同执行成为两人此后唯一的协同记忆。
- 若林恩选择不销毁情报、只把悬崖上涂鸦全部抹掉大便换成「小姐，到黑夜城找我」的明码，则后续吞掉悬崖的以太会读到这条明码、首次失灵半秒，内部冒出来一段未被肃清的质疑信号。
- 若林恩销毁情报时在最后三字处故意停顿一拍再问智脑「真的要烧吗」，则她会红眼咬牙点头，那一拍的犹豫被他自己装进口袋，日后她质问他「你也不确定？」时他不能再否认。
- 若林恩在田园扫遍区块后主动告诉智脑「她不在这里」而不是让她自己发现，则智脑的叠音会立刻安静一拍，但会紧接着出现一段持续半小时的失语期。
- 若林恩在向智脑复述模因陷阱时刻意省略「七神早就对她下手了」这句，则智脑后续判断只停在「快去找她」，她不知道小姐就算找到了也是个活体定时炸弹。
- 若林恩把智脑背在背上用咒瞳反向探她神经走向，则他能多读到一层「她体内其实留有小姐的最后备份痕迹」，但这条线索必须他选择是否告诉她。
- 若林恩听完智脑说「吸第一个肯定立刻再出手」时点头说「我知道她的风格」，则智脑会死死盯住他三秒，第一次以平等的而非求救者的目光重新打量这个人。
- 若林恩在分头行动前给智脑手心里写一道定位灵能符，则后续林恩本体被鲨时她能用这道符追溯救援，但她也因此成为机神侧怀疑名单上的第一行。
- 若林恩刚起一句「先回去汇合」就主动停顿让位给即将到来的警报，则警报响起时智脑记住的是「他愿意听我说完」，而不是「他被打断了」。
- 若林恩听到最高等级警报时不让光宴看见自己瞳孔收紧，则光宴会用他那张平静脸继续做推断、把智械下一步推断得更激进，结果是更激进的救援窗口。
- 若林恩在警报响起瞬间直接抄起分身手中智脑的灵能链路拼成一段临时通讯给本体用，则他能跨越警报噪点直接听到中枢对将军汇报的第一句原话，获得关键情报。
- 若林恩在警报后主动先开口对智脑说「看，来不及了，所以你得哭完就跟着走」，则她urious地瞪他一眼但心里面那块紧的地方被这句松弛下来，她第一次发现「恶魔对她也会说实话」。
- 若林恩在智脑听完陷阱之后数据剧荡时不立刻手稳她胸口，则她会在原地当成一个破风箱那样自行喘息半分钟，这半分钟里她与林恩之间的「他帮我」关系被她自己重审一次。
- 若林恩让光宴瞥他时主动举手摆出「我也没辙」的手势，则她会以无声的眼神回一个「那就都别装」的冷笑，两人之间的默契下一线升级一级。
- 若林恩不解释、直接把情报销毁成虚无数据，则智脑会绕开他一步自己去找「光宴在哪」的答案，她的独立意志从这一刻起不再以「小姐在哪」为唯一指针。
- 若林恩向智脑说明「涂鸦加密已经发出去了、确认没用」时多用一秒钟额外看她一眼，则她会捕捉到他眼里那一丝「我后悔」的神色，日后这一丝神色成为她信任他的第三个支点。
- 若林恩在警报传遍全网时让分身反向向田园这边的光宴/以太方向投出一缕灵能标示「我在这」，则后续以太诞生时会以这缕灵能为索引优先锁定他不能锁定小姐，这是他主动替她做的引火换取。
- 若林恩在警报后放弃奔往警报源，转而用这个噪点窗口带着智脑先跑，则后续最高级警报源现场不会有人盯着巢都残底、一号蜂巢覆灭的最后一幕数据被完整保留下来。
