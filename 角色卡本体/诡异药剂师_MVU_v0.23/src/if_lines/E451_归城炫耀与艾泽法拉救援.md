# E451·归城炫耀与艾泽法拉救援·if线

- 若林恩在打开系统空间倾倒战利品之前先把三叉戟稳稳插在自己脚边,则后续小丑拆穿「那是王骑送的」段会被推迟一拍,「抄家」自夸台词先被允许完整说满一轮。
- 若林恩在倾倒前先把高塔按尺寸从低到高在广场上整齐排开,则小小惊呼「哇哦」会被她指着最高那座替换成「哥哥的好高」,泰坦头颅被惊异的台词从「囫囵搬屋」改为「连塔基都拔了」。
- 若林恩在开口编造「抄了狱卒大本营」之前先把喵喵抱到膝盖上,则他讲述全程会多一线抚摸猫背的小动作,后续谎言被拆穿时喵喵会先用鼻子蹭他下巴替他解围。
- 若林恩在被小丑拆穿「是王骑送的」瞬间直接把小丑玩偶捏到半空用力一扭,则世界清净画面不变,但后续他以「凭本事夺来的」口风接回台词会被缩短一拍。
- 若林恩在被追问大坠落与灾厄针对时主动把自己左轮掏出来压在三叉戟之上,则艾雯爵士注视的方向会从他的脸移到枪托,「最恶劣调教」决议仍准时落下但命令台词中多一句「先把兵器交出来」。
- 若林恩在巨像出拳前一刻故意提前用心声承认「我接不住」,则巨像会改以一记侧扫代替正面直拳,他上半身仍被轰成血雾但飞溅范围从数百米压缩到数十米。
- 若林恩在被一拳轰碎上半身的瞬间主动释放一缕灵能把头部固定住不飞出去,则他「不讲武德」的嘴硬台词会更快被说出,夜医身上的溅血量减少一半。
- 若林恩主动安回脑袋之后先对巨像鞠一个躬,则他被允许多问一句「外物不可主是什么意思」,艾雯爵士的候补教官名单会更早一拍说出口。
- 若林恩在请假申请被驳回期间主动把喵喵抱上肩膀让她陪自己一起被打,则巨像抓脚踝拖行段喵喵会被小小用触手先一步接住,拖行轨迹不变但小小瞅向他的目光里多了一份心疼。
- 若林恩在小丑猛然醒悟「你的海嗣呢」之前先自己打开门看戟,则小丑跳脚砸头段会改为他自报家门,「心怀二心」的甩锅台词不会出现。
- 若林恩在自缚天使意志成型瞬间主动向她低首承诺「我会把她带回来」,则她金色虚影的颤抖会被压一拍,后续开戟时她会先一步用意志稳住房门。
- 若林恩在自伤开门前先把左轮换成一支温血剂插入自己大腿,则半颗脑袋飙飞的画面不会出,他被允许以轻微自残完成门槛,「惨」标签仍由系统记录。
- 若林恩拒绝自伤并提议由艾雯爵士与自缚天使合力联戟,则戟身迸发的光芒会更静,艾泽法拉触手爆射段仍出现但林恩头顶不会有一道血帘。
- 若林恩在触手暴射朝他爆射瞬间故意挺直身体不跪下去,则触手在他眉心前十公分骤停的画面改为「穿肩而停」,他被搀扶的姿势改为被抱臂抬走。
- 若林恩在踏入浅滩之后主动把她熟识的那枚水晶佩饰举在掌心高举,则她从海流浮现的瞬间会先看一眼饰物再落到他脸上,搀他起来的距离从三步压缩到两步。
- 若林恩在气若游丝解释来晚了之前先咳出一口血再开始,则她搀扶他的力度会更沉,「我神说过她一定会归来」的台词被压一拍。
