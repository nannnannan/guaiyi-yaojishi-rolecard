# E94·三蜂巢饱和轰炸与母树降临·if线

- 若林恩不站天台、改趴进废墟通风管观察，则「夜医旁观坐标」错位一拍,万机之神投影那道苍蓝目光扫空,三蜂巢与他首次正面对视落空。
- 若林恩先盖住爱丽丝眼睛不让她看蜂巢,则「主动融入」改成她发火反咬他下巴一口再硬挤进身体,附身后鬼气多一道「被捂住嘴」怨气标签。
- 若林恩拒绝爱丽丝附身、执意用自身咒力硬扛,则三阶段轰炸全程他只能趴在护盾中心,死兆级增幅无存,喵喵改由单点诅咒手替他挡余波,「爱丽丝讨厌猫」被喵喵听到耳里。
- 若林恩让左左从左手探出感知蜂巢结构,则「王后」频率被万机之神投影捕捉录档,护盾绿色光幕多一条「巨像核心暴露」红字。
- 若林恩把喵喵塞进艾雯爵士护盾内圈,则单点诅咒发射器未立威,小黑猫只在护盾里替他数三阶段节奏,战后她多一句口头禅「你不让我出去」。
- 若林恩朝欲望母树主干掷一管以M药剂,则以M之力与欲望权柄隔空对撞,交配本能共振让母树那张爱人脸当场浮出潮红,她已经把「小弟弟」从玩笑改成念头。
- 若林恩朝万机之神投影反向打一道夜医诊断术,则母神威能不至撼动,但系统面板被瞬间反解析,功德扣到底,系统浮出「宿主愚蠢」以红字显示,爱丽丝在体内闷笑。
- 若林恩强行用拟化把三阶段轰炸节奏复刻进左手,则事后他能反推机械神教常规武器序列,右手皮肤被炸成灰白死兆色泽,「未用核武」规则被他写在掌心当下一场赌注。
- 若林恩在第一阶段火雨期间跨出护盾给夜医传讯只一句「还活着」,则视界网里「良医现身诅咒之城废墟」瞬间爆了,「不必要介入」被艾雯爵士改写为「已经介入」。
- 若林恩把白逸送的单反挂在护盾外缘摄录整场,则三根源首次正面冲突 footage 在视界网爆炸性扩散,机械神教将其列为「夜医间谍」第 1 号证据。
- 若林恩在母树吞噬部众那一刻内心默念「别吃」,则她吞声节奏一滞半秒,扭曲人面上笑脸第一次真切望过来,四分之一献祭比例没改但她把夜医的回应记了一份。
- 若林恩朝血色法阵掷一支剧毒药剂,则法阵肿胀型扭曲一次,四分之一献祭体意外带上一缕疫医路径残留,本事件以变形(疫医残种母树)收束,母树对林恩多一层「他下过药」记忆。
- 若林恩操控左左驱动巨像之心低频共振一次,则三蜂巢自动化歼灭程序同时报错,轰击总量不变,万机之神投影不得不分一段逻辑排查干扰。
- 若林恩在护盾里捞起地面一片烧焦血肉按住固化,则赛后他背包多一条「血肉根源现场采样」标签,爱丽丝在身体里默默吞下那一块,绑定再叠一层。
- 若林恩在万机之神下令总攻前发问「艾雯,这是你预期的那步棋吗」,则义兄沉默半拍回「不是」,银色幻想陨落的恨意结算从本事件起多了「艾雯对林恩坦白」扣子。
- 若林恩朝护盾外掷未启封以M药剂当诱饵,则以M波动撞上欲望权柄,交配的意味通过法阵回传,母树干内咀嚼声转为轻笑,爱丽丝在他体内首次因「母体共振」沉默数秒。
- 若林恩把鸟嘴面具旋到最深挡咒模式硬读母树四分之一降临全貌,则面具死兆化程度加深一层,本事件照常收束,「母树诱惑抗性」-2 计入系统。
- 若林恩在轰炸尾段让爱丽丝出身体抽一支死兆之力硬操控落点偏位,则诅咒之城东北角得以幸存,万机之神数据日志多一行「某段轨迹偏移」。
- 若林恩朝母树主干递一支镇静剂当慰问,则她咯咯接下,关键句改成「小弟弟,谢谢你的礼」,母树与林恩因果再叠一层。
- 若林恩主动退离护盾跳到三公里外另一栋楼,则三蜂巢奇观与他本人产生距离差,死兆级增幅仍生效,「夜医旁观」定位被重写,后续「被万机之神第一时间锁定」失效。
- 若林恩在四分之一献祭完成那刻朝母树树心掷一支夜医应急血包,则血包被她藤蔓绞碎吸收,母树脸上笑意转为微微愣神,献祭仍成立但「疫医留名」写进雌蕊记忆。
- 若林恩朝蜂巢第一座掷一份左手血肉增生药剂当探测,则蜂巢外壳被蚀出一小孔,第二阶段钻地弹落点偏向那一处,本事件以变形(蜂巢壳伤)收束。
- 若林恩在左左颤抖时先握住她肩膀按一下,则那句「嘴皮子都不利索」没说出口,事件以原作收束,左左锚点添一条「主人没有推开我」小字。
- 若林恩在母树嘲讥掐脖那刻直接笑出声,则三方目光集合,苍蓝目光第二次回望,笑声被血肉支配者同步收录,后续「三主谈判席」里林恩坐次票直接+1。
