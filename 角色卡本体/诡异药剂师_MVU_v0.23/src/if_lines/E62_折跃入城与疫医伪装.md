# E62·折跃入城与疫医伪装·if线

- 若林恩落地先把夺萃之镰插在地上撑住身体再扯面具，则尸斑暴露慢半拍，左左看清背影先抓住镰刀握柄，『脑袋你形变了啊』卡在喉咙转成一声骂。
- 若林恩扯上衣动作太猛连带撕到肩头，则胸前尸斑直接映出来，左左先看见他，传染判定从『林恩先坦白』改成『左左先惊叫』入场，她自己手背黑点反而后才察觉。
- 若林恩不立刻嗑药剂，先让小宝贝凑近嗅他身上黑液，则小宝贝舌部一卷舔净地上黑液，传染半径暂时收束，但小宝贝舌面也浮起一星黑点，后续要单独压制。
- 若林恩选择嗑光三瓶自缚天使药剂把凋零彻底根除，则『治一半留一半』线作废，『主母的奢华服务』钩子不存在，好感与信赖照旧结算，但成就里『演技+3』被『诚实+2』替换，事件仍收束。
- 若林恩第一瓶还没嗑完就先用金羽贴压胸口，则金羽介入提早，折跃还未发动主母已借金羽脉络投来一声询问，那句『干妈』提前到达。
- 若林恩入视界姿态收敛，只把凋零与白夜失联简短陈情，不哭不闹不喊干妈，则主母细心听完仍挤一瓶『自缚天使的怜悯』交到他手，好感+20+30缩水成各+10，『念念不忘的天使圣血』成就里智力+5被『主母的牵挂』弱替代。
- 若林恩演戏演到一半真实哭出来，把被追杀那段的恐惧原样倒进大殿，则主母分意识那一下更快半拍，金色圣血直接滴进他唇间而非交瓶，好感结算多一项『主母心疼』，信赖+10变+20。
- 若林恩开门晚半秒、让两个触手怪先冲进来把重伤同伴摔在地上，则伤员血肉化程度被多看一眼，畸变堡垒的路标从『循迹追踪』改成『伤员主动指认』，潜行难度降低但暴露风险升高。
- 若林恩砸毁侦察机后拾起一片残翼塞进怀里做材料，则后续伪装里『疫医徽章』用机械残片做芯而非纯药剂涂料，黑弦月验伪时丝线穿透胸膛因这个机械芯多停一瞬，林恩脖子被救回得早半秒。
- 若林恩不给左左讲明凋零十米传染、直接让她站远，则左左反应从警觉变成委屈，进西城区时她主动退后半步，伪装成型前她与林恩『贴身距离』参数被改写。
- 若林恩给左左先压一片自缚天使药剂底子稳住她手背黑点，则左左进畸变堡垒哨站时身上无黑斑，疫医同伴人设更稳，她与黑弦月『帮手+护卫』双定位提前成型。
- 若林恩把『主母的金羽』镶入位置从心口偏到锁骨下，则金羽压制与微妙感位置错开，黑弦月丝线穿透胸膛时锁骨下先刺穿，金羽替他挡下半寸丝线，对穿留下疤位与原作不同。
- 若林恩没把凋零压到20、只压到40就动身，则伪装里『死亡凋零特效气质』反而更浓，黑弦月第一眼没认出他同时更信他是疫医，验伪成立，但主母远程察觉金羽信号时多一层担忧。
