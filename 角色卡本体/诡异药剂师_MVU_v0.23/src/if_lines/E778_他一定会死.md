# E778·他一定会死·if线

- 若林恩在听到「他一定会死」之后先确认这个「他」指的是过去渡鸦而不是现在的自己,则他能立刻摆脱死亡阴影,但黑影也会同步确认林恩能精准切割这两个身份。
- 若林恩让左左在预言落地瞬间用左手按住林恩手背不放,则她存在本身成为「林恩不会被这条预言所伤」的活体证据,但她的左手会被林恩记下为「唯一能确认他活着的触点」。
- 若林恩主动反问黑影「你怎么知道那一定是死」,则黑影会首次被让出半步,他的温柔笑意会以「他试着抗争预言」为由头重新返场。
- 若林恩把「他一定会死」改述为「那个身份一定会终结」并雕刻在心,则他能接受那个身份的消逝但守住现在的自己,但接受本身会让他在某个夜里无声默哀。
- 若林恩在黑影说出「他是解脱」时直接反驳「他不是解脱,他只是收束」,则他把预言从「慈悲」语境里拽出,黑影的措辞策略首次失效半秒。
- 若林恩让黑火在预言落地时不炸不烁只是幽幽燃烧,则他能用「不被点燃的愤怒」反向威慑黑影,但这份压抑也会在他下一次需要爆发出手时多蓄一分延迟。
- 若林恩主动把预言反向抛给黑影一句「那你呢,你也一样会收束」,则黑影首次听到「被你预言的人也预言了你」,他温柔的面具在那一瞬晃了一下。
- 若林恩在预言定下之后主动选择不立刻追看那段历史,则他能保有「我还没看到反而能更冷静布局」的余裕,但空洞会一直在他心底转。
- 若林恩让左左在林恩即将被预言阴影笼罩时主动给他讲一段她左手最近的琐事,则他能被烟火气拽离灾祸氛围,但他也会意识到「左左在为他刻意读档」并因此更爱她。
- 若林恩把黑影提供的「解脱」提议记作一次试探而不是诚意,则他不会被动摇,但这份不信任是双向的,黑影也会学到林恩不易被温情糊弄。
- 若林恩在预言发生之后主动给过去渡鸦在意识里设一座小龛,则他能在每次想起时致意而不必深陷,但这座龛会成为黑影下一次切入他情感面的入口之一。
- 若林恩让左左用左手在预言落地后的几秒里故意捏他一下,则他能从轻微疼痛里被拉回当下,但他也会在某个瞬间感到「我现在必须被这样提醒才撑得住」的脆弱。
- 若林恩主动在时间长河某一段把那具渡鸦的身影置于自己视野里三十秒再挥袖离开,则他完成一次告别,但告别本身会让那个身份真正从他意识里退场。
- 若林恩把「他一定会死」与「我必须活」并置为对冲的两条,则他能持续给活下去加注,但也会让所有未来的关怀蒙上「因为他得活着别人才能活」的伦理扭曲。
- 若林恩在预言之后主动把自己与过去渡鸦的因果链条用黑火加一道隔断,则他能减少黑影下次通过那条链定位他的精度,但隔断是单向的,他再也看不到那具渡鸦的近况。
- 若林恩让左左在林恩即将接受预言之瞬间轻声在他意识里说一句「凑脑袋不是说了不走的吗」,则他能被她用一个旧昵称拽回,「他不会死」从战略问题被重置为情感承诺。
- 若林恩把黑影的预言理解为「那是他必须让渡鸦那个身份消失的引导语」,则他能拆解出对方计谋,但他也会因拆解而主动切断对那个身份残存的所有救回可能。
- 若林恩在预言落地之后刻意选择不去修改任何那段历史而是让渡鸦走完该走的轨迹,则他守住历史底线,但他在未来每次想起都会以「我选择了让他死」的自责存在。
- 若林恩让黑火不再顺着预言方向去确认而是朝「如果他不死」支线挣扎,则他能找出对抗路径,但黑影会首次确认林恩愿意违逆宿命。
- 若林恩主动在预言之后找到画作并对她说「他死了,你知道吗」,则他能测试画作反应来推断她与预言的关系,但这份主动暴露也会让画作对他的判断树重新展开。
- 若林恩让左左在林恩临睡前用左手在他掌心画一个小鸦爪,则他能以一个无害印记在意识里纪念那个身份,但这枚印记会成为他未来面临死亡时的最后一道回忆滤镜。
- 若林恩把「他一定会死」的「死」字从他自己的词典里临时替换为「归位」,则他能用更温和语言接受这件事,但替换也可能让他在未来某次真实危机里低估死亡的重量。
- 若林恩在预言之后主动找一段时间独处不与左左讨论,则他能避免把情绪传染给她,但独处也会让左左感到隔阂,他们的连接会从「一切都共享」调回「各管一段」。
- 若林恩让黑火在预言之后某天突然烧掉一枚无价值的旧物作为「告别仪式」,则他能完成一段情感收束,但烧掉旧物的动作会被左左看见并在她心里种下「他在为什么悼念」的种子。
- 若林恩把「他一定会死」从「预言」重新分类为「黑影的心理战工具」,则他能在战略层面立刻变得冷静,但冷静也会让他不经意失去对那段历史的某些真实温柔。
- 若林恩主动在预言之后用渡鸦形态独自从那段历史飞离一次,则他能以自己的方式告别,但独自会让左左在他返回时紧紧握住他十分钟不放。
- 若林恩让黑火在一次不相关的战斗里比平时都更用力地烧一次,作为他对「他死了」的无声回应,则他能以能量方式消化情绪,但左左会记得这次「多了一分」并在某个夜里轻声问他原因。
