# E778·他一定会死·if线

- 若林恩在远古渡鸦的狱中记忆里见证了定期收割半神的「大清洗」机制彻底成型、以及万千神格被剥夺封入神域「水晶花园」的漫长岁月，则他对新世界秩序的全套枷锁了如指掌。
- 若林恩在看到未来画家亲自来到地狱监牢打开牢门、因不忍抹杀丈夫留下的最后遗泽而放远古渡鸦离去时，他听见衣衫褴褛的远古渡鸦头也不回地说出那句诛心之言：「他爱你。可是他最不该做的事情，就是把新世界留给你，这是他这辈子做出的最错误的一个决定。」
- 若林恩在听见未来画家面对这句残酷指责只是平静回应「我不在乎，我只要他能够回来」时心头微颤，则他再次体会到这位女主人为了复活紫罗兰大君不惜背负万古骂名的偏执。
- 若林恩在感受到出狱后的远古渡鸦于心中斩钉截铁地立誓「我不叫林恩，我不是紫罗兰大君，我只是渡鸦，我将反抗所有的冬天」时，他对这位彻底独立觉醒的过去自己肃然起敬。
- 若林恩在看完远古渡鸦暗中串联地狱旧日之神筹备起义的最后记忆、主动从其体内抽离意识回到海面上空时，望着那道孤绝远去的背影沉重地吐出五个字：「他一定会死。」
- 若林恩在刚断言「他一定会死」的下一秒，见远古地狱上空的时间裂隙骤然撕开、一只遮天漆黑巨手径直抓向毫不知情的远古渡鸦，则他毫不犹豫拔出黑火大剑一剑斩碎巨手！
- 若林恩在看到第七十二柱黑袍身影自时间裂隙中缓步走出、带着温和而悲悯的微笑说出「他必死，如果能由我亲手解决掉他，也未免不是一件好事……这对他来说也未免不是一种解脱」时，林恩眼神冰冷如霜，瞬间识破对方绝非出于慈悲。
- 若林恩在黑袍身影话音落下的刹那直接挥动黑火大剑迎面斩去，则狂暴的剑光将黑袍身影连同时间裂隙一并封锁，不给对方半点触碰远古渡鸦的机会。
- 若林恩让左左在自己冲上去迎战黑袍身影的同时严密监控下方远古渡鸦的动静，则整场高空恶战的能量余波被完美隔绝在时间夹缝内，下方的远古渡鸦对此毫无察觉。
- 若林恩在听到黑袍身影用「解脱」二字替远古渡鸦决定命运时冷声斥责「他的路轮不到你来指手画脚」，则他护住这段悲壮历史的决心坚如磐石。
- 若林恩在回味远古渡鸦那句「我将反抗所有的冬天」时，发现这句誓言与自己在圣堂门外拒绝魇王时的宣言一脉相承，则过去与未来的两个灵魂在信念上完成了跨越万古的击掌。
- 若林恩在斩碎漆黑巨手的瞬间精准测算出第七十二柱黑袍身影此次降临的力量强度，则他发现自己在经历沿途上千次战斗磨砺后，黑火体量已开始反超对方。
- 若林恩在记忆末尾看清了神域「水晶花园」存放万千神格的方位与禁制结构，则这份意外收获为他理解神域核心机密补上了重要一环。
- 若林恩在听到远古渡鸦评价紫罗兰大君“最错误的决定就是把新世界留给你”时默然不语，则他明白无论是远古渡鸦还是未来画家，其实都是被困在旧日遗愿里的苦命人。
- 若林恩在与黑袍身影拔剑对峙时故意将战场向高空时间裂隙深处拉扯，则远古地狱的北海海域得以保持平静，旧日之神们的备战进程未受丝毫干扰。
- 若林恩在黑袍身影试图用言语扰乱他对远古渡鸦必死结局的心态时心如止水，则敌方的攻心之计在他绝对的冷静面前毫无作用。
- 若林恩让左左在左手掌心凝聚起最锋锐的灭世黑炎配合自己全力挥剑，则这一记凝聚了两人默契的斩击直接打得黑袍身影连连后退。
- 若林恩在凝视远古渡鸦远去的背影时在心底默默向他道别，则他既尊重对方“只是渡鸦而非林恩”的独立意志，又肩负起守护这段历史不被魇魔篡改的职责。
- 若林恩在察觉到黑袍身影虽然看似来杀远古渡鸦、眼神深处却藏着一丝算计得逞的笑意时留了个心眼，则他在全力逼退对方的同时对敌方接下来的动作提高了警惕。
- 若林恩在一剑逼退第七十二柱黑袍身影、准备迎接对方反扑时握紧剑柄，则一场波及整个远古地狱时间线的高密度攻防战紧接着全面爆发。
