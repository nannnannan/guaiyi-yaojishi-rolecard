# E719·恐怖成长与灾厄边境决战·if线

- 若林恩在镜魔现身瞬间先抬手以咒瞳扫过三魇全身，则镜魔的复刻被提早锁定一秒，但人首蛇身魇会借此空档把第一击落到林恩背侧，艾维儿的汇合被强行前移。
- 若林恩对镜魔保持沉默、不勾起「十几年前画家那一刀」的旧话，则镜魔不会被激得立刻复刻罪火双瞳，战斗拖入更长的试探期，兽王先行扑出。
- 若林恩主动以常态罪火把刀鞘的锁链完全解开再迎击，则三魇第一次接刀就被烧穿一个，但林恩体内火焰反噬提前浮现，限定他后续在边境前能停留的总时长。
- 若林恩在镜魔刀下展开心象梦境把它拖入推演，则他能以一招挑枪贯胸复刻主线，但此推演会被那虚空中的更深处那位存在瞥见一眼，恨意记录 +5。
- 若林恩放过那只逃跑的人首蛇身魇、只斩镜魔与兽王，则她会把「林恩已回归」的情报带回更深的无序深空，引来下一轮更早的反扑。
- 若林恩斩完人首蛇身魇后不向艾维儿挑大拇指、只静静擦刀，则艾维儿的泪意不会被那句「帅不？」引爆，前线气氛更加压抑，但会合时间更短。
- 若林恩对艾维儿亮出大拇指后接着皱眉反问她「伤是怎么来的」，则艾维儿会沉默很久、把那两处伤口的来历藏起，留给后续单独对话再开口。
- 若林恩不向王骑唤「王骑叔叔」、只以军礼还礼，则四王中的两位紫罗兰旧部会在心中把他标记成「已接任统帅」，后续调度更顺畅但失去一层后辈滤镜。
- 若林恩追问王骑「女主人最多还能顶多久」而不是泛泛问把握，则王骑会给出更具体的吨位估算，林恩手中时限被压到可量的小时数，心理压力翻倍。
- 若林恩在进入灾厄边境前主动把三叉戟递给艾维儿让她暂管，则他这一程失去主宇宙本源支持，罪火燃烧时长明显折损，但艾维儿获得了应急权限。
- 若林恩留下三叉戟后再转身，则他举起的五指会改成握拳，身后艾维儿的回应由「活着回来」换成一句压低的「我把你的军团守住」。
- 若林恩在迈步走入黑暗前最后回望一眼黑夜城方向，则那一眼里他没有再露出笑容，火药味更浓，主宇宙防线整体士气被这一眼狠狠揪了一把。
- 若林恩把走向灾厄的脚步放缓、让边境魇魔先一拥而上，则他能趁它们合围瞬间观察更深处的能量分布，为后续寻找白发身影预先记录下一条地图。
- 若林恩在边境前的最后一刻向诸天广播一句「我过去打一场你们别插手」，则主宇宙诸防线会首次听到他以统帅姿态发声，但他个人也将在无序深空上层被点名。
- 若林恩选择在入边境前先把左左的印记从神格内侧挪到心口，则他在深空行进时不会被旧思想戳刺，但也少了一道自我提醒「要活着回去」的锚。
- 若林恩携着一壶酒入边境以酒践行，则他能以更放松的姿态切开第一层黑潮，画风与 E720 的酒意衔接更自然，但也让某个巡逻的狱卒在遥远处看到他的背影发怔。
- 若林恩以金色梦境覆盖周身全部感官再踏入黑暗，则他对越靠近核心的危险越迟钝，但每走一步都会留下更清晰的回程脚印，为后续撤离保留后路。
- 若林恩在边境让喵喵以猫形态跳到肩头同行，则她首次在灾厄边境发出低鸣，能替他吃掉少量窥视，但也立刻成为无序力量优先标记的目标之一。
- 若林恩跨过黑暗边框瞬间主动激活万机之神通讯备份给银色幻想，则沉睡的她会以最深层的日志形式收下这一笔，醒来后第一时间得知他已入边境。
