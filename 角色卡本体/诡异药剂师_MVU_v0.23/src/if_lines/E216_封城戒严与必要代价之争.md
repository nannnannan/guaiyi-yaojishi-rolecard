# E216·封城戒严与必要代价之争·if线
- 若林恩在弥赛亚泰山压顶那一击时不让左左硬接反而顺手把她拎到自己身后,则夜魔刀劈飞插在塔尖裂缝里被军方收走,成为封城第一份被官方入卷的「地狱兵器样本」。
- 若林恩在说出「鲶鱼效应」之前先把两枚测谎针剂反向弹进弥赛亚的盔甲缝,则她举起十字架高呼「魔鬼」的尾音第一次被生理反应强制卡住,她没能把完整诅咒念完。
- 若林恩坠落前顺势把三名被踩倒在地的大爷大妈用触手拉起放到回收担架上,则军方搜救直升机多接走一车原被放弃的市民,他的名字首次被官方档案标为「双向接待者」。
- 若林恩坠落瞬间把鸟嘴面具脱下来反向扔到弥赛亚怀里,则她本能接住之后才发现手里握着的只是一个普通医生的诊疗工具,事后她偷偷把它藏在了胸甲夹层。
- 若林恩在天台对左左那句「代价必须」不正面回答而是把她拉蹲到同一视线高度,则她首次把全城的踩踏人群当成一个连名字都喊不齐的整体,她的表情里第一次没有笑容。
- 若林恩把回忆里爱丽丝/主母/艾雯/泰坦大哥的执念台词一并向左左念出并自问「那我的执念是什么」,则左左第一次看清这个「地狱之医」并不是个完全坚定的人,她的内心档案首次出现「林恩也有迷茫」这一条。
- 若林恩在戴回鸟嘴面具的瞬间顺手用一缕咒缠反向把全城残余未麻患者都标上临时医疗标签,则军方首次同时收到所有收治点的救治排名表,他的名字第一次以「封城医疗报告」之名推向公开名单。
- 若林恩事先把塔尖广播改装成由触手驱动的即兴播音台,则全城手机首次同时收到一段来自陌生人的关怀广播,内文由他亲手撰写,事后被市民群嘲为「夜半的奏佳音」。
- 若林恩在银左轮那枚子弹扣下瞬间把早已压好的麻痹注射剂同步压在枪机柄上,则子弹擦过王麟肩膀炸出电流火花的同时那枚麻药反向射入他颈侧,他被自己的药当场打昏,林恩无需动第二发。
- 若林恩事先给王麟的门外信封里塞一支未启用的麻痹药瓶,则王麟扑倒保安时被自己胸口内爆裂的药剂当场打昏,首次没人再中弹,押向医疗区的过程亦不再以蔑弃为他展示。
- 若林恩事先给左左布置「王麟咬掉它护士长的裤腿瞬间你立刻扑上去抱住他告诉他'你爹没事'」,则王麟爆发时首次被这样掩护住,而王麟的档案里首次出售有「以皮相推挪救治档案」一档,他之后向护士们再次获得过机械式握手而并非粗暴抢救。
- 若林恩事先教血娃娃「拖地画面立刻跟他平行,他拖动节奏你连你一步慢」,则她事后跟着他的步伐之战装出一对下三滥舞台双人组,王麟的精神强度扔下大力士战车后被锁相他的舞蹈模式。
