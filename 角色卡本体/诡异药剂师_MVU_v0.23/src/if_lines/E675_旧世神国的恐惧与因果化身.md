# E675·旧世神国的恐惧与因果化身·if线

- 若林恩在龙卫澜铺开地图时主动以空间神格反向推演降临坐标的源头，则能锁定「小世界开启时的空间裂缝」，直接获取通行壁画门更深层线索。
- 若林恩窥探圣堂内部时主动把神格的投射影像烙印到石板，则地表会留下他锁定地下宫殿位置的金色沙纹，但同样会被敌方巡逻黑骑警觉到。
- 若林恩在火神拒答时不杀他、改以空间神格抽走他的法则烙印，则他会被迫半死不活地讲述更多被污染者内幕，但林恩的空间位格因此受到短暂污染。
- 若林恩把衰败之神的神格直接收入系统空间做未来武器，则三维一体的融合度会因吸收腐化神格短期紊乱一次，神王之下「无敌感」瞬间失效。
- 若林恩在击败黑骑后主动用三叉戟挑起一位国卫的尸身送别，则全队士兵会被他的姿态触动，士气高涨的下一战他们会奋不顾身。
- 若林恩在壁画门前主动用羽毛笔的笔端轻触墙面，则门扉会以更柔和的姿态展开并显现出一幅「紫罗兰时代的幻象」，过往真相会以不起眼的细节补全。
- 若林恩窥视火神记忆时不带任何隐匿，则因果化身的回头杀会更快落到他身上，原本几百公里的发现距离直接压缩为零，交手不可避免。
- 若林恩看到「因果」回眸瞬间以空间神格斩断因果锁定，则那股关系会短暂中断，但因果化身本身会隐约感到「有人偷了他的线」，神王警惕度暴增。
- 若林恩在林地入口主动用初诞者之力替整个小队筑起法则道标，则虽然他们能顺利通过但林恩自己会被锁定在原地暂时流离一两秒。
- 若林恩在见到植灵嫩芽对话银色太阳时主动接话出现在场景，则银色太阳会瞬间察觉异常并主动屏蔽自己的身份，错失银色太阳的真相打探窗口。
- 若林恩在默默失控瞬间用时间倒退直接将她封印打断，则她的神格能保住但她的记忆与身心会被切断，E675后续会触发「神智蒙昧」状态。
- 若林恩选择不阻止神音姐妹离去但也不同意庇护所帮助掩藏气息，则姐妹会在半路上被被污染者截住，默默的神格正式殉爆，林地遭漫天漂浮碎片藏毒。
- 若林恩当场阻止神音一剑斩断龙卫澜的咽喉，则她们之间的「背叛血债」会被诉诸对峙但能得到彻底弥补，同盟关系反转成「共罪同盟」。
- 若林恩在听完龙卫澜坦诚狱卒弃守的真相时主动亮出他本身也曾被抛弃的个人经历，则双方会产生共振，龙卫澜会像看到旧友一样彻底放下戒心对他全知。
- 若林恩对龙卫澜「杀尽我等」的请求表态拒绝，则她会闭上眼露出遗憾但立刻转身请求自己一战赎罪，庇护所遗民会瞬间目睹龙卫等级尊严的崩塌。
- 若林恩大手笔同意龙卫澜的请求并借机招募所有龙卫为自己效命，则他会瞬间收到「数千龙卫待遣」的名义权限，但代价是龙卫澜一人的兵符永不散手。
- 若林恩在现场主动用时间倒退替全员在林地着陆的那一刻设置安全锚点，则即便出现更大意外他们也能集体返回原本位置，但林恩的灵魂会承受一段微弱的「因果牵扯」。
- 若林恩把默默的记忆片段完整播放给在场所有卫兵，则龙卫澜的部下会陷入一段时间的震慑失语，原本看似铁血的庇护所出现大量情绪化员。
- 若林恩在见到被转化的遗民时主动用初诞者之力尝试逆转污染，则他会发现逆转无效的绝望真实，神界清洗术已彻底无法被凡人之手反转。
- 若林恩在最深处的壁画门前犹豫不进、选择撤离等下一次机会，则林地小世界的幸存遗民会继续遭至屠杀，故事节奏会从「拯救」切入「救不回」的哀鸣。
- 若林恩直接对银色太阳说「我听说过你」、虚构情报激怒对方现身，则银色太阳会罕见地音波散射林恩虚假的指向，两位知情者之间的表态博弈正式进入白热化。
- 若林恩在林地深处选择踏树疾行而不用空间折跃，则小队能更敏锐地避开因果的漆黑细线追踪，但林地内的意外遭遇概率会大幅升高。
- 若林恩主动给被污染过的遗民尸体用火焰啥底掩埋，则现场会留下一缕缕诡异的金黄诱人痕迹，会不会引起后续事端直接影响庇护所的下一波行动规划。
- 若林恩在因果反向锁定林恩那瞬间主动切断自己命线与空间的连通，则因果化身会瞬间失去追击目标，但林恩会短暂陷入「无知无觉」状态无法行动。
