# E438·沉眠者与王戟继承·if线

- 若林恩在戟面意志接入精神时主动抽离并否认自己是大君，则那声苍老叹息会以八度回响拔到耳膜上限，林恩接下来的梦里都会听见有人拖地跟随着他。
- 若林恩让小丑先称呼王骑而不是追问背叛真相，则小丑会首次直白说「你就是王骑殿下吧」，小丑心底里对「王」的执念全貌在此刻展露无遗。
- 若林恩主动以咒瞳扫视戟面意志而非聆听，则它以纯粹画面回应——林恩看到大君本人当年扫海的掠影，但咒瞳从此再也无法忍强度投影。
- 若林恩拒绝接受「渡鸦是工具」的解释并质问「你自己的意义呢」，则神念会立刻失语沉默六拍，表明这具残存神念早已放弃对自身意义的思考。
- 若林恩让小丑神念在场时直接亲吻戟身铭文，则戟面意志会被这一亲吻压到瞬间熄灭，林恩第一次证明自己对王庭遗物的克制权。
- 若林恩主动追问「女主人是谁」，则神念会以不打正面答案的方式描述「掌握时间的那一位」，林恩事后能把她的形象初步画出来。
- 若林恩拒绝接过戟并且主动倒退三步，则戟面意志会以更粗哑的低语哀求一次，那声哀求的音色化作灵魂回响，后续靠近戟时均会共鸣浮现。
- 若林恩让孽主用血族身份触碰戟身，则戟面会像遇到尸骨肉一样立刻震颤后恢复冷漠，表明血族法则与王戟体系存在天然排斥。
- 若林恩主动让小丑比戟面意志先发声，则小丑的这番言辞会被戟压住半秒，殿堂气场彰显出「王戟才是终极考核者」的威压。
- 若林恩在听闻沉眠者真相时主动问「那是我的哥哥吗」，则神念会立刻停止发言，林恩第一次直面「兄弟」这个概念被戟直接跳过。
- 若林恩拒绝接戟而让噬神者抢走，则戟面意志会以全力毁伤噬神者的生存系统终生，林恩会看到鲨鱼鲜血渗透殿堂的场面。
- 若林恩主动把戟身递给小丑，则戟面意志会以「王骑殿下办事，不是给你」为由硬反弹小丑的触碰，由此确立戟身只认主王骑的绝对排他性。
- 若林恩在戟递到面前时假装昏倒，则戟会保持安静五天，林恩面临「装睡逼戟」的临时考验期。
- 若林恩让左左以咒瞳共鸣反扫戟身全貌，则她能揭出戟身内部还藏有第二道铭刻「不可继承」，揭示出「继承资格受法则严格限制」的客观事实。
- 若林恩主动提出「如果你说沉眠者是大君，那你又是什么」，则神念会以一声积压千年般的长叹回应，彻底印证神念的情感并非虚假工具而是具备真实的灵性共鸣。
- 若林恩拒绝接过戟但接受戟作为殿内镇物继续安放，则戟面意志会立刻留下烙印「拒绝继承但承认资格」的标签。
- 若林恩主动询问「女主人有没有提及过我」，则神念会以最宽厚的方式回馈「她反复讲，不讲完整」。
- 若林恩让孽主提前在戟前洒下血族圣血，则戟身会瞬间拒绝并用一阵无声震动回应，由此印证王戟与血族路线存在本质对立。
- 若林恩拒接戟而把小丑玩偶挂在戟上，则戟面意志会通过小丑的载体以一种亲切的方式自问「这就是我主人的新牵」，王戟意志展现出对王骑旧日友谊的无声默许。
- 若林恩主动让左左以咒瞳看戟背后的虚影全貌，则左左会看到一整个海王殿殿庭曾经的画面，林恩获得一段完整历史影像。
- 若林恩在戟降临时刻意滑步离位，则戟会飘浮在殿堂上方一会然后自行落到原处，呈现出「不主动强行锁定目标」的被动特性。
