# E10·视界经营与玥玥治疗·if线

- 若林恩登录视界后先翻完日志再动手炼药则倒吊人塔与魔人协会两条名词提前入脑，本事件内即可追问老师去向，不必等E11血夜被动揭示。
- 若林恩继续动用老师留在店里的4000骷髅币作为推广底气则当日售罄30瓶暴击药剂仍成立，掏空店内账户被血锯归来时问起。
- 若林恩按一瓶3000骷髅币的原价硬扛冷场不去改写广告则"天下药剂一般黑"成就不触发，30瓶库存压在店里，视界经营起步标记为"未售罄"。
- 若林恩改成私下走罪孽城黑市或黑喃渠道分销暴击药剂则店铺无名、知名度不抬，等价收入依然成立，魅惑路人冲击变成黑市侧记。
- 若林恩留几瓶自用或黑箱囤积不作销售则出货量低于30，库存成为后续事件的底牌或引爆点。
- 若林恩顺手把视野里的"我爱萝"店铺改造成别名义或对外挂牌别的店号则老师副业伪装被戳破，视界侧NPC开始盯店，光顾者身份发生偏移。
- 若林恩压根不登录视界、老老实实在实体店卖药则视界经营线形成为本事件未完成项，玥玥治疗仍可独立推进，事件最终以"视界经营没有起步"的状态记偏离。
- 若林恩压根不炼30瓶屎黄屎红暴击药剂而改炼其他药剂则广告文案、副作用舆情、跨区域知名度全部改写，"天下药剂一般黑"成就换成对应品类版本。
- 若林恩只调十几瓶就把全部市场营销烧光则当天收入腰斩，倒吊人塔线索没有更大资金底气去查，后续跟进节奏放缓。
- 若林恩在副作用爆发当天顺势再加推"防秃头""防生毛"配套新品则黑暗精灵王庭、血魔族、狼人、独角鬼族形成回头客源，事件结果等价于"药剂生意品牌化"。
- 若林恩对被脑门反光闪闪的黑暗精灵王庭冲锋队、血族十岁正太、狼化爆毛者等副作用现场公开道歉或赔偿则面子擦损换回口碑修正，三家方势力偏向"善意围观"而非"记仇"。
- 若林恩选择压制广告范围只让老顾客知道则暴击药剂不流入公众视野，王庭冲锋队秃头事件、罪孽城血魔族十岁正太破纪录事件、独角鬼族船队获救事件都不发生，对应地名知名度加成缺位。
- 若林恩听完血锯广告推送后选择摇人帮忙盯着店面再推则店员或帮手目击完整爆卖过程，"故作为难"演法有见证者，被模仿剽窃的风险提高。
- 若林恩故意在广告里写明老师"我爱萝"的店号来历则老师与黑暗世界老主顾的联系被外人拼起来，倒吊人塔线索的保密性下降。
- 若林恩在傍晚店门咚咚咚响起时不开门或装不在则玥玥倒在门口惨烈状态被拖到早上，左左或其他住户先发现，林恩错过"秒加10好感"初遇节拍，好感锚点位移。
- 若林恩听到"需要手术，阔嘞"时直接收诊金再动手则玥玥懵着脸掏钱，临走仍然留下钱袋，好感与信任少了那30+30加成，挚友名头没了。
- 若林恩顺手开出大价格或顺带讨要小妖精酬谢则玥玥面甲后的反应被砍冷场，事件仍以治疗结束，但"吾挚友"宣言缺席，E11血夜吞噬左臂伏笔缺乏情感张力。
- 若林恩听到"你不会想要把我药晕之后捆起来"打趣后顺着打趣回去则好感波幅改版，治疗仍可照常推进，玥玥离店后去向依旧成谜，但初遇节拍气氛换味。
- 若林恩在治疗玥玥断肢时发现血肉增生药剂副作用苗头而停药则增生中断、断臂成形不全，玥玥带着残缺翅膀或残缺手臂离开，副作用变异伏笔挪到她自己身上。
- 若林恩按原方继续逐一剁除触手尾巴翅膀多指等变异组织则治疗等价成立，"胸前隆起失踪之谜"伏笔照常埋入。
- 若林恩在玥玥治疗时保留麻药坚持麻醉则她拒绝时改成口头安抚或物理按住的节拍，面具不再变形，"硬撑"细节消失，初遇画像变调。
- 若林恩在玥玥走后捡起钱袋收为己有则"忘记钱袋"伏笔被抹消，玥玥下次来的接触借口改写。

- 若林恩放下暴击药剂先去处理E09留下的某位复诊患者则本事件的视界经营节拍延后到玥玥治疗之后，夜里的血字警告与店外脚步声仍照常落下，玥玥关联伏笔不受影响。
