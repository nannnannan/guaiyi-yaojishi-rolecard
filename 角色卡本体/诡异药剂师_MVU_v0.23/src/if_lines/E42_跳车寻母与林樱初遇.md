# E42·跳车寻母与林樱初遇·if线

- 若林恩在倒计时跳出后先向白逸交代坐标再跳车，则白逸被一句"对不起"彻底惊醒、扑窗时只剩玻璃渣；尹琴收到的视频里多一段白逸扑窗的背影。
- 若林恩不打碎车窗、改从车厢连接处撬门跃出，则车厢完整、列车员目击就被压成小范围证词，"黑衣少年触手怪"视频热度下降，尹琴压热搜成本显著下调。
- 若林恩叮嘱血娃娃守在车身上，则回归倒计时那一秒是她先围一圈触手防御，林恩被拖回时多一层她本人的护送。
- 若林恩改走货车车顶，则入城延后两分钟，与校车擦肩；林樱那一幕只在远处看到带血身影，主动上前的触碰异象取消，改由后续校园回忆埋一条较弱的"我好像见过他"。
- 若林恩绕开十字路口、从居民楼阳台落地，则车祸不成立，"黑衣少年校车惊变"视频永不出现，尹琴收到的画面是楼间跳跃黑影。
- 若林恩被校车车头边角擦过而未直接被撞飞，则林樱依旧拨开人群蹲下查看，伸手那刻记忆闪现保留；视频质量低于原作血线场面但传播路径等效。
- 若林恩在林樱伸手前先把她手腕按住且一言不发，则"我学过医疗护理"那句台词不出口，触碰异象从主动伸手挪到她事后抓袖口想拦那一秒。
- 若林恩忍住不直起、低声反问"你是谁"，则林樱在记忆闪现与那张似像非像的脸之间卡住，"林樱……你叫林恩？"被吞回去，路人证词只多一句"她喊了什么"。
- 若林恩让脸主动蹭上她掌心，则记忆画面更深一层——两人在桂花树下分糖的童年场景一并涌入，林樱当场僵直昏倒，本事件直接变形为"林樱先被县医院抬走"。
- 若林恩在被拖回前还来得及低声"谢谢你碰到我"，则林樱保有的不是空白而是明确一句"他认得我的脸"；收服林樱时她的羁绊初始值上调一档。
- 若林恩在触碰时被拟化微调瞳孔焦距，则林樱读到的画面被改成"两个孩子在屋檐下分西瓜"，触碰异象仍登记为未明谜团但权重从亲属推测挪向平行世界证据。
- 若林恩在院内母亲背影转身前被完全拖回、那一声"妈妈"只剩半拍，则母亲撩白发望的是无风处骤雨一瞬，丈夫"只有一个宝贝闺女"台词消音，"母亲似有所感"线索中断，事件仍完成。
- 若林恩拦下路人摩托报出"我叫林恩，我是这里的人"，则路人情侣成为旁证，县政府户籍系统多出一条可追的目击登记；院前最后一秒的"妈妈！！"被一句短"妈"替代。
- 若林恩不奔向自家院门、改向母亲常走的遛弯路线迎面冲去，则他与母亲在巷口擦肩，母亲只看到带血奔跑背影；E57 母亲是否记得整条线索被锁死为彻底空白。
- 若林恩在十字路口先用暴击药剂自给，把"被撞飞"从结果链切掉，则林樱没有救人机会；完成条件里"林樱触碰记忆闪现"改由事后在县医院门口擦肩被她看见勉强触发，强度减半。
- 若林恩与林樱对视时留下一撮随身黑色发丝压在她掌心，则林樱从那天起一直把那撮发丝当作"那个像我的男孩"的凭证；林恩回到黑夜城后，回归账本里多一条"留证为凭"的偏离注脚。
- 若林恩在她喊出一声模糊的"哥哥"时已无法回应、只能停留在认出她声音那一瞬，则"林樱直觉认出"作为可追线索写入，后续羁绊路径不替玩家决定。
- 若林恩判断这次赶回已无法突破回归时限、转身改回列车北返，则他错过与母亲县委的全部机会，E42 取消；触感和"妈妈！！""只有一个宝贝闺女"三条线索均不成立，平行世界妹妹身份推后多年才暴露。
- 若林恩抵达院前后先在院墙上稳坐一秒、不是直接冲刺，则母子背影相遇时间从一秒延到两秒；母亲因狗叫抬头却没有走出院门；尹琴收到的画面只多一格"母亲抬头侧影"。
- 若林恩在整条 E42 完成后对左左说"我还要去一次"，则尹琴压热搜线索折叠为较冷状态，林恩与尹琴、林樱的早期接触只能从另一个起点重新开始。
