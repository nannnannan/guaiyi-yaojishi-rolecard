# E390·开棺与渡鸦灵魂尸骸·if线

- 若林恩在开棺前主动以夜魔刀替换电锯进行切割，则刀口迸出更密集火花，刀身完好但棺面依旧光滑，工具损耗路径不变，时间浪费更少。
- 若林恩让左左先以系统空间尝试收入棺椁，则空间边缘与棺面接触处发出咔咔脆响，左左的收纳袋被反震裂出一道口子，棺椁表面连划痕都没有。
- 若林恩在开棺指令下达前先用初诞者之力扫描棺椁内部结构，则他读到一片混沌的能量漩涡，无法分辨内部是尸骸还是纯粹法则聚合体，开棺决策风险更高。
- 若林恩在棺椁升起时主动伸手触碰外溢的法则丝线，则一股强大的吸力试图将他拖入棺内，左左必须瞬间卷出触手缠住他的腰才能避免被吸入。
- 若林恩在光芒褪去前就用咒瞳直视内部，则强光瞬间灼伤他的视觉神经，他的右眼短暂失明三分钟，但提前确认了尸骸确实存在。
- 若林恩让左左模仿幻境中左手拔刀的姿势去撬动棺盖，则餐刀再次断裂，棺盖纹丝不动，左左的虎口旧伤复发，她不得不暂时退出探索。
- 若林恩在开棺后立刻尝试以血肉灾变覆盖尸骸，则尸骸表面的腐败气息与他的血肉产生剧烈排斥，他被弹飞数米，胸腔受到重击。
- 若林恩在法则丝线黯淡时反向加大初诞者之力输出，则丝线亮度短暂回升但尸骸微微颤动，震颤频率加快，空间结构稳定性反而下降。
- 若林恩让左左在棺椁旁守候而自己短暂离开去检查深渊壁面纹路，则左左报告尸骸在他离开后发出一声微弱的鸦鸣，声音无法被任何设备记录。
- 若林恩在开棺后主动以系统商城兑换一支「灵魂安定剂」注射给尸骸，则针管在接触尸骸表面时直接汽化，药剂无法渗入，商城退款但留下交易记录。
- 若林恩在开棺前用鲜血在棺椁表面绘制稳定符文，则符文刚成形就被黄沙吞噬，棺椁没有任何反应，但林恩的血量永久下降 2%。
- 若林恩让左左以心声向黑堡方向传递「发现棺椁」的信号，则信号在穿透结界时被削弱为一段杂音，艾雯只收到断断续续的「危险」两个字。
- 若林恩在开棺后尝试以灵能包裹尸骸进行远程操控，则尸骸在他掌心微微发烫，一股不属于他的记忆碎片涌入，他短暂陷入眩晕状态。
- 若林恩在开棺后立刻记录尸骸的腐败模式并绘制病理图，则他发现腐败并非自然发生，而是某种外力在死亡瞬间强行注入，与幻境中的战场画面吻合。
- 若林恩在开棺后拒绝触碰尸骸并选择原路返回，则他在上升途中发现法则丝线开始追踪他的轨迹，返程难度大幅增加，必须依靠左左的触手才能安全脱离。
