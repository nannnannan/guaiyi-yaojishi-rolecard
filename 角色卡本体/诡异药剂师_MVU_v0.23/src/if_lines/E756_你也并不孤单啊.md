# E756·你也并不孤单啊·if线

- 若林恩在第一位旧日天使回返王庭前先沿王座把她的名字念出来，则她以锋线而入而不是泫然坠地，外层防线首波所列之形更完整。
- 若林恩主动把回返军团的因果与自身王座短暂绑定一拍，则那场集体回应在他灵魂里落下一层新的负重，光幕恢复更快但王座底火更灼热。
- 若林恩在三叉戟压入石柱时向银色幻想递一句具体到秒的方位，则她落戟的角度修偏半度，金色法则沿废墟扩散的轨迹绕开她近来最疲软的右翼。
- 若林恩让王座把最年幼那名天使的羽翼影像投到撤离者通道尽头，则残存撤离队伍在最后阶梯上齐声喊出一声「继续走」，外层法则桥梁多撑两秒。
- 若林恩把第一位回返的军团长背后插着的黑潮倒钩提前以黑火咬碎，则军团长落地时不带伤回归，回返信号在信标网上传得更远。
- 若林恩透过王座向撤离另一端传一声「不要回头」，则最后几名将堕未堕的天使选择把羽翼留在通道里而非追过来救主母。
- 若林恩主动把自己的心跳沿王座漏出来一下让回返者听见，则那些几乎要弃守的老兵在最后一刻撑住，「他也不孤单」第一次在他们之间无声传唱。
- 若林恩把残余人偶家丝线的某个断裂端主动系上自己的黑火末梢，则那一段丝线被点燃，外层裂口堵上一枚可复燃的火种。
- 若林恩让王座故意把噩梦侧翼某一段黑潮错写成友方信号，则那一片黑潮短暂被自身其他段当头喝止，回返军团多挤出一线空挡。
- 若林恩在主母背后挡下某一记从石柱背面钻出的黑刺时让自己的王座背对那一瞬，则主母没有回头分神，正面牵制不失衡。
- 若林恩允许王座把回返中某位已疯癫天使的呓语录下来，则那段呓语日后成为他最后一次听见「家」这个字的声音。
- 若林恩向王座下令把船长的毁灭火从远端一个节点借来一缕，则外层防线该处短暂呈现红黑双色，黑潮经过时被烙下一层持久惧意。
- 若林恩在光幕分散至更多位置时先一步把某座位置的坐标往内挪半米，则那些位置未被噩梦预判命中，外层防线首个高峰比预计多烧一轮。
- 若林恩让某位重伤回返者在抵达王庭前先看到他而不是先看到主母，则该名战士把手中的残旗直接塞进林恩王座的火里，留下一个不会熄灭的方向。
- 若林恩向王座说一句不让任何回返者听见的「辛苦你们了」，则信标网在那一瞬间以不可记录的方式轻轻一应。
- 若林恩用黑火包覆某枚即将被噩梦截断的回返信标，则那枚信标穿过黑潮炸出更响的声波，远处未返者循声而回的速度提升一倍。
- 若林恩在光幕修补时将撤离另一端年幼生还者最后一声呼喊转录成法则符，则外层光幕在那一处多出一层透明隔音罩，庇护了三位藏身其后的伤员。
- 若林恩命令王座把自己名字从信标网的回应语中撤去，则响应者执念对象短暂换成「光幕」本身，外层防线以更纯粹的形式燃烧。
- 若林恩主动向主母借一段她压在石柱上的祷词用来盯住外层防线，则那段祷词在另一名天使坠地时替她挡住致命一击，主母对他的眼神多一线牵连。
- 若林恩让王座把外层防线上某座崩坏的节点编号改写成已死同伴的名字，则那一段法则响应度异常高，噩梦冲击经过时首次停顿一拍。
- 若林恩选择聆听撤离另一端的恸哭而不是回应，则他把那份哭声折进自己的黑火中，王座对灵魂的刻蚀再深一寸。
- 若林恩命令王座短暂关断与某位回返天使的因果以避免黑火反噬她，则她多活数秒，却没能把手中最后一段法则接上光幕。
- 若林恩在某位军团长即将冲回王庭敞开怀抱时主动别开一下头，则军团长以全力撞上光幕而不是他，回返信号未被打断。
- 若林恩在最后阶段让王座把外层光幕的亮色调暖一度，则前线那些将堕的天使在最后一瞬看到的是「家」而非「战场」。
