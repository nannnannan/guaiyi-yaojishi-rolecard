# E756·你也并不孤单啊·if线

- 若林恩在主母（自缚天使）神力彻底枯竭、被无数漆黑恶魔长矛贯穿身躯高高钉死在王庭残破石柱之上的那一瞬，于圣所内发出一声震碎半数锁链的泣血狂吼，则那些刺穿主母的恶魔长矛会在他隔空溢出的黑火中寸寸断裂。
- 若林恩在主母被钉于石柱之上、鲜血顺着洁白衣裙流淌却依然含笑望着圣所方向缓缓闭上双眼时，透过石壁与她完成了最后一次目光交汇，则母亲在闭眼殉城的那一刻知道孩子正看着自己。
- 若林恩在银色幻想目眦欲裂地冲上前、从主母垂落的手中接过染满金色神血的海神三叉戟继续死战时，顺着戟杆将自己滔天的悲愤化作狂暴神力灌入银色幻想体内，则这位重伤的神王一戟便挑飞了三头上前亵渎遗体的魇魔。
- 若林恩在此前被银色幻想强制遣散出城的两千余名黑夜城老兵抗命调头、驾驶着伤痕累累的战舰重新杀回黑夜城废墟高呼「与吾王共存亡」时，让圣所高塔发出震天动地的嗡鸣回应他们，则这支孤军冲锋的声势足以令终焉动容。
- 若林恩在孽主浑身浴血地站在内城通道尽头、回头朝孤儿院方向露出最后一个纯真微笑后引爆全部罪孽本源化作深渊吞噬周围魔物时，以王座之力将她消散前的一缕纯净灵魂火苗收入怀中，不让她再堕入无间黑暗。
- 若林恩在艾维儿身披残破紫罗兰父铠、率领阿鼻地狱全体守望者军团撕裂虚空降临王庭战场时，让全城的暗金火光同时向她们汇聚，照亮这支从地狱归来的悲壮孤军。
- 若林恩在听见艾维儿隔着圣所大门朝他高声喊出「林恩，你也并不孤单啊！」、随后率领全体守望者将士义无反顾地集体引爆本源时，被锁在王座上的他流着血泪拼命点头，在心底回答「我听见了，艾维儿」。
- 若林恩在艾维儿与阿鼻地狱全体守望者军团集体自爆、化作一道横亘在王庭前的无光深渊屏障将扑来的魇魔大军硬生生截断时，以自身神格将那道无光深渊永久锚定在圣所前方，使之成为任何魔物都无法逾越的忠魂天堑。
- 若林恩在主母被钉死在石柱上的遗体即将被漫天黑雨淋湿时，拼命催动三叉戟残留的余威在石柱上方撑起一柄无形的金色光伞，护住母亲最后的尊严。
- 若林恩在那些杀回来的黑夜城老兵们明明知道必死无疑、却依然笑着跳下飞船用血肉之躯替银色幻想挡住侧翼魔潮时，将每一名老兵战死时的呐喊都化作敲击锁链的重锤，加速自己的破封。
- 若林恩在孽主自爆化作的深渊边缘留下一朵由药香凝聚的小白花，则当硝烟散去时，这朵小白花会静静立在深渊畔，证明这里曾有一位为了保护孤儿院孩子而死的温柔少女。
- 若林恩在艾维儿引爆自身神格前的最后一刹那，让她清晰看见父亲紫罗兰神王微笑着向她伸出手的幻影，则这位背负了太多苦难与孤独的守望者统帅，在化作无光深渊的那一刻终于回到了父亲怀抱。
- 若林恩在银色幻想左手持断剑、右手握紧染血的海神三叉戟，独自站在守望者军团自爆形成的无光深渊内侧继续狙杀漏网魇魔时，以王座黑火替他灼烧全身伤口止血，让他得以撑到将三叉戟交给黑弦月的那一刻。
- 若林恩在感知到主母、孽主、艾维儿以及成千上万杀回来的老兵与守望者灵魂金光同时如银河倒泻般涌入圣所时，胸膛几乎被这份沉重到极点的爱与牺牲撑裂，第三阶段的门扉在轰鸣中裂开巨缝。
- 若林恩在一名断了一条腿的黑夜城老兵拄着战旗杆爬上王庭台阶、在咽气前用血手擦亮台阶上的王室徽记时，将那枚带血的掌印直接拓印在自己王座的扶手正上方。
- 若林恩在艾维儿喊出「你也并不孤单啊」的声浪传遍整座废墟、连圣所内奄奄一息的艾雯都听见并露出欣慰苦笑时，低头看了一眼脚边的艾雯，两兄弟在血泊与火光中完成了无声的共鸣。
- 若林恩在阿鼻地狱守望者军团集体殉道掀起的风暴将王庭前方的七尊终焉魇魔震得吐血倒退时，顺势发出一道灵魂穿刺，将其中一尊受创最重的魇魔核心当场震出裂纹。
- 若林恩在看着主母高悬于石柱之上的身影与昔日她温柔抚摸自己头顶的画面在脑海中重叠时，理智防线彻底被极致的悲痛击穿，黑火如火山喷发般将圣所内壁烧成赤红琉璃。
- 若林恩在银色幻想因握持海神三叉戟过度透支生命、一头银发被自己的鲜血染成暗红却依然挺立如松时，在心底一遍遍呼唤他的名字，不让他在交付神兵前倒下。
- 若林恩在那些抗命杀回来的两千老兵中，留下一百名最年轻伤兵被守望者自爆的气浪推回远方废墟掩体，则这批老兵得以幸存下来，成为E760与他共饮「敬明天」之酒的两千幸存者的一部分。
- 若林恩在无光深渊屏障成型的瞬间，听见深渊底层传来千万守望者英灵齐声高唱阿鼻地狱战歌的回响，则他的第三阶段神格中从此多了一重镇压万魔的地狱回音。
- 若林恩在主母消散的最后一缕金光飘进圣所、轻轻拂过他被锁链勒出血痕的脸颊时，偏过头用脸颊贴住那缕金光，像幼时一样贪恋着母亲最后的温度。
- 若林恩在「你也并不孤单啊」的余音中彻底挣断身上大半锁链、只差最后一步便能冲出圣所时，整个人的意识却被拉入了更深层的宿命梦境，迎向织梦最后的告别。
