# E518·奈奈子意识与三柱真相·if线

- 若林恩在银幻挥拳前先迈半步让她拳头停在距脸一寸，则拳头不落，「宁愿不加入你」这句换成「你已经加入我了」的反向嵌套。
- 若林恩选择不挨那一拳而是用灵能卸力，则银幻这一拳打到空处，她的「代表全家否决」姿态变得空手空势，气氛不完全成立。
- 若林恩在「我们又该何去何从」之前先问「主母龙王殿里那口古钟还在吗」，则何去何从命题被转移成另一道话题，本事件摊牌节奏改写。
- 若林恩在远西神王切景中主动想去追羽毛笔而不是旁观，则他错过「时间不曾轮回过」这句关键证词，三柱真相情报链断一环。
- 若林恩选择不把欲望母树种子移入奇异世界而是继续贴身携带，则母树法则涌动延后，回城后无「种子内法则涌动」的可核证物。
- 若林恩在见到巨像时不开「晚上来我房间」的玩笑而是正式约谈，则「物质交互约定」不成立，改换成「同盟会议预约」。
- 若林恩在北海前锋涌现时选择不呼喊奈奈子而是直接迎战黑雾，则他被第一时间卷入，苍蓝意识域相认入口关闭，E519 改由他独自面对。
- 若林恩在具名呼喊时把「黑雾」换成「初诞者」，则召唤信号误入另一条通道，可能召来狱卒或某位王者而非奈奈子。
- 若林恩呼喊奈奈子时以巫神船长的敬语加上「请大人降临」，则奈奈子化身年龄或从女孩变成更成熟形态，摊牌气质改写。
- 若林恩在巨眼睁开瞬间主动闭眼避开对视，则他错过「世界如微尘」的画面但保住双眼不被灼伤，初诞者之力抵挡不复用。
- 若林恩决定不让黑雾再罩而是用自己的翎羽甲胄遮住巨眼，则甲胄承担重创，他失去这件对抗时间污染的关重道具。
- 若林恩在北海死灭场景中选择不撤海族只救少数，则可救一部，撤海族与放弃一部之间的代价由他背负，Karma账记一笔。
- 若林恩在意识域见面时不是称呼「奈奈子」而是称呼「画家」，则她的态度可能从私语转向公开，摊牌内容的亲密度降低。
- 若林恩在质问她时先问「你当年是谁」而不是「你要做什么」，则她可能先摊个人往事再谈机制，叙事顺序逆流。
- 若林恩在见到蓝宝石眸女孩时第一眼没认出她，则她可能主动自报家门或者默然离开，方舟借力轴不成立。
- 若林恩选择不问她计划饵食以太而是问她「你是谁的朋友」，则摊牌走向关系层面而非战略层面，初诞者借力窗口延后。
- 若林恩在得到「灾厄＝终焉之主断片」情报后立刻告诉主母众，则情报提前公知，半夜城会议节奏改变，E520 的时间战争启动氛围不同。
- 若林恩选择不立刻回黑夜城而是先去北海亲自查看前锋，则他错过回城调度窗口，北海损失加重，「放三叉戟内夜医部队」决策也被推迟。
- 若林恩在奈奈子提到「未来回告须走正确道路」时反问「是谁来回告」，则她可能说出哪位未来来客，情报链延展出一条新钥匙。
- 若林恩决定对「地狱＝最后方舟」命题直接否定而坚持要做「最后的反抗军」，则方舟定性改写为「最后的堡垒」，后续大坠落机制不启动。
- 若林恩在拒全尸交易时给出替代提议「分我一半」，则奈奈子可能同意或者否定，渡鸦尸体分配账本改写。
- 若林恩在「开始吧」窗口前主动问「我要付出什么代价」，则她可能答「你以后不能再后悔」，留下一道枷锁，E519 的释力窗口附着责任。
- 若林恩选择不让小小／泰坦在黑夜城画十字而是严肃召回，则赶路喜剧缺席，氛围更凝重。
- 若林恩在「以后也再不会有人对你施加磨难了」听见时反而追问「那以后谁给我磨难」，则奈奈子可能回眸一笑而不答，他得到未来变数伏笔。
- 若林恩在意识域结束时尝试伸手触碰奈奈子的手，则触碰被因果屏障挡回，他多一段「她是真的不能再被触及」的认知。
- 若林恩选择不在甲板众人前公开巨眼事件而是私下告知主母，则公知度降低，回城后的恐慌程度减弱，但戒备也减弱。
- 若林恩决定让船长也一起进入意识域，则船长可能见证奈奈子摊牌全程，死亡神格证词多一名佐证者。
- 若林恩在回到舱内时选择先睡一觉而不是立刻行动，则他错过最佳释力窗口，E519 的大坠落机制推迟数小时。
- 若林恩在船舱见到奈奈子时故意带上一份小小给他的糖果，则他可能把糖果递给她，奈奈子反应冷淡或者侧目，人与神之间多一笔微细的互动。
- 若林恩在对话结尾请她留下一个信物，则她可能留下一缕发丝或一个光点，作为后续召唤媒介，E519 释力过程的难度降低。
