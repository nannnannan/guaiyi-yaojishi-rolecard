# E183·寄生兽催熟与高活性血肉污染·if线

- 若林恩在右臂探入粘液之前先把左手也跟着放入腔内，则双倍活性血肉让幼虫蜕变速率再提一档，事件以变形（双手实测）收束，腔内阴暗处的伏击计划提前一轮触发。
- 若林恩让咒瞳切到最高功率先扫描腔内成虫所有体征、再决定是否探手，则他直接拿到三阶段完整图谱、放弃活体试验，事件以变形（仅扫描不探）收束，血肉污染概率降到零。
- 若林恩让尹依代他把手伸入粘液试验幼虫反应，则她的灵体被幼虫直接穿过无法寄生，事件以变形（灵体无效）收束，腔内负责人首次意识到「欲望教派有灵魂组员」。
- 若林恩用咒术在自己右臂先裹一层根源禁印护膜再放入粘液，则幼虫啃到禁印被弹开、活体试验失败，事件以变形（禁印隔离）收束，血肉污染机理以护盾对照数据被记录。
- 若林恩主动加大巨像之心血输出饲育幼虫至畸变临界，则第一只成虫提前爆裂溅满腔内晶状体，事件以变形（成虫炸裂）收束，负责人把这一异象当作「超规格活体毒蚕」。
- 若林恩让左左代观察寄生兽蜕变、本人退到腔外防守监控视野，则伏击触发时他能第一时间脱离腔体，事件以变形（远程坐镇）收束，E184反伏击开场位置完全改写。
- 若林恩对右眼咒瞳同时发动第二档、把腔内成虫的精神震荡直接反射回幼虫群体，则后续幼虫被自己的震荡干扰、大批量自爆，事件以变形（震荡自残）收束，负责人把责任推给「样品瑕疵批次」。
- 若林恩当着负责人的面一脚踩烂成虫之后直接喝斥「你们大师做得这种欺凌幼虫的烂货不是兵器」，则负责人立刻双膝一软坦白大师地址，事件以变形（直接问出大湿）收束，伏击节奏被打断改走外交。
- 若林恩在成虫出世瞬间抬手召唤咒纹把它的精神震荡压至 0 振幅，则腔内其它幼虫无法感应成虫信号、蜕变链暂停，事件以变形（震荡消音）收束，腔内陷入停滞。
- 若林恩纵容成虫欺凌幼虫场面持续三次并录影，则负责人被这份恋奇癖惊到神志混乱一连三度失误，事件以变形（猎奇录影）收束，腔内警戒延迟数分钟。
- 若林恩把成虫以咒纹单只封印收进系统空间，则他在腔内开辟专属样品栏、负责人警觉值飙升，事件以变形（强行采样）收束，伏击由暗处监控者当场发动。
- 若林恩让血肉人形监控者察觉自己的神经血色被锁定之后反手以咒瞳侵入对方中枢，则腔内暗处监控室被反向震荡、报告内容混入「目标疑似主神附体」字句，事件以变形（反向骇入）收束，伏击档位上调至「献祭式」。
- 若林恩在腔内盘膝坐下摆出「我付钱买你整个腔」架势，则负责人瞠目结舌张口结舌，事件以变形（当场收购）收束，腔内谈判开启一条完全岔线。
- 若林恩看见成虫时让左左跳出以夜魔刀把它的长尾剁下来，则负责人被这份凶残震住、对左左的评级超过林恩，事件以变形（左左先动手）收束，腔内警戒对象切换。
- 若林恩故意让成虫吸食自己一滴心脏热血、使其血脉对巨像之心产生认主响应，则第一只成虫变为对他摇尾亲近、主动脱离原阵营，事件以变形（认主成虫）收束，腔内负责人瞳孔地震。
- 若林恩在验完三阶段机理后立刻封嘴离腔、强行把负责人按在墙上一手剥他殖装接口，则腔内进入乱局，事件以变形（腔内反水）收束，E183伏击模式被林恩主宰反先攻。
- 若林恩让左左提前在腔外街面以夜魔刀悄悄切断爬行者下半段触足控制回路，则腔内伏击启动时无法转移位置，事件以变形（断足钳制）收束，爬行者暂时无法逃逸。
- 若林恩主动以心声联系监控神经网络用「我已发现你们」一句话刺穿伪装，则腔内暗处频道陷入三秒静默、随后攻势加倍，事件以变形（撕破脸）收束，E184反伏击场面整体升级为「双向锁定」。
- 若林恩全程只看不探、记录完三阶段机理后立刻拉起尹依返身就走，则腔内负责人进退两难、被迫在腔内主动启动「强行挽留」模式，事件以变形（主动撤离）收束，E184改在爬行者外部爆发。
- 若林恩把一只幼虫活捉到自己右眼咒瞳内饲养，则右眼获得一份「共生型寄生宠物」，事件以变形（瞳内共生）收束，未来咒瞳升级链条新增一条专属路径。
