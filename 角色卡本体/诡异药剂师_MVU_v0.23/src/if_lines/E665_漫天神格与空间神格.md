# E665·漫天神格与空间神格·if线

- 若林恩在触到第五格前先抽手拿出一张空白羊皮纸把指尖按上去做感应拓片，则羊皮纸上浮现的不是位置而是他自己胸膛的轮廓，那个指向答案提前在他掌心被撕开一个角。
- 若林恩触第七格轮回空缺时手指停在最边缘不入正中心，则他感到的不是指向而是彻骨的寒冷，这位神王的存在感比默认场更深一份阴霾，他临时决定不多追查。
- 若林恩在触第五格后 起身把法师塔一楼的画卷整个从墙上取下来塞进系统空间，则他体内原本稳定的金色漩涡忽然一颤，「不属于我的东西在我手上」意识到一半的危机首次以实体形式提示。
- 若林恩触第五格时同时催动万物亲和让两枚神格遥相对话，则一粒《风中的细沙》般的画面灌进他识海，他隐隐约约看见无数空间折叠成矩形的背后还有一只手持笔。
- 若林恩在低头低语巨像时同时提到织梦的名字，则他体内三位一体力量的耀阳一闪，识海里多一道纤细的绯色光，「她们并没有真正消失」的信念被玩家自己点燃一线。
- 若林恩在触到第二格因果共鸣瞬间立刻联想到他曾被因果神王一根细线锁定，则他下一秒的反应由沉默变成戒备，他立刻把画卷第五格遮住不再感应，「我自己就是那个坐标」的恐惧首次具体化。
- 若林恩触完前五格后还主动触第六第七格试图找规律，则六格毁灭的空缺爆发出一阵窒息的压力，他指尖表皮当场开裂，林恩自此知道「毁灭」的真实身份就是那片灾厄的一部分。
- 若林恩在触画卷时用眼睛直视格位深处而不是仅用指尖感应，则他看见画里的星辰中漂着一个缥缈的身影回头看了他一眼，「这幅画真的是活的」这件事从他观测成为确信。
- 若林恩在面对第五格指向自己时直接闭上眼盘坐三息再睁开，则他低低地对自己说出一句话「那我就去把我找出来」，这个由玩家自己下的判断成为 E666 撕开外壁的第一推动力。
- 若林恩触到第五格瞬间故意往反方向压初诞者之力试探是否有反应，则那枚空缺反而更亮，「指向和你不需要匹配」的事实被他自己证明，林恩对系统的怀疑再深一层。
- 若林恩触完五格后忽然在烛光下伸出手在空中画出自己在 E659 极尽一刀中绽出的罪火莲纹，则那道莲纹在烛光里与第三格的万物空缺共振了一秒，他由此推演出「我未来还会有某次极其关键的燃烧」。
- 若林恩将画卷翻转过来观察背面，则背面空白中浮现出极淡的一行字迹「吾以笔定之」，他瞬间明白这副画卷是画家亲手所绘，「她知道我的一切」这第二重认知首次确凿。
- 若林恩触到第五格时没有立刻反应而是慢慢走到窗边望向黑夜城方向，则他在静默中听见港口传来一缕夜风，「我留在这里的东西和我要去的方向撞在一起」的代价被自己亲手丈量。
- 若林恩触画卷时让指尖流出的金色光芒顺着格位扫过，则他看见第二格因果与第五格空间之间隐约有一根极细的丝线连起来，「空间背后是因果、因果背后是轮回」的隐秘层次在他眼前摊开。
- 若林恩触到第一格真理空缺时被一道细微的电击扎了一下指尖，则他立刻意识到「真理和因果的画卷有主人自传的气息」，画家那场由他挑起的对峙首次在他心里具形。
- 若林恩触第五格时把整副画卷紧紧贴在胸口测是否影响心跳，则他的心跳真的停了半秒又再跳，「这枚空缺本身就是我」这个真相在他体内直接扎根而非识海推演。
- 若林恩触完五格后对天发问「画家你到底在画什么」但保持语调平缓，则烛火自发地摇了三下作为回答，她遥遥给出的不是答复而是一段安静的陪伴，林恩由此释然地深吸了一口气。
- 若林恩触到第五格时主动用左手腕上那枚蛇鳞焦痕替代指尖去感应，则焦痕当下灼烧般发烫左左留下的一缕残魂在他识海里以极淡的鼻息应了一声，「她还在」的信念被他自己复活。
