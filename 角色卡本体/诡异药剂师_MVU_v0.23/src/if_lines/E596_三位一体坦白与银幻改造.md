# E596·三位一体坦白与银幻改造·if线

- 若林恩在被银幻捅破前先一步开口「你已经猜到了吧」，则银幻的「捅破」仍会发生，只是她的气势会被他这一句按矮半档。
- 若林恩选择只对银幻坦白「三质会吞噬我」这一层而不提外来者根底，则银幻的惊恐会更重，她会在意识空间连连要求他做医学性检查。
- 若林恩向银幻坦白时顺手调取当时天堂遗址的映像残片让她亲眼看见，则她会在那一瞬几乎要说不出话，此后对他更沉默。
- 若林恩在坦白时没有提及「吞噬担忧」，则银幻会事后通过他语气中的一处破绽自己拆出来，后续她会暗暗开启远程检查他心能稳定性。
- 若林恩主动让银幻先给三质各自做一个健康检测，则她会先停下改造、花整整一日时间全身扫描，最后给出一份「无警讯」的死板报告。
- 若林恩提出对她体内灌注更多自己的力量作为「保险」，则她会严肃反问他「你是在给我留后手吗」，林恩以一句「是」让她沉默很久。
- 若林恩在与银幻对话途中压制下心灵法则倾向让她自然得出猜测，则她对林恩那份信任的激励会因此更大。
- 若林恩拒绝让银幻灌注「控制权」，则她会愣住一秒后以一种更高冷的「好」点头，但她会在心里下一条「我不再多问」的铁律。
- 若林恩要求她改造时立刻加入「可以全机自动化当打手」不是玩笑而是真心，则她会黑着脸问他「你是认真的吗」，然后真的动手考虑这条路径。
- 若林恩在小丑在旁时公开说「这是我老婆」，则小丑会当场装作没听到，但小丑心里会落一颗「托线不拆」的印。
- 若林恩在离开时没有留下暗伏力量吓阻，则小丑在放哨时会更紧绷，E597 林恩深潜期间他会每隔一念报到一次。
- 若林恩在改造作出时主动给她一个小盒子写「启封后看」，则她不会立刻打开，但会在 E597 林恩失联半小时后才小心掀开。
- 若林恩在离开前给左左一个「你不要对大姐说话」的暗号，则左左会在心中对她更大声喊「大姐！」，喜剧与果决并存。
- 若林恩在坦白时主动约法三章「有朝一日我凶变时你必须立刻杀我」，则银幻会沉默很久才点头，此后她对他的态度沉稳不死板。
- 若林恩对银幻说「你比任何一位大师都懂我」，则她会面无表情地答「嗯」，但整个改造工程会在她手里被她做得更周到。
- 若林恩明确要求她完成后先行离开，则她会在完成时不再陪他静等，而是独自扎进下一段改造，E597 林恩回归时她已悄然走远。
