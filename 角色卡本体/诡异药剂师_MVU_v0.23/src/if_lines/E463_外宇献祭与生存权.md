# E463·外宇献祭与生存权·if线

- 若林恩在将军开口前主动从系统空间拖出小丑的分泌物摆在膝上，则左左尖声问这是什么，绑定值 -1，但学者的数字面孔在同一秒多抖了一帧。
- 若林恩在被锁进魔方时主动用指甲在六棱壁上刻一行小字「不要慌」，则那一行字在针孔成形时被紫光映得发亮，夜医记录员把它单独摘录。
- 若林恩在学者宣称「我才是牢笼」时主动仰头笑了笑并把目光落在自己手腕，则他双脚在魔方内壁踩出两枚浅印，左萝在意识里替他记下这片刻的停顿。
- 若林恩在开棺椁那一刻主动让一缕无序先蚀穿自己的手心，则他掌骨被啃出一个三厘米的洞，但左左在意识里替他挡住一波反冲。
- 若林恩在纳米集群筑法阵雏形时主动从指尖弹出三枚晶簇贴到法阵基座，则法阵筑造速度被打乱三分之一，但那三枚晶簇在冲撞中被炉管吞噬殆尽。
- 若林恩在将军双眼紫黑一闪时主动放慢呼吸注目，则他在识海里多记下「紫黑之污」一项对照样本，但那一秒里他没有听见学者下一句劝。
- 若林恩在龙首落地时主动让左萝的意识从口袋里滑出，则她在被挤压的前一秒探出头看见那群机械巨龙，绑定值 +1。
- 若林恩在学者「我才是牢笼」广播传遍全军时主动把心跳调慢一拍，则他在场外线收到一句「良医的耐心 +3」标签。
- 若林恩在开棺三秒时主动跳进去与那缕灰色混沌贴身了一次，则他的小臂外侧被蚀出一道蜿蜒黑纹，左萝在意识里替他把那道纹画了标记。
- 若林恩在学者动摇瞬间主动朝她投出一道平静的灵能视线，则她的数字面孔在那一秒稳了一拍，但她后续提联合的姿态也被压制了一档。
