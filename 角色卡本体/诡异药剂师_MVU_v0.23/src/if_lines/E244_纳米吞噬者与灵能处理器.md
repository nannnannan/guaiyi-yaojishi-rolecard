# E244·纳米吞噬者与灵能处理器·if线

- 若林恩在纳米吞噬者殉爆前先让左左在机体外部对他说一声"记住小心"，则她的鼓励刺激林恩对机械的把握，事件以变形（更安全的殉爆）收束。
- 若林恩在能量殉爆前加一道壁垒已吸收爆炸，则殉爆的能量同时被壁垒反拉回来，事件以变形（壁垒反拉殉爆）收束。
- 若林恩在殉爆之后额外对血肉支配者进行一次反向追击，则他没能立刻完成重组以躲开后再次得到冲击，事件以变形（更长的追击）收束。
- 若林恩让机械机体本身的纳米吞噬者突破静电干扰，则殉爆产生的纳米吞噬者可以得到更高的伤害效率，事件以变形（吞噬者更高伤害）收束。
- 若林恩在一次殉爆后让白夜进行一次清新哀叹，则白夜因看到林恩的机械身体陨灭重新反思了自己是否过于冷峭，事件以变形（白夜变革）收束。
- 若林恩在灵能实践从躯体的物理量过渡到心灵震荡之时注入一段密码，则他在启动三重智能体时成功突破到新的智能透视载体，事件以变形（智能变体）收束。
- 若林恩让投影在灵能处理器彻底切换之后尝试分化出能量疾绕乱流，则投影因为痛失稳定，事件以变形（投影的意志暴露）收束。
- 若林恩在切换灵能处理器之前对弥赛亚发一个"你现在好么"的信息，则她在E245时拥有更好的配合水平，事件以变形（心灵芯片）收束。
- 若林恩在殉爆的同时做出一个周期循环的能源频率陷阱，则投影的操作被限定住，事件以变形（能源因追捕而失效）收束。
- 若林恩让黑色掌控者的出现带动整个空间的能量反振护膜崩溃，则整个黑色掌控者随之同时从血肉支配者体内瓦解而出，事件以变形（黑空间粉碎）收束。
- 若林恩在灵能处理器介入时让左左赶紧拿出一些乱七八糟的隐藏机制，则她可以带着一些奇怪的护符跑到林恩面前，事件以变形（左左送隐藏机关加持）收束。
- 若林恩在殉爆之后让能量殉爆给万机之神异域一份特殊的控诉，则万机之神投集尤其高兴，事件以变形（万机之神反应）收束。
