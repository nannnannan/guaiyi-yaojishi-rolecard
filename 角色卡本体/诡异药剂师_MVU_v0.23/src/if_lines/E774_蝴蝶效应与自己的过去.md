# E774·蝴蝶效应与自己的过去·if线

- 若林恩在听到历史更迭报警时先往八百五十一年前看一眼再回宛自己所在节点,则他能更精准定位被修改的位置,但他自己所在节点会多一秒的暴露。
- 若林恩让左左在历史波动时同步用左手示警而不是大叫,则林恩反应速度更快,但左左会感到被他在高压时刻要求冷静的压力。
- 若林恩把「他的老师」这个变量换成「左左认识但不熟悉的人」,则因果破坏范围会缩小,但林恩需额外验证那个人是否真不被影响。
- 若林恩在处理完偏改历史之后主动去拜访那个差点被杀的先辈,则他能确认那条分支被修复,但他会首次面对「对方可能认识他却不知道自己会死」的现实感。
- 若林恩让左左在穿越过程中尽量分散注意力,则她不会过度紧张,但也会导致她对「历史」这一概念的把握比林恩弱一拍。
- 若林恩把自己过去的轨迹画成一条线再标出每个渡鸦降落点,则他能更直观找到问题点,但这张图谱会成为他下一步被黑影利用的地图。
- 若林恩在穿越到八百五十一年前时选择伪装成普通人而不是神格持有者,则他能更顺利混入观察人群,但他自己的反击速度会被自身身份限制。
- 若林恩让黑火在修复历史时只烧断恶线而不伤无辜牵连,则他黑火精度会被推向新层级,但执行时间会大幅延长。
- 若林恩把自己在哪次差点改变历史的事件从意识里直接删除,则他不会为「差点犯大错」持续承压,但也会失去这个教训在未来提醒他的强度。
- 若林恩让左左在他修复历史时用左手紧紧握住他的手,则她能成为他在长河里唯一稳定的方向感,但这也会让她过度暴露于历史的回响。
- 若林恩把「三个我同场」的定位技巧从理论化为可重复使用的手册,则他在后续遭遇多个自己时更从容,但这也会导致他对「自己的存在感」产生麻木。
- 若林恩在处理遥远过去时主动选择不与任何当地居民互动纯粹做观察者,则他能完全避免蝴蝶效应,但会丧失在探索中建立连接的机会。
- 若林恩让左左在发现过去渡鸦存在时把手心贴在自己胸前,则他能通过她触感确认自己的心跳不会因发现加速,但左左会对「他的心脏」有过度关注。
- 若林恩把自己渡鸦的存在标记为「这个时空的他不是我」的区域而不是连续过去,则他能降低情感负担,但这种切割会让他对自己的认同感受损。
- 若林恩在见到狱卒和黑压压人群时闭上眼用左左的手感知而不是视觉,则他能过滤极端画面保留感知,但这种依赖会让他在没有左左的时刻产生盲区。
- 若林恩让黑火在听到狱卒「我们庇护众生」时不做任何反应,则他能保持中立态度,但林恩对此事件的憎恶会被无限压抑。
- 若林恩把自己从渡鸦群体存在中找出来再用黑火识别原始渡鸦身份,则他能确认自己的根源,但这个过程也会在渡鸦集群中引发轻微骚动。
- 若林恩在发现「忍耐」讯息时主动让自己的渡鸦形态发出一声呼应,则他能确认自己的过去与现在连接,但这种呼应可能被某些存在侦测到。
- 若林恩把「他是大君的一部分」这个身份接受为自己的一部分而不是只属于大君的过往,则他能更坚定参与历史,但这也意味着要承担更多天的重量。
- 若林恩让左左在渡鸦出现时尽量不理解大君计划的全部细节只专注于当下他能做什么,则他能减轻认知负担,但这也可能让他在某些关键时刻缺乏远见。
- 若林恩把「八百五十一年」这个时间距离感转化为一场他可以立即参与的挽救,则他能在行动中建立成就感,但这也可能让他对历史的辽阔性产生偏差认知。
- 若林恩在八百五十年前修复完成后主动给自己留一段较长恢复时间,则他能更充分消化这次经历,但也会延误下一场应对。
- 若林恩让黑火在他探查辽阔过去时只点亮关键节点而不全部照亮,则他能节省能量,但也可能错过某些隐性连接。
- 若林恩在大君放出渡鸦消息时尝试用自己渡鸦形态发出回应,则他能确认自己是「选择承担这个身份」,但这种主动承担会带来更深心理负担。
- 若林恩在听到女子对狱卒控诉时主动让自己的渡鸦目露同情而不是完全冷漠,则女子会首次感受到「有人理解」,但这种同情会被狱卒记录为异常。
- 若林恩把自己在过去时段里每一秒都当作他在为之后的林恩铺路,则他能赋予自己行动以更宏大意义,但这也可能让他对当下的关注度降低。
- 若林恩让黑火在他听到渡鸦长鸣响彻天空时保持静止不做任何触动,则他能保持观察者的客观性,但林恩心底会因无法发声而累积压力。
- 若林恩在蝴蝶效应发生后主动用黑火在自己意识里烙一枚「教训」印记,则他能在下次面对类似情境时被即时提醒,但每次看到印记都会引动一次小小的自责。
