# E774·蝴蝶效应与自己的过去·if线

- 若林恩在未来画家留下一句「如果我做了什么，我很抱歉」离去后将黑火严密裹住周身，则他在接下来横跨游魂巷、初创黑夜城等上千次小型历史护航战中始终未曾泄露半分未来气息。
- 若林恩在距今八百五十一年的科技世界节点目睹魇魔屠戮平民、失手杀害了血锯老师的一位先祖时，瞬间感到自身记忆发生剧烈震荡，则恐怖的蝴蝶效应已然顺着因果线全面爆发。
- 若林恩在血锯先祖遇害的刹那惊骇发现「血锯从未收养自己，人偶夫人与人偶小姐从自己的生命轨迹中被连根抹除」，甚至连身旁的左左都茫然表示根本不记得人偶母女是谁，则他惊出一身冷汗，彻底体会到历史改写的致命凶险。
- 若林恩凭借时间神格的庇护毫不犹豫强行逆转回血锯先祖遇害之前将其救下，则哪怕要承受「同一时代存在三个自己（包括沉睡中的渡鸦自己）」带来的剧烈时空排斥，他也咬牙将历史硬生生扳回正轨。
- 若林恩在救下血锯先祖、听见左左重新记起人偶夫人与人偶小姐的欢呼声后长舒一口气，则他立下铁律：绝不允许任何一处与至亲相关的微末历史节点出现闪失。
- 若林恩在确认人类时期的历史彻底稳固后，顺着自己作为「渡鸦」时的灵魂因果线向一万年至十万年前的新世界早中期逆流，则他一步踏入了尘封万古的旧日秘史。
- 若林恩在降临一万至十万年前的远古时空时选择附身于一只正在飞行的活体渡鸦而非死尸，则他得以用渡鸦集群的天然视角亲历「第241世界大清洗」的血腥现场。
- 若林恩在焦土废墟上亲眼目睹一名紫罗兰帝国狱卒冷酷处决了该世界的半神国王，而满身鲜血的王后死死抱着幼子对天悲愤哭诉时，他附身的渡鸦之躯也不禁微微颤动。
- 若林恩仔细倾听那位王后的泣血控诉——得知她的丈夫明明只是为了保护子民免遭星际巨兽屠戮才晋升半神，却被自诩维护秩序的帝国使者当成罪犯抹杀——则他对新世界秩序异化的残酷性有了最直观的刺痛感。
- 若林恩在帝国狱卒冷漠宣称「半神即是原罪，我们是在庇护众生」时强行压住体内沸腾的黑火没有当场出手，则他避免了在数万年前的远古节点引发不可测的时空崩塌。
- 若林恩在承受“三林恩同处一世”的时空排斥时以秩序大梦内敛自身存在感，则时间长河对他的挤压感迅速消退，为他后续在远古时代长期潜伏积累了宝贵经验。
- 若林恩在救下八百五十一年前的血锯先祖后悄然在暗处护送其平安离开战区，则血锯老师一脉的家族传承稳如磐石，再无任何魇魔敢打这条血脉的主意。
- 若林恩在附身活体渡鸦俯瞰第241世界燃烧的城池时，让左左同步记录下帝国狱卒的行事准则，则两人对紫罗兰帝国在大清洗时期的僵化统治有了清醒认识。
- 若林恩在看到王后怀中幼子那双充满恐惧与仇恨的眼睛时保持了观察者的克制，则他深知要想真正拯救这片绝望的宇宙，必须找到导致这一切异化的源头而非仅救一人。
- 若林恩在跨越大清洗废墟上空时感应到四周还有无数双麻木冰冷的渡鸦眼睛在注视大地，则他敏锐意识到当时的渡鸦群体早已失去了灵魂温度，沦为机械的清道夫。
- 若林恩在经历左左短暂遗忘人偶母女的惊魂一刻后，主动用黑火在两人灵魂连接处刻下所有至亲的名字作为双重保险，则后续任何细微的因果波动都能被第一时间察觉。
- 若林恩在穿梭上千次小型魇魔袭击的拉锯战中做到零失误全歼来敌，则他在时间长河中筑起了一道坚不可摧的防线，令魇魔企图从近代史抄后路的图谋彻底落空。
- 若林恩在附身活体渡鸦时刻意收敛全部神王气息、仅保留一缕最纯粹的观察意识，则连近在咫尺的帝国狱卒也未能发现这只普通渡鸦体内藏着来自未来的神王。
- 若林恩在听到第241世界王后绝望的哭喊声回荡在天地间时，于心底默默记下了这笔旧账，则他对为何后来会爆发反抗帝国的战争生出了深切的共鸣。
- 若林恩在帝国狱卒处决完半神国王、押解着战利品准备返回地狱时悄然振翅跟上，则他顺理成章地穿过地狱之门，迎面撞上了震撼万古的「大坠落」现场。
