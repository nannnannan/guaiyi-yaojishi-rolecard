# E357·疫医军团湮灭与第二基地·if线

- 若林恩在出征前主动从系统空间召唤那具乌利尔遗体并先以黄沙密封裹一层，则他能在引爆时把无序溢出压到五分之三、自己会被震退但不会被波及皮肉。
- 若林恩决定不再用分身诱敌而是用本体吸引、巨像之脑带着遗体打副攻，则军团会首次感到目标本体靠近、堕天使那一头会立刻收到「对方在现身」的警报。
- 若林恩在分身爆炸瞬间主动让巨像之脑在最后关头把引爆点从围攻中心偏移三里，则能避开军团中某个本应死于爆炸的高阶疫医，那名疫医被活捉成为后续情报渠道。
- 若林恩在禁锢遗体时主动在做引爆准备的巨像之脑身上加注一层黄沙做防护网，则她能在引爆瞬间免受无序反噬、这一层防护在事后会被她反用成她对他的更深一道托付。
- 若林恩让左左在分身引爆前把它从内空间放出作为观察视网膜，则左左能首次亲眼目睹这种级别的无序爆发、她的咒纹会因为近距离灼伤而留下一道永久烙印。
- 若林恩主动从引爆碎片里回收一把还粘附着生物质残渣的疫医法器作为战利品，则他会带回一件本不属于他的疫医起源小证物、主母后续看到时会一眼认出这是她当年的旧物。
- 若林恩在战斗过程中把引爆目标扩大到军团全部而不仅是围攻圈，则整片血雾禁区会在六十秒内被无序夷平、第二基地的坐标会因此被强行暴露。
- 若林恩主动短暂停战让堕天使亲自从画面里看清他的脸，则画面里那副衔尾黑蛇会让堕天使第一次明白对付的是「那个人」、主母的人格在她体内同时被拉起一拍。
- 若林恩在对峙时主动说出自己与主母过去的名字暗号，则堕天使会在共体意识里首次直接听到这个名字、她会停滞一秒后缓缓开口说「你也在等她」。
- 若林恩选择不对峙、只是在第二基地周围布置多重隔离阵法后转身离开，则他不会进入战斗、但他对主母的救援会再延后一程，堕天使也不会因此从主动防御撤离。
- 若林恩在堕天使十二翼展开瞬间主动用灵能直接撞向她的核心，则她的身体会几乎对折、这一撞对共体的伤害同样会传导给主母，但主母的人格在这一次冲击里首次主动回应。
- 若林恩主动把巨像之脑请出来作为这场对峙的另一位同盟者，则对峙面会升级成三方对抗、战况的复杂程度翻倍，堕天使的战术选择会被同时压缩。
- 若林恩提出「交换主母离开，堕天使可以保留共同身躯一段时间」，则堕天使会首次在拒绝中迟疑一拍、这一拍被林恩捕捉到作为之后谈判的关键薄面。
- 若林恩用咒瞳直接凝视堕天使的眼睛，则他会看见她眼底另一双温润的眼、那是主母视野从她这一具身体首次透过来的瞬间。
- 若林恩主动朝堕天使投掷一支未经使用的引魂药剂，则她会在中针瞬间被两具灵魂的存在感反向淹没、共体状态首次出现可见的不稳定。
- 若林恩在军团全部撤离后只对观测小队动手，则他会得到一份极精的观测记录、上头清楚记录着主母与堕天使过去几周的相处状态和他们共同商议的下一步计划。
- 若林恩主动提出把她和肉身的鸠占者交换作为引信，则堕天使会当场用身躯内主母的意志做出回答、那是主母首次正面告诉林恩她自己的意愿。
- 若林恩在战斗中对她的黑羽主动以自身黄沙快速连烧十二根一旦击中不再燃烧的黑羽，则她会当场判断这是一场高风险突袭、在后续三次交手中保留更多选项不再全力。
- 若林恩趁着双方对战未分胜败时主动把对方某个引路者身份的疫医抓出来作为人质，则堕天使无法立刻妥协、但主母会在他们的暗中思维里首次直接开口警告他不要这么做。
- 若林恩主动提出让她自行离开不再追击，则堕天使会咬住下唇犹豫了一拍、那一拍被整队当作「敌对接纳了林恩的一部分意图」记入她之后的判断地图。
