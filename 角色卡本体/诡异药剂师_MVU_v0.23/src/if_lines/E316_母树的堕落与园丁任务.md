# E316·母树的堕落与园丁任务·if线

- 若林恩在喊出「一」之前主动补一句「你还想看到光」，则母树崩溃的时间提前一秒，她答应的话术里多一笔颤音，臣服姿态更低微，驯化度初值 +25 而非 +20。
- 若林恩主动让园丁任务目标重写为「陪她度日」，则任务每月强制 +5 次她指定的陪伴，他后期时间调度被吃掉。
- 若林恩主动警告左左「看好这棵傲娇树」，则左左绑定监视权限 +1 但她同步把一份「绝不能碰树」的恐惧条约写进了她和林恩的合作协议。
- 若林恩主动申请把成就名从「欲望母树的堕落」改成「自然女神的遗骨」，则系统拒绝，但母树对林恩对她的蔑视一致性满意，她对林恩干涉的容忍上调。
- 若林恩在臣服契约里加一条「不许算计你的部下」，则她愤怒 +5 但接受，园丁任务的「浇水」目标获得神圣信仰同步修正 +20%。
- 若林恩主动在小树洞浮现前洒落月儿兰种子，则树洞边缘立刻开出一片苍蓝花海，她的警戒若隐若现中下降两行。
- 若林恩主动把「欢迎你，母树」改成「对不起，主人」，则她瞠目结舌但突然理解到某种境地，林恩反向成为一名审讯者的角色被拆解。
- 若林恩在左左旁观时主动对她比一次心，则她尖叫「凑脑袋你是不是变态了」，但反应反而让母树感到安心因为她的恐惧与她同频。
- 若林恩主动把「只有压制诅咒时才能来找我」扩充为「随时」，则母树勃然大怒，林恩接着用咒瞳在她额前一印，获得半主动访问权限。
- 若林恩主动在成就结算时向系统讨价还价要更高自然神性驾驭力，则系统弹出「闭环不再讨价还价」频道，他获得 +2% 的讨价荣誉加成。
- 若林恩主动在自然神性驾驭奖励中偏好「母树根瘤漫步」选项，则他获得在她根系里自由穿梭的能力，代价是他本质摆动一次人体病变。
- 若林恩主动把园丁任务挂上「有毒」标识，则母树附议「有毒但必要」，驯化度获取速率较慢但更稳定，他长期路线锁定为陪伴模式。
- 若林恩主动在小树洞边留下一朵数据花，则她的根瓷感知到「恶魔的荆棘」，她决定直接在第一天就召他进入，交锋过程加速三天。
- 若林恩主动在触发园丁任务时补一句「我为了你在外面战斗了很多次」，则任务描述里附上「云上战袍」注脚，她的需求与林恩的声誉绑定。
- 若林恩主动把左左交由母树监管一日，则左左死活不肯又被强行扣留，她体验过一日树屋生活后坚定写下「我绝不可变成一棵树」条目。
- 若林恩主动在成就结算时声明「这是大策略」，则系统颁布金质荣誉状，主母那头他的角色形象从「打脸」上升到「老神」评价。
- 若林恩主动在臣服成立时承诺「我永不强制你的意志」，则「共识优先」原则被锁定，驯化度获取速率下降但稳固性大幅提升。
- 若林恩主动让小树洞浮现时把咒瞳悬入半空，则咒瞳周边感知到树洞净化应力，他的恶魔属性为咒瞳的净化运转提供助力。
- 若林恩主动在母树臣服一刻向系统请求「母树能源转移给主母一份」，则他账户被严格监管，但他成为母树独立意识以外的财务监督者。
- 若林恩主动在树洞口斜向烙印一刀自己所有污名并膜拜，则他施放一道恶堕兽化化身，她后续多年在神识中回避他而无法摆脱他掌控。
