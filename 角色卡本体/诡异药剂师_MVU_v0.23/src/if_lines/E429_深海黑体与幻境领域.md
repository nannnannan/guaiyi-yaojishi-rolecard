- 若林恩在蚀痕眼球反馈「冰冷气息」的一刹主动把它远程召回，则触手扑空扎入淤泥、黑体失去首件猎物样本，「海床即是巨兽」的证物反而被整只吸回来交给咒瞳比对。
- 若林恩让蚀痕眼球继续探查直至被吞，则它失联前最后三帧直接灌进他的私人文件，「黑体轮廓」首次以数据形式定格、却比任何口述印证更早。
- 若林恩看到眼球失联时主动用咒瞳现场回放画面给孽主与小丑同步，则两位同行者瞬间获得跟他一致的判断依据，「共享感知」首次在深海里成为主动选择。

- 若林恩在黑雾升起时让喵喵出海面变成浮空哨位，则她作为「与外界唯一的清醒眼睛」稳住方向感，「黑雾里的猫」首次成为团队的陆地雷达。

- 若林恩拒绝以初诞者之力冲击黑雾、让小丑用「无序压制」在前开路，则队伍踩着「无序对无序」的波纹通道突破一段、却同时把黑体的注意力推向小丑本人，「代我受敌」的责任首次由小丑一人扛。
- 若林恩让咒瞳以人偶形态出海面充当诱饵探黑雾边缘，则它在被触手扎穿后通风报废，「可牺牲的前哨」首次以无人伤亡的成本完成勘查。
- 若林恩在缺口中显露竖直海墙时主动让左左摸到那面水壁，则她指尖一按空气与海水在她掌下分离，「方向错觉」首次被一只人类手掌重新定位。
- 若林恩在黑雾中主动让孽主封她自己的血族感官、纯靠他的沙线定位，则她安静十秒得以从「被自然环境欺骗」转向「被人带路」，战力反而因「被领导」首次回稳。
- 若林恩拒绝以「局部屏障」苟住、把小丑的混乱乐律反向用作整体驱雾曲，则他首次把「小丑的咒」从处罚工具升级为防御兵器，他对「小丑的备份价值」的判断被这一条重新估量。
- 若林恩在黑雾中主动借咒瞳读出黑体的「吞噬记忆」，则它吞下那段历史画面以他自己身体为载体重播三秒，「读心术」首次由他的咒瞳把它自己的性质证明。
- 若林恩在黑雾中主动让喵喵化成湿衣哨位飘荡，则喵位落地湿光哨道在它身上一起，「猫在深海主题」首次被她自己主动承担。
- 若林恩在缺口闭合之际主动把左左留在缺口外作为接续的路标，则她「成为公道折口外的安全带」首次被她自己在她伸手握住林恩手腕的瞬间被她亲手实践。
