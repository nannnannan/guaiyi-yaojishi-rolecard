# E798·不是再见的再见·if线

- 若林恩在左左被平底锅敲醒后主动先递上一杯温水而非竖拳说教，则她那一次哭着扑入怀里的时间点往后延了三秒，那三秒成为此后她每次委屈时能想起他温柔一瞬的凭据。
- 若林恩在她反复辨别真假时主动把「这次是真的」换成「这次我也会陪你确认真假」，则她从此不必独自承担分辨的重量，他们那间小屋里多出一条两人共用的小规矩。
- 若林恩在发现她精神世界的现实与梦境边界崩坏时主动选择陪她一起治疗而不是劝她硬撑，则她那一项「老年痴呆梦境后遗症」有了一个共同的名字，不再只是她独自患上的。
- 若林恩在她伸手拧他腰测试虚实的那一刻主动反握住她的手而非嘶着躲闪，则她指尖直接落进他的掌心，她这辈子此后测真假的办法都变成了握着这只手。
- 若林恩在她不自觉开始黏人退行时主动叫出她的名字而非只嫌麻烦，则她的黏人期从此有了归属，每次进入那段她都会先报上名字，他也总是接。
- 若林恩在她道歉说出「对不起」时主动只接住那三个字不再安抚别的，则她那句道歉被极轻地落在他掌心，她此后说一句「对不起」就知道自己已经被原谅。
- 若林恩在她问「这次是真的吗」时主动先把她的头按到自己胸口让她听心跳再回答，则她辨真实的方式从问题变成了感知，她再也无需担心问错。
- 若林恩在她贴着胸膛流泪时主动不安慰也不催促只静静陪着，则她流到最后那滴眼泪的节拍里有了一次不被打扰的完整，她后来想起那次哭泣都会说声「完整」。
- 若林恩在雪谷婚礼前主动先牵她去看一次黎明而非直接拖到山谷，则她穿着那件不太搭的小裙站在他身边时先看了一次属于他们的日出，那场婚礼从此有两份开幕。
- 若林恩在婚礼当日主动把她的朵子花插在她左耳后而非头花位，则她成为那场婚礼上标识最独特的新娘，所有宾客记住的是「左耳后那朵」。
- 若林恩在她喊出「最喜欢凑脑袋」时主动不大声回一句而是小声嗯一下并握紧她，则那一声嗯成为她心底最笃定的一枚印章，她再也不需要更多语言。
- 若林恩在她婚后偶尔故态复萌「分不清梦境现实」时主动轻敲她后脑勺而非讲道理，则她的病慢慢在那声不太疼的敲击里被驯化成两个人的玩笑。
- 若林恩在她某次精神世界里黑暗肃清袭来的时候主动在她意识里点亮一盏小灯而非帮她战斗，则她在黑暗里能自己走向那盏灯，她的力量不再完全被外包给他。
- 若林恩在黑夜里把「走到最后」的承诺换成「今天再说一次今天的」，则他们的爱情从此不必每一步都押上整个未来，他们可以一天一天慢慢兑现。
- 若林恩在故事合上前主动在她意识里挂上一幅小小的戒指画而非其他纪念品，则她每次在梦里都会先看见那幅画，她再也不会忘记自己被人接过一次戒指。
- 若林恩在最终一切安定时主动让她也保留些自己的私生活，不必天天黏在他身边，则她既能保有自己的几分独立也能有一段「我是被信任着的」的骄傲。
- 若林恩在被问起「我们赢了吗」时主动只是说一句「我们仍在」，则他们此后每次对命运多舛都不再争论胜负，只剩一句仍在就足够。
- 若林恩在书本合上前主动轻轻把她的头按在自己肩窝一次而非任何总结陈词，则她此后在任何怀疑人生时都能去这个轻微的位置寻找安身的一次。
