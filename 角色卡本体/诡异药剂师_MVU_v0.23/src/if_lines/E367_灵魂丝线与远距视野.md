# E367·灵魂丝线与远距视野·if线

- 若巨像之脑在荒野血气暴动前主动站立城头投影远望，则她能提前一瞬预感到波动并减少一分羞耻，但也会因为站立过久双脚发酸。
- 若巨像之脑主动用巨像网络的过滤功能减少一半共感，则她能多保持一份镇定，但微妙欲望反噬也照样让她脚下软两秒。
- 若巨像之脑主动拿一条毛毯把自己裹住再听共鸣，则她多了几分安全感，但她耳根的红晕却蔓延到脖颈深处。
- 若艾雯在千钧一发之际主动轻推门缝递上一本古书代替入内，则巨像之脑能悄悄用毛毯压住自己不让书页慌动地落下。
- 若艾雯主动立定三秒后说「那我先离开，你不是一个人」，则她会用一口气憋着声音说出「谢谢」二字，随后整个人趴在床沿抽动。
- 若左左在荒野血气暴动前主动给巨像网络输入一段合理化的解释「这只是训练摩擦」，则巨像之脑能稍微冷静但仍被共感刺激得手脚发软。
- 若林恩主动让灵魂丝线的波动先以最低幅度回馈巨像网络，则巨像之脑可以提前一秒预备好镇定剂，但她自己的羞耻感仍不可避免地暴露一格。
- 若林恩主动让血气暴动通过巨像心脏的过滤机制减幅再泄出，则他能保护巨像之脑不被过度刺激，但他自身也因为压力堆积导致后遗症延迟出现。
- 若林恩主动在手握左左昏迷瞬间低低咬牙一声「对不起」，则巨像之脑能通过网络听到这一句话，她的羞耻感反向转化为一种酸涩的怜爱。
- 若林恩主动让左左的手指在他掌心画一个小圆圈，则巨像之脑能通过第一视角看到自己的心脏被左左缠了一圈小圆，涩涩度+1。
- 若林恩主动在灵魂丝线显现后立即如获至宝地握紧，则他能锁定黑弦月大致方位，但灵魂丝线也会在下一秒更加微弱地隐去。
- 若林恩主动用灵能反向追踪灵魂丝线的波动源头，则他能在巨像网络里定位到一丝黑弦月人偶化的家址信号，但因此暴露他的反向追踪能力。
- 若林恩主动握住左手掌心念黑弦月的名字一百遍，则他能在数分钟后得到一段微弱的「她的回应」但内容是噪声的。
- 若调查夜医主动在黑堡外围伪装成一名路过旅人，则他可以避开黑堡的初级防御，但内部警戒人员一旦识破他的伪装他就会被围攻。
- 若调查夜医主动用克苏鲁之眼的残念共鸣先绕黑堡十圈画个安全结界，则他获得一段安全的侦察时间但被黑堡女主人觉察到他在窥探。
- 若调查夜医主动以伪装身份与外围花卉结界展开交涉，则他可以从花卉中获取黑堡女主人在城堡内的健康参数，但需要答出黑堡的入门密码。
- 若巨像之脑主动让艾雯直接送到床边递上一小杯灵能饮料，则她能稍微镇定下来，但她也会因为接受援助而感到更为羞耻。
- 若巨像之脑主动在思维同步中用灵能将自己的手指蜷缩成拳，则她被迫承受欲望冲击时手掌不会被自己抓破但她会几乎憋出问题。
- 若林恩主动让左左在他耳边说一句「我会保护她」，则她能通过灵魂丝线反向听到这句话并把这一句话记为「大哥的承诺」。
- 若林恩主动在灵魂丝线再次显现后反向把血气暴动解压到左左本体层面，则左左能被这一动作激得苏醒一拍，但林恩的压力必须由他本人扛下余下部分。
- 若林恩主动用左左口中的一缕灵能碎屑在黑堡外围点燃一个记忆提醒，则黑堡外围的调查夜医能看清一朵微弱青色火焰作为重逢信号。
- 若林恩主动把灵魂丝线的波动先传给巨像网络再自我承受，则他能保护网络整体不被过载但自身被反射的双倍欲望冲击几乎崩溃。
- 若林恩主动让左左醒来后第一时间说一下「我没事」，则左左在意识空间怒瞪他一秒「你以为我稀罕你的担心」，板着脸把他的手拍开但涩涩度+2。
