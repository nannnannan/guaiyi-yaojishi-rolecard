# E788·最后的告别与过去杀招·if线

- 若林恩选择在冬泉谷多留片刻陪织梦看一场完整的暴风雪再动身，则两人在漫天风雪中并肩静立的画面会成为织梦此后漫长岁月里最珍贵的慰藉。
- 若林恩把偿还眼泪的誓言具象化为一枚凝结着黑火余温的冰晶挂坠放在织梦掌心，则织梦会将这枚挂坠贴身珍藏，直到在未来的黑夜城与他再度重逢。
- 若林恩主动叮嘱织梦留在冬泉谷安心休养、不要强行介入接下来的时间截杀，则织梦会在风雪中轻轻点头，将所有牵挂化作一句「那你一定要活着回来见我」。
- 若林恩在身体因时间悖论开始虚化消散时不慌不忙地饮下一支特制的灵魂锚定药剂，则他能在剧痛中保持绝对清醒，瞬间看穿第七十二柱黑衣人影在过去布下的杀招。
- 若林恩主动对着虚空冷笑一声点破第七十二柱黑衣人影「利用十万渡鸦降临制造同源悖论」的毒计，则潜伏在时间长河暗处的黑影会因计谋被看穿而骤然加快截杀节奏。
- 若林恩选择在撤离冬泉谷前将一道细微的梦境信标留在织梦的衣袖上，则他在后续生死关头偶有空闲时仍能感知到那一端安稳的呼吸。
- 若林恩放任左左在他身体虚化时死死抱住他的手臂不肯松开，则两人的黑火会在时空排斥中激发出耀眼的火花，坠入新世界伊始时的默契度反而提升一倍。
- 若林恩主动在告别时微笑着与织梦约定「等我们在黑夜城重逢时，我请你喝最好的甜酒」，则织梦会在泪光中展颜一笑，从此记住了黑夜城甜酒的味道。
- 若林恩在转身踏入时空裂缝前留下一封压在冬泉谷青石下的手写信，则织梦在风雪停歇后会把那封信反反复复读上百遍，连信纸折痕都小心翼翼地抚平。
- 若林恩主动把自己刚凝练完成的梦主印记在告别时点亮一瞬照映织梦的双眸，则织梦立刻明白了他的决绝与底牌，不再因担忧他孤军奋战而心神不宁。
- 若林恩选择把第七十二柱黑衣人影的悖论杀招毫无保留地告诉左左并一起商量对策，则左左会立刻拍着胸脯表示「不管是十万只乌鸦还是十万个脑袋，左左都帮你抓回来」。
- 若林恩放任左左在告别时向织梦挥手喊出一句「未来见啦！」，则织梦会温和地向左左点头致意，将左左彻底视为林恩不可分割的家人。
- 若林恩在离开冬泉谷时一步三回头、直到身影彻底被暴风雪与时空裂缝吞没，则织梦会一直站在雪地里目送他消失，眼角滑落的泪珠在雪中化作晶莹的冰花。
- 若林恩选择在告别时轻轻抱了抱织梦单薄的肩膀并替她拂去发间的积雪，则织梦会在他怀里僵硬一瞬后彻底放松下来，记住这个跨越了一千年的拥抱。
- 若林恩在察觉十万渡鸦已被送往过去后立刻以黑火封锁自身周边的时空坐标，则他能延缓悖论反噬蔓延到四肢的速度，为降临新世界伊始争取到宝贵的先手。
- 若林恩主动在脑海中将【黄金梦境】里十万渡鸦的气息全部梳理成网，则他在 E789 踏入古老时间线时便能像感应自己的手指一样精准定位每一只失散的渡鸦。
- 若林恩让梦主印记与左左的时间桥在跃迁瞬间合二为一，则两人化作一道连时间乱流都无法撕裂的黑色流星，直刺新世界开辟之初的战场。
- 若林恩主动把自己随身携带的一枚幽魂巷古铜怀表留给织梦作为信物，则织梦会听着怀表的滴答声度过漫长岁月，每一声滴答都是他们重逢的倒计时。
- 若林恩选择在身体消散的剧痛中放声大笑以震慑暗处的窥伺者，则他狂放的笑声会传遍整条时间长河，宣告这场时间战争的猎人与猎物即将易位。
- 若林恩在踏出冬泉谷的最后一刻回头对织梦比了一个「一切有我」的手势，则织梦会擦干眼泪握紧双拳，在属于她的时代里昂首迎接成神之路。
