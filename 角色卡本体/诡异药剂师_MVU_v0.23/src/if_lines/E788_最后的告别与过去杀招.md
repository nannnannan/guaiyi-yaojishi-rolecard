# E788·最后的告别与过去杀招·if线

- 若林恩选择在冬泉谷留下整夜而不是即刻告别，则他与织梦在雪夜并肩坐一宵,那段记忆替代了千年，成为织梦愿意等候的真正代价。
- 若林恩把眼泪的承诺物具象为一枚冰晶挂坠放在织梦掌心，则她在 E790 与未来关头会以那枚挂坠作为打开最终锁的钥匙。
- 若林恩主动要求织梦不要让步陪他同行，则织梦会在告别时转身离去不回头，但 E798 决战时她会从那方向走来。
- 若林恩放任身体消散过程而不立即吃理代护命药，则他得到一段「真正接近解体」的体验，空白实体无法复制这段体验因此无法预测他下一步。
- 若林恩主动朝空白实体宣布他的悖论计划已被识破，则空白实体会调整截杀逻辑——从「计算所有悖论」改为「只截断最脆弱一条」。
- 若林恩选择把时间桥交付织梦一段让她能偶尔探查主宇宙，则织梦会在 E789 截杀时空降救下一名重要 NPC，她的首次现世被记入史册。
- 若林恩放任左左在他消散时紧紧握住他的手而不放开，则两人会共同消散一部分，但他们在 E789 重组时默契度提升一倍。
- 若林恩主动在告别时说一个具体的重逢日期而不含糊，则织梦会按照日历等待，但实际重逢时间偏离，她必须学会接受「林恩不守时」。
- 若林恩让喵喵叼一封他给织梦的密信跳过告别直接送达，则织梦收到信时他已经离开，她把信读完三遍才意识到那是一封遗书。
- 若林恩主动把自己那缕炼成的梦主印记在告别时悄悄点亮，则织梦能在日后感知他受重伤,E789 截杀时她会因为感知到而提前出手。
- 若林恩选择把空白实体的悖论计划如实地字斟句酌地告诉织梦而不是轻描淡写，则她会因为知情而焦虑,E790 她会主动出谷干预。
- 若林恩放任左左在告别里代替他承担「一直跟着林恩」角色，则织梦会把左左视为「林恩的一部分」,左左从此成为她唯一信任的联系。
- 若林恩主动在离开冬泉谷时不回望不挥手，则织梦会因为他干脆而长久不解，E798 决战时她第一次见到他回头时她已白发一绺。
- 若林恩选择在告别中撕开自己胸口让织梦看到他的心脉仍在跳动，则织梦会把这一刻记住,E789 截杀时空白实体刺向同一位置她会用肩挡下。
- 若林恩放任悖论计划的一部分反噬他自己身体以换取织梦完全无忧，则他会因为她无忧而看起来更加完整,但空白实体已获得他的溃散数据。
- 若林恩主动把十万渡鸦的名字一一报给织梦作为告别的内容，则织梦必须记下全部名字,E789 截杀时她能叫出每个名字，那些渡鸦因此短暂抗拒截杀。
- 若林恩让梦主印记在告别时同时照亮织梦，则织梦会得到与林恩同等的印记，E790 她的印记与空白实体展开共振形成自杀式防御。
- 若林恩主动把自身一件最私人的物件留给织梦而不解释，则她会一直带着那物件,E798 决战时物件被摧毁，她才理解林恩早知道自己会死。
- 若林恩选择在告别前跟织梦打一架作为发泄，则两人的最后一面是喘息着坐在雪里，E789 截杀中空白实体无法理解这段看似敌对的关系。
- 若林恩放任悖论计划在告别当口突然启动一步以测试织梦归属，则她会用一次武力宣告归属,E790 空白实体会把她视为更高优先级目标。
