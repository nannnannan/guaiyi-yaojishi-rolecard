# E107·傀儡接管与双簧大戏诱敌·if线

- 若林恩只在一具死兆傀儡脑干刻下白痴印记先试手，则接管成立但范围限于单兵，后续只能点杀不能群体调遣，双簧大戏的「五大死兆围剿」缩水为单骑护送。
- 若林恩在刻印时让黑弦月改动一处纹路让符印可被她自己反向接管，则傀儡大军的最高钥匙落在黑弦月手里，林恩名义接管实则与她共治。
- 若林恩拒绝在脊椎节点刻第二个印信只管脑干，则315博士可以用利维坦神经从下游反向夺权，傀儡军团在戏演到一半随时反水。
- 若林恩把白痴印记的原稿复刻留在黑弦月手里存档，则符印不再是「只有他能画」的孤本，后续人偶庄园线会把它当作可传家学带走。
- 若林恩让喵喵代他站在容器前逐具辨认旧照片，则她崩到一半情绪被傀儡里那具「prototype 地狱行者」撞见后彻底晕厥，刻印接管在她昏迷期间由林恩独扛。
- 若林恩没有在工厂里替喵喵找到任何对得上照片的傀儡后决定继续往下排查本应封存的低级容器，则名单外的「526 号暗柜」被挖出，里面封着一具从未登记的疫医秘密作品。
- 若林恩在试做型地狱行者面前停下多看三分钟仔细观察缝合纹路，则他会认出这具母型的手法与 Z_Y 血娃娃改造笔记里某一页笔迹一致，从而把疫医与自己早年奇遇挂上钩。
- 若爱丽丝披血镰折跃救场时刻意让面纱被划开一角露出半张脸，则银色幻想会立即识破她不是林恩本人，双簧当场穿帮，演俘变为真打成逃。
- 若林恩透过爱丽丝的嗓子对银色幻想多解释一句「你看到的视界是被剪过的片段」，则逻辑链会出现一处可被银色幻想反向质问的破绽，她会在戴枷时仍保留戒心不肯真正合作。
- 若银色幻想在被打断节奏前就识破以M气雾的走向并侧移半步，则她不会被畸变体拍进地里，演俘剧本打空，林恩必须当场决定是否硬擒。
- 若林恩在「围剿」时刻意让一具死兆傀儡扑空一头撞碎回廊的承重柱，则戏看着惊险至极但子舰外壁被震出裂缝，利维坦全舰警戒提前两小时拉响。
- 若林恩让爱丽丝在演戏时不斩任何一具傀儡只闪避，则画面会显得诡异不合常理，银色幻想会反推「这些傀儡在配合她」，双簧被看穿一层主体成立。
- 若骨链与枷锁扣上银色幻想的瞬间林恩改成捏着她的下巴而非耳边嘲讽，则那句「该有脑子了」被替换成肢体羞辱，入主控室后她对林恩的怒意会盖过对博士的恨意。
- 若林恩让爱丽丝演戏时插入一段她自己记忆中的片段（比如旧年师门承袭）冒充夜医话术，则假林恩人设会被这层陌生记忆撑起一站，但爱丽丝演技走位的私人痕迹也被她自己泄露。
- 若双簧大戏进入押送阶段时林恩以执事身份向第一腔室发送的捷报里没有任何暗号，则捷报纯走官文格式，315博士会在收到时多派一队仪仗验证真伪，入核心的队伍被分割两段。
- 若林恩在发送捷报时夹带了一条只有他与银色幻想先前秘密对过的暗号，则她会在押送途中从傀儡的队形里自己读出「马上动手」的讯号，第一腔室开门的瞬间她已不是俘虏而是同盟。
- 若林恩让傀儡军团在押送路上故意掉队几具领主级，则这些「掉队者」会被他标记为后方预备队，第一腔室动手时外圈多一层生力军，可被用作包围圈或逃脱通道二选一。
- 若接管完成后林恩让五具死兆傀儡额上符印同时进行微弱闪烁的「心跳同步」，则整个傀儡军团在双簧过程中会以一拍节奏整齐动作，画面震撼但极易让博士的术式感知锁定异常波段。
- 若林恩在接管中保留一两具傀儡的「野生意识」不刻印作为观测员，则它们会在双簧大戏里把所见一切反向汇报给利维坦本体，第一腔室开门时315博士会提前三分钟已经在等他。
- 若接管后林恩对傀儡军团下达「我死则你们全灭」的陪葬死令，则军团的存续与他个人绑定，第一腔室若他重伤倒地，五具死兆会立刻执行内战式自爆，鱼死网破。
- 若接管后林恩命令包括地狱行者在内的所有高阶傀儡对外只露出领主位阶的力量压级，则博士的哨兵系统不会把这支押送队伍识别为顶级威胁，入核心的窗口会宽很多。
- 若林恩在双簧演戏间隙透过骨链向爱丽丝追问「你真愿意戴这个枷？」，则爱丽丝会回以一段她从未对人说过的奉献自白，把这次押送从战术工具升格为羁绊节点。
- 若接管完成后林恩顺手封掉工厂全部容器阀并断掉液态培养液供给，则未被接管的一批低级傀儡会在数小时内自然坏死，利维坦后方备用兵源被他一锅端，但当晚疫医总管会察觉异常汇报博士。
- 若林恩只接管超凡级以上、放任低级傀儡原班运转，则工厂日常流水线不中断，疫医系统短期内不会发现异样，但潜入期一旦拖长，他失去对底层的掌控容易被反包围。
