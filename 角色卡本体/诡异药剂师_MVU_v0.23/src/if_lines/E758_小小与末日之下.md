# E758·小小与末日之下·if线

- 若林恩在冲入黑夜城前让王座黑火先焚烧自己脚下那一段路的黑潮，则他抵达王庭原址时衣摆仍带火，但路上多救下一名躲着的伤兵。
- 若林恩在深渊边缘跪下时主动把脸贴进风里，让风吹干眼泪，则他在小小出现的瞬间能以一个尽可能平静的微笑回头，不让她看到一张泪脸。
- 若林恩在抱住小小时让自己的黑火主动降到几乎熄灭，则她皮肤上的狰狞轨迹不会因为他而加速逸散，能够多留一秒在他臂弯。
- 若林恩在小小说「爸爸妈妈找不到」时替她答一句「他们躲起来了，哥哥带你找」，则她最后的表情从迷惑转为放心，但林恩要用一生去圆这个谎。
- 若林恩选择不立刻检查她体内法则崩坏，而是先用力抱住她，则她在被诊断出真相之前多感受到三秒力气，那三秒塑造了她最后表情的底色。
- 若林恩在她讲艾维儿的事时先打断，跟她说其他的，则她免去一次被回忆戳痛的颤抖，但林恩从此不知道艾维儿最后一刻的具体方位。
- 若林恩在召唤三叉戟无果后没立刻改用黑火，而是改用声音轻声唱一首旧童谣，则小小在金发被风带走前听到的是歌而不是黑火的嘶嘶声。
- 若林恩在她伸出小手时主动迎上脸颊而不是任她触空，则她在消失的前一瞬碰到了他，那一触可以被他用记忆压在骨头上。
- 若林恩在她化烟的瞬间让自己的王座黑火锁死她留下的金发一缕，则那一缕金发被他带进 E759，作为黑火之外唯一能让他短暂落回人性的物件。
- 若林恩在小小消散后立刻长啸一声并把自己王座推入黑火狂燃模式，则扑来的魇魔阵形被正面打崩，但他跳过了 E758 的哀悼静默，直接进入清算状态。
- 若林恩在消散那一秒反而静止不动，让自己的灰发被她化作的烟尘染到肩，则他进入 E759 时眼中不再全是火，仍带一点点孩子的金。
- 若林恩主动把她小手最后停在自己掌心的温度写在王座后页，则他在未来无数次怀疑自己动机时能翻出来一次提醒自己：这个温度真实存在过。
- 若林恩在小小告诉他「艾维儿姐姐好像也回不来了」时没让她说完就摇头，则她在闭眼之前不必再讲那一句话，但她的真相从此无人听完。
- 若林恩在长啸之后仍然不肯松开双手，任那群魇魔围上来的同时也在他周身烧出火墙，则他进入 E759 时的姿态从被动清算者转为主动告别人。
- 若林恩在抱着小小时让她听见自己的心跳，则她最后说出的那一句「哥哥一定会回来的」是按他心跳的节拍挤出来的，多一分属于活人的语气。
- 若林恩在抱她时让黑火贴着她后背烧掉体表的无序痕迹，则她在化作烟尘之前皮肤恢复一度光滑，他掌心收到的最后触感不再全是裂纹。
- 若林恩在她提到艾维儿时同步让王座把那一事实记下，则他对艾维儿的悼念不会延后，但此刻的小小察觉到他的失神，最后一句话被打断。
- 若林恩选择告诉她真相「哥哥已经救不了你了」，则她最后在怀中的表情从依赖转为理解，但林恩要承受的是自己亲口承认的无能。
- 若林恩让她讲完所有想说的话再闭眼，则她在消散前多讲了四秒关于她和爸爸妈妈的旧事，那四秒成为林恩未来最珍贵的私人档案。
- 若林恩在小小消散后没立刻转头看围攻而来的魇魔，而是先向她金发消失的方向轻轻鞠了一躬，则那群魇魔不敢第一时间扑上来，多出一段诡异静默。
- 若林恩被动地接受小小触碰而不是主动迎面，让她的手在他颊边消散，则他在 E759 的黑火清算中不再找「合理的理由」，直接进入无差别焚烧。
- 若林恩在她化为烟的前一瞬闷声让她听见一句「小小，对不起」，则她在最后一刻并非全然安乐，但在他心中种下了非复仇性的、更纯粹的承担。
- 若林恩在收下她最后那一缕金发时用唇轻触一下，则金发上从此残留他黑火的一点温度，不会被岁月彻底磨平。
- 若林恩在她即将消散时用尽力气把她比作一缕烟再往自己心口按了一次，则他日后在崩解边缘时会被胸前这一压拉回一次。
