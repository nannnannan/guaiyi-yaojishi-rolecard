# E11·血夜地狱行者与左左诞生·if线

- 若林恩把血字【危险！离开！马上！】抄在账本上并标注笔画、墨性与咒术残温，则老师独门咒术比对样本多一页，E20 师徒归来时血锯认出笔记可追问血字发出端的代价。
- 若林恩按药剂碎裂声逐笔记数（100→500→821币），则系统追加「今夜损失」账目，地狱行者被消灭后赔付议价以这笔骷髅币为锚，魔人协会债单独立成档。
- 若林恩在清除血衣左轮诅咒前先朝游魂巷44号放一响空枪作信标，则血衣辨识方位的延迟缩短数息，地狱行者对第二目标的同步分析起点同步前移。
- 若林恩被倒刺恶灵之手穿胸后仍攥紧剔骨刀顺刀刃拖向对方腕脉，则恶灵之手抽离时自带一道豁口，地狱行者把「刃具威胁」计入下一次形态调整。
- 若林恩在灌第一瓶血肉增生药剂前先把柜台剩余药粉倒进血妖斗篷内衬，则变异生效瞬间斗篷浮起药理膜，第二瓶灌下时竖眼位置由后颈偏移至肩胛。
- 若林恩逃向店外时按下炼药室火源让药剂架先烧起来再撤，则地狱行者沿途多吞一批活性药液，「适应性解析」队列被稀释一次。
- 若林恩第三瓶下肚后顶着脑蛇嗜血冲动先把无面魔心脏贴上胸口，则心脏吸血提早两息开始，脑蛇与心脏的互咬提前成型，地狱行者「最高优先吞噬」延后一拍发出。
- 若林恩把无面魔心脏留在店内作诱饵，则地狱行者抵达后先对店内下达一次「全面吞噬」测试，心脏把它的躯体钉在原地约 20 秒，林恩获得拖回血衣的额外空档但失去心脏反噬这张底牌。
- 若林恩撞见血衣时先把【无面魔心脏】抛给她看一眼再开口，则对话跳过舔脚尖戏谑直接进入战备，好感结算仍按「硬气」路径，萌娃的欧拉声被打断。
- 若林恩在血衣「跪下舔脚尖」戏谑中单膝触地但偏头不认输，则血衣笑意由戏谑转为打量，触手卷住地狱行者的力度更凶一档。
- 若林恩在血衣被吞时先动一根【怨灵发丝】缠她未被吞的小腿而不是披斗篷直接钻入茧囊，则 54% 节点留出一条缓拖通道，血衣获救时损耗按低一档清算。
- 若林恩冲后院前对地窖先抛出含月份、品质、违约条款的正式交易话术再揭门，则「三个月高品质药剂」口头约束被记入后续喂养账目，E12 收尾结算有账可查。
- 若林恩让大舌头绕开正面战场从游魂巷屋檐切入，则地狱行者「巨像缺失组织」识别延迟一次，粘液腐蚀仍生效，血衣被剥离出茧囊的角度更斜、后续缝合难度上升。
- 若林恩利用「品质低下·不建议吞噬」首判静默期，在魂灯熄灭前把几样非卖道具转移进血妖斗篷口袋，则 E12 灾变期开局多一两件可动用道具，「最高优先」重判的触发点改写。
- 若林恩被巨眼凝视、面容溶解时立刻用左手变异体遮住左眼瞳孔，则左左前身诞生时的第一层神经记忆是「替主体挡一道目光诅咒」，她对林恩的初始动作带一层未经宣告的先入姿态。
- 若脑蛇从眼眶挤出时林恩立刻用左手按住蛇颈试图勒住嗜血冲动，则左左前身的第一缕神经冲动混着脑蛇嘶鸣一起震荡，左手事后持续一阵不规律的收缩颤抖，「控制率 31%」读数短时下探。
- 若林恩在地狱行者「品质低下」判定响起时仍把胸口往触手上再送一寸再开火，则「误吞一次」记入它的内核错误日志，后续一次目标切换空档延长半息。
- 若林恩在血衣狂乱形态时低声报出弹孔中看到的六颗眼球排列，则血衣至少一次精准打断它的「目光诅咒」锁定，林恩被目光再度扫到的次数减少一次。
- 若林恩对血衣提出「先救我店再谈价格」反报价并附免单月份表，则血衣不出「跪下」话术直接开价，但附加一项「战后替她做一次贴身诅咒排查」的私人条件，亲密度伏笔。
- 若林恩抱起小宝贝的舌头冲回战场时不直奔血衣正面、改从巷子侧面阴影里贴近，则地狱行者的同步分析短暂丢失他的坐标，血衣被吞噬的百分比停在更低刻度，后续从茧囊拖出的角度更顺。
- 若林恩在小宝贝出发前追加一剂【血肉增生药剂】抹在它舌面，则小宝贝冲刺途中沿途腐蚀一段地狱行者的外层外壳，林恩回场时面对的吞噬进展比原案慢一拍。
- 若林恩在被吞前把两瓶血肉增生药剂分作两次捏碎而留一瓶进血妖斗篷暗袋，则变异层级峰值被压一档、理智残余多一截，E12 灾变期初始意识清晰度上抬。
