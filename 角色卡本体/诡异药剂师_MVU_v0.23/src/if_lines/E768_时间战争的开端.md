# E768·时间战争的开端·if线

- 若林恩在左左辨认时间裂口时先让她从左手的冰晶冻痕里感知，则裂口在她这边的位置更精准，连接层的偏差降到原数的三分之一。
- 若林恩主动进入时间长河前把「林恩要进入过去」这一意图刻到王座脚下，则时间战争火焰起时有过去位面更精准地回应他。
- 若林恩在身体跨越时间长河时让黑火故意烧掉外姓名，则他进入历史时被记录为「无名渡鸦」，不会被旧朝廷认出。
- 若林恩把当前所有黑火存三分之一进入系统空间，则他在过去必须依靠失效的有限罪火，但当前时间框架不会再崩。
- 若林恩在长河水面擦拭一眼城创伤场景，则他裹着左左左手时两人口径上多一层悲恋交织的记忆釉。
- 若林恩主动让左左在时间长河中在他左手上画一只无意义的笑面，则他在过去被捉摸时仍然有稳定的信号锚。
- 若林恩让城墙被前后两幅影像同时显现进行修改，则他亲眼看见自己的一步在历史裂缝里被踢向另一侧。
- 若林恩在时间长河某个端口主动终止声音，则他能听到渡鸦另一侧传来的极弱鸟语，固守「旧朝廷替他们说话」的感应。
- 若林恩主动把时空法则集中在左手之外的其他指尖，则时间桥承负荷量上限 +1，但黑夜城记忆层的干扰会令自己惴惴不安。
- 若林恩在历史节点被噩梦辨认出时主动说出自己的重生场所，则噩梦线路暂时回护他，但更深的一段空白实体被引入现实。
- 若林恩在黑火无法全面带往过去时主动保留一份梦境手柄，则他在过去临时用「旧林恩的姿势」避开一场真实死亡。
- 若林恩主动叩击时间长河外壁的三次以让左左接记宿，则历史某一节点会替他说一句「他将来」。
- 若林恩在第一个噩梦节点提出命运选择时主动摆出拒绝参与的态度，则历史居民被召评议，结果他的路径只会变得更鲜明。
- 若林恩主动让过去位面某个人物认出自己的面孔，则对方会以为他是古神，祭出一份数十年的证词增加时间桥广度。
- 若林恩主动在时间长河面上烙一枚罪火印，则那个位置一旦进入模糊推演会朝他这边回弹，他被认为袭拢了历史控制权。
- 若林恩在历史节点任「平凡过去」被另一个人代他重演，则那一部分过去不会成为历史陷阱的责任。
- 若林恩主动在现在地设一座供奉「时间战争」的青钢柱，则过去某个宿命的噩梦第一次正对林恩。
- 若林恩主动让左左在时间长河对渡鸦气体的位置设立一个触点，则后续每次探恒走无者的渡鸦都会用左手触觉回归。
- 若林恩主动拒斥「以有限寿命交换不同命运」的全部交易，则节点上渡鸦纯粹的过去不会参与这些交叉。
- 若林恩在历史回桃中主动告诉渡鸦「你不必是我」，则渡鸦的自由度 +1，但他自己的五百年缘分被袭掉一角。
- 若林恩主动让梦境外的另一个自己在历史浮出，则他会下意识与「另一个林恩」保持一脚距离，但空白实体背后出现一种新的样貌。
- 若林恩主动把全势收回，让过去位面的未知免冠能插到时间长河外，则历史运往他手上拽一项更重的责任。
