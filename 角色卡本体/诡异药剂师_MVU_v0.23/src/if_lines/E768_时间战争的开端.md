# E768·时间战争的开端·if线

- 若林恩为防自己在静坐感悟梦境时被左左突然一记头槌撞出内伤，特意与左左约法三章、在修炼时于头顶挂上【修炼中，非emo】的木牌，则左左每次看到木牌都会骂骂咧咧地收回准备偷袭的拳头。
- 若林恩在城外墓碑前伫立缅怀故人时，任由左左悄悄在旁边立起一块【emo中，非修炼】的木牌并陪他一起发呆，则那份悲伤不再是独自吞咽的毒药，而成了两人分担的思念。
- 若林恩在左左吵闹而温暖的陪伴下潜心推进梦境转化，直至终焉黑火顺利扩展到将近金色梦境一半的规模，则他的力量已逼近令终焉魇魔坐立难安的临界点。
- 若林恩在某一日突然目睹黑夜城的景象如水中幻影般模糊重叠，昔日熙攘繁华的街道以及主母、智械小姐（银色幻想）、艾雯爵士等早已逝去的身影竟在流光中重现，则他瞬间警觉这绝非正常重逢！
- 若林恩在自身与左左的脑海中同时涌现出大量不属于他们的虚假经历与记忆时当机立断以黑火镇守灵台，则他一针见血地看穿真相：终焉魇魔因惧怕他彻底拥抱黑火本质，已正式向他的过去挥刀，「时间战争」全面爆发！
- 若林恩当即悬起那枚带有裂纹的时间神格，带着左左将意志化作穿越时光的渡鸦逆流时间长河而上，精准锁定过去自己即将登临罪恶王座前的时间节点，则他第一时间赶往最致命的历史靶心。
- 若林恩的跨时空意志引动地狱中心大山底下（昔日狱卒大本营）一座古老棺椁轰然开启，借由未来画家早年预留的一具腐烂渡鸦遗体振翅化作白发林恩的人身，则他成功在不引发本体时空崩溃的前提下完成了跨时代降临。
- 若林恩在借壳化形后感应到时间流的剧烈异动、一念跨越空间降临至神界圣堂大门前，看清门内正是过去那个正在登临罪恶王座切割信仰的自己、门外则是从紫黑色时间裂隙中攀爬而出的魇魔大军，则他周身迸发的神王威压瞬间将整座圣堂的时间彻底冻结！
- 若林恩在挂着【修炼中，非emo】木牌苦修的日子里提前将左左的灵魂与自身时间神格深度绑定，则当虚假记忆入侵黑夜城时，左左也能在第一时间随他清醒过来。
- 若林恩在看到黑夜城幻影中主母与艾雯爵士向他微笑招手时没有丝毫贪恋，而是冷酷指出「她们是我的家人，绝不是魇魔用来篡改因果的傀儡」，则虚假幻象当场在他面前寸寸碎裂。
- 若林恩在逆流时间长河途中仔细观察河水中翻涌的黑色漩涡，则他发现魇魔大军正试图从他登临王座这一最关键的转折点入手，企图将他斩杀在成道之前。
- 若林恩在从地狱中心大山底下的古老棺椁中破棺而出时，留意到棺椁内壁残留着未来画家布下的隐匿禁制，则他明白未来画家早在无数年前就已算到他今日会借渡鸦遗体归来参战。
- 若林恩在降临圣堂大门前的瞬间特意将时间冻结范围控制在圣堂内部，则门内正在艰难切割信仰的过去自己与自缚天使丝毫未察觉门外已有灭世大敌降临。
- 若林恩让左左在自己左手掌心蓄满随时可以拔剑的灭世黑火，则一人一剑横立于圣堂大门之前，宛如一道不可逾越的叹息之墙挡住了千军万马。
- 若林恩在冻结圣堂时间后冷眼扫视门外那道不断扩大的紫黑色时间裂隙，则刚从裂隙中探出头来的数只先锋梦魇当场被他的目光震成齑粉。
- 若林恩在把【修炼中，非emo】的木牌随手收进系统空间带往过去战场时，左左还在意识里吐槽「待会儿打架别把牌子挂出来丢人」，令大战前的紧张气氛瞬间一松。
- 若林恩在体会到“借用死去渡鸦遗体降临过去会令初诞者之力受限、但自身梦境与黑火依然无敌”的规则后，迅速调整好战斗重心。
- 若林恩在圣堂门外听见一墙之隔传来过去自己压抑的喘息声，眼神愈发冷冽，立誓绝不让任何一只魇魔踏进这扇大门半步。
- 若林恩在紫黑色时间裂隙深处浮现出魇王庞大的威压与投影时按剑不动，则他以绝对的强者姿态静候对方亮出底牌。
- 若林恩在时间战争的第一处主战场——圣堂大门外——站稳脚跟，则他与时间终末群魔横跨万古的正面交锋正式拉开帷幕。
