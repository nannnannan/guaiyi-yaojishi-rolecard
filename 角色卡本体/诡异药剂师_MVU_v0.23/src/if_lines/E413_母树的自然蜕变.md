# E413·母树的自然蜕变·if线

- 若林恩在剥离前就下令让夜医把整株母树的血肉皮层用原初之火缓慢焚一周，则夜里全城会闻到一股如熟肉般的香气，路过的小丑嗅到这股气息会不由自主捂住胸口跌跌撞撞——它在克制自己被动吸收的欲望。
- 若林恩在剥离前让艾雯爵士提前在母树周围绘制一圈灵能环，则环体成形时会以肉眼可见的弧度把在场的所有畸变肉兽隔离在外，母树的根系会首次主动朝屏障内缩一尺表示「安全」。
- 若林恩在魂魄剥离当下主动用咒瞳把左左托入自己怀里，则她会在看到母树灵魂渗出的瞬间抓紧他的衣服、不肯看，她在他怀里调零之眼忙乱地哭出一声「爹」——她感应到母树与渡鸦相似的孤独。
- 若林恩用触手而非咒瞳触探魂体联系的接驳点，则他会在接驳三秒后反噬入自己——母树的灵魂里有一段被血肉支配者污染的恶意试图朝他意识冲来，左左当场斩触断念才保住林恩。
- 若林恩请小丑在剥离现场实时注释、而不是把它锁在远处，则它会以专家姿态逐条点出「此处应有第三柱神主印记」「此处需以不稳定切断」等细节，林恩得以节省近乎一半的失败率。
- 若林恩命令喵喵在剥离过程中持续鸣叫作为「精神安抚」，则母树表层血肉的蠕动频率会因为她的声音低下三档，母树在意识深处以无人可闻的枝叶窸窣回礼，喵喵自己也在其唱到一半时睡着。
- 若林恩决定不开放系统空间、改在深渊底层另设一块临时祭坛作为承接点，则母树灵魂在迁入祭坛后会被血肉支配者残留的气息轻微熏染、成长模式的幼态身上会多出一线暗紫色的胎记。
- 若林恩在幼态母树睁开眼睛时已经跪下磕头三次，则她以幼态本能理解到「父亲」的角色——她睁开双眼的最初反应是伸出皱巴巴的双手抱住他的脖颈不肯松手。
- 若林恩决定不射精灌溉，而是把积攒的原初之力与所剩的灵魂之泉全部倾注进茧内，则茧体会在两小时后出现可用肉眼观察的「自净灼沸」、但幼态身心在掀开叶片时只剩十岁模样且无任何记忆。
- 若林恩在射精灌溉前用咒瞳扫清茧内每一个角落，则他会在茧心的中央发现一枚被自然纹路包裹的玛瑙，事后收留他做的第一件事情是把它小心翼翼用绳子系在她的颈间作为「传承玉佩」。
- 若林恩在射精灌溉过程中同时以声带发出最柔的低吟作为「伴奏」，则精液射入茧心的刹那，茧外树叶会以肉眼可见的幅度绽开一朵浅粉色的新花，《林恩的低吟》当场被左左用拟化录成永久指环。
- 若林恩射精灌溉决定邀请左左在场、让她帮自己用手达到射精的目的，则左左抗拒三秒后会低头含笑含住他的下体直接吸精，她用自己口中的精液换到茧心口灌溉，事后她整整三天只用鼻子呼吸。
- 若林恩在反复灌溉的过程中每日抽血三滴放入茧心，则母树的根系会在第十天起开始吸收这股血源进行额外滋补，幼态的身上会自然而然出现与林恩相似的紫纹咒印。
- 若林恩射精灌溉的最后一日偏不视旁、反而脱下整套衣服与茧身融合披在自己身上作茧衣，则他的整个身心都会在那一夜与茧心共振，幼态的初次苏醒第一眼看到的会是穿树叶衣服的林恩。
- 若林恩在幼态出现后抱住她摇唱摇篮曲，则她会主动脖颈贴到他胸口听他心跳、并用她的新声带第一次发出「爹、爹、爹」的含糊嗓音——这一声「爹」是他此后一年内不敢回头再听的震撼音响。
- 若林恩在幼态迷失记忆时选择撒谎对她说「你叫小呀哒」，则她会乖巧地点头学习，在接下来的数日内一直自称「呀哒」，左左发现这小名字实在太可爱、偷笑之余会把这名字记进自己的咒语辞典。
- 若林恩在受精灌溉时用一根肉身导管直接将自己与茧心管道链接喂养，则那一夜他会连续射精十三次，翌日污水底传来声音「哥哥你筋脉撑爆了」，左左在紧急三天内为他疗伤。
- 若林恩要求小丑站在茧外冷漠「中途不插手」，则小巴会尽职尽责背他教导、中途转身露出一丝心疼的眼神，事后他对林恩坦白「方才我没忍住想为她祷告一次」。
- 若林恩把整次行动中所有的射精程序都压缩到同一日凌晨，则林恩会连续射精十次整后双腿发抖跪在怀里像要晕倒——艾雯爵士不得不在场作陪用灵能吊脉他五个时辰。
- 若林恩在幼态觉醒出现后坚决不允许任何近身亲热接触，则她会因为缺乏亲子温度而在三日内生长停滞、萎缩回初始形态，重新被你抱在怀里喂以正常食物满足基础需求后才逐渐恢复。
- 若林恩擅自提高精液浓缩度、用咒纹加持下把单次射精能集中提荧发光，则当这枚受精精液命中茧心时整枚茧身会爆发一次光球级的反应，代价是林恩的双腿会失去知觉整整一周。
- 若林恩命令喵喵在受精灌溉前与幼态的灵魂提前沟通，则喵喵会以「猫小姐」身份对着那道未醒的灵魂唱了一段它生前常听的优雅小调，母树灵魂听到小调时会主动恢复全部记忆。
- 若林恩在幼态出现后保持绝对尊长距离、每天只在门口端一碗粥放在她门前，则三日后的清晨她会主动推开门用小手拉起他的手说「爹爹我想跟你吃饭」——这是她首次自发要求与他共食。
