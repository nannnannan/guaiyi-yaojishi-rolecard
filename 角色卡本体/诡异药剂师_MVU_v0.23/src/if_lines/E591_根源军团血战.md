# E591·根源军团血战·if线

- 若林恩在会战开局主动下场亲自斩第一刀，则「练兵场」气场整体崩解，古神们会改成跟他脚步冲杀，伤亡率短期上浮。
- 若林恩在战前给所有古神每人额外发一枚初诞者金光护符，则双星死光出现时印记抽离的窗口更宽，零伤亡纪录被改写成更耀眼的全额无伤。
- 若林恩在印记植入时公开声明「不准私藏一个反序阵」，则空间组根源们也不敢偷塞彩蛋，死光反伤一战不会出奇迹但会更稳。
- 若林恩允诺战后把拆下来的星体作为战利品开放征用，则银色幻想与泰坦头颅会更主动去抢第一颗星，恶幻人头变成争夺赛。
- 若林恩选择让艾雯与巨像合流同一组，则两尊巨大神灵并立的形象会让敌阵中位数以下的大魔直接腿软崩溃。
- 若林恩在会战前单独叮嘱泰坦「撞星之前告诉我」，则泰坦会先吼一声「贤婿看好了」才扑向另一颗星，巫神头颅在同频道回响一片嘲讽。
- 若林恩在会战半途喝止群水的手段不是「扣发神性结晶」而是「一句媳妇生气」，则所有听到太太名字的根源会齐齐闭嘴，战场群寂一声更滑稽。
- 若林恩留下石祖不让她挑战泰坦，则她会抗议着爬到巨像肩头当观察哨，事后她会把这一役吹成「鸽子蛋逆袭计」。
- 若林恩在会战前主动给左左一个站位让她真正能打，则她会真的拎刀上阵，缠斗中她的幼态杀伤力第一次被污染者真正领教。
- 若林恩下令「半小时之内解决」，则全员战意会被这一句压到紧绷，推进速度更快但排练精度下落一线。
- 若林恩没有提「快速解决」，则半小时死线不立，战后统计拖长到一小时，污染者有更多的撤退窗口。
- 若林恩在会战结束后率先登陆而非坐镇城楼，则他会在深渊大陆第一步踏入的瞬间被时光碎片划一下手臂，留下一道「下第一人」的记忆痕迹。
- 若林恩选择向敌阵投下一道讽刺广播「你们的天父不会来」，则对面大魔会发生阵内动摇，但也会引来双星提前开炮。
- 若林恩主动检查银色幻想的拆星作果实，则他会在银潮轨迹中读出一道「处理器升级到位」的回响，E598 银幻改造尾声省去一道自检。
- 若林恩对这场会战公开定义「为下一场血战铺路」，则古神们的心会更沉静，E593 走廊初探的严阵气息被提前预热。
- 若林恩选择不让左左出现在会战全图，则她会在第四个位面某大陆另一个小剧场独自打一场遭遇战，事后她自述得到了一段「蹲一件木舰舱和黑酱」的小故事。
