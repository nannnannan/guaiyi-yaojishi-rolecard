# E02·血娃娃上门与找妈妈任务·if线

- 若林恩隔着门只答问诊不请进门，则血娃娃抱着洋娃娃坐在门槛外台阶上，由洋娃娃代述症状与断臂经过，魂灯持续压制她的血肉波动直至她主动离开或林恩放行。
- 若林恩先查魂灯火焰再开口，则系统把血娃娃的等级、种族、混乱中立属性与"可以稍微招惹它"的战斗能力逐项列出，进店与否留作林恩下一轮动作。
- 若林恩只缝洋娃娃手臂不开胃，则收费降档为缝纫30币加药剂，断臂创口内残留的她自己的咬痕未清，血娃娃以完好纱布裹娃离开，胃里的女性器官沉入黑暗。
- 若林恩选了开刀手术路线，则血娃娃被推进里屋，肚皮切口取出洋娃娃断臂后缝合，术后畏惧度+40、"黑店"口碑在游魂巷传开得更快，收费追加开刀费。
- 若血娃娃坚持要啪一次抵账，则林恩把"小本生意，概不肉偿"的店规写在账本上递回去，她的欠款栏继续滚利息，右眼抵押仍是默认等价物。
- 若林恩只收30骷髅币就挥手放人，则缺口的80币记为坏账，血娃娃右眼保留，好感度从畏惧往困惑偏移，寻母任务仍以2%触发。
- 若林恩把右眼登记表签成永久买断而非可赎回，则血娃娃离店后在游魂巷对外放话"药剂店伙计买眼睛"，E21相遇时她开口先讨赎价。
- 若林恩验看血娃娃右眼后指了指墙上一排眼珠退回押金，则她只掏了钱就抱娃离开，店内存货多一枚右眼的入库记录不再形成，畏惧度+10。
- 若林恩向血娃娃指出"梦里的那顿大餐"和她口中血液成分一致，则她脸上血淋淋的笑容挂不住，洋娃娃的复读第一次中断，san值多扣5。
- 若林恩主动请血娃娃抽一管血做病灶排查，则针刺入她脖子时洋娃娃在一边大哭大闹，血液样本标"血肉恶灵·五级·混乱中立"入库，畏惧度+15。
- 若血娃娃见血要被抽走当场张口反咬，则她的牙齿卡在支架上拔不出来，林恩在她张开的口腔内直接完成抽血，巨口拔牙要附加费用10币。
- 若林恩把胃里掏出的耳朵、头发、梳子摊开在柜台上逐一过秤，则洋娃娃的笑声消失、血娃娃的双手无意识按住自己的小腹，寻母线索的具体清单当面对账。
- 若林恩指着盘子里的女性器官随口说一句"这搞不好是你妈"，则血娃娃的指甲掐进洋娃娃的缝心、瞳孔缩成针尖，san值-15，寻母任务进度仍停在2%。
- 若林恩把胃内容物整体打包随药一起交给血娃娃，则她抱着洋娃娃一路哭出门，那晚游魂巷一名游荡者收到一包裹着头发的"妈妈的味道"。
- 若林恩只报告治疗不动那盘器官，则它们在试剂瓶中渗血过夜，下个清晨林恩发现梳子的纹路缠着一截新的长发。
- 若血娃娃离店时那声"黑店"被门口游魂记下传开，则E03猪头魔进店前先眯眼打量柜台后的林恩，开场多一句"听说你这店连恶灵都敢开刀"。
