# E40·户籍锁定与血娃娃共情·if线

- 若林恩先跟血娃娃达成情绪同频再开检索，则血娃娃把洋娃娃塞进林恩掌心的那一幕先行立住，母亲影像与"妈妈"两字后到的冲击叠加在这份稳信任上，事件中段的"话里有话"误读被取消，完成条件仍以影像锁定+平行林恩加密+血娃娃认可三格齐全结算。
- 若林恩先查户籍再回头管血娃娃，则血娃娃在屏幕那头沉默扒着板凳边缘旁观，直到"我的妈妈"落地时才凑上来安慰，她接过苹果的那一拍多了一秒犹豫，"没妈很久了"的台词提前到林恩开口前。
- 若林恩中途切掉卫星画面、回避那张脸，则检索暂时中断，血娃娃在洋娃娃耳边小声代他重复那一句"妈妈"，户籍系统保留进度不退步，后续再开时无需重做特征组匹配。
- 若林恩让触手全程代敲键盘、自己腾出手撑住太阳穴，则系统把"操作者紧张度"标成高频状态，触手出错率升高，影像匹配从一次锁定退为三次逼近，血娃娃看出异常先一步把板凳挪近。
- 若林恩当场把血娃娃的话误读成挑衅、提溜后脖颈不放，则她哇哇大哭到窗台震动，门外两个文员妹子递纸进来又退回，洋娃娃被逼得压下笑声，误会解开走原作"对不起"回转，但为了解这一步多扣一拍时间。
- 若林恩把血娃娃的"把娃娃当妈抱着哭"理解为邀请而起身先一步抱住她，则她愣愣地回抱住、把洋娃娃夹在两人之间，两个文员妹子的呆滞如期出现，林恩仍然不替玩家表态任何更进一步动作，温情停在那一次拥抱。
- 若林恩直接检索自己的姓名而不是先查母亲，则户籍系统在"全国范围内林恩"无匹配上提前撞上他给自己加密的那条样本，平行林恩的档案先于"北方妈妈影像"公开，事件走向变形为"先发现自己再发现妈妈"。
- 若林恩找上门文员妹子请她代查一个特定县份名称，则她把权限往内网再推一层违法动作，北边母亲的画面更清楚，但尹琴半小时内调集监控的速度也更快，离开总局的"远远看一眼"窗口缩短。
- 若林恩检索到母亲影像后当场给系统下一条"永久隐藏"指令，则加密层从国家等级再上抬一格，但血娃娃看在眼里并不懂这意味着什么，事后尹琴那台机器只留下一道截屏水平的残影，后续私房侦察线更干净。
- 若林恩对着血娃娃答应"以后有机会带你去见我妈"而不是留在抽象共情层面，则血娃娃把洋娃娃的下巴抬起来当作点头，认可医生哥哥的一格直接写满，后续 E41 白逸车上她主动贴近林恩坐的概率翻倍。
- 若林恩把整个检索终端直接搬走或拆扔进随身空间，则超自然总局中央机房的卫星链路被当场拉断，尹琴白逸反映速度以分钟级提前，事件结果仍照常成立（母亲影像已存、平行档案已见、共情已立），但离开路径多一条物理搬运的逃逸线。
- 若林恩决定不去北方、把坐标写在便签压屏下转身回白逸家，则户籍事件按"已检索但不赴约"结算，母亲影像与平行林恩加密两项结果仍写入偏离账本，E41 之后的北方寻母时间线下滑一轮触发。
- 若林恩当场决定直接赴北方，则他拉着血娃娃腕子走过门口时对文员妹子那句"你们长得很漂亮"多一分冷淡，白逸的人接他出门时多一层"这小子心有所属"的误读，与"远远看一眼"的原有定调不再对齐，事件直接变形收束。
- 若林恩在触手键盘中途突然卡住不发一言，则血娃娃把洋娃娃的脸挤进他手心里、把他手拉到自己肩膀上来一次"反过来安慰"，整个共情方向翻一次，但被认可的对象仍然是医生哥哥本身，等价结算成立。
- 若检索彻底无果、画面只返回一片空白且血娃娃这次头也不抬、只认洋娃娃，则共情与因果同时缺位，事件按取消结算，E40 的"血娃娃信任转向"与"平行林恩档案"两个铺垫均不出现，后续寻母线改由别的入口重启。
- 若检索被外力打断（总局紧急警报、白逸突然冲进来、系统主动切换），则事件按完成度的次序结算：先看已建立的摄情环节是否凑齐；影像与档案未同时入袋且共情未稳时按取消入偏离账本；三项皆齐但尾声台词没说完时按完成入偏差账本、白逸的迎接场次被强制延后一拍。
