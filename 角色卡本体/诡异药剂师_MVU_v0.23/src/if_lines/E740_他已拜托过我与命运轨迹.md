# E740·他已拜托过我与命运轨迹·if线

- 若羽毛笔当场拒绝委托并撕毁艾雯的求助信,则命运会造成反向波动,林恩的王座会在三刻之后因为失去命运锚点而短暂失明——他首次感觉到「无命之人」的寒冷。
- 若羽毛笔当场接受委托但要求林恩本人来命运之地签字,则林恩被迫离开王座三天,信徒看见他们的神「为了他们去找另一位神」,参与式信仰的理论首次得到实证——神也需要协作。
- 若羽毛笔要求艾雯「你也签下一份承诺若林恩那一边出问题你来收拾」,则艾雯的「骗子身份」会变成「担保人」,她必须为自己的谎言出具法律兜底——这会让她的欺骗成本骤增。
- 若羽毛笔在命运之地遇见未来五百年的某个版本的自己并被警告「不要接这活」,则过去的羽毛笔会陷入存在主义危机,他的任何决定都会变成「是否定未来的自己」的悖论——「我拒绝我自己」。
- 若羽毛笔宣布「我只记录不干预」把委托转化为纯粹的「观察者协议」,则他会放弃对因果的操纵权,信仰网络会失去命运加持——但羽毛笔本人会变得极其清廉,成为史上唯一一个不操纵人的命运之神。
- 若羽毛笔让林恩的信徒「每人贡献一段未来的期待」作为网络节点,则信徒的未来会被羽毛笔掌握——他知道每个人最大的梦想,但他也会知道每个人最深的恐惧,这种全知会让他同情众生的重负。
- 若羽毛笔决定把第一根线连接到那个避难区的孩子第二根线连接到三十年后的成年的他,则羽毛笔会看到一个「人」的完整成长轨迹——这种纵向的观察会让他更理解「凡人的尺度」。
- 若羽毛笔把自己的一缕灵能封进命运之笔让信徒轻微感受到「命运在动」,则信徒会产生「被神注视」的幻觉,这种被注视感会激发更强的参与式信仰但也会让信徒倾向服从。
- 若羽毛笔选择把命运轨迹对信徒完全公开任何人都可以查询自己或他人的因果线,则社会会进入彻底的透明状态——但很多人会利用这种信息进行「命运黑客」,故意断裂他人因果以获取个人利益。
- 若羽毛笔与林恩进行密谈警告他「你所爱的某些人会在未来毁灭你」,则林恩会陷入猜疑危机——他会不确定谁能信任,这种不确定会让他在亲密关系中变得退缩,从而伤害所有爱他的人。
- 若羽毛笔把命运的网络设计成「自我销毁型」一旦林恩死亡所有连接自动切断信徒会失去与命运的联系回到凡俗,则这种「神教的寿限」会让信徒珍惜当下,但也会让信徒产生「神是会死的」的虚无感。
- 若羽毛笔决定把信徒的「善行」而非「祈祷」作为连接的力量源泉,则信仰会践行化——只有行动才有权连接,但也会有人为了「连接」做好人好事——把道德变成交易。
- 若羽毛笔把自己的本体（笔）暂借给信徒使用让他们「画自己的命运」,则信徒会亲自体验「我的未来我做主」的掌控,但很多人会画出过于美好的画面而无法面对现实——命运之笔变得危险。
- 若羽毛笔与左左进行对话请求她作为「人类视角」的顾问,则她会第一次被「命运」视为重要的对话伙伴,她的内心会既骄傲又不安——她的意见可能会害了千万人。
- 若羽毛笔让信徒看到「如果他不做某个选择会怎样」的反事实影像,则信徒陷入「多元宇宙后悔」——但也会有人因「看见另一条路」而更加珍惜现在。
- 若羽毛笔拒绝给出任何「确定的未来」只展示「可能的未来集合」,则信徒面对永恒的不确定性——这种不确定会让选择更勇敢「我不知道但还是做」,但也会让信徒陷入决策瘫痪。
- 若羽毛笔决定把「林恩最终的牺牲」从命运轨迹中隐藏,则信徒永远不会知道神在替他们承担什么——这种隐瞒会让典型救赎叙事继续,但同时剥夺信徒的知恩报恩权。
- 若羽毛笔让自己的本体（笔）碎掉变成亿万个「碎片笔」分发给帝国公民,则每个人都可以「修改一点点命运」——但这种微小的修改会累积成无法预测的大改,命运的混乱成为新常态。
- 若羽毛笔选择与信徒中「最不信神的人」进行深度对话试图理解他们,则这种对话会让羽毛笔对「无神论」产生新理解——但他也可能被说服,开始怀疑自己的存在意义。
- 若羽毛笔决定把「林恩最终的牺牲」直接展示给林恩告诉他他将在某年某月某日死亡,则林恩会提前面对自己的死亡——这种确定性可能让绝望但也可能让他更加珍惜,「我知道终点所以我会活得用力」。
- 若羽毛笔让命运网络高度去中心化即使他消失网络也能继续运行,则「去神化」的设计会让网络真正属于信徒——但也会让信徒失去「可以向谁祈祷」的确定性。
- 若羽毛笔最后选择把林恩的命运轨迹永久封存不让任何人包括林恩自己查看,则林恩永远活在「不知道未来」的纯粹状态——这种纯真可能比知道一切更有力量,但也更累因为他必须为「各种可能」准备。
