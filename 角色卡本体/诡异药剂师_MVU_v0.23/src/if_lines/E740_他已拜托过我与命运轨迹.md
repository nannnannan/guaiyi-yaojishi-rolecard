# E740·他已拜托过我与命运轨迹·if线

- 若林恩在重登至高王座、沉入漫长沉眠前向门外的艾雯与自缚天使留下那句「请到下一次战争开始之前，再来唤醒我，我会一直在这里，守你们到……永恒……」，并在闭眼时将怀中的羽毛笔贴得更紧一分，则这份跨越星空的眷恋会清晰地传递到被放逐的命运国度。
- 若三大圣堂的青铜巨门隆隆关闭后，自缚天使在门外突然蹲下捂脸痛哭，当面戳穿艾雯「可是你撒谎了！因为你只有在撒谎的时候才会表现得那么孤注一掷，因为我才是和你相处最久的那个人！！」，则艾雯爵士会在长廊寒风中久久沉默，无法在最了解自己的母亲面前继续伪装。
- 若自缚天使泣不成声地喊出「你和我都清楚，林恩他这辈子唯一能够平静去面对的到底是什么（是死）！」时，艾雯背对着母亲一步步走入长廊阴影，低声回答「他最坦然面对的，不也就是我们最害怕的吗？……所以你又怎么能让他死呢」，则母子二人都将怀着必死护佑林恩的决绝走向各自的战场。
- 若艾雯爵士动用帝国力量寻至被放逐的命运国度、在溪畔岩石前刚刚躬身开口说出「我来是想要拜托您一件……」，便被起身负手眺望星空的轮回神王平静打断：「我知晓。那三分钟，他就已拜托过我。」，则艾雯会瞬间恍然大悟当年地狱决战失却三分钟的草蛇灰线，抹去脸上的雨泪坚定离去。
- 若轮回神王在溪畔向羽毛笔与已长出长长枝叶的初代命运萌芽揭晓林恩必死的残酷真相，命羽毛笔利用留在林恩怀中的本源神格替代已消亡的「因果」、将全宇宙信徒的执念与林恩彻底焊死时，羽毛笔脑海中浮现出初次见面时林恩挡在她身前直面地狱注视的背影，则她会崩溃地捂住双耳失声恸哭：「难道成长，就一定要失去吗？！」
- 若轮回神王冷漠回答「是的，从来如此」，并抬手以初诞者之力化作命运法则强行灌入羽毛笔体内、将她的位格一举拔高至濒临神王界限逼她握笔时，羽毛笔拼死咬紧嘴唇抗拒下笔，则她体内的命运神格会在抗拒中激发出前所未有的纯粹光辉。
- 若在羽毛笔即将被迫握笔的千钧一发之际，一旁的初代命运萌芽如漫天绿叶飘舞般重重撞开羽毛笔、张开双臂挡在她身前，用倔强而心碎的愤怒双眼直视轮回神王质问「命运就一定要被操控吗？！」，则那一日，陪伴了轮回神王无数纪元的她正式与他决裂分手。
- 若彻底复苏的初代命运女孩牵起泪流满面的羽毛笔第一次踏出命运国度、在璀璨星空下温柔对她说「不管做出怎样的决定，我也希望，那是属于你自己的选择，是你自己心里所愿意的」，则重获自由意志与准神王位格的羽毛笔将顺着林恩心口那支羽毛笔本体的呼唤，义无反顾地飞向三大圣堂。
