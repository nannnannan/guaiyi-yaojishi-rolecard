# E546·嘲讽模式与根源拔刀·if线

- 若林恩把「一群废物」改为「一群落伍者」开骂，则嘲讽火药味下降，星轨等人爆发的时点延后。
- 若林恩在嘲讽前先公布一次击杀战绩名单，则羞辱附加事实背书，「站出来的勇气」的底线更狠。
- 若林恩不骂「跪下来给我扣头」而改口「现在退去我不拦」，则勇者筛选由受辱激将改为放任逃避，点燃面被稀释。
- 若林恩让巨像代他先骂一句「你们真让人失望」，则知情层的嘲讽前置，林恩后续姿态从辱骂者变成接过话头的推手。
- 若林恩不开嘲讽而以「我将率先示范」的宣言切入，则勇者筛选的逻辑由「逼迫」改为「示范」，夜医男孩的出手被动摇。
- 若林恩不踩泰坦后辈胸膛而将其扶起再战，则羞辱手段消失，「可杀不可辱」怒火点不亮。
- 若林恩让星轨在锁踝成功后立即公布她的法则细节，则「这是你教我的」从殊荣变成公开教学，二次齐冲力度被技术化。
- 若林恩把战场放到心灵之海而非荒野，则伤人不见血，太古根源的「血性点燃」在精神层叠床架屋。
- 若林恩让自缚天使拔剑齐上而艾雯未拦，则黑夜城核心提前下场，「等一个结果」的悬念由外部进入场内。
- 若林恩倒数从十减至三而未到一便转身走人，则他彻底放弃这片战场，勇者筛选失败，剧情进入更暗分支。
- 若林恩让见习夜医男孩出手前多挂一句「我也怕死但更怕被遗忘」，则凡人拔刀的动机更明确，黑袍回敬的礼节被升格。
- 若林恩对男孩的破喉咙长啸以接住石子而非摧毁攻势回应，则「向神拔刀」画面更纯粹，血腥的锋芒被收敛。
- 若林恩在拔刀致敬时不再肃穆而带笑意，则「神明回敬」气质从庄重转为同侪打气的轻佻。
- 若林恩让男孩扔出的石头带一颗初诞者碎片暗记，则那一枚带礼物的石子在林恩手中变成信物，男孩从赌死者变成种子。
- 若林恩反手接住铁剑后不立刻回敬而转手交还，则勇士不被升级为决斗方，点燃齐冲的方向从根本上改写。
- 若林恩让第二第三古老根源齐冲时以「建制化战法」编排，则他们不再散兵游勇，战场节奏向真正战争倾斜。
- 若林恩把「学不会建制化协同」讥讽成「建制化是为了整齐好看」，则星轨等人的反思被打掉一半，自发战团难聚。
- 若林恩让左左在被镇压的男孩哀号时哼歌应和，则喜剧渗入惨烈，黑袍的危险画面被家庭感削弱。
- 若林恩让小男孩的队长当众把男孩扯回去，则勇者被强制收回，点燃引擎熄火。
- 若林恩在「点燃齐冲起势」一刹把兜帽更深压下而非任由狂风吹起，则身份暴露的窗口延后到下一次近身。
- 若林恩让银幻在观战席不完全空洞而是举手想劝，则知情层与公开层的边界在现场多一处可读姿态。
- 若林恩把「让众人看清与神的差距」宣言用过去式回述而非将来时，则他已在示范，嘲讽不再是预警而是判决。
- 若林恩在齐冲起势瞬刻以一丝微小的心灵法则余波引导，则被点燃的前锋按林恩预想路径冲锋。
- 若林恩让努斯首次战斧砍空而未劈中，则「可杀不可辱」的怒吼落空一格，勇者的第二拳才起势。
- 若林恩对男孩的破喉咙回以轻笑而非回敬拔刀，则神与人的军事礼仪不再对等，齐冲的情绪链平衡破坏。
