# E558·入梦者与狱卒许可·if线

- 若林恩在自缚天使和艾雯推演无果时主动贡献他个人接触过的某一段亲眼见证，则天文算力的失败背景被他亲手补全一份线索，防线机制的破译被推向更具体的位置。
- 若林恩在召星轨和圣安娜当向导时只召星轨而不召圣安娜，则智天使的参与被剥离，「第二次坠落者联盟」的领队视角少一位共证者。
- 若林恩在星轨讲述见到入梦者时主动追问「对方留下了什么物品供你参详」，则精灵族观众对入梦者的物证有了进一步的影像，但星轨摇头表示对方什么都没留下。
- 若林恩在星轨点亮三大边境光点之后主动拒绝听她继续讲三大边疆的细则，则第一线的边疆信息被他本人中断，他对神疆、无序、理智与混沌三者的切换度降低。
- 若林恩在星轨讲述第二条边境时主动直接说「那是无序深空，地狱现在就在这里」，则星轨和圣安娜的震动愕然被宣布出来，二人对林恩所处位置的认知被拉齐，但都未追问。
- 若林恩在星轨讲述三大边境时主动把灵能化作空间坐标系演算三大边境的精确交界，则星轨的讲述被林恩亲手补充，她从向导转为与他齐位的第二位讲解者。
- 若林恩在灵能展开大坠落时主宇宙三维星图时主动只标出最重要的两个节点，则七十一个节点星球的悲惨数目被压缩成局部感染，集体绝望感被缓释。
- 若林恩在灵能展开大坠落时主动圈出漆黑与腥红光晕之外的第三块区域，则「仍有未污染区」的新领域出现在会议桌上，对无退路的判断被推上议程。
- 若林恩在听到「东边疆必须有一位狱卒级乃至柱神级的存在坐进去」时主动接一句「那只能选我自己」，则会议层对东边疆防线的缺口与他个人立场被拉齐，亲访狱卒当场成必然。
- 若林恩在星轨说出「入梦者」三字时主动表示自己听过这个名字，则入梦者的名号在会议上从「谜」被降为「有来源」，星轨对他的敬畏被削一半。
- 若林恩在请星轨入场时主动为她们准备的是简陋木凳而非常规席位，则二人第一次踏入黑夜城权力中心就处于一种被公议的位置，她们提供的情报会被心理掺杂。
- 若林恩在星轨讲述入梦者消失后主动追问「最后一刻你在哪里告别」，则星轨被引向一个隐秘的告别遗址，她对入梦者最后一个景象的记忆被更多外展。
- 若林恩在亲访狱卒前主动把黑雾高山漩涡的路线对自缚天使和艾雯保密，则他离城方向只暴露给小丑人偶，「不再商议」被钉在会议桌之上。
- 若林恩在星轨揭示七十一个节点十二破口时主动复述她话中的关键，则这道数字被钉进公开记忆，参会者对缺口的记量在下一日回到更大关注点。
- 若林恩在亲访前主动让小丑人偶以别的形象而不以哭泣小丑形象引路，则「前同事」的耻被小丑卸掉，他在漩涡锁链前的姿态更稳定，但小丑本身的面子挂不住。
- 若林恩在漩涡前主动答应不强取渡鸦尸体，则小丑的戒心少一半，锁链罗网在初次迎接时少一道预设敌意，西王出场节奏后挪。
- 若林恩在西王宫主动直接用「我早已决定要走」开场不解释理由，则原则性放行的谈判被推到三句话以内，西王林蒙对这位主人的决绝留下更深印象。
- 若林恩在林蒙警告出地狱即被盯时不立刻反驳、而是沉默良久再表态拒绝坐等，则「被动应对」被换成主动选择，「主动回主宇宙遏制侵袭」从他口中被他自己而非对方企图推出。
- 若林恩在与西王对话中主动承诺「打完这一仗会回来向狱卒汇报」，则他与狱卒之间的信任被建立一条时间轴，「做好准备即可」的空洞许可被填上「归来汇报」的实情。
- 若林恩在与西王对话结束时主动要求与自己的同行名单保密，则同行的人不在西王眼中被明确出来，他们的小队形态被装进「做准备」的黑盒。
- 若林恩主动以小丑人偶开大玩笑「他也是个萝莉控？」被西王喷茶后自己也当众接一句「谁说萝莉控就不能创世了？」，则他公开认可自己的玩笑阵营，小丑大怒的亵渎指认更加落实。
- 若林恩在西王原则性放行时主动要求一份书面认可，则「做好准备即可」的口头承诺被物理化成契约，但西王提醒他这种契约会成为狱卒内部斗争的把柄。
- 若林恩在触发许可时主动要求西王陪同参观女主人渊心火，则「女主人混乱前放话可答应条件」的内部证物被林恩亲眼看到，他的返程承诺从口头变成亲眼。
- 若林恩在与西王对话中主动告知自身在地球上的存在方式，则他被西王视作真正的大君继承者而不只是幸运儿，西王的忠诚背书加深一层。
- 若林恩在原则性放行时主动提出一切后果由他个人承担，则西王在放行时多一层了一道保险，「做好准备」这一前提从个人准备正式挂为责任转移。
- 若林恩在原则性放行时主动承认自己未曾做好准备，则西王的放行被判为「冒险」，他仍被准许，但西王眼中看出他需要更多稳重，「做好准备即可」的前提被林恩亲手松一档。
