# E705·离别与以太吞噬·if线

- 若林恩在银色幻想送别时没有只说「替我守着她」，而是多交代一句「如果我十年未归，你就自行决定神格去留」，则银色幻想会当场拒绝后半句，把「等你回来」设为唯一指令。
- 若林恩在光界边缘主动回抱银色幻想而非任由她拥抱半分钟，则她机械躯壳的微颤会更快平复，离别时的悲壮感化作更笃定的守望。
- 若林恩在银色幻想说出「早点回来，我们……需要你」时回以一句「是你们需要我，还是你需要我」，则她会罕见地沉默两秒，低声补上一句「都有」。
- 若林恩在把织梦托付给银色幻想前先在织梦眉心留下一缕白烬罪火护持，则织梦沉睡期间的无序侵蚀会被彻底锁死，银色幻想照料她的损耗大幅减轻。
- 若林恩在未来画家归还已抹去意志的以太本源时追问「你是怎么抹掉它的」，则未来画家会亮出残破的苍蓝指尖，让林恩直观看到她为此付出的本源代价。
- 若林恩在未来画家劝他「你应该吃掉她……去完成三位一体吧」时没有平静回绝，而是当场冷下脸按住刀柄，则未来画家会轻轻摇头退开一步，不再多劝半句。
- 若林恩反问未来画家「在你们失败的那些未来里，我吃掉织梦了吗」，则未来画家会沉默片刻后承认「从来没有，无论重来多少次你都没选这条路」。
- 若林恩向未来画家追问「如果不吞噬织梦，三位一体还有别的路吗」，则未来画家会留下一句「那就只能靠你在梦里自己走通了」，为后续轮回神王的点拨埋下伏笔。
- 若林恩在拒绝吞噬织梦后把「我不会用她的命换我的路」明确说出口，则未来画家眼底会掠过一丝极淡的温和，承认这正是她认识的那个林恩。
- 若林恩在前往天堂之战遗址前先回望一眼黑夜城的方向，则他能借主宇宙本源感知到军团正在集结的灯火，带着这份喧嚣踏入漫长孤寂的闭关。
- 若林恩抵达天堂之战遗址时先以空间神格封锁整片星域再张开双手吞噬以太，则吞噬以太引发的法则风暴不会外泄分毫，外界无人能推算他的闭关坐标。
- 若林恩在吞噬以太本源时采取分批炼化而非一次性鲸吞，则他初期承受的躯体撕裂痛楚减轻，但进入深层时间长河闭关的契机将推迟数月。
- 若林恩在以太入体的瞬间主动用白烬罪火包裹住以太核心，则机械法则与罪火的初次排斥被强行压服，他踏入闭关沉淀的起点更为稳固。
- 若林恩在闭关落座前给左左与喵喵下达「轮流替我守着意识外围」的指令，则两小只会在漫长岁月里乖巧轮值，替他挡下无数细碎的时空杂音。
- 若林恩在彻底合眼进入闭关前留下一道连接银色幻想的紧急神格信标，则日后时间泡叛乱爆发时，银色幻想能以最快速度将求援讯息传抵他所在的深层时空。
