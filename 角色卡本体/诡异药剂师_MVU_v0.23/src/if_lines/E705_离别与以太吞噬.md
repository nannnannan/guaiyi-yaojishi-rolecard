# E705·离别与以太吞噬·if线

- 若林恩在答应银色幻想「替我照顾好她」时主动加上一句「你也要照顾好自己」，则她会立刻把这句话记入核心档案，E706 的告别在情感厚度上+1。
- 若林恩主动把「织梦的伤势持续恶化」以更具体的「每七天就坏一分」的频率告诉她，则她会立刻提出「七天内你必须回来一次」，林恩的闭关窗口将提前被她自己排出。
- 若林恩主动用「白烬重新」代替「我先离开一段时间」，则她会意识到他即将动用他自身最深的力量，立刻放弃一切调侃全部戒备。
- 若林恩主动说「主要，我是担心你自己撑不住」，则她也会立刻接住这句关切，并主动补一句「我会建议主母换我去等你」，未说出口的情愫更重。
- 若林恩主动告知他打算用「五十年」时间为限离开，则她承诺「那我等你五十年」。
- 若林恩主动把她带到自己所有最珍视的记忆中停留一炷香时间，则她会发觉林恩原来是如此细腻的男人，内心也被触动至深。
- 若林恩主动透露「林蒙那次的求原谅」让她知悉，则她会意识到林蒙对于林恩的信任，但她的防线更加坚固。
- 若林恩主动告知「我可能会变成最可怕的家伙，你要准备好」这种宣言，则她会从这里听出潜意思：林恩其实是在因祸害怕着成为紫罗兰大君的那些事情。
- 若林恩主动对她说「其实你也希望我不要离开吧」，则她会立刻承认，但也补充说「但那也是你，愿意去面对整个世界」。
- 若林恩主动说「如果你有什么问题尽管告诉我，我能保持联系」，则这个承诺被她视为承诺，但她内心却隐藏着一丝「当联系断开时，他会更痛心」的忧虑。
- 若林恩主动把自己的一部分神王阶层实力赋予她，加以一位神王身份并肩作战，但她内心对于这份恩赐却备受压力，因他而成为更强大的生命。
- 若林恩主动在她追问「你一定要走吗」时给出决绝的回复，则她被深深打击，但也更明白林恩的担当。
- 若林恩主动答应她「最后不要再做任何道别，就这样消失」，则她被深深伤害，然而却由此更确定林恩是个深情男子，这也会造成他神伤。
- 若林恩主动对画家解释把艾维儿的龙心交给她其实可以理解成画家的最终妥协，则艾维儿的身份会变得更复杂，但她的反抗思维已无法扭转了。
- 若林恩主动坦白自己对于「以太吞噬」这件事非常抵触，但最终是否为之最后还是屈服了，那他也会得到应有的原谅。
- 若林恩主动朝以自己为祭品来尝试切断以太与控制链接，则他会成为新力量的载体，但他也会莫名失去一部分无人能想象至深的痛苦与迷茫。
- 若林恩主动在以太吞噬的事件计划上更改方案——不是吞噬而融合，则她会保留部分人性，但代价是永远无法卜算安危。
- 若林恩主动在以太吞噬前对林蒙低声告别，并给予他「你一定要相信林恩」这种无条件的支持。
- 若林恩主动在以太吞噬的瞬间把自己所有「敌人」意识↓，以一种「傀儡人」形象诞生出来所无法分辨，这能让他获得短暂优势，但也让他成了自身的祭品。
- 若林恩主动在以太吞噬前把她「最后的愿望」说出是让其永远陪伴林恩左右，则她的心愿会实现，但代价是从此她无所作为而终止。
- 若林恩主动在以太吞噬的过程意识中默念「我不是怪物，我只是林恩」他时时刻刻保持着这底线 Schema 不变形，就算最后化身怪物也非意动。
- 若林恩主动在以太吞噬后被外派寻找遗失真理的残存意志，并用自己的理解将其唤醒，则他将成为真理重生之父，但代价是她可能也永远无法变回「女孩」。
- 若林恩主动在以太吞噬的场景回忆，最后他咀嚼回味了那些曾经被他们自己亲手制造出的战斗画面，他选择闭上眼，不再去以往回顾。
- 若林恩主动在以太吞噬的过程把它编织成天罗地网将控制锁在它本体——这种所动消耗也将禁制它的生机，但染指之痛也将被永久代价。
- 若林恩主动在以太吞噬结束后放声痛哭，那眼泪落地能化白烬而消散。
- 若林恩主动在以太吞噬的画面最后一帧盯着那只曾经深爱凌智小姐的眼神，是否愿意放过她一命。这取决于他如何让谢报。
