# E365·巨像剑与神性试用·if线

- 若林恩在召唤血肉剑刃时主动在锋面上多刻一个疫医十字标志，则他可以清晰追索巨像威能在每一次挥砍中的流动路线，但剑体因此额外消耗一成灵能。
- 若林恩主动让左左尝试以巨像之心威能捏出一个「左左头像」，则她最初捏成的是一只胖乎乎的胖鸟，林恩当场笑岔气，涩涩度+2。
- 若林恩在左左一剑挥出截断高塔前主动限制她剑刃输出功率到上限30%，则高塔只在塔顶留下一道浅浅剑痕，但她本人反被这种明显收力的训练方式憋得大骂。
- 若林恩在左左一剑失控砍断高塔时主动扔一片血肉在她身周搭建缓冲软垫，则林恩本人少倒地一次，但左左事后被血肉的黏液恶心到满地打滚。
- 若林恩主动让左左练习「刺穿一颗苹果而不破坏果核」，则她连续失败九次后才勉强成功一次，第一次尝到「控制的艰难」，涩涩度+1。
- 若林恩在左左试图雕刻小字时主动把自己的手背伸出来被她练习，则她的第一次试刀直接在林恩手背上开了一道细缝，但她哭唧唧道歉时他的心痛感+3。
- 若林恩主动让左左只用一根神印催化的手指尖触碰巨像之心威能，则她对威能的亲和度瞬间下降九成，反而能够看到「心脏本身的具现形态」。
- 若林恩在左左直接驱动巨像之心时主动在她额头上轻贴一片治愈药剂，则她的过载压力减少一半，能坚持时间延长一倍，但林恩自己事后鼻血直流。
- 若林恩在尝试自然神性时主动在身体表面铺一层深渊死气作底衬，则皮肤表层的藤蔓生长缓了一拍，林恩能稍微掌控藤蔓生长方向而不被反咬。
- 若林恩主动让一根藤蔓缠绕一根巨像血肉长剑上，则藤蔓当面在剑刃上开出一朵漆黑花朵，林恩首次目睹「自然与死亡共生」的具体形态。
- 若林恩主动让自然神性专注于「治愈」，则夜魔刀上的绿光在数分钟内把林恩本人一条伤疤隐去，他本人对自然神性的信心上浮一档。
- 若林恩在驱动自然神性时主动把目标聚焦在母树的种子发芽，则一颗次元种子瞬间在树洞里扎根，但初诞者储量被抽空到必须整整二十四小时才恢复。
- 若林恩主动让自然神性与巨像血肉混合试用，则夜魔刀上绿光转为黑金色，他首次触到「生命与腐朽」规则相叠的边沿。
- 若林恩在左左失误后果实无法雕刻时主动告诉她「比输了就要受罚」，则她气得要逆推他，但下一次雕刻精度直接提升两成。
- 若林恩在左左被水果刀漏掉时主动藏起那把水果刀换成更难雕刻的栗子，则她直接破防大骂「凑脑袋你作弊」，但林恩握住她的手亲自教她再加一次。
- 若林恩主动把巨像之心储备的本源血气借一缕给左左作底，则她能以更高的精度完成精细控制，但同时她的心会被巨像网络轻轻刺痛。
- 若林恩主动故意在左左试刀时突然打喷嚏，则她被手滑惊得大喊一声，剑刃差一点砍到她自己，林恩从此被她记恨一整日。
- 若林恩主动在自然神性触及规则边缘时立刻停手一拍，则一缕回响会在接下来一整夜里在他灵魂中轻轻反复，他对规则的敏感度上浮一级。
