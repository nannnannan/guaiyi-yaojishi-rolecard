# E160·蓝星百鬼夜行与魔改义肢·if线

- 若林恩在听到「火苗效应」一词时就用咒瞳隔着车窗远程扫过白逸全身确认灵质状况，则读出「猎魔人后裔未觉醒」一行小字，事件以不变形收束但白逸背景多一条未公开标签。
- 若林恩用咒术把自己的合成笔记隔空贴在越野车门内侧，则尹琴开门瞬间被咒术痕迹呛得皱眉，通灵开场节奏被外来咒式打乱一拍。
- 若林恩远程把装有感应器的义体转向车内，则「笨蛋——射她啊」的电子音提前响起、白逸被惊醒大骂，感应器误判场景写入事件档案。
- 若林恩用神的方程式把一杯普通牛奶具象成咒瞳临时探测介质，则浮沫上漂起三秒片段画面，咒瞳获得一次短暂的蓝星视野，事件以不变形收束但牛奶样本被单独入档。
- 若林恩把那杯「精力+1、体质+2」的加工样本牛奶灌进义肢营养槽反测，则义体营养液瞬间暴动冲刷排线，魔改义肢提前露出潜在失控征兆。
- 若林恩在尹琴喊「黑夜里负重前行」的瞬间让左左隔空替她应一声「你扛什么你扛」，则尹琴一怔后微微一笑，尹琴侧首次感知到远方有人在偷听。
- 若林恩把龙的血肉蓝图配合神的方程式画成新合成图、交给系统尝试补全龙息之臂，则失败结果用红字直接烧穿面板，咒瞳碎片修复再次延后。
- 若林恩在废仓上空用咒瞳夜班扫一遍、锁定尸体缝合工艺，则画面中「七道血线锁魂」首次以解剖视角拆解给玩家，血肉神教工艺档案多一页。
- 若林恩主动让左左趁百鬼集结时跳上车顶小小地朝众亡魂行了个礼，则车顶一排背影齐折断地转向她半秒，百鬼队列出现一段静默紊乱。
- 若林恩主动调配一支「阴气抑制烟雾弹」隔空弹到废仓门口，则百鬼队列在尹琴背身视角里显得模糊一团，通灵指引被打散三秒。
- 若林恩主动把一滴利维坦血肉藏入咒瞳远程空投到废仓屋顶，则百鬼围聚之际那一粒血肉会同化屋顶砖块、仓顶出现一小块蠕动黑疤。
- 若林恩主动要求系统记录整个百鬼夜行影像、留作之后咒瞳情报对比，则他回到黑夜城时能在面板中拆解每一帧阴气走向，咒瞳知识检索行数暴涨。
- 若林恩主动用咒瞳反读义体感应器日志，则读出「该类感应器为一年前境外走私批次」，未知势力介入线提前一格。
- 若林恩接受神的方程式但主动放弃咒瞳碎片修复、只用来改良药剂配方，则碎片继续封存，咒瞳修复路径改由玩家另起炉灶。
- 若林恩让左左趁百鬼还在聚集时于废仓四周布一段血肉隔离带，则百鬼无法冲出封锁村、蓝星民众伤亡率被压到零，但废仓聚鬼浓度上升一档。
- 若林恩在林恩住处主动给巨像之脑发送百鬼夜行的实时画面，则巨像之脑隔着屏幕看得入神，首次以「我家这口」语气感慨夜医的造物主。
- 若林恩决定测试神的方程式前先用咒瞳把「失败蓝图」翻一遍文献里所有失败案例，则他多获得一页「失败类型对照表」，之后测试的失败模式可被精确预判。
