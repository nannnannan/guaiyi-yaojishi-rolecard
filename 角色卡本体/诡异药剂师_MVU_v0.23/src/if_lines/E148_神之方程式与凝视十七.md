# E148·神之方程式与凝视十七·if线

- 若林恩在核对神之方程式时直接以自身血液或地狱凝视（17）为材料投入合成，则方程式超负荷运转，初次试验即产生不可控的变异产物，咒瞳碎片进一步碎裂，林恩自身承受反噬伤害。
- 若林恩选择先以低阶魔药材料试验神之方程式，则合成机制逐步验证，但图纸公式消耗精神力远超预期，首次成功产物仅为原药效力的七成。
- 若林恩在合成过程中主动引导地狱凝视（17）作为催化剂，则凝视与方程式产生共鸣，短暂压制反噬，但凝视层数累积速度翻倍，咒瞳裂纹加深。
- 若林恩拒绝立刻使用神之方程式，将其图纸公式交由同伴评估，则触发变形条件，事件转为能力封存线，异常中心调查仍按原计划推进。
- 若林恩在抵达异常中心封锁线前先联络蓝星侧，则白逸考核实况与自身近况首次交汇，但两地信息差导致双方判断偏差，后续行动各自偏离最优路径。
- 若林恩以直线最短路径接近异常中心，则无视灵媒留下的警告标记，直接闯入封锁线，被收容中心内部防御机制锁定为入侵者，夜医误判其身份。
- 若林恩试图用神之方程式解析异常中心的封锁结界，则方程式对超凡规则部分有效，结界出现可渗透裂隙，但裂隙另一侧的认知扭曲立即侵入林恩意识，造成短暂定向障碍。
- 若林恩在异常中心门外选择绕行而非正面突破，则发现收容中心后方存在排水渠暗道，暗道内有被排放的实验残液，残液中检测到羽毛笔反噬的精神残留。
- 若林恩命令地狱凝视（17）附着于异常中心外围巡逻者身上，则凝视反噬加速，巡逻者在无意识中将林恩引向002室方向，但路径记忆在到达后自动归零。
- 若林恩在蓝星侧与白逸建立实时通讯，则白逸在考核中因通讯分心失守，被异体黏液灌入口腔，机械保护装置提前触发，银白长剑从非标准出口刺出，考核评估转为争议判定。
- 若林恩尝试用神之方程式为白逸远程合成辅助药剂，则跨界传输在B13通道中产生不可预测的物质衰变，药剂抵达时已变质为剧毒，白逸被迫在考核中硬抗毒性继续战斗。
- 若白逸在考核中主动向灵媒透露自己体内玻璃瓶封着林恩的血肉，则灵媒对跨界媒介的评估等级上调，总局以"关键跨界媒介"身份介入考核，触发变形条件。
- 若白逸拒绝使用机械保护装置而选择纯肉身硬抗，则异体口器肉管穿透其腹部，内脏战争被迫升级为对外联合战线，心脏与双肺第一次停火协同泵血，白逸以重伤换考核通过。
- 若白逸在末轮对战护士异化怪物时放弃古拉丁驱魔咒改用林恩曾演示过的基础符文，则圣火未烧穿自身，异体被正确净化，考核结果当场判定为通过，但灵媒对其符文来源产生追查兴趣。
- 若林恩在异常中心门外遇到黑弦月，则黑弦月以"羽毛笔反噬的第一批受害者"身份提供内部通行暗号，但暗号本身带有认知污染的印记，林恩每使用一次暗号便丧失一段短期记忆。
- 若林恩暂不进入异常中心而优先修复咒瞳，则神之方程式的首次实验目标转为咒瞳碎片，修复过程触发碎片中残留的反噬意识，林恩在意识空间中与羽毛笔的投影对峙，事件转入特殊遭遇线。
- 若林恩试图将神之方程式的图纸公式与自身已有的炼金知识体系合并推演，则两套体系在底层逻辑上产生不可调和的冲突，林恩必须在放弃一方或承受双重反噬之间做出选择。
- 若林恩在蓝星侧考核期间通过普通手段完成自身调查，则蓝星线全程不交汇，白逸考核结果在无人知晓林恩关联的情况下独立判定，两地信息差在后续事件中集中爆发。
- 若林恩利用地狱凝视（17）在异常中心外围制造大范围恐慌驱散人群，则收容中心内部异常体因外部恐惧刺激而集体躁动，封锁线压力骤增，林恩反而更难接近002室。
- 若林恩选择以最小干预方式仅观察异常中心外围，则发现收容中心内部已有其他调查者先行潜入，该调查者留下的痕迹指向羽毛笔反噬之外的第三势力，事件因果链被重新排列。
- 若白逸考核失败但拒绝总局收编安排，则以普通学生身份离开道场，体内内脏战争进入慢性消耗期，林恩在数月后才通过间接渠道得知其身体状况，狩猎者候选线彻底关闭。
- 若林恩在异常中心调查期间地狱凝视（17）突然失控，则凝视自主锁定收容中心内部最强异常体，两者视线交汇产生空间扭曲，002室门牌在扭曲中短暂消失又重新出现，羽毛笔的反噬节奏被打乱。
