# E384·梦境岁月与衰老·if线

- 若林恩在她的初舞台夜主动假装陌生观众只买一束花而不露脸，则舞台线延续但人设偏「无名观众赠花」浪漫桥段，认领场景后移到私人后台，信任累积远慢。
- 若林恩在梦境中预先宣告「我们以后一定会再见」并塞给她一枚刻字金戒，则她生日确立、信物生效，后续 E385 哨声响起时她不会只是「寻找」而是以婚约认知来寻找。
- 若林恩决定她以普通速度衰老而非停在十八岁，则牧场线朝「她与他同老」走向收束，梦境终局变成双方并卧床前守望，精神损耗显著更低但痕迹清空。
- 若林恩在她惊梦一次之后立刻施用医械检查并用药压睡，则她醒了再睡、睡了再醒，梦境人设朝「药控伴侣」劣化，劣化倾向被系统记为「药物信任」。
- 若林恩在老人人偶店一幕主动亮出自己真实身份，则老人落泪但随即咬破手指在人偶身上留下一道血字，梦境被植入一道「未解之谜」，后续表层惊醒时她也带着这句血字。
- 若林恩在她梦境跌倒时未及时贴近安抚而改在远处观察，则她连续三日不曾继续跳舞，舞台生涯于梦境内中辍，「舞者」特质被剪掉。
- 若林恩在她失语阶段强行以心声连珠灌输大量感情断言，则她识语速度极慢且心智曲线扭曲，苏醒后把他完全当作塑造者而非伴侣，连结性质变形。
- 若林恩在她生日那一天接受成为她法定监护人的设定，则她在新大陆得到「家属」身份，但名字从「小拇指联系」改写为「家属依赖」，亲密定位变形。
- 若林恩单方面跳过婚礼/告白桥段直接过渡到老来伴侣，则她对「他为什么在这里」反复有疑，梦境惊醒的频率被显著提高，深海侵蚀同步加剧。
- 若林恩在她醒来之后递出他亲手写的成长日记，则她按着熟悉的字迹读完一页再一页，把日记当作信物随身带着走，识别联系快于原版。
- 若林恩在她失语康复期改用家中草药+灵能强灌温柔药效，则她语言能力恢复但嘴巴微微失味，梦境标记增加一条「微药感」。
- 若林恩设定雪莉在梦境没有再婚而是终生陪伴女主人，则她的生活里多一位不断提醒「真实」与「假象」的声音，惊醒时点较正常更早。
- 若林恩决定让小狗在梦境中胎死腹中而非健康繁殖，则小狗生下幼崽的回忆场景被替换为「他陪她埋了一只枯萎的小生命」，忧愁种子被埋得更深。
- 若林恩在牧场衰老期反向给她换上新生保健身体以延续陪伴，则岁月流转出现「异龄夫妻」错位，梦境终局变形。
- 若林恩在她昏倒送医之后用血检强行探测她DNA，则梦境立刻「卡顿」半日，她醒来后忘记了「他为什么在这里」，路径被动终结。
- 若林恩在她失语期反向注入一段「他曾被关进黑堡地下」HUD场景，则她以切割视角意识到他也是被人伤过的人，连接从「救援者」升格为「同命人」。
