# E797·我一定会等你的啊·if线

- 若林恩在大君短暂清醒时主动先问候他而非急问原初身体和紫罗兰旧日，则大君在清醒的最后几分钟里被当成「人」而非「问题」对待，他离开核心时允许自己轻叹一声。
- 若林恩在画家以奈奈子身份抵达时主动叫出她的名字而非只是认出她，则那枚戒指第一次被人真正接住，画家能带着一句被念到名字的自己进入终焉。
- 若林恩在被画家束缚在戒指与终焉之间时主动不反抗也不顺从，只在心底说一句「我记得你」，则画家交付终焉时的最后一刻有了一线被记住的余地。
- 若林恩在大君承认自己已经成为终焉一部分时主动接下「那你还是你」而非「你已经不是了」，则大君在离开核心前多了一份尊严，他此后每次被提及都能带着这一部分。
- 若林恩在画家拜托大君吞噬自己时主动握住她手腕而非夺下来，则她的手在他掌心留下他留给她的最后温度，她进入终焉时不再是孤身。
- 若林恩在大君与画家在黑火中共同燃烧前主动对他们说「你们都会被我记住」而非任何告别语，则他们的燃烧有了被见证者的名额，这座核心从此永远替他们记得。
- 若林恩在被推出核心的瞬间主动握住那一枚戒指而不是任它掉落，则那枚戒指成为他左手心里永远能摸到的一件信物，他在其后任何怀疑自己时都能摸一下。
- 若林恩在左左抵达终焉废墟时主动抬头先看到她再抬起头看其他，则她成为他第一眼见到的活人，她今后每次想起那一刻都会先心里一暖。
- 若林恩在旧日同伴、黑夜城、雪谷融合的重建图景中主动选择保留某个无名的角落而非全部重塑，则他今后偶尔能去那角落安静，那角落里仍然没有人干扰他。
- 若林恩在左左因为空置权柄追来时主动先走一步迎上她而不是站在原地，则她在奔跑的尽头被接住而不是撞进他怀里，这一先退一步让她从此更踏实。
- 若林恩在终焉废墟的烟火第一次绽放时主动向左左介绍这第一朵而非任她自己看，则那朵花被她命名为「我们那一朵」，此后每个烟花都以此为准。
- 若林恩在最后回返途中主动让左左先问自己一个最想知道的问题而不着急答复，则她能在一长段等待后慢慢问出那个压了许久的话，他也终于能听到真正想问的。
- 若林恩在权柄转移的最终一刻主动让左左感受一下自己心脏而非立即归还，则她今后每次想起这份权柄都会同时想起他心跳的节奏。
- 若林恩在新秩序结构刚开始建造时主动画出一座小小的桥而非只着重殿堂，则那座桥成为林恩与左左之间的路径，他们从此能以最少的力气走到对方身边。
- 若林恩在林恩真正回返那一瞬主动把自己第一句完整的话留给左左而非对任何其他先打招呼，则那句话会成为他们此后每次最艰难时的那盏灯。
- 若林恩在左左拼命告诉自己「这次是真的」时主动用力点头代替任何语言，则那一颗头颅的起伏成为她这辈子被肯定得最用力的一次，她这辈子都不再怀疑。
- 若林恩在最终相拥之前主动先把身上的尘与火都清理干净再抱她，则他们的拥抱第一次没有一丝污染，她后来想起这个拥抱会记得味道是干净的。
- 若林恩在左左睡觉时主动替她盖好一层薄被而不是任她伏在桌边睡去，则她此后每次被他照顾到都会先想起那一次薄被的温度，她学会了被照顾也可以。
