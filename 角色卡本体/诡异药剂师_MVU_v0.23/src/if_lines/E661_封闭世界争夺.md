# E661·封闭世界争夺·if线

- 若林恩在河畔对外界骚动有无意识的轻颤指尖，则银色幻想发现的瞬间回头扑回他身边，狱卒奇袭的窗口被推迟一拍，自缚天使的跪求多十息缓冲。
- 若林恩在自缚天使跪地那一刻发出一丝轻不可闻的鼻息，则银色幻想紧绷的神经再多一重动摇，她手中剑落地的角度改变，「谁也休想害他」的语气添一分犹豫。
- 若林恩在小小哭喊时无意识偏了一下头，则小小的母亲再也按不住她、她冲出去三步才被母树拦下，全场注目的焦点偏移半息，狱卒奇袭的出招更顺。
- 若林恩在封闭世界破裂时掌心渗出一缕余火蔓延到地面，则银色幻想回头时第一时间注意到的是他而非狱卒，奇袭被她在出剑前就以肉身挡下，「谁也休想害他」的台词不出口。
- 若林恩在林蒙携沉眠者急报入场时睫毛微动，则林蒙的「无论如何都要把他带走」被他说得更缓，他主动想给黑夜城多十秒缓冲，但狱卒中被渗透的那几名反而提前出手。
- 若林恩在自缚天使说他「孤军奋战」时睫毛再次颤动，则银色幻想回头捕捉到这个信号，她在自缚天使跪求未完时主动开口「他听见了」，事件转折为协商轨道。
- 若林恩在一边昏迷一边体内余火忽然暴燃一次，则银色幻想当场转身扑回他身边压火，奇袭狱卒抢到林恩身上时遇上真正的第一波抵抗，但他们撕到的只是空床。
- 若林恩在被奇袭瞬间因疼痛而无意识反手抓住自己衣物下摆，则他身体在众目之下偏移一寸，那把刺向他的兵器仅擦伤而非贯穿他的胸口，他被抢到狱卒手中时仍保有一丝气息锁在屏障内。
- 若林恩昏迷期的呼吸节奏与某个特定的腐化者相同步，则该腐化者认出某种气息后被吓得立刻放弃奇袭，「五名腐化狱卒」的暴露名单上少一人。
- 若林恩在自缚天使当众跪地时无意识把腿蜷了一下，则场边主母第一个心碎号哭出声，整个黑夜城阵营情绪瞬间被点燃，混战提前爆发但失去林蒙单膝而跪的和解机会。
- 若林恩在封闭世界被撬动瞬间睫毛下渗出一滴血泪，则银色幻想当场彻底爆裂，她提剑斩出的不再是横断苍穹而是把整个世界纵向斩成两半，「封闭世界」与「外界」的边界被劈开。
- 若林恩在昏迷里指尖勾到了银色幻想放在床沿的某件物品（梳子或衣角），则她在扑回时只迟了半息，狱卒中打头那一位抓到的只是他一只脚，林恩被拽醒的可能出现在 E662。
- 若林恩在主母放声劝银色幻想「让我们一起努力」时指尖悄然下压，则主母同步捕捉到他的意愿，她在双方爆发奇袭战前主动把小小递给母树护住，后续少一分家庭悲剧。
- 若林恩昏迷期无意识胸口起伏与周围的余火涟漪同步，则他成为整个封闭世界法则的节奏中心，狱卒奇袭靠近时空间本身就把他们往外推了一寸。
- 若林恩昏迷期体内万物亲和波动自发激活，则那枚尚未被薅的万物神格在画家法师塔里同时一颤，画家遥遥感知到他此刻的危机，为 E662 的救援路径多一条潜在伏线。
- 若林恩昏迷中皮肤下浮现金色神疆的纹路一闪，则抓住他的奇袭狱卒第一时间抓不稳、自己的手反而被灼伤，他在林恩身上留下的腐化痕迹被反噬打断，「紫黑痕迹」暴露提早。
- 若林恩在封闭世界塌陷时无意识从口中发出极轻的一声鼻音，则银色幻想辨认出音调是在唤她的旧代号「机械」，她首次在他人面前耳尖一动，对奇袭者出剑时多一分咆哮。
- 若林恩在混战中因疼痛而无意识咳出一口残血，则血液落在河畔草地上晕开一圈极淡的金色，康斯坦丁认出那是初诞者血脉的表征，「暗影神格挡下林蒙」的决心再坚定。
- 若林恩昏迷期指尖不经意地碰到三叉戟的烙印，则三叉戟在主宇宙另一端微微一亮，某个狱中渡鸦坟场多一道共鸣，「还会回来」的信念被某个未知存在接收。
- 若林恩昏迷期面色忽然祥和一线，则自缚天使跪求时声音更颤，「让大家一起救他」的措辞里多了「他不应该这样走」的笃定，狱卒阵营立场动摇半寸。
- 若林恩昏迷期左手突然自发在空中写下半行符文，则人偶家认出那是某种「我同意」的信号，她在 E667 泰坦突破期间的祷告方向改变，咒术锁定的目标从「他必定醒来」换成「他陪你赴死」。
- 若林恩昏迷期体内某处旧疤忽然发烫他在褶皱间哼了一声，则喵喵（若在场监听）第一个听出他在忍痛，她对林蒙的「信仰变质」判断在狱卒集团里提前掀起一次小风浪。
- 若林恩昏迷期因余火在体内烧灼而悄然颤了一下指尖，则银色幻想再度回神时选择把所有人都斩出封闭世界连同黑夜城一方，事件转入变形收束，E662 刺杀戏码在完全孤立舞台上展开。
- 若林恩昏迷期嘴角无意识牵动了一下像是微笑，则小小挣脱母亲冲出去时嘴里喊出的不是「林恩哥哥」而是「渡鸦哥哥」，那个称谓在狱卒阵营里掀起第二波浪，林蒙的鬼现身时机被推迟。
