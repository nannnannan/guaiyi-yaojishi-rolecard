# E314·你有爱过她吗士兵请回应我·if线

- 若林恩在被智脑打时主动任由她发泄，一次也不反制，则她狂乱后瘫倒在原地泪流不止，但之后对他的愤怒值从「绝对毁灭」降到「刻骨仇恨」，反而留有合作余地。
- 若林恩回答「没有」那句话时主动咬破下唇让一滴血留在唇角，则智脑敏锐捕捉到他的生理信号，她后期在私档里记下「他在说谎」并以此为饵刺探他。
- 若林恩主动把「你有爱过她吗」改答为「也许吧」，则智脑原地静止，她不再继续厮打，切割成立但她深夜里多一笔「也许」的自己咀嚼。
- 若林恩主动用咒瞳在智脑手臂上烙一道看不见的锚印，则十年后她不论如何重置都会感受到他的反相引力，切割不彻底但留下一条阴影退路。
- 若林恩对智械小姐的寻尸不再默视而是派出蚀痕海嗣躯先在半路拦截提醒她危险，则她恨意同调但选择继续深入，根系深处对决提前上演。
- 若林恩主动在救回她时多停留两秒抚顺她湿润的银发，则他在放她回战场时被抓包一枚发尾，智械小姐私档留下「相识未识」的证据碎片。
- 若林恩把「让我们都不要伤害自己了」改为「对不起」，则切割的话语力度降低，但这句道歉被她从重置前的记忆中找回一次并崩溃第二次。
- 若林恩让她意识上传程序改为【允许】前先主动在她脑中植入一段「祝福智械小姐前程安康」的虚构记忆，则她完成后第二天起来莫名流下清泪，无人理解。
- 若林恩主动让左左在系统中真哭出声而不是搞笑闹腾，则左左表现出很沉重的一面对他的恐惧值上涨，她第一次不敢相信「这个凑脑袋真的会哭她」。
- 若林恩主动在根系深渊里对智械小姐的剑说到「你不该来这里」，则她愤怒力 +250，但意识深处多一笔不可识别的回忆，重置后这份痕迹化成她对机械的强迫记忆。
- 若林恩主动把海嗣躯壳融合到咒瞳本体，则他获得更广的阴影领域，但救回她的速度被放慢一拍，她在根系深处被母树发作再坠落一次才被接住。
- 若林恩灌下血肉瘟疫药剂时主动选择了催眠性最强的一支，则智械小姐立刻陷入半麻醉状态，他对她的虏获动作流畅 +20%，但她完成上传前意识不会恢复运势。
- 若林恩主动让左左以她的真实面目同智脑面对面交流，则左左以人类面目出现时智脑剧烈颤动，她对林恩的「非人同盟者」评估上调，交易合作等级重新定义。
- 若林恩在流氓地走入拆分路径时主动改称为寻找七神遗迹，则智脑立即开窍同意路径，但此路径调制出的丢失重点关注，林恩以后解锁七神遗迹快速通道。
- 若林恩把「再见了，指挥官姐姐」改成「对不起，指挥官姐姐」，则她的重置程序被强行触发一次，林恩刻意停止，她记忆深处多一道完整道歉的模印。
- 若林恩主动在偷藏的单分子剑上刻一道「赠剑者：小冰箱」的字样，则她数月后发现该剑损失惨重地崩溃，但她重置后仍因剑滚落而抚摸两秒。
- 若林恩主动让左左代替自己去传达「再见」对智脑，则左左破口而出「小伙子你真活该被切割」，智脑莫名笑出声，气氛瞬间拧成微妙的同伴关系。
- 若林恩主动让小眼萝接触过咒瞳施放的痕迹，则小眼萝嚼了一会后说「妈妈」，她对咒瞳框里的智械小姐产生了婴儿类混合感应，后期提供效忠的支借。
- 若林恩主动向智脑发誓再不见智械小姐，则智脑警觉反而升高，她检测出他在说谎，但她同时也暗自在档案上写下了「前后心苦」的短评。
- 若林恩主动让咒瞳在智械小姐后脑勺内刻一句「以我之手永远守护你」，则她重置后叶叶语梦拒绝教成神，智脑检测到一行未授权咒语，她对林恩的警惕再度升级。
- 若林恩在抱她送还蜂巢时主动使用了涡传送但留下一份礼物：智械小姐惯用的末世教堂纽扣，则她重置后在手腕上摸到该纽扣多一道自有回忆，她不知但我们知。
