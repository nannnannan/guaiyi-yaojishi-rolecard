# E483·以太吞噬学者与将军交易·if线

- 若林恩事先把一根灵能监听钉偷偷塞进中枢网道，则他能在外场实时听到整段对峙，事件结束后这根钉被以太识别，林恩首次进入原生神祇的「曾被盯上」名单。
- 若林恩让智脑用叠音反向接进中枢警报频道，则他能借智脑的神经听完整段对峙，但智脑的叠音里从此多出一段「将军-以太」关键词应激反应。
- 若林恩通过分身侧向巫神发送「别靠近中枢」的劝阻信号，则巫神会停在外围不被卷入，但后续她对这位将军的判断只能靠林恩二手转述。
- 若林恩在事件开始时就反向向黑夜城发出「将军-以太勾结了」的完整周报，则这份周报会被巫神与夏娃立刻消化成战场传令、机械神教边缘压力立刻上升一档。
- 若林恩让夜医在机械神教边缘某区块提前布置疫医腐解仪式，则事件结束后将军调兵去追银色幻想时会先得清点这片仪式，林恩多获得三十分钟窗口。
- 若林恩用咒瞳反向推断「将军-以太交易」的可能筹码清单，则他能猜到报酬含「追银发少女＋一个兄弟」，后续所有防御布局都以这份清单为基线。
- 若林恩选择假装这场中枢剧变没发生、完全按原计划推进救巨像与汇合线，则他不会得知「原子革命停滞与熔炉令」的关键时间表，后续大局判断就永远慢半拍。
- 若林恩用一根灵魂丝线一端挂在中枢外网道出口，则他能监测到学者被吞完后那17%以太分身跑去哪里，他提前知道以太下一个寄生目标。
- 若林恩利用中枢对峙的三十秒混乱在机械神教边区反向多点引发警报，则中枢调度注意力会被分割，原子革命复原节奏会被他打乱一拍。
- 若林恩让左左在意识空间对中枢网络悄悄吐一个咒，则中枢会浮起零星故障，将军会怀疑是以太下手而不是林恩，两人关系被这一笔擦得更加扭曲。
- 若林恩让智脑反向外查这名「赤裸银发男人」的来源档案，则智脑的研究线会多一条起步，后续入侵以太本体时会以此为入口。
- 若林恩在事件结束后立刻派遣一支夜医袭击中枢，则「将军-以太」协议刚拟定就被迫中断，但中枢也会立刻完成机械化改造、下一次袭击难度十倍。
- 若林恩施放血肉灾变制造一片数据瘟疫撒在中枢外墙，则以太的流体会被暂时封在中枢内一段时间，原子革命复原期的中枢反而更脆弱一次。
- 若林恩让光宴从深潜状态接入中枢扫描频道，则她会第一时间知道「以太诞生了」，但她同时也会被迫见到自己被认成父亲遗产那种屈辱。
- 若林恩让银色幻想在深潜侧同步反向读取学者的废墟，则她会立刻知道自己父亲部分权能落入以太手中，她的愤怒会比原事件时间提前一拍。
- 若林恩用三叉戟反向向中枢网道打一道灵能记下「将军-以太」的关键词，则这两个名字会被永久烙印进咒纹网、后续所有涉及这两方的事件都能直接索引。
- 若林恩首次当面向黑弦月老师汇报这次交易，则老师会勾起长者那一瞬的表情，这件事会成为林恩后续解读老师情绪的重要教材。
- 若林恩在事件结束后主动飞往中枢外围，则他会直接接住将军和以太交易后续协调现场，但也将首次直面原子革命之外最大量的机神威胁、行动就被迫升级。
- 若林恩把这起事件画面剪进自己梦镜每晚温习一遍，则他会一直把「他们下一步在追什么」这个问题压在心里，每一次出手都因此在预期内偏一档。
- 若林恩选择不干预、不派活、只安静备战原子革命的下半场，则事件按原剧本走，但林恩会错过中原乱局的窗口机会、后续突破中枢时必须正面硬碰。
- 若林恩派巫神触手反向摸一下学者最后散射出的子弹路径，则巫神会首次碰到中枢火力、但被立即阻挡，她的灵能力会被中枢评价为「不可越过上半层」。
- 若林恩让银色幻想在事件结束后立刻做出反制预案，则她的反制会包含「召集九十八光宴残余」，原子革命复原阶段会立刻出现一道无法估量的额外变量。
- 若林恩向以太反向发一条完全超规矩的「勾搭信息」邀请他弃将军转向林恩，则以太会看一眼这条信息并把它丢在后排、但「林恩曾勾搭过我」这条记录会被他留作后续筹码。
- 若林恩在事件结束后向整个黑夜城频道发出裸闪「将军已见以太」，则机械神教的传说空前变形、全员开始改口谈「原生神祇并非伙伴」，机神教内斗第一次浮出。
