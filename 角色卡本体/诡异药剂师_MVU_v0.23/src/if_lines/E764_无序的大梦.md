# E764·无序的大梦·if线

- 若林恩在无序大梦刚展开时主动抓住第一片飘过的梦片而不是任其掠过，则他从那一片开始建立稳定的方向感，但失去其他大量的自由漂流机会。
- 若林恩隔着梦境对羽毛笔喊一句「请替我看着黑夜城」，则羽毛笔在时间外把自身本已有限的精力一部分顾向城本体，E765 时它的衰退更快。
- 若林恩主动让黑火把某一片反复出现的「家」主题梦片绕在他手腕，则那片成为他在无序大梦中永远的家锚，无论身体漂到何处都能瞬间回家。
- 若林恩在一片梦片里主动接住一个下坠的小小影像，则那影像在他掌心中消散前朝他微笑一次，那个微笑以后作为稳定内核跟着他的黑火。
- 若林恩选择把无序潮汐反向引导而不是与之对抗，则他学会一种「随波而走」的梦境行进方式，但自身意识被潮汐带动的痕迹更深。
- 若林恩主动让某片梦片按照他自己期望的方式重组，则那片梦片成为一个稳定的秩序示例，但此片刻模板耗费了他的精神力储备。
- 若林恩让羽毛笔的命运光线第一次主动接到他时就跟着往前走，则他没有花时间犹豫，「沿光线」选项在响应中变得自然为唯一。
- 若林恩在无序大梦中某片梦片里顺势坐下来喝了一杯虚构的茶，则他得到片刻虚幻的安宁，但那份安宁的现实感反而被削弱。
- 若林恩主动在无序之河边停步而不是立刻跳入，则他观察到河流中偶尔浮起的泡沫，其中某些泡沫印着可识别的旧日坐标。
- 若林恩把轮回神王火焰印在黑河水面下看一眼，则黑河对那火焰做出一层不灭的回声，林恩在黑河行进中多一根可摸到的火脉。
- 若林恩主动让无序拆解某一段他刻意不想记住的过去，则那段过去在梦境中消失，但相应地在现实中他对此的记忆也变得模糊。
- 若林恩选择在梦境中照一面虚假镜子审视自己的面容，则他看到一张既疲惫又坚定的脸，那张脸从此成为他在梦境里的自我标识。
- 若林恩在某一时刻对梦境发出的某一呼唤回应了一声「我是林恩」，则他自我身份的锚定在那一刻被牢牢打实，日后被梦境拆解的可能性降低。
- 若林恩主动把掌心探入无序之河捞取，则他捞起一段飘过的碎片并将其私自保存，但河水在他掌心烙下一个永远不会消失的印记。
- 若林恩在某片梦片中向一个过客打招呼，则那过客回以一句陌生人问候，那一句话在林恩记忆里留下一根不属于任何故人的新线。
- 若林恩选择让梦境某段场所变成一座完整坟墓而非旧日生活场景，则他以自己而非哀悼们得以往返的方式，更接近接受末日真相。
- 若林恩主动让黑火在河中发光而不散,则他成为无序河中的一只可见火虫，被羽毛笔命运线直接锁定为救援目标。
- 若林恩让自己的意识在梦境中退后一步观看自身漂过，则他首次获得一种超然的第三视角，未来在现实中解决复杂问题时多一副工具。
- 若林恩隔着梦境朝某片终将消失的梦片挥手作别，则那片梦片在消失前折返一缕光回他掌心,那一缕光被他日后用来点亮他人的梦。
- 若林恩主动让梦境对他展示「如果他从未成为药剂师」的另一种人生，则他得到一份短暂的想象满足，但现实自我这一份轨迹更显得不可动摇。
- 若林恩主动把他的王权烙印在梦境的黑河中洗一洗，则烙印在无序河水中被暂时模糊但得以净化部分污痕，他日后进入现实时黑火的纯净度提升。
- 若林恩让羽毛笔的命运线有时主动松一松而不是紧紧拉，则他能更自由地体验梦片的内容，但相应也增加了在黑河迷路的时间风险。
- 若林恩在某片梦片中接受一个已经不在了的死者的道歉，则死者影像得以安息于消失，林恩心中有一份歉疚的负担因此减轻。
- 若林恩主动在梦境里建一座与黑夜城完全一样的小城作为锚，则那座小城成为他日后回忆的真实坐标之一，但建它耗费的精神力比较大。
