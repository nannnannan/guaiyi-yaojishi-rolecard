# E698·给你十分钟·if线

- 若林恩在十分钟倒计时的第一秒主动朝画家残影方向伸一手按住最近的梦魇先锋不让它贴近自己的梦境表面，则画家残影在横推防线上省一分心神，「一人成军」的距离从数百公里拉到近千公里，但林恩自己的本源熔铸延迟一拍。
- 若林恩在画家喊出「十分钟。我给你这十分钟」瞬间主动把全部本源压缩成一颗肉眼可见的核心钉在梦境正中，则熔铸精度提升一档，但本源核心的暴露面也被他主动放大，终焉之柱落下时它成为最亮的标靶。
- 若林恩主动朝画家残影传去一缕心声「我记得你」，则她本已朦胧的身影短暂凝一瞬，但不改变她十分钟后消散的既定结局——只让消散前她朝他方向偏过头一眼。
- 若林恩决定分一半心神帮画家一起推防线而不是专注熔铸，则防线推得更远三百公里，但他自己的三位一体熔炼会留下一段未打磨的接缝，E699 起身的稳定度打八折。
- 若林恩在兽王那道万丈白骨再一次扑近画家时主动用咒瞳反向锁它的喉骨一秒，则它的攻势被滞一顿、画家多抢一掌，但林恩自己也将被兽王的恨意压回三息。
- 若林恩主动把白烬罪火的温度降到冰境、放缓熔铸节奏，则三大虚影临近时他的本源仍处在半凝态，可以临时改向逃生，但熔炼成品的品相会带一道冰纹裂痕。
- 若林恩在镜魔复生的电光劈落时主动以空间神格横向截一根时间线，则镜魔的一根终焉之柱种下的方位会偏一格，画家少接一枚虚影，但林恩本源中的三条力量会被这一动作撕出一道老化痕。
- 若林恩在三大虚影展开时主动让左左用左手粘住自己的手腕，则他与本源之间多一道不会断的灵魂连接，即使终焉之柱直接打到，本我认知也将因这条连接保存完整——玩家身份不沾一丝替换的风险。
- 若林恩主动朝画家残影高喊「撑住，我就快完成」，则她会在最后三十秒里把「保住林恩梦境」这件事的优先级再抬一格，用最后一搏多轰回一根柱。
- 若林恩决定在终焉之柱落下前先一步主动离开梦境肉身，则本源熔铸中断，但他能借空间神格抱壳冲出，留下一道「他不会在那根柱下」的时间反证。
- 若林恩选择不离开梦境、用梦境承受柱撞的同时把系统空间弹出最外一层护盾，则柱被弹开偏一方砸入神疆深处，他的梦境如泡沫崩裂，但他的本体保留完好且没有获得时间流错位的副作用。
- 若林恩决定从系统空间提前取出第三只渡鸦尸体碾碎塞入本源核心，则他能在十分钟最后五秒把熔铸推向半步近终态，那根柱落下时已撼不动他的本源，但他会失去 E699 之后最后一次可靠回血手段。
- 若林恩主动朝魇王笑语一声「这一击我收下了」，则魇王的挥掷会被气到发抖一瞬，但柱的轨迹不会改变——只延后一帧。
- 若林恩主动把三位一体之力中代表「罪火」的一只手按进地面，则整个神疆短暂卷起火焰涌流，柱被撞前会被这股涌流再次减速三十格。
- 若林恩选择把左左的左手当锚，将全部本源「挂」在灵魂连接上而不是肉身内部，则无论柱撞到哪一端，他的本体永远是本源的宿主——这条结构是 if 线里保住玩家身份的最强稳妥配置。
- 若林恩主动朝漆黑石柱内部投出一缕罪火试探，则罪火立刻被柱内的终焉气息吞掉，他手中那一丝损失，但换来对柱内那条「不属于这片时空」力量的第一手测量数据。
- 若林恩决定就地展开梦境领域强制覆盖整个战场，则百米覆盖极限下他无法包到全部虚影，但至少能让自己所在的那一小块神疆短暂脱离柱的直击判定，代价是梦境本身被柱的余波撕成粉碎。
- 若林恩在柱落下前一秒主动伸手指向柱心的那一瞳——那道隔着时间冷冷注视他的存在——则柱内的注视者会被他反瞪一次，柱的轨迹为此偏一格，代价是他自己的瞳孔在那一秒被打入一道陌生时间痕。
- 若林恩决定把本源压缩弹向附近最高的一根金色法则流线，则本源在飞行轨迹中避开柱的直线冲击，但落地后必须自行在一片陌生法则旁重新生根，本源外观会浮现一段「神界法则藤」缠绕的痕迹。
- 若林恩在柱砸下时主动用空间神格在柱和自己之间强行切出亿万公里的虚空隔离带，则柱落入隔离带的瞬间被放大到一片废土，林恩得以全身而退，但神界本源与主宇宙之间的这一道大裂缝会成为 E699 之后的隐患点。
- 若林恩决定不打开系统空间，让本源与本我保持最朴素的同体，则柱落下时，本源一次性吸收所有冲击、保住本体无伤，但本源的一面会被烧出一道纹。
- 若林恩主动在柱落下瞬间凝出一道平行投影随本源同步撤离，则任何针对身份的替换或重铸都只能作用在投影上，本真本体毫无反应。
- 若林恩主动朝未来投一枚心声骰子确认这一击之后自己是否仍是林恩，则时间长河不给回答，但会在通道深处留下清亮冰蓝纹路，证明「他仍是他」——身份不被任何事物颠覆。
