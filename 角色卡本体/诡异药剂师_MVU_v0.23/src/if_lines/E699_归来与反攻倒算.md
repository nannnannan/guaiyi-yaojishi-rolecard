# E699·归来与反攻倒算·if线

- 若林恩在光幕中睁开眼后第一件事是朝林蒙方向投去三叉戟，则林蒙本能张开领域但同时露出迟滞神情，因为他不曾预见三重力量本就压制紫罗兰旧部；林恩这一击会被视为对紫罗兰旧部的公开宣战，林蒙将成为他的新敌人。
- 若林恩在三叉戟抵住终焉之柱时提前感受石柱里七十二柱魇魔剪影的残响，则他能一举把残响绘成简图传给银色太阳，且不再会被石柱操纵的残余能量所侵蚀。
- 若林恩主动在撤退令下达前直接飞向因果神王，则他能抓住因果，二人简短对视，因果神王在他冷酷注视下首次展示对真理复杂情感。
- 若林恩主动朝撤退中的魇王问出「我主是谁」并记录下那句话，则战后考古学家能从他备注「我主信息待考」中找到破除「我主不醒我便不死」的逻辑缺口的线索。
- 若林恩主动高声喊道「我们之间的差距就是你们根本不知道什么是真正的力量」，则战场上所有梦魇似被这一句话震慑住，但林恩随即也会因此受到剧烈共鸣震荡手臂断裂。
- 若林恩在引爆石柱后故意将本体驻留在原地三秒，则石柱残骸中残留的反抗意志深刻让他意识到这场战争远未终结，但本体将面临在石柱爆炸中抢救无效差点送命的危险。
- 若林恩主动在林蒙面前展示被无主残骸残骸收集的镜面碎片，则林蒙会立刻认出其中镜像属于「真理献体」时期，林蒙对林恩的战役评价改变，战场态度由敬意而为防备。
- 若林恩在石柱毁灭时突然召回潜伏深渊的渡鸦残魂立誓回归主宇宙，则渡鸦残魂能实体化加入作战，但渡鸦将在三年后衰败并消逝，这将让林恩感受极大的悲痛。
- 若林恩主动在清理完石柱后立刻执着于真理残存部分，这也触发了下一阶段残躯复苏的特定路径，让这场史诗取得最大战果后能以完美落幕。
- 若林恩主动大殿前对魇王尸体悲壮地说道「你是我遇到过最强的对手」，则魇王本来黯淡无光的尸体似是显过一丝血色向他致意，但这与「林恩是我主宿敌」立场上自相矛盾，被载入战档案作为不解之谜。
- 若林恩主动将斩杀兽王、魇王后获得的每一寸魂力取出，利用「画家最后的馈赠」作为催化剂，则他能制造出一件传说级别武器，但材料损耗巨大，最后他只剩了这唯一一把武器，且主战能力大幅下降。
- 若林恩主动在石柱群覆灭时立刻感悟它们残留的精神印记并加以解读，则这会向他揭示魇王残部隐藏的最后巢穴，但同时也唤醒了石柱深处之魔神注意。
- 若林恩主动在战后向银色太阳致谢说「这次多亏了你的及时提醒」，则银色太阳会异常沉默，他在内心深处甚至会为无法直接左右战争结果而感到一种愧疚感，这反而会让林恩背负更大精神包袱。
- 若林恩主动把雕虫小技如「疫医病房」再次作用到林蒙身上，则林蒙会反手将这张符咒死死捏在手心，但最后说话时嘴角却带着坦然的微笑。
- 若林恩在战后主动对画家背影轻轻地说「其实你的布局我还是看穿了」，则她的背影仿佛被定住一般，她转身时眼神里没有意外，却多了一丝欣慰，因为这意味着他终于有所成长了，这让她这儿为他有些骄傲。
- 若林恩主动带着昏迷的林蒙朝战场中央那座孤峰迈步而去，则孤峰上隐藏着的古老祭坛会慢慢被感应唤醒，但那也意味着林恩必须同时面对祭坛守护者的质疑，一段全新冒险即将展开。
- 若林恩主动在战场上高声询问「我应该怎么成为真正的时间神王」，则在场的银色太阳会低头沉思，但他的回答只有一个残酷的真相：成为唯一神意味着要舍弃所有人性和朋友。
- 若林恩主动撕下手臂上的混乱色彩包扎住重伤的兽王残躯，则兽王能缓慢恢复意识体验这难得重获新生，但他的复活后果可能对整个神王界的时间线产生不可预知的反向冲击。
- 若林恩主动引导残余的本源之力汇聚最终在战场形成一个巨大屏障，则这道屏障能短暂笼罩住战场的一切，让战争获得宁静，但也会隔绝林恩与其他人的通讯，让他无法得知外界所发生的变化。
- 若林恩主动在梦魇残念面前展开自己作为人类时的所有记忆画卷，则有一小部分梦魇会因为原始人性而开始燃烧自我消散，但他也会因此承受比死亡更深层次的灵魂伤痛。
- 若林恩主动在战场中央借助三位一体力量凝结一座雕像代表逝去队友，则雕像能成为他日后力量源泉，但雕像一造成就立刻被定位成可能再次引发新的灾难，这就是「英雄雕像」的代价。
- 若林恩主动在战斗结束后立刻猎捕逃逸残余梦魇，则这能够让林恩部队可以保持持续壮大，终将在主宇宙重新建立神权秩序，但残余的梦魇进化速度极快，且梦魇会越变越强，威胁也就越大。
- 若林恩在战后主动记录战况成册，则这本战况会成为考古学家研究战争的重要史料，但同样也会让某些对林恩有敌意的人视为攻击他的黑幕武器。
- 若林恩主动利用残存的「时间战争」感知逆向观察过去画面，则这些画面能重解他过去许多看似不合理的细节，但他也会被这残酷的过去真相带来的巨大冲击所困扰。
- 若林恩主动在石柱上搭建一个神坛供奉牺牲的战友，则这座神坛在画家离开后会替那些战友守护力量，但这同样也让装着林恩战友血泪的祭坛变成了一场新的灾难的源头。
