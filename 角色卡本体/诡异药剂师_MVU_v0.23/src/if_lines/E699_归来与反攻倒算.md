# E699·归来与反攻倒算·if线

- 若林恩在终焉之柱轰然贯落、光幕即将散去的最后一秒，不仅以涌动金色黄沙的三叉戟死死抵住黑柱尖端，更将刚刚熔铸完毕的至高神王本源顺着戟刃逆冲而上，则终焉之柱炸裂的碎片会被金光裹挟着倒射向梦魇大军前排，当场将数千头精锐梦魇连同三座前锋战阵一并轰成飞灰。
- 若林恩在三叉戟抵碎终焉之柱的瞬间，分出一缕神念捕捉黑柱碎片中残留的七十二柱魇魔气息并将其拓印传给银色太阳，则银色太阳也能同步看清时间终末那些魇魔的真身轮廓，后续防备时间战争的底气更足。
- 若林恩在听见魇王惊恐呢喃「最关键的一秒里有人降临」时，没有停下脚步与他多作口舌之争，而是趁着魇王心神俱裂、下达撤退令的瞬间，一步踏碎万里虚空，直接拦在无序之路的裂隙入口前挥戟横扫，则魇王连逃出神王界的机会都不会有，整条退路会被金色的死亡长虹彻底焊死。
- 若林恩在撕裂梦魇狂潮、杀向无序之路的途中，顺势将目光冷冷扫过远处吐血欲逃的因果神王，并以一记横贯苍穹的金色戟芒劈碎其半边护体法则，则因果逃往主宇宙边疆时的伤势会更加惨重，一路洒下无法掩盖的法则血迹。
- 若林恩在将魇王钉杀在虚空壁垒上、听见对方疯狂叫嚣「我主不醒我便不死」时，以三叉戟的初诞秩序之力混合自身罪火，在刺穿其眉心的同时于其灵魂本源最深处烙下一枚永不熄灭的「疫医焚魂印」，则即便魇王日后在梦境中再度复生，这枚烙印也会伴随他每一次苏醒带来深入骨髓的灼痛与虚弱。
- 若林恩在跨越无垠虚空追上力竭逃遁的兽王时，没有给它任何引爆残躯拖延时间的机会，而是以三叉戟直接贯穿其头颅，并用初诞者之力将其白骨连同散逸的兽王法则一并炼化吸收，则这股纯粹的蛮荒本源会进一步稳固他刚刚升格的神王躯壳，让他手臂上超负荷燃烧的罪火压力减轻数分。
- 若林恩在降临破碎的艾维儿行宫、面对剩余六十九根黑气蒸腾的石柱与其中半降未降的魇魔虚影时，不等时间终末的那只腐烂巨手完全探出裂隙，便主动跃上高天，以承载着主宇宙重量的三叉戟正面劈向巨手的手腕关节，则那只试图强行破界的终末巨手会被当场斩落三根腐烂指骨，在凄厉的跨时空咆哮中狼狈缩回闭合的裂隙。
- 若林恩在将三叉戟掷入地面、引爆光幕彻底轰塌全部六十九根石柱的刹那，站在漫天崩散的黑气中心向着即将闭合的终末裂隙留下一句冰冷的索命通牒，则所有盘踞在时间终末的魇魔都会在这一刻记住那道沐浴金光的修长身影，神王界内残存的腐化神灵更是当场肝胆俱裂。
