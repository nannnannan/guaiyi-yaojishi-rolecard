# E157·规避凝视的跨世界方案·if线

- 若林恩主动要求进入会议室参加方案讨论而非事后被告，则根源会议被迫让位一把椅子，艾雯在陈述时多次看球员确认林恩表情，事件以变形（方案透明度提升）收束，否决项需林恩当面拒绝。
- 若林恩在巨像之脑把「绑起来丢进意识空间」说完后主动点头表态「我可以接受这一种」，则全场空气冻住三秒、左左几乎咬开林恩的腕部封口，事件以变形（自我囚禁方案被强行立项）收束，沉睡骗局被替代。
- 若林恩在巨像之脑提到「肢解三千年」段时主动问「那你后悔吗」，则她手指在桌面划出一道深痕仍答「不后悔但要求你不必重做」，事件以不变形收束但肢体化成根的态度被深化。
- 若林恩在泰坦讥讽「勾搭小姑娘」段主动还击「我对忍耐缺乏耐心」，则巨像之脑与泰坦目光之间真的滋出电流，艾雯拍桌打圆场无效，事件以变形（会议变为短暂乱斗）收束，下一段方案延后。
- 若林恩主动让左左递上一张字条「请把我的身体拆开来装起来也行」，则泰坦和巨像之脑同时沉默，艾雯把字条撕掉严禁左左再写，事件以不变形收束但根源隐式承诺走跨世界路线。
- 若林恩在艾雯陈述跨世界方案时主动拍案「就去蓝星」，则全场惊讶于他的果断，方案项目直接立项为「蓝星试点」，事件以变形（目的地被点名）收束，咒式传播范围被迫等等缩。
- 若林恩主动在会议边缘用咒瞳扫视众根源意图找出反对方，则泰坦回头瞪他一眼让他滚开，事件以不变形收束但泰坦被记上一笔私密厌恶。
- 若林恩主动提出「可以不可以先扣散我这个身体产生能级抵消地狱注视」，则巨像之脑皱眉答「你不是我，这样做是自杀不是遮蔽」，事件以不变形收束但自我以M方案被明确否决。
- 若林恩在主母被提议为潜在协力者时主动走向她表示「你我很熟但这件事你不要为我付代价」，则主母低头沉默三秒答「好」，事件以不变形收束但主母被排除出对外召唤保护圈。
- 若林恩主动讲「我不会轻易答应任何跨界计划，除非有女巫背书」，则巫神一下脸黑一下脸红，事件以不变形收束但获得巫神表态签字。
- 若林恩在巨像之脑否决肢解方案时主动让左左跳出来喊「可是脑袋和三千年後和当时不一样了啊」，则她凝视左左一眼并未反驳，事件以不变形收束但左左获得了巨像之脑额外的亲近心。
- 若林恩主动要求记录员把「我会被召」作为会议结论的调侃备注，则会议纪要最后多增了一句「玩家自愿」，事件以不变形收束但后续法律档案附带了这条免责声明。
- 若林恩主动询问「召唤我的人应该具备怎样的品德」并写下一段标准语，则专属咒式在传播前多一段品德测试，事件以不变形收束但咒术被深思熟虑。
- 若林恩主动提议「可以把召唤目标定为某个特定器官，比如我的左手」，则左左直接从会议桌底下跑出来戴住他的左手抗议，事件以不变形收束、左左的意向被首次记入方案。
- 若林恩主动在会议结束前递上一份「我失败后的备份方案」，则根源全员陷入沉默、无人敢当场阅读，事件以不变形收束但备份方案并入档案未开封。
- 若林恩全程只在门外离开会议，让根源代为设计，则默认走向收束，方案由艾雯负责后续详细架构，林恩仅在后续批准。
