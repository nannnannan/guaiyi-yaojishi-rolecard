# E281·失落的眷者与星空之引·if线

- 若林恩在把左左支开前主动向她报备「我去海底扫一遍残肉就回来」，则左左盯住他三秒后塞给他一枚黑颅币当定位器，E282 追逐戏改为左左提前到海面接应。
- 若林恩在海床捡起第一缕克苏鲁残肉时先用咒瞳扫一遍而非随机诊断术，则【无序增殖】根源诅咒被直接锁定，但克苏鲁的呼唤提示延后五秒才浮现，他被涌动的血肉阻拦一拍。
- 若林恩在诊断出「呼唤」后第一时间掏出传讯器呼叫血衣远程核实封印缝隙，则血衣立刻明白底情，后续在 E282 广播前她会主动赶来「押阵」支援一发渡鸦翎羽。
- 若林恩决定先把海岸上的增殖残肉全部就地灼烧再深潜，则他节省了后续被追逐的数量，但机体损耗 +8%、巡航时间被压缩，E282 最后一段蓝星弧线更佳但也更短。
- 若林恩在海沟下方对艾泽法拉重生茧直接用咒瞳入侵扫描，则他能在血肉刚刚附着她脸颊的瞬间就提前出手，艾泽法拉意识保留度 +20%、灾变侵蚀 -10%。
- 若林恩在撕扯艾泽法拉出茧时不使用拟化而是冷静将她整段背起硬挣脱，则血肉追击强度 +30%、左左要替他挡一发触手，但艾泽法拉维持原体型无需后续调理。
- 若林恩拟化之后更进一步直接把她缩到能放进口袋的尺寸，则她被收进系统空间时不再散逸气息——信标失效，血肉转向锁定林恩肉体本身，事件走向变形。
- 若林恩破海冲高时抱着她在空中停一拍给她看下方沸腾的海域再往上拉，则她首次直观感受到「15%」这个数字的可怕，后续坦白环节的抗拒度 -15%。
- 若林恩在海岛落定后第一件事先修复自己折跃引擎再开口讲坏消息，则坦白被推迟十分钟、血肉攀岛进度 +10%，海岸线被多侵蚀两个层级。
- 若林恩坦白时没有拍她屁股那一记，而是握住她的手腕直视她眼睛说「我的确有私心，但你的命我不会让」，则好感度 +20 起步、左左在系统空间内监听时咬牙扭断一根栏杆。
- 若林恩把「我答应你会复活你哥哥」这段改放在坦白末尾再说，则艾泽法拉态度由「冷淡」跨两档跳到「动容」，但契约条款被她自己加上一条「不得再糊弄我」。
- 若林恩在讲克苏鲁流放故事时主动补一句「祂央求我带回地狱的那句话我至今记得」，则艾泽法拉眼眶泛红，沉睡信标阶段她主动配合呼吸节奏、血肉散逸信号更稳定。
- 若林恩敲晕她之前先低下声把 E289 视界里那三条件讲清楚，则她沉睡时情绪平静无挣扎，血肉以她为信标时的「二次拒绝」风险被压到 0%。
- 若林恩拒绝敲晕她、改让她清醒地待在系统空间作信标，则信标精度更高但艾泽法拉在 E283 全程清醒目睹星空豪赌，事件以变形（清醒信标）收束。
- 若林恩把昏迷的艾泽法拉放系统空间时口袋里多塞一枚咒瞳烙印，则后续在 E287 海嗣女王抉择时这枚烙印被点燃为「她的眼」，成为她觉醒的关键触发器。
- 若林恩在仰望星空时再多回头望一眼舰队方向再动身，则系统捕捉到他胸腔的微颤被记忆留存，成为 E285 艾雯爵士看他病历时的隐藏情绪注脚。
- 若林恩在发动升空时没有对左左留任何信息信号，则左左在海面上彻底扑空，E282 左左追到大气层时她会以更高强度暴怒、关系结算幅度上调。
- 若林恩用理智之血强化自己以应对深海肉堆，则他的灵能吸力短期 +25%，但克苏鲁残存意志在他身上留下一层隐性注视，E290 一段被加重。
- 若林恩在海面留下一组咒瞳作哨，则后续黑夜城的夜医回访时能拿到海面灾变的原始影像，E285 冰箱病房里多了一个可视档案。
- 若林恩在破空前先低声跟血肉说一句「跟我走吧，咱们回家」，则整个蓝星海域的血肉在他身后汇成一道完整的嘶鸣回响，蓝星所有幸存者都听到那一声。
