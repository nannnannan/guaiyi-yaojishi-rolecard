# E397·渡鸦残躯与细胞记忆·if线

- 若林恩在巨像之脑颤抖召光瞬间主动散出更多渡鸦气息，则她基因里的臣服会盖过理性，她跪坐在地垂下脖颈，玩家是否顺这股势推进亲昵由输入决定，幼态姿态不结算性事。
- 若林恩在她询问「这就是当年引导巨像文明的渡鸦吗」时立刻承认，则她的崇拜层级瞬间翻两档，但相似性仍只是迹象，档案标注「林恩自报同源」。
- 若林恩选择让她拟化为成年人形再接触残魂，则她的臣服本能外显度收敛，可以稳着谈吐分析古老记忆，但失去幼态姿态下那种本能反应的原始证据。
- 若林恩明确拒绝让她拟化、坚持让她以真实形态接触，则她带着「胸怀天下」的原始体型走入房间，左左会本能地朝那具温热的身躯蹭过去，玩家需另行处理三人同床的画面。
- 若林恩在读取残魂到四成时主动中断，则画面停在虚无空白之前，渡鸦气息不再震荡他的细胞，但白发身影的影像与旧日神明的嘱托一并缺失，主宇宙悬念延长。
- 若林恩让巨像细胞承载残魂但限定只由非关键器脏分担，则撕裂压力平均化，读取可推进到六成仍不触及极限，但共享精度被稀释一档。
- 若林恩选择把残魂全部塞给巨像之脑承载，则她的小身体瞬间承受超负荷、整个人颤抖蹲在原地，玩家必须立刻把她抱起来，她的幼态外形被血色血气覆盖。
- 若林恩读取到白发身影转身那一帧时主动让系统暂停，则画面定格在「三种力量并存」这个可疑节点上，玩家可以反复回放但得不到额外信息，疑问被永久悬置。
- 若林恩读到谷地残躯质问「能不能让我们离开」时选择立即回复，则影像按原作崩塌，但玩家可在崩塌前追问一句「你们是谁」，残魂会因为额外刺激而加重撕裂。
- 若林恩读取到八成时让巨像之脑破颈喂血、但拒绝吸食，则她脖颈动脉暴露在空气里，撕裂继续推进，玩家必须启动备用方案——让巨像之脑接管意识共享主机——才能免于失控。
- 若林恩咬住她脖颈吸食巨像精华，则她会被那种碰触激得颤抖，但她在动作开始瞬间就会挥拳砸向他的头侧作为警告，血液被吞咽后撕裂压力暂缓，发丝掠过他面颊。
- 若林恩在被吸食期间主动递过去一块糖让她含住代替攻击性安抚，则她含着糖嘟囔着吸食动作，不骂他「色狼」，但她颈侧的咬痕被记成林恩所有。
- 若林恩吸食巨像精华时同时让左左以触手触碰他另一只手臂分担压力，则左左会因为「共享负担」而多发一笔绑定记录，但她会在事后抱怨「凑脑袋又在两个女孩子之间搞分流」。
- 若林恩在警铃响起瞬间拒绝让巨像之脑收仪容、执意把她抱在怀里继续吸食，则她会一边骂一边扯平衣角，同时周身血气更盛，进入战斗位时嘴角还带着血。
- 若林恩主动告知她「刚才看到了什么」，则她会以幼态认真的神情记下来，并问他要不要把这段信息共享给其他核心关系人，玩家可决定名单范围。
- 若林恩选择不告诉她看到的内容、只说「你以后会知道」，则她会赌着气背过身去，但夜间会偷偷用细胞联系在他手腕上写「凑脑袋欺负我」的小字。
- 若林恩读取时让残魂画面以「记忆碎片」形式分发到喵喵和小小，则两位同伴会在夜里做相似梦境，白天复述出与林恩所见一致的片段，事件走向「共享读取验证」分支。
- 若林恩读到渡鸦残躯并未始终留在战场中央的画面时让系统标记疑点，则事件日志自动多一笔「白发身影离去原因」，后续残魂解析优先级升高。
- 若林恩主动用渡鸦气息在残魂上多打一层封印，则读取窗口缩小一半，但撕裂冲击减弱三成，玩家的细胞承载可撑过八成五的极限线。
- 若林恩在警铃响起时先让左左变回左手形态收进臂膀再站起戒备，则巨像之脑见不到左左的存在，她对「王后在哪」的疑惑在战斗结束后才爆发。
- 若林恩让残魂读取进行到八成五瞬间主动切断，则撕裂冲击在临界线被硬生生拽回，巨像之脑脖颈的伤口来不及被吸食，事后她自己舔掉血迹独自处理。
- 若林恩把「吸食巨像精华」这件事公开告知艾雯爵士，则爵士会皱眉说「你们俩的亲密行为越来越像真正的王权过渡了」，事后会单独约谈巨像之脑核实。
- 若林恩读取结束后主动抱巨像之脑回房、让她在怀里睡下，则她的幼态身体在他怀里不再颤抖，但醒来后会红着脸要求「下次不许再这样抱」。
