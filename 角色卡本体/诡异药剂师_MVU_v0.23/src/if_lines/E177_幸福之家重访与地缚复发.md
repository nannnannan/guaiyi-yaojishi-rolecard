# E177·幸福之家重访与地缚复发·if线

- 若林恩推开冷库大门前先以咒瞳扫过铁钩队列、锁定那具无面血肉人形挂位，则冷库铁链被命令单钩降下，事件以不变形收束但俘虏隔离审讯、其它食材的集体呻吟未触发。
- 若林恩在传送落地瞬间把尹依从体内拽出护在轮椅后方，则她未被古堡鬼气震慑到形容僵硬，事件以不变形收束但「爱丽丝压迫感」原场面减弱。
- 若林恩在爱丽丝扑进怀里前先单手抵住她肩、改用「先汇报游魂巷异常」起头，则拥抱延迟至汇报结束后才发生，事件以不变形收束但爱丽丝次日赌气锁菜园大门。
- 若林恩中断传送改从离魂街徒步带尹依靠近古堡，则落地广场漩涡场面消失，事件以变形（徒步抵堡）收束，沿途被外乡人目光锁定的几率上升。
- 若林恩先把当日一份诅咒清除留给爱丽丝再开口询问，则地缚复发的黑雾当着她身后散去、她的回答反而被幸福感吞吞吐吐，事件以不变形收束但口供细节减半。
- 若林恩让尹依附身自己于冷库内分担鬼气负担，则她能稳定记录俘虏反应而不失控，事件以不变形收束但她对恶灵古堡阵营评价反转。
- 若林恩在爱丽丝汇报「外乡人变多」之后直接以古堡男主人权限把冷库大门封死改期再审，则俘虏新鲜度下降，事件以变形（冷库封门）收束，E178审讯窗口延后一日。
- 若林恩在菜园前顺手摘下那颗长着大脑状果实的「庄稼」带去冷库做对照，则这件样品首次入列古堡证物袋，事件以不变形收束但矢量载入背包一格。
- 若林恩在冷库见到无面血肉人形时先行以自己胸口穿刺而出的触手把它卷成一团悬挂半空，则它醒来时已被缠成蛹状无法扑杀，事件以变形（偷袭未发）收束，审讯快节奏略减。
- 若林恩在尹依表情僵住时直接以男主人权限命令古堡将一条铁钩降下演示，则她首次目睹古堡自我运作，事件以不变形收束但尹依世界观更新一行。
- 若林恩审问前先让左左从体内钻出来威胁「再挣扎剁成泥」，则血肉人形因双重恐怖陷入沉默，事件以不变形收束但左左的凶名在敌方档案提前补一条。
- 若林恩把艾雯爵士改装轮椅的减震模块激活后驶入冷库，则寒气被隔在轮椅罩外，事件以不变形收束但古堡寒意档案加入一条「可被硬件压制」。
- 若林恩在爱丽丝汇报后未踏入冷库、转身先把这顿重逢陪伴陪到底，则冷库审问整段延后，事件以变形（审问延后）收束，城堡当晚多出一场兄妹私语。
- 若林恩扔下轮椅不用、改坐在爱丽丝黑丝秋千上悠闲听汇报，则尹依被独自留在原地围观，事件以不变形收束但古堡从容度+1。
- 若林恩在古堡停一晚不走、把冷库审问排到次日凌晨，则爱丽丝地缚咒纹得到一轮温养，事件以变形（古堡过夜）收束，E178审讯氛围整体缓和。
- 若林恩主动在爱丽丝面前声明冷库俘虏是「要活口不是要食材」，则她放弃把它们计入当晚菜谱，事件以不变形收束但古堡餐桌上少一道腥荤拼盘。
- 若林恩全程不唤出尹依、让她继续藏在自己体内旁观，则冷库审问没有旁观证词，事件以不变形收束但她眼压高到意识差点昏厥。
- 若林恩在爱丽丝交钥匙串时主动回赠一枚系统商城购买的普通戒指，则她兴奋到周身黑雾翻涌压塌一丈荆棘，事件以不变形收束但古堡当晚修复费极高。
- 若林恩完全放弃冷库之行改陪爱丽丝在花园待满一日、把地缚咒纹现场温养压制，则血肉人形在那段时间被古堡里另一种生物吃掉，事件以变形（地缚治愈优先）收束，E178链条整体取消、改由其它线索点开。
