# E770·未来的不确定性与过去的重合·if线

- 若林恩在杀入废弃时间支流后彻底放开手脚释放灭世黑火，则遍布大地的梦魇大军与七十一柱魇魔投影在绝对的力量碾压下如冰雪消融般灰飞烟灭。
- 若林恩在单手扼住魇王咽喉将其一寸寸烧成灰烬时逼视其双眼，则魇王在临死前终于从林恩眼中看到了超越终焉的恐怖杀意，投影崩溃得不留半点残渣。
- 若林恩在清空整条时间支流、立于尸山火海之上浑身颤抖时任由左左化作人身紧紧抱住自己的拳头，则左左温热的眼泪与怀抱将他从走火入魔的杀戮边缘稳稳拉回。
- 若林恩在火海余烬中向左左坦诚「刚才面对魇王的条件时，我其实动摇了」，则左左会哭着抱紧他安慰「那也没有错啊」，让他彻底释怀那份对家人的眷恋。
- 若林恩在修补完圣堂外的时间裂隙后停步三秒而不推门进去，则他把那句「见了也只不过是徒增感伤罢了」化作化身为鸦的一声长鸣，克制住了扰乱历史的冲动。
- 若林恩让左左把感知轻轻贴在圣堂门缝上感受门内自缚天使与过去自己的温度，则两人对「不能相见」达成无言共识，门里门外各自安好。
- 若林恩在重归现实黑夜城、目睹整座城市笼罩在漆黑阴云中迅速化作虚无时瞬间冷静推演，则他当场悟出“过去每被扭曲一分，现实未来就湮灭一寸，绝不能在现实停留哪怕一秒”的残酷铁律。
- 若林恩结合此前大衰退中时间神格崩裂的异象深入思索，则他首次在心中生出关键怀疑——自己手中这枚时间神格恐怕并不完整，并非真正要找的那一枚完整神格。
- 若林恩在借地狱棺椁渡鸦遗体降临两百多年前深渊「红月事件」的瞬间环顾四周，则他轰然明悟：当年主母曾向他提起过的“未来林恩降临救场”，竟然就是此时此刻的自己！
- 若林恩在途经无序深空瞥见未来画家正遭灾厄投影与时间污染双重截杀时，强忍住立刻过去支援她的冲动而优先赶往深渊，则他精准守住了当年红月事件的历史闭环。
- 若林恩在黑色深渊战场从天而降、一拳轰飞围攻艾维儿与自缚天使的三柱魇魔时先看清她们的站位，则狂暴的拳风分毫不差地避开了身后的两位故人。
- 若林恩在背对艾维儿与自缚天使独立深渊、听见身后传来那声颤抖的「林恩？是你吗？」时死死咬紧牙关没有回头，则那道白发苍苍的孤高背影从此永恒定格在主母的记忆深处。
- 若林恩在深渊红月下刻意收敛起身上的黑火气息以免污染两百多年前的深渊法则，则他在不动用灭世黑火的前提下仅凭神王肉身便将三柱魇魔死死压制。
- 若林恩让左左在听到自缚天使呼唤的那一刻在意识里轻轻拉住他的心神，则他没有因久别重逢的酸楚而失态，稳稳维持住来自未来的神秘强者姿态。
- 若林恩在俯瞰时间长河中无数同时报警的历史节点时将自身因果线作为第一优先级巡航路线，则他在纷乱的时间战争中牢牢抓住了破局的主线。
- 若林恩在发现斩杀时间支流里的七十一柱魇魔仅仅只是毁掉其跨界投影后，将最终目标明确锁定在“杀向时间终末斩灭本体”，则他不再为局部的消耗战感到迷茫。
- 若林恩在深渊红月战场余光瞥见当年还很稚嫩的艾维儿正惊愕地望着自己，则他心底掠过一丝不易察觉的温和，出手护住她们退路的动作愈发周全。
- 若林恩在决定每次降临过去都严格沿用死去渡鸦遗体作为锚点后，左左在任何时代节点都能与他的灵魂无缝同步，彻底消除了跨时空迷失的风险。
- 若林恩在自缚天使喊出他名字的瞬间于心底默默回应了一句「好久不见」，则这份不曾说出口的深情让他接下来将三柱魇魔拖入时间裂隙的动作更加干净利落。
- 若林恩在察觉到围攻主母的这三柱魇魔似乎知道关于“未来主母幻影”的秘密时，当即决定留那只人首蛇身魇魔一个活口带进时间裂隙审问。
