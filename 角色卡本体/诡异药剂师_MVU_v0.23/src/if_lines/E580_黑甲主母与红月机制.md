# E580·黑甲主母与红月机制·if线

- 若林恩拒绝与黑甲对决任由其破坏，则露脸与主母得见延后，但弑莉叶被贯穿与红月按时重置仍立，事件以防线失守的加重分支收束。
- 若林恩试图直接破坏红月本体，则本事件不写成已探核成功，按时重置仍可立，红月免疫层级被确认但机制口述仍由天使出口。
- 若林恩在弑莉叶率部迎王女时主动上前一步挡在自缚天使身前，则主母的愧疚线再次点燃，但弑莉叶杀意癫狂在看见林恩挡路时迟疑了一瞬。
- 若林恩对弑莉叶「刽子手」指控回以「她数万年未归但至死仍忠诚」，则弑莉叶的怒吼卡在喉咙里，那半秒的动摇被自缚天使全程捕捉。
- 若林恩在骑士长枪破血空贯穿弑莉叶时同步以初诞者之力轰击黑甲，则弑莉叶的致命伤被转移但死亡仍至，主母记住林恩「试图救她」的那一把力。
- 若林恩抓住枪尖时不用力掰而是说「长得像她但不可能是她」，则黑甲炸裂力度稍减，但这一句话被主母「我亦看不见」的盲区点亮新的疑问。
- 若林恩在左左拔夜魔刀纵劈时主动释放一缕初诞者之力指向她刀背，则左左的斩击从劈成两半升级为劈成四半，她那双眼睛亮起一秒的认可。
- 若林恩在艾维儿人头形态收割大魔时主动让她别孤军深入，则她反呛「你自己不也一样」但剑刃速度不减，两人的斗嘴在杀阵中建立一层战友默契。
- 若林恩在钉杀黑甲前主动对主母说「要开始了，你看着别闭眼」，则主母罕见地没有照做而是闭上眼强行听声，她在艾维儿钉杀后的顿悟从视觉变成一个闷响。
- 若林恩对自缚天使以林恩而不是王女的语气说「我在这里」，则她抓住他衣袖的力度从恐惧转为确认，「至少现在我还在你们身边」的宽慰在此时被提前预演。
- 若林恩在钉杀成功后故意把夜魔刀举到头顶让全城都看见，则守军天使的跪拜带上一分看英雄的狂热，「魔君化身」的认定由他主动点燃。
- 若林恩对天使「所以你们见主母反应那么大」反问时加上「她是我的姐姐」，则天使惶恐中第一次听见他直承亲缘，弑莉叶残留的意识里对这一笔关系账单被修正。
- 若林恩主动对忠诚派恶魔傀儡下令「守住城门口直到我回来」，则恶魔傀儡虽停摆但接收指令的种子被埋入，后续循环里它们会无意识执行残留指令。
- 若林恩在被按时重置前主动把左左塞进自己嘴里，则左左被「共生式含住」后重启时仍在他口中苏醒，「公报私仇」喜剧添新的荒诞层级。
- 若林恩对主母的拥抱打气中主动吻了她的额角一下，则她的巨翼停滞半秒，之后把这句话原样翻译成「主母心里一直都是最棒的」送还给他。
