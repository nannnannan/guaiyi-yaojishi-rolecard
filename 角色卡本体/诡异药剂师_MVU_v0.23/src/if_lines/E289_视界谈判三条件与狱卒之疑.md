# E289·视界谈判三条件与狱卒之疑·if线

- 若林恩在三条件中漏掉「解除对我血肉的剥夺」，则视界之主毫不犹豫应允全部条件，但林恩时限内继续承受血肉诅咒一律结算。
- 若林恩在三条件后附一条「你也要还我一个人情」，则视界之星沉吟不语，「狱卒欠你一份」伏笔多加一层。
- 若林恩把「你得亲自来跟我谈」放进条件，则视界之主罕见地停下，深渊中传来一缕巨大低语、却没有人降临。
- 若林恩在谈判开场先问「你怎么认识我」，则视界之主不会正面回答，但「为什么你让我觉得熟悉」那句天问被提前抛出。
- 若林恩在谈判中突然对视界之主说「我饶恕你」，则视界之主沉默三秒，最后一言、态度更加冷峻。
- 若林恩在把交易回执递给视界之主前顺手把一份血肉神教的情报作为礼物，则视界之主任务简易化，但林恩与疫医的关系可能改善。
- 若林恩在被传送回书房前顺手在视界之领域摘下一根黑藤，则那根藤在他手中枯萎成粉末，成为开门时一桩小小物证。
- 若林恩在书房中对羽毛笔说「如果我能重生一次，你还会认识我吗」，则羽毛笔没有正面回答，但对他产生了更深的信任。
- 若林恩决定立刻去找艾泽法拉商量对策，则她愿意用自己独特的思路帮林恩，但她的介入会引来灵魂上的微调。
- 若林恩在书房里贴一张机械神教死星的彩色画像来自勉，则左左故意用黑笔把画像涂成「林恩冰箱侠」。
- 若林恩提议「那我也去陪你下地狱看看」，则羽毛笔怔住，感动与拒绝在她眼眶中打转。
- 若林恩从书房某处翻出一本《旧神年代纪》，则他用了一夜读完、E290 入手半条新线索。
- 若林恩把「搞死星结晶」的计划升级为「三位一体机重建总纲」，则机械神教线路被拉成一条主线、E291 重量被加重。
- 若林恩跟羽毛笔摊牌「我觉得狱卒其实在帮我」，则羽毛笔决定尝试替她揣摩一下狱卒心理，「反派截面」增加一缕温柔。
- 若林恩在书房里试验把克苏鲁之眼从冰箱门把手上挖下来举到眼前，则它不再亮，他重新装好，但权能空间短暂抖动。
