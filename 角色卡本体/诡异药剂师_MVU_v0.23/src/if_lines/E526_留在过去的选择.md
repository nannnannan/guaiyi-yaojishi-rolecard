# E526·留在过去的选择·if线

- 若林恩在左左一拳打晕时选择躲开而不是承受，则她可能更气愤地多打他一拳，剧情节拍延续。
- 若林恩决定在被拳头打晕前提前晕倒装睡，则左左的拳头落空，她的发泄渠道改写为言语。
- 若林恩选择在被左左抓领子拉下床时顺势拉住她，则她也被拉倒，两人的姿势从「被压」变成「相持」。
- 若林恩决定不回击「我不得已的」而是说「我知道我错了」，则左左的连环拳可能停下，对话氛围从对抗转向自白。
- 若林恩在选择留在过去时先询问主母／银幻／孽主的意见，则他可能得到不同的反馈，决策的来源从「自己想通」变成「集体协商」。
- 若林恩决定不选最远的 21 万年前而是选某个关键时期，则他可能遇到具体历史人物，修炼机缘更精准但风险更大。
- 若林恩在新躯降临时故意让自己看起来很苍老，则孽主和巨像的反应可能从安慰变成惊慌，他必须在解释中消除误解。
- 若林恩选择在被左左说「你就是太钻牛角尖」时大笑而不是沉默，则她可能被他的笑声感染或者更加愤怒。
- 若林恩决定不在跨入前明确说出「谢谢你左左」而是直接微笑，则她不感知到明确的肯定，但情感温度仍在。
- 若林恩在选择跨入的时段时选择白天而不是深夜，则他在进入时永远先见阳光，对那个时代的自然气候感受不同。
- 若林恩决定先用恶灵能量探路而不是亲自附身渡鸦，则他可能不直接面对污染者，但收集到的信息较间接。
- 若林恩选择让首波污染者被林恩放过一只跟踪而不是全部碾碎，则他可能跟踪到污染者的来源节点，情报线索延展。
- 若林恩决定让左左在跨入前用拳头打在他肚子而不是脸，则他的身体不同部位承受，醒来的感受不同。
- 若林恩在左左劝停时选择主动认错「你说得对我太莽了」，则她的「拳头倒脑袋」环节可能不再发生。
- 若林恩决定在半封裂缝的布置中使用三叉戟提供能量稳定，则他失去立即使用三叉戟的自由，但裂缝更牢固。
- 若林恩选择不选择渡鸦棺而是用其他渡鸦尸作为容器，则他可能得到不同的寄生体验，能力效用不同。
- 若林恩在推棺被第一波污染者突进时用灵能震打而不是三叉戟，则不同战斗风格收获不同战果，但体力消耗不同。
- 若林恩决定让左左在跨入时一起过去而不是留在现实，则她成为超长旅程伴侣，但她本人可能被时间流逝损伤。
- 若林恩选择让半封裂缝的布置成为「每隔一百年自动开启五分钟」，则他可能获得间断的回归窗口，长时间修行不脱离现实。
- 若林恩决定在这个 21 万年前时空内建立一座临时实验室而不是只是点篝火，则他的修行设施更完备，但可能被历史记忆察觉。
- 若林恩在跨入前选择不与孽主和巨像当面告别而是留信，则他的离去方式可能更孤独但不让她们当场伤感。
- 若林恩决定在被首波污染者攻击时不防御而是迎接其中一只进入体内，则他可能吸收到污染者的本源资讯，但承担污染反噬。
- 若林恩选择在跨入瞬间让左左以透明影像形态随行，则她既不实际受伤又能在他身边协同，跨时空联动模式创新。
- 若林恩决定在进入时代时换上古代服饰保持融入感，则他可能不被该时代的人注意到，修炼可能更安稳。
- 若林恩在选择半封裂隙时决定要让「只有他自己能通过」，则他人无法主动靠近，但他在被封之前可能与外界断联。
- 若林恩在被半封裂隙布置时决定让每个裂缝像「网眼」一样细密分布，则拦截能力更强但布置时间更长。
- 若林恩选择与神王碰面的方式从「硬闯」换成「礼貌预约」，则三招赌约的提出方式根本改变，剧情走向合作，但战斗戏份减少。
- 若林恩决定让左左在整个事件中既是劝停者也是战斗激烈的参与者，则她的角色从「守护伙伴」变成「同甘共苦者」，关系更为亲密深刻。
- 若林恩选择不入渡鸦尸棺而是让某段渡鸦尸体本源流入自己体内携带，则他可直接携带某种本源回归现实。
- 若林恩在跨入时代之前决定先告诉主母自己要去多久，则这段时间她在现实等待的耐心与焦虑账目改写。
