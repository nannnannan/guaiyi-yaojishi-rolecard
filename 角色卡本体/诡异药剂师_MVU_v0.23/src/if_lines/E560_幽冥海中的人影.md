# E560·幽冥海中的人影·if线

- 若林恩在撕开幽冥海无序屏障时主动加大那道缺口的宽度，则物质风暴涌入强度加倍，锚点布设难度上升，逆流航道被迫偏航数度。
- 若林恩在布设空间锚点链时主动加大锚点间隔，则法则细线隧道稳固度下降，逆流速度加快但失控风险上升，抵近主宇宙边境的时间被压缩。
- 若林恩听小丑尖叫「前面有大恐怖的无序巨物」时主动令全队改道绕行，则小队避开镜面巨物，蓝发女子引流下游的相遇场面被完全错过。
- 若林恩在镜面巨物升腾时主动把屏障撑到三倍体积，则自缚天使法则紊乱的眩晕被缓释，但小丑维持无序力的负担骤升。
- 若林恩在小丑尖叫时主动用咒瞳扫描镜面巨物的碎裂矩阵，则他被集束的镜面碎片反向锁定半秒，出海后眉心多一缕无名杂音。
- 若林恩在自缚天使惊呼「那头怪物前面好像有人」时先稳住主母再循其指向看去，则他与蓝发女子对视的时点被推迟一拍，「巨大错愕」被推入更后一帧。
- 若林恩在蓝发女子开天一剑劈碎镜面巨物时主动让屏障反光被她乍见，则林恩的位置不再是「偶然入她回眸路径」，她的错愕从「瞥见」升级为「认出黑袍」。
- 若林恩在对方隔海对视后不立刻收敛气息而是反向探出一缕心声致意，则蓝发女子回眸那一下「微微顿挫」从「诧异」定格为「回应」，下游引流被她主动放慢一拍。
- 若林恩在意识到蓝发女子在引流下游时主动让全队追上去碰头而非继续上游，则「上游必有灭顶变故」的判断被他自己放下，主宇宙边境的战斗在他们缺席下发酵。
- 若林恩主动让全队立刻按原路返航，则蓝发女子引流下游的视线被切断，小队回到地狱后延误了「上游正在发生」的预期信息。
- 若林恩在小丑惊叹「能驾驭无序力量」时主动猜测对方可能是另一位狱卒，则「女主人下属网」被奉上一条具体猜想，西王之前的提示被捞回重读。
- 若林恩在蓝发女子回望他的瞬间主动以咒瞳标记她的方位与外形，则他在后续主宇宙边境能凭这道标记去找她，「幽影之女」的伏笔被自己亲手埋下。
- 若林恩在镜面巨物错身时主动默默记下它身上最大的那道剑痕位置，则他在后续再次遇到这头无序巨物时能立刻判断它曾被引流过的痕迹。
- 若林恩在小丑惊呼从未在狱卒序列见过此人时主动建议先把这段发现压下不与西王汇报，则「蓝发恶鬼面具人」的身份标签挂在秘密档案里，地狱内部对她的存在不知。
- 若林恩主动向蓝发女子示意「我们也向上」并以手势指路，则二人从看似相向变成看似同路，「同理心的偶遇」被他自己推出一拍。
- 若林恩在对方错身后主动不让小丑全速上游而是先紧急修补法则细线，则上游航程延后半小时，蓝发女子引流下游的成就被先一步扩展到「甩开」的量级。
- 若林恩主动开口让左左替主母清点行装查漏补缺，则主母的负载分布更合理，他给左左的功用从「储备箱」被多加一条「行船官」角色。
- 若林恩主动让左左负责监看蓝发女子远去的方位，则下游引流完毕那一幕被左左目击，「她消失于何处」的坐标被小队内第三只眼睛登记。
