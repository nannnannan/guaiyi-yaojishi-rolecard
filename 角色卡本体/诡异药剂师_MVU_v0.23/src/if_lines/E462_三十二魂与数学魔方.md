# E462·三十二魂与数学魔方·if线

- 若林恩在分魂到第十六道时主动把其中一道灵魂形态捏成左萝的模样，则她在意识里笑了一声，绑定值 +1，但那一道灵魂在系统空间里整整三小时不愿变形回来。
- 若林恩在无瞳之眼法阵铭刻的中途主动停手、改一笔眼缘弧度，则固定咒语落地时多出一缕不合规的尾音，被左左笑到没力气骂。
- 若林恩在吟唱时主动把「萝莉控」三个字从庄重换成默念，则这三个字的字符力量损失七分之一，但夜医部队多保留了一丝不被调侃的尊严。
- 若林恩在左左捏灵魂小林恩脸蛋时主动让那一道灵魂的脸颊凹陷更深一分，则她指尖被自己的玩笑呛到，绑定值 +1，但小林恩那道灵魂显眼地抖了一下。
- 若林恩在第一枚瘟疫弹发射时主动让它穿透他的指尖，则他指尖皮肤在微观侵蚀下裂开三道细缝，但后续三枚瘟疫弹的病变速度提升了三成。
- 若林恩在灭绝者骇变时主动对她点点头示意「是的，还能这样用」，则她那一秒的判断窗口被打乱，疫雾在死星蜂巢合围的防线上多挖了一刀。
- 若林恩让三十二分之一的自己在外围深坑出现时主动把那一道身影穿成夜医制服，则纳米警报在第一波齐射时不认得那具林恩，他借那一瞬真身顺利降临。
- 若林恩在咒语完整落地瞬间主动把一枚旧日残片贴在无瞳法阵正中央，则林恩那一道身影在火山外景被加速抽走，残片本身被咒烧出一圈白边。
- 若林恩在将军报出「不需要永久」时主动在意识里把下一步推演成三条路径，则他在魔方成形前一秒识别出自己将进入星空容器，但他来不及告诉左左。
- 若林恩在切换瘟疫侧翼时主动拽住夏娃一根血管往自己身上缠一圈，则她被这份信任激动得触手直颤，绑定值 +2，但她那一分钟里的判断都交给了林恩。
- 若林恩在死星蜂巢合围时主动用王戟在头顶撕出一个小小的三叉门，则那一道门在被顺势打开时多留了一道未被关闭的缝隙。
- 若林恩在学者以「牢笼」自居时主动抬手按在自己心口，则他心跳在那一秒慢一拍，绑定值稳，但他没听到学者下一句。
- 若林恩在数学魔方成形时主动用灵能切开一滴自己的血珠塞进星空的某个角落，则后续这道血珠在容器里变成一颗可被追踪的红点，左萝在意识里记下这颗星。
- 若林恩在学者提联合开价时主动沉默十秒没有应答，则她的数字面孔在停顿时多颤一帧，但她接下来的合作提议也没被他听见。
