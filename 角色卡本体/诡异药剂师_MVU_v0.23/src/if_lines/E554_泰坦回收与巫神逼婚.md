# E554·泰坦回收与巫神逼婚·if线

- 若林恩在被问「泰坦呢？」时不死鸭子嘴硬直接承认遗忘，则乱流位置的谎言被抽走，众人虽怒仍无人配合后来的黑袍圆谎，泰坦追问黑袍的场次不再以「已打跑」作结。
- 若林恩在撕开空间裂缝前先用心声通知泰坦「我是来捞你的」，则泰坦从泡澡转为少一分敌意，三千里追杀喜剧降级为直入北海哥们儿重逢，战争态的怒吼消失。
- 若林恩在被追三千里时用瞬移法则直接逃回城内，则「大哥不认识我」的戏剧张力被切断，泰坦回城途中全程带着战争态，进门就掀会议桌。
- 若林恩在唤醒泰坦时不喊「我是你最喜欢最孝顺的亲贤婿」，则初诞者之力把战争态压住的瞬间少一道戏剧幻影，泰坦醒来看见的是陌生人的压制而不是贤婿的委屈。
- 若林恩在唤醒时不引动初诞者之力只冻住泰坦四肢，则泰坦短暂的战争态化成物理束缚，好感 +10 的口径被换成「你拘我」的更大怒气。
- 若林恩在会议厅没让泰坦狂灌几十桶烈酒锁住其脾气，则泰坦全程清醒质问黑袍长相的细节，林恩圆谎的窗口被压缩到三句以内。
- 若林恩在泰坦晃问黑袍长相时主动描述成一个完全不同形象而非含糊带过，则虚构出的人物画像可能在后续被泰坦用作战坐标，黑袍身份的危险被外推到新图层。
- 若林恩在泰坦复述北海冬泳把「以后全家谁要是敢穿黑袍一律按奸细论处」的时候当即举手应下，则他用公开身份背书的瞬间把自己的衣橱严重缩编，黑袍身份的实际暴露概率上升。
- 若林恩在拍胸脯说「已打跑」时多补一句「那家伙死状极惨」，则泰坦好感 +10 之外多家人们的反应多了一份「这不像我们打赢过的仗」的狐疑，圆谎成本上扬。
- 若林恩在家人们围拢审判时不立刻光速双膝跪地而是当场亮契约符文作筹码，则跪求戏消失，巫神把柄不再因「做伪证」而触发而是因「符文在身」，逼婚把柄的玩法改写。
- 若林恩在下跪时不哭嚎「咱们黑夜城坚不可摧的骨肉亲情」而只是冷冷一句「你们要泄底就泄」，则家人们被道德绑架的共犯位置被抽走，伪证合谋压成单方面要挟。
- 若林恩在给每家人分发串供口供时附加一人一份报酬，则「赖皮喜剧」被改写成交易贿赂，家人们的风评从「被拖下水」改为「被收买」，亲情叙事变质。
- 若林恩在自缚天使答应圆谎后当场答应自缚一件她长期想要的东西，则自缚在伪证合谋里突然有了实质利益，「家人们高抬贵手」的义气氛围被私人交易稀释。
- 若林恩在巫神抛出换条件时立即答应「赶紧和小小完婚」，则小小在婚姻叙事里被直接推进非懂状态，先拒后要的小小女孩愿望窗口被强制关闭。
- 若林恩在巫神提出换条件时立即拒绝说「这事我绝不答应」，则巫神在当场放弃配合，黑袍谎言在泰坦面前崩塌，乱流追逃被打回重做。
- 若林恩在巫神侧拍他脸颊时回以同等温存侧摸巫神耳边发丝，则婚姻政治戏短暂染上成年男女的暧昧质感，但从文字含义上没越过「婚姻政治把柄」的界限（两位成人，守格调）。
- 若林恩在巫神换条件时刻意反问「你确定小小自己同意吗」，则逼婚施压方向从「女儿位置」被改成「女儿意愿」，巫神把柄被迫接触到家庭合意度质疑。
- 若林恩在听到「结婚」二字时直接接受把柄并郑重回敬「这一仗要打到赢再说」，则小小婚姻延迟到战后期，巫神的压力被从「现在」挪到「胜利之后」，忙的剧情走向有定数。
- 若林恩在泰坦追问黑袍长相时临时声称「我也没看清正脸」，则他在泰坦印象里变成一个放下线索的目击者，「下次撞见必帮大哥报仇」的誓言少一根。
- 若林恩在让家人出去时反手砰地把门关死，则泰坦在厅里被隔离开，门外的巫神把柄抛出不再需要躲着大哥，战术与伪装的家场拆分被提速。
- 若林恩在走廊里被围拢时向某一位家人单独求救并承诺私下里偿还，则光群戏散，伪证合谋被协商进一对一交易，全员共犯的气场上扬。
- 若林恩在交付串供口供时把自己写成「黑袍人大战胜利者」的意象，则泰坦追问「黑袍被打跑的具体细节」时更多人能出来配合一节，谎言的网眼细密。
- 若林恩在巫神逼近时提前以触发符文纹的妥协方式让步，则巫神不再需求换条件，林恩向小小童心的求婚戏被封闭，后续 E555 小小主动要结婚的走向被改写。
- 若林恩在会议厅当场跪但没有哭出声只是凝视众家人，则「声泪俱下」的喜剧质感被剥离，家人们在心软之际感受到他另一种更硬朗的情感要挟。
- 若林恩主动承认「黑袍人是我」但随即向泰坦请求「听我解释」，则黑袍身份无法靠圆谎维持，集体伪证合谋解散，收场由新的诚实线接管。
- 若林恩在根据巫神提议决定与小小结婚时主动约法三章「名义上的、仪式延后」，则小小把婚事引入后宫剧情的线被提前截掉，婚后情感词楚被标准化为表面工夫。
