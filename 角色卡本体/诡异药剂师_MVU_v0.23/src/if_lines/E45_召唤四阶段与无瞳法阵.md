# E45·召唤四阶段与无瞳法阵·if线

- 若林恩接过羊皮信时不当场答应病院报告，则主母先催他动身，仪式塔之行照常展开、病院报告推迟到仪式结束之后
- 若林恩进塔第一步就盘问大厅屏幕上的随机召唤条目，则艾雯爵士改以"无指定召唤的渗透风险"开场，讲解顺序从定向要素切向灾难边缘试探
- 若林恩在图书馆里直接追问视界至高意志或主母的第四阶法阵细节，则艾雯爵士仅以"尚未有召唤记录"带过，不展开
- 若林恩要求先刻第一阶、跳过第二第三阶的预先铭刻，则艾雯爵士尊重其选择，后续若获更高能级认可需另行补齐缺失法阵
- 若林恩在黑暗虚空中构思的标识不含"人类、血肉、触手"任一元素，则法阵照常生成但中央标志呈现为抽象几何或他物种轮廓，绑定流程不变
- 若林恩在黑色虚无丝线覆盖法阵时因恐惧后退或试图逃离六芒星，则烙印中断、艾雯爵士就地重启，丝线不追击只重新收录
- 若林恩对"是否烙印过"的质问闭口不答，则艾雯爵士不追问，直接转入逆向追溯，脚下无瞳法阵照常浮出
- 若林恩被反向追溯时闭眼躲避，则法阵仍在脚下成型，无瞳之眼中央血纹不会因视线而关闭
- 若林恩当场追问"这只是更大法阵一部分"的猜测，则艾雯爵士保持推测口吻、不点破也不否认，血纹扩张继续不中断
- 若林恩请求先将无瞳法阵记录下来而不急着写祷文，则事件停在法阵记忆完成、祷文未定稿处，完成条件暂不达成
- 若林恩在仪式塔测试台前把祷文写成"正统人族、善良夜医"之外的方向，则成功率依旧不足百分之三，不引入"萝莉控"字样则稳定卡在低位
- 若林恩拒绝让左左碰祷文文本，则左左依旧在他转身时以极快速度塞回纸条；若林恩当场夺回并撕毁，则测试人员重新排队、事件走向变形前的等待
- 若林恩主动在祷文末尾添上"萝莉控"或等效贬义标签，则成功率从低位飙升至九成以上，测试人员不视之为左左所为
- 若林恩在召唤成功后就地撕毁文本并禁止任何人再提此事，则94%底本事实仍被系统记录，左左的嘲讽丝毫未减
- 若林恩被法阵拉上台后以拟化能力当场反击左左，则左左在众目睽睽下被拟化成人形，后台秩序短暂混乱但不取消召唤成功事实
- 若林恩在街头巷弄中拒绝与左左玩闹、强行终止旧账话题，则左左悻然收声，后续拟化惩罚改为私下无目击者场景触发
- 若林恩要求艾雯爵士在送走自己前停止血纹扩张，则艾雯爵士中断咏唱但保留已扩张规模，无瞳法阵的未知伏笔不变
- 若林恩在仪式塔内向测试人员透露自己"可能绑定过其他法阵"，则工作人员仅记录备注，不影响当前四阶段体系讲解与无瞳法阵追溯结果
- 若林恩在祷文里写"伟岸的善良夜医"却私下不认同此身份，则召唤成功率仍按文本计算，文本与内心背离不影响法阵锁与钥匙的机械对应
- 若林恩在测试后台被召唤波动扫过时强行挣脱而非接受，则召唤仪式解除、本次测试失败，需重新排队且94%底本不被抹除
- 若林恩在艾雯爵士讲解"力量能级"时插话提及血肉支配者或主母的献祭规模，则艾雯爵士不展开具体数字，仅以"远超低魔世界承受"概括
- 若林恩追问第四阶段"根源之上"是否包含旧日支配者或外神，则艾雯爵士保持"尚无召唤记录"的口径，不新增分类
- 若林恩在六芒星中央因旧记忆闪回而更改标识构思，则法阵以最新构思为准，先前画面不会残留、绑定指向唯一
- 若林恩在事件结束后向主母报告时隐瞒左左的"萝莉控"添笔，则主母不主动查问，事件完成状态不受影响、后续衔接照常发生
