# E197·鬼婴救援与罗斯特灵魂收押·if线

- 若林恩在白夜挥拳前先一步踹飞结界残片大喊「给我停」，则白夜的金属指刺停在罗斯特眉心一厘米处，咒缚触发被整整推迟一次呼吸。
- 若林恩当场摘掉高脚帽直接行礼并主动报出「傀儡」二字，则罗斯特瞳孔猛缩但来不及反应，小呀哒那一刀不被触发，傀儡替身戏码提前公开。
- 若林恩让傀儡当场掀胸露空壳但保留眼球不挖，则罗斯特产生极强不安但仍试图启动咒缚，白夜的圣纹指刺在预警中被林恩一手拍开。
- 若林恩在罗斯特冷笑刚起时就让咒瞳从结界顶端投下阴影，则罗斯特抬头那一秒被瞳孔直射，咒缚的绑缚咒语在喉咙里生生卡住。
- 若林恩让左左从自己肩头探出张嘴先做一声模拟婴儿啼哭，则笼子里的小呀哒应声抬头，罗斯特把她和林恩的联系误判为「控制物」。
- 若林恩主动对罗斯特报出血衣女士还在游魂巷等他，则罗斯特意味到情报等级反转，咒缚的稳固度在他自己的颤抖中松掉三成。
- 若林恩把左轮上膛但不开枪只抬到罗斯特鼻梁前，则罗斯特眉心的冷汗顺着指令刺滴到地面，他的咒缚专注度分走一半。
- 若林恩让傀儡用骨骼咯吱声刻意贴近罗斯特耳语一句「猜猜我现在在哪」，则罗斯特左右转头的瞬间咒缚传导路径出现三毫秒迟滞。
- 若林恩在白夜准备圣光吸摄时提前把左左拟化成小萝莉站在旁边压阵，则白夜的手势更稳，罗斯特的灵魂被抽出来时少了一声哀求。
- 若林恩让咒瞳在掷骰前主动顿一下刻意让罗斯特看见「一」的点数，则罗斯特的表情在死前最后一秒露出彻底明悟，而不是恐惧。
- 若林恩在抱小呀哒时先在自己胸口割开一道血口让她直接吮，则她摄取血液的接口从皮肤换成入口，系统提示从【血液-1%】跳到【血液-3%】。
- 若林恩在小呀哒的触手缠上时主动把她转个向让她贴在自己颈侧，则她的凸起扎进他的喉结旁，林恩一边呛咳一边笑骂「小笨蛋」。
- 若林恩对左左的警告回一句「让她吸，她是我接生的」，则左左张了张嘴不再说话，只在他背后默默把咒纹收紧一圈护住他的心脉。
- 若林恩在小呀哒缩小成型时把自己的高脚帽扣到她头顶，则她的蠕动触手安静了三秒，随即从帽沿下探出一颗眼睛骨碌碌盯着他看。
- 若林恩拒绝当场抱她起来改用外套把她裹起来单手提着，则她在外套里安静蜷成一团，事后当晚却对准他床头的方向一直鸣咽。
- 若林恩在离开教堂废墟时故意走慢一步踩在罗斯特的血泊里，则他鞋底带出一路断断续续的红脚印，左左在他耳边幽幽一句「你在挑衅他的同伴」。
- 若林恩在白夜吸摄罗斯特魂魄时让自己分一丝注意力给血色世界方向，则他捕捉到那一颗庞大眼球隐入黑暗的瞬间，眉头在无人看见的角度皱了一下。
- 若林恩把罗斯特的灵魂容器接手过来随身携带，则容器在夜里传出一缕缕细碎的咒骂，左左暴怒一拳砸上容器口把它敲成哑巴。
- 若林恩在离开前回头对夜医交代「把这座教堂彻底烧掉」，则火海在他背后映出一片血红的剪影，小呀哒在他怀里第一次发出类似安心的呜鸣。
- 若林恩在抱她的时候故意用手指挠她掌心一粒凸起，则她本能地把手指叼住吮吸，血液流速比触手摄取快了一倍，林恩疼得嘶了一声又笑出声。
- 若林恩在事后对白夜交代「罗斯特没死透，他的灵魂还有残留线索」，则白夜破例把容器再度打开加一道圣纹钉，咒骂声彻底沉寂。
- 若林恩让小呀哒在自己手臂上咬一口再放手，则她牙尖划破皮肤时贪婪地连吮三口，左左在旁边别过头嘀咕「变态父女俩」。
- 若林恩当晚让小呀哒睡在自己床脚的冷却槽里而非怀里，则她整夜把头搭在床沿盯着他，第二天天亮时她的手心里攥着他的一根头发。
- 若林恩在血肉支配者转移重心画面投落时主动朝那画面比了个中指，则那边的眼球僵了一秒，画面信号提前被切断。
- 若林恩在战后对左左宣布「我要把她养回原来的样子」，则左左瞪着他看了三秒忽然嘟囔「那你先把我的那口养分让给她一半」，林恩当场扶额。
- 若林恩在事后独自重游教堂地下结界残骸并捡起一枚罗斯特的圣纹钉收入背包，则这枚钉子在事后某一天会作为证物被巨像之脑指认出来。
