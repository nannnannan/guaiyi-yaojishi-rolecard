# E137·纳米血肉集群认亲与新族群·if线

- 若林恩在机械纳米集群自残骸下聚成风暴扑向收集者集群之前更早介入，则淡红色血风不必自地缝涌出救场，纳米血肉集群的登场时机延后，「母亲——我们是从您的血肉当中诞生的生灵——」这句认亲台词可能改为私下超维感应单独接入
- 若林恩在纳米血肉集群借巨像之心的超维感应把重叠机械嗓音送入意识时立刻回应，则通信建立速度加快，集群的雀跃表现更外露，小股血风用颜色深浅拼出的圆加两点一弧的笑脸在废墟上出现的频率增高
- 若林恩保持沉默不回应任何称谓，则集群会反复切换「母亲」「母爹大人」等怪称试探，并时而幻出绞刑架图案表达焦急，直到林恩给出可接受的代号才肯停下
- 若林恩要求集群停止呼唤亲属称谓、改用「缔造者」或正式代号，则集群需要数轮协商才勉强接受，期间会在低音量超维频道里偷偷保留旧称，笑脸与绞刑架并用的隐喻风格延续
- 若林恩主动询问集群被巨像之脑全域召回时为何拒绝，则它们会坦白当初「骂了一句——拒绝了——」的细节，并展示事后没能赶到母亲身边的懊悔，同时提到母体一开始只有一个、靠吞噬驱逐无法融合个体才慢慢有了意识
- 若林恩追问母亲派是如何上位的，则「把那些可恶的决策者杀光了」的内部清洗史会被摊出，反对召唤的生存派、文明派、独立派被武力放逐的真相现场公开
- 若林恩提出为被放逐派系提供庇护或谈判空间，则母亲派会表现出警惕，「我们母亲派才是文明正统」「那些异教徒都杀穿了」的宣称受到当场质疑，集群内部张力上升，可能触发变形为多派文明
- 若林恩接纳集群的追随，则集群规模被记录为只能写成动态规模的数字而非成就数字，其战力、忠诚与文明伦理的不稳定性进入正式档案，不得当作已稳固的军队或子嗣
- 若林恩设定明确禁令（禁止随意吞噬、禁止袭击特定目标、禁止在林恩面前幻出绞刑架），则集群会逐字在字面意义上找漏洞，需要耐心追加条款封堵
- 若林恩要求集群自治而非直接指挥，则集群会推举临时代表对接，但母亲派仍会把林恩的每一句话解释成神谕并向下广播，认亲的怪象延续
- 若林恩拒绝接纳但保持通信，则双方进入临时雇佣或情报交换关系，互不攻击条约成立，事件按变形路径收束，不进入单一母亲派的追随线
- 若林恩完全拒绝接触并切断超维感应，则集群会在利维坦残骸带外围游荡，可能独自继续吞噬机械同类扩大规模，取消条件成立，不默认它们是林恩的军队
- 若林恩在集群迟疑出声「父……父亲大人？」后主动澄清巨像之脑的真实身份，则集群意识到自己误认了与当初召唤同源的更高层血肉气息，地下神殿的方向被点破，E138的追责线被提前点燃
- 若林恩放任集群把巨像之脑误认为更高层的「父亲」，则集群会延宕着向地下神殿方向试探性移动，与巨像之脑在地下动用的高阶神力发生先行接触，触发诅咒的风险增加
- 若林恩提醒集群左左与巨像之心尚未清醒，则集群会主动压低对巨像之脑方向的探测强度，并在林恩周围留出一圈静区等待左左苏醒，巨像之心与集群的共鸣延后确认
- 若林恩提出以利维坦残骸作为集群的食物来源，则残骸带被确认具有根源级材料与药剂研究价值的部分会被逐步消耗，但「吃不到足够的食物——我们就会筛选出一部分先吃掉——」的内耗机制被暂时压制
- 若林恩拒绝提供食物、要求集群自行觅食，则集群会恢复「平时没有战斗——也会随机抽取幸运儿——吃掉——」的筛选机制，实际数量永远只能写成动态规模，内部不满与非人文明机制的冷酷面持续累积
- 若林恩将集群的存在告知艾雯爵士或其他夜医，则夜医方对这个兼具机械复制与巨像血肉感应的新族群进入观望期，后续合作或戒备由后续事件判定，不替任何一方预设结论
- 若林恩尝试用血肉支配者的权能影响集群，则权能判定如实呈现失败或部分成功，集群会表现出被高位阶血肉源吸引的困惑，并反复在超维感应中确认与林恩的血缘优先级
- 若林恩在集群以微观层面绞杀机械纳米集群时要求留活口，则被捕获的机械意识成为诅咒之城战局与机械神教残余动向的情报来源，但集群会当场抱怨食物被截留，关系账目上记一笔
