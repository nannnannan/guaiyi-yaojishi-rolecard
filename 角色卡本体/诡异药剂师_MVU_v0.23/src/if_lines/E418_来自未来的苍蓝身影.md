# E418·来自未来的苍蓝身影·if线

- 若林恩在苍蓝身影凝出轮廓前先用原初之力把旧躯腿间器物继续修复到完全形态，则系统会报快乐微增，他在与来者对视时不再因外伤而半身佝偻，这场会面以他站直的姿势开局。
- 若林恩在黑雾空腔成形时先用咒瞳对准苍蓝眼睛方向扫一次，则他能在来者凝形之前看到一缕极淡的银白线条缠绕在她腕骨，那是与时间翎羽同源的标记——他提前识出她身上装备的来历但没说破。
- 若林恩主动把血娃娃立下的血契文书压在柜台石板下再前来会面，则他证词中提及「历史能否被改写」时会多一份实物佐证，来者在听到石板去向的瞬间苍蓝眼底会掠过一丝极淡的赞许。
- 若林恩在来者说出「最终仍是林恩」之后不追问、只点头，则她会以几乎低不可闻的声音补一句「你能不问，是他没看走眼」，这句话是他事后对白发人身份推测最重的一根砝码。
- 若林恩在来者警告「时间战争已经开始」时主动把臂章内的乌鸦符文展示给她看，则她会短暂地以画家的目光端详那枚符文，告知「他给的钥匙没有送错人」之后不再多提。
- 若林恩在来者消散前主动伸手想拉她的指尖，则她会以一道薄雾从他之间流过退开三米，留下一句「还不到能碰到我的时候」，这句话在左左事后听来会被她连声嗤笑。
- 若林恩决定不向小丑提及这场会面，则小丑只能凭短暂时间异常推断「林恩刚才不在此处三里」，林恩会把这个秘密压到未来的某一晚小丑醉意上头时才以一句悄话揭开。
- 若林恩选择领取奖励后第一时间把黑翎长袍披在身上走出黑夜城主殿，则途中遇到的所有夜医都会在那一刻朝他行一次与面对渡鸦同款的低头礼，他自己还没察觉装束已改变局势。
- 若林恩穿上两件装备后第一时间不告白身份、只静默地立在左左面前看她的反应，则左左会先愣住再伸手颤颤地摸他兜帽下黑发，她口中喃喃出的第一句不是问句而是「白发人也是你」。
- 若林恩决定立刻对左左亲口点破「那个在历史中的白发人就是我」，则左左指尖会停在他掌心整整十秒不动，事后她在意识里只嘀咕一句「我早该知道」，没有大哭也没有大笑，只多了一份落定。
- 若林恩发动往日鸦鸣化作乌鸦后故意不朝女澡堂飞去、改落在黑堡主殿顶端的乌鸦雕塑上栖息，则他会以完全无害的初体验完成这件装备的首次公开，左左乐得在意识里踢他一脚「算你识相」。
- 若林恩发动往日鸦鸣化作乌鸦后真朝女澡堂方向飞去，则他会在窗外被艾雯爵士以一道灵能斩拦下，爵士本人没看清是谁、只觉一道黑影掠过——林恩当晚在意识里挨左左骂到天亮。
- 若林恩在回归后立刻掘开石板核验血契是否仍在，则他能确定「就他当前记忆而言历史未被抹去」，三字核验被他写进随身笔记本，作为今后关于时间可否改写的最基础参考。
- 若林恩掘开石板时发现血契已被无关人士提前取走，则他会立刻意识到在他的过往中还有另一双眼睛在行动，他后续对白发人身份的推测会再加上一条「对方可能也曾回到这一刻」的新分支。
- 若林恩在询问左左对自己新装束的看法时她不直答、反以一段俏皮调笑反问「你今晚打算先做白发人还是先做林恩」，则林恩得被她这一反问定住整整三秒，那一晚他以林恩身份拥她入睡。
