# E414·无序三柱与渡鸦因果·if线

- 若林恩在开场就先把心脏碎片上挪位放回原处，则小丑会以肉眼可见的幅度松一口气，它对「碎片压制」的威胁度立即下调一档，第一句话的声音也跟着柔和三分。
- 若林恩拿出未使用过的变异药剂针筒朝小丑的脖子比了比，则小丑会毅然扑上去抓住针筒要喝，它认出了黏液里能改写存在的气息，但被林恩及时收回，它在错愕中抿嘴笑出声。
- 若林恩在小丑避谈女主人时忽然把左左扔进小丑怀里作为「破冰工具」，则左左会友好地揉搓它的栗子脸，小丑表面嫌弃却忍不住纵容她，交涉中断一秒，它以真正放松的语气继续谈话。
- 若林恩在小丑谈到乐者被抹时试探性地问「那乐者可曾留下半句音符」，则小丑停顿三秒，用一段几乎低不可闻的小调哼出短短一小节，左左在意识里反映「好熟悉」的咒纹共振。
- 若林恩把「大君入主沉眠者」反过来追问「沉眠者是否入主了大君」，则小丑会突然捂住心口短促震了一下，他回答改为「这本是一体的两面」，对大君的纯粹忠诚开始出现第一道裂缝。
- 若林恩对小丑说「我已听出你在为渡鸦留后路」，则小丑会第一次完整承认，点头表示「我一直为他留着」，它从胸口掏出一块被岁月磨秃的旧绢帕抵住眼下，眼泪顺着血管爬过整张脸。
- 若林恩让小丑在自己面前演唱一段他为大君所作的安魂曲，则它会停下招牌大笑，用近乎消散的气声唱完一曲，事毕当场跪地，林恩扶起来为它拭泪，它的手指感激地按住他手背不放。
- 若林恩在小丑提到女主人的画布百年未更新时主动拿出自己手画的小本子递上当作「画布」表示心意，则小丑会以肉眼可见的幅度动容，当场把本子贴身收好，从此刻起它对林恩的忠诚等级暗升一档。
- 若林恩让小丑列出女主人的画布近作名录做进一步追查，则它会以自己亲历为限点出三幅「最后一笔永远停在同一个角」的画幅与对应年号，林恩得以把女主人的沉睡窗口精确到具体年代区间。
- 若林恩对小丑追问「时间若被污染，过去是否已被人改写过」，则小丑会低头沉吟良久，含泪说出一句「我亲眼见过一段被撕碎又缝合回去的昨日」，林恩对自身过去的信任基础遭到强烈震撼。
- 若林恩在小丑谈轮回法则时故意插话问「那渡鸦已轮回几次」，则小丑把手指竖在唇边眨一只眼拒绝回答，但眼底分明透出敬服之色，林恩对自身前世的可能性推测被这一眼神默认固证。
- 若林恩把小丑的表情逐格用咒瞳录下准备回去与人偶家对帧分析，则它会在第三帧忽然故意做出吐舌头的滑稽鬼脸拒绝继续，林恩因此判断出它在刻意掩盖某种深层的悲伤。
- 若林恩突然追问「你对那株幼态母树心里如何想」，则小丑诧异抬眼，没直答而是承认「我与她缔结过一场沉默的同盟」，眼底深意不散，林恩把这句记入私人备忘决定日后再问。
- 若林恩在小丑说完主宇宙灾厄后伸手紧捏它的下巴、用平稳呼吸问道「告诉我你将来想怎样」，则它此次不再倔强，以真心话回答「我只求再被她注意一次」——不再谈救赎，只剩卑微祈愿。
- 若林恩在小丑讲完秩序三基石后即兴用钢笔在掌心画出时间、空间、因果三柱交的图腾再递给它看，则它会情不自禁地夸出一句「你逃不过我卯在身上的眼」，那种被夸奖的语气令它眼底上扬。
- 若林恩突低下头对小丑献上一个深深的鞠躬与额前一吻，则小丑会完全愣住并把脸红透，事后它独自嘲笑自己「我怎么会为一个奴仆的额前之吻发毛」，并把这份错愕写进日记某一页。
