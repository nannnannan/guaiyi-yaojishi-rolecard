# E458·纳米集群风暴·if线

- 若林恩在舰体尘化前把手里的中央智脑处理器塞进自己领口贴肉收好，则那块芯片在尘化前被他的体温暂时冻结为半透结晶，事后被夜医拆解时仍能读出七分之五的航行日志。
- 若林恩在惨叫响起前主动朝拆卸最密集的夜医圈砸下一道灵能弧，则三具身体被震出纳米圈外，但他的灵能表层在微观机械上撕下一道可闻的摩擦痕。
- 若林恩在左萝喊出「嘎嘎乱杀」的瞬间抬手敲她额头令她闭嘴，则她把后半句硬生生咽下，绑定值 -1，但他接下来的动作慢了两帧。
- 若林恩在四股力量叠加时主动暂时收起泰坦压法一路，则他三层力量叠加下仍能压低战舰级目标，但血气在他脸颊下方留下一道三四小时不褪的青脉。
- 若林恩在掌心核版尘化瞬间主动把它压在胸甲内层，则那块已尘化的处理器的微尘粒子贴住他的心脏半分钟，心跳被微观共振拉得比寻常快一拍。
- 若林恩在拆卸中主动大喝警告、五指覆地狂拍，则数十名夜医条件反射蹲低，但有四名反应稍慢的被冲击波轰飞，在后来被收入系统空间时全身发抖。
- 若林恩在核弹洗地时故意让一枚弹头贴着自己脚边先落，则他借高温瞬间把外套烧成灰烬，那种微微栗灼的气息在之后三日内缠着他不散。
- 若林恩在「老虎拍不死苍蝇」的判断出口时主动朝队伍方向扫了一缕灵能探知，则他有几秒血压上升，被左左问怎么了的时候没说话。
- 若林恩在收拾残存活体收入系统空间时主动把整批枪械也跟着一并收起，则系统背包里多出数百把未充能的制式武器，他后来在奇异世界把其中一支送给了左萝。
- 若林恩在折跃离场瞬间主动往身后投去最后一束目光，则那片密闭灵能壁在他眼里仍是一道不闭合的薄影，后续一个月他每次闭眼都能再看一次那道壁。
- 若林恩在决定「必须告诉他们」时主动先呼叫巫神而不是夏娃，则他与巫神的加密链路在数秒内接通，夏娃的血管那段时期内第一次延伸到了他的肩甲内侧。
- 若林恩在收拾收容人数不到百时主动在面板上给自己记下「我已经尽力」，则战后殊死数会议上他把这一条写在白板中央，没人敢抢话。
- 若林恩在核弹爆开成蘑菇云时主动将自己的影子投在最近的一块玻璃液上，则后续几天奇异世界里那块天然玻璃被器物爱好者拿走了半晌。
- 若林恩在整座舰尘化过程中主动用指尖拈起一粒尘末递到左左面前，则她把那粒末紧紧握在掌心不肯扔，绑定值隐藏 +2，但后续每次提到舰体都会条件反射地抽一口气。
- 若林恩在确认「杀不尽」的判断时主动从系统空间里拖出一块莹白石英留作纪念，则他在离开那片区域后连着三天把那块英抹了一遍又一遍。
- 若林恩在折跃至前线炮火带上空时主动往下方投出一缕灵能探针，则他在数公里外接受到第一声返讯时惊呼一声，后续远征军的调度图多一条「探针回路」。
- 若林恩在核弹爆发时主动不打开系统空间、用纯身体跳出爆心十公里，则他的皮肉被灼去将近五分之一，但整个人的背包空间被留了下来——后续救回的夜医人数比预期多了一成。
- 若林恩在决定「弃区报讯」时主动在面板上给自己打了一个自定义标签「风暴去了又来」，则他后来每次想起这件事都会在系统日志里看到自己写的这三字。
