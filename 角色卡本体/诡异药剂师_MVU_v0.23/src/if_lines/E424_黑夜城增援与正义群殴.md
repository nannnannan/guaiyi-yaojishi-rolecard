# E424·黑夜城增援与正义群殴·if线

- 若林恩在求援时主动指定「全部八位根源都要到场」，则传送门坠落一刻「八气息齐压」的地狱纪录被打破，孽灵失去全部退路，首回合就被压成碎片。
- 若林恩只求三人援助（泰坦、天使、巨像之脑），则她的无序优势仍能与三位方向互口，战斗被拖长二十分钟，破坏范围被推展到地表三圈。
- 若林恩在黑夜城求援时把坐标直接报上城主广场，则传送门在她头顶砸来，宫殿崩塌面积增加三倍，孽主、小丑心脏、眷者全数被尘埋，事件以变形（广场改写）收束。
- 若林恩让夏娃血管提前把自己包裹成卵，则空中落雷与泰坦撞击时他变成最先被遗忘的落点，反而获得独立视角评估所有到场者的力量比例。
- 若林恩在自缚天使到位前主动替她拔除一道诅咒锁链，则她的战甲首次在神殿外展全形，「天使城外飞行」的地狱首例画面被现场直击。
- 若林恩请求人偶家以左左形态加入群殴，则她作为「绑定之手」与林恩本体联结的动作画面外传成「主人与从属齐攻」，孽灵先读识到双倍主从夹击的战场加重。
- 若林恩让巨像之脑空中持续举重锻炼后抵达战场，则她首击力道比空巢设定更强 20%，但她自己也热汗淋漓几乎掉甲。
- 若林恩刻意不让小小参战、用夏娃血管把她举到后方百米，则她从「后方摆造型」转为「远处防防弹」，「八位到场七人作战」的分工首次被她本人接受。
- 若林恩让巫神头颅藏在宫殿里以「最后伏击」身份介入，则孽灵斩杀她依赖的暗影被迎面抽出，「神性压制」层次首次打捞到桌面。
- 若林恩拒绝使用初诞者之力加持，则孽灵的无序真正压过五位根源，她被小红三人组压制三回合被折挂，会议变成她挑人杀场。
- 若林恩在修补裂隙时主动召孽主协助动用她族内无上压制能力，则她的血线压制与林恩封锁下令裂隙收束速度快一倍，但她在施术结束后诅咒发作跪地咳血。
- 若林恩拒绝修补裂隙、只木然跃出，则宴会灾难持续殖落，「地下帐篷被顶住」的画面维持到 E425，前来未来来客的涟漪未来被推后二十分钟。
- 若林恩在群殴进入第二回合时主动用咒瞳录下孽灵面容变化，则他与孽主的「同位」逻辑被他自己以逐帧验证，「未来身份」推论被提下打入档案。
- 若林恩用巨像之锤主动加持泰坦的重锤路径，则两位巨人同时涉及地面，城市地图推演界首次出现「泰坦+巨像一起撞」的叠加走势。
- 若林恩让喵喵变化为斗篷贴住泰坦头颅，则她首次体验「与根源合二为一」的宠物视角，「猫是他的一部分」从被证明上升为被强调。
- 若林恩在泰坦撞地面主动宣布避面线，则狱卒、罪民及孽主都被迫在地上让路，「绝对实力撞一切」成为城主上报画面。
- 若林恩在群殴中段主动以萄萄压力指向孽灵，则她被双重源压制，首次实结「主动投降意愿」表面出口。
- 若林恩选择召六位根源加林恩自己，共七人对一，则「正义群殴」首尾呼应秩序形态成立，舞台次序在「七打一」的定律上留下他本人的招牌。
- 若林恩让左左以手形态替他拿文件进战场，则她成为史上首个「持有公文与咒瞳同时」的从属状态，画面温度零重与五位同列女深
- 若林恩在修补裂隙完成后主动给下水道弹一枚恐吓之语「下次再见是我进你时间」，则她最后崩溃的画面里有他的意难平反向首次。
