# E267·圣女的天灯神的方程式·if线

- 若林恩在弥赛亚被蚀痕巨触拖走瞬间点燃【主母的红茶包】，则万丈光焰提前亮起，巨触在光亮中化为灰烬，她被光柱笼罩显现出来,事件以原作路径收束但好感结算条件改为「光明之源」。
- 若林恩启动【神的方程式】时以【圣天使的圣像】为目标而非故障魂灯，则炽天使圣像被「修复」成活化单体飞向远方，事件以变形（修复圣像）收束。
- 若林恩把【炽天使魂灯】repair circuit再次损坏，则四盏灯同时熄灭，事件以变形（魂灯全灭）收束，大殿瞬间陷入绝对黑暗。
- 若林恩在弥赛亚说出「我就知道你一定会来的」时以淡然回复「是的，我一直在」，则她沉默数秒后不再追问，事件以原作路径收束且好感结算条件改为「无言信任」。
- 若林恩用蚀痕覆盖自己的咒瞳使目光锁定深渊，则他被污染侵蚀速度加50%,san值快速降低,事件以变形（主动受污染）收束。
- 若林恩没回应弥赛亚的请求而是挥手击碎圣像底座所有神秘符文，则地下大殿被强行封锁，事件以变形（圣像封锁）收束,海嗣无法进入。
- 若林恩把【主母的红茶包】送给血衣女士而不是自己使用，则她持火种走出自己的进攻道路,事件以变形（交付红茶包）收束。
- 若林恩在见到海嗣修女时主动上前抱住她们说「你们原本是人」,则她们愣住后哭出声，事件以变形（悲情对话）收束,海嗣未受重伤但情绪崩溃。
- 若林恩把【圣女的天灯】成就换成其他献礼，则他放弃天灯成就,事件以变形（更换成就）收束,好感度结算条件变化。
- 若林恩亲自吹灭弥赛亚手中的魂灯让众人瞬间陷入黑暗，则所有人惊慌崩溃，事件以变形（吹灯致乱）收束。
- 若林恩用双指捏爆一只路过的猫耳娘，则他不杀无辜但消灭了生灵,事件以变形（消灭猫耳娘）收束,血衣当场皱眉。
- 若林恩最高点燃烧【红茶包】带来巨大的光辉但未驱散旧日污染，则旧日仅在更远处操控海嗣，事件以变形（旧日迁移）收束,海嗣打法更显变化。
- 若林恩在弥赛亚被蚀痕触手缠绕时用圣水溶解它们，则她被救出但更感羞辱,事件以变形（圣水救回）收束,她好感度未变。
- 若林恩把左左当做人形护盾,在触手横扫时用左左挡住弥赛亚，则左左受伤且气氛糟糕,事件以变形（左左受难）收束。
- 若林恩在大殿深处寻找天主所遗下的宝物,则他发现一卷未打开的梵蒂冈教廷密卷,事件变形为（获得宝物）收束,密卷内容待揭。
- 若林恩挑衅并主动挑起旧日怒火，则旧日操控海嗣力扑向他,事件以变形（引火上身）收束,他独自应对旧日狂怒。
- 若林恩指示血衣单独飞出大殿去追杀天主,则天主真身可被判决击杀,事件以变形（天主被杀死）收束,梵蒂冈法则系统崩塌。
