# E114·万机梦魇与解救巨像之舌·if线

- 若林恩带着左萝绕行万机投影外围远远避开梦魇核心,则迟来一步,小宝贝被灵能发生器32压得更紧,巨型舌头已经破皮渗血,救回时陷入长时间微弱喘息,需要林恩用巨像之心低频一度一度叫醒。
- 若林恩下意识朝梦魇投影正中央迎上去观察万机之神心魔细节,则被那一双血红瞳孔锁定,巨像之心暴露坐标,机械意识群提前在血雾中四面合围,解救小宝贝变成正面对上千个机械化意识体的突围战。
- 若林恩当场示意左萝先隐藏去见巨像之心共鸣不被发现,则以单人触手突袭缠住灵能发生器32的锁链,小宝贝最先认出的不是林恩而是那股血脉温度,舌头剧烈扭动发出求认亲的超维呜咽。
- 若林恩选择先顺路追上去揭穿那个长相跟自己一模一样的疫医冒险货,则银色幻想暂时把杀意吊起看完这场"正版打盗版"的好戏,互不侵犯契约延迟触发,林恩比剧本晚一步赶到小宝贝身边。
- 若林恩当着银色幻想的面把以M之拳留在掌心不发,只冷笑着丢下"你现在最忌惮的是我"这句话就走,则互不侵犯契约破裂的扳机留给她自己扣,银色幻想赌咒要追进下一层血雾。
- 若林恩顺手朝银色幻想胸口按了一记盗版同款三倍涩度而非地面,则智械小姐理智崩线暴走追击,互不侵犯契约反噬烧穿半个机械意识群,反而替林恩清出一条通往小宝贝的临时通道。
- 若林恩救出小宝贝之后没有立刻撤离而是在围猎广场短暂停留逼问机械意识的兵装出处,则灵能发生器32的母树藤蔓样本落进林恩口袋,后期反向追踪欲望母树钓饵路线的证据提前落手。
- 若林恩让左萝先用"恶萝咆哮"吸引机械意识注意自己再爆发触手,则左萝被数十道血红光束同时锁定,小姑娘差点被一发擦着头发的灵能弹掀飞,林恩此战之后整整一层血雾没敢再让她冲在前头。
- 若林恩救小宝贝那条铁链的当下故意慢半拍,先看清楚所谓"镇压回路"的运行频率,则小宝贝多受几轮镇压压得舌头粘在地上爬不起来,但被带走时已对万机之神这套兵装的谱系有了第一手破解线索。
- 若林恩击溃机械意识群后立刻拽着小宝贝和左萝一路狂奔掉头就走,则途中迎面撞上欲望母树垂下的第一缕脚踝,守株待兔陷阱直接在血雾中段触发,母树现身的位置比剧本提前数十米。
- 若林恩听完小宝贝自述没有立刻揭穿"钓饵"结论而是顺着逻辑接受它"碰巧走到这"的说法,则垂柳枝条无声从背后包抄,林恩被勒进血肉藤蔓时才反应过来,母树登场时林恩处于半被动位置。
- 若林恩当场蹲下来用巨像之心向小宝贝静默致谢,把"你是队友不是诱饵"这层意思讲透,则小宝贝第一次在这个意识空间主动环住林恩的脚踝,母树的钓饵计谋当场反被巨像之舌识破,小宝贝反过来朝血雾深处嘶嘶示警。
- 若小宝贝被救回时直接哭诉自己一路迷迷糊糊见到母树藤蔓就贴着走的细节,则林恩提前锁定欲望母树塔的方位坐标,反向圈定母树真身的领域,任何后续遭遇都能在预知距离上抢半拍。
- 若小宝贝在被救瞬间说出"我记得有姐姐在我耳边唱歌"这段精灵舌记忆,则林恩与左萝同时沉默,母树对巨像部件的同化手段第一次以完整故事形式呈现出来,左萝脸色发白直到事件结束都没松开林恩的衣角。
- 若小宝贝被围住那阵子自己用舌头狠狠咬伤过一个灵能发生器32却装作忘了,则它在获救之后才慢慢从舌根下吐出那个咬断的半枚兵装,林恩接过那枚发烫的金属时触手被它的余温震得发麻,万机之神机械制式第一次以残件的形式留在林恩手里。
- 若林恩在救小宝贝的关键时刻选择不用触手而用巨像之心主动共鸣把它整个拽出镇压,则小宝贝立刻认出这正是它魂牵梦萦的另一半心跳,这一夜它黏在林恩身边,左萝吃醋却无从发作。
- 若林恩全程没让左萝出声,把整个解救压成无声潜行,则机械意识群直到四分五裂都没听到"恶萝咆哮",万机之神对巨像之心的警报晚传一层,母树钓饵的现身时机被推迟数个呼吸。
- 若林恩救下小宝贝之后选择留下来反向清点机械意识残骸并核查"灵能发生器32"是否留了第二套触发逻辑,则母树藤蔓在血雾边缘盘根半圈迟迟不敢接近,欲望母树对这位识破她守株待兔的"夜医"产生了第一次真正意义上的评估。
- 若林恩一边跑一边对小宝贝承诺"我会带你回家",则小宝贝在后续与母树正面对峙的瞬间爆发出它从没展现过的反扑支撑,母树的第一次色诱被这条巨舌主动打断。
- 若林恩以一敌多无法顾及小宝贝时让小宝贝自己往血雾深处滚,则它在逃亡途中误打误撞滚到巨像之塔近前,母树藤蔓第一时间锁定它,林恩赶到时小宝贝已被藤蔓缠住第二层,救场变成双线救援。
