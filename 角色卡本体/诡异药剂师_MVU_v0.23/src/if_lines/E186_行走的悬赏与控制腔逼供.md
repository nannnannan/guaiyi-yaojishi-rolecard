# E186·行走的悬赏与控制腔逼供·if线

- 若林恩不在首领面前恢复真容，而是维持疫医护士伪装直进控制腔，则「行走的五百万」失声惊呼不发生，首领把林恩当作「异端同僚」处理，逼供开场由恐吓转为身份博弈。
- 若林恩把猎魔左轮换为咒瞳锁定而非枪口抵额，则首领在生理层面的恐惧稍弱、但精神层面多被咒印压制，「兑换点」「坐标」「权限」三段口供节奏整体放慢一轮。
- 若林恩当场摊牌「血肉神教两个老大都被我干趴下过」而非恐吓开枪吓唬，则首领进入「既然知道我打不过你我就摆烂」心态，口供反而更干脆但少了原始的崩溃张力。
- 若林恩主动免除那八百九十枚骷髅币债务、连本带利一笔勾销，则首领立刻对他产生「也许还有活路」的错觉式顺从，「两次活命的机会」金句不触发，事件以变形（债务勾销）收束。
- 若林恩把复利改成每分钟百分之五百、并把抹零数字从九百推到一千，则首领当场哭晕一次、被林恩一脚踹醒再供，「高利贷清算」恶名更上一层楼，E187 接头暗号段多出一句不情愿的妥协。
- 若林恩在逼供前额前先主动射爆控制台外壳、让他看到「我真敢动手」，则首领过于惊恐反而咬死两句关键坐标不肯松口，林恩需要用第二轮恐吓才能补齐全部数据。
- 若林恩把「是他说了算还是我说了算」的咆哮换成低声陈述「我数到三，你不说我就崩碎你左手指」，则首领的恐惧从火焰式咆哮转为冰锥式压迫，口供节奏反而变快、林恩角色定位轻度偏移。
- 若林恩在逼供间隙让左左拟化成萝莉出来「审问友情客串」，则首领在人偶和左手萝莉轮流凝视下崩溃得更彻底，连环追问节奏压缩一半，但左左对该事件的「恶童形象」在她内心留下新一笔。
- 若首领在供出坐标后试图反咬「其实还有第二据点」，则林恩多获得一条备用情报，但需要他同时权衡是否先去验真、再去钟塔，事件以变形（额外据点解锁）收束。
- 若首领供到一半口吐白沫抽搐，则林恩需要现场以疫医手法简单维持他的意识，逼供从「恐吓」改写为「林恩又怕他死又想他招」，临场黑色幽默反转。
- 若林恩主动以咒瞳反向扫首领大脑、不给他撒谎机会，则口供全部「读取」而非「听出」，事后首领无法反过来供出林恩身份，「五百万」名头的扩散被局限于在场视听者。
- 若林恩让尹依在边上笔录口供并现场念一遍让首领确认，则她首次以见习身份完整经历审讯流程，警戒教学第二条「任何时候都要留证据」得以落实，师生线 +1。
- 若林恩在首领求饶时当场表示「我给你个机会换你手下的命」，则首领被反向利用变成带路人，E187 接管畸变体阶段多一名不稳定陪同者，背叛风险常驻。
- 若林恩供出坐标后立刻以夜魔刀切断首领右手作为「押金」，则首领无法操控任何神经台、彻底沦为行走情报，事件以变形（首领被废）收束，后续接管节奏更稳但失去原合作剧本。
- 若林恩当场把首领拖上腔壁让他看着整只失控爬行者，则首领心理防线崩溃方式由「枪口」改为「视觉刺激」，他旁观整场失能后在高度焦虑下主动供出更细的据点名单。
- 若林恩在逼供而非高利贷间二选一、只追五百万兑换点不追骷髅币，则首领在被放走前还抱有最后一丝「他也没那么坏」错觉，黑色幽默反转成首领无言瘫坐在血池里。
- 若林恩立刻把坐标用咒瞳密码写回给黑夜城、当面让首领听见自己的报告，则首领意识到自己的口供已经被上层监听，他的下场变得比他以为的还要糟，恐惧感变相放大。
- 若林恩放弃接管权限、只索取坐标与暗号，则事件以变形（不接管爬行者）收束，E187 整段畸变体驾驶与撞向钟塔的剧本不再成立，需要改走地面潜入等价路径。
- 若林恩强制性把首领带上爬行者作为「活指南」，则他在 E187 路程里随时可能被林恩榨取新情报，但也存在自我牺牲式假暗号反噬风险。
- 若林恩改用「我用咒纹替你保你一命」作为交换腌臜条件，则首领与林恩之间生成一条临时契约神经锚，事件以变形（契约换情报）收束，后续首领可被远程召回。
- 若林恩在逼供结束时主动卸下左轮弹药留一颗子弹在首领眼前晃说「下次还敢血肉神教，我就还你」，则首领即使日后翻身也会在记忆里留下擦不去的威慑锚点，林恩恶名+1 不体现在成就栏。
