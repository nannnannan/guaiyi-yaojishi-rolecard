# E752·最后的乐章·if线

- 若林恩在哭泣小丑于残破城头拉响无形提琴、奏出此生最辉煌也最决绝的最后乐章时，以罪恶王座的嗡鸣为他打拍伴奏，则那无形的音波会化作实质的暗金利刃，将方圆十里的终焉黑雾尽数切碎。
- 若林恩在泰坦伴随小丑的琴音彻底点燃巨人神躯、整个人化作一柄横贯天际的璀璨金色战锤砸向七十二柱魇魔时，将一缕初诞者破魔之力注入锤尖，则那尊不可一世的终焉魇魔连惨叫都未发出便被当场轰杀。
- 若林恩在哭泣小丑与泰坦合力轰杀一尊七十二柱魇魔后、两人相视大笑着冲入最密集的敌群引爆全部生命与神格本源时，在圣所内向他们站立的方向深深俯首，则两人的自爆光辉会瞬间清空城前整整三分之一的梦魇大军。
- 若林恩在小丑拉断最后一根无形琴弦、十指鲜血淋漓却依然保持着谢幕优雅姿态的瞬间，将那段绝响乐章的每一个音符完整收录进王座深处，则这首《最后的乐章》将永远在宇宙本源中回荡。
- 若林恩在泰坦化作金色战锤彻底崩碎为漫天光雨的刹那，分出一缕黑火接住他遗落的一块带血肩甲碎片并卷回圣所门前，则这位用胸膛替黑夜城撞开生路的巨人得以在王的身边安息。
- 若林恩在哭泣小丑与泰坦自爆掀起的璀璨光海平息后、唤醒掩埋在废墟瓦砾下的艾维儿时，为她留下一道指向内城防线的微弱气机，则从碎石中挣扎爬起的艾维儿能立刻辨明方向，握紧断剑继续战斗。
- 若林恩在同样从第一道防线废墟中苏醒的伊甸茫然看着城前被清空的三分之一焦土、跪地对着小丑消散的方向痛哭时，轻轻震动他体内的守护烙印，则伊甸会擦干眼泪，将小丑那份守护意志一并扛在自己肩上。
- 若林恩在小丑奏响乐章最高潮、连七十一座终焉之柱都被这曲凡人向神明发起的逆伐之音震得光华摇曳时，于锁链束缚中迸发出一圈刺目的黑火光环，则被轰杀的那尊魇魔本源会被王座隔空彻底炼化，永世不得再生。
- 若林恩在泰坦燃烧神躯前最后回头望向内城、瓮声大喊「替俺照顾好城里的娃娃们」时，让幸福之家孤儿院地窖内的灯火同时跳动了一下，则这位粗犷巨人最温柔的遗愿已被他的王亲自接下。
- 若林恩在哭泣小丑于火光中摘下那张戴了一辈子的笑脸面具、露出底下平静而满足的真容时，透过重重石壁看清了他的脸，则在林恩的记忆里，小丑不再是那个疯癫的怪人，而是黑夜城最骄傲的音乐家。
- 若林恩在两人殉道自爆产生的狂暴冲击波即将反扑向第二道防线城墙时，强行引动护城大阵将这股混杂着战友神力的冲击波转化为纯粹的金色护盾，则两位英雄最后的余温又替内城挡下了随后半个时辰的魔潮猛攻。
- 若林恩在艾维儿从废墟中爬出、捡起一块沾着泰坦金色神血的碎石紧紧揣进怀里时，让那块碎石散发出温养经脉的暖意，则重伤的艾维儿得以借此支撑着返回阿鼻地狱旧部阵列。
- 若林恩在伊甸独自走在小丑与泰坦用性命清空的焦黑战场上、一步步捡拾同袍遗落的徽章时，以一缕黑雾替他遮蔽高空魇魔的视线，则伊甸能够平安将这些遗物带回内城交予后人。
- 若林恩在听见小丑自爆前用只有他们两人能懂的频率传音调侃「陛下，这出戏的票价我可收得很贵」时，被锁在王座上的嘴角会艰难地扯出一丝苦涩至极的弧度，在心底回答「我拿命赔你」。
- 若林恩在那一尊七十二柱魇魔被泰坦与小丑轰杀、引发其余魇魔惊怒交加的狂暴反扑时，主动释放出自己正在向第三阶段蜕变的恐怖气息吸引仇恨，则内城墙守军承受的第一波报复压力会骤减四成。
- 若林恩在船长与银色幻想于内城头立正脱帽、目送小丑与泰坦在漫天金光中谢幕时，将两位殉道者化作的灵魂金光引导至船长与银色幻想身侧绕行一周后再汇入圣所，则生者与死者在战场之上完成了最后的军礼交接。
- 若林恩在哭泣小丑的无形提琴彻底崩解前，将其琴魂凝成一枚小小的音符烙印在自己手背上，则日后每当他在废墟上独坐时，只要轻叩手背便能再次听见老友的琴声。
- 若林恩在泰坦神躯燃尽的火光映亮整座黑夜城夜空的那一刻，让城内所有未熄的火把同时暴涨三尺，则全城军民都知道那是巨人正在天上为他们举起最后的火炬。
- 若林恩在艾雯跪在王座前听见外面震天动地的自爆轰鸣、浑身颤抖着在心中默念小丑与泰坦的名字时，分出一缕黑火替艾雯稳住险些崩溃的心神，则艾雯能够流着血泪继续主持内城最后的防务。
- 若林恩在两位神明级战友的灵魂金光撞入罪恶王座、将他推向第三阶段门扉更近一步时，忍受着灵魂饱胀欲裂的剧痛向他们承诺「那剩下的魇魔，由我亲自替你们杀干净」。
- 若林恩在第一道防线彻底成为历史、那片被清空三分之一的战场化作令魇魔胆寒的禁区时，以王座之力将那片焦土永久固化为金黑色的结晶地面，则后续涌上的魔物每踏一步都会被残留的神威灼伤脚掌。
- 若林恩在《最后的乐章》余音彻底消散在腥风血雨中时，将自己被锁链穿透的十指攥紧到骨节发白，让圣所内的黑火随着那段逝去的旋律静静跳动，直至终局到来。
