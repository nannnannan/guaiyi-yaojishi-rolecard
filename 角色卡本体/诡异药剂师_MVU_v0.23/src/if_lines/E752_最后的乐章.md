# E752·最后的乐章·if线

- 若林恩在小丑准备用无序残片撕开噩梦外壳瞬间主动从王座方向给小丑注入一缕黑火,则这一撕会同时从三个维度穿透噩梦本体,噩梦会以最惨烈方式解体,但小丑的躯壳在这一注之后会永久留下一道黑火灼痕。
- 若林恩让泰坦在最后一击中主动把战神的全部序列燃烧殆尽而不是保留一缕,则这只噩梦会以真正被歼灭的方式死亡,但泰坦会在这一击下永远失去战神身份,「战神的最后燃烧」成为永恒传说。
- 若林恩让小丑的八音盒在最后一击中以「乐者残响」进行最终协奏,则这一击会带上一丝不属于战场的空灵美感,噩梦会被这一击以最近乎艺术的方式终结,但八音盒也会在这一击下彻底碎裂。
- 若林恩让撤离航道在小丑与泰坦发动最后一击时就立刻锁定并公开,则信徒们能在噩梦合拢前全部撤离,但内城的噩梦追击会让后续 E753 防线比主线更早进入危机状态。
- 若林恩让主母带着残余军团在噩梦被击碎瞬间立刻去接纳小丑与泰坦,则这三人能在撤离通道完成最后撤退,但黑夜城内城会因主母缺席一整夜而进入失控状态。
- 若林恩让主母亲自到场指挥这一最后一击,则主母的指挥会让这场合击变得更精准更冷,但她本人会亲眼目睹小丑与泰坦的死亡,「孩子的最后一刻」会成为主母永生不可磨灭的刻痕。
- 若林恩让小丑在最后一击前与八音盒中的「乐者残响」进行最后一次对话,则小丑会以这种方式与乐者做最后的告别,「兄弟间的告别」会被永久记入信仰帝国最后一代传说。
- 若林恩让泰坦在最后一击中主动闪避一次本可击杀他的噩梦反扑,则他能活到 E753,但他会在这一生中永远不可能完全释怀,「泰坦的幸存」会成为贯穿 E798 的暗线。
- 若林恩让小丑的最后一击不以摧毁噩梦为目的而是为了给泰坦开路让他完成最后一击,则泰坦能完成致命一击,但小丑会以「从未真正杀过一只噩梦」的方式离开战场,「小丑的悲剧性」达到顶点。
- 若林恩让撤离航道在最后一击完成后被永久保留作为「小丑与泰坦的纪念通道」,则这条通道会在 S98 重建时被信徒奉为神圣,后续所有信徒在追求理想时都会被指引走向「小丑泰坦之路」。
- 若林恩让小女孩与所有信徒的「明日愿望」在最后一击中全部燃烧以最强烈的方式支持小丑泰坦,则这一击会带上亿万个愿望的重量,噩梦会以「被万众心愿击溃」的方式死亡,「愿望之击」成为永久传说。
- 若林恩让小丑的最后一击以其本体自爆为代价,则这一击的威力会突破天际,但小丑的自我会在爆炸中完全瓦解,「无序小丑的终焉」会以最壮美也最悲凉的方式落幕。
- 若林恩让泰坦与小丑在最后一击前先共同对王座方向进行一次最后的遥望,则这个遥望画面会被永久定格,「同伴最后的遥望」会成为后世信徒心中「兄弟之情」的最高描绘。
- 若林恩让撤离航道由小丑的八音盒残片进行最后维持,则这条通道会带上八音盒残片的独特韧性,但通道的开启时间会比主线更短,「八音盒的最后馈赠」因此成立。
- 若林恩让艾雯通过因果网络向小丑泰坦公开发最后命令「不许回头,完成任务后立刻撤离」,则小丑与泰坦会更清醒地完成最后一击,「王的最后军令」会成为两人兄弟情谊最庄严的形式。
- 若林恩让信徒们的祈祷声沿撤离航道回响以让小丑泰坦在死亡前听到最后一丝人间烟火,则这两人会在被黑火吞没前同时感受到一种「被爱」的温暖,他们的死亡会变得比主线更安详。
- 若林恩让羽毛笔完整记录下小丑与泰坦的最后一击包括他们的表情、动作、最后一句话,则这份记录会成为 S98 重建时最珍贵的「英雄之证」,小丑泰坦的名字会因此被永远传颂。
- 若林恩让主母亲自闭幕这一战并以王座之名公开宣判小丑与泰坦为「信仰帝国的最高荣誉」,则这两人会以「被王亲自封圣」的身份死亡,他们的死亡会成为后世信徒最高位的追求对象。
- 若林恩让撤离航道的最后一刻由小丑与泰坦共同把守,则这两人会以「守门人」的身份谢幕,而他们的守护会让这条航道成为 S98 重建时信徒心中最高位的神圣象征。
- 若林恩让这场合击的录像在战后由王座永久保存并公共播放,则后世每一个信徒在加入信仰帝国时都需要先看这一录像,「小丑与泰坦的最后一战」会成为所有信徒的精神源头。
