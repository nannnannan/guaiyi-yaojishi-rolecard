# E724·只能靠我们了·if线

- 若林恩在四大神王幻影浮现时率先挥刀斩向半边脸颊腐烂的因果女子，则因果锁链会最先崩断，背上的画家也能少受一轮旧日宿命的牵引反噬。
- 若林恩在面对紫罗兰大君残影时没有只用大君传授的招式、而是将属于自己的金色大梦与熊熊罪火尽数灌入夜魔刀，则他劈开那道不可逾越的「一米疆域」时会快上半拍，大君残影眼中泛起的欣慰涟漪也会更加清晰。
- 若林恩在单膝跪地呕血、看着大君残影崩解让路时低声说一句「这一次换我走在你前面了」，则背上的画家会轻轻握紧他的衣领，不再说出那句关于仇恨与高墙的叹息。
- 若林恩在道路尽头油尽灯枯倒下时仍死死拉住画家的裙角不肯松手，则画家会蹲下身轻轻掰开他的手指，把一缕苍蓝色的秩序本源留在他掌心护住他的心脉，再独自走向那尊白发海市蜃楼。
- 若林恩在画家化作苍蓝耀阳、向白发身影伸出小手轻唤「徒儿呀」的最后一瞬强撑着睁开双眼，则那一抹跨越万古的苍蓝泪光会永远烙印在他的灵魂深处，成为他日后直面灾厄时永不退缩的执念。
- 若林恩在边境被找到时还有意识、还能说话，则他会要求直接立在虚空里向整个主宇宙通告「画家走了」，那一句话会通过神疆烙进无数世界的晨昏。
- 若林恩在昏迷前用最后一丝力气在掌心写下「左左还没死」几字，则那行血字会成为他苏醒后第一个解释自己的凭据，艾维儿也会因此明白他接下来一生的方向。
- 若林恩没有递上风衣只是静静站在花海里看艾维儿抱画哭泣，则她会哭得更久更彻底，但这场哀悼在她心中被标记为「独自完成」，她与林恩之间多了一层不可说的距离。
- 若林恩在风衣之外再把自己肩上那条斗篷一并披到她背上，则她会真正哭出声、终于敢在那片花海里喊出一句「母亲」，林恩失去那条陪伴多年的斗篷。
- 若林恩在苏醒后第一眼看见的是银色幻想沉睡的侧脸，则他会默默在她额头留下一句誓言，这个微动作不会被任何外人看到，但心中会多一分等她归来的笃定。
- 若林恩在召集旧部讲话时加一句「画家死于我慢了一步」，则黑夜城的军心会更加敬重他但同时他也背上一道永远卸不下的自咎，紫罗兰旧部会有人背后流泪。
- 若林恩在讲话中回避「画家」二字只说「我们已经没有靠山了」，则他的语气会更硬，但紫罗兰旧部会集体感到一阵失控的不安，士气短期反而下跌。
- 若林恩没去泰坦大哥那颗星球，则那位战狂的混乱状态会继续延后数月，等他归来时主宇宙某些秩序的收复将多一层阻滞。
- 若林恩在花海下与艾维儿并肩站立足足一刻钟不发一语，则两人后续在政权交接上的默契会比主线更厚实，林恩成为她心底唯一一个真正「不被试探」的同盟。
- 若林恩在重建誓师上讲话时不承诺任何「一定会赢」，则将士会觉得他更可信，但也会有人担心他已经预判了失败，士兵夜间私下议论会增多。
- 若林恩在第二次神灵建军誓师上没有讲话、只让艾维儿代发，则黑夜城的民心会更多倾向王女而不是他，但他自己的肩膀会少一分压在「必胜」上的枷锁。
- 若林恩在全体狱卒下跪之日独自不跪、只对王旗深深望一眼，则他会被永远记录为「唯一一个站着送画家的人」，这件事会成为紫罗兰后世史书中最饱受争议的一页。
