# E724·只能靠我们了·if线

- 若林恩在边境被找到时还有意识、还能说话，则他会要求直接立在虚空里向整个主宇宙通告「画家走了」，那一句话会通过神疆烙进无数世界的晨昏。
- 若林恩在昏迷前用最后一丝力气在掌心写下「左左还没死」几字，则那个纸条会成为他苏醒后第一个解释自己的凭据，艾维儿也会因此明白他接下来一生的方向。
- 若林恩没有递上风衣只是静静站在花海里看艾维儿抱画哭泣，则她会哭得更久更彻底，但这场哀悼在她心中被标记为「独自完成」，她与林恩之间多了一层不可说的距离。
- 若林恩在风衣之外再把自己肩上那条斗篷一并披到她背上，则她会真正哭出声、终于敢在那片花海里喊出一句「母亲」，林恩失去那条陪伴多年的斗篷。
- 若林恩在苏醒后第一眼看见的是银色幻想沉睡的侧脸，则他会默默在她额头留下一句誓言，这个微动作不会被任何外人看到，但左左印记里会多一笔「他同意了第二次诞生」。
- 若林恩在召集旧部讲话时加一句「画家死于我慢了一步」，则黑夜城的军心会更加敬重他但同时他也背上一道永远卸不下的自咎，紫罗兰旧部会有人背后流泪。
- 若林恩在讲话中回避「画家」二字只说「我们已经没有靠山了」，则他的语气会更硬，但紫罗兰旧部会集体感到一阵失控的不安，士气短期反而下跌。
- 若林恩没去泰坦大哥那颗星球，则那位战狂的混乱状态会继续延后数月，等他归来时主宇宙某些秩序的收复将多一层阻滞。
- 若林恩在黑花海下与艾维儿并肩站立足足一刻钟不发一语，则两人后续在政权交接上的默契会比主线更厚实，林恩成为她心底唯一一个真正「不被试探」的同盟。
- 若林恩主动提出把三叉戟暂时收进黑夜城王座的背面供全民祭奠，则民众对紫罗兰的哀思会有一个具体容器，但林恩自己日后每逢作战都得从王座背面对三叉戟致意。
- 若林恩在重建誓师上讲话时不承诺任何「一定会赢」，则将士会觉得他更可信，但也会有人担心他已经预判了失败，士兵夜间私下议论会增多。
- 若林恩在誓师结束后独自走向左左冰封的时间之外方向一眼不发，则他会在那段路上把一句「对不起」反复咀嚼到烂，回黑夜城时整个人冷上许多。
- 若林恩选择去先唤醒船长而不是处理智械小姐的后续，则银色幻想的神格反噬会更深，林恩将不得不在 E727 之前花额外时间处理她的两次精神崩溃。
- 若林恩决定在人偶家的病房里多留一夜、陪她聊蓝星时代，则人偶家会多一段真正释放的悲伤，林恩也会获得一份来自她的「永不责怪」信件。
- 若林恩在第二次神灵建军誓师上没有讲话、只让艾维儿代发，则黑夜城的民心会更多倾向王女而不是他，但他自己的肩膀会少一分压在「必胜」上的枷锁。
- 若林恩在紫罗兰画像前把她那张笑着的脸用手指轻轻抚过一下，则画像表层会因此留下一道极淡的指纹灵印，往后任何看到它的人都会多感觉一丝暖意。
- 若林恩在全体狱卒下跪之日独自不跪、只对王旗深深望一眼，则他会被永远记录为「唯一一个站着送画家的人」，这件事会成为紫罗兰后世史书中最饱受争议的一页。
