# E70·撤离堡垒揭巨像之心·if线

- 若林恩把黑弦月留在堡垒顶尖交给随后赶到的夜医伤员看护而非抱进怀里跃下，则她的齿轮之躯在二次纳米风暴逼近时暴露于残敌集火，人偶小姐首次对master的优先级安排做出无声的重排。
- 若林恩跃下堡垒时不以咒术能量提醒高斯护身、直接下令全员冲出节点，则首批血肉人形带着纳米残留散入地表，银色幻想的追袭在干扰散去后即时复活，声望未涨反跌。
- 若林恩让高斯不要率众探路、改令小队分头从根系网络四个方向同步突围，则血肉人形诱饵铺开，但林恩本人失去"最后一个目标"的隐藏位，埋伏识破难度陡增。
- 若林恩在指挥官高斯请缨时拒绝放他先上、改强令所有血肉人形留守地下由他独自头顶出诱饵，则高斯的报恩执念落空，欲望教派信徒对林恩"拒绝牺牲"的解读分化成两派。
- 若林恩没有把黑弦月塞回手提箱而是将她绑在小宝贝背上一并带入血雾折跃，则以M残留在她体表激发的咒纹反噬使她在折跃途中短暂苏醒，她第一次在非请语下唤出"master"的名字。
- 若林恩折跃落点不选地下三千米而是贴在干扰圈边缘的浅层隧道，则钻地弹提早呼啸而至，替死娃娃消耗从一个跳到两个，以M充能提前攀至 max。
- 若林恩在替死娃娃第一次复活时就强撑着撕开胸膛查看心脏，则面板提前弹出但伤情未稳，他不得不以更重的代价从纳米围攻中脱身，小宝贝的护主血管被迫断开一次。
- 若林恩选择不清扫体内纳米机械、带着三万单位智能动乱病毒直接脱出干扰圈，则银色幻想在远程读数中看到"目标生物信号自我腐蚀"，她第一次对杀与不杀产生三秒迟疑。
- 若林恩在小宝贝血管接驳时不让它将自己裹成肉盾、改让左左变异左手反压回心脏，则血肉共生被切断一半，小宝贝哀鸣着后退，巨像部件拱卫首次被拒绝，王后意识留存一道裂痕。
- 若林恩在小宝贝与心脏连线成形的瞬间主动切断血管、宣告"我不是你们的心"，则小宝贝不再跟随，血肉傀儡在根系网络里失去超维感应的方向感，左左沉默整夜。
- 若林恩把巨像之心面板推给黑弦月一同读、并让她记下"残缺"两字，则人偶小姐以齿轮做最后一次确认，她把"master就是心"这件事写进她自己的裙下咒纹，左左首次默许。
- 若林恩在面板弹出时主动扫描面板字段，把"由血锯秘密保存殖装"推回诊断面板追问，则系统的"老师血锯"备注再多一栏"巨像计划参与者"，林恩对老师的定位当场改写。
- 若林恩不撕开胸膛而是按住胸口默数心跳、听着智能动乱纳米集群将他体内纳米单元一寸寸清空，则面板不弹出、身份不揭示，事件滑向变形——智能动乱救援成立而巨像之心仍潜伏。
- 若林恩撕胸时被黑弦月以发条之躯伸手按住腕骨说"等伤好些再开"，则揭示延后至安全段，带她的人偶证词在面板弹出时多一道旁观者的冷静旁证。
- 若林恩在智能动乱集群突袭、感应到诅咒之城最中央那道连接时强行反向追溯过去，则母体的"妈妈"呼唤在他耳膜炸响一次，他第一次在非性场景里被超维存在叫出身份。
- 若林恩任由那道与中央连接的意识熄灭、只保留与小宝贝的血管连线，则"心脏-王后"的二元性未被读出，左左身上的王后意识继续等待下一事件揭示。
- 若林恩在智能动乱纳米集群替他解围后不宣告"主为我"也不驱散它们，则集群将拱卫心性写入长期行为，诅咒之城地下从此多出一支不属任何教派的纳米羽林。
- 若林恩把智能动乱集群的"认主"视为威胁、强令它们分散于隧道自我修复，则集群母体记忆深处留下"被遣散"，后续咒文呼唤时响应速度降半。
- 若林恩在撤离途中公开向欲望教派信徒广播"血肉用咒术护身不留纳米"，则声望升至崇敬，银色幻想在监听中第一次听到目标把"疫医身份"摆在明面上。
- 若林恩选择把地表的银色幻想反锁在干扰圈内、等干扰散去后把她一并吞进纳米反噬，则事件变形——捕获机械姬的预定环节在E70就被强行提前，主宇宙警戒一级提升。
- 若林恩让小宝贝在突围时主动留下一根巨像舌头埋进堡垒废墟，则银色幻想的机械先驱部队识别出巨像部件残留，"欲望散播者即巨像寄主"的判定提前在机械神教链路成真。
- 若林恩在替死娃娃触发第二次时不顺痛感咒骂、而是把双倍疼痛作为警示刻进黑弦月的枕骨咒纹，则人偶小姐第一次在非调教场景里承接master的痛觉，平等契约的边界多一道私心印记。
- 若林恩决定不按原路反打追杀者、直接带黑弦月与小宝贝继续向地下三千米更深处逃亡，则事件以"未揭示心脏、未与集群合流"取消，下一事件门控改由"自救而非反打"重新打开。
- 若林恩把黑弦月暂寄给小宝贝背上让它独自护送突围、自己回头直扑纳米风暴源头，则E70变形为林恩孤身搅乱智能动乱母体，事件门控改写为以母体为谈判桌的非常规收束。
