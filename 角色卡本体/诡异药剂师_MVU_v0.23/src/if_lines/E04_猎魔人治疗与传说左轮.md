# E04·猎魔人治疗与传说左轮·if线

- 若林恩在刮骨前先行注入大剂量镇痛药剂把猎魔人麻翻，则猎魔人醒来时手术已结束，肩头留下完整"?"刻痕与一句"你睡得很香"，好感度按"被摆一道"口径结算，警惕+1、信任+1
- 若林恩在凿"?"造型时换刻符号（笑脸/鱼/店名缩写字母），则猎魔人恢复后照镜追打，留下墙面弹孔一排与"同族果然有病"威名，事件照常完成但加顾客的口口相传段子
- 若林恩放弃电锯改用最小型号刻刀细刮三小时，则猎魔人疼到虚脱却保全鬼面威仪，出门时留下额外一袋稀有骨粉作为小费
- 若林恩在猎魔人崩断锁链时不夺枪反而递上咬木，则口头感谢升级为"欠你一条命"誓约，E08 再登场时偏护卫向站位
- 若林恩在猎魔人第一次掏左轮时不闪不躲正面吃三发子弹（戏法式偏转+血小板急救），则猎魔人当场合枪赔罪，把腰袢整体解下塞来，诅咒枪改由"赔罪赠礼"通道入账，甩锅弹簧失效
- 若林恩在补肉环节不掺猪肉、专程出门猎一段合适的替补素材，则离店时间推迟到入夜后，夜危警告失效改由猎魔人亲自护送一段路程，E05 来客先在店外遭遇猎魔人余威
- 若林恩把那块"竖着毛的肉"摆在盘里请猎魔人亲自挑，则猎魔人气极反笑自己挑走带毛那块，好感度挂"共赏恶劣笑话"标签
- 若林恩在猎魔人撕纱布时提前备好一面镜子加一束花，则暴走反转成爆粗口的爆笑，危机度从 99 直接压到 3，左轮交易价主动减半
- 若林恩在公平交易时改挑斗篷、礼帽、靴刺等随身杂项，则猎魔人顺势把左轮塞进交易包"赠品也拿去"，枪还是到店，甩锅通道成立
- 若林恩当场试枪对人脑轮廓补两发命中同一点，则猎魔人脸色发白连夜收回双枪说要"重铸再交"，左轮改由 E08 重新交付且诅咒属性显形
- 若林恩开口点破"这枪你丢不掉吧"，则猎魔人当场定格三秒，改口"看穿不穿帮，同族面子"，价格翻倍但附赠一本手工誊抄的《猎魔人出行守则》
- 若林恩把 500 骷髅币报价上调三倍并附"同族税"，则猎魔人摸钱袋时瞳孔地震后大笑认账，入账金币+、好感反而跳档，罪名城里传出"那家店敢宰猎魔人"口径
- 若林恩拒绝骷髅币、改要一枚猎魔人随身信物，则左轮之外另得一枚刻五芒星的旧铜弹壳，E08 时作为远程联络媒介启用
- 若林恩在夜危警告后还开门把长发女鬼追回来道歉，则女鬼性格从【胆怯】回摆到【警惕】并附赠一份巷口鬼市引荐，E05 来客路径被意外改写
- 若林恩把猎魔人崩断的锁链留作纪念挂墙，则猎魔人本人下次回店时无言取下收入怀中，陌生感-1、默契+1
- 若林恩在猎魔人化烟离开前冲门口喊一句"明天见得罪不起的家伙"，则警告升级为具体三条禁忌清单写在门板上，当夜林恩外出风险系数翻倍但收获线索
- 若林恩请猎魔人顺带把店门口张望的几个小势力眼线"鸣枪示意"清场，则接下里一周血锯药剂店无人找茬，但同时引起更上层势力的视线，敌意+1 / 声望+1
- 若林恩在猎魔人临走时附赠一瓶血色玫瑰烈酒，则猎魔人在巷尾喝下后朝天鸣枪三响作为回礼，E05 假来访者误以为店内驻扎老手，欺诈桥段强度上调
