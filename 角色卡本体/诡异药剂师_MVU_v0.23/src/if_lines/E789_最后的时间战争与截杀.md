# E789·最后的时间战争与截杀·if线

- 若林恩选择优先救冬泉谷的渡鸦载体而不是紫罗兰旧地，则紫罗兰渡鸦在保留完整记忆时被空白夺去，「奈奈子」在 E790 已经被迫二次自杀。
- 若林恩主动与画家残影联手打乱悖论链布局而不是各自独立，则两人合作导致画家残影在 E790 出现「活着的画家」版本，她会与林恩面对面算一段旧账。
- 若林恩放任悖论截杀中等事件先发生并抓紧最后窗口闪电阻止，则他能在最后一刻保住两个载体，但代价是烧掉自己三个月记忆作为时间补偿。
- 若林恩主动将十万渡鸦分为三组交给不同队友看护，则在 E790 他无法同时确认三组状态，被迫接受「有可能某组已经殉灭」。
- 若林恩让左左把最后时间桥改造成单向密封把空白实体困在外面，则左左因此失去回程路径，E790 她被自己亲手封死的那扇门挡在林恩身后。
- 若林恩主动以自己为诱饵把十万渡鸦暂时藏置于自己身体，则他要承受悖论反噬的具体化——四肢开始从末端化为灰白虚化。
- 若林恩放任某只高重量渡鸦自愿牺牲自己作为截杀吸引，则他失去那只渡鸦的所有关联记忆，但剩余渡鸦因烈士的自杀而休克一秒，那一秒里林恩完成转移。
- 若林恩选择把悖论锁从一个渡鸦转移到自己心脏，则他成为新的截杀目标,在 E790 被空白实体优先劫持，左左必须以自己的命换回他。
- 若林恩主动把左左当年为他做的所有事情一句一句向空白实体陈述为「她是我最大的悖论」,则空白实体会被这堆「林恩专属悖论」淹没计算力，截杀出现一秒迟滞。
- 若林恩让织梦在过去从未知情的情况下悄悄进入截杀场作为变量，则空白实体因为多出一个未纳入计算的灵能而反应偏移。
- 若林恩主动把自身每段降临记录焚毁一份以削减悖论链，则他变相缩短了自己的存在历史，主宇宙的某些红颜开始无法记起部分关于他的画面。
- 若林恩放任悖论压力沿时间桥倒灌到织梦所在的过去，则冬泉谷的织梦会突然感知到，她在那一瞬独自拔剑准备穿越到当前。
- 若林恩主动把自身某段根骨作为悖论诱饵交给空白实体，则他能转移空白注意力,但被交出的根骨会成为 E790 空白实体研究的核心。
- 若林恩选择让画家残影接过悖论链一半而不是独自扛，则画家残影在 E790 因为过载短暂失去语言能力，她只能用画而不是话告诉林恩意图。
- 若林恩主动用咒瞳反向穿刺空白实体的影像核心，则他能短暂「看到」空白实体的本体形状——那是一个他曾吻过的脸的反面。
- 若林恩放任悖论截杀达到 99% 才启动梦主印记反制，则反制成功率大幅提升,但他必须承受悖论侵入带来的濒死体验。
- 若林恩让喵喵叼走某个渡鸦载体跳时间窗一次，则那只渡鸦彻底从悖论上除名，但喵喵也因此永久失去回到冬泉谷的通道。
- 若林恩主动朝悖论链洒一把他自己被抽离的渡鸦记忆碎屑，则悖论无法识别记忆归属，截杀链出现混乱，但他也因此失去那段记忆。
- 若林恩选择把左左交给某个渡鸦载体作为共生锁，则左左成为新的活体悖论，她与渡鸦共享命运，E790 空白实体攻击渡鸦时左左同时受创。
- 若林恩放任悖论截杀成功后立即以梦主印记回溯一秒，则那个渡鸦在死过一次后复活，渡鸦从此带着「死过一次」的记忆，它与林恩的关系被根本改写。
