# E659·置之死地与极尽罪火·if线

- 若林恩在罪火褪尽前就提前把神格屏障藏在脊椎而非心脉，则魇王掌心落下时屏障触发位置偏上三寸，反噬路径改写，第一条裂缝出现在他颅骨而非胸膛。
- 若林恩在矛雨第一轮就主动退却、贴着一根刺穿肩膀的长矛滑跪装死，则钉杀节奏被打乱，魇王命令追加第三轮时已经走到他十米之内，金色梦境的包覆半径缩短一半。
- 若林恩不主动迈向矛雨而是倒地装作被钉穿当场，则因果神王终止命令的时机提前两轮，她能用来停手的「体面」筹码更足，但林恩保留的反击余力也更容易被识破。
- 若林恩踉跄前行时故意放一根长矛贯穿自己左心房旧疤，则他在伤口里埋了一缕罪火种，后面极尽一刀的烈度+10%，但他苏醒期再延长七天。
- 若林恩朝着矛雨方向直视因果神王一眼再闭眼，则缥缈女子在他倒地时瞳孔颤动的那一下被放大，她从余火中现身的瞬间争夺意志的裂缝多一道。
- 若林恩在倒地前用左指在虚空画下半枚小丑纹章，则哭泣小丑在 E660 狱中怒吼的内容多一句「他给我们留了记号」，他脱离狱卒阵营的时刻提前一轮对话。
- 若林恩没回应魇王「你又何必执着」那番劝降，只在心底用左左留下的最后共振敲一下，则体内神格屏障激活时机被他主动提前半秒，魇王的瞳孔猛缩出现在伸手前一拍。
- 若林恩在屏障张开瞬间故意让一根长矛的腐化之力渗入屏障内壁，则极尽一刀中多带一缕无序异色，被烧到的腐化神灵在湮灭前先浮现一次「鬼」的紫黑痕迹，事后林蒙能反查的腐化链条多一条。
- 若林恩唤王戟归位时同时催动三叉戟里封存的左左旧鳞让它在虚空浮现一道绿光，则三叉戟破空进城时多一道裂响，魇王转头那一瞬画面里多一笔「他旧伤未愈」的判断，金币神疆的狂潮末端多一道短暂的龙吟。
- 若林恩在【罪】一刀斩落前低头对左左的位置留一句「借你最后一片鳞」，则左左留下的残魂在他识海深处一亮，极尽罪火中多一道锋利刃，但他从火中走出后左腕永久烙下一枚蛇鳞焦痕。
- 若林恩在金色梦境展开时主动把它压缩到只罩住魇王与他两人，则外部腐化神灵冲入的数目缩减为零，薛定谔的救援窗口没有打开，E660 小丑赶到时面对的是一片完全封闭的战场。
- 若林恩在被长矛钉跪瞬间对下方某个腐化神灵笑了一下，则那尊腐化神灵在塌陷后第一个转身叛逃，E662 后腐化者暴露名单里少一人但多一条「渡鸦笑过」的谣言。
- 若林恩在因果神王伸手终止命令时隔着虚空对她点头致意，则缥缈女子在 E660 余火中挣扎的两个意志中「她」的那一缕更占上风，细线被拽紧的力度打折三成。
- 若林恩在最后一刻体内屏障里多塞一枚他从画家那里薅来的万物波动石，则极尽一刀结束后他指尖残留一缕不灭的创造之火，为 E663 触碰万物神格时的亲和度埋一笔暗账。
- 若林恩引法则浪涛入体时主动让它先冲过自己的三叉戟烙印再入体，则【血肉】【生命】【灵魂】【死亡】四法则重铸的秩序被打乱，他醒来后躯体恢复完整但灵魂留下一道需要事后缝合的窄缝。
- 若林恩在释放金色梦境时故意让它先扫过一遍跪迎的腐化神灵再罩魇王，则神灵群里多三人被烙印「他曾看过我」，事后部分腐化者内部传开「渡鸦认脸」的耳语。
- 若林恩【罪】一刀斩落时把刀锋刻意偏向因果神王一尺，则缥缈女子在烈阳中被灼到左肩，她在 E660 现身的瞬间两个意志的拉锯更剧烈，「原来你还活着」那句低语的对象变得暧昧。
- 若林恩在金字塔般的矛雨里用最后力气折断一根刺穿大腿的长矛握在手心，则极尽一刀斩落时他双手执戟一手执矛，断裂长矛随罪火一起汽化，塌陷的第一位面里多一道漂浮的矛形烙印。
- 若林恩决定这轮不释放金色梦境、直接催动极尽罪火屠场，则魇王在刀落前脱身撤离，「罪」斩空，整个事件转向变形收束，E660 的救援改为他独自漂流在法则洪流里等人打捞。
- 若林恩在屏障启动瞬间对身边某个最近的梦魇投出一句「下一轮回见」，则那个梦魇被罪火烧尽前最后一帧传入沉眠者视野，梦魇集群后续复活时身上多一缕警惕标记。
- 若林恩在倒地装死期间主动切断初诞者之力对外的所有波动，则因果神王无从感知他是否留了后手，她选择终止命令的决心多依赖直觉而非判断，事后她对他「身份」的怀疑多加一层朦胧。
- 若林恩在极尽一刀斩出瞬间把一半的烈度压进自己灵魂而非外放，则「罪」的威力打折但反噬变慢，他在 E660 漂流期保持一缕清醒，能在被救走前短暂睁眼看见因果神王的缥缈轮廓。
