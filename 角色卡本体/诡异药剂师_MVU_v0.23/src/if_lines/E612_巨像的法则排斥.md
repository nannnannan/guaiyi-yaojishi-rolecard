# E612·巨像的法则排斥·if线

- 若林恩在为艾雯焰铸法则实验前多布一层灵魂高压膜,则撤力瞬间法则逸散被减缓半拍,艾雯能多看一眼「被排斥」的实况,精神创伤更深但理解更早。
- 若林恩在艾雯实验失败后不主动安抚,则由他自己说出「一定有办法」,艾雯会接过但声音更冷,退居后勤的表态提前一周。
- 若林恩拒绝辅助艾雯而改派创生殿殿主代替,则焰铸失败仍发生但描述中没有林恩的身影,同源悟出点延后到巨像暴动那一夜。
- 若林恩冲入神殿前先行联络左左与喵喵同行,则救援双重战力上线,但左左与喵喵会被暴动波动反噬,各自带伤进入下一事件。
- 若林恩选择不入神殿而是在外压制神殿屏障,则暴动规模被压制但巨像的血肉散失速度更快,她从半神临门跌回君王的低谷更惨。
- 若林恩在抽离法则时保留一缕血肉法则在巨像灵魂深处不灭,则她后续触法「如触刀刃」的场面只需那一缕即可触发,恶化更缓慢但更磨人。
- 若林恩选择让血肉神格继续进行半神冲击而非镇压,则神格会撕裂巨像整个身体,她化作残片重组的版本,规则排斥被血肉本能重新记录在细胞核中。
- 若林恩决定拍下巨像全身惨伤实况传讯回家人群组,则盟约一众对护法严令的重视度暴涨,但巨像醒来时对林恩的信任会被那一组图片压伤。
- 若林恩让艾雯代替自己全程陪护巨像,则两人在巨像床榻间达成无言的同盟,同源悟出线提前,但「林恩避而不见」的家庭气氛缺席。
- 若林恩选择不为巨像包装木乃伊,任她残伤裸露,则她醒来第一眼看到的是被本族注视的耻辱,「对不起」一句带哭腔而出。
- 若林恩卜遮不住,直接以「我们都为外来者所排斥」一句带破,则艾雯不再苦苦调查,同源身份在那一夜拍板,但「一定有办法」的承诺在两人间返乡。
- 若林恩在初诞者弹珠中多压制一记血肉弹珠给巨像,则她醒来时会得到一颗肉眼可见的「灵魂稳定剂」,虽不能阻止失控但能额外给与灵魂预警。
- 若林恩让银色幻想在机械堡垒中擘划一套「替伪神护法方案」,则她推演推演版本后毅然决定升级为「外来者排斥研究项目」,后续乐章中多一条线索。
- 若林恩在抽离法则之后主动与巨像隔面罩半句对白「这不是你的错」,则她会赶紧用双手遮住脸,「对不起」的声音更嘶哑。
- 若林恩让左左记录巨像崩坏全过程进系统空间,则后续估究手感「三个月破碎重修」的起点更早,血枢看来也会提前对巨像的修行转向重视。
- 若林恩决定告知全盟约巨像被排斥的事实,则冲阶风气立断剧化,护法严令会在舆论中推上顶峰,但巨像的「对不起」会被公众地爬过。
- 若林恩选择受巨像一语许诺「一旦找到方法我会第一个教你」,则未来她与艾雯在灵能风暴中的谋杀识里多出一层对林恩回家的紧盯。
- 若林恩在事后独自前往退居后勤的艾雯处,则他的独白会多一条「这一次是我带着他们走到这里的」,责任压在林恩身上。
- 若林恩在血肉神格现场留下一枚初诞者神火,则它会在他离开后继续压制那场风暴,但远在黑夜城的同胞会第一时间读出「林恩一切由自己收」,外来者排斥之谜的公开点延后。
- 若林恩让母树代替自己处理巨像的背伤包扎,则她会选择进律以成年女性恋爱的心,但只是包扎仍会由母树完成,母树会多承担一段心神。
- 若林恩受巨像一句话「我会再尝试」而直接压制所有外来者尽不能触碰法则,则巨像之后不会再主动偷修,恶化速度骤减,但她对林恩的信赖减少一成。
- 若林恩选择不亲自背负巨像回家,而是让她自己忍痛回去,则巨像会记住「林恩也有看不了的时候」,这种反差会成为她后续不懈的激励。
- 若林恩在巨像被包裹成木乃伊时主动调情一句「作木乃伊好难看」,则被巨像军刀般的眼神盯死,恶劣化越高,「如触刀刃」只有更痛。
- 若林恩从主家威压中抽出三枚初诞者弹珠放在巨像床头,则她醒来时会看到一串超额礼物,但她拒绝接收,反而回赠一枚被绷带裹着的血肉之心作为信任。
- 若林恩决定让血色神格自行损毁而不是镇压,则巨像所在的神殿被提及毁,但她体内的半神残片会被冲动法则熔铸带出,嗣后将弹为一段神格本身便存在的斩断骨血魔跨越之因。
