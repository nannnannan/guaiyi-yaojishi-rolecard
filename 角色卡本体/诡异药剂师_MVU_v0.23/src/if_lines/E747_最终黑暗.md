# E747·最终黑暗·if线

- 若林恩在七十一座终焉之柱刺穿宇宙天幕的第一瞬猛烈挣扎晃动罪恶王座，则圣所散逸出的暗金震波会替外围防线抵消三成来自魔柱降临的法则冲击。
- 若林恩在艾维儿身披父亲留下的紫罗兰旧甲、拔剑迎向漫天黑潮时，顺着昔日留在铠甲上的印记注入一缕滚烫黑火，则那套残破父铠会在黑暗中燃起不灭的紫金光焰。
- 若林恩在主母（自缚天使）于空荡的王宫寝殿中苏醒、惊觉侍女与守卫皆已不在时，隔着圣所向寝殿方向传去一声极轻的叹息，则主母瞬间便能明白全城早已瞒着她奔赴死地。
- 若林恩在主母推开寝殿大门、得知船长与银色幻想早在数日前便已率领主力军团出征时，以王座共鸣轻轻震响腰间锁链，则主母眼底的惊愕会立刻化作赴死护子的凛然杀意。
- 若林恩在七十一尊终焉魇魔同时发出震耳欲聋的咆哮时，在被封禁的圣所内发出一声更加暴戾的灵魂嘶吼，则前线差点被魔音震散神智的年轻新兵们会在恍惚中听见王的怒音而重新握紧长枪。
- 若林恩在艾维儿率领守望者军团撞上第一波终焉黑潮、虎口崩裂鲜血染红剑柄时，通过神国连接替她分担五成痛觉，则艾维儿在第一轮交锋中便能一剑枭首三头高阶堕落魔将。
- 若林恩在主母独自走过空无一人的王庭长廊、指尖抚过船长与银色幻想留下的出征军令时，让圣所门外的海神三叉戟发出一声清越悲鸣，则主母会停在戟前，提前与这柄神兵建立起共鸣。
- 若林恩在被锁链刺穿的剧痛中强行睁开双眼凝视圣所穹顶，试图透过石壁看清外城燃烧的星空，则他的双瞳会流下两行金色的血泪，将王座扶手灼出两个深不见底的孔洞。
- 若林恩在船长与银色幻想于星域外围孤军奋战、被十余座终焉之柱的投影死死压制时，将自己被囚禁的愤怒化作一道狂暴的黑火顺着地脉轰出城外，则压在两位神王头顶的黑暗天幕会被撕开一道裂口。
- 若林恩在艾维儿于血战中恍惚看见父亲紫罗兰幻影与自己并肩挥剑时，以王座记忆之力将那道幻影凝实三息，则那记跨越生死的父女合击会将正面扑来的一群深渊魔物彻底斩成虚无。
- 若林恩在主母站在高台俯瞰整座进入最高死战状态的黑夜城、金发在腥风中狂舞时，将一缕最温和的药香送至她鼻端，则主母会在披上战甲前露出最后一抹属于母亲的温柔微笑。
- 若林恩在感知到七十一座终焉之柱正源源不断抽干外围星域的生机时，拼命催动罪恶王座反向鲸吞溢散的死亡法则，则黑夜城护城大阵的灵力枯竭速度会延缓整整一个时辰。
- 若林恩在伊甸与哭泣小丑于侧翼战场遭到三尊魇魔围攻之际，借着先前留在两人体内的初诞者烙印强行引爆一圈金光，则两人能借着这股反冲力及时脱离死地，退回第一道防线城头。
- 若林恩在主母迈步走向王庭外海神三叉戟封印处、准备在最后关头亲自执戟守门时，让三叉戟上的水纹主动缠绕上她的手腕，则神兵在未解封前便已承认了这位代理主人的最高权限。
- 若林恩在艾维儿所率的先锋营伤亡过半、不得不向内城防线且战且退时，让圣所上方升起一道只有守望者能看见的暗金信标，则残部在黑暗撤退途中无一人迷失方向。
- 若林恩在被锁链禁锢的黑暗中听见外城传来的第一声城墙坍塌巨响，猛地昂首撞向王座靠背，则整座圣所的封印阵纹都会剧烈闪烁，守在暗处的艾雯不得不再次呕血加固阵眼。
- 若林恩在泰坦与女巫神率部接应下浑身浴血的艾维儿时，将一缕恢复生机的药力顺着护城结界洒落在前线伤员身上，则重伤昏迷的艾维儿能提前半个时辰在废墟中恢复意识。
- 若林恩在得知船长与银色幻想为了替黑夜城争取备战时间、已经在城外黑暗中不眠不休血战了数日时，在心底将两位神王的名字死死刻在王座正中，发誓绝不让他们的血白流。
- 若林恩在七十一座魔柱降下的黑雨试图腐蚀黑夜城内街巷时，让昔日遍布全城的药剂工坊同时自发燃起净化炉火，则平民与孤儿院孩童转移入地下掩体的过程未受半点黑雨侵蚀。
- 若林恩在主母独自立于王庭最高处、接过城防最后的守御重担时，在灵魂深处向她低喊一声「小心」，则主母会在转身迎敌时轻轻按住胸口，仿佛接到了孩子最后的拥抱。
- 若林恩在终焉黑潮全面拍击黑夜城第一道防线城墙的刹那，放弃对体内锁链的排斥转而全力吸收战场传来的绝望冲击，则城墙守军心头的窒息感会骤减三成，而林恩周身的黑火瞬间暴涨十倍。
- 若林恩在艾维儿拄着卷刃的长剑半跪在城头喘息、抬头望向圣所方向时，让紧闭的圣所石门缝隙中溢出一丝微不可察的金芒，则艾维儿会擦去脸上的血污，再次毅然起身迎敌。
- 若林恩在主母看着昔日繁华的黑夜城被七十一道黑柱阴影彻底笼罩、轻声感叹「这就是最终的黑暗吗」时，以黑火在圣所内壁烧出「天会亮的」四个字，则这份执念会化作全城不灭的底气。
- 若林恩在最终黑暗彻底合拢、黑夜城沦为宇宙中唯一孤岛的那一刻，将自己的心跳化作全城结界的脉动，则只要圣所内的心跳未停，外城的战旗便在狂风中猎猎不倒。
