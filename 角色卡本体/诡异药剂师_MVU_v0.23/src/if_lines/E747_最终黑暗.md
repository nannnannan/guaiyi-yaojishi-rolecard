# E747·最终黑暗·if线

- 若林恩在七十一柱落下瞬间主动把王座黑火推出一道缓冲波,则他承受的双重压力会先撕开他自己一条裂缝,后续防线更稳但林恩的燃寿被提前抽走三成。
- 若林恩在主母全军投入裂口时通过黑火对她说「别全投,留一支回来护你」,则主母会摇头仍全投,林恩从此知道这句话没用。
- 若林恩让银色幻想只堵一根柱影而不是迎战两侧,则她能保住更多机械军团,但另一根柱影会更快逼近信仰殿,后续 E750 信仰城会更早进入「孤城」状态。
- 若林恩让船长固定节点而不是投入冲击,则船长能多保住一缕本源留给 E753,但有一处节点会因缺他而失落,远处某颗星域会被黑暗覆盖整整一日。
- 若林恩让艾维儿把蓝色权柄全部压在神界边缘,则神界能撑到最后一刻,但王座黑火会稀薄一层,林恩在 E754 城破瞬间几乎要坠入失控。
- 若林恩以心声向某柱高阶噩梦喊话「你们的主人不该要我死」,则那只噩梦的攻击会停顿一秒,但会引来更多柱影朝王座聚焦。
- 若林恩把自己的意识分一缕沿因果网络向外探查每一根柱影,则他会首次亲眼看见每柱背后的魇王,他对终焉的认识从「灾厄」具象化为「有名字的敌人」。
- 若林恩在外环第一次断裂时把那一带信徒的信仰压成一枚心火种子,则这枚种子会成为 E750 信仰城初期最重的一份燃料,但信徒被压瞬间会同时失去意识。
- 若林恩让主母不要在第一轮就全军投入而是分轮上前,则黑夜城军团能多撑一日,但外环的信徒会更快被黑暗覆盖,林恩在王座上能听到他们最后一刻的祷告。
- 若林恩主动调动人偶家的丝线把七十一柱间距扯开半厘,则柱们的协同比主线略弱,防线能多撑半日,但人偶家的丝线会在这一拉之下烧断三成。
- 若林恩让旧旗帜在黑风中折断的那一面被羽毛笔以灵能接住保留完整,则这面旧旗会在后续 E754 被主母亲手插在王庭广场,成为「王旗不倒」最后意象。
- 若林恩在王座上主动承受到底而不再分担,则所有军团作战压力会减轻,但林恩的燃寿会从「可控」进入「倒计时」,后续 E748 他听到真相时会带着更沉的体力伤。
- 若林恩让艾雯把公共叙事在黑暗到来时立刻撕开一角,则信徒们在震惊中会失去一半斗志,但他们也会更早进入「知情赴死」状态,后续整场战争的真诚度升高。
- 若林恩反过来让艾雯把所有真相继续压住,则信徒仍以「黄金时代即将胜利」的幻想战斗,他们死时脸上带着希望,信仰帝国的悲美度翻倍,但事后揭穿会让高层集体崩溃。
- 若林恩在这一夜从王座方向给每一位军团主帅发一道「不许回头」指令,则所有主帅在后续作战中都不会回望王座,他们会把背影留在林恩意识里作为最高位帧。
- 若林恩在小丑从另一侧赶到前主动在黑火中给小丑画了一张防区图,则小丑找到战场时不需要浪费一秒,他能比主线更早撕开一只噩梦,但他杀完那只噩梦后会陷入短暂沉默。
- 若林恩让黑夜城所有医院在第一轮落下时主动把灵能全部抽给王座,则医院里的病人会以平和心跳结束生命,但他们的灵能会为之后 E750、E751 的防线续命。
- 若林恩在主母分派防区时通过黑火对她说「你守内城就好,出外让我」,则主母会第一次违抗他的命令,她还是出来了,后续她在 E754 挥剑斩腐化者时一直在心里念这一违。
- 若林恩让左左此刻立在王座肩上陪他承受整个第一轮冲击,则她会一声不吭陪他看完,后续她出场时眼里已经多了一层「看过最终黑暗」的成熟。
- 若林恩让喵喵在第一轮落下时以自己肉身为王座当一层缓冲,则喵喵会被烧得半边毛发焦掉,但她没有躲,后续她在所有战斗里都占据「为王挡火」的位置。
- 若林恩主动把罪恶王座的黑火分一小缕递给旧旗帜让它在黑风里燃起来,则旧旗帜会在整个第一轮冲击中烧得狂亮,所有信徒在那一夜心中都有一个「不可熄灭的旗」意象。
- 若林恩决定整个第一轮不与任何人通过因果网络说话只沉默观战,则所有军团成员会感受到一种「被静默送行」的沉,后续他们作战时都会带着这一份共同沉默。
- 若林恩在第一轮结束时主动以黑火点亮一颗照明弹升到主宇宙上空让全域都能看到,则所有信徒会同时抬头,这颗照明弹会成为 E750-E754 期间他们的「希望之灯」。
- 若林恩在金色神疆第一次断裂时主动以王座之力把缺口临时拼合一次,则拼合成功但会耗掉他整整一缕本源,后续 E748 他听到真相时躯体更虚弱。
- 若林恩让军团成员每人带一件私人之物上战场作为「回家凭证」,则战场上会洒落无数小物件,后续 E754 城破后这些小物件会成为后世考古学家重建战场的关键证物。
- 若林恩主动接入战场某一处噩梦柱视角从内侧看一次,则他会首次看到柱中的「燃料」其实是无数被分解的信徒与无序生物,他对这场战争的愤怒从这一刻起完全点燃。
