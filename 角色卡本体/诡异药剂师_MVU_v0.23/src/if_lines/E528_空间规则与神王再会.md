# E528·空间规则与神王再会·if线

- 若林恩在指缝黄沙将划未划时主动停手更长一拍，则裂隙停滞时间更久，他对「不迅速闭合」的把握更稳，回到神王处时那一刀的优先级被推高一档。
- 若林恩用食指点的不是黑暗而是墓室地面，则繁星微光落在脚边而非头顶，光球研习的收束姿态变成「先踩过无数星辰再抬头」，「我不曾理解何谓初诞者」的自白延后向后续事件回填。
- 若林恩在食指点光前先开启灵能高维测距扫一眼整个墓室，则下文与神王测「半米即星系」的判定手感被他自己提前端在手里，再战那一下「不错」在他心里更不像肯定而像印证。
- 若林恩不摘渡鸦尸而直接以本体跃入神王保留裂隙，则附身那一步消失，他首次出现在神王面前时带着二十一万年的岁月积淀的本体面目，神王「修炼了多久」的一问停在更早的层级。
- 若林恩再入时称的不是「我准备好了」而是「我又回来了」，则神王罕见睁眼的时点向后挪一步，先落在「又来送死」的层面才升到「你有进步了」。
- 若林恩在镜面碎片推进时主动让左左从自己的左手中脱离并落到战场侧旁观，则她对「空间规则」这一概念的具象化会切到一颗透亮的微型空间碎片握在她手掌，挂件/独立两条轨道在这一刻叠印。
- 若林恩咬牙把碎片加速到超光但没有及时收手，则灵能高维测距的「超星系半径」结论不在他手下读出，而由神王亲口报出，规则碾压的重量落到现场对话而非林恩的喘息里。
- 若林恩直接照做神王「拖入体制而非抵消」的提示当场演练一次，则那条「这不是你的路」的提醒前缀「我们已不再是敌人」的暗示降到次级，无序对策被他自己先记入内化。
- 若林恩问的不是「我们不再是敌人了吗」而是「你还会再来见我吗」，则神王「狱卒之下当世无敌再来见我」的遣返仍在，但「不是竞争者」的判定被换成「他仍是一个未结束的答案」。
- 若林恩在被轰出过去历史瞬间反向抓一下神王的衣袖，则他回到二十一万年时身上多一缕神王袖口的规则痕迹，那缕痕迹在他指缝黄沙的下一次自证里充当一次看不见的引导。
- 若林恩回到床榻时先不睁眼、仍然装睡，则左左第一反应是压住他胸口用触手唤醒，他对「已与艾雯他们分别数分钟」的落差在更强烈的她呼吸声中被测出。
- 若林恩在镜前穿翎羽甲胄时主动带上那条曾被左左咬下指印的肩膀上的旧绷带，则白发与甲胄之下的身体印记都进入镜子，他「当世无敌」定志更沉一层。
- 若林恩不写留信、改用神王遣返时附赠的一手因果信标通知艾雯，则「失联一月」的轴被替换为「定位模糊可被追踪但不回应」，黑夜城会议的焦虑指引不同方向。
- 若林恩留的信是空白页只画一枚初诞者符号，则艾雯第一眼没法读出「下一次让众人吃惊的再见」承诺，会议上对「是羽毛笔找上他」的猜测比例上调。
- 若林恩把「当世无敌」的四个字改为「道之无敌」，则左左对他的变化的觉感更抽象，后续黑袍挑战链的名义标签可能偏离现有名字。
- 若林恩当场问左左「你觉得我应该当世无敌吗」，则挂件顺着撒娇会先否认再默认，他知道黑洞的第一步是被牵着走出来而不是他自己迈进去。
- 若林恩在跃入神王裂隙前再多停一秒，把左左按在自己肩膀上不许下来，则她目睹「独刀客再现」的瞬间成为他的羁绊证人，左左后续在「左左修刀与玩具打发时间」的自修议程不再单独成立。
- 若林恩主动要求神王把「三招」并为一招，则那三招依旧有效的承诺当场被改写为「一招决胜负」，他失去把惨败分三段慢慢领悟的余裕，进入当世无敌门槛的难度抬升。
