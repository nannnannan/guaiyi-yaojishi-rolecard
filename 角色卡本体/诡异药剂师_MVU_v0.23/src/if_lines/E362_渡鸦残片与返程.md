# E362·渡鸦残片与返程·if线

- 若林恩在返程时主动揽住主母肩头让她所有十二道金羽同时开放挡风，则她的神圣气息散布小半个荒野，返程途中再无任何畸变兽敢靠近半公里。
- 若林恩在主母掏出灵能芯片时主动多手抚过她指尖，则她握芯片的动作慢了一拍，林恩率先从芯片缝隙中嗅到一缕极淡的赛博文明腐锈香。
- 若林恩在主母讲述她得到芯片那段过往时主动追问「你那时在想什么」，则她会沉默数秒后回答「我担心他有朝一日再也站不起来」，林恩首次听到她当年情意的心底话。
- 若林恩主动请求主母「让我也帮你看一眼那枚芯片」，则她会犹豫再三后将芯片递到他眼前仅三秒，他能借着初诞者气息看到芯片表层浮现的一段赛博文明核心编码残影。
- 若林恩在主母提到「他很少动乱」时主动接一句「可这次动乱是因为你」，则她垂下金眸轻嗯一声，肩上披散的金羽随之落了一片。
- 若林恩在猪头屠夫与羽毛笔对峙的幕后场景中多停留一息，则羽毛笔眼底那一缕复杂会在远距灵魂丝线中模糊折返到他小拇指尖，他能隐约感到一股对屠夫话语的不甘。
- 若林恩主动朝深渊方向遥望一眼而非只顾返程，则他能借助克苏鲁之眼在数百公里外锁定那具漆黑渡鸦尸体的轮廓，并被初诞者共鸣穿行过一阵古老的悲鸣。
- 若林恩在羽毛笔手持漆黑渡鸦那一刻主动以初诞者气息做反向共鸣，则远处那名与林恩相貌完全相同的少年会瞬间抬头，两人的目光在黄沙般初诞力下擦过一线。
- 若林恩主动把自己一根头发搓入系统空间备案日后凭此寻找那具渡鸦主人，则系统中「渡鸦线索」藏档多一条未明trigger。
- 若林恩在返程飞机上主动问主母「羽茧是不是第一次」，则她沉默数秒后回一句「你觉得呢」，涩涩度+2，好感度+1。
- 若林恩主动让左左以自己身体的天线对准羽毛笔那一侧脑波监听拍长谈，则左左呛得头疼，但抓回两段羽毛笔与屠夫的低语，分别关于「神格无存」与「主人心头那位」。
- 若林恩在意识中将那枚灵能芯片与自身赛博飞升之路做模糊比对，则系统记下一条「继承而非新生」的档案条目，他后续追问艾雯的路线隐隐发生偏转。
- 若林恩在猪头屠夫高举屠刀示威时主动用巨像网络远远投去一道警告之意，则屠夫的屠刀在半空凝滞半秒，羽毛笔背后随之松一口气。
- 若林恩在主母展开十二金羽庇护众人跨越荒原时主动靠到她腿弯坐下让她一并笼罩自己，则她又羞又恼地收回第三道翼，但羽尖反向在他脸颊轻拂过。
- 若林恩在羽毛笔握拳低声「我一定会杀了你」时主动往灵魂丝线里塞一句「我先杀了你那位主人」，则羽毛笔灵魂深处随之一震，那缕对陌生少年的复杂追涨一层。
- 若林恩在返程途中主动面向荒野长风起誓「我一定会收回所有渡鸦残片」，则他体内初诞者黄沙自发响应，誓言在灵魂深处烙出一线誓言因果。
