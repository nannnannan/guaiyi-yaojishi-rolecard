# E702·重归地狱·if线

- 若林恩在光束落地前先在意识空间对左左、喵喵低声一句「先别出来，让我一个人面对他们」，则广场上的迎接第一眼看到的将是他孤身一人，血萝的惊呼会延后一拍，林恩多一段独立的回归画面。
- 若林恩在落点广场时先望向黑夜城北墙、再开口，则人群会顺着他的视线发现那面墙在几十天里被修补过整整一遍，主母会在他开口前就主动汇报「我们把城修好了」。
- 若林恩第一句话不是说「我回来了」而是问「大家都还在吗」，则巡逻夜医会在汇报之前先沉默一拍，那一拍让在场所有人意识到他刚从哪里回来。
- 若林恩主动在血萝开口前先朝她招手，则血萝会立刻扑上来熊抱，他必须用一只手稳稳接住，广场的气氛从悲壮瞬间被打断成家常。
- 若林恩主动不告诉血萝他将再去破碎神界，则她会继续在会议上绘声绘色地讲她在地狱的「关系户蹭饭史」，林恩会得到一段不被打断的轻松。
- 若林恩主动把神界战役中那把残破三叉戟的最后一缕印记在会议上公开展示，则会议厅集体沉默整一分钟，自缚天使的恍惚程度更甚，「战争代价」以最直观的方式被传达。
- 若林恩主动点头说「是的，我又被她算计了」，则自缚天使会问出「那你打算怎么办」，林恩将被推着进入 E703 的动员讨论，而不是由他自己主动展开。
- 若林恩主动把「危机未解除」一句说得比原文更重，则船长的拳头会在桌面上砸出裂缝，军团首次在和平期就进入临战心理。
- 若林恩主动在会议上把「画家到底是谁」展开讲，则他会触发变形条件：紫罗兰大君与终焉之主的连锁被提前公开，军团的认知短期内背负过重，E703 的动员令会推迟。
- 若林恩主动宣布将「防线扩展到主宇宙」的时间点提前到当天晚上，则军团总动员会立刻进入执行状态，黑夜城夜晚的灯会一直亮到天明。
- 若林恩主动点头答应血萝「下次带你去破碎神界看一眼」，则血萝会在会议余下的整段时间里都安静得反常，林恩必须决定这个承诺在 E703 里是否兑现。
- 若林恩主动不点破林蒙旧部的事，则自缚天使不会问、林恩也不会主动讲，E706 的「紫罗兰旧部理念之争」桥段将被压缩到只有他和林蒙两人之间的私下对话。
- 若林恩主动在广场高声宣布「从今天起黑夜城进入战时编制」，则黑夜城的普通居民也会立刻参与，林恩的统治合法性首次以「直接号令」的方式被强化。
- 若林恩主动在会议结束时说一句「都去陪陪家人吧」，则这场会议的收束比默认走向更柔软，军团各半神会去他们家那一边，E703 的站台场景将有更多羁绊侧写。
- 若林恩主动在回归首日召集所有直系亲属进行私密通报，则艾雯大哥、织梦、巨像等人的去向会在当日就被片面倾吐，军团的反应会更绵长但更早消化。
- 若林恩主动把「我可能很久不能回来」直接说出口，则站长那个「百分之五的意识」场景会从一开始就带着告别色彩，「我们一起还」的台词被迫提前。
- 若林恩主动不在广场落脚、直接走进会议厅再现身，则人群的「林恩先生回来了」欢呼会跟在他身后一道追进会议厅，会议氛围变得更市井、更本色。
- 若林恩主动以白烬形态落地而非常规状态，则新神与巡逻夜医会以战阵礼仪迎接，广场多一段「白烬仪式」，林恩在人群心里的「神明距离」+1。
- 若林恩主动确认「主宇宙在数十天里没有再出现大规模污染」，则他会立刻下令对全地狱进行清点，E703 的「两天后进驻」时间表提前压缩。
- 若林恩主动在会议开始前先私下朝银色太阳问一句「我现在的状态算安全吗」，则银色太阳会用一句「在这一刻算」收尾，林恩会得到一张「短暂安全确认单」，但他也会立刻意识到「短暂」两个字的重量。
