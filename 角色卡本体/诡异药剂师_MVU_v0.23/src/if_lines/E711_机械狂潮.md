# E711·机械狂潮·if线

- 若林恩当初在万物神格内留下的禁制在银色幻想展开银色金属盒时产生共鸣，则那座行星级机械要塞的展开速度会再快三成，瞬间将外环战场化作绝对的机械领域。
- 若银色幻想在三十二柱魇魔神压境时没有先与魇王隔空对峙，而是直接引爆预设在外环星域的亿万纳米机械云，则魇魔大军先锋会在照面瞬间折损数尊投影。
- 若银色幻想在展开机械狂潮时将火力优先集中于魇王身侧的辅佐魇魔，则魇王的投影会被迫分神救援部属，无法第一时间锁定她的核心本体。
- 若船长康斯坦丁从破碎神界撕裂空间赶到战场时没有出声喊出「算我一个」，而是隐匿于死亡阴影中直接向魇王劈出死亡与毁灭阔剑，则魇王连格挡的余地都没有便会被一剑枭首。
- 若船长在与银色幻想并肩作战时主动将毁灭神力注入机械狂潮的主炮阵列，则倾泻而出的毁灭机械洪流会将外环战场的无序黑潮硬生生犁出一条万里真空带。
- 若魇王在投影被船长一剑劈开前试图自爆投影污染周围的机械军团，则银色幻想会果断切断受污机械节点的量子连接，以局部弃子换取主力军团零受创。
- 若地狱与神界的后续增援军团在船长劈开魇王投影的同一刻全线压上，则溃退的三十二柱魇魔神投影会被成建制围剿，第二次战争的战果将进一步扩大。
- 若银色幻想与船长在击溃魇魔大军后立刻联手封印外环的空间裂隙，则梦魇残部将无法原路逃回无序深空，主宇宙防线能赢得更充裕的喘息整补时间。
- 若林恩在天堂之战遗址的闭关深处感应到毁灭神王格与万物神格同时爆发的璀璨光辉，则他会在心底确认两位同伴已真正扛起大梁，更加心无旁骛地冲击更高境界。
- 若魇王在投影消散前向深空传回「主宇宙已诞生两尊新神王级战力」的警示，则梦魇一方会立刻放弃正面强攻策略，提前转入长达十年的梦境渗透与消耗战。
