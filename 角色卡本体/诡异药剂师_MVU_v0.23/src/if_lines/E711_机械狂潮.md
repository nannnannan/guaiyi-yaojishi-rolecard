# E711·机械狂潮·if线

- 若画家在第七晚下场前先派分身探明四魇行跡而非直接捕捉，则她失去第七晚的先机，守卫战的时间紧迫度再高一档。
- 若画家在四大魇突入时不以一对四而是分两批在不同方位拦截，则她同时陷入被围的风险，胜负手被不分分页的局面拉平。
- 若四大魇在战败后不立刻退回深渊而是躲藏在神界附近观察，则他们会在一个月后对画家虚虚消耗，战后修复成本大幅提升。
- 若那些梦魇接受「画家杀不死的」事实之后改为只聚集在边境形成庞大集合而不化整为零，则主宇宙边境在持续性消耗战之余还未被全面入侵。
- 若神智械小姐出手不仅仅在派出机械而是亲自下场与画家一同截杀四魇，则她的身份昭告天下，而她作为统帅或战士的角色立即重写。
- 若银色幻想在机械狂潮被制造完成前就提前将部分成品投放到战场，则她失去了「遮天银色狂潮凭空出现」的戏剧效果，换来局部的强化。
- 若神界对梦魇的来袭采取先消灭高级其他再围剿基层的规则，则紫光探手当域魇王在第七晚被招捕，第四层等人无法在第一线出现。
- 若林恩在此时出关回黑夜城，则机械狂潮失去了存在的意义，所有人的努力变为过场，战役的走向改名为「林恩回归战」。
- 若康斯坦丁没有出事，则银色幻想不会出现在黑夜城会议中露面，人们对她的印象仍然停留在地狱时期，「机械女神一直在看着林恩和黑夜城」的印象被强调。
- 若银色幻想不在地狱事情后就很少出现，而是频繁参与黑夜城日常管理，则她就算不在战场出现，但她的变化也早已被大家认识，战时出现在夜幕之上的光幕随之成为「机械女皇一直为我们准备的后手」的公布。
- 若在战争中银色幻想没有接手出手而画家在继续分身镇压，则四大魇可能真正突破主宇宙边境，内环不再被保住。
- 若有人提前猜测到了机械狂潮的含义并启动警戒，则银色幻想的出现不再具有神助的效果，但依然有其作用。
- 若这一年里银色幻想没出手而是选择观察这场战争并与林恩远程联系，则我们会在更狼狈的状况下保住边境，一般将战役延误到第二个年头。
- 若最后一颗北极点的折跃之塔被玲珑般击先攻下，则通往深渊和神界的支援断开，外环迁移沦为无法回到源头的行星，一切联系断绝。
