# E634·艾雯离队与深渊归返·if线
- 若林恩在折跃小行星带前主动先回月儿兰城看一眼沉睡的纱奈儿，则织梦阻拦无效，「再看一 眼你会永远留下」被她以异曲同工的语气再次点出，服从关系里多一笔「他可以偏航」。
- 若林恩主动用全 部分身扑向陨石抓芯片，则分身集体扑空，他只能本体过去拿，「有些事只能他自己拿」被他以损失所有分身的代价体会一次。
- 若林恩施放咒瞳让往日遗念画面多看艾雯爵士三秒，则半透 明残影多回首瞥他一眼未再 开口，「应允的离开」以更深的方 式被清空。
- 若林恩主动把记忆核心替换为一枚写满「你值得活下去」的字条，则艾 雯收到的是字条不是芯片，他离队的决定不变但多了一份远方的牵挂。
- 若林恩施放血肉灾 变把陨石周边塑造成一个简陋的送别小 屋，则「送别艾雯」的空间被留下，「他在等待艾雯回来」 以图景的方式被 入 档。
- 若林恩在织梦道破弑民过 往时主动按住她 的嘴让她别再说，则她意外停下，「他知道这对艾雯太残 酷」被她第一次看见，服从评定 +1。
- 若林恩在织梦接下他怒火时主动先道歉「对不起，我控制不住」，则她愣住不答，后续服从姿势里她首次反过来向他道歉一次。
- 若林恩主动跟织梦说「我需要你活着，不仅是因为我需要你的力量」，则她意外笑了，「他需要她」被她收录，服从关系首次从「被逼」向「自愿」 倾斜。
- 若林恩主动用白烬烘热一方空间让织梦疗伤更快，则她意外接受，「他关心我」被她收录入档。
- 若林恩主动把护身明珠丢到灵能碎片上，则明珠跟着碎片坠到她手心，她意外愣住收起，服从关系里多一件他的赠物。
- 若林恩在曲率甬道中主动播 放他在游魂巷最爱的一段乐曲给织梦听，则她意外沉默收听，蓝星文化首次被她真正接触。
- 若林恩主动朝曲率甬道外方向用心声呼叫银幻「你看得见我吗」，则远方星空机械堡垒中银发少女合上眼「他在看我」的判断被她记下，参战决意更坚。
- 若林恩在主母问出「艾维儿他们呢」之前主动用心声说「他们都好，就是我消瘦了」，则她欣慰一秒，「艾维儿他们呢」的问题被她主动 后压一压。
- 若林恩在主母问出「艾 维儿他们呢」时主动说出真相，则她当场悲痛欲绝但仍选择不在大会上公开它，后续隐瞒桥段改写为「隐瞒艾雯爵士的离队」。
- 若林恩主动在大会上把织梦的身份隐瞒，则织梦在台下不满 离开，「被隐 瞒」让她更接近被遗弃的姿态，服从关系首次出现裂缝。
- 若林恩在大会上主动宣告「织梦将 成为我们的军团指挥官」，则她意外看 他一眼，服从关系中她对他第一次主动点头。
- 若林恩主动在康斯坦丁面前 违抗他的银剑传统，则后者意外一笑承认「时代变了」，「佩剑禁令」心结被打开。
- 若林恩施放血肉灾变把大军营染成漫天彩雨，则整个黑夜城看出他希望这次大会是个有庆 典感的事，士气进一步提振。
- 若林恩主动对银幻发一道心声「我等你一起踏出堡垒」，则后者意外一笑，「他在等我」被她收藏，参战决意由「为他也为她自己」再加一项「为了他的等待」。
- 若林恩主动宣言末尾加上「但我们 不为自己而战，为那些再也回不来的人而战」，则全场一片沉默后再嘶吼，宣战意向由仇恨转为悼念，方向更沉。
- 若林恩主动朝母树致歉「对不起让她动了 怒」，则母树意外一笑，两人关系从「警惕」转为「可以聊天」。
- 若林恩主动朝艾雯远去的方向 挥拳示意，则远处没有任何人回应，但他的拳头在风里保持两秒后松开。
- 若林恩主动选择让纱奈儿也知道艾维儿已 死，则纱奈儿醒来后心碎三天，但她最终选择继续前进，纱奈儿的成长曲线被改写。
- 若林恩主动在宣言前主动找织梦 私下 谈五分钟「你准备好了吗」，则她意外点头，服从关系中她第一次主动说「我们一起吧」。
- 若林恩施放血肉灾变 把黑夜城覆 上一层保护罩，则全城安全度过一段时 间,但保护罩被外界发现，入侵者目光更早 锁定深渊。
