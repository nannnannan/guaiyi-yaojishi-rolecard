# E35·左左拟化与蓝星鬼袭·if线

- 若林恩不给左左看拟化说明、直接按下技能，则银白光瀑把左左变成她从未预期的形态——可能是巨大化的战斗兽、可能是更幼态的轮廓，左左的暴怒升级为实质攻击。
- 若林恩把拟化目标对准自己而非左左，则血肉灾变与拟化在自己身上叠加，左左被迫旁观林恩变形，她的「身体自主」怨气转化为对林恩的护食式担忧。
- 若林恩接受左左「不要」的拒绝而放弃拟化，则技能保留未用，左左对林恩的警惕下降一级，但「欠蛋糕」的旧账仍在发酵。
- 若林恩在议价时真的兑现上次的草莓蛋糕与奶昔，则左左的戒备实质松动，拟化从「蛊惑」转为「交易」，事后暴怒烈度显著降低。
- 若拟化完成的形态不是黑发小萝莉而是成熟女性，则左左的抗拒核心从「变态萝莉控」转为「你把我变成这种样子想干什么」，后续亲密线提前解锁。
- 若左左在拟化后主动要求维持人形、不再变回左手，则左左的「独立存在」身份确立，与林恩的连接从寄生转为对等寄生，左左可离开林恩视觉范围行动。
- 若林恩在守卫询问时把左左藏得更深、用触手封住她的嘴而非只拦住腰，则左左的耻辱转化为真实窒息恐惧，事件后她对林恩的信任出现裂痕。
- 若林恩对守卫实话实说「我刚拟化了我的左手」，则黑夜城高层得知拟化技能存在，左左的真实身份暴露风险上升，后续根源众对林恩的态度重新评估。
- 若林恩在左左咬打时不以「喝农药」威胁、而是正面承受攻击，则左左的暴力输出逐渐减弱为委屈，互不侵犯协议的性质从「被迫」转为「默契」。
- 若蓝星线白逸在审讯中改口承认召唤法阵是禁忌、不再坚持「大哥不是怪物」，则九州官方降低警戒等级，白衣女鬼的袭击目标从「销毁现场」转为「追踪白逸」。
- 若九州调查总局决定转移而非就地销毁召唤材料，则白衣女鬼的袭击发生在押运途中，蓝星侧的战斗规模扩大，白逸在转移车上首次直面女鬼。
- 若灵媒女专家的「边境」结论被高层采纳、提前疏散审讯区域，则鬼袭造成的人员伤亡大减，但白衣女鬼的「找到你了」宣告转向蓝星灵媒体系本身。
- 若林恩此时已能感知跨界波动（如通过羽毛笔或系统），则他能在蓝星鬼袭发生的瞬间捕获到异常，但无法定位来源，断指信标的求援线提前激活。
- 若林恩忽略左左的抗议、强行在拟化后检查她身体各部位，则左左的抗拒从「身体自主」升级为「所有权侵犯」，后续亲密路线开启但恶堕值上升。
- 若林恩在拟化后给左左大量投喂点心作为安抚，则左左的怒气转向「糖分依赖」，她的幼态轮廓在情绪作用下进一步幼化，成年灵魂与幼态身体的反差成为日常笑点。
- 若九州侧在鬼袭现场捕获白衣女鬼的部分躯体或血液，则蓝星官方获得死界物质样本，后续蓝星科技线对「鬼」的研究正式启动，与林恩的跨世界召唤形成科技-玄学对照。
- 若左左拟化后趁林恩与守卫纠缠时挣脱触手、以人形在黑夜城走廊现身，则「林恩有个小萝莉」的流言在夜医内部扩散，艾雯爵士等熟人对林恩的私生活评价改写。
- 若白逸在鬼袭中死亡，则蓝星线以「白逸召唤失败」收束，林恩后续必须通过其他渠道（羽毛笔、系统、血衣）感知蓝星危机，跨世界求援的锚点从人转为物。
- 若白衣女鬼的袭击目标不是销毁仪式而是白逸本人，则「找到你了」的直接对象变更，白逸被掳走或标记，蓝星侧的后续事件从「机构遇袭」转为「营救白逸」。
- 若林恩在拟化技能使用后因副作用（眼痛、精神反噬）而昏厥，则左左被迫以新的人形形态独自应对守卫，她的「左手」身份在这种处境中彻底外化，抗拒感反而减轻。
