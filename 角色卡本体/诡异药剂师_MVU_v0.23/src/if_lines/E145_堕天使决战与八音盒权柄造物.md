# E145·堕天使决战与八音盒权柄造物·if线

- 若林恩在主人格反扑瞬间用咒瞳预先锁住神圣节点共鸣段，则金光提前渗入黑羽，命运书写抢回的「一拍」被节点代替羽毛笔承担，羽毛笔省下的额度改写下一行「主母意识上浮更快」。
- 若林恩咬破手掌把血抹在碎裂十字架上代替白夜冲上高塔撞响大钟，则白夜免于百倍侵蚀与第二段攀塔致命伤，但城民祷告对象改写为「异端血脉」，结界仍张开却烙上他的血脉印记。
- 若林恩在法阵塌陷前启动反向结界代羽毛笔拦下堕天使漆黑巨手，则 002 室避险由反向结界承担，羽毛笔无需改写「轨迹偏移」，相对代价是林恩咒能瞬间见底并被巨手反震吐出一口黑血。
- 若林恩在空殿大战爆发瞬间朝艾雯爵士喊出咒瞳扫到的节点坐标，则破阵提速三拍，全城庇护结界更早张开，但林恩咒能被强制抽去维持节点锁定，事后咒瞳过载渗血数小时。
- 若林恩朝堕天使面门掷出一支疫医畸变药剂直击黑羽中心，则羽毛失控崩散半秒，巨像之脑趁机一拳砸进天使雕像代替原节奏，药渍被八音盒发条自动吸收后小丑笑容更深一分。
- 若林恩用人偶之臂硬接堕天使一记尾击替白夜挡下塔顶坠石，则白夜免于臂骨断裂、撞钟动作完成度拉满，代价是林恩人偶之臂出现裂纹，需要事后缝合以M丝线修补。
- 若林恩用左左长鞭从背后夹击堕天使钉入雕像基座的角度，则堕天使被钉入比原作更深半寸，崩塌波及到一处夜医避难区，事后夜医欠下林恩一次「不该出现的协助」备注。
- 若林恩以直死书残页从高空盖下直接封印八音盒发条，则残页被发条寸寸绞碎、狱卒机制被触碰一次，林恩耳边多一行「权柄干涉者已录」的低语，san 值隐性下滑一线。
- 若林恩从怀里掏出血肉再生药剂灌注主母躯体代替原计划，则主人格存续期意外延长半息，但血肉感透过肤色渗入黑羽与金光，堕天使反击节奏被这股温热血气打乱一拍。
- 若林恩抢先接住被反震抛出的巫神头颅并以咒能接住他剩余视界，则巫神头颅因此欠下林恩一份人情，事后多透露一条「狱卒不喜欢被人正面叫名字」的隐秘习惯。
- 若林恩亲自顶替一名虔信者登神圣高塔充当结界节点，则全城庇护罗网加一道异端支点，结界感知林恩血脉烙下永久圣痕灼印，事后主母主人格意识上浮迹象额外显一次。
- 若林恩潜入地下大殿暗处静观而不现身，则他能听清堕天使那句「才只是开始」的对象确认为狱卒而非主母残余，拿到第一手情报，但失去第一时间介入的物理位置。
- 若林恩用咒瞳反向标记主母意识方位并以心声传给巨像之脑，则咒瞳过载渗血三日不退，咒能永久降级一阶，但主母被压入心灵深处的坐标首次被实体锚定。
- 若林恩朝黑弦月传一句心声请她以丝线缠八音盒发条延缓转动，则发条寸断引动小丑提前诡笑一秒、黑弦月首次被列入「干涉者名册」，林恩欠下她一份极难还的人情。
- 若林恩用成年形态左左直接压场与堕天使正面交锋，则黑羽短暂收拢、母树权柄与堕天权柄首次正面碰撞，结界出现一段真空，事后林恩与左左绑定参数被强制升华一阶。
- 若林恩在撤离前主动凝视小丑泥塑超过三息而不移开视线，则眼底被写入一缕金丝，san 值延后至下一事件才判定反噬，狱卒机制记下「直视者」一条标签。
- 若林恩在钟声空隙出声吟诵主母祷告词，则全城结界额外感知到第二血脉的承认，主母主人格意识上浮迹象在他面前显形一次，事后巫神头颅对此报以诡异沉默。
- 若林恩雕像破开瞬间扑进去以手爪剖向主母意识所在，则被堕天使死扑抓住胸口撕下一道鹰爪疤，疤烙下即永久，但主人格也因此第一次在现实中与林恩对视。
- 若林恩用系统商城兑换一块万机之神残片改写法阵符纹，则塌陷路径偏移避开居民密集区，万机残余意志残留一缕未识别信号，事后林恩面板多一条「神祇残响」备注。
- 若林恩甩出咒能黏丝把即将脱手的八音盒强行拉回半空一次，则发条第一次卡顿、小丑诡笑一声未发完，但他咒能折损近半，且狱卒机制在他耳边落下「你冒犯了」四字。
- 若林恩在法阵塌陷高潮主动以血肉灾变在门口多铺一道畸变网拦截暴走的疫医复制体，则能保下异常生物中心半毁的一线内部职员，但避难区会把「畸变血污」残留物当作圣痕展览。
