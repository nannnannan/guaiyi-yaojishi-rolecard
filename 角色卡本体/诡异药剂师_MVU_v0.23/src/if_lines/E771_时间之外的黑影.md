# E771·时间之外的黑影·if线

- 若林恩在深渊红月战场听见自缚天使呼唤而心神微震的刹那任由左左化作右手拔剑横扫，则扑上来的三柱魇魔当场被剑气逼退，未能在历史节点掀起半点风浪。
- 若林恩在拔出黑火大剑的瞬间严厉叮嘱左左「绝不可让黑火外泄到这片历史时空」，则左左立刻将沸腾的黑炎死死锁在剑脊之内，避免了深渊红月节点的因果崩塌。
- 若林恩在徒手捏碎其中两柱魇魔后单手掐住人首蛇身魇魔的脖颈将其拖入时间裂隙，则他在不惊动深渊法则的前提下完成了战场转移。
- 若林恩在踏入时间裂隙前背对自缚天使与艾维儿沉声留下一句「走吧，离开这里」，则他既护住了故人周全，又没有留下任何扰乱她们未来轨迹的多余话语。
- 若林恩在时间裂隙内死死捏住人首蛇身魇魔逼问「当年主母见到的未来主母幻影究竟在哪里」，则人首蛇身魇魔眼底流露出的惊骇证实了背后确有更高层级的黑手布局。
- 若林恩在上方裂隙骤然探出那只遮天漆黑巨手捏爆人首蛇身魇魔灭口时果断挥剑斩去，则黑火与巨手正面硬撼的轰鸣让他第一时间察觉到此敌竟能抵御灭世黑火。
- 若林恩在顺着巨手缩回的轨迹一路追杀冲出「时间之外」时先以神王感知锁定四周，则他瞬间看清了那道伫立在时间长河上方的神秘黑袍身影。
- 若林恩在目睹黑袍身影背后缓缓升起那根没有任何铭文与修饰的巨大「空白之柱」幻影时瞳孔微缩，则他当场确认了对方正是从未在历史记载中现身的第七十二柱。
- 若林恩从第七十二柱黑袍身影身上感应到与自身黑火同源共鸣的恐怖气息，则他瞬间明悟：眼前之人正是终焉大君因他的梦境而诞生的反制杀招，掌握着终焉大君真正的灾厄之力。
- 若林恩在对峙中听见黑袍身影温和叹息「你救了我的部下一命，你的诞生本就是我的失职」时冷笑一声，则他毫不退让地挥动黑火大剑正面劈向对方。
- 若林恩在与黑袍身影在时间之外全力对撞时将秩序大梦的力量凝聚于剑锋，则狂暴的终焉与秩序对冲直接震裂了时间长河外壁，将两人双双卷入河水深处。
- 若林恩在坠入时间长河的瞬间让左左死死锚定自身的因果坐标，则他在剧烈的时空湍流中没有迷失方向，精准感知到两人正坠向深渊红月事件数小时后的节点。
- 若林恩在时间之外交锋时刻意留意黑袍身影招式间的发力习惯，则他记下了这位宿命对手偏爱「以正面强攻掩护暗处杀招」的战术风格。
- 若林恩在人首蛇身魇魔被捏爆的刹那用黑火截下一缕逸散的灵魂残片，则他虽未拿到完整口供，却确认了那道“未来主母幻影”与时间终末的直接关联。
- 若林恩在冲出时间之外看到脚下奔涌不息的岁月长河时将自身神王气息彻底放开，则他在不受历史法则束缚的场域里打出了苏醒以来最酣畅淋漓的一记重击。
- 若林恩在听到黑袍身影自称「因你而生」时反唇相讥「那就由我亲手送你上路」，则双方的宿命对决从初见起便注定不死不休。
- 若林恩在下坠途中提前感知到数小时后的那处空间节点正有当年人类时期的自己在进行空间跃迁，则他心头顿时警铃大作，第一时间提防黑袍身影对过去的自己下手。
- 若林恩让左左在两人坠入新节点的瞬间护住心脉，则他们刚一落地便能立刻稳住身形，从容迎战即将从时间终末全面降临的魇魔主力。
- 若林恩在空白之柱幻影浮现时用咒瞳仔细拓印下那根石柱的虚无轮廓，则他对七十二柱体系的最后一块拼图彻底补全。
- 若林恩在坠落长河前最后看了一眼黑袍身影那抹温和而诡异的微笑，则他敏锐意识到对方主动与自己一同坠入这一节点绝非巧合，而是一场精心策划的围猎陷阱。
