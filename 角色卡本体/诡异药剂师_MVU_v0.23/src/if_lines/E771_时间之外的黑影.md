# E771·时间之外的黑影·if线

- 若林恩在左左提醒出剑前先反手把人首蛇身魇魔投入梦境封印,则他能省下熔炼时间直接逼问,但人首蛇身在梦境里会被林恩的幻影主母冲击,口供与情绪同步崩坏。
- 若林恩在时间裂隙里没立刻追黑影而是先找一枚未烧尽的梦魇核心,则他能在系统空间留下「降临残材」存档,但黑影会借此拉开半个呼吸的逃遁。
- 若林恩让左左在河里一直用左手按住他眉心,则她每笔感知都精准稳定,但林恩无法在某些节点做出「不让她触碰」的隔绝,后续她要替他挡刀的代价反而更高。
- 若林恩把黑火收成一圈牵引离地,则裂隙边缘被烧出一段可复用的窄桥,但那只遮天巨手降临瞬间能直接顺着桥追到林恩身前。
- 若林恩在巨手降临瞬间先朝反方向踏半步再反手挥斩,则他能卸掉那一遏压,但黑袍身影会借此更多地记录林恩应战姿势。
- 若林恩下意识脱口喊出「你是第七十二柱」,则黑袍身影首次主动对答「原来在你那里是这个名字」,因果标记在初次对决即落地为双方同记。
- 若林恩刻意在追击前朝长河多投一缕黑火测轨迹,则他能预判黑影遁入下游的位点,但那缕黑火会分出一圈涟漪,被远处某存在看见。
- 若林恩在时间外以渡鸦形态迎敌改用爪代剑,则近身时多一段与黑袍身影擦肩的移动性,但拳刀交锋的终焉对冲强度被他自己削弱一档。
- 若林恩放弃追问人首蛇身魇魔「她在哪儿」而是直接烧尽,则他省下最后几秒的底检,但幻影主母被践踏这件事在他脑里再无具体口供对证。
- 若林恩让左左在意识里描述主母被蜃化场景的每一帧,则他黑火转速立刻 ↑,但左左会在接下来的几日陷入轻微的失真召回。
- 若林恩把时间外虚空命名为「渡鸦外垩」并心底铭刻一笔,则事后他对这只黑影的追踪路径拥有可回溯的私人地名,但同一命名被黑影听到后,他首次知道林恩在给它贴「龛」。
- 若林恩主动把黑火从「燃尽」调成「封焰」烧黑影一刀,则黑影被击飞后需多两秒重组,林恩赢得一段可追问的窗口,但封焰让黑火对終焉的对冲力临时衰减。
- 若林恩在对峙中主动把「我是为了应对你而生的魇」复述一遍,则黑影的呼吸微微停顿,他第一次确认林恩真的听进去了他自我介绍的全部含义。
- 若林恩让左左用左手感应黑影说话时刻底音之上的湿度,则她底软里读到一缕「不是梦境,也不是本体」的古怪隔膜感,林恩据此推断出「他至少是被直接从终焉里投出来」的位阶。
- 若林恩在被「你的诞生是失职」刺中时反而笑出声,则黑袍身影的语调首次微调,「他不怕被定位」的判定成立,他下一次出手的判断树需重新定义。
- 若林恩把时间外这段遭遇战全程交给黑火自己决定收放,则他首次体会终点火焰在他不时刻制约时也有轻重节奏,但黑火杀欲在该刻被定档为「可独立于林恩作出微调」。
- 若林恩在黑影坠落长河刹那追上去时先踏上一段渡鸦尸体轻舟,则他的降临定位更稳,但那具尸体在下一刻会被黑影顺手烙一枚追踪印记。
- 若林恩让左左在他跳入长河前紧紧拉住他一根手指,则她同步定位他的落点,但她也同步陪他经历刚才那场对冲的余震,左手冰晶冻痕出现一道新细纹。
- 若林恩在听到「你救了我的部下一命」时不接话,则黑影首次失去一次引导对话的机会,他嘴角的温柔笑意首次没了明确对象去放。
- 若林恩把手中黑剑长度故意压在齐肩而不是全开,则他在虚空的形象被黑袍记录为「近身型」,他下一次的对抗设计会默认林恩不进行远距离压制。
- 若林恩主动让自己的身影在黑影面前微微凝多一层模糊,则黑影误判他位格为「未终结定型」,但他的定位也会被左手抓住的左左感到一阵失真。
- 若林恩在黑影用「这是时间之外」点破场域时主动把长河外壁也烧了浅浅一指,则他赢得「这家伙敢在此劈长河」的印象,但长河里本来安静流淌的某段被轻微灼弯。
- 若林恩让左左在巨手降临瞬间从左手送她一缕冰,则那缕冰被巨手一并击碎,她首次实际粘上「终焉对冲」的余温,后续几日她的左手需要林恩一点点焐热。
- 若林恩在冲出裂隙时主动哼唱一段不成调的旧童谣,则黑影在追击中首次识别出「他在自我安抚」,他对林恩心性档案里添上「会在高压下保留童趣通路」一笔。
- 若林恩选择第一次遭遇不全力以赴,则他保留余力给后续与七十二柱的处理,但黑影会在记忆里把他归类为「保守派」,后续算计都会在「他会留手」基础上展开。
- 若林恩让黑火在虚空里不烧黑影而只烧自己周围一圈作为领域界定,则他首次赢得一段明确的「由他划定」场域,但黑影也会学到「林恩能让人退出他的领域」这一概念。
