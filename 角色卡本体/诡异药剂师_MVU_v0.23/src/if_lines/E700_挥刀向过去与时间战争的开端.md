# E700·挥刀向过去与时间战争的开端·if线

- 若林恩在投出三叉戟重创因果后不再追杀、转而追上她低声说「真理最后一刻叫你名字时是什么眼神」，则因果在巨手抓下前先沉默一秒，遗言里多一句「他没叫我的名字」，时间战争的开端档案里多一条「林恩曾试图救赎她」。
- 若林恩对因果说「你可以回头」之后主动补一句「我也可以替你去求画家放手」，则因果反而会凄然一笑拒绝，因为她「回不了头」的理由被她自己坐实到「连求情都不必」的程度。
- 若林恩在抓住三叉戟的瞬间主动切断与它的联系、改以纯三位一体之力继续追杀，则三叉戟会脱手飞回神王界本源处，主宇宙暂时失去那件「不属这片时空的武器」，但林恩本人在后续漆黑巨手出现时没有重器可投，历史冲击路径改写。
- 若林恩在漆黑巨手出现时主动让三位一体之力凝成神疆锁链缠向巨手腕部，则他会立刻被那股时间之外的力量反噬拽到时间长河边缘，比原本的反噬多一笔「他试图拉住那段历史」的档案。
- 若林恩在强攻巨手无效后选择不再投戟、而朝因果远去的方向直接燃烧三位一体一波对冲，则他能撼动时间长河闭合节奏半拍，那场「来自时间之外的战争」会多一道他的身影，但他透支至当场呕吐鲜血。
- 若林恩在时间长河闭合前主动朝那苍蓝光晕喊一句「你就是未来的我」，则光晕不会应答，只是更亮一分，林恩心声中多一条「他没否认」的判断。
- 若林恩选择不切断与三叉戟的联系、继续承载主宇宙本源，则触发变形条件：银色太阳的「分庭抗礼的资本」成立，林恩能在短期内横扫一切敌方投影，但每动用一次就引来灾厄本体更深一层的注视，进 E701 前先承受一次超位格扫描。
- 若林恩主动把三叉戟托付给银色太阳而不是放逐遥远彼岸，则银色太阳拒绝并明言「我也承载不了这个东西」，林恩必须自己再想一条出路，本事件的「切断联系」步骤被延后一段。
- 若林恩在切断与三叉戟联系前先以心声对它说一句「对不起」，则三叉戟会发出一声类似叹息的嗡鸣，远处那片灾厄注视消退之前竟也短暂柔和了一分。
- 若林恩主动把神疆播入地狱的种子数量翻倍、计划抵御灾厄注视反扑时也更广，则他切断联系后的余波危害下降，但他会因此失去「回到原点」叙事中「一无所有」状态的存档，等于公开承认他已不是普通渡鸦。
- 若林恩主动朝银色太阳追问「你说整个时间长河全部都是我的身影——里面也有失败的我」，则银色太阳会承认「也有」，并把每一次失败的代价说得很轻，林恩对未来的预期首次被具象化折损。
- 若林恩在画家化身的颜色出现在神界边疆前先朝狱卒大军方向挥手示意，则大军会集体单膝跪地致敬，画家将至的那一刻注意到他的姿态，「最后的渡鸦」的人心请求被加深。
- 若林恩主动在画家抵达前先独自离开神界边疆去处理主宇宙污染，则 E701 的直接对话被压缩成借混乱色彩远程传讯，「我们失败了无数次」这一推断不会当面对着他讲出。
- 若林恩主动对银色太阳告白一句「我先撑过这一阵再考虑你那句时间神格」，则银色太阳会罕见地不再劝说，只留下一句「随你的便」，时间神格之行开启时点被延后。
- 若林恩主动在切断联系时让左左、喵喵在意识空间同时按住自己的手腕，则他能完整地把自身意识剥离、不带走任何主宇宙本源残痕，但两位挂件会昏睡一段事件。
- 若林恩主动在烧伤中释放一缕以M气息朝时间长河闭合点试探，则他能立刻感应到时间战争里另一股「以M情绪」的存在，但那是敌方兵力布置中的诱饵，他将被反向定位。
- 若林恩主动以白色罪火代替金光在切断联系时燃尽三叉戟表层，则他与三叉戟的缘分以更暴力方式终结，那把武器的「黄昏之伤」将被永久烙印，林恩本人不会留下银光。
- 若林恩主动在耳里响起「这是他最后的机会」时选择不听从银色太阳的劝退，则他会在时间长河闭合前再试图冲过去一次，那段「来自未来的渡鸦长鸣」将替他挡下一半反噬，但他自我铭记的遗产减少一半。
- 若林恩主动在本事件发生前主动把真理残存的情报写进系统空间以便画家化身直接读取，则 E701 的对话会更紧凑，但画家对他的看透也会更深一层。
- 若林恩主动把神界本源以「再等等」之名继续封存，则引发新的变形条件：本源驻留此役地，林恩要更久才能动用初诞者助力。
