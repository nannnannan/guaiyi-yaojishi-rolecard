# E571·幽冥海入口·if线

- 若林恩在跨越边境线的瞬间主动以咒瞳解析那股「无边大道」的排斥力而非单纯硬扛，则他对「主宇宙本能排斥外来者」的底层规则会有更直观的体悟。
- 若林恩在小丑人偶痛苦抽搐时主动伸手按住人偶脖颈替它梳理紊乱气息而非挥手送走，则小丑痛得昂起头嘶吼连连、嘴里喷出一连串深渊俚语，直到撑不住才被收回奇异世界。
- 若林恩在艾维儿说「你是大君女儿」之后主动多添一句「我不怪你之前没表明身份」，则她平静地瞥他一眼回道「这话你留着跟死人说吧」，两人之间那种冷硬的同伴默契反而更沉了一分。
- 若林恩在主母白裙现身时主动以感知捕捉她身上那股古老而圣洁的法则韵律，则主母金瞳中的敬畏与复杂情绪被他尽收眼底，「前代大天使长」的底蕴令他印象深刻。
- 若林恩在主母开口询问「您真的就是古老大君王女」时主动上前一步挡在两人侧翼表示「主母与我们同路」，则主母眼底的紧绷会明显缓和，看向他的目光多了一分慈和。
- 若林恩在艾维儿承诺「必伴深渊站稳」时主动追问「只是站稳还是彻底共进退」，则艾维儿警惕地顿了一秒才答「那取决于你们能走到哪一步」，让他看清她此刻的心理边界。
- 若林恩在艾维儿告知前路凶险、需全力潜行时主动提出自己备有遮蔽天机的替身秘术，则她听后微微颔首，眼角掠过的一丝担忧随之敛去。
- 若林恩在主母与王女互相确认身份后主动提起刚才小丑狼狈退场的模样来活跃气氛，则艾维儿会冷冷扫他一眼，主母却会掩唇轻笑一声，凝重的气氛随之松动。
- 若林恩主动在物质洪流前行途中尝试将一根手指探出护罩测试流速，则那种近乎光速切割的法则冲刷感会让他瞬间收回手指，对幽冥海入口的凶险程度有了切身体会。
- 若林恩在听艾维儿讲述边境防线机制时主动追问「外来者的排异反应会随深入而减弱吗」，则她会详细解释「外环最烈、破环入内反降」的规律，省去他自己摸索的弯路。
- 若林恩主动在艾维儿承诺战后陪他探寻时间真相时将这句口头约定凝成一枚小小的灵魂信标递给她，则她沉默片刻后仍会收下，为日后的同行埋下伏笔。
- 若林恩在小丑被送回奇异世界前顺手塞给它一枚用于稳固魂体的深渊魔晶，则小丑在养伤期间不仅恢复更快，还会把这枚魔晶当成主人的赏赐四处炫耀。
- 若林恩主动在主母加入同行队伍后先递给她一瓶自己调配的宁神药剂，则主母欣然饮下，长途跋涉带来的灵体疲惫明显消退。
- 若林恩在穿行物质洪流时主动分出一缕初诞金光加固队伍最前方的破浪屏障，则三人推进的速度会再快上一线，更早抵达迷雾之海的边缘。
