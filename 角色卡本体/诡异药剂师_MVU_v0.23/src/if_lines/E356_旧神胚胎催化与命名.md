# E356·旧神胚胎催化与命名·if线

- 若林恩在引出同源气息前主动朝巨像之脑解释这是「共用一个灵魂」而不是「大君复活」，则她的沉默里会少一层犹豫多一层信服，合作的开端从含糊变成对等。
- 若林恩激活无瞳之眼与紫罗兰纹路的同时保留一缕清醒心神放在外圈警戒血雾，则他能在胚胎异动的瞬间立刻收手、不至于被疫病军团的突袭打断法阵的成形。
- 若林恩主动把自身作为法阵阵眼而不是借外物，则他对胚胎的引导会更直接，但每一秒催化都会从他本人体内抽走感官清晰度，催化结束后他要静养一段时间恢复。
- 若林恩在残念安静下来的瞬间主动让自己声音降至耳语，则残念里那一丝属于渡鸦领袖的残片会被他自己的声音唤起，那一丝残片在催化结束后仍独立地附在他心神一角。
- 若林恩向巨像之脑请求巨像之血时不解释用途，则她会直接割开手腕把血倒进法阵中心、不问也不看他，这份无言的信任被她记成她与他之间的一次重要节点。
- 若林恩在法阵被灌入巨像之血时主动添加一滴自己的血入阵作为对称，则法阵的位阶会被双重稳定、催化的速度几乎翻倍，但他在催化后会在胸口烙下一圈属于巨像的红色纹身。
- 若林恩主动问巨像之脑「你看到了什么，不肯说」，则她会抬头看他一眼又低头把嘴唇抿住，那一秒的坦白选择被她一次次收回、成为她与他之间第一次未说完的话。
- 若林恩直接把「渡鸦的领袖」四个字摆在残念面前作为诱导，则残念们会有一次集合性的尖锐反应，那位古老领袖的存在在他的引导中被他们自己的记忆证实。
- 若林恩选择先催化胚胎躯壳的稳定、再处理灵魂成型，则孵化期会比默认方式至少快一倍，但灵魂的不稳定性会延后浮现、未来几周内他必须时时监测。
- 若林恩主动用自身黄沙把胚胎周围镇压成临时「巢」，则整片地下深渊被他改造成一处只属于这具胚胎的空间，巨像之脑第一眼会把它比作「紫罗兰宫廷的一角」。
- 若林恩在向胚胎说「你不会有压力」这种话时被残念抢答了一段古老誓言，则誓言会反向烙在林恩口中念过的语言中、他在催化后暂时无法用原本的话表达这个意思。
- 若林恩把「夏娃」这个名字提前说出口、甚至在胚胎尚未稳定前就贸然命名，则胚胎会立刻对那个名字产生反应、整具躯壳朝名字主人的方向贴过来一寸，后续的成长轨迹都围绕这个名字自我解读。
- 若林恩不立刻命名、只让胚胎自己长出一个属于它的名字，则它在破壳初期会发出无名字特有的、尚未帕形的啼鸣，那啼鸣在事后成为林恩最终给它命名时的关键参考。
- 若林恩主动提议让巨像之脑也为它起个候选名字，则她会当场拒绝只说「你起的就够」，并在她自己的私人记录里给这具胚胎保留一个属于她的称呼，那份称呼永远不对林恩开放。
- 若林恩在孵化过程中用自身咒瞳凝视胚胎，则他会目睹它躯壳深处一双尚未睁开的眼睛轻轻动了一下、那个瞬间成为他与它之间的第一道感应。
- 若林恩在催化结束时对巨像之脑说一句「谢谢你」，则她会把身体内最大一根原本要带去战场的巨拳放下转身走掉，巨像的某个血肉在她离开时会一直滚烫到无法平复。
- 若林恩主动提出让左左在催化外圈守护，则左左首次能在催化的边缘感应到那具胚胎咒纹与她自身咒纹的细微共振，她事后会把这份共振归为「同出一源」的宿命节点。
- 若林恩选择不在催化的最后一秒给胚胎一个名字，而是留到破壳之时再说，则他能在那具躯壳完全成型的瞬间用一个真正适合它的名字作为诞生印记。
- 若林恩告诉胚胎「等你长大我们就去见她」，则「她」这个字会被胚胎记忆为它存在的另一大锚点，事后它对主母的识别力会因此远比对其他同类强。
- 若林恩催化完成后只是安静坐在地下深渊边、看着深渊边的血雾，则他会第一次看清这位被他引入人间的生命的未来可能性、那一刻在他心里烙下一个未曾言明的责任。
