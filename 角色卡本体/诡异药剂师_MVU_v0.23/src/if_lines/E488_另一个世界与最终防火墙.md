# E488·另一个世界与最终防火墙·if线

- 若林恩在银色幻想远远停步时不靠近，则她与他的几十米距离会被她保留为永恒的「最后一格」，「也许吧」之后她不会再回头。
- 若林恩在她质问「你有资格吗」时先答「没有，我只是想说」而不是反问，则她会愣一拍再笑一声，「你这种人」被她第一次划进允许靠近的圈层。
- 若林恩直接回应「另一个世界的我不会让你等」，则她的眸子会闪一下随后压平，这条台词被她写进「非现实候选」文件夹，不再给任何回应。
- 若林恩告诉她「那个梦注定会醒但你可以不赔」，则她会反问「你替我赔吗」，这一句反咬之后两人都不再说话，倾诉结束的方式改写为共沉。
- 若林恩在她说到「被奴役万年」时接「那是历史的失败不是你的失败」，则她会立刻侧过脸把后面原本想说的「我不再相信任何人」咽回去，情绪节奏被打断。
- 若林恩掏出智脑的旧通讯记录给她看「也有人为你等过」，则她会在看到记录的瞬间数据体起雾，「另一个世界」的想象被改写为「曾经被靠近过的现实」。
- 若林恩让左左不在奇异世界那侧戳脸而是平静地问「你脑子里是不是在打架」，则他会少挨两巴掌，「假慈悲」这件事不会被左左当面拆穿，但他的消沉会延后几小时才被压制。
- 若林恩在左左戳破「假慈悲」时承认「我确实哭过」，则她会震惊一拍随后瘪嘴，这次对话换成「他敢承认」收尾，左左给他的振作力度反而是温和的。
- 若林恩让左左直接说出「你没家所以把这里当家」前面那句，则他会愣住、不接任何话，左左的两巴掌拍不下去，这段公式被两人心照不宣地收尾。
- 若林恩在左左激励后顺着她的话直说「我确实怕黑夜城伤亡」，则她会满意地摸他的头，这段假慈悲对峙换成「他被允许承认自己怕」的形态。
- 若林恩不回答左左的「你没有家可回」，则左左会愣一拍、随后不再追问，两人之间多一层「互相不拆穿」的默契。
- 若林恩在苍蓝数据壁垒前用咒瞳做一轮反向扫描，则他能从壁垒的密码风格里读出「将军手笔」和「学者补丁」两层的叠加，对防火墙的认知≈小号万机遗产级别。
- 若林恩在倒计时「3、2」中不坦白智脑真相，则她会带着「他绑架智脑」的怒气上传、上传大厅的屠戮强度+30%，但她对他的敌意保留到后续事件。
- 若林恩在倒计时「3、2」中顺手报「光宴其实是人质」，则她会停顿一拍重新评估两机合作的可信度，纳米瘫痪的协助窗口被她自己主动再削一成。
- 若林恩把「现实突破」换成「我让分身先探路」，则她会直接拒绝节奏被打乱、倒计时重新归零，这次防火墙停留窗口可能整个错过。
- 若林恩在坦白智脑时加上「当时她差点死了」，则她会骂「混蛋」的力度降一半，「救了她」的口径压过「绑架」的口径，上传后屠戮节奏反而更克制。
- 若林恩在坦白前先看一眼奇异世界侧的左左眼色，则左左会回一个「你敢」的嘴角，他坦白出来的勇气来源被三级外显，整段对话变成三人当事。
- 若林恩让咒瞳把她倾诉时的「也许吧」那一帧完整存档，则他后续每次面临她的合作请求都自带这一帧回放，判断她的诚意基线被他自己主动抬高。
- 若林恩在她说「梦注定会醒」时反问「那你梦到他什么」，则她会愣住、随后坦白那个虚构人物的轮廓是「他年轻的样子」，两人之间多一层「替身承认」的悬案。
- 若林恩在她答完「也许吧」转身就走不留台阶，则她会愣一拍后下意识地跟上来，这一段「并肩回网道」被改写为「他先动身她跟上」的顺序。
- 若林恩把「你掉队是最好的结果」重新翻译成「你活下来了」，则她会久久不出声，整段「倾诉」以无声对视收尾，没有落寞那一帧被外显。
- 若林恩让左左出面陪她一起走网道，则她倾诉的对象会被一半分到左左身上，「另一个世界」段落被改写为「两个幼态少女陪她做白日梦」。
- 若林恩自己接手「最后一道防火墙」的开凿计划让她留守，则她会当场拒绝、理由从「我有万机遗产」降到「我不能看你一个人扛」，信任线与战斗序列同时改写。
- 若林恩把「上传之后我会找你」从承诺改成命令句，则她会点一下头、应声里没有任何起伏，这一段关系被她重新登记为「我服从他安排」而不是「我们并肩」。
- 若林恩停留在原地听她倾诉完才动身，则他会被她多留意一眼、被她备注「他没有催我」，本事件的「倾诉完成」被登记为「双向倾诉」而非单向。
