# E436·深海王庭与紫罗兰葬所·if线

- 若林恩在广场雕像前故意紧握三叉戟石头空壳藏于身后，则他靠近雕像时石壳会突然共振一声闷响，小丑首次发现「你和吾王石雕在相互呼唤」。
- 若林恩主动触碰雕像基座那只被钉巨物的刻纹，则林恩的指尖会被弹出来并残留一行未知古字的幻感，事后睡梦中林恩反复写出那个字但醒来看不懂。
- 若林恩直接问小丑「那座龙少女雕像是吾王妻子吗」，则脸上会挨一记玩偶拳头，事后小丑整整三天不再主动讲话。
- 若林恩在小丑跪磕「吾王」雕像前主动绕到雕像另一侧读取铭文，则他能解读出小丑忽略的一段——大君当年亲口说过这座雕像「像旁白多于像自己」。
- 若林恩主动以树木岩石阻挡孽主的视野先一步检查第二座龙少女雕像，则他能私藏雕像底部镶嵌的那枚古老紫罗兰玛瑙而不被孽主发现抢占。
- 若林恩让喵喵在石柱间跳窜弄乱陈列灰层，则她会擦亮某一个棺椁露出一行「医师参谋·祭酒官」铭文，林恩直接拿到骸骨兵籍一位角色原型。
- 若林恩拒入殿只摸石门符文，则碧蓝光晕只在他指纹处绽放一次，长明灯永远不会点亮；葬所将永远只对他开放成一个半启动状态。
- 若林恩让左左以血族尖啸激活石门，则碧蓝光晕会被血红侵染，石门开启时一道血光直射最深王座，林恩的多入一手「王座预知位置」情报。
- 若林恩让孽主先抢先进殿并被一石阶上掉下的灰尘砸到，则她会被那颗尘埃控制鼻子半天流涕，被队友反复嘲笑取乐。
- 若林恩主动在石柱长明灯前点燃自己留下的一撮黑发，则石柱会临时改投射他生前留念的全息影像一次，他瞥到很久以前某个林恩站在这个殿里。
- 若林恩让小丑先闯入殿内用布料擦一座石棺，则布擦完的灰里会浮现一枚紫罗兰私印，小丑第一次说「这个家族比我想的更年长」。
- 若林恩拒让孽主接近王座而令她留守门厅，则她会发现殿内地面一排紫晶脚印，事后林恩知道曾有人比他更早走过王座却留下脚印而无回答。
- 若林恩主动在石棺灰上吹气试图读出更多铭文，则尘埃会堵塞他的泪腺，他的眼泪将以紫罗兰色水珠残留在下颌几天。
- 若林恩令左左激活一只石棺顶端铭文反读，则她能念出一句给新入葬者的祷文，第一次为已故族人祷告，绑定关系多一笔「她做过祷告」。
- 若林恩主动在王座轮廓可见时绕到王座后侧检查，则他能抠下一块木片作为物证，未来遇到艾泽法拉时刻放在掌心互证身份。
- 若林恩让小丑比搭档先一步摸王座轮廓，则小丑会在王座低处摸到一行小字「吾王样式仅为门客，真王秘形态被抹除」。小丑只把这句话记下不念出来。
- 若林恩主动朝广场中央雕像注入初诞者之力以反向检索记忆，则雕像的眼睛会以紫光大亮一秒后熄灭，林恩眉心永久多一条紫色细纹。
- 若林恩让喵喵跳下石柱面对长明灯「喵」一声，则长明灯会把灯色换成淡金色一秒，林恩收到系统面板【长明灯已认出陪伴物种】。
- 若林恩尝试用咒瞳扫王座轮廓，则咒瞳会立刻崩解三秒，林恩接下来一天视觉都是紫罗兰调色盘。
- 若林恩请求孽主解读第二龙少女雕像的古紫罗兰文字，则孽主能翻译出雕像底座的一部分——「我愿以躯体守护他入睡」。
- 若林恩在出发前主动令小丑进入系统空间放空，则小丑会将在王庭看到的所有铭文忘得一干二净，事后只保留「我去过一座殿」的元事实。
- 若林恩主动在殿门广场雕像面前对隐身呼唤艾泽法拉名字，则深海某处的鱼群会跟着节奏抖动一次，林恩获得一条隐性回执。
