# E395·血气与细胞控制·if线

- 若林恩在巨像之脑逼问份额来源时直接承认过往与左左纠缠是回馈路径，则两三个小时的小验证被压缩成当场对质，银瞳萝莉立刻要求他演示一次亲密刺激并同步记录份额曲线。
- 若林恩要求巨像之脑暂缓追问、回居所做受控验证，则她退到隔壁房间计时，房门紧闭的两个小时里她自己脑内模拟出三种转移机制，对质时多一笔「她描述的过程与现场相符」的旁注。
- 若林恩把血气外放压到只贴皮肤一圈红雾、不让触手蔓延全屋，则巨像之脑远程扫描不到血气的形态上限，但她会把这次记录标注为「受试者刻意保留」，对 0.2% 缺口的解释不变。
- 若林恩任由触手变形成战斗装备序列展示——剑刃、战斧、加特林、震动棒全部轮一次——则系统面板多一条「血肉变幻类别汇总」，爱丽丝不在场时喵喵会好奇地扑到那把变形枪械上啃一口。
- 若林恩诱导左左脱离手部形态凝聚人形时主动立下毒誓并且不爆衣，则她裹着临时变出的床单坐在床沿配合两小时验证，全程骂骂咧咧却没中断，验证数据完整。
- 若林恩在誓言落定瞬间当场爆衣，则左左条件反射飞扑抓毛巾裹住自己，枕头如狂风砸地，但骂声间她胸口也跟着染上薄粉，验证数据反而比克制版本多出一截反馈强度记录。
- 若林恩回敬「只有在左左面前才不需要维持绅士姿态」，则她会呆滞片刻后抓起床单又一次炸毛，骂声里多一句「凑脑袋的嘴就是用来塞住的」，份额涨幅与原版相当但过程拉得更长。
- 若林恩把验证推进到数小时且让左左全程维持人形，则她彻底脱力昏厥、系统播报「您的左手已昏厥」成立，血肉强度 +10×2 与驯服度 +2% 不变，但罪孽城下一位偶遇的夜医将被她睡醒后当成出气筒。
- 若林恩改用较短的三十分钟烈度、刻意压制冲击上限，则左左仍保留半程意识，她能在被喂伏特加时半垂着眼咬他指尖一口，反馈转移曲线反而收敛得更均匀。
- 若林恩验证完后不进巨像之脑房门，让左左睡到自然醒再由系统面板自行读取，则银瞳萝莉会因为缺一次实证而闷闷不乐，下一次会议里多一句「你们俩到底在共享肉体数据的领域进展到哪一步」。
- 若林恩扛着昏厥左左敲巨像之脑房门，则她那句「你又玷污了我的王后」照念不误，但「又」字的下意识暴露被改为「第一次发现」时，她会立刻转身偷偷擦眼泪，事后给左左做一整套细胞安抚疗程。
- 若林恩主动指出「会不会源于渡鸦的联系」，则巨像之脑会立刻检查他体内欲望母树本源，那条由「欲望本源 + 吞噬转化 + 渡鸦基因」组成的因果公式提前十几句落成，她额前一掌跟原版同样用力。
- 若林恩在她整理出因果公式后再追加一句「要不要你也亲身试验一下」，则她面无表情回敬「不打算」，但这次她会附加把房门轻轻关上一个缝的姿态，事后几小时会躲在被子里偷偷以血气模拟类似的刺激路径。
- 若林恩计算「那只需要三千次」并真的在系统里建一个进度表，则她当场抓住他伸向左左的手腕，压恼怒说「不行」时会多出半秒的犹豫，但该次验证仍被叫停。
- 若林恩提出「让左左主导节奏、林恩配合」的反向验证，则她的人形压在林恩上方、不再是被动承欢，左左的主动权会让份额提升速率抬高一档，巨像之脑的毒誓伦理观瞬间崩塌并抗议这次「不算科学」。
- 若林恩把整段验证电话直播给黑弦月听——只开放心声不入画面——则血爪家族那头气氛立刻凝重，黑弦月会咬牙切齿地骂「学徒又在欺负软乎乎的姑娘」，但份额曲线照常上升。
- 若林恩让左左在验证中期短暂变回左手形态，则刺激通道瞬间截断，巨像之脑的远程扫描会读到一道「控制权切换」标记，验证曲线出现一次明显跌断，需要重新进入状态。
- 若林恩让血气不只在体表升腾、而是把整间房间裹成一颗半透红色肉球，则巨像之脑的远程扫描被这层外壳屏蔽，她在外头只能靠抓门听到里面阵阵呜咽与破碎咒骂，对「强弱不对等」的猜想加深一层。
- 若林恩在验证后用触手当然地对左左进行一番全身清洁整理、再抱她去床上盖好被，则左左在记忆里多一笔「凑脑袋还算有人性」，驯服度 +2% 不变但她暗暗把枕头下那把菜刀换成了狗粮枕头。
- 若林恩在事后向巨像之脑提出「下一次验证由你亲自下场模拟」，则她眼底闪过一瞬动摇，但下一刻她以一句「不打算」把门关死，份额公式不变，但她自己当晚会回房拟化幼态侧写兀自模拟。
- 若林恩把这次验证同步告知艾雯爵士的指挥频道，则爵士语气依然硬挺但会多一句「请把夜间时间窗留给我一小时处理公务」，个性化备注「这种事不能摆到公屏上」成为他的日常语癖。
- 若林恩让巨像之脑在验证中途伸手进他胸膛扯母树藤蔓「寻根究底」，则她扯出藤蔓瞬间被他体内的吞噬机制反噬一口无形侵袭，她失控半秒、靠深呼吸压下，藤蔓形态完整列入档案。
- 若林恩只在爆衣阶段停留数秒、不推进数小时的深验证，则系统提示不出现「您的左手已昏厥」，血肉强度 +10 一次，驯服度 +1%，整体涨幅明显收敛。
