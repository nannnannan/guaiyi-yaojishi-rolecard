# E677·因果化身的终止·if线

- 若林恩回村向龙卫澜坦白因果化身就藏在林地时压低声音，则她会把信息控制在十一人小队范围内，庇护所的保密层级提升到最高。
- 若林恩在封锁小世界时主动对外释放假信号引诱因果化身回援，则她能被成功诱导提前出手，但林恩必须承担一次正面交手的风险。
- 若林恩身化千万折跃到世界边境时用空间神格强行压制这部分法则的震动，则化身们的作用全达化敌我双方发现时机的相对迟缓，密不透风的牢笼在无声中成型。
- 若林恩在独自清扫黑骑时故意放跑几只，则它们会把「入侵者就在林地」的情报带回因果府邸，但计反过来也让林恩能反向锁定敌方藏身坐标。
- 若林恩在决断清扫的方式时让一部分遗民作为诱饵，则这部分遗民能重获生机但会有几人无法避免被重新污染。
- 若林恩在主动清算前先进废墟和银色太阳单独会谈，则银色太阳会更愿意合作透露因果的情报，甚至主动教会林恩一些与因果作战的技巧。
- 若林恩在清完林地后立刻转向废墟与银色太阳交锋，则他会立刻被收回外表，林恩能在信息上获得先手打击。
- 若林恩在见到因果化身时直接兜头一击、不给对方反应机会，则那场对峙会瞬间短兵相接，因果化身将在不曾认清全局的情况下惨败收场。
- 若林恩选择不现身交手而是以威压压制让因果化身自爆，则虽然规避了直接对抗但因果化身本体能从死亡讯息中窥得林恩的存在与实力。
- 若林恩在清扫林地时把初诞者之力的威压全开，则整场横扫时间会大幅缩短，但因果化身会立刻感觉到林恩的强大并传回神王总部。
- 若林恩主动用语言试探因果化身的立场，则她会透露更多关于本体和终焉之主的信息，但代价是林恩也在交流中知晓一部分自身受限的秘密。
- 若林恩在战斗时主动躲入暗处观察因果化身的所有手段，则他能在后续交手中对因果化身的技巧应对游刃有余，胜招因此提升。
- 若林恩在交锋中主动以身送出一次受伤机会换取更深入地打击因果化身，则因果化身的死局将出现，但林恩自身也必然受创流血。
- 若林恩在剥离因果化身之前对它进行一次深度搜身，则会找到她随身的小型器具可以记录因果法拒绝的密文，后续在其他战场对抗会显得得心应手。
- 若林恩选择把因果化身钉杀后带回庇护所尸体，则庇护所可以研究提取其内的情报但因果本体必然感知到尸体位置加大搜捕力度。
- 若林恩在因果化身死时主动留一口气让她有机会提供最后问诊的机会，则她会说更多内幕，包括因果神王下一次出招的准确情报。
- 若林恩在战后把因果化身的残留法芒用时间倒退分解，则因果神王体达会立刻发生侧翻波动，神界的舆论会因此出现林恩已经杀死分身的消息。
- 若林恩在夺走因果化身的神格时心里犹豫，则因果化身会感受到威胁爆发出必死一击，林恩若硬碰则以命换伤只能回退。
- 若林恩主动对银色太阳承认因果化身的死亡代表了他已经点燃反击的烽火，则银色太阳会说「那你已上了因果的名单」，林恩的备战节奏从被动转为主动。
- 若林恩在战后用空间神格封锁整片废墟阻止线索泄露，则他的隐秘性会大增但同样因果神王会在一段时间内确认林恩的确切下落。
- 若林恩选择不杀死因果化身而用空间折跃送回神王府邸，则因果神王会大发问询并迅速动员响应，林恩的位置必然暴露开来。
- 若林恩在消灭因果化身后对它体内的因果印记进行快速瓦解，则因果神王感知会失去力度但只要再作一番就能成功锁定具体的位置。
- 若林恩在尸体分解中主动去寻找隐藏的线索，则可以提取她的部分因果轨迹，后续追踪因果神王的行动会更加得心应手。
- 若林恩选择把因果化身的残缺神格藏好以备必要时刻启用，则他在未来交手中能获得一击制敌的时机，但同样会被因果本体在无果中寻找到关键线索。
