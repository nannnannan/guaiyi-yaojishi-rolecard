# E272·破界血战叹息之潮·if线

- 若林恩在走廊听到轰鸣前先拽着左左向前冲而不是拉艾泽法拉，则「我和艾泽法拉先行一步」被改写成「我独自赴险」，血衣与弥赛亚被迫殿后，核心区分别时间提早。
- 若林恩主动先回应艾泽法拉「如果炽天使依然是炽天使，你该如何自处」，则他坦白自己也无解，但承诺「我陪你想」，她的敌意温度降一档，情感裂痕被预先安抚。
- 若林恩提前用巨像之心模拟负载测试，则他能在冲到封印大门前算好 51% 的承受上限，但血肉瘟疫在他身上的发作提前暴露，血魔得以识别他的血肉本质。
- 若林恩朝血肉教徒宣告「你们都要死」前先朝最远的唤潮者掷一支镇静针，则血魔得以立刻举起火炬的动作慢一秒，林恩第一轮死光扫到更多教徒。
- 若林恩在无主触手扑来时没及时唤血衣上身、先用咒瞳反照，则咒瞳被反打一道冰尘，机体出现一道独特的「蚀痕」标志，事后被主母追问。
- 若林恩举起火炬对抗黑潮时增加巨像之心到 70%，则他能为后方前代使徒额外撑出三秒，但机体损耗 +8%，开门消耗被预支。
- 若林恩主动朝血魔掷第二只灾厄魂灯引爆，则血魔被自己旧日残念反噬半秒，开枪时机补齐，但剩余魂灯减一、E278 反手给克苏鲁投喂火炬情节被掐死。
- 若林恩决定放弃斩血魔、只专心破坏火炬，则血魔脱身逃脱，E273 的血肉支配者二次降临改由血魔亲自打开血阵，难度直接升至古神 + 早期。
- 若林恩抓到火炬瞬间主动把自己也纳入黑潮的一部分防护圈，则他会被无序侵蚀率先出创口，但前代使徒的幸存率提升到 90%。
- 若林恩在艾泽法拉被淹没那秒强行伸手过去而不松手，则他与艾泽法拉一并被吞入黑潮，B 线再登场变成双双同行、E273 孤岛 B 线视角被改写。
- 若林恩对黑潮喊「我就是你的旧日主人」，则黑潮停顿半秒但未炸，他在那一秒看到克苏鲁意识残片哀鸣，作为 E274 渡鸦幻象的预演伏笔。
- 若林恩把火炬反插在地面当桩子并 Rally 众人围火，则火炬变成临时圣物，前代使徒开始膜拜这座火炬而不是他，E274 的「双火炬合流」走位路径要重排。
- 若林恩的机械左臂被黑潮沾染时选择立即切掉左臂而不是忍受腐蚀，则左左与机体的紧急脱离预演完成，但 E279 那幕「血肉左臂顶替」情节就要改写为「残臂被咒打造成短枪」。
- 若林恩在黑潮外围抛出高浓度伏特加火种，则火焰延缓黑潮逼近三秒、为救回一到两名使徒创造窗口，但这批被救使徒对火焰神迹的依赖被永久烙印。
- 若林恩捕捉黑潮中一枚旧日残肢入系统空间，则后续会成为他在 E277 仪式中临时替补的引子，而血肉支配者的夺舍狂喜被分走一缕。
- 若林恩在分殿突围时一记回旋踢踹飞从左后方偷袭的唤潮者，则唤潮者落入黑潮被吞，血肉神教在封印大殿提前损失一名唤潮者，E273 外层血阵脆弱度上升。
- 若林恩对黑潮宣告「谁拿走艾泽法拉我就灭谁满门」，则黑潮中传出几声讥笑，血肉支配者的注意力被从艾泽法拉上挪走一瞬，E273 二次降临首发目标改向他。
- 若林恩把 `sigh_tide` 区域封锁咒刻在机械臂上并快速成型，则他成为独一个能在黑潮边缘徘徊不被吞噬的人，但代价是表层机械被永久烙上一层扭曲彩膜。
- 若林恩决定不让左左探出来而改让咒瞳外溢，则咒瞳被黑潮的混乱色彩直接污染一格，后续咒瞳使用必须额外进行一层净化。
- 若林恩在最后停下的瞬间望向黑潮对艾泽法拉伸出最后一根触须，则那根触须被黑潮截断，林恩手里察觉到她被吞前的体温残存，作为 E274 认亲的物证。
- 若林恩放弃带回使徒、只与血衣弥赛亚突围回孤岛，则剩余使徒全灭、E273 海崖圣者骷髅数量减少、炽天使的信徒氛围变得哀戚孤独。
- 若林恩在黑潮退去后再回头摸取几缕样本，则他能估算出叹息之潮的粒子浓度，但机体损耗再 +6%、工程师维修费上升。
- 若林恩决定点燃一支灾厄魂灯作为对黑潮的「回馈馈赠」，则黑潮吞食该魂灯后延迟五秒退散，但魂灯被记入血肉支配者在地狱侧的梦境中作为下一次咒语的引子。
- 若林恩主动叫血衣相信自己不会死，则血衣点头，态度从「附身保护」转为「信任同伴」，E273 她离开林恩改去守弥赛亚时的心态更稳。
- 若林恩把巨像之心最后的输出全部推入触手动作而不开门，则他凭空劈开黑潮一线，为前代使徒抢到一条通往孤岛的小路，但个人武力储备跌落。
- 若林恩在最危急关头喊「我愿意和血肉神教重新谈判」，则血肉支配者在黑暗世界同步露出头颅，E273 投影时间临时推迟，但交换的代价是被要求一份高级血族遗传物质。
- 若林恩在封印大殿门口拓印一份蚀痕模型回系统空间，则后续艾雯爵士可以凭此进行「灾变反向工程」，E274 旧日时代幻象解析度上调。
- 若林恩拒绝孤注一掷、决定回孤岛再图救援，则艾泽法拉被黑潮多困二十分钟、E274 救回时的救赎场景完全错位，她心底的「理智证人」标签失落。
