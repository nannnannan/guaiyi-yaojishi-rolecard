# E410·旧日血肉之核·if线

- 若林恩在碑林里先用咒瞳逐柱扫过亚弗戈蒙、索德罗斯的墓铭再前进，则祂们的殒落年表在他面板里自发排成一条时光轴，长廊两侧某一尊无铭石柱会在他靠近时主动渗出紫黑血珠，避雷一条「无铭石柱是活物」的预警。
- 若林恩没直奔中央空洞、改沿王座后甬道往更深处摸三十米，则他能撞见一面被血肉巫术半封的「侍从殉葬壁」，墙面嵌着一排已石化的疫医面甲。
- 若林恩在空洞外先让喵喵出来沿结界外圈巡视，则她会嫌恶地捏着鼻子踢开一块仍在蠕动的残肉，嘴里骂「这玩意还在呼吸」，那块残肉被她踢得朝林恩方向翻了个面、不自觉地露出底下一截刻纹脊椎。
- 若林恩不直接用往日遗念、改让艾雯爵士以灵能屏障悬在石门上一寸处「等门自重」，则门上的血肉巫术会在一炷香后主动流下黑色黏液、把铭文重新描了一遍——这个免费表演事后被列为「石门主动示形」首次记录。
- 若林恩把血肉支配者影像中的门序倒过来按、以「左下、右上、中心、再左下」的反向路径试验，则石门会以一声低沉咳嗽般的肉响回应、然后咯吱错开一道尺宽缝又自动合拢，门里透出的寒气把在场夜医面甲全部结霜。
- 若林恩用咒瞳往石门铭文深处压一层扫描，则他发现铭文表层之下还嵌着一排属于泪烛语系的辅助符号、组合意为「父赐我钥匙」，事后他向艾雯转述时没提这行小字、只记进自己的私人备忘录。
- 若林恩把刚入手的旧日血肉之核先挂在腰间摇晃着走向石门，则核心自带的心跳会忽然加速到与石门浮起的那声低鸣同频，中央空洞残肉不自觉齐齐一颤、把夜医副官的枪都吓掉了。
- 若林恩选择把核心送往黑堡由博士团队远程评估、而非自己殖装，则破晓315会以「同源献祭」的名义申请独占样本并附上三支人形寄生虫酬金，林恩背包当日多出一份「博士定制礼包」。
- 若林恩最终决定殖装、但把植入点临时改到右肩而非右胸，则链接瞬间核心会把他整条右臂掀入痉挛状态五秒，咒瞳里那条旧神低语的第一句直接烙进肩胛骨——事后每逢月相变换他右肩就发烫一次。
- 若林恩在殖装反噬瞬间主动召唤左左回体内充当「临时意识锚点」，则她会被拖动进入他的颅内与万千不属于他的尖叫同频共振，事后她整整三天不说话，恢复后第一句就是命令他晚上用嘴把她的咒纹一根根亲醒。
- 若林恩拒绝殖装、只把核心用原初之力封进一颗临时血肉匣里挂在胸前，则匣子会随他呼吸发出类似婴儿吮乳的咕噜声，泰坦远远见到后皱眉表示「我嗅到了爹的脏气」。
- 若林恩趁夜医换岗间隙独自下到中央空洞探一探残肉，则他的靴底沾上残肉表层黏液时会触发一整段不属于他的血腥记忆——他被回忆起自己曾站在旧神尸骸之间手持长枪，那一秒的他落泪。
- 若林恩主动把喵喵的喵喙覆盖在自己嘴上「替我亲这头心脏」，则她一边嫌弃一边把喙贴在核心上一秒，核心以极低音量回赠一句「孩子，你来了」——喵喵被吓得当场炸毛飞回林恩怀里嚎了半小时。
- 若林恩决定向殖装反噬偷渡一缕以M气息稀释，则万千尖叫会在他颅内被一层油腻的柔光罩住、不再那么刺耳，反噬强度下降三档，但他在接下来的十天里每逢打哈欠就会从阴道里渗出一缕淡金色以M雾气，被左左指控「你嫁给我还是嫁给我下面那位」。
- 若林恩在殖装成功后的第一次旧神低语里故意沉默不答、只用舌头舔了舔自己唇角，则低语第一次出现明显的「停顿」，他得到一粒「沉默反制低语」的临时加成印记。
- 若林恩事前用拟化把核心的搏动声音录成一枚塞耳指环戴在左左的耳轮上，则她那一晚梦里听见万千旧神齐声咒骂、醒来把指环摔在他脸上要他赔一次深夜舌弄她左右耳的赎罪。
- 若林恩对殖装拒绝置评、转身命令夜医撤离中央空洞而他自己留下「再坐一会儿」，则他单膝跪在颤抖的残肉堆前哭了一场没有泪水的哭，咒瞳自动把这段影像加密成「林恩·无声的父」存档。
- 若林恩把殖装成功的消息第一时刻当面告诉泰坦，则泰坦会罕见地伸出骨指按住他右胸口沉吟三秒，然后用骨节敲了敲核心表面说「小弟心脏挺会跳」，随即转身在墙上用战斧留白一道刻痕作为「认弟见证」。
- 若林恩在开门失败当晚就把试错过程全部醍醐灌顶给黑堡团队，则315博士远程申请「我们通过你的视界模拟」，林恩首次在面板里看到「被远程共研」状态的灰字标签，恨意结算悄悄 -2。
- 若林恩主动让艾雯爵士坐在殖装术台旁与他十指相扣作「精神依托」，则核心释放反噬的瞬间她的灵能也被同步扯入，她咬住他指尖不让自己叫出声，事后爵士第一次主动在他掌心写一个字「傻」。
- 若林恩尚未稳定殖装就强闯石门试门，则核心会在他骨头里撕裂式低吼一声、把他整个人从甬道里掀飞十米撞进碑林某一尊亚弗戈蒙石柱，石柱崩塌砸出第二口浅坑，夜医全队被惊醒、紧急把他抬回黑堡停尸房休养一周。
- 若林恩在殖装成功后主动用原初之力反向探入核心寻一脉旧神残念，则他锁定一段「白发人递给心脏者这块东西时眼中含泪」的极不完整影像，他当即把这段影像刻进一枚玛瑙指环戴上不摘。
