# E162·多次召唤失败与跨界失联·if线

- 若林恩在第一次召唤失败瞬间就关掉免打扰并把「能级不足」置顶钉在黑夜城状态栏，则后续三次失败都不再猛烈震荡，事件以变形（响应节奏前置）收束。
- 若林恩主动用咒瞳隔界扫过白逸那套专属法阵、把错误的谱系节点反向涂红标出来，则白逸在第二次刻画前就改笔，事件以变形（阵图提前修复）收束，尹依阴气损耗降低一档。
- 若林恩主动把自动回执「您召唤的生物不在服务区，请听到叮声之后自裁」改写成「莉莉洼，为了你我会来」，则白逸在第四次失败时听见带有温度的人声，事件以变形（召唤回执改写）收束。
- 若林恩在那四次失败之间主动把咒术延伸出去、为白逸的刀刃涂上一层临时的血肉恢复膜，则他的反复自残不再是当场崩盘的爆伤节奏，事件以不变形收束但白逸生命曲线被拉平。
- 若林恩主动让左左隔界浮在古井上空、用小手向下轻压阴气堵住法阵漏洞，则第四次失败时阴气外泄减少三成，事件以不变形收束但聚合体吸取量被掐短。
- 若林恩主动用咒术把四次失败的能级不足记录反弹回去、刻进法阵本身作为记号，则法阵外壁多一道能级瓶颈纹样，事件以不变形收束但后续读取门槛更清晰。
- 若林恩主动用一根血肉触手从裂隙另一侧反向递过去一支阴气注射剂给尹依，则她的祭品流失速度减半，事件以不变形收束但阴灵保魂窗口扩出一格。
- 若林恩在聚合体讥讽「一根火柴让重型轰炸机起飞」时主动用咒术把那句话原样弹回给它，则它半秒沉默后改口「换句话说你得自己当那架轰炸机」，谈判节奏被硬生生掐拐。
- 若林恩主动把一段利维坦血肉通过法阵裂隙反向封进古井底部，则法阵每次失败时不再泄干净、留一线余力给下一轮，事件以不变形收束但失败代价被对冲。
- 若林恩主动远程把尹依抱紧白逸的瞬间用咒术推一把，则她含泪喊出「带我姐姐回家」之后多了一句「好吗大哥」，事件以不变形收束但召唤请求多了一层温情滤镜。
- 若林恩主动让左左在古井阵图一角种下咒纹种子作为「回家路标」，则聚合体一旦想夺走法阵就先撞到这颗种子，事件以变形（法阵预设阻碍）收束。
- 若林恩主动用咒术把「召唤能级不足」的第四条记录标记为「弟兄已听见」并把响应窗口留给玩家，则玩家在任何一次失败时都可主动响应，事件以变形（玩家响应窗口持续悬挂）收束。
- 若林恩主动让咒术向整个蓝星南方村落撒一张血肉警戒网，则在聚合体正式现身前他已被三位黑名单分子感知到，事件以变形（警戒网触发）收束。
- 若林恩主动请聚合体把尹依和尹琴暂时留在他看不见的地方谈判，则它咧嘴一笑反问「鸦族什么时候有心了」，事件以变形（聚合体谈判转向协商）收束。
- 若林恩主动让白逸的最后一次自残改为撕裂自己衣襟露出猎魔人印记当祭品，则阴阳两界都短暂看见该印记，事件以变形（印记替代血祭）收束。
- 若林恩主动在第三次失败后就把咒瞳连接自动回执、向白逸单独讲一句「请继续试」，则第四次失败中白逸少一分惊慌，事件以变形（玩家远程陪伴成立）收束。
- 若林恩主动用咒术改变法阵铭文中「不通地狱」一句的解读，将其指向尹依的阴气本源，则第四次失败时法阵首次以外部阴气作为补助，事件以变形（阴气叠加补能）收束。
- 若林恩全程不介入、任由四次失败发生且免打扰生效，则默认走向收束，聚合体夺取法阵并围困尹依与白逸。
