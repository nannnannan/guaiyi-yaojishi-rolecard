# E457·地狱火走廊突袭·if线

- 若林恩在穿越空间传送门瞬间主动把左左从意识里拉出来按在肩头，则她被火山灰糊了一脸、大呼「早知道不出来」，当晚拒绝回应作战图纸。
- 若林恩在十万湮灭光束两秒洗地利到前先把近旁三名夜医反手摁进一个刚撬开的维修舱里，则他本人在外接下了余波，那三人后来被他从舱里拖出，一人右腿已失去知觉。
- 若林恩在眼眶蚀痕加重时主动把咒瞳换成普通眼球观察导弹轨迹，则他一口气数出十七道穿透气道，但左萝在意识里骂他「白白浪费特权」。
- 若林恩在隐身舰外壳被撕开一道缝的瞬间主动用王戟撕下舰首一块完整的气泡装甲，则那块装甲被夜医拖回当成了「良医的第一次击落纪念」，三月后糊在训练营内壁。
- 若林恩在仰首的第七秒让灵能薄纱无声无息落下而所有导弹在半空消泯，则夜医士兵齐齐举头看见了那一线淡纱，此后整整三日「良医的透明帘子」成了不被允许说出口的打趣词。
- 若林恩在反向对撞中故意留下一枚黑导弹单独击穿他的左肩，则他肩胛骨裂一道斜线，但后续三发齐射他凭骨骼感觉提前 0.4 秒回避。
- 若林恩在闯入舰体走廊机械人形红光扫射前突然让左萝的意识短暂退到意识最深处，则她躲在他意识角落里缩成一团——他胸前护甲被激光擦去一块，正好是她原本依附的位置。
- 若林恩让血肉之核在三次分脉中把巨像细胞直接送进舰体反应炉旁的椽钢里，则那具舰身在接下来几小时里会随他自己的心跳轻轻震动，士兵在撤离时能听见低频「咚、咚」。
- 若林恩在舰船即将坠入荒野时主动不跳下去，则他在残骸顶端静坐五分钟，让夜医把他的支援纪录上报成「指挥官姿态」。
- 若林恩在拆舰令下达前主动接下了一道掠过半空的巡洋舰主炮，则他的左臂被贯穿一个直径手掌大小的洞，但那一发炮弹没掉进夜医阵线。
- 若林恩在走廊血肉漫灌时让一部分自己的血肉带上一缕引战素，则纳米机械在显微镜下办起迷惑行为，多取出三秒——但左萝当晚被他「敢用那条刺激去治」的态度吓了一顿。
- 若林恩在稳定双瞳里调出他的神经总机把左左的手掌倒贴自己额前，则她冷静下来进而协同他计算下一波编队的落点，双脑并发使破解速度倍增。
- 若林恩刻意不启用泰坦法只凭初诞者之力凌空斩下护卫炮，则他在第二站稳落地时双肺缺氧唤作「大气烫」，一月内多了一项「战时不要贪酷」的代号。
- 若林恩任由舰队几波集中盐炸烧掉他一部分背肉的神经细胞，则他事后在奇异世界里留下了一条永久性后背旧记忆阴影，不能长时间仰卧。
- 若林恩在左左问「下次可不可以提前叫」的瞬间抬手按住自己的眉心、让一滴苍蓝血珠滚下来，则她拿手指蘸层血珠偷偷尝了一口，之后三天一直不肯看他。
- 若林恩在「不是良医是林恩」的自谏被夜医喊出后反向自承「对，就是良医」，则全场士兵气势+30，但被指挥官当成「过于亮眼」被单独列入外部宣传名单。
- 若林恩在金光庇护下被战舰爆炸残光所刺，故意脱下护目镜熏成半盲，则他把后半段战斗用了完全的灵能感知，后续「良医盲打」成了心猿意马的暗项。
- 若林恩在三叉戟钉取中央处理器时主动扭动王戟让那块芯片正好卡在戟脊的拨盘里，则它成为他后来一份战利品遗物，被左萝抢去当珍藏。
- 若林恩在舰坠断裂后主动把整具残骸最末段的一段舰桥骨指染自己的血气，则后续在拆解时那一段被设定为他的「私物存放区」，远征军不会动那里。
- 若林恩在士兵惊问「还能这样打吗」的瞬间随手举起一块战舰残片拍了拍、再扔回去，则他们集体读懂他的意思——后续突袭计划里多出了一条「良医提供可投掷废件」备注。
- 若林恩在拆舰大宗流程中故意跳过验尸岗位、走向战场前沿工地，则「良医极少清点数」被写入了后勤手册收尾条目。
- 若林恩全程不动用泰坦法、纯以初诞者与血气布局，则他在战后被评定单加一项「无装配合格」，但巨像循殖的同步率在当日下滑三个百分点。
