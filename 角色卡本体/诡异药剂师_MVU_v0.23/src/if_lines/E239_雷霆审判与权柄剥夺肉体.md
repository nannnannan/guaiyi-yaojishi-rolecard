# E239·雷霆审判与权柄剥夺肉体·if线

- 若林恩在雷霆降落瞬间同步运转咒瞳拍向自己、以4点魔化效果主动接受血肉剥夺，则咒瞳以他自身为坐标自主吸收权柄威力，剥夺强度折半，他以变形（权柄剥夺减半）收束，但咒瞳本体当场爆炸。
- 若林恩在血肉剥离到达脖颈时及时启动灵能处理器换成直视人格视角，则他从"我在失去血肉"切换到"我在被裁决"的旁观者视角，精神震荡减轻但肉身损失未被压制。
- 若林恩在被剥夺血肉之前先把左左的傀儡之印在自己胸口挖一个隔离舱安置，则"剥夺权柄"逼近心跳时被隔离舱挡下一半，心脏保住，事件以变形（心脏隔离求存）收束。
- 若林恩在弥赛亚折返拥抱的瞬间把权柄剥夺引导到她体内的圣血上，则她被拉入"血肉被剥夺"的灾难，十二翼天使羽翼变成保护伞盖住两个人，事件以变形（圣血反向承载权柄）收束。
- 若林恩在被剥夺过程中让巨像之心改成"吞食权柄残力"，则他心脏以反式位元取代血肉支配节奏，"剥夺"被转换为"重铸"，事件以变形（不受剥夺、保留血肉）收束，整场机械之路被改写。
- 若林恩让左左的傀儡之印在他被剥蚀到面部时把左左本身投射过去替她承受剥夺，则左左的手臂当场崩解、事件以变形（左左断臂）收束，血肉支配者发现这具"血肉傀儡"身份，后续追踪路线被指向左左。
- 若林恩让雷霆审判不仅落在血肉支配者身上、还分出两道精芒同时劈在自己额头与脊椎，则他在权柄剥夺之前先"被雷霆净化过一次"，后续剥夺过程因为已被净化反而减速20%，事件以变形（夺权自净）收束。
- 若林恩在被权柄包夹时故意朝第一使徒伸出腐朽的手笑一声"这是你教我的"，则权柄剥夺带上一道反向情绪污染反向侵蚀对面五秒，第一使徒被这一秒影响，他趁机把自己的意识空间再次加深。
- 若林恩在权柄剥蚀到达下肢时用最后一丝意志把左左塞进系统空间，则血肉剥夺完成时左手不在他身上，事件机械机体制造环节少一位左左，三位一体结构在E242时被重新拼合。
- 若林恩在被剥蚀前先切断自己与巨像之心的链接，则权柄剥夺只能作用于他肉体而伤不到心脏，巨像之心脱机存活、躯体残躯也能无损保存，事件以变形（巨像之心外悬）收束。
- 若林恩在弥赛亚将自己拉起时用最后一口低沉的命令说"把我的脸画成你心中最深的恐惧"，则她在黑焰翅膀包裹思维时那一瞬间对上那张脸，san值崩溃+危机意识+觉悟同步发生，她被强拉到升腾系统空间的速度提升一倍。
- 若林恩让血肉支配者发现他在被剥离时左手依然能动一下，则对面意识到"这具身体仍藏有血肉丝线"，权柄剥夺的最后阶段被他反向盯住，事件以变形（权柄剥夺局部停滞）收束。
