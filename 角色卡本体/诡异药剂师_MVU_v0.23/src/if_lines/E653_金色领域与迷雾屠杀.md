# E653·金色领域与迷雾屠杀·if线

- 若林恩不吹散伪装而直接突入包围圈中心，则敌方上位神会在他现形的前一刻识破，他们主动引爆一位友军以警告自己的同侪，林恩先损失一半突杀机会。
- 若林恩用「神王已死」的消息在残部里播下恐慌，则恐惧立刻蔓延，敌方上位神也压不住阵脚，金色领域能直接收割一半逃兵。
- 若林恩只对付高位者、放过下位，则金色涟漪锁定数位上位神后立刻被他拔走，敌方大军失去主心骨，下位神群瞬间溃散、无人可拦。
- 若林恩让金色领域只罩住三位上位神、其余任由四散，则会保有领域里三位但任由其他残部逃出幽冥海，他赢得领域却输掉情报封锁。
- 若林恩在身上披一缕疫医伪装而不是真理法则，则敌军立刻认出他不是神王，直接用无序生灵反击，他必须在第一时间破快速杀出。
- 若林恩让三叉戟化龙而非神兵横扫，则金色巨龙会击落一位上位神，其余会疯狂逃窜，他能锁定多一半残部但会减少抢走神格的机会。
- 若林恩在离开孤岛之前特意回去投一枚棺椁的碎片在迷雾里，则那片迷雾会产生一道延迟爆发的时间涡流，残余追兵在撤离时被突然拖回时间长河。
- 若林恩选用三叉戟直刺那只曾想吞噬他的无序神灵，则他会获得一个横跨感觉生灵情感的回馈，他会在那瞬间恢复对身体的觉知。
- 若林恩让金色涟漪圈住最远的那个上位神先隔着很远撕下他的头颅，则残部会立刻转移、只向他逃至的出口方向逃去。
- 若林恩把金色领域扩张到极限的三分之二，则所有在场高位者都被定格、他从容解决问题，但领域里死相会被留存，他无法在这一场之后立刻离开。
- 若林恩在逃兵堆里突然点亮罪火升到二档，则剩余的敌军立刻停止逃窜原地等死，他能一口气收干净战场，但他本人会被罪火反噬一丝。
- 若林恩在追击逃兵时用初诞者之力把某个逃得最远的神灵炸得只剩神格，则神格会在他手心跳动，他能立刻收缴全部残部神格，但对手会对他畏惧得连挣扎都不愿。
- 若林恩先对着西边的黑洞巨兽喊一句「回去吧这里不是你该来的」，则它会听从这声音转身离开，但金色少年会在听到这一声之后半年里不顾一切守在这块海域。
- 若林恩在自身罪火尚未彻底兴奋前先把一条染上金色涟漪的雾气接引到他的呼吸里，则他就着雾气的凉意，将金色领域扩张到惊人的地步，他可以单挑数只上位神，但吸入的雾气会在他胸腔愣上数秒。
- 若林恩让一位多余打伤拿掉手臂的腐化神灵逃出去投送情报，则他会换取一个人人自危但不敢再与他对抗的阵营气氛。
- 若林恩毁掉神格而不收缴，则神格会在敌方的深渊里彻底熄死，敌方残部里会有新一批上位神的接管者出来代替他们的位置。
- 若林恩用一枚疫医血包放在某个被金色涟漪定格的上位神手心里，则一息之后他看到那位神灵白眼翻活，能替他挡下一波无序生灵攻击，却会被他自己身上的疫医气息反噬而死。
- 若林恩在收网结束之后准备离开深渊，则一阵微弱的心风让他意识到自己忘了给左左一个信号，他不会急着恋战，而是把一件疫医护身符塞进系统商城，换来左左收到一件护身符的反应。
- 若林恩离开战场之前把所有的战利品放在一个半透明疫医小球里，则他在认领战利品时会得到一枚「可用异域材料换购疫医药剂」的系统提示，但不需要兑换的情况下他也能随手使用。
- 若林恩在屠杀结束后点燃一枚信号弹给神界发去「猎物已死」的错误讯号，则敌方残部会信以为真、立刻放空警惕，他能趁机偷偷离开迷雾之海返程。
- 若林恩坚持到最后只剩一人对着黑洞护主，则他会主动放开周围所有散兵、追到大黑洞和它一同坠入，他会和黑洞里那一缕神王对决，但这场对决会让他损失大部分金色领域之力。
