# E149·重返002与认知空间驱逐·if线

- 若林恩在门外先以猫形态撬锁、被羽毛笔「对猫咪的喜爱一如既往」的字据接住，则认知驱逐对猫身不生效，原作路径以猫身潜入异度空间直接展开，林恩未触发「回床惊醒—再闯改道」循环。
- 若林恩拒绝接受猫形漏洞、坚持以人形直接穿越走廊，则002驱逐机制在他身上完整兑现：他毫无警觉地自行回屋睡觉、惊醒后记忆空白数小时，强闯第二次无意识改道去澡堂，直到黑弦月追上才恍然，本事件以「认知操纵被实证」完成而非「进入异度空间」。
- 若林恩事先请黑弦月或左左在他每次跨门前就地写一行当日目标与签名作为外部锚定，则驱逐触发时锚文与记忆冲突被读出，他能在第一次「决定回去睡觉」的当口停步，本作变形条「外部锚定记忆」成立，002把他认作「已登记来访者」短暂放行。
- 若林恩组织喵喵、左左、黑弦月三人以上互证进入、每人各自口头复述同一目标，则驱逐机制首次面对多点同步证词出现一帧迟疑，队伍被推回走廊口而非各散，原作「独自撬锁」改写为「群体抵达门前」，事件以「驱逐被群体证词压制一次」完成。
- 若林恩通过夜医通讯器与艾雯爵士建立远程通话、由艾雯实时同步他脑内所想与行动，则驱逐开始改写行动时远端会立刻指出偏差，等价路径成立：进入异度空间的稳定办法由「远程互证」而非「猫形字据」兑现。
- 若林恩在被「回去睡觉」的驱逐命中后选择不抗、直接睡到第二日，则002同步把梦境中一段夜医被自己认作看门犬的画面植入他梦中，他醒来时多一段「亲眼见过的错位样本」，异常中心的情报从口述升级为亲历。
- 若林恩在门外遇到把自己认作看门犬的夜医并选择回以相应犬类礼节、不强行纠正，则被错位的夜医认定他是「新来的兄弟」、四脚着地替他引路至002门口而不触发驱逐，等价路径以「错位患者代引」成立。
- 若林恩对错位夜医直接展示咒瞳并试图用神之方程式修正其自我认知，则夜医原地僵直片刻后倒地昏迷，002感应到「同类权柄波动」、驱逐机制暂时抬升一级，事件以「修正失败＋驱逐升级」记为紧迫支线。
- 若林恩接受艾雯爵士封锁建议在门外扎营观察三日，则事件按取消条件推进：002室内扩张的黑色异度从门缝渗出一线脉络、林恩以远程样本取得「病变空间存在」的关键证据而不亲身进入，原作默认走向改道为「远程取证」。
- 若林恩在猫形撬锁成功后让羽毛笔（仍失控中）的扩张空间把他当作「无害小兽」而非来访者，则他被门内血肉经络主动吞入而非穿越，落地时身处异度空间腹地、跳过入口大厅那一段，原作怪物迎敌序列相应重排。
- 若林恩决定在异度空间摸底时同步让咒瞳记录空间结构、被黑弦月远程协助比对，则咒瞳在描绘第二圈脉络时被002感应为「非允许的测绘」，咒瞳镜面出现一道新裂缝、林恩获得一份残缺的异度结构图。
- 若林恩在羽毛笔本体相遇前先认出那些黑色血肉其实是她本体扩张的隔离壳，则事件结果影响改写：他对羽毛笔「温和本性与失控权柄并存」这一判断从外部推断升级为提前内部确认。
- 若林恩在强闯失败后主动告知黑弦月他确实被驱逐、请她代查记忆空白数小时的时段，则黑弦月以履约保护为名在他胸口烙上一道月纹追记符，之后每一次驱逐开始时月纹先一步灼痛、林恩获得「驱逐即将发生」的预警机制。
- 若林恩让喵喵代替他以猫形潜入002、自己在门外远程指挥，则喵喵被羽毛笔的猫接纳逻辑误判成「字据对象本人」、异度空间对她的态度比对林恩更温顺，但505字据的权柄连接在回程时被拉出一条淡红丝线缠在喵喵尾尖，本事件以「代探成功＋权柄转移痕迹」记结。
- 若林恩在门外与艾雯爵士交易、以一次免费诊疗换取她先行潜入探路，则爵士在走廊内被驱逐改写为「回办公室喝茶」、连茶都没喝完就忘了来意，林恩由此实证「驱逐对夜医同样生效、不针对外来者」，事件以「影响范围确认」完成。
- 若林恩选择不依赖字据、不依赖猫形、不依赖锚定，只以咒瞳直视002门牌长时间凝视，则驱逐机制反向锁定咒瞳并暂把他认作「门牌的一部分」，他在原地僵站直到黑弦月拍肩，事件以「咒瞳与权柄共振失败」记录变形。
- 若林恩在被驱逐改道去澡堂时段中、主动把浸湿的字据摊开在池边晾干并逐字读出羽毛笔原句，则字据上「不管在什么时候，她对猫咪的喜爱可是一直都是一如既往而不会改变的」这一句浮现微光、002的扩张暂停一拍，事件以「字据主动显效」给出等价进入窗口。
- 若林恩在002门口直接表明「我来找羽毛笔谈字据与调教约定」，则门内血肉经络停止蠕动一瞬、藤蔓状肢体为他让出一线窄道，权柄契约被门内承接为「伴侣归来」的通道凭据，原作怪物迎敌环节被以「伴侣通道」整体旁路。
- 若林恩接受封锁撤离并选择将002长期隔离，则事件按取消条件关闭：异常中心夜医的认知康复缓慢推进，羽毛笔的扩张异度在数月后自行退潮，林恩在 E150 条目到达时只剩门诊记录可查，原作「病变空间被发现」改由夜医后期档案代交代。
