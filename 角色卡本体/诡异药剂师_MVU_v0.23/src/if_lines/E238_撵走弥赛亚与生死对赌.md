# E238·撵走弥赛亚与生死对赌·if线

- 若林恩用左轮抵住她脑门时没有二次上膛只放了一发子弹，则她判断他"还剩一颗"不敢动，被逼撤退的范围缩小，她没能真正走出战场，事件以变形（她在远处观战）收束。
- 若林恩清完两轮弹夹后把左轮丢到她脚下补一句"这是保命的"，则她握着枪从"被驱赶者"转换成"获得护具者"，她在远处折断一枚子弹许愿的仪式触发，祈愿波动改写后续咒瞳骰点。
- 若林恩在撵走弥赛亚之前补一句"如果我没回来就让左左从蜀都过来收尸"，则她离开战场的姿态从被动变主动收尸预期，"明日之约"被多方确认，血肉教徒监视到这一幕把消息反传第一使徒。
- 若林恩让她走之前吻了一下她额头，则她愣在原地一秒钟挪不动脚，这一秒反而让血肉支配者逼近一步，"咒瞳发动"被他以一秒之差卡住、位移失败，事件以变形（最后一掷失败）收束。
- 若林恩把咒瞳拔出后没立刻发射而是先凝视血肉支配者的脸三十秒再掷骰，则对方意识到"他在评估等待某种结算"，提前在心底做好接受对赌的准备，骰子4点的"生死对赌"效果反向打折。
- 若林恩不给血肉支配者掷骰机会、独吞咒瞳反噬单独扛下"百分之百未命中"，则事件以变形（他一力承担）收束，但咒瞳的完整反噬把他从精神炸到颈椎以下瘫痪。
- 若林恩在骰子落定瞬间补一句"不管我赢不赢，你都别再骚扰左左"，则血肉支配者愣神一拍，骰子的3 vs 2结算变成3 vs 3，"平点重投"机制被触发，赌局重新掷出一轮。
- 若林恩在血肉支配者提出"日以继夜折磨"反提议时立刻接一句"我接受"，则对面错愕他没反驳，"生死对赌"打成"主人-奴隶"对赌，咒瞳的规则被扭曲成新玩法，事件以变形（规则变形）收束。
- 若林恩先让弥赛亚把"师父和徒弟会平安"这条愿望用颜料写在山丘的树皮上，则她离开后留下的字迹恰好被第一使徒在嘲弄时看见，"你这个徒弟"被识别出身份，事件以变形（身份暴露）收束。
- 若林恩在掷骰之前先用血肉灾变在自己胸口刻一道"我绝不后悔"，则骰子落定瞬间这条信念被咒瞳捕捉成"信仰加成"，点数从3 vs 2改写成5 vs 2，事件额外获得一次反转窗口。
- 若林恩在血肉支配者咆哮"林恩"的一秒突然用血肉拟化出左左的形状被她所假装，则第一使徒对面不再是血肉支配者而是"自己的徒弟突然出现"，分身判断卡住，规则挟制在那一瞬松脱。
- 若林恩让左轮丢下战场时被山丘的傀儡之印自动拾起并按它自己的节奏补一发子弹，则血肉支配者一侧脚步被失误打断，"生死对赌"的掷骰动作被迫拉长一秒，事件以变形（规则时间延长）收束。
