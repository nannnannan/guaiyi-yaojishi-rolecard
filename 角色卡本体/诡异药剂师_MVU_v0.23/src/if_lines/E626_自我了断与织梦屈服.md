# E626·自我了断与织梦屈服·if线
- 若林恩在餐馆吃面时先耐心听左左谈完枷锁论再发言，则她顺利把「保护伞」定性说完，他的「偏执一辈子」自认在出口前以点头成立，裁决权从那一刻他已经拿回来。
- 若林恩反问左左「如果有一天你也像我一样保护伞心态怎么办」，则她哽住一秒竟不答，翌日她在酒店二楼窗口独坐看月儿兰城夜景。
- 若林恩在七日监视中突然对那双灵能注视挥手打招呼，则远方楼内织梦首次轻微皱眉，自己是否被看穿的不确定性落地，舰队画面劝降语气再多半分柔软。
- 若林恩酒店对峙开局先起身点烟给她递一支，则织梦拒绝，烟雾开始前她多一句「原来你也会想给我递烟」，鹰隼视线短暂软化一秒。
- 若林恩在听舰队画面时先反问「他们即使把那支舰队全部吃掉，对我有什么用」，则织梦滞半秒，「数字生命即我分身可复活」的事实被她点破，施压强度没有下降但底牌完全闪亮。
- 若林恩在答应「我听你的」瞬间突然再反问「我杀自己呢」，则织梦笑容僵住，自我了断的节奏被她以半秒优势提前看透，但她仍拦不下。
- 若林恩的自我了断节奏再慢两秒，则织梦冲到面前时已能够拦下他四分之一湮灭，她本质切割减半，代价是从本事件开始就灵能镇压全队。
- 若林恩的自我湮灭不设提前对准自己的力量、而是临时拍胸，则他需要两秒蓄力，织梦已经冲到面前，自我了断当场被阻止，整个服从测试不发生，事件转为无限期对峙。
- 若林恩在湮灭瞬间主动喊一句「左左，对不起」，则左左歇斯底里声浪暴 增一倍，织梦救援投入更猛，本质碎片切割更多一分。
- 若织梦切割的碎片是七角型，则林恩重燃时初诞者之力颜色从苍白叠加光泽，白烬首次公开在 E631 时就多一层绯色光泽。
- 若林恩在重燃后不说「你才出一张牌我掀了牌桌」，只淡淡起身，则织梦反而更心虚，服从测试节奏由她主动加速，四道命令以更快的节拍推进。
- 若林恩在放人命令后加一句「也把她放回来」，则织梦滞半秒，主动试图跟他讨价还价，最终落地仍是放艾雯但刀法稍晚两日送达。
- 若林恩在引舰队命令后多补一句「把他们引到地狱旁边」，则织梦迟疑一秒，最终选择引到更远的边缘宇宙，深渊留守部队危机彻底解除。
- 若林恩在下跪命令前主动伸手帮忙扶她，则她诧怔一秒反而主动跪下，「被扶的跪下」比「被逼的跪下」更让她愤怒，服从测试的屈辱加倍。
- 若林恩在耳光命令前先问她「你觉得你会被我打吗」，则她出言「你不会」，耳光落下时她的失控感由「被背叛」改为「被愚弄」，跪规矩的定力更强。
- 若林恩在舔脚命令前主动多说一句「你可以拒绝，我不杀你」，则她反而被迫下跪舔脚，他的「不杀」比「杀」更压得她喘不过气，屈辱加倍。
- 若林恩倒数三秒后真的放她走，则她在门口回头停留一秒，「被放」的姿态让她比被命令更不甘，她自己回头跪下完成舔脚动作。
- 若林恩在立规矩前多问一句「你有朋友吗」，则织梦愣住十秒，「你这个魔女」一声独白被她以沉默收下，服从测试以无对话收束。
- 若林恩捏住她下巴时主动多看一眼她切割碎片留下的眼角，则她在被捏下巴那一刻心底升起一缕「被看见」的诡异情绪，日后在与他的对弈中她试着让步频度稍多。
- 若林恩在服从测试结束前主动让她起身扶起她，则她怔住不肯起，服从底线由「跪」改为「跪后起身」，后续她与他的平等对话空间更大。
- 若林恩在四道命令后主动约她明早一起去餐馆吃面，则她表示愤怒拒绝，但第二日仍会换个面出现在餐馆的另一端。
- 若林恩在她问「我可以走了吗」时答「你可以走也可以留下来，你选」，则她选择留下来听审问，服从定位从「被命令」顺势过渡到「主动奉陪」。
- 若林恩在服从测试中让她做四道命令后再加第五道「对着月儿兰城远望三秒」，则她照做，服从测试段位收尾时她多一份「他居然让我看风景」的诡迷恋。
- 若林恩直接在服从测试开始时就说「我决定不杀你，你活着为我服务」，则她当场问「那为什么不杀我」，他开始新的博弈，事件推进节奏改写为单线情报审问。
