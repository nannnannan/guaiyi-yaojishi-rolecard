# E420·罪孽城公开惩罚·if线

- 若林恩在灌药前先把她两只翅膀用蚀痕钉在王座背板上，则她挣扎空间被压死，药剂从唇角灌入的画面被两边石柱上的血族浮雕完整映照。
- 若林恩拒绝灌药、改用巨像之锤直接锁喉进行家长式管教体罚，则她的暴怒从「被药剂整蛊的羞恼」切换成「被体术压制」的路线，药剂戏弄桥段整体删除。
- 若林恩在眷者撞开门前让她先跪在自己面前磕一次头，则大门撞开首帧画面是女王伏地，眷者由维护转为目击主位颠倒，全场士气骤降一档。
- 若林恩反向用左左卷住嘴唇不许她尖叫，则体罚全程无声，眷者进殿时只见主人抽搐却听不到骂声，羞耻度更高但威慑面降低一半。
- 若林恩在当众体罚中途让她自己高喊「我是血族老祖、不怕被打」，则她从咬牙死撑改成破罐式哭喊，尊严最后一块遮布由她亲手扯掉。
- 若林恩把公开体罚场景移至宫殿外广场、召来更多城民围观，则她尖叫调门突破物理极限，事件以变形（全城公开）收束，伪神级威压同样使在场平民麻木。
- 若林恩在眷者冲到五步以内时主动把巴掌换成轻敲她额头训诫，则她从剧痛切换成羞愤憋屈，尖叫转为咬牙低吼，属下目瞪口呆的场面再翻一层。
- 若林恩用蚀痕从大厅角落冒出贴上每个眷者大腿后方威胁，则无人敢进前一步，体罚与围观同时成立，她的最高音命令被双重剥夺。
- 若林恩拒绝让眷者旁观、命令小丑心脏用空间屏障封锁殿门，则体罚只留下她与林恩两者，事件以变形（密室惩罚）收束，公开立威效果减半但调教专注度升满。
- 若林恩在体罚前先把黑颅币塞进她嘴里让其咬紧不许出声，则她被罚之前先被罚咬住身份象征，怨毒表情成为可核瞬间。
- 若林恩在惩罚间隙停手问她「还要继续嘴硬吗」，则她被迫说出服软的回答，她的嘴硬第一次被自己亲手打破。
- 若林恩把她痛哭求饶的狼狈瞬间以咒瞳录下后展示给她一人观看，则她从又羞又恼变成短暂失语，「以后听你的」这句承诺可信度提升一档。
- 若林恩在放俘前先让她当众跪求放人，则「施放人族女子」由她的求情转化、林恩成为施恩者，孽主对属下的权威也被这次跪姿彻底压塌。
- 若林恩把释放人族俘虏改为「让她亲手解开每一根铁链」，则她浸在自己做过的恶里一边开锁一边咽泪，体罚的等价替代成为修复路线第一道。
- 若林恩在放俘之后主动喂她一支舒缓药剂助她缓过药效与痛楚，则甜头的施与时间窗口紧贴体罚，管教节奏从强硬切到怀柔，顺从折服曲线首起。
- 若林恩拒绝任何放俘谈判、纯以立威为目的体罚，则她的求生欲让位于尊严破裂，事件以变形（纯惩戒）收束，关系短期无法挽回。
- 若林恩让左左在自己管教体罚时也在一旁敲打帮腔，则她同时受到双重管教夹击，被复数压制的认识比单方体罚更快将她压入臣服轨道。
- 若林恩让她在受罚前自己选「挨几下戒尺还是当众背诵认错词」，则她犹豫的十秒比任何回击更清晰地显示她已经接受受罚结局。
- 若林恩在体罚结束后主动替她裹好斗篷安抚，则她哭到尾声会误以为这是长辈式的偏爱，顺从心理从这一丝照拂开始埋线。
- 若林恩让小丑心脏在殿外高声解说这一棍一棍的历史坐标，则殿外围观的城民把她此刻的尊严粉碎当成某段「圣经新章」，她的统治威严终结于一次解说。
- 若林恩在本事件尾声主动收起温和态度、把她扔到地上转身走出宫殿，则她对人族的判断从「他可以被色诱拿捏」彻底翻转为「他不是猎物是天灾」，日后的服从根基便由这次丢弃奠定。
- 若林恩拒绝走人、在体罚结束后亲手把她扶回王座并替她擦去眼泪，则她被反向的温和击穿短暂不反抗，管教入口向顺从一侧开放一缝。
- 若林恩在拍打惩戒后立刻以初诞者之力替她梳理一次体内翻涌的诅咒痛楚，则她对林恩又敬又畏的依赖感首次成型，臣服方向被敲入本能。
- 若林恩在放俘时额外加上「再放掉所有血族眷者俘虏的囚犯子女」，则她放人的同时把林恩的施恩规模自我放大，谈判筹码向林恩倾斜一倍。
- 若林恩把她抓脚踝倒吊的画面改成帮她穿鞋扶她起身，则在场眷者集体瞳孔地震，从「城主当众受罚」翻转为「主人被男人服侍」，气氛断裂。
