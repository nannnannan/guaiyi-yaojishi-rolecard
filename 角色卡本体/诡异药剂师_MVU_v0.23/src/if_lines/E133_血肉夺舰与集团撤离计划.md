# E133·血肉夺舰与集团撤离计划·if线

- 若林恩在实施夺舰前先让巨像在网络侧瘫痪目标舰推进器再以血肉瘟疫弹登舰，则首舰以「失灵迫降」路径落地，感染外扩范围更小
- 若林恩改为先用瘟疫弹黏住舰壳再由巨像隔离切割，则感染面更大、不重连概率更高，但瘟疫失控扩散风险同步上升
- 若林恩只挑一艘最容易切断链接的独立舰实施，则结算【星内战舰+1】且其余舰群保持敌对，不扩展为集团缴获
- 若林恩同时发射多枚瘟疫弹覆盖两支舰群，则万机立刻识别并发动万炮齐射，巫神首轮抗住后无法保证持续防护
- 若林恩放弃缴获改为远程引爆瘟疫弹摧毁整支舰群，则结果转为「消耗战果」，万机失去弃子筹码但不留下待净化资产
- 若林恩用赛博破解替代血肉瘟疫接管舰群，则需先切断万机链接成功，否则夺到的只是「黑盒舰壳」而非完整权限
- 若林恩用巨像血肉隔离替代瘟疫，则污染与失控风险归零，但要求巨像本体近舰作业完成，机动窗口极窄
- 若林恩让艾雯在转移之余顺手撕裂一艘独立舰再让巫神托回，则撤离节奏被拉长，被万机锁定概率上升
- 若林恩指派小小单独突击感染舰，则违反家族安全约束被艾雯、血锯当场否决，分工方案重新洗牌
- 若林恩让巫神同时承担万炮防护与托举双任务，则远程防护出现空窗，首舰落地时表层受损
- 若林恩在夺舰前先与艾雯对口径「只收一艘不打包舰队」，则撤离分工明确、结算易被记录为可控战果
- 若林恩临时决定一锅端整支集团，则万机被迫改变撤离计划，将炮口全部转向林恩队伍，事件直接转向高强度撤退战
- 若林恩允许瘟疫弹命中半感染的舰群，则获得「瘟疫舰」战果但必须在隔离区处置，否则带回驻点会污染友军
- 若林恩在锁定画面里看到瘟疫蔓延失控时主动切断弹体链接，则损失已投放瘟疫但保住首舰完整性
- 若林恩让血肉瘟疫弹只命中舰桥而非引擎，则舰体仍可被拖走但内部智械船员需要额外清除
- 若林恩要求巨像在落地前剥离舰内腐化数据，则缴获品破解难度下降但落地窗口延后
- 若林恩把握时机差在万机切断链接前的三十秒内投放瘟疫弹，则首舰能在失联前完成一次信息快照，附带部分万机内部通讯
- 若林恩在落地后立刻命令焚烧舰壳外感染区，则损失部分外部装甲但避免污染持续蔓延到撤离队伍
- 若林恩让小小配合巨像完成落地牵引而非对抗攻击，则撤离流程顺利但首舰完整度进一步受损
- 若林恩对万机的「血肉是体液」「他连树都能上」认知偏差公开嘲讽，则万机反应转向「镇定试探」而非当场万炮齐射
- 若林恩在交火中把瘟疫弹刻意打向周边未感染区制造隔离带，则万机舰群重连路径被拉长但瘟疫库存消耗更快
- 若林恩在撤离前只确认【星内战舰+1】并切断弹链停止投放，则队伍能完整退出交火区，不被万机拖入追击战
- 若林恩决定留下已夺舰不撤离、试图借助首舰反围剿，则事件向变形走，需先在E134重连压力下维持控制权
- 若林恩召回已被瘟疫感染的巨像分身而非任其留在舰上，则巨像短暂受累但保留完整战力，首舰仍需他人值守
- 若林恩以撤离窗口换时间对首舰内部瘟疫作初步稳定，则队伍晚走数分钟，被万机舰队锁定的尾部风险加大
