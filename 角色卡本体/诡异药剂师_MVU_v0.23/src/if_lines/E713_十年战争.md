# E713·十年战争·if线

- 若林恩在向轮回神王道别说出「老先生，我要走了」时主动留下一壶黑夜城的烈酒放在时间长河岸边，则那位被困在过去的初代神王会在他转身离去后独自举壶相送。
- 若林恩在听到轮回神王叮嘱「无论发生什么，不要回头」时停下脚步回望最后一眼，则老者会笑骂着挥袖将他彻底送出时间长河，不留半点拖泥带水。
- 若林恩在离开时间长河的瞬间将自己即将回归的波动提前传给左左与喵喵，则两小只会在他的意识海里欢呼雀跃，瞬间冲淡十年苦修的孤寂。
- 若十年战争期间银色幻想将机械狂潮的指挥中枢与黑夜城主母的城防网络深度并网，则内环与外环的调兵响应时间会缩短一半，防线轮转更加严丝合缝。
- 若船长康斯坦丁在十年血战中每一次斩灭魇魔投影后都以毁灭神火焚尽其残留印记，则梦魇一方借死灰复燃侵蚀前线战场的企图会被彻底掐灭。
- 若母树与人偶家在十年拉锯战中主动承担起破碎神界第三层的后勤与伤员救治，则前线半神与狱卒的战损恢复速度会明显提升。
- 若自缚天使在十年间始终驻守在距离无序边境最近的哨塔，则她能比任何人都更早捕捉到深空深处那股正在积蓄的终焉悸动。
- 若林恩在重返现实躯壳的第一时间先以内视检阅自身十年积淀的三位一体、金色梦境与白烬罪火，则他会清晰感知到那一层通往黑火的薄膜已吹弹可破。
- 若前线将士在十年苦战最疲惫的时刻听到黑夜城钟楼传来的守望钟声，则全军低迷的士气会再度振作，死死钉在各自镇守的星域防线上。
- 若轮回神王在林恩踏出时间长河的最后一刻将毕生对轮回法则的体悟化作一道流光送入林恩眉心，则林恩对生死与时间的掌控会再添一分圆融。
