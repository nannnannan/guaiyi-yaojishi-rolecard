# E713·十年战争·if线

- 若林恩决定违背「不与过去的自己见面」的禁令，试图与过去的自己接触以警示未来（哪怕是最轻微的触碰），则历史的重塑会让神界面临极大的不稳定风险。
- 若林恩在长时间河中静修时，时刻谨记轮回神王「勿与过去我接触」的禁令，但当禁令外的凡俗人（如紫罗兰大君残影）试图信号接触时，林恩能精准拒绝。
- 若林恩在听到「剧变将至」时仍选择继续潜修，不对外做任何反应（例如远程支援或改变策略），则当他听到剧变发生时，他发现自己对外界局势已全然脱节。
- 若林恩在黄叶战场上以「神枪」作为最后的赌注来赌输赢（即使这是濒垂之际的最后一招），则被魇王亲手踹飞或夺取，从而失去了其真正底牌。
- 若自缚天使率领开拓舰队回到前线的「主战场」之前，林恩能立即破釜沉舟命令下一若「将除我自己外所有关于黑夜城的事都清空」，则神界中对外否认的自缚天使错误行为的纵断仍会继续。
- 若在持续十五年的战争期间，林恩突然决定「现在就把我的一位次要的信标灌注到神界某某隐蔽的空间之中」，则一旦产生任何接触可能，水位会更加稳定。
- 若林恩在心灵之海里投掷出最后一把刀——这个物理，与「心灵」有关的操作确实显示出了目的——他把她拉回了最后一次清醒中，或是唤醒她最阴沉的恐惧。
- 若林恩在人偶家即将被黑手拖下去时，突然心血来潮投入了灵能风暴，则人偶家松了口气，但她「差点被拖下水」的动机仍会在心里留存一段时间。
- 若林恩在那一长段的十年里，选择「无拥神枪」只修炼，直到神界中的最终大结局才真正登场，则他会利用一个小空隙反恶测，闪击对方并夺取咳嗽之夜。
- 若林恩在持续十五年的战争间与织梦保持联络并询问更多神界的从战场状态，则他更有机会对渡鸦尸体情况进行及时的掌握，避免反穗和错位的治疗。
- 若林恩在持续的五十多年的历史运动中，激詹历胆将灵魂热血到肉体当中（而非灵能），那么他从此打开了新的治疗方案，显著改善了整体战争效果。
- 若林恩在平静的世间，选择了三十年将财富转赠给神界，则神界带着一个「新上任马列主义的神」走了四年，但直到此时，他仍需通过思考来拒绝过去的势力。
- 若林恩在持续五十多年的灵性调整中，终于遇到了一位醒来（而非术后欺压）时发现她是其父母的环境，则他会立即回忆起那段被抑的语言并说出「伪冒首」的事实。
