# E80·直死书与六诅咒同归于尽·if线

- 若林恩只开直死书不同开六诅咒，则直死灭绝成立但万机之神未被死线缠绕，祂顶着根源锁链把龙首完全压出裂缝，林恩失去第四替死娃娃后被一爪拍碎，事件以变形（仅直死无同归）收束。
- 若林恩先开六诅咒再开直死书，则六股死线先缠他自己，他在龙首压顶前已被疯狂/狂笑/昏昏欲睡同步反噬，直死书未翻就掉落，全城机械意识未遭血洗，事件以变形（诅咒自噬先行）收束。
- 若林恩开书前用咒瞳锁定龙首根源核，则直死沿视线精确指向祂，全城观测者未被无差别灭绝，机械意识剩余数保持十二万，事件以变形（点杀型直死）收束。
- 若林恩撕袖口时未裹住左左的胸、把她暴露在直死光视野里，则左左与林恩视线同源未被灭，但意识核被诅咒擦过、惨白数月，事件仍以原作收束，王后意识多一道永久裂痕。
- 若林恩改道绕后、不正面开直死书，则E79接应错失，黑弦月扑空，林恩转地窖改用死疫配方等价灭城，事件以变形（配方等价直死）收束，直死书被岁月锈蚀尘封。
- 若林恩开书瞬间闭眼念诵小小一家不死咒名，则血光范围减半，他只死一次、替死娃娃剩3，但全城灭绝七万余，事件以变形（保留一线的同归）收束。
- 若林恩留《看了就会涩涩的书》不开，则六道缺一道，万机之神仅被五道死线缠绕、保留欲念根基，反手持根源权能压制林恩左手王座，事件以变形（五道同归）收束。
- 若林恩让艾雯爵士提前布传送阵将黑弦月强拖出接应线，则E79约定变更，林恩开书时无人见证，暗中观战被升格为光明介入，事件仍以原作收束但义兄锚点加重。
- 若林恩直死光照亮半城时同步割心口洒血入书扉，则直死强化为定向死洒，灭绝扩到全城方圆三倍，替死娃娃剩0、第五次复活即死，事件以变形（血祭直死）收束。
- 若林恩对左左下令『你也开眼看』，则她未被灭但根源核被擦出裂纹，对『看』这个动作应激，事件仍以原作收束但王后意识加一道隐疾。
- 若林恩六书中混入《看了就会叛变的书》（若此前获得），则七道死线缠龙首，万机之神狂笑中下令蜂巢反向轰炸自己部下，机械神教内讧爆发，事件以变形（七道同归＋内讧）收束。
- 若林恩拒开任何一本、只凭自身根源硬扛万机之神，则他被龙首连拍四次、替死娃娃用尽，咒瞳崩裂失明，巨像之心强行接管肉身发动超维吐息，事件以变形（巨像反噬而非直死）收束。
- 若林恩在僵持中阖上《看了就会没有斗志的书》扔还给万机之神，则祂最后一道诅咒被解，巨龙眼中重现杀意，林恩用最后一命接下全力一爪，事件以变形（解除僵持的同归）收束。
- 若林恩在导弹升空、烟花般迎接死亡时驱小宝贝从体内反扑根系护主，则血宴中多一层巨像盾，他未死而是被压进废墟沉睡，黑弦月赶到时用丝线拖出，事件以变形（血宴未死）收束。
- 若林恩开书前把以M快感拉爆、让自己死前最后一次高潮，则直死光夹带欲念渗入龙首，万机之神死前眼神从嘲讽变成难言的请求，事件仍以原作收束但多一道涩涩残留。
- 若林恩等黑弦月到位且目视她接应，则他开书时避开她视线焦点，她眼见master连死两次，丝线灼出第十七道焦痕，事件仍以原作收束但『master之死』成为后续变形伏笔。
- 若林恩咒瞳裂缝暴扩时把左左从左臂撕出、让她独立成小娃娃守心口，则神识未断，万机之神被压制时间加倍，事件以变形（左左独立护主）收束。
- 若林恩复活落点恰在艾雯爵士脚下，则义兄目睹他连死连活全程，正面护持送出轰炸圈，事件以变形（义兄救走）收束。
- 若林恩在『你们怕吗』出口前改念左左真名而非宣战，则全城听到的是对王后的告别而非挑衅，万机之神死前多一瞬迟疑，林恩等级多跳一级至37，事件仍以原作收束但左左锚点改为『临终告白』。
- 若林恩把王大锤根除誓言压在书扉下，则直死与根除叠加，被灭机械意识留下『根除印记』，机械神教追凶线索指向血锯老店而非林恩本人，事件仍以原作收束但仇敌链条偏移。
- 若林恩六书全开再叠《看了就会石化的书》（若此前获得），则八道死线缠龙首，万机之神被永久封城而非暂时压制，事件以变形（石化封城）收束。
- 若林恩不愿连累全城血肉、读血书瞬间用咒瞳把注意力转自己，则灭绝定向他在场视野，他连死五次、替死娃娃清零、咒怨反噬吞掉半截左臂，事件以变形（自噬式直死）收束。
- 若林恩直死书开得太早、黑弦月尚未赶到背后，则他开书时空门大开，被副将一爪拍碎脊柱，连死三次还没接住血宴高潮，事件以变形（接应错位）收束，E81改为救援重伤。
