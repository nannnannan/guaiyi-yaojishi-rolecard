# E06·诅咒清除能力与鬼婴塑形·if线

- 若林恩先测试诅咒清除的对象不是左轮，而是恶灵血婴体内的怨气则蓝光扫过血婴，怨气短时平歇但根源封印未解，塑形窗口被提前
- 若林恩用一次性兑换机会选血肉增生药剂配方以外的物品则配方不入账，血肉增生产线延后，后续事件按等价路径补
- 若林恩把兑换清单收起暂时不换则清单保持一次性叙事挂载，不建立商城余额，他也不得被默认兑换
- 若林恩在塑形前先喂血婴鲜血或怨食则塑形面板词条同步偏斜，「嗜血」「护主」浮现，沉睡期延后
- 若林恩以雕刻刀深挖血婴眉心的根源纹路则权限不足锁仍以红字弹出，血婴溢出一声低频啼哭，游魂巷周边低阶游魂连夜绕开
- 若林恩在塑形时尝试抹掉「杀戮」「病态」被锁词条则面板红字不退，血婴体表浮出黑斑，林恩手背被反噬粘出浅痕
- 若林恩以拉面搓圆法反着用、把血婴捏回骷髅雏形则塑形失败不入眠，血婴怨气回升，事件保活跃直至重做
- 若林恩在塑形中途停手应付上门患者则血婴半成型躺在柜台，新患者优先看见一张没完工的鬼脸，店铺声望小幅异动
- 若血婴在塑形完成前再度张口扑向林恩则畏惧值仍把它弹回，林恩衣袖被撕掉一截，塑形面板挂起「敌对·残余」
- 若林恩在晨光下就走出门试枪、流弹误伤的不是食腐者而是路过人皮车则拾荒者掌心一缩，二次上门改为当夜，赠礼内容偏战向
- 若林恩封木板加固墙板时多封了一层隔音则阁楼塑形期的啼哭不外泄，游魂巷夜里更静，血衣恶灵后续登门推迟
- 若林恩把猎头者残肢不撒给拾荒者、留着配药则等价交换不成立，拾荒者离开前收回灯笼注视更久，「庇护游魂巷」传闻起效放缓
- 若林恩顺手附上自配的小瓶安神药剂当添头则拾荒者瞳孔在眼眶里连转三圈，下一回上门时带上更高阶的残肢清单
- 若林恩接过无面魔心脏没有立刻收进柜台暗格而托在掌心端详则心脏对他脉搏的节奏产生标记黏连，远程标记对象抢先指向林恩自己
- 若林恩拔出旧匕首割破指尖喂无面魔心脏鲜血则心脏认主成立，副作用伏笔记入系统账本，林恩心口偶发一拍错频
- 若林恩当夜就试着用无面魔心脏标记食腐者报复白天那一枪则心脏打击兑现，食腐者尸体被拾荒者连夜收走，「小道友」身份被进一步坐实
- 若林恩向拾荒者开口追问游魂巷为何完好则她含笑不答，只留下一句「巷子里有看过牙的人」，对话信号入账
- 若林恩在血婴沉睡后立刻测试血肉增生配方的第一笔炼成则炼成物畸变走样，材料折损，配方升级路径转入发酵
- 若林恩抱着沉睡的血婴守到天亮则林恩困倦，第二日开店延迟，血衣恶灵登门时点不变，迎客的换成睡眼惺忪的林恩
- 若林恩在塑形期间与血婴多说几句话、像在哄一个孩子则血婴沉睡时词条多出一条「依赖」，后续鬼婴互动黏性上调
