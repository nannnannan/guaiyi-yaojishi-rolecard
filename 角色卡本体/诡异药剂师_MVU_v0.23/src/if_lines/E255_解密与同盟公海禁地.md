# E255·解密与同盟公海禁地·if线

- 若林恩开门时先与弥赛亚视线对上抬手示意礼貌，则那位白人第五使徒的挑衅语句被她提前拦下，会议室里只有陌生而压抑的静默，"清理嘴巴"的戏码不会上演。
- 若林恩在第五使徒讥讽"心智不全的怪物"瞬间直接将其手掌钉在桌面，则圣光在房内爆闪两秒又熄灭，他在血迹未干的木桌上摊开地图，旧日遗产与隐修之地的讲解被迫在血腥味里进行。
- 若林恩把"想要消除间隙就要表现出一点诚意"换成"想要消除间隙就今天让我用一夜慢慢审问你们"，则整个会议的谈判节奏转向囚徒审问，弥赛亚被推到"救人或救组织"的两难现场。
- 若林恩在弥赛亚替他清理嘴角时把她整个抱到腿上，则普鲁斯在场亲手抽出圣光十字剑一剑劈下，会议现场被掀成废墟，血肉神教围剿胜利带来的好势头瞬间瓦解。
- 若林恩在弥赛亚唇边替她擦净后顺手在她耳畔低声许诺"梵蒂冈之行顺路把基建修一修"，则弥赛亚的"疗伤邀请"被解读成战略援助，她把当晚的屈辱部分量化为政治筹码。
- 若林恩听白夜讲完隐修会历史后主动补一句"那位天使就是黑夜城主母"之外再加一句"我和她同床共枕"，则会议气氛被强行降到私人八卦频道，普鲁斯当晚拔剑当场。
- 若林恩在弥赛亚提出回梵蒂冈的当晚暗中派左左跟拍护卫，则梵蒂冈典籍检索过程被林恩侧路监视，她翻到的每一条炽天使记录都会在次日凌晨以心声形式抵达他脑海。
- 若林恩要求弥赛亚在众人面前替他整整深吻十秒作"关系证明"，则使徒队伍三人当场脱队，弥赛亚声名在隐修会内部跌破冰点，但也把"林恩的女人"这个标签压在公海议题之前。
- 若林恩在讲到公海坐标推断时主动喝一杯祝酒"敬我们的女炽天使"，则他把拼图拼合的瞬间变成宗教仪式，指挥部高层纷纷记下"黑夜城主母曾现身蓝星"的档案条目。
- 若林恩把关于隐修之地坐标的推算权交给弥赛亚自证，则她在梵蒂冈翻典籍的过程被无限延长，公海行动计划整体延迟至少两周，启示录式的自我怀疑在她身上累积。
- 若林恩当众调教弥赛亚后立即命五位使徒分列两侧宣誓效忠，则圣光在耻辱里凝结成一层暂时契约，隐修会残部正式划入林恩势力，普鲁斯的私人怨念被压到骨子里在后续事件爆发更剧烈。
- 若林恩对系统跳出的【尝试性地拐带】成就当场比中指狂骂"用不用打扰气氛"，则系统弹窗冻结三秒，万机之神在副档里悄悄补一条"宿主脾气"标签。
- 若林恩临别时在那个"疗伤"约定之外主动把一枚玻璃瓶塞进弥赛亚掌心，则那支"恒星熔炉专用药膏"在梵蒂冈之行被多次取出凝视，弥赛亚的世界观崩塌来得更早。
- 若林恩在公海推断成立那一刻主动表态"我也想要那块遗产"，则黑夜城合作被蒙上一层利益色彩，白夜对他的信任指数被减掉一项"无私"的光晕。
- 若林恩在会议散场时直接折跃跟到弥赛亚的客房，则她那一夜的梵蒂冈行李收拾过程被一个无声的身影旁观，"两个人的时候"提前到蓝星上演。
- 若林恩把旧日遗产的图谱与乌鸦臂章的流逝符文反向叠加，则他首次在系统空间看到一幅完整的"地球地下旧日遗迹地图"，隐修之地之外还有整整五个岛屿亮起红点。
