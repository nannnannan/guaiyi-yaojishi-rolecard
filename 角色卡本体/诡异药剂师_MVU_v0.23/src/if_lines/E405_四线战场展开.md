# E405·四线战场展开·if线

- 若林恩让切界方案由艾雯爵士主导灵能分界、自缚天使稳外层、巫神缝内层三人共执，则切口圆润但命运辅助需另付代价，羽毛笔不能随意叠加。
- 若林恩只让艾雯单独切界、不调天使与巫神，则切界成立，但外层不稳、内层也未被缝合，边界的脆弱度大幅上升。
- 若林恩让羽毛笔在切界同时再次干涉，则黑线缠上执笔处的速度大幅加快，命运反噬压过切界收益，事件变形为「干涉反噬反客为主」。
- 若林恩在切界后放任机械四神开辟通道、由艾雯在边界扭转炮击至无害角度，则机械被困空间背面，但艾雯与天使巫神巨像需要持续牵制。
- 若林恩在切界后不强扭转炮击，则机械四神对现实战场的火力校正依旧，泰坦需要同时承受支配者与机械炮火两面压力。
- 若林恩让巨像之脑聚集分体、配合他手中份额恢复完整战姿，则聚合招来的地狱反噬在限时压制下勉强承受，但战后分裂问题不被解决。
- 若林恩让巨像之脑保持分散形态各守一线，则她不承担聚合反噬，但失去完整战姿带来的根源级防御。
- 若林恩让左左实际离开林恩配合巨像完整战姿，则她需要做心理建设，原作未预设她会让步，事件走向「王后是否割爱」的内部讨论。
- 若林恩让泰坦独自承担与支配者正面交锋，则他的愤怒能延续作战，但他的体量与耐力也是有限的，需要预设对策以防被血肉剥夺。
- 若林恩让孽主在泰坦接战时不出手、选择暂时观望，则她未消耗战力，但支配者失去唯一可以彻底依赖的支援。
- 若林恩主动把王座残样交给夏娃解析后再揭露给孽主，则孽主会被胁迫情报击中立场，她在谈判中被撬动的概率显著上升。
- 若林恩不先解析王座残样、直接与孽主对峙，则孽主不会留下任何把柄，她仍是支配者的临时盟友。
- 若林恩让小小承担荒野机动，则她能快速转移同伴与补给，但她需要避开支配者的血肉剥夺范围，否则她会感到自己的血液被拉扯。
- 若林恩让夏娃待命协助对付血肉造物，则她的同源血肉在小规模冲突中具有压制力，但单体伤亡会反向踏入支配者的侦察带。
- 若林恩让人偶家带黑弦月上幽灵船与死亡之主交涉，则她在甲板上能对接古老船长的历史，但船长仍是独立的未知强者。
- 若林恩不让人偶家上船，则黑雨覆盖区域的倒行性事故无法被交涉压制，死亡之主的伤亡食粮机制继续运作。
- 若林恩让黑弦月单独接触幽灵船、不带人偶家，则她能以电报厚度接通船长，但她无法说服「死亡之主」。
- 若林恩主动帮助死亡之主识别「死亡是食粮」的机制，则人偶家能以此作为谈判筹码，但也可能触发死亡之主的敌意。
- 若林恩在支配者联系上试图反向告知孽主支配者的残余弱点，则孽主立场摇摆，但她的真实动向仍未可知。
- 若林恩让切界方案分四线展开——背后线与泰坦、人偶家、小小、夏娃各自承担，则战斗覆盖四线，但各线必须独立承受压力。
- 若林恩让任意一线独立作战、跨线支援路径中断，则该线在切断支援后会因缺乏联动而更快失利。
- 若林恩让机械阵营与支配者在切割后仍保持血脉联系，则支配者的反抗将比孤立切割后更顽强。
- 若林恩主动帮助机械阵营重新评估联系路径，则敌方会在切割完成后反向重构联系通道。
