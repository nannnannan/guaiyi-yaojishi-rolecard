# E733·第三阶段的黑火·if线

- 若林恩在风雪城墙上听艾雯爵士说出「织梦预见到下次战争只要再多三五个魇魔你就会深陷泥沼，所以她用死助你完成唯一性」时，死死握拳任由指尖刺入掌心、让鲜血滴落在白雪上，则那抹刺目的猩红会让他彻底看清自己脚下这条道路的残酷。
- 若林恩在痛苦剖白「我不是大君，我也没有他的那份心性……为什么我每往前走一步都会有一个人牺牲在我面前」时声音颤抖不止，则艾雯爵士会猛地转过身来，用力按住他的双肩喊出「第三阶段我来为你破！只要跨越那个门槛就再也不会有人因你而死了！」
- 若林恩在艾雯决定违背织梦遗命、将第三阶段【黑狱】的完整真相告诉他时，平静地直视兄长的眼睛说「告诉我吧，大哥，不管是什么结局我都接得住」，则艾雯不再有任何保留，将两步破境条件与必死结局全盘托出。
- 若林恩在得知点燃第三阶段黑火的第二步条件是「与芸芸众生建立因果，让众生的相信变成执念、化作点燃黑火的柴薪」时，立刻联想到几年前自缚天使背诵渡鸦歌谣请他称王的一幕，则他会恍然意识到命运的齿轮早已在不知不觉中咬合。
- 若林恩在听艾雯描述黑火点燃后的可怕反噬——众生心底的失败主义、绝望与怀疑杂念都会化作亿万利剑日夜刺穿他的心灵、令他生不如死时，连眉头都没有皱一下，则艾雯会明白任何精神上的酷刑都吓不倒这个为了家人可以豁出一切的少年。
- 若林恩在艾雯泣血般道出最终真相「没有第四个阶段……因为你会死，所有人都可以活，只有你会死」的瞬间，非但没有崩溃绝望，反而像卸下了千斤重担般长舒一口气，则这出乎意料的平静会让艾雯爵士当场怔在风雪之中。
- 若林恩在得知「只有自己一个人会死，而大家都能活下来」时，脑海中第一时间闪过时间之外那抹带着虎牙的浅笑、沉睡的智械小姐与船长、主母、艾维儿和小小的笑脸，则他嘴角泛起的那抹释然微笑会比漫天冰雪更加纯粹。
- 若林恩在听完必死结局后反过来伸手替泪流满面的艾雯爵士擦去眼角的冰碴，轻声说「原来只要我一个人死就够了，这比我想象的最坏结局好太多了」，则艾雯紧握的双拳会剧烈颤抖，彻底明白自己永远无法劝阻弟弟走上这条赴死之路。
- 若林恩在风雪中向艾雯追问「那作为最后一块灵能拼图的你呢？大哥，你会怎样？」，则艾雯爵士会移开视线，用看似平稳的语气隐瞒下自己也将在为他铺平道路后燃尽自尽的宿命。
- 若林恩在城墙上与艾雯定下「由我登座赴死、由你统帅帝国替我向家人隐瞒真相」的兄弟盟约，则从这一刻起，主宇宙的至高君王与王下第一骗子便在漫天风雪中正式成型。
