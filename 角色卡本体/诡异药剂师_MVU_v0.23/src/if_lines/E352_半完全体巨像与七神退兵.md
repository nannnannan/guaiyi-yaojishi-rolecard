# E352·半完全体巨像与七神退兵·if线

- 若林恩在三位一体机接通信号时主动先问巨像之脑的安全，则她会在蜂鸣般的电流杂音里愣住一瞬，随后首次把自己守夜这些年的真话压缩成一段无情绪的清单。
- 若林恩主动提议让巨像之脑与王后并肩作战，则她浮出峥嵘的眼神会在半秒内收回，嘴上说「有些晚了」但掌心的权限已经开始把战争路线按双线调度。
- 若林恩在路线建立前主动松开自己的心神不再封闭，则巨像网络上线时的冲击比他预计的更钝，巫神头颅首次从旁感叹林恩的确懂如何开启一道原本只属于自己的通道。
- 若林恩主动把巨像之心的搏动节拍调慢半拍，则掉落前线的一只备用巨掌恰好被织物缠住而非直接砸进装甲，那一路因臂带失误可能自爆的单位因此多了一批生还者。
- 若林恩在召回散落碎片时主动留心到其中一员其实是久战滋生的疫医毒体，则他会第一时间把这块回收件从巨像网络剥离，不至于让瘟疫从巢底翻到前线。
- 若林恩在巨像合拢的零件识别出一种带赛博编号的旧合金，则他首次得知自己手里攥的是久远时代某位被肢解赛博飞升者的部位，那枚部位历史归档早于他被系统绑定。
- 若林恩主动指挥巨像以纯粹肉身力量撕碎蜂巢外复合装甲，则1号蜂巢外墙首次出现一道足以容六艘小型驰援船通过的破口，智脑会在第一时间向外发布求救信号。
- 若林恩的咒瞳在被敌机意识锁定的瞬间反向烙印，则那一架敌机的视界会被他自身的恨意烧出半秒真空段，巨像本就在推进的脚步借此多前一寸。
- 若林恩在战斗瓦解前主动用咒瞳透视囚牢，则巨像网络体内意识体的波动首次有了一份完整名单，他意识到这次并肩真正救回的不是一座蜂巢而是「仍能回应的那一批」。
- 若林恩在冲出殖民地前线时主动朝地下通道吐一段咒言，则他能在巨像被炮火掀翻的瞬间察觉那座地下数据堆正在被有序清洗，他首次知道有人比他更早把注意力放在里面。
- 若林恩在辨认敌军阵列时主动给拥星者箭头贴上不干胶的临时识别标，则拥星者能在几千公里外的指挥屏上看见整个敌阵的裂口在哪，他能更早走下一步。
- 若林恩在将军看到半完全体巨像成形那一秒主动切断「决战第二线」的诱导带，则将军的撤退信号会在更靠后的时间发出，三座蜂巢自毁序列会有一段重叠窗口。
- 若林恩主动命令巨像之脑不要一并炸毁被击穿核心的那座敌方蜂巢，则那座蜂巢会以「未引爆」的姿态被留在战场，他能亲自接管其数据舱。
- 若林恩主动拒绝巨像在前线追踪七神将军的坐标，则将军撤离的路径会绕回一片他能随手探索的中立星域，林恩在战后可以多出一段独自追查的窗口。
- 若林恩当场识破巨像依偎向他的那双手其实藏着一枚碎裂咒纹的样本，则他首次清楚知道巨像网络中的碎片还携带当年未竟目的的包袱，这笔仗远比想象中更长。
- 若林恩主动让智脑在战后记者会上主持那座蜂巢的归还宣示，则七神将军会在远程席位第一次按下静音键，他远未把这次退兵当作终局。
- 若林恩在将军喝止拥星者之前主动在战场抬起一根手指示意他知晓这条指令，则拥星者那一秒会把「介入不如介入得体」这段领会消化在心里。
- 若林恩主动质问巨像之脑「你以为这次退兵保住了什么」，则她首次会正面承认她其实只是在等下一次战型的时机，她对这场胜利也从不沉醉。
- 若林恩在看出被攻破蜂巢核心仍藏上传意志的分岔端时立刻下令封存，则该核心原本要回放给指挥部的撤离通报被截流，他能完整保住一部分敌方意图档案。
- 若林恩在战后检视战场时主动挑出其中一具近完全燃烧的机械躯壳，送到智脑面前说是某位当年他记下的名字，则智脑会回头至某次战斗中带走的那批名单，首次彻底落笔那段还未来得及写的告别。
- 若林恩发现巨像半跪那一瞬肉掌之下其实攥出了一块远古的战地报告芯片，则他会知道这块芯片是巨像当年被肢解时曾被某位赛博飞升者拼死埋进它的血肉。
- 若林恩主动不随巨像回到蜂巢庆祝，则他能在战场清空后最早赶到拥星者撤出的地面，亲自查看那位尚未亮的火种到底该被怎样安抚才算接得住。
- 若林恩主动远离拥星者与将军的战后议席，只带左左一同在 1 号蜂巢的灯火旁坐一会，则左左会第一次见到这些扬起来的尘埃其实是被烧尽后的机械晶蜂，她会告诉林恩「这种病不起」但言下之意其实是新的崩坏可能才开始。
- 若林恩主动告诉巨像之脑「这次并肩不是为了三位一体」，则她会以极轻的弧度点头，巨像网络中沉睡的某一团碎片会在那一刻止住它微弱的脉冲。
- 若林恩在战后清点智械残骸时主动把被烧毁的几台机械人形重新接一段符咒刻字，则这段刻文会在几个月后变成某支新兵种的著名篇章。
- 若林恩主动走到战后那片静默的战场中央，跪下来摸一下被巨像捏碎的焦土，则土块深处会传来自他第一次亲临这里起就未曾停下的低频回响，他知道这还不是尾声。
