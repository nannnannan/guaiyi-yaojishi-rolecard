# E354·羁绊召唤与无序抗性·if线

- 若林恩在法阵落成之前先按巨像之脑的要求撤一回，则他会看见那批天使双翼符文完整的对称布局，巨像之脑也能在初次施法前多得到一个完整校验样本。
- 若林恩在施法亮起瞬间主动把召唤信标信号接收端切换为主母的翎羽，则那片翎羽会在施法完成时发出极轻的脆响，白得几乎透明。
- 若林恩在查询灵魂数字化记录时主动调出「备份独一无二」的旧数据层，则巨像之脑会首次将那段判词的物理原典读出给他听。
- 若林恩在侦查坐标的废弃基地时主动绕开浅层矿区，则那片矿区的临时路引会在地图上被画上「禁入」颜色标记，猪头屠夫远远在悬崖看见那条浅色轨迹会眉头轻挑。
- 若林恩在面临大量黑线涂满囚牢的那一秒主动收回现场侦察意识，则他会发现那片黑线本身其实是对面的预警触端，林恩首次成功没有引发警觉触发。
- 若林恩主动动用初诞者力量去压制其中一枚足以算入献祭的临时结晶，则巫神头颅会承认接触此物的代价极高，哪怕最高阶献祭品也无法全额履约。
- 若林恩在发现坐标附近存在几百公里生物波动时主动告诉巫神头颅请他再次启动侦察，则巫神头颅会用粗老的声线重新标注一份核查范围。
- 若林恩主动放弃追问「视界之主」那段名字背后的真正渊源，则巨像之脑会第一次不再纠结于他到底从何处得到那样强大的力量残留。
- 若林恩主动在现场提升自己的无序抗性等级，则他知道远方巨像之脑的下一句提醒必然是「哪怕一次成功搬动也只是暂时的」。
- 若林恩在战场第一次看到那场关于灵魂数字化废墟中的凝重冲击时主动避开正面迎击，则他会用长袖划定他的执行边界并耐心备注与「入侵者」的身份差别。
- 若林恩主动承受迎面袭来的灵魂碎片撞击时把咒瞳反向偏开半度，则他能以最低损耗接触到对方的视界温度，首次体会到无序远比想象中更冷。
- 若林恩在边界通道口主动找一件自己此前舍不得丢弃的旧法器做纽带，则那件法器完全不在眼下名单内，但会因陌生身份产生极强的恢复力。
- 若林恩在汇报之后查清那位堕天使并未在宣告命运神等具体权限，则巫神头颅会在听完汇报的当口说「所以你早就知道，我们所有人都被拴在一根细绳上」。
- 若林恩在他连地理坐标都到不了的方位强行前往，则巫神头颅会以「其实仍在等待」面貌与他首次坦白相遇，并首次告诉他那份等待是她自己保下来的。
- 若林恩让巨像之脑说出了那些本不该从她嘴里说出的话，则她会从「仍在维系的存在」身份变为「不再只是被托付者」，巫神头颅一旁无话可插。
- 若林恩无视规模比拼强行进入前场，则他再没有肉体能量把那道旧囚牢的防线逼回原地，中央那座古遗像在他眼底渐渐失去稳固形状。
- 若林恩主动靠近旧围猎禁区前先在心里为自己立一条「绝不深入」的红线，则无序压迫反弹回来时会按那条红线减速，他首次证明可以在无序中保持主权。
- 若林恩主动把运出的两具狱卒遗体中的一具立刻送到蜂巢由智脑保管，则智脑会在自己数据舱中腾出一块独立区域，首次为这具遗体建立守墓编号。
- 若林恩主动请巫神头颅在搬运途中陪同监护，则巫神头颅会在某具遗体被翻动时立刻报警并给出解除危险的便捷通道。
- 若林恩主动在向巨像之脑汇报祭材来路时撒一个不太大的谎，则她的声音里首次多出被人信任过后又被轻易背叛的疲惫。
- 若林恩主动对堕天使在场的誓词说出「这不是任何界位都可接受的祭品」，则一位正要为堕天使宣誓的疫医会抬手按住斗篷内的徽章并退回原位。
- 若林恩主动让羽毛笔在那份「死去的渡鸦」的口信被呈到他面前时斜闭着眼不再追问，则白袍少年与猪头屠夫远方的观察会从「紧盯」转为「暂缓」。
- 若林恩主动在自己怀中多留一份他此前舍不得丢弃的咒纹备份，则那份备份会在无序袭击时先一步承受伤害，代价是他本人需要重新长出一段可承载意志的肉身部位。
- 若林恩主动把主母翎羽与命运神的口信并排放进同一支木匣，则匣子合上之后会在夜里发出极轻的扣击声，这声音像某种不肯歇下的警告。
