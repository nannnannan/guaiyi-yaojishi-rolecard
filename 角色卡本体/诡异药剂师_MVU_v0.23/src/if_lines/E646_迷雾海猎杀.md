# E646·迷雾海猎杀·if线

- 若林恩在合围扑空后主动在迷雾中留下一个虚假气息陷阱，则腐化神灵搜捕群第一次各自分散，林恩首次得以无阻碍杀戮。
- 若林恩主动用白烬覆盖全身后主动与一排腐化神灵平行擦肩而过，则他首次在自己都没被发觉的前提下完成穿越。
- 若林恩主动第一次猎杀后带着剥离的腐化神格马上找寻织梦的灵能残感，则神格与残感之间无反应，林恩的「救织梦」的希望少了一格但仍然不熄。
- 若林恩主动在每次猎杀后把敌方尸体以三叉戟燃烧，则迷雾中的搜索讯息为他让路，但敌方对「渡鸦的怒火」的认知升级。
- 若林恩主动在折返回杀之前对左左发出一道「如果我没回来」的留言，则左左在奇异世界中第一次咬住下唇待命，林恩的入诲使命在他心中定格。
- 若林恩主动在洞察敌方「不要落单」的警觉时第一次主动在两名同伴身边落一颗焦点，则他被对方察觉，但他首次利用「白烬常态的气息遮蔽」以一敌二。
- 若林恩主动从位面中的一只神兽身上吸取灵能，则他在画布中隐藏一道复杂线条的同时，发现了深渊中另一种独特的存在形式，并且帮助其获得了意识。
- 若林恩主动把珠子放在第三排的随从身上，则他的反应分为喜极而泣和讽刺两种，但内心的抵触并未因此而减少。
- 若林恩主动在她的对白中插入一段歌词，则她的反应分为喜极而泣和讽刺两种，但内心的抵触并未因此而减少。
- 若林恩主动让这一次猎杀的目标是敌方两名中位神灵的「情感」之门，则他成功地追查到潜入离劫的目标，并且事先把藏留在敌人的「情感」中掺入了一些信息，这则新闻报告发布。
- 若林恩主动让对方对他在深渊中收到的消息保持理智，则对方的警惕感更强，但对方的忌惮也更强，他认为他有一条珍贵的知识链条。
- 若林恩主动把第四排的随从身上放在一起，则他的反应分为喜极而泣和讽刺两种，但内心的抵触并未因此而减少。
- 若林恩主动让这股力量直接合为一个主神，则他的主题在镇山石碑旁呈现，而他的自我意识被驱散。
- 若林恩主动把握住离开战斗中返回来的武器，则他的火焰从一片广阔的地界线引申到了一条鲜艳的原野中，同时火焰的能量不再局限于一两个域。
- 若林恩主动对敌人的情感表达力，则他会当面告知对方自己的真实想法，但由于对方的自我认知不断已经突破地缘底线而无法完成他的要求。
