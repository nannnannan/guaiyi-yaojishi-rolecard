# E646·迷雾海猎杀·if线

- 若林恩在合围扑空后主动在迷雾中留下一个虚假气息陷阱，则腐化神灵搜捕群第一次各自分散，林恩首次得以无阻碍杀戮。
- 若林恩主动用白烬覆盖全身后主动与一排腐化神灵平行擦肩而过，则他首次在自己都没被发觉的前提下完成穿越。
- 若林恩主动第一次猎杀后带着剥离的腐化神格马上找寻织梦的灵能残感，则神格与残感之间无反应，林恩的「救织梦」的希望少了一格但仍然不熄。
- 若林恩主动在每次猎杀后把敌方尸体以三叉戟燃烧，则迷雾中的搜索讯息为他让路，但敌方对「渡鸦的怒火」的认知升级。
- 若林恩在折返迷雾之海展开猎杀前，主动对左左叮嘱一句「守好心神，看我怎么替她们收利息」，则左左会在意识深处死死攥紧拳头与他同仇敌忾。
- 若林恩在察觉腐化神灵因畏惧而两两结伴后，非但没有避开，反而利用白烬常态近乎完美的隐匿特性悄然贴近其中一对神灵的背后同时暴起发难，则他能在一息之内完成双杀，令敌群的恐慌彻底失控。
- 若林恩在连续猎杀十余名腐化神灵后，故意将其中一枚残破神格丢在迷雾航道的显眼处充当诱饵，则随后赶来查探的三名敌方上位神会在踏入陷阱的瞬间被他预埋的星寂拳劲当场轰碎。
