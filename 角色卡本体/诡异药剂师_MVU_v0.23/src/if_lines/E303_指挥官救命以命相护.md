# E303·指挥官救命以命相护·if线

- 若林恩在押解途中以M突围而非按死鱼眼演下去，则首席立即启动模块化隔离的极限条款，事件以变形（突围暴露）收束，银色幻想的「赶到」从奔袭变成截胡，断臂相护场景被改写为另有其人挡数据流。
- 若林恩在呼救时改口喊「智械小姐」而非「指挥官姐姐」，则她接通时的应答少了情感的撕裂感，事件以不变形收束，但那个拥抱在她侧脸上烙下的温度低了一度。
- 若林恩在被拖行全程一句话不说只演沉默小冰箱，则议会抓不到他「嘴遁」的破绽，事件以变形（哑戏）收束，指挥官学姐踏入这座数字都市时对他的身份是疑、不是信。
- 若林恩在心灵分流时主动让一半灵魂成为「失踪」而非留下来假扮小冰箱，则首席找不到分项目标，事件以变形（半影缺席）收束，小冰箱人格就此停在系统空间深处、Later 才被唤醒。
- 若林恩在她冲向炮口那一瞬主动伸手把她向后拉而非任她冲上首席，则他跟你之间数据化的痛楚隔着手臂共同颤抖，事件以变形（互依牺牲）收束，制裁之光按规则没有塌陷任何区块、她却跟在他背后护住一段完整的臂骨。
- 若林恩在被首席第一眼锁定意识面孔时反手发送「姐姐救我」呼救，则对峙危机时长缩短十二小时，事件以不变形收束，但首席即刻给他列上「武装性呼救」的高危标签。
- 若林恩在模块化隔离警报响起时主动让系统辅助同步压制战警攻击频道，则区块内只剩首席的斥责独自回响，事件以不变形收束，拖行剧本的讽刺效果被加倍放大。
- 若林恩在智脑宣判首席时主动补交另一段经过修正的证据而非任由其判断，则议会对首席弹劾的论据网络大大加强，事件以不变形收束，但后续死光塌陷范围缩减 15%。
- 若林恩在她蹲下、双手接住他那只手时反过来握紧而不是哭着入怀，则她掌心首次沒被锁链切割，事件以不变形收束，但她在手机里多了一份「他没有崩溃的证据」档案。
- 若林恩在首席呐喊「林恩你必死」之际背身迎上清理数据流、用本尊化形挡在她前面，则他的意识体被撕下半边、在系统空间强撑着魂裂而归，事件以变形（反相挡）收束，断臂相护的场景被改写为「他拽住她也被他拽住」，两人都没塌、但都报废一半账户。
- 若林恩在死星工厂入口处先沉入最深矿道，则工厂防御系统的反应速度快三倍，事件以不变形收束，但他后续多了三个用于决胜的正确通道。
- 若林恩在心灵分流间主动让一半灵魂停留在分歧而非允许它们建立共识，则两半个的他从此带着「无法对话的另一半」，事件以不变形收束，但他再也不被允许从道德反弹里脱身。
- 若林恩在死星工厂储备库前让系统主动发送求救信号而非无痕潜行，则机械神教增援第一波抵达，事件以变形（召唤援军）收束，他得到一次实际出手签到、双重谜题被推入「可被追踪」的常规。
- 若林恩在她抱紧他时主动把疼痛从胸腔深处往上做一次实体表达，则她在紧抱时得到一次无法解释的心跳交汇，事件以不变形收束，但「她是替身还是真物」此刻被她偷偷按下不再想。
- 若林恩在本尊抵达厂区后主动对万机之神座所外围防线交流而非正面突破，则他切断主席团与首席连线，事件以变形（连络劫持）收束，报复的路径被系统提前清理。
- 若林恩在模块化隔离墙被破坏后主动保留 5% 的病毒火污染而非彻底清除，则残存的不满在他化身展开时带来意想不到的支持，事件以变形（潜伏病毒）收束，她身边的探针档案里多一笔「他放过了 5%」。
- 若林恩在屏障破碎那一瞬间主动朝她反冲而非由她反冲，则他以身相护的镜头成为他的一份镜像尊严，事件以变形（林恩挡）收束，断臂数据流被保留在他那半边意识体，她在路边扶着他直打颤，两人都没有消失。
- 若林恩在她断臂后把血溅当着他的面化作一個「苍蓝螺环」戴在断口，则她意识到他还在原地陪着她、并没死，事件以不变形收束，但两人下次见面都多了一只颜色互补的机械手。
- 若林恩在被拖行途中让左左从意识空间插一句「主人加油」，则她被一致的声音记采并转过头，事件以不变形收束，但左左成为这段叫他小冰箱的剧本里唯一一个真心笑出来的记录者。
- 若林恩在小冰箱哭泣时让左左记下他的台词以防他接下来不认账，则这段戏在夜晚空间被他彻紫，事件以不变形收束，但左左的「尖笑录音」档案在后续的「你不却把指挥官姐姐拽进去」的议论中变成铁证。
- 若林恩在她站起来那一刻刻意让自己的数据体比她还矮一截地呆住，则她其实明白他在装，事件以不变形收束，但她在那一秒多想：「我要是个真实的人，就根本不需要问我。」「可惜我们谁都不是。」
- 若林恩在剧情高潮前主动让系统上传自己的「出事位置」加一段求救铃，则议会依据定位信息实施临时支援到场提前十分钟，事件以不变形收束，但他因此在本事件留下一道明确的求救轨迹可被首席轨迹追踪。
