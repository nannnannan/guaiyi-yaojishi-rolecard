# E581·未来留言与王座灵识·if线

- 若林恩拒绝开门并带主母撤离，则循环不破，化灰与灵识现身不立，但留言与「开则破循环」条件仍作已知，城堡陷入下一轮循环。
- 若林恩开门后拒绝入内庭而直接转向城外，则灵识自证延后，但破循环化灰仍立，恶魔与天使已经在岁月中腐朽的确认被他背影记录。
- 若林恩在弑莉叶面告时主动打断「不要跟我废话直接说重点」，则留言依旧完整但以更简短版本出口，弑莉叶的哽咽线被剪短一秒。
- 若林恩在弑莉叶说「陛下您带着面具」时立刻摘下自己的单片眼镜对镜自嘲，则留言接收者身份的微妙替换被他本人承认，主母在旁目不转睛。
- 若林恩在弑莉叶说「他会参战」时反问「谁」，则弑莉叶摇头「那位陛下的真身」，参战者指向未来的另一笔悬案被林恩亲手挂起。
- 若林恩对艾维儿说「你在城外别动，看好她们」，则她依令不动但内心不安被强行压成「如果你死了我就亲自把这个位面撕了」的宣言。
- 若林恩在覆门时选择不用初诞者之力而是让艾维儿的无序之力开，则门无法开启，循环不破，这一次他亲口确认「只有我能开」。
- 若林恩开门瞬间回头看主母一眼点头，则自缚天使在化灰前的目光从惶恐转化为被托孤的沉静，她知道他去拿回属于自己的东西。
- 若林恩在王座前主动对白发身影说「我叫林恩，你叫什么」，则对方沉默后只答「我没有名字，我只有这缕灵识的编号」，身份差异被更进一步剥离。
- 若林恩在灵识睁眼后主动伸手并触碰他的脸，则冰冷反馈传来，灵识的边缘在他指尖处开始碎裂，传承指针被强行拨快。
- 若林恩对灵识说「你就是我要找的渡鸦吗」，则对方否认「渡鸦是被清除的锚点，我才是烙印」，本体与灵识之间的辨识成为他后续判断的坐标。
- 若林恩在王座大厅主动出口「活下去哪怕只剩一个」，则灵识回应里带上被点亮的疲惫，「三千年后」的承诺在这一句上被再度确认。
- 若林恩在出城堡时主动把左左从怀里换到肩上，则左左首次在这个场景里没说「放开我」而是静静趴着，她的绑定被这一分钟加重。
- 若林恩离开时把弑莉叶化灰现场的一枚黯淡纹章收入系统空间，则纹章成为后续忠诚派恶魔与天使轮回中的身份辨物，忠诚的痕迹被他亲手留存。
- 若林恩在内庭石门关闭瞬间主动用力撞了它一拳，则石门纹丝不动，Li灵识的声音从王座传来「它认很多人，但只为你开过一次」。
