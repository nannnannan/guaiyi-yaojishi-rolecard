# E694·漫天星火与神疆再临·if线

- 若林恩在银色太阳开口质疑之前先把三叉戟横在膝上闭眼不发一语，则银色太阳的风险警告被压成三句以内，与外客的对白场先到。
- 若林恩让金色梦境薄薄涌出一层贴住体表、暂缓与全系列法则建立联系，则初期法则风暴不改向，镜面之魇的折跃时点推迟数十秒，梦魇大军继续按原方向行军。
- 若林恩把逆向转化的汇聚点定在数千里外的虚空中继，则第一轮法则浩日出现在远空而非他身侧，镜面之魇首次折跃落点也偏向那一侧。
- 若林恩在第一轮浩日汇聚到七成时主动掐断，则镜面之魇长枪刺入的爆炸演出缩水一半，魇王通过镜的视野看不到真正的超新星。
- 若林恩先放出三根渡鸦翎羽而非数十根，则虚空里最初点亮的星点稀疏得像有人在森林深处一点点篝火，镜面之魇优先判定那是骚扰而非割肉自戕。
- 若林恩在渡鸦翎羽上额外裹一层他自身的梦境光泽，则星点看起来像「每一条都是他自己割出的灵魂」，魇王那句「他疯了」会更早崩出，但梦境损耗也真实上涨。
- 若林恩只在二三枚翎羽里夹入真正的渡鸦灵魂、其余用纯法则伪造，则魇王察觉死寂气息的时间后移，神疆扩展窗口被拉长，反转冲击更剧烈。
- 若林恩在魇王嘶吼「快回去」之刻在神疆深处发出一声轻笑，则镜面之魇折返的轨迹被拖住半秒，回头看声音的来处而非直接湮灭疆域边缘。
- 若林恩任由镜面之魇击破前十轮浩日不做阻拦，则他省下的精力让神疆总面积更大，但每轮熄灭时溢出的无序余波紧随镜面之魇，他的本体坐标更早被锁。
- 若林恩在镜面之魇撕入第一道神疆缺口时立即以三叉戟迎击而非后退，则那次正面冲击的发生点选在能量最稠密的区段，爆炸回灌覆盖至少三成损耗。
- 若林恩接战瞬间刻意让三叉戟脱手三秒，则镜面之魇分出半数攻势追索那只武器，林恩免费换出一次重新站稳的空档，但三叉戟被打离他十里之外。
- 若林恩让神疆深处现身的轮廓比本体更高、更宽，则镜面之魇最初的「长枪竖劈」偏移数尺，他在接招前拥有一次真正的调整姿态机会。
- 若林恩让神疆的无序余波有序地朝数个固定方向倾泄，则远处梦魇大军的推进路线被那几条「通道」重新引导，半数梦魇被甩进他预埋的乱流。
- 若林恩把金色疆域的边缘故意留出三处缝隙不闭合，则这三处缝隙立刻成为镜面之魇攻击的优先目标，他的攻击节奏被林恩反向牵引。
- 若林恩在捕捉到对方提防杀招的眼神瞬间说一句「别盯我的手，盯我的脚」，则对方首次被迫把注意力分散，缠斗中的破绽面瞬间翻倍。
- 若林恩在银色太阳提示「他每一次攻击都留有周转」之后做出一记毫无意义的追杀，则银色太阳那句「你在做什么」被迫中断一次，他借此确认对方留余地是否只是惯性。
- 若林恩将神疆内某一处法则密度临时压低到稀薄，则镜面之魇踏入该区时瞬间失去一成的反作用力，那一回合的支撑结构被林恩主动改变。
- 若林恩在数百回合交手中故意五次用同一种起手式接招，则第六次起手时镜面之魇基于前五次做出预判，他的攻击路径首次可被林恩反向预测。
- 若林恩让渡鸦翎羽在散去之前留下一缕真正的灵魂影像而非全部湮灭，则魇王通过镜的视野看到那一帧时暂停半秒，重新审视「那不是他自己割的魂」这条推断。
- 若林恩在神疆深处自称「我的神国」时期语调故意放缓，则银色太阳在他话音落地前主动补一段战术，整场对决的指挥权暂时切为两人共谋。
- 若林恩在缠斗中主动引动罪火一刀的杀意先兆却始终不出手，则镜面之魇被迫持续分一部分注意力守住头颅裂隙，他的刺枪在每一次进攻中自动缩短半寸。
- 若林恩在神疆中心制造一次法则真空让周遭能量暂时无法供他借力，则这一次换位窗口出现，但他在这一息内的力量真实下跌到比游离状态更低的水平。
- 若林恩让金色疆域延伸出数十条末端没入虚空的触角，则那些被探出去的区域同步传回更多法则结构，他的后续选项增加，但神疆真正意图的一部分被魇王视野读出。
- 若林恩留出一条金色走廊引导梦魇抵达神疆边缘，则半数抵达的梦魇先被贴上「被引至此」烙印，他们后续的战斗阵型下意识绕开这条走廊。
- 若林恩在梦魇抵达神疆边缘时先与最前排的梦魇正面接三招，则后续魇群列队观望而非一拥而上，他的以一敌多变成车轮战序列。
- 若林恩在事毕首次正面冲击后主动公布「这不是我的神国，这是你的死局」，则魇王通过镜的视野读到这句话时重新评估他的目的，林恩「算计路线」的评级上调一级。
- 若林恩让渡鸦尸体里尚未被使用的最后一具暂时脱离系统空间悬浮在神疆外缘，则它成为一枚高价值诱饵引开下一波专门搜捕的魇群，他短期内失去最后一手的保障。
- 若林恩在魇王察觉真相前先用一段极短的「我已经把神王界租给了我自己」的自白宣告所有星光的主人，则这场以欺瞒为内核的开局被他亲口破解，魇王的反应被早推一秒。
- 若林恩在银色太阳提示「拖下去」之后主动停止攻势、专心以神疆撑住整体结构，则整场战局进入长期消耗模式，他必须承受的不是一口气撑下场，而是一段比谁更稳的耐心。
