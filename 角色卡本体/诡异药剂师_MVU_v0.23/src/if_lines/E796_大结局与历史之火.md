# E796·大结局与历史之火·if线

- 若林恩在轮回燃烧自身前主动对它说一句「不必为我燃烧，我自己来」，则轮回第一次没有只为他挡劫，而是把一半的火焰留给了自己，它今后每次被想起都会多出一点从容。
- 若林恩在历史悖论聚成火海的瞬间主动指出其中属于他自己的那一份而非任由所有起火，则那一份先烧尽，他此后在任何背叛与错过面前都能立刻认出「这是我自己的」。
- 若林恩让时间王在被拖入历史之火前主动所说最后一句不是乞求也不是咒骂而是「我错了」，则那一句话成为火焰的白磷，整个核心从此多了一层可被原谅的余温。
- 若林恩在空置权柄从轮回手中转移到左左时主动按住她掌心而非任它自动落下，则权柄记住了「这是有人给的」而非「这是没人要的」，左左今后握住它时不再只感到沉。
- 若林恩在大君原初身体初现秩序裂纹时主动用自己的心与那道裂纹对话而非直接撕大它，则裂纹得以慢慢展开而非瞬间破碎，原初心灵能够被温柔地唤回一份。
- 若林恩在空白与秩序同时流过左左身体的瞬间主动把自己的一缕黑火喂给她缓冲，则她在桥接里获得的不再是纯粹的损耗，而是可以被他分担的一段小暖。
- 若林恩让历史之火把过去的每个因果节点同时点亮而非只点其中主要的几个，则他今后在每个回忆里都能精确说出「这一刻发生过什么」，他再也说不出「我记不起来了」。
- 若林恩在时间王已经被火焰压住的瞬间主动伸手替他挡一下焰头，则他成为时间王这辈子第一个也是最后一个替他挡过的人，那一下被火焰永远记下。
- 若林恩在左左即将崩溃前主动用自己左手勾住她指尖而非任她独自承受权柄，则他的左手从此成为她最本能的支点，她今后每次经受重压都会想起那一下。
- 若林恩进入灾厄般的黑暗核心时主动点亮一盏属于自己的小灯而非依赖历史之火，则他在任何黑暗里都能保有一线个人化照明，那光永远不会被外物吹灭。
- 若林恩在轮回把最后的记忆交给他时主动只取其中最温暖那一片而非全部接受，则他今后每次消耗记忆里都会优先想起它，那一段温度成为他做决定前最后的灯。
- 若林恩在历史之火覆盖终焉核心时主动让自己心脏的节拍与那火焰共振而非防御，则他的心率里写下火焰的节奏，他每一次心跳都自带一小段燃烧。
- 若林恩在大君秩序影子与黑火短暂重叠时主动把手放在那重叠处而不离开，则那一瞬被烙进他皮肤，他今后每次伸手都能触及那个渺小重叠。
- 若林恩在左左空置权柄即将失控时主动用自己的身体垫在她身下而非以任何其他方式保护她，则她在重量之上立得比权柄更稳，她在任何后续危机里都多了一份「他会接住我」的底气。
- 若林恩在终焉与原初意志分离的瞬间主动先承认「你是被造出来的」而非「你是应被灭的」，则原初意志首次被作为存在而非问题看待，它今后能在新结构里有一点点位置。
- 若林恩在轮回最终留下一句话时主动不回应也不忘记只静静收下，则那句话在他心底占据一角不说话的位置，他在其后任何思考里都会路过那角落。
- 若林恩在权柄转移完成时主动把那份权柄的一小部分喂回给轮回，则轮回有了「最后一缕被感谢的火苗」可以带走，它破碎时嘴角有光。
- 若林恩在历史之火即将临别时主动握住左左的手而不是拥抱她，则那一下只牵不拥的触感被两人共同记住，他们今后的每次再见与再离都不再需要更多语言。
