# E648·高塔引诱与二档罪火·if线

- 若林恩从出口而不是入口突袭，则由另一侧守军接战，变形：入口的两位腐化上位神不登场，二档节点被推迟。
- 若林恩在催动白烬前先朝入口投一支三叉戟试探，则两位腐化上位神即刻合围、不等他入场就先锁定戟刃，入口混战提前半个呼吸。
- 若林恩冲向入口瞬间不点亮罪火、只用星寂开路，则他能少付出皮肉代价，但两位上位神不会因恐惧而后退半步，战局拖成消耗。
- 若林恩不唤出左左，则「开天」缺席，两位上位神可贴身围殴，二档转化的时间窗被压缩到一半以下。
- 若林恩让左左以常规大小现身而非真身，则她能连出多刀、但夜魔刀无法横贯三分之一迷雾，拦截两位上位神时多一道破绽。
- 若林恩在二档转化时主动分一缕初诞者之力护住脸颊，则面容焚毁进度减半，但罪火总量被抽走一线，最终一拳威力下降。
- 若林恩只掷三叉戟给黑发女子而不瞄斧神，则斧神会抓准女子中戟的瞬间从侧面切入，林恩要同时应付一位重伤者与一位尚全力的对手。
- 若林恩故意让三叉戟在贯穿斧神前先绕行引动四尊黑色神只，则戟刃会被四掌强行按下一段远距离，胜率大幅下降，但他仍保有武器。
- 若林恩先击黑发女子再掷戟，则斧神的战意会随她所受之伤一路飙到顶点，他挥出的下一斧堪比此前所有斧之和，林恩若不升级为二档将被一斧砸出迷雾。
- 若林恩把大君记忆里对那柄巨斧的熟悉感刻意压住不让它浮起，则斧神的旧世界烙印不被挑动，对方全程保持战意而非震撼，对战的局势更冷。
- 若林恩刻意在三叉戟入海前以心声向黑发女子说「让他活吧」，则女子只用半秒迟疑，戟尖仍穿透她胸膛，但她会反手一掌替他抵消斧神的临死反扑余波一线。
- 若林恩不带左左同行、只让她护在左手深处，则二档罪火爆发时她的意识会被灼到，夜魔刀不会断裂，但她要在意识里独自承受一阵漫长的痛。
- 若林恩在二档燃烧的同时调用一缕梦境涟漪护住双眼，则视线不被罪火灼白，但梦境在现实里要撑住两秒就让他眼角滴血。
- 若林恩在斧神倒地瞬间抽回三叉戟不让它钉死两人，则两位上位神被一道金色涟漪同时定格、却仍保有神格活性，E649 里金色少年会先救他们再追踪林恩。
- 若林恩在变换到二档前的间隙朝被吞噬的迷雾投出一声叹息，则那缕气息会在无序边缘形成一条短暂的反向流动，他不会得到任何战略收益，但左左会紧紧握拳。
- 若林恩在钉杀一瞬主动把大君记忆里的「那个时代的神」画像压在斧神识海，则斧神在临死眼里会闪过一丝清明，但立刻被腐化再次吞灭，不会改写结局。
- 若林恩以罪火为引烧断自己一缕长发作为祭品，则二档启动会更快、更彻底，但事后左左会对着那缕黑发出神整整一夜。
- 若林恩不掷三叉戟、只用双拳，则他必须近身迎两位上位神的神器齐下，血肉与骨裂的代价比掷戟多出数倍，但不会失去武器。
- 若林恩让金色涟漪只罩住两位上位神而不扩张，则突袭的成功率骤降，但他保留了梦境领域的余量，后续行动仍留一线后手。
- 若林恩在叉尖近身瞬间以心声催一句「以M」，则两位上位神的腐化心智浮现极短暂的混沌，戟刃更快到位，但黑发女子握戟的瞬间双眼多了一缕不愿退让的倔强。
- 若林恩利用二档的极致燃烧压扁周身迷雾形成一圈真空，则火焰更亮、拳头更稳，但迷雾的真空引来某个无序生灵的注视，让金色少年更早一步发现罪火的存在。
- 若林恩让星寂的最后一击反向带偏一记黑发女子的掌势，则她的攻击会偏移到吞噬中的无序生灵躯体上，那具生灵会痛得发颤、向这边回望一眼。
