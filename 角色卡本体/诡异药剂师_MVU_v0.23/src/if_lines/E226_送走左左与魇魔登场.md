# E226·送走左左与魇魔登场·if线

- 若林恩告别时先揉她的头顶而非按住后颈，则触手刺入中枢神经的位置偏移，左左在昏迷前保持一线清醒念出「主人不许死」，事件以不变形收束但她昏迷后仍掉泪三分钟。
- 若林恩在告别时向她正式承诺「回来给你带一颗鬼面尖啸者内核当报酬」，则她被传送进黑夜城后第一件事是蹲在仓库门口等，事件以不变形收束但左左在留守期间替仓库守夜解锁一项成长。
- 若林恩不送走左左、改把她藏入自己胸腔第二心室，则事件以变形（拒送左左）收束，她贴身旁观核爆后段，但魇魔首次攻击穿透血肉壁垒时她受到余波半昏迷。
- 若林恩答应弥赛亚的要求把她一并折跃送走，则她在消失前喊出「你们这些恶魔代言人」，事件以不变形收束但弥赛亚从此欠林恩一笔「救命上天」的债。
- 若林恩在摊牌时直说「你的炽天使欠我一个道歉」，则弥赛亚金芒熄灭一瞬，事件以不变形收束但她在隐修会档案里被记为「叛意微弱」，第一使徒对她的处置宽松一档。
- 若林恩不把第一使徒真身信息告诉弥赛亚，则她痛哭后仍然在废墟里守候，事件以变形（保留信息）收束，隐修会识破傀儡的时间点推迟到第二日凌晨。
- 若林恩让燕尾服在折跃途中提前从系统空间飘出，则他抵达城外时已是全副武装，事件以不变形收束但魇魔第一眼就识别出死兆级咒器的气息、首次交锋改为远隔百米试探。
- 若林恩在城外废墟先绕到魇魔背后发动咒瞳锁定，则被识破瞬间「往日的罪孽」任务以失败形态开局，事件以变形（先攻未中）收束，他不得不在交锋中重新稳住面板锁定。
- 若林恩在对话中直说「我扮演过汪涛、现在站在你面前的就是替他复仇的人」，则魇魔首次出现长达半秒的精神震荡，事件以不变形收束但任务难度+1（魇魔将视他为头号目标）。
- 若林恩拒绝触发与白夜的往事共鸣、冷淡报出自己的夜医身份，则【往日的罪孽】任务面板在他眼底只闪一秒就熄灭，事件以不变形收束但白夜好感度止步在原值，没有+100预告。
- 若林恩在魇魔显形前先以白雾笼罩废墟并释放三只血肉傀儡试探反应，则魇魔第一次精神冲击波被三具傀儡分担，事件以不变形收束但傀儡损失三台，整场战斗节奏提前一轮。
- 若林恩在魇魔反问「你为什么不怕我」时不答而笑、反手把夜魔刀插进自己腹部强化血祭，则他的暴击药剂效果在战斗中延续多90秒，事件以不变形收束但战后恢复期延长三日。
- 若林恩让小眼萝在刀光落下瞬间代他执行一击，则魇魔被切成三段而非两段，事件以不变形收束但小眼萝在战后沉睡一周、咒瞳短期不能加钱。
- 若林恩对「燕尾服是得到的最好的礼物」一句改口为「就一件破外套」，则背部花纹骤然熄灭至暗光泽，事件以不变形收束但第二次反制触发延迟一拍，魇魔成功削掉他五分之一血气。
- 若林恩在暴击药剂的「秃头」效果落下之前先用咒术把头发化成一对血肉翅膀贴在背后，则他的爆射速度+50%，事件以不变形收束但后续战斗他必须以「秃+翅膀」形象示人，全球卫星拍到的画面被命名为「机械秃鹫」。
- 若林恩临走前在左左身上压了双倍的咒血承诺，则她在黑夜城比在蜀都更安全但也更沉重，事件以不变形收束但左左在守阵时持续被咒血刺痛，需要林恩后续亲自解开。
- 若林恩把守阵任务改为「主动毁掉法阵、让虫群失去彼岸入口」，则事件以变形（毁阵脱身）收束，虫群被迫绕路来到蓝星，蜀都战场延到更远的荒野。
- 若林恩在告别时不向弥赛亚点头示意、直接折跃离开，则她追出去的脚步停在废墟南缘，事件以不变形收束但她在后续隐修会报告中把林恩写成「无情恶魔」而非「可谈判对象」。
- 若林恩让一台微型机械震荡器藏在左左体内陪她一起被传走，则她在黑夜城内悄无声息充当一枚活体诱饵，事件以不变形收束但林恩失去了这一台震荡器在城外猎场的布设容量。
- 若林恩在小眼萝的咒瞳首次扩张瞬间用双指捂住右眼、改由左眼执行死缚，则死缚锁链路径反向、直接缠住他自己，事件以变形（自缚）收束，他不得不在30秒内挣脱才能继续追击。
- 若林恩把自己的夜魔刀换给左左带走作信物，则她怀抱着这把黑刀在黑夜城仓库夜夜安眠，事件以不变形收束但林恩接下来战斗中只能依赖血肉触手与咒瞳，纯武力值下调一档。
- 若林恩在折跃途中向系统下达「把这场对话全部存档、发送给白夜」，则白夜在隐修会密室里看到实时投影，事件以不变形收束但白夜的好感度提前一日爆表、他在 E231 提供的支援力度+1。
