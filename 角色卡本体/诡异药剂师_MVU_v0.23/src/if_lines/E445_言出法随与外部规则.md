# E445·言出法随与外部规则·if线

- 若林恩把三叉戟平掷插进权柄光束侧沿而非直刺核心，则光束晃裂半寸，外宇代行链保住不崩，黑袍反噬延后。
- 若林恩先以心声令熔岩巨兽撞偏光束再出戟，则戟刺入点不再在罗网中央，断链仍可发生但黑袍暗金纹路晚半秒浮现。
- 若林恩朝坐王座黑袍掷一支镇静药剂，则对方精神领域表面一荡，反噬加深一层，康斯坦丁精神抹杀窗口比戟更先到。
- 若林恩在黑袍说出「再相见」时用初诞之力锁住对方下一句言辞，则「滚」字被截在王兽群之前，门外金瞳目光提前半秒落在他身上。
- 若林恩在康斯坦丁被逐出精神世界瞬间踏上王座法阵铺初诞之力入地槽，则坐王座窗口提前被林恩亲启，但禁制反噬更早烧至灵魂。
- 若林恩先把小丑推向殿后结界方向而自己留守王座前，则外援窗口仍开，康斯坦丁被迫在刺杀前分一缕意志去稳城。
- 若林恩在王兽冲入大门时高喊面板「编号751」，则升格王兽怒吼节奏乱半拍，黑袍目光首次真正落到这副面孔上。
- 若林恩朝界门内紫色金瞳掷一支夜医应急血包，则金瞳目光闪过被打断的惊讶，污染者头一秒涌入出现呆滞。
- 若林恩让左左先用心声敲王座黑袍精神内壁，则对方眉头微蹙，言出「灭」字迟发一秒，但左左脑内立刻发烫。
- 若林恩主动扑到最近王兽背后扛住「灭」字规则冲击，则那只王兽重伤减一档，林恩胸口被切割痕撕裂。
- 若林恩掷戟前念一段渡鸦真名祝词，则戟融合光束瞬间亮出紫金纹路，断链更彻底，但坐王座时多一重古老审视。
- 若林恩故意让左左打头阵硬闯言出法随，则她被一道红霆掀飞殿外，但暴露黑袍动用规则的冷却半秒。
- 若林恩跃上康斯坦丁肩头分担精神刺杀承受的余波，则康半边骷髅垮塌减一档，林恩右臂切出方块状缺口。
- 若林恩用血肉灾变伪装成掀飞王兽尸体混入尸堆，则黑袍第三次言出法随漏他一回，起身掷戟时戟偏半寸。
- 若林恩主动宣称后世他曾坐同一座位，则黑袍死前眼瞳闪过真正惊讶，但那句谎言撑开的干扰只够匕首更深入一截。
- 若林恩向光束侧沿掷一支初诞者精炼药剂，则门外金瞳短暂离开光束，裂缝打开速度放缓一瞬。
- 若林恩的戟擦过康斯坦丁骷髅指尖再入光束，则戟附着一线杀意回响，黑袍被破识后躲闪多锁半秒。
- 若林恩在断链后对黑袍喊「你的主子认得我」，则黑袍目眶里闪过确定的回忆，但只够冷笑一声未吐一字。
- 若林恩抓住代行链具象化的金色丝线扯进自己灵魂，则他烙印永久标记，但坐王座反噬烧得更深。
- 若林恩把王座边沿一口咬下，则破口外泄一缕地狱机制气，他吞进一缕权限本源，系统空间即时警告。
- 若林恩在权柄接入第一秒就斩断与代行链的精神接触，则他能立刻分身，但王骑沿链路杀回的窗口提前。
