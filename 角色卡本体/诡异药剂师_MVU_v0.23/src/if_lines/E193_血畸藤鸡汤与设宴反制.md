# E193·血畸藤鸡汤与设宴反制·if线

- 若林恩一枪崩掉圈养房看守却忘了拽回笔记，则本子被留在原地，后续大舌头打扫现场时会再次认出笔迹而二次加深恐惧，事件以证物遗留变形收束。
- 若林恩当场把笔记撕两片塞进看守嘴里补刀，则「满脑子坏水」评价连同作者身份一同被掩埋，事件以作者身份封口变形收束。
- 若林恩摘下迷魂铃时手贱对它吹一口气，则铃声猝死共振，阁楼与书库的所有血肉人形同步被迷魂，暗杀区瞬间成空城，事件以人形整片倒地变形收束。
- 若林恩顺手把四包摄魂花粉全部嗅到饱，则精神-40、debuff「深摄魂」挂定，左左与喵喵咒纹共鸣扑面担心，事件以林恩本人中招变形收束。
- 若林恩把花粉分两包丢给左左「你拿去玩」，则左左当晚自行试错出一连串异常反应，事件以左左中招变形收束，宴席节奏被迫延迟。
- 若林恩暗杀书库改用迷你手枪而非消音左轮，则一声细微枪响传出，两名队长当场听出动静、血畸藤下毒时机被迫延后，事件以警报破袭变形收束。
- 若林恩暗杀时让喵喵而不是左左补刀，则喵喵多生一份「犬口吃尸」特质，吐金牙变成吐萌毛，事件变形为双宠反踯收束。
- 若林恩在厨房撒血畸藤种子前先插一支解毒剂进自己长袖，则他额外多一张「事后醒毒」牌可玩，厨师进度慢三秒，被队长「怎么还没来汤」喝问，事件以拖宴变形收束。
- 若林恩把血畸藤直接下进酒杯而非汤锅，则「鸡汤来喽」名场面整体取消，大舌头入喉即炸，事件以酒毒同下变形收束。
- 若林恩在汤里多一倍血畸藤，则大舌头畸变比队长更早爆发，能反向用他当镇压钮，事件以「小宝贝先中」变形收束。
- 若林恩故意避开大舌头不给他下毒，则原作「鸡汤怨念+10/+20」提示整体删除，事件以小宝贝清白变形收束。
- 若林恩让左左灾变成店小二端汤、自己躲进后厨，则队长隐约认出端汤者「左手擎盆的味道像谁」，事件以手下揭点变形收束。
- 若林恩端汤时手抖故意向队长桌面洒下几滴，则队长会立刻观诊汤面被范围解毒适应症，「尽快喝汤」节奏被打断，事件以变数启幕变形收束。
- 若林恩不下进厨房、改在最终教堂后花园投毒，则事件变形为毒堂外攻收束，后端突杀战篡位成核心。
- 若林恩用本脸敬汤而不是灾变店小二，则队长认出「这汤师像林恩」、惊愕与香欲并存，事件以不饰伪装变形收束。
- 若林恩掀开锅盖的同时启动咒瞳透视后厨全貌，则血畸藤播种的最佳时机被错过，队长反而急迫催汤，事件以先动手后播毒变形收束。
- 若林恩在外端同步启动夜医外圈，则报信人完全来不及入场，事件以内外同步变形收束。
- 若林恩让左左提前在哨兵手里塞哑药，则队长吹哨那一秒发不出声音，事件以哨音未响变形收束。
- 若林恩在队长汤下肚那一秒先一语「这是爹给你的血畸藤酿」，则大舌头惊愕扔碗在地尖啸，事件以小宝贝直接摔倒变形收束。
- 若林恩掀牌后改口「我是来劫店的」而非宣示「我是店主」，则队长判断失误、以劫客姿态反扑，事件以角色扮演变形收束。
- 若林恩用无声手枪射杀冲门报信人在餐桌之下，则没人听见门外动静，事件以封端口变形收束。
- 若林恩掀牌同秒让喵喵与左左齐现压盘全场，则同伴阵容压场端住，事件以全场压群变形收束。
- 若林恩掀牌后先动手再打话，两名队长被打了七寸只能白毛挣扎，事件以纯动作不用嘴变形收束。
- 若林恩主动召夜医大军破门闯入宴席，则原作设宴反制被强行破坏，事件以暴力袭击制收束。
