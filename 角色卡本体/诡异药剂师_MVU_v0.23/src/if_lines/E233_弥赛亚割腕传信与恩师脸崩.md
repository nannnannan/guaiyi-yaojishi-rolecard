# E233·弥赛亚割腕传信与恩师脸崩·if线

- 若林恩在破译血肉信前先让利维坦残片在她伤口上轻轻照一下"试真伪"，则小股反应证实血肉与左左同源，事件跳到直接分享而非审问式破译，弥赛亚的"被威胁"自陈被压后说。
- 若林恩在解析血肉信时只读出左左"约定归来"的最后一行、故意略过"明天召唤"的威胁，则他依然不知晓左左的底线与炸弹情怀，接下来的召唤节奏在林恩视角里变成"她在等我"，亲密密度反而上升。
- 若林恩对弥赛亚开口时先给她一根安抚触手按在肩膀说"你辛苦了"，则她后续自陈威胁时多了一句"我承认我当时腿都在抖"，主仆语感被她从对方的"半关怀"里扭曲出来，事件以变形（她对他产生依恋）收束。
- 若林恩在她讲述"被威胁"过程时故意笑出声，则她首次意识到"这个男人不装圣洁"，画像从怪物切换到流氓，"我不是为你而来、我只是被迫"的表述力度反而更坚定。
- 若林恩挥挥触手把她拖进山丘后不让她说更多、直接交给她一枚手写便签让她记录神迹，则她如原作被叮嘱"做见证人"但少了一层对话试探，事件在纸笔交接处收束。
- 若林恩在她开口前先把血肉信递回她手中示意"你自己读"，则她在读出左左威胁时脸上红一阵白一阵，反过来补一句"她就是这么凶"，林恩对左左的人格做了一次远程侧写。
- 若林恩在恩师脸崩瞬间一把用触手把弥赛亚拉低，则她没看到那张脸，林恩单独与第一使徒对峙；她以变形（未当场认出恩师）收束，后续崩溃时间整体后移。
- 若林恩把血肉信先交给血娃娃保管不让它在场上出现，则弥赛亚开口自陈时没有物证支撑，她对"左手"的说服力降级，林恩对她的信任门槛反而更高。
- 若林恩在她讲述同伴耳朵被咬时当场帮她打一针镇痛并让她再说一遍，则她对血娃娃的视角从"小恶灵"换成"护主的小恶灵"，事件以变形（跨阵营敌意软化）收束。
- 若林恩让她在监听器前重新复述一次左左口信录成血肉纹，则该段证词可后期用作"她曾协助林恩对抗血肉神教"的隐修会内部把柄，事件以变形（留下证据）收束。
- 若林恩在诅咒反噬气息浮现瞬间强忍不露、把咒瞳装在礼貌的表面之下，则弥赛亚对林恩幅度的评估只看见"他很强"，没体会到反噬崩溃，她后续的立场推算是"我加入可以保命"而非"他需要我保护"。
- 若林恩让山丘体内的傀儡之印在弥赛亚对话期间以低频嗡嗡回应，则她听见"这具工事的意志站在他那边"，事件以变形（阵线明确）收束，她开始怀疑隐修会的道统并未垄断"真理"。
