# E529·黑袍人现身与夏娃战书·if线

- 若林恩（黑袍）在写血信时不写「三天之后再来」而写「我会再来的」，则艾雯无法立起精确的警戒日历，黑夜城会议的多争一天「是他在拖」还是「是他在赶路」。
- 若黑袍把夏娃抛下城墙时主动加一句黑袍层心声「这位是见面礼，其余的你们自己来领」，则夜医部队第一时间推到「他在向某人私信」的方向，会议对身份试探议程前移。
- 若黑袍在夏娃落地前故意在她的血管断裂处先按上一缕初诞者之力做半稳封，则她的体表伤惨如故而内伤不到灵魂层，夜医定性从「极重」调成「重伤但可控」，「对方留手」信号更刺眼。
- 若黑袍血信没有提「喜欢一对一」，则巨像镜像战之初巨像可能不再孤军深入，会议一开始就把「围殴顺序」列入布防，巨像与黑袍的单挑改写。
- 若林恩在写血信时在落款处加一笔只有自己看得懂的轮回者符号，则羽毛笔旁观资讯时可能读出身份层信号，黑袍身份在羽毛笔处提前半拍偏向确信。
- 若巨像在镜像空间内不开第一拳而先用血气凝聚出一柄与黑袍长刀相仿的短柄武器，则「我不用兵器」层失守，「我认可你了」的口径变成「跟你认真」。
- 若巨像在拳雨百连时不摘掉黑袍的兜帽试探，则黑袍兜帽下的左手拔刀画面延后一拍登场，「那不是速度」的判定多一层悬念。
- 若黑袍在镜像战开端先用一段「学者弦流」规则干涉试探巨像，则巨像会更快识别那不是初诞者之力可拟化的领域，她把「法则」这个词喊出的时点不清在战斗中期而是战斗早期。
- 若黑袍主动让巨像先把全部血肉攻完、而不自启法则反制，则整场战斗呈现「巨人压力级压制」，但巨像「力量法则」的领悟时机被推迟，教招环节更突兀。
- 若黑袍在教招句尾不再赘「在你把法则一点点锻在自己体内之前不要加持到自己身上」，则巨像对法则负荷代价的认知停留在身体疼痛层而非体系层，她后续的「借外附法则而加持每击」改良逻辑要重推。
- 若林恩让黑袍的左手在巨像欲扯兜帽时主动摘开一角让她看到一缕自己的发际颜色，则不立刻拔刀反而引发巨像愣神，揪这个空隙他想保持神秘感的下一招不需斩得这么快。
- 若黑袍在全城原子机械之前就主动撤去镜像空间，则船长入失却之海找不到「就在你们那个位置」的心灵感应，整个镜像现实同位叠映的核心技术证据链丢掉一节。
- 若黑袍在临走时点名巨像之外再多说一句「下下一位是巫神头颅」，则城内以泰坦空等为核心的序列推理立刻被改写，巫神所在地的戒严档位上移。
- 若林恩在夏娃重伤后让羽毛笔以他的「私藏医生」身份出神片刻远程帮她灵魂层把脉，则夜医报告的灵魂创伤数据更缓，会议对「留手」的判定更宽，对身份的猜忌反而更尖锐。
- 若林恩（黑袍）在战后给巨像注入一缕极轻量的初诞者之力帮她封锁创口一侧（不让别人察觉），则她恢复速度比夜医预期快一档，艾雯会第一时间把这线索归到「他在帮她治疗」而非「他手下留情」。
- 若巨像在战斗结尾不是先道「好刀」而是先道「再来」，则黑袍教招环节被推迟，镜像碎裂的承接可能落在另外的台词。
- 若黑袍在出发前先独自把一只初诞者光球塞进镜像空间某角落留作后来剑尊的换位锚，则镜像破后这光球会被银幻的原子机械捕获成为「他下一步会重开这个位面」的预警证物。
- 若黑袍在「一个幻影你不需要知道我是谁」之后主动加一句「但你可以喊我刀客」，则银幻后期试探身份的「喊刀客名字看反应」手段会迈到与「私藏反应」并列的另一轨道。
- 若黑袍在教「掌控就掌控」后不立马消失，则他可能听到巨像昏迷前的呢喃「我已经找到了我的路」，他会在门口停留一秒、内心对这条路是否就是她巨像双生子传承的延伸产生一秒迟疑。
- 若林恩在整张镜像战期间让左左强制屏蔽这一条战争数据源，则她在家中完全不知情，后续对她发起「左左清凉照」试探时她对这场战斗的反应只有系统记录的间接痕迹。
