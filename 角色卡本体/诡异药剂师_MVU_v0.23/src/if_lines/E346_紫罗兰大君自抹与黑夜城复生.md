# E346·紫罗兰大君自抹与黑夜城复生·if线

- 若林恩在月儿兰花圃蹲下身先把指尖插进花泥而非直接刻阵，则法阵响应会慢一拍展开，水潭底部的古老面孔先映出奈奈子年幼时睡在法师帽下的旧影。
- 若林恩在刻紫罗兰无瞳法阵时主动跑出节奏的错拍一笔，则古老影像只肯显到一半，紫罗兰旧影不与他对视，复苏度提示停在【+12%】的半途水线。
- 若林恩顺着老人指引在记忆中跟着数十，则影像里的苍蓝女孩第一次察觉观众席位，她会回过头朝花海这头轻轻咧开嘴笑。
- 若林恩在旧影里主动扶住那具被白毯裹着的白发人，则轮椅会向前挪半寸，奈奈子的数落第一次落在他耳边而不是落在徒儿肩上。
- 若林恩在影片碎裂那一秒盯住对方复述自己的名字，则法师塔内的苍白面颊会因这声重叠多掉一滴眼泪，复苏度爬升的幅度向后推慢十倍。
- 若林恩把法阵复刻成一半就停下来等待，则无瞳之眼的瞳孔处出现一枚稳态的紫斑，紫罗兰旧影会侧面盯着他多伫立一段不带私人意图的空白。
- 若林恩直接把苍蓝女孩的名字用血写在法阵外圈，则奈奈子在影像里抬手按住自己心口，她的侧脸首次被紫罗兰大君的视角注视。
- 若林恩在白发大君拒绝复生那段落下之前握紧法阵，则被镇压的狱卒群中会有一名披甲狱卒抬起头盔，狱卒鼻梁上挂的眼泪被时间魂媒先行收容算入回归名额。
- 若林恩随大君走出塔门时主动在塔前拄一柄旧杖作为隔离标线，则紫罗兰光芒不再席卷整片花园，时间魂媒释放的灵魂会被限定在大君亲手划出的半径内。
- 若林恩在左左尚未奔至面前时抢先喊出她的名字，则她满身的泥污先一步凝固在原地，紫罗兰大君的微笑会稍稍偏向这个正在拼命赶路的少女。
- 若林恩主动用黄沙托住左左踏在废城外的碎石路，则黄沙平掉沟壑的轨迹恰好与白发大君行走的轨迹重叠，紫罗兰旧影在复生光芒起闪的前一秒轻轻点了点头。
- 若林恩让巫神、白夜、艾雯的复生时间刻意错开一盏呼吸，则黑夜城废墟中三道魂魄点亮顺序变成巫神先醒、白夜次之、艾雯最后，紫罗兰大君的力竭跪倒幅度有微小减缓。
- 若林恩在大君注视左左那段沉默里主动站到左侧替左左挡掉一缕逆天神光，则左左的泪眼能睁开看清大君嘴唇的口型，那句「照顾好他啊」会被她真正听见。
- 若林恩把大君临终的嘱咐原封转录给左左，则她手中的破布裙角在风里被掌心攥到起褶，「不被人管束可是不行的啊」这句话第一次被刻在巨像之心的怜恤面上。
- 若林恩在大君白发褪为灰白的瞬间替他接住一缕断发，则断发在他掌心凝成一枚不带复苏度的纯结晶，系统备注写明「此物只作纪念，不可入药，不可驱动」。
- 若林恩主动向时间魂媒申请保留一份紫罗兰旧影的非意识模板备份，则魂媒会拒绝以人格形态归档，只留下一段「曾经有过」的客观笔录字段。
- 若林恩在大君闭目那一秒与他同步呼吸，则对方白发散开的最后一秒会在他瞳孔中留下一段极短的回眸——那回眸看的是苍蓝世界的方向，不是看他。
- 若林恩主动用初诞者力量为由拔起一株月儿兰送到苍蓝女孩塔顶，则花瓣会在门边收根，奈奈子的恸哭里挤出一声被吵到的轻咳，法师塔的墙基多一行紫色残留谱。
- 若林恩没有去摸那株新栽的月儿兰、只把它留在原地，则花开一季后会成为无味的陪祀，紫罗兰旧影这一支复苏度之后在任何历史修缮日志中都不再有回升空间。
- 若林恩在黑夜城复生之后、大君尚未彻底消散时，请巫神立刻做一次基础体格检查，则巫神枯手按住大君脖颈的动作晚了一瞬，他指尖在空气中摸到的只是被风化的半透明粒。
- 若林恩主动请求艾雯将赛博文明的阅读镜头对准大君消散的那片光谱，则里头有一段被命名为「自赎的误差值」的特有波动被记入艾雯的人格芯片空白区间。
- 若林恩让白夜负责把复生者名单按民生部门重新分类，则白夜不问为什么会缺一名「白发的源」，他只在名册最末位注一行「城，因他而建；人，因他而归」。
- 若林恩在大君闭眼刹那悄悄用母亲符号的法贴包起一角紫罗兰花泥，则他将来某天回头看这块花泥时不会再看见任何白色背影，那段旧忆从那一刻起对他彻底关页。
- 若林恩在大君出塔前先尝试让法阵反向逆流，则无瞳法阵的紫斑会顺他的鞋尖爬芥而行，系统下方首次多一行提示:【此尝试成功率过低，已写入拒绝分支】。
- 若林恩在临别大君忍住伸手碰他肩的冲动、只站在旁边应声「我会的」，则大君阖目时嘴角向上走了一点微小的幅度，复苏度自 36% 一路坠落至 0% 的时间里没有反弹任何数字。
- 若林恩主动按下替左左去握大君手的想法，只在旁侧看着，则左左握住那只手时大君的体温不低反暖，那只手上还残留着紫罗兰作为「人」的最后余温。
