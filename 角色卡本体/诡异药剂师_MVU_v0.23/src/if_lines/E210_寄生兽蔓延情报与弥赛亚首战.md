# E210·寄生兽蔓延情报与弥赛亚首战·if线

- 若林恩在冲出山顶之前先把傀儡化的那具教徒尸体藏进尸堆底层给军方指路，则超自然总局比隐修会早六小时收到西南运输线情报，事件以不变形收束但他与隐修会的首次面谈被让位。
- 若林恩掠过山林时绕开伴生蓝宝石的金矿脉不再深入，则那块鹅蛋大的原石不会被劈碎，事件以变形（放弃蓝宝石）收束，但他银行账户的损失额度下降一位数。
- 若林恩在被弥赛亚一记圣芒砸进岩层瞬间主动把脊椎骨折叠回避一击，则他没被砸成肉泥而是顺势钻入另一块岩层，事件以不变形收束但"被崩塌山体压住"的视觉冲击被抹掉。
- 若林恩选择不骂"辣么大一颗蓝宝石"而是冷静地把矿粉集中留作分析，则他抽离情绪立刻进入对隐修会的反制节奏，事件以不变形收束但少了一句现场笑料。
- 若林恩用以M之拳击中十字架前先用触手包裹自己拳头做缓冲，则弥赛亚承受的快感冲击被减半，事件以变形（控制力度）收束，她的"屈辱+10"提示减半但破防未被击溃。
- 若林恩沿用原作的以M连招但在拳头触及十字架瞬间让她听见自己一句轻喃"抱歉"，则弥赛亚的恨意计数仍涨、但她的责任心错裂出一道缝，事件以不变形收束。
- 若林恩不没收弥赛亚的三件套而是只没收圣十字架作抵押，则她保留罗盘与半身铠、事后仍能召集支援，事件以变形（部分缴械）收束，林恩的威慑力减一档。
- 若林恩把钱包里的钞票原样塞回她胸甲里、只抽走那张证件照，则她首次在林恩脸上看到非淫邪的认真，事件以不变形收束但恨意+10替换为恨意+5。
- 若林恩在抽她藤条的过程中主动塞一支止痛针到她颈侧，则她身体仍泛红却不再疼得抽搐，事件以恶堕调教路径推进但叠加"被恩惠冒犯"双重屈辱。
- 若林恩抽毕一脚把巨型十字架踢下悬崖让她去捡，则她被绳索吊着的姿态被迫保持到恢复自由，事件以不变形收束但十字架面前她不得不做出艰难抉择。
- 若林恩在羞辱尾声对她做一段简短的"地狱的魔鬼风格诊断"说明她不该轻信教条，则她没听懂但记住了一句"教条不是盾"，事件以不变形收束但隐修会侧的教义动摇。
- 若林恩让左左全程在他耳边用萝莉唱《虫儿飞》盖过弥赛亚的呜咽，则他自己的情绪被稳在低位，事件以不变形收束但整场审讯带上反差感。
- 若林恩主动给她一份从教徒尸体里翻出的寄生兽幼虫样本，则她首次以盟友身份触摸到入侵证据，事件以变形（部分合作）收束，但仍"被捕"姿态。
- 若林恩让她骂他一句"恶魔"再摘她下巴让她叫不出第二句，则她的咒骂被卡在第一半音里，事件以不变形收束但她在林恩脸上看到一种"允许你骂我"的怪笑。
- 若林恩弃藤条改用咒纹在她手腕内侧画一个小"仆"字，则一分钟之后那字自动消失只留痕，事件以恶堕调教收束但汇报到隐修会侧成为后续审问证据。
- 若林恩在她的白圣女裙上亲手撕一道斜口让她保持暴露状态被拖向运输线，则她的圣光在被撕碎的裙裾下首次凋零，事件以恶堕调教收束。
- 若林恩把她的钱包塞回去再补一张手写的"蓝星应急合作纸条"，则她松开她的手把东西收下、又立刻把手抽回痛恨自己的反应，事件以不变形收束但林恩的把柄转为了"亲笔"。
- 若林恩把她吊在树上之后再跪拜一次、用"地狱的魔鬼对圣女"的姿态封口她的怒，则她的精神被休克性锯断一截，事件以恶堕调教收束，拒绝抬头的她哭得更深。
- 若林恩选择不没收镇魔罗盘而是把它撞碎再踩一脚，则隐修会同步感知到罗盘消失，事件以变形（升级切断）收束，弥赛亚的求援链路瞬间瘫痪。
- 若林恩让左左在她面前公然捏一块蓝色冰棒送入口中，则她所有"圣萝"仪式感的边界被这一根冰棒划破，事件以不变形收束但弥赛亚把"荒谬"作为对林恩最后的印象。
- 若林恩先把她的双手捆在自己胸前让她面对聆听运输线虫类的细节，则她首次以"合作伙伴"模式而非"俘虏"模式听见情报，事件以变形（短暂信任）收束。
- 若林恩当场咬破舌尖把血抹到她唇上让她"体会地狱的味道"，则她全身震颤却猛地向后仰闪开，事件以恶堕调教收束但弥赛亚SAN骤降。
- 若林恩让她保留十字架但折断她的靴跟、让她只能踮脚站立，则她再无追击能力、被迫原地思考，事件以变形（羞辱控场）收束，林恩已绝尘而去。
