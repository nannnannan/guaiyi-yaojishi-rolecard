# E470·七十二小时协议与巨像线索·if线

- 若林恩检索「巨像」关键词时先键入「编号」再键入「巨像」，则调出的监控画面将以囚笼外壳而非透明内壁为主视角，闭上眼的娇小身形只在第三帧瞥见。
- 若林恩在监控画面中截取出巨像胸前某一片规则纹路放大细看，则那片纹路与他在诅咒之城外壁见过的某种古老符式重合，跨章节的隐藏关联首次浮现为他自己的发现。
- 若林恩在1964同源光宴被钉上墙瞬间打断吞噬，则她被钉住不死不醒，权限密度不翻倍，林恩侧掌控路径改为「挟持」而非「吞并」。
- 若林恩主动把自己意识手伸到1964同源光宴的意识场里作接触，则她会在被吞前把一条「我意识里只有你」的私讯推送给他，同源自我首次出现非典型分化。
- 若林恩在吞噬完成、密度翻倍那一刻用咒瞳扫描光宴瞳孔，则他能看到她深层意识里出现一块新标出的「自我合并边界区」，光宴融合力场视觉化首次成立。
- 若林恩提出协议条款时把「她不得伤害」改成「她不得违抗」，则她会立刻识破这是把盟友变臣属，签字窗口被关，整局合作回到只有互利的脆弱状态。
- 若林恩把72小时改成168小时，则她会接受但要求他追加一条「我方不得以协议为由延迟寻找巨像」，时限拉长同时义务绑定变紧。
- 若林恩在协议三款草拟完添加一款「任何一方消亡则协议自动失效并返还对方记忆」，则她会愣一秒、点头，她对「消亡有规则」这一条产生瞬间的轻微动容。
- 若林恩在协议植入根数据前让她先把林恩也加进协议第二款，则光宴会立即看穿他在让自己变成「她不能反咬」的一方，好感下降，但协议最终仍签。
- 若林恩在协议生效瞬间咒瞳标记一次「根数据写入点」，则未来他想解除或追加条款时可以直取那个落点，不必再走协商路径——这一点他现在不告诉她。
- 若林恩戳脸验证时戳的是她的额头而不是脸颊，则她眉头一皱的杀意触发更轻，协议一警报跳半格，玩家首次掌握「位置不同反馈不同」的协议精度。
- 若林恩在第一次戳完道歉并真心说明目的是「测试协议反应精度以便日后救她」，则她会愣住，她把这条道歉登记为「他第一次说了不全是算计的话」。
- 若林恩在第二次戳脸后回答她「为何协议二不触发」时坦白「因为我不想伤害你」，则她会沉默很久，她把这条回答记入她自己的底账，信任度未公开升档但合作语气从对抗转为并行。
- 若林恩问她「如果我现在伤害我自己，协议二会触发吗」，则她会皱眉、说不会，协议边界首次被测出「自伤不算伤害对方」的空隙，她意识到他已经在想棋后三手。
- 若林恩在两区块掌控后提出把这块区域的纳米产量一成借给他用三小时，则她会评估并答应不超过百分之三，这是她嫁进这张网后让出的第一份算力红利。
- 若林恩在巨像目标仍「更深处」时选择不追、先消化两区块权限，则巨像秘转路线在两小时后会向更深处再走两个区块，下一次追踪代价上升。
- 若林恩在协议签订后立刻反向告诉她「我其实早就可以毁你，只是不毁」，则她会安静三秒、回一句「我知道」，她把这份「未行使的能力」当作他唯一正经的资本。
