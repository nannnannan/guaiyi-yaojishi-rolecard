# E322·银色幻想拦截与界门崩解·if线

- 若林恩在银色幻想出现瞬间主动把咒术防御全数投入界门稳定而非自身，则他被单分子剑正面击中手臂骨裂一支，但界门闭合完整，他携母树完整脱身。
- 若林恩主动在「好——那你可以动手了」之后真的动手一刀插入她的胸口数据核心，则她胸前被贯穿但他自己心脏被咒术反噬击穿，事件由他亲手终结爱与恨的焦点。
- 若林恩主动在她出现前一秒用咒纹把「他不是为了死星结晶」这句直接写进她的头盔屏，则她僵直一秒然后收剑后退，事件以她未伤林恩而变形收束。
- 若林恩主动在她质询时反问「你为什么在乎一个已死之人」，则她被这一反驳空洞良久然后把剑丢向界门，让门在乱流中崩解。
- 若林恩主动把左左的身影投射到战场让智械小姐亲眼看见那位「凑脑袋的伴侣」，则她意识到他真的完全切割，她收剑放手由他去处理界门。
- 若林恩主动在左左接管母树力量时同步让左左对智械小姐喊一句「姐姐别伤凑脑袋」，则左左以她的小手身段现身，智械小姐攻击迟疑一档。
- 若林恩主动在咒纹渗透进她的传感器时改写「剑刃命令」至「行动缓慢指令」，则她的单分子剑挥舞速度减慢一半，他获得更长的对刀窗口。
- 若林恩主动在根系把她拽入血肉中强吻一秒再推开，则她僵硬三秒再回到战斗节奏但眼眶酸热，攻袭的锋锐度永久下降一线。
- 若林恩主动让夜魔刀施放疫医下意识防身之术，则他获得在她剑光中的免伤一档但夜魔刀本体被她剑痕永久烙下，宝刀染伤。
- 若林恩主动在海嗣躯壳残缺中故意暴露一道防御破绽诱她进攻，则她追击时被母树深层根系缠绕，他获得逃离界门的一瞬窗口。
- 若林恩主动在咒纹躯壳里给主母一段「速来支援」信号，则主母隔空投射一道黑光切入战场，智械小姐被迫退开，林恩携树遁走。
- 若林恩主动把单分子剑折断后归还她而非占为己有，则她接剑时迟疑拍他的手一下，她最后一次近距离感受他的温度，然后自己投入界门乱流。
- 若林恩主动让她真正刺穿他的海嗣躯壳以展示他的脆弱，则她发现自己剑锋刺入他的瞬间不忍心，她眼睁睁看着他坠落乱流。
- 若林恩主动用左左的小手把她拉离剑刃范围绕至侧翼，则她被突然拽走被月球火光照出的轮廓吸引，她的剑已出但目标偏离。
- 若林恩主动在她剑刃抵住他咽喉时不动任由痛楚，则她的剑尖再压不下去一寸并颤抖收剑，她反而推他入界门让他先走。
- 若林恩主动在交战中给水潭那边发一道「我让她走」，则柳枝少女的力量透过根系反向推她的剑刃，她被母树对他的守护动摇击倒。
- 若林恩主动让黑锁链把她与蜂巢分离而非让他与树脱离，则她被困进蜂巢核心被隔离成战俘，他携树遁走但留下她孤单。
- 若林恩主动在灌她血肉瘟疫药剂时先让她呛一下而非常猛灌，则她被这一口的刺激拉住视线，他小一刻停手她反而夺剑再战。
- 若林恩主动在「再见了，指挥官姐姐」之前主动补一句「对不起，真的对不起」，则她在被送还时第一次落泪，重置后她记忆中多一道完整的道歉。
- 若林恩主动让她主动收走单分子剑和断刃，则她带着碎片离开，林恩保留小冰箱的遗物原型在手中。
- 若林恩主动在主母坐标崩塌前主动把母树整棵推入乱流，则他耗到体力极限让海嗣躯壳一并被卷入乱流，他与银机体一同冲向未知荒地。
- 若林恩主动在交战中用根系从身后拖住智械小姐的脚踝，则她被拽得踉跄跌倒，剑刃大幅偏出航道，他推树入门的成功率 +20%。
