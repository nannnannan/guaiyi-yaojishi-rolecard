# E701·我们失败了无数次·if线

- 若林恩在画家说出「你成功了」时先一句「但你也没全赢」，则画家不会再做任何辩解，只把自己的手轻轻垂下，林恩对她的警惕等级 +1。
- 若林恩主动朝画家追问「你故意把本源留在神王界——那你当年撤退时为什么不直接告诉我」，则她会用「每个时间点的我并不完全同步」把事情轻轻推回去，林恩记下「她有限制」这一事实。
- 若林恩主动在画家面前摊开手掌让她看自己体内那缕混乱色彩，则她会用两根手指轻轻一抹，色彩被收回，林恩身上的画家气息首次彻底归零。
- 若林恩反问「你说只有我才能契合它——那是不是也在说你早在挑我」，则画家不会承认是挑，但会承认「是等」，林恩得到更准确的定位。
- 若林恩主动告诉她「我已经放进去吸收以太了」，则她首次在他面前露出半秒真正的讶异，因为这条信息走的不是她的渠道。
- 若林恩主动把「我看到了两个未来之人」这一细节从头到尾告诉画家，则她会沉默许久，第一次正面承认「他们在很多次里都没能救下因果」。
- 若林恩主动讽刺「你们修历史修到今天这个地步也算本事」，则她不怒，只回一句「所以我们才输」，林恩的烦躁被压得更深。
- 若林恩主动要求她以苍蓝身影的形式在场，不要立刻变回色彩，则她会停留更久，但狱卒大军会被她的「亲临本体」气息压得全部跪地，林恩要分心照顾军威。
- 若林恩主动对她说「我不是你的棋子」，则她说「从来不是」，又接一句「可是这条路上就这样多局无法绕过的棋」，林恩无法反驳。
- 若林恩主动拒绝听「失败无数次」的推断，则画家会立刻收口，但林恩将错过这一信息，未来在时间战争里他对失败的预期过于乐观，第一次正面受挫的代价会加倍。
- 若林恩主动把「我觉得这场战争我们赢不了」说出口，则画家不会安慰他，只回答「我也觉得——但还是要打」，林恩第一次直面她的疲惫。
- 若林恩主动问「你父亲是谁」，则她第一次没有马上回应，良久之后说「你知道的，不必再问」，林恩心里却卷起千层浪。
- 若林恩主动询问「渡鸦已经死尽了，那你这个容器还在——你以后还会再换吗」，则她坦白「不会，因为我已经不想再换了」。
- 若林恩主动提出「我不想再做这个容器」，则画家会尊重，但同时提醒「那只渡鸦就飞出去了就再回不来」。
- 若林恩主动提及紫罗兰大君的名字，则画家会全身一顿并以消散一缕苍蓝色彩作为回应，林恩首次得到她身上情绪的物理证据。
- 若林恩主动提议「那就让我和你一起面对失败」，则她的眼瞳首次凝滞，良久之后说「你不是在陪我失败，你是在替我重来」。
- 若林恩主动表态「你以后不许再单方面安排我」，则她的回答是「安排你是我必须做的事，但对你道歉是我可以做的事」，林恩对她的情绪模型更复杂一层。
- 若林恩主动把自己斩杀镜之魇时的「匣中色彩」碎片还给她，则她会收下，但明示「以后我不会再用这种方式帮你」。
- 若林恩主动指着那被她称作「灾厄」的东西追问「祂到底是什么」，则她回答「祂是我们的父亲，也是你们的父亲」，林恩一时间无法理解。
- 若林恩主动提出让狱卒大军分批回撤、减少曝光风险，则她会同意并把一位苍蓝副手暂交给他指挥，林恩的指挥链条首次越过狱卒层级。
- 若林恩主动在她说「我们失败了无数次」时立刻接上「那这次怎么算赢」，则她会沉默，因为这句话她没法回答。
- 若林恩主动问她「你的本体在哪里」，则她会指一指天上，林恩顺着看过去会只看到漆黑虚空中的那一个苍蓝暗点。
- 若林恩主动追问「你以后还会直接干预我的人生吗」，则她会回答「会，但我会尽量提前告诉你」。
- 若林恩主动告诉她「我决定继续走下去」，则她会首次用「谢谢」这个词来作答，狱卒大军中有人怔住，因为没人听过她说过这个词。
- 若林恩主动用「奈奈子」这个名字称呼她，则她会在原地僵住一息才慢慢回应「请不要再用这个名字」，林恩对她的认知被再次刷新。
