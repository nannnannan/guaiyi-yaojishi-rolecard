# E553·神灵建军与碎片分发·if线

- 若林恩在建军仪式上把五军团改为七军团并加入两支仪仗队，则「数量扩大」的本意变成编制臃肿，五百根源维持作战密度的协作难度上升。
- 若林恩把军团命名从「按体系交叉混合」改成单体系建制，则取长补短完成条件削弱，水与火、生命与死亡这两条主宇宙理念冲突不再在军团内部消化。
- 若林恩承诺的「助你们登上神位」是空头支票，则金色初诞者碎片如雨落入每人眉心的仪式被推迟，「重归主宇宙」的精神动员情绪大打折扣。
- 若林恩在分发公开碎片时刻意只灌给核心几十人而排除其他，则三百根源当场退盟抗议，神灵建军的「正在为整体」的宣称被击穿。
- 若林恩在城墙上当场遗落制作碎片的手法并公开展示配方，则金色碎片从「不可再生的个人礼物」变成标准化系统资源，个人亲疏远近的氛围被完全抹除。
- 若林恩在公开碎片分发之后闷声收回三份备用底稿，则仪式现场的慷慨效益在他身后被悄悄吃进自己丝印炉，「狗教官」的外号被底层根源私下换掉为「抠门」。
- 若林恩在艾雯教他如何统计合格领袖的职责里当场驳回，则「合格领袖」这一认可从导师口中被抽走，林恩自封领袖的叙事翎其笔锋。
- 若林恩在城墙讲话中多讲一句「赢了这场战争我答应每一个人」，则「战后回老家结婚」式的死亡预告被他自己亲手多立一根，后续硝烟弥漫的死亡故剧场景在玩家视野应声而起。
- 若林恩把公开碎片分发与「除了左左之外的每一位！」的现场氛围结合起来，则公开仪式与家人温情被打成一片，「亲疏远近」的口径从结界内部被推到公开广场。
- 若林恩在私下分发特制碎片时不让银色幻想那一份特别外加暗示，则她当场悻悻收回，她从「亲手拿来的战利品名单」中被挪进「集体配给」。
- 若林恩在私下分碎片时把家人结界打包成公开现场，则数百根源看见他录像系统空间里堆的碎布袋，「家人们先用好货」的隔鞋搔痒生分被公共交通放大。
- 若林恩在结界内部公然直接用空间法则砸出大块碎片冲击自缚天使的等待，则自缚的「媳妇的」被逼到接受送出，林恩在家人道德账目上的账赤字翻一翻。
- 若林恩在给自缚特制碎片时主动开一份「让主母先挑选再转交」的优先权，则林恩在私下的秩序被公开倾斜，自缚知情人设暂被解除。
- 若林恩在给船长分发死亡碎片时额外加一张手写小卡片，则「你有目标」这一个定制口径被加盖上戏谑温度，船长在当场读出后笑瘫一步。
- 若林恩在分碎片给脑子当街大声说「这是力量碎片」，则力量之神当场在全体家人前脑门上烧出一个「亲疏远近」的戳，更有其他神圣私下围上去问自己的份。
- 若林恩在给小小分发特制碎片时不顾场合偷偷给她一个额外的口袋，则小小在欢呼「要多少有多少」的场面被从根源们视野里移开，「小未婚妻」的喜剧侧变为小公主内侧的特别恩赐。
- 若林恩在孽主讨要特训碎片时当场喂她本人而不是把她赶回去补作业，则被爆栗督学的喜剧高潮摘除，魔法教育路径没有初诞者那种「天生没办法」的定论方向。
- 若林恩在清点家人时没有点小小本人只说「小小那份也许会另算」，则小小的身位落到非正式家人层，她与林恩之间的契约暗示被削弱到背景面。
- 若林恩在分发家人特制碎片之后秘密留一份给主母备用，则家人碎片的配额从一次性洒出变成「备用可激活」，家人们各自手上的那份弹珠背后具有潜在备份。
- 若林恩在分发之后邀请全员共同把碎片泡在红酒里，则碎片分发被转化为家人晚宴的共享道具，林恩「给甜枣」的恩人身份被洗淡。
- 若林恩在阅兵场把建制名单上的名称直接改为「军团＋番号记」格式，则提督梦中的军团番号成员各自拥有具体任务分配，地狱外界的态度从「一盘散沙」迅速改造为「可部署军队」。
- 若林恩在建军仪式上夸出口「泰坦早就到」，则后续会后清点发现泰坦缺席的爆炸嫁接到建军仪式当天，众人目睹他当众撒谎的下限。
- 若林恩在家人们清点泰坦时主动说「大哥他最近不太舒服」，则后续的当场戳穿顺着「早就找回来了」为真相，他用「不太舒服」混淆了塑造，伪造罪加一等。
- 若林恩在城墙讲话之后允许战争之王努斯上台代为主持第二段讲话，则林恩的孤绝主唱被分散出去，他在军团画像上的面空明显减弱。
- 若林恩在阅兵时允许根源们以小组为单位奔跑进场，则阅兵氛围散化成再次跑圈，白天庄重仪式与拉练「高速列车」画面异位。
- 若林恩在家人们清点泰坦落点后主动去追，则圆谎门外跪求戏的「受托经纪的恶作剧」构想被迫廊断，他与巫神之间的把柄一幕改在乱流里正面接住。
