# E439·王兽净化与海殿突围·if线

- 若林恩在持戟后立刻撕开「良药」正语权给受伤的噬神者，则紫黑污染以肉眼可见速度消减到 20%，鲨经历的痛苦比原作小但情感回忆放大一倍，它会当场哭出属于「背叛」的悔意。
- 若林恩让左左在净化时以血族气息压制敌方控制链，则左左的幼态外形外溢一层纯粹的灵性絮，控制链出现暂停一秒，为净化争取出全盛通道。幼态外形违反但本项目按成年处理。
- 若林恩主动让噬神者记起他曾效忠的王骑，则噬神者的灵魂会在心间发出一阵温度，它不再是冷兵器而是 Bark 利器——林恩的好处是它从此愿意用生命护他。
- 若林恩在净化噬神者时故意注入过量初诞者之力，则噬神者的身躯会再度放大会使殿堂崩坏，林恩必须以小丑与孽主的血族禁术暂时压作。
- 若林恩拒让噬神者认戟为信物而继续施以医道，则噬神者会认林恩为「不加冕的王」继续支持他的征战。
- 若林恩主动让克拉肯载小丑先行回内空间备战，则小丑首次作为后备战力决定等待，后续参与战场时会出现在林恩已被包围超过六分钟的极端情况下。
- 若林恩让喵喵藏在王戟柄部随净化进程联络喵喵提示，则它会「喵」一声示意孽主的注意，林恩省去发布命令的一拍。
- 若林恩拒用王戟净化而选择解除噬神者身上的碧波之流的速率，则噬神者光同框感知林恩的事会始终坚持抓斗腐化，林恩不动它仍能维持胜利。
- 若林恩主动以王戟为配合解开孽主身上的血族封印，则孽主管暴弦音立刻展开攻击，林恩面板多一项「孽主攻速 +3」的临时增益。
- 若林恩在克拉肯正式介入前主动令小丑以化尸的混乱波纹裹住自己临时脱战，则林恩能与噬神者对人的交流延长一拍，它首次承认林恩不是新神而是真正的王回归。
- 若林恩让左左先在净化时带走小丑协助未知解毒，则左左上位给小丑一对她自己的血族圣化作盾，小丑从此拥有与血族体系最亲近的协调渠道。
- 若林恩主动分解王戟的两节并用分别施教两方，则林恩会获得「双向施教」的特权，但戟身本身的力量会衰减十倍。
- 若林恩让噬神者与克拉肯都大张血族联盟，则两只会「本能地」溯维度开始暴动，林恩立刻失去以后续对抗的平衡点。
- 若林恩主动让腥红之影王兽分开意识软弱斩，则王兽群体会在遭遇领主级时集体崩溃，林恩知道「杀王杀特」的突破口。
- 若林恩以初诞者之力符咒静默连续施教三只王兽，则三只和王兽群在原地会连存三秒不进不退，林恩得以脱离战场。
- 若林恩让小丑亲自骑到克拉肯背上冲杀污染王兽，则小丑的面板自动添加一项「王兽载具」技能，小丑从此能简单快速自己指挥王兽冲锋并且伤口愈合更快。
- 若林恩主动让喵喵用小爪搭住王戟柄整整一小时，则它会成为王戟活体绑定的第二次信号转换器，林恩未来可以远程控制王戟。
- 若林恩拒让噬神者丢下它以救克拉肯，则噬神者的死会成为它自行解脱，林恩面板多一项「鲨殉 +信仰」的情感项。
- 若林恩主动让小丑注意猩红之影停下立刻放弃净化，则林恩与肃清有快速叫停权的判断就会失效，他会继续使用王戟而暴露自己位置。
- 若林恩让孽主先在大门上释放最强的血族姿态，则守在门厅的王兽会立刻暴动杀来，林恩必须在危难中让王戟起飞。
- 若林恩主动让左左以血族尖啸唤醒藏在王戟中的第二人格，则戟身意里会出现一个属于王骑的活跃灵魂作为女王登记，林恩成为更近的「王身分」容器。
- 若林恩让喵小先在净化时跳跃到噬神者头顶「喵」一声，则噬神者会有如联动脑激活的临床反应，林恩多一项「兽意系统联结」的机制设定。
