# E439·王兽净化与海殿突围·if线

- 若林恩在外层结界炸裂瞬间先将小丑与孽主收入系统空间再独自持戟迎敌，则他无需分心护住身后同伴，面对万吨海水灌入殿堂时动作更为果决。
- 若林恩任由孽主留在殿内躲在自己身后发抖，则她在猩红之影喝令群兽冲锋时会死死抓紧林恩衣角追问胜算，直至巨鲨撞破外墙才被收回空间。
- 若林恩面对噬神者巨鲨冲撞时不以蛮力硬撼、而是举起王戟发动海洋权柄改向拖拽海水，则狂暴水流在戟前化为无形，他得以借势踏上巨鲨冰冷铠甲。
- 若林恩将王戟刺入噬神者病变皮肉并全力灌注初诞者之力作为「良药」，则黄沙自创口蔓延全身将紫黑病变化为灰烬，猩红之影对巨鲨的控制链当场崩断。
- 若林恩在噬神者恢复清明却因愧疚求死冲阵时厉声以王骑铁令喝止「不能死在这里」，则巨鲨会在悲恸中强行收住狂性，改为如铜墙铁壁般横挡在林恩身前。
- 若林恩再度挥动王戟发动海洋权柄将前方大海左右劈开，则敌我之间瞬间裂开一道擎天沟壑，十几只受控王兽与深海骑士的合围之势被硬生生截断。
- 若林恩在噬神者一口咬住迅捷者·克拉肯将其固定时果断放出小丑发动「诅咒动乱」，则混乱音律瞬间引爆克拉肯体内的诅咒黑线，协助初诞者之力将污染彻底烧穿。
- 若林恩不放出小丑协助而单靠王戟强行净化克拉肯，则初诞者之力与弑利亚的远程控制会在克拉肯体内剧烈拉锯，突围时间窗口被大幅压缩。
- 若林恩在接连解放两只王兽导致灵魂重负滞涩时强行尝试净化第三只，则识海剧痛会令他动作瞬间变形，噬神者不得不拼死撞开敌兽将他甩上克拉肯后背。
- 若林恩在撤离前将约四分之一初诞者之力灌注进噬神者体内并嘱咐它「活下去」，则巨鲨全身刀刃化生狂暴机械巨兽，双瞳猩红地转身独挡群兽追击。
- 若林恩在克拉肯破水疾驰甩开追兵后立刻取出船长留下的深海罗盘，则罗盘微光会笔直指向更深地下的大峡谷，锁定康斯坦丁本体沉眠的方位。
- 若林恩在峡谷上方要求克拉肯掉头回援噬神者、自己独自下潜，则这头刚恢复自由的异形王兽会用触手执拗地拽住他胳膊放回背上，化作半人半兽刀刃形态陪他一跃而下。
- 若林恩随克拉肯冲入大峡谷最深处时先以咒瞳远眺深蓝结界，则他能提前看清结界外密密麻麻的污染骑士口袋阵与城墙上颤抖守望的鲛人眷属。
- 若林恩在看见口袋阵成军合围的瞬间便握紧王戟收敛外溢气息，则外围受控王兽转头的时机慢上半拍，为克拉肯下一刻的闪电冲阵争得先手。
