# E181·禁欲监护与诅咒失控排查·if线

- 若林恩在街头拔刀立誓之前先把刀刃抵在自己下胯的毯子上威慑一遍，则左左被这份认真吓到后退三步、第一次没接「不可能做到」的吐槽，事件以不变形收束但监督仪式整体严肃化。
- 若林恩在百日禁欲立誓时主动追加「每破一次就给左左一万骷髅币补偿」条款，则她瞬间拔刀抛向半空鼓掌同意，事件以变形（罚金条款）收束，监督动机加入利益因子。
- 若林恩拒绝接受「戒涩」系统任务、对系统叫骂「我是那种随意立誓的人吗」，则系统直接把倒计时改成无法撤回的常驻状态，事件以变形（被动立誓）收束，始动日仍照样记录。
- 若林恩让尹依在立誓现场作证并按手印签字，则她在血雾来袭前先默默记住公证人身份，事件以不变形收束但禁欲证据链首次有了第三方背书。
- 若林恩立誓完立刻让左左把夜魔刀收回去改用咒纹烙印在他左手背，则她放弃天天挥刀监督、改以感应式警戒，事件以变形（监督改烙印）收束，原作「斩作案工具」威慑被软化。
- 若林恩强忍欲望不拉扯左左、改把冲动发泄到汉堡店宰割仪式，则原作拉扯失败五分钟的纪录被改写为「一小时爱抚下厨」，事件以变形（转化发泄对象）收束。
- 若林恩用咒术在自己下腹设一道咒纹锁、一旦起冲动就会钻心痛，则他能够撑过最初五分钟、第一次打破原作的翻车纪录，事件以变形（咒纹锁欲）收束。
- 若林恩在街头对左左低声说「至少今晚让我以主人的身份惩罚你一次」，则她犹豫三秒之后仍旧摇头，事件以变形（求欢被婉拒）收束，禁欲第一夜以冷睡结束。
- 若林恩拉扯时输得惨烈、反被左左压制在轮椅上大快朵颐，则「主动方」纪录首次出现反转，事件以变形（左左反压）收束，诅咒失控排查进程未受干扰。
- 若林恩把疯狂对轰回忆当成决意燃料、在血雾来临之前让自己进入冥想状态，则他能够跳过推倒左左的冲动而保持平静，事件以变形（冥想稳定）收束，双源污染压制取得临时进展。
- 若林恩在血雾抵达瞬间直接把左左和尹依先后送入系统空间隔离，则她们错过爬行者初登场，事件以变形（随行隔离）收束，全部被卷入实战视角失去。
- 若林恩在左左挥刀之前提前以咒瞳把她扮演兽锁定在自己大腿上，则她无法自由拔刀，事件以变形（左左被锁）收束，监督效率减半、血雾路线由他独挑。
- 若林恩立誓之后立刻找尹依传授「欲望情绪观测表」并请她打分监督，则她第一次以「记录员」身份加入监护团，事件以不变形收束但她的人设在监护档案上多一笔纯净。
- 若林恩在拉扯拉锯时刻意把左左抛入一位女夜医怀里，则她被事发突然的女夜医抱住僵在原地，事件以变形（左左被托管）收束，街头监护链加入第四位成员。
- 若林恩拔刀立誓未完、血雾先把大街吹得睁不开眼，则仪式被实时打断，事件以变形（立誓被打断）收束，百日禁欲延后到爬行者事件后再补立。
- 若林恩把每日奖励的骷髅币预先划分一半给左左作为「监督辛苦费」，则她由被监督方转为「共同受益方」，事件以变形（利益绑定）收束，监督动机掺入合谋味。
- 若林恩强横反向声明「禁欲是我个人修为，不需要任何监督」，则左左罕见皱眉表态「那你上次也这么说过」，事件以变形（拒绝监督）收束，五分钟翻车几乎必然。
- 若林恩在大街拉扯时顺手对尹依示意「你也要加入监督行列」，则她红着脸从旁掏出小本本打算记录，事件以不变形收束但监护团阵营首次人齐。
- 若林恩在百日禁欲立誓完成后临时改口「我现在只禁七日」，则系统沉默三十秒之后接受修订、任务面板倒计时长切换，事件以变形（周期下调）收束，每日奖励同步折算。
- 若林恩在血雾来临时让左左第一时间拔刀站到自己身前担任盾牌，则她以战斗姿态把监护任务转化为同行作战，事件以变形（监督转战斗）收束，五分钟翻车戏剧化延后。
- 若林恩在立誓现场故意向街道尽头高喊「我林恩不是那种人！」三遍，则他引来远处一只小恶灵转头围观，事件以不变形收束但禁欲名义首次在公开频道被嘲讽。
