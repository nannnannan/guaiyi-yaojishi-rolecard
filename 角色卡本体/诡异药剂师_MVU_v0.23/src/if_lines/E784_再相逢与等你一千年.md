# E784·再相逢与等你一千年·if线

- 若林恩在织梦拒绝未来身份时主动放弃说服转身离开，则织梦会在他离开后数日内独自凝视黑火灰烬，最终主动追到冬泉谷边缘。
- 若林恩选择把冬泉谷的限制圈扩大成整个山脉而不是一谷，则织梦的自由度提升，但灵能恢复速度会被稀薄一半。
- 若林恩主动把自身黑火完全留在谷外由左左代管，则织梦能在完全无未来干预的状态下恢复，但林恩失去黑火也意味着他无法在谷外应对突发威胁。
- 若林恩放任织梦多次离开冬泉谷再任由她被限制拦回，则每次拦回都让她对限制的抵抗减少一分，E785 她会对林恩说「你的城池比我自己更严」。
- 若林恩在千年桥接中主动把某段自身人生放进织梦可读取的梦境池，则织梦在 E785 进入凡人城市前已经预知了林恩的童年。
- 若林恩主动在谷中为她亲手搭建一间药房而不是只留她独坐，则织梦会忽略那间药房一年，从第二年起她每月进去一次，E785 时药房四壁挂满她晾晒的叶。
- 若林恩选择让喵喵常驻谷中陪伴织梦而不是自己，则织梦会把喵喵当成唯一可以呵斥的存在，喵喵被她揪耳的次数成为 E785 之前的笑料档案。
- 若林恩主动为她每日送一餐凡人吃食而不要求她回应，则第一千天后织梦第一次回送一颗她自己摘的果实，那一刻被视为千年桥接的里程碑。
- 若林恩让左左在谷外制作一面可以透视谷内的单向镜，则林恩能偷偷看到织梦的脆弱瞬间，但织梦最终会发现那面镜子。
- 若林恩主动要求织梦在谷内不可自伤以保灵能完整，则织梦第一次用咒术回道「我不是你的藏品」,但他们的对话从此多了一条禁区。
- 若林恩在某一夜主动在她门外坐下不入内只低声哼一首主宇宙的摇篮曲，则织梦在那一夜失眠到清晨，从此她的梦境里多了一段她一开始没听清调子的歌。
- 若林恩选择在织梦突破关键时刻主动把自身的某段失败记忆打回去给她作为反面教材，则织梦要直面林恩最不堪的一段过去，两人的关系在那一刻被迫走向更深。
- 若林恩放任冬泉谷的限制被空白裂痕轻擦一次而修补，则织梦会感知到外界追兵的接近,E785 她会主动要求加快速度而不再抗拒。
- 若林恩主动给她一把利刃让她可以自卫也可以在失控时给他一刀，则织梦会收下但从不出鞘,E788 她把刀还给他时刀身已有她体温的痕。
- 若林恩让她灵能恢复期间主动分担她的疼痛，则他会因为共感而在每天夜里咳一口血，但他从未告诉她这血的原因。
- 若林恩主动在千年结束前最后一刻开口问她「你会跟我走吗」，则她会用一整夜来回答，最后的答案是她在 E788 告别时那句未曾说出的话。
- 若林恩让冬泉谷的时间流速差更激进——一日十年——则千年压缩到百日，但织梦的灵能会因过载在第一年就濒临崩裂。
- 若林恩完全不在谷中出面只让左左陪伴，则织梦一共只与左左交谈十句，E785 她见到林恩时会把他当作陌生人重新打量。
- 若林恩主动把空白实体追杀她的影像也展示给她看，则织梦第一次真切感知到「未来林恩在保护什么」,她删除掉一半对林恩的戒备。
- 若林恩选择把冬泉谷作为最终告别地点而不告诉她，则她在 E788 会在原地站一整个季，那片冬泉从此多了一份她专属的孤独。
