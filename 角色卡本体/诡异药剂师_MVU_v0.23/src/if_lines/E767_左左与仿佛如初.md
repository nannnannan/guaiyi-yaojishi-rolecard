# E767·左左与仿佛如初·if线

- 若林恩在伊甸园般的金色秩序梦境中陪回光返照恢复少女容貌的羽毛笔一同重建黑夜城、命运神国与地狱初见时的小书桌，则两人在最后的时光里重温了相识以来的所有美好。
- 若林恩顺从羽毛笔的央求变成两人初见时那只黑白相间的狸猫、任由她抱在怀里逆毛猛撸并倾听她诉说当年他沉默不理她时的恐惧与孤独，则他用柔软的猫爪轻轻拍了拍她的手背以示安慰。
- 若林恩在少女羽毛笔坐在书桌前执笔书写以小狸猫为主角的新冒险故事时，恶作剧地在稿纸上踩出两个梅花印并叼起她的羽毛笔夺门而出，则身后立刻传来她欢快的笑骂声：「坏猫！快把我的羽毛笔还给我啊！」
- 若林恩化作黑白狸猫跃过走廊拐角、舔着爪子等待身后追逐的少女，却发觉走廊突然陷入死寂——羽毛笔已在最欢快的追逐欢笑中化光消散——则那种从极致欢愉坠入冰冷虚无的剧痛瞬间击穿了他的心防。
- 若林恩以孤单狸猫的形态坐在高高的屋顶上叼着那根遗留的羽毛笔，对着蓝天撕心裂肺地大哭大叫「把羽毛笔还给我！我还给你了……你也还给我吧……」，则这场迟来的恸哭将他压抑了万古的悲伤彻底宣泄而出。
- 若林恩在现实虚空中守候沉睡的左左听完梦里羽毛笔最后的温柔嘱托（「在他疯的时候要拉住他，他要是还执着地回想着大家，那就一个大嘴巴子打醒他！因为只有左左在，他就还有那个家」）并睁开双眼，则他在泪光中迎来了这世上最后一位亲人。
- 若林恩在苏醒的左左看着他满头白发与沧桑面容、得知百年间全员战死牺牲的真相而放声恸哭时，轻轻将她揽入怀中拍背安抚，则两人相依为命的羁绊在此刻坚如磐石。
- 若林恩带着左左回到空无一人的黑夜城，在中心广场上亲手为所有逝去的家人立下一座座铭刻名字的丰碑，则每一座丰碑都成为他们发誓要将大家接回未来的庄严路标。
- 若林恩向哭肿眼睛的左左伸出左臂发出邀请，听她高喊着「我们从很早以前开始，就早就已经是共犯了！」重新化作他的左手，则熟悉的共生脉搏瞬间传遍全身，一切仿佛如初。
- 若林恩在此后静坐观察体内黑火、被左左误会成又在黯然神伤而一记头槌或大耳光子扇过来打断时，哭笑不得地捂着脸跟她拌嘴，则孤王身上那股令人窒息的死气被左左彻底敲碎。
- 若林恩在夜晚篝火旁恶作剧地往左左的烤肉上洒满变质农药（杀虫剂）、看着贪吃的左左被药得口吐白沫翻白眼，则这熟悉的日常整蛊让冷清的黑夜城重新响起了久违的欢闹声。
- 若林恩在扛着口吐白沫的左左往回走时骤然驻足，望着身后跳动的篝火与肩头吵闹熟悉的女孩，任由两行滚烫的热泪滴答滑落，则他在历经万古沧桑后终于真正找回了身为人类的眼泪与温度。
- 若林恩将屋顶上叼回的那根羽毛笔贴身珍藏在胸口衣袋内，则每次他在战斗或修行中按住胸口，都能想起伊甸园里那个追着黑白狸猫笑骂的明媚少女。
- 若林恩在黑夜城广场立碑时将血锯老师、人偶夫人、人偶小姐、主母、智械小姐与艾雯爵士的碑位依次排开，则左左在一旁难得安静地陪他献上一束束白花。
- 若林恩在左左扇完他耳光后没有动用半分神王防御而是结结实实挨下，则左左虽然嘴上骂他「凑脑袋」，左手却悄悄揉了揉他被打红的脸颊。
- 若林恩在篝火旁落泪的瞬间没有背过身去掩饰，而是任由肩头的左左装死眯着眼偷偷看他哭完，则两人之间那份无需言说的默契与温柔达到了顶点。
- 若林恩在重获眼泪与人性温度后再次内视己身，发现原本冰冷暴虐的终焉黑火竟随着心境的软化而变得如臂使指，则羽毛笔用生命换来的这步棋真正救活了他的道心。
- 若林恩在伊甸园梦境消散后保留了那张踩着两个梅花猫爪印的未完稿纸，则他约定等打赢最终一战后，一定要让归来的羽毛笔亲手把那个小狸猫的故事写完。
- 若林恩在黑夜城的日常起居中重新捡起药剂师调配古怪药水的爱好（专门用来逗左左），则他在大战前夕的心态始终保持着鲜活的张力。
- 若林恩与化作左手的左左在夜空下击掌为誓、约定一起杀向时代的终末，则这对“生死共犯”正式开启了将整个金色梦境转化为终焉黑火的最后冲刺。
