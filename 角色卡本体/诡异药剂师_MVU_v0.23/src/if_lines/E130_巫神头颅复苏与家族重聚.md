# E130·巫神头颅复苏与家族重聚·if线

- 若林恩不消耗强化卷轴、只靠小小安抚与玩偶隔离，则变形条件接管，巫神只部分清醒，复发风险保留，盟友行动权不授予。
- 若林恩声明消耗卷轴、新增一次【限时诅咒清除】，则默认结算成立：暂除35%，二十六小时计时与十三小时冷却如实入账。
- 若林恩提前强化清除但暂不出手，把卷轴留作下一场战斗筹码，则同步伤害照原作成立，他承担被拖行全部风险。
- 若林恩用巨像之心挡玩偶，则首次同步创口由巨像之心承担，万机长啸压成闷哼，巫神首次停手推迟半拍。
- 若林恩把机械龙玩偶拽到怀里当替身，则「邻居」标记改落他本人，万机远程受创压力大幅减轻。
- 若林恩放任细线绞索拖行，则默认走向成立，他被拖成吐白沫的风筝，巨像之心抢救的紧迫度如实入账。
- 若林恩拖行中硬撑补话给小小或艾雯，则清醒时长延长，巫神杀意节奏被打成两段。
- 若林恩认出瞬间表态「她没有伤害小小」，则慈爱配比偏移一档，「我疯起来特别坏」的愧疚宣言不打折。
- 若林恩主动自我介绍而非等小小补刀，则初判从「被拖的风筝」调到「敢说话的药剂师」，巫毒探测顺位上调。
- 若林恩把贴近巫神的玩偶换成人类少年玩偶，则「认出」时刻推迟半拍，细线绞索暂不成立。
- 若林恩立刻指认泰坦玩偶「不是他」并把机械龙推前，则默认转移成立，万机脖颈旧创的阴狠断言保留。
- 若林恩不指认泰坦玩偶，则泰坦被远程巫毒迁怒，与林恩关系被波及，态度从冷漠转自守备。
- 若林恩替小补刀「除了我和他之外都戳烂了呢」，则该句改由他口出，巫神对他的避讳度降一档。
- 若林恩私下告知艾雯准备援护小小，则艾雯介入节拍提前，巨像之脑误伤风险被均摊。
- 若林恩不向巨像之脑预警，则默认误伤成立，【巨像的双生子】对巫神态度推到敌对。
- 若林恩后撤只留母女重聚，则他被标为「缺席者」，单独对话巫神的难度上调。
- 若林恩布【狂乱压制雾】临时措施，则戳刺节奏被打乱，雾散即复发，事件按部分清醒结束并记一次反噬。
- 若林恩顺口对巫神加「我可以帮你」，则标记从「可牺牲」调到「可利用」，个人风险敞口扩大。
- 若林恩声明不介入她对万机的远程巫毒、只保不伤己方，则【巫毒准备成立】入账，赛博与巨像对她各记一笔保留。
- 若林恩用血肉手术刀斩断细线暴力介入，则巫神狂状态转移攻击顺位到他，事件变形为「巫毒失控·林恩正面受击」。
- 若林恩承诺不告诉万机巫神的存在，则记入一份隐瞒合约，对林恩的强制利用概率上调一档。
- 若林恩立刻声明「你需要长期压制计划」，则她记下求助级好感信号，E131 母树引子让出一句发言位。
- 若林恩不宣告后续、只带小小离开，则她作为「半醒失控盟友」入账，万机逃离窗口压窄一档。
