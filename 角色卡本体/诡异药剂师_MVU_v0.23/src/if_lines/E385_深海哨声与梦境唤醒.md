# E385·深海哨声与梦境唤醒·if线

- 若林恩在艾雯准备开始切割过去与现在的联系那一秒主动拦住并说「让我最后打招呼」，则她有一句话的时间，但切割线仍持续推进，留下一道「他没说再见」的精神裂痕，后续重逢时她以微弱责备回应。
- 若林恩在竹哨精神尖啸响起之前先用左左的尖啸震慑全场，则黑弦月深层意识被波及的恐惧情绪压倒求生意愿，哨声迟来一段，苏醒节点推后一日，救援成功率被影响。
- 若林恩在深层冻结期反向切断竹哨联系并选择完全自绝，则她的回溯找不到任何伴侣信物，梦境被解读为「被人遗弃的伪生活」，苏醒路径完全崩塌。
- 若林恩让艾雯同时启动两套锚点（现实病床+深层丝线），则接应成功率上升但艾雯现实身体崩坏一度，他需要被左左重新接线才能维持。
- 若林恩在哨声回应时突然唱出她当年在海岸听到的那首即兴小曲，则她与他丝线在深层连线被强化一成，苏醒后第一句她说的是歌曲名而非「我来了」。
- 若林恩拒绝切割过去的方案并提议让她深层人格整体回归现实，则艾雯警告「她的现实中人格」可能被深层执念吞噬，走向变形，存在两种人格共存的复杂身体状态。
- 若林恩在她深层挣扎反向看见一只小型左手像符号一样悬在她身边，则他把该画面记入档案并传达给左左，左左确认自己并未进入过那片场景，由此建立「幻境左手非左左」的关键分叉证据。
- 若林恩让左左在深层引爆一枚系统空间手雷强行破坏周边难攻意识肉脉，则肉脉被切出一道口子但黑弦月深层记忆被同时撕去一片，苏醒后她忘记一段重要旧名。
- 若林恩在深层以咒瞳反冲向她的精神剑芯，则她深层人格受伤剧痛，并在苏醒后第一时间射出一道敌意气波，重逢第一眼是敌视。
- 若林恩拒绝留在深层接应而改成单独与艾雯从现实病床反向观察，则深层感应中断十几秒，黑弦月深层意识一阵恐慌，她的锚点立刻失效需要重启。
- 若林恩在深层以医生立场诊断她求生意愿并下达正式康复计划书，则她深层形象短暂被「病人/医生」框架表达，亲密定位变形。
- 若林恩在她哨声响起瞬间以心声告诉她「你自由了，可以不必回来」，则深层静寂十几秒后她浅浅地指出「这不是自由，这是抛弃」，深层路程反向沉重。
- 若林恩让左左代替他走在深层丝线最前端以阻挡潜在敌意，则左左除了手边餐刀外毫无防备，她在深层道远端爆发出一声「让我回家」的呼喊请林恩感同，深层恐慌被精准激发。
- 若林恩在深层掏出系统商城一支助眠针并独白「让我睡一会儿」，则深层瞬间被绘制成「他也是昏睡的」，两人共沉，深层时间以双倍速度结算，外部方无法救援。
- 若林恩反向抵制求生而以咒瞳剖析她的「死去的美好」并捧她进入深层长眠，则深邃沉入死亡路径并触发 E383 全程变形「长眠」。
