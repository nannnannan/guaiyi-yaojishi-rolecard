# E562·机械战争与神皇伪装·if线

- 若林恩在挥手打开光门时主动出厂节奏拉慢两倍，则原子机械风暴蔓延变慢，全城改造时间被他自己推开，污染者近地轨道集群获得更长窗口。
- 若林恩在原子机械吞城时主动避开躲藏平民的衣物，则「光溜裸露惊吓喜剧」消失，平民从惊恐转为安心，但机械扩张速度减半。
- 若林恩主动保留中央大君雕像但用原子机械在它外面再加一层贵金属外壳，则神皇雕像被他自己保护成「私藏圣像」，认脸揭面具时的震撼力升级一档。
- 若林恩主动把城市改造成战争基地时保留一段古老街区不动，则边缘世界平民看见旧区与新厂共存，对神皇的好感不被「彻底改天换地」所干扰。
- 若林恩主动让原子机械扩产以「自保」为先，先建防御屏障再建攻击炮台，则战争开放性缺失，整场的进攻密度从「自杀式殉爆」退化为站桩防守，污染者近地集群有更多时机重组。
- 若林恩摘面具时主动先戴上一个伪装性更强的面具再摘下，则「真容与雕像一模一样」的揭示被两层面具隔开，守卫小队需要更长时间才看清楚神皇真面。
- 若林恩摘面具时主动保持沉默不语而不是说「我还是回来了」，则神皇临世的氛围从「归来宣告」变成「无言认脸」，守卫小队齐跪叩首的节拍放慢但更加虔诚。
- 若林恩在守卫队长颤问「您是……」时主动说「我只是路过的」，则神皇信仰不被他自己的话点燃，「虔诚狂信」守卫他只口头存在，守卫们当做一次幻觉处理。
- 若林恩在左左掐腕传音怒「暴露真面目不怕灾厄军队注意」时主动问她「那我用哪个面具更安全」，则装神的分寸被他自己把关，「长这张脸不好好利用白来一趟」的口径先在换上左左的头。
- 若林恩听队长口述「神皇边疆/原混沌领域更名」时主动追问改名的具体时间，则神皇信仰在边缘世界深入的历程被他拉出一条时间轴，「反神领袖死后成神皇」的讽刺被他看清。
- 若林恩听队长口述「九十七边王/七大边王/星炬塔」时主动让他把名单全列出来，则守卫队长进入被迫回忆模式，林恩手中的边疆局势从传闻变成百人花名册，情报获取升格。
- 若林恩主动让守卫队长把他认为是「机灵一点屌大一点」的全部喊出来，则林恩被一场关于王朝、马钦随手成立的宴请而随意带动的人际关系击中。
- 若林恩主动让守卫队长把莫名认出几个队友搞淘汰出来，则边王们疑云重重暗中俯视着他，林恩担心自己奥希决定破坏。
- 若林恩在信仰确立后主动不与守卫多谈而战毕立即删忆，则「一次性身份诈取情报」原则被保持彻底，神皇临世消息不扩散，灾厄／污染者注意力不被挑拨。
- 若林恩在信仰确立后主动留下一两个清醒守卫当线人，则神皇信仰在边疆保留记忆残余，「删忆昏迷」的不完整结果被他主动放开。
- 若林恩听队长讲完星炬塔边王议会后主动改变行程不再前往，则「传墙卡死在穹顶墙壁里倒吊如灯」的下一事件走向被根本性取消，主线重新定向。
