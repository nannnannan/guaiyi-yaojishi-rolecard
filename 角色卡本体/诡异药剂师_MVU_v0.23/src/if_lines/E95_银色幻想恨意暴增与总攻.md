# E95·银色幻想恨意暴增与总攻·if线

- 若林恩在听到专属 BGM 时先让左左把掌心收进袖中再抬头，则「巨像之心共振」不被同频万机之神投影捕捉，银色幻想落地第一帧只看到普通疫医轮廓。
- 若林恩不脱口而出「智械小姐都来了」而是先反问艾雯爵士「她机体型号见过吗」，则绿色光幕内那段闲聊被改写，银色幻想转头定位声音源的时机落空一拍。
- 若林恩把「我认识，我在地下调教了她一个多小时」压在心里不接话，则艾雯爵士只当他认得脸，银色幻想的恨意第一波缺少口头引信，系统恨意结算压在+10以下。
- 若林恩主动把鸟嘴面具装有裂痕的一侧转朝银色幻想方向，则她穿越战场锁定的是旧伤证物而非眼神，恨意+10照常但涩涩度+1没有触发。
- 若林恩推开面具露脸但不比剪刀手、只把左手搭在艾雯爵士肩上，则亲近画面先刺进银色幻想视野，恨意窜到+29之外再多一条「针对左左的敌视标注」。
- 若林恩在银色幻想望过来瞬间用夜医礼式单手抚胸微躬身，则礼式被万机之神同步收录进档案，恨意狂刷不停，但「挑衅」劣迹名单中多一条「可解读为礼数」的口子。
- 若林恩扭头对艾雯爵士说「她是万机之神独女」，则揭晓顺序变成林恩先念破、万机之神后承认，银色幻想捶胸那声「是，主宰」改在自尊被代答之后压出来。
- 若林恩当场朝银色幻想方向用口型念「地下」，则不发声的口型仍被她读唇拾取，恨意狂跳频率加倍，万机之神目光回扫光幕一秒才被母树咀嚼声拉回。
- 若林恩先朝欲望母树主干镜一管镇静药剂再关注战场，则银色幻想未被注意、恨意结算起步较低，但母树干内的咀嚼节奏乱一帧，四分之一投影妖冶笑脸首次真正朝他这一侧偏。
- 若林恩把左左从左手探出感知半秒再收回，则「王后」信号在万机之神投影扫描场中泛出一圈涟漪，祂破口训诫顺带改写为「记住还有身边人」，独女揭晓与身份警告同步打包。
- 若林恩当场对艾雯爵士说「那个机体让我摸一小时」，则内容被绿色光幕反弹回荡一次才被银色幻想听清，她单分子剑反光里多一道林恩的面具侧影，涩涩度+1之外多一条「耻感记忆强化」。
- 若林恩主动越过艾雯爵士光幕半步让全身暴露在银色幻想视野，则护盾外的粒子光束把他定成优先目标一轮，万机之神侧目光幕两秒，把「机械单位仍锁定他为优先目标」写进本事件档案。
- 若林恩不推面具不露脸、改只在光幕后竖起一根中指，则手势被绿幕放大一轮再投递，恨意照样冲天，但银色幻想铭记的画面只有那枚鸟嘴面，战后她誓杀的指令锁死面具。
- 若林恩朝万机之神投影打一记夜医诊断术，则面板在数据洪流里被瞬间解析，万机之神抬眼望来一秒再收回，林恩系统黑屏三秒，功德扣一格，恨意狂刷同期照常结算。
- 若林恩主动对银色幻想喊「地下那一小时你还记得多少」，则记忆被公开点名，她剑尖第一次真正脱鞘半寸，万机之神训话提前一句，肃正法庭警告外多一条「念及父女」的词。
- 若林恩朝光幕外掷一支以M药剂化作薄幕，则以M波动撞进欲望领域，母树咯咯笑节奏一滞、银色幻想机体表面行为分层紊乱十分之一秒，独女身份掩盖期被她本人身体反应意外撑开一道缝。
- 若林恩先把欲望母树干内咀嚼声抄录成【诊断】写进面板再传艾雯爵士，则赛博光屏上多出一份「她在吞己部众」通报，三主炮充能口号间隔一滞，总攻定格迟三秒。
- 若林恩当场举手对着全场比出「夜医礼」而非剪刀手，则「挑衅意图」在万机之神录档里从「劣迹」改写为「医学礼数」，恨意同样暴增，但银色幻想的誓杀誓言被迫加上「先破礼数」一句。
- 若林恩对着万机之神背影挤出一句「她是你女儿吧」，则独女揭晓顺序改写，银色幻想在全场先听到的是他而不是主宰，恨意顶端加一份「当众揭短」刻度，令祷词节奏错一拍。
- 若林恩把条件压到底、全程只凝视不语，则不露脸不挑衅，但银色幻想仍凭机体本能锁定他，恨意自然上行到+20附近即停留，涩涩度不变，战后她仍发誓但要先解开「他为什么不回我」这个扣。
- 若林恩主动朝母树主干再掷一支剧毒梦境剂，则她吞下顺药性的部众时意识短暂深潜一秒，欲望领域气场衰减一线，总攻齐射落点偏位数十米，诅咒之城废墟东北角多一片瓦砾未被初期压平。
- 若林恩在总攻号令前当众对银色幻想喊一句「战后我接你单挑」，则她把誓杀誓言在心底改写成「我要让他亲口兑现」，机体表面亮起独女徽记一秒再压回，万机之神目光第一次真正落到林恩光幕位置。
- 若林恩当场拒绝参战、启动门跳撤退，则独女揭晓与肃正法庭警告照常发生，但锁定定位落空、恨意+29与涩涩度+1未同时成立，本事件不构成完成，后续主链从「远程通报」改写。
