# E173·九次垫刀与史诗级咒瞳复原·if线

- 若林恩在半瓶猛毒下肚时主动追加一句「顺便帮我打包安葬费」，则艾雯与巨像之脑被这份自觉寻死的滑稽提示同时出声制止，事件以变形（毒性过量被叫停）收束，垫刀链条在第一步就被打断。
- 若林恩把绿瓶猛毒换成普通忧郁药剂、外表近似但毒性全无，则骨盆取样未被污染、盲修样本数骤减、事件以变形（垫刀弄虚）收束，九连败记录由模拟生成缺乏实证基础。
- 若林恩喝毒后当场吐血倒地不省人事，则四大根源被迫先救他，事件以变形（试验提前收尾）收束，咒瞳持续封存未修复、原作的第十次成功未发生。
- 若林恩调配垫刀药剂时刻意多掺一种配料「斯卡娜的骨灰」，则夜医侧对原始取样起忌惮，巨像之脑首次提出停止，事件以变形（新增反感成分）收束。
- 若林恩在第九次失败后举枪示意最后冲击，则四大根源反向断电阻止方程式触发，事件以变形（第十次被拦截）收束，咒瞳复原完整未发生。
- 若林恩在第十次高喊「咒瞳修复」时改喊「母亲啊赐我力量」，则巨像之脑被主母感应推入供能链路，咒瞳修复成功但成品添加一缕主母注视属性、原作「自主活动」另附「凝视主母」项。
- 若林恩复原成功后并未捡起落地眼球、反而吓得后跳三步远离，则眼球自己滚到他脚边被他无脚踢开，事件以变形（拒接复原品）收束，植入环节整体延后。
- 若林恩复原成功后第一时间把复原眼球吞入体内不植入眼眶，则咒瞳与身体内部系统产生未控融合，事件以变形（直接吞食）收束，下次命运骰测试时出现不可预估的新属性。
- 若林恩复原成功瞬间突然消逝没有生命体征超过一小时，则四大根源启动重大救急、抢救时段变形（复苏推迟）收束，原作半小时时限被打破。
- 若巨像之脑吐槽「赌狗赌输了」时被林恩听清并回骂「别说，我死了谁帮你治孩子」，则她被反暴雷击中语调陡增，事件以变形（反雷升级）收束，气氛从戏谑变成家庭矛盾支路。
- 若林恩复原后第一时间主动叙述「它在我手里活了」并递交眼球供鉴定，则四大根源共同接手异常样本，事件以变形（鉴定升级）收束，下一次测试不再是林恩单独控制。
- 若林恩复原时眼珠呈现「兽瞳」形态而非常规人眼，则复原品被判定为「魔改加强版的加强版」，事件以变形（品阶再次升级）收束，「植入眼眶」决策门槛升高。
- 若林恩在复原瞬间同时令双方咒瞳都重置，则另一只原本完好的左眼也被逆向魔改，事件以变形（双眼连带）收束，宿主从此背负病变咒瞳的复合风险。
- 若林恩喝毒同时默念五点命签期望，则垫刀链条被塔罗方向引导，事件以变形（牌术误导）收束，原作纯靠运气豪赌改写成「有方向豪赌」。
- 若林恩复原之后选择将复原眼球投入系统空间短期悬挂不植入眼眶，则事件以变形（悬挂储存）收束，命运骰点掷机制未触发，E174原始链条整体变更。
- 若林恩复原成功但成品眼球表现完全正常无自主活动，则事件以变形（无异常成品）收束，E174所有骰点机制整体不存在。
- 若林恩复原过程中某次失败时眼球滚落进他怀中主动贴上他胸口不离开，则事件早期埋下「复合咒瞳」伏笔，原作第十次成功被异物抢戏，事件以变形（杂合进化）收束。
- 若林恩第十次尝试前四处张贴「这次一定行」的祈福仪式，则垫刀链条从纯机械失败变成「带仪式感的失败」，原作黑色幽默方向加强。
- 若艾雯在第九次失败时提前从林恩手里抢过咒瞳碎片代替他执行第十次尝试，则修复成品与原作不同配方，事件以变形（代理修复）收束，命运骰点机制与灵能属性维度走向变化。
- 若林恩复原后眼球在他手心跳动、主动用细细触手和他指尖绞住，则事件以变形（认主涌现）收束，超越原作单纯被动观察、活性意识体提前诞生。
- 若林恩复原成功时主线金光展现出「多个人格」复调一击，则咒瞳被判定为「魔改精神分裂版」，事件以变形（复调品阶）收束，骰点范围扩展至不止六个点数。
- 若巨像之脑在供能期间临时把手抽出拒绝继续配合，则咒瞳修复在最后一公里因单一根源缺失而失败，事件以变形（临时退阵）收束，无法见证「史诗级复原」。
- 若林恩在复原成功瞬间立即起手动用左左把复原眼球封印进一个outer小匣子，则事件以变形（匣子隔离）收束，植入与测试均被暂时悬置。
- 若林恩复原之后立即拿起眼球朝着四大根源摆出「看」的姿态，则四人被这份扬扬自得惹到联手白眼，事件以变形（应酬气氛）收束，复原的严肃感被幽默稀释。
