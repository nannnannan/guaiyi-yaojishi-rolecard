# E416·时间之外的污染者·if线

- 若林恩在来客破门之前先用恶灵显形药剂朝门口洒一圈，则整扇木门会在药剂作用下化为半透明，来客畸形的身影先在门外被照出，林恩提前三秒看清他背上青铜钟的锈蚀纹路。
- 若林恩在来客跨门一步的瞬间预判式投出爆炸药剂，则来客躯干会被炸成四段旋回屋内，胸前紫黑眼睛短暂先于躯体显形，林恩能用血锯剔骨刀插进那枚瞳孔打到重伤。
- 若林恩率先用魅魔特制药剂喷向来客的口鼻部位，则这具紫黑躯体会被药剂之力缠绕成三秒麻痹，但随即其体内污染核心借药性反扑，林恩的咒瞳会被烙印上三道紫黑血丝视为代价。
- 若林恩用强效腐蚀药剂朝来客胸前的紫黑眼睛直接喷射，则瞳孔会被腐蚀出一个汩汩冒液的小洞，来客发出刺耳如婴儿啼哭般的长鸣，林恩可乘这瞬间用原初之力贯穿那洞。
- 若林恩决定不下杀手、只用腐蚀药剂压制来客四肢让他跪地，则来客残存自我会获得数秒清醒间隙，他会握住林恩的衣角抽泣着请求「把我的钟带回给那位大人」，他给出一项可选遗愿。
- 若林恩在雷声中忽然放声大喊「血锯三月前已下葬后山」稳定来客情绪，则来客涣散的眼睛会短暂对焦到他脸上、停下手里的破坏，他从怀里颤抖取出一封未寄出的羊皮信递给林恩作为移交。
- 若林恩让污染意志附身的紫黑眼睛与克苏鲁之眼正面对视一秒，则旧店时间场域会出现一瞬的凝固与重影，两股力量互相映照、谁也不相让，那一秒把远在三年后的左左眉心也刺出三道冷汗。
- 若林恩在战中被逼到柜台死角时选择手持剔骨刀以脉动血肉模拟魂壳共鸣引燃原初之火，则他成功在旧躯上点出指甲盖大的金紫火焰，但那道反噬随之而来——他会呕出一口沾咒纹的暗色血液。
- 若林恩用咒瞳扫过污染核心同时持原初之力成拳击向核心，则核心在被打散的瞬间会发出一声非人的女人哭泣，待声音散去，林恩的左手掌心多出一枚米粒大的紫黑晶渣，事后黑堡将其定性为「样本·代号『落泪』」。
- 若林恩胜利之后为来客尸身套上一张干净的床单并就地掩埋于旧店后院，则半夜来客会以腐蚀的形态从潮土里短暂复活数秒，他在那一秒向林恩深深躬身表示谢意后才真正烟消云散。
- 若林恩在来客表述「不想杀人」时主动报出自己姓名林恩、并说明自己便是被血锯赏过的某位少年，则来客深陷痛苦地呜咽并请林恩务必逃走，他已被污染意志挤压得只剩最后一丝清明。
- 若林恩为来客临时清理时决定注射一支夜医急救恢复剂试救，则来客病情会有短暂好转、甚至能摇晃着站起来道出最后遗言，但污染核心会以更剧烈音调反噬林恩咒纹，事后他腿上多出三道永久紫纹。
- 若林恩在检查来客身上材料时拾取到一枚锈迹斑斑的怀表并打开，则怀表内层会映照出三年前血锯照料年幼林恩的残碎画面，林恩对这枚小物审视良久才揣入怀中决定日后追查血锯真相。
- 若林恩决定把来客留下的青铜钟带回黑堡进行分析，则钟面会在他碰触的瞬间忽然以古钟之声清鸣三下，在场所有夜医的咒纹都会短暂共振，事后核验中多一条「时间钟音唤醒残魂」的记录。
- 若林恩决定将来客的尸体和污染源用原初之火彻底焚烧，则当院土地会在三日内长出一株稀有骨肉互馈的花芽，这株花芽事后被黑夜城药理组命名为「青溅藤」，列入珍稀药材目录。
- 若林恩在灭敌之后没有立刻追查钟塔、而是回到旧店把每一页的药剂台账都翻透，则他会在第三页找到一张被随手涂鸦的钟塔底层通道图，这张图直接帮他在 E417 中节省了绕路两小时。
- 若林恩在灭敌后用拟化把整场战斗以影像方式录成一枚塞耳玛瑙戒指作为证据，则在回归黑夜城后他把戒指递给艾雯爵士，爵士第一次看到「时间污染者」的本象、对他的警觉级别临时上调一格。
- 若林恩在灭敌后执意用旧链锯切断那位来客的青铜钟作为刀具埋葬，则链锯会在切割钟体的瞬间忽然被紫黑引力卡住、锯齿逆卷划破林恩的手腕，他学到「邪物不该随意拆解」的教训。
- 若林恩在旧店内战后用原初之力把整间店铺的腐朽气味净化到能居家水准，则门外的旧雨随之变柔，下一刻那具青铜钟自发从地下室飘上来敲响一记送客钟，告慰林恩不再孤守三年。
- 若林恩在战斗尾声消耗掉整整三支腐蚀药剂之后仍无法伤到污染核心，则他迫不得已连续动用旧身后院那把血锯剔骨刀作最后一击，刀刃刺入的瞬间他自己也会因反冲力在后墙留下血印脱臼。
- 若林恩在被污染核心的第一波紫黑雾团扑向面门时及时取出一支爆炸药剂反手自伤换取机动，则他拼着自己胸口重伤把雾团撕出一个口子，事后这道炸开的伤在 E417 里也成为他不破的耻辱印记。
- 若林恩在消灭核心后用咒瞳定格来客尸身以留给未来自查，则他在回归后开幕那枚影帧时会看到来客的手心里凝着一个极小的木头木马——血锯曾送给婴儿林恩的第一件玩具。
- 若林恩主动出击将来客的青铜钟从背上强行扯下、以它抵挡污染核心的最后一击，则青铜钟会以共鸣之力替林恩承受一半反噬之力，钟面自此多了一道被原初之力永久蚀刻的紫斑作为勋章。
