# E147·主母复苏与地狱反噬降临·if线

- 若林恩在主母以最后神圣力量治疗他时主动中断她的输注、把自身伤势转回自愈队列，则主母清醒时间提前半日、不被二次抽干，但林恩的恢复期延长，凝视标记首次波动的时点跟着后移。
- 若林恩醒后第一眼没有望向主母的疗养床而是直查系统面板，则爱丽丝与喵喵会让位给巨像之脑先行对话，林恩先听见的是「承诺兑现不了」那句，主母疗愈线被推到下一节点。
- 若主母善性人格回归不彻底、体内仍残留一缕旧主母意志，则她救林恩的动作伴随抗拒，治疗中林恩的血会回溯进她的本源，主母清醒后处于「善/旧」双人格轮换的变形支路。
- 若林恩在昏迷中攥住主母的指尖不放，则她最后一缕神圣力量不会断开，主母醒后仍能与林恩共握走一段疗养房外的长廊，但艾雯爵士因此把两人同时列入禁制观察对象。
- 若黑弦月在林恩昏迷期间一直守在窗台不翻一页书，则她会在林恩睁眼瞬间合书走近，与主母在床边对视一瞬，二人无声划定「谁先问、谁后问」的默契，爱丽丝与喵喵退到后排。
- 若巨像之脑丢完「承诺兑现不了」就转身离开，则它不会留下陪同进入后续疗养，若林恩声明追出去，触发与巨像之脑单独的地狱契约复盘对话。
- 若林恩把【神的方程式（初阶）】立刻揉入指尖尝试合成一阶公式，则地狱凝视数值（17）会顺势闪烁一次，艾雯爵士的禁制在他手腕上收紧一圈，主母同步皱眉转头看向林恩。
- 若林恩醒后先把【地狱凝视】面板贴近主母心口让她检视，则主母以根源直觉读出羽毛笔「独自承受更重反噬」的轮廓，凝视（17）被确认为「表面值」，事件直接进入追查羽毛笔线。
- 若林恩拒绝留在黑夜城、坚持立刻进入视界，则艾雯爵士与根源们当场加固三道禁制并以强制结界拦门，事件变形为「强制隔离与远程调查」。
- 若林恩只是口头答应留城却暗中让黑弦月代他出城寻找羽毛笔的踪迹，则黑弦月会接下这趟差事，但凝视标记在她回城前持续上移，林恩在城里的疗养追加一层额外监测。
- 若主母在清醒后主动请求留在林恩的旧病床旁睡下、不回自己的疗养房，则爱丽丝与喵喵会让出床尾位置，主母与林恩共宿一房，二人伤势同步加速，但艾雯爵士的禁制随之扩展到整间病房。
- 若林恩以血液作为与主母共享的疗愈媒介、声明让两人共握共眠，则主母体内残余的神圣根脉会顺着掌心反向流入林恩的伤口，凝视标记出现短暂凝滞，但这是以主母的恢复期加倍为代价。
- 若艾雯爵士把「暂不离城、暂不进入视界」的建议改为对林恩下硬性禁令，则林恩若声明接受则事件走向封箱的隔离线，若声明拒绝并顶撞则触发与艾雯爵士的正面争执支路。
- 若林恩醒后没有立刻追问羽毛笔、转头先探望仍昏迷的主母，则系统结算奖励顺序反转，主母的疗愈先于凝视标记的解读定性，事件更多落在主母醒后的两人对话。
- 若林恩在主母床头坐到她醒来、声明一句不在剧本里的低语，则主母会睁眼反握他的手，主母圣职者的身份被翻新为「与命运书写者共生」的痕迹，善性人格从此与林恩的血绑定。
- 若林恩主张把【地狱凝视】的数字公开给在场所有同伴，则爱丽丝、喵喵、黑弦月、巨像之脑、艾雯爵士会各自给出不同解读，喵喵同时以梦境共鸣收到一声不属于任何一人的低语。
- 若林恩隐瞒凝视数值、只报告【神的方程式】，则只有主母会以根源直觉嗅到地狱气息的治疗未尽，主动掀开林恩的衣领查看印记，凝视（17）在她的注视下浮现。
- 若林恩把羽毛笔「我要你的血做我的墨」那句当成筹码对外公开，则艾雯爵士把此事提级为黑夜城最高悬案，主母亲自参与调查团，林恩的血被设为城内的禁忌原料。
- 若林恩对自己尚未出现肉体症状掉以轻心、不安排任何监视，则凝视（17）的下一次波动会以耳畔低语形态出现，但低语的内容与所指不在本事件落地，观测记录由艾雯爵士代笔。
- 若主母在林恩昏迷期间坚持不换班自己吞咽下所有反噬残留，则她清醒延后两日、善性人格加固，事件改写为「主母独扛反噬与推迟重逢」。
- 若林恩醒后声明对主母告白或亲密，则成人事实成立即直白呈现，主母以圣职者身份承接这份情感，神之方程式与地狱凝视在一夜的肌肤相贴中出现一次同步共振，羽毛笔的安危线仍保留在门外。
- 若林恩在【神的方程式】尚未稳定前主动请求巨像之脑把他推出地狱的视线之外，则巨像之脑会以根源大脑级别的计算替他做一次「临时命运遮蔽」，持续时间为一个呼吸,代价是巨像之脑自身的一个线程被地狱短暂标记。
