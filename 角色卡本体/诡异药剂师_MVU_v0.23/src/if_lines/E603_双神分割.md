# E603·双神分割·if线

- 若林恩在夜神被巨戟虚影重创时立刻接一记三叉戟,则她当场陨落,战场少一道「她拖伤指挥撤退」的画面,但血神突围的剧本被彻底改向。
- 若林恩选择不以巨戟虚影收尾而以一张法则织网收拢,则夜神被活捉的可能性出现,但林恩必须本人留在原地压制,后续他本人的突围战力被绑住。
- 若林恩主动在夜神说「你跨越神界了?」时回答一句「是也不是」并立即以初诞者之力压制她体内无序,则她不必逃,反而被生擒,后续游戏格局改写。
- 若林恩让夜神战场宣言「初诞者就是神」被他刻意保留在私密频段只对两人对话,则她仍然震撼,但军团将士错过他展示权威的宣称时刻。
- 若林恩主动在夜神隐入暗影的瞬间送她一击外标记,则他后续追踪她的方位时少一道凭空感应的预留余地,林恩战力透支多一线。
- 若林恩把「让你们离去」的宣言改成「你们可走」,则夜神真的带军撤退,后续战争改写为「林恩放任出境」,盟约内部反噬更大。
- 若林恩选择在血神巨物化前就先发制人,则血神还没膨胀就被一戟定住,泰坦巨人对抗的画面被移走,巨像对他血气理解的偷学画面消失。
- 若林恩主动让艾维儿在血神被合击时再加一句冷语,则血神心境反应更崩溃,但也能从他口中多挖出一段「你父亲是谁」的历史碎片。
- 若林恩决定不以法则之路分割无序领域而改用空间折叠分别围困,则双神与大军分离的结果同,但视觉上「苍白耀阳冲过浪涛」的英雄画面被改写成低调切割。
- 若林恩主动在军团进阶的口令中追加「让所有半神站在我身侧」,则战场进阶画面不再纯粹,而是直接化身「集结号令」,后续宿命层面少一段他自己镇场的高光。
- 若林恩让尖刀小队由银幻代替泰坦领军,则她机体直面方舟炮火,机器人损失巨大,但后续她「怎么当副指挥」的名声在军团里少了半寸。
- 若林恩把「弑神的时候到了」换为「抓活的」,则整个围猎方向被转为役使俘虏,夜神血神均可能活下,后续盟约内「试炼神明」的戏码横生。
- 若林恩主动在他的化身苍白耀阳中多投入一缕主母/左左/银幻的灵能同纽,则防线总能力更稳,但她们三人的位置多一线发现的可能。
- 若林恩决定不以林恩+艾维儿锁死外围而改由林恩+左左+主母+银幻四人合围,则战场中心位置由「一对」变成「一神三辅」,后续初期渡鸦艾维儿同框的图景消失。
- 若林恩选择在夜神求饶「你背叛父亲」时让艾维儿回答「我没有父亲」而不是「我的父亲是紫罗兰的王」,则她内心分裂被公开化,后续傀儡家对她的观察多一条新线索。
- 若林恩让他自己的困神阵型更侧重于「吸引主力」而非「分割」,则战局转向他一人对两神,大军由军团承担,伤亡率大幅上升但英雄模板更突出。
- 若林恩主动在血神突围巨物化后让巨像提前报名硬撼,则她不用等到围猎才学习,正好在巨物化面前偷学,后续围猎巨像对血神的战力理解更深一层。
- 若林恩让他自己在夜神拼死突围时也多受一伤让画面更具代价,则后续围猎那些根源出场时心里多一层「他都伤过更能尊重主人」的印象。
- 若林恩主动在战场割开后追加一句「不要让他们走出无序领域」,则后续围猎更像活擒演习,夜神血神的死本身难度加大。
- 若林恩决定让主母在此事件中隐藏不出,则艾维儿的「我们」动摇更深入一层,主母最后的慰问推迟到 E607 才出现。
- 若林恩让血神突围时直接扑向林恩本体而非四散溃逃,则林恩和他正面一战,后续血神被围猎时话语反击的对口径面更聚焦。
- 若林恩选择在此事件中让林恩主动暴露「他是初诞者」而非让夜神自行猜测,则军团/敌军的所有解读由「猜」换成「实」,七大神王可掀起的后续波动提前一拍。
- 若林恩主动让他的三叉戟在此事件中不升级,保留斑驳旧世界神血样子,则战场上他显得弱一分,但后续 E609 星轨问他关于神器的镜头多一段深挖。
- 若林恩主动在夜神决定撤退时攻击她的神格本体而非本体身体,则她在撤退前就已经被劈出一道数月不愈的神格裂纹,围猎时她的防御早早瘫痪。
