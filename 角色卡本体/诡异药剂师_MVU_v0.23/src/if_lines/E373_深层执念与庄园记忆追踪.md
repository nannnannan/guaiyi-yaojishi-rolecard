# E373·深层执念与庄园记忆追踪·if线

- 若林恩在自缚天使劝说时主动接过话头说出「先尊重她的节奏」，则艾雯不必反复强调苏醒征兆，档案揭示改走「人偶夫人主动展开」路线，执念讨论延后一拍。
- 若林恩在听艾雯报告前就先把灵能压回自己掌心、不再下潜，则本轮追踪停在「外部诊断」档，深层执念那条线被记下但未揭法阵，下一轮进入需玩家重开条件。
- 若林恩主动要求艾雯把「活着等于折磨」的执念权重画成可见曲线，则执念首次出现量化刻痕，后续治疗路线可对照曲线检验而非凭直觉。
- 若林恩当场翻看人偶夫人递来的家庭记录只读批注与日记、跳过人偶师手记，则教育细节缺失，紧接其后的归家记忆片段里出现手册才会补盲。
- 若林恩选择让爱丽丝或左左任一位陪在他身边一起记录观察，则「执子同伴」位置多一名，但人偶夫人在档案上只盖一枚陪同印。
- 若林恩在黑弦月归家记忆里主动凑近她伞沿下那本厚书想看清批注文字，则他的意识会被书页里凝固的历代主人笔迹吸住半秒，回归后眉心多一道水渍状浅痕。
- 若林恩在看到「女儿回来了」那一鞠躬时主动出声点评「这个家的礼数比想象中重」，则记忆画面微微起皱，人偶夫人在现实里同步抬眸一次，档案上加一行「宾客在观礼中出声」。
- 若林恩试图在赤足小女孩出现瞬间直接伸手拉住她、不再让她跨入主堡大门，则小拇指联系猛地被拉紧、整条丝线瞬间高温发光，意识海随之出现细小裂纹，追踪路径被迫退回黑堡床边。
- 若林恩在迎人群里主动数一遍出席姐妹、记下人数与站位，则归家记忆获得一份名册底稿，后续定位童年段时可以比对人数差异。
- 若林恩在幼小观察者跨出大门、记忆破碎瞬间选择把意识硬抽回现实而不追过门，则他从床边猛地睁眼、五指发抖、咳出一口带灵光的血沫，但深层执念仍然压在原位。
- 若林恩在破碎前一秒改道向左侧湖面走、不穿过门，则他先抵达一片未被记录的黑暗水域，陌生生灵的片段开始混入视野，艾雯立即在现实里提高灵能警报。
- 若林恩拒绝当场再潜、只请人偶夫人把家档按年份排好，则本轮追踪暂时收束，等于顺位把决定权推给下一次对话，但.book 里多出一条「下次追踪待启动」的暗色标记。
- 若林恩请自缚天使先单独评估黑弦月的苏醒概率、再决定要不要深挖，则她的回答停在「不足三成但不能定零」这种量级描述，没有给方案，但小队对深潜风险有了共识。
- 若林恩当场把认识印象最深的一段——女儿归家的鞠躬——向艾雯复述并要求解释权重，则艾雯确认该段权重最高、呼应执念最深，治疗方向在档案里首次指向「家」而非「痛」。
- 若林恩决定暂时不告辞人偶夫人，则她在雨夜门口多站了一刻才撑伞送他出去，后续联络时她主动多给出一件布偶线头作为引路证物。
- 若林恩向艾雯请求把观察到的幼小身影暂时贴标签「同伴」但不算敌我，则巨像网络里那一栏位格换成「未识别-同伴倾向」，宾客记录上多一笔人情。
- 若林恩选择明知超范围仍要跨过主堡大门，则记忆破碎反噬不是瞬时的，他会被弹回床边时短暂失聪约三息，此后再下潜的耐受度 -1。
- 若林恩在幼小身影消失那一刻主动用疫医气息裹住小拇指丝线想保住联系，则丝线确实没断，但疫医档案里多一行「该宾客在非目标客体上使用了气息」，被艾雯记入观察日志。
- 若林恩对深层执念只问一句「她是想压着活下去还是想压着让一切停下」，则艾雯给出「后者权重更高」的回答，这条结论被存档、成为下一段治疗方向的分岔依据。
- 若林恩决定把刚才看到的归家记忆压在自己意识深处不告人偶家，则他多出一条仅限自己可达的「未公开记忆」目录，后续决定是否分享成为一个分岔节点。
- 若林恩当场宣布本次追踪到此为止、不再下潜，则治疗路线转走「档案研究为主」档，黑弦月床边维持低强度灵能灌注，苏醒时间相应顺延。
