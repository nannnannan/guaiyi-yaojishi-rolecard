# E180·爱丽丝的燕尾服与双重污染预警·if线

- 若林恩在接过燕尾服之前先单膝触地吻她手背谢礼，则她当场回头扑进他怀里收紧双臂、古堡烛火集体蹿高三寸，事件以不变形收束但左左的目光瞬间结冰。
- 若林恩让左左代试燕尾服检验锁链反击机制，则她被虚无锁链钉在天花板两分钟没能下来，事件以变形（外人试衣被反噬）收束，古堡对此记录的描述是「非一家之主者禁穿」。
- 若林恩先当场穿上燕尾服再入席，则全桌宾客看到新男主人正式着装，事件以不变形收束但爱丽丝的好感度提示出现连击。
- 若林恩拒绝试吃「触手铁板烧」整道，改用自己的咒术将盘子密封后收进系统空间，则爱丽丝面色一黯、原地跪坐问他「哥哥不喜欢爱丽丝的手艺吗」，事件以变形（拒吃道歉）收束，宴席氛围短暂凝滞。
- 若林恩在宴席中先把那盘「蔬菜炖汤」一饮而尽、再故作轻松把它也端到独眼女仆面前逼她喝完，则宴席节奏被他控场，事件以不变形收束但独眼女仆当晚腹中冒泡出声。
- 若林恩借着燕尾服锁链反击机制主动让古堡荆棘在宴席四周腾起护网，则赴宴全员被古堡正式标记为「客座」，事件以不变形收束但离席后身份无法轻易抹除。
- 若林恩在察觉「对爱丽丝也起冲动」的瞬间立刻启用咒瞳扫描自己颅内的哭泣小丑封印，则他读到封印裂纹处渗出的欲望母树神性脉络，事件以变形（双源污染当场确认）收束，E181禁欲任务更早下达。
- 若林恩让左左在宴席间把独眼女仆领到偏厅训话规矩，则主桌人少一双餐具、爱丽丝的注意力更集中哥哥身上，事件以不变形收束但独眼女仆错过主桌胃袋试炼。
- 若林恩在爱丽丝抵达宴席之前先把她拉到古堡窗台边低声说「今晚留下来陪哥哥」，则她双眼当即泛红流泪、宴席迟到一刻，事件以不变形收束但宴席前段由尹依撑场。
- 若林恩用咒术在宴席上把「庄稼」馅料头颅换成普通香肠，则爱丽丝发现被骗后气得扑进他怀里啃咬哥的耳垂，事件以变形（伪装食材）收束，主桌恐怖氛围减半。
- 若林恩把燕尾服外披离开古堡继续使用，则它在离开古堡范围时锁定机制失效、锁链反击未触发，事件以不变形收束但林恩体表多一件纯白燕尾服形变。
- 若林恩以一家之主身份命令爱丽丝在宴席后留下做一对一污染检查，则她安静点头、宴席结束即跟入卧房，事件以变形（亲密诊疗）收束，冲动与亲密路径按媚药机制直白展开。
- 若林恩放任欲望冲动在宴席间对爱丽丝动手动脚、左左的【危】提示瞬间在颅侧炸响，则她当场拔夜魔刀从姐姐位置扑过来，事件以变形（宴席冲突）收束，污染信号首度见血。
- 若林恩克制住冲动、仅在离席时以「晚安吻额头」向爱丽丝告别，则她愣住后眼泪涌出、古堡锁链纷纷坠落一地，事件以不变形收束但兄妹羁绊注脚新增一行纯洁。
- 若林恩在宴席中段让尹依出来作证「林恩先生最近经常神情恍惚」，则爱丽丝第一次得知哥哥身体异常，事件以不变形收束但她自发加强古堡寝居照护频率。
- 若林恩主动把独眼女仆的真名问出并在宴席上当众称呼，则它激动地独眼里热泪盈眶、忠诚评级二次上扬，事件以不变形收束但古堡家仆档案第一次记录「被主人唤名」。
- 若林恩当场拒绝触发「贤惠的爱丽丝」隐藏任务、并以系统骂战把弹窗打回去，则任务奖励未结算、古堡宴席末段陷入「系统无声」空窗，事件以变形（任务被推回）收束。
- 若林恩让左左坐在他另一侧肩膀上帮爱丽丝夹菜，则独眼女仆惊恐地注视兄妹主仆同席、忠诚评估上升一档，事件以不变形收束但左左首次与姐姐在同一张桌上分食。
- 若林恩借着宴席醉意向爱丽丝透露游魂巷药剂店失守消息，则她笑容当场凝固、当晚即可带队离开古堡，事件以变形（古堡随行回援）收束，蓝星运输线遭提前阻击。
- 若林恩在宴席结束后独自留下收拾、把欲望冲动化为一轮咒术精细自省，则双源污染在他心里被拆成「欲望母树神性」与「哭泣小丑二阶」两条独立通道，事件以不变形收束但E181排查精准度上调。
