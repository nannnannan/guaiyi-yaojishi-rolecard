# E332·七神重组与母树迁回·if线

- 若林恩在听闻七神重组时立刻命令左左记录「远征军残部」逃亡航线,则E334 和谈人选可能包含一位远征军旧部、谈话内容新增一条「银幻清白证明」。
- 若林恩回母树后不脱衣跳潭而是先捡起沙地上那枚被踩碎的鸟嘴面具,则他在迁移期间全程系在腰上、E333 入城时被居民当作新式头饰引起一阵模仿风潮。
- 若林恩脱得只剩四角裤前朝母树方向丢一句「水暖则来,水冷则走」,则她愤怒 +30、她在水中对他连施七道藤蔓、他无法不呛水就躲。
- 若林恩在艾雯拔枪射他时立刻侧身避开并把枪口转到母树方向,则艾雯爵士首次对这位青年评价 +5、E334 和谈上艾雯主动替林恩讲述其冷静性。
- 若林恩在艾雯注入灵能时偷偷记录他的手腕脉搏频率,则他未来可隔空模拟艾雯的灵能特征、E334 在羽毛笔前争取一次主动对话权。
- 若林恩在艾雯大喊「不能开淫趴」时反向耳语「改成泡澡派对总可以吧」,则他被艾雯当场暴扣 200 精神伤害,但他收获一条「泡澡许可」、E333 入城后母树合法享受全天泡澡会。
- 若林恩在母树挑衅艾雯时立刻出手捂住她嘴说「不许说话」,则母树暴怒三秒被冷场、E333 入城时她主动保持沉默三小时。
- 若林恩在抄板子进树洞前先在自己胳膊上画一个「家法」印记,则母树见印一愣、E332 调教过程多了一层「这是仪式」的接受度。
- 若林恩在 40 分钟调教中每次抽打前问一句「还准备再侮辱艾雯爵士吗」,则母树每次都必须低头承认、她的服从度累计 +5、但内心反抗意志 +50。
- 若林恩在两小时双修时同步把胸口的金丝丸贴近母树的根须连结,则他被腐蚀的同时解锁了体内第一枚「母树共存节点」、E333 入城时他能远程感知她的情绪潮汐。
- 若林恩在双修结束时先阴阳怪气地来一句「夜医报告说水潭长了一棵树」,则母树当场气炸把他踹回树洞,但林恩笑着被踹入、E333 父慈子孝场景成立。
- 若林恩在双修后从树洞中走出时先举起双手朝白夜方向比出「我从未见过此话」手势,则他全身释放光明信号、E333 的白夜自然对他心存更多信任。
- 若林恩在界门开启前先用灵能扫描通道稳定度并用巨像之心加固一处不稳点,则母树移植过程完全顺利、未污染任何土壤、艾雯爵士对迁移技术评价 +10。
- 若林恩通知艾雯开门时让左左在城墙上挂一条「欢迎女神入驻」大旗,则白夜立刻获讯、E333 入城仪式上他获得白夜准备的一份「良医专属坐席」。
- 若林恩让左左在城门处对居民喊「禁止拍照、违者罚款 500 黑颅币」,则首次蒙羞的居民仍悄悄拍到了神人穿过界门的照片、E333 良医传奇再增一笔城市史料。
- 若林恩在母树扎根时悄悄让她选择一片更深的郊外围场,则她离内城距离 +2 公里、E333 花粉对居民的影响范围 -40%。
- 若林恩迁移前与母树约定「你不能再在夜晚开花」,则她达成承诺但白昼开花全开、E333 白昼城市迎来一片血红芬芳花瓣雨,部分居民主动守候欣赏。

- 若林恩在迁移完成时让左左第一个跳下界门落脚城郊土地召唤白夜,则左左被授予「迁移引导先锋」标记、E333 花粉扩散的第一波她站在最前沿替她挡光。
