# E125·废墟渡鸦誓言与咒瞳绝唱挡刀·if线

- 若林恩不冲向意识空间角落踢翻巨像之脑，只在远处冷声呵斥，则祂自碎裂纹仍扩展，救赎对话被压缩，渡鸦誓言的信任捏合度下降但仍可成立。
- 若林恩用后旋踢之外的招式（正面踹腹或拽衣领拉起）对付巨像之脑，则崩溃激活的时长被拉长，誓言承接仍归入同一路径。
- 若林恩在背上巨像之脑时不按胸膛维持意识不灭，而改用诅咒清除银白光芒在她虚影上包一层光膜，则单手抗黑线的窗口变窄，三大根源合击前的赶路距离更紧。
- 若林恩在喊出「让我做你们的渡鸦」前，先把巨像之心从自己胸口短时取出贴近祂手心，则誓言份量被具象化，巨像之脑的回握从「死死握住」升级为「主动贴上」，但林恩本体承伤上限被拉低。
- 若林恩拒绝喊渡鸦誓言，仅以「我带你出去」一句完成背负动作，则巨像之脑的信任成立但誓言名号未定，E126 银发女孩苏醒时的称呼口径改为「背我出来的人」。
- 若林恩在被哭骂「窃夺心脏的混蛋」瞬间回以戏谑或顶嘴而非沉默承托，则巨像之脑的泪崩更早止住，但「古老文明的投降」从感性转为互相顶撞的等价收束。
- 若小小在拔起林恩意识残骸时优先把巨像之脑的虚影也一并卷起，则两人同线离体，艾雯的抛投力道需同时覆盖两体，林恩本体落地伤加重但巨像之脑的意识消散节点延后。
- 若艾雯召出的灵能抛投不是把林恩本体扔出、而是把林恩与巨像之脑的连体虚影一起往外送，则林恩挡刀落点偏移，咒瞳粉碎仍成立，但肉身重塑的四肢完整度下降。
- 若林恩在发动不死泰坦诅咒前不摁右眼、直接双瞳一齐看向三大根源，则左眼被透支为代价替代右眼，咒瞳碎裂改落在左眼，不死锁血与透视的损失结构对调。
- 若林恩主动约束不死泰坦的血肉巨头只遮右半身，则三大根源合击被泄一半到小小与艾雯的防线上，咒瞳仍碎但后两者灵能线断裂变形。
- 若林恩在合击落下前用最后一段自由喊话，把「加入我的阵营」换成对万机之神、血肉支配者、欲望母树其中之一的点名挑衅，则该根源记恨度抬一档，E126 对峙顺位被改写。
- 若林恩选择不发动不死泰坦、改用巨像之心硬顶终极合击，则咒瞳保住但心脏出现第二道晶裂，后续银发萝莉躯体重塑的等级抬升被削层。
- 若林恩在咒瞳迸碎瞬间强行把碎裂的右眼碎片抓回掌心吞下，则咒瞳功能性损毁仍成立，但保留一份「右眼残渣」的可重触发引子，供后续某段事件链接回。
- 若林恩主动把咒瞳碎片喂给小小或艾雯，则该 NPC 获得一次性的「右眼碎屑预知」消耗能力，咒瞳本体退场不受影响，等价结果是 NPC 部分继承遗产。
- 若林恩在咒瞳粉碎后仍尝试调用右眼旧能力（透视、预知、锁血），则系统层面不响应，只报右眼空洞流血，本条目作为一次明确的能力封禁证据点。
- 若巨像之脑在送回心脏时不低语「奸诈的家伙」，而改为第一次用「渡鸦」称呼林恩，则意识消散的台词重量前移至 E125 收束，E126 苏醒时第一句衔接被改写。
- 若林恩在巨像之脑意识消散瞬间主动把自己的一段心头血注入回归的心脏，则心脏重置入林恩胸腔的融合度被推高，但林恩自身的恢复期被延长一档。
- 若林恩不在巨像之脑消散前接受心脏回归、改让心脏悬在意识空间自由漂浮，则心脏被三大根源合击余波扫碎一角，后续重塑根基不稳。
- 若小小或艾雯在抛投过程中被合击余波直接命中，则林恩落地后须先回头救援 NPC，巨像之脑意识消散的目送窗口被压缩成秒级。
- 若林恩选择把巨像之脑从背上放下、让她自行走完意识消散，则「背」与「救赎」的动作叙事被弱化，巨像之脑的死法趋向三千年孤独的收尾版。
- 若林恩在事件尾声用拟化流银先裹住自己断裂的右臂再裹巨像之脑的残影，则银发萝莉躯体重塑的部位优先级被改写，右手先于躯体成型，E126 银发女孩的初始外观出现单臂优先落地。
- 若林恩把整个事件压成最短路径（背起、誓言、挡刀、碎瞳、送心），中途不说多余台词，则一切结果等级不变，但 E126 苏醒时巨像之脑与林恩的羁绊对话被压缩，银发女孩对林恩的初印象趋向「沉默的工具人」。
- 若林恩让渡鸦誓言、不死诅咒、咒瞳碎裂、心脏回归四要素按默认全部成立，则本事件直接以变形收束，E97 至 E126 事件群顺利衔接，不再召开变形回溯。
