# E30·血月狼群与寂静镇试诊·if线

- 若林恩在冲入狼群前抢先对狼王使用针对性诊断【喷射型腹泻】改为全屏喜剧效应，则【满城尽带黄金甲】成就照常入账，但狼王威严当场坠底，审讯环节改为「老大当众赖账不愿认怂」的闹剧模式
- 若林恩放弃随机撒诊断，改用触手一只一只捆倒冲在最前的十几只狼人，则第一波压制成立但耗时拉长，狼王趁机近身近到一步，【心绞痛】延迟结算时已经擦过颈侧
- 若林恩在狼王「忍不住」瞬间靠得太近、没有立刻拉开距离，则金色花雨把他自己也淋成落汤鸡，左左笑声持续三分钟，狼人惊恐改为迷之崇敬「首领的连颜色都和这位是同款的」
- 若林恩把昏厥狼人冲洗净后没收利爪再松绑，则审讯顺畅度+，狼人供述追加一条「前族群长者仍在镇外徘徊」的伏笔
- 若林恩审讯时主动提及「你们先祖是被驱逐的联军」，则狼人颤抖以外出现更深的恐惧，供述顺序颠倒、夜医据点情报提前爆出，但镇外围火把戒备加倍
- 若林恩携带着狼人俘虏一同入镇而不是独行，则卡蒙持权杖的喊话升级为「连狂犬都能拴着来的人」级别的戒备，求治队伍延后半小时才排起
- 若林恩在卡伦剥除「自缚天使的怜悯」药膜时改用小号刻刀慢条斯理分层，则卡伦叫疼等级上调一档，镇民「他是真被感动了」的议论更盛，排队人数×2
- 若林恩在重新缝合时给卡伦臂上留一枚极小的药剂师戳记（问号或小刀图案），则镇民口耳相传，下一波病人主动要求「我也要那个记号」，寂静镇声望+1
- 若林恩当场点破卡蒙「你们逃走那批长辈不是怕夜医，是怕圣遗物被收走」，则卡蒙脸色瞬变，权杖垂下半截，剧场级沉默换成一句「你只是想看病还是想挖坟」
- 若林恩直接拒绝给夜医执行者开门、只从门缝里递出一枚诊断报告，则对方沉默三分钟后翻面读回自己名字，对峙改由「纸上谍战」模式进行，考验难度上调
- 若林恩在执行者面罩掀开瞬间主动掀开自己领口露出颈部旧疤与药剂师戒指，则对方「病里挤出个人形」台词换为「有病的不止病的形状」，敌意-1、考察深度+1
- 若林恩在渡鸦注蛭病毒反诊断时故意漏报一项「左肩胛骨膜水肿」，则渡鸦当场记录「准确度 96 分」，扣下的 4 分改为「下次不许藏私」的隐性埋怨
- 若林恩反向要求渡鸦先给他抽一管血作样本互换，则渡鸦怪异盯他三秒，照办，蛭病毒株一并入库，后续药剂店解锁一项传奇级病毒样本
- 若林恩在试诊间隙主动坦白「每报一个病名我都会不舒服一下」，则渡鸦与黑颅的视线立即锁到他身后那面墙，小丑轮廓被记入「观察者笔记」而非「突发事件」
- 若林恩住口不再用诊断术、改用触手直接切开探查大肠确认位置，则左眼抽痛延后，试诊合格但眼泪鼻涕齐流，黑颅低声一句「有疯医的潜质」
- 若林恩在小丑轮廓浮现的瞬间反向伸手按住那片墙把它「按回影子里」，则可见征兆被压回但整只手掌瞬间苍白，诊断频率上限被动下调，渡鸦在笔记本角落画了一个圈
- 若林恩在试诊结束条件达成前主动申请「附加施行一台小型无害切除术当面试」，则考察模式由「被审」反转成「互评」，夜医小组好感+1、警惕+1，软禁三日改由「实习留观」名义替代
- 若林恩在黑颅攀爬观察他时顺势送上一瓶自己配制的缓解焦虑药剂，则黑颅的态度从冷淡扭到别扭地道谢，寂静镇通道通行权限悄悄+1，卡蒙那边得到的是「他还不算个疯子」的简短述评
