# E67·纳米风暴追杀与快感冲击蜂巢·if线

- 若林恩脚下一颤时没扶稳栏杆、被颠簸甩到走廊对面，则避风墨节骨眼上多一段狼狈翻滚，畸鲸啃穿外壳的第一口把他的夜医长袍下摆咽进去半截，他才借左左一把揪回。
- 若林恩没先与指挥官建立意识链接、直接冲进指挥舱揪住高斯领口问情报，则链接推迟，『几百年仅胜两次』换成高斯贴脸咆哮交代，纳米风暴余量更紧。
- 若林恩不指望对堡外开火那一波迟滞、直接把信息流回溯提到第一步，则侧炮沉默，畸鲸注意力不被拉走，外壳崩解加快，左左喂招的窗口被压到只剩一口气。
- 若左左喂招时林恩刻意压制肩头的涩涩冲击、不让2号涨到位，则以M之拳的前摇拉长，第一拳轰下时肉瘤灯全黑，堡垒短暂陷入死寂才亮起应急灯，空气里多一拍心跳声。
- 若左左咬肩头时掺了私心、牙尖在旧疤上辗出一段红痕，则林恩充至52那一下肩上火辣辣发麻，涩涩度跳档同时痛感同步冲味，以M之拳的回溯路径里多一线血腥底味。
- 若黑弦月那一脚没踹准『哔』部位、擦着大腿根偏了一寸，则充至max失败、以M之拳回滰延迟一拍；林恩当场把人偶小姐按回墙上重新对齐位置，『这次踹准』。
- 若黑弦月那一脚踹实但同时往前蹭了半寸、留下鞋尖压出的桃形红印，则以M之拳轰下时拳风里多一丝人偶小姐高跟鞋的金属腥，涩涩度+max之外多一段她收腿时故意的停顿。
- 若以M之拳的涩涩被分散到多颗机械粒子而非集中冲击蜂巢智脑，则3号智脑的『呀』被稀释为含混的『咦？』，涩涩值只涨1，九千接管推迟，肃正议会多一段沉默。
- 若以M之拳没传染到3号智脑、而是偏离漂到邻近的二级节点，则事件未达『传染蜂巢』，主链断裂，但同区域纳米集群出现集体涩涩摆尾，肃正议会在回滰前已经多一段集体重评。
- 若林恩面对九千意识『你不该调戏我们的蜂巢智脑』时反口接『那就让智脑出来说话』而不是『野爹』那句，则机械意识的愤怒值+0，事件收束路径里少一点个人恩怨，【机械意识对你的愤怒】不结算。
- 若林恩回『你们不得叫我一声野爹表示一下尊敬吗』之后追一句『叫声爹就给你们母饰付费』，则机械意识愤怒+20，纳米集群改换策略时多一段『以其人之道』的異步集体应答，后续E68进入时带着这笔记录。
- 若九千意识接管后直奔林恩本体而非集中分解堡垒，则主链『放弃追人集中分解堡垒』变形为『围杀林恩』，林恩翻上堡垒顶端那一刻身后成龒涨，黑弦月能量暴动的输出判定压力上移。
- 若林恩没翻上堡垒顶端、改留在走廊里与黑弦月商定方案，则『我们在更高处谈』不成立，能量暴动的起始点压低两层甲板，黑弦月护体时多承重垮塌的锻骨声。
- 若林恩不许黑弦月以90%能量暴动、改接一根死星结晶储能棒，则主链『90%能量暴动』变形为『外源满压暴动』，黑弦月不退零，E68养蛊阶段她能为林恩多顶一次暴走。
- 若林恩脱夜医装备时留了咒瞳坠链不肯摘，则『只剩一条四角裤』多一件例外，血肉增生药剂灌进喉咙时坠链被黑血浸透，E68进入时坠链与血肉机体同化，多一线神性微压。
- 若林恩没当场开咒瞳、改为压战后期随机诊断术的『瘟疫』项作赌注，则主链『开咒瞳』变形为『纯诊断回滰』，黑血喷涌的视觉减少，但咒瞳那一丝诅咒因子留在机体里未被引爆，E71尘埃落定时多一段封存。
- 若林恩喝第二口、第三口血肉增生药剂而不是一口灌尽，则血肉暴乱不一次成形，机体在十米之后还有一段中途滞涨期，包裹黑弦月的过程被拉长到她在他体内还能听见外部畸鲸啃壳声。
- 若林恩留下的不是『我在赌一个瘟疫』而是玩家声明的另一句话，则以声明为准；血肉机体合拢那一下黑弦月接收到的核心语义换核，E68里她对赌局的反应底色改写。
- 若林恩包裹黑弦月的血肉机体没把她『当老鼠』一样顶在最外层，而是把她包进心脏侧壁里，则黑弦月在他体内的共振位更深，涩涩传导路径从皮下改到脏器贴附，E68养蛊过程中两人意识交互的黏性更高。
- 若林恩战斗启动前回头望向艾达琳方向、还是没说再见，则事件不新增对白，但艾达琳远程咒纹感知到那一段黑血波峰，E68后她主动赶来时多一句先开口的抱怨。
- 若林恩以M之拳借信息交互传染蜂巢智脑之后加一拍、回滰时把『涩涩+1、+2』的数值故意刷高，则智脑的『呀』换档为更连续的哼声，九千意识接管瞬间愤怒值上限刷新，E67后续纳米集群对外公布的战术手册里出现『涉M之拳慎用』条目。
- 若在能量暴动启动那一刻林恩的血肉机体已经形成、他选择先用机体护住黑弦月而不是让她先独自给暴动让位，则暴动顺序逆转：先护体后干扰，堡垒被纳米集群完全啃穿前几息暴动才发，外壳最后一块金属片被啃下时黑血刚好包拢。
