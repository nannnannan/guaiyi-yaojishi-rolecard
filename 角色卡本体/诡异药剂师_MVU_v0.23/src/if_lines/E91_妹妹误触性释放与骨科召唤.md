# E91·妹妹误触性释放与骨科召唤·if线

- 若林恩做完随机诊断后没有立刻拟化、先把诊断面板摊给她看，则爱丽丝对着"濒临魂飞魄散"几字眨半天，事件以变形（照料前置）收束，做衣推迟、误触链路顺延。
- 若林恩摸出旧衣时改用左左的人偶缎带做底料而非自己衣物，则连衣裙多一道深色边，事件仍以原作收束但爱丽丝锚点新增"裙上有嫂嫂的味道"。
- 若林恩把叠好的内衣裙推到她怀里转身要走，则爱丽丝拽他手指的力道加重、第一次主动唤"哥哥别走"，事件以变形（留守照料）收束，后续误触位置改在床沿而非腿边。
- 若林恩拒绝替她穿衣、坚持让她自己穿，则她攥着胖次愣住、眼眶先红，事件以变形（自立穿衣）收束，骨科召唤（二）延后到下一次亲密互动结算。
- 若林恩替她穿衣时指尖多了几寸停留、把她整个人从头打量到脚，则系统多弹一条【叮！爱丽丝害羞度+5】，事件仍以原作收束但骨科召唤（二）结算时魅力加成由+2改为+3。
- 若林恩挽长发时顺手在她发顶落下一记吻，则"摸了脑袋"提示叠加"亲了发顶"，事件仍以原作收束但骨科召唤（二）提前一拍触发，经验由300涨至350。
- 若爱丽丝挪动蹭怀时林恩先一步起身避让，则误触不发生，事件以变形（规避误触）收束，骨科召唤（三）与奇妙超体验（二）不结算，"诅咒之物"说辞不出现。
- 若林恩被握住瞬间强压下去没有射出，则压力条停在极低值不归零，事件以变形（硬忍过去）收束，爱丽丝只觉手心滚烫、不知发生何事，压力留待下次释放。
- 若林恩在白浊垂坠时抬手替她挡下大半、只溅上指尖，则她脸上只沾两滴，事件仍以原作收束但"哥哥护住我"成为爱丽丝锚点新条目，愧疚值下调。
- 若林恩事后没有立刻解释、先沉默替她擦净脸颊，则她泪水先一步涌出再听到"诅咒之物"，事件仍以原作收束但爱丽丝对解释的相信度小幅下修、日后再问起。
- 若林恩不用"诅咒之物"圆场、改以"哥哥的弟弟睡着了被你吵醒"作比，则爱丽丝信得更彻底，事件仍以原作收束但锚点词条改写为"弟弟会睡觉"，下次再触时她会说"我又吵醒他了"。
- 若林恩把"水满则溢"延伸讲成"壶开揭盖"的家常譬喻，则她听懂了还点头复述一遍，事件仍以原作收束但"水满了就帮忙揭盖"成为爱丽丝惦记住的固定句式。
- 若林恩承诺"下次镇压不动会叫你"，则她郑重伸出小指要拉钩，事件仍以原作收束但兄妹羁绊升级"立过约"，E92诱捕左左时爱丽丝不会撞见。
- 若爱丽丝在鞠躬道歉时不小心又蹭到那处一次，则二次释放不发生但压力值再降一格，事件仍以原作收束但系统补弹【叮！压力-5】，成就不重复结算。
- 若林恩在她闭眼点头后替她盖好薄被才出门，则她睡颜安稳、呢喃"哥哥晚安"，事件仍以原作收束但爱丽丝锚点新增"被哄睡过"，为后续同住线铺垫。
- 若林恩出门撞墙痛呼时没有把矛头转向左左、改为先自我惩戒跑圈，则E92引子改写，左左锚点新增"哥哥把责任揽下了"，诱捕线暂歇、改由系统提示强行召回。
