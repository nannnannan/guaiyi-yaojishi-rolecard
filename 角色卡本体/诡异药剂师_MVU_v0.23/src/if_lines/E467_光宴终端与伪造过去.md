# E467·光宴终端与伪造过去·if线

- 若林恩开场就把她手腕那条最粗的数据锁链用咒瞳照出算法缝，则她会本能把链缩紧三寸、确认自己还在原地，诘问节奏先被她警觉压一拍。
- 若林恩第一句不是追问肢解，而是问她「现在几点」，则她下意识去调终端日志、发现早已被剥离时序权限，她自身囚禁强度被她说服前先自我确认一次。
- 若林恩跳过伪造对手情谊直接用双证压上，则她的戒备层只退一层、停在「这是敌方制造的叙事」，自由诘问仍可推进但破防须更多轮次。
- 若林恩把「可敬对手」叙事反向用到将军身上（赞美将军才可敬），则她会立刻护主否认，她把「龙首／将军清白」钉得更死，后续卖炸弹负担加重。
- 若林恩在剥洋葱中途突然被她反问「你想从我这里得到什么」，则他必须现场摊出至少一个真实诉求作抵，话术漏洞被她记在意识底账。
- 若林恩用左左的声音而不是自己替她说「你被肢解得不公」，则她对这个小题外音色产生短暂困惑，左左会被迫以境内形态在意识空间里安静吃瓜一整段。
- 若林恩只投影巫神侧战况录像、不投影污染者记忆映射，则她的失神停在「将军可能背叛」而非「将军已献祭给外部污染」，崩塌冲击降一档。
- 若林恩把两证据同时铺出并沉默不再说话，则她会自己把紫黑污染与献祭法阵连成线，「如果这就是代价」那句诘问不必明说也会在她心里成形。
- 若林恩把她光宴不屈史档案按圈养／潜伏／复仇／接纳四段逐段铺读，则每读一段她虚拟身体数据亮度升一档，火把象征那段被点亮时她的瞳孔首次重新聚焦。
- 若林恩在「等一下」窗口前不减速、抬脚直接做离场投影像，则她会咬住下唇到最后一刻仍不出声，三位一体筹码不了了之、合作窗口被关。
- 若林恩答应时不限「不毁灭整个文明」这一护勾起句，只答「我答应帮你」，则她会追加逼问护文明条款，玩家必须现场补签或拒绝，信任记账起笔重写。
- 若林恩在口头合作成立后立刻追加要求她先切断自己一根数据锁链作为诚意，则她会反过来要求他先开放万机之神备份检索路径，谈判进入互相先付阶段。
- 若林恩故意在意识侧写中让左左听见「我会用完就丢她」，则左左在体内气急败坏抓他肋骨的幅度比原线更大，事后压住她需多花三秒。
- 若林恩抛出三位一体筹码前先问她「这事你自己能做到吗」，则她会承认被删了关键数据但眼神第一次向终端深处某个隐藏目录倾斜，资料位置被意外提前一笔。
- 若林恩当场提出「融合意识剥离的另一种做法是分布式同步」，则她瞳孔猛烈一缩，在她体内底层露出一行「该理论曾被她自己否决」的备忘加密条目。
- 若林恩选择不投影任何证据、只用自由诘问＋文明意义反诘，则她逻辑链卡住的位置从「奴役是否活着」提前到「活着的意义是什么」，崩塌更快但缺石证支撑。
- 若林恩在她瘫坐后试图伸手入数据流扶她一把，则她下意识后退一步让指尖穿模，她的虚拟身体在那一刻第一次被允许露出虚弱反应的延迟。
- 若林恩选择把「那时你也说过同样的话」改成「那时你说的是相反的话」，则她会瞬间检索自身记忆找不符，正式进入「我的记忆被编辑过？」的自我质疑。
- 若林恩在意识侧写回头一望中看见自己数据牢笼外有更深层一间「审讯回放室」，则该房间标记将被登记进他面板，E468的资料检索路径会优先指向它。
