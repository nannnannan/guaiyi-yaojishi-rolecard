# E152·命运规则神与正式对话·if线

- 若林恩在羽毛笔坦白身份前直接说出「你是命运规则的神」，则她立刻停止倾诉、重新缩回血肉防御，事件变形为「认知驱逐重启」。
- 若林恩在她说出「本名命运之神」后当场跪拜或改用尊称，则平等信任破裂，她认定林恩与其他生物一样畏惧神性，后续对话退回工具化权柄交易。
- 若林恩追问「你屠灭一国时具体杀了多少人」，则她如实报出数字并伴随血肉剧烈抽搐；数字越大反噬增殖越快，左左强制中断谈话。
- 若林恩说「那不是你的错，是规则让你做的」，则她摇头否定，坚持罪责属于自我选择；若林恩顺势接过「那我们一起想办法」，则反噬转移选项提前亮出。
- 若林恩回避目光、只嗯嗯应付世界观说明，则她察觉敷衍，停止罪责坦白，事件取消但既有事实保留，不得抹掉她已开口的部分。
- 若林恩在听到「地狱机械执行惩罚」时插嘴「那我把这机制毁了」，则她惊恐警告这会招致更高层注视，系统警报升级，002室封锁倒计时启动。
- 若左左在对话中突然拔刀指向羽毛笔，则空间血肉暴走，林恩被推出异度空间，事件变形为「左左强行护主中断」。
- 若林恩主动把渡鸦、紫罗兰力量或黑灾元凶并成同一存在，则她立刻否认并简短划线，记录为「未解关联」，不洗白、不强行并线。
- 若林恩提议以性行为作为信任证明或解咒途径，则羽毛笔因羞耻与反噬失控而拒绝；若玩家坚持，则血肉病变瞬间加剧，事件转入「色色失败与反噬暴走」变形，罪责与身份话题全部让位止血。
- 若林恩承诺「我会陪你到反噬结束」但不提具体方法，则她获得短暂安定，反噬增速被延缓一拍，E153 的七日倒计时延后一日。
- 若林恩在系统警报响起时立刻以本名写下转移契约，则跳过沉睡节点直接进入E153默认走向；若只写转移一半，则按变形态实际比例结算残留病变。
- 若林恩要求先带大家撤离002室再谈，则羽毛笔留在原地独受反噬，002室封闭；既有事实保留，可在后续事件以远期外援重新激活，但信任度减半。
- 若林恩以自身血肉为样本研究反噬病变，则发现病变与巨像之心共鸣微弱，获得「双向侵蚀」伏笔，但当场无法反向修复。
- 若林恩把谈话内容同步给艾雯爵士或巨像之脑，则地狱机制察觉信息外泄，猪头屠夫提前在 E153 前现身警告，应对时间被压缩。
- 若林恩在她力竭沉睡时试图触碰病变血肉核心，则苏醒的反噬直接标记林恩为「新容器候选」，E153 临床死亡风险翻倍。
- 若林恩拒绝相信「黑灾不是大清洗」，坚持按旧大清洗逻辑应对，则后续事件链沿错误认知推进，地狱回应时遭额外惩罚性注视。
- 若林恩在罪责话题上全程沉默、不原谅也不谴责，则她把沉默视为默认审判，悔恨加深；E153 的「不会死」诺言附带自我牺牲条款。
- 若林恩以书写方式代替口头对话，则字迹被「书写未来者」身份异常共鸣，坦白时间缩短一半，但林恩本身的笔迹被地狱规则存档。
- 若林恩把左左支开单独与羽毛笔对话，则左左在外界启动强制救援协议，十分钟后破门，谈话提前宣告中断但不取消。
- 若林恩先问「你想怎么赎罪」而非「你犯了什么罪」，则她把话题引向「保留文明火种」的机械使命，暴露地狱标本库位置，罪责本身不减轻。
- 若林恩在反噬重新病变时选择留在原地观察，则病变血肉试图反向包裹林恩，触发「血肉同化」即时危机，左左斩断连接后才可撤离。
- 若林恩让她逐项列举规则体与普通古神区别，则她给出书面化清单但不解释黑灾例外，黑灾真相仍待后续事件拆封。
- 若林恩要求她示范一次「书写未来」的完整流程，则她拒绝并指出演示会立刻引来注视；记录为「示范被拒绝」，规则身份事实仍成立。
