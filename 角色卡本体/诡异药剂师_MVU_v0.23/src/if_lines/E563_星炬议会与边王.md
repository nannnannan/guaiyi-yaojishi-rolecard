# E563·星炬议会与边王·if线

- 若林恩在响指传送前先朝星炬高塔外壁掐一道稳定法则印记，则传墙倒吊意外被改写为稳稳落厅中央，三百六十度回旋落体与砖砸脑袋两段笑料同时失去锚点。
- 若林恩在半身卡墙时主动朝穹顶上方边王们喊「不许回头」，则七边王齐齐抬头的瞬间被替换，近卫警报调门先低半度，后续「刺客」二字出口节奏慢半拍。
- 若林恩主动把歪斜姿态扭成单膝跪地仰首宣告而非三百六十度回旋，则边王眼中逼格升一档，但「法则波动」怀疑比「滑稽」印象先进入问询。
- 若林恩在被喝刺客时主动伸出左手挡在最前面而非任由左左缩回袖口，则左手浮出红瞳，潘尼皱眉多记一笔「来客左手独立存在」的备注信息。
- 若林恩在被问身份时直接亮月儿兰而不先出「你们神皇陛下」玩笑，则拔武器的金属摩擦声少了那一茬，但「神皇」二字悬置未出口，杀意拔刀窗口错失。
- 若林恩把「如果我说我是你们神皇」玩笑换成「如果我说我是女主人的女婿」，则七边王眼神从杀意切换到错愕仅一瞬，潘尼首次皱眉思索「女主人」三字指向。
- 若林恩掐出小丑人偶时主动掖住其后脖颈毛而非拎后脖颈皮，则小丑尖叫破口时肺活量稍弱半分，认出他的边王迟一秒才从他骂街声里对上号。
- 若林恩法则针刺小丑心脏前先轻声提醒小丑一声「忍着」，则小丑骂街前半秒是咬死的闷哼，狱卒气息渗出更缓，长名边王辨认过程多承受两秒死寂。
- 若林恩主动追问小丑三千年前收税黑史的具体收条数字，则长名边王报馆藏的整面回忆被数条小账翻旧税负取而代，小丑认人时气焰略矮半分。
- 若林恩在潘尼拒绝承认小丑身份前主动用法则再点第二枚小丑随身携带的旧符文，则小丑脖颈那枚堕落符文首次显形于边王视野，身份核对省去一轮怀疑。
- 若林恩在边王们集体单膝下跪时主动伸手抬最前面潘尼的肩而非任由「边王议会向您致意」完整说出，则潘尼起身抬头，致意礼节变体为握手，地狱层级感降级为对谈。
- 若林恩在听潘尼讲双线入侵时主动抬手打断并要求直接讲「腐化神界入口坐标」，则潘尼把「传说中已被彻底腐化的神界」压缩成一句话，但「大君记忆中幽冥海衔尾」细节不出口。
- 若林恩在两千年隔离带科普刚出口就插话「那是谁改的星位」，则潘尼坦诚他不知道，「两千年前的机制」首次以悬案形态留在对话里，星辰阵列成因不指向任何人。
- 若林恩听到「排异巨大削弱」时立刻追问具体削弱幅度与速率，则潘尼给出「深入上百天文单位仍存活」量化数据，边王们的脸色在数字落地那瞬间又沉一层。
- 若林恩在判断「此地是最佳外破口」时主动提议立刻在破口布下第二道法则屏障，则潘尼摇头说无人能在无序边疆内侧立稳法则，提议被驳回但破口位置被边王们更紧记。
- 若林恩问潘尼「画家能否进入主宇宙」先于「灾厄意志是否清晰」，则「画家是创世者不被排斥」这条事实提前出口，灾厄意志缺清晰构想那段顺延到末尾作为收束。
- 若林恩全程不提「续命之法」只安静听完局势，则「能抗灾厄仅因其缺清晰意志」这句被边王们当作常识吞下，没有额外追问，画家例外条款也无机会被点出来。
- 若林恩在问询结束后主动提出要见识星炬高塔本体结构而非立刻传送走，则潘尼愣了半秒答应，下一事件的「三维战线地图浮现」接入点向后挪一段。
- 若林恩在边王都退下前主动叫住最小个的那位边王多问一句「你见过大小姐本人吗」，则「只有她能在法则领域追踪」这句提前落座，大小姐身份猜测提前多了一个实证锚。
