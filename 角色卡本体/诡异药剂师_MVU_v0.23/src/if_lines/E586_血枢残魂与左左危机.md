# E586·血枢残魂与左左危机·if线

- 若林恩拒绝对质并立即撤出血枢区，则权限召唤与左左融合冲动升级，封印完成态不立，左左在战斗边缘的共性压迫变成不可逆危机。
- 若林恩拒绝歼灭改尝试沟通，则残魂意志混乱无法对话，左左被召唤冲动推向危险的主动性边界。
- 若林恩战后强留尸骸区继续探索，则机械星云引入延后，残魂已灭血肉已封事实仍作已知，但灾厄对这片区域的注意被进一步吸引。
- 若林恩在残魂开口瞬间主动挡住左左，则权限威压在他身上先缠一圈，左左的压力被遮蔽一半，她的痛苦尖叫延迟半秒。
- 若林恩对残魂的「林恩」称呼回以「我叫林恩，但不认识你」，则残魂的「紫罗兰」误认被他自己亲手打破，残魂在下一秒的暴怒里陷入更深的混乱。
- 若林恩在被残魂控诉时主动承认「是，是我要你的血质」，则残魂的愤怒从恨转讥，「窃夺者」的定性被他主动承担，残魂的攻击火力重新集中到他本人。
- 若林恩在残魂扑杀时把左左从自己臂膀上解开放到身后，则左左的左手形态被强行解除，她的战斗力大减但她获得了高位格面前的自由。
- 若林恩在用心灵法则歼灭时同时用初诞者之力护住残魂的一段记忆碎片，则歼灭更艰难但战后他在手中捏住一枚血色的记忆残晶，血枢终焉之主反噬的最后证据被保留下来。
- 若林恩在左左「肢解自身融合」冲动中主动轻拍她后脑唤她名字，则她在叫声里恢复片刻清明抓住他的衣服，冲动的第一波被他的声音化解。
- 若林恩主动问残魂「你恨的只有我吗」则残魂陷入停顿，那漫长的恨意突然失去了具体对象，它的攻击速度在这一秒出现了一层空隙。
- 若林恩在战后对左左说「你不是巨像，你是左左」，则她的起源焦虑被直接压制，她抱着他的手臂把头靠上去。
- 若林恩把体内以太核心的共鸣回响主动分享一缕给左左听，则她第一次以旋律形式听到机械的存在，她对巨像的恐惧被转化了对巨像的怜悯。
- 若林恩主动把三位一体猜想向系统求证，则系统无法证实但提示「旧有相关档案已被加密」，他的求知欲在系统边界被强行拉回。
- 若林恩离开尸骸区时捡起一枚血枢掉落的血色水晶并收进系统空间，则这片晶核在后续成为打开巨像秘密的实体钥匙。
- 若林恩在离开时对虚空低语「至少你死在了自己选择的战场」，则被封存的血肉块表面的封印纹路亮了一秒，残魂最后的意识以某种方式放下了。
