# E606·魇的自毁预言·if线

- 若林恩在审讯魇之前让左左先进入八音盒试探,则她作为初诞者同类的身份让魇第一眼惊惶,口供中的抗拒值大幅下降,但左左本身被污染可能性成为悬置变量。
- 若林恩决定不让小丑交出八音盒而由林恩本人直接从系统空间取出,则小丑的「我抓的」资历被剥夺,魇对他的恨意少一等,但林恩「全知全能」的形象更立。
- 若林恩主动在提审时让艾维儿第一个提问,则她的愤怒值从被引爆改为被引导,夜神和主母的后续反应对她更为心疼。
- 若林恩让魇在自爆前留下一缕黑雾残片而不是完全消散,则后续 E607 的会议中林恩多了一个不稳定的俘虏,梦魇一脉的威胁被延展为持续悬念。
- 若林恩决定不向魇透露自己已知「沉眠者」的身份,则魇的供述中关于天父与张狂派的信息仍可被诈出,但它对林恩「渡鸦」身份的判断更模糊。
- 若林恩主动在梦魇供述时以心声问「你们有几个」,则梦魇可能报出数字,后续敌人规模被数字化,但「我们无处不在」的心理压制转化为具体战力计算。
- 若林恩让主母在会议室出现并认出了「沉眠者的音符」,则她对天父脉系的了解被揭开一角,但「主母是旧世界知情人」的设定被提前摆上桌。
- 若林恩决定不在会议上讨论神王威胁而是转入密室与艾维儿/主母三人谈,则会议规模变小,但「真理神王」的名号未传开,军团对此的警觉性更低。
- 若林恩让林恩在审讯时把三位一体之力全部展露,则魇被残焰灼得更彻底,但林恩「压箱底牌已现」的后果在两神圈传开,后续反制力度更大。
- 若林恩主动让康斯坦丁在魇自爆前问「你们的舰队编号是什么」,则军团得到一条可用情报,但这条台词的冷面船长气质被人为拉高。
- 若林恩决定让艾维儿在听到「你父亲的魇」时不只握剑而是直接向黑雾出手,则黑雾提前自爆,供述被截断一半,但「她会为父暴怒」的印象被写入所有与会者。
- 若林恩让小丑在审讯时多问一句「你进过主宇宙几次」,则梦魇对主宇宙的认知被进一步揭开,后续防御布局有了历史地理参数。
- 若林恩主动在会议末尾把「先放一放」改成「即刻备战」,则军团速成计划被压上台面,但任何心理铺垫仍未做足。
- 若林恩决定不让自缚天使出席会议,则「目击者」证言少一人,艾维儿的证词独占此段,她的记忆负担更重。
- 若林恩让林恩在魇自爆前生擒一缕黑雾塞入系统空间,则后续他可以随时提审,但系统空间本身被污染的风险登记在案。
- 若林恩主动让巨型「杀光所有渡鸦」的战书变成幻象播放给全盟看,则军团士气被震慑,但「我们正在被追杀」的共同意识更实在。
- 若林恩决定不让艾维儿解释七大神王设定而由主母代讲,则灵界知识传播渠道被换位,主母的博学者人设更立。
- 若林恩让林恩在审讯中多次使用「大君」称呼紫罗兰大君,则艾维儿情绪反应更复杂,后续父女线的纠斗画面更多。
- 若林恩选择在魇自爆后立刻召出轮回神格询问同僚动向,则轮回神王的视角被引入,情报网被扩宽,但轮回的态度让会议多一层不确定。
- 若林恩主动在会议末尾追加一句「我会让天父睡得更深」,则军团气势被推到巅峰,但任何挫败都会双倍反噬这句豪语。
- 若林恩让左左在会议后私下对林恩说「那东西的气味我记下了」,则后续侦测梦魇的暗线被埋下,但左左本人被梦魇记恨值+10。
- 若林恩决定不在会议中提及「半神量产」而改为「精英突破」,则军团目标从数量转向质量,后续时间小屋的战略意义被重写。
- 若林恩让银幻在会议中提交一份「机械军团对梦魇的克制方案」,则她作为副指挥的存在感更强,但会议长度被额外拉长。
- 若林恩选择在会议后立刻带主母回神殿独处,则 E607 的长谈提前在会议余温中开始,「你不能哭」的训诫更直接地砸在刚刚受创的林恩身上。
