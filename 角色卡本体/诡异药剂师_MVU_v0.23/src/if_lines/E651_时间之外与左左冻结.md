# E651·时间之外与左左冻结·if线

- 若林恩没有引动最后的初诞者之力铸出梦境，则他会在最后一刻被永恒定格，左左独立留在时间之外、独自等待、独自冻结，金色梦境不存在。
- 若林恩在铸造梦境时把目标从「独属于他自己」改成「护住他和左左两人」，则金色涟漪需要立刻铺到两米远，他付出的初诞者之力加倍，梦境成形的速度大减，但左左不会在茧外被冻结。
- 若林恩把梦境的边界直接推至十米远起步，则初诞者之力会一闪而过、立刻燃尽，他和左左一起被永恒冻结，事件以取消收束。
- 若林恩只护住心脏而放身躯受创，则金色涟漪只裹住胸口，左左触不到他身体，她会对着他透出的血迹发呆，但当领域扩张时他碎掉的四肢已在涟漪边缘随风飘散。
- 若林恩让金色梦境从左手而不是从眉心展开，则涟漪会先覆盖住左左的意识，她不会立刻冻结，但林恩本人会被定格在领域之外，宣告梦境到他身亡才完全成茧。
- 若林恩把领域从一米扩到五米，则他和左左能多撑两天，但扩张的代价是他永远连一根手指都不能动，左左只能把他整个人拖到下一程，拖行速度再减半。
- 若林恩提前告诉左左「涟漪一旦越过我眉心我就会沉眠」，则她会不停托住他下巴、用尽办法不让涟漪涨到眉心，两人的昏睡会被无限期推迟。
- 若林恩借着左左流下的眼泪让涟漪染上一点温度，则她的泪水会被定格成一颗会发光的冰晶，它能反射出时间长河的方位。
- 若林恩引动了领域之后又主动让一缕疦疵的时刻记忆滑入茧内，则左左在茧里会梦见他小时候的模样，她在梦中放声大哭但没有声响。
- 若林恩把夜魔刀残片放进茧里随左左一起漂流，则她在冰雪里会多一件用以支撑身体的锚物，她对「要带他回去」的信念有着更稳的拐杖。
- 若林恩提议左左只把他拖到时间长河出口的另一只神灵尸体旁边，则她不会一路走到最初那条长河，但她必须接受他以「和那只腐化神灵同样的结局」作为节点，他能回到现世、却回不到原时间线。
- 若林恩允许自己在茧里做一场看见童年旧景的梦，则他会在梦里看见一片长满夜医药剂草的原野，涟漽边立刻为他描绘出那个原野的地图，他会在醒来后然后才被送回孤岛、但场景会多一座草坡。
- 若林恩让涟漪在左左的指尖上停留一点时间，则她第一次触到时间长河边缘时不会感到寒冷，只会觉得像被谁的指心默默暖了一下。
- 若林恩在沉眠之前用心声向左左最后道一句「不要跟来」，则她会咬住牙把这句话吞回去，但涟漽会替他在每一个她撞上河道边缘的瞬间重复一次。
- 若林恩在沉眠前催促左左「带着『以M』这个词走下去」，则她会低语地重复几次，她的脚步在被冻结的前一刻会比之前稳上一分。
- 若林恩回望一眼被定格的腐化神灵尸体作为路标，则她会刻意把这只尸体拖到金色茧的内侧，借此为他点亮一盏反射时间长河微光的定点光。
- 若林恩在冰封之前拖住左左小腿不放她走，则她会笑着按着他眉心说「笨蛋放开吧祝福我」，然后她会把额头贴在他眉心上说出一句只有自己能听见的告白。
- 若林恩在左左拖到他返回时间长河的那一刹强行睁眼，则他会一次次看见她发丝上吊着的冰晶像星光，这是这条绵长救援之路上他最后一次用肉眼见到她。
- 若林恩在最后被她推进时间长河前还特意用一滴血点在她额头，则她返回原时间线之后，那滴血会化成一个永不消退的红色痣印。
- 若林恩醒来后左手掌心查看空空如也，则他会试图去回想她最后那句「明天再见」是不是一句谎，但涟漽里没有答复，只有他自己的心跳。
