# E671·破碎神界与命运神国·if线

- 若林恩在出征前主动找康斯坦丁与人偶家对证互杀之约，则两人会坦言那是彼此救赎的最后体面，但林恩的面板上会多一条「双人绑定·同生共死」的隐秘标记，可后续以初诞者之力尝试拆解。
- 若林恩在黑海岸叫住伊甸娜说出「无序已经侵染半个神界」，则她驻足一秒却仍踏浪而去，临别赠一枚海纹鳞片，可在深海迷茫时为她引路一次。
- 若林恩在黑雾之上先与哭泣小丑对奕一局棋子再放任他离去，则小丑会把八音盒最后一枚完好的齿轮塞进他掌心，带往无序深渊的信物由此成立。
- 若林恩在银色幻想修复仓外守了一整夜直到她走出，则她会愣神后低声道一句「你怎么还在」，亲密段的墙边交合改写成她主动扯开他衣襟，恶堕羁绊浓度显著提升。
- 若林恩在银色幻想自设监督委员会时亮出万物神格，则她会抬手压回他的掌心说出「我配不起」，但事后她会暗自把桌角那枚神格的位置每次巡逻都多扫一眼。
- 若林恩在三重界以初诞者之力灌遍银色幻想灵魂时故意触发一缕她体内的腐化残响，则能短暂锁定腐化频率纳入个人档案，但她本人会瞬间面色苍白说出「我也察觉到了」。
- 若林恩在亲密后主动用一句「替我好好活」回应告别，则银色幻想的纳米机械会把这句话硬编码进她的核心循环，即便后期失控也会自锁一秒。
- 若林恩不与银色幻想告别而留一封「别等我」的字条，则她读到时会面无表情撕裂字条却把碎片收进胸口的原子收纳格，监督委员会的警报阈值改写成「林恩归来时优先通知」。
- 若林恩在画家面前执意追问奈奈子下落，则画家会罕见地沉默三秒说出「这不属于你这次任务」，但会多赠一瓶她亲自调配的「色彩停滞剂」，可冻结一次小范围无序涌动。
- 若林恩耍赖装伤向画家讨外物时编造一种「反正要死就拿走你调色盘」的借口，则画家会一边笑骂「狗东西」一边真把调色盘里最锋利的一撮塞给他，混乱色彩纯度+50%。
- 若林恩在接过龙蛋瞬间用咒瞳反向扫描艾维儿，则蛋内无序力量会被短暂锁定显形一缕沉睡的龙形，画家眯眼说「你最好别让她在这里就醒」。
- 若林恩拒绝接受龙蛋而反问「你自己为何不亲自去」，则画家会罕见把头颅压低说出「我不能见她」，旋即以色彩之力强行把蛋封进他胸口，附加诅咒「必死不退」。
- 若林恩在世界边界选择神界其他坐标而非破碎神界，则折跃瞬间会被四王以符文眼球强行修正回命运神国轨道，被嘲讽「地图由画家画的」。
- 若林恩踏入神界瞬间主动垂落至高神王威压，则方圆数千公里被污染者集体俯首退避，但因果的神王化身会提前在壁画门内察觉入侵者。
- 若林恩在石碑前以空间神格反向读取「命运之国愿每一个生灵都能找到他的归宿」，则能挖出羽毛笔当年崩溃时亲手刻下这行字的血色记忆一缕。
- 若林恩赶往黑骑围猎时不现身只观战，则音音会以一命换斩杀，她的狐尾被折断一截，庇护所欢迎规模大幅缩水。
- 若林恩提前出手一击瞬杀两名黑骑，则音音回头只会看见他单手持枪立于灰烬，她会当场怔住但随即认出「渡鸦」的气味儿，主动引导去庇护所的路会缩短一半。
- 若林恩用空间折跃把两名黑骑直接丢进万里外的污染池而非斩杀，则他们能短暂幸存并把「法则无效化」的情报带回敌方总部，神界大戒严提前启动。
- 若林恩跟着音音潜入裂隙前先在崖壁口留下一枚金色沙粒锚点，则后期林恩可瞬间折返此处，但魇群的因果追踪也会因为这一缕坐标而被吸引到附近荒原。
- 若林恩在逃入裂隙瞬间主动以空间神格把崖壁表面禁制全部引爆制造混乱，则守卫会在裂缝关闭后误认为敌人已入侵庇护所内部，谁知后来龙卫澜会以更高战意盘问来人。
- 若林恩决定不去见画家、直接独闯三重界取时间神格，则神界地图不会被交付，他将在数千万公里破碎大地上步履维艰手动重写庇护所坐标。
- 若林恩接受画家资源包同时主动撕碎一封她转交的「送给羽毛笔的手稿」，则她会露出残忍神色说一句「你果然不在意那些」，但手稿的腐化残响会反噬化为一次小型空间崩塌。
- 若林恩把画家混乱色彩全部留给银色幻想压制体内无序，则她后期失控时间窗会延后约一个月，但他的进攻手段被削弱一档，造化弄人。
- 若林恩在黑骑踏虚空围剿音音时主动暴露身份，则「渡鸦现身神界」词条会以邮件形式传至三大神王，地狱的围困立刻做出调整，画家的计划被迫强行清算。
- 若林恩在崖壁前放弃尾随音音而径直循地图黑走，则他会错过庇护所与龙卫澜这条线，命运神国的情报弧将被强制以其他手段解锁。
