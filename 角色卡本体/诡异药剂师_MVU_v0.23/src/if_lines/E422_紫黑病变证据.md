# E422·紫黑病变证据·if线

- 若林恩在她抱怨吸血眷者翌日发疯时主动追问具体时间线，则「战争前一周已出现」的节点被锁定，【疫医投毒】假说提前失效。
- 若林恩在她焚烧发疯眷者前先调用蚀痕保留其中一具尸体的切片样本，则病变组织首次进入系统空间比对库，紫黑病灶后续可分手性。
- 若林恩在她矢口否认「玩得花」时让小丑心脏把血红典籍翻回仪式现场第一页，则图样与法阵残痕一对应，她的「第一次」被公证处废纸化。
- 若林恩拒绝下地下牢，则紫黑病灶仅以孽主口述成形，事件以变形（证词阶段）终结，时光涟漪的物理证据就被推迟。
- 若林恩在找回地牢前先赐咒瞳扫描宫殿外墙刻痕，则密码锁与祖传铭文风格格格不入的线索被他早一拍发现，「外来锁具」话题提前从她口里拔出。
- 若林恩在她倒提眷者密码锁时主动接过机械锁尝试解码，则「三位一体机」首次以谜题装备身份介入血族祖传地牢，破解画面被一个因染病反锁在内的眷者透过栅栏目击。
- 若林恩让小丑心脏用无序力量短路机械锁，则密码锁齿轮爆出一道物理火花，门面例证化「门可以用力开」，但后续里面那位自己反锁的眷者被火花伤了一臂。
- 若林恩在她亲手输密码错误警报响起时让她连错三次以上直至上锁，则锁定冷却时间超过十分钟，她被迫看向林恩，承担「这一次必须依赖他」的首个峰会画面。
- 若林恩在门前主动召唤蚀痕化形先行探头进入，则「进入前窥视」代替「开门直触」，首帧时光定格的画面由蚀痕单眼主线而不是三人组的脚步切入。
- 若林恩拒绝带上更要钱小丑心脏下牢，则小丑借机袖手旁观，后续「孽灵追杀」时林恩失去「无序侦测」一层防火墙，进入 E423 时小丑被代替任务失败。
- 若林恩在门底结算前两重咒瞳试图透视时空涟漪，则面具从「有异常但无身份」反馈转换为「有异常高斯」，他的因果预测滤波器默认上线一档。
- 若林恩在尘埃时空定格瞬间主动伸手抓一颗尘埃弹开，则静帧被外力破坏一像素，她破坏这个宇宙警告的画面首帧被现场捕捉。
- 若林恩亲自选择走西路绕走机红砖墙，则地下空间绕路十二分钟，她前导地位被弱化，「黏丢主人」的气氛首次出现。
- 若林恩让喵喵台下探路代替以咒瞳，则猫行极稳，时光定格被猫爪推开一道缝，只有她意识到「喵喵也穿过了」这个细节。
- 若林恩在她矢口否认玩得花时让她「重做一次小小召唤法阵」现场验证，则她脸涨破一个笑点，「我发誓不说第二次」的夸张态度反而变成证词重锤。
- 若林恩主动把轰碎密码锁的举动作为向她证明「我代表力」的进场，则她首次把林恩不作为「被色诱猎物」而作为「合作伙伴」对待，「坏死」味转向「战友」味。
