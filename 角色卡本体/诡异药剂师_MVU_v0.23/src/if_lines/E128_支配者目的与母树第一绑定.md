# E128·支配者目的与母树第一绑定·if线

- 若林恩在支配者触手刺向自己之前主动闪入小小或艾雯身后掩护位，则母树无需替他截断刺击，「喂肥了谁」的质问被压成一声冷哼，支配者中段讥讽照常成立。
- 若林恩主动预告「我身上有母树的第一绑定」并以自身靠近触手引导反噬，则猩红咒线提前刺入触手，支配者自断触手的位置由中段改为根节，诅咒加深权柄颤抖更甚一拍。
- 若林恩在母树追问「盟约喂肥谁」时按玩家口径公开承认与她的既成关系，则母树反瞪一眼但被迫承认，支配者的「我会成为你的解药也会成为你的毒药」台词未说完就被反噬打断。
- 若林恩选择沉默不答、把公开权让给反噬自动验证，则默认走向成立，全场由咒线与万机之神代答，玩家保留绝不亲口承认的余地，本条只记录立场不强行承诺。
- 若林恩主动向母树暗示「我可以解开第一绑定」并把手中药剂或咒术作为筹码，则母树在反制支配者的同盟里多留一手，敌意未减但保护意图从「不得不」加成「留看可用」，后续支配者问责火力仍压在林恩。
- 若林恩顺手向支配者扔出亵渎之词提「当年她被我啪过」之类的耻痕细节，则母树根系当面抽出藤鞭把林恩倒吊，三方战线被开出一道母树—林恩对立的副场，支配者反过来成为看客。
- 若林恩在触手缠绕母树时主动冲向树干想办法剥离咒线，则反噬扩大的风险自担，母树记恨度上涨一档，但她保住自身的脱狱窗口被多撑半秒。
- 若林恩转头救助巨像之脑、把支配者的吞噬目标抬出战域，则支配者的「先消化再利用」链条被打断一环，他对林恩的杀意由「仇敌」升级为「首要灭杀对象」，E129 追猎火力前提被加深。
- 若林恩向万机之神发信让她带走银色幻想避开母树根系，则「女儿快跑」的原话被林恩代发，万机之神记住林恩这一次的示警，母树对林恩的仇意不变。
- 若林恩在反噬成型后主动表态「这是强制既成，非你我本意」，则母树不反驳、但对「本意」二字留一句冷讥，关系朝向「非自愿同盟」固定一格，色色调教口径仍按等待玩家主张展开。
- 若林恩保持沉默让母树独自吞下反噬，则母树替他挡下一波支配者追加攻势但伤势外显，她对他的立场从「敌视但不能让他死」加上「他欠我一笔」的债记条目。
- 若林恩尝试用左左名号或渡鸦旧称呼试图软化母树，则母树明确表示「不必装熟」，本条共情不成立，支配者讥讽的「可口」台词反而落得更重。
- 若林恩主动把巨镰折跃送入支配者本体近身位发起自残式冲锋，则支配者对林恩的评估从「杀即可」上调为「认真拔除一级威胁」，林恩肉体承担一次不小的代价，事件完成仍默认收束。
- 若林恩选择远距离甩药剂支援母树表皮帮她反制触手腐蚀，则母树在战后多留一息 время观察药剂师成药能力，后续恶堕调教线对药剂交互权重被拉高一档。
- 若林恩撤离战场中枢不与支配者照面，则母树必须独自承受全部绑缚与反噬，支配者完成「成为解药也成为毒药」的宣言段落完整无干扰，母树对林恩的债记转为「缺席记恨」。
- 若林恩在场但始终不吭声、不做动作、只旁观，则默认走向 100% 展开，支配者对林恩的定位由「绑定者」顺手加注「怯战无能之辈」的判断，E129 追猎优先级被压后一格给小小和艾雯。
- 若林恩尝试以傀儡线或咒术链路切断母树与支配者触手的接触点，则咒线反噬被引向链路中点，林恩吃下「刺伤+腐蚀」一次显形伤势，母树的反制窗口被提前一拍。
- 若林恩主动向巨像之脑坦言「你暂时不被吞噬」，则巨像意识空间在事后给林恩留一条私讯通道，E130 巫神头颅复苏接回家族重聚的两条通道之一被预先点亮。
- 若林恩当场摆开「三大根源互殴我煮汤」的脱离式姿态，则支配者与母树都不接这招，事件进入「咒线反噬+支配者暴怒驱逐异己」的并列局面，林恩的「中立人设」记录落空。
- 若林恩借反噬瞬间向支配者甩一份成形血肉药剂作回礼，则支配者本体增一层腐蚀增益但自身咒线腐蚀加倍，「谁和你交配过」的咆哮带出更重异色。
- 若林恩设法把小小或艾雯叫进战场中圈护在身后，则支配者对林恩的杀意锁定顺序由「母树+林恩」扩成「母树+林恩+小小」，后者被默认为绑定关联者，后续追猎顺位前挪。
- 若林恩在母树被缠绕时用嘴遁点燃她的愤怒值，则母树暴起更烈但被支配者更轻易镇压，绑缚时长被拉长，「罂粟般渴求」收尾多一拍讥讽。
- 若林恩尝试用隐秘咒术改写自己身上的第一绑定印记让支配者查无实证，则变形走「绑定事实曾被安全改写」通道，支配者的母树中继计划被压缩为纯粹力量剥削阴谋，亲密事实被抹除、不伪造。
- 若林恩在事件落幕前选择默不作声让咒线反噬自动镇场，则民风记录中林恩的公开姿态是「绑定方但不语」，母树对他的恨意被锁在最大值,E129 追猎时她的救援节拍被压到临界值。
- 若林恩以系统提示扫视全场、点出「母树中继+第一绑定」双阴谋的因果链，则林恩【推演】判定成立但母树会追问「你怎么知道第一绑定」，林恩必须再用一句话挡住，本条为难度提升分支。
