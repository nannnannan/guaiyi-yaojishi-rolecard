# E623·蓝龙启程·if线
- 若林恩在广场集合时主动询问母树她戳的是哪一笔旧账，则熊猫眼由「知情者心照不宣」转为「公开笑柄」，集合段气氛多一层调侃，艾维儿扶额加深一线。
- 若林恩拒绝按纱奈儿的要求发毒誓，只平静丢一句「信不信随你」，则闪电不落，纱奈儿仍被爷爷强制交付上路，但知道路途间信任铺垫延后到 E624 幻城前另行结算。
- 若林恩在毒誓内容中加入「若违背保证，让我师父的师父替我挨一道雷」，则雷声滚过随即停住，纱奈儿怔住追问，林恩摊手卸回去，誓言成立但担当指向被玩心卸掉。
- 若林恩俯身替纱奈儿戴正巫师帽前先摸出系统商城的龙骑士徽章别在她帽檐上，则「出息」情绪提前，化龙瞬间纱奈儿欢呼分两段炸开，AAA出现一物「龙骑徽章」落地账单记录。
- 若林恩主动帮老者打包行李，让他随队上龙背去紫罗兰世界看看，则老者摇头拒绝，只把家里剩下的传家宝「魔药底材」塞进林恩手里，留下一段未开销的赠送账。
- 若林恩在龙背上主动找艾维儿提月儿兰城，问她「月儿兰是不是你的母亲」，则她立刻恍惚收拢龙翼，「母亲命名」对话在更早高度落出，纱奈儿的欢呼被压回喉咙。
- 若林恩在穿云海时主动让左左从怀里探出头打招呼那只客机，则舷窗惊呼叠两波，「巨龙＋左手」被现代社会的航拍摄像机实时录入，紫罗兰世界某一天会流传一段「蓝龙背上的左手」神秘影像。
- 若林恩在飞行途中用心声问织梦「你在看吗」，则遥远的教学楼里笑吟吟的姿态停滞一秒，「欣赏宿命」的画面无声叠加一缕「棋子发现自己被观看」的初版裂痕。
- 若林恩把咒瞳视野钉在纱奈儿体内窥探本质，则读到大君血脉与三位一体波动提前一事件公开，但织梦立刻投来「他看到了」的注视，E624 幻城剥落时灵能强度明显进一步提升。
- 若林恩在临近南方大陆时突然要求先落月儿兰城看一眼，则艾维儿目光更恍惚仍按指示绕行一半，「擦肩」变「擦肩而过更多一次」，月儿兰城命名对话提前完整给出。
- 若林恩主动让巨像、母树、伊甸分别盯紧纱奈儿不许她跌下龙背，则纱奈儿的鸭子坐姿态被三双大手轮流稳当，「不正常的融洽」变成「三家同居的孩子」段落，母树对纱奈儿注意度 +1。
- 若林恩在海风降落前主动朝那座城市掷一支探测药剂，则液体穿越半空被某种灵能屏障无声消化，「完美融入现实的幻城」首次向林恩主动显形，他对纱奈儿的笑保持沉默。
- 若林恩在纱奈儿鞠躬恳求时伸手按住她的发顶不准她低下去，则她怔住抬头看见他，「求你别伤害老师」的恳求改写为「求你也别下跪」的平衡句，信任铺垫当场完成大半。
- 若林恩在落地后当众宣布「我打算把纱奈儿身上的师生锁链剪掉」，则纱奈儿愣住，织梦遥远注视的幅度明显加深一次，幻城段她现身的姿态从一开始就多一缕「防他拆台」的边角。
- 若林恩拒绝纱奈儿的恳求、直接说「来都来了，我自己走」，则她仍执意跟随，向导职责不解除，但「本可以不来但还是来了」的台词由她换成她自己低声自言自语，信任线更慢。
- 若林恩让左左展示一次巨像王后本源位格的灵能辐射给纱奈儿看，则纱奈儿怔住「哥哥姐姐原来这么强」，对林恩的信任垫高一级，但织梦在暗处多录一笔「王后本源在侧」的新牌。
- 若林恩在飞行途中数清沿途气象云层与时间，把「一千五百天修行抵不上此刻一秒」的感慨留在心里，则他选择沉默，但隔事件后一句台词在 E627 前后回到他嘴边。
- 若林恩主动问艾维儿「蓝龙真身是否分身之一」，则她咬牙否认，「真身是巨龙」的事实钉死，本体与分身区分记录进面板，后续 E632 解放段「蓝龙之躯扭曲」一行改写为他早有预判。
- 若林恩在纱奈儿介绍月儿兰城时跟她约定「等你二十岁我也帮你出首付」，则她惊喜嚷出声，爷爷远远听到，「冬泉谷重现辉煌」一句被林恩私人开支号上多挂一笔债务。
- 若林恩选择一直沉默看完所有桥段，则事件走向按默认推进，他在 E624 幻城剥落瞬间多一分直觉反应时间，织梦感叹「这家伙早就看穿了」。
