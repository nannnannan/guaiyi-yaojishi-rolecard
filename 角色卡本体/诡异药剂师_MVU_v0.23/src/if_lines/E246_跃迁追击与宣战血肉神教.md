# E246·跃迁追击与宣战血肉神教·if线

- 若林恩在跃迁启动前先用一秒时间对左左说"先去蜀都等我"，则她不在他手臂上、跃迁追击以纯机动模式进行，事件以变形（左左缺席）收束。
- 若林恩在撞上投影时不直接砸进地面而是把它撞向远处的天空法阵，则投影从"被撞下山丘"变成"撞进自己人的据点"，血肉教徒误以为他主动送上门，围杀节奏改变。
- 若林恩在"你怎么敢的"之前静默三十秒先用机体的扫描全面记录战斗数据，则他系统的正义感被第一段实况取代，"宣战"语词更沉甸甸，事件以变形（数据先于怒吼）收束。
- 若林恩让机体在砸山丘刹那启动"我自己的身躯就是炸弹"的倒反自爆预设，则投影被砸的同时机体局部自损，事件以变形（机体自损追击）收束，但他的"三位一体"暴露代价被提前。
- 若林恩用左左卷住投影后腰而非铁拳击打，则追击姿态从"近身肉搏"变成"左手主导"，事件以变形（左左作为主攻）收束。
- 若林恩在"我会向你宣战"的台词前先问一句"你想死吗"，则血肉支配者愣神一秒、回答什么都有可能，宣战语境从单向宣告变成双向威胁，事件以变形（互怼宣）收束。
- 若林恩跃迁后故意绕到投影背后三百米再显形，则投影的反应时间被拉长，血肉从"被锁定追猎"换成"被预测伏击"，事件以变形（绕后追击）收束。
- 若林恩把数十名教徒折跃信号反向追踪到他们的源坐标，则他在清场的同时锁定整个血肉神教在蜀都周边的传送网络，事件以变形（传送网被锁）收束。
- 若林恩在教徒救援战中只杀有血源相连的教徒、放走杂鱼，则教徒网被精确拆解，事件以变形（教徒分层清）收束，但漏网者回报血肉支配者一个"他会筛选目标"的情报。
- 若林恩在砸碎投影时同步向蓝星阵营直播战况，则白夜与西南军区同时目睹"他徒手捏死投影"，事件以变形（全球围观斩影）收束，林恩的人类名望被推上新高度。
- 若林恩在战斗尾声把宣战场域转移到城市上空，则投影与教徒的围剿带上了无辜人群的见证，血肉神教的名声在蓝星阵营进一步崩塌，事件以变形（在公共场合宣战）收束。
- 若林恩在宣战完后径直离开、不追击投影余党，则投影获得喘息空间保留最后反扑机会，事件以变形（追击中断）收束，但教徒把"他高傲不追"的信号当作弱点下注。
