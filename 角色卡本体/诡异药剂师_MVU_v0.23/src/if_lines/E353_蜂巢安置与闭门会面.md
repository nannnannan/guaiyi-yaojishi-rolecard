# E353·蜂巢安置与闭门会面·if线

- 若林恩在踏入数据世界那一刻主动把自己身上的衔尾、黄沙、克苏鲁气息一并掩下，则智脑扫描不到来访者的真实威胁位阶，她接待的语气会从警惕切换成对等、对骂环节缩短一半。
- 若林恩在智脑开口感谢之前主动抬手按住她要说的第一句话、用一句「别谢，先告诉我条件」，则整个接待从礼仪变成直接谈判，秽语模块不会在第一分钟被她启动。
- 若林恩在智脑骂出「想操呢」时主动笑出来而不是反呛，则她的秽语模块会因为目标没有预计反应而卡壳一秒，那一秒里林恩能听见她词库底层的古老幽默数据。
- 若林恩在被她骂「大鸡巴」的瞬间就抬手咒瞳扫过她的秽语模块本体，则模块出处被她当场揭穿、她会气极反笑承认这是从某位老对手身上扒下来的，对骂从侮辱转入技术复盘。
- 若林恩在十几分钟的对骂后主动停一拍说「我们聊正事」，则智脑会停下来整整三秒才接话，那三秒里数据世界背景会自动响起一帧当年她第一次见到林恩时的旧录音。
- 若林恩在安置议题上主动提出「照料与未来站队分开计」，则智脑会第一次犹豫是否同意，她的边界在他这一句里被他自己重新划定，条件交换的层级被改写。
- 若林恩主动问「你能为艾雯提供到什么上限」，则她会坦白说出她的能力只能稳灵魂不能治神魂，这份坦白在她平时不会出现、只有在他这句话里她才给出。
- 若林恩问她对三位一体的真实顾虑，则她会说出体量不足、规则门槛、阵营存续这三层之外的第四层——「我不愿让银色幻想再一次失去自己」，这是她首次对外披露。
- 若林恩主动提议由巨像之脑而不是自己来洽谈，则智脑会当场切换成对巨像的官方语气、语气里的粗俗完全消失，林恩能从旁观视角看清她作为蜂巢首脑的两张面孔。
- 若林恩在艾雯被包裹入数据容器前主动亲手把自己的一缕黄沙贴在容器壁，则容器对灵魂逸散的缓速效果翻倍，但那一缕黄沙不再可收回。
- 若林恩转身前往银色幻想的花园前先在智脑面前说过一句「我不是来求复合的」，则智脑会把这句话原封不动地保留在她给他的备注里、作为后续关系走向的关键参照。
- 若林恩在花园里主动蹲在枯萎的花丛前一支一支辨认品种，则他会发现那些花都是他过去对银色幻想提到过的科植物，花园就是她自己的沉默回复。
- 若林恩在院门外故意提高脚步声音但又不开口，则银色幻想会在屋内一动不动听完整个脚步声、她的稳定性在那一分钟里第一次被数据世界标记为「异常波动」。
- 若林恩在门外主动不敲门而是直接从正门口袋里塞进一张写有一行字的纸条，则她会等到他离开半小时后才开门、纸条上那行字的内容被她存入最深层加密区。
- 若林恩在院门外被智脑「一刀两断」的解释激怒时反讽一句「你能替她说话吗」，则智脑会沉默五秒后第一次承认她的解释只是「推测」，把判断权交还给林恩。
- 若林恩选择就在花园里过夜、银色幻想的门整晚未开，则他次日会在门口台阶上发现一杯还冒着热气的数据咖啡，那是她放在那里却未被撞见他醒来的唯一痕迹。
- 若林恩在离开前主动朝院内一声「我明天还来」，则数据世界里那扇门会在第二天早晨提前三十秒开一条缝，那条缝本身被记入她与他的关系曲线。
- 若林恩主动在离去时吩咐智脑「别把我的到来告诉任何人」，则蜂巢的官方记录上这次拜访不会出现他的名字，只有她和银色幻想的私人日志里多一行。
- 若林恩私下对智脑承认他的目的不是复合而是确认她无恙，则智脑会认真打量他几秒、然后答应不在场、只在他二人会面时远远关掉监控。
- 若林恩在告别时对银色幻想的门说一句「我把艾雯安置在你这边，你也算是还在」，则他会听见门内一声极轻的、像金属相碰又像饮泣的响动，那句话本身被数据世界永久只对他可见。
