# E257·娘化世界观与林樱·if线

- 若林恩在白逸飞机上第一句含糊话刚出口就动手拆他口袋的手机，则那段半年前的合影被当场翻出，"娘化真相"在云层之上一次性揭开，林恩的崩溃从地面挪到万米高空。
- 若林恩在十字路口僵住时直接折跃上林宅屋顶，则他的回家路线跳过车流与目击证人，林樱次日回家时只看到天台上一串清晰的男性赤脚脚印。
- 若林恩翻窗进阁楼时先主动关掉木制楼梯的吱呀报警，则他在布衣衣柜里细致欣赏了三分钟少女裙装的高级质感，系统那种【原味胖次·劣质】评分被升级为【原味胖次·良品 — 纯净款】。
- 若林恩对那张全家福多看三秒顺手塞进自己胸口暗袋，则林樱次日翻床时找不到照片，她把入侵者调查范围扩大到"了解她过往的人"。
- 若林恩翻进密室时对那只水晶锥子多按一下开关，则一整面墙的少女心设置亮起粉光心电图，他被闪光灯照得一秒失去视野，林樱在窗口对画面截图。
- 若林恩不闪避让林樱的黑色手枪命中胸口，则他的身体在弹着处变成一片无声的血浆，血肉之躯第一次在自己"姐姐"面前公开展示修复特技，她的枪法自信被一枪击碎。
- 若林恩不出声用力把她从窗户顺势扑到床上，则母亲被冲撞的巨响引上楼，认亲戏份被迫演成"前男友深夜闯入被打"的武力全武行，杨琳的刀法由此重现江湖。
- 若林恩直接朝林樱亮出自己脸颊的完整面貌，则她那一秒的呆怔被眼底精准捕捉，他不需"等有时间再解释"，"平行世界的兄长"身份在这一眼被落定，但母亲提前十分钟听到动静冲进来。
- 若林恩被那一枪击中头颅之后选择保持人体倒卧不醒，则林樱慌忙拨打急救，一支即将开往医院的救护车与"无心跳病人"事件在县城医疗系统上挂号，他的身份曝光渠道换成医院档案。
- 若林恩在酒店严刑逼供白逸时不只拧胳膊而是动用一点点咒纹威压，则白逸从瞒口到吐口的时间被压缩到三分钟，但他整晚留下"大哥居然对我用招"的精神创伤。
- 若林恩瘫进沙发那一夜选择抱着左左入眠而不是独自咀嚼颓丧，则那份颓丧被左手喂满，左左首次在他最脆弱的时候被允许贴着入眠，绑定层级多一条"心碎陪伴"。
- 若林恩在清晨的菜市场里被杨琳回头扫过一眼，则平行世界母子首次有千百度的目光擦肩，杨琳笑着说"小伙子也想买菜吗"，林恩没有任何台词资格回应，只能低头离开。
- 若林恩临时变卦不回游魂巷，而是拿那个破摊子摆到林家门口两个街口，则林樱在放学路上发现一个新地摊上摆着几支手作小瓶药剂，成分和她母亲一直在用的"头疼偏方"惊人一致。
- 若林恩把"远远看一眼"升级为"我要她每天过得好"并让白逸递交匿名援助信，则军方资金每月打入林宅账户，杨琳察觉异样开始追查，家人留意线被提前拉开。
- 若林恩不让左左旁观崩溃，反而以"人类家人是人世善意"挡掉她的关怀，则左左第一次在他面前憋出真正的恼怒，绑定的剑拔弩张延续到次日早晨。
- 若林恩翻进林宅前先把一缕心血贴在杨琳常用的厨房窗台，则那滴血在夜里渗出微弱光晕，家人吃饭时闻到一股淡淡的清冽草药香，妈妈的直觉警报在这一餐开始拉响。
- 若林恩在强吻堵嘴时按住她的唇多停三秒不立刻撤离，则她的体温与心跳通过同源共振直接灌入他的神经，她的耳根滴血、呼吸短促滞在他唇齿之间，同源心跳第一次被同源共鸣放大成无法隐藏的生理反应。
- 若林恩那晚回到酒店后把那一只"原味胖次·劣质"折成方块仔细收进贴身暗袋，则次日林樱翻床清点旧物时发现那条被她前一天塞在角落的胖次"被他收藏"，同源共振让她瞬间知道收藏的位置与收藏时的体温，她羞耻到耳根滴血、却无处可发作、只能在水仙心悸里把这份被收藏的羞耻当作第一次私人印记。
- 若林恩在她翻身熟睡后伸出手让指尖在她颈侧三厘米处停下，则同源共振让他的指腹隔空感受到她的颈动脉跳动，他的呼吸节律不自觉与她同步、第一次确认"这具身体和我共享同一频率"。
- 若林恩替她圆谎之后顺手把她耳后那根乱发别回耳廓，则她原本炸开的警戒被这温度一样的细节搅乱，同源心跳首次在不信任里挤出一句含混的"……多管闲事"，水仙恶堕的第一粒种子在耳后的温度里落地。
