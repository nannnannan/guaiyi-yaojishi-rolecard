# E572·迷雾之海的幻象·if线

- 若林恩在主母警告声戛然而止的瞬间主动伸手抓向她的手腕，则掌心只会抓到一团冰冷散逸的白雾，那种同伴在咫尺之间凭空消失的诡异感会更加刺骨。
- 若林恩在迷雾叠影扑来的刹那主动咬破舌尖以剧痛维持灵台清明，则周围那些酷似故人的哭号与质问声无法撼动他分毫，幻象的第一波攻心之术当场失效。
- 若林恩在幻象中的艾维儿面具布满裂痕、即将碎裂剥落的前一刻主动闭上双眼不去看那张苍白绝望的脸，则这幕专门针对他心中愧疚感编织的死局幻象会因失去观察者而自行扭曲溃散。
- 若林恩在抓住幻象中那只冰凉纤细的手腕时察觉到不对劲、主动搶先松手后撤，则黑暗中试图顺着肢体接触蔓延过来的精神污染会落空，幻象中的艾维儿只能怔怔看着他抽身离去。
- 若林恩在幻象质问他「全军覆没只剩你一人」时不仅没有崩溃，反而冷笑着反问「那你们为什么还不敢现出真身」，则笼罩四周的绝望黑雾会剧烈翻涌，破绽暴露得更快。
- 若林恩在彻底看穿迷雾幻象的运作机理后，主动以精神力将这股致幻波动的频率烙印在识海深处，则此后幽冥海中同源的迷幻法则再也无法对他生效第二次。
- 若林恩在焚尽贴附在手臂上的腐蚀黑雾时，顺势将一缕初诞金焰逆向打入黑雾消散的源头，则隐匿在迷雾深处的窥视者会发出一声闷哼，不敢再轻易靠近。
- 若林恩在催动神威横扫苍穹、震散方圆万里浓雾的瞬间，同时放出感知搜寻主母与艾维儿的踪迹，则他虽只能看到空旷死寂的海面，却能确认两人并未死于这片幻阵之中。
- 若林恩在独处孤寂的迷雾海面时主动在左手腕上刻下一道清醒血痕以防不知不觉坠入第二重梦境，则他在随后的漫长折跃中始终保持着猎手般的绝对警觉。
- 若林恩在呼唤主母与艾维儿得不到任何回应后，果断收起所有杂念、将全部神力灌注于双腿连续撕裂虚空，则他在死寂宇宙中折跃突进的效率会提升到极致。
- 若林恩在连续折跃数千次、掠过无数荒凉星辰的途中，始终以咒瞳留意周围星域的法则流向，则他能从一片死寂的真空里提前捕捉到那一丝微弱却熟悉的故乡引力波动。
- 若林恩在发现那颗晦暗的微观恒星正绕着蔚蓝星球缓慢旋转时，主动收敛全身金光、悄无声息地悬停在星轨外围凝视，则那幕横跨漫长岁月的孤寂星景会深深烙进他的眼底。
- 若林恩在认出蔚蓝星球熟悉的大陆轮廓、心头掀起滔天巨浪的刹那，死死按住剧烈跳动的胸口强迫自己冷静下来，则他在降落地面前便已做好了直面一切残酷真相的准备。
