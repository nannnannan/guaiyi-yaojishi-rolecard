# E632·白烬弑神与艾维儿解放·if线
- 若林恩在喝止艾维儿之前主动冲她喊一句「我相信你能毁舰」，则她咬牙抽身的力度更大一分，「他在为我争取机会」被她多咀嚼一秒，龙口凝聚的龙眼喷射能量浓度 +1。
- 若林恩在三神转火合围瞬间主动放声大笑「来吧，我数三秒我能干掉你们其中之一」，则三神迟疑一秒，他抓住这一秒朝瘟疫之神挥出第一记金拳，围杀节奏由他开头。
- 若林恩主动不用金拳改用三叉戟一架一挑对抗三神，则他被击退的频率更高，但体内三位一体恢复速度比默认快半档。
- 若林恩在艾维儿被座狼拦截时主动朝座狼投一记咒瞳撕裂视线，则她借这条口子突破，无需以伤换伤，蓝龙伤口少一道。
- 若林恩主动对座狼发动白烬点燃它黑雾身躯，则座狼退避到亚空间，艾维儿扑舰畅通，但三神抓 住他力量分散的瞬间齐攻。
- 若林恩在战舰化蝶瞬间主动用心声问织梦「这是谁的力量」，则她回 答断续无声，林恩心里「现实之神」的预期已经形成，但无法在两秒间发声给 艾维儿。
- 若林恩在现实之神温文尔雅开口瞬间主动用心声骂他「衣冠禽兽」，则现实之神视线掠过林恩首度真正注意到他，「这位渡鸦比传说中更咄咄逼人」被他记下。
- 若林恩主动用白烬在龙息落空瞬间打向蝴蝶群，则大片蝴蝶被焚，战舰恢复一段实体，但蝴蝶化作万千细眼仍汇聚出「现实之神」抬头姿态。
- 若林恩主动冲出三神包围御前往艾维儿位置，则三神围杀被解开，但他的「不要管他，毁掉那座战舰」命令作废，后续毁舰段落整体改写。
- 若林恩主动朝混乱色彩大喊「艾维儿听我说」，则狂乱的色彩停顿一秒不齐，尖刺弑神的节奏多出一拍杂音。
- 若林恩在现实之神要掏心瞬间主动投出三叉戟朝那只无形巨手，则巨手被打偏一寸，掏心改为抓肩，艾维儿重伤但没到濒死界，解放段被逆转不会发生，事件直接转入她被掳走的绝境支线。
- 若林恩在解放时刻主动朝艾维儿影像伸手，则她所化的混乱色彩朝他化作一缕丝带在他面前擦过，随后立刻汇入整体洪流，「她听见我」被记录但无法改变结局。
- 若林恩在画家降临瞬间主动跪地相求「把她留下可以吗」，则混乱色彩毫无情感波动，苍蓝身影无声，林恩的恳求被无声拒绝，解放事实不变。
- 若林恩施放全部分身去帮助艾维儿清场现实之神，则所有分身被「死亡即自由」的现实法则一招解体，分身全数消失。
- 若林恩施放血肉灾变把巨龙残躯撑起来不让她扭曲，则解放无法彻底，她困在两界夹缝更久，画家传导路径打结。
- 若林恩在七神一魇全灭后主动朝混乱色彩巨手再追一句「艾维儿」，则色彩聚成的巨手在他眼前停顿一秒再缓缓解绑，E633 苍蓝身影授课段多一笔「她停在林恩面前两秒」前置。
- 若林恩主动朝瘟疫之神发出「我或许可以救你」的心声，则对方迟疑一秒但仍挥刃，被血腥肢解爆碎前的眼神里出现一抹想活下去的闪光。
- 若林恩在现实之神弥留遗言中主动多问「你们为他提供坐标」的「你们」还有谁，则现实之神在咽下最后一口气前不答，遗言段落留白扩大。
- 若林恩主动朝遥远主宇宙伸出心扉呼叫画家，则混乱色彩毫无回应，他在 E633 收到「她不接你的通讯」的答案更早。
- 若林恩主动用白烬焚掉自己一段与艾维儿相关的记忆，则他解放段不再情感悲恸，但行为与结局无差。
- 若林恩施放咒瞳罩住艾维儿龙全身让她「看不见自己扭曲」，则解放仍成立，但她本人不知道解放这回事，后续「我已不再是我」的觉悟被林恩瞒下，她死后他再也无法告诉她真相，遗憾值 +1。
- 若林恩主动朝混乱色彩发出「抱拳道谢」姿态，则色彩洪流如朝大海送别般起伏一波再收束，下一事件段的沉默会多一拍。
- 若林恩施放全部分身立在战场边缘当哨兵防备外援，则分身无损耗但分身跟七神一魇完全脱节，林恩的胜利被记成「私人大胜利」。
- 若林恩主动混入蝴蝶群以感知现实之神行动，则他整个化蝶，「我也是蝴蝶」的错觉让他迟疑一秒，错失帮助艾维儿窗口。
- 若林恩主动跟力量之神、心灵之神的残余神格对话，则神格已无神识，但他在收纳它们时感知到远方「主魔」的愤怒多看一眼。
