# E600·魇与最后的黑剑·if线

- 若林恩的意识体在摁住银幻时多说一句「让无序生灵去撞舰队」,则银幻第二次阻击的引导节奏被他亲手收得更明确,但她对他的指挥官服从度数据里多一条「父亲式授权」。
- 若林恩的意识体不摁住银幻,任她踏入走廊,则她以身为饵成立,血神追她一个,小丑独行,魇线照旧,但她机体被追到只剩头颅级残件。
- 若林恩的意识体在摁住银幻之后追加一句「让魇先动手再破盒」,则小丑封魇节奏后移一轮,但小丑本人会被黑镰多穿一次,心脏位置多一道从前胸到后背的旧痕。
- 若林恩主动以精神分流向小丑传递一句「乐者残存可被八音盒认出」,则他对魇的反制提前半拍,封盒时点前移,但梦魇一脉第一次记下「渡鸦能喊到原初无序」的注脚。
- 若林恩的意识体在战场现身形态不是人间相而是渡鸦全相,则银幻第一反应是退后一步短路,小丑当场破口,「熟悉温柔笑脸」画面被完全改写。
- 若林恩的意识体把「时间,足够的」改成「已足够,我来了」,则血神扑到深渊入口提前,但封魇收尾照旧,魇进盒的画面多了一个远远望着渡鸦的凝视。
- 若林恩的意识体选择只共享视野不现身,则银幻真要踏进走廊,小丑会被迫自己上前把她拖回来,第八十次被机械姬冷眼顶嘴。
- 若林恩的意识体在多摁那一秒里把一缕三位一体灌进银幻机体修复她半身,则她稳住了立刻想要再上前的冲动,但灌注量被她从面板里读出后,她对造物主的敬畏参数 +1。
- 若林恩决定不让小丑拔出初诞者碎片,改由意识体亲自送剑过去,则小丑封魇不用贯穿伤换,但初诞者入体的那刻他体内旧权柄不再共鸣,八音盒半合不上。
- 若林恩主动在小丑封魇前泄露一句「你是权柄,你不是仿造」,则他的自白提前一帧,封盒后小丑的反问声少一层,后续七大神王讲解他旁听时少一拍尴尬。
- 若林恩的意识体提前在乱流边境铺下三具「渡鸦静止相」,则血神扑向深渊途中会撞上其中一具,被拖半秒,但渡鸦一方数据里多一行「三度时间为零出关」。
- 若林恩主动以心声提醒银幻「留一座引擎不引爆」,则她手上的底牌由两座变三座,后续小丑撞墙时她兜里多一枚可扔。
- 若林恩决定把无序生灵的释放改成两连发,则第二只被提前丢出,血神出手时遭遇的是二连撞,但第一只被引到舰队的标定更粗糙,舰队部分复制体被撞散入走廊内壁。
- 若林恩的意识体在银幻踏上走廊前追加一句「别急」,则她停顿一秒,小丑有时间飞回来再把命令压下,但血神扑来的那半秒第一道锁定锁到了小丑。
- 若林恩让左左在这场现身里与意识体同出,则银幻被摁住的同时也接住一只塞进她怀里的绿色小触手,小丑封魇的画面里多一道软乎乎点缀。
- 若林恩的意识体对艾雯爵士发送「等我来」的灵能传讯,则她在第四位面入口多扛一线,庞杂军队节奏不变,但爵士本人体表灵能光度暴涨一阶。
- 若林恩决定不以精神分流现身,而是直接结束闭关,则全 E600 之后的本事件链整体重排,防线未成,E601 之后的所有故事线一并改写。
- 若林恩主动让小丑封完魇后立刻把八音盒丢入系统空间,则后续议事厅那一幕小丑拍盒上桌的画面被改成光子般闪出,但魇的一瞬间震撼消失。
- 若林恩的意识体在摁住银幻时顺手把喵喵从怀里抛出贴在她衣领,则她在后续乱流边境整段路途都有一只猫蹭在她脸颊上,机器人面板里多一条「陪伴参数」。
- 若林恩的意识体在说出「时间,足够的」之后直接散形消失,则银幻被留在原地,小丑被迫面对一个突然又消失的渡鸦,后续祖线对白里多了一段他破口大骂的额外音轨。
- 若林恩的意识体在现身的瞬间顺道扫了小丑的伤处并以三位一体轻稳一次,则他胸口贯穿伤凝血快一阶,但同时初诞者碎片共鸣也减弱,封魇时黑镰撕出的走廊空洞稍小。
- 若林恩让小丑在封魇完成后才放出第二只无序生灵,则血神扑到前线时已被两只生灵各拖一线,但敌军通过舰队的总耗时被错开压制。
- 若林恩的意识体在摁住银幻的瞬间十五度看一眼小丑,则小丑整段封魇画面里多一束「渡鸦在场」的安定参数,但他本人没注意到。
- 若林恩决定在这段让艾维儿继承黑剑前就跨境,则黑剑不落林恩身前,血神扑击的第一道对撞直接对上蓝发王女的手腕。
