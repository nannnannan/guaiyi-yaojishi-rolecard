# E343·送葬魂灯与灭狱赌局·if线

- 若玩家点燃【时间的魂媒】时先朝灯芯吹一口气，则灯火在废墟中摇曳成送葬队列的形状，喵喵的影像第一个汇入灯内。
- 若玩家在夜医队长喊「不许哭」时主动递上一块手帕，则队长用帕子捂住脸，队列在压抑的呜咽中继续前进，火把的光晕在泪水中变得模糊。
- 若玩家选择只收尸不复仇，则夜空在送葬结束时泛起微光，残余夜医把灰烬埋入城墙裂缝，裂缝中长出第一株无烟的紫色小花。
- 若玩家把旧日少年的影像从灯火中抓出来对话，则影像在触碰瞬间碎裂成光点，光点在地上拼出「哥哥」两个字后熄灭。
- 若玩家让左左在送葬队里举火把，则咒体的小手被火焰灼伤，她的咒纹在火光中第一次露出近似人类皮肤的质感。
- 若玩家在两名法阵夜医瘫坐时先递上一杯热茶，则他们在颤抖中接过茶杯，茶杯上的裂纹恰好拼出「赌」字的形状。
- 若玩家把召唤倒计时的十秒改为三秒，则狱卒的「住手」在第三秒零一毫秒抵达，谈判的窗口被压缩成一次心跳的缝隙。
- 若玩家在蓝星海底法阵启动前先朝大海扔了一块石头，则石头下沉的速度在那一刻变慢，海底的封印出现了一次不属于剧本的波动。
- 若玩家用血在广场地面上画出自己的指纹，则指纹在紫色光柱中变成召唤的坐标，坐标被广播到主宇宙时多了一道生物加密。
- 若玩家让智脑在倒计时里同步直播给银色幻想，则她的数据链路在「九」那一秒出现一次无法解析的波动，波动中传来「回来」两个字。
- 若玩家在灭狱赌局启动前把所有以M结晶埋在广场中央，则结晶在黑暗落下时绽放成屏障，屏障的晶莹中映出天堂之门的轮廓。
- 若玩家让左左在系统空间里为送葬的魂灵唱歌，则咒体的声音穿透屏障，灯火在废墟中摇曳成更多的送葬者形状。
- 若玩家把时间魂媒的灯油倒出一滴给残余夜医，则那滴油在夜医掌心变成一颗种子，种子的芽孢在灰烬中长出能短暂停留时间的叶片。
- 若玩家在外宇黑暗突破边界时主动张开双臂，则湮灭的洪流在他身前分流，分流的轨迹恰好避开两名法阵夜医的位置。
- 若玩家把白夜的金剑插在广场法阵中央，则剑柄上的守诺灼痕与紫罗兰阵纹共鸣，召唤的坐标被锁定成「守诺之地」而非「毁灭之地」。
- 若玩家让残余夜医在倒计时里齐声数秒，则数到「一」时他们的声音与狱卒的「住手」重叠，谈判的窗口被他们的声音撑开了一秒。
- 若玩家在无祭品召唤提示出现时回答「祭品是我」，则系统界面出现一次判定混乱，混乱后的召唤坐标指向了某个被遗忘的名字。
- 若玩家把乌鸦臂章抛向高空作为信号，则臂章在苍蓝色天空中变成一只真正的乌鸦，乌鸦的鸣叫让狱卒群的动作出现一次迟疑。
- 若玩家让左左在系统空间里用咒纹画出自己的笑脸，则笑脸透过屏障映在外宇黑暗上，湮灭的洪流在抵前出现了一次可观测的迟疑。
- 若玩家把主母的黑羽插在广场法阵边缘，则黑羽在紫色光柱中燃烧，燃烧的灰烬组成了一条通往某个古老遗迹的地图。
- 若玩家在倒计时「五」时突然对天空说「你们真的敢看吗」，则温度降到冻结灵魂的瞬间，无形注视第一次出现了「退缩」的波动。
- 若玩家把蓝星法阵的启动按钮设计成只有他能用自己的血液激活，则他在按下时感受到一阵不属于这个世界的引力，引力来自海底封印的某个存在。
- 若玩家让智脑在通讯里问银色幻想「你会来吗」，则她的数据链路在沉默三秒后回了一句「我在看」，但看的内容被加密成最高优先级。
- 若玩家在灭狱赌局启动前把黑弦月的灵魂线缠在火把上，则火把在送葬队列中变成了引魂灯，魂灯的摇曳中出现了不属于任何先知的画面。
- 若玩家在广场法阵启动时主动朝无瞳法阵伸出手，则瞳心的紫色花蕾在那一刻盛放到最大，紫罗兰的能量顺着他的手臂爬进他的血管。
- 若玩家把旧日女孩照片放在法阵中央，则照片在紫色光柱中变成一张符咒，符咒的燃烧让召唤的坐标多了一层「守护」的伪装。
- 若玩家在十秒倒计时里用牙齿咬破舌尖朝天空喷血，则血腥味在冻结灵魂的温度中扩散，扩散的血液让狱卒的「住手」出现了一次无法解释的迟疑。
- 若玩家让左左在系统空间里为两名法阵夜医祈祷，则咒体的声音穿透屏障，两名夜医在瘫坐时突然感受到一阵不属于这个世界的温暖。
- 若玩家在外宇黑暗突破边界时主动把手伸进湮灭的洪流，则洪流在触碰瞬间冻结，冻结的洪水中浮现出某个正在注视着他的存在。
- 若玩家把时间的魂媒灯芯拆下来编成一条手链，则手链在送葬队里变成了一条可以拴住时间的绳，绳的另一端拴着尚未消散的魂灵。
