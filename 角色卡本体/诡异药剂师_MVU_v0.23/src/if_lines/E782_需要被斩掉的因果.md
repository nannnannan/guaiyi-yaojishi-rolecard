# E782·需要被斩掉的因果·if线

- 若林恩在时间终点主动用完整黑火硬接空白实体一击,则他会被击退三步,根骨裂一线,但他会在那三步里第一次实测出空白实体能被打退的距离。
- 若林恩主动让左左把当前时间桥从外侧固定改为缠在他自己左手腕,则左左能腾出手来施放第二道法术,但林恩的左腕从此烙下一圈银白的桥纹。
- 若林恩在击溃某只噩梦时主动保留它的石影残片不烧掉,则那块残片会作为 E786 的物证,但它会在林恩口袋里持续散发噩梦气息一整夜。
- 若林恩主动把自己的一段因果裂痕用黑火当作刻刀自割,则他能精确控制裂痕闭合的位置,但他要当场吞下一次比空白攻击更剧烈的内伤。
- 若林恩放任噩梦把某段历史裂痕转化为本体力量不阻止,则该裂痕在 E783 会凝成一只新型噩梦,但他在转化过程中能逆向追出噩梦本体的位置。
- 若林恩在撤退前主动把左左先推进时间桥而自己断后,则左左会在桥那头转身伸手拉他——那一只伸回来的手会成为 E784 两人重逢的画面锚。
- 若林恩主动把空白实体引向某尊特定噩梦石影让其对撞,则他与左左获得三秒空窗撤退,但那尊石影在对撞中碎成不可控的细小碎片四散时间底部。
- 若林恩在战斗尾声对溃败的噩梦群喊出一句「你们也是被烧掉的」,则会有三只噩梦突然停下攻击,他们的石影崩解成可被林恩拾取的「失败纪念」。
- 若林恩把完整黑火拆成七条细线同时缠住七只噩梦,则他能同时压制七只的反击,但余下六十四只会顺着他的分身空隙蜂拥挤进他的因果裂痕。
- 若林恩主动让左左在时间桥上手绘一幅当前时刻的小型锚定,则这幅锚定在 E787 会作为他的备用回归钥匙,但左左的手指必须全程按住画布不放。
- 若林恩在空白实体即将反击瞬间主动朝它掷一支绯红罪火而不是闪避,则空白实体会出现第一次的短暂停顿——停顿的长度不足一秒,但足够让左左完成一句咒语。
- 若林恩让喵喵(若随行)叼走某只被击溃噩梦的核心晶,则晶在回程会持续渗出梦境渗液,E784 林恩能从中提取一段「噩梦侧的梦主观测」。
- 若林恩主动朝时间长河底部望去寻找被抽离的渡鸦记忆痕迹,则他会看见一群半透明的面孔在深处睁眼——那些面孔会在 E789 与他当面对峙。
- 若林恩在溃退时故意把一件随身信物留在时间终点引开空白实体,则空白实体会在信物上耗费一轮攻击,但林恩就此失去一件能证明自己身份的实物。
- 若林恩选择让渡鸦因果裂痕自然闭合而不主动干预,则裂痕会在 E784 自愈,但闭合意味着渡鸦群体从此脱离林恩的可干预轨道。
- 若林恩主动用黑火在自己胸口烙一个「此身未死」印记,则该印记会在 E788 成为空白实体截杀失败时唯一无法篡改的反证物。
- 若林恩在战斗前主动与左左十指相扣约定不放手,则两人回到当前时仍紧紧相扣,但林恩从此左手一段时间内无法执武器。
- 若林恩放任自身某段根骨在终点裂痕中碎裂而不强求完整,则他在 E783 会成为一个「有残缺」的林恩,残缺反而成为空白实体难以计算的盲区。
- 若林恩主动对时间终点的黑暗喊出一句「下次我还会来」,则空白实体会把这句话录入记忆,E789 截杀时不再给他任何试探窗口。
- 若林恩在退回当前时间前主动把一段绯红罪火封进时间长河底部的某道裂缝,则那缕火会在 E786 燃烧起来,为他标示一条可走的反向路径。
- 若林恩选择保留所有自身过去的轨迹不做任何抹除,则他抵达当前时会感觉记忆比离开前重了一分,但他仍是那个左左认识的林恩——左左能在桥头立刻叫出他的名字。
- 若林恩主动把击退空白实体那一击的受力感受在撤离前低声告诉左左,则左左能据此优化下一座时间桥的承重,E783 的桥本稳定度提升一档。
