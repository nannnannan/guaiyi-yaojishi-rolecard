# E782·需要被斩掉的因果·if线

- 若林恩在踏入时间之末的黑夜城废墟前先让左左将他的气息与整座残破城市的阴影同步，则他在第七十二柱黑衣人影察觉前能多向前推进百米，亲手触碰到一根终焉巨柱的冰冷表面。
- 若林恩在黑火领域与第七十二柱黑衣人影正面碰撞的瞬间主动收缩火焰半径以凝聚穿刺力，则他的黑火能刺破对方周身翻涌的灾厄黑雾三寸，看清黑袍下那截与自己别无二致的苍白下颌。
- 若林恩在被灾厄本体的绝对质量震退时主动借力将左左推向后方的时空裂缝，则左左能毫发无损地架稳返程通道，但林恩自己的右肩骨骼会在硬抗余波时碎裂一道细纹。
- 若林恩在终焉王座下的七十一尊噩梦苏醒咆哮时向它们投掷一瓶浓缩的深渊腐蚀药剂，则冲在最前的三尊噩梦会被短暂糊住视线，为他撤离时间之末腾出三秒空窗。
- 若林恩在撤回时间长河中段后没有立刻推演战局，而是先把左左冰凉的双手拢在掌心用温火暖热，则左左紧绷的神经会迅速平复，随后在推演时间神王踪迹时主动帮他补上一处关键盲点。
- 若林恩在分析第七十二柱黑衣人影的攻击招式时将其逐一拆解并复刻进自己的剑术记忆，则他在下一场时间交锋中对同源黑火的招架成功率会提升三成。
- 若林恩在推断出时间神王未死且藏身于时间长河某处后，主动以黑火在虚空中写下一行挑衅的战书任其顺流而下，则时间长河深处会传来一声若有若无的冷笑回响。
- 若林恩决定前往天堂之战早期寻找织梦前，先与左左约好一套只有两人懂的敲击暗号以防在时间乱流中迷失，则这套暗号会在后续跨越千年的守候中成为两人确认彼此的定心丸。
- 若林恩在左左维持梦境投影略显吃力时主动分担一半的精神锚定重量，则左左的投影会重新变得凝实，她会在他耳边小声嘀咕一句「脑袋现在的力气比以前大多了」。
- 若林恩在离开时间之末的最后一瞬回头将一缕黑火钉在黑夜城废墟的断墙上作为坐标，则他在终局决战重返此地时能凭借这枚坐标瞬间锁定王庭入口。
- 若林恩在复盘自身与黑袍大君的体量差距时主动放弃单纯堆砌黑火数量、转而锤炼火焰的纯粹度，则他体内的深渊黑火会凝练出一丝暗金色的纹路。
- 若林恩在向早期时间线跃迁前主动将沿途收集到的几缕破碎渡鸦残魂安放入【黄金梦境】休养，则那些残魂会在梦境边缘化作守夜的飞鸟，替他预警来自时间长河外部的窥探。
- 若林恩在推演出「必须斩掉过去冗余因果」的结论后，当着左左的面郑重承诺绝不斩掉两人共同的记忆，则左左原本不安耷拉下去的眼角会立刻弯起来，用力点头说「左左替你记着」。
- 若林恩在穿越时间乱流时遭遇时间神王布下的暗流陷阱并选择以空间切割硬行劈开，则他虽会损耗两成灵能，但能当场缴获一枚残留着时间神王气息的时之碎屑。
- 若林恩在进入天堂之战早期的时空节点前先换上一身不起眼的灰布斗篷掩去深渊气息，则他在降临初期不会惊动正在混战的旧日诸神，能够从容锁定织梦的去向。
- 若林恩在时间之末撤退途中顺手斩下一截扑来的灾厄触须并封入玻璃药剂瓶中研究，则他能从触须的蠕动频率中提前摸清终焉灾厄吞噬梦境的规律。
- 若林恩在短暂休整时让左左枕在自己膝头小憩片刻而自己独自守夜推演，则左左醒来后精神百倍，搭建远古时间桥时的稳定度大幅提升。
- 若林恩在确定以「织梦」为破局关键后，主动在心底梳理了一遍自己所知的织梦生平与遗憾，则他在见到年轻织梦的第一面时便能精准刺中她内心最警惕也最脆弱的防线。
