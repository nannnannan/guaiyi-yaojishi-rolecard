# E441·毁灭创造与王兽牺牲·if线

- 若林恩在墓船内感知到噬神者生命联系猝然断绝时强行稳住心神不中断输出，则初诞者黄沙得以在结界被攻破前彻底渡入神骸并浸透王座下的渡鸦尸体。
- 若林恩在接过王座下第二具渡鸦尸体的瞬间立刻将其收入系统空间与第一具并列，则两具同源尸躯的共鸣让他体内枯竭的初诞者之力瞬间恢复至满盈状态。
- 若林恩冲出地下甬道目睹欲望母树被黑色光束贯穿化为飞灰，则他在狂风中伸手接住那枚翠绿欲滴的生命种子并收入奇异世界，保住母树重生的火种。
- 若林恩在看到克拉肯与芬里斯为护城墙而躯体无序化坍塌时当即纵身跃出城池，则残存的鲛人守军会借他冲锋的刹那拼死合拢内层残破防线。
- 若林恩面对二十五只王兽汇聚的庞大黑色光球时不退反进，则他在生死一瞬豁然领悟「创造即是毁灭」的真意，将金黄色初诞者火焰尽数压缩凝聚于三叉戟尖。
- 若林恩挥动缠绕金焰的三叉戟正面劈入黑色毁灭光球，则金光如破晓利刃般将漆黑能量球从中一分为二，暴虐的无序洪流在他身后海面炸开滔天巨浪。
- 若林恩在劈开光球后直取高空黑色光团中的弑利亚，则头顶黑雾会骤然裂开一张遮天蔽日的无序巨口，带着吞没天地的吸力朝他当头咬落。
- 若林恩被无序巨口的引力死死锁在半空难以挣脱，则下方早已濒临崩溃的克拉肯与芬里斯会仰天长啸，率领残存王兽以血肉之躯在海面叠起一座通天肉梯。
- 若林恩踏着王兽们用脊背垫起的阶梯借力跃出巨口吞噬中心，则殿后的章鱼王兽克拉肯会被无序巨口死死咬住半截身躯，在最后关头向他传音高呼「为了真正的王，为了自由」。
- 若林恩在听到克拉肯诀别心声的刹那拒绝抛下同伴独逃、转身将全身初诞者之力灌入王戟反手投出，则三叉戟会化作一道贯穿天地的金色流星直刺无序巨口。
- 若林恩投出的金色三叉戟精准轰穿黑雾巨口的核心节点，则遮天巨口在凄厉轰鸣中寸寸崩裂溃散，濒死的克拉肯得以从吞噬边缘被硬生生拽回海底。
- 若林恩在反手投戟救下克拉肯后因力量倾泻而从高空坠落，则黑色光团中的弑利亚会首次露出难以置信的震骇神色，失声惊呼他竟敢为了一头猎犬赌上性命。
- 若林恩在坠落途中召回贯穿黑雾的王戟重新握入掌心，则戟身残留的毁灭金焰会在海面犁出一道百米真空带，迫使前排受控王兽齐齐后退。
- 若林恩在救下克拉肯后第一时间以灵能封住它与芬里斯无序化的伤口，则两头重伤王兽虽彻底失去再战之力，却能保住性命退往结界城墙根部喘息。
