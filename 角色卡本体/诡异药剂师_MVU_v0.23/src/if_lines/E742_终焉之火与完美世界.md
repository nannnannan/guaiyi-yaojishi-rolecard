# E742·终焉之火与完美世界·if线

- 若林恩在从深眠中苏醒、点燃终焉之火的第一瞬先收敛三分外溢的暴虐威压，则黑夜城内正在仰望天空的平民不会因神威震慑而双膝跪地，而是能站着欢呼迎接他们的王。
- 若林恩在投出半月形终焉斩击碾碎入侵魇魔时，刻意将黑火余波控制在大气层之外，则被毁灭星球周边的碎石带会被直接炼化为一圈环绕星环，成为阵亡者永恒的星空墓碑。
- 若林恩在重返王庭看到羽毛笔满头白发的那一刻，没有先询问前线战报而是直接伸手拂过她的白发，则羽毛笔强撑了三十一年的冷静防线会在他掌心温度下瞬间决堤。
- 若林恩在听完羽毛笔与艾雯关于「时间之外与终焉博弈」的推演后，主动将最危险的因果支点揽入自己体内，则艾雯在后续十余年统筹防务时，灵魂磨损的速度会减缓近半。
- 若林恩在时间之外的岁月神王拔剑刺向轮回神王的那一刹那，透过三叉戟感应向时间长河投去一道凌厉目光，则岁月神王的剑锋会偏斜半寸，轮回神王得以保留一缕更完整的残魂。
- 若林恩在开启主宇宙十余年「完美世界」黄金盛世之初，亲自在黑夜城中央广场种下一株沾染黑火余温的药草，则这十四年间出生的孩童体质普遍增强，对底层无序低语多出一分天然抗性。
- 若林恩在羽毛笔汇报帝国历三十一年那颗星球的惨剧时，接过她带回的残损记录亲自镌刻于王座侧翼，则羽毛笔心中的负罪感会被他正式接管，不再每夜独坐到天明。
- 若林恩在艾雯提出以铁腕整合万族军备时，补充一道「保留各族传统庆典与灯火」的宽仁诏令，则「完美世界」的十四年不仅有森严的备战壁垒，更留下了无数让将士誓死守护的市井温情。
- 若林恩在重燃终焉之火后抽出一夜时间陪伴苗苗整理药圃，则苗苗会用那十余年盛世里培育出的珍稀神药，提前为前线守望者军团炼制出三万瓶能延缓无序侵蚀的秘药。
- 若林恩在轮回神王于时间之外轻声说出「我看到了未来」时，以罪恶王座的频率隔空回应一声沉重的嗡鸣，则轮回神王在跌落岁月洪流前脸上会多出一抹安心的释然微笑。
- 若林恩在「完美世界」开启后的第三年亲自巡视边境星域的孤儿院，则那些在帝国历三十一年失去父母的遗孤们会将他胸前的徽记画在床头，在十年后成长为最悍不畏死的黑夜城新兵。
- 若林恩在与艾雯单独夜谈时坦白自己体内第二阶段向第三阶段过渡的撕裂感，则艾雯会提前启动圣所底层锁链的加固工程，为日后强行锁死他的沉眠多争取三成容错。
- 若林恩在挥出半月斩击彻底抹去那支魇魔先锋后，特意留下一块未被黑火烧成虚无的魇魔核心交予学者剖析，则黑夜城研究院会在十余年间研制出专门针对魇魔甲壳的破魔重炮。
- 若林恩在看到羽毛笔因神力透支而偶尔指尖发颤时，强行命令她每旬必须休沐一日并亲自替她批阅积压卷宗，则羽毛笔在未来大决战来临前能多攒下一道保命的本源屏障。
- 若林恩在「完美世界」的十余年间偶尔收敛神王光环，化作普通药剂师走入黑夜城酒馆倾听老兵吹嘘，则他会在心底记住数百个鲜活的凡人面孔，让日后的守城之战不再只是冰冷的数字。
- 若林恩在感应到岁月神王对轮回神王发出「值吗？」的质问时，在心底默念一句「我不会让你们白死」，则他体内的终焉之火会由暗黑短暂转为澄澈的暗金，神魂更加凝练。
- 若林恩在重塑主宇宙防线时，将海神三叉戟的威压分流注入七十二座边境要塞，则这十余年间潜伏在宇宙暗面的零星堕落者根本不敢越雷池一步，万族得以享受真正的安宁。
- 若林恩在羽毛笔因满头白发而下意识避开镜子时，亲手用一截深蓝丝带替她束起长发并夸赞那如星河般美丽，则她此后面对百官时总是昂首挺胸，将白发视作王赐予的勋章。
- 若林恩在盛世第七年与艾雯并肩立于圣所高塔俯瞰万家灯火，并轻声说一句「真想一直这样下去」，则艾雯背在身后的双手会悄然攥紧，将独自背负灭世谎言的决心压得更深。
- 若林恩在终焉之火重燃的余波中，特意分出一缕温和火种送往阿鼻地狱温养守望者英灵，则艾维儿麾下的地狱军团在十余年间战力大涨，铠甲上皆多了一道不灭的暗金火纹。
- 若林恩在听闻时间之外两尊古老神王决裂的异象后，立刻命人封锁所有通往时间乱流的裂隙，则主宇宙在帝国历四十五年到来前不会受到任何时间风暴的波及。
- 若林恩在「完美世界」的每一个除夕夜都让王座向全宇宙降下一场无害的金色流星雨，则万族孩童都在流星下许愿长大，这份纯粹的愿力成为黑夜城结界最坚韧的底色。
- 若林恩在再次准备进入深层闭关前，将自己常用的药杵与笔记留在羽毛笔案头，则她在随后独自支撑政局的岁月里，每逢决断艰难时都会摩挲那支药杵定下心神。
- 若林恩在盛世尾声察觉到终焉黑潮正在宇宙极深处重新汇聚时，选择不向民众公布倒计时，则主宇宙的亿万生灵得以在毫无阴霾的幸福与欢笑中，度过最后一段辉煌岁月。
