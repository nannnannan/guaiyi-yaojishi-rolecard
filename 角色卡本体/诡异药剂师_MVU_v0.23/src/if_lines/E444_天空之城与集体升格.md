# E444·天空之城与集体升格·if线

- 若林恩跨过生命红线前先给喵喵单独罩一道薄纱，则她在红线区不必承受同款身体腐化，可作先遣探路提前半秒回报红线排斥曲线。
- 若林恩把黄沙沿戟尖外拨一圈再举升，则狂风会把黑雾从背后刮出一条短暂走廊，王兽跃空冲城时视界更清晰。
- 若林恩倒数「三」前先对熔岩巨兽单传「你带队先扑左侧塔柱」，则黑袍高塔联动第一波会被迫防守左线，破口方向偏左。
- 若林恩倒数「二」前用咒瞳把王兽体内现存诅咒强度排个序，则黄沙灌体分压更均，阶位跌落差距更小。
- 若林恩在倒数「一」瞬间改喊由自己亲定的吼声，则升格王兽会因主人之声更具意志性，黄沙爆发的形状更凝固。
- 若林恩临时插队让喵喵骑到自己头上扑向城墙黑袍，则破口点偏移几秒但城门顶黑袍会被迫回头应对。
- 若林恩直接拿三叉戟朝天空之城底下黑雾处划开一道裂缝，则海面被撕出立足之地，王兽飞行弧线可更短。
- 若林恩升格时额外问康斯坦丁一句「你恨的到底是谁」，则骷髅灵魂之火节奏更沉，但控魂内卫窗口不变。
- 若林恩在雄狮王兽出手前多说一句「这一击属于你」，则它能在阶位跌到底前更冷静地计算，破口更精准，但威力会稍弱。
- 若林恩阻止雄狮王兽第一时间出手，则它会等到阶位跌到最低才爆发，实际破口力度更小但破口阶段更稳。
- 若林恩在雄狮冲撞时给其一缕初诞残光，则双爪爆碎减为单爪断裂，破口幅度更强。
- 若林恩破口后把雄狮拖到自己背后，则它能从跌回死兆级中撑住一口气不会摔死，能多参战几秒。
- 若林恩放弃破口直接朝圣殿冲，则会因破口未完全打开被高塔防线打飞，破口窗口关闭，破口失败。
- 若林恩破口后让王兽在破口核心区再补三次冲击，则破口深度扩大，内卫溃败时间提前。
- 若林恩破口时把破口点选在黑袍最密集处，则守城方破口杀伤最重，但破口难度更高。
- 若林恩破口时用三叉戟引导破口方向朝向圣殿大门，则破口更易穿透圣殿，但圣殿反击可能更早爆发。
- 若林恩破口后立刻配合康斯坦丁的灵魂缚锁对内城卫兵压制，则破口更易维持。
- 若林恩破口时让熔岩巨兽砸塌城墙一侧塔楼，则破口更易扩大。
- 若林恩破口时让左左冲到破口处再放声戏弄黑袍，则破口易于让黑袍分神半秒。
- 若林恩破口时让喵喵站在破口核心动用猫猫咆哮，则破口易于令王兽意志更凝一瞬。
- 若林恩破口击后立刻用咒瞳扫破口后方防线，则破口后防线排列立即被掌握。
- 若林恩破口击后大呼小叫引发嘲讽，则破口更难维持，黑袍防线可能迅速反扑。
- 若林恩破口击后立刻发布评价破口威力的台词，则破口更易引发黑袍斗志，破口更艰难。
- 若林恩破口击后让熔岩巨兽充当破口封锁者，则破口更易守。
