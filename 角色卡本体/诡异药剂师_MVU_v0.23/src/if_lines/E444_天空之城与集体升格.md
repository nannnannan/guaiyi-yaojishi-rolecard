# E444·天空之城与集体升格·if线

- 若林恩在跨过天空之城外围的生命红线前先以初诞者薄纱护住自身与左左，则生命红线剥夺生机的排斥法则被尽数隔绝，他得以在最前排稳稳举起王戟。
- 若林恩把初诞者黄沙沿三叉戟尖外拨一圈再高举向天，则狂风会把翻涌的黑雾从背后刮出一条短暂走廊，让后方王兽军团跃空冲城时的视野无比清晰。
- 若林恩在倒数「三」前先以心声对熔岩巨兽单传指令命其主攻左侧塔柱，则城墙上的黑袍高塔联动防线第一波会被迫分兵左移，正面防线露出空当。
- 若林恩在倒数「二」前用咒瞳将众王兽体内残留的伤势与诅咒强度迅速排序，则初诞者黄沙灌体时的分压更为均匀，众王兽集体升格后的持续时间得以延长。
- 若林恩在倒数「一」落下的瞬间高喝出冲锋号令，则被金色火焰包裹的数十头王兽会齐声咆哮跃出深海，以短暂重返根源阶位的狂暴姿态撞向天空之城。
- 若林恩直接挥动三叉戟朝天空之城下方的黑雾海面划开一道断流裂谷，则翻腾的海水被硬生生压作平整跳板，王兽军团起跳扑城的冲刺距离缩短三成。
- 若林恩在集体升格启动时侧头问康斯坦丁「你最想亲手撕碎谁」，则骷髅船长眼眶中的灵魂之火会骤然暴涨，死亡锁链第一时间越过城垛死死缚住内城卫兵。
- 若林恩在雄狮王兽燃烧生命准备自爆破盾前向它傳去一句「海王殿会记住你的名字」，则雄狮浑浊的兽瞳会闪过一抹清亮决绝，撞向城门护盾的姿态没有半分迟疑。
- 若林恩在雄狮王兽冲撞护盾的刹那再补入一缕初诞者残光助推，则天空之城的外层结界会在震耳欲聋的轰鸣中炸开一道贯通城门的巨大缺口。
- 若林恩在城门护盾破碎的瞬间立刻指挥熔岩巨兽将重锤砸向城墙一侧的高塔基座，则塔顶黑袍祭司的联手施法被当场震断，缺口处的反击火力骤降一半。
- 若林恩在冲入缺口时让左左化出蚀痕触手横扫城头残余黑袍，则试图修补结界缺口的前排黑袍守军被瞬间掀飞，后续王兽大军得以长驱直入。
- 若林恩在突入外城后第一时间用咒瞳锁定圣殿大门的后方防线排列，则康斯坦丁的亡灵大军能顺着他标出的薄弱节点精准穿插，将守军分割包围。
- 若林恩在攻入城门缺口后不作停留、直接率领主力王兽顺着中央大道直扑圣殿，则黑袍守军来不及组织第二道防线便被彻底冲垮。
