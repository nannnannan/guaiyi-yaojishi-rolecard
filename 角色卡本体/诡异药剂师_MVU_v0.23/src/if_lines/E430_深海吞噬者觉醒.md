# E430·深海吞噬者觉醒·if线

- 若林恩把小丑玩偶连同体内碎片以龙狙直射黑体核心，则金色裂纹从碎片穿刺孔向外扩散，「玩偶为载体」的战术首次被他自己签下批文。
- 若林恩拒绝任何投送载具、单凭巨像之锤压制黑体主触，则它首次见识「人类以非武器入腹」的肉身战，狂攻被迫停顿三秒。
- 若林恩命令小丑「撅起屁股露出碎片」并以初诞者之力充能，则碎片与他一并穿入黑体残骸、把金色裂纹拉成一条直线，「以载体弹药化」首次被他自己测试验证。
- 若林恩让咒瞳扫描黑体的污染分布、读出「百分之四十七」的污染位阶，则它的紫黑病灶首次以坐标形式呈现，「身份验证」在他眼前由口述升级为证据。
- 若林恩在混乱乐律牵制时让孽主以双匕切开它的创口、把现场调配好的血清直接送进它体内，则同族血液与初诞者之力的结合反应首次成为它本体的解药引子。
- 若林恩让喵喵潜到黑体下方担任嗅探后卫，则它的下一次攻击情报首次被猫鼻变成预警信号，「后场雷达」首次属她个人。
- 若林恩主动喂给黑体创口一块渡鸦残躯组织让它吸收其中的初诞者之力，则它被吞没多年的身份在它自己的意志下回响一次，「渡鸦的记忆」首次成为它自我的一部份。
- 若林恩让小丑主动点燃自己胸前碎片并对黑体表面进行金色界限的冲击，则他作为「人形箭头」刺穿流体躯干、把「自体武器」首次升级为「自体弹药」。
- 若林恩拒绝对它施加混乱乐律、仅让它独自面对诅咒，则它血渴的再次发作首次成为它对它自身的挑战，不再是林恩的牵制工具。
- 若林恩主动建立灵能远程控器以将小丑纳入自己的臂膀，则他作为「远程操控员」角色首次对它自己承担责任，小丑的逃亡选项被一道符印挂上锁。
