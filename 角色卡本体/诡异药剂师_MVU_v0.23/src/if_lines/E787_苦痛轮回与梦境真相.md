# E787·苦痛轮回与梦境真相·if线

- 若林恩主动拒绝接收梦主的部分印记而只挑选关键段落，则他在 E794 终战时梦游残缺，无法唤醒完整的梦主反制。
- 若林恩放任梦主印记直接穿透他左臂而不是缓慢吸收，则左臂从此成为「活化的梦境容器」,E789 截杀时它能短暂脱离林恩扩展防御。
- 若林恩选择将记忆印记直接存储在系统空间而不是身体，则他不用承受精神冲击,但系统空间会开始偶尔自我播放历史画面。
- 若林恩主动让织梦与他同时听真相并提问，则两人会各得到一半梦主记忆，E788 必须互通记忆才能拼凑完整真相。
- 若林恩让左左独自维持锚点而他前往梦境深处，则左左会在他归来时衰老三日，但林恩获得一段「未被任何外部影响的纯净真相」。
- 若林恩在梦境真相揭开瞬间主动切断与三位一体之主的链接，则他只能获得一半真相，剩余需由织梦独自消化。
- 若林恩主动把自己某段对爱的理解投射进梦境，则梦境会反向还是那个投射的形状，但投射的内容会作为伤痕留在梦境本体中。
- 若林恩放任梦境中的紫罗兰大君主动靠近自己，则大君的影像会在他胸口留下一个紫罗兰形状的紫青，那紫青在 E789 截杀时会成为空白实体的诱饵。
- 若林恩主动让自己的眼泪滴入梦境——那是偿还织梦意义之外的另一场，则梦境路径在他离开时会留下一串连续的水纹，E789 截杀时空白实体无法完全擦去。
- 若林恩选择在真相揭示时主动杀死一个梦境中具象化的自身过去影像，则那个影像在死亡瞬间会说一句话——「你也在杀死未来的自己」。
- 若林恩主动在梦境中辨认出林蒙的影子并要求单独对话，则林蒙影像会短暂苏醒给出一句关键警告，那句话在 E791 会被验证。
- 若林恩让喵喵在梦境边缘设一道警戒哨，则喵喵会因为吸收过多梦境而在醒来后拥有六小时的预知能力。
- 若林恩主动把自身的某段害怕记录入梦境作为抵押，则梦境会还给他一个用这恐惧锻造的护身符，但那段害怕的内容会在梦境中具体化为他未来必经的场景。
- 若林恩放任苦痛轮回不停歇直到它自行疲惫，则他在轮回尽头会遇到一个疲惫的自身昔日影像，对方的疲惫会成为林恩的鼓警。
- 若林恩主动切断与过去梦境的连接让他成为「旁观者林恩」,则他得到完整真相但失去与织梦的灵魂共振，E788 告别时长出一层不能被磨平的陌生。
- 若林恩让织梦在梦境中承担关键问话，则她会问出林恩从未想过的问题，答案让林恩听到他自己都不知的事实。
- 若林恩主动把自己的黑火改色投入梦境作为更大光源，则他在 E789 截杀时那道颜色会被空白实体直接识别为「林恩」,从而被迫隐形。
- 若林恩选择把梦境真相的一部分以黑火记忆的形式刻进自己肋骨，则他从此无法驼背，每次弯腰都是记忆的痛。
- 若林恩放任梦境中某段苦痛影像走入现实，则那段苦痛在现实中会以虫群形式降临附近城池，他必须独自消灭它们而不解释。
- 若林恩主动在梦境结束前亲吻梦境的边界向三位一体之主告别，则三位一体之主在他身后低声留下一句「下次」,那句下次在 E794 兑现。
