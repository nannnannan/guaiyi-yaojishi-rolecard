# E150·权柄病变与拒绝放弃·if线

- 若林恩读到血字残页中「我不该用他的血来为我分担反噬」一段后立刻合上册子不再深挖，则羽毛笔在异度空间另一端写下「做得对」，紫罗兰注视被她的主动遮挡压回去一拍，事件按「边界尊重」小幅变形推进。
- 若林恩把残页逐字抄入自己的手册并加批注，则手册在午夜被她隔空借走一页，留下一行「你不该写下来」的小字，他对紫罗兰的认知被她自己动手删减一次。
- 若林恩公开告诉艾雯爵士「她的反噬源于我的血」，则艾雯爵士立刻调高对林恩的护送等级、并在夜医手册里把他标记为「禁忌影响因素」，主母从外部出手压制反噬的窗口被抬前。
- 若林恩只把残页内容复述给黑弦月一人听，则黑弦月以丝线在走廊上另织一道「镇记忆」微型锚点，本事件的「多人互证」变形条件部分成立。
- 若林恩在羽毛笔再次驱逐前主动退到门口、向她留下一句「我等你亲手开门」，则她在被划掉的恶毒命运旁多写一句「……他还算懂分寸」，E151 的开局好感度上调一档。
- 若林恩选择尊重驱逐、改请艾雯爵士与主母从外部分担压制，则事件按变形条件第一项成立，羽毛笔的反噬窗口被拉平，林恩本人不进入真身区域，E151 起点被推后一个事件。
- 若林恩改走书面、远程锚点路线，先写一封信贴在 002 门口等她回函，则她在第七次驱逐后首次留下一行小字「你不该再来」，首次主动允许被记入偏离账本。
- 若林恩在被抹去记忆的次数达到某次后在床边贴一张「你正在被她驱逐」的字条，则下一轮唤醒时他能凭字条识破过程空白，驱逐效果在他的主观记账中被打断一次。
- 若林恩请左左以血肉支配潜质在他颅内留一道「不要被改」的锚，则下次驱逐只能删掉表层记忆、删不掉那道锚固，事件按「远程锚点」变形条件成立。
- 若林恩在女性夜医尖叫围观的场景中哭笑不得地扯过床单裹身，则艾雯爵士「等几分钟」的巡守被改成有分寸的友善调侃，他在疗养院的尴尬名声止步于本事件、不外溢。
- 若林恩在赤身狂奔途中临时躲进应急衣柜换装，则沿途夜医只看到一团被子滚过，笑柄级别被压低，但 002 室对他的驱逐节奏未受任何影响。
- 若林恩顺手抓下一名看热闹的夜医的白大衣遮体，则该夜医事后在记事板上写下「那个裸奔医生欠我一件大衣」，他被小范围调侃但不被记恨。
- 若林恩用巨镰折跃切入地下空间的瞬间主动落点选在离她血肉真身最远的角落，则她的拒绝从「滚出去」降级为「别靠近」，她抽飞他的力道压低一格。
- 若林恩把埋设的定位机械改为只开一条通讯缝隙而非人进入，则她不再驱逐他的肉体、只切断信号，事件按「书面许可」路径部分成立。
- 若林恩在地下空间第一次见到被划掉的恶毒命运页，主动帮她多划一笔，则她在狂乱中转头的那一拍噤声半秒，紫罗兰注视顺着他的笔触短暂落到他自己掌心。
- 若林恩在她划墨失控时出声喊「羽毛笔，停一下」，则她的笔尖真的停在一行残句上、留下一颗墨滴，「她仍在主动保护城市」这一完成条件经由他的声音被第一手确认。
- 若林恩带去一条她自己早年在书桌上用过的小毯子放在门口，则毯子在下次驱逐后被她拉入异度空间深处，「可靠联系通道」被这条毯子间接建立。
- 若林恩在拒绝接触的边界向她口述「你出事对谁都不好，但不只是对我」，则她承认受托但不允进门，驱逐节奏从「秒删」放缓为「分阶段抹除」，留下记忆残片。
- 若林恩以M或以权柄尝试镇压她的反噬外泄，则紫罗兰注视顺着他的权柄介质反向锁定他本人，事件直接落入禁忌视野、记入偏离账本「被注视状态」。
- 若林恩选择长期封锁、停止接近等待反噬自减，则事件按取消条件第一项收束，羽毛笔的保护动作继续，他与她的联系交回 E151 由她主动恢复。
- 若林恩发现定位机械失效仍执意强闯入口，则 002 的空间缝合在他脚下塌陷一段，取消条件第二项「立即不可控灾变」被触发，应急封印层的夜医全员全城戒备。
- 若林恩让喵喵、黑弦月或银色幻想轮流在 002 门外驻守作为活体锚点，则羽毛笔的驱逐只删当前在场的个体记忆、删不掉同伴的复诵，事件按「多人互证」与「远程锚点」双重路径成立。
- 若林恩在拒绝放弃的边界向她保证「我不再用血」，则她的笔在他看不见的地方微微一抖，写出一行未划掉的「……我不信」，好感度记录上多一笔「他在承诺」注脚。
- 若林恩触动那本被划掉的恶毒命运集子试图带走作分析，则整座地下空间的血肉经经络在他脚下同时一紧，他被一次性强制遣返、紫罗兰注视在他的鞋跟上烙下一枚隐踪符。
- 若林恩在她最新一次拒绝接触时主动停在安全距离、把整个病区疏散图挂在墙上让她能瞄到，则她对自己的失控承认度+，「建立可靠联系或定位」这一完成条件以「间接定位」成立。
