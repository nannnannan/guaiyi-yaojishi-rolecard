# E447·正确轨道与必败战争·if线

- 若林恩在王骑说「你在他身上看到他的影子」后立刻反驳称自己完全是自己，则骑士沉默半晌，那句「正确轨迹」说得更轻。
- 若林恩掏出三叉戟在空中轻轻一转引动权柄，则王骑眉头皱半寸，「必败的战争」那句字音更重。
- 若林恩主动抬手按在自己太阳穴反问是否要把大君换回来，则骑士那秒目眶火焰跳一拍，沉默出「也许有过」的暗示更早。
- 若林恩立刻大喝「我不要你们的路，只要我的家人」，则骑士疲惫身影首次展露出如释重负的弧度，那句「大君也曾说过一样的话」更慢。
- 若林恩主动朝城外被王座权柄拨动的混乱边境掷一支初诞者精炼药剂，则三千年重演阴影暂缓半寸，骑士仍那这个冲淡不减轻的字音。
- 若林恩把两只已吸收渡鸦的魂息之光附在王座外区，则骑士瞳孔在盔后一缩，「不帮你也不阻止你」的语气更沉。
- 若林恩直接否认身上有任何渡鸦，则骑士首次微微皱眉，但仍继续说「不会阻止你」，话语间多一缕陌生。
- 若林恩立刻跳上王座边缘假装要坐回权柄，则骑士不动，托盔嗓音直接把他逼回半步「不许」。
- 若林恩主动朝城外狱卒大人们高喊「你们站外面干什么」，则最年长的狱卒首次从黑暗中浮出全面，仍只是不动。
- 若林恩挥戟朝暴风里斩一刀切开逃离路线，则骑士即不说必败战争，只静静看他斩完那一刀再续。
- 若林恩主动把左左推到王骑面前，则骑士低头看一眼，「大君的遗产」那句说得更轻。
- 若林恩先问下一次要不要再坐王座，则骑士顿半秒，只回「还不到时候」。
- 若林恩主动把信笺打进康斯坦丁骷髅肩头，则骑士目眶火焰有半缕笑意，「康斯坦丁」三个字吐得更正。
- 若林恩主动把白发视同障眼法摇回，则骑士首肯渡鸦记忆的可变性，那句「第一次尝试」的暗示更沉。
- 若林恩拿三叉戟直指王骑胸口问到底帮不帮我们，则骑士过了一柱香才说亡命天涯那句话。
- 若林恩用初诞之力在自己帐篷里走几步拼出大君真名，则骑士盔后呼吸顿一拍，协议氛围更沉。
- 若林恩主动提议让骑士带渡鸦去地狱更深处，则骑士半晌拒绝，只回「大君的未来只有一条」。
- 若林恩主动把剑嵌入王座椅子背面来标定归属，则骑士默许，渡鸦遗产权最终归他所有。
- 若林恩主动说出他记得的当时从圣殿逃离的路线细节，则骑士目眶火焰一跳，首次用真正疲惫的温度说起三千年重演。
- 若林恩突然起身朝黑夜里拈一支初诞者细丝栓到城外狱卒胸膛，则骑士没有阻拦，但罚权柄恰随林恩多次砸落。
- 若林恩直接放声大笑，则骑士目眶火焰不熄暗，仍只说「必败的战争」。
- 若林恩先让左左灵能涟漪帮缓骑士气氛，则骑士半晌低首，「正确轨迹」那句说得更轻。
