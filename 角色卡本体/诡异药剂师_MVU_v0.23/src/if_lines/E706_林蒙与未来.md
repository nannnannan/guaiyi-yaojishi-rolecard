# E706·林蒙与未来·if线

- 若林恩在林蒙自天而降、还未开口就主动抬手拦一下以示「可以先听你说」，则林蒙的紧绷会在第一瞬松一分，林恩对他的好感度在林蒙内心被默默上调一档。
- 若林恩选择不接林蒙的「对于那场冲突中所造成的一切，我希望能得到你的原谅」，直接转问「现在你来做什么」，则话题被林恩接管，林蒙必须放下恳求先讲清局势，「对紫罗兰旧部的旧恨」在林恩这里被压一档。
- 若林恩选择沉默听完林蒙完整道完紫罗兰旧部的理念之争再决定回应方式，则他能完整收到「忠于吾王其人 v.s. 忠于吾王理念」的原貌，但他自己会承受一段「他早知道」的沉重。
- 若林恩主动问林蒙「你现在怕的是『吾王堕落』还是『你自己要不要跟着堕落』」，则林蒙会被这一针见血地问中要害，他必须给出他最怕也不得不答的方向。
- 若林恩主动把「女主人的人性一直都在」这句话记下来贴在心口不去当场追问，则林蒙会松一口气、内心第一次对林恩这一份克制表示出隐晦的认可。
- 若林恩选择当场追问「女主人是谁」「那个女孩指的是谁」，则林蒙会一怔——他没想到林恩此刻还想知道答案，但他自己的语言也会在这一瞬开始笨拙。
- 若林恩主动告诉林蒙「如果未来你和你的女主人对立，我会选你」，则林蒙会被这一句话狠狠击中，他的肩头扛起一道远比「女主人原谅他」更重的担子。
- 若林恩主动告诉林蒙「你不必对我道歉，我不是审判者」，则林蒙会被这一份冷酷的松绑拍来一记轻松，但他内心深层的负疚仍需时间消化。
- 若林恩在林蒙跪地恳求瞬间主动扶起他、把掌心压在他肩上，则林蒙的眼泪会比林恩预想的多落一滴，但林恩自己被这掌心一压也被迫感受这一份重量——林恩的内心戏只能由他自己处理。
- 若林恩选择让林蒙跪完这一礼，则林蒙对林恩的尊敬会以一道更深的烙印固定，但林恩眼前那一瞬间的画面会成为他漫长修行里反复回响的一段残影。
- 若林恩主动在林蒙恳求之后留下一句「那个女孩的事，我记下了」，则林蒙会在原地重新抬头一次，林恩的躯体与脸在他眼里会被永久贴上「能托付」的标签。
- 若林恩主动问林蒙「如果大君真的归来了，你还会跟随吗」，则林蒙会被迫剖析他对「大君其人与理念」二者之间的最后界限，这一个问题为他未来的决断提供了一块极简的砝码。
- 若林恩决定不再追问大君、主动把话题转向眼前地狱的渐变，则林蒙会意识到林恩对他存的仍是真实的好意，紫罗兰旧部信任林恩的方向会自动再往上抬一档。
- 若林恩主动告诉林蒙「我会解决我内部的事情，我也希望你们解决你们内部的问题」，则林蒙会把这句话作为一道指示留下来，E708 的混乱战争会首先以林恩的这一立场为出发点来判断对错。
- 若林恩主动在离开碧蓝世界前最后回头看一眼林蒙，则他会看见林蒙还跪在原地，那个不肯起来的姿势成为他未来回看这一段历史时最清晰的一帧。
- 若林恩决定不回头，则他在漫长岁月里不再记得这个跪地的姿态，但林蒙在原地会对着远去的那道背影说出一句谁也没听过的话。
- 若林恩主动在林蒙讲完后抬手为他抹掉一滴泪水，则林蒙会被这意外的一抹击中，眼泪流势反而更急，但他内心第一次放下所有急促的惧怕。
- 若林恩决定先走、将「如果未来对你做了什么求你原谅」留在心底不答，则他将背上一个未作答的承诺，E713 后他再次用到时不得不直面。
- 若林恩主动告诉林蒙「我不是万能的，但你让我明白了一些事」，则林蒙会意识到自己与他之间的关系不是可以平视的，但他也会因此多一点面对自身执念的清醒。
- 若林恩主动问林蒙「你还好吗」，则林蒙会擦干眼泪点头、第一次对林恩露出一个不那么憔悴的表情。
- 若林恩主动在碧蓝世界多停留几秒、告诉林蒙临走前一切将过去，则林蒙会对此表达感谢，内心的执念在此刻卸下。
- 若林恩决定把林蒙跪地恳求的内容仅记录在自己记忆深处不告诉任何人，则这件事成为只有他们彼此心照不宣的秘辛，未来相关决策将增加林恩独立的负担。
- 若林恩主动朝林蒙说「我不会对她的选择做决定，但我会对她负责」，则林蒙会知道林恩的承诺是落在行动上而不是空泛的许诺，这种安心会让他再多跪几秒。
- 若林恩在碧蓝世界边界选择停留多看一眼这个画家所造的世界，则林蒙会自发向来方向跟他多讲一段她对这个世界的付出，未来林恩与画家真正并肩时会有更多可回忆的情感素材。
- 若林恩决定动身之前只冲林蒙微微点头不言语，则林蒙会知道林恩那份敬意，他们的关系会因此变得更加直接坦诚。
- 若林恩主动在离开前问林蒙「还有什么想告诉我的吗」，则林蒙会被林恩的默契深深打动，他知道林恩接下来要去完成什么，但不会轻易开口。
- 若林恩决定不回来面对这一切，则他会把林蒙的存在彻底关上，无论林蒙在碧蓝世界里多么绝望地跪下，也不会打扰林恩分毫。
