# E425·未来林恩带走孽灵·if线

- 若林恩明确选择「完全融合模式」，则未来来客的语气、用词、停顿瞬间被写入他自己的唇齿，他在场家人分辨不出「谁在说话」，「我是谁」的问题首次被众人集体暂停呼吸。
- 若林恩选择「旁观者模式、保有意识」，则他作为副驾全程看到未来自己抬手弹飞匕首的画面，强制目睹一次「未来自己的力量规格」，他回归后一段时间内不敢出手。
- 若林恩选择「完全断开、失去那段时间感知」，则他在房间苏醒后发现周围人心事重重但无人能完整复述，「记忆断层」首次被他自己定义为值得调查的证据黑洞。
- 若林恩拒绝接引、冷眼看涟漪在空中回旋三圈，则未来来客停在门外、最终散开，事件以变形（没有接引）收束，孽灵失去被带走的机会、她的躯壳继续任由无序崩解。
- 若林恩在接引前主动提出条件「你必须向我解释三件事」，则未来来客共享躯体后克制地留下三个空白的停顿，「他想说但说不出」的张力首次被众人实眼直面。
- 若林恩在未来来客出现瞬间主动用初诞者之力抓他手腕做对抗测试，则两股同族同源之力在他自己的血管里决斗一次，他亲身体会「我未来会这么强」的刻印。
- 若林恩以拒绝接引为筹码要挟未来来客交出某段信息，则未来来客首次向他直接摇头，「未来不能全说」的规则成为两者间首个明确定律。
- 若林恩让喵喵以猫形态跃到未来来客肩上，则未来自己顺手抚摸猫耳，「未来他也认得喵喵」的亲昵被现场实眼证明，家人对来客身份彻底不再怀疑。
- 若林恩让左左先与未来来客对话测试真伪，则左左抓他手腕追问「他蛋糕吃什么味道」，未来自己答出与玩家一致的隐私答案，家人的「那是林恩」确认度 +1 台阶。
- 若林恩主动要求在未来来客动手前先看孽灵卸下面具的全脸，则众人提前三秒目睹「那是孽主面孔」的现场破防，他的领受度被提前预支一拍。
- 若林恩在未来来客抱起尸身走向裂隙时主动伸手也想扶一把，则未来自己停顿一秒拒绝了，「有些重量只能他独自带」的边界首次被两人协作证明。
- 若林恩让未来来客在走之前用力拍林恩后脑勺一下作为「交接信号」，则「我未来的你会提醒现在的我」的信号首次被以体罚形式签署。
- 若林恩在苏醒时主动抓住左左手腕拧耳反问夹子疗法，则她的「咬手反击」成立但伴歉意外加一句「我怕你死了」的吞吞吐吐坦白，家庭日常首次加一笔「无言的互相后怕」。
- 若林恩苏醒后当场让左左把他身上所有夹子一只一只当众取下并按颜色分类记录，则「仪式化的善后」被她认真执行，「她服药方」之外她首次入档扮演「护理员」。
- 若林恩没苏醒、持续憔悴躺在床上超过一昼夜，则巨像之脑与艾雯轮流值班守护，「家庭担忧的等级」首次被提上台面。
- 若林恩苏醒后向巨像之脑亲口说出「是以后的我啊」，则她成为首位亲耳听见机制的家人，她与艾雯的对策会议绕开「神王附身」分支，行动方案重绘一次。
- 若林恩拒绝点破、仅以三缄其口面对家人的追问，则他本人在场沉默一分半钟，「不告诉你」的姿态首次被家人识别为「他自己心里没底」。
- 若林恩主动向巨像之脑询问「你为什么相信你看见的」，则她用她银眸扫描他的声带颤动频率最终选择相信，「专业认证」首次成为她归他的基础。
- 若林恩在夹子恶作剧中主动反击以咒瞳激活她手心刻痕令她短暂失能，则左左含泪报复性咬他耳朵，「她用咬人做道歉」的双向曲线首度完整呈现。
- 若林恩苏醒后拒绝后续谈话、起身离开现场，则家人们相信他不愿再说的决定，「沉默主权」首次被众人签字确认。
- 若林恩让喵喵在苏醒现场爬到床头坐下做「欢迎回家」的欢迎仪式，则喵喵首次获得「他是该警报的中央」的译置地位，家庭同谐一度获得。
