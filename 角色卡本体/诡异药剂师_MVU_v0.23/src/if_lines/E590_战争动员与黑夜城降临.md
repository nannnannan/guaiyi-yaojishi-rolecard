# E590·战争动员与黑夜城降临·if线

- 若林恩在踏入边境前先用一缕心神把艾维儿的轨迹连上令她主动来迎接，则她会提早数小时出现在迷雾海入口，与左左的「拉头发」小剧场加时一幕。
- 若林恩让左左自己去刷剧冥想、不盯他推演法网，则推演效率反而提一档，但左左会在群频道里把「新款薯片」发出来引发一片应和。
- 若林恩在艾维儿到来时主动先开口喊「女儿」，则艾维儿会立刻以一声「爸爸」回应，一瞬之间港口所有夜医都误判成家庭团聚演出。
- 若林恩在艾维儿心头紧张时主动告知「我这一路被白焰护下来了」，则她的担忧立刻降档，对后续动员的执行会更松一拍。
- 若林恩不向艾维儿隐瞒三位一体，则她会以艾雯同等档位的「肢解熔铸蛊惑」看他，但她会忍住没说，仅在心灵海独自消化。
- 若林恩在召唤黑夜城时不是整城降临而是只带五名核心元老跳转，则动员场面缩小成最精锐暗袭阵型，污染者先头改策略。
- 若林恩让银色幻想提前报告「左边有圈套」，则银幻会以「机械后勤官」身份接管他右臂，整场动员她始终伴随他侧。
- 若林恩在动员演讲末尾给一句个人承诺「此战过后我会带你们回家乡看一眼」，则四百余名坠落古神会同时沉默三秒，随后是比之前更响的轰鸣。
- 若林恩隐瞒熔铸风险时主动对艾雯与脑子补一句「此力与你们无关」，则他们「亲近感」没被点破，E596 里银幻捅破的窗口变得更尴尬。
- 若林恩选择让泰坦头颅担任先锋，则他会带头冲锋而非镇守中央，E591 撞星轨那一幕改由冲锋流推展。
- 若林恩拒绝响指破咒、让古神平地升格不立，则开战时只有原本的数十名高阶根源可用，E591 练兵场改写成更为凶险的硬碰硬。
- 若林恩给左左一面小旗子让她带队挥，则她会真的如小将军喊口令，巫神与泰坦在她打开喉咙齐笑一整场。
- 若林恩在动员结束后单独召康斯坦丁船长与人偶家私下问他们对这场仗的真实把握，则林恩会拿到一句「我们能赢，但你得答应不先死」。
- 若林恩公开说出「此战主要锻炼军团」，则古神们的战意会被这一句话推得更急，E591 冲锋气势更烈但伤亡率也更高。
- 若林恩给银色幻想一个「别在城里任总工」的暗示，则她会先一步追到前线，E591 海洋过她银潮更早投入战场。
- 若林恩在动员时不提「回家」只说「决战」，则军团心境偏利落硬冷，E597 死战不退的齐声怒吼被改写为更沉重的沉默。
