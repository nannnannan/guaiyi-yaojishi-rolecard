# E732·成熟就意味着失去·if线

- 若林恩得知织梦死亡时没有沉默而是当场崩溃嘶吼,则自缚天使自责会瞬间加深十倍,她可能选择以死谢罪,王座信仰网络因此失去一名重要守护者。
- 若林恩抚摸本源时选择捏碎而非收好,则她的最后礼物当场消散,林恩身上多一道「亲手毁她遗物」烙印,后续任何关于她的回忆都会带来剧痛而非慰藉。
- 若林恩对自缚天使说「这不是你的错」,则她的下跪姿势会稍微放松,但「没守在她身边」的愧疚仍会持续发酵,只是延迟爆发。
- 若林恩不去瞻仰那片废墟而是直接回到主母身边,则主母会多一晚温暖陪伴,但也会更加怀疑他在隐瞒什么。
- 若林恩告诉自缚天使「我要让你活到你原谅自己的那一天」,则她的生死被他强行挂钩,从此不敢死,但每一日都活在「我还没被允许死」的煎熬里。
- 若林恩把织梦之死的真相即刻猎杀告知艾维儿与主母,则黑夜城陷入三天三夜的哀悼期,信仰殿建设停滞,但众人的眼泪反而成为王座最初的燃料。
- 若林恩在本源中注入自己的鲜血混合织梦最后的灵能,则一枚新生血缘信物诞生,佩戴时既受织梦残响守护又被林恩反噬,危险时多一层燃烧自我的守护。
- 若林恩让左左在这个瞬间强行接管他的身体去替他痛,则她第一次主动承受绑定者的悲伤,单眼流泪不知道自己在哭什么,绑定深度+2。
- 若林恩把织梦留下的本源当作王座第一根柴薪直接点燃,则黑火初次燃烧时会带她的笑声,林恩每次看火都会看见她在焰里对他竖中指——这是织梦式的告别,痛但带劲。
- 若林恩在床边发现她留下的手写便条并选择当众朗读,则所有人都会听见她最后的俏皮话,悲痛被稀释一层,但林恩的隐私彻底消失。
- 若林恩决定不再悲伤、用绝对冷漠包裹自己直到战争结束,则所有认识他的人会认为他已死了只是躯壳还在走动,这种误解会持续到某个比他更悲痛的瞬间。
- 若林恩决定立刻跳到下一阶段速建信仰网络用疯狂工作麻痹自己,则他三个月内建成帝国雏形,但也会在某个深夜突然崩溃,延迟性的崩溃会比当时更危险。
- 若林恩在本源前沿血迹走七步以他的足印为引,则织梦的灵能残影会短暂凝成模糊的回眸微笑,那个微笑说不出话但足够让他撑过接下来的所有战役。
- 若林恩对主母说「她是笑着走的」,则主母会在反复咀嚼后稍释怀,但也会留下「她到底是不是真的笑了」的执念,她会暗中调查织梦最后表情。
- 若林恩让自缚天使把那枚本源捧走由她保管,则她走到哪里都感觉到织梦的视线,再也不能偷偷自责——她背负着「替她看他」的职责,这是另一种形式的永生监禁。
- 若林恩选择把织梦之死的每个细节写下来烧入王座,则那些文字会成为永恒铭文,她的名字与功绩将与王座共存,不再只是林恩的私人痛楚。
- 若林恩选择不取名织梦的尸体、把它当神龛日夜供奉,则黑夜城多一座私人神社,主母们轮流守夜,但林恩失去最后一片独处的哀悼空间。
- 若林恩让艾雯把织梦消散的画面封存在记忆水晶里日后观看,则他当时不会看到,但三个月后的某个夜晚他会自己打开,那次截屏的痛哭是他一生中最接近死亡的瞬间。
- 若林恩让喵喵跳入本源池去捞织梦残存的气息,则她会因位格过高而被弹出三次,第四次她会叼回来一缕淡淡的属于织梦的发香,林恩将那缕发香封在小瓶里佩戴一生。
- 若林恩选择把织梦的本源与灵能飞升者传承信物合铸成一枚新王印,则他从此不是普通的信仰接收者而是「继承被造者遗志的开国君主」,王座会有更坚实的法理基础。
- 若林恩选择不去瞻仰织梦消散的废墟而是独自待在房间里三天三夜不吃不喝,则七天后他会瘦脱形,但眼神会变得极其清明,第一句出来的话是「我准备好了」。
- 若林恩在悲痛中强行催动以M 气息,则身体出现剧烈排异反应,织梦残响会以最温柔的方式镇压他的欲望,他在极乐与剧痛的边缘体会到「她还没走」的错觉。
