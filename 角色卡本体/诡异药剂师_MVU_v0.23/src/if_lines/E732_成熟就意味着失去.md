# E732·成熟就意味着失去·if线

- 若林恩得知织梦死亡时没有沉默而是当场崩溃嘶吼，则自缚天使（主母）的自责会瞬间加深十倍，她甚至可能萌生以死谢罪的念头，王庭因此面临失去核心主持者的风险。
- 若林恩抚摸织梦遗留的灵能本源时选择将其紧紧贴在心口而非封存，则她的最后馈赠即刻与他共鸣，林恩身上多一道「织梦残响」烙印，每逢回忆起她时都会伴随彻骨的心痛与清醒。
- 若林恩对自缚天使说「这不是你的错，主母」，则她颤抖的下跪姿势会稍微放松，但「没能在奇异世界守住她」的愧疚仍会在她心底持续发酵。
- 若林恩告诉自缚天使「我要让你活到我们真正赢下这场战争的那一天」，则她的生死被他强行挂钩，从此不敢轻生，把全部的悲痛化作维持黑夜城运转的动力。
- 若林恩把织梦为成全唯一性而死的真相正式通告给艾维儿与自缚天使，则黑夜城会陷入三天三夜的沉痛哀悼期，全城将士的悲愤与眼泪反而凝聚成一股决死抗争的意志。
- 若林恩在织梦遗留的本源中滴入自己的一滴鲜血，则灵能与他的血脉彻底交融，在未来直面无序深空时多出一层燃烧自我的精神守护。
- 若林恩在呼啸的风雪城墙上听到身后艾雯爵士走来的脚步声时没有回头、也没有再维持帝王的坚强伪装，而是直接双手捂住脸颊痛哭出声，则艾雯会默默走到他身旁为他挡住风雪，听他把积压了数十年的委屈与疲惫尽数倾吐出来。
- 若林恩在城墙上哽咽着对艾雯哭诉「艾雯大哥，我真的好累……为什么成熟就意味着要不断失去身边的人？」，则刚刚在城下向母亲自缚天使坦白了自己必死宿命的艾雯会眼眶通红，在心底暗誓绝不让弟弟独自孤单地走完最后的路。
- 若林恩把织梦留下的本源当作冲击第三阶段的第一份引子融入大梦，则他的梦境之火在燃烧时会隐约映出她红裙翩跹的残影——这是织梦式的告别，痛彻心扉却又推着他不断向前。
- 若林恩在织梦房间里发现她生前留下的半截批注手札并选择妥善珍藏，则每当他在王座上感到孤独时翻看那熟悉的字迹，都能从中汲取到一丝撑过漫长寒冬的慰藉。
- 若林恩决定收起眼泪、用绝对的克制包裹自己直到下一场战争，则黑夜城上下都会看出他们年轻的王在这场死别后彻底褪去了最后青涩，但艾雯与主母看他的眼神会更加心疼。
- 若林恩在织梦残存的血迹旁静立良久、以刀尖挑起一缕染血的红纱系在夜魔刀柄上，则这抹暗红会伴随他斩过未来每一尊来犯的魇魔。
- 若林恩对自缚天使说「她最后是笑着把路留给我的」，则主母会在反复咀嚼后稍稍释怀，并将织梦的名字郑重刻入黑夜城先烈的最高纪念碑。
- 若林恩让艾雯把关于织梦最后时刻的记忆封存在一枚灵能水晶中交给他保管，则他当时不会触碰，但那枚水晶会成为他日后枯坐王座时的精神寄托之一。
- 若林恩选择在风雪城墙上与艾雯并肩坐到天明、听兄长讲起这二十多年在各星区流浪救人的见闻，则两兄弟之间的隔阂与生疏会在一夜之间消融殆尽，重新找回当年在地狱并肩作战的默契。
