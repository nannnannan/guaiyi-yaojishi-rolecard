# E192·伪装顾客与大舌头经营网络·if线

- 若林恩掏出黑颅币那一秒直接把柜台看守一枪毙命，则「这些钱我想买下你当我的狗」名场面整体消失，后院分赃酒席未被惊动，但迷魂铃与摄魂花粉不再由看守亲口供出，事件以潜入路径完全转暗线变形收束。
- 若林恩改走小额贿赂，先扔二十枚骷髅币慢谈，则看守态度升级但只肯交代圈养区位置，不肯讲大舌头与眷者的关系，事件以收到一半情报变形收束。
- 若林恩途中主动问「这批货是怎么调教的」，则看守会顺势讲解铃音与花粉配对机制，机制公开比原作提前一拍，事件以调教课前置变奏变形收束。
- 若林恩当场解除伪装、超维感应全开，则大舌头立刻通过巨像共鸣反向认出主人，分赃酒宴进入警戒，后院所有黑骷髅警铃齐响，事件以亮真身变形收束。
- 若林恩先让左左从暗处伸出触手勾走大舌头的一根须腿，则宴席现场「小宝贝失踪」没有立刻曝光，但大舌头会在三十秒内收到远超原作的危险预警，事件以主人先入警戒圈变形收束。
- 若林恩认真点头接受「奴隶少女」环节并真实扮演性癖豪客，则他从「调查流」切到「嫖客流」，进入圈养房那一刻立刻被多扣一层以M承受者标签，事件以顾客本人被推上奴床变形收束。
- 若林恩要求在圈养房里先看完变形演示再议价，则魅魔与萝莉变形被提前演示掉，但他得全程站着看、忍到鼻血，事件以顾客被演示拖住变形收束。
- 若林恩点单挑一份「还原到大坑原貌」的血肉样本带走研究，则看守认为他癖好奇特、信任度反而上升一档，事件以怪癖客人身份通过变形收束。
- 若林恩在听到「变态狠人写笔记」时主动附和「我是他粉丝」，则看守更乐意翻旧笔记内容，林恩没写过的额外玩法也被一并口述出来，事件以冒充自己粉丝变形收束。
- 若林恩承认那本笔记是自己亲手写的，则看守哄堂大笑、判定为外乡骗子，身份信任等级掉到冰点，事件以自爆伪装变形收束、强行正面冲突开场。
- 若林恩当场要赎一只魅魔走、拍黑颅币现钞，则他能释放一名被囚血肉人形回家做样本，但按流程他得亲自下奴床验货，事件以顾客交易变形收束。
- 若林恩对大坑内所有血肉人形沉声宣告「你们全部都能被我镇压」，则他们突破迷魂药性认出主人身份，圈养区暴动开场，事件以奴群反水变形收束。
- 若林恩搜查看守尸兜时没把摄魂花粉收进系统空间，则后续左左能顺手牵走一包私下研究，林恩「下在左左饭碗里」的念头根本没机会升起，事件以花粉走线变形收束。
- 若林恩走书库线但跳过阁楼，则阁楼两名血肉人形有幸逃过屠杀，他们会在后院掀牌的瞬间目击主人真身，事件变形为杀人总数比原作少二收束，大舌头警觉度大涨。
- 若林恩让喵喵也来协助暗杀，则左左与喵喵双宠下手，阁楼、书库两段清理速度提前两分钟，事件以双宠合击变形收束。
- 若林恩穿墙时燕尾服意外失效，则大舌头从酒席上第一时间看见陌生主子凭空现身，事件以当众亮牌变形收束，全店警报拉满。
- 若林恩直接砸开地下书库的门板当武器朝后院掷去，则两名队长当场被门板击晕，事件变形为物理破袭收束，血畸藤下毒路径整个废弃。
- 若林恩超维感应提前定位到队长杯中烈酒，则他能把血畸藤埋伏点切断，改以佐餐盐水替换香汤，事件以劝宴改邀变形收束。
- 若林恩让左左从暗处拖一只真魅魔来与魔化大坑对峙，则看守被揭「真魅魔与伪魅魔」的身份，现场一片冷场反击，事件以公开打假变形收束。
- 若林恩在门口被柜台人形从气味上认出「您身上有主人的味道」，则柜检识破真身，封锁警报+2，事件以身份泄露变形收束，正面冲突开场。
- 若林恩提前在店门外扔一支静默药剂封住后院，则酒香氛围被破坏，分赃场面架不起来，事件以酒席破场变形收束。
