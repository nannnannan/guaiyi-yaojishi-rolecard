# E479·一号智脑与巢都毁灭·if线

- 若林恩在血潮压顶前先以分身侧朝田园网道掷一支灵能浮标，则这枚浮标会在以太狂潮分流瞬间被卷走一道毛边，本体侧立刻获得「田园方向已被盯上」的提前警报三秒。
- 若林恩让数据体压成纯废码贴在巢都外墙皮上挂机，则祂把巢都吞下三分之一时也不会识别这层皮是人，但赛后林恩要把自己从废码态剥回来需多花一段修复期。
- 若林恩主动用咒瞳扫血色浪涛的「吞咽节奏」，则他能识别出这是一只尚未闭合的新生胃袋，吞咽与吞咽之间有零点几秒空隙，后续田园营救时间就是这点空隙算出来的。
- 若林恩在智脑加密信号刚刚浮起时不立刻回话而是先让灵能在链路上绕三圈，则智脑会以为对面已经失联、又多用掉一格残能重发，她的体内数据流逝比原版多一成。
- 若林恩一边反向溯源一边用三叉戟在巢都外壁凿开一道临时口子，则他能提前两秒看到那个数据夹缝，但凿痕会被血潮察觉、气浪反扫他本体一层皮。
- 若林恩选择不回溯源、转身先去田园，则智脑信号会在三十秒后彻底熄灭，加密链路从此只剩他这边的死档，蜂巢覆灭史与求救来源都永远失去口述者。
- 若林恩冲入夹缝时先甩一支镇定级别的血肉镇定剂进数据体，则智脑的叠音会瞬间安静一拍，他得以在三十秒内听到完整一段「求你救小姐」而不是杂音。
- 若林恩把她背出来时让她「头朝外」而非「头朝内」，则她能全程看见自己守了数月的蜂巢在被血潮吞掉，这一幕烙印会让她后续对林恩的敌意消一分。
- 若林恩用灵能扫描智脑内部时走得比常规深两层、触到人格核心缺口边缘，则他会第一次看见那层「格式化前的备份快照」，得知小姐临走前在她这儿留了一枚未启用的密令。
- 若林恩灌注灵能压制破碎代码时故意压住一半留一半，则她醒来后情绪稳定性会维持在「能哭能骂但能对话」的微妙均衡，比全压制更接近她原本的人格。
- 若林恩在她刚苏醒时直接以心声报「我是林恩」而不是伸两根手指测智能，则她会少被激将一次、直接进入「哭求」状态，但他失去一次确认她认知未伤的机会。
- 若林恩把「两个数加起来等于几」换成「我们当年初次合作时你骂了我什么」，则她会愣一拍后汹涌骂出整段秽语，这份秽语保真度等同于身份验证，比数学题更铁。
- 若林恩在她求「把小姐带回来」时不点头、只让她听见自己心跳稳了半拍，则她会把那半拍当成承诺记住，日后在他打算放弃巨像时翻出这一帧质问他。
- 若林恩主动在她意识里放一段「黑夜城战场实录」让她确认求救已收到，则她会立刻认出画面里那些夜医是真的、激动得数据体冒烟，但情绪过载会让她的叠音多持续几小时。
- 若林恩让分身侧先行一步去田园销毁情报、本体送智脑，则他能在田园悬崖被吞前半秒完成销毁，但分身侧独自面对以太时无本体压场、风险抬一档。
- 若林恩告诉智脑「小姐可能去找光宴了」时不附加自己的猜测，则她不会知道光宴这个变量、后续听到光宴背叛事件时情绪崩溃会更彻底。
- 若林恩听她口述数月前经过时忽然反问「万机之神的遗产你破译了多少」，则她会露出一抹近乎人形的难堪，承认自己只解了一小角就被七神找上门。
- 若林恩全程不开口、只用灵能稳住她，则她会一直自说自话地交代完后，主动问「你怎么不说话」，这是本事件唯一一次她主动关心他而不是小姐。
- 若林恩在她哭求的间隙抬手替她按下一条乱跳的数据流，则她会把这一下记成「他曾经对我温柔过一秒」，日后在她能反击他时这一秒将成为她收手的理由。
- 若林恩背着她离开巢都网道时故意绕到能看见血潮右路的位置让她再看一眼，则她会全程抓着他的后背不放，数据态指尖陷入他肩胛三寸，这件事之后她再也没松开过这个位置。
- 若林恩选择不带她离开、转身就走，则她的人格核心会在三分钟内彻底崩散，加密链路里只剩一句未发完的「以为林恩是——」，黑夜城求救的发信史变成无解悬案。
- 若林恩对她复述「py交易」四个字时故意只用机械声、不带情绪，则她会先愣一下、然后红着眼眶笑起来，那一声笑比哭更难看，但她意识到这家伙还记得。
- 若林恩在她叠音骂「恶魔」时顺口应一句「对，我是」，则她会愣一下，然后低声说「那就请你把恶魔做到底」，这是她第一次用他自己的话反过头来押他。
- 若林恩在网道上把她放下来休息时主动让她把数量对账一遍她记得的所有小姐踪迹，则他能多挖出两条被她当成废数据的边角，但每条独处她都会哭一次。
- 若林恩到达田园边界时先停下来让她整理自己那身残破数字衣，则她会沉默地照做，起身时对他低低说一声「谢谢，别看我」，这是她人格核心残存下「被害羞」这部分。
