# E409·诸天狱卒与康斯坦丁·if线

- 若林恩在康斯坦丁登场前就把支配者尸体用魂砂分成两份、只先交出一份，则死亡之主吃下这份后湮灭度从 97% 微降到 96.4%，另一半的交付变成交涉中的「一手交货一手交罗盘」的强约束。
- 若林恩主动把渡鸦残魂在骷髅面前晃两下又收起、不重述来历，则康斯坦丁压抑住想夺的冲动，整场交涉安静如仪式，但他之后会在波纹中反复做同一个姿势、像在求这对乌鸦再次现身。
- 若林恩刻意先答应尸体换罗盘、等到人偶家把规则讲完才补一句「报酬和救助捆绑，缺一件都不算数」，则康斯坦丁会先沉默再点头，罗盘在当场交付条件里多附一行「一年之约的死线」的骨质烙印。
- 若林恩当场拒绝尸体交换、改以「初诞者之力压制崩坏」的提议反咬，则康斯坦丁会在潮汐声中沉默良久，最后抬手指向自己空洞的右眼、要求林恩先在他眼窝里滴一滴原初之血当定金。
- 若林恩用拟化手套在骷髅肋骨上粘贴一张「卖身契」字条戏弄，则骷髅整场都不再正眼看他，但人偶家会私下转告「他其实被逗笑了，但觉得让同伴作贱他助兴是件很严重的事」。
- 若林恩在人偶家翻译时主动替她一句「他说的是父母、不是父亲」，则人偶家眼神一滞、康斯坦丁对她的好感度瞬间结算+3，但他对林恩的信任值会被这一句纠正打上一个问号。
- 若林恩让左左以左手形态当面摸一把骷髅的肋骨试试质感，则骷髅漠然不管，但喵喵立刻跳出来嚷「这是债主你好不要脸」，事后她对骷髅的初印象分上升、对林恩的信任分下降。
- 若林恩让小丑代他先与康斯坦丁寒暄一段、自己站在远处观战，则小丑会用一整段渡鸦式的古礼招呼对方，康斯坦丁的待客仪式整体放慢到琴弦般缓慢，人偶家会在事后感谢林恩让他出场。
- 若林恩主动对艾雯说「这骷髅的肋骨我拿去加码给你做灵能盾衬」，则艾雯的灵能屏障在当夜自动叠了一层骨质纹路，康斯坦丁隔天发现肋骨上少了一根伴生骨、盯着林恩看了许久。
- 若林恩拒绝让泰坦帮忙看家守尸，则尸体的看护责任被系统挂记为「临时战利品漂移」，艾雯不得不从咒纹警察岗上调配两名守夜夜医专门看护，事后消耗一笔额外的「战场公用品借用」状态。
- 若林恩刻意把战斗背景的「飞船沉骸」当成厨余堆留在涟漪边，则康斯坦丁会随手把那堆废铁扫进深海加一撮湿沙、化成几件可见的「水面鲸骨画」，事后人偶家愿意以其中一幅换走这份蜃景。
- 若林恩让喵喵代他与康斯坦丁对视十秒表达「己方有猫的祖宗警告」，则骷髅肋骨上的苔藓会浮现一抹绿锈、像害羞的潮红，它的蓝焰多了一瞬暖意，但他的下一句话变成「我不是来收猫的」。
- 若林恩用咒瞳扫视康斯坦丁胸口的「初诞者之力压制残留」，则他当场得知这股力量覆盖度不足百分之三，他以后在任何一次和死亡之主并肩时都会下意识把注意力集中到那个窄小的蓝纹上。
- 若林恩战斗中主动替人偶家挡下一波辐射、负伤，则她当场替他包扎，康斯坦丁对林恩的态度由此改为「尚可对话者」、不再带骨刺，但交涉时间被延长半天作为「礼尚往来」。
- 若林恩让小丑以「大君旧部」身份拜会骷髅、强调他的君主已死，则康斯坦丁对小丑的死亡礼遇规格全面提高一档，但他对当前林恩的态度反而冷淡一分，事后做个「你远差于老主子」的明确评分。
- 若林恩主动在骷髅面前展示自己体内的原初之力流动图、以医生的恭敬点头示意，则骷髅的肋骨瞬间亮起一阵共鸣蓝光，康斯坦丁当场定住半天不说话，人偶家侧问了一句「需要我转言吗」。
- 若林恩事后让骷髅把蓝色火苗人形化态保留下来挂在自己房间墙上当装饰品，则火苗每晚都变换一种色彩，他会在夜深人静时听到微弱哼唱，事后他把这视为「第二份随身伴侣」并挂在床头。
- 若林恩主动与康斯坦丁谈判时提到「我有一位叫杨琳的家人会想见见你」，则骷髅那么回复「如果是渡鸦后裔来历，那愿意考虑私信」，立刻让杨琳成为他面板上「可信赖的渡鸦后人」列表第二名。
- 若林恩答应人偶家的交涉、但特意在骷髅眼里藏一颗影像水晶回放支配者爹声哭戏，则康斯坦丁会突然沉默、用大骨指捏走那枚晶体，他的第二次出现时已穿戴假装正经的骸骨领带。
- 若林恩刻意用同样的「兄弟味道」跟康斯坦丁打招呼以显得自己早已调用过亚当证词，则骷髅完好地回答「兄弟闻起来也不一样」，主动把「亚当之调」背后的所有话都嘴皮子地保留下来，大幅降低对话互动质量。
- 若林恩在交涉中时刻压制咒瞳不向内侦测骷髅胸腔，则他保住一回干净的非暴力身份记录，但也错过一次「看穿灵魂之囚」的机会，事后破晓315博士对这件事件的报道失败、浓缩进404档。
- 若康斯坦丁在交涉中反对隐瞒初诞者之力、要求林恩亲口承认是同源给予者，则他会以「聆听生命真诰告述评」的方式封闭三天检视言行，第二天早上给予一张「原初者与罗盘的联盟之牌」。
