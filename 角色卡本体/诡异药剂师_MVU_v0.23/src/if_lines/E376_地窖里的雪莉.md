# E376·地窖里的雪莉·if线

- 若林恩在记忆开场瞬间主动俯身识别潮湿石板上的水渍来源，则他闻到地窖外有海风咸气，地下工厂靠海这条信息被预先锚定。
- 若林恩在铁栅栏打开瞬间主动抬头测量栅栏与地面的距离，则他估算出孩子无法从此逃脱的客观高度，雪莉的隧道计划在档案里第一次具备合理动机。
- 若林恩在孩子们争抢木桶瞬间主动计数食物分量与人数比例，则「年长强壮者占优、残缺瘦弱者拾取残余」这条顺序被写成量化记录，让疫医档案里第一次见到纯血的人类底层现状。
- 若林恩试图在分发瞬间用心声压住一两个较强壮的孩子想重新分配，则历史回弹、争抢原样推进，但他首次确认自己对集体场面只能旁观。
- 若林恩在那只布满伤疤的手伸向小女孩瞬间主动聚焦雪莉的手指形状，则他看到她食指被永久压短一截，旧世疫医缝合手法在他脑中闪过，认出这可能是长期劳作的旧伤。
- 若林恩认真听完雪莉那段朋友吃过友人的自述、并在记忆里记下「她吃过逝去的同伴」这一事实，则他未来要评定雪莉时可避免简单划分善恶，档案里留下一行「幸存者」前缀。
- 若林恩在雪莉递出食物时尝试悄悄用一缕疫医气息扫过她指尖的温度，则温度冰凉、心跳平和，这位十一二岁女孩的体能储备被他首次量化。
- 若林恩决定只关注小女孩接过食物那瞬间她的眼神，则他确认那是「空空荡荡」下的「有反应」，深层执念的「活着」一面清单多一条。
- 若林恩在雪莉说「我不打算抢你的娃娃」时主动在记忆里放大看布偶此刻的污损度，则布偶从花树街道到地窖只多了一道擦痕，这条布偶保存状态被作为后续情感参照。
- 若林恩尝试记下年龄较长的孩子里谁的眉眼与记忆中舞台上举牌人相似，则他认出其中一位正是舞台竞价时的那个买家模样，旧世人物联系首次在两段记忆间画线。
- 若林恩在铁钉偷袭记忆回放瞬间主动扫一眼咬人那一刹那的小女孩眼神，则他看到她空洞中第一次泛起「保护」的波澜，关于她并非全然的「无感」被再次记录。
- 若林恩在铁钉袭雪莉而她被救瞬间主动记住那个男孩的脸，则后续地下工厂等级或逃生场景中，他可以识别出这个心怀怨恨的孩子是否还在队伍中。
- 若林恩主动凑近工厂的机床并辨认齿轮的润滑方式，则他查觉那种油有动植物混合配方且温度极高，疫医档案里多一条「旧世润滑油麻醉成分研究」的伪兴趣记录。
- 若林恩在童工等级表被描述时主动把「合同工、劳工、奴隶孩童」三档工时并列记下，则档案首次量化旧世工业底层，疫医档案里「旧世劳工形式」分类落档。
- 若林恩决定只跟在雪莉与女孩两人的动线上、忽略其他被囚孩子，则他看到的画面虽聚焦却失去整体，下次想统览需要从另一时间线重新获取。
- 若林恩在雪莉处理老鼠那一幕主动观察她的铁片手法，则他学到一种旧世底层求生的锈铁钉猎法，疫医档案里多了一份别的时代求生技巧副本。
- 若林恩在雪莉警告「不要吃这个」时主动把她那段记载食物判读为旧世食品安全备忘录，则档案里形成一份旧世可食/不可食短清单。
- 若林恩主动接近地窖暗角查探是否还有其他孩子没被记录，则他在阴影中翻到一名已经停止呼吸的孩童残骸，疫医档案里多一条「无名童骨一号」记录。
- 若林恩试图在这个阶段主动留下疫医气息作为索引方便后续回访，则疫医气息在地窖旧世记忆里首次附着一枚「地窖标记」，但也首次被一个旧世生灵察觉。
- 若林恩在雪莉说「你可以当我的小跟班」瞬间主动评估小女孩此刻的接受度，则他看到她点头幅度非常轻微、但确定，深层执念的「依恋」一项首次有正面量化。
- 若林恩选择停留在两人初次递食画面反复回放十遍，则他对「求生互助」的细节足够熟，但失去从地窖片段推进到后续时间的机会，玩家需主动终止回放。
- 若林恩当场确认结束本轮追溯，则「雪莉保护者」身份、「初识」、「第一口食物」被落定归档，黑弦月的旧世苦难史第一页被锁上。
