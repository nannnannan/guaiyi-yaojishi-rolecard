# E348·自由与有人要见你·if线

- 若林恩在水面浮出首个泡影后就主动伸手戳穿其中一颗最近的人生泡影，则该段人生在他指间崩破成无数光点，老人会明确指出这是耗费轮回记录的不可逆动作。
- 若林恩看到泡影里那位少年初遇蓝龙的画面前主动把头偏向一侧不去看，则蓝龙与苍蓝女孩同源的揭示会在他错过画面时由老人亲口补出，节奏被替他推迟。
- 若林恩在紫罗兰大君与蓝龙重逢那一刻主动俯身贴近水面要看清那对恋人相拥的细节，则他会被水面反咬一口，那一帧幸福画面在他瞳孔里烧成一小片刺痛的灰斑。
- 若林恩在老人讲述大君以碎戒自焚时主动问出「是谁真的捏碎它」，则老人会第一次直视他说「答案就在你身上」，主体调查焦点从轮回移到那枚留在某处塔内的戒位。
- 若林恩追问衔尾黑蛇的来历时顺手把右手抬出水面，则衔尾会在水下投出一条比实物更长的倒影，老人会用这条影子作为他「就是掉入轮回的神」的最直接证据。
- 若林恩在泡影里认出那位温柔的大君之后在老人面前当场否定「那不是我」，则老人不会说服他，只会在水面轻轻点出一圈涟漪，让泡影自己去反驳这一否认。
- 若林恩试图把某一帧已经退色的泡影用自己的黄沙之力重新亮起，则那帧画面确实会短暂复燃，画面最后一次定格在一双紫罗兰色的眼睛上，老人警告他别再做第二次。
- 若林恩在听到分魂渡鸦解释时主动问出「渡鸦们都还在哪里」，则「已是最后一只」的事实会提前落地，老人不会再用漫长的叙事慢慢逼近这一句。
- 若林恩问「外宇灾厄具体是什么」时用一种过分平静的口吻，则老人会犹豫一下才回答说「连我也不愿正面描述那个形状」，未知威胁的悬念替他加深一层。
- 若林恩在老人说出「你已经自由了」的瞬间抬手把右手衔尾贴到水面，则整片黑海会以衔尾为圆心轻微朝内塌陷，他知道这一刻自身的存在在黑海维度里被重新加密。
- 若林恩拒绝接受「自由」这个宣判、用一句「我从来不是被关着的」回嘴，则老人会在离开前几秒留下一句额外的话：「被释放的人都这么说」，作为对下一段调查的隐喻。
- 若林恩在泡影中寻找紫罗兰大君的失败镜头而不是只看成功画面，则他会发现段位偏差不同的同一段人生，轮回迭代的底层不甘在泡影里第一次露出来。
- 若林恩在黑海试图召唤一枚从大君身边被放逐的渡鸦，则召唤波动会在水面拖出一圈渡鸦虚影但无法聚形，老人叹口气说「他能召回的那些也都随他同归了」。
- 若林恩在远景废塔画面被老人顺手揭开一角时恰好把咒瞳扫过那片血雾塔境内，则远方那位被困的命运神首次能隔一段距离被他的视线盯住，咒痕在她领口微微发烫。
- 若林恩在远景听到「有人要见你」四个字后主动追问「见谁」，则废塔画面会瞬间被老人用水面屏蔽，他没资格在那一帧追问下去只能记下「召见尚未公开」这一事实。
- 若林恩问老人废塔里那位命运神是谁的代理，则「曾经被觉醒的代理人」这一侧面被老人亲口补出，现世主母与渡鸦关系的底层脉络在这里多一笔勾画。
- 若林恩在远景画面切断之后回到正题问「我的下一处可去坐标是哪里」，则老人不再描述黑海、而是把空中一片虚空撕开成另一处老人亲手点出的海面缺口作为出口。
- 若林恩在告别前主动送给老人一缕自身血肉作为对引路人的回报，则老人接过那一缕时第一次把枯手放到了林恩肩上，这个姿态在黑海记录里第一次出现。
- 若林恩听完整个轮回解释后只是笑了笑、什么都没说就转身离开黑海，则老人并不阻拦，「你已经自由了」那句话在他背后变成一句完全开放式的空白接纳。
- 若林恩在离开前主动要求回头看一眼所有泡影里那位温柔的王，则他会看到最后一次定格是大君正推开一扇看不见的门，门后是他在这一世后来的所有样貌。
- 若林恩问轮回之外的下一世是什么、老人此刻说不知道，则老人不会编造安慰，他用一句远比描述真心的沉默告诉林恩：这一世可能就是末班车。
- 若林恩邀请老人同行走出黑海去黑夜城，则老人微微一笑推辞说「引路人的任务是引到这里为止」，远处水面的荒凉在他身后响起一声凋落似的轻响。
- 若林恩在老人临别时祭出他将自己的一句台词「我不想让位」，则黑海水面会为这句话震起一圈巨浪之后瞬间抚平，衔尾在他手上第一次烫得他几乎想缩手。
- 若林恩在黑海临别时主动把手中大君早已破碎的象征——裂开的戒指画面在心里重新拼合，则水面会为他照出一条隐藏在泡影之后的戒指原本模样，这是大君留给他的最后一份图纸。
- 若林恩确认「我不会作为渡鸦存在」，则「最后一只渡鸦」这一界定在他这里被锁死成不接受，黑海与废塔的后续因果不会以这条主线作为预设路径推进。
