# E37·白逸召唤降临与总局清剿·if线

- 若林恩在召唤降临前正与左左进行关键时刻，则可声明让左左以触手缠绕自己一同被召唤，左左作为附属信标被拖入蓝星，清剿队伍多一名根源级战力，但左左的拟化外壳被精神波动撕开更早，蓝星总局直接目击林恩与非人伴侣关系。
- 若林恩在法阵爬出时未着四角裤而是套着夜医长袍或工作服，则登场气场从「人形恶鬼」变为「异位面夜医」，王长官与杨柯的初判从「恶灵入侵」改为「异界支援」，挑衅链条改走谈判路线。
- 若林恩抵达时先把1元硬币捡起还给白逸再开打，则白逸恐惧度增幅降低，但林恩在清剿结束后少了「祭品签收」的口实，后续向白逸讨债的锚点改写。
- 若林恩选择不一电锯拍倒白逸而是先扫视全场读局势，则白逸保持清醒可即时对话，林恩跳过「先揍后问」环节直接进入事件问询，但白逸少了被一巴掌立威的恐惧记忆，敬畏值结构改变。
- 若林恩在隔空扇飞白衣女鬼时不宣告「他是我小弟」而改用其他措辞（如「这具身体我登记过」），则白逸与林恩的从属关系定义微调，总局记录的档案措辞随之变化。
- 若林恩只戴鸟嘴面具不掐恶灵显形药剂，而改用血锯或其他配方（如魂视药剂）替代，则恶灵显形范围与持续时间改变，蓝星方对林恩药剂库存的第一印象改写，后续总局以物易物的采购意向清单相应调整。
- 若林恩拒绝接过官员递上的AK而坚持用电锯或触手近战，则清剿耗时拉长，王蓓在暗处观察的窗口变多，她对林恩手段的认知从「火力手」偏到「血肉系」，影响E38审问时她的供词重心。
- 若林恩接过AK但不附魔直接使用，则普通子弹对部分恶灵无效的事实被现场验证，林恩被迫中途改用其他手段，总局对「凡火无效」的记录更早成文，后续专项组武备立项提前。
- 若林恩在清剿影中女鬼时不直接踩爆而是选择活捉，则多一只可审问的蓝星恶灵样本，血肉神教入侵路径与克勒斯下落获得更早线索，E38审问对象从单一王蓓扩展为多对象。
- 若林恩清剿时刻意放走一两只低阶恶灵，则血肉神教接收到「异界疫医已降临蓝星」的活口情报，蓝星分部进入警戒收缩，林恩后续在蓝星的行动难度与突袭价值同步上升。
- 若林恩在戴面具前先用触手在白逸腹部做紧急止血，则无麻手术环节前置失败，【灾变的造血法】成就以非完美路径结算，阑尾标本可能因应急处理无法保留。
- 若林恩向白逸索要麻药而白逸交代「麻药过期」之前就改用自己的药剂麻醉，则白逸进入真正无痛手术，恐惧度+30改为+10或感谢向数值，但林恩暴露药剂库存深度，蓝星方的索取清单扩大。
- 若林恩无麻手术时让白逸保持清醒对话而非任由其昏厥，则「白逸的刀伤」任务结出的好感中混入共患难度，白逸后续冒死求林恩救治尹琴的动机更早铺垫。
- 若林恩在拉肠子检查时不只取阑尾同时取其他组织样本（如一段小肠、淋巴切片），则蓝星方的医学观察报告更厚，白逸对身体被「过度采样」产生额外芥蒂，医患关系紧张度上浮。
- 若林恩选择不以尾巴材料给白逸缝合创口而改用常规医用缝线或自己调制的生肌药剂，则【白逸的阑尾x1】膨胀肉块失去「同源修复」前提，肉块活性与后续可调用场景改写。
- 若林恩在手术结束时没把绳状装置穿过白逸颈部直连静脉，而改用腕部留置针或外敷药剂，则白逸的日常行动自由度提高，但「被林恩债权拴住」的视觉符号减弱，E38—E40期间白逸的服从姿态松弛。
- 若林恩在「这里又是哪儿」之前先撕开矿泉水瓶泼在白逸脸上把他弄醒，则问询节奏从「林恩主动提问」变为「白逸先描述」，林恩获得信息顺序调换，蓝星局势的讲述视角从求援者主导。
- 若林恩在克勒斯透过水晶球窥探时反向感知到视线，则以触手或血锯刺水晶球一角，克勒斯被Retroactive反噬受创，他后续被活捉的地点与状态改变。
- 若林恩注意到阴影里san值狂降的王蓓并当场把她拎出来显形，则E38审问现场提前至清剿尾声，王蓓在总局众人面前被审，供词被多耳共听，根源关系网的公开范围扩大。
- 若林恩落地后第一时间要求见总局最高负责人而非跟白逸单聊，则王长官/杨柯/灵媒组同时到场，林恩与蓝星官方的合作框架在事件内直接摆出，跳过后续单独建交的回合。
- 若林恩在清剿结束后选择不在蓝星停留而是立刻让白逸用反向法阵送回，则半天召唤时限未用尽，林恩回到酒店时左左「事业」未被打断太久，但蓝星方对林恩的身份记录只有短暂一面，后续召唤成本上升。
- 若林恩主动延长驻留至时限压满，把剩余时间用在勘察地下收容区结构，则蓝星方对林恩「可追溯」的记录更详尽，林恩反向了解蓝星灵能防线情报，E38根源关系网推演时素材更足。
