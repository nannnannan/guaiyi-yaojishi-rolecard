# E105·密室除患与全舰生化下毒·if线

- 若林恩不演殖装爆炸戏而是直接以执事令强闯瘟疫研发部，则 401 莱恩起疑先拨通了 315 的密线，第一场对峙升级成 315 亲自监场，密室独处窗口被取消。
- 若林恩在向 315 汇报时把"更换身份识别"换成"扩充行动部战备药剂"，则他跳过瘟疫部直通武备库，E105 失去绝密瘟疫配方这一收益，转入变形——改走正面军备扩权链路。
- 若林恩没带黑弦月而是换左左进密室，则莱恩虽被电钻贯穿却仍能用缝合人濒死神经反扑，整个除患的过程被拉长到走廊外疫医听见的程度，事后需清场灭口。
- 若林恩不封喉而是让莱恩有机会惨叫，则门外的疫医队长立刻破门，密室战变成瘟疫部混战，黑弦月不得不把整层走廊全部提线封口。
- 若林恩在密室里放弃夜魔刀而改用 96 级缝合人的神经麻痹术，则莱恩当场被麻痹但未死，存活人被押入系统空间，E105 收成"俘虏"而非"斩首"，刑讯链后续改为活体拷问。
- 若林恩贪心把密室里所有柜子整体搬空包括巨型机械容器，则系统空间报警溢出，林恩被迫当场丢弃部分禁药，遗失哪几种药剂由玩家勾选指定。
- 若林恩对喵喵隐瞒母亲真相、只汇报"她早死了"，则喵喵短暂失去复仇焦点，但 E107 真相被 315 揭穿时她的信任值直接腰斩，需后续重建。
- 若林恩在刑讯时承诺莱恩"交代配方就给你个痛快"并言出必行，则系统判定忠诚履约，解锁"信守承诺的死神"标签，但瘟疫配方只录到七成。
- 若林恩不刑讯而是改用记忆读取型药剂灌服莱恩，则配方一次拿齐，但记忆残片里夹带 315 与破晓 315 当年的血脉真相，林恩提前获得不该在 E105 出现的设定情报。
- 若林恩在调配四合一药剂时刻意剔除涩涩药剂与血肉增生药剂，则最终配方只剩催化+延时双组分，引爆后疫医全员只冻毙不恶堕，后续全舰布毒故事偏向冷酷战损而非肉欲作乐。
- 若林恩反向在四合一里多加一滴魅魔药剂 2.0，则部分年轻疫医在毒发前陷入肉体狂暴，利维坦内舱陷入自发性群交暴动，全舰生化下毒变为滑坡堕落大婚。
- 若林恩把"试验环节"的触手爆浆剂用作身份识别针剂的正品，则全舰数千疫医在注射瞬间同时被触手型诅咒扎根，E105 收成"全舰触手满身"重口味版本。
- 若林恩拒绝亲手分药、把针剂全权交给某小队执行，则小队队长成为叛变的免检点：他有可能私扣一批药剂献回 315，全生化布局在引爆前被发现。
- 若林恩故意给特定自己人不注射、事后伪装他们也注射了，则E106—E108期间会留下两位数干净疫医作为潜藏备用力量，但行踪明面上仍按"已注射"上报。
- 若林恩带着喵喵当面向莱恩亮出旧照，则喵喵情绪彻底失控当场扑上去撕咬，刑讯链条被打断，配方只录一半，莱恩被喵喵咬死而非斩首。
- 若林恩把莱恩的头颅留作通灵素材而不是现场销毁，则他将获得一颗"缝合人博士梦魇颅"，可在后续事件中换取对 315 的额外勒索情报，但头颅本身会吸引利维坦其他疫医的目光。
- 若林恩不动手杀莱恩而是把他放逐进系统空间"永生监禁"，则 E105 收为"失踪"而非"死亡"，315 会用全舰搜寻莱恩，林恩的潜伏身份面临被深挖的二阶清查。
- 若林恩在走出密室后立刻对门外疫医下令集体封锁瘟疫研发部，则他跳过"四合一注射"演出直接军事管制，全舰生化下毒改为分批强制注射，触发数千人戒备状态。
- 若林恩在对药剂命名时不沿用"身份识别针剂"而是公开声称"增强各小队神经连接的精神性强化药剂"，则疫医主动踊跃注射且事后无人起疑，生化下毒的执行顺利度拉满。
- 若林恩在 E105 完成后立即选择立即引爆四合一，则全舰疫医同刻毙命，利维坦机能局部瘫痪，但 315 与破晓 315 因为等级豁免存活，主线进入"全舰屠杀+正面对决两位元老"的高危变形。
- 若林恩在 E105 完成后延后引爆、把四合一当作长期休眠蛊，则 E105 收为"毒蛊已布，未爆"，后续任一事件都可被玩家触发引爆，生化布毒沦为常驻威胁按钮。
- 若林恩把刑讯时莱恩透露的"喵喵母亲心灵扭曲木偶化"情报如实告诉黑弦月，则黑弦月在 E106 里主动请战去人偶庄园，但 E105 当夜她在林恩怀中崩溃大哭一整晚。
