# E377·朝夕伙伴与逃生管道·if线

- 若林恩在雪莉回忆初识保护瞬间回数两人相互拯救的次数，则他发现「她先护布偶、她后咬铁钉」是等价交换，深层执念里的「互相」一项得到首次可对照证据。
- 若林恩在鞭打画面瞬间主动测量血痕长度与孩子背部面积比例，则疼痛阈值档案里首次写入「鞭痕长度超过背宽」这一量化。
- 若林恩决定只跟随雪莉视角观看两年工厂生存，则档案里多一本「雪莉求生手册」角度副本、却少了小女孩视角的大量细节。
- 若林恩在雪莉说「我吃不进齿轮缝了」瞬间主动评估她的体型与齿轮缝隙宽度比，则地下工厂淘汰曲线被标明，逃生时间窗首次具备限期。
- 若林恩在她递还给雪莉布偶安慰她那瞬间主动锁定这一动作的意义，则「她的互相安慰首次动作」被记录下来，深层执念里「安慰他人」的方向被点出。
- 若林恩在雪莉诉说妹妹往事时主动把疫医气息柔化成温暖白光扫过她，则疫医气息被记忆边界压回，但他第一次在旧世记忆里测试纯白安慰被回绝。
- 若林恩在雪莉鼓励女孩发音瞬间尝试心声教她喊「姐姐」，则他在历史里不能真正教、只能旁观，但他第一次听到这个词的历史音量。
- 若林恩在掀开木板看到隧道那一秒主动测量隧道长度与直径，则「一年多挖掘」量化被写入档案，逃生规模被锚定为「女童用」。
- 若林恩在两人开始外逃瞬间主动跟在队伍后面选择爬行顺序，则他在记忆里能验证雪莉让小女孩先爬这条顺序的真实动机。
- 若林恩在恶犬惊动工厂的哨音响起瞬间主动记哨音频率，则档案里多一份旧世工厂警戒音效档案，下一段记忆先听觉就能识别。
- 若林恩在排污管恶臭瞬间使用疫医气息试图给女孩一缕氧气，则疫医气息无效、历史原样，他首次确认在他人记忆里连呼吸都不能干预。
- 若林恩在雪莉被铁片割腹瞬间主动凑近想看她伤口的走向，则画面瞬间血色漫过画布边缘，疫医气息在那刹那被动触发，他感觉到她失血的真实量级。
- 若林恩在雪莉交代硬币处置瞬间主动记住那一枚硬币的形状与记认之路，则档案里首次确认硬币的物理特徵，后续剧情里再出现能直接对上。
- 若林恩在她嘶哑喊出「姐姐」那瞬间主动贴近再听一遍发音细节，则他在声音图谱里认出这是「人声初次、泪腺打开」的罕见声音，疫医档案多一条「情感首声」。
- 若林恩在她被推向海面时试图拉住她衣角想参与救援，则记忆反弹强劲，他被击回到黑堡床边、咳出一口黑雾，本次下潜被迫中断。
- 若林恩在雪莉说「我听到了」那一秒主动用灵能把这句话封成一枚声音化石，则他在档案里多一枚可重播的雪莉语音样本，当作后续情感治疗的素材。
- 若林恩在分离那一秒反方向转头朝黑暗里雪莉的方向目测她是否真的被卡住，则画面瞬间模糊，他意识到「历史在这个点不给我继续看」的边界。
- 若林恩选择把海底分别的画面就此收束、不再往下看，则本轮记忆接触停在分离一幕，档案里默认「雪莉去向未决」。
- 若林恩主动尝试跟那段已经推入海底的黑暗追溯它的延伸方向，则他被记忆边界强行弹回床边，深层意识海首次让他体验「不在历史主线」的流弹。
- 若林恩在回到现实瞬间把刚才记下的所有细节向床边人偶夫人汇报一遍，则人偶家档案里多了一页完整的雪莉求生史，与黑弦月深层执念呼应度被首次量化。
