# E760·敬明天·if线

- 若林恩在两千人集会之初主动把名字从他们口中的「王」改成「林恩」，则第一阶段的重逢充满笨拙，但后续每一次碰杯他听到的都是「林恩」而非遥远的王。
- 若林恩在第一位幸存者恸哭向他忏悔时主动开口承认「是我铸下的恶果」，则恸哭转为沉默，他在那一刻真切成了孤家寡人，但两千人免于再错付信仰。
- 若林恩选择隐瞒真相继续扮演他们心中的王，则盛宴与笑声多延续十日，但每一个死者临终的信赖都要在他心头刻一笔。
- 若林恩主动在每一场宴会上记住一个新名字而不靠因果记录，则两千个名字以他自己的肉身记住，死后这些名字没有依凭，却只在他一个人记忆里活着。
- 若林恩在最后幸存者「敬明天」举杯时也举杯并陪一句「敬你们」，则那个职业者临终的笑容转成孩子一般，E760 的告别从他举杯的那一刻起就提前成立。
- 若林恩主动把自己第三阶段升格后产生的某种力量，作为礼物分一小份给宴席上的人，则他们短暂拥有抗击法则衰退的药剂，但每人身后多一根引向林恩的无形细线。
- 若林恩在葬礼上允许自己流泪而不是坚持黑火压住，则他的眼泪在废墟上砸出第一个可见的小坑，未来那里成为重建黑夜城的一个泉眼。
- 若林恩主动在宴会上讲一个关于小小和主母的故事，则那些故事成为后来他对每个死者告别时的份子，但每讲一次他都要承受一次真实失血。
- 若林恩让黑火在每一个死者临终时烧掉其最痛苦的记忆，则他们走时都带着微笑，但林恩的存档里多两千份他必须独自记住的黑暗。
- 若林恩主动把最后一位幸存者的滑稽舞步完整记下来并复刻一次，则他日后在废墟独自练舞时，会有一双不再存在的手搭上他的肩。
- 若林恩在某位幸存者临终时收到一句「不要难过」并真的不难过，则他学会了一种不还价的哀悼方式，但每使用一次，心口某处就枯一寸。
- 若林恩在两千人中挑出一名孩子与她单独相处一天，则那孩子在死前拥有一次不被分享的温柔，但其余一千九百九十九人多了一层无法排除的羡慕。
- 若林恩主动把自己王座投影一部分到宴席大厅作为共同火炬，则两千人的光在同一盏火焰下重叠，但每熄灭一次他都多承受一份火焰自身熄灭的痛。
- 若林恩允许某位幸存者当面骂他「你为什么没能救他们」，则那位死者的罪责不必带去九泉，但林恩的黑火在那一瞬反噬他一根指骨。
- 若林恩在宴席黄昏时主动告知他们「我就是你们的刽子手，我不求原谅」，则两千人面前少一具被普度抬走的神，多一个能被他们真心憎恨或真心原谅的活人。
- 若林恩在宴会间偷偷为某位老者多续了三日寿命，则那老者可以多看完一次落日，但林恩日后必须告诉自己：这是用他自己黑火里抽出的一格。
- 若林恩在最后一名死者墓前主动种下一棵用记忆火催生的幼树，则未来黑夜城重建时那棵树先于一切长出新叶。
- 若林恩主动把每位死者喝空的酒杯都收进王座，则未来他在废墟上一人独酌时能摆出两千只杯子，每只都对应一段旧宴。
- 若林恩在某次宴席中主动讲述羽毛笔的存在，则某个幸存者在死前为他画了一幅赠羽的涂鸦，那画作日后在命运之地的桌上展开。
- 若林恩让黑火温和地烧掉废墟周边所有可见的死状以保两千人眼不见，则宴席气氛不被戳破，但他承担两三千份不再被人记得的具体状况。
- 若林恩主动把「敬明天」这一句话刻进王座底面而不是口述，则它成为一种持久法则，未来每一次他濒临崩溃都可以直接召唤那一句而不必解释。
- 若林恩在宴席中对最后一位幸存者坦白小小的事，则那死者在举杯时多了一种「我也是为小小」的版本，敬酒词改写。
- 若林恩主动放弃寻找那位神王，只把时间用在陪伴这两千人，则主宇宙的某位神王位置永远缺失，但两千人的死亡仪式全都在他亲历。
- 若林恩在两千人都死后主动把自身王座的某一段折叠封存，则他未来在沉眠中不至于被两千人的记忆一次性压垮。
