# E27·白逸遣返与九州异变·if线

- 若林恩在手机修好前先把那张黑色网页照片冲洗成实体底片挂进店里，则血契诅咒波动被墙面基底吸收一半，遣返时限延缓数日，白逸获得额外告别窗口，但底片本身成为下一份低阶召唤媒介，引来新的异界窥视
- 若林恩用夜魔刀砍下小拇指之外再剜一滴指尖血滴入白逸衣领内侧，则信标升级为血肉双联凭证，跨界回响更强，白逸回九州后家中厨房水龙头定期流出黑色汤药渣滓
- 若林恩以完整手掌替换小拇指作信标，则血肉支配者容器权柄被削弱一线，白逸在九州入睡前会梦见血锯药剂店的货架与捣药声，跨界感知通道被强行撑开一线
- 若林恩拒绝自残、改用一段猎魔人赠予的鬼面骨粉作信标，则凭证稳定性下降，白逸回归后凭证时限紊乱，九州方只能在月相特定的深夜接收模糊跨界定标
- 若林恩在血锯面前隐瞒《契约：黑暗世界的邪神降临仪式》来源、只拿出照片要求解读，则血锯眯眼不语、事后单独把书页抄录塞进林恩枕下，附一句"下次藏深一点"
- 若林恩把自己的名字也写进家书里并请白逸转交九州亲属，则白逸父母入院后翻出信件陷入新一轮恐慌，专项调查组把"黑暗世界药剂师林恩"立为一级档案对象
- 若林恩用九州文字抄写全套召唤法阵并自愿署名，则专项调查组根据笔记指纹与书写习惯锁定"蓝星曾存在过林恩此人"，跨位面身份记录被官方建册
- 若林恩让白逸在遣返前试穿一件店里售卖的简易护具或揣一瓶疗伤药剂，则白逸砸落第九国立医院时胸骨裂纹大幅减轻，院长 X 光片省去"下垂心脏旅游"那张桥段
- 若林恩在白逸临行前晚陪他通宵打游戏机请一顿饯行餐，则道别段落从工作台前挪到店外门阶，遣返瞬间白逸喊的是"大哥保重"而不是"不锈钢"，余韵更轻
- 若林恩在遣返瞬间扑上去抓住白逸手腕、试图跟随穿越，则血契判定"非契约签署者"，林恩被跨界涡流弹回店内、撕掉三枚指甲，九州方只接住白逸一人
- 若林恩在白逸虚化前把店招牌铜钥塞进他口袋作为替代信标，则遣返后铜钥跨越位面成为九州方唯一可定位黑巷的物理标记，调查组在巷口连续蹲守三个月
- 若林恩完全不准备信标与家书、默认白逸自回，则事件按变形口径收束：跨界仅凭血契一次性喷发，白逸归位后茫茫无寻，九州线推入更长周期才重启
- 若林恩提前拆穿白逸曾在魔都网吧输入真名的细节，则白逸因羞涩与后怕主动交出手机所有浏览记录，新闻收藏夹里发现另一条同类黑色网页，留下第二位限时召唤物伏笔
- 若林恩在血锯解读契约时段外唤来左左旁听，则左左把"短期召唤物"口径与血夜地狱行者记忆串线，后续与林恩探讨"是否可把血契反推为某种位面交易"的新研究方向
- 若林恩在白逸走后把那张修复完成的手机充电并维持开机，则手机在九州方偶尔自动亮起、屏幕浮现腐烂符文，调查组技术人员报废三台读卡器后封存
- 若林恩请血锯在遣返瞬间加贴一张血族封缄符，则跨界喷发波形被压成单向，九州方不会再有回流泄露，但白逸回归后也无法反向投递任何消息
- 若林恩在遣返结束后才告知左左/小小白逸已经离开，则二人隔日上门扑空，小小把店里诊疗床拍得轰轰作响、左左沉默半日，幸福之家日常在 E28 登场时先挂一层低落底纹
- 若林恩把白逸留下的碎屏手机残骸碾成粉末掺入新药配方，则药剂附带微量"九州信号残留"，后续调配故障诊断类药剂时偶尔闪回蓝星街景画面，进入长期伏笔条目
