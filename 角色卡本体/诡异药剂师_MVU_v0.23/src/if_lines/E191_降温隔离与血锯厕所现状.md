# E191·降温隔离与血锯厕所现状·if线

- 若林恩在折跃落地前先掏一支冰髓药剂直接塞进尹依怀里，则她的以M发作被短暂压回意识底层，湿透长袍不再贴身，「塞子」名场面整体取消，事件以低温急救变形收束。
- 若林恩用冷水强行又泼一遍尹依头顶换掉那身冰水，则她关于「被林恩包裹」的幻觉减少一层，抵达游魂巷时不打喷嚏改为眼皮发烫，后续侦探节奏改成由她先开口念店牌。
- 若林恩在街角止步时让左左替他读出店牌四字，则「血锯厕所」由左左先炸、尹依先愣，林恩本人被挤到旁观位，事件以左左率先失控变形收束。
- 若林恩在第一个烧死鬼出门时就开枪点名，则系统那条知名度提示直接作废，店门口警戒瞬间升级，第二、第三类奇葩顾客可能不再出门，魔改真相正面开撕。
- 若林恩把猪头人身游客拦下来按外乡顾客做笔录，则他能撬出一条「澡堂预约点单走哪里」的口语线索，事件调查节奏改为先问后抄。
- 若林恩在独眼妖娆搀缝合怪那一幕触发超维感应，则地下圈养区的畸变铃铛源头被提前锁定，E192潜入节奏前移，但被大舌头反向警惕概率翻倍。
- 若林恩用折跃镰刀把「血锯厕所」门牌现场削改成原店牌，则门面拆台一招见血，大舌头和血肉神教在十分钟内接到自家公物被毁的警报，事件以林恩当众摊牌变形收束。
- 若林恩把尹依寄存在街角不让她跟进店前，则她不再目击三类奇葩顾客，后续她的以M发作在店内撞上「奴隶少女」话题时直接炸膛，事件以尹依暴走变形收束。
- 若林恩在店前直接拍黑颅币示意「爷来嫖」劫闸门，则上钩进门的速度提前，但他第一时间撞见的是柜台血肉人形而不是地下圈养，事件变形为「一开始就被推去接客位」收束。
- 若林恩选择不惊动门内、等到夜里再来，则店门口三类奇葩顾客全部放量走掉，观察窗口延长一夜，但陪同的左左会一路口头催促「不如动手」。
- 若林恩改从后院外围绕进地下圈养区，则店外的「血锯厕所」对峙完全取消，事件变形为暗线接 E192，原作收束标志改由「潜入圈养」触发。
- 若林恩在情绪失控那侧还没开始高脚帽威慑就先自报「我叫恩·林·血锯」，则夜医包围体系先于正门暴露被架起来，林恩本人失去伪装潜入的合法借口，事件变形为以强突硬闯收束。
- 若林恩把店牌与整扇门现场拆下来塞进系统空间当证物，则店面变得连招牌都没有，血肉人形柜台接待挂成「本店今日停业」，外面黑雾上游魂巷老邻居会第一时间向眷者打报告。
- 若林恩打开巨像之心反向锁链，把大舌头的忠诚印记在店门口现场唤召，则店内三当家立刻跌跌撞撞出门接驾，「血锯厕所」对峙直接转为「被召来的小宝贝当众下跪」，事件以身份亮牌变形收束。
- 若林恩把尹依暂时放进系统空间不带进店，则事件以单人潜入姿态运行，但他失去一名现场目击者，后续说服尹依相信这是「宗亲被夺店」需要另找证据。
