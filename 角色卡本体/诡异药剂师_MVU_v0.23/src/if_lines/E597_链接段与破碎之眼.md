# E597·链接段与破碎之眼·if线

- 若林恩在感知链接段异常时立刻通过心灵网络向所有根源预警，则军团会陷入一阵更紧张的备战，但林恩个人的侦查窗口会因此被打乱。
- 若林恩让小丑先带回消息、自己刻意藏起来一日不出现，则劣种侵蚀现实会更早加剧，但林恩能亲见更多的底细。
- 若林恩在遣回小丑时用心声向他说「麻烦你了」，则小丑反而会沉默几秒才回一句「哼」，但他回程路上会更用心汇报。
- 若林恩在空间乱流中潜行时主动对乱流取一段本体作样本，则他会在事后带出一条由乱流本身构成的「路径来路」，此路会成为 E598 心灵闭关中一个核心材料参考。
- 若林恩靠咒瞳放大盯住神国骑士的胸前徽章，则他能读出这些骑士来自第一次时间战争里他与星轨所说的同一「第几区」，对面来历就此落入他的面板。
- 若林恩在碎碗之星残迹内试图远程感应一股「天父」气息，则他会立刻被那股气息反咬一口，瞳孔裂一道细缝，但感应得以锁定残迹。
- 若林恩直接在破碎之眼边上留下一根空间签名，则他能从那里拉扯回这次侦查的所有数据，但也会让他个人的痕迹被敌方感应得一清二楚。
- 若林恩选择绕过破碎之眼返回第四位面，则他会失去一手「远征起点影像」，但他会保住自己与敌方距离的一线隐晦感。
- 若林恩在返回时直奔银幻所在地而不是岔路口，则他会撞见她独自改造中的某个尴尬片场，他们的合作程式从此插入一个隐秘的私人记号。
- 若林恩不公开「死战不退」口号而只用自身行动示意，则军团会经过一段迟疑后才自行聚集，但聚集起来的心境反而更坚定。
- 若林恩在真相揭露前访问过多关于破碎之眼的记录，则他会在那一段夜里一个人呆立片刻，只有左左在意识里看着他没有动作。
- 若林恩在发布死战不退前先私下对左左说「这可能是最后一场」，则她会在心灵网络里再次失控双臂抱住他，所有人的眼神都会被迫回避。
- 若林恩选择让银幻继续改造而自己一人留守第四位面接收消息，则他会错过她改造途中那次微妙的「怒而砸一拳」现场。
- 若林恩让小丑随行一并去监控节点布置，则小丑会以急促但精准的手法留下比林恩更浓密的监测，敌方若启用感应隔幕将面临更大挠乱。
- 若林恩群发布「死战不退」后主动留下一句「事后我请你们吃饭」，则巫神、泰坦、石祖会在群频里真的开始讨论宴席菜单，紧张中找到一口喘息。
- 若林恩对破碎之星中央再次发动一次时空手艺以确认轨迹，则他能从大得星空象中读出他们已被多层封锁嵌入，但也会触发敌方察觉到一丝不对劲。
