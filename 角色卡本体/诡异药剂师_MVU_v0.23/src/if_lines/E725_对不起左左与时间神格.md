# E725·对不起左左与时间神格·if线

- 若林恩在冰晶前再多停留一分钟、把她脸上的每根睫毛都记下来，则他日后任何疲惫到崩溃的瞬间都能立刻唤出这张脸重新提起刀，但左左的印记在那一刻会真正灼烧他一次。
- 若林恩在把她推回时间之外时不喊「等我」，则她意识深处会少这一句话的锚，将来某个节点她可能比他预想晚一刻才被唤醒。
- 若林恩在心里把「对不起」说出口之后立刻把刀架到自己心口说「这是最后一次」，则这个誓言会被罪火直接烙进他骨髓，违背它的代价是当场陨落。
- 若林恩没有把「回游魂巷的小家」这段说给她听，则她将来在苏醒时不会立刻知道该往哪里走，需要先听林恩说一次才能安心。
- 若林恩在银色耀阳劝他带回左左时破口大骂说「你根本不懂什么是爱」，则银色耀阳会真正愣一秒，那一次的笑容会极轻地变成沉默，他对林恩的兴趣自此再上一个量级。
- 若林恩接受银色耀阳「把她带回」的建议，则左左会陪他走完接下来的路，但那个残酷未来降临时两人的因果将死死缠绕，他将失去「让我一个人背」的选择。
- 若林恩在心里承认银色耀阳说对了「凡人劣根性更深」，则他不会反驳，但他也不会改，他会以更深的执念把它贯彻到底，整个人多一分坦然也更多一分疯狂。
- 若林恩在收下时间神格那一刻突然把刀出鞘半寸威胁银色耀阳「你在骗我我就斩了这条时间」，则银色耀阳会大笑一声、第一次真正认同这个后辈的狠劲。
- 若林恩不问银色耀阳的目的，则他会失去一次确认「对方帮我的原因」的机会，但也会得到对方一句「其实你有这一刻没问，已经比他像样多了」。
- 若林恩试图当场杀银色耀阳试探其不死身，则银色耀阳会以一缕笑意接下这一刀、并把那一刀反灌回林恩的罪火里，让他多了一次淬炼。
- 若林恩在表达「我会盯着你」之后不再多说、转身就走，则这次会议以最短成本结束，但与银色耀阳之间的隐形对峙关系被永久确立。
- 若林恩接过时间神格之后不立即熔铸、先藏在系统空间底层，则他能保留最大的灵活性，但每次离开黑夜城都得担心它被偷或被夺。
- 若林恩没有时间神格入体之前先在精神中刻下左左的名字，则他将来在熔铸时会以「为她」作为最稳的引子，自斩阶段需承受的内心挣扎会略微减轻。
- 若林恩在收神格后的第三日立刻自斩空间神格，则他会更快摆脱初诞者隐患，但同时也在接下来两年里失去对神疆的精细调度能力，必须靠艾维儿补位。
- 若林恩决定先靠三叉戟承载权柄再自斩神格，则那条路能成，但他在未来一年里都再也握不住属于自己的刀，必须先习惯「战士而非执刀者」的姿态。
- 若林恩在研究罪火进阶黑火时主动把自己的梦境扩张到极限并强迫火焰自燃，则他会把自己烧到濒临心神崩溃，但黑火门路会在他几乎断气的那一瞬开启一线。
- 若林恩在尝试自斩神格前突然想起左左说过的「脑袋你不要一个人硬撑」，则他会停下动作、留下这一刀不斩，回到黑夜城去和艾维儿商量后再斩，留一条退路。
