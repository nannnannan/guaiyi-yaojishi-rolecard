# E172·修瞳条件与失控的视野勘测·if线

- 若林恩在四大根源就位供能前主动在勘测仪外壳刻下一段保险咒纹，则艾雯试戴时的全息影像被拦在他本人眼眶处不溢出，女夜医澡堂名场面不发生，社死链条整体取消、盲修结论缺乏佐证样板。
- 若林恩拒绝接过视野勘测仪、直接把手抽回表示「我修不了别人的作品」，则艾雯被这份单方面弃修整到权力地位受质疑，事件以变形（拒触）收束，后续「盲修魔改率极高」结论无样本支撑、修瞳仍延期但缺乏硬证据。
- 若林恩修完勘测仪后抢在艾雯之前自己先戴并检索「夜医·非澡堂」，则装置魔改版反向检索出某段「夜医密档里的主母背影」直接落入林恩眼帘，事件以变形（先戴攻击）收束，社死对象由艾雯转为林恩。
- 若艾雯戴上勘测仪之前先在镜片内侧刷一层「画面屏蔽」防护咒，则镜头映出检视画面但不锁定澡堂坐标，艾雯社死场景消失，原作名场面整体转移成其他抽象画面。
- 若林恩在装置被扣上自己眼眶时主动向外发动拟化、使勘测仪与自己一体的鬼魂化具形，则众人拔不下来他额头上的仪器，事件以变形（被扣装备）收束，危险性比原作更大但画面观感改变。
- 若林恩在画主母背影速写时主动多画一行标注「观察社会记录用途」，则艾雯抢到装置时多了一层无法反驳的借口、社死加重、主母在画面卷起发丝时才响起的声音变成「你的记录很不错」、路线再分岔。
- 若林恩在主母从画面里发话前的半秒钟主动反手遮住勘测仪镜片，则主母的声音被默，艾雯只看到中段背影，社死火力减半，事件以变形（遮住反制）收束。
- 若林恩在摘下装置抽出折跃镰刀夺路而逃时不向广场跑，改跃入黑夜城地下暗室，则艾雯与巨像之脑无法追上，事件以变形（跳站）收束，修瞳结论会议因林恩本人缺席而被无限期推迟。
- 若四大根源密谋跨界召唤时林恩已提前得知并主动送上诅咒修复请求，则根源们不仅没回避他参与、反而把「跨界召唤」与「咒瞳修复」并列计划，事件原始「背着林恩」设定被改写。
- 若林恩在修瞳前主动把咒瞳碎片送进系统空间完全不取出，则根源供能找不到物质锚点，修复失败、事件以变形（取不出货）收束，原作「神之方程式金光」整段取消。
- 若林恩在修瞳前临时更改条件：「我不要求咒瞳修好，我只想知道为什么会碎」，则根源们被这份减配请求减压，事件以变形（目标降级）收束，E173垫刀链条不会产生。
- 若艾雯在主母发声后并不慌乱抢装置、反而大方朝向画面行礼寒暄，则林恩被迫在画面里亲眼目睹父妻对话半分钟、原作社死转移为隔阂冷场，事件以变形（艾雯大胆）收束。
- 若林恩在盘膝坐地速写时画的是「主母正面肖像」，则画面信息量比原版更强悍、艾雯抢装置时会把这一幕牢牢记住，事件以变形（正面画泄密）收束。
- 若林恩在艾雯强扣装置上自己眼眶时瞬间以恶灵视角化身离开本体让装置悬浮空转，则他被不留下来，勘测仪看到的是「空无一物的眼窝」，事件以变形（灵魂空转）收束。
- 若林恩在闹剧后第一时间取出纸笔记录「盲修魔改率」写入正式报告上呈主母，则严肃学术化流程启动，修瞳由「豪赌」变成「正式立项」，E173的玄学垫刀只会改成可追溯的实验设计。
- 若林恩并没盘膝速写只是站起来环顾四周，则艾雯抢装置时看到的就是空白画面、社死场景整体未发生、修瞳结论的依据只剩艾雯试戴那一刻的澡堂名场面。
- 若艾雯在试戴失败后当场把勘测仪摔碎了事，则盲修魔改极客的样板被毁，修瞳会议失去排他证据，事件以变形（撕毁样板）收束，「必须垫刀」结论基础松动。
- 若林恩从镰刀跃出后自己主动回到广场并摆出一副「你们逼我的」恳求表情，则四大根源反过来被他的态度整到失语，事件以变形（倒打一耙）收束，修瞳结论的公正性打折。
- 若巨像之脑在修瞳条件提出时主动增设一条「修复失败就把你右手砍掉重长」，则修瞳筹码变成生死局，事件以变形（加码升级）收束，后续垫刀决策压力加大。
- 若林恩在整个事件中完全拒绝涉笔关于主母的任何信息，则艾雯安全退场、修瞳结论仅在「澡堂社死」一项证据上得出，垫刀结论因证据单一被延迟再议。
- 若林恩在艾雯抢夺装置那一秒主动把装置抛给巫神头颅，则主母影像传入第三人眼前，事件以变形（第三者介入）收束，修瞳会议参与者层级升级。
- 若林恩在盘膝速写时使用速写速度起占卜结果，则勘测仪画面被看作命定象征，修瞳结论反而导向「不应修」、原作垫刀链条被反向激活。
- 若林恩在闹剧结束后主动递交一份「勘误报告」讲解自己为何画主母背影，则四大根源被这份笨拙诚实打动，修瞳协议签下时附带一条「理解心理阴影」备注。
- 若巨像之脑在跨界召唤密议中被林恩偷听到一句，则原始「背着林恩」的二心位置裸露，事件以变形（密议暴露）收束，根源之间首次出现信任裂痕。
