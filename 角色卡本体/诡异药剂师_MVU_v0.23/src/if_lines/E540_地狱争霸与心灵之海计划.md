# E540·地狱争霸与心灵之海计划·if线

- 若林恩让战报节奏从五日压缩到三日，则危机团体来不及结成，地狱恐慌提前爆发但残余盘点更单薄。
- 若林恩漏掉某一处北方蛰伏古老根源不去挑战，则残余名单里多一位未被压服的，登船决议的情绪强度下降。
- 若林恩在第五日黑堡战败后给人偶家多留一道「下次再来」的口信，则她在会议中以「拒绝再败」率先表态交碎片。
- 若林恩把全地狱战报压缩成一日密集投放，则会议被迫在震惊中立刻决议，巨像犹豫与银幻推测都没有展开空间。
- 若林恩允许部分战报通过巫神头颅的嘴转述而非艾雯，则情报里带一层恶意润色，催交碎片的效应更猛但合作意愿更弱。
- 若林恩刻意让某支中型联盟在战败后留下求饶书，则公开层多一条「黑袍人可谈判」的误读，登船决议的孤注感被冲淡。
- 若林恩在战报间主动制造一次「空一日」假装休整，则黑夜城众人误以为得到喘息，船长接下碎片的急迫度下降。
- 若林恩提前把一颗初诞者碎片通过银幻私下塞给巨像单测，则巨像在会上不再犹豫而直接附和「交船长」方案。
- 若林恩让人偶家在黑堡战败当天顺手替她放走数只做实验的玩偶，则人偶家赴会时的攻击姿态软化，但她对林恩真实身份的疑窦加深。
- 若林恩通过原子机械在艾雯会前递一条「孽主也拒学法则」的催办，则艾雯发言里多一笔对「后进根源」的催促，交碎片口径更带压迫。
- 若林恩在会议中通过人偶家之口先提「交给泰坦」的狂战士路径，则巫神与艾雯反驳更激烈，「交船长」方案对比更鲜明。
- 若林恩让巨像在会前亲眼看到一次泰坦幻境作战的力道失控，则她在会上否定泰坦路径的主动性抬升，不再只从众。
- 若林恩邀请船长在会前公开演示一次心灵之海浅潜，则「我们起航」的全票通过提速，但潜意识的危险被具象到小看。
- 若林恩借原子机械把「林恩与紫罗兰大君关系」议题在会前散布，则会议方向一度偏向「找大君请教」，登船决议被分票。
- 若林恩刻意让某一位地狱本土根源在最关键一天主动投降，则「战败连续」叙事断裂，恐慌与团结都打折。
- 若林恩放任人偶家在会前先把泰坦私下叫去黑堡一谈，则战神路径被一对一先否决，会上不再浪费争议。
- 若林恩把战报中某一战败根源刻画为「宁死不屈被当场剿灭」，则会议氛围从「必须行动」转为「必须立刻行动」，全票无异议。
- 若林恩让船长在登船前公开把「死亡神格阶位不碰」的红线重申给所有人，则后续船长半步出关时的边界更清晰。
- 若林恩在起航前安排夜医队在城外秘密列队见证，则「我们起航」被赋予一层仪式感，全地狱战报的情绪转为悲壮。
- 若林恩暗中让小小或母树在船头现一次身，则「抛开小小母树不谈」的口头排除变为可见事实，众人对顶尖战力缺口更直观。
- 若林恩策划让人偶家在会后仍主张独自寻找失踪的根源碎片，则碎片集中线被延后，起航被压缩到一个缺席者。
- 若林恩让巨像在船头那一刻公开说出「我加入」先于任何其他人，则全票决议由她一人定格，后续她在求法中心化的号召力更强。
- 若林恩在起航前通过左左把「回溯能撑多久」的私人警告传给船长，则船长对百年修炼失败模式多一条预案。
- 若林恩在起航场景选择不让船长说出那句「我们起航」而由银幻代言，则仪式感易主，船长「牧魂者」身份的象征动作被减弱。
