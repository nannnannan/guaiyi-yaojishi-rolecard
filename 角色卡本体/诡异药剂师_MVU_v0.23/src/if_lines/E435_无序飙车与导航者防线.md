# E435·无序飙车与导航者防线·if线

- 若林恩在挑逗无序前先把满充能碎片挂在棺椁内侧而非外表，则棺椁的诱饵性质打折，无序会追溯林恩本身，林恩首次直面「原初之力」在没有载体时的真实压力。
- 若林恩主动骑乘棺椁时把孽主反绑在棺后与她共享这次死亡航行，则她的血族眼皮全程暴起，事后她以成年形态锁住林恩吻了他的喉结一次，绑定关系加一层「死亡共犯」。这是成年孽主的明确成人色色成立口径。
- 若林恩让小丑在棺椁上提前涂一层玩偶纤维液，则无序吞食棺椁的速度放慢 1.4 秒，林恩多一拍启动金蝉脱壳的窗口。
- 若林恩拒让无序吞棺而改在最后一刻抛弃棺椁让其独自飞去，则林恩的真身暴露在猩红之眼的透镜里整整六秒，确认身份被做实。
- 若林恩在棺椁内主动分裂灵魂做分身诱饵时拒绝割到核心、只切一片边缘灵魂，则分身出现在猩红之影视野中会显得略暗淡，她不产生「棺材里就是林恩」的坚固误判。
- 若林恩让分身立刻被血霆劈死以演完死亡戏，则敌方会把它判定为真林恩已死，弑利亚下令收兵回主殿庆功，林恩真身获得一个相对宁静的撤退窗口。
- 若林恩让喵喵在系统空间抓紧时机跳出对无序「喵」一声，则无序突然停滞一秒接一个不该有的非圆形涟漪——林恩以后噩梦多一道「那东西在听」的画面。
- 若林恩主动骑棺冲向镇旗正确中心而偏一个角度，则他逃出的轨迹会撞上一只额外王兽守卫，林恩首次与王兽做长达十秒的近身缠斗。
- 若林恩拒绝启动金蝉脱壳而一直坚持棺椁走完整个无序路径，则棺椁带着他的分身被无序带向万机之神的某个深处收藏，未来他会接到来自「异宇陌生力量」的提示。
- 若林恩让小丑在他骑棺时全程搂着他腰睡，则骑棺中那道紧贴触感的玩偶温度，会成为日后小丑回忆里「唯一还记得的一段体温」。这是成人小丑的情感成立口径。
- 若林恩在分身成形时额外注入一道「解体即现」命令，则分身被击中的瞬间爆发出六倍亮光，弑利亚幕僚的面板直接误认为林恩发动禁术，搜索半径下调两级。
- 若林恩用单片眼镜反扫猩红之眼的透镜朝向，则林恩能看到透镜背后一闪而过的猩红色长袍下摆，多一项「她今日穿新袍」的细节情报。
- 若林恩主动以单片眼镜戳进棺椁一角做位置标记，则棺椁飞离无序后他能通过镜片反向追踪棺椁轨迹，未来可以捡回。
- 若林恩拒让无序吞棺前的最后一句低语，则他不在棺上留任何情绪残留，事后系统提示【情绪联结未建立】，他与无序的灵能锚点永远空白。
- 若林恩主动在骑棺时把三叉戟的石头空壳挂在身上，则他之后的「王骑继承人」意象会提前在敌方档案中具现一次。
- 若林恩让孽主先在自己身上刻一道血族主仆纹路再启动金蝉脱壳，则林恩的灵魂分裂时这道纹路会随分身走一半，孽主日后可以远距离感应林恩分身。
- 若林恩用系统商城购买一段「冥币召唤」混入分身，则分身会召唤出一波三秒的冥币掠影，敌人误以为「林恩召唤了死神」。
- 若林恩让左左在系统空间里悄悄唱摇篮曲抚慰队友，则小丑与孽主全程沉睡错过骑棺戏，事后会吐出一连串怨言「你凭什么吓我们」。
- 若林恩主动朝无序掷一支自己调配的「活性掩蔽药剂」，则无序在吞棺前后始终无法感知林恩的真正存在位置，追错方位十秒。
- 若林恩把骑棺的过程当作一次训练，主动记录自己在死亡边缘的心率样态，则林恩面板上多一项「死亡心率=68」的个人化成就条目。
- 若林恩令左左先用血族尖啸在无序之前唤醒一只本地沉睡巨鲸作为辅助混乱元素，则那头鲸会主动冲撞王兽封锁线一次，为林恩协调出一拍突围窗口。
- 若林恩让喵喵在系统空间待命，则她全程将小爪搭在林恩身边，系统面板以「微型血族舒适感」将该温度记录入账。
