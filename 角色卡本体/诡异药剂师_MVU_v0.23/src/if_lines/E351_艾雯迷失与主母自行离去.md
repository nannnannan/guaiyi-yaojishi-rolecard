# E351·艾雯迷失与主母自行离去·if线

- 若林恩在推开地下大厅的门之前先敲三声，则巨像之脑会撑着墙壁先说出「进来吧，他没事」；这一句话让左左第一次听到她仍愿意为林恩多作解释。
- 若林恩看到她裹着血迹斑斑的绷带靠坐角落时不立即靠近，则她会抬手指指自己太阳穴间的裂缝让他看清她此刻的样子，绷带随呼吸剥离的节奏在他瞳孔中被放大成她意志的证据。
- 若林恩施用黄沙压制诅咒之前先在角落放一盆洁净水，则水中倒影映出她几乎碎成千百块的脸庞重新贴合的过程，她闭眼时泪水顺着鼻梁滴进水面。
- 若林恩提出带她去外层大厅接种空气，则她拒绝时伴着一阵温和的波动，巨像之心在林恩口袋里微微一震向他汇报她的信任层级。
- 若林恩在左左被拒之门外后主动接过左左的手腕让她坐在他身边等，则巨像之脑会留下一缕权限把左左的旁听资格写入巨像网络的临时决议。
- 若林恩在艾雯石墙刻画期间不发一言静静站在他身后，则艾雯的刻刀在一次停顿时会回头看林恩的背影，这是他失控以来第一次辨认外来者的容貌。
- 若林恩用黄沙沿艾雯伤口触碰而不是只观察，则那些裂开的缝隙不会一条一条收拢，而是在他指尖下化作一条条极细的净光，巫神头颅会在旁记录这是巨像病理史上少见的平稳贴合。
- 若林恩直接试图读取艾雯的人格备份芯片，则灵能芯片在他掌心的温度会骤降到接近零度，芯片内容的坍缩面直观呈上一份赛博文明濒临消散的实况报稿。
- 若林恩提议把损坏的人格备份芯片交由巨像之脑保管而不再是林恩独览，则巨像之脑会以「巨像最高的权限持有者」的姿态收下，这是她首次承认自己不再能承受，但愿意为林恩分守一份。
- 若林恩提出成立专门修护小组由几位学者去重新看待艾雯遗留的修行资料，则这几位学者会在黑夜城的学术殿堂中开设长期课题，接受当代赛博研究投稿。
- 若林恩主动提到死缚与主动离城的矛盾，则在场的指挥官中首次有人改变立场承认白夜的判断值得严肃对待，整份方案的态度从逻辑推理转向了实际救援的路线分歧。
- 若林恩在散会后单独留下继续追问那根黑色翎羽指向的线索，则白夜会毫不犹豫交出他压住的画面：堕天使暗面在主母身后展开、成群的疫医跪地邀请她加入的一幕。
- 若林恩主动压低声音承认「我也在等这个答案」，则白夜会不再用「情报官」的语气回他，而是以疲惫的同路人口吻低声说他这几日夜里梦见主母的脸贴在死缚墙上。
- 若林恩问白夜「主母是自己选择的吗」，则白夜会沉默很久，最后才把手中黑色翎羽递到他掌心，低声说「我希望不是」。
- 若林恩在艾雯石墙刻画接近完成时轻轻按住他的手腕，则那块石头上的古老画面会在关键的空白处凝住，艾雯首次有了与人对视的静止。
- 若林恩把巨像之脑临时留下的权限，转交给巫神头颅代为行使一部分，则巫神头颅会得到一笔临时多层通道口令，它枯着嗓子说这是它「几百年没领过的新活」。
- 若林恩在治愈巨像之脑的最后一道裂缝贯接之前提议自己暂代她的视野，则她会透过林恩的眼睛扫视整片大厅，当场在林恩视野里为他标识出诅咒源头还藏着的两缕残脉。
- 若林恩主动把母树沉睡的情况摆在议事桌上，放在主母失踪话题之后，则在场的几位学者首次将两条失联线路分别入档，「沉睡」与「离去」在系统笔记里被分开为两栏承担不同的权重。
- 若林恩主动安排蜂巢数据容器作为艾雯休养容器，则左左会第一次从抵抗状态转为接受提案，她会向巨像之脑提出一个公开调查请求，把神魂重建的优先级写入巨像网络周表。
- 若林恩对巨像之脑说「你把自己当作容器太久」，则她会在沉默中微微垂下眼睛，身上的胸甲发出一声因为节制而未曾释放过的响动。
- 若林恩主动按照艾雯留在墙上创出的不完整线稿去翻他旧日给少年留下的传承教法，则在记忆某段域里他能找到少年面容的一抹侧影，那面容与墙上描绘几乎一致。
- 若林恩把羽毛笔失踪的消息用在场者能听见的最小声音缓缓说出，则大厅北门当值的两名夜医悄悄交换了一个眼神，那是林恩首次意识到羽毛笔的去向已在疫医圈私底传开。
- 若林恩对左左说「她现在的状态，不只是伤」，则左左会重重闭上眼侧脸，把那个不为人知的推测藏回心里，指节因为用力而泛白。
- 若林恩在主母座上瞥见灰尘的层数不一时举起手把其中一抹拍在指腹，则他首次知道主母至少是在某个还活着的时刻主动坐回这张位置，「自行离去」这一结论在那一刻变得无可回避。
