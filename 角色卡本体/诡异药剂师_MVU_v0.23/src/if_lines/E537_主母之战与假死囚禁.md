# E537·主母之战与假死囚禁·if线

- 若黑袍现身点名主母时不要「十秒钟逃命」，直接对上现身之初便开战，则其傲慢姿态简化，极限挑战压强更高，但「他不是林恩」的爆点会延后。
- 若圣安娜战前以神降加护自身同时呼求主母以十二翼圣光叠加，则二人的团队战将以试图击退黑袍为多对照，后续光明法则抹除的震击波会更剧烈。
- 若林恩在系统空间囚禁圣安娜时不只封口也强制蒙住她的双眼，则她会没有看见他摘面巾，她后续在圣堂中不会被「他是谁」这层事实引导刷新。
- 若左左在林恩入系统空间救急时不只催打还主动扔下一块她自己血刃供林恩用于在主母面前演「既装死又被杀」，他会做更狠的真实黑袍身亡装象，主母会有更深信念。
- 若林恩在时间洪流修行不只几百年而是上千年，则回归时他身上岁月积淀的「神王风味」更重，主母的「你不是林恩」判定会在更厚重的对峙中失利，杀伤更强。
- 若林恩回归重返战场时不带满面蒙面黑纱布、而是直接戴下全脸铁面具，则碎布一场戏式人物整体偏离，主母「林恩你别装了」会指向铁面人的另一肉体及轮回经验。
- 若林恩在「热身结束」后不主动喊下一句「我的小天使」改口叫她的真正史诗称号「大天使长」，则场面会被拉成更尊严级的真神冲突，战争的叙事会升格。
- 若主母以命第一轮时她的金发转黑不只伴随发色转变、还扛起地狱之眼和十二翼堕落化身，则她的成为最重要一位老师的可能性上升，蓝焰不是金发而是堕落金发。
- 若林恩在光暗一刀重创主母后没撤退而是主动递上一滴初诞者之泪帮她稳住一口气，则主母昏迷时不会伤势太重，但事后圣堂发现时会多一层「他留手」的线索。
- 若林恩在假死囚禁圣安娜后不把她立刻拉进系统空间囚禁，而是先放进自己指缝空间的一颗储物珠保管，则封存层级更高，圣安娜的体验会在珠内感知到空间规则的标尺。
- 若黑袍在斩向主母的第一刀不指向心口、而是直接敲碎主母的剑刃，则她的重伤原因将从伤口变成武器折断带来的物理创伤，教训意味会比「打击」更深刻。
- 若林恩在圣堂开药并保留伤者身份让她醒后向她发疯，则他对自己伤者的险情承担层级更高，主母的诊治过程会由他亲手编修。
- 若主母在事后醒来时不只声道沙哑还隐约哼唱三千年前的圣歌片段，则她的回归会被拉回创立神国时期的音乐时代记忆，圣堂静谧呵护会降低。
- 若林恩在战场结束时不只刀合，还留下一枚自己指缝捏出的黄沙作为给主母的记号，则主母几日圣堂清醒后会主动检视这枚黄沙是否是某爱过的人的信物。
- 若左左在时间洪流期间主动催打时还建议他先去吃东西、喝一瓶茶，则她挂件属性的精神落款会更柔和，她后续放弃三仓库零食的承诺会更可信地交付。
- 若林恩在光暗一刀之前主动向主母「小天使」呼告时反问「你要准备好吗」，则他的威严不在傲慢层的斩杀上，反在更高的教育事前宣告上。
- 若主母在重创后数日落回圣堂时主动点名邀圣安娜出来照顾她，则圣安娜的系统空间链条囚禁与圣堂坐诊关系会成为并列线索，圣安娜的处境会更复杂。
- 若林恩回归后重逢光明一刀不只打伤主母，还在同一时间打碎她的黎明剑，则主母自始至终站立的根基被减少一刀，她的虚耗层级更高。
