# E658·重归起点与背水一战·if线

- 若林恩不迎战而直接突围，则漫天腐化神灵与魇会从所有方向围堵，他能撕开一条血路，但代价是身上多添几道深可见骨的伤，奇异世界内的震荡会更烈。
- 若林恩不点燃罪火而只用星寂开路，则他能保住尽可能多的血肉，但完全无法撕开身前的神灵海，敌方会立刻把他压回重围中心。
- 若林恩一上来就朝魇王掷三叉戟，则他能立刻撕开战局，但他会失去近身的唯一武器，剩下的战斗只能靠双手支撑。
- 若林恩向因果神王投矛的同时调转方向突围，则他能避开正面迎接金色涟漪，但魇王会立刻用黑雾大蛇填上那道缺口。
- 若林恩在杀戮中途提前敞开金色梦境领域，则他能让整个战局的时间停滞一拍，但因果神王会立刻识破他的底牌并找方法斩断他的梦境。
- 若林恩仅用一档罪火而不升级二档，则他能立刻清空周身百公里的敌人，但他无法贯穿魇王的黑雾大蛇，敌方会因他的喘息重新围拢。
- 若林恩早早动用燃烧本源的绝命一刀，则他能在措手不及中撕开一道虚空裂缝，但他会失去关键的压箱底牌，他自身的生命力会因此大减。
- 若林恩全程不掷出三叉戟而把它扛在肩头当作近身武器，则他能保住最锋利的兵器，但每挥一次都要面对敌方倾尽全力的反扑，他的双臂会先一步发麻。
- 若林恩在战斗中突然撤去三叉戟的金色雷霆、只用本体肉身死战，则他能减少奇异世界内所有人的冲击感，但他会立刻陷入敌众我寡的下风。
- 若林恩在合围时持续在星寂与罪火之间切换，则他能用多样的打击把敌方的压迫节奏拉断，但他比单一攻势消耗更多的精神力。
- 若林恩以白烬严密护住头颅与识海、不让任何一道金色因果涟漪近身，则他能正面撞碎身前大半的封锁波纹，在漫天围杀中硬生生趟出一条血路。
- 若林恩在自身退路被因果铁律斩断的刹那没有停下脚步，而是凭着百折不挠的凶悍意志强行向前踏出一步，则因果神王也不得不分出更多本源之力来压制他的反扑。
- 若林恩在最后关头故意以左臂硬接因果罗网的切割，借着血肉横飞的剧痛换取右手三叉戟毫无阻碍地劈开前方黑雾，则这一记以伤换命的狠招会让围攻的众神齐齐胆寒。
