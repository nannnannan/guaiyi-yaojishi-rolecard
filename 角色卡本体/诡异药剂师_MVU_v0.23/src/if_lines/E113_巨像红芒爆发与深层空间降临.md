# E113·巨像红芒爆发与深层空间降临·if线

- 若林恩在塔身爆裂一瞬强行展开血肉斗篷罩住黑弦月与小小，则红芒冲击下他与两名队友被卷入同一坐标，深层空间里四人从一开始就没被冲散。
- 若林恩在红芒逼近时抬手硬扛上界位格不闭眼，则他的咒瞳被那种位格灼烧出三道血痕，进入深层空间后前方三百米雾海在他眼里会残留短暂的破雾清晰视野。
- 若林恩没收住巨像之心的悸动任由那句"我的王后"在意识里回荡数秒，则巨像之脑对他的呼唤定位精度上调，深层空间血雾中的心象造物会主动绕开他三丈。
- 若林恩压制住那句呼唤强行封堵心跳共鸣，则巨像之脑把他误判为普通闯入者，深层空间对他的"主宰特权"暂时收回，心象造物会主动向林恩索敌攻击。
- 若林恩在血雾中循着左萝的脚印气息第一时间冲刺追过去，则他会赶在蜘蛛触手扑向左萝之前先行用触手把她整个人卷进怀里，左萝连"凑脑袋吓唬我"的误会都没来得及犯。
- 若林恩故意放缓脚步让左萝先在血雾里多迷路一会儿，则她会哭腔越喊越大，再走一段就撞上第二只更庞大的心象造物，林恩赶到时为双线救场。
- 若林恩从一开始就出声唤她"左左别动"，则左萝会把那声音错认成心象造物的又一次捉弄，反而抱紧胸口朝反方向狂奔，林恩的追迹路线被她自己拽长。
- 若左萝掰断触手时林恩立刻撤货收声装死，则这只蜘蛛把"凑脑袋玩弄手"的剧本演到底，左萝会把蜘蛛当成林恩的伪装一路骑在它头上数落，林恩被迫跟着这只被骑的蜘蛛在雾里绕圈。
- 若林恩直接以触手洞穿蜘蛛头部而非虫体蠕入，则怪物爆裂的粘液溅射量大幅下降，左萝依旧是浑身干净的小萝莉，换装环节缩水成只系一条毛巾。
- 若林恩在蜘蛛爆裂时让左左自己从它体内回归手臂，则心象蜘蛛瞬间溃散化作一滩肉泥，深层空间不再出现分离的"左萝"形态，事件变形为"林恩与合体的左左探索空间"。
- 若林恩接住溅满粘液的左萝第一时间是吻她头顶而非调侃，则左萝满腔愤怒瞬间泄气变成红着脸的呆滞，主仆关系在从此时起向"被对方允许依赖"的那一类偏。
- 若林恩先把左萝放在地上再去对付第二只心象造物，则她一个人站在血雾里会被第二波扑袭的阴影吓到腿软，林恩战毕回头时见她缩成一团抱住膝盖。
- 若林恩掏出毛巾之后随手把整套黑丝吊带替换成白丝蕾丝长裙，则左萝在深层空间的主装形象首次变更，E114 之后她对这套白丝的依赖度记为初始偏宠。
- 若林恩只把毛巾塞给她让她自己擦自己穿，则左萝一边咕哝一边任务式完成清洁，主仆间"被照顾 vs 自己动手"的差别会被她记进深层空间之后的摊牌对峙里。
- 若林恩换装完成后没有立刻讲空间法则而是先伸手揉她的黑发，则左萝的瑟缩会慢慢解开，深层空间探索节奏从"双人警戒"切到"小萝莉主动牵住林恩衣角"。
- 若林恩直接宣布"这里越怕什么越遇到什么"法则的全部细节，则左萝后续遇到心象造物时会主动背对它们，但"心脑一体主宰特权"的她那一半被她暂时搁置不用。
- 若林恩故意把法则讲一半留一半，则左萝会本能把未讲的那层靠自己试错补完，她在 E114 前可能自行弄出一次小规模的"心象反噬"惊吓，林恩要替她兜底一次。
- 若林恩决定带左萝朝着巨像潜意识最深处而不是尾随脚印的反方向走，则他会更快遇到深层空间的核心，但同时错过蜘蛛救场事件，左萝实体化坐标偏移，最终林恩面对的是更单刀直入的巨像之脑对话。
- 若林恩在不救左萝的前提下单独在血雾里行走，则深层空间会判定他"伙伴缺位"，每隔一段距离就生成一只具象化的心象左萝试图与他同行，林恩要么揭穿要么接纳这只虚像。
- 若林恩在深层空间里多次尝试用系统扫描"巨像之脑"坐标，则每次扫描都会让红雾浓一分，最终雾海加深到他自己也要靠巨像之心的共鸣导航，空间对他的主宰特权反而被反向稀释。
- 若林恩主动牵起左萝的手而不是只让她跟着走，则心脑一体的共鸣在接触面上首次建立通路，E114 万机投影围猎发生时林恩与左萝的反应动作会比剧本同步快半拍。
- 若林恩救出左萝后选择立刻朝着呼唤声源头方向推进，则 E114 万机投影与小宝贝围猎的遭遇时点整体前移，银色幻想那段插曲会被压缩或跳过，事件链节奏被林恩主动调紧。
