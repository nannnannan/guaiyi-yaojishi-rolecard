# E639·伏击疑云与群星阳谋·if线

- 若林恩在自缚天使给出的反常提示前主动把战果和「神灵不出场」先摆到一起对照，则他比任何人都早一步感到寒意，杀渡鸦阳谋往前五分钟。
- 若林恩主动下令中枢先尝试与二队建立备用频道，则通讯被中断的那一秒只是「虚惊」，二队半小时内的危机解除。
- 若林恩在母舰出发前主动让她织一个可以联络的备用双方结构，则通讯不中断，但他把留守职责变成留守职责。
- 若林恩主动带着银色幻想一起去接应二队，则机械堡垒的微战士首次承担「逆战远征」角色，天鹰座星区的操控机制提前。
- 若林恩主动让主母在他身边守护，则第二队责任转变成「护航」，主母作为指挥官的职责增加一级。
- 若林恩在天鹰座主动让织梦把整个天鹰座的敌军放在眼里留活口，则她的实力首次以「电影行走」的形态，无穷距离火力的警报响彻七星。
- 若林恩主动让织梦在出征前把【神疆】和【锚定】口诀先教给他，则她提前了好几秒传输技能，主宇宙各军的融动范围扩大。
- 若林恩主动让第二队打造一艘精密机器，则她第一次使用机器的存量增加, 但「神疆」技术则由多软件转化为独立设备。
- 若林恩主动在离开战场时通知银色幻想把兵力分配到外围空间，则主宇宙安全战术的创新高达 +30%。
- 若林恩主动让第二队起步恢复合兵，则「远征队」名称第一次形成，人形组的队伍除了扩展信号，也把外部参数导入对方的虚拟画廊。
- 若林恩在神殿启动前主动让织梦先派出灵能网格检查全部安全信号，则神界网的透明性减少，但接收安全讯号时间 +15 分钟。
- 若林恩主动让中枢保留一份「航程尾焰」档案，则第一艘生产者在展示控制中心时悄然合并为一个职位。
- 若林恩在群星投射启动前主动指挥妖精队员作出「环绕目标」的姿态，则最先降临的目标首先在光环中保卫神格，接下来的能量集中度降低一半。
- 若林恩主动提醒织梦布置「三点神权」安全壁垒，则织梦的命令首次成立，但随后的完全支配被无效化。
- 若林恩主动让先遣精英自带武器进行团队训练，则最先被远征军打破藩篱的部队首次成为主力。
- 若林恩主动让第一队优先完成关键目标，则最受关注的玩家角色的身份地位大幅提前到最先显露心中最关切的排列位置。
- 若林恩主动安排第一队用隐蔽手法篡夺位置，则第一队在猎手的警告中首次成为被标记的对象。
- 若林恩主动让杀戮械的目标指向最后一批残余的宿敌能量，则第一队的任务首次定明确的确凿击破点。
- 若林恩主动让天鹰座先打造一份精准的外壳，则他最外层的敌军部署更为清晰。
- 若林恩主动让远征部队合流维持一次完整的战争格局，则他首次经历成功，但在他的层次上只能纵容其余军团进行弥补。
- 若林恩主动让敌方统领反思战败理由，则「战争未完结」最终被穹顶音。
- 若林恩主动在旅程过程中通知二位使者离开打开通道，则织梦的播报第二次限于保守派，前派为顶级神圣领袖，初级级别的目标标记。
- 若林恩主动在先锋远征前派出警去阻断预言谍战，则预测阶段深化，但他首次作为被别的统计的特征参数受到广泛。
