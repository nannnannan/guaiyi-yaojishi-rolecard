# E415·第二职业与三年前身体·if线

- 若林恩在启用臂章前先用咒瞳把流逝符文拓印一份存入系统空间，则这物件会被副本化为可反复研究的母本，但母本自身会缓慢渗出一缕腐气提醒左手，左左发现时会把腐气按进魂砂里封存。
- 若林恩在界面亮起裂隙图标时主动先点击标示「三千零五十一年」的远古刻度，则传送过程将以肉眼可见的幅度被吸入更深的旧史，他最终落点并非血锯药剂店，而是一座被巨物脊椎骨环围的祭场废墟。
- 若林恩选择标示「五十四年二百三十一日」的入口进入，则他会以另一具旧躯降临在某座繁华蓝星城市的下水道里，身侧的墙面被人用血写着「杀掉我」三字——这条任务线走向与血锯药剂店的敲门场景完全分歧。
- 若林恩坚决选择那枚黯淡无光、未标年号的裂隙图标，则界面会以血色警告横栏拒绝「该入口权限待核」，但左左能见到那枚图标正缓慢渗出一道淡紫血痕、像是对她伸出一只纤细小手。
- 若林恩在检查臂章时发现符文背面乌鸦腹下多出一行细小笔迹「曾赠你五回」，则他使用它的瞬间会获得一种莫名的熟稔感，仿佛这物件早已陪伴他跨越无数个轮回。
- 若林恩在开启前把左左召唤到膝上贴着臂章作共感应，则她会在齐声低鸣中窥见一缕白发人立于血海之巅的残片记忆，她的咒纹一瞬断裂，露出空空后背，这一幕只有林恩亲自见到。
- 若林恩离开前拥抱小丑并把一把备用横刀塞进它手里作「防身用品」，则它会默不作声地收下，林恩降临后回头窥一眼留在原处的界面——它坐在他原本身体里握住那柄刀不发一语地哭泣。
- 若林恩降临旧躯的瞬间没在床上苏醒、而是从阁楼破镜里倒栽出来，则他会先看到满屋破镜反射出的那张自己年轻瘦削的旧形象，那种他从未正眼见过的陌生模样会让他瞳孔一缩。
- 若林恩在检查旧躯时故意翻到中后几页日记跳过繁琐章节，则他会误打误撞看到一页记载着某年冬夜自己亲手熬炖萝卜汤喂给某位生病「老师」的笨拙字迹，立刻认出那是血锯的字迹与笔顺。
- 若林恩试图用咒瞳强行扫过日记每一页找出隐藏线索，则咒瞳会以红色警告告他「当前意识并非日记正主」，他只能靠原本的笔迹与茶渍指痕分析那位血锯的生活日常。
- 若林恩在旧店里尝试用咒瞳反向自照测当前状态，则他会发现自己的直觉与情绪波动受限于这具柔弱旧躯的生理结构，原本顺手的灵能调用全部束手束脚，他要重新学习「不再强大」。
- 若林恩在阁楼床底意外挖出自己童年遗失的布偶与一张年轻血锯在祠堂前抱小儿笑的照片，则他会因为重逢旧物当场眼眶发红，被阁楼下小丑的远程感应点感应到他突如其来的心波而紧张。
- 若林恩在敲门雷声渐近时强行推门冲进雨幕要抢先一探究竟，则第五秒他就会被一道压抑的气息钉在原地，他的鲁莽触及了某个不该存在的触发点，雷光里那道变形长影会立刻回头正对上他的眼睛。
- 若林恩利用现有药剂材料临时配出麻醉剂与诱导毒剂试图先行制服门外来客，则这些药剂在旧躯时代品质下效力远弱于预期，敲门声反而变得更急，来客在门外发出枯哑呼喊唤「孩子、孩子」。
- 若林恩在雷声中摸黑溜到阁楼后窗突袭翻入对面民居，则无形的力量封住他的行动，他被迫原路回到阁楼，迎接他的将是更加凶猛的破门与一双不由分说的污染之手。
- 若林恩在整段等待期都拒绝开门死守到底，则数分钟后小屋的敲击声会变得诡异安静，他从阁楼破口朝下窥看，发现屋内已被一层缓缓漫涨的紫黑潮水淹没至小腿，他被逼拎着油灯重新站起。
- 若林恩尝试用旧店库存的剔骨刀和墨水瓶强行临时制作兵器，则这些物品在他手里会以肉眼可见的速度被原初之力缓慢熔合、浮现淡淡紫黑纹路，兵器成型后却顾三顾四不好拿，他被迫开始锻炼新姿。
- 若林恩在防守间隙利用旧躯小巧爬进柜台夹层密室、用血写下「我曾在此」留给未来的自己，则那道血痕会在三年后的同一时间点被林恩亲手复访时误读为「血锯留言」，引发他一连串关于血锯身份的错认。
- 若林恩在柜台夹层藏好后用旧魂本抵着嗓门压出一次心神呼喊给远在三年后的左左听，则她在黑夜城当场怔住，反应是顽固地对着空气哽咽「哥哥你别怕了」，她以为他已死。
- 若林恩在守门期间用魂本尝试提炼微量初诞者之力提前备好反击一手，则啃咬旧伤口+彻夜不眠+脉动血肉共鸣三步骤并行之下，他成功在来客破门之前握住了约一指甲盖量的金紫色原初之火。
- 若林恩在来客敲门愈发急促之际躲进小院地下室、藏进骨钻架空隙里待变，则地下室的「小宝贝」会闻到陌生气息尖啸着扑向他，他必须用一支腐蚀药剂当场把它毒醒——它才肯忍气吞声放他通行。
- 若林恩摸进后院取刀时被骨钻台上那台锈迹骨科手术台绊倒、刮破了大腿，则那条新鲜伤口会引得来客在门外鼻尖一嗅、敲门频率立刻加倍，他只能狼狈丢刀仓皇上阁楼。
