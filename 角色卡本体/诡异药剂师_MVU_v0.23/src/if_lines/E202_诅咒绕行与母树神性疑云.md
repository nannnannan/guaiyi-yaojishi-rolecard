# E202·诅咒绕行与母树神性疑云·if线

- 若林恩把「最迟明天晚上召唤我」改成两版交替重吼一遍,则白逸频道先收到一次镇静后留存一次残片,他在药劲退潮里最先记住的是「明天」这个关键词,事件以不变形收束但召唤窗口异常紧张。
- 若林恩吼完通牒后顺嘴补一句「你听不清就点头三次,让梦魇帮我执行」,则梦魇将「点头」当成医嘱,白逸在镇静里机械地点了三下头后沉睡,事件以不变形收束但白逸醒来时留有模糊潜意识。
- 若林恩对燃烧的羊皮纸现场再踩一脚跨阵碎步,法阵火焰意外卷起一道二次光幕,则羽毛笔在002室镜面里听到的不是告别而是通牒,她的笔尖在纸上快速勾下「蓝星」「林恩」两个字。
- 若林恩裹着小呀哒一起送往主母殿堂前先在她额头点一道缄默咒,则地下殿堂内的诊断对话全程未被小家伙偷听,左左拆台火力降低,事件以不变形收束但诊断氛围变肃穆。
- 若林恩主母殿堂开口第一句就选「我宿主不再纯洁了」,则自缚天使先皱了三秒眉才回话,诊断节奏被拉慢一拍,事件以不变形收束但主母问「你确定不是你单纯变态」的语气更冷。
- 若林恩游魂巷缴获的寄生兽一部分不递给药剂学研究、压在背包底层,则主母殿堂里的复核多绕一道感染排查,事件以不变形收束但白逸蓝星侧的药剂师对接不上抗虫手段。
- 若林恩在主母按上眉心之前激活巨像之心护罩罩住全身,则神圣光晕渗透速度减缓,检查耗时加长一倍,主母金色鲜血渗出更多,事件以不变形收束但锁链收紧到切入伤口。
- 若林恩在主母激发神性燃烧时主动收敛巨像之心波动,则肉体差点被净化湮灭,巨像之心启动代偿狂跳,事件以变形(检查中断)收束,主母抢先诊断出母树神性却已在自己身上留下一层伤。
- 若林恩诊断中离题提起自己在欲望母树躯体内的那一夜细节,则主母听不进去半截,审判严肃度直线上升,事件以不变形收束但额外多加一条「欲望交流不彻底」的标注。
- 若左左咳嗽节奏错开一秒才补那一句「你现在已经是了」,则主母「长期影响会把你变成涩狗」一句话完整说完,事件以不变形收束但左左之后被林恩追加踩到地板两次。
- 若林恩对主母灵魂拷问「你确定属于诅咒,不是你单纯地变态」直接选择沉默三秒,则殿堂内空气静默到主母主动缓和语气请林恩继续陈述,事件以不变形收束但圣光检测强度被拉满。
- 若林恩在殿堂中主动汇报欲望以M在游魂巷后已不能用「曾经爽」来形容,则自缚天使诊断路径改从心理段切入,事件以不变形收束但「适应它战胜它」的劝诫被换成「先熬过今晚」。
- 若林恩离开殿堂后直接把这次诊断结果转达给艾雯爵士和巨像之脑,则事件以变形(绕开三方案咨询)收束,主母殿堂三极端疗法只口头研讨并未被拿到桌面。
- 若林恩让主母先实施一道小尺度的欲望神性侦测附加诊断,则母树神性的异常样本被完整记录,事件以不变形收束但蓝星召唤前林恩额外获得一份「神性绕行机制」的讲解手抄。
