# E412·古老的堕落之心·if线

- 若林恩在甬道外先用克苏鲁之眼远远扫一眼那颗搏动心脏再入场，则他能在咒瞳视野里看到心脏表层血肉的纹路下隐约藏着一个跪地祈祷的小人形，事后他向艾雯描述这画面都不敢提「是活的」二字。
- 若林恩让喵喵在甬道口充当「顺风耳」，则她会听到心脏的搏动声中夹带一缕熟悉的笛音——那是紫罗兰大君的召唤信号——她当场软在林恩怀里咬他袖口讨饶「别让我去」。
- 若林恩让艾雯爵士先行在半途加上三重灵能屏障作为「防倒灌」，则艾雯爵士灵能会凝聚成一面水镜，镜中会浮现心脏主动想对他诉说的第一句无声告白——事后艾雯在夜里反复揣摩那一秒的画面。
- 若林恩在见到心脏后主动以「亚当证词」口令先报一句「兄弟你好」，则心脏会第一次主动停顿一秒搏动，低音提琴的音色下意识颤抖——它辨认出那个称呼属于「父亲时代的语言」，从此刻起它对林恩的轻蔑直线下降。
- 若林恩选择单刀直入先拔出那块碎片、不给心脏诱导的时间，则整个甬道的血肉会在碎片被拔出的瞬间塌缩挤压向中央，心脏本身被挤压出一道浓浆状触手四散甩向甬道各处，林恩与艾雯当场淋一身。
- 若林恩在心脏提到「屠夫」二字时主动出示几帧影像、且其中包含小丑夜半独自哭泣的私密一幕，则心脏看到那一帧时会陷入长达十秒的怔忡，事后它对林恩的态度以肉眼可见的幅度降温——它首次知道小丑不是自己一个人的奴隶。
- 若林恩出示黑堡影像时让小丑站在自己身旁看完、不躲闪，则小丑的血管会无规则颤动、伴随数根爆裂喷血，但它的手会不自觉伸出来握住林恩的手腕，事后它坦白「这是我第一次知道你是谁」。
- 若林恩对小丑道「你选择大君还是选择我」并附上脱下左袖的手，则小丑会低头沉默，没立刻答，但它的指尖会攀上他的袖口缠了几乎十秒，这个无声的接触被林恩记在手机备忘录里：「它有救」。
- 若林恩对小丑说「好好舔我」并真的勾过它的脸贴近自己胸口，则小丑以熟练的咒骂句反击但耳轮却悄红，它的指尖在他胸口皮肤划下一道浅浅的痕，事后自己却擦干净那道痕陪他演戏一整晚。
- 若林恩对心脏说「我会好好调教你」链上手铐，则心脏的搏动会在前一秒停顿随后爆发出一阵强笑，它的整颗心脏露出一个由血管拟化的猥琐笑脸——它觉得此刻这场景十分滑稽。
- 若林恩对心脏反问「你为什么想救大君」，则心脏会收缩成一颗更小的实体，再展开时搏动里渗出一段不带声音的远古影像——那是大君拉住年幼小丑的手的画面，小丑看到此段影像当场双膝砸地。
- 若林恩对心脏出示一直留存的渡鸦残魂，则心脏的扭曲表情会瞬间缓和，它的搏动声会以肉眼可辨的幅度低回落到温和档位，它第一次完整称呼林恩「令主」——心脏承认渡鸦继承人身份。
- 若林恩用小丑来威胁心脏「你不合作我便对你杀无可割的小丑」，则心脏会无所谓地耸一条血管表示「它早被调教无惧」，但林恩会从小丑攥紧的手心察觉它的紧张——心脏这句话是假的。
- 若林恩暂时把心脏放在透明魂砂容器里「关小黑屋反省」，则它的血管会在容器内壁持续写满古字、几小时后连成一篇深长的忏悔信，事后人偶家阅读这篇信哭得花了妆。
- 若林恩决定暂时不取出碎片，而是用原初之力持续磨灭碎片上的纹路使其失效，则碎片在临时失效约三天里心脏的失控范围会扩大到整个黑夜城，左左被诱导入魔、被林恩亲手按进怀里养性疗伤三日。
- 若林恩在交涉后伸手抚摸心脏表层最粗的那根血管，则心脏的反应是回颤和收缩，但半秒后它主动扩张一寸让他把手掌按平——它意识到他并非要伤害它。
- 若林恩主动让左左以咒纹共鸣模式贴近心脏听一段完整搏动，则她会流下泪水，因为心脏的基底音色里她听到了一段熟悉的咒纹印记——那是渡鸦残留的一部分自由意识。
- 若林恩决定暂不带走心脏，而是把它锁进临时架设的初诞者水晶笼里挂在黑堡试炼室天花板，则其每日搏动会以一目了然的强度影响在场所有夜医队员的运功效率，泰坦见过这种反应后咧嘴笑。
- 若林恩在离开前用纸笔在心脏外层画一个小丑的马戏图腾并贴一张便签「这是你弟弟玩笑的画像」，则心脏见到画像时会陷入数十秒的沉默，事后它主动把那张画用一根油皮血管圈在自己搏动表皮上当作「爱的花环」留存。
- 若林恩故意把心脏放在泰坦手臂上让它紧贴骨躯，则在数秒内泰坦会感觉到自己臂上 E408 留下的那道霉斑在小幅回缩、由深紫转成浅灰——心脏在主动反哺它的原初力量。
- 若林恩召唤人偶家到场并通过她的手轻触心脏皮层，则人偶家当场沉醉，她在心跳声里听到一场完整的深渊交响曲，事后她写下一首长诗献给这颗「堕落之心」，挂在黑堡主殿墙上留存。
- 若林恩在小丑探索空间时释放一缕以M香气，则小丑的指尖会不自觉地在心脏皮层上戳出一圈圈指痕，它的呼吸会加快，关于大君的忠诚会被一层暧昧的迷离掩盖——事后它为此对林恩施以一礼表示「我愿被你再次调教」。
