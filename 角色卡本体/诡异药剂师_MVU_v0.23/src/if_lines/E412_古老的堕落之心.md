# E412·古老的堕落之心·if线

- 若林恩在进入解剖甬道前先用克苏鲁之眼远远扫描那颗搏动心脏，则他能在咒瞳视野里看清表面蛛网血管下贯穿的原初碎片走向，提前标出无序外泄的安全距离。
- 若林恩让艾雯爵士在半途先行布下三重灵能屏障再靠近，则屏障裂纹蔓延的速度被大幅延缓，随行夜医免受诅咒躁动波及。
- 若林恩在心脏低音提琴般的搏动声响起时不急于搭话、只静立观察其纹路，则哭泣小丑会主动打破沉默先试探来者身份，暴露其急于脱困的焦虑。
- 若林恩当场出示黑堡记录并点出「屠夫」与古老怪物的勾连，则心脏表面血管剧烈狂跳甚至爆裂喷血，哭泣小丑从矢口否认转为恸哭辩解「那是无法反抗的命令」。
- 若林恩只口头质问屠夫之事而不出示黑堡影像证据，则哭泣小丑会将一切指控推诿为污蔑伪造，始终咬死自己只是奉命行事的受害者。
- 若林恩在哭泣小丑恸哭时冷声逼问其对紫罗兰大君的立场，则它会毫不掩饰地承认为了大君复生随时可以牺牲林恩，狂信底色不因求饶而改变。
- 若林恩以高压姿态威胁要严厉折磨这颗心脏，则哭泣小丑会极其熟练地切换为卑微顺从或咬牙咒骂的腔调，用表面服软换取喘息空间。
- 若林恩顺着合作话题追问狱卒情报的价值，则哭泣小丑会摆出识时务者的姿态抛出一两条边境秘辛作诱饵，试图引诱林恩拔出贯穿心脏的碎片。
- 若林恩在哭泣小丑请求拔出原初碎片时当场拒绝并反向注入一缕初诞者之力，则碎片上的天然纹路骤然大亮，无序波动被死死压回心室深处。
- 若林恩冒险尝试松动那枚贯穿心脏的原初碎片一分，则甬道内的空间感瞬间如被无形巨手揉捏，艾雯爵士不得不立刻加固灵能屏障喝止冒险。
- 若林恩在交涉中提及城外母树枝干繁盛却意识未醒的异状，则哭泣小丑会带着嘲讽般的悲悯指责林恩让母树吸收了过多诅咒、已从自然之灵沦为堕落之躯。
- 若林恩下令用特制容器将整颗堕落之心连同原初碎片一并封存带走，则哭泣小丑会在容器内收起咆哮转而一路冷眼旁观，寻找下一个套话与反扑的空隙。
- 若林恩在离开甬道前向艾雯爵士确认血肉支配者权柄的去向，则艾雯爵士会指明尸躯内唯有这颗受碎片约束的堕落之心、真正的血肉权柄早已被人从躯壳中剥离。
- 若林恩命令夜医部队彻底封锁解剖甬道并严禁任何人私自接触残留黑血，则外围墙内的诅咒污染被控制在最小范围，未再引发二次伤亡。
