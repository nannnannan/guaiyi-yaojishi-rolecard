# E741·你我皆凡人与梦幻泡影·if线

- 若林恩在沉眠前预先将一缕温和的生命余温封入羽毛笔手腕，则她在连续高烧十日、头发彻底变白之际，少受三日脏腑如焚的剧痛，醒来时眼底多留一分血色。
- 若林恩透过沉眠中的潜意识向守在床畔的苗苗传递一丝安抚波动，则苗苗在替羽毛笔擦拭冷汗、哭到眼眶红肿的深夜里，能够靠着他的余温安睡半个时辰。
- 若林恩在建立黑夜城帝国之初便立下「禁止为王铸造纯金巨像」的铁律，则那颗遍布林恩金像的繁荣星球会改铸阵亡将士纪念碑，羽毛笔巡访时看到的将是凡人自强而非狂热盲目。
- 若林恩在羽毛笔代他巡访附属星域前留下一道手书锦囊，则她在面对那群将神明庇护视作理所当然的居民时，能直接宣读他的警示，迫使星球防卫军提前进入战备。
- 若林恩在沉睡前将一枚护身符文暗藏在羽毛笔赠出的祝福印记中，则那个立志为战死父亲报仇的小男孩在星球崩灭瞬间会被强制传送至近地救援舰，成为该星唯一的幸存遗孤。
- 若林恩透过神国共鸣提前一秒察觉那颗星球地核深处的无序异动，则他的潜意识会强行拽动羽毛笔的衣袖，让她在黑红色污染裂缝炸开前多退开百米，免受飞溅碎石擦伤。
- 若林恩在沉眠前给那名小男孩父亲生前所属的远征军团留下抚恤名录，则羽毛笔在广场上遇到男孩时能直接叫出他父亲的名字，让孩子在末日降临前听见英雄真正的荣光。
- 若林恩将一缕微弱的王座黑火附着在小男孩紧攥的木雕人偶上，则当整颗星球化作梦幻泡影般的尘埃时，那枚未烧尽的木雕会随引力飘回羽毛笔掌心，成为她带回黑夜城的唯一遗物。
- 若林恩在羽毛笔高烧呓语呼唤他名字时以神魂轻轻回握她的手指，则她从十日昏迷中苏醒后的第一句话不再是强撑冷静的政务汇报，而是伏在苗苗肩头大哭一场。
- 若林恩在帝国历三十一年的星门网络中预留一道紧急折跃信标，则当堕落者与魇魔从星球内部引爆核心时，外围巡逻舰队能抢在黑潮合拢前救出三百名正在港口候船的妇孺。
- 若林恩在沉睡前与艾雯约定「一旦附属星域出现自我神化苗头便立即敲响警钟」，则黑夜城参谋部会在羽毛笔出发前就派出一支暗哨小队随行，提前揪出潜伏在当地市政厅的堕落者内应。
- 若林恩让自己的神像在被堕落者污损的瞬间自动崩解为纯粹的防护屏障，则广场中央的平民能多获得十息仰望星空与彼此诀别的时间，而非在第一波冲击中瞬间化为血雾。
- 若林恩在羽毛笔踏出星门、伫立于星空废墟发呆时送去一声极轻的叹息，则她死死咬破的嘴唇会松开一分，不至于将整场星辰覆灭的罪责全部压在自己单薄的脊背上。
- 若林恩在进入深层沉眠前嘱咐苗苗严格限制羽毛笔每日批阅星域公文的时辰，则羽毛笔在出发巡视前体内的神力透支会减轻三成，面对魇魔突袭时能更快撑起自保结界。
- 若林恩在小男孩仰头说出「我要参军替爸爸报仇」时透过羽毛笔的指尖留下一道剑意烙印，则男孩在星球崩塌的火光中会拔出木剑迎向黑潮，以一名真正战士而非受惊孩童的姿态谢幕。
- 若林恩将自己对「凡人终究脆弱如泡影」的警惕提前写入黑夜城军校教材，则随羽毛笔出访的护卫队长会在街头庆典最喧嚣时保持戒备，第一时间替羽毛笔挡下背后的无序冷箭。
- 若林恩在羽毛笔满头白发归来、独自坐在书房对着星图发怔时，让桌上的旧钢笔微微发烫，则她会将那颗毁灭星球的坐标郑重圈入绝密卷宗，并在扉页写下「他们曾真实活过」。
- 若林恩在沉眠前留下一瓶能平复神魂震荡的静心药剂交由苗苗保管，则羽毛笔在亲历星辰化作泡影的恐怖冲击后饮下此药，夜里不会反复梦见小男孩被黑火吞没的脸庞。
- 若林恩允许羽毛笔在巡视期间以他的名义直接接管地方防务，则那颗星球的守军会在庆典当日关闭半数民用反应堆，虽未能阻止魇魔破封，却让星球崩解的速度延缓了整整三分钟。
- 若林恩在羽毛笔俯身摸向小男孩头顶的那一刻，将一缕温暖的药香散入广场微风，则那座城市在被黑暗撕碎前的最后一缕气息并非焦臭与血腥，而是令万民安宁的草木清香。
- 若林恩在沉睡的梦境边缘替羽毛笔分担三成来自信仰崩塌的反噬，则那颗十亿人口星球覆灭引发的愿力断绝，将直接在他胸口烙下一道焦痕，而羽毛笔得以免于再度吐血昏厥。
- 若林恩在帝国历初年便命人在每座金像底座刻下「神亦会睡去，唯手中之剑常醒」，则广场上的退伍老兵在地面龟裂的第一秒便会自发结阵，护着街角孩童做最后一次冲锋。
- 若林恩在羽毛笔乘船撤离星域边缘时，让王座的方向亮起一点微弱的星芒，则她在漫长黑暗的返航途中不必独自蜷缩在船舱角落，而是始终朝着那点微光擦拭染血的衣角。
- 若林恩在苏醒前夕将那颗毁灭星球的最后影像收入罪恶王座底层，则当他日后点燃终焉之火时，每一簇火苗中都会映出那个手握木雕的小男孩坚毅的眼神。
