# E538·光暗融合与根源横扫·if线

- 若林恩邀群殴时不只刀刃遥指还主动把整条战场的空间压缩至只能跑百步之地，则全体坠落者被迫肉眼可见地集中，横扫观感会更聚众、更有压迫感。
- 若战争之王努斯首冲时不只是攻击还念一段他母星反神权宣言首句，则林恩对面不仅是上身对抗，还是主宇宙抗争的精神对峙，战争法则的教学会更深。
- 若林恩在战争法则口授时不让努斯看到血海杀戮、而是看到主宇宙各族群文明的和谐对望，则战场上的「战争」含义会被代入反战讯息，林恩的路会挤向和平神。
- 若天空之神在林恩抓其脖颈重击地面时不立刻昏迷，而是尖啸咬牙发声再追击，则他的顽固被凸显，速不达顶的反应搏击将拉开更长段。
- 若林恩在超过天空之神时不使用空间规则、而是单纯以身体力量凌驾此「急速者」的气态体验，则他的战力将突破「类创造规则」的边界、而其他坠落者会更难读懂他的方法。
- 若林恩以立定石巨人横扫元素时先与石祖视觉相同视角，则他会让石祖亲眼感受到被他立于肩上并被撕碎元素的倒数，升级成伙伴视角的对视。
- 若核子之神转化周围物质为能时林恩不逆转、而是借助能量流灌注自己体质让自身短暂狂增，则他的力量将验证「使用对手力量」的老乡逻辑，并会被定名为「吸收法则」。
- 若林恩在教训核子时不只点眉一道，而是直接用他全身作为能量容器导入到外星沧海，则核子的「星核」将无法维持，创法则教导的代价更高。
- 若星轨在元素融汇时不只召唤元素召唤、还主动安慰元素本身（像安抚小动物），则她的道路会更偏向「联盟契约型元素之神」，后续「不再狂暴」的莹莹灯火将更加自然。
- 若星轨的五彩烛光被林恩的「不错」轰昏倒地时不完全的归息，她倒地后手指仍握着一小丝完全不可控的电光，则被击败状态的她仍带残余优势，会让看到的人回头惦记。
- 若林恩在元素融通时不仅用了「不错」，还主动跪下让自己亲手将她的指尖举起元素灯熄火，则他对她的尊敬将规律为「师父跪迎徒弟的成就」，战场全局情绪会转向。
- 若林恩在每一赢后不主动给领域解释，让坠落者自己去总结各自被击败原因，则整份横扫不教导，正确是「检验」型，坠徒等级 +「后背皆惧」。
- 若林恩当众接下「林恩」三这个字时他不是愤怒而是深深叹气，则众坠落者将读出「他可能不是为了一个错误名讳动怒」，对真实身份的猜测便会从「是林恩」转为「曾是林恩」。
- 若左左在主母喊「林恩你别装了」瞬间不发出「惊呆惹」声音而是蹲下悄悄捂脸，则她对主母文化的感通会更柔和，她后续会不会跟林恩吵一顿将被模糊。
- 若林恩的死亡圆满通牒多端「让你们退却，不是杀死你们」，则他的尊严定位成「还是过渡型」，这波动会再回挟恐吓正在打得如骨头响的坠落者。
- 若主母起身冲「林恩你别装了」时不只释出「雪耻」，还主动裂开左膝倒入泥泞里求全，则她的身体极限化推向死角，全员内心议论「主母也要折服他」的必定是此刻的门槛。
- 若林恩在主母面前不摘兜帽、也不「众多已经问过这个问题了」默应，则他的黑袍身份保护要点仍存，他会用「她不是这种我」一整段话来划清鸿沟。
- 若左左现场现身后主动用左手与主母持平支持，左手「（乛◡乛）」形态会陡然缓解全场压强，她将被记作「林恩在不会辱他名」的被动背书。
- 若林恩让最后令死亡圆满的行为是从他背后斩下一道空间裂隙悬于主母头顶而非直接出刀，则死亡通牒的方式会有刚才交流中的修、有余地的定。
- 若林恩的「从来不止一只渡鸦」不只是在主母面前出口，而是面向整个战场宣告，则他的误导会同步广播到所有坠落者，主母闻言时的干劲会加重，她将对 '全新渡鸦' 波形紧张。
