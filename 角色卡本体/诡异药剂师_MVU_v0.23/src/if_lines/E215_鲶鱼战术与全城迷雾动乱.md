# E215·鲶鱼战术与全城迷雾动乱·if线

- 若林恩攀塔前用触手把外立面广告屏翻面换成「今夜大雾出行请缓」七字，则半城通勤族手机同框收到提示，官方应急播报未发先慢半拍，广播电视塔招牌首次被写入驱魔界警示档案「未授权市政发布」。
- 若林恩在鸟嘴面具回路上加插一枚咒缠神经钢钉，则迷雾切断的除了民用信号还包括特种通讯加密频道，弥赛亚扑来无法传讯求援只能徒步突入，她的撞击轨迹首次被夜巡的隐修会散兵亲见。
- 若林恩让左左拟化为铺天盖地乌鸦群替代血肉触手显形，则数十万市民相册里拍到的是「乌鸦撞白雾」的怪诞天象，而非「触手恶魔」，次日新闻焦点被导向「超自然生物种群普查」话题。
- 若林恩事先让血娃娃预先投影三具仿制的直升机机群混在迷雾外缘配合触手伪装，则军区误判他劫持装备，封城指令紧迫度再升一档，军方档案首次列出「未确认装备污染源」专项。
- 若林恩在塔尖演说之前先把两瓶麻痹剂高抛给对面狙击位，则两支隐藏步枪被他创可贴包着的麻药瓶当场麻痹，驱魔人档案首次记录「敌方具备远程精准投送麻醉能力」。
- 若林恩事先把稀释的麻痹粉封装成小纸鹤沿迷雾边缘空投给居民区门卫，则当晚疫苗自接种人数超出预期四成，他意外被列为「未知民事助手」，事后班底首次发放手册出现「非授权药剂包」字样。
- 若林恩在面具释雾瞬间把自身咒压反向注入天顶云层，则夜空首次被他用血雾绘出一只巨型鸦嘴剪影，地方电视台黄金档播出「本市天象异闻」实录。
- 若林恩先抛出十万张预先打印的「本周城市燃气泄漏请远离高处」字条混入空投物，则弥赛亚跃上塔尖时不得不先扫开三百张乱飞纸片,驱魔档案首次记录「敌方善用廉价印刷术干扰战场」。
- 若林恩让左左提前把十四个虫灾感染热点坐标刻进他计划坠落路径两侧地面，则他坠落后触手沿途沿着标记打靶式清扫,弥赛亚首次亲见他红黄两色雾气分线的差别用法。
- 若林恩事先教血娃娃在塔尖最后十秒自称「敌方侦察官」砸开军区电台，则军区误判他是双面间谍,事后报告把他列为「未确认潜伏作战人员」。
- 若林恩在塔尖背诵台词时顺手把两袋医疗解毒包和一句「给隔壁楼层还醒着的」抛给楼下执勤警察，则当日新闻里他被标注「散物恶魔」,军方档案首次把「敌方医疗意图」单独立档。
- 若林恩拒绝在塔尖公开演说、改为全程哑语式催雾,则电视台只能拍摄崩毁的塔尖与迷雾扩散画面，弥赛亚冲到塔顶面对的是一具空戏台，剧本档案首次出现「静默演出」这一新标签。
- 若林恩让左左先在他坠落路线终点布置一处临时接应血池，则他从塔尖坠落时被一团活体血肉缓冲包吞没,弥赛亚目送他下坠却扑了空,她被逼入白雾中心首次亲睹转移过程。
- 若林恩决定全城迷雾只笼罩一小时就主动退散,则城市舆论由他放出风口而非持久战,媒体次日头条从「恶魔围城」改写为「恶魔退走」，舆论张力转向「他想要的是哪一种对话」。
- 若林恩在广播塔顶先把话筒接到城市公共广播系统并预告「我会让每一条电话线都响一次」,则全城固定电话同时响铃但无人接听,军方档案首次记录「敌方可操作民用通讯信道」。
- 若林恩建议在白色迷雾中混入无害荧光粉、让市民夜间能看清触手轮廓,则数百万市民目击清晰尸体级的活体巨物剪影,远程画面首次被驱魔界认定为「主动解剖示范」。
- 若林恩在释放血肉触手之前先朝高空释放一枚自己体内分离的副脑假发信号,则那枚副脑被空军雷达误识别为独立飞行器,事后报告中「敌方生物分裂雏形具独立机体特征」首次成档。
- 若林恩压面具音量却让全城手机同时传出鲶鱼威胁台词,则六百万手机主人听到他绿珠气泡声响,驱魔档案首次记录「敌方可侵入同频电子设备」。
- 若林恩主动把巨手显形成明显避让开医院与学校轨迹的图案,则驱魔界档案首次记录「恶魔保留人道红线」,教会高层档案里添一条「非讨伐名单候选」。
- 若林恩借着迷雾把数百具医疗解毒气胶弹空投到各家医院急诊门口,则次日医院在混乱中意外得到数百份救命解毒方子,他的「恶魔」名声首次和「救星」并列出现。
- 若林恩让触手把广播塔顶留作废墟雕塑,塔尖还盘着未消散的残余血肉,则封城后复原工程队首次遭遇「建筑级生物质建筑」的拆装难题。
- 若林恩让左左在他坠落瞬间把身影拟化成弥赛亚模样,则楼下驱魔人阵营目击「圣女亲自击落恶魔」的视觉误报,事件以变形（替身演出误报）收束,舆论撕裂焦点转到「圣女与恶魔合作」论。
- 若林恩在坠落前顺手把一封写着「请把医院病人事先撤离东南管区」的血信塞进最近的军方指挥官停在外围的指挥车车窗,则封城军令在执行时多了「提前移转就医名单」的隐藏条文。
- 若林恩完全不碰鸟嘴面具、只用纯肉体畸变爬上塔尖就广播,则驱魔档案首次记录「敌方不依赖法器也可独立完成大规模散影」,他被改列为「非外械驱动的可怖样本」。
- 若林恩让巨手显形时做出三快两慢的拍点,则军方声波仪器侦测到与感染虫群繁殖脉动同步,事件以不变形收束但他被改列为「与虫群同心跳活体指南器」。
