# E643·全军撤离与深渊陷落·if线

- 若林恩在中年人揭示「目标是林恩本人」时主动追问「为何不直接对黑夜城下手」，则中年人首次用一句「你死了他们才会散」把军团命运绑死在他身上。
- 若林恩主动在中年人展示突围梦境时伸出灵能试探一次，则他的意志和中年人的梦境之间留下一道微弱的引路手感，E644 的突围方向多一枚入点线索。
- 若林恩在中年人化灰前主动用手隔空挽留一秒，则灰烬在他掌心化作一缕长河照烧，林恩首次直接触到一段梦境残留。
- 若林恩主动把「画家分身被三王镇杀」的监测警报先递给织梦，则织梦立刻提亮她的灵能之眼，「他们的下一步」被她提前十五分钟预测。
- 若林恩主动下令在最大规模空间召唤中优先召回七大位面的监理人，则深渊撤离时的整体伤亡会大幅减少，只是那些被迫放弃驻地的监理人心中不免多一分悲怆。
- 若林恩在被银色幻想扑出光幕那瞬间主动回抱她一秒，则她的「不要再把力量浪费在这些地方」的台词首次多了一拍肢体接续。
- 若林恩主动在撤退令下达前对军团说一句「对不起很多深渊生灵留下了」，则深渊原住民的求援声第一次被林恩以家主身份当面承认。
- 若林恩主动把折跃次序改为「军团 → 黑夜城 → 纱奈儿」，则军团先于黑夜城入戟的画面被中枢档案记下，他在指挥官与保护者之间的优先级首次被定义。
- 若林恩主动为最后一位入戟的家人亲手点亮一枚灵能火炬，则自缚天使的身影在通道之前被记录，她对「家主」的身份首次公开。
- 若林恩主动让自己立于奇异世界入口最后一秒才踏入，则他被映照成一座独自守门的守门人，黑曜石双眼与三叉戟中路边界被深刻记录。
- 若林恩在金色少年展现「真理」神格威压的刹那，毫不示弱地全面解放自身三位一体的璀璨金光，则两股截然不同的至高力量会在深渊裂隙间正面碰撞出震耳欲聋的法则轰鸣。
- 若林恩在直面金色少年冰冷俯视的瞬间，非但没有后退，反而握紧三叉戟指向对方眉心立下必杀之誓，则全军将士撤入奇异世界前的最后一瞥看到的便是主帅不可撼动的背影。
- 若林恩主动把织梦的「他们来了」心声立刻共享给中枢，则奇异世界的家中人第一次实时听到追兵路径，银色幻想的反击小组提前 30 秒就位。
- 若林恩主动在撤向迷雾之海途中把三叉戟竖在胸前，则他以「守门人」的姿态让「真理」神格的试探性奴役刚好打在戟尖上，林恩的「戟意志」首次直面神格。
- 若林恩主动在追兵折跃锁定前主动开设一条「战斗替身」残影，则金色少年的第一次抓握落空一次，林恩争取到三秒的入海外面。
