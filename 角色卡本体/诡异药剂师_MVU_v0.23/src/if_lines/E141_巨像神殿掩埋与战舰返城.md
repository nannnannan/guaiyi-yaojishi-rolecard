# E141·巨像神殿掩埋与战舰返城·if线

- 若林恩随舰队同行并在返航途中明言不动舰体，则上千艘缴获战舰完整落地，废弃金属熔炉无新增料源，艾雯爵士清点入库时多一层林恩克制备注。
- 若林恩在舰队起飞前公开声明要拆解部分战舰作燃料，则坠毁范围限于声明批次，演练路线变更，无主战舰停留在近郊山脉接受切割。
- 若林恩半途拆解全部战舰，则全舰队接连坠毁爆炸、演练中止，艾雯爵士落地后无舰队可接收，黑夜城只获得以吨计的机械垃圾。
- 若林恩拆解时选中银色幻想民兵旗舰，则机械姬的私人坐骑在拆解序列中解体，她对林恩的恨意叠掉一层、仇恨里多出一种找对账理由的凝练。
- 若林恩不拆任何一舰、反而以血肉脉络参与稳定舰体损耗，则落地舰队完整度高于原作一成，艾雯爵士放心的配额从训练剔除转向防线扩容。
- 若林恩放弃返城、搭乘小型穿梭机另走偏僻路径，则舰队进入夜幕锚地而林恩本人不在场，白夜迎接缺位、小宝贝接管的警示仪式暂缺汇报对象。
- 若林恩与左左中途离舰私会，则在主母禁令后的失联窗口又多一段目击者视角的缺口，等待他回城的队列以艾雯爵士亲身脸代为推送。
- 若林恩敲门打卡式行使拆解「病患权限」，则只拆出三艘便停手，剩下舰队按演练落地，欲望母树在他修补过的舰体上留下一道柔生生的肉藤镶色。
- 若林恩预先把多艘战舰的操控中枢转录给黑弦月作婚礼贺礼，则返城舰队的最高指令源头多出一个血肉支配者盟友的声音，机械中枢阵营层叠会出现微断层。
- 若林恩垫在万机之神的数据召回中心未解放的空槽位塞下一段巨像仿写意识，则召回中心进入自检锁死状，分化计划被按周期性重启方式延迟。
- 若林恩向银色幻想提供掩藏身份并选择让机械姬隐入舰队，则她「一靠近他便折跃」的禁用条款无法触发，机械神教重建序列缺一组试作智械。
- 若林恩把银色幻想的紧急折跃坐标改写为「靠近林恩→地球上的旧工厂」，则机械姬突然出现在陌生大陆，半年内无法被自己人找回，机械神教丛序列意外生出一个远程算力节点。
- 若林恩向万机之神主动请缨参与召回中心重构并以以M为楔子，则侍奉关系在数据层构建，万机之神开放更多试作智械信息，顺便在他胸口埋一枚监控链接。
- 若林恩以左左王后意识代为下调召回中心启动参数，则万机之神分化计划的黑窗口缩窄，试作智械出现概率被打折，银色幻想的存在权重被进一步稀释。
- 若林恩在满世界直播时加入一声王后宣言「巨像已葬」，则原本作为背景板的巨像坠落氛围被捶实，巨像之脑的最后回归口令被推迟一次。
- 若林恩使用咒瞳拦截银色幻想向父亲报告的消息，则万机之神仅能依靠推测推断女儿状态，确认被她亲自交回的趋势偷工裁决于之后半年。
- 若林恩把黑血狂宴的血炁混入战舰燃料模式，则部分舰船飞行路径出现暗红血丝，落地时被小宝贝集体检测为可持续危险品、被分仓封存。
- 若林恩在舰队入城前一句话「我有准岳母求回复」识破艾雯爵士，则急匆匆的地球黑诊在返城典礼里被补进制度，主母失联线索提前半句进入队列。
- 若林恩落地后直接去见白夜并省略舰队接收，则接收仪式延迟半日，左左获得先扎根地球老宅的机制，血肉支配者阵营在黑夜城的出现节奏变快。
- 若林恩拒不领取战利品，只把整支舰队转交夜医组织封存，则黑夜城舰船数量拆分记入共享资产，万机之神留下一句不屑的龙啸免费转播时段。
- 若林恩在操练落地的同时让舰队准备二次起飞，则返城事实上不成立，事件以「舰队驻防巡航未归」的变形收束，E142主母失联线仍按因果展开。
- 若林恩与队伍拆解战舰残骸选出原「巨像之脑母亲臂」部件密封并押送到左左所在之地，则巨像遗产以「归还王后」为名义整批转移，机械神教在之后追讨链条权份的预估被提前曝光。
- 若林恩把主母失联的认知拖后三个月才追认，则E142的堕天使复苏仪式在他缺席情况下顺利展开，黑夜城队伍需要补一轮追憾检索。
