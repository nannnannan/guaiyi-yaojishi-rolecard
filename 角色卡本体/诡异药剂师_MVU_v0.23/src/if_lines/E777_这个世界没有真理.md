# E777·这个世界没有真理·if线

- 若林恩在「这个世界没有真理」成为执念之前先接受「真理是动态的过程」,则他能用更宽容的视角看待过去的失败,但这份宽容也可能使他放弃某些必要的坚持。
- 若林恩让左左在真理之父出现时同步用左手紧紧握住他的手,则他能获得情感支持,但这也让他对她的依赖感比意识到的更强烈。
- 若林恩把「真理」这个概念彻底从他的人生价值观中移除,则他能摆脱这个沉重的追求,但缺失方向感也会让他在行动中失去指引。
- 若林恩在追求真理的过程中选择只关注实践而忽略理论,则他能避免陷入抽象哲学困境,但实际问题的复杂程度可能让他陷入更深的混乱。
- 若林恩让黑火在他产生「我理解了」这个想法时反向警示这可能是幻觉,则他能保持警觉,但这也会让他对自己的每一次认识产生持续的怀疑。
- 若林恩在真理消亡的定时点上选择接受而不是反抗,则他能避免与更高存在的直接冲突,但这也意味着他会放弃改变某些可能改变的事。
- 若林恩把「真理之死」作为一次必要的悲剧而不是一个需要扭转的错误,则他能以更平和的心态面对未来,但这种接受也可能使他忽视了其他的可能性。
- 若林恩让左左在经历了真理信仰崩塌后主动为他寻找其他信仰或目标,则她能帮助他重建价值观,但这个过程也可能让他意识到「没有绝对的真理」。
- 若林恩把「他是大君」与「他是渡鸦」这两个身份融合为一个完整的自我,则他能实现自我认同的统一,但这个融合过程也可能带来身份危机的全新挑战。
- 若林恩在真理争端中选择站在无知的一方而不是追求绝对真相,则他能避免被卷入复杂的哲学争论,但这种无知也可能使他在关键时刻做出错误判断。
- 若林恩让黑火在表现「真理」这个概念时出现过度激烈的反应或失控,则他能表现出这个概念的荒谬,但失控的黑火也可能引发连锁反应让他付出更大代价。
- 若林恩在接受无真理的状态下主动寻找其他形式的价值或意义来填补心灵空虚,则他能找到新的方向,但这也会让原有无真理带来的痛苦变得不那么重要。
- 若林恩在真理信仰彻底崩溃后选择一种看似绝望的方式来应对,则他能传递出「这一切都是徒劳」的信息,但这种态度也可能让他在未来的挑战中缺乏动力。
- 若林恩在真理的废墟上选择寻找象征性的替代而不是彻底重建,则他能从混乱中找到某种秩序,但这种象征性也可能让他脱离现实。
- 若林恩让左左在他感到彻底虚无时主动分享她的感受,则他能被引导出低谷,但这也会让左左成为他在虚无中唯一的依靠。
- 若林恩在理解无真理的本质后选择让它成为他行为的指南,则他能更有效地调整他的行为,但这种以真理虚无作为原则也可能让他的行为变得随机和不可预测。
- 若林恩让左左在他决定是否要反抗时主动提供支持而不是直接反对,则他能感到被理解,但她支持的程度也会直接影响到他最终的决定。
- 若林恩在对真理这个概念彻底绝望后选择直接转身离开,则他能暂时摆脱这种痛苦,但离开也可能使他失去从痛苦中学习和成长的机会。
- 若林恩在真理信仰崩塌后的混乱中选择让自己成为「真理之父」的代言人,则他能保持一定影响力,但这种身份也可能让他在面对他人质疑时变得脆弱。
- 若林恩在真理消亡之际选择用他记忆中的痛苦来惩罚那个「真理之父」,则他能通过复仇来缓解部分痛苦,但惩罚也可能让他与之前的自己产生身份认同冲突。
- 若林恩在灵魂彻底被撕裂后选择与那个「真理之父」进行一场不平等的谈判,则他能通过协商来争取某种形式的和平,但谈判结果也可能让他感到被出卖。
- 若林恩在真理信仰瓦解后选择用一种看似消极方式来应对,则他能传递出「一切都没有意义」的信息,但选择这种方式也可能带来无法挽回的后果。
- 若林恩在真理消失的那刻选择通过黑火来重新定义这个概念,则他能重新赋予它新的意义,但这种重新定义也可能带来前所未有的困惑和混乱。
- 若林恩在失去所有希望后选择与那个「真理之父」分享他的痛苦,则他能被理解并获得一定程度的接纳,但分享痛苦也可能让他在未来的关系中变得更加脆弱。
- 若林恩在真理信仰彻底崩溃后选择将其视为一次必要的考验,则他能以更坚强的姿态面对未来的挑战,但这种看似坚强的外壳也可能隐藏着他真实的脆弱。
- 若林恩在理解无真理的本质后选择让它成为他行为的唯一准则,则他能拥有某种形式的自由,但这种以虚无作为原则也可能让他在需要决策的时刻感到无所适从。
- 若林恩在真理信仰颠覆后选择通过建立一个新的信仰来填补心灵空虚,则他能重新找到方向,但新的信仰也可能在不远的将来被颠覆。
- 若林恩把渡鸦的「流泪」属性记录为「渡鸦可以流泪」而不是「那只渡鸦发生异常」,则他能修正种族认知,但修正会让他在后续面对每一次渡鸦目光时多一丝无法描述的失重。
