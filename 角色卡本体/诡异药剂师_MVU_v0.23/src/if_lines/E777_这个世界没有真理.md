# E777·这个世界没有真理·if线

- 若林恩在记忆中目睹昔日七王幸存者重组为「四王议会」、以铁血手腕重建紫罗兰帝国镇压全宇宙叛乱时暗自叹息，则他看清了帝国从建立之初便已背离了紫罗兰大君的本意。
- 若林恩在看到十余代更迭后那名追求文明自由的凡人革命者打破无神铁律、点燃神火成为新世界第一位神明「真理之神」时心头微震，则他为这份凡人逆天改命的勇气生出一丝敬意。
- 若林恩随着远古渡鸦的视角体验了追杀真理之神整整一个纪元的漫长拉锯，并亲历远古渡鸦在屡次挫败中首次诞生名为「愤怒」的情绪，则他见证了一具冰冷分魂觉醒人性的第一缕火苗。
- 若林恩在世界尽头的绝壁上看着远古渡鸦率领群鸦将真理之神团团围困、冷酷下达「你若不死便重置整个世界」的最后通牒时屏住呼吸，则那场宿命对决的压抑感扑面而来。
- 若林恩在听见真理之神仰望苍穹深处那道根本无法逾越的画家阴影，惨然一笑说出「当我成为真理之神的那一刻我才知道，这个世界没有真理」时，那句泣血的叹息深深刺痛了他的心神。
- 若林恩在目睹真理之神留下一本描绘“凛冬将至前举火渡鸦”的童话歌谣集后当众拔剑自裁时沉默良久，则他认出那本童话书正是后世流传于地狱与人间的希望火种。
- 若林恩在感受到远古渡鸦望着真理之神的尸骸与遗书、平生第一次流下名为「悲伤」的眼泪时，他与数万年前的这个自己在灵魂深处产生了强烈的悲悯共鸣。
- 若林恩在随后的大清洗记忆里看到远古渡鸦面对同胞挥向无辜母女的屠刀、终于违抗铁律张开双翼护住母女时，他眼睁睁看着远古渡鸦满头黑发在悲愤中寸寸化作雪白！
- 若林恩在目睹满头白发的远古渡鸦亲手撕裂身上的渡鸦黑袍、孤身踏入神域紫罗兰帝国王庭时心潮澎湃，则他看到了自己无论在哪个时代都绝不向不公低头的傲骨。
- 若林恩在听见远古渡鸦直面高居王座的未来画家、痛声质问「这就是你想要看到的新世界吗？！」并怒斥帝国早已活成当年他们亲手推翻的旧神模样时，王庭内的死寂令他印象深刻。
- 若林恩在看到未来画家面无表情地挥手镇压远古渡鸦、将其打入不见天日的地狱监牢而未取其性命时，他读懂了未来画家对这具承载丈夫反抗精神的分魂那份矛盾的留恋。
- 若林恩将真理之神留下的那首关于“凛冬与举火渡鸦”的童谣逐字记在心底，则他明白正是这位自裁的神明用生命为迷茫的远古渡鸦点亮了反抗的方向。
- 若林恩让左左在看到远古渡鸦护住母女一夜白头的画面时握紧他的左手，则左左低声感慨「不管过去多少年，你这家伙永远都是这副爱多管闲事的脾气」，令林恩心中微暖。
- 若林恩在体验远古渡鸦于神域王庭孤身舌战群鸦与四王议会的记忆时，将那股虽千万人吾往矣的决绝气魄彻底融汇进自身的神王道心。
- 若林恩在观察真理之神自裁前望向苍穹的绝望眼神时，愈发坚定了要在未来打破一切囚笼、还万千生灵一个真正自由宇宙的信念。
- 若林恩在看到被远古渡鸦救下的那对母女在废墟中对着白发渡鸦磕头泣谢的画面时，他清楚正是那一刻的人间温情彻底取代了冰冷的机械法则。
- 若林恩在远古渡鸦被铁链锁入地狱监牢最深处的黑暗记忆里保持平静守望，则他陪着这位过去的自己一同熬过了那段最为孤独漫长的铁窗岁月。
- 若林恩在回味「这个世界没有真理」这句话时，没有陷入虚无主义的绝望，而是将其理解为“旧的枷锁并非真理，真正的道路要由生灵自己去踏出”。
- 若林恩在记忆中看清四王议会与神域王庭的运转全貌后，对紫罗兰帝国统治体系的弊端再无任何幻想。
- 若林恩在感知到地狱监牢外终于传来一阵熟悉的轻盈脚步声——未来画家亲自来到牢门前探望远古渡鸦——时凝神倾听，则两人之间最决绝的那场对话随之浮现。
