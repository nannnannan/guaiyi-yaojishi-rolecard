# E39·暴食血祭与血娃娃回收·if线

- 若林恩先开一枪警告而非直接打穿胸膛，则克勒斯化作黑藤遁走的时间多一拍,【暴食】法阵多一轮蠕动,血娃娃成形位置偏出原爆点,后续召唤走向改为"半成形血娃娃+克勒斯同步逃跑"。
- 若林恩把第一枪留给一对黑袍教徒之一,则克勒斯现场唱诗走完最后一段,法阵完整成阵,血娃娃拥有更清醒的开口瞬间,敌意起点更深,追捕路线仍按高速收束。
- 若林恩全程戴面具不摘,则"特殊警察"的身份公开结算取消,媒体侧记为"无名灵异代理人",血娃娃事后认人的关键一拍只能凭触手与语气对上号,信任转向推迟一拍。
- 若林恩摘面具时先报名号而非那句"不就是我吗",则血娃娃叫出的"林恩先生"先于具体身份落地,她瞳孔锁死的是人的那一面而非药剂店学徒,惊恐度曲线少一格骤升。
- 若林恩没认出召唤进场的恶灵就是当年那个血娃娃,则洋娃娃率先在法阵尘埃里举臂指认,"嘎嘣嘎嘣"的台词直接砸下,林恩靠系统图鉴反向亮起身份标签,改走"被认出先于认出"的等价路径。
- 若林恩任由血娃娃张开噬阴巨口吞尸、不撑开,则连环吞噬持续到第三具尸体,总局广场民众陷入更大范围骚乱,王朝北、白逸赶到时多一道封场工作量。
- 若林恩撑开巨口后没有选择灌腹拷打而改以触手捆住脚踝只吊不抽,则血娃娃从"食物"向"求饶"的转化慢一拍,"明天去拜年"的台词延迟数秒,完成标记仍成立。
- 若林恩灌注后用触手把她当洲际导弹掷向克勒斯方向但未命中,则她撞上对侧楼体滑坠两栋高,尹琴侧的卫星画面多出一段无谓折线,她在拜年台词落地前多一轮剧痛与倒吸冷气。
- 若林恩把她掷出后选择不钩回,则血娃娃自行挣扎逃脱再卷土重来,血祭法阵的裂隙没人栓死,她在法阵残骸边再做一轮召唤前摇,尹琴、王朝北被迫提前介入,救援节奏改写。
- 若林恩用鱼性力量压制血娃娃时顺带取走系在脚踝的铜铃,则她在被吊起时失去一件核心恶灵组件,后续 E40 的共情戏设置改为"她从怀里掏洋娃娃时先摸向铃铛空位"的偏离写照。
- 若林恩拷问时追问"你妈在哪",则血娃娃先冷场、再被洋娃娃用她自己的语调代答"没有呀",共情前置一拍,"找妈妈"话题在 E39 现场提前埋入偏离账本。
- 若林恩完全放弃制服血娃娃、只追克勒斯,则她在法阵后背起洋娃娃踉跄往外溜,总局现场的"血娃娃甄别"与追捕由杨柯线额外补强,E39 按取消结算,E40 触发条件改由别的入口进入。
- 若林恩在总局广场当场处决克勒斯,则"活捉"完成条件未达成,尹琴方的"特殊警察"定性语气从温和滑向凝重,后续涉案的官方通道自带一层"缉拿无果"备注。
- 若林恩高速薄雾封包时抓到不是克勒斯而是错拖一辆民车,则那辆车主被顺带卷入迷雾,车上三口平安结果被破坏,补偿行为记入偏离账本,救援等级被压为部分完成。
- 若林恩高速探查不选触手逐车而改为薄雾中反向上嗅,则克勒斯的【诅咒】交换那一拍被林恩提前听见,他无法从民车里驾车入城,三口之家在自身车上平安下车。
- 若林恩救下母女后不主动表明"我是警察",则"特殊警察"的身份结算取消,她们在噩梦中醒来后只记得一位"戴面具阴冷手温的未知者",白逸档案多一条未解之人。
- 若林恩把抓获的克勒斯直接交给白逸、尹琴处理而不亲自接触,则后续审讯与逼供环节由官方接管,克勒斯未兑现的情报要等到下一事件入口才再次到位。
- 若林恩在母女醒后补一句"他们只是在做恶梦压出来的玩笑",则母女害怕程度少一分、她们与"特殊警察"的接线更顺畅,官方档案里少一条虐待标签。
- 若林恩对母女说完那句"这里也算是我的半个家乡"就离开,则白逸在原地少一道跟踪询问的机会,林恩与总局的"老乡暖人档"迟至 E41 再上一档。
- 若林恩任由血娃娃跟着自己、不在广场道别,则她抱着洋娃娃拖着一身挂布追到总局楼下,E40 的"同一处安稳空间"结算位置从室内改到店门口,事件仍按完成推进。
- 若林恩在血娃娃求饶后只丢下一句"明天来拜年"便公开放走,则她的倒吊场面取消,"求饶"从"当场反转"变成"暗暗应允",善恶矢量向她偏向敌意一侧倾斜一格,后续共情氛围更冷。
- 若林恩把克勒斯的替身化作黑藤仅打中一片,则克勒斯现身后化为黑藤的真实身份在官方记录中首次曝光,机密级别上升一档,王朝北在事件后签署"目标反向标记",后续追捕线拖长。
- 若林恩全程不介入、坐视克勒斯在广场铭刻完整个【暴食】法阵再逃走,则法阵完整成形后原地自燃,广场死伤范围按原作扩容一倍,救援条件不满足,E39 按取消写入偏离账本,后续主线改为"全国总动员应对血肉教派"的分支。
