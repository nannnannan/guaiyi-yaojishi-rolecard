# E368·根源会面与黑堡行程·if线

- 若林恩在主母端出神性自缚装束坐在主位前主动为她披一件白大褂做披肩，则她金眸泛起复杂的柔光，整个大殿的威压反向松了一分。
- 若林恩在泰坦破顶而入砸出大窟窿的瞬间主动用巨像之心血气填上洞口，则主母皱眉的「你给我修」一句被生生压回，泰坦的头颅愣在原地说不出第二句。
- 若林恩在泰坦咧嘴喊出「抢回来」「直接撞过去」时主动按住他的肩膀低声「她是盟友」，则泰坦的头颅凝固半秒随后咆哮声拔了八度，巫神和小小同时扑上来拽住他。
- 若林恩在主母第一次显露出「担忧的暖意」时主动把右手搭到她肩上轻拍一下，则她的自缚装束的黑链随之松了一扣，那张千年冷酷的脸出现一线破绽。
- 若林恩主动选择只带艾雯和巨像之脑两人前往而不带主母，则主母当场起身用十二金羽包住他的手腕说「我也去」，决策被她自己改掉。
- 若林恩主动向艾雯爵士递出一份他专用的灵能稳定剂作为同行证，则艾雯的虚化灵能躯干瞬间矿化半实体一拍，他第一次有机会实地握住一件实物。
- 若林恩在说明「夜医透过灵魂丝线感到幼小身影的回应」时主动把那一缕灵魂丝线的频率用洛书投影在大殿中央，则所有根源的目光会同时锁在投影上，「确实是她」成为无需再争的事实。
- 若林恩在陈述中不点出人偶家的盟友身份而是直接说「我需要把她们打服再带走」，则主母会第一时间喝止并拂袖离开主位，整场会议被推迟到下一次。
- 若林恩在巫神带着小小到场时主动朝小小招招手并塞给她一片果肉，则小小会立刻黏到他腿边不再听巫神指挥，巫神暴怒但被主母一句话镇压。
- 若林恩主动让巨像之脑在会议开始就公开她与林恩之间那次荒野共感的事，则她会耳根通红地把头压到桌面以下说什么都不再抬起来，涩涩度+3，但原定的同盟议题得延后推进。
- 若林恩主动要求把界门的同行名额严格控制在四人以内，则泰坦的头颅会因无法在名单上而咆哮，巫神与小小一致举手要求同行，队伍名单必须当场按林恩心意重排。
- 若林恩主动提议「先派一个分身投射过去试探而非实体前往」，则艾雯会支持但主母坚决反对，因为分身无法在生死轮转的她面前真正交谈，会议需要重开一轮。
- 若林恩在大殿中主动展示灵能芯片与神印并列放置在桌心，则众根源的视线会同时被这两件物品牵引，艾雯主动第一次对林恩说一声「这些日子辛苦你了」。
- 若林恩主动透露他曾经在人偶家住过一阵子并讲到黑弦月的白裙与稻草人旧事，则主母会轻轻抿一口灵能热茶低声「原来你已经走过那么远的一段路」。
- 若林恩主动对人偶家做信息隔离「我不会透露任何你们不愿公开的旧事」，则人偶家的某些成员在他的描述下露出缓和的迹象，但主母对此保持警惕。
- 若林恩主动替主母拉了拉身上那道粗大的黑色锁链让她可以稍松，则她会先一愣然后把整个锁链一甩直接甩到地下，「我现在已经不是需要束缚的状态了」。
- 若林恩主动在会议尾声沉静一句「如果她还没准备好见我，那我可以再等」，则巫神会赞许地拍拍他的肩膀说「你长大了一些」，但主母会立刻反对「不可以，必须现在去」。
- 若林恩主动向根源们提出一段关于黑堡的猜测而非事实，则根源们会各自根据自己的判断来做出回应，主母会提醒「我看得出你是有备而来的」。
