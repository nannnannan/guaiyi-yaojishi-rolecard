# E794·最终的决战·if线

- 若林恩在踏入终焉之城前主动对自己说一句「进去的人不一定能出来，我先接受这个」，则他的脚步在城门那一瞬没有任何犹疑，此后每一步都比默认走向稳一分。
- 若林恩在时间王再次邀请时主动只是听完后说「我已经有要陪的人了」而非激烈回绝，则时间王首次没有继续磨利话语，城门处一线风微微松了些。
- 若林恩在七十一只噩梦沿城墙布列时先朝它们报出自己名字再开战而非直接厮杀，则其中最年长的那一只第一次认出了一个「能被记住的敌人」，此后它的攻击里多了一份惆怅。
- 若林恩在城门深处主动把轮回碎片按序安置而非随手撒下，则它们在他身后排成一队影子，此后他每次回头都能看到整整齐齐的一列送行者。
- 若林恩在黑火与三叉戟的影子交叠瞬间主动先握住自己心脏而非三叉戟，则他的战斗节奏从此分成了「为谁打」与「打谁」两条曲线，所有的决绝都被温度包住。
- 若林恩在城门倒计时归零那一秒主动闭眼一秒再睁开而非盯着时钟，则他见到的是「开城的是他」而非「他必须走过这扇门」，此后所有进入都不再带胁迫。
- 若林恩决定接受时间王一句邀请中的共情成分而非立场，则他从此能偶尔在终焉的回廊里听到时间王说一句「这次算你赢」，那一句成了他偶尔还能笑的来源。
- 若林恩在紫罗兰旧日的旧痕迹前主动停留一秒放下一份药剂作为致意而非直接冲过，则那条旧径第一次被人正经记起，他此后再走过同一片旧迹都会被它轻轻托一下。
- 若林恩在左左外部桥接紧绷中选择让自己的梦境向她展开而非祈祷她撑住，则她第一次能从他的视角里看到决战的另一端，她的桥上多了一条「他也在等我」的回声。
- 若林恩在核心深处主动给自己留一条出口而非把门彻底封死，则他此后在任何被吞没的边缘都仍有一线主动选择的权力，那座城再也不会整个把他锁住。
- 若林恩在七十一噩梦把力量让给核心时主动朝它们弯腰一次而非只是战斗结束，则那股转移的力量里多出一份「敬」，核心后来的颤动有了这份敬的节拍。
- 若林恩主动把轮回记忆做成一枚能藏进左左掌心的符而非全塞给自己，则她此后每次握紧都能借到那种古老的坚定，而她拽他手的时候也带他稳一分。
- 若林恩在轮回碎片即将脱落历史的瞬间主动用左手把它们都勾住一片不让它们散，则他左手里从此多了一团永远回不去的过眼烟云，每次抬手他都会想起。
- 若林恩在终焉黑火燃烧最烈的那一瞬主动从火焰里抽出一缕让它陪伴自己而非任它自焚，则他此后的所有战意里都带这一缕温度，那把黑火成为他特有的祭仪。
- 若林恩在最终决战第一线主动先替左左问出「我能让她幸福吗」再挥拳，则他的每一次攻击都朝着答案方向前进，他赢的不再是战斗而是可能。
- 若林恩让城门在关闭前主动留下一条他专属的暗缝而非完全封闭，则终焉在他离开之后仍会有一个他呼吸过的回音，那座城永远记得他来过。
- 若林恩在跨过最终门槛前主动对左左轻声说一句「如果我没回来，你也要活得好好的」，则那句话被她压在心底成为往后每次思念的底火，她从此不只靠希望活着。
- 若林恩在最终决战进入白热化前线主动让自己的某个过去自我短暂浮现一次而非完全压下，则他能够短暂借用那份过去的技艺，但他今后也会时不时瞥见那道自己。
