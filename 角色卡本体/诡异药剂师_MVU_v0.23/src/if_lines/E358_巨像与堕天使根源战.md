# E358·巨像与堕天使根源战·if线

- 若林恩在黑羽攻势落下前主动提醒巨像之脑不要独战，则她会在血气起里用比往常更沉的语气说「这是我一直以来为自己准备的战场」，半完全体的协同与否在他这一句话里被她亲自衡量过。
- 若林恩在战斗最初肉身试探阶段主动下场以疫医身手加入侧翼，则巨像与他首次以「医生+巨像」的并列阵型出现在战场上，气压震动顺着拳路扫开两侧建筑残骸。
- 若林恩在堕天使自称路西法那一秒主动用法阵压住自己内心对大君名字的本能共鸣，则他不会失神、她能以十二翼姿势完成宣告，但他自身的稳定度被这一场对峙记录。
- 若林恩在她释放漆黑涟漪沿巨像扩散纹路时主动用黄沙把自己和巨像的连接轨道切断一拍，则纹路在他身上被中断、巨像单独承受全部反冲击，他对网络的伤害承担落到零。
- 若林恩主动请巨像之脑把「战斗主导」交给自己一段，则她会首次犹豫两秒才点头，半完全体的动作从她的节律切换成他的、巨像的速度变慢但精度变高。
- 若林恩在她分出大量黑魔法分身时主动让左左出马辨认哪一具是真身，则左左会用咒纹感应从十几个分身里指出真身所在的黑雾高处，巨像的矛不再落空。
- 若林恩主动开放内空间让喵喵从怀里钻出来旁观，则她会首次在战场的远端用一对竖瞳盯着堕天使十二翼的每一根羽毛、在意识空间记下整份攻势图。
- 若林恩听到左左为巨像之脑助威时主动把她的心声也想掺进去，则她的助威在他心口叠出一个二段合音，网络里的士气第一次在他这里折成双拍。
- 若林恩在黑羽飘落的瞬间主动用黄沙向漫天黑羽反向吹散，则黑羽有一部分在落地前被黄沙的热量烤焦、它们落到他脚边不再造成实体伤害，但黄沙本身被耗掉一大半。
- 若林恩察觉第一波羽毛已经渗入意识领域时主动用黄沙封住自己心神，则他能保住自己，但这一封同时也隔开了他与巨像之脑在网络里的直连，修复期被拉长。
- 若林恩确认堕天使体内病变可诱发时主动用灵能「引爆」那一片病变区域，则病变在她骨肉里炸开一角、她那只伸向甲胄的暗影手臂抽搐了一下，但她眼底的怨毒因此更深。
- 若林恩同意巨像之脑呼叫散落血肉增援，则巨像四周数十道微光会从天而降、半完全体往前走一格成为最接近完整形态的一次，他的体力也随之大规模透支一拍。
- 若林恩主动用右手衔尾贴上巨像甲胄裂痕处，则衔尾在巨像上第一次出现、那一秒的连接使他听见巨像之脑以他熟悉的声调说出「我交给你算一次」。
- 若林恩在她完成法阵吟唱前主动用灵能打断咒文节点，则她的法阵被迫中途崩解、大量反噬灵能倒卷回她十二翼内、她首次在这一场战斗中被迫后退三步。
- 若林恩主动把克苏鲁之眼和精神领域重叠范围控制在最小，则反制仍生效但深蓝权限的耗损程度比全开时小一半、他在事后不需要长时间冥想就能恢复日用心神。
- 若林恩在她的暗影手臂穿入巨像头颅的瞬间主动触发自缚天使那枚旧徽章，则徽章浮出一层不属于这场战斗的古老屏障，他与那枚徽章的来源因果被这一次召唤重新激活。
- 若林恩主动用黄沙把主母的灵人光芒从堕天使体内短促地剥出来一缕，则那一缕不属于她的光在战斗中独立悬浮一秒钟，事后他首次确认主母人格在这片黑暗下仍然存在但极微弱。
- 若林恩没有殖装克苏鲁之眼而是改用无瞳法阵对抗神魂攻击，则堕天使的入侵会顺着紫罗兰纹路逆行、在他与巨像的连接轨道上烙下一圈属于对方的印记。
- 若林恩在她退入血雾之后主动追击、与巨像之脑兵分两路，则巨像追向她退化路线、他自己循着主母那一缕光单独深入，战场自此分裂为「追击」「救治」两条独立行动。
- 若林恩主动在战斗尾声对堕天使开口说「我知道你在保护她」，则她会首次在十二翼之间停顿半拍，那个停顿被巨像之脑捕捉到、记入她对敌策略的下一版更新。
