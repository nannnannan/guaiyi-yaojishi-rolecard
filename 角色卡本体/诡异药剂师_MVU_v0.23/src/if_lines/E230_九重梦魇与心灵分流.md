# E230·九重梦魇与心灵分流·if线

- 若林恩在「诅咒？」一句喃喃自语的下一拍升级成「这场诅咒我买单」，则清除咒术的覆盖范围从他自身扩展到整个废土，事件以不变形收束但魇魔投影被白色罗网夹在中央、连残余本源都被一并收录。
- 若林恩当着魇魔的面把手臂上的符文展示给它看、像晒藏品，则魇魔最后一秒惊愕到失去继续挣扎的意志，事件以不变形收束但收录结算画面被命名「祭品自送」。
- 若林恩在收录九重梦魇时不调侃、改以疫医礼节深鞠一躬致意，则魇魔投影在消失前看到「主人」形象而非「恶魔」，事件以不变形收束但血肉支配者远端感受到一股完全对不上的「温柔」气息、对林恩的警惕等级直线上调。
- 若林恩在心灵分流入手瞬间立刻测试一把、把一缕灵魂转移到巨镰刀柄，则巨镰在未来战斗中与他的连动增强一倍，事件以不变形收束但他必须学会在战斗中同时维持两具灵魂版的自己。
- 若林恩在【往日罪孽】结算时拒绝接受白夜好感+100、要求换成别的东西，则系统提示「奖励不可修改」，事件以不变形收束但白夜的好感度仍然被强制灌入、林恩被他自己刻意拒收的礼物压出胃痛。
- 若林恩在等级+2入场后立刻把自由属性点全部丢给精神，则他的精神力从垫底一跃成为次强，事件以不变形收束但「体质流」战术路线短期内需要重新校准。
- 若林恩在完成收录后顺手给左左折跃打去一份「搞定了」的简言，则她在守阵法阵听到这句话当场软坐，事件以不变形收束但左左后续一小时无法起身、阵法由一只普通傀儡代守。
- 若林恩在心灵分流的新技能栏被点开时先研究「对其他承载物转移」分支，则他首次把自己的意识短暂注入一只路边野猫，事件以不变形收束但「野猫林恩」的视角给他上了重要一课、他之后再也不轻视动物作为载体的价值。
- 若林恩不放声大笑、而是在原地平静地致谢「感谢老铁送的诅咒」，则他的语气轻得吓人，事件以不变形收束但他回头在全球卫星画面里那副淡定脸孔成为新一代网络符号。
- 若林恩把爆衣后的肉身直接转化为对血肉支配者大厦的方向指去，则一根触手在废土上扬起、指向东南方向，事件以不变形收束但第一使徒识别出他的指向后提前在三千公里外召唤投影进入战场。
- 若林恩在钓血肉支配者前先收回白雾整片废墟、让地表重新见阳光，则战场被「消毒」一遍，事件以不变形收束但后续的布场环境从「雨林血肉区」变回「阳光废墟区」。
- 若林恩在升级瞬间顺手问系统「距离第二职业还差几级」，则面板上写着「一级」两字，事件以不变形收束但他在心里压下激动、表面上仍是一副平静面孔。
- 若林恩在收录九重梦魇时让乌鸦臂章从系统空间飘出共鸣一响，则臂章流出一行古老符文印在他锁骨，事件以不变形收束但「流逝符文」在他身上的附魔时长+30天。
- 若林恩在魇魔投影炸开瞬间让巨镰在冲击波里额外收割一次，则魇魔最后的意识残片被钉在镰刃上、带回作藏品，事件以不变形收束但白夜后续会在看到这份「礼物」时久久不语。

- 若林恩在结算后选择不回蜀都、改向横断山脉某处预先埋下「钓场基石」，则事件以不变形收束但 E231 的「假召唤法阵」建设提前三日开工。
- 若林恩在离开战场前用一根触手把爆掉的衣服捆好收起，则「裸奔少年」画面只持续数十秒，事件以不变形收束但全球卫星拍到的影像里仍然留下一抹耐人寻味的白光。
