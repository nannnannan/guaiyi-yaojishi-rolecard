# E101·夺舍洛什与芬芳尖啸者嘴遁·if线

- 若林恩先让爱丽丝附身其他疫医队员套出小队编制与口令、再伺机换掉洛什，则夺舍成立但初级神经权限延迟到手。
- 若林恩在爱丽丝附身瞬间让左左放噪声干扰走廊回声，则夺舍异常波动被掩盖、尾虫惊恐期延长。
- 若林恩选择只吞脏器不吞血肉外壳、保留洛什外皮做触手傀儡，则可短暂双人站位骗过远端监控。
- 若林恩不下手吞噬而是把洛什活捉塞进系统空间，则爱丽丝撑住外壳时限变短、必须尽快交接控制权。
- 若林恩对尾虫不下以M之拳而是顺时针捏碎，则信息素检测立即红灯、大门验证桥段改写为硬闯。
- 若林恩给尾虫灌入以M之力到昏厥但不遮味，则走廊沿途留下催情信标、引来其他殖装造物躁动。
- 若林恩只向部分瘟疫容器注入以M而保留另一半原样，则后续狂热效果分批爆发、工厂那边先怀疑批次差异。
- 若林恩把以M之力改注进尖啸者而不是瘟疫容器，则尖啸音波附带媚毒、第一重合唱先放倒自己人。
- 若林恩利用初级神经权限反向给利维坦肉壁下「瘙痒」指令，则检测吸盘自检失常、验证桥段用玩笑式通关。
- 若林恩在更衣室不搬走全部尖啸者而只改装其中三颗，则党争火焰压低、315博士介入时点延后。
- 若林恩当场承认「是我拿的」之前先点名一名替罪疫医，则诱惑气场+感染性气场双开、党争目标转向内查。
- 若林恩把名单写成两份：表面一份正常申请、夹带一份天价吨级，则血肉工厂高层在屏幕上先松口再爆血管。
- 若林恩在嘴遁中直接亮出夜医身份挑拨，则全场警报拉响、转入变形：夺舍暴露突围战。
- 若林恩选择听左左劝、只搬一半尖啸者留一半证物，则后续工厂互查时罪证链更完整、党争撕裂更狠。
- 若林恩在315博士接通瞬间主动改口只提赔偿不提围剿，则四寸不烂之舌成就降级、但执事荣升路径仍开。
- 若林恩让爱丽丝在315博士面前假扮洛什流出血泪表演忠诚，则博士疑虑加深、E102 荣升门槛抬高。
- 若林恩用感染性气场叠加「我以党国名义发誓」桥段，则周围疫医自发跪下作证、党争瞬间成型。
- 若林恩故意漏一颗未改装的尖啸者混在队列里，则双重奏里掺一句原声尖叫、被工厂抓住反击点。
- 若林恩当场没收高层通讯水晶、把对话录音留作后手，则后续E108全厂下毒可免一次自证。
- 若林恩不兑换【四寸不烂之舌】成就、继续压制声量，则后续同型嘴遁难度上升但隐蔽性保留。
