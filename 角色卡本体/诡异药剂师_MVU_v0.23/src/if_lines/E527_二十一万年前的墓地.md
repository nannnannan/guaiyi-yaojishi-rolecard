# E527·二十一万年前的墓地·if线

- 若林恩在半封裂隙时把罗网缝隙留在裂缝内壁而非表面，则时间流被压入内循环通道，污染者下一次勘破时损耗向缝隙集中，三叉戟阵眼的耗损记录「缝隙内耗」而非「表面回弹」。
- 若林恩拒绝让三叉戟留作阵眼、改以自身一部分初诞者之力长期封入地底，则他离开时节点仍能维持封锁，但每一次久修都会从他身上按比例抽走精力，左左拔刀训练时他面色会更憔。
- 若林恩让左左协助编织结界而非独自缝合，则电流与初诞者之力在裂隙表面镶出合作纹路，结界对她的触碰不再反馈灼烧，左左后续修刀时不需避开阵眼。
- 若林恩飞升到上层墓穴时不举手悬光球、改用咒瞳直接透视黑暗，则丰碑的名字不立刻显眼，他先看到中央尸山的轮廓，「是我造的」的认名时刻延后、但更直接撞上恨意消解瞬间。
- 若林恩在认名丰碑时主动伸手触摸「阴影与窥视之神亚弗戈蒙」名字，则碑体渗出的一缕太古回音混入他的记忆洼，他对渡鸦墓穴布局的似曾相识更具体化一层。
- 若林恩在尸山前没有直接瘫坐，则恨意消解过程短半拍，他保留站立姿势完成「是我造的」自认，但内心那根弦不在此处当场彻底松，E528 的黄沙自证多一道压抑余烬。
- 若林恩让左左在自己久修起始就先斩一座小些的碑以试手感，则她的失败次数前移，练刀的曲线在盘膝研习期间多一段磕绊，斩出那一刀的时点延后数日。
- 若林恩同意左左继承巨像双生子的记忆以换她力量立刻到手，则她斩出那一刀的瞬间不再是「左左成功」而是「双生子成功」，挂件身份轴被去掉，后续挂在林恩腿上的姿势会被她自己排斥。
- 若林恩在左左斩碑成功那一刻睁眼起身见证，则光球研习中断一次，黄沙自证时点延后，但左左后续的训练多一段「脑袋看到了」的回声，挂件心更稳。
- 若林恩主动把战斗中夺取三叉戟的那一帧画面从光球里抠出来做成一枚独立的记忆珠留给左左，则她每晚睡前多一次独自可视化左手那一刀的练习。
- 若林恩拒绝让长明灯齐亮、改用指间一星初诞者之光维持微弱照明，则墓室氛围整体保持昏暗，久修氛围更冷，「历史推着向前」的孤独感被放大而非缓解。
- 若林恩在光球外再留一道耳挂，让新月渡/黑夜城的现实声音以极慢速率渗进来，则他在二十一万年前仍能模糊知道「那边才过了几分钟」，时空不适感减弱，但「恍如隔世」的锋刃也钝一层。
- 若林恩决定不告诉左左「血肉支配者诞生之地」这一定位，则左左对中央尸山的恨意遮掩维持不知情，久修期间她对墓穴的排斥仍是环境级而非命运级。
- 若林恩任由自己在长明灯齐亮后再点燃一盏「家人树上所挂」的引路火光，则二十一万年前的墓室多一缕属于黑夜城的方位锚，E528 离开时他找到神王保留的裂隙比现在更顺。
