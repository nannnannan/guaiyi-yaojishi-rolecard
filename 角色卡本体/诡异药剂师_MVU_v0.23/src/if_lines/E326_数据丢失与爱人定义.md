# E326·数据丢失与爱人定义·if线

- 若林恩在替她诊断时先用灵能扫描再上手拆机,则他能读出「她主动放弃数据」的神经遗痕、E327 才质问母树的判断早三小时成立。
- 若林恩没有说出「但如果她本来就想死呢」改成「她一定是受伤了」,则母树不会震动、推断链不出,E327 她的质问线改变成「你为什么修不好她」。
- 若林恩在母树朝他挥拳头时不闪不避接下那拳,则他被揍飞十几米、但随后母树扶起他道歉,E326 后续对话氛围从怒火转向沉重共识。
- 若林恩在听完缘由后主动按住母树的手赎罪,则她怒火 -50、但强迫他承诺所有后续对银幻的接触必须有她在场。
- 若林恩在诊断时把她机体上「001」的出厂序号抹掉改成自己的指印,则他在她系统中植入了一道「林恩私有」的标记,E331 决裂时被她清除并成为仇恨的焦点。
- 若林恩在 seq 调试中不响应对母树那句「你不值得」,则她被激怒、E328 主线中她多一次主动挑衅林恩。
- 若林恩在发现「数据白花」后不立即提问而是静静观察,则他错过了她现在主动展示的机会、E326 反而先解决存在意义问题再回到白花。
- 若林恩在白花被投影瞬间脱口而出「这是我从蜂巢田野摘的,我现在还记得」,则她的处理器立刻锁定「蜂巢」关键词、E326 直接跳到关键追问、漏检三组话题。
- 若林恩在她问「还有吗?」时故意诱导「你肯定还有一个梦境,暖暖的房间」,则她摇头、但在底层代码中被他这条提示唤起隐性搜索、E327 她独自在母树水潭边花了整夜自问。
- 若林恩在被问「你是我什么」时回答「只是修理师」,则她标注为「低权限接触者」、E329 接吻传输的权限不足、三大模块无法完整写入。
- 若林恩选择回答「曾经是敌人」,则她在人格模块中把林恩标记为「待观察对手类」、E331 沙漠等待时她的返回立场变得更加坚决。
- 若林恩回答「光是朋友」,则她接受这一答案但处理器深处出现一个无法解释的「失真感」错误代码,E331 决裂时她以额外愤怒的回击清算此失真。
- 若林恩延期回答「让我再想想,在你能记得一点的时候回答」,则她转入「等待模式」、整个事件进入全新阶段。
- 若林恩在她问「存在的意义是什么」时引导她「你想要什么」,则她在最低耗能状态下开始首次自行定义、E326 末尾她要求一株红花作为目标。
- 若林恩在她问「集体是什么」时详细解释蜂巢架构,则她处理器活跃度上升、但同步拉扯她记忆缺失区域、导致短暂头痛宕机两小时。
- 若林恩在她主动问出关键问题前先发现她处理器中的一段「加密锁定文件」,则他面临是否强行破解的选择、若破解则数据恢复但灵魂创伤同步复发。
- 若林恩在听完她说「无法检索到相关信息」后主动透露自己拥有检索钥匙并解锁她的深层数据库,则她能完整看到小冰箱事件档案,E331 转变为她主动告别。
- 若林恩在手掌白花之存瞬间悄悄取走一滴数据备份,则他获得了一份「她的纯净情感样本」、E334 在羽毛笔书写时作为灵魂定锚物使用。
- 若林恩在多日调试中每次现身都戴同一顶帽子,则她开始把「帽子」作为安全信号、E329 的吻传输场景中以帽子触碰作为信任确认。
- 若林恩选择直接对银色幻想说「你和我曾经上过床」,则她的处理器立刻崩入错误冻机、E326 直接进入紧急修复。
- 若林恩在最后时刻选择为银色幻想更换一台完全崭新的「非唯一机体3a」型号,则她失去了唯一机体的骄傲、但获得了未来蜂巢修复的可行性。
