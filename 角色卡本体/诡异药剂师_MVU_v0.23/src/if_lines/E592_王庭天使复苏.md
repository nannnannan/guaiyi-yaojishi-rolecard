# E592·王庭天使复苏·if线

- 若林恩同意让左左陪至废墟作见证，则左左会在魂灯首次散幽蓝时拽紧他衣角不发一语，事后她把「女仆团」调侃换成了真心的安静。
- 若林恩在祭魂灯前先看一眼红月，则他会确认「它只是普通红月」的判断在读数上更可靠，不再有「轮回威能疑似残余」的悬念。
- 若林恩不把细胞塑身过程公开给左左看，则她心里「你是不是设想过这种龌龊事」的吐槽会变成一句「你不告诉我过程我就担心」，喜剧气质改温软。
- 若林恩在塑身过程中刻意微调每一位天使的羽翼幅度，则复生后的近卫队列会呈现出各不相同的羽型轮廓，战场群中会有人以「花团锦论」赞叹。
- 若林恩在召唤弑利叶睁眼时先默念一句「欢迎回家」，则弑利叶会先以一个深呼吸后才睁眼，整个誓约节奏更稳一拍。
- 若林恩坦白渡鸦身份之前先看看主母反应，则主母会用指尖触他下巴点个头，天使们把这一动记成「魔君与主母对话」而非「魔君与仆从」。
- 若林恩正告弑利叶「你姐姐正在并肩作战」时同步给她一段主母最近战场影像，则弑利叶沉默的时长会更短，姐妹旗提前拉开一条缝。
- 若林恩没有正告弑利叶那句「她没有背叛」，则弑利叶会继续保持沉默不再多谈，E593 _ROUTE 走廊初探中她对主母的态度仍带戒备。
- 若林恩接受弑利叶编入指挥时允诺给她们独立序列，则后续 E593 作战频道中就有专属于近卫团的另一个频道上线。
- 若林恩拒绝额外补给而让弑利叶自解黑甲，则她会以更快速度抽调到一/二位面追击前线，但深渊第一魔君的古魔大军会被更早曝光。
- 若林恩在买一赠十阶段主动给十二把黑剑烙印初诞者金印，则这批武装会被定性为「继承级」，弑利叶对他的敬意会再上一阶但让她日后更不愿违背他话。
- 若林恩选择不让左左参与镇压戏份，则她会憋着一股气无处发，事后在 E593 _ROUTE 走廊中她会更主动要陪行。
- 若林恩让圣安娜参与见证复生场景，则她会在心里把「堕天使」这一脉与她的六翼定位重新校正，对后续她自己的礼数会有影响。
- 若林恩在指挥体系接入时给弑利叶一个独立「魔君私卫」牌头，则她会以此名称接受任务，但整个军团衔「魔君陛下」声线会被再多一份。
- 若林恩拒绝接受「买一赠十」的心意，则弑利叶会愣住三秒后以一种「请魔君赏面」的辞色再次呈上，背后古魔大军不再被隐匿。
- 若林恩在天使复生后单独召弑利叶问「你想要什么新剑」，则她会沉默后答「请您赐我一柄能为您效死的剑」，这条私线会延伸进后续事件。
