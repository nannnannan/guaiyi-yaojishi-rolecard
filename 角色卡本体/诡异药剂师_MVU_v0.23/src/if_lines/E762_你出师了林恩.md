# E762·你出师了林恩·if线

- 若林恩在透过时间洪流看到过去正一步步迈向圣堂罪恶王座的自己时，血泪交织地撕心裂肺嘶吼「不要！不要登临那个王座！！不要相信艾雯爵士的话！！」，则长河内王座前的过去身影似有所感地怔怔抬头。
- 若林恩在即将冲入时间大幕触碰过去自己的一瞬被掌控初诞者之力的轮回神王强行拽出，则他借势看清了强行干涉过去会引发何等恐怖的时空反噬。
- 若林恩在一次次突破皆被挡回后歇斯底里地催动升华至顶点的终焉黑火、嘶吼质问轮回神王为何一定要逼自己出手，则轮回神王眼中浮现出严师般欣慰而决绝的目光。
- 若林恩在听见轮回神王平静回应「我一直都在等这一天」、并见其展开庞大梦境以无尽初诞者之力铸出锋锐长剑时，他瞬间记起了师徒二人很久以前定下的「三招之约」。
- 若林恩在接下轮回神王第一招与第二招时将毕生所学与终焉黑火融于一炉全力迎击，则斑驳的时间线在两人纯粹到极致的招式碰撞中被彻底照亮。
- 若林恩在第三招宿命对决交错而过、光芒散尽后与轮回神王背对而立，听见身后传来那句带着笑意的「你出师了，林恩」，则他浑身剧震，满腔疯狂瞬间化作惊惶。
- 若林恩在听到轮回神王手中长剑咔嚓碎成无边碎片、看见熊熊终焉黑火由外而内烧入老师爬满裂纹的梦境时，猛地转身扑过去接住倾倒的轮回神王，则师徒二人在火光中完成了最后的相拥。
- 若林恩颤抖着双手拼命想要扑灭烧在轮回神王身上的黑火、哭喊着质问他「你为什么要放水？！」，则轮回神王会死死抓住他的手腕阻止他灭火，微笑着坦言「这就是我的全力了」。
- 若林恩在听轮回神王道出真相——他想在最终一战中不因因果牵连而崩塌，就必须斩断与这个梦境世界的一切因果，而作为世上与林恩因果最大之人，「这是我欠你的」——时泪如雨下，则老师用生命为他铺平了通往终焉绝巅的道路。
- 若林恩在轮回神王于熊熊黑火中用力一掌将他推回原本所属的时间节点时伸手想要抓回老师，则指尖掠过的那缕灼热火光成为他脑海中永不磨灭的烙印。
- 若林恩在向长河内嘶吼「你不会想知道等在你前面的是一个你无法接受的残酷命运啊」时声音嘶哑泣血，则这句跨越时空的警告在冥冥中化作了过去自己心底的一丝季动。
- 若林恩在三招对决中清晰感受到轮回神王每一剑都在引导自己将狂乱的黑火彻底凝练收束，则他明白老师直到生命的最后一刻仍在手把手教导自己如何驾驭终焉。
- 若林恩在轮回神王抓住他手腕阻止灭火时感受到老师掌心传来的浩瀚初诞者本源，则他瞬间明悟老师不仅是在斩断因果，更是要把自身梦境化作助他突破的最后柴薪。
- 若林恩在被推回原时间点的下坠途中死死盯着时间之外那团越烧越旺的黑色火炬，则他眼中的迷茫与偏执被老师的死彻底烧尽。
- 若林恩在三招交锋前对轮回神王那句「我一直都在等这一天」有所触动，则他在出招时少了一分失控的暴戾、多了一分堂堂正正的弟子敬意。
- 若林恩在长剑碎裂的清脆声响中听出了轮回神王解脱般的释然，则他终于理解了这位背负无数轮回重担的老人为何会选择以这样壮烈的方式谢幕。
- 若林恩在接住倾倒的轮回神王时任由对方染血的手掌拍了拍自己的肩膀，则那句「你出师了，林恩」真正成为了他独自扛起整片宇宙大旗的加冕礼。
- 若林恩在被推入时间壁垒前含泪向火海中的轮回神王深深叩首，则这一记跨越生死的叩拜为两人的师徒缘分画上了最悲壮圆满的句号。
- 若林恩在重重摔回原本时间节点的焦坑中时死死攥紧拳头，则掌心残留的一片长剑碎屑让他时刻铭记这一战的重量。
- 若林恩在焦坑中压抑低鸣片刻后毅然起身重返时间之外，则他已做好了直面老师留下的漫天柴薪与自身宿命的准备。
