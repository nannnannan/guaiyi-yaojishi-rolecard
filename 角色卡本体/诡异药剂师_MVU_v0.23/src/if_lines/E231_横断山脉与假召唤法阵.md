# E231·横断山脉与假召唤法阵·if线

- 若林恩在白雾禁区外沿加布一层咒瞳信标哨探，则弥赛亚翻越丘陵的脚步在抵达山丘前就被捕捉，触手捆缚节点提前、后方召唤铭刻节奏被打乱。
- 若林恩把第一层防御换成纯【血肉解构装置】零殖装布局，则后续即使被权柄剥夺血肉也不会波及山丘防线，但利维坦殖装的强攻手段没了，第一次面对第一使徒的肉搏缓冲更脆。
- 若林恩在铭刻召唤法阵时偷偷掺入一缕主母的气息压底，则血色光柱除了刺穿白雾还额外带上一道低频震动，第一使徒接到的汇报里多一条"夹带域外天使共振"的诡异标志，恐惧+20而非愤怒+50。
- 若林恩第一次献祭就故意让利维坦血肉残渣风化大半、只留一丝召唤波动，则血肉神教监测到的能级不足以断言"利维坦"，第一使徒权衡再权衡，南下时机延后一整天，左左等候窗口被拉长。
- 若林恩在同一座山丘连续布置七座法阵呈北斗阵形同步催动，则七道血柱齐起、整个横断山脉被点亮，蓝星阵营要多国卫星同时捕捉到这一异常，超自然总局对林恩身份的警觉提前爆发。
- 若林恩提前把催动反应收敛到蓝星地脉深处而非冲天光柱，则波动只有近距离天使血统者能捕捉，弥赛亚寻来时带着更早的预判、第一使徒反而收不到信号，南下决策拖延。
- 若林恩在蹲守一夜之后拒绝天亮发动、继续静守三日，则血肉支配者因"诱饵不给动静"反而起疑，主动派出斥候触手先探，山丘防线首次对阵的是眷属而非投影本体。
- 若林恩在割掌铭刻之前让左左远程接入通讯、把台词先念给她听一遍，则左左从蜀都方向同步发动巨像链接，她心血来潮的"那我就先在法阵外沿加一笔"会改写整个诱饵的地脉走向。
- 若林恩的第一道诱饵法阵直接以"献祭巨像之心残片"为燃料而非利维坦血肉，则召唤波动带上巨像之脑的低鸣，远在地狱侧的主母也会捕捉到信号，圣天使的注视提前落到蓝星。
- 若林恩在弥赛亚踏入禁区瞬间不缠她触手反而故意放她直走，则她会先撞见召唤法阵的剩余余温，把林恩的位置判断错一公里，下一次照面延迟到来。
- 若林恩用左左卷出的触手在禁区边缘摆下"已被入侵"的假象，则弥赛亚感知到的是另一股血肉气息，她走偏被山腹内部弹出的猛毒陷阱困住，进入事件的姿态从"自愿来访"变成"获救者"。
- 若林恩把"傀儡之印"预埋在禁区边缘的枯木上，则弥赛亚被捆缚前会主动拼出一条求饶口信、林恩收到的是"计划中的访客"而非"未经允许的入侵者"，监护等级从带刑审降为带茶会。
- 若林恩在第二次召唤波动升起时把左眼咒瞳对空、强行扫描第一使徒的破空轨迹，则他被反向锁定一瞬，血肉支配者认出"那个小咒瞳术士"的气息，南下姿态从"顺水推舟"变成"带着杀意直扑"。
- 若林恩沿用原作九次连续召唤波动催动但把频率调成"利维坦残片自身痉挛节拍"，则第一使徒收到信号后怀疑"利维坦还活着"，投影带着恐惧守护的姿态而非嘲讽，第一回合的开局氛围整个反转。
