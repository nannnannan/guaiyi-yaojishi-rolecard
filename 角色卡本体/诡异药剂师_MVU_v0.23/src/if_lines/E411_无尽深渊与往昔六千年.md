# E411·无尽深渊与往昔六千年·if线

- 若林恩让左左先拟化成一根细长丝绳接在他腰上、沿垂直深渊往下垂坠，则她不慎把丝绳末端蹭到带刺石棱擦出血痕，咒纹共振下他俩人同步在颅内听见一声遥远的女人叹息。
- 若林恩起始就朝深渊底下倾倒一支大桶显形药剂、宁可浪费一整瓶，则密密麻麻的魂灵被瞬间打亮成一片惨白星海，其中几张保留较为完整的旧神面孔会抬起头朝他这个方向咧嘴一笑。
- 若林恩让喵喵作为「空降先锋官」沿着石壁跳跃下探、而不是直接用咒瞳扫，则她沿壁遇到的某只无魂傀儡会突然仰头对她咧一张由意志碎屑拼成的笑脸，她被吓得到退三步、当场在林恩通讯频道里骂「爹的吓人玩意」。
- 若林恩不立即停机、而是沿管网内壁把魂力积淀刮下一把放入口袋作标本，则那根停靠他口袋的残片会在事后持续发烫并试图渗入他的皮肤，左左发现时会尖叫着按住他的手腕把那残片拔出来掷地上践踏。
- 若林恩用克苏鲁之眼在停机瞬间反向蓄压，则整座血肉机器不会顺利压缩、而是会爆裂般抽出更多的魂力和紫黑晶渣，中央残肉区域会被一层全新郁结的雾团覆盖，克洛诺斯之眼当即在面板里提升一档感知消耗。
- 若林恩停机成功、直接跃到百米血肉块的顶端跳一段即兴踢踏，则血肉块会以低鸣回应他的节拍，一排张望的夜医副官在频道里齐声吸了一口气，事后「林恩在尸体上跳舞」被列入黑堡档案侧录。
- 若林恩在找到艾泽法拉兄长残魂之前先用一缕原初之力嗅探空气，则他会撞见一缕属于弥赛亚的远房血亲残魂正被钳在管道口，对方见到他后用仅剩的嘴唇做出一声「别碰我」的口型。
- 若林恩见到兄长残魂时主动先低头鞠躬三次、而不是直接伸手去触碰，则那缕微弱意识会从习惯性颤抖转为停顿、第一次主动唤他一声「小、小朋友」，艾泽法拉后续远程得知此调度时红了眼眶。
- 若林恩把兄长残魂用一根左左变出的透明丝带裹着收进口袋，则在回程的折跃中丝带会渗入一缕金色余烬烙进他的胸口皮肤，事后每当他听到艾泽法拉的声音这处胸口就会发烫一阵。
- 若林恩放弃继续追查残魂、只取出古旧油灯直接给所有魂灵作「临时避光屋」，则油灯会一次性被点亮为魂灵灯塔，它的灯芯会以肉眼可见的速度凝结成一颗未名的紫色魂髓，事后黑堡夜医把这块魂髓命名为「夜医的希望」。
- 若林恩把左左的唯一性与遗物里的渡鸦赝品对照扫描，则赝品表层的伪装壳在她的咒纹共鸣下脱落露出里面真正的羽毛纹路，左左当场爆哭，她首次知道她与渡鸦之间存在真实血脉共振。
- 若林恩在碑林起始就用十一小时的具化上限穷追，则他在第六小时起开始看见重合画面：两个血肉支配者同时存在，向那个白发人行跪拜礼，事后他的咒瞳会在十二小时冷却中变成双重瞳色。
- 若林恩看到白发人递给幼体血肉之核的画面时伸手向前做抓取姿态，则具化画面会以肉眼可见的颤抖把那只伸出的手照得更清楚一寸，事后他的左手掌纹多出一道紫黑线条无法恢复。
- 若林恩在追到两万七千年时喝下一升灵魂之泉同步观看，则他的视野会叠加到「三万年前白发人再次来访」的画面，看到白发人摘下兜帽露出一张古怪的温和的脸，那张脸在形象上与「他自己」的差距不详为多少。
- 若林恩放弃前往十二万年前、只把影像凝固在两万七千年并保存样本，则他能用拟化抠出那块影像里血肉支配者幼体伸触手的动作，封存成一枚「触手探礼」水晶作为未来的研究标本。
- 若林恩在影像结束的最后瞬间主动选择让画面停在幼体触手与白发人指尖即将触碰的那一帧，则他能在面板里把那一帧放大十倍，看见白发人眼睛深处闪过的一缕如释重负的浊黄色。
- 若林恩在看完所有影像后没有对左左说任何话就离开碑林，则她会一路无声跟在他身后，到了晚上在他意识里哆嗦着哭出「哥哥我害怕」，那一晚他抱着她坐到天亮。
- 若林恩要求夜医把兄长残魂直接送往黑堡与艾泽法拉远程见面，则艾泽法拉听到「异端」二字当场跪地，咒骂兄长「死人仍是死人」，第一使徒残魂闻讯反而归于沉默，兄妹重逢以一场哭声告终。
- 若林恩亲自陪同兄长残魂与艾泽法拉见面，让左左在场旁观作为「调停人」，则左左强忍着不哭出声把两只魂灵的手拉到一起，事后她把自己的袖口咬出一个缺口作为见证。
- 若林恩在看到白发人影像时忽然把左左拉到怀里、把额头贴在她眉心，则她会在那一秒被他的体温躁得面红耳赤，但意识里感应到他背影孤独得湿冷——她首次主动搂紧他的腰。
- 若林恩回程时把百米血肉块装载在系统空间坐骑上跑在前头、让全体夜医列队跟在后面行进，则当日返程路径会在黑堡战报里被命名为「领尸走马路」，许多夜医副官后来对它津津乐道。
- 若林恩拒绝把血肉块压缩运输，坚持原貌保护作「博物馆石碑」，则这块血肉块会在未来的三日里持续脉动渗液、把黑堡外环街道染成深紫色，泰坦见了皱眉命人把它连夜搬离。
- 若林恩在下探时让喵喵吊在他腰间充当「巡视眼睛」，则她会在最深处看到一只半埋在血肉机器缝隙里的微型人偶对他眨眼，事后那只人偶会自发爬出作为 E412 中一声「殿下」的开场。
