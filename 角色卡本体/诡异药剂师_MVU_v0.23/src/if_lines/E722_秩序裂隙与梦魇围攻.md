# E722·秩序裂隙与梦魇围攻·if线

- 若林恩在听完方案后第一句不是挣扎而是「我答应你」，则画家会在那一瞬把未说完的半句承诺压回，转身悄无声息地开始缩小苍蓝边境。
- 若林恩在她讲述「你不能拼命、保命第一」时倔强地反问「你也是」，则她会极轻地摇头，不接这个反问，林恩会意识到她从一开始就没打算让自己活。
- 若林恩以心声悄悄把这一刻的画面传给沉睡的银色幻想，则沉睡中的她会以梦境形态挣扎一次，那条「老师傅在消失」的念想被埋进她的神格反噬之中。
- 若林恩在最后一刻抬手想要拦她的袖摆却没拦下，则他的指尖会抓住一缕苍蓝色的光尘，往后十几年那缕光尘会一直在他掌心灼烧，提醒他这一次他慢了半拍。
- 若林恩在那声「开始吧」之后突然单膝跪地、向她行了一个紫罗兰时期狱卒的旧礼，则她会背对他、肩膀极轻地颤一下，但她不会回头。
- 若林恩在画家化作箭矢冲向黑瞳瞬间喊她一声「不」，则她会停顿 0.3 秒，但没回头，那一声「不」在她内心铭刻为最后一个有人想留她的人。
- 若林恩拦在她身前、不让她通过自己，则两人会在通道尽头爆发一次本可避免的强强碰撞，林恩被她以秩序之力强行压过肩头越过，他会受一次真正的内伤。
- 若林恩提前在通道外准备好撤回系统空间的应急门，则他能在失去她的瞬间启动门扉逃回现实，但他也会永远失去看着她最后一眼的权利。
- 若林恩在撤离前猛地撕下自己一缕罪火按进她的胸口，则那缕罪火会在她被消化过程中保住她最后一丝自我意识，未来某个节点她可能因此传出一句话。
- 若林恩在边境潮退时不闭眼，则他会陪着最后那一点苍蓝色完全沉入黑瞳，那一幕会在他往后梦境中不断重播，他的恨意记录永久 +30。
- 若林恩睁开眼睛时第一句话是咒骂画家的名字而不是长叹，则身边气浪会激起一阵更猛烈的火焰漩涡，梦魇群会先被他吸引一波，为他争到向深处拓路的窗口。
- 若林恩选择在黑潮来临瞬间冲向三叉戟、先把这柄神兵从法则原点拔出来，则他将失去 Finishing 这次送行的姿态，但抢回一件能在将来号令主宇宙本源的工具。
- 若林恩在王旗下跪的万千狱卒面前不跪，则他会被永远写进「唯一未跪的那一个」，紫罗兰旧部中有人把他视作叛徒，也有人把他视作新世界裁决者。
- 若林恩不为她送行、扭头就朝外环飞，则整个战场不会有那道撕裂夜幕的火光流星，将出现一道「没有目击者」的撤离通道。
- 若林恩在冲入黑潮最深处时脑海中浮现左左的脸，则他会立刻清醒一瞬，把罪火护得更紧，但左左的印记会被这次深空之行永久地压深一层。
- 若林恩在最后那道黑墙前没听到她说「这是我为你准备的最后一次起舞」，而是直接拔刀就斩，则他会失去一生中最后一次听到她嗓音的机会。
- 若林恩在她低语「交给你了」时没有回任何话、只是更深地握刀，则那句告别会作为两人之间最后的对白定格，再无其他任何话语。
