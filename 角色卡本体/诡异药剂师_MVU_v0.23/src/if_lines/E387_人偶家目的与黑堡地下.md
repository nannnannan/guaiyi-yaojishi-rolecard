# E387·人偶家目的与黑堡地下·if线

- 若林恩拒绝与人偶家直接对质地下线索而改在深夜以幽灵模式潜入王座厅后方，则他以观察者身份读出她未对外明示的坐标暗号，但她的丝线立刻察觉异常，举荐事实仍在但地下线索被加密一段，需要后续解密。
- 若林恩首先强制艾雯公开对人偶家做出态度表态，则艾雯公开警告她「你比我们更接近那道天命，不要让我判断你是我们的人质」，黑堡大厅陷入紧张，地下线索交易升级为谈判。
- 若林恩对泰坦那一局棋直接旁观并提议和人偶家下一盘，则她以慢姿态接受并以棋子敲击地面画出地下地形概图，地下通路概形被当场可视化。
- 若林恩主动以咒瞳扫描黑弦月的丝线是否曾被加签，则读出她丝线确实从未被施加额外契印，举荐事实不变但「她被利用程度」证据更清晰，对话语气被冷静。
- 若林恩要求左左以伙伴身份旁听众神会谈，则她一脸茫然地递给他一张纸写着「她好像不是敌人」，作为倾向参考但被系统打为「未验证观点」。
- 若林恩从人偶家发问失败之后转向地下自由探索，则他在没有引导的前提下被深度结界滞留两小时，左左出现一次「主人失联」的紧张报告，但他仍然未深入到 E388 阶段。
- 若林恩对黑弦月坦诚「我怀疑你的老师收了不该收的东西」，则她望着他并以柔和但坚定的语气否认并说「她是我的老师，请你不要诽谤」，现场关系短暂紧张。
- 若林恩拒绝接受黑堡暂住并立刻带黑弦月回黑夜城，则人偶家标为「失约客人」，地下线索路径取消，整个 E387-E390 链路变形，需重新设计回归。
- 若林恩动员自缚天使以感应力侦测地下信号，则她以微弱身姿勾画出地下有「我族的感应信号」，地下路径被额外补充一条「天使族遗产」关联。
- 若林恩动员系统商城兑换一枚「天命回应珠」交给人偶家换地下通路，则她在接珠一瞬间意识被吸入黑堡地宫入口，一场小型失控发生，但地下通路因此被初次打开。
- 若林恩让巫神头颅与小小公开对人偶家喊话「你的举荐是恶意的吗」，则她以冷静姿态回应「我保护我的人偶，这不是恶意」，但她的戒备心被同时激发，举荐被理解为「主动保护」。
- 若林恩要求黑弦月以生人身份直接参与地下探索队，则她拒绝但答应在地面以丝线远端协助，分工明确，地下通路安全 +1。
- 若林恩独自动用初诞者之力强行撕裂地面以探索地下，则他立刻被反噬灵能流冲击并被黑色沙尘覆盖一天，探索路径以「失败代价」记录。
- 若林恩对艾雯私下说「我不相信她，请把地下坐标先抄给我」，则艾雯犹豫一会儿并悄悄记下两个他不理解的符号，作为未验证情报备用。
- 若林恩主动延后地下探索并先在庭院参与泰坦棋局观战，则一局棋胜过瞬间产生全员「事后回忆里黑堡地下」的共同记忆，临场协作 +1。
