# E344·外部灾厄与苍蓝法师塔·if线

- 若林恩在草地上醒来时伸手摸了摸左臂的黑衔尾,则那道缠纹在他掌下缩了一寸,缩的动作把那段没人认领的复苏度藏得更深。
- 若林恩第一秒便开口呼喊左左,则系统空间里没有任何回应,他喊到第三声时嗓音里多了一丝他自己都没意识到的哭腔。
- 若林恩对佝偻老人先问「你听得懂我说话吗」,则老人的黑气在那一秒绷直,半晌后他回了一句「听得懂」,之后再不开口。
- 若林恩在鹅卵石小路上故意落后一步,则老人没有回头,但脚步节奏明显放缓,缓下来的三步里风中掠过一声极轻的叹息。
- 若林恩把乌鸦面具戴在脸上去跟老人走,则老人在前方愣了一拍,随后用拐杖敲了敲地面,敲出的三下闷响在草地上留下三个缓慢合拢的土坑。
- 若林恩在鹅卵石路上主动把一把石子踢向远处,则石子没有落在草地上,而是嵌进了天幕某一条不可见的褶皱,波纹在那一瞬凝了又褪。
- 若林恩在跪伏狱卒群里认出某具尸体的气味后走近半步,则那具身影的枷锁应声收紧半环,那名死者仍维持跪姿,但脖颈骨节在他注视下发出一声细响。
- 若林恩朝那位被灵能枷锁捆住脖颈的受缚者直接喊出「视界之主」,则那具虚弱身影在原地颤了一颤,颤完仍不肯抬头,但身侧一片影子矮了半寸。
- 若林恩路过狱卒行列时蹲下来把一枚乌鸦臂章放在队伍末尾,则最后一名狱卒的指尖颤抖了一下,臂章被一片不可见的手藏进了膝下。
- 若林恩在篱笆虚掩的院门前多想了三秒才推门,则门内积灰的桌面上那枚破碎戒指在尘下轻轻一转,转出一个小小的挪位。
- 若林恩进门先把乌鸦面具放在竹凳上再转身,则面具的鼻孔方向恰好指向塔内,塔内的苍蓝身影在那一秒极轻地抿了一下唇。
- 若林恩在长椅积灰上落座时主动吹开灰尘,则灰尘里扬出一阵不属于此世的旧木香气,记忆闪过一段他从未经历过的午后。
- 若林恩伸手摸那枚破碎戒指却不拾起,则戒指主人留下的痕刻在他指尖印了一秒,那一秒里他看见一段陌生画面,画面里有一个背影和他自己极像。
- 若林恩在小木门外先敲门三下再推开,则塔内那道冰凉清澈的声音顿了半秒,回句多了一丝她此生不会重复的起伏。
- 若林恩进门的第一句话是「你等的人是不是我」,则她帽檐下那双与天空同色的眸子在那一瞬凝住,茶杯被搁在桌面上的声音比她预想中重了两分。
- 若林恩进门后先把桌面上灰尘拭净再坐下,则她微微侧头,在拭净的木面上她第一次直视他,视线里藏着一段漫长的岁月。
- 若林恩开口前主动给她倒了一杯茶放在她面前,则她的指尖在茶杯边缘微微蜷缩,那杯茶她到谈话结束都没敢伸手取。
- 若林恩在她化身为混乱色彩那一瞬间伸手挡在她面前,则色彩在她的收拢里缓了一拍,事后她的语气里多了一句她自己都不会承认的犹豫。
- 若林恩在她收拢色彩恢复人身之后只说一句「你还好吗」,则那一句话被她在塔内反复回放,塔外狱卒群的动作在下一分钟整齐了一次。
- 若林恩在整段召见中一直沉默到谈话结束,则她最后留给他的指引少了一半,他只能凭着老人留下的那句「破局之道」独自摸索。
