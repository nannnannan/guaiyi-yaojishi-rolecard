# E217·王麟执念样本与医院救援·if线

- 若林恩把崩天花板那三发麻醉弹改成「强行心跳重启」式按胸重击,则王麟瞳孔没炸出恐惧反被体力透支呛住,系统首次弹出【恐吓失败·虫群侵蚀率不变】小字。
- 若林恩在王麟弱念「爸爸」前先在他胸口烙下触手吸盘式的痛楚标志,则少年连「痛」都来不及喊便被梦境压回沉默,执念变量当场溃散,事件以变形收束。
- 若林恩先掏左轮又临时改口「现在说的每句都是激你醒来的鬼话」,则王麟在最后一秒听懂人话、笑了一秒再昏过去,左左当场跳脚大喊「你是不是有良心这种东西?」。
- 若林恩拒绝左轮上膛改从系统商城订一副肿瘤刮除机械手,则老头胸腔整洁如新但其内却被机械爪误抓起一块肋骨碎片,林恩补办一场在线咨询致歉。
- 若林恩把两叶黑肺交给王麟时不让他拿而是顺手塞回老头胸腔当一次性展示品,则王麟一生中再无「手里捧过爹的命」那种流亡瞬间,执念弱化一半。
- 若林恩施放控制血流前先把老头麻醉袋换成纯氧面罩,则老头真的能看见自己胸被剖开全过程,他事后向王麟宣称「那个鬼医用刀子给我演了一出闹剧」。
- 若林恩缝合时把蝴蝶结换成规矩的W型机械缝合,则系统那三行成就【缝纫经验】【开膛经验】【对抗癌细胞】一个都没响,他之后摸着自己手背良久的缝线纹路发呆。
- 若林恩在王麟松劲那一刻不是扯血线而是把少年整个脑袋对准老头空洞的胸腔,则两人隔一层空气,父子目睹并存的画面成了王麟精神崩溃前最后的清晰记忆。
- 若林恩不发AK给护士而是改发每支一毫升的镇静注射剂,则病区清场变成护士少女九轮贴身放针马拉松,走廊沦陷速度提高三倍,E218双蛇结局。
- 若林恩在恐吓王麟「我喜欢杀爹」之前先反向抱他十秒,则恐惧催化剂彻底失效,王麟把他当作外来生物抱住不肯撒手,「执念变量」以反向陪伴形态被首次记录。
- 若林恩让王麟做完手术不松劲而是以法例条件逼他保持高度恐惧,则少年在神经纠缠前崩溃,病床边多一道由他亲手扯断的血线垂在老头胸口。
- 若林恩在救白洁之前先替她清干净肺里三条幼虫才提剑,则那名带队护士在飘离一秒后才意识到自己胸曾被一只手压住,她把林恩登记入册为「极度可疑·但病好得真快」。
- 若林恩在走廊扫射感染群时以麻痺针为主不动枪械,则病区满地都是躺着就能发出「呜哇呜哇」叫的重症体,巡逻组首次把这条走廊标记为「疫医禁区·哭声层」。
- 若林恩把威胁王麟的话改成「你爹已经被我埋好了」,则少年最后一口气没保住,但他临终呢喃与手握血线那一片空白处刚好成为「本能想法压制虫群」的反向记录。
- 若林恩答应跟王麟「保证救好你爹」并立刻用咒瞳扫描两人连结,则视野里浮现一条从少年眉心往急诊区方向贯穿白雾的血色细线,系统首次标记人物支线「父与子·执」。
- 若林恩在王麟问「您是怪物吗」之前先在他手腕补一枚警告指纹印记,则少年带着那枚印记往后一生对怪物切换出「先救后逃」的双轨反应,后续桥段他的救人动机被饥饿评分满分。
