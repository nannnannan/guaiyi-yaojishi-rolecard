# E686·神尸之路与七十二柱·if线

- 若林恩没化身乌鸦寄居真理残魂肩头，而是在他身后三尺以隐形形态独立前行，则石像眼中红光第二次亮起时会自动转向林恩的方位，两人必须在那两尊巨神石像发动第一波武器扫击前先出手。
- 若林恩从水晶长廊一侧撬下一块神尸面部作为样本收进系统空间，则当夜织梦在三叉戟世界里于昏迷中流下两行泪，泪水在晶石上拼出旧世界神殿里一个熟悉的名字——这些被铸进长廊的神灵与她是同源血脉。
- 若林恩在王座附近驻足超过三息，则王座靠背上密密麻麻的诡异纹路会无声蠕动，一缕与兽王同源但更早被定格的凶残视线会在他识海中烙下一个极淡的坐标——那是时间之末的入口残影。
- 若林恩未循真理残魂的建议绕开王座与石柱，而是上前一步直接触碰那根通天石柱，则他掌下的纹路会全部凝住、然后像潮水一样在他手里倒退一寸，七十二柱中属于「他」的那一根，第一次在他身上认了错。
- 若林恩让银色太阳在时停发生瞬间不直接解除、而是反向追溯时停的来源，则脑中会多出一段极短的画面：那片遥远孤岛的夜空下，一个漆黑的人影正在把无数石柱像立木桩一样，一根一根插进梦境边缘。
- 若林恩在被定格前主动将一缕初诞者之力注入真理残魂脚踝，则他的半身时停三秒后即自行解除，但界结另一端传来一声极细碎的磕碰响——有什么原本藏在时间缝隙里的东西，第一次被他惊动。
- 若林恩没走左侧通往第四层的大门，而是先在七十一根黯淡石柱中央画一个极小的识记阵，则这片内嵌深渊里每一根石柱的真实来历都会在他识海中闪过一句封印文字，但返回时再也找不到那两个岔路口——他将被一路引导到第四层监狱的侧墙外。
- 若林恩在白骨利爪破柱而出瞬间反手把它握住一寸，则那根骨爪会裹着他的手骨一起缩回时间之末，他手臂上会留下三道无法愈合的深可见骨的裂痕，但他清楚地「看」到了那只怪物头颅顶端的轮廓——与他自己一模一样。
- 若林恩让真理残魂先冲回走廊、自己断后阴一手掷出一支疫医烟雾弹拂向时停中央，则烟雾会在半空凝住，形成一个永恒的「静止截面」，他在逃出结界时能顺手把这个截面扯下来一片，作为日后破解时间之末的一枚钥匙。
- 若林恩在冲破结界瞬间喊一声「银色太阳，记下这些人的脸」，则神尸长廊里的那张张扭曲脸庞会化作一线金纹烙入他眼底——这些死于神战的人，从此不再是一堆无名遗骸。
- 若林恩没理会「长啸」继续深入内嵌深渊再窥三座石柱，则回来后发现左侧入口已被无声推移——通往第四层的那条路在他身后缓慢合拢，金砖崩塌，林恩与真理残魂必须在彻底封死前的最后四息里做出选择。
- 若林恩这段潜入过程里一直保持双脚悬空、不让自己的气息真正沾到第三层的地面，则石像守卫在他离开时不会做出第二次注视，但他在脱离结界后会发现自己的影子变得极为稀薄——他在这一层没有真正落脚，就无法带走这一层的任何东西。
- 若林恩在三十一座石柱中自愿停下脚步、主动向其中一根最古老的石柱叩首三下，则他周身会覆上一缕极轻极淡的白光，那根石柱不再有凶性，紫色裂隙止住蔓延一瞬——七十二柱中的一位，第一次被一缕不同于「灾厄」的法则安抚。
- 若林恩在逃出结界前从地上抓起一把神尸水晶粉末掷回自己去处，则粉末会在甬道里化作一缕极轻的低语：「带回去给王……让她们的好主人……替她多吃一顿饭……」紫罗兰军团最后的嘱托，落进了行囊。
