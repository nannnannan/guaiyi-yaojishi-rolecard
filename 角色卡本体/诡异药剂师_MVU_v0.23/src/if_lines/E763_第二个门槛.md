# E763·第二个门槛·if线

- 若林恩在从焦坑中爬起、再次重返时间之外时，目睹轮回神王熊熊燃烧的巨大梦境如黑色火炬横贯在岁月长河外，则他瞬间明白老师已将自身与无垠初诞者之力全部化作了他的柴薪。
- 若林恩伸手触及轮回神王留下的燃烧梦境柴薪，任由那股浩瀚本源涌入体内令自身终焉之火体量暴增，则他在悲恸中彻底承接了老师的遗志。
- 若林恩在岁月长河前再无人阻拦的时刻，久久凝视着长河中一步步登临王座的自己与前仆后继化作柴薪的家人们，仰天发出「就让我，成为你的墓志铭吧」的绝望悲鸣并主动放弃去篡改过去，则他终于跨越了逃避现实的心魔。
- 若林恩在形如枯骨地返回原时间点陷入浑噩沉睡、眉心扩散出充满寂灭与狂乱的漆黑无序深渊时，任由羽毛笔吃力地背起他走出黑夜城前往主宇宙的无序边界，则黑夜城得以免遭无序黑梦的吞噬。
- 若林恩在主宇宙无序边界沉睡不知多少岁月后，将膨胀至超越星河的无序黑梦尽数蛰伏回体内并清醒过来，第一时间紧紧拥抱守候在身旁的羽毛笔，则羽毛笔悬着的心终于落下一半。
- 若林恩在苏醒后激动地向羽毛笔阐述自己领悟的「第二个门槛」境界哲理——「极致的无序抵达顶点时便会诞生秩序，正如衔尾蛇；当终焉与虚无抵达极致的时候，也一定能够带来新生，实现从零到一的变化、突破逻辑的枷锁」——则他彻底找准了逆转末日的唯一通途。
- 若林恩在领悟唯有真正成为手中的终焉之火、模糊虚无与存在的界限才能一念万物追回所有逝去之人后，眼神重新焕发出灼热的光彩，则他彻底摆脱了孤王时代的死寂。
- 若林恩在阐述完第二门槛哲理后骤然红了眼眶、死死抓住羽毛笔的肩膀点破真相：「是因为你和我签订了那个契约，是吗？」，则羽毛笔试图隐瞒到底的牺牲算计被他当场识破。
- 若林恩在时间之外凝视轮回神王燃烧的黑色火炬时默立良久，则他在火光中彻底读懂了老师“不破不立、向死而生”的最后一课。
- 若林恩在放弃改写历史转身离开岁月长河的那一刻，将长河里每一位家人的面容深深刻入骨髓，则他立誓不再靠回溯旧日苟且，而是要在未来亲手重造一个她们都在的新世界。
- 若林恩在无序沉眠中任由漆黑梦境肆意演化而不强行以旧秩序压制，则他在极致的混乱与凋零中反而触摸到了万物生灭轮转的底层脉搏。
- 若林恩在羽毛笔背着他跋涉向无序边界的途中，潜意识里收敛了一丝外溢的黑火温度以免灼伤她的后背，则这份本能的温柔让羽毛笔在漫长守望中倍感慰藉。
- 若林恩在理解「第二个门槛」并非某扇物理大门、而是“从无序生秩序、从终焉生新生”的衔尾蛇境界蜕变时，他体内原本互相冲突的秩序与终焉力量开始呈现圆融之兆。
- 若林恩在拥抱羽毛笔时察觉到她比之前更加虚弱轻盈的身躯，则他立刻意识到她之所以能在连法则都崩解的大衰退中存活至今，全凭两人当年签订的命运契约。
- 若林恩在点破契约真相时声音微微发颤，则他已经猜到羽毛笔留存至今是准备在他彻底迷失于无序时用她自己的性命拉他一把。
- 若林恩在无序黑梦收缩回体内的瞬间顺势将主宇宙无序边界的狂暴乱流抚平一角，则他初窥第二门槛后的恐怖掌控力已然初露峥嵘。
- 若林恩对“突破逻辑的枷锁、实现从零到一的变化”这一神王至高哲理进行反复推敲，则他推演出接下来必须亲身完成无序与秩序的轮转苦修。
- 若林恩在抓住羽毛笔肩膀追问时目光寸步不让，则羽毛笔终于无法再用轻松的笑容搪塞过去，不得不向他哭诉全部实情。
- 若林恩在彻底接纳过去的历史不可篡改这一事实后，心境反而如大雪初霁般明朗，所有的悔恨都转化为了向终焉更深处进发的决断。
- 若林恩在无序边界握紧羽毛笔冰凉的双手，则他在踏入真正的无序大梦之前，先为这位一直默默陪伴自己的女孩筑起了一道绝不允许她赴死的防线。
