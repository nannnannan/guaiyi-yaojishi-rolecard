# E763·第二个门槛·if线

- 若林恩在无尽沉眠中先绕着第二门槛走满一圈而不跨过，则他在门槛周围读懂了火焰的脉动规律，跨入时脚下火种已对准落点。
- 若林恩主动把沉眠黑夜城中主母的那张空椅搬到门槛前，则门槛火焰识别出一件承载故人重量的物件，开启时长延长。
- 若林恩让王座梦境中的小小医院和王庭在他跨门槛前预先各点一盏灯，则两盏灯的火苗曲线成为他识别「秩序」与「家」两条路径的标志。
- 若林恩隔着王座对羽毛笔低声一句「你撑住」，则羽毛笔在时间外虽然远在梦境之外，但那一句把它自身火焰稳住一拍，E764 的命运光线更长一分。
- 若林恩主动在门槛前以自己黑火里抽出的一缕作为交换代价，则门槛火焰给出的答案更深一层，但他在沉眠中面对无序大梦时少一缕防身之火。
- 若林恩在门槛前主动念出轮回神王最后那句「你出师了」，则门槛火焰对那句话做出回应，火焰底色从金黑变为更纯的神王金。
- 若林恩选择以一只脚先试探性跨过门槛再撤回来反复三次，则他在跨门槛前熟练了回归路径，但门槛被反复触发，火焰即将熄灭的速度加快。
- 若林恩主动让梦境黑夜城某位幸存者影像陪他站在门槛前，则影像在门槛火焰照耀下消散，但消散瞬间把一段能量回馈给林恩。
- 若林恩把感知压在门槛背后羽毛笔微弱气息的坐标方向而不是门的中心，则他在跨入无序大梦时直接被羽毛笔的命运线接住，不在门口迷路。
- 若林恩主动在门槛前刻下一句他想对下一个自己说的话，则那句话被烙在门槛边缘，他在更深的梦境迷失时能偶尔摸到。
- 若林恩选择把对艾雯爵士的道歉改写成一串祷告按进门槛火焰，则火焰的温度从烙骨转为抚心，林恩进入无序大梦时的初始心态更平。
- 若林恩让王座的某段存档提前打开供门槛火焰读取，则火焰识别出他此前的所有选择路径，门槛对他的接受度比预期更高。
- 若林恩主动问火焰「我能否用她们的名字替代我自己的名字作为钥匙」，则火焰沉默数秒后给出一个折衷：每个名字抵扣一份火焰的燃烧。
- 若林恩在门槛火焰即将熄灭之际主动把自己一段血液撒到火焰根部，则火焰回光返照一轮，但那一段血从他体内永远失去。
- 若林恩在门槛前主动把一份同级秩序元素预先交给羽毛笔作为接应物，则羽毛笔在时间外可以用这份元素在他跨入无序大梦时精准定位他。
- 若林恩选择先进入羽毛笔气息所在的侧路再折返到门槛中心，则他在门槛之外就多一层羽毛笔视野，但羽毛笔因此多承受一段时间反噬。
- 若林恩主动在门槛火焰里烧掉一段有关某位死者的愤怒，则火焰换得一缕更纯净的燃料，但那位死者的影子从此在他回忆中失去锋刃。
- 若林恩让梦境中残留的织梦影像陪他共同识别门槛边缘的无序与秩序张力，则他在跨入无序大梦时多一副梦境感知器官。
- 若林恩主动在门槛火焰中保留一缕交给羽毛笔的火种，则羽毛笔获得一缕可在最困难时刻反向把林恩从黑河拽回的应急信号。
- 若林恩选择跨门槛时不闭眼而是保持目光注视火焰根部，则他得以在火焰将熄未熄的瞬间锁定火焰本源，跨过门槛时黑火得以保留最完整的轮廓。
- 若林恩在跨门槛前主动把自己的黑火调成一种沉稳的低浓度，则他进入无序大梦时不被潮涌的无序推着乱撞，但反应速度减半。
- 若林恩让门槛火焰识别并接受一份他与小小共同记忆作为入门信，则火焰允许林恩携带一段人性重量进入无序大梦，那段重量不会被拆解。
- 若林恩主动在门槛火焰附近刻下「敬明天」三字作为再次确认，则他把普通人的敬酒词升格为他跨越法师门槛的密令，加持了他对内在秩序的把握。
- 若林恩在门槛前主动问火焰一个「如果我失败会怎样」的问题，则火焰给出一个诚实的答案，林恩跨过门槛时带着双重清醒，无效恐惧被剪除。
