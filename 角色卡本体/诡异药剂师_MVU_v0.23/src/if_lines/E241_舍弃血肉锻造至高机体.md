# E241·舍弃血肉锻造至高机体·if线

- 若林恩在点明"血肉苦弱"之前先用一根灰烬组成的手指碰了碰弥赛亚的手背，则她后续的崩溃大哭多一道"被承诺过"的安定，"你说什么我都听你的"成为她被安抚之后的主动选择。
- 若林恩把蓝图的排列从"赛博→智械→利维坦"改为"智械→利维坦→赛博"，则至高的"灵能处理器"部位被延后，机体具备更高的物理硬度但延迟了"心胜万物"的可能性。
- 若林恩在锻造过程中让利维坦血肉碎片仅剩一小块绑作"血肉的觉悟"放在锻造台旁，则至高的物理属性-3%、但他在精神上多出一条"我曾经用过的路"的心灵标记。
- 若林恩让弥赛亚以神圣力量灌注整个锻造仪式分担反噬，则她的天使血脉被这种"残火燃烧"消耗掉一半，事件以变形（天使血脉稀释）收束，后续E267她在地下大殿里战斗力下降。
- 若林恩把机体的双眼殖装成左左重复视角、两个"眼睛"，则他一整段时间里都听到"机械的左左碎碎念"，事件以变形（左左仍在体内）收束，但左左的回归不再独立。
- 若林恩让巨像之心承担心灵的任务而不是机体动力的任务，则他的战斗能力集中在"灵魂燃烧"上，灵能处理器的强度廉价化，事件以变形（心灵代替动力）收束。
- 若林恩在锻造台上一笔一笔刻画左左的姓名，则后续她自愿回到左手位置的速度提升，"她回家"的仪式感在机体上被携带。
- 若林恩让弥赛亚在锻造途中被精神勾结直接拖到烈焰里亲眼看到蓝图进入火焰，则她被烧掉一条手臂，事件以变形（牺牲一条手臂换锻造）收束，但林恩多出一块"柔角色的焚烧"记忆。
- 若林恩在锻造中途放弃一半计划、以"血肉苦弱但仍有出路"为由恢复原血肉，则血肉支配者的权柄并未失效，事件以变形（双重换取）收束。
- 若林恩在锻造成功之后立刻将自己主动"杀"一次测试机体的复活能力，则他发现"心灵分流"反向阻抗，他的原始灵魂永远报废，事件以变形（灵魂损耗定型）收束。
- 若林恩让弥赛亚在燃烧的画面里说出"我想再叫你一声林恩先生"之后才开始锻造，则机体第一件成型的装备带有她的祈祷烙印，事件以变形（机体略带圣光）收束，但至高的冷科技感因此而削弱。
- 若林恩把至高机体拆解再重组两次以获得"全新的机动性"，则每重组一次弥赛亚就受一次情感颠覆，事件以变形（造型反复让弥赛亚疲惫）收束。
