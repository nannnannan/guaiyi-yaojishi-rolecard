# E579·时间入侵与血月循环·if线

- 若林恩拒绝闭合第一裂隙任其蔓延，则第二裂隙与黑甲毁灭戏提前，但「整城毁灭→血月重置」之核事实仍立，事件以恶化分支收束。
- 若林恩重置后拒绝入城只外围观察，则接引记忆与战术差异仍可立，但二次循环双方保留记忆的确认由他单方面记录，不入城则弑莉叶指控线全断。
- 若林恩在敌我迟滞初现时主动卧倒贴近一具天使尸体对口型套话，则守军记忆残留的确认更早，但左左目睹他会揪头发把他拖起来。
- 若林恩在面具滚烫警报时立刻切换至系统商城查询「时光涟漪抗性」，则商城无对应货但历史记录中跳出他曾以类似仪器挡过一次时间系冲击。
- 若林恩在示警时把「时光外污染者」替换为「它们不属于这个时间」，则左左和艾维儿同时懂，守军天使却因无法理解而进一步混乱。
- 若林恩在蓝龙载飞掷他向裂隙时大喊「轻点扔」，则艾维儿在空中翻白眼但扔掷轨迹精准度提升，呕出初诞者之力的临界窗口长半秒。
- 若林恩在闭隙成功时以右手对湮灭中的大魔比中指，则大魔化灰瞬间它的眼孔对过来一瞬，死前的恨意标签被系统录入。
- 若林恩在黑甲身影投枪瞬间尝试用三叉戟拦截，则两者碰撞被强行弹开，黑枪仍贯穿城堡，但林恩的手臂因对击晋升一道光痕。
- 若林恩在血月红光爆发前主动把左左死死抱在怀里并用翅膀把她遮住，则左左苏醒后从他翅膀缝里钻出，第一句话是「你刚才是不是抱我特别紧」。
- 若林恩苏醒后不先喊艾维儿而是先喊主母，则自缚天使的应答更快，但她同时发现林恩在寻找她们时自己位置最前，愧疚线再加一层。
- 若林恩在观测到骸骨龙逃窜时主动大笑「它们记得我的龙息」，则守军天使听见后禀报弑莉叶，她在下一轮欢迎中多说一句「王女的伴者亦是传奇」。
- 若林恩入城时主动向接引天使询问「你们记得几轮」，则接引天使面露茫然回答「不下数百」，循环惨烈程度被他用一句话拉到明面。
- 若林恩在被接引的路上主动问左左「如果我被重置掉你会记得吗」，则左左在他手背上狠狠咬出牙印，「笨蛋，左左会把你从结局里拉出来」。
- 若林恩对主母说「无论第几次，我的脸你总会找到」，则自缚天使在循环中的目标被锁定为寻找与确认，她的定位技能在残余意识里被无意识强化。
- 若林恩在二次循环骨龙改战术时主动反向冲到前线硬撼，则骨龙逃窜速度更快，但林恩被反推撞回城墙，王女护卫队提前对他产生「也是怪物」的印象。
