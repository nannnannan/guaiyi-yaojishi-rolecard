# E369·六根源降临黑堡·if线

- 若林恩在巨像肩头主动压住想吐的冲动摆出冷脸，则人偶夫人和苍玄月会注意到他神情过度刚毅反显生涩，对他的判断反向松弛一档。
- 若林恩主动让巨像之心在出场瞬间轻轻跳动一次，则黑堡外围花卉结界会因这一心跳产生一丝微弱共振，人偶夫人能多得到一条「来者即为王后心上人」的物证。
- 若林恩主动在巨门撑开时把一根初诞者黄沙塞入门外流间，则门产生的空间乱流将出现一线暂时稳定的通路，巨像之脑在网络里多一个可用于后续穿行的样本。
- 若林恩在泰坦暴起要毁门瞬间主动贴到他耳边低声一句「她的妹妹在里面」，则泰坦的头颅会瞬间停止动作，主动让自己的触手撑门更稳，巫神和小小同时松一口气。
- 若林恩主动站在巨像肩头对黑堡喊出「我带血信来不是带战书来」，则黑堡女主人的嗓音多了一线迟疑的回音，结界防御打开速度降低一成。
- 若林恩主动让巨像之脑把一段「王后排面」用文字投影在巨门上，则整个人偶家以最高级别整顿欢迎仪式，苍玄月主动率城堡高阶人偶出门列队。
- 若林恩在黑堡开口说「我虽然带了几个根源但我并没有恶意」时再补一句「我有理由相伴而来」，则人偶夫人会多得到一份分承诺的余地，她同意接见阵容外加一部分前提。
- 若林恩主动要求「我必须和她签订无害化协议」，则人偶夫人现场立起半个「无害化」誓言树结出来一份简单的「不伤人」文书，林恩与黑堡遗址之间的关系登记非正式发生变化。
- 若林恩在艾雯的灵能巨人被黑堡第一道防御反杀时主动调集初诞者气息加入他的护罩，则艾雯的黑壳变得坚硬，巨像之脑的动作同时也就顺位衔接。
- 若林恩主动直接把黑弦月与黑堡女主人身份并列描述「她是她最亲密的学生」，则苍玄月的警惕能降至冰山之下，不至于当场翻脸威胁。
- 若林恩在艾雯试入魔法网络查看黑堡防御时主动以巨像之心共振跟随一同扫描，则他能获取更完整的防御数据但同时也暴露巨像心脏对黑堡之「反感」。
- 若林恩主动当众对泰坦怒吼「先让我说完了你再吃东西」，则泰坦的头颅会故意把吃掉的东西还原回来，小小紧随其后哑然失笑，主母被这一出逗得笑出声。
- 若林恩在巨像之脑出言「你还在乎这个？」时被巫神插嘴一句「这是大哥的毛病」，则巫神反过来在人偶家暴露了林恩的真面目，后续交涉需半个弯。
- 若林恩在结界外一公里主动举一个【疫医武器警告】旗帜当信号示意，则他能提醒黑堡是「非威胁级来访者」但同时，会留下一份可被反侦察的痕迹。
- 若林恩主动把讨伐者之首的大脑筒皮抛到黑堡外以示战结休战，则黑堡会非常紧张地启动最高警戒，但人偶姐妹也会对他无可奈何做出一个被迫让步。
- 若林恩主动公开自己曾与黑弦月私下相处的某一细节，则人偶家对他的身份与诚信评估会提高一成但也会对他的来意猜测更奇怪。
- 若林恩主动替黑堡外围收集一批最近发现的病变样本作为赠礼，则他能换来黑堡女主人更公正的待遇但黑堡保留权对样本是否接受。
- 若林恩主动让随从以艾雯为首的智械系先行展开全面侦察，则他能看到黑堡方的布防核心但黑堡的人偶家也会以「侦察即敌意」作为回应。
- 若林恩主动对结界外围地脉做轻微的初诞者气息净化，则黑堡附近的「生死轮转」能量波动将停下一段时期，人偶家会当场对他产生「他是敌人或盟友？」两极反差。
- 若林恩主动对巨像之脑说「你要进去吗」，则她会沉默一会摇头「在这里适合减轻感情压力」，但被邀请的信任+1。
- 若林恩主动在巨门撑开时以身先士卒修正入口方向的乱流，则他能让巨像之心剧烈阵痛代价小，但接下来几个根源都可以平稳登上黑堡。
- 若林恩主动在结界外先移交一件他从不离身的旧物给黑堡守卫作为信任信物，则人偶夫人的姐姐苍玄月将手动因信物存在了某种「联系」。
