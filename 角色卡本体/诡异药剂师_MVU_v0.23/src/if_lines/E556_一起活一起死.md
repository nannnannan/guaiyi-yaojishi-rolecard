# E556·一起活一起死·if线

- 若林恩在小小主动要结婚后立刻答应并举起小小在广场宣布「事已定了」，则婚礼在战前成为被普遍认可的定局，小小尚未理解的生死重担被将近扛肩，「等战毕由小小亲口决定」的窗口关闭。
- 若林恩在自缚天使和艾雯以笑遮泪式起哄「结了就别死」时主动回敬一句「我怕的是你们死」，则「怕你们」的独白由埋脸私密收听升级为广场台词，家人共听战前恐惧。
- 若林恩在埋脸只给自己听那句独白结束时起身消失在广场、不再回应起哄，则家人们只看见一个硬撑的黑袍，林恩的脆弱被收拢回他自己，共活共死的语境延后。
- 若林恩在放一天假之外主动延长到两天并推迟神灵建军后续督察，则军团日常与艾雯/智械的甩事被打入积压，后续他要为这两天付出更多工作时间。
- 若林恩在与小小游玩过程中特别付出旺盛的精力陪伴，则小小「还年轻、想长大、想到处玩耍」的需求被分配得更多，他们相处的时间维持度增加。
- 若林恩在游玩时只顺着小小的步伐游玩、不主动再延展任何动作，则陪伴密度低一档，小小对他记忆的厚度微弱一些，「医生哥哥陪她玩」的印象更稀薄。
- 若林恩在小小问「哥哥会有很多的小妻子吗？」时不厚颜扯称呼而是直接坦白自己跟小小不会有那种事，则小女孩获得清晰的婚姻边界，「全家式结婚的童言」被林恩本人端走。
- 若林恩在小小主动要结婚时反问小小「你知道结婚要花多久时间吗？」，则小女孩被迫思考比「永远在一起」更具体的现实，童稚愿望被加上时间轴的考验。
- 若林恩让孽主在女王维护时同时拿着爆栗督学去给小小补课，则小小的玩耍档期被细节织入作业表，她与哥哥独处的时光被切去一块。
- 若林恩主动待小小去母树旁等待一会儿，则小小在林恩不再相应时更能分辨「哥哥也离开」，她对他的挂念从被动挂到主动。
- 若林恩在小小问「你想变回和我说话吗？」时不立刻启光照耀而是先问小小「你确定要承担吗」，则小女孩在神迹前先过一道自主的判断门槛，还原是她本人的选择而不是哥哥安排。
- 若林恩在小小短暂还原时当场弯下腰抱着她并把头贴一帖她的额头，则短暂清醒被哥哥情感放大，小小在纯粹时光的最后一秒存储了更多勇气。
- 若林恩在小小短暂还原后不多作叮嘱、只仰望黑夜城塔尖良久，则这场还原被她哥哥的沉默封存，「请你不要死」的话语缺一根听感接收器。
- 若林恩在小小短暂还原期间主动检查她的诅咒深度，则这一笔被登入他后续要跟着小小学到「不能压掉」的负担，还原后少女们出征路线之间少了一根隐形钉。
- 若林恩在小小哭求勿去外面时主动说出自己的恐惧「我也怕我自己死掉」，则小女孩在童稚心情里被额外点出哥哥的脆弱，「我不要哥哥死」的决心更强烈。
- 若林恩在小小哭求勿去外面时不直面她的眼睛，只低眉道「我会回来」，则小小从一句模糊的承诺里获得慰借，但那句承诺的厚度未真正进入孩子的内面。
- 若林恩主动承认「我害怕你们死掉」在拥抱小小时也向全员外展，则「怕你们死」不再只是哥哥内向的独白，家人们在场都能感受到同频的压力。
- 若林恩对左左和巨像之脑追问多妻妄想主动灭场，则「小妻子」一词被从对话中拔去，小小领悟到哥哥的关怀而不是哥哥自己的喜剧轨。
- 若林恩在小小问「我不想长大」时直接回答「那就不必长大，永远当小小」，则小女孩的童貌被确立成不需负担的安宁，「回主宇宙后再长大」的后端可能性被剪掉。
- 若林恩在小小哭求勿去外面时主动不改装睡而是直视她幼小的心让小小看见哥哥的坚决，则小女孩被手掌按在真情的正面，安抚在深度上却并非高兴的安抚。
- 若林恩在北海之约钓鱼时只望向鱼漂而不作缚涩遐想，则小小从玩闹里感受到的是纯净的游乐，戏场上的捉虾场所不作成人化暗示。
- 若林恩在小小变回触手头颅后不立刻被舔脸亲昵而主动避开她的唇，则「舔脸」这一喜剧惯例在林恩的坚持下不被复读，幼态亲昵的界线被更严地划分。
- 若林恩在北海之约口里答应「不死不死」但眼里没望小小，则小女孩从虚假的点头里获得安慰，她也更清蕓这是哥哥的真心信息而不是合力走出她的害怕。
- 若林恩在小小变回触手头颅后邀请「要不要玩一个攀岩游戏」，则小女孩从游戏乐趣中获得好转，她在哥哥身上寄托的稳重在他的游戏当中表现得逼真。
- 若林恩主动承诺小小「我会回家」在耳边以全句子并落下此次的承诺，则小女孩从一句定夺里得到生命历程的提示，她在过程中不断悟到出发点。
- 若林恩在小小哭抱他的瞬间把她抱到肩头沿北海散步，则她从哥哥肩上一起看见整个黑夜城灯火，童稚的害怕在景色里先稀释一道，共活共死的基调被调整成纯净的鼻腔。
- 若林恩在睡梦中搂着小小不说话直到天亮，则小女孩在哥哥温度里彻夜无惊，醒转之后她自己记得昨晚他们靠近过、但还能担当自己还是自己的女孩。
