# E649·真理神王一掌与傀儡疑云·if线

- 若林恩没有正面迎击而是当场折跃逃走，则金色少年不会看到「硬接后逃走」那一幕，一米钳制的异常被推后到下一次近身遭遇时再现。
- 若林恩在迎击中真的被神王的力量当场压碎，则事件以取消收束：左眼所见、左左的哭喊、收网令与傀儡疑云都不会成立，主体生死悬置。
- 若林恩迎击瞬间催动白烬全力倾在罪火之上，则一拳抵消得更彻底、他付出的代价更轻，但金色少年会立刻判定他的极限、之后出手直接拔高三档。
- 若林恩在三叉戟收回前朝斧神再补一拳，则那两位上位神真死，但金色少年少了两个废物当作垫脚石，他对局势的评估更冷静、出拳更纯粹。
- 若林恩不接那一击而朝旁闪，则那一掌砸在无序生灵身上，那具庞大生灵会受创挺立，金色少年会先回头镇压它再追林恩，迷雾扩张短时停滞。
- 若林恩在折跃前朝金色少年咧嘴一笑并比出拇指朝下，则神王冰冷的眼神会更凝一分，他下颌微抬，把林恩的威胁级别再上调半档。
- 若林恩以心声对左左说「不许哭，护着我」再昏迷，则她会把所有情绪压到指节、拼命动用初诞者之力续住他的命脉，她昏倒的时间比他更晚。
- 若林恩在折跃落地瞬间强行保留一缕意识不让自己完全昏迷，则他能亲耳听见左左的哭骂，但初诞者之力的自愈速度会因此慢半拍。
- 若林恩在疼痛顶点用一缕残识反向推衍「这一掌为什么带着工具感」，则他能捕捉到真理法则中那道极细的滞涩，傀儡线索更早一步在他识海里成形。
- 若林恩迎击时以初诞者之力作楔在硬接那一掌的同时反向感应，则他能感知到对手法则脉动的奇怪节律，身体上多一道金色灼伤、不解于是谁的手笔。
- 若林恩主动让斧神与黑发女子的尸体在自己撤离后坠向无序生灵，则那位四具神嗣中被钉死者会躁动半拍，金色少年会将被钉者锁进无序领域深葬，尸体不能回收。
- 若林恩在昏迷中无意唤出左左，则她会以戾气全开的形态将他护在身后，整个幽冥海外围的无序生灵都会感知到这份战意，遁形远远避开。
- 若林恩让左左把他的痛楚引向自己，则她能替他分担三成剧痛，但她的指尖会持续苍白、日后握夜魔刀的稳定性下降一格。
- 若林恩在睁眼之后第一句话只是「水」，则左左会愣上一秒才敢哭出声，她把水喂给他的手一直在抖，那一夜没人再提真理神王。
- 若林恩在恢复原气前用心声向系统商城换一瓶「回春露」，则商城会以时空差交付并附一条「神王位阶以下使用有效」备注，但因他已是神王位阶，效果只剩安慰。
- 若林恩醒来后故意向左左隐瞒两条对金色少年的疑点，则她会更早一步问出真理法则那件工具，她会带着怀疑在意识里替他列出一张潜台词。
- 若林恩在重伤期间尝试用梦境领域覆盖自己的伤，则创伤会被锁进涟漪中不再扩大，但他的意识会持续在第二层疼痛里，梦境很容易被他自己扯碎。
- 若林恩在胸口最后一缕罪火熄灭后告诉左左「还活着」，则她会一口咬破手指涂在夜魔刀上，那把刀在 E651 断裂前会多一道隐隐的发光。
- 若林恩向左左坦承「我对那位金色少年有一种很不对劲的感觉」，则她会停下来想了整整五秒，只说一句「那就别再硬接」。
- 若林恩先赶回深渊而不继续留在迷雾海域附近，则变形：金色少年在收网时会扑空，傀儡疑云继续留存，但林恩在 E650 的伏击阵地要重新选址。
