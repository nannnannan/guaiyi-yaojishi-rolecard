# E161·尹依身世与死界恶鬼辨认·if线

- 若林恩在唤魂曲响起前就通过咒瞳遥控把仓库摄像头改回直播链路，则神教留下的预设录像被临阵刷掉，缝合尸体的「舞台出口」第一次失控，事件以变形（神教录像干扰成立）收束。
- 若林恩在内应举枪瞬间用咒术远程把枪口挪偏半寸，则子弹贯穿尹琴肩膀而非头部，事件以变形（枪伤转移到肩位）收束，尹依保魂窗口多出一线。
- 若林恩让左左隔空扑到尹琴胸前、用小手压住她后脑的弹孔，则创口大出血被临时锁止，事件以不变形收束但左左以最低限度与尹依首次见面。
- 若林恩用咒术远程把尹琴周身覆上一层极薄冰霜减缓失血，则她被转移到古井时还能保持一丝清明，事件以变形（尹琴短暂苏醒）收束。
- 若林恩在唤魂曲开始前让左左先替尹琴挡一次死亡谶言，则当尸块开口报出多个姓名时尹琴没有因此动容、声音稳定三倍，事件以不变形收束但尹琴形象被拔高。
- 若林恩主动远程告诉白逸「把你那台义体感应器先按一下关机键」，则那句「笨蛋——射她啊」的电子音没有响起，事件以变形（感应器哑火）收束，内应延迟暴露一拍。
- 若林恩让咒术改写尸块的「报姓名」节奏，把「卡林、张严陵、白」压缩成单一姓名，则尸块供词首次失去艺术化手法，事件以变形（聚魂合唱被打散）收束。
- 若林恩在尹依开口坦白双胞胎身世时让左左隔空在她耳边轻唤一声「妹妹」，则尹依全身阴气一震、顿住半秒才继续，事件以不变形收束但尹依第一次被外人以「妹妹」称呼。
- 若林恩主动给尹依塞一支阴气补充药剂通过锁链倒灌，则她持续保魂时间被延长一段，事件以不变形收束但保魂资源窗口被推后。
- 若林恩在尹依请白逸召唤大哥时用咒术把她的恳求原样转录到黑夜城状态栏，则这一行字第一次直接砸进玩家视野，响应窗口被强行前置。
- 若林恩主动请尹依当面念出红衣恶鬼的神教代号「暴怒」，则咒术捕捉到「暴怒」一音里的低频神韵，事件以不变形收束但红衣恶鬼的代号首次被她亲口述出。
- 若林恩远程反向把仓库外侧阴气抽走一缕让尸块躁动，则尸块被迫提前狞笑供出神教利用聚魂陷阱，事件以变形（神教口供前置）收束。
- 若林恩在尹琴开始唤魂曲第一句时用咒瞳唱反调为她伴奏，则尹琴眉头只抖了一下没有被打断，事件以不变形收束但唤魂曲在林恩面板中留下完整副本。
- 若林恩主动让左左从内应出手一秒前就钻进他后颈皮肤搅局，则他的扣扳机动作被一秒迟疑替代，事件以变形（枪击被偏）收束。
- 若林恩主动把仓库天花板倒悬亡魂的画面反向灌送给左左的意识，则她在事件中第一次体验「被恶灵围观」的恶心感，绑定关系多一条心理记录。
- 若林恩主动让咒术让尸块打不开那张「笑声」，改给他装上系统提示音效，则尸块狞笑被替换成机械女声「仪式进行得很顺利」，事件以不变形收束但神教舞台感被进一步剥夺。
- 若林恩主动让尹依与白逸先听一句他的远程咒术回应「你姐姐交给我」，则尹依的阴气自此向「守」而非「冲」扭转，事件以变形（尹依进入求援姿态）收束。
- 若林恩全程不介入、让白逸府渴渠按原作完成召唤，则默认走向收束，尹依以自身为祭品换取林恩部分降临的窗口。
