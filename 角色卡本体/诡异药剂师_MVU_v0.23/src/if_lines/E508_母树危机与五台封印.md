# E508·母树危机与五台封印·if线

- 若林恩在跃出界门之前先朝城上方向掷一支夜医应急血包，则警报锁定节拍提前，「反应还真快」一句从他嘴里先落到守卫耳里，地下圣堂合围队形由守转攻。
- 若林恩落地时直接拽住主母袖口让她压低剑势半度，则金剑不再笔直贯堂而是斜着切入地下，欲望母树园圃的园土多保一层，幼苗根须保住一缕。
- 若林恩没有先大喝「主母！！」而是改叫艾雯大哥先拆圣堂屋顶，则心灵巨人更早暴露在外，以太的逃脱窗口从地下转到半空，「恬噪」风暴扫向更高处，伤亡转嫁到城墙一侧。
- 若林恩让小丑在八音盒响起之前先抛出一段反向的混乱韵律，则欲望母树的动乱起步多一拍错位，黑线枷锁的根数减少，他夺控时树干便不再那么听话地抽出。
- 若林恩在人偶家拉以太上地面瞬间主动让左左从左手掌心探出一截血肉触手扣住他脚踝，则原子风暴化形那一刻多一道滞留帧，他纳米化摆脱枷锁的时机被推迟半秒。
- 若林恩夺走母树控制权后不立即抽树干而是先把根须缠回园圃，则以太切割动乱树干时切断的是空枝，幼苗本体留在园圃中不露，「你是我的了」的宣告直接作废。
- 若林恩在以太宣称「我就已无处不在」那一刻反向让银色幻想先扫描全城原子机械共振基频，则她能提前一步把西部坐标压到三位数，界门远征不必再借失联原子机械做引信。
- 若林恩拒绝让银幻接入失联原子机械做格式塔定位，改由他用咒瞳对苍银流体做反向追踪，则他可凭初诞者之力黑线感应到核心方向，但每一次开合咒瞳都会多一缕由以太反向烧进来的回路。
- 若林恩让船长在心灵之海截击时把灵魂火焰汇成一枚巨型船锚而非整船撞向裂隙，则心灵底域时间膨胀依旧出现，死亡之船不必整艘坠入，主母等人免一次灵魂压载。
- 若林恩在五台启动前主动掷骰把「吸噬范围限定城周三公里内」写给小眼萝，则巨构矩阵无法扩散到城外苍银浪潮，城周剥离彻底但城外原子机械得以逃散重整。
- 若林恩把五台的吸噬功率强行再抬一档，则城周剥离加速三成，但他的初诞者之力储备当场见底，「光门闭合」后他在界门远征开拔前先昏迷半刻。
- 若林恩让艾泽法拉在城周裂缝里铺蚀痕但不准其追入界门，则她留下的蚀痕只够稳住城周裂口不动荡，无法随队远征，西部巢穴一战中蚀痕缺席，巨构少一道分散锁链的借力。
- 若林恩命令银色幻想在数据升华后顺路把以太残留水银残影也吞入机体，则她本体内多一条由以太分裂出的敌意子线程，「我只听你的」的笃定度被搅乱一拍。
- 若林恩在远征界门开拔前犹豫并向主母请求由她先过去查探，则时间差让以太抢先完成本体转移，西部坐标失效，五台再次扫过黑雾将只会标出一片死寂空壳。
- 若林恩拒绝致歉担责并改口强调「这是我私事不需要你们一起」，则远征队的合力灌门环节缩水一半，「遮天巨门」从足以横贯百万公里掉到只能半途坠落，船板被撕掉一层。
- 若林恩让黑弦月的灵魂丝线缠在死亡之船的桅杆上做反侦测支座，则船长入心灵之海时被以太意识网探到的概率腰斩，「他的气息被遮蔽」局面逆转。
- 若林恩在以太吞噬幼苗瞬间直接把自己的初诞者火气作一缕追打引信夹进流体，则他后续感应核心的精度翻倍，但他自己眉心多一道由以太反向烧进去的反击记录。
- 若林恩让大头娃娃小小在城头举鸭舌帽指挥夜医火线清空广场，则地下圣堂合围反应快一拍，「最多攻略」的诅咒覆盖面积从地下层向半空漫延。
- 若林恩让左左坐在他肩上不能屏息旁观，则她在母树藤蔓暴动那一刻首次直接接触诅咒枷锁活性形态，绑定关系多一笔「见证主人逆罚」的沉默注脚。
- 若林恩决定在五台启动前留一台不启，则城周剥离出现一道真空窗，以太凭此缺口把一缕流体甩入城外黑雾备用，「无处不在」宣告提前立根。
- 若林恩在心灵之海时间膨胀段主动释放全面动乱加初诞者加护，则船头曲率通道多一道清醒爆辉，「撞穿现实与心灵界限」的一刻由免费代价换作他灵魂再压三成。
