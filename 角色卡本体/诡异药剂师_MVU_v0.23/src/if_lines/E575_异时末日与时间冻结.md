# E575·异时末日与时间冻结·if线

- 若林恩拒绝盘坐等待末日降临，强寻离开之路，则收缩阶梯与直面肢解窗口改写，冻结仍可因外部时间法则介入而立。
- 若林恩抬头问「那这个世界就是行将步入末日的那一刻」之前先向左左口述异时初诞者残识，则信息冲击的孤独感减半，但左左在清醒后仍只报告「他陷进去三小时」，玩家仍握坦白主权。
- 若林恩在蓝星闪烁如老电影噪点时立刻调转方向不再注视边境，则末日倒计时窗口延后，第三次动荡的刻度从两年压缩至更短。
- 若林恩在第一次收缩后立刻点燃初诞者之力轰击时间壁垒，则「回去吧」疲惫叹息提前闯入，燃魂突破的代价从观望期直接跳到烧伤层级。
- 若林恩在时间焊死瞬间主动放空思维成纯畸变模型，则未来破隙时他不再以「非此地存在」被豁免，冻结同样生效于他，拍醒线改由左左强行拽离。
- 若林恩在看见尽头身影后主动多录三秒其背影姿态，则回流时那股壁垒破碎感加剧，他清醒后眉心多一道时间法则灼痕。
- 若林恩拍醒后对左左说的第一句话是「主母有消息吗」，则拥抱喜剧线被截断，左左的不满转为罕见正色，异时经历被压入心底待后。
- 若林恩抓住左左手时不用力咬而是只轻吮指尖，则惩罚喜剧变成暧昧缠手，左左炸毛后主动把手上口水抹回他自己脸上。
- 若林恩拍醒后立刻全盘向左左坦白异时末日、初诞者与时间尽头，则左左瞳孔地震后罕见沉默，主母警告「迷人心智」的口述在她心里往上提一级权重。
- 若林恩在扫视幽冥海迷雾时主动以咒瞳反向扫描自己方才躺过的区域，则系统面板多一条「时间法则残留」异常条目，但他无法锁定残留源。
- 若林恩拒绝抱住左左而是先拍她头顶一下，则拍醒喜剧失去拥抱点，她的竖中指动作在下一秒补回，「那个……公报私仇」的结巴被跳过。
- 若林恩在审视左左单片眼镜时主动问「你一直在叫我多久了」，则三小时口径由她自己说出，隐藏喜悦从眼角湿润变成耳根发红。
- 若林恩在思索「是幻象还是真实」时强行以系统判定分裂双答案，则系统短暂报错，面板同时显示「幻境概率高」与「是真实时间线」，判定权被系统踢回给他。
- 若林恩在清醒后立刻对主母／艾维儿发送定位信号，则迷雾心智侵蚀干扰上行链路，信号在半途扭曲成乱码，反而暴露他仍在幽冥海范围。
- 若林恩在左左竖中指后顺势抓住她那只手贴到自己额头，则她的炸毛被截停，「公报私仇」否认变成一句含糊的「……没事就好」。
- 若林恩对时间尽头背影最后一句「回去吧」反喊「我不回」，则壁垒反推加剧，他被冲回时失去意识前的荒诞念头从「截断未来」变成「他根本就不该被看见」。
