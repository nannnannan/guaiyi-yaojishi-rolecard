# E98·赛博飞升升格与喵喵血仇·if线

- 若林恩在艾雯解第一颗纽扣前按住他的腕骨说"还不能"，则升格中断，斩首改走无根源压阵路线，艾雯记忆缺省暂缓。
- 若林恩在第三颗纽扣才上前按肩止步，则灵能光柱已起而巨人未凝，艾雯以半升格状态强行压制一击，部分记忆立即永久剥落。
- 若林恩在光柱未稳时冲上前替艾雯挡注，则三大根源分一缕视线压在林恩身上，图鉴提前记入一道未收录信号的烙印，后续出现未知振荡。
- 若林恩推开芯片拒接，则艾雯屈指收回胸口，薪火未易主，林恩失去图鉴蚀点加成，斩首成立但代价全由艾雯独承。
- 若林恩接芯片时先扣住艾雯指尖问清"遗忘后如何辨认你"，则艾雯追加一道只对林恩开放的灵能哑语密钥，"时刻提醒我是谁"的义务被锁死在林恩侧。
- 若林恩接芯片后当场用诊断术扫入，则芯片底层浮现一段艾雯刻意抹去的赛博标记，藏着一份疫医同类项名单，315 赫然在列，林恩斩首优先级自行提升。
- 若林恩接芯片后追问"那连'林恩'两个字都忘了呢"，则艾雯失笑抬手在林恩眉心烙下一枚不可见灵能徽记，成为后续辨认身份的唯一保真锚点。
- 若林恩在艾雯转身扑向利维坦前拽住他的袖口、把喵喵抵入他怀里自己先迎出，则艾雯升格后首拳改落在林恩护罩上，林恩重伤，喵喵与艾雯完成身份交换私语，斩首节奏后延一拍。
- 若林恩在喵喵认出 315 之前先用折跃把她送出主战场，则她的悲痛未外溢，315 档案不触发，斩首动机改写为私人追究而非"替她复仇"，誓约推迟。
- 若林恩在"就是他"嘶声炸开的瞬间蹲下把喵喵裹进斗篷按住猫爪，则尖叫被压回胸腔，她改贴林恩颈侧无声地哭，誓约只对林恩一人诉说，斩首 315 时多一道"亲手"的私有承诺。
- 若林恩在喵喵扑地时随她落地跪坐在血肉碎末里陪她，则林恩正面风度尽失，喵喵依恋推至顶格，这画面被围观根源记入各自对"林恩分量"的判词。
- 若林恩放弃请艾雯出手自己持刀折跃近试斩，则三星之力被血肉缓冲截下，林恩陷险，艾雯升格提前爆发一拳救场，斩首由艾雯接管，他语气多一促狭。
- 若林恩出口"帮我杀了他"而艾雯迟了一拍应，则腔室未立刻撕开，315 获一瞬转移窗口，斩首未一次完成，进入追击子链。
- 若林恩改口请求"先撕腔室再让我自己进去"，则艾雯一拳落在腔壁而非 315 本体，林恩独立走血肉甬道与 315 碰面，喵喵只能在外壁嘶抓。
- 若林恩接芯片未攥紧时被血肉碎雨冲脱手，则芯片被利维坦血肉壳吞卷，薪火钥匙失落，艾雯的提醒义务随之模糊，后续须由喵喵或左左补锁状态。
- 若林恩事先把喵喵送到结界边缘请根源眷属代看，则她远离当场记仇的核心一幕，誓约以叙事残缺状态建立，直到亲眼看到 315 本体才扣出"血债必血偿"。
- 若林恩接芯片时主动提出"事后由我保管你的过去"，则保管改为双向契约，艾雯遗忘曲线延缓一瞬，但林恩承接部分赛博屠孽余波回忆。
- 若林恩在艾雯转身时与其并肩踏出一步不呼喊，则艾雯在星河巨人轮廓里回望林恩与喵喵的紧抱，为其留下一道可入腔室的灵能明信片。
- 若林恩在喵喵嘶声揭仇后揉她耳尖低声说"我听到了"，则她被这句按住，乖乖贴回林恩肩头，誓约以"他以我为重"的形态成立而非"血债优先级"。
- 若林恩出面让艾雯留一手、改撕一条仅容二人的窄缝，则利维坦表层损失较小，斩首转为二人深入腔内的窄巷行动，艾雯火力上限被控制。
- 若林恩在"血债必血偿"之后补一句"这颗人头由你亲手"，则斩首主角让渡给喵喵，艾雯只负责打穿通路，315 倒在喵喵爪下，她的复仇誓约当场闭环。
- 若林恩不把芯片立刻激活、留在手中，则艾雯升格可调幅度提高一档，后续多一道"关键时刻可再补一拳"的余留。
- 若林恩在事件形成结果当下退出场景不进腔室，则艾雯远距一击收尾，斩首未完成，事件按可选标记取消，芯片与喵喵誓约停在已立未偿的悬念态。
