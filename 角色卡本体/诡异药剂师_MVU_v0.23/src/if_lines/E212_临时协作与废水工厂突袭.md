# E212·临时协作与废水工厂突袭·if线

- 若林恩在钟塔十三声钟鸣前就让血娃娃撑伞升空在厂区屋顶嗅一口恶臭浓度，则她的「细小的触须和蠕动的脑子」陈述在他动手前已成作战备案，事件以不变形收束但血娃娃首次被纳入战术评估项。
- 若林恩踏入监控室前让左左用咒纹横扫走廊监控镜头，则教徒"敌袭"喊声被压晚十五秒，事件以不变形收束但走廊教徒被清掉时无一警报上达分部。
- 若林恩选择不"礼貌敲三下门"而是徒手掀翻监控室大门，则他在教徒脑海里"绅士恶魔"标签被换成"破门恶魔",事件以不变形收束但少了一段幽默节拍。
- 若林恩让左左先吃掉猩红高跟鞋里的厉鬼而非与血娃娃分食，则左左单独吸收第一波诅咒载体、咒纹边缘首次染上猩红，事件以不变形收束但她后期需主动消隐血味。
- 若林恩先把高跟鞋放在鼻尖轻嗅三秒判断鞋主的屠杀记录再丢给左左，则"鞋主侧证"首次进入他跨案件比对库，事件以不变形收束但厉鬼入腹时机比原作晚三分钟。
- 若林恩在捏碎首领心形吊坠前先把他按墙听他念完最后一句"血肉永恒",则首领的结束语被完整记下，事件以不变形收束但林恩染上"教条终结=生命终结"的现场记忆。
- 若林恩在首领供出"已散播一半"前先引爆剩余未开封容器，则时间窗往前拉一整天，事件以变形（资产销毁）收束但污水污染扩散风险反向上升。
- 若林恩让血娃娃不要亲手堵排污管而诱导她念出"暴食主人真名"用真名咒封管，则她首次在他面前承认自己的真名与职能，事件以恶堕调教收束，调教止于「承认位格」对她身位压低一档。
- 若林恩在她咧嘴喊"已经叛变组织了"瞬间一把捂嘴不让她出声，则首领没听清叛变宣言，事件以变形（封口）收束，他死前仍以为她只是被掳。
- 若林恩在扭断首领脖子的同时让触手在他胸前刻一行"血肉已被换主",则地下实验间的尸首成为下一波教徒的恐吓教材，事件以变形（阵营标记）收束。
- 若林恩在实验记录本上主动撕掉涉及灵肉绑定的章节交左左先背诵，则左左首次掌握"催化到一天"的硬知识，事件以不变形收束但完整册页数-3、隐修会取证链出现译文缺页。
- 若林恩让被抓无家者按伤势排成两列、亲手为最先能走动者披上外套，则他们首次重获"我是人"的尊严，事件以不变形收束但隐修会到场时最先问的不是"恶魔在哪"而是"疫医在哪"。
- 若林恩以疫医身份而非"地狱恶魔"自介进入实验间，则无家者恐慌线大幅下降，事件以变形（身份重置）收束但首领生前错把他当成政府派的外援，供词里多一份"内部清算"叙事。
- 若林恩让弥赛亚部队先行攻入监控室、他只在排污管口出手切断剩余容器，则功劳簿被分割两半，事件以变形（联合抓捕）收束，弥赛亚对"救人的恶魔"印象分+1。
- 若林恩在突袭期间把容器散发出的红雾用左左的咒纹当场净化，则污水系统污染未扩大，事件以变形（提前净化）收束但林恩SAN消耗跳一档。
- 若林恩把对血娃娃的承诺从"告诉我就不杀你"升档为"告诉我帮你找妈妈",则她的被动力从"活命"改写为"寻亲",事件以不变形收束但她自此挂在他身后不撤。
- 若林恩在突袭尾声让左左从首领尸体里拆出半枚未捏碎的心形吊坠自己带走，则林恩握住一条通往"血肉支配者"的可能通信物，事件以变形（器物截获）收束，与血娃娃的交涉筹码重新定价。
- 若林恩把被试者里那名还能说话的流浪汉单独带到工厂屋顶做深夜问诊，则运输路径更多细节曝光，事件以不变形收束但城南线索首次入档案。
- 若林恩当着血娃娃的面拆开教徒记录本让她在"暴食主人"名下签字，则她首次按笔按章承认"我替血肉神教打过工",事件以恶堕调教收束但调教停在签押责任链层、未触身体。
- 若林恩把血娃娃系在他触手末梢让她从排污管口往里探，则她以"暴食主人"身份首度被教徒当场认出，事件以不变形收束但她在教徒口中升级为"深渊叛徒"。
- 若林恩在撤离前一脚把实验间的天花板踢塌下来压住未开封容器，则污染源在工厂内被物理封存，事件以变形（封厂）收束但被试者救援通道临时塌陷。
- 若林恩不追击逃走的最高层而只把首领的脸用手机拍照发给超自然总局官方频道，则总局首次掌握该分部指挥面孔，事件以变形（公开通报）收束，林恩从"恶魔"被改写为"协助者"。
- 若林恩在血娃娃抓出最后一条幼虫时从她指尖抽一滴虫血留作样本，则他当场掌握原始毒株分离物，事件以不变形收束但她的"暴食主人"身份首次被刻入疫医档案。
- 若林恩在突袭中段让血娃娃短暂脱离战场让她去追一只逃逸的幼虫，则她以战斗姿态独立完成一次小型猎杀，事件以不变形收束但林恩首次允许她独立作战。
- 若林恩用左左的咒纹在被试者手腕写下"已治"两字而非移交隐修会记录，则他们能成为他后续回访的目标人群，事件以变形（私域接管）收束但隐修会档案缺一段数字。
- 若林恩让左左先吃掉首领的右耳作为"信任信号物"递给血娃娃，则她首次接过来自地狱侧的同盟证明，事件以恶堕调教收束但调教落在"信物承接"而非身体约束。
