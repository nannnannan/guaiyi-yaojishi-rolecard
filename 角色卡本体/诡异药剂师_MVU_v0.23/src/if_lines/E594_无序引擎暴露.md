# E594·无序引擎暴露·if线

- 若林恩在重伤大魔冲入走廊更深处时同步连上左左让她感应他节奏，则她会在意识里陪跑近半小时一语不发，事后她会以「陪你跑过」为一次小纪念。
- 若林恩允许在尾随途中主动向初诞者金光借一线视野拉得更远，则他会比原文更早看到第二座、第三座引擎轮廓，引擎群集体前移的判断会被提前一步说出口。
- 若林恩对小丑直言「让你撑屏障把你的老友都搭进去」，则小丑会黑着脸仍然撑出来，但心中对林恩的多了一线不满，之后会更加对抗性回应。
- 若林恩在引擎中心注意到三位被囚无序生灵的面孔时给小丑一条人脉指令，则小丑会以零碎无序力把那些囚徒的表情一一刻进记忆，为后续可能的「救生灵」支线铺垫。
- 若林恩选择绕过所有守卫直达拓路尽头而不是削能，则守卫与恶魔大军不会在第一时间被惊动，蜂组方阵足以完成齐射压制林恩。
- 若林恩在恶运方舟围堵时主动「装被围」，则大魔们会冒进压缩队形，林恩反手一阵中空间心智爆碎裂缝，潜在伤亡规模变大。
- 若林恩选择先砸第三台再砸第一台拓路引擎，则敌方殉爆令更晚下达，后续敌方推进节奏被拖延对阵时机。
- 若林恩让左左举刀一起劈第一台拓路引擎，则引擎爆鸣会更剧烈，左左会因此把齿尖咬破了唇，但破阵瞬间也让她记住「这一击我出过」。
- 若林恩用三叉戟贯穿引擎时瞄「引擎心脏爆点」，则连锁殉爆会反向蔓延到下一台，敌方残余引擎只剩下了一台可战。
- 若林恩在「三叉戟」当场落定形态而非临时变化，则三叉戟之服役史上多一条「一击穿星」的勋章。
- 若林恩在旗舰恶魔君主喊出「为了天父」时用咒瞳反向冲入旗舰，则旗舰内部一幕被他完整看到，敌方最高指挥官的面孔被永久存档。
- 若林恩在「殿后」甜点大厦静止时不退而推进，则后方追击大魔反而追不上，林恩走为先行军的路径被改写。
- 若林恩全程不喝止群水则泰坦、巫神、石祖、银幻会在群频里把这一战吹成传奇，艾雯与脑子的沉着反而被这一股「传奇热潮」衬得更显特殊。
- 若林恩在初诞者金光裹住白焰做出最终推撞，则敌方所有会记录此战的人都会把这一拳定性成「那道白光与金焰并起的尽头」。
- 若林恩选择把「殉爆」提前引爆由自己攻入主动破局，则敌方难以应对这一变数，但林恩会在殉爆后被反噬出更严重的内伤。
- 若林恩示意让左左先撤回再出手，则她会被他强行塞进系统空间，事后她会整整一天都不理他。
