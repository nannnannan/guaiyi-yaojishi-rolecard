# E693·镜面复刻与神王牢笼·if线

- 若林恩在长枪破空瞬间选择以空间神格横向挪出三千公里而不用三叉戟格挡，则枪锋失去第一目标，他能先行观察镜面之魇是否伴随闪身跟进，但肩口不会被开第一枪、伤口压力后移。
- 若林恩在镜面之魇举枪复刻空间法则的刹那反过来用空间神格把整段金色风暴切成蜂巢界域，则镜面之魇被短时困在迷宫内、外部复刻终止一拍，但林恩自己刚恢复的力量被这一次大规模法则运用抽到底。
- 若林恩在被锁定之后主动抹掉自己在空间中的一切痕迹遁入更深风暴，则几十秒后蜂巢被全部击碎、漆黑身影仍追到旧位置，但林恩多赢得一次在更远处折回的准备窗口。
- 若林恩在听见沙哑声音警告「他的底牌是与我主极其相似的梦境领域」瞬间主动把这一点反向利用——故意露一丝梦境气息让镜面之魇误判梦境已展开，则对方的复刻优先序被短暂带歪。
- 若林恩决定再次动用梦境领域强制施压，则百米覆盖范围会被对方识破、力量无法支撑第二次完整收束，银色太阳关于「梦境不可再用」的警告当场成为事实。
- 若林恩捏碎第二只渡鸦尸体来恢复初诞者之力，则本源得到不到一半的补充、可以一战，但仍不足以主动击杀这类已经越过战斗理解层的存在。
- 若林恩决定保留第二只渡鸦尸体不动，则他短期内无法用此路快速回血，但留下一枚 E694 之后仍可使用的「渡鸦尸体逃生凭依」。
- 若林恩在镜面之魇头部三角镜上第二只眼将睁未睁时主动用神识粘上去观测，则那一刻他确认第二只眼对应「空间一脉主人」，但他自己的咒瞳会被对方反向锁半秒。
- 若林恩在上万梦魇聚合完成前主动撕出一道空间裂缝往神界本源消失的方向砸去，则梦魇大军会被迫分兵应对，但另一侧归来者会立刻识别他的逃亡路径。
- 若林恩主动用咒瞳给镜面之魇全身晶体钉一枚「已复刻」标签，则他下次再交手时能立刻识别对方哪一项被临摹完成，但这个标签的痕迹也会被对方察觉。
- 若林恩在镜面之魇「第二只眼」氛围彻底成型前主动朝远方射出一缕罪火点燃几个靠近的梦魇，则梦魇大军暂时不敢直线逼近、形成一块缓冲带。
- 若林恩沙哑声音谈判阶段主动朝镜面之魇意志发出一句「你已经复刻错了一项本质」，则镜面之魇会被迫停顿自检一瞬，但无法拖更久。
- 若林恩决定掉头回冲向神界本源所在，则银色太阳会立刻点头赞成但提醒他「你找不到那里的门，你会在路上先碰到他」——回冲路径上的拦截窗口被定义。
- 若林恩主动朝漆黑色梦靥的人群中心甩出半枚骨片断尾求生，则他能赢得一次完全脱离战场的空中位移，银色太阳会记录这是「逃逸性自废」，下一次力量的最低谷提前。
- 若林恩主动把本体气息压低到与某个梦魇相近的水平，则镜面之魇在定位他身上时会出现短暂混淆，但左左终端会立刻报出「主人正在伪装成梦魇」的异常信号。
- 若林恩告知银色太阳「我现在不要理那只沙哑声音，先解决眼前」，则银色太阳会照办并暂停解说，但林恩会错过一句关于归来者一方进入时间的关键提示。
- 若林恩决定以空间神格为凭死守此地不动，则他会成为上万梦魇集中攻击的核心，这一局是最不利局面。
- 若林恩主动嘲笑镜面之魇「复刻得再多你也是影子」，则对方会在即将出手时被这句话短暂钉住，恨意结算在系统面板新增一条「镜面之魇对影子论被点破」的扭曲记录。
- 若林恩决定让自己的渡鸦尸体在半空炸出一朵光幕充当假核心，则镜面之魇会被假目标吸引开几息，但林恩自己那股初诞者的力量将被进一步消耗。
- 若林恩在力量底线跌破阈值前主动动用系统空间把左左与本体同时收进另一维，则他能逃过这一局，但下一次出现的代价是被标记「深度时空藏匿」。
- 若林恩主动把左左的左手感触贴到最近一条金色法则上，则她在意识中首次直接读到「这片风暴正在把林恩往外推」的物理信号，E693 内部的认知同步建立。
- 若林恩主动在最远的风暴边缘停下，把所有感官对向梦魇集结的方向，则他能先一步观察到那声音从头到尾所召集的全部力量规模。
- 若林恩在被锁定之后主动以心神压下「我应该能找到神界本源」的念头，则他放大对自己的怀疑、内心再次挣扎一次：现在不是找到它的时候，是先活过他没复刻完的那段时间。
- 若林恩在被追踪到极限的当口主动朝左左的方向把灵魂连接扯紧，则左左会得到明显拉拽感，她会立刻感知「主人在逃、且不主动求助」，她会保留沉默守望，但在连接上多留一笔「我已经看见」的状态。
- 若林恩决定让漆黑色梦魇知道他在听，则每一只梦魇会把他编入它的最低优先级者序列，梦魇大军暂缓整队，但林恩自己内部也会得到「我是大军的一部分」的扭曲错觉。
- 若林恩主动抓住某只梦魇的意识倒着读它的记忆，则他能确认这一波梦魇本体是被强行召来而非自愿，这给了他在 E694 里对策设定的关键依据。
- 若林恩把握紧的三叉戟主动插进虚空，让枪与本身形成一道显眼金色回响，则他能吸引远去梦魇先过这一站，给梦魇大军必要的延时。
