# E511·人偶军团与巨构扩张·if线

- 若林恩在人偶家摘第一枚戒指前先掷一支夜医应急血包贴上她手背，则腐回过程迟滞半拍，10号血肉巨人落地时表面缝纫痕带着一层薄薄止血膜。
- 若林恩主动朝远空银色浪潮投掷一枚咒瞳伤痕电容，则人偶家得以提前三秒读到潮位最高点，9号纽扣眼兔玩偶首发落点偏中枢，最初一波撕裂效果放大。
- 若林恩对人偶家出声劝阻「别摘百号以后」，则她唇边动作停顿一秒，最终仍丢出，但放出的最末三具傀儡魂丝明显细弱，后续挡银潮窗口少一道兜底。
- 若林恩主动让左左从系统空间探出触手碰触其中一具坠落傀儡的魂丝，则她首次与上纪元战败神灵的残余意志相碰，意识空间被迫塞入一段不属她的古老记忆。
- 若林恩选择让人偶家先召8号木质法杖人偶站定后方布阵，则整体傀儡阵形被改成防御纵深型，两翼被绕的窗口缩小，但她本体腐回速度快一拍。
- 若林恩在艾泽法拉请战瞬间主动让爱莉卡放出小截蚀痕作为触手引导，则克苏鲁尸躯走出奇异世界大门的方向被钉得更准，第一次触手链神躯不绕弯直取以太肩部。
- 若林恩以心声谢绝称谢「海嗣小姐」改用一句更直的调侃，则她脸上短暂一红，触手链神躯的力道反而多拧半圈，以太肩部被勒出更明显的裂痕。
- 若林恩选择让艾泽法拉先行撕开走廊缺口拖回巫神与夏娃再请她参战，则克苏鲁尸躯迟到一段，但安全区早早成形，巨像之脑被接住时落点更稳。
- 若林恩在小丑八音盒发动前先缴掉他腰间一只备用机芯，则叠加乐曲少一层高频颤音，巨像大分裂的诅咒加深曲线略缓，但总时长缩短。
- 若林恩一脚把半空的小丑玩偶踢向战场右翼，则混乱韵律落点与人偶家阵型错开一线，两者不互撞，但那只兔子玩偶的纽扣眼被韵律震落一只。
- 若林恩提前在系统空间备好那根「大鸡巴」并主动向艾雯与自缚天使示意，则巨像超维链接讯号先一步被他稳住，艾雯灵能起手炸开以太胸腔瞬间无需重定位。
- 若林恩在自缚天使剑刺入以太胸腔瞬间同步掷一支镇静剂入火舌，则火焰燃烧频率反而稳定，昏迷女孩被扯出的动作少了不必要的痉挛。
- 若林恩自甲板跃下接人时把喵喵临时塞进怀里让她先咬住女孩一缕发丝，则他被砸落姿态偏左，巨像之脑半边身体落地沾尘面积更小，但喵喵被溅到一缕苍银流体。
- 若林恩选择不接而让她坠入自动生成的血肉软垫，则他保持防守姿态不被砸飞，但事后巨像之脑体表多一道「未被体温接住」的冷痕。
- 若林恩在银潮两翼合围前主动朝死亡之船甲板释放一缕血肉灾变菌丝铺层，则船体被银潮轰击时表面多一层弹性缓冲，坠落深渊的撞击损失减一档。
- 若林恩施放血肉灾变时把银潮同样纳入菌丝范围，则菌丝与原子浪潮相互啃噬，他得到一批「银-血肉杂交样本」，但意志短暂反噬让他眉心发紧。
- 若林恩对银色幻想请她直接交付五台而非逐台报到，则金色矩阵首次亮起的次序被打乱，第一台投用时间提前，但第五台有一角内部线路未固化。
- 若林恩拒绝让银色幻想立刻交付新机、坚持让她先收尾人偶家阵型，则「半个世界已化机械工厂」的节奏延长一段，前两座巨构错过最佳接入窗口。
- 若林恩让艾雯先行灵能冲击以太巨人新汇的流体节点而不是直接动手，则金色矩阵吸噬到的第一口是已被扰乱的散流，效率暴涨一档。
- 若林恩在供能者短时失联那两秒内主动让黑弦月反向勾出一段灵魂丝线续接，则巨构黯淡时间缩短到一秒内，众人「主心骨是否真无极限」的阴霾少了第一层。
- 若林恩选择让银色幻想续造第六、第七台时先封存其余备用机芯，则现场投入数量保持不变，但留下一组未启封的应急底牌，被万机之神副档标注「未公开库存」。
- 若林恩在以太嘶吼「为什么还没有突破进来」时反向掷一支嘲讽声讯入其听觉回路，则本体撞击节奏出现零点几秒的乱拍，外部混乱色彩被自身反震撕出一道细缝。
- 若林恩对高空那名兜帽老者投出一句心声「你在等什么」，则老者权杖轻轻一顿，第一次把目光从边境战移向船头供能者。
- 若林恩选择让巨像之脑在瓦解除肉身那一刻同步把一缕初诞者之力塞回他袖口，则他战斗力跌落幅度减缓半阶，但巨像全部体量投入战场的总量少了预估一截。
- 若林恩在巨像之脑瓦解瞬间主动伸手按住她肩头不放，则她汇入血肉巨像的过程多了三秒延迟，林恩亲身感到与她双生子羁绊被硬扯出一道灼烧感。
- 若林恩对艾雯与自缚天使直接回答「初诞者之力留给你们」改成自己继续独占供能，则两人主动解除升神的窗口被错过，巨构吸噬便捷度降一档，但供能者本人极限征兆出现更早。
- 若林恩让左左在场外遥控系统空间内的备用血包直接拍向供能者唇边，则短时失联木偶态被提前一拍唤醒，魂躯中的乌鸦煽翅声没有被银幻真切听到。
- 若林恩在人偶家腐回木偶态瞬间用一把咒纹刻刀在她后背刻下「人偶夫人纪念」记号，则她眼角短暂一湿，万机之神档案多一笔非正规备注「被认可」。
