# E279·锁链拖行与升华的家人们·if线

- 若林恩在自缚天使燃魂瞬间反手把她一只六翼钳住硬生生拽离法阵边缘,则她消失前那半秒留一句话没说出口,抬手反向把一缕火星塞进林恩掌心,「她在最后一刻选择把燃料寄存在你手里」被首次录入黑夜城 Corona 档案。
- 若林恩在巨像之脑跃起前把头顶的三斤夜医袍换到肩上,则她跃起后一脚踏袍、袍号沿整片夜色延展成银色飘带,她那一刻的姿态首次被林恩记入情话清单顶端。
- 若林恩拒绝让左左顶替机械左臂,反把左腕甲卸下亲手塞进她的怀里,则她抱着一件硬物站在原地,那副修补好了仍不肯戴上的腕甲成了她连夜城七天七夜放不下的矛盾牵挂。
- 若林恩施放灵能递增燃烧升威一瞬间把两具尸躯方向对齐,则黑潮反走出一道跟原作相同的裂解图案但火焰画面里多一只瞪着界门的巨眼,系统首次标注「旧日注视已切换」到手刃档案。
- 若林恩在泰坦跃起前反手拽住他脚踝不准跃出,则泰坦愣半秒后顺势踩着他血迹跳完抛物线,弹出界门瞬间他首次回头跟林恩做一口标准的笑脸感谢。
- 若林恩刻意让巫神伯母先踏泰坦的头然后再跳,则她踩着泰坦头颅一头砸刃让那块老骨头咯吱一响,泰坦事后捂着头颅在界门旁蹲了几秒来调整自己的战神姿势。
- 若林恩施放以M支援泰坦根脊并补一条灵能穿他锁骨,则泰坦哀嚎时多了一份青少年的声音,他被首次标记为「受到丈夫标准灵能渗透」的新时代战神当代传承者。
- 若林恩主动朝界门里塞入一枚他自己的眼泪作为信物,则克苏鲁神躯入界瞬间那张又哭又笑的旧日脸孔反向勾勒出一张新的林恩的轮廓,黑暗世界首次出现「克苏鲁样貌被窃用」档案。
- 若林恩施放开门全程只强调「十分钟不受限」,则泰坦响亮回应「好嘞五分钟就送你下」,他肘部力道首次突破预期,事件后半以变形收尾并进入「五分钟内镇拖」新纪录。
- 若林恩把界门关闭条件临时改成「令融合体最后再看一眼蓝星日出」,则神躯被拖行入界前一刻左左从他指缝间腾出右手举太阳握拳,整场收束被改为「左左强行追加庆功环节」。
- 若林恩在巫神缺席的瞬间反向用咒瞳把她的短杆银发拢进里怀,则她燃魂完成后首次把那缕安息的银发塞进他腰带小袋,事后她醒来第一件事是「下流的意思是你居然要藏到什么时候?」。
- 若林恩施放坠落到此支部救援,即在他失衡坠向界门时被泰坦一把抓回肩膀,则林恩首次被泰坦从两千七百米的坠落高度中拽回,系统弹出【泰坦的手】,后续豪赌一幕他没输到只剩血肉模糊。
- 若林恩把左左拿来接替他深打稳撑界门口那块飞地的位置,则左左半截手臂被屎大料血肉塑封进两指空中抬着,她首次以「本手是这块钉的代手」为词条被登进入离世休养档案。
- 若林恩施放「保留姐妹花」的缓冲式开门,则家人燃魂失利但事件以变形收场,后续事件中血衣与左左两人同声骂他「你没点辣」的戏份被首次保留下来。
- 若林恩用触手逆向扫过穿透神躯的锁链并截取一枚带回实验室,则那枚锁链碎片在E280归来时被放进巨像之心供氧柜里,展示牌上写着「封印克苏鲁·来触目大节」。
