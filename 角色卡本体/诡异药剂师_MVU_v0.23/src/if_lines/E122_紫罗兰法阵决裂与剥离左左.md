# E122·紫罗兰法阵决裂与剥离左左·if线

- 若林恩在左左崩溃之前就公开剖白是自己需要左左、而非左左需要留下，则左左的哭骂转为怔忡沉默，巨像之脑的威压仍会降临但怒火减半，谈判基调从对抗转为陈情。
- 若林恩选择不回头、真的走过桥梁让左左归入巨像之心，则事件转入变形：左左独立剥离不成立，巨像之脑完整回收双子，后续衔接到巨像完全苏醒的另一条支线。
- 若林恩以紫罗兰法阵硬拒威压时不亮出心脏、只以法阵立场对峙拖时间，则巨像之脑会判定他在试探并真的下杀手，林恩需以血肉硬扛数轮冲击，左左的光茧会被加速融合作为恫吓。
- 若林恩在法阵发动同时向左左伸出手要她踩着自己的掌心挣出光茧，则左左的攀爬速度倍增，巨像之脑会被迫把剿杀林恩与按住左左二选一，剥离节点被抢出来。
- 若左左在攀爬过程中喊出的是「我跟你走」而不是「我讨厌你」，则林恩自剖心脏时笑场，谈判仍成立，只是左左事后会被他气得连锤他三个月。
- 若林恩事先把自己胸腔里的备用心脏结构改造过（植入式药剂腺体或蚀心玻璃罐），则他递出的不再是原生心脏而是等价替代件，巨像之脑会识破附加杂质而追加一条「割让一段人性」的代价。
- 若林恩当场承认自己是异界坠落者、并主动亮出更多身份筹码换取巨像之脑退让，则巨像之脑的银瞳杀意收敛为凝重好奇，剥离仍是结局但祂会留下一句「我会再去查你」。
- 若林恩反过来以「你不肯收心脏就泄密巨像文明坐标给万机之神」作为要挟，则谈判立刻崩坏成生死局，左左会被巨像之脑当场压回光茧深处，剥离失败转入变形线。
- 若左左的光茧里同时封着某位心脏姐妹的执念残响并在此刻苏醒插话，则她会替左左喊出一声「哥哥」，巨像之脑会允许剥离但要求林恩留下一截自己的骨头作为新的契约钉。
- 若林恩在挖心过程中手抖到无法对准心脏位置，则左左会隔着光茧反向把一堆铭文推回他胸口替他止血，这一幕被巨像之脑看见后反而加速了祂的妥协。
- 若林恩亮出紫罗兰法阵时附带引动了万机之神留下的旧烙印回响，则巨像之脑会立刻判定林恩与万机之神有染并加码敌意，必须从对峙转入一场短暂缠斗才有谈判机会。
- 若林恩一进门就不绕弯子、直接把心脏拍在王座前的台阶上讲条件，则整个谈判压缩成一句话「心脏换妹妹」，巨像之脑沉默片刻即答允，左左在剥离时连骂人都来不及。
- 若林恩选择把整座紫罗兰法阵自爆来掩护左左逃脱而非用它谈判，则左左能脱困但林恩当场重伤濒死，巨像之脑会因失去谈判对象而暂时收起心脏不回收，留下一条「无心之人也未必活得过今夜」的悬线。
- 若左左在剥离瞬间反过来死死抱住林恩的胸腔不让他失血，则她的巨像铭文会烙进林恩自己的肋骨，两人从此共享一条痛觉链，无心之人的代价由「空洞」变为「双生共感」。
- 若林恩拒绝交出心脏、只承诺「我把命留在这里陪你镇守地狱直到她独立」，则巨像之脑会接受这个人质式方案，剥离成立但林恩被永久钉在禁库不能离开巨像半步。
- 若左左在剥离完成时反手扇了林恩一巴掌骂他混蛋才扑进他怀里，则这一巴掌会被巨像之脑记为新签约的见证烙印，好感提升的同时林恩脸上会长期留一枚淡淡的铭文掌印。
- 若林恩在剖心之前把一段自己幼年坠落地狱前的记忆剥离出来裹进心脏递给巨像之脑作为添头，则祂会让剥离的过程变得更温和一些，左左被放下时不会带满身铭文伤痕。
- 若另一名夜医同伴在此刻闯入禁库撞见剖心现场并出手干预，则巨像之脑会把该同伴视作「外部变量」立刻逐出地狱，但林恩可以借这数秒空档抢回左左再全力突围。
- 若左左在攀爬至林恩面前时决定不挣脱，而是主动把半枚心脏姐妹的契约印记塞进林恩的空洞胸膛里补位，则无心之人的状态被左左亲手「补心」，两人的共生关系被改写成双向寄生。
- 若林恩把紫罗兰法阵完整解析口述给巨像之脑作为学术交换而非威胁，则祂会以「学者对学者」的姿态同意剥离，但会要求林恩留下这部法阵的全部刻印图纸作为地狱藏书。
- 若林恩把整个谈判过程暗中通过系统向外界直播，则巨像之脑发现后会判断林恩早已布好舆论退路，剥离仍成立但祂会在最后一刻追加封印让那段直播变成乱码。
- 若左左被剥离时发现她的巨像铭文已经深入骨骼无法完全拔除，则她独立成立但带着半身铭文常驻，林恩日后的每一次治疗都得绕着那些铭文走。
- 若林恩在递出心脏时附上一枝左左以前送他的、早就被他收在系统空间里的枯萎小花，则巨像之脑会罕见地沉默数秒，然后把那枝花也一并收进光流作为「这颗心脏的来历证明」。
