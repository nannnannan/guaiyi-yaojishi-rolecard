# E721·灾厄梦魇层推进·if线

- 若林恩在踏入黑瞳范畴瞬间先把自身罪火压成内敛形态不外放，则他不至于在黑潮中成为第一靶心，但「狂风中烛火」的熄灭感会更刺骨，他必须靠金色梦境硬撑。
- 若林恩在第一波历史梦魇成形时尝试认出其中一两张面孔并叫出名字，则那个历史强者的残影会停滞半秒、空洞地回望他一次，给他留下一段「灾厄记住过我」的诡异线索。
- 若林恩主动在梦魇幻形中搜寻紫罗兰时代的渡鸦，则他会找到一只被缚得更深的渡鸦虚影，那是画家未献祭的旧部，他会立刻明白这就是她保留的火种。
- 若林恩在画家说「现在，你明白了吧」之前就抢先说「我知道，那是他」，则画家会停顿半秒，把「我每一次窥探都比上一次更接近」那段独白省略，直接进入「献祭真相」。
- 若林恩在听到「大部分渡鸦是被我所杀」时立刻拔刀指向她，则她不会闪避、不会还手、只静静看着那把刀，林恩的手若不下落，那一刀就多一条他此生跨不过去的坎。
- 若林恩选择在这一刻朝她吼一句「你疯了」，则她的苍蓝光影会剧烈波动一次，第一次在外人面前露出内里那个被岁月撕扯得支离破碎的玲珑女孩。
- 若林恩听她把献祭讲完、不发一言，只把刀收鞘、然后用力给她一个耳光，则她会硬生生接下、嘴角渗血，但她后面所有劝说的话都会换一种更疲惫的语气继续。
- 若林恩对她「你也会变成恶鬼」的平静宣言点头说「那你陪我一起当」，则她会第一次愣住，那是这十几年里她第一次从别人身上听到「陪」这个字。
- 若林恩在那只遮天黑瞳注视过来瞬间主动把自身形象压缩成普通狱卒的模样，则他能躲过一次直接被锁定，但白发身影也会在那一瞬消失在更深的黑潮里。
- 若林恩醒来后立刻问她「他还能撑多久」，则她会给出一个具体到年的估算，但这个估算比主线更短，林恩紧绷的时间感会被进一步迫近。
- 若林恩追问她「当年小丑和屠夫是你派来的吗」并且不收刀，则她会再次点头、再补一句「左左那次也是我」，林恩过往的旧疤会被她亲手全部挑开。
- 若林恩在对话中一直握着刀、不松开，则她会把他紧握的手反握住，那是两人之间第一次也是唯一一次肌肤相触，她把力道压得极轻。
- 若林恩从她话语中挑出「让祂整个吞掉我」直接反问「那我呢」，则她会给出那句「你只剩走完正确路的选择」，但表情里第一次看到一闪而过的「我也想有人陪我走」。
- 若林恩没有跟随她、独自朝白发身影方向冲，则他会被内部混乱法则撕到只剩一线生机，被画家在最后一刻强行拉回苍蓝残垣，她会第一次骂出一句脏话。
- 若林恩听完方案后提出「我去找时间神格先救回左左再陪你走这条路」，则她的目光会闪一下，第一次正眼把「他不听话」当成一个可以商量的变量。
- 若林恩在撤出黑瞳范畴时主动把一只被他斩碎的历史梦魇心脏捏在掌心带走，则他回到外界会得到一份「灾厄内部物质样本」，主宇宙后续研究多一条路径。
- 若林恩在回到苍蓝残垣单膝跪地的画家身边主动跪下与她平视，则她会第一次真正与他对视数秒，那段对视被她铭刻为往后所有牺牲里最后一次被温柔的注视。
