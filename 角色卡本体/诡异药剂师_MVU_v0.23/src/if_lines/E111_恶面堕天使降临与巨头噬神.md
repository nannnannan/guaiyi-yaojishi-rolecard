# E111·恶面堕天使降临与巨头噬神·if线

- 若林恩在黑羽雨落瞬间先把315的灵魂容器塞进自己瞳腔最深一层再上骸骨外盾，则母神手腕改抓林恩本尊而非容器，巨头咬合仍可成立但锁神目标偏到头部而非手腕。
- 若林恩让爱丽丝先一步吞掉灵魂容器再被她占据主导出手，则母神抓握目标转为恶灵形态的爱丽丝，整段巨头咬合桥段让位，主线改走"恶灵噬神"变形。
- 若林恩在315嘶吼"母神陛下"时直接撬开他下颚倒一瓶强效静默药剂，则315声线被掐、母神不会进一步被激怒，但她的注意力立刻全部转向林恩本人。
- 若林恩面对艾雯的"快跑"警告真的转身掠走小小就走，则母神探手直接夺回灵魂容器扬长离去，事件变形为"巨像之脑夺回战失利"，E112开场改成残局清点。
- 若林恩选择不变身巨头而是以夜医伪装跪地行礼冒充疫医信徒，则母神暂缓抓握，让出一次直接对质窗口，但伪装被识破风险升至极限，露馅即归变形收束。
- 若林恩把巨头咬合目标改成裂隙边缘本身而不是神明手腕，则空间裂隙被不死诅咒硬生生咬住闭合一半，母神被困半身在另一侧，315与灵魂容器一并被抛出落回残骸。
- 若林恩在变身前先把咒瞳剥离交付左左暂存，则巨头形态不带咒瞳，母神不会因为【束缚315】消散而连锁夺走瞳力，但左左立刻成为新抢夺焦点。
- 若林恩用死缚锁链时不把自己一同锁进去只缠住神明手腕，则母神仍可发力挣脱拖走整条锁链，但林恩本尊保留自由行动力，E111收束标记改为"锁神失败、半锁神"。
- 若林恩让活物语的招呼从舔手掌升级成粘稠诅咒唾液大面积糊上手腕，则母神愤怒数值额外叠加，【十二翼堕落天使对你的愤怒】系统提示连续刷新，E112亵渎段以更烈火姿态开场。
- 若林恩那句"主母，是你吗"换成直呼"疫医"二字，则双魂真相公开节奏被打乱，艾雯的揭秘对白被打断，母神以一种更原始的狂怒直接爆发黑羽潮汐第二段。
- 若林恩点破真相时不叫"主母"而改叫小小曾经暗地里喊过的昵称绰号，则母神手腕出现一瞬的僵直，恶面与人面在意识层面发生第一次可视的撕扯，E112唤醒桥段提前埋钩。
- 若林恩不向小小分离方向确认直接原地变身，则小小不在安全距离内，被黑羽潮汐边缘擦到，E111紧急度再上一档，后续事件多出"小小治愈"续段。
- 若林恩把分身娃娃先行抛出冒充自己迎向神明手腕，则母神第一击落空，真身可从侧翼另起咬合路线，但分身娃娃被捏碎会反馈一道灵魂震颤给林恩本尊。
- 若林恩让银色幻想隔空一剑先斩断母神一根黑羽再变身，则神明怒气被分一半给她，E112以M亵渎时母神反击被切成两段。
- 若林恩在巨头咬合成立同时让黑弦月在残骸底布一层蛛网兜底，则即便锁链被挣脱残骸也不会立刻自爆，利维坦自爆倒计时延长数分钟，留出更多对话与亵渎窗口。
- 若林恩用第二个诅咒时换成低温冻髓而非死缚锁链，则神明手腕被冻结在裂隙口但灵魂容器同时被冻住，喵喵兄长线需要追加解冻桥段才能延续。
- 若林恩在315爆发触手时直接以血肉编织把他钉到母神手腕旁当肉垫，则315当众崩溃自白疫医伪信仰，事件追加"疫医教徒群崩解"段，林恩在夜医系统的评价偏冷。
- 若林恩在巨头形态下顺手扯断母神一根黑羽攥在齿缝里不退，则黑羽在E112开齿灌注以M时化作第二导管，亵渎效率翻倍但母神愤怒值一并翻倍。
- 若林恩点破真相的同时把夜医疫医同源同体证据举到残骸所有幸存疫医信徒眼前，则周围信徒群体出现大范围崩溃与跳反，E111后半段从单神战扩展成群像崩解。
- 若林恩那句"主母，别来无恙"语气换成狂妄笑声配上【恐惧魔王】称号全开，则母神不乱方寸反而冷静收回手腕，事件变形为两尊神级存在的对峙外交，E112亵渎桥段需要换开场。
- 若林恩变身巨头的瞬间让左左以自己为模板同步血肉编织成一颗小型不死巨头作陪衬，则母神同时面对两个咬合目标，分神的同时灵魂容器被扔进王座残骸深处，抢夺失败。
- 若林恩在死缚锁链结成后主动把锁链另一端钉进自己脊椎而非残骸，则他变成人肉锚点，后续任何移动都伴随锁链拉扯剧痛，但母神被锁的稳定性上升一档，E112操作窗口更稳。
- 若林恩锁神成功后用牙缝挤出一句对小小的远程心音"别过来"，则小小不会闯阵，但林恩独占全场视线，E112红茶包唤醒段的开场对白将只有他与母神对峙，无外部缓冲。
- 若林恩在艾雯揭秘时主动切断传音听一半就动手，则双魂真相以不完整版本被他广播，后续事件需要补一段艾雯重置解释，主母苏醒节奏被动拖慢一次。
- 若林恩整场事件都没有说出"主母"这个称呼、只用架式与动作回应，则系统不授【亵渎前奏】隐性加成，E112以M灌注段需要更强的以M剂量才能突破母神外壳。
