# E381·孤儿院实验与人偶改造·if线

- 若林恩在孤儿院初收容画面瞬间主动记录冷水与鞭刑间隔的时间，则旧世虐待器具档案里多一份量化样本。
- 若林恩在伊甸园机构初次进入瞬间主动辨认机构徽记的字体与颜色，则档案里多一笔「旧世界秘密组织」识别样本。
- 若林恩在解剖、器官移植、额前叶切除手术等被列举瞬间主动记录每项名称与参与者数量，则档案里多一页「旧世机构罪行字典」。
- 若林恩在她作为「疼痛研究」第一个样本出场瞬间主动记录她年龄与体重，则档案里多一条「旧世人体实验参与儿童规格」样本。
- 若林恩在火灾瞬间主动记录燃烧的热源类型与持续天数，则疫医档案里多一条「旧世火灾销毁»样本。
- 若林恩在她是「经受住所有折磨还能存活的唯一孩子」被言明瞬间主动记录这是参与者评价还是客观事实，则档案里多一条「疑点指向她的异常存活」的备忘。
- 若林恩在南北战争改变资助来源那一秒主动记录政府秘密支持撤出的关键节点，则档案里多一笔「机构破产动力」样本。
- 若林恩在布偶店老人再次出现在她面前瞬间主动记此人的服装风格与身体褶皱细节变化，则档案里确认这是同一人，疫医旧世同道线索延续。
- 若林恩在老人自述「花钱游说把她送入特定孤儿院」瞬间主动记录用词与动机假设，则档案里多一份「嫌疑人自认」样本。
- 若林恩在老人描述「心跳曾停止十五分钟却仍存活」那一秒主动记录心脏停搏时间长度，则疫医档案里多一条「异常存活数据」样本。
- 若林恩在老人列举她在脸上疤痕感染后仍存活的例子瞬间主动记录疤痕的位数与她所经受的每一次苦难的对应关系，则档案里多一张「苦难印迹图谱」草稿。
- 若林恩在老人提及种植园第三发弹壳与血迹证据瞬间主动记录这与公开叙述的差距，则档案里多一条「疑点指向官方掩盖」的备忘。
- 若林恩在老人怀疑她早已死于记忆某一时刻仍靠执念停留瞬间主动压一缕疫医气息落到老者肩头试图表示安慰，则疫医气息被历史反弹、但他意识到这位工匠的观念与疫医救心理念接近。
- 若林恩决定是否接受她那疑点仍未决的假设，则档案里多一笔「玩家审定未决」备忘。
- 若林恩在机械框架逐渐替代原有身体瞬间主动记录这一工程需十几年，则档案里多一笔「旧世机械人偶改造耗时」样本。
- 若林恩在她永远保持年轻容貌被言明瞬间主动记录这与「无衰老」对应的疫医旧世生物学意义，则档案里多一笔「似人非人旧世工艺」样本。
- 若林恩在舞台认出人偶即是几经改造的她瞬间主动记录这一段往事的重组，则档案里多一笔「疫医旧世界的同道改造工程全景」样本。
- 若林恩在买家出现在华贵大门门口瞬间主动记录买家身体肥胖与老态细节，则档案里多一笔「买家成年形象」样本。
- 若林恩在认出买家是成年哥哥瞬间主动记录脸部与幼年特征的对应度，则档案里确认新旧印迹联动。
- 若林恩当场选择不观察买家后续，则档案里多一笔「玩家选择停滞」备忘，本轮追溯被默认收束。
- 若林恩决定结束旧世接触退回现实向人偶家汇报完整实验史，则人偶家档案里多了一份疫医视角的「旧世人体实验档案」，与黑弦月深层执念呼应度被完整量化。
