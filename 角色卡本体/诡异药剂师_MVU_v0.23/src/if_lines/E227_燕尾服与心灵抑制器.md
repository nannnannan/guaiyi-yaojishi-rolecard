# E227·燕尾服与心灵抑制器·if线

- 若林恩在翻系统空间时先把「万机之神战舰蓝图」拿给小眼萝扫一眼，则她识别出三套额外可拆装置，事件以不变形收束但林恩可用装置总数从5台中型变为8台。
- 若林恩让傀儡套上燕尾服后再加一层巨像之心的血肉皮肤，则傀儡在远处看起来像活人而非空壳，事件以不变形收束但燕尾服必须持续被他贴身血灌，血气消耗+30%。
- 若林恩改以白雾+巨镰正面强攻、放弃地下伏击，则事件以变形（放弃伏击）收束，他必须在面对魇魔时依赖咒瞳四次掷骰成功的运气，E228全部机制重写。
- 若林恩给心灵抑制装置接入的不是机械姬剑柄而是他从万机之神战舰上撕下来的蜂巢主脑芯片，则装置识别为「高级指挥官」，事件以不变形收束但蜂巢主脑反向锁定他编号，后续机械神教对他的追踪+1。
- 若林恩在身份验证时倒入的是机械姬的「臀部润滑液」而非「口腔润滑液」，则装置提示「身份特征验证通过，欢迎使用智械科技，臀部型号」，事件以不变形收束但机械姬下次见面必须被修理一顿。
- 若林恩在左手刻傀儡之印时改刻在右手，则后续他在魇魔对决中无法左手挥刀右手引爆，事件以不变形收束但「死缚」发动后自动激活节奏慢半拍。
- 若林恩放弃用超维感应操控傀儡，则傀儡必须以传统精神力驱动，事件以变形（精神驱动）收束，他再次被魇魔识破「无魂」特征，战术倒退到E226原始水平。
- 若林恩将70台小型心灵震荡器分成三层同心圆布设而非均匀散布，则魇魔进入中心圈时承受三倍震荡密度，事件以不变形收束但外圈反制半径缩小、魇魔逃逸路径多三条。
- 若林恩顺手把五台中型装置里的一台埋在蜀都市区作为「保险」，则装置剩余量为4台，事件以不变形收束但蜀都市区居民在启动瞬间集体短暂失眠一周。
- 若林恩在白雾覆盖前先以小眼萝的咒瞳给整片废墟打上一层「白雾反弹」，则魇魔的精神冲击波被部分反射，事件以不变形收束但小眼萝的咒瞳活化度消耗+10点数。
- 若林恩给机械姬的「保养品」里偷偷加一滴自己的体液作为身份标记，则装置识别为「林恩型智械」，事件以不变形收束但后续这台装置在正式归档中成为以他命名的专属版本。
- 若林恩在破译赛博装置时先用三秒钟凑合接入而非精雕细琢，则装置全程发出蜂鸣警报，事件以不变形收束但远处魇魔听到异响后战术意识+1，伏击难度上调一档。
- 若林恩把左左的传送目标直接锁定在心灵抑制器中心点，则她出现在一幅「蓝色光圈里的少女」画面，事件以变形（左左误置）收束，她必须被紧急撤退否则将被自己的抑制器压垮。
- 若林恩在刻傀儡之印时刻入的不是自己符号而是左左的咒纹，则死缚引爆瞬间傀儡由左左远程操控，事件以不变形收束但左左在黑夜城那一端同步承受一次反噬。
- 若林恩让机械姬本人出场激活装置，则她到场后做的第一件事是引爆他藏起来的一台中型装置作为「折旧测试」，事件以变形（机械姬插手）收束，布设总量永远只能到4台中型。
- 若林恩在手中傀儡之印刻完的瞬间用一根触手把自己的左臂暂时结晶化，则印记无法被魇魔的精神冲击波扰乱，事件以不变形收束但他在整场战斗中左臂不能回血。
- 若林恩把心灵抑制器的目标范围设置距蜀都边界仅一百米，则启动瞬间蜀都所有夜医短暂昏厥，事件以变形（波及市区）收束，隐修会在他战斗期间顺利撤退大半。
