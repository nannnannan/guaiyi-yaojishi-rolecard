# E432·遗忘法则与小丑承诺·if线

- 若林恩在小丑抓起尖石前抢先按住他手腕，则小丑不会挣扎，只会反复问「你记得他叫什么吗」，林恩的拒绝回答会让小丑当晚消失在内空间角落整整四小时。
- 若林恩主动接过小丑手中的碎石替他刻那个已被抹去的称呼，则碎石在他掌心化成灰白色流沙，林恩手指会连续三年梦到自己的指腹在写字但总是上空无一物。
- 若林恩抓住小丑手腕后反而把石块压在自己胸口替他划下第三道疤，则林恩胸前会留下一道永远愈合后仍在的紫色纹路，小丑从此停止在自己胸上加疤。
- 若林恩在小丑刻字的瞬间主动用自己的血把石雕涂满，则血与石一同褪色成空白，但石面残留的凹凸形状让林恩能以指尖摸到念不出的字母轮廓。
- 若林恩直接拔碎片取小丑自由，则心脏拔出瞬间小丑胸前那两道旧疤会同时发热变白，他第一次完整地说出「我疼」而不是「我忍」。事件标题「小丑承诺」按变形未发生结算。
- 若林恩改以触手缠绕小丑心脏把碎片缓慢拔出且全程保持眼神接触，则小丑在碎片离体那一秒心率从拍戏的模拟变成真实紊乱，系统登记【小丑情感阈值破壁】。
- 若林恩拒拔碎片但提出「继续束缚直到找到屠夫为止」的延期条款，则小丑默认接受但胸前多一道新增的浅磨痕，队长职责由狱卒体系枷锁转为自缚。
- 若林恩在小丑茫然询问「我刚才在写谁的」时故意装作自己也不记得，则孽主当场拍打地面哭出声，小丑从此每天凌晨仍会下意识去同一位置拿碎石。
- 若林恩向小丑展示自己曾经写下的名字消失的画面，则小丑首次承认「你也被人夺走过东西」并主动靠过去三寸，信任悄然升级。
- 若林恩提议把整个事件折叠进初诞者之力封存的记忆琥珀，则琥珀会成功固化下来，但每次打开都会清空林恩一整段无关记忆作为代价，机制成立但代价惨烈。
- 若林恩放任小丑继续刻、不阻止、不帮助，则小丑会刻到指腹渗血、玩偶布料溃烂，第二天林恩才能从墙角找到一堆失去意义的碎石。
- 若林恩让小丑在自己失去记忆的时候由旁证激活——比如安排孽主每天固定念两次「我们有同伴消失了」，则孽主的念词失去目标却保住「有缺口存在」这一元事实。
- 若林恩主动声明渡鸦位格的抗抹除机制给小丑听，则小丑会咬牙要求林恩「把我们每一个都记下来」，林恩背包多一项无法拒绝的长期负债。
- 若林恩让小丑用娃娃布料缝一个「空口袋」替代刻写，则小丑每晚把碎石、断笔、干血都塞进那个口袋，口袋表面会浮现一行不会褪色的字「我忘了」。
- 若林恩主动用自己灵能在小丑心脏位置额外留一枚追踪标记，则小丑未来任何一次想起那个被抹去的同伴都会触发标记发热，林恩成为他唯一可控的「记忆提示音」。
- 若林恩提出「我替你保管那个名字等你复仇时再还」，则他胸前的渡鸦印记会永久加一条锁链纹路，他自己也从此无法再听见那个名字。
- 若林恩拔碎片瞬间故意让小丑先咬住自己手腕，则小丑咬破玩偶布料嵌入林恩皮肤，伤口愈合后小丑手腕内侧会浮现一个成人尺寸的咬痕纹身。这是成年小丑的情感宣泄成立口径。
- 若林恩拒拔碎片却说自己「不背叛地忍受狱卒本身」，则小丑会当场冷笑一声、第一次直称林恩「情夫」而非「人类」，绑定关系从上下辖制转为对偶情感。这是成年小丑的明确成立口径。
- 若林恩在讨论下一步时只指向「去找康斯坦丁」一句，则小丑立刻若无其事接着推理第二渡鸦坐标；他不会告诉林恩自己是因为被拔碎片后的情感真空才急着转移话题。
- 若林恩向小丑承诺「我会替你记住任何一个想记下的人」，则小丑当晚悄悄把自己仅剩的两道旧疤对应的两位前同伴的代号写在林恩系统空间的隐形界面上。
- 若林恩提议把「遗忘」本身当成武器反向用在弑利亚身上，则小丑首次露出真正的恐惧而非讥讽的表情，他会说一句不带讽刺的「那也会用在我们身上」。
- 若林恩拔碎片前先令左左用血族仪式给小丑一滴永久血印，则小丑获得自由的同时也获得了一枚可以通过血族通道随时被林恩召唤的标记——他看到自由的价码时只有一秒犹豫。
- 若林恩拔碎片后不立刻把碎片据为己有而是公开销毁，则系统会爆出「原初碎片灭失不可回收」的提示，小丑眼中会出现一种近乎悲伤的轻松。
