# E769·如果可以给你选择·if线

- 若林恩在魇王提出百年之约前先让左左从左手拽出一缕黑火烧上自己掌背，则他以疼痛封住自己开口的那一秒，裂隙对面的交易条件多一次性地没有落点。
- 若林恩让左左把「脑袋里闪过的家人名字」一个一个念出来并按在她左手上,则他心底最薄弱的那一片不会再被魇王挑出作钓钩。
- 若林恩在裂隙前主动问出「愿意牺牲的到底是哪些人」逼魇王具象回答,则魇王口中「蝼蚁」二字会与主母、智械小姐、艾雯爵士的名字并排悬挂,林恩立刻得到破约的具象画面。
- 若林恩在黑火点燃节点前先用咒瞳扫一眼节点居民各自的命运支路,则他看见任何一条被交易出去的命都会以真实因果写入未来,梦境里的所有幻影在他眼里再难被视作筹码。
- 若林恩主动把「整个主宇宙复活」这种量级的要求丢回去给魇王作答,则魇王必须从承诺退到「牺牲一部分换取一部分」,林恩首次听到对方亲口承认诚意有边界。
- 若林恩在梦境城镇某户人家窗外停住三秒再多看一眼那对等来生的母子,则那户人命运的细线在他脑里被强制留档,他做不到点头让他们成为燃料。
- 若林恩让左左在大裂隙面前主动把左手抽出她自己的一段冰晶冻痕撒进裂口,则裂口内部的「未来美好生活影像」首次失真,魇王口述的承诺在被影像验证时出现裂缝。
- 若林恩在交易结构面前主动后退半步,把视线从「将得到的」移到「将失去的」,则他看清居民们并不是幻影而是真实过去,交易名单从抽象符号变成有名有姓的脸。
- 若林恩让黑火从指缝里漏出去一缕烧到裂隙边缘,则魇王的投影首次出现不稳定波纹,对方答应「让整个未来改写」的承诺可信度当场降到他自己都不信的层级。
- 若林恩主动接受左左递来的一根手指并把那一根手指按在自己眉心,则他任由「最痛苦的那个我」在意识里被唤醒一秒,那一秒的确定感让他无法再落于「放弃的安稳」。
- 若林恩在节点中主动走到某条已经被交易过的命运支路尽头看一眼结果,则他会看见被交换安全的人最终仍在更早节点被噩梦收割,「交易给出确定未来」的招牌当场塌一半。
- 若林恩让空间法则在梦境城镇上方固定出一条不被噩梦扭曲的真实天幕,则节点里所有在交易与拒绝之间摇摆的居民首次同时看见「不交易也能活」的第三种可能。
- 若林恩主动把「我不接受」三个字说得很慢并把每一个字都嵌进黑火里,则那三个字会带着灼热的实体感写到时间裂隙对面,魇王口中的「重启谈判」彻底消失。
- 若林恩让罪火首次只烧自己而不烧敌人一瞬,则他以肉体疼痛作为「清醒锚」,魇王口述的家人影像在火焰里被强行照出投影本质。
- 若林恩在听完魇王承诺后主动转问左左「百年够吗」,则左左会无声地把他的手握得更紧,两人之间多出一份「不需要回答也能知道答案」的共识。
- 若林恩在拒绝交易的瞬间主动把「开拓」两个字刻进王座脚下的黑夜城城墙,则那个词会在极远的未来节点里同时显现,过去与未来两个林恩都收到同一句宣言。
- 若林恩在递出拳头前一秒主动对左左说一句「等我」,则左左没有冲上去拦他也没有崩溃,她留在时间桥这边的位置稳稳地未被魇王的回响撼动。
- 若林恩让黑火首次绕开魇王、只烧毁其身后那段「交易广告板」式的裂隙边缘,则魇王的承诺失去画布,但魇王本体未被立刻击毙,战争多延续一段以更彻底的方式展开。
- 若林恩主动把某一位已经被收割的居民灵魂接住一瞬再交回其家人手中,则那一小段真实因果被稳稳推回过去,「噩梦燃料」的图式首次出现破口。
- 若林恩在决战之前主动朝时间长河下游某处望去并锁定一个还未被魇魔触碰的节点,则他把战场部分引开,噩梦节点得以保下一片干净样本。
- 若林恩让左左把「请选择」三个字冻结进她左手的冰晶,则林恩在做决定的最后瞬间仍有一个不被魇王污染的、属于同伴的「外部声音」贴在他手背上。
- 若林恩主动把「我的家人不是交换出来的」这一句话内化并写在灵魂连接上,则左左那边同步收到这句宣言,她从「担心他会接受」切到「陪他走开拓路」。
- 若林恩在拒绝魇王一瞬选择先不出剑而是先闭上眼一秒,则他留给主母、智械小姐、艾雯爵士最后一段属于过去的告别,黑火出手时再无迟疑。
- 若林恩把时间裂隙的入口先用黑火烙印一圈不让更多魇魔进入,则他可以一对一地面对魇王,拒绝交易时不会被群声淹没。
- 若林恩让黑火首次只在节点边界烧出一条路而不是全面焚毁梦境,则居民获得被引导撤出的路径,「非交易但活着」的中间态被直接落地。
- 若林恩在节点收尾时主动朝时间长河说一句「未来的我,听见了吗」,则下游某处的更老的林恩首次在时间战争史上向过去的自己点头。
