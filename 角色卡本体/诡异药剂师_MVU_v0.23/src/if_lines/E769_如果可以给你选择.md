# E769·如果可以给你选择·if线

- 若林恩在魇王提出「百年之约」前先透过圣堂大门的门缝感知到一墙之隔那道熟悉的颓唐气息，则他心头猛地一颤，那些曾被深埋的温柔记忆瞬间在脑海中翻涌。
- 若林恩在听到魇王许诺「给你们一百年安稳时光，让主母、智械小姐、艾雯爵士全都活过来陪你」时沉默了整整三秒，则那三秒的动摇真实得令人心碎，但也让他随后的拒绝更加重若千钧。
- 若林恩在心神动摇的刹那感受到左左从左手传来的坚定紧握，则那份真实的同伴温度瞬间将他从魇王编织的虚假温柔乡中拽回残酷现实。
- 若林恩在裂隙前冷冷质问魇王「用整个主宇宙众生的性命去换我一人的百年苟安，你也配提交易？」，则魇王伪善的谈判面具当场被撕碎，双方再无半点妥协余地。
- 若林恩在脑海中闪过主母、人偶夫人、智械小姐与艾雯爵士的笑脸时，清楚知道她们绝不会愿意活在用无数无辜者鲜血换来的虚假温室里，则他眼底的最后一丝犹豫彻底化作滔天杀意。
- 若林恩在圣堂大门外刻意压低声音以免惊动门内那个过去的自己与自缚天使，则他在承受巨大情感冲击的同时依然死死守住了不破坏过去因果的底线。
- 若林恩在拒绝交易的瞬间斩钉截铁地宣告「我会带着所有人的希望，去开拓属于我们的未来！」，则这句掷地有声的誓言令漫天梦魇为之胆寒，秩序黑火随之暴涨数倍。
- 若林恩在挥拳轰向魇王投影前先以黑火将整座圣堂外围严密包裹隔音，则门内的红烛摇曳未受半分波及，过去的他与自缚天使得以安然度过那一夜。
- 若林恩让左左把「我的家人绝不是用来交易的筹码」这句话同步烙印在两人的灵魂连接上，则左左毫无保留地与他一同拔剑，攻势凌厉无匹。
- 若林恩在看穿魇王提出交易实则是因为正面战场根本无法奈何自己时露出一抹冷笑，则敌方企图以心理战瓦解他斗志的算计彻底破产。
- 若林恩在拒绝魇王一瞬选择先闭上眼一秒向门内的故人作无声告别，则当他再度睁眼时，双眸之中只剩下焚尽八荒的决绝黑炎。
- 若林恩把时间裂隙的入口先用黑火烙印封锁不让任何一只梦魇逃窜，则圣堂门外的魇魔军团在顷刻间被他单方面包饺子全歼。
- 若林恩在听完魇王蛊惑后转头在意识里问左左一句「如果是你，你会选百年苟活吗」，则左左会毫不犹豫地啐一口骂魇王做梦，让林恩彻底展颜一笑。
- 若林恩让黑火精准绕开圣堂的一砖一瓦、只将漫天梦魇与裂隙烧成虚无，则他对力量的入微掌控令对面的魇王投影惊骇欲绝。
- 若林恩在轰碎现场所有梦魇后没有丝毫停顿，直接徒手扣住尚未闭合的时间裂隙边缘将其硬生生撕大，则猎人与猎物的身份在此刻彻底逆转。
- 若林恩在跨入时间裂隙反杀敌方大本营前回头看了一眼紧闭的圣堂大门，则那一墙之隔的烛光成为他孤身杀入废弃时间支流时最坚实的后盾。
- 若林恩主动将方才那一瞬间的动摇坦然留在心底而不去掩饰，则他接纳了自己身为人类的七情六欲，神王道心反而在真实情感的滋养下愈发不可摧折。
- 若林恩在撕开裂隙时对着对面惊愕的七十一柱魇魔投影冷喝一声「滚出来受死」，则他那霸道绝伦的姿态直接震散了数柱弱小魇魔的战意。
- 若林恩让左左在冲入裂隙的瞬间化作黑火大剑紧握在手，则一人一剑化作贯穿时空的黑色流星，直扑魇魔投影盘踞的废弃时间支流。
- 若林恩在踏入裂隙的最后一刻将圣堂门外的每一寸空间都恢复原状，则这一场足以决定宇宙命运的谈判与决裂在历史上没有留下任何外人可见的痕迹。
