# E536·南方坠落者联盟·if线

- 若主母圣安娜重逢中三千年的泪水没被圣安娜直接拥抱而是先大致对质「我以为你已经死去」，则她会有一段过渡心绪从「哀她是亡灵」转向「恨她活着」再回到拥抱，立心疮疮较文略慢。
- 若圣安娜不告诉主母「半月前就建立联络」而在她被拒绝入会那一刻才抖出，则主母会被预期外冲击击穿，她的「并不恼怒」状态延后，星轨可能会立刻读出她的伪装。
- 若石祖、努斯、星轨、核子出场顺序不按原文由巨人到智天使、而是先核子老者推开个枯城市大门再引石祖扶出，则同一片段更突出「坠入即成废墟」的悲剧主题。
- 若星轨拒组织时她不单单说「让他亲自过来」还附加条件「亲自带着巨像或对等的战场成绩」，则林恩的登场在条件上会更重一个砝码，他可能会主动取舍是否现场携左左。
- 若主母展示光之法则时不只让黑雾消散还剪影出对应海面浮斑群岛，则「我可以在黑夜城拥有一片海」的筹码会被附加到「我能给你们法则」之上，她的劝说重量加倍。
- 若圣安娜在会见时透露自己的脸部伤痕早就成为她力量的磨刀石，则主母的慰藉可能吸附到「你的伤也是你的骄傲」层面，圣安娜会更加戒备并非她弱、而是她强才不愿再建神国。
- 若黑袍打断不是「真的是无趣」而是用一句「你们的茶话会太长了」，则他直接切入傲慢姿态的人会立刻带油腔滑调的非主角风采，下落者联盟对傲慢的愤怒值会更高。
- 若巫神在圣安娜谎称扛不住时主动给主母安上一缕她的巫咒安抚，则主母的「安心」迹象多一段巫术感，重夺回主母主的难度上升。
- 若林恩以黑袍身份突破风暴之前先发出他自己的「月风」波动预告，则南方的女巫会预先被告知、战场空间有更清晰的心理准备，但「他来的目的」会是被众坠落者算计的。
- 若主母现场没提风评，圣安娜反向先抖出「萝莉控」一串，则公开层的笑场变成耻辱，主母在收剑打几天后未必有同样的耐心提供半月承诺。
- 若林恩主演出黑袍时不拎刀、而是用一句心声传出「我来了」，则他不需要现身就能让整场谈判垮台，星轨会有机会立刻判断这是夜魔级者的心灵进攻。
- 若黑袍的「滚吧」补一段「半个月我重新数一遍，今日滚的不进，明日进的不滚」，则他会把一场单挑宣布成系统化的选官制度，这种声音中的傲慢会更重要地激化众坠落者。
- 若圣安娜在引荐主母的同时另引荐一位小妹（文中未出现），则会侧面渗漏另外成员阵，南方据点的落脚秩序会是「观众规模至少比本文更多两人」。
- 若主母临走时把初诞者玻璃珠弃一半给圣安娜垫身，则她为下落者联盟留下的「光」筹码会为后来者留下战力，此筹码可能会被星轨摆到显眼位置作为战利品。
