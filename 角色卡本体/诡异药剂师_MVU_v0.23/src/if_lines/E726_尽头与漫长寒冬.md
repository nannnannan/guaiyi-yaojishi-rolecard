# E726·尽头与漫长寒冬·if线

- 若林恩在击杀二十级噩梦之后立即记录它的梦魇结构发给银色幻想的沉睡神格，则这份材料会在将来某天唤醒她时多一个研究起点，但林恩需多花半天驻守现场。
- 若林恩在连续作战中拒绝休息、以巡警姿态横扫数个星区，则他的屠杀效率激增，但连续三月不眠之后会有一场突发性神智模糊期，期间他差点误杀自己人。
- 若林恩主动去找艾维儿提出分兵部署，则噩梦柱压境速度会被延缓，但他会失去一轮独自领悟黑火的窗口，时间线整体向后推。
- 若林恩选择不与任何人商量直接深入黑狱门缝方向探路，则他会先抵达门缝、先于所有预警，但他也同时被无序深空中的存在注意到。
- 若林恩在黑花海下偶尔回到艾维儿所在的王庭陪她吃一顿简餐，则她的精神韧性会缓慢恢复，林恩的负罪感会被一点点稀释。
- 若林恩在主母的预警下绕开某一片新出现的噩梦柱，则那个柱会在一个月后吞没半个新星区，艾维儿会因此责怪他「不该绕」。
- 若林恩研究和「梦境瓶颈」时主动回到时间之外向左左的虚空喊话，则冰晶偶尔会微弱发光作为回应，林恩能借此推断她还活着，但每一次都被银色耀阳警告「你在消耗她的余量」。
- 若林恩主动去给沉睡中的智械小姐擦一次脸、把她的发丝理顺，则她沉睡的反噬速率会放缓一分，但林恩需要在那里守望整夜。
- 若林恩开始培养一批专守噩梦柱的青年军，则后续战争压力分散，但林恩需要投入更多精力在训练而非修行上。
- 若林恩在某次噩梦中瞥见画家的影子，则他会被惊醒并立刻拔刀，那一夜他会向空气连斩十几次直到左左印记把他唤回。
- 若林恩在发现瓶颈的瞬间花时间写一篇自省手记，则他能以更清醒的头脑推进后段，但黑狱门缝会趁这段时间悄悄再裂一分。
- 若林恩在噩梦柱信号出现时优先和艾维儿共享情报再决定行动，则两人会形成真正的「合议制指挥」，但每一次决策周期都被拉长。
- 若林恩选择无视瓶颈、继续累积击杀数，则他的个人威势会持续攀升，但到真正对阵灾厄时他会发现自己的力量根本无法撼动根本。
- 若林恩在寒冬中以三叉戟定期给守夜军团分发温暖的神格辐射，则军团的士气长期高位，但三叉戟的主宇宙本源会因此被缓慢消耗。
- 若林恩独自深夜里拔出那把半出鞘的刀对着远方星区一刀虚斩，则他会把这一刀的思念寄给遥远的她，那一夜黑夜里会有一颗流星反常地亮起又熄灭。
- 若林恩在睡去时主动让金色梦境覆盖整间屋子、把所有人包进去，则他与黑夜城众人会有共享的一夜好梦，但梦境的负担会让他次日醒来短时间内无法作战。
