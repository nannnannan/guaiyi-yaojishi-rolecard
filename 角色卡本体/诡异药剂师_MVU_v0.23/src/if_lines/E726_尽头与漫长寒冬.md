# E726·尽头与漫长寒冬·if线

- 若林恩在自斩空间神格与初诞者之力熔入三叉戟时毫不犹豫地一刀斩落，则神疆的过渡会更加平稳，但他自身将在随后数月内承受撕裂般的本源空虚与剧痛。
- 若林恩在逆流时间回到过去溪畔请教轮回神王、听到对方说出那个「等」字时追问「如果等不到呢」，则轮回神王会淡淡看他一眼，回答「那便说明连你也走不出逻辑的囚笼」，令林恩更早警醒第三阶段绝非单纯的实力堆砌。
- 若林恩在冲击梦境扩张极限时强行用意志力再向外撑开十米，则他的精神海会出现一道细微的裂痕，虽证明个体意志确已触顶，但也让他次日不得不休养整整一天。
- 若林恩在画家被吞噬的第三年、面对十二尊降临的魇魔时没有独自出战，而是带着新神军团一同迎敌，则十二尊魇魔虽仍会被击退，但新神军团将付出惨重伤亡，后方士气更加低迷。
- 若林恩在将十二尊魇魔拖入梦境火海、魇王叫嚣「在我主下一次清明之时就是你们覆灭之日」时没有多费唇舌，而是直接咔擦一声扭断魇王脖颈投入火海，则其余十一尊魇魔的凶焰会被瞬间震慑，令他后续的斩杀更加顺畅。
- 若林恩在斩杀十尊魇魔后没有按原计划留下两尊苟延残喘的重伤者，而是将十二尊魇魔全数斩尽，则那十二尊魇魔将在无序深空中同步开启重生，反而让下一次全面入侵的时间点提前到来。
- 若林恩故意留下的那两尊垂死魇魔在逃回深空前被他打入一缕隐秘的罪火烙印，则这缕烙印不仅能进一步拖慢它们的恢复与同伴的重生，还能在下一次大战爆发前为林恩提前预警。
- 若林恩在横扫各星区战场、于神疆外围凭一己之力将梦境之火照进现实拉起漫天罪火防线时，多维持了半个时辰的全盛输出，则外围防线会稳固数倍，但他归来时会在自缚天使面前险些脱力晃神。
- 若林恩在自缚天使眼眶通红地迎上来高喊「林恩！我们又一次地赢了！」时温和地拍拍她的肩膀说「辛苦你守住后方了」，则自缚天使紧绷了数年的心弦会稍稍松弛，眼泪当场夺眶而出。
- 若林恩在黑夜城最高会议上听到自缚天使提议「我们需要一个能让我们所有人都盲从的帝王」时当场严词拒绝，则会议会在压抑的沉默中散去，各大星区蔓延的失败主义与绝望将无法在短期内得到遏制。
- 若林恩在自缚天使含泪单膝跪地、一字一句背诵那首古老的渡鸦寒冬歌谣时，亲自走下台阶将她扶起并默许成为众生的王，则全场新神与狱卒会同时单膝跪下，渡鸦救主的信仰将在一夜之间燃遍主宇宙。
- 若林恩在听完渡鸦歌谣后轻声接上一句「如果这冬天太久了，我会一直举着火把站在这里」，则这句话会被史官写入帝国最初的圣典，成为亿万底层生灵在寒夜中吟诵的誓言。
- 若林恩在默许建立帝王信仰的同时私下叮嘱自缚天使「不要搞活人献祭或极端狂信那一套」，则初期的救主信仰会保持相对温和的守望色彩，直到后来为了点燃黑火才不得不走向极致狂热。
- 若林恩在休整期抽空去探望仍在沉睡中对抗神格反噬的银色幻想与康斯坦丁船长，并替智械小姐理顺额前的发丝，则两人在沉眠中的法则躁动会平息许多。
- 若林恩在深夜独自立于黑夜城高塔之上、眺望神疆外围那条烧尽天空的罪火防线，则他会清晰地感受到无序深空深处那股正在缓慢消化画家的恐怖脉动，更加笃定留给自己的时间已不多了。
