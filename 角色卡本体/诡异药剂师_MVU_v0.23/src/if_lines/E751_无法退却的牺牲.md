# E751·无法退却的牺牲·if线

- 若林恩在黑夜城第一道防线于终焉黑潮冲击下轰然崩溃的刹那，强行催动罪恶王座替前线分担三成法则崩解冲击，则正在断后的女巫神能多获得五息时间从容整理衣冠与长发。
- 若林恩在女巫神拒绝后撤命令、独自立于坍塌的城墙缺口面向漫天魇魔展颜一笑时，从圣所深处送去一缕昔日与她共饮时的温和神念，则她引爆神格前的那个笑容会更加绚烂夺目。
- 若林恩在女巫神引爆自身神格与全部巫术本源、化作漫天紫红色绚烂巫火与扑上的魇魔大军同归于尽时，以王座黑火接引她消散的最后一缕本源火苗，则那抹巫火将永远在罪恶王座一角静静燃烧。
- 若林恩在泰坦亲眼目睹女巫神化作漫天火雨陨落、双目泣血发出震天怒吼进入狂暴状态时，顺着昔日赐予他的神力烙印注入一股守护气机，则泰坦崩裂的血管不会当场炸开，得以撑到与哭泣小丑并肩。
- 若林恩在哭泣小丑跃上残破城头、摘下礼帽向漫天巫火余烬深深鞠躬并站到泣血暴走的泰坦身旁时，让城头狂风短暂静止一息，则全城撤往第二道防线的将士都能看清两位英雄接替死守的背影。
- 若林恩在女巫神自爆掀起的巫火风暴席卷城外十里、将数千头终焉眷属烧成灰烬之际，以自身神魂强行锁住其中三头欲逃窜的高阶魔将，则女巫神用生命换来的战果不至于漏掉任何一名强敌。
- 若林恩在第一道防线幸存的守军含泪后撤、频频回头望向那片紫红色火海时，通过圣所共鸣在每个人耳畔敲响一声沉稳的战鼓，则撤退部队在悲痛中依然保持着严整的阵型，未发生半点溃乱。
- 若林恩在泰坦双手抡起染血的巨锤、每一击都砸得自身骨骼寸寸碎裂却一步不退时，在潜意识里陪他一同发力怒吼，则泰坦锤下迸发出的金色雷霆会带上王座黑火的毁灭锋芒。
- 若林恩在哭泣小丑架起无形提琴、准备为泰坦奏响最后的伴奏乐章前，用一缕微弱的神念替他拂去脸颊上的血污，则小丑会咧开嘴角露出一抹比哭还难看的灿烂笑容，低语「看好了，陛下」。
- 若林恩在女巫神神格碎裂的瞬间，将她毕生钻研的巫术手札与药理心得从崩散的记忆光点中抢救下来封入王座，则这位惊才绝艳的女巫神留在世间的智慧结晶不会随战火彻底失传。
- 若林恩在感知到第一道防线陨落的三万名黑夜城将士灵魂正化作金光涌向圣所时，主动放开自己神魂的防御任由他们带着战场的硝烟味撞入怀中，则他的每一次呼吸都浸透了前线将士的热血。
- 若林恩在艾维儿与伊甸于第一道防线坍塌的废墟中被冲击波震晕、险些被后续涌上的魔潮掩埋时，激发留在两人身上的初诞者余威撑起一尺气罩，则两人能在碎石堆下平安撑到E752苏醒。
- 若林恩在女巫神化火前的最后一秒，听见她在心底轻声向他道别「下辈子再请我喝酒吧，林恩」，则在王座上被锁链禁锢的他会用尽全力朝着外城方向昂起头，以沉默的血泪应下这杯来世之酒。
- 若林恩在泰坦泣血暴走、庞大的巨人身躯在魔潮围攻下布满深可见骨的伤口时，让空气中漂浮的女巫神余火化作温暖的灰烬覆在他伤口上止血，则两位战友即便在生死两隔之际仍在彼此扶持。
- 若林恩在银色幻想与船长于内城防线含泪下令关闭第一道防线闸门、不得不将女巫神与泰坦等人留在门外阻敌时，替两位统帅分担那份割舍同袍的锥心罪责，则他们的剑心不至于因悲痛而动摇。
- 若林恩在漫天巫火缓缓熄灭、露出城头孤零零站着的泰坦与哭泣小丑两人身影时，让圣所顶端的暗金光芒穿透滚滚浓烟直射在他们脚下，则两人仿佛正站在王的王座台阶前为他守门。
- 若林恩在女巫神麾下的女巫军团学徒们哭喊着想要冲回火海与导师同死时，借艾雯之手降下一道严厉的王命强行拘禁她们退入内城，则巫术一脉得以在战后留下宝贵的火种。
- 若林恩在泰坦一锤轰碎一尊终焉魔像的头颅、自己右臂肌肉也彻底炸裂的瞬间，将一缕止痛药力精准送入他右肩神经，则这位铁血巨人能毫无停滞地用左手接过战锤继续挥砸。
- 若林恩在哭泣小丑看着满地同袍遗骸、指尖在无形琴弦上微微发抖时，于他识海中轻轻哼出当年王庭晚宴上的第一个音符，则小丑瞬间找回了最巅峰的演奏状态。
- 若林恩在第一道防线彻底化为焦土、终焉黑潮踩着女巫神的余烬再次涌来时，将自己体内正在疯狂暴涨的黑火压制得更加凝练，等待着为所有牺牲者彻底清算的那一刻。
- 若林恩在女巫神消散的火光中捕捉到她生前最爱的那朵暗夜蔷薇幻影，并用神念将其定格在王座扶手之上，则冰冷的罪恶王座上从此多了一抹永不凋零的艳色。
- 若林恩在泰坦对着漫天魔潮嘶吼「来啊！看看爷爷的骨头硬不硬」时，让整座黑夜城的地基随之轰鸣应和，则扑在最前方的数百头梦魇会被这股天地同悲的声浪震得凌空炸裂。
- 若林恩在感知到艾雯跪在王座下因为女巫神的死而再次吐出一口鲜血时，没有再用愤怒的眼神刺痛他，而是垂下眼帘与他一同默哀，则圣所内的气氛从剑拔弩张化作了悲壮的同舟共济。
- 若林恩在无法退却的牺牲拉开序幕之际，将第一道防线每一名战死者的面孔都烙印在自己即将成型的第三阶段神格表面，则他的神格从诞生之初便背负着整座黑夜城的忠魂。
