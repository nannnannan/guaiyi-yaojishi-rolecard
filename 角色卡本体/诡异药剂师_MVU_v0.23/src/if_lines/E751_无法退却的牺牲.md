# E751·无法退却的牺牲·if线

- 若林恩在女巫神屏障即将碎裂瞬间主动通过黑火给她注入一缕王座之力以让她多撑一击,则女巫神会在屏障碎到最后一层时仍顽强站着,她死时脸上带着一种完成感,「女巫神的最后一刻」会被永久定格。
- 若林恩让泰坦与小丑的合作攻击加一道黑火协奏,则这一击会同时从三个方向穿透噩梦核心,噩梦会以最惨烈方式崩毁,但泰坦的躯体在这一击下会撕裂得更严重。
- 若林恩让主母从黑夜城带一支精锐军团去信仰城支援以分担女巫神压力,则主母细胞能在 E751 与女巫神并肩作最后一战,但黑夜城内城会在这一夜被噩梦突破第一层防线。
- 若林恩在小丑准备撕开噩梦时主动把一小块王座本体传给他作为兵器,则小丑会用这块王座残料在小丑泰坦合击中产生更高威力,但王座黑火会在这次交易后第一次稀薄到可被外人察觉。
- 若林恩主动开启一段全域广播让所有信徒一起为信仰城守城将士祈祷,则信徒们的祈祷会以灵能形式汇入战场,女巫神的屏障会因此多一层韧性,但这一份汇聚会让因果网络产生不可恢复的扭曲。
- 若林恩让撤离路线在小丑泰坦攻击前就提前锁定并公开,则信仰城内的信徒会更早撤离,但噩梦也会更早封锁这条路线,「撤离通道」会从「希望之门」变作「死亡迷宫」。
- 若林恩让女巫神在屏障崩溃瞬间通过黑火与他完成一次心灵对话,则女巫神会留下最后一句话「请你赢」,林恩从此把这句话作为自己不可推卸的最终责任刻进骨里。
- 若林恩让泰坦在战神力量爆发时主动让他避开一处本可净化信徒的溅射范围,则这批信徒能多活数小时,但泰坦的怒火会被削弱一线,「泰坦的慈悲」会被记入所有幸存信徒心底。
- 若林恩让小丑的八音盒在攻击瞬间被黑火强化到能产生「时间错乱」共振,则噩梦的核心会在错乱中自我撕裂,但八音盒从这一刻起会留下一道永不可修复的裂纹。
- 若林恩决定让撤离通道在完成撤离后立刻关闭以防止噩梦追踪,则所有幸存者能活,但未能走完这条通道的信徒会被永远遗弃,「王的决定」会成为一个永久的痛苦符号。
- 若林恩反过来坚持让撤离通道保持开放直到最后一刻,则会有更多信徒活下来,但噩梦也会沿这条通道追到内城,后续 E753 内城防守压力会因此加大三倍。
- 若林恩让主母亲的因果线在此夜被燃烧完毕以让她作为「被燃尽者」继续指挥黑夜城,则主母的指挥会变得更沉更冷静,但她再不会对林恩的处境产生情感波动,「无私主母」形象从这一刻成立。
- 若林恩让小丑在战斗中主动选择承受一次本可由泰坦承受的反噬,则泰坦能活到 E753 守内城,但小丑的反噬伤会让他在后续 E752 中以已经力竭的姿态战斗,「小丑的弱位」成为永远。
- 若林恩让信徒中的孩童在最后一夜全体参与一次「王之声」合唱,则这亿万个童音会通过黑火传到王座成为林恩意识里最沉的一段记忆,「童音海」会成为他后续 S97 期最后的慰藉。
- 若林恩让艾雯在信仰城守城时刻公开向所有信徒承认「这就是终焉」,则信徒会在信仰最深处迎来一次大觉醒,但觉醒后的选择并非一致,会出现大规模的分流——半数选择继续,半数选择自救。
- 若林恩让女巫神在屏障碎裂前主动把她最后一缕神性传遍全城让所有信徒共享,则所有信徒在被黑火燃烧时会带着女巫神的一缕护佑,「女巫神的遗赠」会以永存形式跟随每位信徒。
- 若林恩决定让泰坦在最后一击完成后立刻撤离不与小丑同死,则泰坦能活到后续 E753 守内城,但他会在这一生中永远背负「未能与小丑同死」的愧疚,「泰坦的独活」成为他后来的永恒刺。
- 若林恩让小丑的八音盒在彻底损坏前留下最后一串音符存入王座作为永恒纪念,则这串音符会成为王座黑火中一处特殊亮点,后续林恩在王座上每一次失控时这串音符都会让他短暂回归。
- 若林恩让信徒们集体为信仰城的最后一战写下遗书并以黑火发送给他,则他会在 S98 收尾时收到亿万封遗书,「王的遗书山」会成为他在新秩序中最重的精神负担。
- 若林恩让主母在此夜以王座之名公开宣判信仰城为「圣地」即便城破也永远神圣,则信仰城余生会成为信徒心中唯一的圣地,后续 S98 重建时会以信仰城原址作为新秩序的最高圣所。
