# E171·餐刀危机的降温与事实核查·if线

- 若林恩在刀锋落下前选择硬挨一记、不躲不闪任餐刀钉入肩膀，则巨像之脑首次失手见血当场瞳孔骤缩、松刀跪地捂住伤口，质问路线从「割以永治」改写成「你为什么不躲」，事件以变形（挨刀示弱）收束。
- 若林恩在捆上椅子审问期间完全放弃话术、保持沉默并长时间流泪，则左左侦察不到他的狡辩向与愧疚向，第二次刀举前被拖进莫名情绪泥潭，事件以变形（泣而不辩）收束，原作「煽情反杀」突破口消失。
- 若林恩在被审问期间改换策略全盘招认「就是我们啪了、我就是故意的」，则巨像之脑与左左同时被这份大大咧咧整到思维空白，事件以变形（全盘承认）收束，原作任何补救说辞一概作废。
- 若林恩在感言总决赛中途反过来质问巨像之脑「昨晚明明是你先拽我进被窝的」，则她被自己一手不明的动作记忆卡住三秒、随后反驳时声音分贝下降，原作单向追责出现攻守逆转。
- 若林恩在强吻反杀发起前一刻改换成深深低头道歉「对不起，确实是我不对」，则巨像之脑的【危】提示反应时间被打断、抓到反杀窗口的概率归零，事件进入不同类型的降温通道。
- 若林恩在解开绳索那一刻没有抓腕强吻改与巨像之脑拉开三步深深鞠躬，则她反而被这份保持距离的郑重适得其反感到一丝失落，修瞳报价筹码需要重新堆叠。
- 若林恩在强吻反杀时不是吻嘴而是吻额头，则巨像之脑被意料之外的触碰整到耳根通红、刀子主动拍开他脸颊却动作并没原作狠戾，修瞳条件从「任她提一件」变形为「先把额头那一抹记忆抹掉」。
- 若左左在巨像之脑【危】提示时不仅没觉察反而兴奋接话「你说的我都信了」，则监护盲区首次暴露，林恩强吻反杀后左左留在原地继续抹眼泪，事件以变形（左左呆掉）收束。
- 若林恩在巨像之脑收刀答应召集根源时主动追加一句「你提什么条件都行，就是不能再挥刀」，则「条件到时由不得你不答应」的原始筹码被她咬牙调整成一个新的不重提，条件簿第一道刻痕已经写下。
- 若林恩在审问中改打「巨像文明」身份牌，专门陈述「你是文明三千年的最后孤例，不该浪费在这种杀戮上」，则巨像之脑文明走马灯关联被牵引到她族存亡层面，追责动机分裂出「族人检察官」新身份。
- 若林恩起先后顺序把「我对不起你」说到一半却被左左中途捂住嘴，则那句钉在原地的话没有完整落地，巨像之脑的转身离开未被中断，事件以变形（左左抢戏）收束。
- 若林恩在解绳反杀前悄悄暗示左左「准备好有反应」，则左左早半步拉铃按下警报，艾雯爵士闯入撞见两人纠缠画面，事件以变形（乱场外助）收束，修瞳谈判被迫推迟且信用账户被扣一笔。
- 若林恩强吻反杀未完成、巨像之脑侧身避过但吻到颈侧，则她被未命中的吻反倒带入更深的慌乱、刀锋收得更急，修瞳协议仍签订但附加一条「再也不许有第二次」。
- 若林恩在筹码谈判时改请巨像之脑召唤根源「为我治伤、不修瞳」，则原始修瞳计划整体推翻、任何咒语碎片继续封存，E172神之方程式验证链条被拆解。
- 若林恩在筹码谈判时就地起价抬到「两件条件换瞳修」，则巨像之脑交易计算超预期、需要回去请示进而延期，事件以变形（条件加倍悬置）收束。
- 若林恩当场表示「条件我来出，请你提资深多多包涵」并主动赠送一件古老遗物，则谈判方向反而变成送礼模式，修瞳协议达成但「任她提一件」悬念被双向滋养。
- 若林恩在解绳后不仅强吻还在巨像之脑耳边低声诚挚说出「我真的很喜欢你」，则她被突袭俩次、刀柄几乎脱手，修瞳条件簿上的「再敢乱摸直接割以永治」字面力度在本实被消一半。
- 若林恩以「昨晚是被迫」坚持全部事实陈述并坚持不添加任何情感筹码，则巨像之脑核对几次目击证据之后只能退刀，但勉强答应修瞳时不会接手任何承诺尾款。
- 若林恩在临死演说中引用了巨像文明某句尚未公开的经典台词且不差一字，则她被这份了解中国移动到将餐刀反饭午餐并由她自己接续下一句，事件以变形（同流回忆）收束。
- 若巨像之脑在林恩起「人之将死」演说途中突然落泪丢刀号啕「你太可恶了」，则左左惊讶之余反过来扶住她，事件以变形（巨像之脑崩溃）收束，路线整体变成安慰单亲母亲调。
- 若林恩在解绳后不进行任何反杀、直接转身去书桌取出纸笔详细列出修瞳所需根源名录递交，则巨像之脑在理性渠道上无法拒绝、修瞳协议成立但「任她提一件」尾款被一笔删除。
- 若林恩演说到一半突然抱头蹲地说「我的眼睛在痛」，则追责任务被迫中断，左左以「你又要装」质疑同时却上前检查，修瞳谈判铺垫重心由责任转移到「伤痛状况」。
- 若林恩在发表「怕的是地狱的注视」时顺手指向窗台外的某一点、巨像之脑真的循手指望去见到一线高空异光，则演说的说服力被额外实物佐证，修瞳筹码价值再次升级。
- 若林恩在条件簿上主动先提一项「请不要再让我用右手做饭超过两次」的微不足道条款，则巨像之脑被这份反客为主整到幽默感松动，修瞳协议带着轻飘飘笑声落下帷幕。
