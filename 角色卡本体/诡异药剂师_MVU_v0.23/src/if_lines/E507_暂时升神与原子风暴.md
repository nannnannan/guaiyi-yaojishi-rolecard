# E507·暂时升神与原子风暴·if线

- 若林恩在大头娃娃小小冲出界门时主动伸手接住他，则「我也去帮医生哥哥」的画面被改成一次稳住落点，但小小的战斗地位未变。
- 若林恩在黑弦月扑到怀里瞬间顺势把她抱高，则她的眼泪会掉得更早，「我以为你已经死了」换成被笑声打断。
- 若林恩让人偶家不立即送傀儡下场而是先查她丝线暗码，则100号傀儡的启动时点延后十秒，原子浪潮迎头那一波被打得更薄。
- 若林恩在升神时故意给自缚天使只注八成初诞者之力，则她金色巨剑威力稍逊，但诅咒反弹也轻，能续航作战时长+。
- 若林恩让艾雯爵士的心灵巨人先锁定界门曲率，则他落地时顺带稳定通道，第一波夜医疗伤员能即时撤回。
- 若林恩选择不让原子机械海啸撕开一条走廊而是直接引爆，则夜医军团的整齐阵列会瞬间被打乱成散兵冲击。
- 若林恩远远地用夜魔刀示意黑色棺椁上的狼烟引信，则棺材内残余以太残迹会爆发一道黑雾，反让以太本体短暂遮蔽视野。
- 若林恩让船长在升神状态下让灵魂火焰与林恩的初诞者之力交融，则火焰变成金色船锚，舰体耐久+50%，但船长魂力耗损翻倍。
- 若林恩在战场上同时召唤黑弦月和左左，则两位左手级存在会瞬间共享感知，对指挥节奏提升一档。
- 若林恩命令大头娃娃小小跳到最前线挥动那顶鸭舌帽当信号旗，则他会被原子机械优先瞄准，「回来」台词他会先听到。
- 若林恩只把艾泽法拉蚀痕铺在战场四周而不深入核心，则初诞者之力不会被蚀痕反向分摊，巨构启动效率+，但战线侧翼失守。
- 若林恩让原子机械抓住夜魔刀先击碎刀背，则林恩近战被剥夺，但这时他改用咒瞳远程诅咒，反而比近战更危险。
- 若林恩让巨像之心在左左的意识里翻动一次共鸣，则能听到「我也想去」的低语，E514 左左登山时点提前。
- 若林恩把原子革命风暴的根源当成银色流体先掷入棺椁镇压，则以太被迫把本体提前暴露，「我只造了五台」嘲讽不再成立。
- 若林恩在军团集结时先让十二翼大天使领头致意，则金色烈焰的威慑扩散面+30%，原子机械推进速度整体放缓。
- 若林恩拒绝夜医直接燃命冲撞而是建起死亡之船船锚炮台，则他能在安全距离点燃血肉瘟疫弹，伤亡比倒置过来。
- 若林恩让主母在升神时诅咒再被压一成，则她能发挥出古神级全功率，但需要第二次升神做收尾。
- 若林恩要求小丑在八音盒旋律中加一段新乐章，则诅咒韵律里会出现扰乱心智的副歌，巨像分裂效果更剧烈。
- 若林恩主动把林恩自己的魂躯给左左做护盾，则她能在精神世界登山的路上多一层保护，但他本人魂躯损耗暴涨。
- 若林恩让以太在升神状态下主动暴露本体而不藏西部原子浪潮里，则巨构启动范围能一次性吞噬他八成体量，但他能立刻反击。
- 若林恩只派出康斯坦丁一人冲入心灵之海追踪以太意志，则他能追得更深但独自面临巨像分裂的风险。
- 若林恩让原子机械在升神状态下集体引爆，则黑色棺椁承受的冲击让它暂时裂开一条缝，镇压的以太流体可能漏出。
- 若林恩在原子浪潮袭来时用初诞者之力点燃大地，则他能把地表炼成一片火光阵，原子机械无法轻易靠近，但消耗加倍。
- 若林恩让银色幻想在升神状态下短暂恢复万机之神完全形态，则原子机械一击即溃，但她会瞬间燃尽数据，进入冷却。
- 若林恩拒绝艾泽法拉参战而把她留在奇异世界继续供应物资，则巨构生产不中断，但克苏鲁尸躯不被召唤到战场。
- 若林恩决定不在升神结束时撤退而是赌一次全力镇压，则他会在原子浪潮里激起一道突破口，但事后会陷入昏迷。
