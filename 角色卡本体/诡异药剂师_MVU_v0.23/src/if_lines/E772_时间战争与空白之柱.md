# E772·时间战争与空白之柱·if线

- 若林恩在通往天国战争废墟的夹缝空间内见时间终末裂隙全面撕开、魇王与镜魔及兽王红魔等数十柱魇魔本体齐出时毫无惧色，则他周身燃起的灭世黑火瞬间压住了群魔的嚣张气焰。
- 若林恩在一袭青蓝长裙的未来画家本体踏破时空降临、以画中世界拦下四散魇魔时朝她点头致意，则两人无需多言便已结成最默契的跨时空战线。
- 若林恩在听未来画家说明她来自「魇魔战争爆发数十年后的未来，因寻不到你才顺着时间线一路逆流阻击」时心生触动，则他终于明白这位沉默的守护者在背后独自扛下了多少岁月。
- 若林恩在黑火全开状态下高举大剑施展神王技「星寂」，则化作黑炎流星的剑光瞬间熄灭了群魔掀起的漫天灾厄异象，正面战场为之一清。
- 若林恩面对群魔从时间终末引来的滔天灾厄瀑布不退反进、一拳将其硬生生轰回时间裂隙，则他那力挽狂澜的神王伟力令所有跨界魇魔本体肝胆俱裂。
- 若林恩在旧力刚尽、第七十二柱黑袍身影鬼魅般现身身侧并以漆黑战戟直刺他脖颈时，瞬间将秩序大梦投影入现实，则实质化的梦境壁垒当场震退了那柄企图斩断他意志的魔戟。
- 若林恩在逼退漆黑战戟后冷声喝问黑袍身影「你究竟是谁」，则黑袍身影会露出温和而残酷的微笑道出「一个被你创造出来的，阻止你的可怜虫罢了」。
- 若林恩在听到黑袍身影说出「其实杀一个人，永远只需要一颗子弹，而区别在于你在什么时候把它打出去」时瞬间意识到对方声东击西，则他第一时间顺着对方指尖方向望去。
- 若林恩在黑袍身影屈指弹出一缕细微灾厄黑气射向远方虚空的刹那全力爆发想要拦截，则黑袍身影会不惜代价以空白之柱与漆黑战戟死死缠住他的去路。
- 若林恩在战斗伊始便分出一丝神王感知留意远处正在进行空间跃迁的过去人类林恩，则他在黑袍身影弹指的瞬间便惊觉那缕灾厄黑气瞄准的竟是毫无防备的过去自己。
- 若林恩在未来画家本体展开画卷封锁空间时主动以黑火为她的画界加固边缘，则企图绕过战场去破坏该时代历史的魇魔无一能够逃脱。
- 若林恩在施展「星寂」横扫魇王与兽王等本体时刻意将爆炸余波控制在夹缝空间内部，则数里之外过去人类林恩所在的空间通道没有受到正面战场的能量波及。
- 若林恩在漆黑战戟擦过脖颈带出一丝寒意时借机以黑火反噬戟刃，则他在那柄终焉兵器上留下了一道难以磨灭的焦痕，迫使黑袍身影不敢轻易近身搏杀。
- 若林恩让左左在群魔围攻时全权接管左侧防线，则左左化作的黑火屏障滴水不漏，让林恩得以全力轰出击穿灾厄瀑布的那一拳。
- 若林恩在与未来画家并肩作战时注意到她苍白面容下掩藏的旧伤，则他在挥剑开路时主动替她分担了大半来自魇魔本体的正面冲击。
- 若林恩在黑袍身影弹出灾厄黑气的瞬间高声向未来画家示警「那缕黑气冲着过去的我去了！」，则未来画家得以在千钧一发之际做出瞬移挡枪的决断。
- 若林恩在面对数十柱魇魔本体围剿时展现出远超时间支流投影战的恐怖统治力，则魇王等魔彻底明白哪怕真身齐出也绝非林恩的对手，只能寄希望于黑袍身影的暗杀。
- 若林恩在将秩序大梦投影入现实时让黑夜城的巍峨城影短暂浮现在虚空背后，则那座承载着众生信念的城池虚影直接压碎了空白之柱散发的绝望威压。
- 若林恩在看穿整场浩大的本体降临战都只是为了掩护那一缕“灾厄子弹”时心头凛然，则他对第七十二柱黑袍身影的阴险程度有了更清醒的提防。
- 若林恩在被黑袍身影死死纠缠的半秒内拼尽全力震开对方战戟望向跃迁通道，则他正好看清那抹青蓝长裙决然挡在过去人类林恩身前的震撼画面。
