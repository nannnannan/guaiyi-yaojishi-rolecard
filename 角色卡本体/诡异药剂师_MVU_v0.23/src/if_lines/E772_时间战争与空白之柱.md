# E772·时间战争与空白之柱·if线

- 若林恩在裂隙涌出天灾洪流之前先让自己梦境具象化为黑火盾,则他不会被终焉潮汐冲力波及,但身后艾维儿他们的退路线会被他自己缩短一格。
- 若林恩在星寂一拳挥出前先把黑影位置标记为「观察优先」,则他对黑影的跟踪从未断线,但那一拳的集中强度会被分走三分。
- 若林恩让画作在她抵达之前主动被他感知,则他提前一拍知道她会来,但那份「我来帮他」的惊喜感也被他自己剥夺。
- 若林恩主动用黑火为画作烧出一条安全退路,则她不会被迫一人面对数十个分散的魇魔,但林恩自己的战线宽度会被分出一条。
- 若林恩在空白之柱降临瞬间选择先看一眼柱纹力量再反击,则他多获得一段「空白之柱位格来自哪里」的线索,但周身会被终焉之柱投影波纹短暂压住。
- 若林恩让左左全力收集黑影每次出手的间隔数据,则她能建立完整的「黑影出招节奏簿」,但她自己需要承担连续高度集中心智的负担。
- 若林恩把黑火控制为「只烧投影不烧本体」,则他能避免时间污染,但对魇魔的杀伤速度会明显放缓,战局多拖一段。
- 若林恩在听到「杀人只需一颗子弹」时立即反问「你什么时候打出的那一颗」,则黑影会首次主动承接语言交锋,他的笑意会多一层「林恩听懂他哲学层面对话」的赞许。
- 若林恩让画作在他身边时主动对她衣角抓一下再松开,则他知道她能感受到并不不适,但他也会失去她对他拉开距离时那个位置有多宽的直觉。
- 若林恩把「这不是终点而是第一课」贴在意识里,则他对这场战斗的定位从高张决战调为长期磨砺,但那份「必须一招解决」的紧迫感会暂时消退。
- 若林恩在黑戟斩向他脖颈时不躲不挡以黑火硬接,则他会受到真实刺伤,但黑影也能第一次直观看到林恩黑火对终焉的直接抗性实损。
- 若林恩在画作倒下接黑戟偏转杀招时主动在她身后也撑起一段黑火挡板,则画作受伤大幅降低,但黑影会感知到「林恩在保护她」,他对林恩心理优先级面板会多一个明确名单。
- 若林恩把星寂用在空白之柱本身而不是冲来的魇魔身上,则空白之柱首次被打出一个可量化的「受影响程度」,但身边的魇魔会趁隙落到艾维儿他们的主宇宙上空。
- 若林恩让黑火在抵消黑戟刺伤时故意留出小缺口让毒伤渗入,则他能用那一缕伤作为今后黑火抗性校准的锚点,但伤口会恶劣到需几十秒才能重新压制。
- 若林恩主动把「我们后再见」这句话还给黑影,则黑影首次听到林恩主动承接未来对局的预约,他对林恩的评价从「对手」上升到「值得等待的延续」。
- 若林恩让左左在战斗中主动贴近他脊背而不是只在意识里言语,则她体温会成为他黑火节奏的稳定器,但他会发现自己对这种依赖正在形成。
- 若林恩在画作问他从哪里来时刻意转移话题到「你下一步要做什么」,则画作的猝不及防会让她一秒停顿,但她也会从此知道「他不愿说自己的时间位」这条边界。
- 若林恩把梦境具象化为一个巨大的倒扣黑碗包住整个战场,则所有魇魔被迫进入仅限他与黑影两个谁能驾驭终焉的范围,但艾维儿他们的主宇宙退路被他自己切断一段。
- 若林恩让黑火在黑戟刺穿瞬间主动对黑戟反向侵蚀,则黑戟首次显现「被林恩概念压制」的痕迹,黑影会直接慎重到收戟重新估算。
- 若林恩主动在黑影挥出那一击时大吼「那是过去的我」,则他赢得半秒预警让画作有反应,但这句话会在长河边被另一位时间存在截获。
- 若林恩让左左左手放在他背后而不是身前,则黑影难以直接目视她的存在位置,但林恩自己的前手会少一层即时感应。
- 若林恩在击败让他最不顺眼的魇王时不将他烧尽而是留下残尘,则他能留下一份「再出现再处置」的清单,但魇王那点的复活路径会被黑影提早准备出「他知道你会这样」的备选。
- 若林恩在跨越长河降临之前主动在自己过去那里留一段未来提示,则他能引导那个过去的林恩做出更相容的应对,但他也会为此承担因果提前交织的风险。
- 若林恩让左左用左手在他手中紧紧蘸一点黑火再放开,则左左首次实际接触到林恩的全部火焰而不仅是指尖微量,但她的左手会被永久烙上一颗微小火痕。
- 若林恩把黑戟刺伤的位置用黑火缓慢愈合而不是直接烧尽,则他能感知到伤口被终焉力量渗入的真实深度,但愈合时间会长到影响他下一段应对。
- 若林恩让画作在他们视线死角另放一个苍蓝投影,则黑影会在第一眼被骗,但当投影被识破后,画作自身精神会因此需五秒重置。
- 若林恩在撤退时主动留下一段模糊姿态让黑影知道「林恩在走但没完全离开」,则黑影会在下次遭遇时调整进入该区域的节奏,但林恩会浪费三丝现在正使用的气机。
- 若林恩让左左在画作站起来后第一时间朝她发出精神传慰而不是问林恩的伤,则画作对林恩的评价会在「救过他」基础上多一层「他重视同伴」的标记。
