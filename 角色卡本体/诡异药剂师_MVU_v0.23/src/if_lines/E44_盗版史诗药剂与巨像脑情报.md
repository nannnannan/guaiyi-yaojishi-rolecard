# E44·盗版史诗药剂与巨像脑情报·if线

- 若林恩在一次爆炸后干脆把炉子搬到殿外露天炼制，则仪式塔外墙的烟熏色留在室内，主母的隐忍叹息减税一格，但左左看热闹的视线从窗口挪到院中，连续一百九十九次失败的景观向巡逻夜医公开。
- 若林恩在某次炸炉后负气停炉三日自我复盘，则熟练度停在 199 不动，主母难得在金眸里浮出一丝"他总算学会了冷静"的审视，重启炉火的那一次成功率被暗暗上调半格。
- 若林恩在讨不到圣血后直接跪地喊"妈妈求求您"试图续上 E43 教母情的余温，则被缚天使侧过脸去不看他，左左在旁边笑得从凳子上摔下来，"不给"两个字仍成立但多了一句"这招只够救急不够救贪"。
- 若林恩改口讨要她梳落的金色发丝或锁链上的旧血痂作为替代材料，则主母打量他三秒后果断摇头，"材料必须跨过我身"这条隐性规则被当面钉死，但允许他以她呼吸过的炉温替代次要药性，熟练度从 199 微升到 199.5。
- 若林恩不敢提姨妈巾、改提袜尖或指尖的汗液，则被缚天使斜睨他一眼换成一句"滚回去继续练"，圣光连炸段落不触发，熟练度累积曲线照常，但她当晚多擦了一遍脸盆。
- 若林恩在提出"借姨妈巾"时左左没在旁边帮腔、而是认真捂住他的嘴说"她会杀了你"，则主母的气色从通红压回到半红，连炸次数从十几轮降为三两轮，狠话"给你动刀变成萌妹"被咽下没说，记入偏离账本。
- 若林恩收回那盆唾液时动作克制、不用指尖去拖那道水丝，则主母睫毛不会轻颤，危机度从八十八降到五十上下，但下一炉炼成时她遥遥相望的视线少了一层"这孩子其实非分之想很浅"的宽宥。
- 若林恩得了唾液后不立刻入炉、先分装一小瓶封存入随身空间，则盗版史诗药剂照常出炉，但随身空间的那小瓶在后续事件中成为可被搜出的"主母气息证物"，左左每晚嚷着要拿去拍卖。
- 若林恩入炉时把唾液与其他替代品（他自己的血或左左的鳞粉）混合后再投放，则出炉的不再是【自缚天使的怜悯（盗版）】而是另一种未命名药剂，能力压制诅咒的方向不变但副作用条目被系统评注为"此路不通"，熟练度 200 照常结算但药剂不被主母认可。
- 若林恩在熟练度至 200 后主动向主母炫耀、把盗版药剂举到她眼前，则她闭眼不答一秒后抬手在他头顶弹了一下，"小小的奇怪的副作用"那一行系统字被她无声圈出三道红痕，后续服用该药剂的对象会先遭她隔空审视一遍。
- 若林恩在追问巨像脑情报时刻意避开"它能不能复活"这句、只问它在哪儿，则主母的凝重语气减弱半格，"魔人协会也不过只是诸多窥探者之一"的情报照常递出，但"那串残骸蕴藏足以颠覆一切的能量与知识"一句没有完整说完。
- 若林恩追问时直接抬出店里那条"成了精"的巨像大舌头作为佐证，则主母第一次把目光从战火移到他脸上看了很长一会儿，"你必须赶在所有人之前"那句改由她亲口说出，情报从"线索"档位升至"嘱托"档位。
- 若林恩汇报完自缚天使的怜悯后顺势请求主母顺带讲一讲召唤四阶段，则她不答而笑，把"去找西仪式塔执事"一句直接递出，E45 的引入不需再绕一圈铺垫，直接以"主母亲自安排"的版本触发。
- 若林恩在第一百次失败时就已经试图用唾液入炉但被主母当场没收，则熟练度停在 100 不动，事件按"提前干扰"结算，盗版药剂不成立，主母加赠一节"什么时候才轮到我这份"的私下讲解，后续那一份圣血改在她自愿时亲手交付。
- 若林恩得到 200 熟练度后不接着追问战事、转身回店立"炸炸平安"成就牌，则巨像脑情报这一段不触发，事件按"完成条件半数达成"结算，E45 引入段改为左左替林恩跑腿打听，情报档位下降一个层级。
- 若林恩炼出盗版药剂后主动把第一瓶递给主母请她品鉴，则她瞟一眼不接手，只在炉沿轻轻敲了一下，炉膛里残余的紫焰刺刺地转成一线金辉绕过他指尖，记入偏离账本"她其实没收下这一瓶，但把它当成了炉子的一部分"。
- 若林恩当着左左的面把那句"那主母……可以把您用过的姨妈巾借我用一下吗"完整说出口，则左左的捧腹升级为滚地狂笑，被缚天使的圣光连炸轮数加倍，【炸炸平安】成就弹出时左左在笑声里多加一句"这次我服气"。
- 若林恩愣住没去接那盆唾液、任它凉了半晌才回神，则口水温度掉到底，第两百次入炉时紫焰不起、出炉的是【自缚天使的怜悯（赝品）】而非盗版，能力压制诅咒档位减半，主母的"忍耐到极限"在她换一盆温水递来时多一拍无言。
