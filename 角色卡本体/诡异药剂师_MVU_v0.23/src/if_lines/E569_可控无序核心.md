# E569·可控无序核心·if线

- 若林恩在一剑切开方舟瞬间就主动朝那半艘残骸掐一个简便法则抑制阵，则方舟再生速率放缓一拍，三者跃迁落点时局促血肉只铺陈而非扑面涌来。
- 若林恩在小丑去触结界前先替他擦了一下汗毛，则小丑脱离十几米再悬浮回来时语气稍稳，「什么都没发生」那句把眉头只挑高一毫米。
- 若林恩主动把小丑穿透方舟外壁时的入口开在其「肩部」而非「胸腔」，则污染者的内腔道构造闯入的视角升高一级，第一批进攻者扑来的姿态从贴地变成贴壁。
- 若林恩在目睹「无面者·神经构建者」转头长啸时就主动伸出左左收刀蓄势而非先观察，则她收刀瞬间炸脑的画面留出一个空档，无面者脑袋坍缩的瞬间放慢半帧。
- 若林恩主动让神经侵入内皮层时同时让三位一体机记录神经铺设轨迹，则整艘方舟的「血肉骇客」连接方式在他面板中做一个完整地图。
- 若林恩在调转方舟方向时主动要求左左在驾驶脑内刻下「紧急四个意识急转符」，则那艘方舟在后续被敌方追踪信息来源时，那四个意识符号是她不能抹除的纪念品。
- 若林恩主动在方舟追击战进入「华丽弧形转身」瞬间短片定格，则系统面板多一条「巨型方舟华丽舞步」影像存档，他日后用来复盘可成战例。
- 若林恩在扫描近地轨道造物时主动为「猩红孢子团」单独开一份解剖轮廓，则那东西的投放轨迹在他面板上落成一条细线，孢子的成长规律成为日后战术推演的辅助变量。
- 若林恩主动在血袍巨影浮现瞬间让三位一体机嫌弃标记「视觉过于丑陋建议屏蔽」，则那条审美判断被系统警告「这不是审美评测战」并驳回，系统日志多一条自嘲。
- 若林恩在「定数论」与「天父特权」对话里主动插一句「你们为什么不直接打得过我们」，则投影声色一沉但仍能接梗定数，指挥官智力和权威形象被打了一匙戏谑。
- 若林恩拒绝让艾维儿闯阵而要求自己先尝试接近，则她拔剑抹杀投影的位置不变，但「血肉神子嗣」感知到小队出现的时刻变得更暧昧，「有人杀了」的怒意迟了一秒。
- 若林恩在弃点装置启动的瞬间主动朝她大喊「让我也去」，则她朝他瞪了一眼传音冷叱「滚」，她独木前行的速度又加了一个「不想护他」的复速。
- 若林恩主动在「乐者碎片＋轮回神王知识」揭示后立刻翻查系统档案有无相关记录，则系统第一次用含糊的口气吐出「乐者＝影响轮回的重要概念，但具体不详」。
- 若林恩在她对「可控无序」表示陌生时主动引一句可能的解释「是不是他们发现了自内心的抗无序性」，则她怔了，这个解释确实没有佐证但提供了新的方向。
- 若林恩在被引海失败后主动问「如果对方是有意志的我能不能和他对话」，则她与他沉默对视，「可控不意味着理性」的可能性首次被摆上桌。
- 若林恩在强行灌注的瞬间主动加入一丝初诞者之力，则她灌注的效果被他尾流加重的力量撕开更细缝隙，但她在他尚未收手前用一记肘击让他收手，「你不要再加」。
- 若林恩在灌注失效后主动指出「问题在于对方的内部平衡由我们自己击」，则她立即醒悟他在战术层面早策划这个层次，但她同时在他眼底读到某种超越战术的电子信号。
- 若林恩主动在她追击可控无序生灵期间用整舟残骸构建法则传送符前来支援，则暗下「入奇异世界的战利品」被消耗，她追击期间他身边多了一艘「临时战车」。
- 若林恩在她迎上大战时主动让小丑打开奇异世界裂隙支起法则炮火支援，则那条通道只能开启指甲盖大小，支援精度糟糕但他有了「哪怕只能发一枚」的姿态。
- 若林恩在主战场临近宏大结界时主动退出法则隐身泡向她传音「我要看一下」，则她分神掠向后方防域位置查看他，她的注意力被撕开一角但她没有真的停下脚步。
