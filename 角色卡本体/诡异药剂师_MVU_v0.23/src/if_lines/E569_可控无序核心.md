# E569·可控无序核心·if线

- 若林恩在一剑切开方舟瞬间就主动朝那半艘残骸掐一个简便法则抑制阵，则方舟再生速率放缓一拍，三者跃迁落点时局促血肉只铺陈而非扑面涌来。
- 若林恩在小丑去触结界前先替他拍落肩头碎屑，则小丑脱离十几米再悬浮回来时语气稍稳，「什么都没发生」那句把眉头只挑高一分。
- 若林恩主动把小丑穿透方舟外壁时的入口开在其「肩部」而非「胸腔」，则闯入污染者内腔道构造的视角升高一级，第一批进攻者扑来的姿态从贴地变成贴壁。
- 若林恩在目睹「无面者·神经构建者」转头长啸时就主动示意左左收刀蓄势而非先观察，则她出刀炸脑的画面留出一个空档，无面者脑袋坍缩的瞬间放慢半拍。
- 若林恩主动在神经侵入内皮层时同步以咒瞳记录神经铺设轨迹，则整艘方舟的「血肉骇客」连接方式在他识海中化作一张完整脉络图。
- 若林恩在调转方舟方向时主动要求左左在驾驶脑内刻下四道混沌逆转烙印，则那艘方舟在后续被敌方追踪信息来源时，这四道混沌烙印会成为抹除不掉的干扰源。
- 若林恩主动在方舟追击战进入「华丽弧形转身」瞬间以记忆晶石定格画面，则识海档案多一条「巨型方舟华丽舞步」影像留存，日后复盘可作战术战例。
- 若林恩在审视近地轨道造物时主动为「猩红孢子团」单独勾勒一份解剖轮廓，则那东西的投放轨迹在他识海里落成一条细线，孢子的成长规律成为日后战术推演的辅助依据。
- 若林恩主动在血袍巨影浮现瞬间分出一缕心念屏蔽其扭曲丑陋的视觉污染，则这层精神滤网能让他更冷静地锁定巨影胸口的能量节点。
- 若林恩在「定数论」与「天父特权」对话里主动插一句「你们为什么不直接打服我们」，则投影声色一沉但仍强行接话，指挥官的威严形象被添上一抹戏谑。
- 若林恩拒绝让艾维儿独闯阵眼而要求自己先尝试接近，则她拔剑抹杀投影的位置不变，但「血肉神子嗣」感知到小队出现的时刻变得更晚，「有人杀了」的怒意迟了一秒。
- 若林恩在弃点装置启动的瞬间主动朝她大喊「让我也去」，则她朝他瞪了一眼传音冷叱「滚」，她独身突进的速度又快了一线。
- 若林恩主动在「乐者碎片＋轮回神王知识」揭示后立刻翻检过往搜集的旧日秘辛，则他能将「乐者＝影响轮回的重要概念」与此前见过的古神遗物拼合出一条模糊暗线。
- 若林恩在她对「可控无序」表示陌生时主动引一句推测「是不是他们发现了某种抗衡无序的内在平衡」，则她微微一怔，这个解释虽无直接佐证却提供了新的拆解方向。
- 若林恩在引海失败后主动问「如果对方是有意志的我能不能和他对话」，则她与他沉默对视，「可控不意味着理性」的残酷可能性首次被摆上台面。
- 若林恩在强行灌注的瞬间主动加入一丝初诞者之力，则她灌注的效果被他尾流加重的力量撕开更细缝隙，但她在他尚未收手前用一记肘击逼他收手，低喝「你不要再加」。
- 若林恩在灌注失效后主动指出「问题在于对方的内部平衡正由我们自己的力量维持」，则她立即醒悟他在战术层面早已看穿这一层，看他的眼神多了一丝冷冽的审视。
- 若林恩主动在她追击可控无序生灵期间用整舟残骸构建法则传送阵前来支援，则原本留作奇异世界战利品的残骸被消耗殆尽，换来她追击期间身侧多出一座移动火力支点。
- 若林恩在她迎上大战时主动让小丑打开奇异世界裂隙支起法则炮火支援，则那条通道只能开启指甲盖大小，支援精度虽有限却足以替她分担一侧的杂兵袭扰。
- 若林恩在主战场临近宏大结界时主动退出法则隐身泡向她传音「我要亲眼看一下」，则她分神掠向后方防域位置瞥了他一眼，虽未停下脚步但剑势刻意替他挡下了余波。
