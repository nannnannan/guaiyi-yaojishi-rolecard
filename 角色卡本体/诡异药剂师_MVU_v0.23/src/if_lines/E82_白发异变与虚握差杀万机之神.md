# E82·白发异变与虚握差杀万机之神·if线

- 若林恩在黑弦月中弹落地瞬间嘶吼着她名字扑过去把她护进怀里，则后背迎向湮灭死光的姿态先于任何算计成形，紫色紫罗兰法阵以他为轴心照常浮现。
- 若林恩在黑弦月倒下后短暂僵住没有立刻挡上去，则苍银死光先压到，异变引信晚一拍被引爆；法阵成形时她体表已多一道永久焦痕，但"白发异变＋差杀＋永久握痕"主链仍收束。
- 若林恩在挡身前下意识垫在黑弦月下方而非上方，则他先被弹雨掀飞再仰面迎死光；白发形态出现时他倒地位置贴着她断臂一侧，血迹与她的火花混在一处。
- 若林恩在异变刹那对体内那位本能恳求"再借我一点"，则法阵无瞳之眼先于花朵完全绽放，白发存在先扫过身后黑弦月半秒再望向机械巨龙；这一回眸被蜂巢记为"异常"。
- 若林恩虚握时五指没掐实只悬在巨龙颈前，则万机之神脖颈上的不是凹陷握痕而是一圈压缩空气的扭曲印记；"永久握痕"标记替换为"残留握意"，蜂巢面板照样爆表。
- 若林恩虚握时把方向略偏对准龙首正面，则白发身影掐住的是颅骨而非颈椎，机械巨龙当场失去发声能力但意识保全；"差杀"达成判断维持成立，握痕改记入额甲正中。
- 若紫罗兰法阵浮现时林恩刚好站在黑弦月散落的机油与骨屑旁，则她的残屑被光流吞入，白发形态手中多缠半缕银发；此后万机之神面板扫描"白发身影"时检出战斗人偶特征频率。
- 若黑弦月在倒地昏厥前强行睁开眼看了林恩最后一眼，则她空洞瞳孔里映出的不是白发存在而是那个拼命抬起肩的黑发少年；该画面完整保留，成为 E85 强吻时她脱口"我看到了"所指影像。
- 若黑弦月中弹擦过发声模组而非中枢，则她在死光压下前喊出一句含混的"林恩"；白发存在五指因此微顿半拍仍在一息内完成差杀，这条颤抖被蜂巢识为"异常战栗"。
- 若林恩昏迷前从白发残影里察觉到那位存在在笑，则他倒地时唇角带一点无法自控的弧度；艾雯爵士后续把这抹弧度误认为嘲讽，记为 E83 认义弟前的第一次微妙试探。
- 若万机之神被虚握扼住一瞬主动向白发存在投射通讯波，则法阵内回给他一段不属于任何已知语言的长啸；该长啸内容解不出，但记为后续他主动退让的私人理由。
- 若湮灭死光只九成在光瀑中破碎，则余下一成光屑洒在战场，机械军团非精锐单位面板同时闪一秒"复苏度 9%→10%"的伪数据；该伪数据不入主线，但记为 E83 救场间隙艾雯读到的噪点。
- 若白发形态散开前最后回望的不是黑弦月而是林恩自己站立的位置，则法阵消隐瞬间有一缕白发自他颈侧落下压在她断臂创面；此白发融不进任何材料，只能收进她胸前储物格。
- 若林恩倒地时被诅咒镇压残留的六诅咒之一在此刻暴起，则他昏迷中浮出"七罪同现"黑纹又被强行按下；艾雯到场时黑纹已隐去，只留一缕灼热焦味，作为 E84 时"祂"短暂醒来的旁证。
- 若林恩倒地时紧抓着黑弦月崩断的半截丝线，则丝线在他指缝里被白发余温烙出浅紫纹路；后续归还时她把这缕纹路编入左腕。
- 若万机之神在握痕成形瞬间就主动切断了与蜂巢的同步广播，则诸机械单位只感知到主宰失联的那一秒空白；这段空白记为后续与林恩重启对话时未被广播掩盖的私域记忆。
- 若白发形态消散时光瀑中传出一次类似"风掠过长空"的颤音，则战场边缘所有残破丝线同时绷直又松开；黑弦月被救起时该余音成为 E85 她脱口"刚刚那个东西不是林恩"的唯一物证。
- 若林恩在白发出现前就因异变指引用血在掌心画了一道无瞳之纹，则法阵成形速度被压到一息以内；消隐后掌心纹路持续渗血，诊为灵魂刻痕，无法以常药止血，只能由艾雯灵能封住。
- 若湮灭死光破碎时空中掉下一枚未引爆的主炮弹头砸在两人一侧，则艾雯爵士比原案早半息入场先把弹头踢落海沟再回看现场；该时间偏移让 E83 首音错一拍。
- 若黑弦月昏迷前用手臂把林恩推向爆炸反方向而非压在自己身下，则她后背承伤位置下移、关节毁坏更彻底；白发形态仍以其为掩体挡死光，但 E83 试图抱起她时艾雯会说出"伤势比看上去更深"的台词。
- 若林恩在白发形态消散前从光瀑里听到一声像从很远地方传来的"哥哥"式呼唤，则他昏倒后意识残影里闪过一段无法捕捉的残响；本事件不对残响来源作任何揭示。
- 若万机之神在握痕成形同时反向发动过一次"核心自爆警告"，则白发存在没动手引爆核心，只把警告信号压回主宰体内；万机之神自此刻起把"白发存在能解除我的自毁"作为私下记住的恐怖事实。
- 若湮灭死光破碎后，白发形态在转身望黑弦月那一瞬发出一次极轻的叹息，则这声叹息在灵魂层面被她残存意识接到；她醒来后只记得胸腔里最深处有某处被轻轻碰过，作为 E85 她自述"我好像有点什么"的引子。
- 若艾雯爵士在白发形态尚未完全散去时已先一步潜入高空俯视，则她看到完整的白发存在与机械巨龙对峙画面；她不在本事件出手，但把"刚刚那个东西"记入灵能日记，作为 E84 认义弟时她对林恩说"我认识那种眼神"的凭据。
