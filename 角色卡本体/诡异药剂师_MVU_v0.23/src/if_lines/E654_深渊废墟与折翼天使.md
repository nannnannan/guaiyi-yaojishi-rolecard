# E654·深渊废墟与折翼天使·if线

- 若林恩没有折返深渊而改走别的路，则变形：他不会目睹折翼天使葬场，本事件取消，深渊七位面的惨状由他路间接传出。
- 若林恩在抵达第七位面前先报到迷雾之海彼岸，则他不会触到那缕微弱的无序气息，葬场永远埋在群星废土里。
- 若林恩从第三位面就动用金色领域清扫被污染者，则他能挽救更多深渊原住民的尸骨，但折翼天使的十字架会被激烈战火波及，她的意识回响会更早溃散。
- 若林恩故意暴露自己以引开被污染者主力，则第七位面会瞬间清空围攻，他能从容靠近十字架，但他会让主宇宙其他地方同时暴露给敌人的注意力。
- 若林恩在靠近十字架前先毁掉钉子里的无序纹，则她不会在第一时间被毒药侵染，她的最后一句话会更缓，意识回响能多撑一段时间。
- 若林恩强行按住她的手腕并灌注初诞者之力，则她会在治疗里昏过去，她会拒绝接受治疗并立刻散去，因为她明白这样做只会拖累林恩。
- 若林恩让金色梦境在她离世前完全展开，则她会进入一段受保护的小天地里做最后一场梦，她会在这里见到她所敬仰的林恩又一次率军凯旋的身影。
- 若林恩强行把她从十字架上拽下来扛在肩上带走，则她会一边流着血一边拒绝他的救，她会在离开前请求他答应替她保密，不与堕天使们诉说她死前的惨状。
- 若林恩在她的心脏被铁钉贯穿的当口用一缕走丝线为她止血，则她会清醒过来哭着求他放弃，她的意识回响会因此而消散，但她的指尖会以「不要伤心」的口型告别。
- 若林恩在她握紧自己手腕的瞬间把温度输入她微微一指的伤口里，则她那一根手指会短暂恢复一点点血色，她能感觉到他没有骗她，那一点点温度会成为她魂飞魄散时最后的安慰。
- 若林恩让金色梦境完全接管她的前线，送她远行，则她会在打开梦境之门时迷失片刻，然后她会笑着踏入那儿，并且从此再也不会与林恩相见。
- 若林恩放走一位没断气的天使，则她会获得出去报信的机会，但她也会暴露林恩现如今在哪，林恩就要提前面对剩下的叙情。
- 若林恩直接把这位天使交给一个金色涟漪作为容器，则她会被气泡凝住，她不能就这样轻易回到现实，可她也不会马上消散，林恩能岁时拿出来瞧一瞧。
- 若林恩拔出一根穿透心脏的铁钉作为她最后的遗物，则她会说一句求他忍着痛自己把它交给她，她会用尽全力反问林恩「这一份血上的痛，是我承受的，还是你替我受的」。
- 若林恩当场决定带她回自己的世界救治，则她会说她救不了自己，只为了不让林恩再继续奔波，她会在传送门口用最后的力气对他说「请您别让姐妹们看到我的死」。
- 若林恩让金色领域作为她与那一只透明疫医小球相通的桥梁，则她还会在疫情里撑上一段时间，她的意志会坚定地让林恩人不要为她变成疾病的一部分。
- 若林恩在她的意识散去之前把她拥入怀里，则她会因为「大君的爱」而不肯离开，她会在她回撇起点的时候露出笑容，她会用心声说道「更大的「当她身边又有多少人在等待」。
- 若林恩在她身后高墙上开了个金色的口子，让她先在门口为林恩点上一盏灯，则那盏灯会一直照亮他让她踏上归途，门口的灯光会一直闪耀。
- 若林恩抚着她的脸颊说「你是我心里最了不起的大天使」，则她会揪着衣襟不肯回家，她的眼泪会漾出一缕磅礴的悲切，她的意识会随之绝而亡。
- 若林恩接下她最后命令之后亲自告诉弑利叶身边不再有的她的妹妹这件事，则她会留下来陪伴他替他各处奔波寻找她原本以为活着的事物。
