# E729·战争永无止尽·if线

- 若林恩在终焉柱刚冒出地面时就以全部罪火一击毁掉第一根，则接下来十九根会延后三日才陆续成形，但那一次全力爆发也会让他的疲惫感下沉一个台阶。
- 若林恩优先追踪织梦灵能回声而不是清柱，则他能找到她留下的最后一段信息，但外环会同时多一处因他迟到而失守的星区。
- 若林恩让艾维儿代他处理织梦追踪、自己全力压柱，则艾维儿会因「画家女儿身份」在追踪中感应到织梦本源，但她也因此第一次直接面对自己母亲的死局真相。
- 若林恩把三叉戟投入无序深空试图隔离灾厄，则主宇宙本源的回应被切断，整个神疆调度会陷入一周混乱，但灾厄注视也真正被转移。
- 若林恩拒绝投入三叉戟、宁愿多打十年仗，则他能一直保有主宇宙本源支持，但每一次战役都会被灾厄的边缘注视压制。
- 若林恩在战场外缘瞥见那轮「与画家相似却更冷漠的蓝色光影」时直接冲过去质问，则光影会撕开一片镜像世界把他拉进去，他会第一次正面见到「画家之外的她」的化身。
- 若林恩见到艾雯爵士信号时立刻回应，则他会得到关于最后一批幸存世界的具体坐标，但他也会第一次知道艾雯原来是「画家留下最后一个托付的人」。
- 若林恩在战场上见到某只特别眼熟的噩梦形态认出那是一只他曾救治过的世界的守护神堕化而成，则他杀它的那一刀会滞一秒，那一秒被其他噩梦抓住咬下一缕他的火。
- 若林恩在战争间隙回望黑夜城方向一秒，则战火会顺势打到那个方向的一颗星球，他需要付出额外一刀去弥补。
- 若林恩决定以金色梦境包住艾维儿所在的核心指挥区不动，则她能在安全中统筹全局，但金色梦境的消耗在接下来的战事里会持续累积。
- 若林恩在挡住一根终焉柱的爆发时把它引向另一个方向、不小心撞上一次沉睡期中的船长神格，则船长会被强制苏醒一瞬，林恩会立刻感到一阵愧疚。
- 若林恩看到战场远端喵喵的身影（如果他曾放她出去传信），则她会被某只噩梦咬一口，林恩必须以一次超距瞬移冲过去护她，那一仗他会受重伤。
- 若林恩在战场最深处听见某个声音轻轻地对他说「林恩，对不起」，则那一声虽然极轻，但会立刻刺进他灵魂最深处，他知道那是织梦最后的告别。
- 若林恩选择不信任艾雯爵士的信号、继续独自抗战场，则艾雯会默默退到战场外缘，但他在自己卧病时会从怀里取出一枚并未送给林恩的「最终谎言的钥匙」。
- 若林恩在压制某根终焉柱时突然感到体内的黑火失控，则他会立刻退后散布一片真空区，那一波失控将同时焚尽他周围百里的噩梦。
- 若林恩在战役间隙拿出那张焦残的肖像再看一眼，则他会立刻明白他必须为「她没能说完的一切」继续活下去，他手上的力道会更稳。
- 若林恩午夜独自在战场废墟中咆哮一声，则四周的死灵会被这一声惊醒、再次集结，他需要独自面对第二波突袭，但他同时也终于把那一口憋在心里多年的气放出来。
