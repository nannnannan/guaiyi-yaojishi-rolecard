# E729·战争永无止尽·if线

- 若林恩在感知到闺房结界剧烈震荡消散的第一时间便一脚踹开房门冲进去，则他会在织梦握着灵能匕首刺入咽喉的下一秒便扑到她面前，拼死按住她喷涌鲜血的颈部伤口，抢回最关键的一线生机。
- 若林恩在满地鲜血中疯了一样将初诞者之力与三叉戟的浩日本源灌入织梦体内、嘶喊着让她不要睡时，死死握住她冰凉的指尖，则织梦会在彻底拥抱混乱与沉眠前极其微弱地反扣一下他的手指，作为无声的诀别。
- 若林恩在自缚天使等黑夜城家人赶来、看到浑身是血的他与昏迷不醒的织梦而忧心忡忡时，哑着嗓子下令「把所有的灵能医疗资源全部调过来」，则夜医们会立刻在奇异世界外围搭建起最高规格的维生法阵。
- 若林恩在守候病榻、得知织梦是主动拥抱混乱思绪拒绝清醒时，立刻意识到她是为了成全自己三位一体的「唯一性」才选择自尽，则他的双拳会捏得骨节发白，心底对第三阶段门槛的抗拒与悲愤达到顶点。
- 若林恩在边疆传来「梦魇大军以肉身为桥强行冲破罪火防线」的血色警报时，仍在织梦床前多停留了十息替她掖好被角，则他在撕裂空间踏入前线战场的那一刻，周身爆发出的罪火会因滔天怒火而暴涨三成。
- 若林恩在杀入无序深空、亲眼看见二十余尊实力无限逼近本体的魇魔围绕着重建的「终焉之柱」向自己张开天罗地网时，没有半步后退而是直接提刀冲入柱群中心，则一场震动整个主宇宙的惨烈血战将瞬间白热化。
- 若林恩在二十余尊魇魔借终焉之柱引导出灾厄本体力量、令他独木难支的危急关头，不得不咬牙将镇压织梦伤势的三叉戟从奇异世界召唤至前线战场，则他在握住三叉戟的那一刻心头会如刀割般剧痛——因为他清楚三叉戟一旦抽离，后方的织梦将彻底失去最后的本源庇护。
- 若林恩在召唤三叉戟横跨虚空驰援前线的同时，留下一缕自己的初诞者本源封在织梦心脉处，则这缕本源能勉强支撑织梦在油尽灯枯前化出最后一缕红裙虚影，去边疆废墟见艾雯爵士最后一面。
- 若林恩在前线与二十余尊魇魔浴血搏杀、战局陷入绞肉机般的僵持时，感知到沉睡了二十余年的康斯坦丁船长与银色幻想强行破开沉眠苏醒参战，则他会通过神疆向两人传去一句「小心，别硬拼」，三人的气机在星空中再度遥相呼应。
- 若林恩在船长与银色幻想率领所有半神与新神杀入边疆防线替他分担无尽梦魇潮时，将全部火力集中在那根引导灾厄力量的终焉之柱上，则他能硬生生斩断终焉之柱与灾厄本体的连接，为这场全面大战锁定胜局。
- 若林恩在斩碎最后一尊殿后魇魔、浑身浴血地准备第一时间撕裂空间赶回奇异世界看望织梦时，心中突然掠过一阵莫名的心悸与空落，则那正是织梦在漫天黑雨中彻底消散的瞬间。
