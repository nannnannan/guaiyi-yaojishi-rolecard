# E454·灵能课与失却之海·if线

- 若林恩在盘膝装睡反向爬逃的瞬间主动用心声劝阻左左「你别跟过来」,则她会试图飞扑前来,「我不熟,只是表面朋友」的划清台词被压一拍。
- 若林恩主动张口说「我知道错了」,则他被灵能立场拖走的轨迹不变,但「整晚课」宣布的语气被他提前软化一拍。
- 若林恩偷偷瞟那一人高的「目录」之前先抿一口手里的血包压惊,则他一口一口喝的画面被压一拍,他被震惊之后的「只有这些吗」台词不变。
- 若林恩在听到目标其实是身后整座图书馆的瞬间主动反向攀上立场壁,则他被康斯坦丁响指昏睡的时点会被提前半拍,「鬼啊!!」呼喊画面不变。
- 若林恩主动提议让喵喵陪他一起进入失却之海,则她会被艾雯爵士温柔拒绝,「她不拿书」的理由不变,他被独自推进船舱的画面不变。
- 若林恩主动跪求「我不想看灵能能先看血肉吗」,则他被驳回的台词更凛,「我已经拜托别人加速」的宣布被提前一拍。
- 若林恩一到失却之海船舱就先把书册一把推开再开始冬眠,则他被加深坠落百年的窗口仍会准点出现,他考不出空间修改变量的画面不变。
- 若林恩在几百年精读期间主动联系左左的心声,则她和星海之间的那条透视线被留了一扇窗,他被几千年读完之后的疲惫画面被压一拍。
- 若林恩在结束几百年之后主动自夸「我没摸鱼哪怕一秒」,则艾雯爵士拍他肩膀的欣慰台词被多挽一拍,「最好学的人类」台词不变。
- 若林恩在机械背诵段主动停下来打断自己,则他不会被康斯坦丁骨拳砸醒,他被醒来的方式改为灵能共振,「学傻了」的评价仍准时到达。
- 若林恩在看到书籍呕吐的瞬间主动申请「我能消化几年再看吗」,则他被推入实践的台词被提前一拍,「先教干涉空间」的宣布被插到胃前面。
- 若林恩多日无休里在夜静时段主动从系统商城点一杯咖啡端上去,则他被艾雯爵士看到咖啡时惊异画面多一拍,「你这时间还能喝咖啡」的台词被多说一句。
- 若林恩在灵能浮动高塔期间主动让左左在他掌心里一挂,则他被压一挥的重量更多一分,但「艰难浮动一座高塔」的画面不变仍被艾雯赞许。
- 若林恩在「一念即达」教读之前主动问「我能把书全送到她面前吗」,则他被允许试图的窗口之后他真用灵能搬了一座书山,但「一念即达」教读不变。
- 若林恩在女澡堂误闯瞬间主动闭眼再反向起跳,则他不会看到半个尖叫画面,「未看见的远离」画面不改。
- 若林恩拒绝进入无情无感状态而选择保留一线柔和,则他在城墙与塔中两次跳跃之间会叨咕一句,「变成了一个旁观者」画面不变。
- 若林恩在落地镜碎裂蝴蝶的场景里主动抓一只蝴蝶细看,则他被艾雯爵士警告「别让它扯到你」的台词被多说一句,「改现实的本事」评价多再添一线自信。
- 若林恩主动问艾雯「我的灵能为什么是唯心」,则他被解释的台词多添一道迷,「万事万物的真理被心思看到的距离」被加重一拍。
- 若林恩在自评阶位时主动在「死兆级……」之后补一句「再来几年」,则艾雯爵士微笑接「那为什么不试一试呢」的邀试台词被压一拍。
- 若林恩坚持拒绝邀试而申请「让我先跑一遍百公里」,则他被驳回的台词会更直,「你现在的根基够」的画面不变。
- 若林恩主动提出「我带她一起去机械基地」,则艾雯爵士会赞许朝他多看一眼,他被邀请作决定的画面多一拍,但机械基地的通讯段不变。
- 若林恩主动请艾雯爵士先去市场端一杯饮料再陪他上机械基地,则他被允许的拖时间窗口被延长一拍,「超凡机甲评定」的宣布窗口不变。
- 若林恩在结束一日课程反向爬逃时主动掏出符咒「传送转移」,则灵能立场会察觉并直接抽空他的动作,他被响指昏睡的画面会稍快一拍。
- 若林恩在被宣布整晚课的画面里主动说一声「我喜欢这个课」,则他被艾雯爵士笑眯眯注视画面多一拍,「我猜你终于认真了」的台词被拉前。
