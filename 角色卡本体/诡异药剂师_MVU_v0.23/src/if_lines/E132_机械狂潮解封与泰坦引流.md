# E132·机械狂潮解封与泰坦引流·if线

- 若林恩在万机神性镇压松动前主动与其最后谈判、拖延镇压解除的节奏，则虚化黑洞展开时再增添数秒缓冲，但咒骂性宣战被收敛成阴沉冷语，「地狱之力」的证明以更低姿态呈现。
- 若林恩以咒术或药剂先行试验虚化黑洞的空间稳定性、显式记录下舰群显影坐标的重复模式，则巫神对抗舰群时多一层先验情报，泰坦引流成立时虚化裂缝出现的规模被半量化写清。
- 若林恩在艾雯爵士启动光束引导前为巫神火力强化提供阵位支点（玩家声明行动），则引导光束成立时不消耗全部强化余量，泰坦转向后巫神仍剩一轮阻断伪指令的能力。
- 若林恩站在接引光束路径上、以自身为可观察节点帮艾雯爵士校准泰坦后脑落点，则斑秃范围被压缩到拳心大小，泰坦一斧斩出的外放军势从四分之一被默认写高到三成，但林恩本人受灵能余波灼出肩伤。
- 若林恩拒绝亲临接引位置、改由巨像之脑远程测距牵引光束，则泰坦转向成立但斑秃被推演成"另一半火没能接到的残影"，虚化裂缝出现路径改由泰坦斧刃自然斩断而非受控穿透。
- 若林恩主动调用血锯召回旧战场遗骸、堆在泰坦与他之间的距离中充当导火缓冲，则虚化黑洞在泰坦斩向它时的吞纳节奏被拖慢一拍，万机本体反应时间变相被延长。
- 若林恩在巫神传音判定「他已经不在这里了」时反问虚化本体是否真正远离，则巫神把头骨侧的巫毒定位权推给林恩一次，林恩得以亲眼看到虚化空间的边缘抖动一条细缝。
- 若林恩在万机虚化展开时同时以咒术强行刻画虚化黑洞的环形边缘、限定其扩张速度，则舰群铺天盖地显影的速度被压制，齐声播报「无差别灭绝，启动」的节奏被拆成三阵广播，泰坦引流窗口更明显。
- 若林恩在泰坦入场前先以自身血脉的气味制造一次战场标记，则泰坦本身对当前最高仇恨的判定被打偏一拍，转向万机的时点延后半息，斑秃直接对应额角而非后脑。
- 若林恩在泰坦转向万机后以行动公开为艾雯爵士的引导背书（玩家声明），则全场死寂后血肉支配者那一句「患难见真情」之前增设一段林恩方的简短陈词，万机爆出的咒骂对象按次序先点林恩。
- 若林恩让左左在引导成立瞬间主动以血肉藤蔓接住任何从艾雯灵能外泄的余波，则林恩阵营伤亡被压至较低，但血肉支配者隔空感应到了这层同源血脉反应，「患难见真情」的台词里多出一句关于左左的评价。
- 若林恩拒绝让小小介入、仅让她在两千公里外的安全边缘提供灵能防护，则引流成立，但小小对「血肉瘟疫容器」未提前露面牵涉，E133 的舰群分化因果不变但首舰落地时的接应名单减少小小。
- 若林恩在虚化黑洞展开后就一直主动核对其显影舰群数量与现场实际损耗比，则他对「数据持续补充但受位阶限制」的推断先于队伍说出口，为后续 E133 识别远端分化舰群埋下逻辑依据。
- 若林恩在泰坦一斧斩破发器后以咒术反向追记万机虚化受创的方位，则虚化裂缝所在坐标成为持续可见的临时锚点，万机本体向南撤走的雏形在 E133 触发前即被林恩阵营标记。
- 若林恩拒绝局外旁观、坚持站在艾雯爵士与巫神中间预备随时承担冲击后果，则引流成立时他获得直面两股根源级别威压的伤与代谢亏，但万机转而以不死不休的敌意直指林恩本人，「我此生若不杀你」改由林恩承接全部。
- 若林恩在引导路径被确认后主动丢出若干爆裂药剂到舰群集火方向，则泰坦被魔渣与咒光双重吸引，他转向时点难以推迟，但万机在远端立刻抛出新一批舰群填补损口，E133 的集团分化意识变厚。
- 若林恩在万机虚化展开时启动一次大范围治愈烟雾以淹没全场视野，则巫神强化、艾雯引导失误的概率因视野噪音上拍，泰坦转向成立但斑秃落位被默认写偏离预想，虚化裂缝出现形态变形但仍可成立。
- 若林恩在泰坦斩得虚化空间颤动后主动跟上、以咒术撕开一条对虚化空间的第二道细缝，则万机本体急迫感被推高，「我此生若不杀你」的台词被默认写入变为尖啸佈告，主线死仇成立程度增加一档。
- 若林恩对万机虚化开拓出一道反向咒术测距、在其毁灭指令下达时就获得星内舰上一层指令的局部可读性，则他提前看见「弃子舰群」的落成计划，E133 的识别动作从验收变成他的主动举证。
- 若林恩在引导成立前强行把巫神匕首贴近黑洞边缘以巫毒咒杀定位万机本体，则巫神确认「他已经不在这里了」的判定在她出力之前就被否决，全部后续转向动作在信息准确的前提下成立，但巫神匕首出现上一道不可逆裂纹。
- 若林恩在艾雯灵能即将枯竭时口服一剂咒力补给药剂、替她托住最后一段引导，则曝光成功但药剂 overdose 的代价落在他本人，后续 E133 全程林恩处于能量过贫状态。
- 若林恩在万机虚化空间裂缝出现后立刻召唤左左横渡到裂缝上与其近距对视，则她身上感染同类的部分以原身意图与万机产生一次印化学衝，隔空干扰虚化空间稳度，泰坦后续一斧造成的裂缝尺寸被默认写深了一层。
