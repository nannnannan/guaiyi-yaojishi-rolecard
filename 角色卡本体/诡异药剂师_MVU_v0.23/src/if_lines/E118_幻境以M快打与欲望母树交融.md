# E118·幻境以M快打与欲望母树交融·if线

- 若林恩在塔顶开口先用「我们有共同的敌人」而非质问，则母树攻击节奏缓半拍，欲望权能拉满前的意识刺激波次减一，涩涩度峰值压到+50，但以M对拼窗口同步缩窄。
- 若林恩先让死兆傀儡送死换三秒观察出招前摇，则傀儡被捏爆时已记住两条主藤的衔接盲区，闪避与反击各让出半步优势，代价是失去一枚备用傀儡。
- 若林恩塞回碎裂咒瞳时把残余诅咒转接自缚锁链做一层诅咒锁，则藤蔓初次卷上即被反噬出细裂，母树多出一分对咒术师底牌的忌惮。
- 若林恩刻下的紫罗兰法阵是精简骨架版而非完整无瞳之眼，则起阵快一倍但半径减半，母树不必抬起全部枝干撑投影，互喂阶段意识冲击整体降一档。
- 若林恩硬吃第一波+50不反制，则意识烧到边缘时他把左左、白银之手、艾雯坐标全部锁进意识最深处，母树剥不到核心秘密，但他失去一次以M回敬窗口。
- 若林恩第一波回敬刻意压到七成拉延长线，则母树误判他后继乏力提前拉满权能，第二轮以M过载反噬，她的涩涩度直接冲破+80，垂柳妖精形态第一次在对峙中失态潮吹。
- 若林恩互喂时以咒瞳看穿她维持黑暗投影的力线路径，则他理解「她只剩一半火力」，主动激她说出被万机之神逼入绝路的真相，母树失神片刻被以M侵入心脉。
- 若林恩在绿叶萌发瞬间说「这是你自己本来就有的」，则母树停下攻击长达十秒，万机之神光柱冲天而起，希望破灭的绝望被加速推至。
- 若林恩把解咒银光引向她撑投影的根部而非枝干，则母树在「保投影」与「保自己」之间选后者，黑暗投影提前崩塌，事件直接滑向巨像之门争夺战。
- 若林恩被卷进树干时主动放弃挣扎任由藤蔓捆紧，则暴力层级降一档，但欲望权能注入浓度反而更高，「神性渗透」绑定扎得更深，替死复活属性狂飙上限抬升。
- 若林恩在撕扯中以犬吠咬住她探向心脉的主藤，则母树在失控中生出「他在护己之外还在伤她」的错乱认知，交融演化出扭曲的合作性撕扯，双方各留印记。
- 若林恩在力竭前用巨像之心把意识坐标钉进她妖核边缘，则他死后那片坐标成为母树无法拔除的异物，每次她沉睡或调动本源都会被这根不属于她的刺惊动。
- 若林恩在交融中用触手主动探入妖核外壁，则母树在极度屈辱与快感撕裂中发出原始尖啸，血肉古树藤蔓瞬间失编，游魂巷口袋阵现三秒真空，左左可借此撤离。
- 若林恩在被撕碎前把一枚欲望诱导剂拍进她花瓣最深处，则母树在他死后独承催情余波一刻钟，「他不会死」第一次压过「我要杀他」。
- 若林恩拒绝一切肉体交融并自我放逐出潜意识空间，则事件标记为取消，母树独力硬扛投影与万机之神，林恩失去神性绑定与替死复活，巨像之门路径彻底改写。
- 若林恩在交融中途强行分离欲望与神性只取神性不接血肉咒力，则他死时躯体完整但力量未飞跃，母树看着这具干净得近乎安详的尸体自我怀疑，心防裂开比交融更深的缝。
- 若林恩在意识消散前说一句完整、无算计的遗言（内容由玩家输入决定），则母树停手注视他彻底暗下去的眼睛，没有撕碎尸体而是把他安置在树干最深处，神性渗透多出一缕连她自己都没意识到的执念。
- 若林恩把终max以M一次性灌入，则互喂三秒达爆发阈值，母树痉挛失力，投影崩一角，但林恩意识同步过载，泰坦不死诅咒提前燃尽，死亡判定从「力竭」变成「自灭」。
- 若林恩全程不展示咒瞳、紫罗兰法阵或巨像之心权限，只用以M与不死诅咒硬闯，则母树认定他底牌浅陋，交融暴力层级上升，但她对他「危险程度」的评价被她自己下调一档。
- 若林恩在被拖入树干前把死亡坐标广播给机械意识群与银色幻想，则他死后两道外敌同时感应到血雾能量波动，母树在修复与情感余波中被迫提前迎敌。
- 若林恩爱交融中以咒瞳再偷一次欲，则涩涩度倒灌时他额外记下母树本源欲望的光谱，替死复活后对欲望权能抗性永久提升。
- 若林恩在死亡边缘绽放最后一个无算计的笑，则她抱着残躯静止了一个沙漏，血珠在脚边积成浅洼，她没有追左左也没有迎敌，只是把他留在最靠近树根的地方。
- 若林恩主动切断与替死娃娃的链接，则血肉咒力与神性照常绑定但替死复活不发生，他确实死在这片血淋淋的树干深处，母树从狂乱中清醒后第一次理解「永恒失去」，从此这株血肉古树再也不开花。
