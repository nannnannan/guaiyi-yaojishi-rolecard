# E36·左左醉酒与酒店暧昧·if线

- 若林恩抱左左进酒馆前先与守卫亮出夜医纹章并顺手递上一瓶药剂作为安插，则盘查过程被压缩为一次点头，左左在袍内补踹的裆部那一脚少了目击证人，「激动喊几嗓子」借口不再成立。
- 若林恩点的是最便宜的黑麦酒与烤角蹄，则左左当场拍桌、拐杖骨直指他鼻尖，微醺转成拍案骂街，酒店暧昧的进入条件整体重置，改由「深夜酒馆互吵」承接。
- 若林恩亲手撕碎烤象腿蘸酱喂到左左嘴边，则店家把她扒着肩膀咕嘟骂人的画面误读为小两口拌嘴，粉色豪华房间额外添了烛台，未声明亲密也未发生。
- 若林恩在左左爆醉段先开自诊断术压她酒意，则微醺与爆醉两枚状态被同时清零，旅店开房段与偷吻镜头不触发，事件标记为「醉酒未坐实」。
- 若林恩开房时坦白「左手和我连在一起只能同床」而不说报销，则店家收起暧昧笑容改开同行双人房，玫瑰与脸红油画都没摆上，偷吻机会改由他自己关灯时亲手制造。
- 若林恩在左左醉倒后只盖好毯子便独自躺下，则【背德的冒犯】不成就、好感+20与信赖+10缺位，「亲密的变异体」入门改由好感条原值兜底。
- 若林恩偷吻时右手未搭上左左后颈，则动作记下但缺一份肢体佐证，左左醒来只剩酒气没有亲近感，「密封式回应」的睫毛眨动未出现，好感+20减半结算。
- 若林恩在系统二选一的弹窗处点取消不做选择，则两个分支任务挂起，成就【背德的冒犯】被时序锁定，好感+10正常入账但信赖项不叠加，E37的蓝星信标照旧推进。
- 若林恩正视左左「你是不是醒着」的逼问并回以「那就做一些什么」，则她炸毛拍枕、心跳砰砰狂跳，事件停在唇齿之间的一丝轻微抚摸，下一步由她的动作或林恩的声明接管。
- 若林恩顺手清洗左左蜕皮后的左手根部旧痕再睡，则血心联结被主动推深一档，禁脔预备值+5，下一次分支任务到来时门槛整体压低。
- 若林恩当晚把醉醺的左左抱回黑夜城总部而不在旅店过夜，则主母在医护间撞见他抱人归馆，偷吻仍结算但事件地点改写为「夜色回廊」，记入偏离账本。
- 若林恩给左左灌一勺自配醒酒剂再躺下，则她半小时内彻底清醒，挑逗段失去前提，好感+20不结算，事件被标记为「亲密节点跳过」。
- 若林恩趁左左宿醉未醒在旅店床侧完成蜕皮缝合复诊，则偷吻机会窗让给一台临时手术，【背德的冒犯】让位给【夜半缝合】成就，好感+25、信赖+15入账。
- 若林恩次日结账才发现左左昨夜以他名义签了二十四瓶最贵红酒，则月俸被预扣两成，左左全程装睡装傻，好感条不动声色，事后她把酒瓶塞留在酒杯底下作纪念。
