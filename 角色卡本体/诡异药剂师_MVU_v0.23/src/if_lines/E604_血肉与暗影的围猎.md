# E604·血肉与暗影的围猎·if线

- 若林恩选择亲自处决两神而非号召围猎,则巨像偷学、人偶家星轨抢猎等支线不发生,双神陨落与神格现身仍立,但军团「人人沾染神血」的仪式感消失。
- 若林恩主动在号召围猎时追加一句「不许死人」,则战场攻击性反而更猛,林恩控场更紧,任何一帧失控都由他亲自出手拉回。
- 若林恩让巨像在硬撼血神时第一次就理解血气掌控,则她后续围猎战力暴涨,但那股「她不屈不挠」的精神弧光被缩减。
- 若林恩决定只让暗影序列出列而不让血肉序列出列,则巨像被按住待命,血神面对只有暗影根源的围猎,她偷学血气管理的路径不存在,后续巨像血肉神格的竞争难度陡然上升。
- 若林恩主动在围猎画面里点出人偶家「您是心灵序列」的事实,则她抢夺暗影路径的当场反讽更烈,星轨与人偶家的内部火花多一段公开。
- 若林恩让星轨的元素浪涛在人偶家合围时突然减半她的攻击输出,则王女的法力平衡被她主动让位于傀儡,后续星轨自身突破得到更多心理配置。
- 若林恩主动在血神临死三问时刻意迟一秒出手,则他的遗言完整传完,后续军团对「渡鸦的血债」的咀嚼由「被中断」变成「被听毕」,人心更复杂。
- 若林恩让血肉神格遁入虚空未被截获,则血肉序列的神位悬空,后续整个血肉根源集体失去方向,但林恩也不用承担「净化与温养」的漫长负担。
- 若林恩主动在拘禁血肉神格时对外宣称「它属于全盟约」,则两个根源闭关的画面被化为「谁先走进就谁」,后续闭关潮的场面被推迟到公开竞争。
- 若林恩选择把暗影神格当场颁给人偶家,则她在 E605 的交付画面消失,但她心灵之路与暗影之路的选择被提前摆上台,后续半神师承的描述更纠缠。
- 若林恩决定让夜神不死而让她投降被囚,则她的「朋友/自由」对话押后,但污染阵营多一个活口奴隶,后续审讯局面变得冗长。
- 若林恩主动在艾维儿说「看在过去」时让夜神回应「我从来没当你是朋友」,则王女内心被切断更彻底,后续她「那就是我们」的动摇方向从单一悲伤转向对友谊本体的质疑。
- 若林恩让林恩在夜神自裁瞬间出手阻止,则她被活体拘禁,后续 E605 的会议多了一个根本未被消灭的俘虏,夜神残存意志可继续反哺情报。
- 若林恩决定在围猎结束后立刻为每一位参战根源颁发勋章,则后续军团存储的「神血冕」仪式感更足,但「屠神者可以平凡」的态度被弱化。
- 若林恩主动在血神自爆前用主宇宙浪涛把他一寸寸消解,则他的自爆本源被分流,血肉神格的腐化程度反而更纯净一分,但血神死前的遗言只有一半传出。
- 若林恩让「巨像复原力」设定失效,她在对血神时第一次就被劈散,围猎场面变成「死者屠神」的调性,军团的嗜血氛围更多哀伤。
- 若林恩主动在他收血肉神格的瞬间让艾雯爵士/自缚天使同时看到,则两人对他「伟大教官」的信任指数同时暴涨,但也可能各自心里多一下「他对这世界还要多少」的另一维度疑问。
- 若林恩选择让夜神在被围猎时按程序战斗而非情绪爆发,则她的死更平静,王女对她的死亡画面变成「冷血的处死」,后续动摇更具罪恶感。
- 若林恩让他的控场总览变成「他屏住林恩意识,只是主宇宙法则自身维持秩序」,则军团作战更自由,但任何失控都由法则本身压制,生灵们对战场的真实感更直接。
- 若林恩决定让围猎结束后不开场会议而直接进入 E605 漫步查看,则会议里「后怕感」减少,情报揭示的戏剧张力减弱,但呈现更现实。
- 若林恩主动在收血肉神格这句话里加一句「我会为它洗清」,则后续军团对他净化就业的信心更多,但净化过程中任何反感都会被拉高期待值。
- 若林恩让艾维儿在夜神死后直接对林恩说出「那就是我们」的整段独白,则动摇当场被释放,后续 E605 她的收束更果断,但少了「沉默良久」那段压抑美学。
- 若林恩主动把围猎宣称「弑神的时候到了」换成「报仇的时候到了」,则战场动员的语义从权能宣示转向个人复仇,夜神血神面对他的应对里多一层人心层面。
- 若林恩决定在围猎盛期让小丑的八音盒当面打开让魇观看,则场上多一层「历史见证」的仪式感,但魇会以此为契机影响某个根源的心智开锁。
