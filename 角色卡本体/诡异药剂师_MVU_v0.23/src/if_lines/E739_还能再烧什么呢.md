# E739·还能再烧什么呢·if线

- 若林恩在全灭三十尊魇魔震慑无序深空后，第一时间严令外围防线各大军团严防死守、不得趁势冒进，则帝国主力能完美避开深空深处因三十魇魔陨落而掀起的无序反扑风暴。
- 若林恩眺望着支离破碎的神界废墟、伸手一把握住破空归来的三叉戟，果断下令「就让神界成为过去吧，从今以后黑夜城和整个帝国的决策中心转移到三大圣堂附近，由我直接庇护」，则旧日幽冥海遗留的后门隐患将被彻底废弃，魇魔再想偷袭唯有正面强攻外围防线一途。
- 若林恩在废弃神界前高举手中三叉戟、以初诞者神光照耀虚空施展盛大神迹「复生」，将神界大破灭中死难的无数亡灵从废墟中召唤而回重归人世，则全宇宙信徒与黑夜城军民对他的崇敬将达到无以复加的顶峰，自缚天使（主母）也会立刻率部将这些复生者妥善安顿至圣堂周边的新世界。
- 若林恩在当众施展完「复生」神迹、转身独自踏入三大圣堂并将青铜巨门合拢的下一秒，双腿一软毫无征兆地力竭倒在冰冷的地板上，则一直守候在殿内的艾雯爵士与自缚天使会大惊失色地冲上来扶住他，确保门外没有任何外人看见王虚弱的一面。
- 若林恩瘫坐在台阶下捂着额头，向艾雯与自缚天使坦白「黑火与罪火不同，罪火可以降档，而黑火一旦点燃便再也回不去，会永不停息地疯狂燃烧三位一体与众生信仰」时，摊开手掌露出那簇吞噬光线的漆黑火苗，则殿内的空气会瞬间凝固如冰。
- 若林恩凝望着掌心黑焰，声音沙哑地向艾雯问出那个致命的问题：「如果全宇宙的信仰之力都到了临界点，而我依然没法与那片灾厄一战的话……那我还能再烧什么呢？」，则艾雯爵士会在死寂中重重按住他的肩膀，以孤注一掷的坚定眼神向他保证「不需要再烧什么了，众生的信仰足够支撑到你完成那最终的一跃」。
- 若林恩在听完艾雯的保证后深深看了兄长一眼，没有拆穿他眼底深藏的焦虑，而是抓着艾雯的手重新站起身来，则两兄弟在心照不宣中再次完成了宿命的交接。
- 若林恩在转身走向至高王座前，特意叮嘱艾雯与自缚天使「对外绝不能透露我力竭的消息，要让全宇宙都认为我依然处于随时能一人镇杀强敌的巅峰」，则这道命令将成为帝国最高机密，威慑无序深空长达数年不敢轻举妄动。
