# E739·还能再烧什么呢·if线

- 若林恩把「还能再烧什么」当作公开的哲学命题让信徒辩论,则帝国的智识阶层会就「奉献的极限」展开激烈论战,这种反思会让信仰更成熟但也会引发「过度思辨」的瘫痪。
- 若林恩决定「伪装巅峰」持续到油尽灯枯的最后一秒,则他的崩溃会是突然的、不可挽回的,帝国的崩塌也会是瞬间的——这种「骗到最后」的选择比逐步坦白更残酷但也更浪漫。
- 若林恩让信徒看到王座火焰的真实稀薄度并与他们共同面对「我们快没火」的事实,则信徒会立即献上自己所有的记忆与生命,但他们也会看到「原来神也会穷」——这种觉醒可能拯救也可能摧毁帝国。
- 若林恩让王座火焰飘进自己体内变成「神被火烧」的形象,则他会成为持续受难的神,信徒会因为不忍而奉献更多,但他也会因内伤而在五年内死亡。
- 若林恩在燃料枯竭时向噩梦的王庭求和用帝国的投降换取停止攻击,则这种「以臣而不是臣」的策略会让帝国多活三十年,但信徒会永世不忘「我们的神投降过」。
- 若林恩选择把自己的私人记忆（与织梦、主母、左左、自缚天使、艾维儿的所有亲密时刻）全部燃烧作为燃料,则他会获得几个月的巅峰力量但也会忘记所有爱的人——这种牺牲比死亡更可怕。
- 若林恩决定散布「王座有无穷燃料」的谣言,则帝国的恐慌会暂时压制,但第一个发现真相的信徒会成为帝国的内奸——他会因「神骗了我们」而背叛。
- 若林恩让信徒以「付出」取代「燃烧」不再消耗他们的记忆或生命力只要求他们工作或创造,则信仰的因果会变得更可持续——但黑火的强度会大幅下降、无法维持原有规模。
- 若林恩还是选择回到最初的药剂师身份用科学而非神迹来拯救帝国,则他会放弃神格但也放弃负担——他可能创造一个基于医药的帝国,但这与织梦的遗愿相悖。
- 若林恩决定「燃尽自己一次彻底结束神权把帝国还给凡人」,则这会成为最有力的神话——神为了子民自我牺牲,但结果会是帝国的解体与重新陷入凡俗战争。
- 若林恩选择让信徒轮流「燃烧自己」每个人一天而非他独自承担,则帝国的负担会被平等分摊,但也会有人主动「逃班」——这种集体牺牲的可负担性会成为道德难题。
- 若林恩对外宣布「王座已经升华为更高阶存在」从此神迹减少但神话增加,则信徒会被一次次的「降级安慰」麻痹,但信徒的后代会觉得他们活在「神的余晖」中——一种永恒的哀伤感。
- 若林恩让左左撰写一部「谎言记录」详细列出他的所有欺骗等他死后出版,则历史的真相会被保留——这种「死后的诚实」会让后代人同时爱戴他与恨他。
- 若林恩让信仰殿转型成「凡人医院」用剩余的神力治愈信徒的疾病而非燃烧信仰,则帝国会变福利国家,但军事防御力会大幅下降。
- 若林恩决定把信徒的燃料「分期支付」不再一次性燃烧所有记忆而是一年烧一点,则信徒的生命质量大幅提升,但帝国的火焰永远保持「不够亮」的状态——无法应对大的威胁。
- 若林恩让自己的身体成为「容器」王座火焰在他体内燃烧透过每个动作显现,则他会成为「活体神圣」——信徒会以「亲吻他的手」来感受神力,但他的身体会因持续高温而快速衰老。
- 若林恩对信徒宣布「你们的记忆已经被我存进了另一个宇宙你们燃烧的只是副本」,则这种安慰会让信徒放手去燃烧,但也有人会质疑「副本的燃烧有意义吗」——如果是假的、那珍惜的是什么。
- 若林恩选择让织梦的残留意识来接管王座成为「新的神」,则她会成为比林恩更性感的神——她不是被造者她是造物主,但她的统治风格会与林恩完全不同,帝国会发生风格转变。
- 若林恩决定「分散装睡」他假装沉睡让各个星域自主统治只在最危急时刻镇压,则帝国会变成「松散的联邦」信徒的自主性会提升,但一旦有大灾难林恩的「苏醒」就变成末日审判。
- 若林恩在燃料短缺时选择与信徒「互助借贷」信徒借记忆给神、神借力量给信徒,则信仰会变成「金融契约」,帝国会高度商业化——信徒从「崇拜者」变成「股东」。
- 若林恩让信徒把「能再烧什么」看作日常用今天的回忆换取明天的保护,则这种消费式的信仰会让信徒越来越「记忆贫穷」,他们会变成一生奉献却一生失去的行尸走肉。
- 若林恩决定把信仰的重心转移到「艺术创作」让信徒用绘画、音乐、诗歌奉献,则帝国会诞生爆炸性的文化繁荣,但这种繁荣的燃料是不稳定的——艺术需要自由而帝国需要控制。
- 若林恩选择让「燃烧」变成生理性的信徒用免疫力、寿命、生殖力来换取保护,则信徒会快速消耗肉体、人口会锐减,但这种肉体奉献比精神奉献更直接,看得到摸得着。
- 若林恩在燃料枯竭时向信徒坦白一切说「我不行了你们自己活下去吧」,则神的人性化会让信徒获得最大的自主——「神走了我们得靠自己」,这种遗产比任何神迹都珍贵,但林恩会成为「被爱过然后离开的神」。
- 若林恩选择让噩梦大军不灭而圈养把它们当成「信仰熔炉」定期引导信徒的恐惧来燃烧,则帝国会有源源不绝的燃料,但这种「恐惧经济」会让信徒活在永远的恐慌中——他们需要害怕才能生存。
