# E08·暴击药剂与视界曝光·if线

- 若林恩对黑骑士只摆出狂怒药剂与钢铁体魄便试图劝退，则危机度直接飙过95，店内爆发武力冲突，事件按变形记"拒绝售药"
- 若林恩事先声明药剂存在秃头与发光副作用并取得书面签收，则黑骑士事后追责口径弱化，视界首条控诉帖措辞收敛
- 若林恩在暴击原液里削去地狱三叶草的配比，则爆击率压低至150上下，黑骑士砍墙失败升级当场拔剑，事件取消记账
- 若林恩把猎头者牙结石改作骨粉替料，则副作用从"秃+闪"翻转为"骨刺+耳鸣"，奥卡洛斯上门时不再"刀刀暴击"骂街
- 若林恩在后院熬药时偷倒半杯原液试喝，则自己先秃一块、脑顶每隔几秒叮一声微光，视界提前出现"店家自带灯泡"讥讽帖
- 若林恩当机立断扔掉试管换端第二坛更浓原液，则暴击率突破300上限但持续时间砍到十分钟，黑骑士扬言退款否则封店
- 若林恩不为黑骑士拴"无效当场砍"毒誓而是改口"按结果计费"，则黑骑士砍价到1200骷髅币一瓶，药剂倾销家成就折损
- 若黑骑士当面试瓶时林恩借口去后院清点库存拖时间，则他从第三瓶起就拔剑架在门板上，药剂交货节奏被武力威胁压死
- 若林恩把给黑骑士的10瓶标成"试喝余量"故意少给一瓶，则黑骑士回店追加，副作用连锁加倍且口碑帖暴击成"缺斤少两"
- 若林恩对奥卡洛斯装纯良、声称之前从未卖过同级药剂，则猎魔人当场掀桌刀架脖，双秃连锁在同店柜台对峙
- 若林恩给奥卡洛斯同款暴击药剂时主动加价到1800一瓶，则猎魔人出门后在视界贴上"药剂师趁火打劫"佐证帖
- 若林恩劝奥卡洛斯喝药前先脱头盔，则副作用提前暴雷，猎魔人只买3瓶并记一笔"试药返利记账"
- 若林恩放任两位灯泡客户出店时不赠配送安全包装，则双秃荧光沿街散播，视界区域频道同夜涌出十几段短视频
- 若林恩在店内直接挂出"秃头医师"招牌承认副作用，则游魂巷暗巷猎魔人与骑士闻讯上门，第二日客户登记翻倍，药剂倾销家成就按变形口径入账
- 若林恩在视界开启前先让黑弦月删掉长发鬼红眼控诉帖，则区域频道流转节奏被截断，血衣恶灵破门时点延后一夜
- 若林恩亲自下场在视界跟帖反讽血娃娃泣诉"娃娃深喉"是误会，则恶灵女王直播连线追着林恩入场，舆论升级为公开连麦对峙
- 若林恩当晚选择离线不读视界，则他隔日开店时才发现门口已被恶灵画出血百合迎宾纹，血衣送请帖改为当面递交
- 若林恩主动回帖"药剂副作用属正常范畴"并贴出三种解药配方，则舆论在拾荒者与烧死鬼中反转，血百合请帖塞进门缝时附一行"交货清单请一并带来"
- 若林恩在血衣恶灵破门瞬间主动下跪抱拳赔罪并将请帖当场接下，则血衣火气减半、追加写一句"小姐说喜欢你的药剂"，鸿门宴身价小幅抬升
- 若林恩把请帖当场撕碎扔回，则血衣恶灵不递改强掳，事件取消并记账"非赴约路径"
- 若林恩收下请帖但先去翻药店账本核对双秃订单数额，则视界镜头回放到拾荒者门前的小车踪影，血衣站立位置被二次确认
