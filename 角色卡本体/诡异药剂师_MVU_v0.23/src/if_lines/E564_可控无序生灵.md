# E564·可控无序生灵·if线

- 若林恩在三维战线地图亮起时主动伸指在第一边缘世界红点处旋一圈，则后续岗哨世界丢失毁灭的叙述从旁观变成由他追问世道，边王愧疚神色多停一秒。
- 若林恩在听锚点稳固器时主动开口要见识一台实物，则大恶魔摇头说锚点非边王可造，「女主人自身难保顾不及此」这句更早落地，领地缩三分之一那数字压成更沉的一句。
- 若林恩在潘尼说「如果不是大小姐到来」时主动接一句「我在幽冥海见过她」，则预谋引开的指认提前一拍成立，大恶魔急认的速度随即慢一拍变实证已知。
- 若林恩在「大小姐」首次出口时先扭头望向小丑再开口追问，则小丑眼中的震动被目光扣住，「只可能是小女主人艾维儿殿下」由小丑自己苦涩说出口而非传音确认后才回答。
- 若林恩用「我闺女？」开玩笑前主动先揪一下小丑的衣角暗示，则小丑就在被气疯大骂前先朝林恩额头弹一个爆栗，那句「放屁，是吾王的闺女」后半句差点噎住。
- 若林恩拒绝以「我闺女」调侃而是直接问「她叫什么」，则小丑进入正式介绍态，艾维儿三字在边王耳中砸下时伴随紫罗兰大君与女主人长女的完整位格，分量更沉。
- 若林恩追问「她与女主人决裂的具体缘由」，则小丑脸色想起几千年前的狱卒禁忌会再沉一线，那段连普通狱卒也不知具体分歧的空白被刻意保留，不解之谜加重一层。
- 若林恩在听「已有预谋引开最强存在」时主动提出立刻通知大小姐返航，则大恶魔摇头说无序深空传讯会被她甩开，「追杀污染者追得太远」的现实挂在她身上，等待被默认。
- 若林恩在观测到污染者集结成无光漩涡时立刻抬手掐法则探向漩涡，则那种「诞生」气息以更直接的方式灌进他指尖，边王齐呼「他们在制造无序生灵」的惊呼随即提前一秒出口。
- 若林恩放弃抬手探向漩涡而是静静退后半步望向潘尼，则「成型后第一目标必是最靠近主宇宙的我方」由潘尼沉重说出，林恩以静立姿态对全景保持旁观。
- 若林恩在潘尼说「控制不了也不需要控制」时立刻反问「那献祭之后他们自己怎么收场」，则大恶魔答「不需要收场，他们被吞也不在乎」，污染者指挥官的理智层次更深一层浮现。
- 若林恩在吞噬近一半军队时主动回头望向侧墙星炬塔核心方向，则「短短十几分钟献祭三分之二」的时间压在心中更直观，他对后续接管指挥权的犹豫重心前移。
- 若林恩主动询问大恶魔「曾亲自造过无序生灵是什么体验」，则那段「一点点无序不断喂养可极速成长」的口述从潘尼自己带着失眠痕迹的口吻里碾出来，定性更冷。
- 若林恩在小丑苦涩出口艾维儿殿下后追问「她怎么沉睡到今天的」，则小丑收回目光说她从未沉睡过，这一信息在边王眼中新增一层「这个女人数千年来始终在动」的侧影。
- 若林恩拒绝继续追问大小姐的去向而是把目光锁在无光漩涡上，则艾维儿的身份线悬置，漩涡崩坏的恐怖气息在沉默里被放大，边王们的呼吸节奏被压短一拍。
- 若林恩在感知到漩涡已成形时主动要求边王描述他们对「成型后第一目标是我方」的应对方案，则大恶魔坦白没有应对方案，沉默替换了所有回答，接管指挥权被默认接到了他手里。
- 若林恩在「无序生灵」一词落地时立刻扭头望向边王询问该造物的能量规模，则潘尼给出的不是数字而是一种「几分钟就能把边缘世界吞干净」的近乎祷告式定性，紧迫感压满。
- 若林恩主动示意小丑不要插嘴只让他自己听，则这段让小丑首次亲眼目睹无序生灵成形的体验留在他个人面板，但小丑没机会在场中叹出那句「这不是我见过的任何东西」。
