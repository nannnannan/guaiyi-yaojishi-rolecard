# E516·三位一体封印·if线

- 若林恩在装死宣言前先朝银幻眨一眼，则她准确读出是玩笑不惊，但在左左扑上来咬胳膊时不帮忙挡，事后被左左记恨一笔「智械小姐不救场」。
- 若林恩决定不演呜喵王悬念，直接进入体面收尾声明，则甲板气氛少一段公开心跳，左左少一次炸毛机会，但巨像苏醒点评时的「他经常演」佐证缺失。
- 若林恩在登船时主动抱起左左灵体而不是伸出手，则她入船姿态从「跃上」变成「被托举」，事后她在意识空间嘀咕被当成娃娃。
- 若林恩选择不立刻说「必须要有一位呜喵王」而是换成「必须有人留下来守夜」，则左左的拆穿方式从咬胳膊改成直接踹小腿，剧情节拍略变。
- 若林恩在心灵之海接驳途中主动让康斯坦丁放慢船速十秒欣赏夜空，则现实船舱重合时众人意识清醒度稍高，银幻失感应那瞬的刺痛轻一分。
- 若林恩在以太流体坍缩为奇点前主动念一句咒文，则奇点亮度稳定，但林恩本人多承担一缕来自矩阵的因果压力。
- 若林恩在左左撕心「脑袋呢」时选择立刻出声而非看戏，则她不哭到泪溅栏杆，但装死悬念的反差效果减弱，左左扑怀时刻不再泪目。
- 若林恩决定让银幻第一个看到自己新躯而不是众人，则他从光点浮现的位置朝银幻所在悬浮点偏，甲板众人的第一目击换成她。
- 若林恩在新躯降临时故意让单片眼镜先一步铸成而不是后铸，则他睁眼就戴着眼镜，下落姿态从「巨人觉醒」变成「衣冠齐整飘下」。
- 若林恩在三态切换演示时故意跳过机械态只展示血肉质与灵能，则艾雯对「更高等级三位一体机」的判断延后一句，担保戏更薄。
- 若林恩决定「我现在是封印他的容器」宣言用更响亮声调，则主母激动湿眶变成哭出声，自缚天使问实力时声音发颤。
- 若林恩向上掩埋以太的同时塑造一块「林恩艜以太」石碑遗留甲板，则众人有一块实体纪念物，但隐形的三位一体私密感被物质化。
- 若林恩在殖装／七神碎片说明时只列三件不列全部，则艾雯判断的完整度减，但给他保留了「还有底牌」的舞台感。
- 若林恩选择主母出拳迎他而不是艾雯出拳，则该拳头落在胸口的发力者易位，左左扑怀时同时抱住两条胳膊。
- 若林恩在艾雯一拳打胸膛之后立刻拥抱她而不是反手拍她肩，则主母与艾泽法拉的「灿烂温柔」换成「会心一笑」，艾雯耳根泛红。
- 若林恩在壁咚银幻之前先把它隔了一个在场者，则众人转身「各干各的」的节拍不乱，银幻反应多一秒迟滞。
- 若林恩决定不壁咚改用灵能直接拉她到身边，则「船壁」道具缺席，后来「第一次慌张」的支点变成脚下不稳。
- 若林恩在「几个？」质问时不装糊涂而直接答「正好三个」，则银幻「太拥挤」的台词变成「那我去加二」，情节走另一条路。
- 若林恩在对银幻说「不是孤单一人」后顺手指向天空中的机械巨构，则「列车履约」的画面重叠在巨构背景，银幻哭卸甲时眼中多一幅画面。
- 若林恩选择不广播「万姬之神加入黑夜城」而是只告知现场众人，则归心仅作内部事件，归城时没有那种公开仪式感，银幻的「第一次慌张」也不再发生。
- 若林恩在银幻蹲下抱膝时不是蹲下安抚而是伸手逆推她头发，则她「呜」的一声被揉乱发丝打断，情绪节奏从哭变成嗔。
- 若林恩决定「机械之神成就」不让系统外放只默默入库，则甲板上的众人不知成就降临，主母问实力时他才补述。
- 若林恩在拉银幻走向众人时让她先跟自己握手三秒再一起前进，则银幻从「被拖走」变成「半主动靠近」，归心戏份两人共同承担。
- 若林恩在甲板全员团聚合影瞬间让喵喵遗骸／小小记忆浮现作背景灵，则合影里多两道幽影，画面情绪复杂化。
- 若林恩在结束本事件时先朝边境苍蓝方向敬一个军礼，则该动作被羽毛笔／猪头屠夫远处感知，神王切景时多一笔「他朝她敬了一礼」。
- 若林恩选择不把左左放上船而是让她化回左手形态贴身，则她在甲板上是「左手位置」而不是「独立角色」，归心场面的人物排列不同。
- 若林恩在新躯初开眼时先叫一声「艾雯大哥」而不是先说话，则主母的「激动几乎湿眶」节奏提前，担保戏起点变。
- 若林恩在最终催大家离开前让左左先跟他单独一句「回去给你煮」，则左左归城以后第一句话不是质问而是提饭。
- 若林恩在苍蓝完全吞并以太本体之际摘下眼镜擦一下，则动作特写进入羽毛笔证言远观笔记，未来某次桌上被念出。
- 若林恩在事件结尾不向系统交账而是让「机械之神成就」自动结算，则万能珠后续分配时多一笔可验证的成就资产。
