# E140·王后归属谈判与巨像收容·if线

- 若林恩没有抢在巨像之脑伸手前把左左护到身后，则谈判的第一句主权宣告由左左自己喊出，林恩失去第一发言权但仍可在第二轮补位。
- 若林恩直接开口向左左宣告「等她自愿找回记忆随你便，在那之前她是我的人」，则巨像之脑首次把谈判焦点从左左转向他，怒气改写为质问依据。
- 若林恩提出把巨像之心归还、只留左左伴身，则等价交换通道打开，左左体内旧日印记被暂时封存而非剥离。
- 若林恩坚持巨像之心与左左都不放手，则只有当场给出具体等价物才能让她暂缓动手，否则巨像之脑判定他贪婪并立刻转为根源级清剿。
- 若林恩坦承自己只是想要一只会说话的左手陪自己过日子，则巨像之脑会像原作那样短暂哑然，谈判气氛得到一次微小松动。
- 若林恩在左左说「少了她以前救他几次就白救」之前抢先替她回答，则左左会当场打他后脑勺抗议越权，并让巨像之脑把林恩写进失信名单。
- 若林恩主动以担保人身份向左左承诺「王后不是人格覆盖」，则巨像之脑要求这份担保落到超维链接中由艾雯爵士见证，否则不生效。
- 若林恩提议由艾雯爵士作为第三方全权监督收容协议，则巨像之脑会因七千年前的旧缘头一次真正迟疑，谈判窗口被拉长一倍。
- 若林恩在巨像之脑噗嗤笑出声的瞬间调侃「你笑起来像个孩子」，则她会立刻红着眼圈扭头擦泪，下一秒恼羞成怒催动血色锁链把他摔上殿壁。
- 若林恩试图用蛋糕、糖果等哄左左那套去哄巨像之脑，则她会被这份凡俗的好意刺得哑口无言，但会把「以后你也是我朋友」这类话记在心底。
- 若林恩试图用亲密口吻喊左左「小宝贝」或暗示她已是他私产，则巨像之脑把这句话当作宣战，立刻撕破脸并催动铁幕清场，和平收容通道关闭。
- 若林恩完全沉默不担保、不承诺、不劝，则左左只能独自对巨像之脑喊出「我是我、不是祂」；她喊得出就保独立，喊不出就按默认回归路径进入隔离变形。
- 若林恩答应返城后替她封锁「巨像未灭」的一切消息，则她默许这份合作，但要求以主母失联情报的具体进度作为对价。
- 若林恩主动提出让左左以「养女」或「妹妹」身份留在他身边，则巨像之脑把这句话定性为对巨像传统的亵渎，杀机当场暴涨，变形路线启动。
- 若林恩提议为巨像文明复归出力、条件是左左独立人格永续，则她会把承诺烙进血肉契约，林恩后续失信将触发维度链接反噬。
- 若林恩试图阻止她催动血色锁链震塌地下神殿，则她会以「死者本就不该再被打扰」为由坚持亲手埋葬，并在此后拒绝林恩靠近眷属遗骸方圆百步。
- 若林恩主动提议帮她在返航后照看沉睡泰坦的鼾声起居，则她会把他视作受监护盟友的候补，但要求他不在泰坦面前再提「王后」一词。
- 若林恩试图说服左左「恢复几段记忆也没坏处」，则左左会立刻把他和巨像之脑归为同路人，独立宣言自带三分敌意，谈判退化为冷战。
- 若林恩在艾雯爵士赶到现场前就私自与巨像之脑签下任何条件，则这份条件在艾雯爵士复核通过前只被认定为个人许诺，不进入正式收容档案。
- 若林恩替巨像之脑挡下万机之神残部临时袭来的一击，则她会第一次在凡人面前收起铁幕，但要求他不得把这次出手当作筹码在谈判里翻账。
- 若林恩主动提出在返航前帮她清点眷属遗骸并一户一户念名，则她会第一次透出从未对凡人展示过的松动神情，但此后每到月夜都会把他召到废墟边沉默并肩。
- 若林恩在谈判全程都用敬语又称她「王后陛下」，则她会越听越不适，最终当面撕破这份敬称并要求他只叫名字，否则拒绝继续谈判。
- 若林恩趁谈判间隙偷偷用血肉灾变替左左揉了揉被铁幕擦疼的指节，则左左会小声骂他这句「凑脑袋」并在心中划归最温柔的一次，谈判气氛微妙回暖。
- 若林恩在艾雯爵士面前替她开口解释「她也不是想要王后，她只是怕再次孤独」，则巨像之脑会狠狠瞪他一眼但没有反驳，艾雯爵士会把这份未否认加进见证记录里。
- 若林恩把主母失联的消息提前透露出来以此作为返城不利证据拖延签字，则巨像之脑会立刻要求他交出全部已知情报，谈判重点从王后归属被迫改写为信息互通。
