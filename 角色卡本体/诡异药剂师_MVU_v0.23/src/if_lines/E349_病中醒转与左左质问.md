# E349·病中醒转与左左质问·if线

- 若远景废塔里那位来客没有立刻报出任何名字、只是静静跨入寒风，则所有「衔尾黑蛇」的视觉证据都被他主动按下，屠夫与命运神的对峙保持完全未具名的状态。
- 若被囚命运神在见到来客时主动嘶名出一声她曾指挥过的某个旧世代号，则来客不说话、只用手指在她下巴抬起一秒，场面从解缚倒转成双方心知肚明的对峙。
- 若猪头屠夫在来客转身那一秒主动跪也跪得更深，则现场第一次见面就被记录成屠夫代理对旧世魔王的彻底归顺，学徒在远处看不清但那条线已被固定。
- 若林恩在左左还没开口戳他脸前先自己说出「我现在不想去找任何人」，则心里那句「心病」在她没说出口前就被他自己主动扯出，后面的质问压力减小一拍。
- 若林恩顺嘴承认分出去的那半个灵魂现在仍能和本体微弱感应，则在场所有人首次获得准确的灵魂切片信息，左左的试探闭嘴成小心翼翼的状态。
- 若林恩对左左描述的「心病」直接反击一句「我没事，是你多心」，则左左指间的触手会瞬间缠上他的咽喉但不下力，整个对话从质问升级成两具身躯之间的对峙。
- 若林恩在左左质问「为什么不去找大家」时只是拉她坐下来，沉默半分钟后才开口，则她脸上原本的强硬表情会缓慢崩解，整场质问先在中间打通一道间隙再继续。
- 若林恩在她还没说完「你根本不知道别人担心你」那段话时，主动把她抱起来放在自己腿上让她贴着胸膛，则她要说的下半段被生生吞下，转变成她贴着他肩膀静默了好几秒。
- 若林恩承认「变成你不认识的人是可能的」，把「你不认识的我也许就是事实」说出口，则左左不会冲上来捶打，她会沉默一会儿，然后从背后把他圈紧只能咬他的后颈而不啃颈前。
- 若林恩在左左掐住衣领开始连珠炮问「疼不疼」的时候抬头挑衅回应「根本不疼」，则她会改为咬住他的下唇而不是脖颈，质问的语气里会带一丝她自创的报复笑意。
- 若林恩在她说「每天咬一次，直到咬死」那句话落点时没有制止，则左左当真得出下一步是连续攻击，她一次又一次咬在同一个点上，直到林恩抬手扶她的后脑颉就停下。
- 若林恩反问她「如果我消失你会顺势始变回去吗」，则左左顿住几秒，她第一次以没有回避的表情告诉他她不会被主动权丢下的，为你咬住这一句她才肯收住质询。
- 若林恩主动让位给左左坐在床上、他跪在她脚下，则左左原本高高在上的悖势被瞬间反转，她只能用两只手乱挥试图推开凑近的他但根本推不掉。
- 若林恩在她发问时主动倒一杯热水塞到她手里让她冷静，则左左的火气被一杯水软化一分，她从「指责你」转入「质问你」的频道那一步。
- 若林恩在她抱怨的间隙主动表达「我只是需要几天」，则这段本身不会被当作解决承诺、而是一个量化时间边界的记录，左左会默认接下来几日不再添乱。
- 若林恩主动提出明早一起去看艾雯与巨像之脑，则左左压在心底的「寻找失散者」焦虑会随之松开一拍，这一安排在她那里被计为「你在路上」。
- 若林恩在她咬牙控制冲动时主动搂住她，用极低声音说一句「你是我现在唯一安定的全血」，则这一句话会让左左的接近失控的捶打停止在这一秒。
- 若林恩拒绝说任何借口、只用沉默应对，则左左会更动手而不是动口，她会一气之下屁股往他大腿上一坐压着他迫他必须与她对视。
- 若林恩在她口中「你连一句解释都舍不得说出口」之后，把手心按到她额头上、用一缕残余黄沙贴上她咒纹，则黄沙会顺皮肤渗入她咒纹里，她怔一下、心底的质问被这一触触碰压制一拍。
- 若林恩在她说「每天都咬你」时突然反问她「你敢咬吗」，则左左愣住一秒，下一刻她会真的扑上来啃咬他的颈侧，但她在缠咬的过程里会抽泣出些许可察觉的哀鸣。
- 若林恩在整个质问过程中都不说话只是握住她的手腕不出声，则左左的怒意会像找不到可攻击的空隙而逐渐熄声，她自己反而先为他的沉默而满怀委屈地抽泣起来。
- 若林恩在她捶胸反抗的瞬间果断用一只手扣住她两只手的天宗穴，则左左会被他制住双手无法继续攻击，颈项之间的撕咬反而因此越加夸张，她跳到彻底喊「你无赖」是他预期之中的结果。
