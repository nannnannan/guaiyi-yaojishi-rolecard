# E757·梦中的弦奏与现实悲歌·if线

- 若林恩在坠入深层梦境、看见织梦（入梦者）带着纯真微笑站在花海中向他伸出小拇指时，没有迟疑而是立刻伸手与她勾指，则织梦说出「拉钩上吊，一百年不许变」时的笑容会灿烂得如同初升暖阳。
- 若林恩在与织梦完成拉钩约定、看着她化作漫天白色光点消散在梦境尽头时，拼命伸手抓住了其中最亮的一缕白色灵魂火苗送往命运之境方向，则羽毛笔得以接住这缕火苗并在E759托付给苗苗。
- 若林恩在梦境中听见现实世界传来银色幻想力竭倒下、将染血的海神三叉戟交到弦月小姐（人偶小姐/黑弦月）手中的声音时，在梦境边缘发出一声痛呼，拼命撕扯困住意识的梦境帷幕。
- 若林恩在弦月小姐双手接过沉重的海神三叉戟、独自一人站在圣所最后一道守护结界前奏响现实悲歌时，顺着三叉戟传递去自己正在苏醒的心跳，则弦月小姐在战死前知道她的主人马上就要醒来了。
- 若林恩在银色幻想交付完三叉戟后终于流尽最后一滴神血、拄着断剑半跪在王庭废墟上溘然长逝时，于梦境破碎的瞬间接住了这位骑士神王的英灵，替他拭去剑锋上的血迹。
- 若林恩在弦月小姐以纤弱的人偶之躯挥动海神三叉戟、本命丝线在终焉黑潮冲击下一根接一根崩断如泣血琴弦时，将一缕初诞者神力注入她的指尖，则她奏出的最后一段弦音足以震碎十头扑近的梦魇。
- 若林恩在织梦消散前轻声对她说「谢谢你替我编织的这场温柔好梦，但我得回去救他们了」，则织梦会乖巧地用力点头，主动引爆自己的梦境本源推他重返残酷现实。
- 若林恩在弦月小姐的人偶身躯被魇魔利爪撕裂、精致的脸庞布满裂纹却依然死死抱着海神三叉戟不肯松手时，从圣所内提前轰出一道黑火冲击波，将那头欲折断她颈骨的魇魔当场烧成飞灰。
- 若林恩在从织梦的梦境中彻底惊醒、睁开燃烧着滔天黑火的双眼那一刻，全身穿骨锁链应声寸寸崩碎，整座圣所的石门被他狂暴的威压直接轰飞出去数里。
- 若林恩在冲出圣所大门的第一瞬、看见弦月小姐已彻底失去生机却仍维持着持戟守门的姿势立在最后一道结界残垣前时，伸手轻轻合上她的双眼，并从她冰冷的手指间郑重接回海神三叉戟。
- 若林恩在低头看见不远处被钉死在石柱上的主母遗体与半跪战死的银色幻想遗骸时，周身黑火瞬间将整片王庭天空染成深不见底的墨色，连七十一座终焉之柱都因这股戾气而剧烈颤抖。
- 若林恩在织梦化作光点消散的刹那，将她梦中那片宁静花海的坐标牢牢刻入罪恶王座，则无论现实中的黑夜城变成了怎样的人间炼狱，他心底始终留着一处与织梦拉过钩的净土。
- 若林恩在弦月小姐战死前夕、圣所最后一道守护结界即将破碎的最后一秒，让她听见了石门内侧曾封存的那句温柔告别，则这位追随他已久的人偶小姐在闭上眼时嘴角带着浅浅的笑意。
- 若林恩在握住那柄先后沾染了主母、银色幻想与弦月小姐三人鲜血的海神三叉戟时，没有抹去戟身上的血迹，而是以黑火将其锻入神兵骨髓，让每一记刺击都带着三位守门人的怒火。
- 若林恩在破封苏醒的冲击波扫过圣所内部、看见跪在台阶旁已油尽灯枯的艾雯正仰头对他露出释然微笑时，强行收敛脚下黑火以免灼伤兄长分毫。
- 若林恩在弦月小姐碎裂的人偶关节散落一地时，以王座引力将她每一块碎片与断裂的丝线小心翼翼地收拢到圣所台阶内侧，不让任何一头魔物的脏脚踩到她的遗骸。
- 若林恩在梦中与织梦拉钩时，将自己指尖的一滴金色神血染在她小拇指上，则那缕随后飘向命运之境的白色灵魂火苗核心会多出一抹金芒，在战后更容易被苗苗温养复苏。
- 若林恩在听见现实中最后一道守护结界破碎的清脆声响与梦中琴弦崩断的声音完全重合时，灵魂深处的第二阶段枷锁被彻底扯碎，以半步第三阶段的狂暴姿态踏出圣所。
- 若林恩在银色幻想半跪不倒的遗骸前停下脚步、伸手替这位老友扶正歪斜的骑士肩甲时，周围数百头终焉眷属被他身上的恐怖杀气硬生生逼得不敢上前一步。
- 若林恩在弦月小姐最后奏响的悲歌余音中，以三叉戟重重顿地发出一圈横扫王庭的暗金冲击波，则所有踏上王庭台阶的魔物在顷刻间尽数化为齑粉。
- 若林恩在从梦境坠回现实的通道中，顺手将织梦残留的梦境碎片编织成一层温和的保护膜覆在自己识海表面，则他在随后直面满城尸山血海的惨状时，神智未被疯魔彻底吞噬。
- 若林恩在接过海神三叉戟、感受到戟身内仍残留着主母与银色幻想未散的战意时，低声对着三叉戟说了一句「接下来交给我」，则神兵发出了震彻寰宇的铮鸣。
- 若林恩在迈出圣所大门、脚底踩到浸满同袍鲜血的焦黑泥土那一刻，将每一滴血中的绝望与不甘尽数转化为焚天黑火，一步步走向深渊边缘寻找幸存者的气息。
- 若林恩在梦境与现实交汇的这道分水岭上，将织梦的「拉钩约定」与弦月小姐的「护主悲歌」同时压进胸膛，带着逝者全部的托付撞入末日战场。
