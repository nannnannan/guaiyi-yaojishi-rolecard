# E757·梦中的弦奏与现实悲歌·if线

- 若林恩在王座黑火把第一声故人呼喊拉成梦境弦奏时主动配合而不是抵抗，则那些声音以音乐而非火刑的方式进入他，但记忆的火焰灼入更深。
- 若林恩在梦中弦奏里先找到艾维儿的呼吸再听其他人，则他优先锁定她在心灵墙上的位置，人偶小姐丝线铺墙时多一段「他还记得我」的弧度。
- 若林恩让王座把现实悲歌与梦中弦奏强行对比半秒，则他瞥见那一瞬所有的真相——哪些还在、哪些已失——但意识差一点当场崩裂。
- 若林恩主动把某一位亡者的名字从王座燃料堆里剔出来，则那名字不作为燃烧对象，而是作为压在他心口的一枚不能再唤起的镇石。
- 若林恩让王座黑火主动吞下现实中某一具仍温的天使尸体，则王座火量短期上涨，但那个名字日后的梦境回声永远带着焦炭味。
- 若林恩隔着王座问人偶小姐一句「你还撑得住吗」，则她铺满墙面的丝线在被击穿重织时多出一段不该存在的韧度。
- 若林恩把梦中弦奏里那名老匠人锻器的声音与现实打铁声错开半拍，则他在现实里听出锻锤真正的位置，锁定一名可能尚存的老兵。
- 若林恩选择关闭左左梦中的睡眠频道专心聆听现世的告别，则他错过她发出的微弱求助，但避免了王座被双向撕扯。
- 若林恩隔着王座让喵喵在他怀里别过头去不看现实墙面，则她的恶灵视觉不再被亡者影像灼烧，事后她仍能在他怀里撒娇一声「哥哥」。
- 若林恩主动把现实中某一栋即将倒塌的撤离通道桥写进梦境，则那座桥在梦里被完美重建，撤离者过桥时在意识深处抓住一缕熟悉。
- 若林恩允许王座黑火直接烧自己而不是烧亡者名字，则他承受的代价换来数个名字不被吞噬，黑火因此暂时跨越燃料稀缺瓶颈。
- 若林恩在人偶小姐丝线铺之上再加一层自己的黑血细线，则墙面每破一次会同时流出她的丝与他的血，修补节奏被她重新定义成一种共作。
- 若林恩在梦境中反向把某个亡者的告别录成一段可被未来重听的语音塞进王座背面，则他日后每次濒临崩溃可以打开它一次，但每次打开都要付出等价燃烧。
- 若林恩让王座把某段现实悲歌改写成另一段故乡童谣，则那一段防线上的孩童突然安静下来，但林恩对自己的憎恨多添一笔。
- 若林恩在亡者声音最多的时候选择从中挑一句「你要活下去」反复背诵，则那句变成他在 E758 面对小小时唯一还能吐出的理智。
- 若林恩主动把王座的听觉锁进人偶小姐的呼吸里，则他错过半数亡者告别，但她的丝线从未在他耳边断过一次。
- 若林恩把王座黑火一度压到完全熄灭，则所有弦奏与悲歌即刻停止，他以无痛的空白换取接下来不知还能否再点燃。
- 若林恩把黑火触须探入墙后因果网络寻找小小，则他在 E757 内就提前感知到她的微弱信号，隐藏生命信号被发现的时间提前整个一拍。
- 若林恩主动对王座说一句「请让我哭」，则他首次在这场末日里掉泪，王座黑火因此熄半寸，墙后因果网跟着晃了一下。
- 若林恩把某段亡者的告别改写成自己写给对方的一封信，则那个名字在王座存档里以「已读未回」的形式保留，不会被纯燃烧登记。
- 若林恩让王座黑火反向烧向他自己的记忆深处删掉某一幕，则那段死亡真相在未来的回归路上暂时被遮蔽，他可以继续走而不当场倒下。
- 若林恩允许现实悲歌中那段关于小小的低语渗入梦境，则他提前在梦中找到她的方位，但那一夜的梦被她幼小的呼吸占满，无法再做其他运算。
- 若林恩主动通知人偶小姐「墙后某一段交给我」，则她在那一段的丝线压力骤减，能够把更多力量集中到最危险的裂口。
- 若林恩让王座把他自己的名字写入即将到顶的燃料名单最末，则黑火燃烧名单的优先序被改写，某位亡者的名字获得多留一天的余地。
