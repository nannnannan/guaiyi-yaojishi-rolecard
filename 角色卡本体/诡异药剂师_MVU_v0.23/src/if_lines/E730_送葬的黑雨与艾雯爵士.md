# E730·送葬的黑雨与艾雯爵士·if线

- 若林恩在奔赴边疆主战场前曾委托自缚天使与各地夜医留意那位在沦陷区默默救援难民的「暗夜独行者」，则前线各星区的守军会主动为那位披着残破黑斗篷的身影提供撤离飞船与航道掩护。
- 若林恩当年在各星区竖立的救世主神像中留有一丝微弱的神疆感应，则当工业星球港口的小女孩指着半边破碎的神像对艾雯爵士说「大哥哥是好人，和我们的王一样好」时，远在深空死战的林恩会隐约感应到那一抹熟悉而温暖的灵能波动。
- 若艾雯爵士在摘下兜帽、露出脸上那道如利爪撕扯般的狰狞疤痕并被小女孩用力抱住腰身时，林恩曾留在他体内的旧日家人羁绊微微发烫，则艾雯原本死寂苍白的眼底会泛起一丝久违的柔和，目送飞船升空的背影也不再那么孤绝。
- 若林恩在前线战局稍缓时将神疆感知扫过那颗沦陷的工业星球，则他会震惊地看见漫天黑雨悬停化作灵能涟漪、整颗星球的梦魇主力在无声黑雨中尽数化灰的壮观一幕，第一时间认出那是属于艾雯大哥的手笔。
- 若那座古老魔法文明破碎王都的夜医执政官在艾雯引爆「天葬」灵能风暴后、跪在血泊中哭喊「是您……艾雯爵士！！主母和良医先生一直都在找您！！」并第一时间将这条紧急讯息传回黑夜城，则自缚天使会在王庭中喜极而泣，立刻派人沿着星域航路迎接自己的儿子。
- 若林恩在无序深空感应到奇异世界中织梦的本源气息突然跨越星海出现在边疆某颗战火星球，则他会拼命想要杀穿眼前的魇魔封锁赶过去，但二十余尊魇魔的死战缠斗会让他终究慢了一步。
- 若织梦的那抹红裙虚影在废墟街道尽头唤住艾雯爵士、说出「这样漫无目的的自我放逐，你还要继续多久呢」时，林恩留在织梦心脉处的那缕初诞者之力轻轻闪烁，则艾雯会立刻看出眼前的创造者已是油尽灯枯的回光返照，停下离去的脚步转过身来。
- 若林恩在彻底击溃终焉之柱的魇魔群后立刻顺着那缕灵能痕迹追踪而至，则他在抵达那颗废墟星球时只会看到漫天淅沥的黑雨与空无一人的街道——织梦已完成最后的交托，而艾雯正带着她的遗命先行一步返回黑夜城。
