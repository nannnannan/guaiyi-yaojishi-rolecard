# E730·送葬的黑雨与艾雯爵士·if线

- 若林恩在艾雯爵士打开黑雨通道瞬间也踏入黑雨、跟他一同把幸存星球往外推，则两人能共同多救三颗星球，但林恩的疲惫体征会在雨水中暴露无遗，艾雯第一次真正看清这个后辈几乎已经撑不住。
- 若林恩在通道尽头看见织梦的化身时第一时间冲过去抱住她，则化身会在那一抱中直接消融一半，他能从她残影中捞到一缕完整的灵能记忆。
- 若林恩只是静静站在原地听织梦化身说话、不动也不流泪，则她会把所有信息一次说尽，林恩听完后整个人像被掏空，往后他会对着镜子一遍遍说服自己「必须继续走」。
- 若林恩向织梦化身反问她「你有没有后悔过」，则她会用最后的力气摇头，但那一摇头会让她的消散加快一倍，林恩必须接受「这是我替她选的回答」。
- 若林恩在织梦化身消散之前主动把她最后一句祝福用手心按住，则那一句「不要让他孤独地走到终点」会以灵能印记的形式烙在林恩掌心，他此生再也洗不掉。
- 若林恩当场质问艾雯爵士「你在骗我什么」，则艾雯会在极大痛苦中选择不答，但他的沉默本身就是答案，林恩从此看艾雯的眼神会多一道读不透的雾。
- 若林恩没问艾雯任何问题、转身就向罪恶王座方向走，则艾雯爵士会松一口气但也同时感到更深的罪疚，他日后会以更深地服从赎这份沉默。
- 若林恩在最后一个星球被推入安全带的瞬间抬头向黑雨发出一声咒骂，则黑雨的密度会突增一倍，他必须在雨中再多撑半刻才能撤离。
- 若林恩选择让艾维儿和自己一起听艾雯汇报，则艾维儿在听到织梦死讯时会直接崩溃三天不出王庭，林恩会因此失去这段时间一位最重要的同盟。
- 若林恩选择独自先听艾雯汇报、再以自己稀释后的版本转达王庭，则王庭能稳住，但林恩从那一刻起会永久背负「信息过滤者」的位置。
- 若林恩从艾雯手里接过那枚指向罪恶王座的残片后立即熔入自己心口，则这份残片将与他的灵能共鸣、为罪恶王座的进入直接铺路，但林恩从那一刻起也将与「罪」彻底缔结。
- 若林恩在黑雨中悄悄滴下了一滴眼泪，则那滴眼泪会与雨水融为一体，黑雨整个族群会因为它而停顿一秒，那一秒被林恩视作织梦最后的回应。
- 若林恩没有流泪、只静静望着雨幕，则艾雯爵士会在他身后默默垂首，两人都明白他们已经走到了不得不戴上面具的地步。
- 若林恩对艾雯说「你累不累」，则艾雯爵士会第一次苦笑、第一次承认他这个「画家留下的骗子」其实也想死，林恩会立刻在心中把他划入「真正的同盟」之列。
- 若林恩回到黑夜城时不再是大步流星、而是缓步走入，则路过的每一个居民都会停下来给他一个无声的点头，他从此被永远铭记为「带回噩耗的那个林恩」。
- 若林恩选择先去找沉睡中的智械小姐、在她额前低语织梦死讯，则沉睡中的她眉头会紧锁一下，主宇宙深层的另一位同盟第一次被这个消息撼动。
- 若林恩在前往罪恶王座前独自到那片黑花海立了一夜、一动不动，则艾维儿会黎明时偷偷站在花海入口、以一夜的陪伴终结她对母亲和织梦的所有哀悼。
- 若林恩把手伸进雨中、让黑雨直接打在他裸露的手背上，则那一晚的雨痕会在他手背留下永远的暗青色印记，他的人生会被永远分成「黑雨前」与「黑雨后」。
