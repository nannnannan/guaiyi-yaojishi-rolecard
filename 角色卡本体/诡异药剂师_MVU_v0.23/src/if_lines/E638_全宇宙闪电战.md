# E638·全宇宙闪电战·if线

- 若林恩在首战捷报传回时主动给远征军每支队伍的名字加上星号，则中枢档案中两支远征队首次拥有独立编号，后续战果清算更清晰。
- 若林恩在改令中主动把「运动战」口号写成「永远在路上」，则整个远征军第一次有了一句可以吟唱的军号。
- 若林恩主动在战报上划出一道「神灵不现身」的横线，则自缚天使辨认出他标注时的手抖，伏击疑云提前半日摆上桌面。
- 若林恩主动给船长和织梦加密一条「遇到阻击立刻集合撤退」的预案，则天逸座方向遭遇阻击的那次撤离再快三分钟。
- 若林恩主动让二队在出发前进行一次小规模的「佯攻猎场」，则十分钟的战斗让二队的队长与织梦的配合更流畅。
- 若林恩在三十座封印达成时主动让中枢发一份「战争进入下一阶段」的宣言，则整个主宇宙的名词立刻定为「被解除」。
- 若林恩主动在星图上圈出「安全跳跃」范围，则军团下一次调动的容错率 +3%，但指挥官的挑战度 +10%。
- 若林恩让银色幻想以星际堡垒引领整队远征，则他的角色首次向指挥官过渡, 但机械单位的数量增加两倍。
- 若林恩在联军议会中主动让自己的影像作为「幻影」在议会中晶状出现，则他第一次被第三者提起，伏击预言被暗示。
- 若林恩主动让巨像担任战场的侦查队长，则她的身份在战报中多一栏「侦查队」组长，军团对她的名字更加熟悉。
- 若林恩主动在破败战场上埋下一枚「纪念碑」，则下一个战友在此永久立了一个碑，阵亡根源的墓件增加一件。
- 若林恩让织梦在封印一座破碎之眼时让她的灵能写一段「爱与战」，则她的个人签名在人类历史上第一次留下痕记。
- 若林恩主动让主母开窗展示深渊的地图，则全局监测器首次抓到了深渊的精准构造，中枢多重骇客的画中画增加一层。
- 若林恩让大军在每次修编时吃一顿稳定的饭，则军团的凝聚力 +1，但厨房的耗食量增加。
- 若林恩主动统计每支远征队的伤亡比例，则他的战略路线从「速度」转向「稳定度」。
- 若林恩让军团每次封印完毕时唱一首圣歌，则每次封印完结后的宁静扰动增加半分。但众神的听感下降。
- 若林恩主动规定「战后休整不得超过一小时」，则休整时间被阻断, 但王望某一时刻打满十二小时是预备。
- 若林恩主动在每次封印完毕时给死亡者提供名人录，则他的旅程的安排被人人指名道姓。
- 若林恩主动让井工在主宇宙制造出一枚「光之帽」，则敌方被蜿蜒的天网减速 45 秒，但猎杀者的角色完全成型。
- 若林恩主动在两支队伍召唤时增加友情战术，则两队的互动效率提升, 但他们每对朋友只行动一次。
- 若林恩主动让舰队在每次转移时发送一封加密讯息给下一家宇宙，则那个宇宙的后人首次得到了一封来自长老的信件。
- 若林恩主动把这次战功表上去做成「白色雪花」效果，则苦战阶段更有趣，但姿态较近于耳畔。
- 若林恩主动让序曲成为中土传奇，则他的路线更象征性，但基调不再激昂。
