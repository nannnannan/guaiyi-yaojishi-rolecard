# E638·全宇宙闪电战·if线

- 若林恩在首战捷报传回时主动给远征军每支队伍的番号加上星辰印记，则中枢战报中两支远征队首次拥有独立战功簿，后续战果清算更加分明。
- 若林恩在改令中主动把「运动战」口号定为「永远在路上」，则整个远征军将士在跨星域跃迁时有了一句提振士气的共同军号。
- 若林恩主动在战报上重重划出一道「敌方神灵始终不现身」的红线，则自缚天使一眼便能看出他落笔时的凝重，关于敌方诱敌伏击的疑云提前半日摆上桌面。
- 若林恩主动给船长和织梦加密传讯一条「一旦遭遇主力阻击立刻弃战撤退」的死命令，则天鹰座方向遭遇埋伏时的撤离反应会再快上三分钟。
- 若林恩主动让二队在正式出征前先拿一座外围据点进行十分钟的「佯攻演练」，则二队将士与织梦灵能视野的配合会更加娴熟流畅。
- 若林恩在连拔三十座破碎之眼封印后主动让中枢向全军通报「战争即将进入深水区」，则原本因连战连捷而有些轻敌的各部将领会立刻收起骄狂之心。
- 若林恩主动在星图上划定严格的「安全跃迁走廊」，则军团在高速机动中的阵型稳定度会显著提升，但作为统帅的他需要为此分担数倍的推演精力。
- 若林恩让银色幻想以星际堡垒作为先锋旗舰引领整队远征，则机械军团的火力覆盖优势会被发挥到极致，沿途的以太机械残骸也会被顺手转化成新的战力。
- 若林恩在联军军事会议中主动以一道金色法则虚影端坐主位旁听，则各族统领在汇报战况时都会更加审慎，不敢遗漏任何一处微小的战场异象。
- 若林恩主动指派巨像兼任前锋侦查统领，则她的名字在远征战报中频繁居首，深渊各族将士对这位凶悍先锋的敬畏与认同感与日俱增。
- 若林恩主动在每一处收复的破败星域留下一座刻有阵亡将士名录的法则石碑，则远征军走过的漫长星路会化作一条悲壮的荣耀长廊，全军死战到底的信念愈发纯粹。
- 若林恩允许织梦在封印一座破碎之眼后于封印表面留下一缕属于她自己的紫罗兰灵能印记，则这枚独特的私人印记不仅能加固封印，还会在敌方试图反扑时第一时间向她传回预警。
