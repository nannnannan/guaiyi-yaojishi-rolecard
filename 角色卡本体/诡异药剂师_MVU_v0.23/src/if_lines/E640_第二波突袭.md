# E640·第二波突袭·if线

- 若林恩在二队出击前主动为康斯坦丁船长加一条「战果必报」令，则中央对每座破碎之眼的破眼时点能精确到分,但船长的临场自主权第一次被中枢压缩。
- 若林恩让银色幻想从机械军团中拨一支小队垫在二队后卫，则二队的常规损耗下降一线，但林恩本队周边的防空密度随之稀薄一层。
- 若林恩主动通过群星通道把神疆提前压向二队即将空降的那座破碎之眼,则织梦破开第一波防线的速度再提半拍，但敌方会把「这片星区有主」的反应提前一刻。
- 若林恩把织梦每次破眼后留下的灵能碎屑当场封印入匣,则后续与中枢谈判多一枚实物筹码，但织梦需要当场分出一缕精神去稳定封印。
- 若林恩在敌方开始分兵死守瞬间下令二队反向撤位佯退,则敌方最高规格布防的阵型首次展开即被撕开一道缝,二队能挑最重的一座要眼首攻。
- 若林恩主动把自缚天使的战果清点推迟半日再上达中枢,则深渊军团的士气高点被多保了一晚,但敌方借这半日能多转移两座要眼的布防。
- 若林恩让织梦在斩下那名腐化神灵半边身体后再补一刀取神格,则她首次违背「拿不到神格就退」的节律,但她会在动手前先看林恩一眼——那一眼被在场所有神灵记住。
- 若林恩在击溃某座破碎之眼后让古神军团在此立一块无字碑,则该星区光复当日即有一处可叩拜的实物,但军团的行进速度会因停留立碑慢半刻。
- 若林恩主动把一名被困的根源灵魂以黑火护住而不是任其与织梦战场同燃,则那名根源在战后向他叩头一次,中枢战报里首次出现「根源主动谢林恩」一行。
- 若林恩下令银色幻想在战场中优先回收阵亡机械单位的核心,则后续修造能省三成工料,但美杜莎会私下追问他一句「为什么要替机械做这件事」。
- 若林恩主动让巨像在收复某座故土星球时同步祭旗她的旧乡议会,则她与艾维儿在地狱的旧颜第一次在圣徒文献里被正名,但敌方会因此锁定她的存在线索。
- 若林恩通过群星对织梦递一句「你也在主宇宙立过功」,则织梦当夜最后一击的速度提了零点一秒,但她在战后第一次主动来向林恩讨还这句承诺。
- 若林恩主动让船长在二队归来时抱起自缚天使一次,则中枢首次出现一队与二队公开相拥的场面,深渊军团的派系裂隙因此被抚平一线。
- 若林恩把「闪电战」的称号当场写进远征军档案,则士兵今后自称会用这个词,但敌方在事后破译档案时会把这个词当作林恩本人风格的指纹。
- 若林恩主动询问织梦这场仗还要打多久,则织梦会难得正面答一句「打到神王出来为止」,林恩第一次握到一个有形的目标边界。
- 若林恩让中枢为阵亡的那位根源按古礼立一道升灵仪轨,则他的灵魂残片被织梦亲手托举上升,自缚天使在该夜罕见地流了一次眼泪。
- 若林恩在真理神王脱困风声传来前先压军中通报半日,则军团在大胜的高点上多维持了半日,但中枢信任他的层数第一次被试探。
- 若林恩主动决定本队完全不动、只让织梦与二队单路推进,则敌方收缩战略会更快成型,但林恩本人将完整缺席这场闪电战的所有现场画面。
- 若林恩在战后主动踏上天鹰座边缘凝视被收复星区,则他会看见古神军团里某个古神在自己的故土残骸前跪下,那一幕会作为 E641 庆功场景的对照底色。
- 若林恩让银色幻想把阵亡机械单位的残件熔进下一批新机体的外壳,则新一批机体首次出战时外壳会带一缕旧紫光,银色幻想本人在熔炉旁站了一整夜没说一句话。
- 若林恩主动把敌方「只让不守」的战术规律写成一道简报发放全军,则后续每座要眼的攻坚时间都缩短一刻,但敌方在第三次识破简报后会反向布置一份假规律。
- 若林恩在织梦破第二十座破碎之眼时递一支镇静药剂给她,则她首次在战场上暂停服用,灵能输出短暂回落但清醒度大幅提升,战果反而更净。
