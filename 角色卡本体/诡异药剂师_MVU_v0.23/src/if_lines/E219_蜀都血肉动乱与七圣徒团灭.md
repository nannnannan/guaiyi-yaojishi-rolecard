# E219·蜀都血肉动乱与七圣徒团灭·if线

- 若林恩在畸变躯成形瞬间先把全身触手反向压在身下,让巨物维持第二人形态而非七八层楼高,则驱魔大阵只能瞄一颗比常人略高的目标,事件以变形（缩身避阵）收束,金瀑八成命中空处,周边半条街被焚烧。
- 若林恩在白人使徒下令布阵的瞬间先甩一根触手勒住对方手腕,则七道阵纹少一角,金瀑倾下时只剩五成威力,事件以不变形收束但金发使徒右臂首次被烙印入「不能再举圣器」的残伤。
- 若林恩把殖装鬼面尖啸者的数量从千计压到百计并把声波频段调高到伤人耳膜不伤心智,则使徒们的san值不再跌到崩溃线,事件以变形（有限声波骚扰）收束,圣保罗仍能站立试图谈条件。
- 若林恩在导弹来袭瞬间主动展开胸口一条已废弃的旧伤让弹头精准嵌进,则创口愈合画面被指挥无人机拍到完整特写,事件以不变形收束但林恩的「不变再生」首次被军方生物学家评级入档。
- 若林恩在弥赛亚以自身为筹码的瞬间主动点头放她走、只留其余六人,则谈判筹码从七减到六,事件以变形（圣女自由）收束,她带着「恶魔也曾放我」的实证归队,后续军事会议对她的怀疑陡升。
- 若林恩拒绝掳掠任何圣徒、只把七人捶晕丢在工厂水泥地撤走,则军队进场看到的是七具昏迷的活体圣徒而非空楼,事件以变形（无筹码离场）收束,后续他需要另起一个对话渠道或转向完全不同的施压杠杆。
- 若林恩倒提弥赛亚时顺手让她口袋里的崭新护照、钞票、单一号码手机当着其余六人掉落在地上摊开,则「未涉世圣女」的证据成为公开事实,事件以不变形收束但其余六人对她的同情值飙升、隐修会内部立场动摇提前。
- 若林恩用触手拨通弥赛亚手机里唯一的预存号码并把话筒凑到她耳边请对面回话,则梵蒂冈方向的圣音首次被七圣徒亲耳听到「允许牺牲」的口径,事件以变形（亲证上层冷漠）收束,弥赛亚对隐修会的信任当场崩塌。
- 若林恩在畸变躯毛孔里殖装夜魔族群而非鬼面尖啸者,则精神冲击由理智闪避换为暗影腐蚀、一件件圣器被咬碎,事件以变形（暗蚀非尖啸）收束,驱魔档案把「不明暗影族」单独立档。
- 若林恩让左左从体内钻出当众点名王麟「你爸的肺癌病历我看过我会治好他」,则王麟当场泪崩主动替他见证七圣徒未阵亡,事件以不变形收束但王麟的口供在后续被军方直接采信。
- 若林恩在七圣徒被卷入畸变躯之前先把他们的十字架法器逐一扯下地面垒成一排,则七件圣器作为战利品入列临时背包,事件以不变形收束但「炽天使信物」装备词条被点亮。
- 若林恩让血娃娃以【往日遗念】把七圣徒倒地姿态做成定格画面投给天台傀儡当背景,则傀儡开口时配着七张定格圣徒脸,事件以不变形收束但军方心理压力翻倍。
- 若林恩拒绝掳掠弥赛亚只把她钉在天台十字架与傀儡并列,则谈判现场多一张「活体人质」与「傀儡口舌」对照画面,事件以变形（圣女留场）收束,她只能以见证者身份出席。
- 若林恩用傀儡之印当场铭刻两名昏迷圣徒作隐藏耳目,则隐修会内部会议被实时窃听,事件以变形（圣徒反装）收束,容器阵营的情报提前两日到达他手中。
- 若林恩保持巨物状态不收回就这么碾压路面向城外走,则沿途三十条街民众目睹「恶魔游行」实况,事件以变形（公开示形）收束,蓝星舆论撕裂提前至当夜。
- 若林恩下令王麟先回家守在父亲床头再来集合,则晚期病人床前多一位战场见证者,事件以不变形收束但王父对「恶魔药剂师」的信任度填满,救命谈判多一枚亲情筹码。
- 若林恩用触手卷起融化柏油在半空烙下「救治专用勿扰」六字悬于蜀都上空,则军队进场先看见挑衅标语,事件以不变形收束但当日指挥官开战意愿升一档。
- 若林恩在弥赛亚被卷入畸变躯瞬间朝她手掌心塞进根自断的活体触须,则她归队消毒审查时无法洗清污染嫌疑,事件以不变形收束但后续审讯时档案多一条「不可信」红色标签。
- 若林恩在导弹来袭瞬间主动抬臂硬接而非任其炸胸,则创口愈合画面插入全球直播流,事件以不变形收束但某国超自然作战中心对「生物无限再生」评级跳到S档。
- 若林恩在掳走七人瞬间顺手把王麟塞进体内血肉袋护住,则他第一视角目击全程自带「恶魔日记」独家笔记属性,事件以不变形收束但情报口供独家度被点满。
- 若林恩拒绝傀儡话剧改全城广播直接对市民交代「圣徒还活着跟我谈条件」,则军方失去居中角色,事件以变形（跳过军队）收束,封锁大楼审讯室场景整体改由他直接对市民展开。
- 若林恩在掳掠时顺手把伤势最重两名圣徒用血肉缝合维生,则七人医疗曲线延后十二小时,事件以不变形收束但「恶魔行医」词条在蜀都市民口中扎根。
- 若林恩当场把掳来七圣徒以分身血肉做成七具雕塑排在十字架上,则傀儡开嗓时背景是七具仿真木乃伊式展览,事件以不变形收束但隐修会追责层级升一档。
- 若林恩在掳掠完成后勒索教廷一分钟内交出「真实伤亡清单」否则踏毁一栋圣彼得堂,则教廷三小时内多一本协商记录,事件以变形（勒索教廷）收束,谈判渠道从军方被强行转到教廷。
