# E187·样本截获与爬行者接管·if线

- 若林恩不亲自接入神经控制台、改让左左生成临时触手阵列代操控，则畸变体反应稍钝但林恩本人保留余裕，后续潜在反噬时间窗口被多留一拍。
- 若林恩在识破「故意调错频率」验证暗码的瞬间不动声色按原暗码发报，则钟塔接头首次接收到的就是伪装求救，林恩反向伏击提前一拍进入，事件以变形（暗码识破仍按部就班）收束。
- 若林恩任由俘虏把那条错误频率真的发出去，则钟塔接头立刻识别求救信号、守军立刻进入防御姿态，事件以变形（伏击暴露）收束，E188 整段炮轰名场面不再成立、转为强攻。
- 若林恩不骂「给爷立正站直了跪下来迎接补给队老爷」、改成走物流术语官腔，则翻译官不必硬译出「野爹」「榨汁机」，钟塔守军虽然没被气破防但也没被调到空地列队，E188 全队列欢迎的舞台场景消失。
- 若林恩在被畸变体警告「词库无此组合」时立刻改口换成「全员排好队，跪下」，则暗号被精准识别，接头语官毫无波澜发令，守军整齐列队，事件贴近原作但更流畅。
- 若林恩故意不把四百枚寄生幼体「妥善封存」而是让血肉灾变现场吞噬，则蓝星扩散危机当场减半，但他失去未来用作反向研究或贩卖的高阶材料筹码。
- 若林恩把寄生幼体全部现场销毁，则系统跳出「销毁寄生源地」成就并同步蓝星方向一道不可见的「断链回响」，闫未明这边的补给焦虑被提前推高一档。
- 若林恩只取走一半幼体样本、另一半留在畸变体腔内任其自毁，则他获得足够研究材料同时在蓝星残党侧留下大量证据，血肉神教后续追踪路径偏到他身上。
- 若林恩在收缴迷雾药剂配方时顺手让系统对照自身咒纹比对兼容性，则他发现该配方与燕尾服反伤机制略有互斥，使用时会暂时弱化一项被动，配方到手但带轻微负面。
- 若林恩拒绝缴获迷雾药剂配方、只截走幼体，则蓝星侧守军在 E188 战斗中保有反制手段，林恩弱化反伏能力，事件以变形（放弃药剂配方）收束。
- 若林恩让尹依坐到畸变体主控神经台上作为见习练习，则她首次担任实际操控手，师生线 +1，但她首次被以M神经反馈污染的概率同步抬升。
- 若林恩让首脑俘虏临时充当副操控、由他指路，则驾驶过程有更多细节情报可挤，但首脑随时有机会篡改暗码反噬伏击剧本。
- 若林恩驾驶畸变体时主动以燕尾服锁链固定钟塔方向、提前试发一发血红死光校准，则 E188 炮轰节奏的精准度+1，但钟塔守军提前听到动静、警戒线抬高一档。
- 若林恩放弃驾驶畸变体、仅以咒瞳远程牵动它前行，则林恩得以分神照应尹依与左左，但畸变体反应速度减半，E188 炮轰延迟一拍。
- 若林恩把爬行者暂时拆成两段、前半交给畸变体本能后半由他直接神经链接，则伏击执行效率+1，但精神负荷加重，后期审讯或诊断阶段他可能更疲惫。
- 若林恩在控制台发现额外一条「备用寄生兽投放腔」未在剧本内，则他可以选择临时截获一批二级样本，E188 战后战利品列表再加一行。
- 若林恩拒绝操控畸变体亲自前往钟塔，而改派首脑挟持畸变体前往、自己埋伏侧翼，则事件以变形（不亲自操盘）收束，首脑可能反叛也可能配合，剧本风险陡增。
- 若林恩让左左以人偶形态混入畸变体货舱内部伪装样本，则她在 E188 战时可以从内部刺探钟塔守军最初反应，为林恩提供第二视角情报。
- 若林恩把四百枚寄生幼体并成两只密集集装箱而非散存，则战时若畸变体被击毁、幼体流失风险集中在两点，蓝星扩散风险概率分布改写。
- 若林恩在出发前往钟塔前主动以咒瞳向黑夜城发一道简短战况通报，则 E188 集合接管的夜医部队提前一拍出发，到达钟塔的时间从「三十分钟」压缩到「十五分钟」。
- 若林恩付出一定代价把首脑俘虏的性命交给畸变体作为生物电源维持神经活跃，则畸变体在 E188 战斗中更稳定，但首脑被榨干死亡、事后无审讯对象，事件以变形（俘虏充当电池）收束。
- 若林恩在畸变体抵达钟塔前就主动朝黑夜城再接一条「准备全面接管」，则 E188 末段三十分钟等待被压缩到林恩炮轰结束瞬间夜医部队立刻到位，整体节奏整体前移。
