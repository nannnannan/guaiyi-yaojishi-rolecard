# E431·西海叛乱与深渊逃亡·if线

- 若林恩在吞噬者警戒追兵前先把一支镇静剂打进它残余触手的病灶根部，则它叙述叛乱时那阵记忆冲动被压下三成，提到「林恩」二字不再颤栗，能多还原一段女主人离开前的私语。
- 若林恩主动拒绝进入巨鲸腹腔改以咒瞳反向遮蔽队伍气味，则弑利亚幕僚在伏击圈外多损失十五分钟搜捕，但熔岩巨神的热浪会先从海床燎到他们脚背。
- 若林恩在九十九重幻境展开前主动令左左钻入一层血雾附在他背后，则她以幼态外形全程紧贴他颈侧不放手，事后登记一条「她在政变深海里第一次真正安静」。幼态固定非性。
- 若林恩接受吞噬者庇护却要求它改道避开熔岩巨神正锋，则队伍从寒冰生物封锁口中撞进一片死礁巨砾带，多拿到三袋可用于兑换的紫晶海胆，但失去听吞噬者讲完船名那段回忆的窗口。
- 若林恩在吞噬者讲述女主人失踪那段时直接喝问「她去了哪一层时间」，则它会被这问题逼得短暂恢复清醒、念出大君在异宇打时间战争的关键碎句，小丑在旁首次沉默不补讥讽。
- 若林恩趁巨鲨撞来时把第二枚满充能碎片反向藏进自己胸膛再令小丑撅起碎片露出，则初诞者注入路线被迫改由他自身做中继，灵能拿捏碎片成功率高两成，但他右肋多三道灼穿指痕。
- 若林恩在小丑配合投送时故意先在他颈侧留下一道咬合印记再令撅姿，则碎片充能瞬间那道印记泛起灼光，小丑事后无法解释自己为何全程僵直不敢改姿势。该协议属于成人色色机制成立口径，小丑为成年存在按成年处理。
- 若林恩直接把龙狙架在小丑腰窝强行让他固定射姿，则投送口令被压成闷哼，碎片命中黑体的瞬间小丑心率从零飙到一百八，事后他在内空间里对着墙角骂了半小时「人渣」。
- 若林恩拒用口令改用左左递送碎片，则投送轨迹偏出半米，黑体只被撕开一道细缝而非断裂，万机之神日志多一条「该黑体活性 +1」。
- 若林恩主动把吞噬者留下的替身触手割下一小段封入系统空间，则那截触手飞快无序化瓦解，但留下的残响让林恩日后可短暂复现「巨鲸腹腔」作为一次性护盾。
- 若林恩在弑利亚现身瞬间先用单片眼镜锁定她头盔缝隙，则她那番「父神窥见思想」的宣告被打断一秒，林恩多拿到她面皮底下半张被污染侵蚀的真脸影像数据。
- 若林恩主动命令队伍不回头撤离而改向左绕到吞噬者湮灭点背后，则他们全程目睹那片无序化海域如何吞掉一个整编骑士小队，林恩首次亲见无序吞人的真实恐怖量级。
- 若林恩在湮灭誓言喊出的瞬间同步把自己的渡鸦位格反向展开，则他能短暂「保留」那一声誓词的回响却不违反遗忘法则，事后他独自可对某个名字喃喃但写不出来。
- 若林恩让左左先用血族尖啸反向冲击弑利亚，则她的混乱干扰只维持两秒，但足以让林恩顺手在她王兽视野上烙下一缕渡鸦印记，弑利亚之后三天都甩不掉那道眼底黑点。
- 若林恩主动朝深海黑体掷一支自己调配的腐烂药，则黑体短暂紊乱放出一股紫色烟雾，林恩第一次听到黑体发出的不是噪音而是类似低语的语调。
- 若林恩拒绝接受「女主人打时间战争」的推论并当面对小丑说「我们死定了」，则队伍的士气登记直接掉入负值，孽主当场瘫坐在鲸腹腔壁上。
- 若林恩反过来接受推论但要求小丑也签字承认，则小丑首次在林恩面前放下讥讽，认真念出一句「那就活下来给我看」，绑定关系多一笔「他第一次没笑」。
- 若林恩让喵喵从系统空间探出头来对着巨鲨喵一声，则那头旧日机械巨兽的核心回路出现一拍紊乱，噬神者网络暂时没分清这一声是敌是友。
- 若林恩主动以渡鸦身份尝试对秩序化的西海叛乱骑士广播，则他最靠近的三名骑士突然跪伏进入沉睡，但弑利亚立刻切断他们与本体的联系强制重启，林恩注意到「重启后眼神换了」。
- 若林恩在撤离通道停留超过三秒做无效告别，则弑利亚的副手骑士追上切断一段林恩左手小指，后续他以初诞者之力缓慢重铸，这根小指从此带一丝旧西海咸味。
- 若林恩主动回头望湮灭海域，则他能在记忆里固定下「空洞吞海」的画面，但理智值短期 -3，且无法再对外说出吞噬者的名字。
- 若林恩在吞噬者湮灭前主动传一句心声「你名字我记得」，则它在消亡最后一刻残念颤动半秒，林恩之后三天会反复在梦里听见那半秒的回浪。
- 若林恩把整段 evacuation 改为用系统商城直接传送队友，则现实层林恩独自留下面对弑利亚，弑利亚第一次产生「这人在送什么」的真实迟疑，围捕节奏出现五秒空窗。
- 若林恩让小丑在湮灭誓言响起前先记下誓词而不依赖记忆，则他可以保存誓词内容却保不住说誓词的那个个体的身份，小丑胸前的旧疤旁比原作多出一道空白灼痕。
