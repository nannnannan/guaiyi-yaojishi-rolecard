# E131·母树临时同盟与未来筹码·if线

- 若林恩在巫神连发诅咒前先为她画出万机脖颈创口的精确坐标，则腐蚀与虚弱直接命中同一创口、生锈与短路沿着金属骨架蔓延，连锁负面让万机的撤离曲线整体下移一档。
- 若林恩主动替巫神头颅扛下一部分远程施术的反噬，让她的本体能够离战场半里继续发咒，则巫神的咒术射程拉长、不再依赖玩偶近距离传递，但她对林恩这只「好用的女婿」的溺爱度也随之加一。
- 若林恩在巫神笑谈家传刀法时顺势接话吹捧她当年的战绩，则她的兴致与咒术热情同步上扬，下一次诅咒附带额外恶作剧式负面。
- 若林恩劝阻巫神不要在女儿面前细讲偷看与捅刀细节，则她啧一声收起刀法自述，转而把怨气全堆到万机身上，诅咒集中度提升。
- 若林恩在万机龙息逼退群敌那一刻主动后撤为母树让出打击位，则母树的孢子与枝干接力封锁裂隙，撤退节奏被进一步打乱。
- 若林恩在万机欲闭合裂隙时抢先掷出身上携带的强腐蚀药剂而非交还芯片，则裂隙边缘的金属结构被啃掉一块，但艾雯的混乱继续恶化、防线压力转嫁给其他盟友。
- 若林恩把赛博记忆芯片拆成两份分别交给艾雯和母树，则两边都只获得部分记忆回填，艾雯的力量跌幅更浅但折射死光的威力减半。
- 若林恩坚持要艾雯在记忆回填后立即远离主战场而非折射死光，则万机不会吃到自己的死光，但艾雯能多保住一个阶位，文明记忆保留得更完整。
- 若林恩以巫神诅咒叠加自己体内哭泣小丑的咒性共同对万机施压，则万机的理智出现明显裂缝，但场域的咒性同步反噬林恩身上的旧创。
- 若林恩只取回「往日遗念」中艾雯三千年前那一小段而战前的片段不显化，则艾雯清醒但只回忆起战场以外的部分，折射死光角度偏移、错过万机命门。
- 若林恩让机械龙玩偶继承的不是「狂躁」而是「生锈」的回响，则万机的撤离裂隙金属骨架先一步锈穿，闭合速度被拖慢但母树的枝干也开始出现反向脆化。
- 若林恩在与母树讨价还价时直接以「一亲芳泽」之外的报酬开价（如帮其对巨像施加特定打击），则母树兴致稍减但谈判节奏加快，第一次出手落在巨像而非万机身上。
- 若林恩在母树化出垂柳精灵形态的瞬间不伸那只手而是先转述「你当年比这模样更漂亮」，则母树的泪光被压回去，出拳时多了几分收着，不再追加灌入全部欲望。
- 若林恩让母树以少女形态现身的同时不放弃三百米主干的对空封锁，则她的少女化只能维持极短时间，出手力度打折，但万机的后续龙吼也会因主干仍在而受扰。
- 若林恩让巫神头颅在诅咒之余为艾雯念一段安抚咒程式，则艾雯记忆崩溃的速度减缓，为林恩争取一段额外的窗口再权衡是否交还芯片。
- 若林恩在母树一拳灌入欲望后递上一瓶快渗式束缚药剂尝试封住欲望残留，则创口中涌出的肉芽被短暂压住，但万机对林恩和母树的锁敌列表同步加深。
- 若林恩反过来任由母树灌到满、让万机的脖颈创口连续爆发出三段恶堕回响，则万机将在短时间内被他自己的欲望反噬，但林恩也同步听到一段属于自己的恶堕预兆，E132 开端的泰坦引流映射出一段不该存在的林恩幻景。
- 若林恩在母树化身少女落拳前先以 M 拳在她拳锋上叠一层充能，则那一拳的欲望冲击附带快感冲击的复调回响，万机的理智下端被连根拽出，但母树会在事后用余光舔舔拳锋、把这笔账记进下次谈判的利息里。
- 若林恩把「以旧日自我换一次出手」的协议改成「以一次出手换一张离开地狱的地图」，则母树会抛下他更狠地砸一拳后要求更多筹码再放手，谈判被拉长到 E132 开场。
- 若林恩在协议里追加「我可以帮你打听三位一体真正的弱点」这一项额外筹码，则母树含泪出拳的力度会更重，但她也同步记下这笔远期欠账，往后的每一次接触都会以「你欠我的地图还没画完」的话术先行收回。
- 若林恩在协议里坚持写死「合作不等于归顺、不附加第一绑定的延伸义务」，则母树虽然仍哭喊那句「我才不要接受你的那条路」，但她在离场前会留下一枚开放性的地图碎片，作为一种「不解释的承认」。
- 若林恩让左左在对母树的谈判中当场戳破他脑中那份「大气层算计」，则母树立刻对林恩加高警惕，协议被迫转为更短一次性的单纯换拳，后续筹码窗口收窄。
- 若林恩在母树退场时跟着她一并跃出短距，则被她的根须鞭子毫不客气抽回，林恩留有一道让巫神看得直乐的血痕，错过她的临别宣告。
- 若林恩在万机神意识受欲望干扰的瞬间主动放弃追击残兵、转而盯住巨像之脑，则后者对林恩的视认加一，联合压制与压制对象在 E132 的排序发生互换。
- 若林恩拒绝在母树退场后立刻对小小她们发回去程信号，则她们抵达现场的时间被推迟，艾雯的跌阶被巫神独自吃下更久，咒牢内的成伤更重。
- 若林恩趁着谈判空隙把母树少女形态的画面通过视界群发给左左与小宝贝留档，则左左后续的「凑脑袋居然又看树」咆哮会比剧情点更早到来，同时巫神岳母也会顺藤摸瓜把林恩的「啪树」标签钉进视界档案，E132 的开场旁白多一道针对林恩的吐槽。
