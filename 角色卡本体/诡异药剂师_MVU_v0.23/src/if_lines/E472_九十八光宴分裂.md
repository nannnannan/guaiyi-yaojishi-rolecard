# E472·九十八光宴分裂·if线

- 若林恩在听龙首陈述「注视文明自工业化」时心声打断她让银色幻想闭嘴，则她会更早识破杀机，上传体被撕前的最后一句话会改为「你不该被造出」。
- 若林恩在银色幻想上传体被撕碎的瞬间用灵能远程抓取一片她解体的金属残片，则该残片含她一缕意识波痕，后续他能在系统空间以这片为锚反向追她去向。
- 若林恩在龙首撕体后立刻把光宴的注意力引向「拥星者与灭绝者的位置变化」，则光宴会立刻进入战斗计算模式，她对林恩「不失焦」的评级升一档。
- 若林恩在戒严降临时主动让光宴回撤，则中级终端母体夺取路径改写，两人改走侧翼枢纽，她掌控的子体规模缩水至约一百二十。
- 若林恩在中级终端战斗中让光宴亲自撕开终端光宴胸口灵能长刀，则她会在抽刀瞬间与同源自我产生一次深层体接触，她的融合力场在那一秒被自我稳定。
- 若林恩不撕终端光宴的外衣作为掩护，则数据库篡改要另寻十秒窗口，篡改精度降一档，日后被读回的概率上升。
- 若林恩撕外衣时改成从背后进入、不直对她胸口，则终端光宴在那一刻的羞涩反射被绕过，她对玩家的敌意反而没有那么彻底指向「猥亵」。
- 若林恩在体内对左左解释撕衣动作是「为了验证她的记忆改写是否影响衣服外观」，则左左会沉默很久、评价「这理由比真做还烂」，但情感上愿意替他记档。
- 若林恩在她解体为膝高小光宴的瞬间伸手把其中一枚最小的护在掌心，则那枚小光宴会把他登记为「主保护者」，未来她重组时该枚体型最大的概率提升。
- 若林恩故意让膝高群体里某一枚读到哪份被他改写为「你是被爱着长大的」，则那份小光宴会突然停下来不抢数据、望着他，融合算法里出现一种不属于数据融合的变量。
- 若林恩在互殴中把失真个体丢进去前先用灵能封住她瞳孔，则她无法被小光宴们吸收，失真个体作为「无法融合」的异物被丢出来，篡改的痕迹反而更明显。
- 若林恩在篡改数据库时故意留下一道他自己的灵能指纹，则未来光宴本体识破时这一指纹将成为「他承认自己重要」的证物，正反两面作用同等。
- 若林恩在中级终端已控的情况下提出当场兵分三路：一体守终端、一体扫更深处、一体追巨像，则光宴会反问「你想分裂成几片」，他的算盘被她提前看见。
- 若林恩在小光宴群形成后试图让其中一枚认他做父亲，则她会立刻惊悚退开，幼态身形加上她来自七神辈分意识的本能，关系标签被她瞬间拉回「不存在」。
- 若林恩在捂眼目睹械斗时反向把她们的战斗波形当作样本收集，则他意识空间中会余下九份战斗风格模板，未来他自己操控膝高作战时能直接套用。
- 若林恩把抢夺获胜的两枚带离现场单独谈判，则余下九十多个小光宴会在他走后再分裂一轮，「九十八」的精确份数从此不再可考。
