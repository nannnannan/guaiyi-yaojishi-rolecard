# E389·旧日渡鸦幻境与左手疑踪·if线

- 若林恩在旧神战场幻境中主动朝狱卒掷去一支镇静剂，则画面出现一丝涟漪，狱卒扑击动作滞后半拍，他被疼痛贯穿的体感强度下降，现实坠落速度未变。
- 若林恩在幻境里尝试与「那只左手」对话，则画面静止一瞬，左手背印记亮起一声「该战斗了」后戛然而止，现实左左同步发出相同音色，系统记为「音色重合」。
- 若林恩拒绝共享幻境画面给左左并独自消化，则他对左左的信任度暂时下降，左左在意识空间里抱臂不吭声，后续共享建立需额外一层主动解释。
- 若林恩在共享幻境时故意掐断炽天使被金属骨骼挡住的那一段，则左左只看到左手拔刀，她对「那只手是不是我」的困惑更深，但缺少关键矛盾证据。
- 若林恩用初诞者之力包裹左左一起沉入幻境，则两人同时被拉回现实，左左的小触手因时间差抓住石棱慢了半秒，下坠速度陡增，着陆风险上升。
- 若林恩在幻境中以夜魔刀辨认左手所持战刃，则画面里的左手微微侧目，战刃发出与他现实中武器完全一致的频率颤动，同源证据 +1 但身份仍无法确认。
- 若林恩在蓝星海面幻境里尝试对炽天使呼喊「自缚天使的妹妹」，则画面毫无反应，她依然持剑警戒，现实左左同步打了个寒颤，报告「有人在看我」。
- 若林恩在幻境中主动触碰左手拔刀时留下的那枚翎羽，则翎羽在他掌心碎成光点，渡鸦凶性信息首次以可交互形式出现，他获得一缕「远古存在」的模糊气味。
- 若林恩在幻境里强行用咒瞳扫描左手手背印记，则印记反噬出一股古老威压，他眉心被烙下一道无法消除的金色灼痕，现实身体同步出现同款伤痕。
- 若林恩让左左在幻境外以餐刀模仿左手拔刀姿势，则餐刀应声而断，左左虎口震裂，她哭着说「我做不到」，模仿证据被系统标记为「力量层级不匹配」。
- 若林恩在幻境里主动切断意识链接以保住身体控制权，则他提前醒来，幻境记忆只保留到左手拔刀前一刻，后续炽天使画面完全缺失，线索链断裂。
- 若林恩在幻境中尝试用血肉灾变覆盖左手，则画面剧烈震荡，左手反手一刀劈开他的幻境具象，他被强制弹出，现实身体多一道深可见骨的刀伤。
- 若林恩在幻境里记录左手声音与左左的频谱对比，则系统报告显示两者基频完全一致但谐波结构存在微妙差异，「同源不同体」假说首次获得数据支撑。
- 若林恩在幻境结束后拒绝向左左透露任何内容，则她在意识空间里沉默良久，最后轻声说「主人，你是不是看到了什么不好的东西」，信任裂痕首次出现。
- 若林恩在幻境里主动吸收左手残留的意志碎片，则一股冰冷杀意涌入他的识海，他瞬间失去对身体的控制三秒，现实坠落速度失控，左左必须用尽全力拉住他。
