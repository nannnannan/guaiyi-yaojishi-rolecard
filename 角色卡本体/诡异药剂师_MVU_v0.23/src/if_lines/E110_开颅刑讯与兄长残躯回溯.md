# E110·开颅刑讯与兄长残躯回溯·if线

- 若林恩不顺银色幻想的单分子剑而是自带疫医药剂师解剖刀开颅，则银色幻想不会被气到炸毛，但林恩失去"顺剑"的调侃张力，博士的恐惧铺垫更冷更直。
- 若林恩接剑后回敬"借剑付费，弑神另算"，则银色幻想愤怒再飙，但她也会记下这笔人情债，在后续事件里以更牙尖嘴利的姿态逼他还。
- 若林恩在开颅前先把单分子剑的火属性附魔换成自己配的低温冻髓药剂，则315脑浆不会被高温熔成泡沫而是被冻成脆晶，敲碎取样的体验更血腥但痛苦层级下调，博士招供速度放慢。
- 若林恩第一次下剑就没有"插错位置"的调侃，直接精准刺入脑干要害，则315的恐惧累积被打断，博士反而会在剧痛中找到一丝"对方也是新手"的侥幸，招供完整度下降。
- 若林恩在每拔一次剑时刻意把脑浆增量药剂换成致幻版的记忆回灌药，则315会在恐惧中被自己几百年来所有试验品的脸孔包围，招供内容会更详尽，但林恩也会被博士那段最深隐秘记忆反向冲击一瞬。
- 若林恩在刑讯间隙让爱丽丝从胸口探出恶灵之手抚摸315颅顶，则315会误以为那只是安慰信号瞬间松懈，林恩可以趁机套出比原计划更多的储物坐标，但博士事后会以"被骗"加重灵魂反噬。
- 若林恩放弃钻孔开颅改用左左血肉编织针刺入315脖颈神经丛做软刑讯，则同样能掏出兄长骸骨下落，但失去血肉增生药剂那套反复熔浆的回环展示，事件张力降到软刑层级。
- 若林恩选择不开颅直接让咒瞳全力压垮315意识，则博士会在精神崩解中自行打开储物空间，但林恩失去【开颅者】气质加成，系统为其升39级时只记一次压服不记刑讯工艺。
- 若林恩在315储物空间打开前先用系统扫描锁定内部，则他能提前发现骨架上还残留活性灵魂碎片，过往遗念的回溯会被标记为"含活性怨念"，告别场面的温柔底色会带一丝未化解的刺。
- 若林恩在骷髅被取出瞬间让咒瞳直接净化死者恨意浆液，则爱丽丝的恶灵之手不会被轰出，但少年骨架在【过往遗念】启动前就被剥夺了最后一丝残留情绪，回溯出的"哥哥"会更纯净也更单薄。
- 若林恩在【过往遗念】银白光晕铺满骨架时主动注入自己一缕魂丝作为锚点，则少年不仅能回溯肉体还能短暂保留"新生意识"，他会在道别后化作魂种可被林恩收进背包，E111后林恩多一件一次性灵魂道具。
- 若林恩在回溯时主动只回溯肉体不回溯灵魂，则站在喵喵面前的只是一具没有意识的少年空壳，喵喵会在拥抱空壳时崩溃，事件变形为"安慰喵喵"续集。
- 若林恩让喵喵亲自用手把那具少年骨架从储物空间里抱出，则她在途中会触发自己幼年记忆的二次崩塌，回魂告别时叫"哥哥"那一声会带哭腔，后续事件里喵喵对林恩的依赖度显著上调。
- 若林恩在少年不甘灵魂作别时多问一句"要不要留下来变成我的仆从"，则少年会摇头拒绝但仍然凝视林恩数秒，他对喵喵留下的最后一句会从"再见"变成"跟着他"，把林恩绑定为喵喵兄长线唯一受托人。
- 若林恩在少年消散前让银色幻想留下一缕剑光作为纪念，则少年会带着那道剑光化作微光，银色幻想的全场怒气会在这一刻转成一种复杂的敬意，E111她对林恩出手的态度软化。
- 若林恩选择不让少年灵魂再现只让喵喵对着枯骨道别，则事件仍能收束但失去温柔底色，喵喵不会泪流满面而是陷入长时间沉默，她后续会以冷硬姿态抱着315的灵魂容器不放手。
- 若林恩掏出灵魂容器后没有随手掂了掂而是立刻封存进咒瞳瞳腔，则博士意识残片撞击容器壁的声音会被瞳腔吸收放大，林恩短期内会持续听见博士的哀嚎，获得临时【灵魂共鸣】buff但每夜的睡眠结算都会扣一点稳定。

- 若林恩把灵魂容器没有交给喵喵而是自己收起，则喵喵不会在事件中与他和解，事件变形为"喵喵争夺灵魂容器"的支线，直至她情绪被另一事件安抚才重新回到主线。
