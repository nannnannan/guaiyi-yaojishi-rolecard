# E374·最后记忆与心灵边界·if线

- 若林恩在大窗前那段重复读书画面里主动代入她的视角数一遍书页，则他确认这本书翻了两百多次，画卷时间被估算完成，他在回到现实后多了一段「看到书脊就熟」的隐性代价。
- 若林恩在那片灰白淡漠的视野里反向搜索一丝彩色残影，则他首次翻出姐妹们某次归家时她夹进书页的一枚干花，深层执念与「家」的关联又多一条对照证据。
- 若林恩主动凑近黑色镜面前幼小女孩手腕的旧伤只看一眼即收回目光，则他眉心被倒映旧伤刺痒半秒，巨像网络在宾客档里加一行「对创伤影像过敏级 +1」。
- 若林恩在幼小身影放下旧布偶瞬间主动记下布偶的裙摆花纹与磨损点，则归现实后他能向人偶夫人报出完整残缺清单，两者比对若一致则在档案里画一条连线。
- 若林恩在她跨进最后光点时选择不追而站在原地记下光点的位置坐标，则他给后续进入留了一条「锚点归位」的落点，下一次下潜省去重新搜索整片镜面。
- 若林恩跟着光点走完烬寂海岸那一段，则他耳膜边回响着旧世海浪的低频轰鸣，回到现实后三息内不能听清床边低语。
- 若林恩主动凑近观察那具齿轮骸骨脚丫落岸瞬间的黑色丝线萌芽，则「人偶改造先于诅咒」这一事实首次被他用现场视角锚定，档案里被盖「亲眼所见」的红印。
- 若林恩决定在人偶夫人撑船接人那段记忆里凑近听她那句指引的来源，则他听见一缕极远的女声，听不清内容，但他确认她是被指引而非主动寻来，留下一个未决疑问。
- 若林恩在艾雯提出质疑时主动替人偶家缓颊一句「在生存面前取舍本就是疫医也做过的选择」，则人偶夫人的目光在他身上停了一瞬，档案里多一行「宾客与疫医视角同频」。
- 若林恩当场决定放弃越界、把疑问打包给人偶家自己解决，则本轮调查收束在「边界之外未入」，深层意识海不再被惊动，黑弦月床边灵能耗费 -1。
- 若林恩仍要越界但在越界前主动把一缕疫医气息封入左左指尖作为锚点，则他在心灵边界外多一枚定位参考，误入混乱之海时可被拖回，但疫医气息残留会被边界外某个生灵注意。
- 若林恩越界时主动停止主动思考改成被动接受片段，则他先看见的是来自别时间线的他人梦境，陌生人脸混入画布，黑弦月锚点一度偏离。
- 若林恩在边界外想用心声与艾雯联系而忘记自己已经跨出，则他首次体验到灵能联系在边界外的衰减，回到边界内时联络那头只剩一记暖光、没有了清晰字眼。
- 若林恩顺着小拇指丝线小心拐进那条油画与电灯并存的奇异走廊，则他看见两侧仆人如镜面般无五官，他意识到这里不是真实年代，但他选择不掉头。
- 若林恩在无五官仆人端菜经过瞬间主动停下凝视某个瓷脸，则该瓷脸在记忆里凝望回他一秒，随后整列仆人同时把他的位置标入「陌生宾客」栏，画面出现轻微凝滞。
- 若林恩在听到窗外汽笛与齿轮声时试图辨认大厦的旗徽，则他勉强认出这是旧世某座工业主城的一角，地点坐标首次写入画卷但却没有时间锚。
- 若林恩在边界之外主动叫出「黑弦月」三个字想确认她是否还能听见，则整条丝线在那一刻毫无反应，他意识到她无法接收越界信号，该事实被时刻记下。
- 若林恩决定放弃沿走廊深入、退回边界内汇报，则他在灵能缓冲区咳出一小缕黑雾，但本轮记忆已获得的全部线索被保存为「已完成片段」档。
- 若林恩主动向人偶夫人询问「女主人」的身份一角，则她目光停顿、说自己只是被指引过去，未给名称，留下一个明确的悬置。
- 若林恩选择把艾雯那句「这里不再是她一个人的意识」记成警句，则下次越界决定一次性从重评估，玩家对该边界的态度被写进档案态度栏。
- 若林恩当场宣称「越界后我不再好奇她之外的事」，则他在边界外主动屏蔽陌生生灵进入画布，混乱之海刺激 -1，但他对深层意识海的探测灵敏度同步下降。
