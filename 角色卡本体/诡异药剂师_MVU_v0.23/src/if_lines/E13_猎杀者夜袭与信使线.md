# E13·猎杀者夜袭与信使线·if线

- 若林恩提前在视界看到「游魂巷再次入侵」信息流，则可在夜袭前数小时警觉，主动布置房梁、门框、天花板三层卡位，三个猎杀者入店时被动遇伏，战斗烈度被压短。
- 若林恩选择在门外、街角、隔壁废屋之一设遛哨，则猎杀者入店瞬间只能锁定空铺，林恩从外侧包抄开局；店内财物与手术台保留整场战斗。
- 若林恩提前把萌娃托给血衣女士回避，则夜袭仅林恩+左左两人迎战，血衣女士次日得知才到场，好感度按「被瞒下」扣减一轮。
- 若林恩在械魔神经同步完成前击杀3号猎杀者，则械魔来不及反打，1号2号同步崩溃；倒吊塔当晚只拿到模糊的最后画面，对林恩的威胁评级从a级下调一档，协会下一波追兵延迟到来。
- 若林恩被自己人第一个卷入左手巨口（血衣母女、邻居或其他住户），则夜袭前先把伤者拉出来赔药剂，「来者」延误上楼架位，三猎杀者完成扫描到完整布防。
- 若林恩让分身触手向外诱敌出店，则三猎杀者被分批引开，血锯药剂店本体得以保留，但首都动态共享片段可能纪录为「药剂店学徒在街头乱斗」。
- 若林恩不取用聚焦之瞳、而让左左/血衣女士吸引住械魔意识同步体，则用猎魔左轮+龙息之臂硬拼三具猎杀者，赢得更慢、伤势更重，但聚焦之瞳也脱手到他人口袋，为后续议价筹码。
- 若林恩只用聚焦之瞳而不动龙息之臂，则三猎杀者被凝视诅咒融到半毁，械魔被反噬弹出同步时只看到「一只异变的血瞳」，对林恩的评估全新翻一版；左手没机会兑现「吃掉敌人」份额，与林恩关系短暂恶化。
- 若林恩只要把械魔同步体打成半废而放过1号2号，则那两具猎杀者倒吊塔还能转交下一批，第二天街区就会出现「哑了」的残体被在视界散布更多画面。
- 若械魔反噬的那一刻林恩顺势让场中烧着，龙息余焰卷进隔壁住户，则第二天需要面对邻居赔偿与管理局斥责，当前事件仍算完成，但「血锯药剂店不可夜间动火」会被放进区域规则提醒。
- 若林恩在战后以相对完整的状态出现在血衣女士面前，则女士会多提一个「带萌娃走」的岔话，血衣女士部分好感度交付护命，而E14的术后复诊次序可能被提前。
- 若林恩从尸骸上只拣起一两样能用的部件（刃腿、冷却液包）然后放弃掘坑，则械魔的「血锯身上巨象碎片」剧情补语不变，但认为造主线索暂时没有向外走。
- 若林恩拒绝去视界找情报者024，而是靠剩几个骷髅币在街头打听，则024的镜头会主动贴过来推销，情报线照样打通但首价翻两成。
- 若林恩先被024报价吓退、只买最低档100骷髅币的废话答案，则名册不会展示，林恩只能亲自跑腐地龟王的野区推迟联络，事件仍在1日后算作等价走向。
- 若林恩向024多投1黑颅币问「械魔现况」，则024会把械魔手脚状态、已接管区域概要列出来，这会成为E15求援大家时的决策依据。
- 若林恩在名册上放进隔壁空铺门牌，则信使到货需要在废屋蹲点一夜，瘦长鬼影上门会扑空一次到正品小店门口，第二天才会闪进正店补签收。
- 若林恩只预约虚空折跃兽两只，不预约腐地龟王，则第一份急件先行送出，第二份（备份）永远没到；血锯或小小只收到一份被烫焦的信纸，扣不到关键信息也当成求救成功，E15会开出一个「情报不完整」分支。
- 若林恩签契约时把血滴入两份卷轴同血不同名，则信使们会认领为「变态双生兄弟」，E15求援回执会同时被送到两个疑似同来者身上，戏谑意外事件。
- 若林恩顶下「不平静的夜晚」任务奖励立刻换取随机诊断术并使用，则第一次手吐后左手开始保持多个戒备周期，作为道具结论的高阶商品，并可提前锁定E14患者的首次复诊。
- 若林恩决定暂不进入视界，也未使用名册信使，而靠人手画地图、街头购买传闻，逐日韩追查魔人协会动向，则夜袭结束=事件完成，但E14/E15伏笔两路涉水推迟，同期协会的第二波重兵不会被提前预警。
