# E28·爱丽丝日常与十四病战蜥·if线

- 若林恩不出门逛街则爱丽丝自己溜进店翻棒棒糖，改为店内陪伴，恨意降幅延缓不取消。
- 若林恩答应爱丽丝摁住黑暗生物啃食则她扑咬留下断尾，恨意即时降一段并引发街坊避走传闻。
- 若林恩以讲故事、修玩具、做糖浆顶替逛街则陪伴收益等价记入关系。
- 若爱丽丝自洗、林恩只递皂角热水则洗澡变形为侍奉陪伴，信赖涨幅降低恨意仍降。
- 若洗澡接触滑向亲密则按成年角色直白呈现身体反应与过程，信赖好感按经过结算。
- 若林恩抚摸缝合处问「当时痛不痛」则触发她对古堡一句「已经不痛了」，记未言明心结。
- 若爱丽丝在手术台索吻或更进一步则以M等价机制并行呈现，重缝亲密不冲突，信赖大幅上调。
- 若林恩不重缝只敷药压裂口则缝线隐患记入近期事务，下次受伤引发「缝合散架」。
- 若林恩第一枪击毙战蜥则抢劫线取消，少一长期患者，名声记「狠辣医生」。
- 若林恩擦枪警告未做诊断则战蜥离去不回头，十四病列表延后至E30-E31引爆。
- 若林恩被压制则由左左或爱丽丝按人设救场，落点仍是战蜥跪伏或逃逸。
- 若林恩骗战蜥「没事」用安慰剂收钱则成误诊客户，未来病发成医德债伏笔。
- 若林恩认出猛男图反应并挑逗调侃则诊断推向羞辱调戏，战蜥羞愧仍以病患回头。
- 若爱丽丝露恶灵之躯吓退战蜥则抢劫以「非人病人」等价收束，爱丽丝声名传开。
- 若林恩只收成本或免费则战蜥记恩情，游魂巷传言「那家店是良心」。
- 若林恩把诊断故事讲给爱丽丝则她对人类疾病产生兴趣，对照古堡背景记小温度。
- 若两线均不在场则按取消条件收束并记偏离账本，药店稳定改由其他日常建立。
- 若战蜥对爱丽丝言语轻佻则按成年身份呈现她反应，林恩干涉由玩家声明。
