# E399·夏娃进入家庭·if线

- 若林恩在自缚天使警告后立刻让小小与夏娃同台吃饭，则小小会立刻放出细触手掠走盘里肉片，夏娃的捕食本能被小小速度压制，事件走向「小小示范进食礼仪」。
- 若林恩让喵喵主动把小鱼干塞进夏娃血管堆里，则她会因「体型小巧+食物分享」的信号而停止攻击先兆，但她的万千眼睛仍会直勾勾地盯着喵喵的胸口。
- 若林恩让夏娃在浴室清洗时直接扯掉她的血管外衣露出核心，则她的「没有皮肤、布满眼球与嘴巴的血红女孩轮廓」会立刻呈现在他面前，入夜夜袭的可能性极高。
- 若林恩在她变成血红女孩轮廓之后立刻用毛巾盖住她的眼部，则她的「万千小眼球」视觉被遮挡，但触觉敏感度翻倍，她的血管会更频繁地贴到他皮肤上。
- 若林恩在她咬左左吸血读取记忆时立刻切断她的血管，则左左不会被读取，但夏娃会因为「被剥夺亲密信息」而缩在墙角发出低沉呜咽，关系需要重新建立。
- 若林恩让左左被咬后反击咬回去，则夏娃会因「猎物反击」而愣住，随后会因为「品尝到缔造者之左手的记忆」而陷入混乱，需要去客房静一静。
- 若林恩让小小陪同夏娃一起睡觉，则小小会用触手把她捆成粽子形状防止乱爬，但夏娃的血管可以通过缝隙钻出继续夜袭。
- 若林恩让喵喵和她一起洗澡，则喵喵的爪子会不受控制地戳她的血管，她会被戳得痒痒而蜷缩，浴室里全是黏丝和笑声。
- 若林恩给她讲睡前故事，则她的万千眼睛会随着故事节奏眨动，但她可能在听到「勇者战胜恶龙」时把「恶龙」理解为自己，需要玩家及时纠正。
- 若林恩让她在料理活动中负责切肉，则她的血管可以替代刀具完成切割，但小小会立刻抢走她切好的肉片先跑，她需要学会保护自己的劳动成果。
- 若林恩让巨像之脑穿裙子来当副家长，则巨像之脑会皱眉但会配合，她的裙摆在夏娃血管扫过时会沾上黏液，事后她需要换一套礼服。
- 若林恩让左左当她的武器教练，则左左会让她用触手练习抓握，但她会不自觉地把触手往左左身上缠，左左需要不断警告「不许摸本左手」。
- 若林恩让她模仿左左的幼态外形，则她会分化出五指与眉眼，但皮肤颜色仍然是本体的血红，看起来像一个红色的小女孩，需要后续调整肤色参数。
- 若林恩让她模仿喵喵的猫耳外形，则她的血管会凝出猫耳形状，但材质是血肉不是毛发，喵喵会摸一下说「你这耳朵怎么是湿的」。
- 若林恩让小小教她飞行，则她会尝试模仿小小的悬浮，但她的血管重量太大，只能低空滑行，且落地时会因为冲击而散落一地眼球。
- 若林恩让她模仿人偶家的精致外形，则她的血管可以排列成接近人偶的复杂纹理，但材质仍然是蠕动的血肉，人偶家看到她的「血色人偶」会发毛。
- 若林恩让她在人偶家面前展示「变成和大家一样的人形」，则人偶家会被她的「没有皮肤」震撼到失语，需要玩家解释这是她的基础形态。
- 若林恩让她用触手帮忙收衣服，则她的血管会把衣服缠成奇怪的形状，左左会骂「笨蛋！！衣服不是这么叠的」，但她会学会「衣物不是食物」的概念。
- 若林恩让她和喵喵抢小鱼干，则喵喵会亮出爪子护住食物，她的血管会退缩，但事后她会偷偷告诉林恩「那只猫好凶」。
- 若林恩让她和巨像之脑一起洗澡，则巨像之脑会被她的万千血管搅动水面而不悦，但夏娃会因为「同类气息」而主动靠近巨像之脑。
- 若林恩让她模仿左左的「切齿磨牙」动作，则她的血管会模仿出锯齿状的形态，但看起来更像恐怖片里的怪物，左左会评价「你这是想吓死谁」。
- 若林恩让她和喵喵玩「追逐游戏」，则她会用血管在地面上滑行追逐喵喵，喵喵的敏捷性比她高，但她的血管可以瞬间包围喵喵，游戏以「被捉到会舔脸」结束。
