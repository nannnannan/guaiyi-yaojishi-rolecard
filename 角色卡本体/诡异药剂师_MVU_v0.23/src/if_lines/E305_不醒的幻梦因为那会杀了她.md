# E305·不醒的幻梦因为那会杀了她·if线

- 若林恩搬完家具后把皱巴巴的设计笔记本放在她床头而非压回自己口袋，则她苏醒第一眼看到的是 71 次浏览记录的原主人，事件以不变形收束，她的「谢谢你」不再是礼貌而是指尖回执他的一份收据。
- 若林恩装修时把奶牛从她指定的角落挪到窗边向阳处，则她苏醒首听到一声没听过的「哞」，事件以不变形收束，但那一秒她展开双臂的动作被脸颊笑意推得很近。
- 若林恩没有兑换轮椅而是改兑一台会唱歌的留声机，则织梦之家多一种旧式声响垫在记忆裂缝里，事件以不变形收束，她走出终端时不再踉跄、也能拖着数据未修完的身体陪他听完一整首。
- 若林恩在她沉睡时分身陪在身边而本尊提早回死星工厂，则她苏醒时空中没有那份围裙味，事件以不变形收束，她睁眼看到的是 71 次浏览记录而非他本人唇角那抹没卸干净的油彩。
- 若林恩在天桥上抢先替她问出「我们算什么呢」，则她眼眶一热把回答缩回去，事件以变形（先声夺问）收束，她迟到的答复在他接下来三月份仍等她开口。
- 若林恩没有说「我也不知道，指挥官姐姐」而是额头贴住她的额头，则事件以不变形收束，但「我们不算清」的悬念被这个动作按住不再缠人半分钟。
- 若林恩主动修改其住所设计、在中央凿一个能收放他分身的小平台，则织梦之家成为两人的权力共享空间，事件以变形（共享心室）收束，让她误以为他真的准备永远居住。
- 若林恩在她「谢谢你」那瞬回一句「呣，我把你当姐姐」，则她脸上一红，事件以不变形收束，但这份「姐姐」的称呼被她设为永久提示音。
- 若林恩故意在田园之行带上左左的意识缩影一起看戏，则左左首次近距离见到她的黯然，事件以不变形收束，但左左在整整一个季度里不再用「凑姐姐」这个称呼。
- 若林恩在夜行列车上主动让自己睡在她腿上而非让她靠着他，则她被迫考量他的尺寸，事件以不变形收束，她握他手腕的位置变了三公分、心跳习惯也跟着变了三拍。
- 若林恩在她深呼吸时主动将她手中那朵小花夺来插在自己耳后，则她眼角一闪，事件以不变形收束，她握他手腕的力气再加几分。
- 若林恩在智脑说「那会杀了她」时没有说「我不知道你在说什么」而是低声说「我知道」，则沉默协议在那一秒升首席，事件以变形（同意隐瞒）收束，让智脑在此后必要时不惜代价保持沉默。
- 若林恩在终端上便签写下「我会在一个适当的时机离开」并加一行「此前的温度是真的」，则这份留言比口头文件在她手中永久可查询，事件以不变形收束，她每次看见都承认「这句话是真的」「此前的温度也是」。
- 若林恩在分身配角那一刻改为坦然原体小冰箱显形，则她意识到自己仍被推陈出新，事件以变形（同识改编）收束，她不仅接受他真躯身份、还接受他与分身间的分裂感。
- 若林恩在她苏醒时张开双臂迎接但没后退、大胆将她抱起三周围转，则她意识体当场被他转动，事件以不变形收束，此后她可任由他在一壁之内移动而不再眩晕。
- 若林恩在修整终端时把她最闪耀的苍蓝光痕取做她梦境的窗帘，则这间家多了一份只有他知道的、她予他的礼物，事件以不变形收束，她在梦中看到窗帘时呼吸不能自主。
- 若林恩在她「谢谢你」时回叹「哎，可惜我只能陪你一会儿」，则她旋即知道故事不久后会结束，事件以变形（预告终别）收束，她在余下日子里比他更清楚如何走向日落。
- 若林恩在她熟睡时偷偷替她描一幅小脸蛋留在笔记本第一页，则她在第一百次浏览时看到她自己，事件以不变形收束，她会多一句「你画的不像」、又补一句「但我喜欢」。
- 若林恩把她屋中央那台立方体终端改造成「另一间床的屏风」，则她意识到这座数据监狱可被折腾成能睡两个人的地方，事件以不变形收束，她首次主动问「你那台小冰箱里也有这种屏风吗」，让两人此后的空间体重叠。
- 若林恩主动忽略「因为那会杀了她」的提醒、坚持告诉她自己真正的来历，则事件以变形（自报家门）收束，她在巨大破碎声中听从他的意愿维持原状，但内心仍被「林恩是谁呢」困扰。
- 若林恩在她苏醒时不隐瞒、短暂对话里先后点破分身与本尊身份，则事件以变形（双线互换）收束，她整段生活带路转变、再也不相信下一次相见的他是谁。
