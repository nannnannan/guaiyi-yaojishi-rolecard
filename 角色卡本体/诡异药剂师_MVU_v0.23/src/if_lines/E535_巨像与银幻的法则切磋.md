# E535·巨像与银幻的法则切磋·if线

- 若银幻应邀切磋时不铸战争堡垒，直接把自己升到机械巨龙形态对标，则整场开场省一段堡垒碎裂再看巨龙重组的二段式，血肉巨人迎上的对手会是同级巨物而时间更长。
- 若巨像邀战时不是伸出小手而是先伸出一只仍包着与林恩战斗新伤的手掌让她自己撕掉，则双方互相理解是以共享伤痕开场而非林恩私授。
- 若银幻以原子机械借用周围物质塑造代替单纯动用创造规则，则切磋战形成「外力搬运对内功迸发」的对照主线，规则理论对话会更偏自然科学。
- 若巨像在力量法则加持时不沿外附路径而是先把它锻入自己右拳骨一边试爆，则她走出的是更高风险的「承受进驻式」路径，外附增幅理论的开口会后撤。
- 若银幻在切磋结束后不只「我也收获很多」还主动开口：「下一个教我的是……」并急收，则巨像会立刻捕捉「他」这层名字被刻意收紧，她的私核保密同盟觉醒时点前移。
- 若林恩远程联系时不只「耐心等待勿泄身份」还主动汇报「我现在已经找到同路人」（指自己给自己），则银幻的同盟感知范围多一层抽象，远比「同盟在外面」的承认更精神性。
- 若巨像主力气场是红，银幻主力气场是蓝，则切磋将呈现鲜明的红蓝对照视觉效果，观者（林恩若远程旁观）会立刻想到冰火两重天的领域混合。
- 若巨像在无意中看到银幻体内血肉气息残留时主动以探视方式清理一部分，则她会提前一段「要擦干净」的戏份，她帮银幻做这件事会带来身体之间的更深一层亲密。
- 若银幻在原子机械链接激活时不只发讯号也发一段声音，则二人的远程对话会比「只说了两句话」更具体，巨像会多一层「她和他对话感觉如何」的观察面。
- 若切磋结束时不是巨像先变回银瞳小女孩，而是银幻先变回银色短发少女形态，则视觉的「力量归还」由她主动呈现，巨像的气场收缩将带有一份回应姿态的优雅。
- 若银幻主动告诉巨像林恩在南方时多加一句「他就在主母巫神那里」，则巨像的允许范围会更明确地知道他下一步将进入危险区，E536的破折感会更高。
- 若同盟结成时巨像不只与银幻握手还主动给她一个「我们是同路人」的拥抱，则她第一次主动拥抱非林恩的成年女性，她关于身体的柔情轴走出一条新径。
- 若切磋二人主动把战场从荒原改在镜像虚空，则她们后续的法则演练不会被众根源远程感应到，同盟保密度再加一层，但与「平等切磋」的初衷更偏离。
- 若左左在离开主眼识时恰好溜到切磋场边围观一会儿，则她可能看见自己主母「挨着打路开悟出比别人更远」的画面，她后续劝他再见主母时会有沉重克制。
