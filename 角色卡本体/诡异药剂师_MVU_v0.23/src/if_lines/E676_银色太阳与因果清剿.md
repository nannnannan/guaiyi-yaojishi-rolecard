# E676·银色太阳与因果清剿·if线

- 若林恩在抵达第一处火海时主动用空间神格扫视全场判断无一生还，则他会瞬间锁定下一处坐标，但火焰中的遗民尸体将因无人回收而完成污染转化。
- 若林恩在第三处火海时让龙卫澜停下脚步，对她说「还来得及，别再走了」，则全队会士气定格在悔恨，但林恩能腾出时间去布置更大范围的折跃信号圈。
- 若林恩在「全死了」那一刻故意不接龙卫澜的话、只拍她肩膀，则她会罕见地落下一滴泪但军纪不乱，林恩会被全队视作无声支持的支柱。
- 若林恩选择把感知极限缩短到五百公里范围潜行搜索，则林海的隐藏信息会更少被发现但因果化身的因果细线扫描将被遮蔽。
- 若林恩把感知扩大到整片林海时故意不加隐匿威压，则因果化身会瞬间锁定到他的方位并以因果细线围堵，林恩会被迫以一次硬战换来生存。
- 若林恩折跃救下村庄中老者时把他直接扔回庇护所，则老者的记忆会保留但无法再现新环境提示，关于银色太阳的细节线索必须靠林恩自己推演。
- 若林恩在斩首黑骑后主动抽出对方的画卷，则画卷会在林恩手中诡异地转动并尝试渗透神智，若非他意志力坚定会被瞬间化为因果傀儡。
- 若林恩在老者喜 recounting 银色太阳时主动用咒瞳拓印画面，则那段模糊而不稳定的银色画面会被完整保留，作为后续追踪的可靠坐标。
- 若林恩在老者描述峡谷时主动反复确认细节，则他能拼凑出更广阔区域内的异象全景，因果化身的追踪细节会由此被推算出来。
- 若林恩在村庄救治结束后要求所有人「跟我一个不少」，则庇护所会抽调一半兵力随行，遗民全保的愿愿意大大提升，但代价是庇护所彻底示弱。
- 若林恩离开村庄时故意不告而别，则老者和难民会因失去心理依靠全面崩溃，村庄会被被污染者重新锁定围剿。
- 若林恩独身进谷时选择以三叉戟开道而非暗隐，则漆黑细线会立刻缠上他，但若他能挺过因果反噬，下一秒他就会站在银色太阳面前。
- 若林恩在分界线前主动跃入其中一步，则因果细线会瞬间亮起把林恩的位置钉死，因果化身将可以通过血脉追溯杀来。
- 若林恩在分界线外以三叉戟指住林地高空、激发一点白焰照彻黑暗，则漆黑细线会短暂响起警报被强化，因果化身的意识会被推动进更高的专注模式。
- 若林恩在峡谷里主动用神王威压驱散漆黑细线，则它们会被强制后退让林恩进入，但因果化身会以此推断到林恩的真实境界立刻回援。

- 若林恩对获救遗民坦诚「是我们来晚了」，则难民会痛哭失声但又奇迹地安静下来告诉他们「我们会记住你」。
- 若林恩带着获救遗民回到庇护所并把他们放入绝对安全区，则庇护所内的所有人会把林恩当作新神，专注度加强引发信仰波动。
- 若林恩在告别遗民时把一部分金色沙粒分给他们作纪念，则金色沙会在遗民手心发热一页森林的祥和出现过，信物传承度因此大增。
- 若林恩决定不进谷直接返回庇护所，则他能第一时间巩固基地但因果化身会优先获得更深处的搜素权，银色太阳的位置将永远成为谜。
- 若林恩把庇护所的兵力全部抽出来支援救援，则庇护所会彻底留守空虚，若被敌方突破林恩将面临无家可归的困局。
- 若林恩用「你们伱留在这里」强行管束卫队，则龙卫澜一行人会被迫原地待命，林恩能获得绝对自由但同伴们的膈应情绪会聚沙成塔。

- 若林恩决定无视漆黑细线继续深入，则因果化身下一步将定位到他的具体位置展开毫无预兆的致命一击。
