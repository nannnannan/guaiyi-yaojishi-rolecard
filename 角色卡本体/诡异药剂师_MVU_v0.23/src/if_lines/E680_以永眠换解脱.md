# E680·以永眠换解脱·if线

- 若林恩在踏上平台时先冲入羽毛笔怀里沉默相拥，则她会僵硬片刻后泪流满面说出「你回来了」，林恩的怀里从此多了一份永远不能松开的责任。
- 若林恩先告诉羽毛笔「命运神国还有幸存者」，则她会瞬间瞪大眼低声追问名字，林恩说出的每一个名字都会让她重新点亮双眸。
- 若林恩在听见「好久不见，哥哥」时以初诞者之力凝出一面镜子端详轮回神王，则他会第一次见到与自己一模一样的脸并心头一寒。
- 若林恩在两位神王对话时主动提出「先告诉我渡鸦的过去」，则轮回神王会罕见地停顿片刻抬手示意林恩靠近，开始口述他的真实来历。
- 若林恩在被掀出时间长河前用三叉戟钉住水面，则他能在被逐出的途中保留一缕定格的画面供日后回放佐证。
- 若林恩在两位神王对奕时主动按下其中一枚棋子，则时间长河的节奏会被突然扭转，轮回神王会罕见地露出警惕与敌意。
- 若林恩主动问时间神王「你隐瞒的部分真相是什么」，则他会沉默片刻后罕见地承认「我无法逃脱终焉的围剿」。
- 若林恩主动选择相信轮回神王，则轮回神王会罕见地皱眉说出「你竟然愿意相信我」，两人的关系由对立过渡为有限合作。
- 若林恩主动对轮回神王承诺「我会让一切安息」，则轮回神王会罕见地轻叹一句「那就拭目以待」，时间长河的波澜因此更进一步加深。
- 若林恩主动问轮回神王对永恒的理解，则轮回神王会罕见地答道「那是牢笼不是永生」，林恩的认知因此更进一步。
- 若林恩主动对轮回神王承诺不滥杀无辜，则轮回神王会罕见地轻拍他的肩说出「那你比大君更懂人心」，时间长河因此出现光华。
- 若林恩主动要求轮回神王提供渡鸦的一切真相，则轮回神王会主动配合但又追加一条苛刻条件作为交换，隐秘信息由此被层层剖开。
- 若林恩主动向轮回神王展示自己对时间与渡鸦的推断，则轮回神王会罕见地发出凛然的冷笑，认同之后却又追加几条限制。
- 若林恩主动利用轮回神王作为助推器，则轮回神王会主动配合但又会引导林恩走向他自己的计划路径，林恩的角色由此更复杂。
- 若林恩主动要求轮回神王倾听自己的故事，则轮回神王会罕见地延长停顿片刻后讲述他自己的故事。
- 若林恩主动问轮回神王关于大君遗愿的真相，则「以永眠换解脱」的整段对白会被完整解开，林恩因此获得第一手证据。
- 若林恩主动问轮回神王他对时间的立场，则他会罕见地承认「我已经对时间失去信心」，这句话会被铭刻在时间长河里。
- 若林恩主动询问渡鸦为什么是大君的砝码，则轮回神王会把「我生你生、我死你也死」的死局全貌和盘托出。
- 若林恩主动要求自己不入时间长河留在外界，则轮回神王会罕见地答应并答应为他保留信息通道。
- 若林恩主动用初诞者之力为羽毛笔筑起一层永恒静谧的守护，则轮回神王会罕见地默许并加一层他的法则。
- 若林恩主动选择把羽毛笔强行带离这个平台，则因果神王会立刻做出反应，时间长河的对垒由此打响。
- 若林恩主动透露「我怀疑大君永眠的真相」，则轮回神王会罕见地皱眉并说出「你知道太多了」并附加一条威胁。
- 若林恩主动追问「死亡对你意味着什么」，则轮回神王会用哲学色彩阐释「不必再复苏」，林恩的灵魂因此受到深刻的震撼。
- 若林恩主动想摸摸那枚未落的棋子试探，则轮回神王会当即冷冷嘶吼「不要打我的棋局」，时间长河的风立刻卷起杀意。
- 若林恩主动想把那瓶老酒带走，则时间神王会罕见地笑着把瓶口对准林恩的怀里塞回去说「你回去的时候带上」。
