# E320·母树意识反击与蜂巢隔离·if线

- 若林恩在主炮轰击前主动用咒瞳把母树外层防御刻度上调，则她抵住第一波集火时损耗 -15%，但林恩的存在被三座蜂巢反向锁定。
- 若林恩主动在水潭交合中加快节奏让母树情欲激荡，则猩红欲海的反欲望洪潮在三秒内提前引爆，两支蜂巢在反应过来之前已被拖入欲海。
- 若林恩主动把咒瞳嵌入母树躯干时使用「伪装潜伏」模式，则咒瞳反噬延后一小时爆发，但爆发时的「以M max」反噬比默认更剧烈一档。
- 若林恩主动让1号智脑在隔离命令下达前三秒收到一段「小心咒术反扑」的私警，则她的切断动作更利索，但她同时记下了「他在监视我的决策」。
- 若林恩让在黑锁链降临时主动扯开一段蚀痕海嗣躯殓问智脑「现在你还能再说什么」，则智脑被这一示威挑衅后愤怒 +30，但她立刻启用更高规格防火墙。
- 若林恩主动在水潭中把少女的腰更紧地扣住，则她欲望投降速度加快，驯化度 +5，但咒瞳施放的骰点结果更倾向【3】【无事发生】。
- 若林恩主动让欲望冲击优先吞噬第三座蜂巢而非另两座，则那座蜂巢上传意识在欲海中狂欢比例 +40%，但另两座因此保留更多战力反扑林恩。
- 若林恩让咒瞳第一次施咒骰点弹出【1】而非默认，则以M反噬即刻 max 并伴随整株母树的剧烈电光，他当场痛到几乎断裂，但压制结果直接满格。
- 若林恩主动把咒瞳的施放动作交给左左代打，则左左施放咒术时被反噬反扑，她的左手抽搐三日才让林恩能用咒瞳。
- 若林恩主动在蜂巢链接切断前三秒反向渗透一部分欲望影像进1号蜂巢，则智脑立刻把该数据流销毁，但她意识到「他能穿透模块隔离」的更大威胁。
- 若林恩主动让两座蜂巢的合流在主炮蓄能前被破坏，则智脑只用单蜂巢镇压力量，母树获得更长的压制喘息窗口。
- 若林恩把「性善压制」节奏从默认改为「在欲海前静默先降予她完整祝福」，则她被这一温柔反向降伏，驯化度瞬间 +30，但欲望强度下降一档。
- 若林恩主动在电流传遍母树时同步用自己的咒纹给她隔离一道心室保护膜，则她被电流烧但心灵不至完全断裂，事后她对林恩的复杂情感 +12。
- 若林恩主动让黑锁链一根扣住蜂巢侧翼让其倾斜半度，则智脑立刻计算恢复方案，蜂巢被拖动但内部平衡勉强保住。
- 若林恩主动让左左在意识空间同步听到智脑的隔离决策通讯，则左左记录下「智脑在被逼迫的边缘」并日后用作劝降筹码。
- 若林恩主动把智脑的隔离指令解读为「她已把我视为敌人」，则他的恶魔笑容在脸上维持三秒后转为冷酷，他后续对她的态度从调戏改为竞争。
- 若林恩主动让母树根瘤在反击时延伸到蜂巢侧底掏出一个微型洞，则他获得一条后续渗透路径，但母树付出根系重损的代价。
- 若林恩主动在进入欲海反扑前一秒对她说一句「对不起你有点可怜」，则她空洞一秒然后立刻清醒，她把这句话作为日后对他的评价条目。
- 若林恩主动在水声之巅主动承诺「我会让你继续活下去」，则她在那声「啊」的瞬间全身颤抖，驯化度 +20。
- 若林恩主动让左左记录蜂巢隔离全过程签名成「她为恶魔认定的差距」，则左左事后把这一签名寄给智脑，智脑情绪崩溃一档但更决心谋反。
