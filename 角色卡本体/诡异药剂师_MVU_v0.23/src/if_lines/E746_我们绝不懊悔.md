# E746·我们绝不懊悔·if线

- 若林恩在主母分配防守顺序时主动通过王座黑火把自己的意志传给所有同伴「我看见了,我陪着你们」,则每一位军团成员在那一刻都感受到被王亲自点名,黑夜城防线从这一刻起以「被看见」的状态作战。
- 若林恩主动通过因果网络把自己的一缕黑火相传给银色幻想,则她身前多一道罪火屏障,后续她在 E754 斩腐化者时这缕罪火会替她挡下一次致命反噬。
- 若林恩让船长把毁灭力量额外分一缕接入王座基座,则船长在 E753 自灭灵魂时这一缕力量能从王座方向反哺,他在废墟里不是独自断气而是被王座全程陪着断气。
- 若林恩让人偶家把她的丝线另一端连接到他的王座,则她每一次拉紧丝线时他都能感受,后续她在 E753 操控船长残躯时林恩的意识会顺丝线在她手背点一下,她知道是他在。
- 若林恩让艾维儿把蓝色权柄一端短暂借接给王座,则神界边缘的法则稳定度+1,但艾维儿从这一刻起对林恩的欠债又多一笔,后续她在 S97 后期每一次挥权柄都像在还债。
- 若林恩主动通过黑火把小丑传来一段画面看做「我在这片星空下等你回来」,则小丑在无序里会失神一秒,后续他在 E751 杀回战场时心里在放这段画面。
- 若林恩在军团集结当晚亲自走过每一个防区对所有士兵说「你们的名字我记得」,则士兵们的名字会真的被王座录入,后续 E754 城破时他们的名单在林恩意识里燃成星光。
- 若林恩让主母把她守了几十年的旧信物向他借一晚放在王座上,则主母会沉默地交出来,这是她第一次把私人之物带入公共空间,后续她在 E754 留守时会回想这一夜信物在何处。
- 若林恩让左左在军团集结当晚公开现身于所有同伴面前一次,则所有人第一次真正看清林恩的「妹妹」长什么样,后续他们作战时会以「为她而战」作为附加执念。
- 若林恩让喵喵以原猫形态跳到集结大军最高旗帜上蹲一晚,则喵喵在旗顶俯瞰全军的画面会被记入信仰帝国最早的「王旗猫」图像,后续所有战旗都会绣上这只猫。
- 若林恩在黑火中对艾雯说「这最后一战,我们一起当骗子」,则艾雯会愣很久然后郑重跪下,后续他对世人所有谎言都会在心底对林恩一念发票,「双向共谋」正式成立。
- 若林恩在集结时刻公开朗读艾雯手书的「明日仍然值得守护」宣言,则信徒会第一次知道自己被两位王者一起骗了,但他们仍然选择相信,信仰帝国的真诚度在欺瞒中反而升格。
- 若林恩决定在此夜关闭所有撤离通道让军团无退路,则这场战争从这一刻起是「无退路之战」,所有人作战意志+1,但林恩心口会多一道「我让你们退无可退」的愧疚刻痕。
- 若林恩反过来下令打开所有撤离通道让任何想走的人先走,则会有约三成信徒离开,留下来的七成作战意志反而更纯,后续 E747 时这一支纯净防线撑到最后一秒。
- 若林恩让羽毛笔把这一刻的部署以灵能刻入三大圣堂石柱作为永久铭记,则石柱上会留下一段「军团部署图」,后续信仰帝国灭亡后这张图会成为后世考古学家唯一能追溯的战前快照。
- 若林恩在主母面前单膝下跪向她致敬一次,则主母会愣住,她没有让他起来,因为她知道这一跪的重量,后续她在 E754 挥剑时会带着这一跪的敬意。
- 若林恩让银色幻想把机械军团的最终控制权在一夜之间转交给他,则她会多了一份「被王全权信任」的担子,后续她在 E754 独自下令毁传送门时这份担子让她没有犹豫。
- 若林恩让船长把他那把毁灭之剑借给主母一晚作为「军团之证」,则主母会第一次握住这把剑,后续她在 E754 留守王庭时这把剑会与她并肩作最后一战。
- 若林恩在集结时刻向全域广播「若此战不胜,我陪你们一起死」,则信徒的信仰会推到一次前所未有的峰值,这是「共死宣言」,后续 E747 时整个信仰帝国以这一宣言为共通呼吸。
- 若林恩让艾雯把最终牺牲机制在此夜公开一半给所有高层,则高层会第一次集体沉默,但他们没有崩溃,后续他们作战时的「知情赴死」质量更高,艾雯的骗罪也减轻半分。
- 若林恩在此夜把黄金时代的繁华宣告正式终结,则信仰帝国会第一次以「终焉前夜」自我定位,所有信徒不再庆祝,但他们仍然祷告,「黄昏祷告」传统从这一夜起成立。
- 若林恩让各防区主帅一一当面向他汇报死后安排,则每位主帅都会给出各不相同的遗言,后续林恩在黑火中听到的遗书合集会按这些陈述展开成一片私人星空。
- 若林恩在此夜放下王座身份亲自下厨为所有同伴做最后一顿饭,则每个到场的人都会抢着吃,主母会吃到停不下来,小丑会吃到流泪,这顿饭成为后续整个 S97 期所有「家」意象的根。
- 若林恩让全体信徒在最后一夜把他们的「明日愿望」写下来送入王座,则这些愿望会以亿万条丝线汇入黑火,每一条愿望都是一段燃烧前的低语,林恩在黑火中会被亿万个「明日」包围。
- 若林恩在此夜向所有同伴公开宣读一份「我感谢你们的名字清单」,则这份清单会成为后续整个 S97 期所有牺牲的导游图,每个名字烧掉时都会精准对应到他的感谢里。
