# E746·我们绝不懊悔·if线

- 若林恩在被封入圣所前曾与船长在城头共饮，并听他提起当年凡人王宫的旧事，则船长在出征前夜擦拭那柄古老银剑时，剑锋上会映出林恩温和倾听的侧脸，令他挥剑再无半分犹疑。
- 若林恩在沉眠前曾允许艾雯在城外墓园为他们两人预留墓穴，却不知她偷偷立下了第三座无字墓碑，则当小小在墓园问起那座空碑是谁的时，潜意识中的林恩会感到一阵莫名的心悸。
- 若林恩在小小独自跑向黑夜城外墓园、对着艾雯立下的三座墓碑发呆时，透过王座残留的地脉感应吹起一阵微风拂过她的金发，则小小不会因墓园的阴冷而害怕，反而会乖巧地替空碑拔去杂草。
- 若林恩在被封印前曾赠予黑弦月（人偶小姐）一枚能安抚噩梦的安神香囊，则当她在人偶庄园从灭世预兆的噩梦中满脸泪痕地惊醒时，攥紧香囊便能迅速止住颤抖，拿起丝线准备战斗。
- 若林恩在圣所大门彻底封闭、内外隔绝的第一日，以被锁住的指尖在王座扶手上刻下一道浅痕计算时间，则他在黑暗中始终保持着对外界战局流逝的敏锐感知。
- 若林恩在船长摩挲银剑回忆当年那个凡人王宫小女孩的瞬间，从圣所深处溢出一丝微弱的共鸣，则远在人偶工坊的人偶家会同时抬头望向城头，两人的宿命在决战前夜悄然重叠。
- 若林恩在艾雯独自立于城外墓园、凝视着那座留给林恩自己的无字墓碑时，透过灵魂锁链传来一阵剧烈的挣扎震动，则艾雯会抚摸着冰冷的碑身低声呢喃：「若你怪我，便在地下也不要理我吧。」
- 若林恩在沉眠的潜意识里捕捉到全城将士写下「我们绝不懊悔」的决死誓言，则他体内的黑火会在无人察觉的角落里静静沸腾，将每一份誓言都烙印在自己的骨血之中。
- 若林恩在黑弦月流泪醒来、独自坐在人偶庄园窗前仰望黑夜城方向时，让圣所上方掠过一抹极淡的暗金微光，则黑弦月会擦干眼泪露出微笑，将自己的命运与那座圣所彻底绑在一起。
- 若林恩在小小向守墓老人打听「为什么这里有三座墓碑，除了哥哥和艾雯哥哥还有谁」时，让一阵温暖的药香包裹住小小，则她在得知残酷真相前，还能保有最后一段天真烂漫的猜想。
- 若林恩在船长与银色幻想整军备战、准备趁主母尚在沉睡时先行率部秘密出征的那一刻，在王座上发出一声低沉的叹息，则两位神王会在跨出星门前回首向圣所方向深深一拜。
- 若林恩在圣所彻底封闭前曾留下一份给幸福之家孤儿院的物资调拨令，则夏娃与孽主在全城进入最高战备封锁的这几日里，依然能用热腾腾的食物安抚院中受惊的孩童。
- 若林恩在潜意识中顺着锁链窥见艾雯独自一人在统帅部签署一道道阵亡抚恤预案的背影，则他对艾雯的滔天怒火会在心底悄然化作一阵酸楚的无力感。
- 若林恩在船长将当年护住小女孩的那柄旧银剑重新挂回腰间时，以留在船长体内的神王火种轻轻温养剑身，则那柄凡铁铸就的旧剑在随后的神战中竟也撑到了最后一刻才折断。
- 若林恩在黑弦月整理庄园内所有人偶、准备将它们全部投入黑夜城防卫战时，于梦境边缘对她轻声说一句「小心」，则黑弦月会将最核心的本命人偶留作守卫圣所的最后底牌。
- 若林恩在得知全城守军在出征前夜没有一人哗变、家家户户门前皆挂起黑夜城战旗时，被锁在王座上的身躯会微微挺直，以神王的姿态在黑暗中默受万民的诀别。
- 若林恩在小小蹲在三座墓碑前把一朵白色小花放在第三座无字碑上时，将那朵花的影像清晰地映入自己的识海，则他在E759将艾雯葬入此碑时，会想起小小曾经来过的痕迹。
- 若林恩在圣所内对抗锁链侵蚀的间隙，分出一丝神念去触碰门外的海神三叉戟，则戟身上会浮现出一圈水波般的金纹，替正在城头巡视的将领们驱散终焉逼近带来的窒息感。
- 若林恩在船长率领第一批敢死军团静默开拔、连马蹄与战靴都裹上厚布以免惊醒主母时，在王座上默默为他们数着步伐，则这支孤军在踏入黑暗星域时每个人心里都揣着一团不灭的火。
- 若林恩在黑弦月擦去眼角泪水、换上昔日随他征战时的盛装礼服走出庄园那一刻，以微弱的王座威压替她拂去路途上的阴霾，则她走向圣所的每一步都走得如同赴宴般优雅从容。
- 若林恩在艾雯将圣所钥匙彻底熔毁、断绝任何人在战前放他出来的可能时，猛地拽动锁链发出一声震耳欲聋的金铁交鸣，则整座王庭都能听见他们被囚禁的王仍在咆哮。
- 若林恩在潜意识的煎熬中反复回忆起王庭晚宴上每一个人的笑脸，则当无序与绝望的黑雾试图从王座底座渗透进他脑海时，那些鲜活的笑脸会化作坚不可摧的屏障。
- 若林恩在小小离开墓园前一步三回头地望向圣所高塔时，隔着厚重的石门向她的方向投去一缕温柔的注视，则小小会开心地对着高塔挥挥手，相信哥哥一定正在里面看着她。
- 若林恩在决战前夜的死寂中，将「我们绝不懊悔」这六个字与自己的心跳频率完全同步，则当次日七十一座终焉之柱轰然降临时，他在王座上的每一次呼吸都在与全城守军同生共死。
