# E204·多世界强制召唤与折跃逃脱·if线

- 若林恩抽刀劫持左左那一刻改用夜魔刀背轻压左左手腕,则巨像之脑并未感应到那么强的血色威胁,她没一拳轰碎空气墙,事件以变形(劫持失败)收束,五根源当场完成强制转移。
- 若林恩数秒时故意把「五」漏掉直接从「四」跳到「一」,则巨像之脑事先没作收拳准备,林恩迎头迎上拳头之后被那一拳砸得半边脸肿起,折跃摔出黑夜城偏离原有目的地。
- 若林恩让小诅咒在刀起瞬间附身到左左身上放出二段威胁台词「你不救她我就把她手切掉」,则左左哭腔配合度+1,巨像之脑攻势更加失控,事件以不变形收束但她一拳轰碎大殿侧壁。
- 若林恩折跃前先在胸口拍一道主母神圣诅咒的锁定符,则折跃目的点被提前绑定到002室门框,事件以变形(定向折跃)收束,跨界召唤波动在半路被斩断一半。
- 若林恩假戏成真,刀上真的切出浅浅一道血痕才抽走,则巨像之脑扑空后再补一拳,林恩在血雾折跃中受创,事件以变形(受创逃脱)收束,他撞进002室时身上带一条血淋淋划痕。
- 若林恩折跃中途临时改向窜进黑夜城最繁华的游魂巷,则五十多个跨界召唤波动跟踪到游魂巷上空后被游魂巷墙根杂音误码打散,事件以变形(游魂巷隐匿)收束,但被注视的游魂精怪全体看到狱主本人。
- 若林恩逃跑途中碰到小小拦路,他先不解释就把她拦腰抱起一起带进002,则50多个召唤波动在002门口紧急停下,事件以变形(附身搭客)收束,巫神头颅在殿外暴怒骂「贤婿连小小都敢拐」。
- 若林恩在002门口才想起喊「小小快来救我」,则猫耳耳机的小小全程没听见,事件以不变形收束但泰坦头颅先到一秒,002大门被封住,林恩无法反锁。
- 若林恩折跃落地时刻意把一根钢笔从怀里抛出代身,则在五根源视线里折跃的人变成一根钢笔,事件以变形(物身折跃)收束,他本尊安稳溜到002屋内。
- 若林恩抽刀一瞬间切了一段表演台词「这是我哭数十天的结果」,则左左被神魂不能漏戏,巨像之脑一拳后长伤失控轰出第三拳打碎半座外层结界,事件以不变形收束但乌鸦臂章的倒计时在背包深处进一步跳响。
- 若林恩在002门口想取钥匙时突然记起钥匙已经丢在法阵现场,则2秒后一根触手卷进门缝内反锁,事件以变形(触手反锁)收束,跨界召唤波动已经咬到他的肩。
- 若林恩夺萃之镰抽出后顺手在大殿石板上画一道巨像追迹模糊符,则五根源启动的跨界定位系统短期偏离,事件以不变形收束但乌鸦臂章的法阵失准之后再度补一轮。
- 若林恩折跃瞬间手脚并用把左左挂在胸前挡灵能波动,则左左在折跃落点被小力冲击到变形,事件以变形(左左受创)收束,脑子的王后反应把后续追击全面围堵。
- 若林恩逃到不正常生物中心前台才想起大厅外那个监控晶石,他先用一根触手砸碎了它再撞进002,则事件以不变形收束但五根源在追抵门外时失去一段现场视觉。
- 若林恩折跃落地那一刻临时加设一道假响警报指向外街,则五根源在半路被身上带起来的灵能爆破声分散半秒,事件以不变形收束但多元召唤波动差点在街头把他揪出地狱。
- 若林恩在002门口冲过前先握住门把手顺嘴一声「羽毛笔请帮我」,则门槛上的羽毛笔权柄略微加防,跨界召唤波动在屋内被干净隔绝,事件以不变形收束但羽毛笔笔记本封面多出一行新字「有人在找我」。
- 若林恩被巨像之脑一拳擦伤手臂之后仍强行折跃,则血雾折跃里带一根半斩断手臂,事件以变形(半臂折跃)收束,左左变成充当临时缝线缝那根上手臂。
- 若林恩在劫持失败后按原计划冲入离魂街,则50多个跨界召唤波动被离魂街邪气掩盖,事件以变形(邪气隐匿)收束,他得以滞留48小时但增加一次冤枉追阻。
- 若林恩逃入002门口时不关大门、用身体撑住把左萝推到安全位置,则他本尊被一道微弱提瓦特召唤波动咬到,事件以变形(被波及轻伤)收束,他被追到002才知那一道召唤已经失效。
- 若林恩折跃后一眼看到羽毛笔就扑过去抱住,则羽毛笔书写权柄被强行激活打开一段「紧急求救」纸页,事件以变形(羽毛笔介入)收束,五根源殿外暂停脚步三秒。
