# E97·三大根源混战与利维坦升空·if线

- 若林恩先让左左藏进意识空间再举单反,则「巨像之心宿主」在三根源视野里失焦一拍,血肉支配者的血瞳扫过护盾时没收进那一栏「王后坐标」。
- 若林恩把单反视角从欲望母树笑脸改压到血肉支配者撕开虚空的缝隙,则视界网头条换主角,旧神变节者一系对这场影像的回收优先权从母树滑向支配者。
- 若林恩把喵喵从肩上塞进艾雯爵士护盾最内圈再开口,则她在利维坦血雨倾泻时不被同源血肉回声提前扯痛,多保住三分清明直到主控室露脸那一刻。
- 若林恩在艾雯爵士宣告「我们，参战」前先把夜医应急血包递到他掌心,则护盾外正是数据流逸散最晚的那一瞬,夜医精锐的先遣序列被艾雯亲手提前锁好。
- 若林恩不直指利维坦命门、改写纸条塞进灵能屏障褶皱,则护盾外的血肉支配者没有捕捉到那道声音的频率,林恩的声纹在「三主谈判席」档案里仍属未录入。
- 若林恩朝欲望母树那张血红笑脸搁下一句「小弟弟这次不站你这边」,则母树藤蔓擦过护盾外缘的轨迹拐了一寸,「庇荫」从默认可选改为需要他之后再讨一次。
- 若林恩在艾雯爵士护盾第一道贯穿性裂纹浮现时反手压一支以M药剂进他臂弯,则交配的刺痛流进灵能回路,护盾多撑七秒,艾雯侧过头第一次用陌生眼神重新量他一眼。
- 若林恩当场用拟化把「万机之神半真身机械巨龙振翼对轰那一瞬」烙印进左掌心,则事后反推蜂巢序列的破口留在掌心,靠近任何机械机体烙印就发烫,银色幻想读出那一段时手抖了半寸。
- 若林恩在指向利维坦时顺口点出「全场只剩银色幻想还能动」,则万机之神遥遥回望的眼神里多一拍停顿,为后续「冤家组队」提前埋下一枚引子。
- 若林恩朝利维坦主控腔室方向掷一支未启封噩梦混合药剂,则枯手在苍白乌鸦面具前接住那一支,面具下流出第一声不成句的喉音,利维坦外层几颗瞳孔同时偏过来。
- 若林恩在护盾内跪姿不变先向万机之神机械巨龙方向行一次夜医礼,则机械神教残留侦测器把「非敌目标」标签打在他档案首页,蜂巢群对他的炮火优先级整体下调一级。
- 若林恩朝欲望母树主干递一支夜医应急血包当回礼,则藤蔓把它绞碎吞下,母树那张脸上笑意三十年来第一次在脸上停成「愣」,她低低咕哝一句「小弟弟,不像话」。
- 若林恩在艾雯搭上纽扣时主动请缨「打开缺口后算我一个」,则艾雯爵士指尖在权杖上敲了三下,将他列为破局首选。
- 若林恩当场对左左说一句「待会要是打起来你缩回手心」,则意识空间里传来一声被她牙关咬断的应答,巨像之心在胸腔里响成闷鼓,母树隔着法阵嗅到「王后被护」的味儿笑得枝叶簌簌。
- 若林恩在血肉支配者发出无序低语那一刹朝他对吼一声以M静心咒,则以M权柄与无序波动正面对撞,血瞳在他脸上停一秒,「以M者」标签在支配者档案里升格一级。
- 若林恩朝三大蜂巢之一掷一支肾上腺素药剂替它抢回半秒上传窗口,则那一座蜂巢最后回传的数据包里夹一行加密短句——「夜医护盾,可信」,这行字绕了半个黑暗世界传回主母耳里。
- 若林恩把单反摔在护盾根基当场碎掉,则「根源混战影像」从此只剩左左口述版本,视界网估价窗口空悬,白逸在蓝星那一头等不到画面只剩一段语音。
- 若林恩朝血雨一阵泼洒血肉增生药剂,则他自己的脚踝被第一波孢子锁定,「林恩=母体候选」标签首次打上,利维坦升空轨迹在最后一刻偏了三度绕开他的坐标。
- 若林恩在护盾裂纹第二道贯穿时反手撕下一片外袍掷向血瞳,则支配者的注意力被那片浸了夜医气息的布料牵走半秒,护盾里另一名夜医从那半秒里抢回一条命。
- 若林恩在母树藤蔓擦过护盾外壁时咬破自己指尖把一滴血印在屏障上,则母树那一口沾到夜医印记,舔舐声停顿,她若有所思地把这滴血的味道记入自己的储藏室。
- 若林恩在艾雯准备解扣升格前先把喵喵抱紧按在怀里,则艾雯爵士沉吟一拍多加一道灵能隔音层,喵喵在他怀里竖瞳紧盯高空利维坦。
