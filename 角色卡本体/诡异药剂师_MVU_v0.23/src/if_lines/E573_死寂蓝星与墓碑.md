# E573·死寂蓝星与墓碑·if线

- 若林恩在从高空降落蓝星地表前主动放开神念扫过整片荒原以避开地面的残破石碑，则他会精准落在墓碑群中央的空地上，没有惊扰任何一座沉眠的孤坟。
- 若林恩在看清墓碑上镌刻的竟是熟悉的汉字瞬间，本能地后退半步、屏住呼吸扫视全场，则「艾雯之墓」四个大字会在群碑环绕中格外刺眼地撞入他的眼帘。
- 若林恩在走到第一座墓碑前没有立刻去读碑文，而是先伸出颤抖的右手轻轻拂去碑面的积灰，则指尖传来的刺骨冰凉会让他无比清晰地意识到这不是幻觉。
- 若林恩在辨认墓碑名字时主动先走向角落里最小、最歪斜的那座石碑，则「左左之墓」四个歪歪扭扭的字会第一时间刺痛他的双目，让他胸口的悲怒瞬间冲破顶点。
- 若林恩在一拳砸向地面宣泄悲愤前特意收敛了向四周扩散的余波，则恐怖的拳劲只会垂直轰穿数千米地壳，而周围林立的同伴墓碑全都完好无损。
- 若林恩在指天破口大骂时并非毫无方向地宣泄，而是将滔天杀意死死锁定在高天之上那道无形的宿命幕布后，则他的道心在极致悲愤中反而淬炼得愈发坚不可摧。
- 若林恩在指天怒骂的半个时辰里用上了自己记忆深处最古老的故乡俚语痛斥诸神，则那些跨越时空的咒骂声会在死寂的蓝星大气层内久久回荡，仿佛替整颗死去的星球鸣不平。
- 若林恩在宣泄完所有情绪后没有瘫坐在地，而是走到最大的「艾雯之墓」前郑重单膝跪下、以掌心贴住碑身立誓，则他起身时的眼神已再无半点迷茫，只剩背负一切的孤绝。
- 若林恩在腾空尝试离开蓝星前深深回望了一眼「左左之墓」的位置，则当他被无形屏障弹回地面时，会第一时间回到那座小碑旁盘膝坐下，静心推演破局之法。
- 若林恩在动用初诞者之力轰击天幕禁制时，将爆发节奏改为由弱至强的螺旋穿刺以试探屏障结构，则他虽同样无法破开禁制，却能更快看清这座天地牢笼的法则本质。
- 若林恩在以心灵与死亡法则共鸣墓园时，主动分神留意每一座小墓碑底部残留的刻痕，则他在唤醒「往日遗念」前便已察觉这些墓碑全是由同一个人亲手立下。
- 若林恩在催动「往日遗念」回溯过往画面时主动加快残识流动的速度，则那段漫长而压抑的立碑岁月会如疾风骤雨般撞入他的脑海，带来更强烈的灵魂冲击。
- 若林恩在遗念画面中看清那名自葬少年与自己一模一样的面容时，主动迈步走到少年虚影的面前与之平视，则跨越时空的两个「林恩」会在光影交错间完成一次无声的对视。
- 若林恩在看到画面中少年独自一人挖坑埋葬自己的凄凉一幕时，握紧双拳将指甲深深掐入掌心，则这份锥心之痛会化作他绝不重蹈覆辙的决绝意志。
- 若林恩在遗念影像消散后强行将面容收敛得毫无波澜、如冰雕般静立原地，则即便暗中有跨越时空的视线窥探此处，也休想从他脸上读出半分动摇。
- 若林恩在影像散去后尝试伸手推动面前的石碑以检验其物理特性，则墓碑纹丝不动的反馈会让他彻底明白：这片墓园的每一寸存在都已被法则焊死在时光之中。
