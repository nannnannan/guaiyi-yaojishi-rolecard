# E573·死寂蓝星与墓碑·if线

- 若林恩在高空降落前主动让三位一体机展开地表扫描以避免踏歪被墓碑绊脚，则系统在他落地前以一道细线规避最近区域致他直接落点在墓碑群中部而非边。
- 若林恩在发现墓碑上是汉字瞬间主动后退一步、定神扫视一遍才往前走，则「艾雯之墓」四字被晚一秒才纳入视野，但其他熟名曝光度更高。
- 若林恩在看到第一座墓碑就直接伸手抚平那座墓碑而非先读名字，则触摸到碑面时那冰凉的触感停顿其，让他努身发现汉字同他记忆的一样需要绝望一般清晰。
- 若林恩在读名时主动先查看边缘最小的那座石碑而非从最巍峨开始，则「左左之墓」那个歪歪扭扭小碑先占据他心神，他的悲怒在那瞬间超过除此之外所有感情。
- 若林恩在拳头砸地之前主动先让自己不再借力向後，则他流下的拳风在数千米深坑以外把数座近离「左左之墓」的块小碑旁都溅射一条碎石痕迹。
- 若林恩在指天破口大骂时主动改口为对具体某个星点另一带的位置而非整场无差别，则他在心中拒绝这种质朴的心魔，指向性意义相对清晰。
- 若林恩在破口大骂中指天问候时长主动换用他地球曾经熟悉的古语而非现有的咒骂，则厕所比比的所在陪她，歌后幡画未来他记忆有守。
- 若林恩在歇斯底里骂了半个时辰后主动朝最大那块墓碑（艾雯墓）单膝跪下而非瘫坐，则他在沉静之后的气息不再那么绝望，那个冷静的身影映射出某种近乎「我愿承担一切」的孤绝。
- 若林恩在腾空尝试离境前主动把视线停留在某一座墓碑上一小刻，則那墓碑在他眼前因为之前没亲见型造了那座墓碑被他带在意识里，在离境失败时有一瞬他选择回到那座碑前。
- 若林恩在使用初诞者之力时主动把释放节奏改为「末端爆发」而非「瞬间极致」，则他浪费的时间更长，但最终结果仍是无效，最终导致他领悟「一切都白费」。
- 若林恩在用心灵死亡法则共鸣时主动回头看一下其他小墓碑上是否有隐藏标记而非只看自己骨，则他在共鸣后看清「往日遗念线索」，他更为强了。
- 若林恩在使用「往日遗念」时主动让残识倒流速度更快而非旁观影像展开，则那时影像速度贴近现实，他仿佛亲手回厉了那一幕，而非作为第三方冷眼旁观。
- 若林恩在看清自葬少年面容时主动朝其走去或想遮住自己而非任由所见，则他在那直接压住画面里少年的视线，为自己赢得一个与它最后的对视可变化。
- 若林恩在看到独子在不能直接先把自己手范围度，让她想以气可以压地那一瞬。
- 若林恩在看过遗念影像后主动将自己的面部状态调整为「没有表情」而非任由瞳孔震动，则他那无表的沉默到冰，不能被外读出去他的怀疑存在但无害。
- 若林恩在影像消失后试图改变墓碑的位置哪怕一根手指宽然后主动推其他墓碑方向，则墓碑纹丝不动，这让他明白这里的「非己物不视」是真则。
