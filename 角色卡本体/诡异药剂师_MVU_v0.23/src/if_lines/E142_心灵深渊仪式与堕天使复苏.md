# E142·心灵深渊仪式与堕天使复苏·if线

- 若林恩随艾雯爵士一同下楼并主动走在队伍最前，则被转化的守门侍卫优先锁定他，巫神触手拍肉酱的环节改由林恩亲手处置，对两名旧识守卫的处置权被推到玩家手上。
- 若林恩选择留在地面负责疏散，则破阵门、第一波法阵反噬与「努力祈祷吧」面板由艾雯爵士带回二手口述，林恩失去与堕天使的首次面对面对峙机会。
- 若林恩带银色幻想或万机意识某一分集同行，则堕天使会立刻把这支根源级战力视为首要压制目标，法阵启动时间被拖慢、全城污染窗口反而被小幅拓宽。
- 若林恩借巨像之脑或小小在城外建立远程支援链，则破阵过程中全城上空浮现「巨像注视」的次级投影，居民理智污染速度下降、堕天使当场认定林恩为首要目标。
- 若林恩让左左自己钻进他的身体内随队进入大殿，则堕天使在镇压力量最强的那一拍对左左报以一次明确辨认的目光，留下「主母暗面也认得这具身体」的伏笔。
- 若林恩提前当众公开主母双人格真相换取全城协作，则默认变形支路成立，夜医高层出现信仰震荡、白夜典狱长当场失声，林恩获得协作疏散但失去与主母主人格私下合谋的可能。
- 若林恩选择继续保密，则只能以「根源入侵」口径组织撤离，主母寝殿外的禁卫在被堕天使转化前至少保留一段时间对林恩已公开身份的敌意。
- 若林恩在法阵尚未升空时尝试以M破势，则以M波动会被堕天使完整吸收一次、她当场回头锁定林恩并发笑，第一拍对林恩的恫吓压强追加一格。
- 若林恩用权柄或异物直接轰击法阵中央，则堕天使会放弃镇压主母主人格一瞬来挡下这一击，主人格在体内反抢数秒主动权，等价路径成立但堕天使对林恩的猎杀位阶上调一级。
- 若林恩试图以呼唤、喊着「主母」等口令唤回主人格，则在堕天使镇压未完全到位的早期窗口，主人格能借一次回话留下限定线索，例如一句断续的「……走」或某件物品的名字。
- 若林恩把「主母之吻」唇印当众示人并以此为信物，则在场夜医记起她过去的庇护口径，队伍士气短暂抬升，但堕天使立刻把这枚唇印折算成对林恩本人的额外厌恶。
- 若林恩知情却拒绝让艾雯爵士下殿，则艾雯爵士表面服从、私下另立小队跟进，地下大殿会同时出现两支队伍，堕天使因此把仪式节奏压缩一档。
- 若林恩在大殿门口先斩被转化的两名护卫，则他不获得任何精神加成、只如实承担杀死旧识的事实，账本记下「处置由林恩亲手完成」一条。
- 若林恩坚持留活口、让巨像之脑压制转化守卫不杀，则守卫在事件结束后可被送回城中央囚禁研究，等价路径成立但破阵时间被拉长、第一波全城恐慌造成更多伤害。
- 若林恩带着白夜同去见证，则白夜在得知真相瞬间短暂失神、把主母被镇压的画面刻入心底，他后续在救援中不再接受任何「放弃主母」的提案。
- 若林恩提前从词条中读出「努力祈祷吧」的提示并公开告知队伍，则艾雯爵士把它误读为尚有祈祷通路，队员陷入短暂迟疑，堕天使反以为对方识破仪式而提前收口。
- 若林恩在大殿内先对堕天使使用诡计配方或异常物品引她偏移，则堕天使会接住这份挑衅并把其中一份反噬顺着媒介弹回林恩身上，玩家须承担一次明确的权柄代价。
- 若林恩完全不接触大殿、只在地面组织应急撤离，则事件完成条件改为「堕天使身份由艾雯爵士与巫神确认并带回」，林恩本人失去对主人格受压状态、转化机制的一手确认。
- 若林恩在法阵启动半途中选择直接强攻堕天使本体，则被法阵从主城表面撕下一整条街区作为代价，事件记为「强攻收口」，全城污染不可一笔抹除。
- 若林恩临场改口向堕天使假装投诚以拖延时间，则堕天使不会在第一时间处死他、只以「努力祈祷吧」加码、把他纳入第一阶段待转化名单，伪装存续期与权柄强度成正比。
- 若林恩本事件全程缺席（在城外、召回中心或巨像空间），则事件仍按默认走向收束，主母寝殿外的转化守卫、巫神的辨认、法阵升空都被记入夜医战报，林恩后续介入起点从「全城污染中」开始。
- 若林恩在法阵直刺高空那一刻向堕天使主动献身式靠近，则堕天使会真把他当成值得研究的样本留下活口、暂缓启动对外的全城转化一拍，等价结果成立但林恩本人进入她的近身控制范围。
- 若林恩把喵喵、黑弦月或银色幻想藏入手提箱带入大殿，则堕天使会把这视作林恩自带同类战力，仪式开始后第一时间点名要她扣押这一箱，战后手提箱处置路径被玩家重写。
- 若林恩在最后放弃对抗、率队伍撤回地面集中疏散，则事件以「牵制成立、救援窗口打开」收束，堕天使对林恩的猎杀位阶保持默认，但主人格的受压时间被相应拉长。
- 若林恩在法阵上空写下一句明显的挑衅言语（含紫罗兰字眼），则紫罗兰注视会被法阵波动放大、堕天使体内主人格被这注视反向助推一瞬，等价路径成立但林恩直接被拉入禁忌视野。
