# E744·苏醒的信号·if线

- 若林恩在黑色裂纹扩大那一刻不是先召见艾雯而是先召见主母,则艾雯会站在殿外等了一整夜,他眼底那层阴霾在这一夜翻了一倍,后续他对林恩说「最后谈话」时语调更哑。
- 若林恩主动伸手按住王座上方的黑色裂纹试图以罪火填平它,则裂纹不会闭合反而把他指尖烧穿一线,他手背从此多一道「触过终焉」的黑色疤,这是终焉在他身体上留下的第一次签名。
- 若林恩让所有无序生物停下动作的信号播出时同步下令三大圣堂敲响警钟,则信徒首次听到「终焉钟声」,数以百万计的人自发涌向圣堂,信仰帝国的因果网络在这一夜多吸入三成祈祷。
- 若林恩下令羽毛笔把「苏醒信号」翻译成凡人能听懂的语言向全域广播,则整个主宇宙从这一刻起不再有「不知道的人」,信仰的纯度升高,但黄金时代的繁华从这一刻起同时开始崩塌。
- 若林恩在艾雯开口说「最后的过程」之前抢先对他说「你瞒了我多少我都原谅你」,则艾雯会第一次失语,他没有说谢谢,只低头很久,后续他对林恩的隐瞒清单反而变得更短。
- 若林恩在艾雯说「我最害怕的是你孤独留下」之后立刻回答「那你就陪我一起死」,则艾雯会抬眼看他很久,他没有笑也没哭,只低声一句「恐怕做不到」,这一刻他把最终结局定得更死。
- 若林恩让主母在「最后谈话」现场、而不是被艾雯刻意支开,则主母会在听到一半时一拳砸在石柱上,但她没走,后续她对艾雯的态度从「敬重」变成「又敬又恨」的混合复杂。
- 若林恩选择立即启动最终晋升而不先撤离星域,则信仰帝国各星域没有被撤离令覆盖,后续 E746 黑夜城军团集结时会带有大量普通信徒的残念,王座黑火起步温度更高但更危险。
- 若林恩选择先撤离信仰帝国再启动晋升,则晋升时点会被推迟数日,无序深空的七十一根噩梦柱提前察觉,「苏醒倒计时」从这一刻起被压缩,后续 E746 防线完成度会降低。
- 若林恩下令羽毛笔记录「每一个人都已被连接到命运网络」这一事实并广播,则所有信徒从这一刻起知道自己的名字是王座燃烧的柴,信仰帝国诞生一种「自愿赴死」的暗流。
- 若林恩在银色幻想、船长、主母、人偶家、艾维儿各自守节点时主动一一巡视,则他首次亲眼看到每一位同伴身上的「最后准备」,后续他在王座上的每一下心悸都会带上对应的画面。
- 若林恩让左左在此刻坐在王座扶手边陪他听完整个苏醒信号,则她一言不发听完,只在信号最响的瞬间握住了林恩的小指,后续所有「孤独」场景中她都会以这个小指动作回应他。
- 若林恩让喵喵以猫形态躺在王座踏板上陪众人听信号,则所有无序生物停下的那一刻她也停了,她抬头看林恩那一眼没有撒娇只有一种誓言,后续她在 E747 之后会以「家猫守家主」的方式守殿门。
- 若林恩当众问艾雯「你还有什么没说」,则艾雯沉默很久只说一句「还有很多」,林恩心里那根弦从这一刻起多加一扣,后续 E748 真相揭开时他会想起这一句「还有很多」。
- 若林恩决定不让普通信徒知道「因果燃烧」只告诉高层,则信徒仍沉浸在黄金时代最后一夜,后续他们在 E750 信仰城被攻破时会出现「震惊式崩溃」。
- 若林恩选择亲自去每一个圣堂巡视最后一夜,则他会在圣堂里看见哭泣的孩子与沉默的老人,后续这些凡人都会被记入罪恶王座的「见过王」名录。
- 若林恩在主母面前说「如果这次我回不来,你替我照顾林恩」,则主母会愣住,这是她第一次听到托孤,后续她在 E754 留守王庭时带着这个承诺。
- 若林恩下令小丑在这最后一夜再去无序深空一次,则小丑会在 E751 才赶回,他带回更准的七十一柱坐标,但赶到时已缺一块残躯。
- 若林恩独自在王座深处闭眼听一遍完整苏醒信号,则他会听到亿万灵魂的合奏与一声不属于任何存在的低语,后续 E754 城破时这低语会在他耳边再次响起。
- 若林恩让艾雯当众宣誓「若有下次我绝不瞒你」,则艾雯不能起誓,林恩心口的那道疤又添一道纹,他不再问,但他不再全信。
- 若林恩选择在苏醒信号持续时向全域信徒发表一次讲话,则他的声音会第一次通过因果网络直接落到亿万灵魂心底,「我们共渡此夜」会成为后续整个信仰帝国的临终祈祷语。
- 若林恩让主母亲自敲响黑夜城最高塔上的古钟为苏醒信号定调,则主母敲钟时眼里有泪但她没让它掉下,后续她在 E754 挥剑斩腐化者时心里在回想这一夜钟声。
- 若林恩决定此刻就宣布自己的登临王座日期并允诺「归来」,则信徒的信仰会推到一次前所未有的峰值,但若登临失败,这一峰值将成为压垮信仰帝国的反向巨浪。
- 若林恩私下问自缚天使「如果失败我该在哪」,则她会平静回答「在我怀里」,林恩没有接话,但他记住这句话,后续他在王座上承受黑火时脑海中曾几次闪过这一怀抱。
- 若林恩决定这一夜和每一位同伴单独道晚安,则他会第一次收到小丑的「别死」、船长的「喝完再死」、主母的「不许死」,每一条都成为他后续在王座上撑下去的具体理由。
