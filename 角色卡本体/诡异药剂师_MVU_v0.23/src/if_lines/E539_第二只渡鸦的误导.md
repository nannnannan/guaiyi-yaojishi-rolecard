# E539·第二只渡鸦的误导·if线

- 若林恩在主母昏迷期间再以黑袍身走访圣堂一次，则「他不是林恩」证词加一层模糊，会议推论多一条「精神误导」分支。
- 若林恩在发布「不止一只渡鸦」台词时刻意改用另一种声线，则圣堂主母记录里多一笔声音比对失败，误导的可塑空间更大。
- 若林恩在击溃主母她们之后现场收起刀不出言「最后的狂欢」，则会议推论失去末日时限，找回林恩的紧迫度下调一档。
- 若林恩公开误导前私下再见银色幻想一次重申表演，则她在会议室故作茫然的剧本更稳，但知情层同盟多一条被点破风险。
- 若林恩刻意在战场留下「疑似第二只渡鸦」的法则残迹作为物证，则会议推论从「唯一合理解释」升级为「可坐实」，艾雯的疑团减轻。
- 若林恩在误导场合主动展示一缕他尚未精通的法则，则会议记录里多一条「他还在学习」的注解，误解同时向「并非完全体」偏移。
- 若林恩仅止步于圣堂转述而不让艾雯召集会议，则误导停留在二人层，银幻与巨像不必登场，保密同盟无从成立。
- 若林恩在散会后拒绝回答巨像任何试探，则巨像把 suspected 名单拉长，机械区私议中多一条「可能在测我们」的备用推测。
- 若林恩放任银色幻想把「达摩克利斯团结论」直接讲给巨像而不加压制，则知情层对公开层的误导配合更顺，但同盟的「推测层」外衣被扯掉一半。
- 若林恩通过分身投下第二条独立目击的「渡鸦黑袍」踪迹，则误导的可信度倍增，但他本人两线演出的消耗轴上升。
- 若林恩不在机械区留任何线索给银色幻想，则她只能从战报与会议推论拼出真相，剧本的破绽概率更高。
- 若林恩诱导艾雯在会议中第一口就说出「第二只渡鸦」而非让他自己提，则误导被定性为「黑夜城共识」而非个人推测。
- 若林恩在开会当天把人偶家同时引去别处静养，则会议桌缺少一张沉默的脸，后续人偶家独立暗查的概率上升。
- 若林恩催促「找回林恩」的号召由巨像先发，则公开层与知情层重叠过深，保密同盟的可信度打折扣。
- 若林恩在主母床前对巫神头颅多留一句「他没下重手」的旁观证词，则会议层对「第二只渡鸦仍有怜悯」的解读被强化。
- 若林恩在误导扩散后主动向几位古老根源透露「还有第三只」，则误导梯度升级，但同时也为后续身份暴露埋下更多反向证据。
