# E199·必赴蓝星与旧神遗产争夺·if线

- 若林恩在处刑俘虏前先摘下高脚帽扣在一旁夜医手上，则整个处刑过程他光头目视，系统提示弹幕连他右眼毛细血管的每一次收缩都被完整记录。
- 若林恩在第一声枪响之后停一下环顾四周再开第二枪，则夜医队列齐刷刷后退半步给他让出一条直线射击道，处刑变成一条有节奏的链条。
- 若林恩在白夜夺枪时反手握住白夜的手腕往下压，则左轮在两双手之间沉默三秒，林恩先松开，白夜的后背已经汗湿一片。
- 若林恩把「我会去蓝星」改成「我会把蓝星的事解决完再回来陪你们吃饭」，则白夜的夺枪动作在半空停了一下，处刑后续的处决被这句话减到三人。
- 若林恩在誓言末尾对着黑雾深深鞠了一躬，则夜医全员下意识跟着低头，誓言从愤怒变成一种更接近告别的仪式感。
- 若林恩在转身离去前朝左左伸出手让她握住，则她跳到他的肩膀把脸贴在他的颈窝，第一次没有吐槽他的固执。
- 若林恩在到达大殿后先停下来给小小一根棒棒糖交代「待会不管发生什么都别哭」，则小小攥着糖愣愣点头，众根源也注意到这份异常的体贴。
- 若林恩把「旧日」二字一出口就直接跳到「我要回去」，则大殿里少了半小时的理论讨论，直接进入五根源反对环节，争执更激烈。
- 若林恩在大殿法阵面前直接跪下对着五根源请愿，则主母第一次从座位上站起来，艾雯爵士的指节在座位扶手上敲出一连串焦躁的节奏。
- 若林恩把「故乡」换成「我唯一的家」，则巨像之脑的银瞳在那一瞬间湿了一点，五根源的反对声音同时低了三分。
- 若林恩当场摊开血衣日记推到众根源面前，则大殿里静了整整五分钟，第一个伸手去翻页的是主母，她的指尖在那最后血手印上停顿很久。
- 若林恩在「邪神子嗣」名号定下来后要求改用「萝莉控」直接作咒文，则巨像之脑当场一巴掌拍在自己额头，艾雯爵士苦笑着妥协「那就一起用」。
- 若林恩对泰坦的托梦降临笑场说「老头子你真的吓死过一群」，则泰坦头颅狰狞地哼了一声反驳「那是因为我霸气」，大殿的氛围松了一拍。
- 若林恩在巨像之脑说「黑雾上的星星是神尸」后主动戳她肩旁问「你们真的相信我们能冲出去吗」，则她瞪了他一眼又垂下眼帘，「如果我们不能，那至少你要先活下来」。
- 若林恩在小小说「医生哥哥好帅气」时把她抱起来原地转了一圈，则小小开心地笑出两个酒窝，众根源的反对声第一次混进了几声无奈的笑意。
- 若林恩在艾雯爵士说「你要明白我们无法带你回来」后沉默了三秒再点头，则艾雯爵士的表情反而更担忧，因为他太了解林恩的「点头」意味着「我会自己去」。
- 若林恩在被释放绑缚时挣脱瞬间直接往外冲，则大殿门口的锁链距离他三尺就开始自动拉起，主母指尖一翻把他钉回原地。
- 若林恩当场对小小说「哥哥要出远门一阵」，则小小攥着棒棒糖突然放声大哭，五根源的反对声音第一次被孩子的哭声盖过去，艾雯爵士的眼眶红了一圈。
- 若林恩在离开大殿之前回头对巨像之脑举了举手并用唇形说了一句口型，则她的银瞳在那一瞬间睁大，血色锁链差点从座位上掉下来。
- 若林恩在传送回自己住处途中遇上大舌头并拍了拍它的脑袋，则大舌头呜咽一声把舌头缩回嘴里，乖乖跟在他后面一起走进家门。
- 若林恩在回到住处对尹依说「你和孩子们先转移到安全处」，则她的虚拟眼眸在魂灵状态里凝视了他很久，然后郑重地点头「林恩先生，我会的」。
- 若林恩当夜带着小呀哒在自己腿上睡了一整夜，则她的小手攥着他的衣领不放，呼吸吐在他胸口，第二天醒来时他的衣服上全是她留下的指印。
- 若林恩把「妥协」的演技在眼底稍微多露出一分挣扎，则主母在事后独自琢磨她当时的判断，第一次开始怀疑他那种「太快妥协」的真实性。
- 若林恩在散场时跟白夜在大殿外单独会面并把背包里一份证物清单丢给他，则白夜翻完那几张纸后闭眼深吸一口气，对林恩的行踪选择性失明二十四小时。
- 若林恩对艾雯爵士单独说了一句「你的兵器我会小心用的」，则艾雯爵士沉默两秒后回了一句「你的命比兵器重要」，两人的目光第一次有了真正的兄长式交锋。
- 若林恩在左左质疑「主母他们说的是对的」时回头轻轻弹了弹她的额头，则她瘪嘴不再说什么，但当晚在他手心里睡成一团不肯离开。
