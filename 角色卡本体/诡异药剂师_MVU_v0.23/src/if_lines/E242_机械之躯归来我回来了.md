# E242·机械之躯归来我回来了·if线

- 若林恩在左左召唤白夜成真之前就反向预测并先一步准备拦截，则他成为她引爆装置的"隐藏守门员"，事件以变形（林恩隐藏拦截）收束。
- 若林恩在左左自己决定引爆之前先主动回应她"来吧，但你得跟我换个地点"，则蜀都虽然免受爆炸，但"白夜"并未收到死讯，事件以变形（白夜未能到场）收束，因暴怒复仇被改成合作调查。
- 若林恩的机械之躯登场时不补"我回来了"台词而是径直出手救援，则被剥夺血肉+人形机体+眼珠的突然出现没有花言巧语，事件以变形（沉默强者介入）收束，亲切感下降。
- 若林恩在砸碎第一使徒的触手之前，先用触手轻轻按了按左左的头说"哭什么"，则左左的失控情绪被一秒安抚下来，事件以变形（亲密突破预期）收束，长吻成立而后续骂局未出现。
- 若林恩让白夜在通讯中主动喊"林恩回来了"而非默默旁观，则白夜阵营对"他已经复活"的信任大增，事件以变形（阵营提前确认）收束。
- 若林恩自己在最后时刻把那道献祭光柱暂停，则左左得到的指令是"林恩还活着、她才是真正的中继器"，事件以变形（法阵未炸）收束，"我要你陪葬"的豪迈场景被抽换。
- 若林恩手上不是机械蓝芒而是一缕圣光，则血肉支配者判断"他被圣天使庇护"，事件以变形（圣光出身）收束，之后他对机械神教的飞鸟路径——他们愿意拥护更甚。
- 若林恩在抽掉"我要回来了"台词时让左左自己说出"你回来啦"，则她被自己产生的喜悦冲昏，事件以变形（她先开口）收束，"可恶的坏事"的兴奋感重组。
- 若林恩把巨像之心处理器的配置从100%锁到85%，则机械出力略有下降、但机体的损敷率被定增，事件以变形（机体更耐用）收束。
- 若林恩在白夜告诉他"她终于召唤我"之前先自行展开一道力场把法阵所爆的光芒包覆，则城市的灭亡被避免，但"我想让他回到我们这里"的心声被他利用，事件以变形（力场复原）收束。
- 若林恩在"我再给你多来几次"的语气里多加一次假召唤，则血肉支配者的投影感知到古怪、他察觉"他的量子纠缠涉及面比想象大"，事件以变形（投影对诱饵起疑）收束。
- 若林恩把触手贴在左左额上说"你还记得从来没有忘记我"，则她被心灵链接触动，事件以变形（急忙热泪盈眶）收束，"坏蛋"的愤骂早早播出。
