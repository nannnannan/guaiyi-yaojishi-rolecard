# E773·空白一击与画家阻挡·if线

- 若林恩在画家说出「不要追」前就认出她要伸手拉自己手腕,则他能提前半步决定是否让她抓到,但他会被画家看穿那半秒的犹豫。
- 若林恩让左左用左手在黑影弹出一击前就感知那股黑气方位,则她能精准定位偏转所需时机,但她的左手会在事后持续颤抖数十秒。
- 若林恩主动把「下一颗子弹你会瞄向哪里」反问黑影,则黑影会让那抹温柔笑意加深一度,「他会以言语对抗」正式进入双方记忆。
- 若林恩在画作穿身时主动让黑火从她后背贯入一段缓冲,则画作可能不被直接击穿,但林恩自己的黑火会被终焉之力灼出一缕不可愈的小缺口。
- 若林恩让画作在倒地前把清醒时的最后意识托在他掌心一秒,则他第一次实际承接住她作为守护者的重量,但她的清醒时间会比原作短三秒。
- 若林恩将「不要追」听进去但提出交换条件——让画作先承诺不在自己所在时间点立刻引发战争,则画作会首次需要权衡,她对林恩判断力的评估会更高。
- 若林恩在画作说出「我会删掉这段记忆」时主动声明「我也可以帮你记得」,则他会首次被画作划定入「可信的承诺者」名单,但需承担这段记忆可能改变他主未来的风险。
- 若林恩主动把黑火从「杀意」调成「守护」领域围住画作,则她的伤势恢复速度 ↑一层,但林恩下一波反击力量会被分散一档。
- 若林恩让左左在画作接住偏转杀招瞬间同步用左手感应那股黑气来源,则她能定位黑影意图路线,但左手会因接触终焉之力冻结半秒。
- 若林恩在画作喘息时主动用渡鸦形态向她靠近而不是人身,则画作不会被「人类形态下林恩的靠近」触发戒心,但会损失用人类声线的语言抚慰渠道。
- 若林恩主动把黑影称为「时间之外的孤儿」,则黑影被定义性名字捕获一瞬,那温柔面具首次出现一丝滞涩。
- 若林恩让左左在意识里把她对黑影的恐惧大声说出,则林恩能更精准地决定要不要护在她前面,但黑影会从林恩应对动作中透视到左左的位置与权重。
- 若林恩在画作站起身后主动让她留在自己身后,则他承担更多前线伤害风险,但画作首次感受到「林恩要保护她」的优先级。
- 若林恩把「你到底是什么在驱使」这个问题在更早时候就向画作提出,则他会在战斗余波中提前得到画作关于大君的答案,但这份提前知晓会改变他后续决策的情感基调。
- 若林恩在画作说出「不要追」之后仍追出半步再被拉回,则他能实际感知到黑影裂隙残存位置,但他会打破画作用身体向他传达的恳求。
- 若林恩让左左在画作接住黑戟那刻同步用左手托住她手腕,则她能为画作分担部分冲击,但左左的左手会沾染终焉之力创伤,需数日恢复。
- 若林恩把「这不是决战是探局」刻在意识里,则他对后续黑影设计有更强免疫力,但他也会失去「这一战就是终点」的果决感。
- 若林恩在画作为自己挡下黑戟时主动把这段画面刻进系统空间作为「被保护过的证物」,则他能随时重温这份感觉保持情感锚点,但证物会占用一格长期记忆位。
- 若林恩主动让黑火从杀伐切换到「只烧黑气不烧人」,则画作的伤势较轻,但林恩对黑影的杀伤威慑同步减弱。
- 若林恩在画作说出「他位置比她想的重要」之前主动说出「你对我很重要」,则画作眼中首次浮现一丝释然,但这份直书会暴露林恩心理优先级的调整。
- 若林恩让左左在这段时间里一直握着他的手不松开,则他能保持稳定,但他也会注意到自己开始对「她的手一直被握」这件事产生依赖。
- 若林恩把画中残影的形象从「敌人」重新标记为「同盟候选人」,则他在后续处理画作关系时有更清晰边界,但他会暴露自己对她信任的进度比原作快。
- 若林恩在画作喘息时主动用国骂缓解气氛,则画作首次露出纯粹笑容,但林恩自己也会在这一刻释放出一丝从未有过的轻松。
- 若林恩主动把「我下一个动作会是保护你」直接说出口,则画作被这份直接触动到手指微颤,但黑影也会在话语中捕捉到林恩保护策略的模式。
- 若林恩让左左在画作说出「下个时间点我会再出现」时对她点头同步,则画作首次感受到「他信任她的持续存在」,但左左也会承担「她是否真能持续」的责任。
- 若林恩把黑影出现频率估算为「每三百年一次」,则他会调整自己应对节奏不至于焦虑,但实际上黑影的出现是随机分布,这份估算会误导他后续判断。
- 若林恩让画作在告别时主动递给他一段关于未来的警告而不是完全封口,则他能提前布局,但画作「不干预未来」的原则会被轻微打破。
- 若林恩在画作离开后主动在长河某节点为她立一座无字碑,则他能保持对那个为她承受过伤害时刻的纪念,但这座碑会成为长河里一个新的因果锚点。
- 若林恩让左左在画作消失在裂隙前用左手向她微微示意感谢,则画作首次接收到「他的同伴也认可她」的信号,但这份互动会让黑影从裂隙回声中侦测到左左的位置。
- 若林恩把「我会成为最后的对手」正式记入对黑影的个人档案,则他在后续每一次遭遇中都有更强复仇驱动力,但这份执念也会成为黑影反制的杠杆。
