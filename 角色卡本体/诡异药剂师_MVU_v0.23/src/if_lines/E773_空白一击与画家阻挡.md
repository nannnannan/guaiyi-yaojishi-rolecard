# E773·空白一击与画家阻挡·if线

- 若林恩在目睹未来画家本体瞬移至跃迁通道前、以双手与胸膛硬生生挡下那缕射向过去人类林恩的灾厄黑气时目眦欲裂，则他瞬间震退黑袍身影飞身赶到她身旁。
- 若林恩在接住双手与胸口被灾厄黑气洞穿、鲜血淋漓的未来画家时第一时间渡入温和的秩序力量替她护住心脉，则她苍白的脸色得以稍稍缓和。
- 若林恩感知到那缕灾厄黑气因未来画家的肉身阻挡而偏离毫厘、仅擦着跃迁通道中过去人类林恩的身侧掠过（令当年的自己只觉一阵心悸），则他悬到嗓子眼的心终于落回实处。
- 若林恩在听见第七十二柱黑袍身影微笑着留下「我们会再见面的，林恩，我很期待我们能在时间终末一战」并率群魔退走时欲追入裂隙，则重伤的未来画家会伸手死死拉住他的手腕劝阻。
- 若林恩在看到未来画家身上的伤口无法靠时间回溯抹平、得知她每次跨时间作战皆是「本体降临，一切伤势都会原封不动带回她的时代」时心头剧震，则他终于明白为何过去岁月里画家总是重伤沉睡、陷入混沌。
- 若林恩在向未来画家追问魇魔为何能自由横渡时间长河时认真倾听，则他首次获知惊天秘辛：真正的时间神王依然活在某个角落，且掌握着真正完整的时间神格！
- 若林恩得知自己目前手中的时间神格其实并不完整（仅在这一场大梦中有效），而在原本的时间线里正是走到时间尽头的自己联合轮回神王对时间神王出手才夺取时间权柄开启重演，则困扰他许久的诸多疑团瞬间豁然开朗。
- 若林恩在未来画家转身准备离开前望着她染血的青蓝长裙轻声问出「你是觉得，我可以给予大君新生，是吗？」，则未来画家的娇躯会微微一僵，沉默中透出她跨越万古的执念。
- 若林恩在未来画家被灾厄黑气贯穿胸膛的刹那用黑火将残留的灾厄余毒从她伤口处强行逼出，则她带回未来的混沌伤势得以减轻一分。
- 若林恩在听闻未来画家轻声道出「不要去时间终末，现在的你去那里只会落入陷阱」时压下冲动听从劝告，则他避免了在尚未集齐完整时间神格前过早踏入绝地。
- 若林恩让左左在旁协助感知跃迁通道内过去人类林恩的状态，确认当年的自己已平安抵达天国战争废墟且未曾察觉外界恶战，则这段关键历史得以完好延续。
- 若林恩在得知画家历次沉睡与发狂皆是为了在时间长河中替自己挡刀护航后，眼神从过往的戒备转为深沉的复杂与感激，则两人之间的因果隔阂悄然消融。
- 若林恩在未来画家谈及“原本时间线里时间尽头的林恩与轮回神王联手算计时间神王”时细细咀嚼，则他对老师轮回神王当年的深远布局更是佩服得五体投地。
- 若林恩在未来画家流血不止时主动撕下一截衣襟替她包扎双手伤口，则这位高高在上的新世界缔造者会罕见地流露出一丝手足无措的怔忡。
- 若林恩将第七十二柱黑袍身影那句「时间终末一战」牢牢记在心底，则他明白在彻底肃清过去历史节点的隐患前，双方在时间长河的博弈还远未结束。
- 若林恩在察觉到手中残缺时间神格的局限后，更加注重在穿梭历史时节省神格本源的消耗，则他在后续漫长的远古巡航中始终游刃有余。
- 若林恩在问出关于“大君新生”的问题后没有逼迫未来画家立刻作答，而是给她留出体面的沉默空间，则未来画家在离去前会深深看他一眼，留下一句真诚的道歉。
- 若林恩在目送未来画家踏入空间裂隙返回她自己的时代前轻声道一句「保重」，则那抹青蓝倩影在消失前微微颔首，这段跨越时空的并肩作战画上句号。
- 若林恩在战场重归寂静后低头审视自己掌心沾染的画家鲜血，则他愈发清楚这趟时间之旅背负着多少人的牺牲，脚下的步伐再无半分退缩。
- 若林恩在清理完夹缝空间的全部战斗痕迹后将灭世黑火严密包裹周身，则他化作一道不可观测的暗影，顺着自身因果线继续向更古老的历史深处逆流而上。
