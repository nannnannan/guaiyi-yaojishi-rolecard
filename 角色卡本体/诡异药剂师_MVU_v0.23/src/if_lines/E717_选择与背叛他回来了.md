# E717·选择与背叛他回来了·if线

- 若银色幻想在被红魔与魇王夹击时没有做出「我带你们去」的决定，而是选择力战到底直至原子机械彻底溃散，则她当场身死，神疆献祭的创造一念神王位置悬空，黑夜城失去最后一位能扛起正面战场的神王级战力。
- 若银色幻想在说出「我知道他在哪儿」之前先向神疆中的自缚天使发送最后一道加密讯息，则主母能在她离开后立刻组织残部撤离神界，保留更多有生力量。
- 若银色幻想在撕裂空间带四魇魔离开时，故意在路径上留下一道可被黑夜城追踪的灵能标记，则康斯坦丁船长得以顺着标记找到第四层入口，但他孤身闯入同样会被困死其中。
- 若魇王在银色幻想说出「求你们」时直接捏碎她的头颅读取记忆而非接受带路，则四魇魔失去进入第四层的钥匙，林恩的位置继续保密，但银色幻想当场身死。
- 若红魔在银色幻想低头时抢先一步用猩红战刃斩断她与神疆的链接，则她无法维持「背叛演出」的完整度，四魇魔失去耐心当场将她斩杀。
- 若康斯坦丁船长在银色幻想离开前赶到并当众揭露「林恩不在第四层」，则四魇魔立刻识破骗局，银色幻想的牺牲变得毫无意义，神界在失去她的同时也失去拖延时间的机会。
- 若银色幻想在第四层空腔中不是背对四魇魔而是正面直视他们说出「在很遥远的地方，你们永远找不到的地方」，则魇王会在第一瞬间就捏碎她的脖颈，林恩来不及伸出援手。
- 若魇王在听到银色幻想说「林恩在主宇宙核心空间第四层」时选择亲自前往而非四魔同去，则另外三魔留在神界继续屠杀，黑夜城在林恩归来前已被血洗。
- 若银色幻想在第四层空腔中悄悄保留了一道与神疆的隐秘链接，则她能在被黑蛇噬魂时向黑夜城传递最后的信息，但这也会让四魇魔察觉并提前破界。
- 若林恩在银色幻想被黑蛇噬魂时选择先救船长而非她，则她在第四层中彻底湮灭，但康斯坦丁得以存活并继续统领黑夜城残部。
- 若林恩在伸出援手时不是低声说「交给我吧」，而是直接撕裂空间现身第四层，则四魇魔会立刻放弃银色幻想转而围攻他，战斗的走向完全改写。
- 若银色幻想在被黑蛇噬魂前一刻主动向魇王透露林恩的真实位置，则她成为真正的叛徒，林恩在天堂之战遗址被围杀，主宇宙失去最后的希望。
- 若康斯坦丁船长在血肉再生反噬倒下时，不是被林恩接住而是被神疆自动回收，则他会在神界中央广场废墟中沉睡数十年，错过最终的决战。
- 若林恩在第四层中斩出的「那一刀」不是针对黑蛇而是直接斩向魇王，则银色幻想会在余波中被波及，她的机械身躯在罪火中彻底消融。
- 若四位魇魔在被困第四层后选择自裁回归无序深渊而非破界，则他们会立刻在深渊中复生并带领更多魇魔卷土重来，主宇宙的窗口期被极大压缩。
- 若银色幻想在做出背叛决定前，向林恩在时间长河中的意志发出最后一次呼唤，则她能提前得知林恩即将归来，从而选择完全不同的战术。
- 若林恩在归来时不是从天堂之战遗址赶来，而是从主宇宙边缘的某处战场直接撕裂空间现身，则他会在四魇魔围攻银色幻想前与她们先遭遇，战斗顺序完全颠倒。
- 若黑夜城众人在银色幻想离开后不是恸哭叛徒而是立刻组织敢死队尾随，则他们会在第四层入口被关闭前冲进去，与银色幻想一同被困，但也为林恩争取更多时间。
