# E615·天堂之战遗址远征·if线

- 若林恩在折跃前让巨像先服用一枚初诞者精粹以稳定体质,则她的失控反噬会推迟到遗址深处才爆发,但会更剧烈。
- 若林恩在撕开坐标障壁时多用三分力,则遗址封印会在突破瞬间反弹,艾雯被震出半步,后续灵能风暴中的失控触发点提前。
- 若林恩决定让银色幻想独自留在机械残骸海,不带巨像与艾雯同行,则她会以更快的速度完成逆向解析,但「只可以这一次」的台词会推迟到下次见面才出口。
- 若林恩让血枢残魂在遗址外虚空就现身,则它面对苍蓝耀阳与机械残骸时的震撼会更大,「那是我的本质」的咆哮更刺耳。
- 若林恩把「反正你们也打不过灾厄投影」挂在嘴边,则巨像与艾雯的意志会更提前地被压垮,左左的拔刀场景更早出现。
- 若林恩在遗址外多布一层「外来者防识别的灵能屏障」,则遗址内的某些规则会被临时屏蔽,但织梦会更容易察觉他们的到来。
- 若林恩让艾雯在灵能风暴中多带一枚能引导灵能的初诞者神骨,则失控的反噬会少一分,但他对林恩的依赖会更重。
- 若林恩把遗址分区划成「灵能区、机械区、血肉区」三个独立修炼场,则三人的互动会减少,各自的突破速度更快但共同成长的线更弱。
- 若林恩允许血枢在遗址内多吃一枚载有「以太记忆」的碎片,则它能提前进入一段短暂的亢奋状态,后续对以太的研究会更急躁。
- 若林恩决定让整个盟约都知晓遗址坐标,则大反攻前的士气会更高,但遗址的秘密性会被打破,后续被污染者入侵的风险更大。
- 若林恩在遗址外的虚空中设置空间跳跃锚点而非折跃,则抵达时间会更久,但队伍的不确定性更小。
- 若林恩选择在遗址内先清理外围的被污染者残影再进入核心,则进展会更慢但安全性更高,织梦现身的时点会延后。
- 若林恩让巨像在遗址中与血肉残骸直接接触以吸收遗产,则她的血肉本能会暴涨,但「如触刀刃」的恶化会更严重。
- 若林恩把「我根本没打算让你们打赢」说漏嘴,则艾雯与巨像的挫败感会更强,家规的执行难度大增。
- 若林恩让银色幻想在遗址内铸造一台能预测灾厄投影的机械装置,则屏幕会显示一片空白,但她会留下「这不是终点」的警告。
- 若林恩决定在遗址深处为巨像设下一道「血肉枷锁」以控制她的本能,则她能更稳定地吸收遗产,但意志力会被压制。
- 若林恩让艾雯在灵能风暴中尝试融合林恩的血肉精粹,则失败会更彻底,但艾雯对林恩的信任会从依赖转为敬畏。
- 若林恩把遗址的发现过程写成一份报告留给大反攻前夕的军团,则一月军令的紧迫感会更强,但保密性会更差。
- 若林恩让血枢残魂见证艾雯的失控,则它会提前在血滴中标记「你看到了吧,她是外来者」,吞噬欲望的伏笔更早被点明。
- 若林恩在遗址内安排母树与左左同住一室,则她们会在深夜里交换关于「三位一体」的私密信息,母树对纱奈儿的兴趣会更浓。
