# E335·和谈契约与独行准备·if线

- 若林恩当面撕毁担保卷轴，则视界之主的天谴反噬落在自己身上，荒野坐标当场暴露给肉教。
- 若林恩让分魂形态保持成年大小随行，则主母大殿内没有小正太缓冲，艾雯爵士直接把他踹出师门。
- 若林恩用咒术隔空取【天使之吻】而不亲自爬上锁链，则主母沉睡面庞前的唇印换成隔空灵体，银丝口水落在空处，守护时效减半。
- 若林恩拒绝羽毛笔的惩罚仪式，则她扣下原本卷轴不还，黑夜城少了一道书写结界，森条例下赴约推迟一日。
- 若林恩对欲望母树的肉果回赠一颗以M结晶，则母树当场验货后把果实换成活体藤蔓，上阵时自带饥渴缠绕。
- 若林恩拒绝小丑与屠夫暗中锁定的既定坐标，改从反方向折跃赴会，则监狱长布置的包围网空张一夜，肉教亦被迫临时改道。
- 若林恩把主母那对「红茶包」真拆下来作护身符，则圣洁枷锁当场反噬，他双手被神圣灼痕烙印，主母今后苏醒第一眼先认出窃贼。
- 若林恩让分魂留守时把全部战斗记忆留在本体，则城内小正太变成纯粹生活系人格，羽毛笔的宠溺无需防备任何越狱可能。
- 若林恩对羽毛笔的威胁反将一军「割以永治我先割你」，则她毛笔停顿三秒，惩罚升级为在他胸口画下她的真名印记。
- 若林恩携小丑丢来的八音盒赴约，则会面现场自带诡异配乐，血肉支配者皱眉时他的触手也会跟着节拍抽搐。
- 若林恩不带左左分体同行，则城里那只幼态咒体独自在家捣毁系统商城，一夜花光他储备的三千骷髅币。
- 若林恩把心灵分流的「复活链接」调到最高灵敏度，则本体一旦受创，小正太当场嚎哭，艾雯爵士被迫全程拎着他避免暴露。
- 若林恩在羽毛笔绑他的时候主动喊「姐姐大人」，则她冷笑一声解开所有皮带，惩罚改成在她书房抄血墨三天。
- 若林恩用往日遗念偷窥主母过往，则画面里出现她与某位白发旧影的诀别，他被那段不属于他的悲伤噎得说不出话。
- 若林恩把分魂藏进欲望母树的花蕾里，则肉体触感直接渗进枝干，城内那段时间的母树呼噜都带着少年腔调。
- 若林恩在艾雯爵士面前变形成疫医取装备，则爵士当场拔剑劈了一整个储物柜，装备散落一地却没人敢捡。
- 若林恩把担保卷轴拓印十份分发给其他根源，则视界之主的诚信条款被无限稀释，天谴反噬变成无法落地的空头支票。
- 若林恩对主母吻完之后补一句「你是我的了」，则沉睡中的她睫毛轻颤，下一记精神惩罚换成长达三秒的真身抱杀。
- 若林恩拒绝登上小丑观察的荒原坐标，则那张早已布置好的大网扑空，猪头屠夫不得已亲自下场寻找替身。
- 若林恩把左左塞进破裙口袋一起赴约，则咒体一路上在口袋里嘀咕他胸口的温度，抵达时对面扫描到「桃色气息」警报。
- 若林恩临行前抚摸母树的投喂姿势改成献上自己血液，则她回赠的肉果体积翻倍并附带轻度催情粘液。
- 若林恩在誓约落印前用乌鸦臂章与视界之主交换一枚旧神遗物，则戒指落入他掌心时，黑发末梢短暂浮现一缕不属于他的霜色。
