# E761·挡在那岁月长河·if线

- 若林恩在最后一名幸存者逝去后任由羽毛笔走进满地酒瓶的废墟将他搀扶起来，则他虽然双目无神，掌心却仍下意识回握了一下羽毛笔冰凉的手指。
- 若林恩在随后数年里不动用任何超凡力量、仅凭双手一砖一瓦地清理瓦砾重建黑夜城，则他手掌磨出的每一道血痕都成为他对逝去故人无声的悼念。
- 若林恩在羽毛笔大哭着将他推倒在地、撕心裂肺地喊出「林恩！不要再这样了！大家已经回不来了！！」时停顿了三秒才爬起身，则羽毛笔看到了他眼底深藏的剧痛而非纯粹的麻木。
- 若林恩在徒手重建城外大墓园时把每一座紧挨的新坟都按生前好友的喜好摆上一件旧物，则整座墓园在死寂的主宇宙中保留了最后一分人间烟火气。
- 若林恩在将黑夜城的高耸尖塔、厚重城墙与广场会议厅全部重建完毕后伫立在空旷广场中央，则整座空城仿佛在一瞬间与他记忆里的繁华黑夜城彻底重叠。
- 若林恩在广场上恍惚间露出如当年初入地狱少年般的爽朗笑容、并习惯性抬手欲扶单片眼镜时，那份突如其来的力竭昏迷让他终于卸下了紧绷数年的神经。
- 若林恩在从广场尘埃中苏醒的瞬间为了不把羽毛笔卷入时间乱流而主动推开她冲向苍穹，则羽毛笔虽在身后哭喊追赶，却也因此免遭时间壁垒破碎时的狂暴反噬。
- 若林恩将体内时间神格催发到极致、以漆黑火焰硬生生烧穿时间壁垒冲入冰冷的「时间之外」，则他那不顾一切欲回到登临王座之前改写历史的执念震动了整条岁月长河。
- 若林恩在时间之外看到全身散发苍白光幕的轮回神王如高墙般挡在岁月长河前方时，没有立刻出拳而是先沙哑地唤了一声「老师」，则轮回神王的眼神会多一分痛惜。
- 若林恩在听见轮回神王平静提醒他曾说过要「等」、并严词警告“没有那段历史就没有现在的林恩，回去只会把过去扰乱得一团糟”时双目赤红，则他内心的悔恨与理智展开了最惨烈的交锋。
- 若林恩在被执念支配下燃起焚尽万物的黑火向轮回神王轰出毁天灭地的一拳，则师徒二人的正面碰撞直接令整条时间长河剧烈动荡、无数无用支流当场破碎。
- 若林恩在徒手搬运黑夜城废墟砖石的岁月里留意到跟在身后的羽毛笔体内命运伟力正在大衰退中不断流失，则他在重建广场角落时悄悄为她搭起了一处避风的石亭。
- 若林恩在羽毛笔哭喊「从你登临王座的那一天起，这一切就已经回不来了」时闭上双眼，则那句残酷的实话如刀般刺入心扉，成为他苏醒后决意冲向时间长河的导火索。
- 若林恩在烧穿时间壁垒的瞬间回望了一眼自己亲手重建的空旷黑夜城，则那座没有一个活人的孤城画面彻底点燃了他不惜逆天改命也要救回大家的疯狂。
- 若林恩在时间长河前与轮回神王对峙时质问「哪怕看着所有人死绝，我也只能等吗？！」，则轮回神王的沉默让他更加确信唯有打倒眼前的老师才能触碰过去。
- 若林恩在与轮回神王交手的第一合中便全力催动终焉黑火，则轮回神王周身的苍白光幕当场被灼出焦痕，验证了林恩如今的力量已真正逼近神王绝巅。
- 若林恩在重建血锯诊所与木偶工坊时连门窗的木纹都分毫不差地复原，则这份近乎偏执的精细让羽毛笔在旁看得更加心碎。
- 若林恩在昏迷倒地前那记摸向眼眶的空抓没有摸到单片眼镜，则他在醒来的一刻更加清醒地意识到昔日那个依赖伪装与算计的药剂师早已留在了过去。
- 若林恩在冲击岁月长河时将自己的神王威压凝成一线只攻轮回神王而不波及后方的主时间线，则即便他在盛怒之下也仍保有一丝不愿轻易震碎故人历史的本能。
- 若林恩在一次次被轮回神王苍白光幕挡回后气喘吁吁地擦去嘴角血迹，则他透过狂舞的时间洪流，猛然瞥见了长河内部那个正在走向圣堂罪恶王座的过去自己！
