# E761·挡在那岁月长河·if线

- 若林恩在重建黑夜城时主动把某面墙的高度特意设低一段，则那一段墙成为后来某个幸存者能爬上去眺望的所在，黑夜城多一线人性尺度。
- 若林恩在搭王庭时亲手将主母当年坐过的位置留出一张空椅，则他此后每次进出王庭都要面对那张椅子，时间长河的攻击也难以打塌这一段情绪。
- 若林恩把某位死者的工具放在城门口作为镇物，则城门在承受时间折返冲击时多一线不锈的硬度，那位死者的手艺以工法镇城。
- 若林恩在冲击时间长河外壁时让自己的攻击频率故意落在心跳节奏，则每一次攻击都附带一缕来自他自身的血温，时间长河把这一段折返的反应稍缓。
- 若林恩主动在时间长河外壁上烙下小小的名字，则时间长河下一次折返他的攻击时在那名字处停顿半秒，他首次获得长河层面的回应信号。
- 若林恩隔着王座向轮回神王说一句「请先开口」，则轮回神王在是否透露自身计划上多一瞬犹豫，林恩多获得一次准备的空间。
- 若林恩把黑夜城某段城墙特意保留废墟原状而不重建，则那一段成为他对「曾经失败」的公开纪念，时间长河的折返冲击经过这段时会替他挡一下。
- 若林恩主动允许某一个幸存者影像在城内短暂伴随而不是立刻收档，则城内出现一个真正的临时与众同行，但影像本身会被时间长河磨损。
- 若林恩让王座把时间长河所有折返的攻击方向全部记录下来，则他对长河的规律获得一份完整的折返手册，未来突破更准。
- 若林恩在长河外壁上钉下自己手掌印而不是黑火，则长河把这份人形温度作为一种信号层层通向深处，轮回神王在另一端更早接收到他的意图。
- 若林恩在长河冲击时反向让自己的心跳变慢，则黑夜城整体时间感被拉紧，城里所有记忆层的损耗速率下降。
- 若林恩主动邀请轮回神王在城外某段未重建的台阶上坐一坐，则他们首次不像敌手那样交换信息，E762 的出师告别变得不是无奈的传承而是被提点。
- 若林恩把时间长河外壁上某一处最早的裂痕用记忆里主母的祷词修补，则那一处裂痕被封印，日后成为他突破时不能触碰的位置。
- 若林恩主动将两千片幸存者名牌串成一条链挂在城墙最高处，则那条链在承受时间折返冲击时会有节奏地响，被城里幸存者记忆用作一种报时的钟。
- 若林恩把黑夜城王庭石柱换成记忆中小小医院的样式，则王庭气场从庄严转为怀旧，时间长河在那一段折返时会先把伤势转到边角而非核心。
- 若林恩在城内某处主动设一座空房间并贴上某位死者的名字，则那间房间的存续与否成为他自己精神状态的晴雨计。
- 若林恩让王座在攻击时间长河时选择从记忆中「最不重要的一段」先发起，则他保住对他最重要的记忆层不被反噬，但最普通的那一层从此消失。
- 若林恩主动朝时间长河放一句「我不是回来改的，我是回来接人的」，则长河把这句话以一种不可反驳的方式烙在他的攻击路径上。
- 若林恩把黑夜城城门方向故意对准时间长河某一段，则他每次出门都朝着那一段，时间长河以视线的方式回应他。
- 若林恩主动把轮回神王在长河外的气息作为一种可交流信号去回应，则他们首次以非武力的方式接触，但林恩也因此被神王捕捉到精神频率。
- 若林恩在冲击时间长河时让某次攻击故意走火偏出擦到远处一座废墟，则那座废墟醒出一两位幸存者，两千人死亡名单上第一次被划去两个名字。
- 若林恩主动在长河外壁上挖一个小孔而不是直接撞碎它，则长河未来从那一孔漏出的时间是缓慢的，林恩得以提前观察终点而不被一次性吞没。
- 若林恩让王座把轮回神王出现时的气息变化完整存档，则他在 E762 面对神王真正开口之前就能预判那一句话的分量。
- 若林恩主动把城内某个庭院命名为「小小花园」并让黑火在那里催生第一批植物，则庭院的盛开与否成为他在沉眠外修行的轴心。
