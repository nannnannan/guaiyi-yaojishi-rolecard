# E605·战后神格与敌情情报·if线

- 若林恩在战后清点时先慰问伤亡而非先查战利品,则军团温情指数暴涨,但神格读取的时点被推迟到 E606 之后,魇的战书缺席本场会议。
- 若林恩主动让艾维儿在动摇未解之前先回家族休息,则她不参加后续会议,「真理神王」的名号由主母或自缚天使口中说出,文本脉络被改写。
- 若林恩决定不亲自窥探血肉神格,改由主母代劳,则三条敌情情报由她宣读,林恩失去「亲手抓出敌人阴谋」的英雄画面,但主母对天父脉的理解被拉近。
- 若林恩让艾雯爵士在法则浪涛福地化的瞬间就入殿闭关,则她在 E609 的半神榜更靠前一格,但本场会议她缺席,「永远最后一个」的自嘲不成立。
- 若林恩主动在间谍情报里加一条「敌方另有一尊古老神王已现」的推断,则双神疑云被立即升级为三神疑云,会议氛围从震惊转为恐慌。
- 若林恩让会议里多留席位给银幻与小丑,则「可控无序」的怒吼台词由小丑变成他二人对骂,场面更喧闹,但「屌人」金句仍出自小丑之口。
- 若林恩决定把血肉神格的净化期压制到一周内而非漫长温养,则血肉根源闭关的窗口被人为压缩,后续巨像的四十个月泡内修行被改写。
- 若林恩主动在会后向艾维儿说出「不是所有秩序都值得推翻」,则她的「那就是我们」从怀疑改为挑衅,后续她参战意志反而更强。
- 若林恩让康斯坦丁船长在会议上多问一句「如果打不过就投降吗」,则满场爆笑,但后续军团对「打不过就投降」这条梗的传播更广。
- 若林恩决定不开放两座神殿公开参悟而改为竞标入驻,则军团内部竞争氛围提前爆发,任何失败都会被双倍放大。
- 若林恩主动把「一大批半神」的目标公之于众并设下期限,则军团速成压力指数暴涨,但任何进度滞后都会被群嘲。
- 若林恩让林恩在窥探神格时被腐化反噬一缕,则他本体带伤入定,后续提审魇的戏码里多一道「他带伤看一眼」的额外张力。
- 若林恩选择在会上当场召出魇的八音盒审讯,则 E606 的惊悚开场被前置到本场,林恩的多重揭示场面叠加,但「天父梦魇即你父之梦魇」的爆点来得更早。
- 若林恩决定不上交血肉神格而当场吞服,则他体内神格冲突剧烈,后续「三位一体」的稳定性提前崩坏一档。
- 若林恩主动在会议中让艾维儿宣誓「助我直至真理现形」,则她绑定更深,但后续她对任何林恩失误的追责权更重。
- 若林恩让巨像在会议里现场报名参加两座神殿的闭关,则她的「誓保前三」被改为「誓保第一」,后续时间小屋的情感戏码更激烈。
- 若林恩把「主宇宙将武装化」的口径从「大幅降低被污染者的优势」改成「彻底免疫」,则盟约的期望值被拉爆,任何后续失败都会双倍增悔。
- 若林恩主动在窥探神格时放一缕初诞者之力进入,则神格内的残存意志被惊醒一瞬,魇的破盒口供里多一句「你们惊动了我」。
- 若林恩让康斯坦丁在这场会议中不提问神格而是问「我们什么时候能主动出击」,则后续破碎之眼攻略由船长亲自推上议程,林恩压力被分担。
- 若林恩决定不让艾维儿讲述七大神王史,则由主母讲述,则「你父亲的老对手」从父女对抗变成女友前史,艾维儿语境被改成非家族叙事。
- 若林恩主动在会后让左左在系统面板上为参战者结算积分,则军团的战斗被游戏化,后续任何战斗都会被积分表驱动。
- 若林恩选择在本次会议中公开艾维儿的「那就是我们」动摇,则全盟的核心被打开,军团中不少根源开始思考「正义与被统治」的边界。
- 若林恩让林恩在战后把本体转移到第三位面而非黑夜城,则主场氛围更加战地化,E606 的会议可能在战场废墟上开,堡垒感更强但仪式感减半。
- 若林恩决定不让小丑出席会议让他继续镇守走廊,则他的「屌人」台词被押后,魇的登场由林恩直接揭示,但小丑「我曾镇压此物」的资历消失在会场。
