# E598·深渊改造闭关·if线

- 若林恩在下潜心灵之海前给左左一个长久的回眸微笑，则她会在心灵网络外守着他那一段静默时间中拥有了一个只是她与他之间的画面。
- 若林恩下潜前告诉康斯坦丁「若我第一次醒不来，你就自己当船长」，则船长会以「你敢」三字回应，整个巨船甲板都被这一句话刻住。
- 若林恩在下潜瞬间把一缕心灵法则依威不得其胜，则他能在闭关中在黑暗里偶尔看见银幻的改造根基与他心中的「三位一体启示」交融得更紧。
- 若林恩让艾雯爵士在下潜期间自己代理指挥，则艾雯会在前线压抑住所有心忧，却并不告诉任何人林恩到底去了哪里。
- 若林恩在下潜前给银幻单独发了条「好好干」的私人传讯，则她会在忙碌中会心一下，然后所有动作的节奏会更顺畅地向前推。
- 若林恩没有唤醒死命令而只留了自动唤醒协议，则康斯坦丁会不得不以自己方法在大敌逼近时强行推醒林恩，但这会打乱林恩的理论参悟节奏。
- 若林恩选择不在心灵之海、而是直接在边境现实位面闭关，则他会失去时间差的优势，敌军到达时他参悟仍只到半，决战被「节点提速」反拿。
- 若林恩在下潜前给所有根源留了一条「你们是我的家人」的总留言，则众根源在心灵网络中会同步因这一句话而集体沉默三秒后才彻底爆发战意。
- 若林恩下潜时跟左左来个私密心灵对答「若我终于被吞噬时，你要叫我名字」，则左左会在意识里整段记忆中，默默地把这个要求用哭泣记成一颗痤疮。
- 若林恩在下潜时对小丑开玩笑「你若醒来我还在闭关，可找地方吊我一顿」，则小丑会在事后安分守实地按时唤醒他，但嘴里要骂骂咧咧一整日。
- 若林恩让巫神头颅在闭关期间代理群频「总娱乐官」，则群频下会是一片浓郁的喜剧底色，而巫神本人在这一幕中异常接地气。
- 若林恩决定不告诉艾雯具体方向、只说「放心」，则艾雯会与船长一样选择扮演「不告诉你真相」的安静角色，并在他本人在心灵网络头抱住左左默默守护。
- 若林恩在下潜中把最新的监控布设技巧纳入理论，则他能以更小的代价在将来养成一个「自我监控」般的深渊。
- 若林恩在下潜中心情过于起伏反而持续失败，则他会在闭关某一天自己故意中断几秒逃走，所有人都会在那几秒里感受到他微微的颤抖。
- 若林恩上潜时恰好遇上敌先头部队压到他所在巨船甲板，则船长会毫不犹豫选择替他跳船拖住敌军，后续林恩必须独自扛下出关的第一道冲击。
- 若林恩完成参悟的瞬间主动先联系银幻而不是任何其他人，则她会第一时间感应到他要她做什么，之后两人会结成一种「德同、位同」的亲密同盟。
