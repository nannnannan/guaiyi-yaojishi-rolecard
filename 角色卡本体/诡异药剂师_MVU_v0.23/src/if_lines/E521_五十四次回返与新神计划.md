# E521·五十四次回返与新神计划·if线

- 若林恩在被主母勒脖时不反抗而让她勒到自己咳两声，则气氛从紧张转向滑稽，散伙通牒的严肃性打了折扣。
- 若林恩选择在「确实无法给明确答案」的承认后立刻补充「但我能给一个模糊的方向」，则主母松手的时机提前，悲愤动员环节被压缩。
- 若林恩在抛出神格理论时故意让画图更精美，则康斯坦丁辨认时间减少，但众人对「这是认真还是玩笑」的判断难度增加。
- 若林恩决定不让巫神猜「灯泡」，则她从「灯泡」代入，猜中真意的难度下降。
- 若林恩选择在封神点名时不点银色幻想为「工匠与铸造之神」而点她为「机械之神」，则她反应从无语变成正色三分。
- 若林恩决定把「小丑自荐丑神」换成「小丑自荐捣蛋神」，则社死等级下降一档，小丑本人可能会真的争取。
- 若林恩在结束时让主母摇他回座位而不是揪后领，则主母的「脸黑」程度减轻，氛围松一些。
- 若林恩选择不分玻璃珠而是在会后单独发给每一位，则众人没有被「全员目睹分发」的团结感裹挟，个别保留态度的人较多。
- 若林恩在分珠时故意让银色幻想的珠子多一颗，则她可能发现这是偏心，猜测他的动机，归心程度或反或升。
- 若林恩决定把主母定为「光明与黑暗之神」改成「母亲之神」，则她被命名当场脸红或者拍案，关系轴轻微偏移。
- 若林恩在选择「胳膊肘不往外拐」的措辞时换成「我们都是一家人」，则玻璃珠分发的家族感更浓，但对外防泄密的压力也更大。
- 若林恩在画大饼时改口「这是一定能做成」，则众人警觉信度下降，会议散场时质疑声大于感动。
- 若林恩决定不让船长第一个认出神格，则辨认环节可能拖延，直到某位其他人偶然提起，剧情节奏断开。
- 若林恩在抛出「分庭抗礼」措辞时换成「战胜灾厄」，则众人信任度下降，但抱负感上升，他的话被定性为「疯了的大话」。
- 若林恩在自缚天使砸桌时主动将头凑过去让她砸而不偏，则她砸完后感动讶异，散伙通牒被取消或被改动。
- 若林恩决定不对「封神点名」社死现场结界设防，则情报可能泄露到外界，新一轮神位争夺战提前爆发，主线被改写。
- 若林恩在分玻璃珠时自己不留一颗，则林恩本人无原初之力护体，后续战斗中需要他人分担压力。
- 若林恩决定让左左也参加会议而不是会后走廊才追问，则她在现场就抢过珠子玩，气氛从庄重变成童趣。
- 若林恩在「灯／晶石／球／包子／炸弹」猜谜时引导气氛更凝重则巫神不会猜「灯泡」，猜想链重新走另一条路。
- 若林恩选择在会议最后不让左左在门外等而是让她先回去睡觉，则她错过这次走廊追问的机会，E522 的灌注法口头窗口延后。
- 若林恩在描述初诞者之力时用「神的心血」代替「原初母力」，则概念色彩从宇宙论变成情感论，众人的感悟路径不同。
- 若林恩决定把大君／历史轮回信息更多投放，则众人对「这位大君」的敬畏加深，对林恩的信任轴加重，但怀疑论也上升。
- 若林恩在封神点名时把船长定为「守护之神」而不是「死亡之神」，则他的死亡神格历史不被点名，情报敏感度降低。
- 若林恩在分珠时让某一颗赋予特定的泰坦／某一位，则众人注意该颗，私下询问分配依据， resentment 或感激都可能。
- 若林恩决定让会议厅在玻璃珠强光中持续一分钟而不是转瞬即逝，则众人有更多时间感受其中的初诞者之力的质感，信服度上升。
- 若林恩在「我们需要一批神王级别」时点出「五六个」具体数目，则众人开始私下讨论提名，会议结束后立即掀起内部动员。
- 若林恩选择在林蒙／骨王／北境海王殿未在场的情况下继续封神点名他们的位置，则被点者的空缺席位成为众人讨论的话题。
- 若林恩在众根源散会后立刻召主母单独约谈解释更多细节，则主母得到额外情报，她对他的信任度加大但同时担起更多保密责任。
- 若林恩决定让会议录制成玻璃珠复盘给不在场的关键人物看，则情报传递路径延伸，但录制过程被发现的风险上升。
- 若林恩在事件结尾选择不对左左说「也许吧」而是说「一定是真的」，则左左的信心被点燃，她在 E522 中要球球的态度更坚决。
