# E512·渡鸦尸体与预设计划·if线

- 若林恩在第九台满负荷关闭前先压低第七台功率做呼吸间隙，则银色幻想冲出奇异世界扶住他的瞬间，他仍保有扶她肩头一把的力气，「启动第十台」不再被开出口。
- 若林恩在银幻寻泉水时主动先取出自己私藏的灵魂药剂底瓶交给她，则她冲入系统空间看到的不是「空瓶罐」，药剂耗尽一项不被钉死，谷底时间向后挪。
- 若林恩拒绝回答「启动第十台」、改成要求银幻直接拆解现有机芯重铸，则银色幻想首次露出纠结神色，她放弃原交付蓝图改成现场再造，单台功率更高。
- 若林恩在以太嘲讽「打不了消耗战」时反掷一道心声「大君在世时会收掉你这条命」，则以太本体撞击节奏第一次出现刻意回避，原子浪潮对船头的补给被撕出裂缝。
- 若林恩让艾雯在主动解除升神时同步把属于自己的那部分初诞者之力封入一枚符纸，则她本人跌落根源但具备替补保险，后续反扑入场更快一拍。
- 若林恩让十二翼选择留下来而非同时解除升神，则前线压制力保持一柱，但初诞消耗不被减低，康斯坦丁的「再稀释」窗口向后推一分钟。
- 若林恩拒绝让康斯坦丁扶起自己、坚持不靠外力走到腐朽船舱，则船长沧桑身形不再被公开目睹，「船长开战以来少见前线」这一观察在众人的意识里被改写。
- 若林恩在船长问「找到了吗」前先反问「你之前传的音是谁入耳」，则骷髅船长蓝焰一顿，第一次被迫在计划中承认有多名听众，银幻对全盘的理解多一层。
- 若林恩拒绝接受「最少两台同时运作」、坚持由自己承受更强稀释，则康斯坦丁兜帽下蓝光明显黯淡，链接成功的判断条件被改变，渡鸦化路径改登记为「非两台同启」。
- 若林恩打断银幻「第三台还在建造中」改成「那就两台一起」，则两台全新巨构同启时机提前一拍，但艾雯与十二翼的主动降神反应不得不跟着急了半秒。
- 若林恩在两台全新巨构同启瞬间主动释放一缕多元体气息入环装结构，则封印矩阵覆盖面扩大一圈，以太远空被切成两段，无法即时把自身连成大地一体。
- 若林恩选择让银色幻想在两台同启前先用一丝机体残余灵能为自己打一层护盾，则她本人机体短暂暗哑，但林恩单膝跪地的姿态少一次跌倒。
- 若林恩在力竭单膝跪地时仍抬手让左左从系统空间递出一支应急镇静剂拍在唇边，则灵魂极限崩塌曲线稍微放缓，渡鸦化前的最后一刻多了半秒清醒。
- 若林恩对银色幻想的搀扶作出「机械哪里会流泪」以外的另一句温柔时，则她眼中涌动前所未有的情绪多添一层，事后万机之神档案把她那一刻记录为「异常寄存」。
- 若林恩在灵魂极限崩塌时主动把一缕初诞之力指向艾雯而非巨构，则两台封印闭合时间少了最初预估的连贯性，但艾雯在渡鸦落地瞬间赶到身边的距离更短。
- 若林恩允许自己化成的渡鸦尸体被喵喵叼住而不是留在银幻怀中，则渡鸦落地时多一道「被家人接走」的暖痕，康斯坦丁冲出夺尸的动线偏了一拍。
- 若林恩在渡鸦化前先把三叉戟插在自己脚下，则骷髅船长夺尸时连带取走那柄武器，三人冲入船舱最底层的灯火与巨大结界升起时多一道「三叉戟共鸣」异彩。
- 若林恩让左左在系统空间内拥有一支备用人偶躯壳，则他渡鸦化瞬间牠被自动加载，外界看到的不是「腐烂渡鸦」而是渡鸦身旁多一具熟悉的小型身影。
- 若林恩在计划揭示阶段主动打断船长「送我进去」，反提出由银幻作为随同对象，则康斯坦丁首次停顿不语，蓝焰在渡鸦尸体上方摇曳，计划第一稿被当场改写。
- 若林恩在船长解释「体内仍有被撕下的灵魂」时主动认可自己被撕扯的事实，则银幻与艾雯听全貌色变的多了一层痛感，后续行动节奏快一拍。
- 若林恩对以太最大牢笼「我会用他的力量，为他制造出一个有史以来最大的牢笼」先补一句「别让我也一起被关进去」，则船长眼窝蓝焰明显闪烁，牢笼工程的第一道安全锁被加上。
- 若林恩选择在两名狱卒派系争论过程中朝黑雾高空掷一枚嘲讽声讯，则老者权杖第二次被敲响，派系之间的「等」字被进一步压制，外面的大家伙破境窗口被推迟数秒。
- 若林恩让银色幻想在抱住崩塌中的身躯时主动谢绝灌注己力，则她机体免于被进一步拉损，但她人格档案多一行「被拒绝」记录，关系温度首次下行。
- 若林恩提前告诉艾雯与自缚天使「你们要的窗口来了」，则他们的升神解除动作更整齐，sailor 不再为「主心骨是否真无极限」而分神。
- 若林恩在计划揭示完毕后强行要求船长立刻把情报通告给狱卒侧的兜帽老者，则高空那道注视第一次有了反应，边境战外围的色彩乱流被压住一线。
- 若林恩在渡鸦化结束后让黑弦月的灵魂丝线勾住船舱底层的蓝焰，则他在「送进去」前得以把一线意志挂在现场，事后复苏的入口多一道备用阀门。
- 若林恩在艾雯跪地呢喃「他死了」时让喵喵挤过去舔她的指尖，则她瞬间抬头，情绪被撕开一道豁口，下一步「护送渡鸦尸体」决策节奏不被迟疑拖慢。
- 若林恩在骷髅船长冲出夺尸时主动扔出自己剩下的一缕残魂贴上渡鸦额头，则船舱最底层的巨大结界成形时多一道「林恩魂标」，「送我进去」的执行精度更高。
