# E766·我们一定会重逢的·if线

- 若林恩在冲到白发枯槁的羽毛笔身边、触碰她轻如鸿毛的身躯时双手剧烈颤抖，则他瞬间感知到曾经的命运女神体内法则已衰败至油尽灯枯的凡人境地。
- 若林恩在刚要开口自责时被羽毛笔伸出干瘪的手指轻轻堵住嘴唇，听她含泪笑着说出「只要有左左在，哪怕到了最孤单的时候你也一定能够振作，我终于可以彻底放心了」，则林恩心如刀割。
- 若林恩在接过羽毛笔怀中安然沉睡、未留下一丝大衰退伤痕的左左时，深深明白羽毛笔是用她自己的命替他守住了最后的软肋与归处。
- 若林恩双目爬满血丝地死死紧抱着衰老的羽毛笔、扩散出新建的金色秩序梦境试图弥补她衰退的法则，甚至提出「哪怕熄灭那团好不容易燃起的黑火，我也要转换你的本源让你成为我梦境中的眷属生灵！」，则这份不惜放弃终焉大道也要留住她的决绝令羽毛笔动容落泪。
- 若林恩在羽毛笔再次伸指堵住他的嘴、温柔而坚定地拒绝成为梦境眷属，并听她道出原因——「因为你的梦境，终究也是要燃烧殆尽的……羽毛笔一点都不想成为你的阻碍啊」——时，他浑身僵硬，彻底读懂了她的成全。
- 若林恩在明白自己梦境中重建的秩序终有一天必须作为柴薪烧掉才能达到终焉之主的高度、而羽毛笔正是怕他届时因她踌躇才宁可走完凡人最后一程时，他再也说不出一句强留的话语。
- 若林恩在无垠的黑暗中任由这位白衣枯槁的老妇人张开干瘪双臂紧紧拥抱自己，听她坚定地说出「我相信，我们一定会再次重逢的！」，则他在心底立下重誓：哪怕烧穿终焉，也定要在新生的世界里将她找回。
- 若林恩在拥抱羽毛笔时将金色秩序梦境化作最温暖柔和的光晕笼罩四周，则虽然不强行转化她的本源，却为她驱散了时间之外彻骨的严寒与病痛。
- 若林恩在羽毛笔摸着沉睡左左的小脸微笑时，轻轻握住羽毛笔布满皱纹的手掌贴在自己脸颊上，则这一刻的温存超越了漫长岁月的生离死别。
- 若林恩在听羽毛笔提起“你早就悄悄把心里最重要的左左藏了起来”时眼角滑落热泪，则他感念于这位挚友比他自己还要懂他的孤独。
- 若林恩在放弃强行转化羽毛笔后，转而将金色秩序梦境布置成一座鸟语花香的伊甸园供她度过最后的时光，则羽毛笔欣然点头答应与他共赴这最后一场美梦。
- 若林恩在羽毛笔说出「未来所有人都会在你新生的梦里归来」时郑重回应「一个都不会少，包括你」，则羽毛笔苍老的脸上绽放出宛若少女般明媚的笑容。
- 若林恩在将沉睡的左左妥善安放在金色梦境最温暖的摇篮中后，全心全意地陪伴羽毛笔走入生命最后的回光返照，则两人之间再无任何遗憾与阴霾。
- 若林恩在感知到羽毛笔的生命之火即将步入尾声时强行压下眼底的悲痛，努力向她展现出最温和从容的笑脸，则羽毛笔得以毫无牵挂地享受最后的相伴。
- 若林恩在羽毛笔感慨自己终于没有食言等到他出关时，轻声向她讲述自己在衔尾蛇梦境中每一次想起她的约定才撑过来的经历，则她听得满眼星光。
- 若林恩将羽毛笔「不想成为你的阻碍」的嘱托深埋心底，则日后他在面对终焉大君燃烧梦境柴薪的决战关头，果真做到了一往无前、绝不犹豫。
- 若林恩在抱起轻飘飘的羽毛笔踏入金色伊甸园梦境的那一刻，任由她借回光返照之力恢复昔日绝美的少女容颜，则时间仿佛倒流回了两人初见的那一天。
- 若林恩在进入最后梦境前悄悄用秩序黑火将羽毛笔散落的一缕白发封存进心口，则这缕白发成为他永恒铭记她为自己与左左付出一切的信物。
- 若林恩在听到羽毛笔小声请求「在最后的时间里，陪我玩一场以前的游戏吧」时温柔应允，则一场最欢快也最催人泪下的伊甸园追逐即将上演。
- 若林恩在无垠黑暗与金色梦境的交界处与羽毛笔十指相扣，则「我们一定会重逢的」不再只是一句安慰，而是镌刻在神王道心上的铁律。
