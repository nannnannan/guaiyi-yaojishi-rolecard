# E766·我们一定会重逢的·if线

- 若林恩在羽毛笔布置最后梦境时主动把自己的王座尺寸改小一号放在桌旁，则他的黑火在梦境里不再是王焰而是炉焰，桌椅可以更靠近他。
- 若林恩让梦境桌上先放一杯热茶而不是先放《狸猫书》，则他在翻书之前先喝一口记忆里的味道，那一口把他的清醒门槛压低一寸。
- 若林恩隔着梦境对羽毛笔说一句「请慢一点」，则羽毛笔把整本《狸猫书》多写出三页，但自身的透明化加快一拍。
- 若林恩主动让梦境黑夜城里某条街道的转角按他真心怀念的样子做旧，则他每次路过那个转角都要掉一次眼泪，但那滴泪成为他识别「这真是我家」的凭据。
- 若林恩在翻《狸猫书》到一半时主动合上不看结局，则羽毛笔允许他在自己消散之前续写那一段，梦境因此多一页林恩亲笔。
- 若林恩主动要求羽毛笔把左左未来坐标藏在他自己常用的一本书里，则他日后无需翻新书就能找到她，但那本书从此在每次翻开时都会露出一次羽毛笔的字迹。
- 若林恩让梦境里那只猫不是陌生猫而是他曾养过的某一只的形态，则那份熟悉让他在醒来前的最后一刻心里多了一份柔软，但那只猫的旧主人记忆会被擦亮一次。
- 若林恩在听羽毛笔「我们一定会重逢」时回应一句「我会等你」，则羽毛笔的告别不是单方面的许诺而成为双方的约定，它的火焰因此更亮一秒。
- 若林恩主动让羽毛笔在写完《狸猫书》最后一页后允许自己掉一滴墨而不是压回去，则那滴墨在书页上开出一朵不可复制的小花，林恩日后每次翻到那一朵都会停止呼吸一拍。
- 若林恩选择不在最后一刻抓住羽毛笔的手，则羽毛笔以完整的笔形退场而不是被拉扯得残缺，但林恩要承受没有握住最后那一寸握感的空。
- 若林恩主动把某段自己在废墟里偷偷写下的句子递给羽毛笔作为《狸猫书》的引子，则这本书从此既有羽毛笔的笔锋也有他的体温。
- 若林恩让梦境里的灯不要在他醒来时立刻全部熄灭，则他在倒计时般的一盏盏熄灭中有时间依次向每一盏道别，每一盏熄灭都是一次真实的哀悼。
- 若林恩主动把小小金发一缕放在《狸猫书》末页作为书签，则未来他沿左左未来坐标翻开这本书时，金发会从那一页给一个回家的路标。
- 若林恩在梦境褪色前主动在某段墙上刻一个不能被抹去的林字，则那一个字成为羽毛笔退场后梦境里第一个不变的东西。
- 若林恩允许羽毛笔在退场前亲眼看一次他留下的日记，则羽毛笔知道他真正想要记住的是什么，退场时视线不再停留。
- 若林恩主动告诉羽毛笔「你已经是我的家人」，则羽毛笔在退场之前获得一个身份而非工具的位置，它的消散不再是无名燃烧。
- 若林恩在《狸猫书》写完的那一刻主动亲一次封面，则那一道温度被羽毛笔收进最后一页，成为它在无序中仍能留着的一团火。
- 若林恩在梦境快要结束时主动朝某个曾经共饮的方向举一次空杯，则那个姿势被梦境记录为一种庆典的礼节，未来他独自面对时间长河时还可以再用。
- 若林恩主动在羽毛笔退场之前问一句「我可以叫你什么名字」，则羽毛笔被赋予一个过去从未使用过的名字，那个名字成为他日后吟咏的私语。
- 若林恩在羽毛笔让他醒来时主动请求「请让我再多看一眼」，则梦境为他延长一秒，那一秒里他能看见羽毛笔的最后一缕轮廓线。
- 若林恩让羽毛笔把他醒来时第一个会看到的场景提前布置好，则他睁开眼时不会因刺眼而立刻流泪，那一眼里有左左未来坐标里一段温柔暗示。
- 若林恩主动用黑火在《狸猫书》末页封一层不会被抹去的蜡，则这本书能够挺过未来任何的火焰与水，左左未来坐标永不会在外力下消失。
- 若林恩在最后一刻允许羽毛笔以未被观测的方式消散，则羽毛笔不再被哀悼所绊，能以最完整的方式退场，但林恩从此再也无法在记忆中找到它的具体消散轨迹。
- 若林恩主动在梦境里留下一张他没写名字的纸条放在桌上，则那张纸条在他醒来时仍然在桌面上，提醒他这段梦境的一部分曾真实到过他的房间。
