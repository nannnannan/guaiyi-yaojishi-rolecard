# E607·主母深夜长谈·if线

- 若林恩在开场时不唤「主母」而唤其名,则两人关系从「母子/师生」切换为「平辈」,主母拒绝的立场更硬,后续拥抱的转折更戏剧化。
- 若林恩决定不当场变出酒水而是让左左送来,则她必须直面女儿送的酒,那段「倒酒她从未有过」的温柔被改为「我们一起收」,但私密感大幅降低。
- 若林恩主动在洒酒祭奠时选择不收回而让酒渗入地板,则主母的怒意不被消解,两人之间多一段持久的礼仪冲突印记。
- 若林恩把「我还想再解一下」换成「我想抱你一会儿」,则强迫段被直接跳过,主母的一巴掌未发生,后续的自愿结合成为双方约定而非意外发酵。
- 若林恩选择在主母掌掴后失神道歉但坚持再次靠近,则主母的二连击出现,这段关系被定格为「他不能触碰她」,金羽交付的时机被无限推迟。
- 若林恩主动在主母垂泪前伸手帮她拭泪,则两人之间的「强者/被保护者」界限被重新划定,主母可能更早说出「黑夜城是你的」。
- 若林恩让左左在关键时刻闯入大殿,则整场私密对话被中断,主母和林恩的肉体关系曝光,但「避风港」的定位被改写。
- 若林恩决定不让林恩霸道吻主母而是等她主动,则强迫段消失,「一巴掌」的记忆点被删除,但主母「主动吻」的独特性不再突出。
- 若林恩主动在主母说出「黑夜城是你的」之后追加一句「那你也是我的」,则所有权宣示被明确化,后续任何林恩的犹豫都会被这句契约绑住。
- 若林恩选择在主母交付金羽时亲手接过并收入系统空间最深处,则金羽成为「最高密级道具」,但后续他拿出羽毛的频率被降低。
- 若林恩让主母在这段结束后立刻离开神殿回黑夜城角落,则两人余韵被缩短,后续她「随时可以做避风港」的承诺被空间距离稀释。
- 若林恩决定不让主母提及「吸血鬼血娃」的旧梗,则那段轻松插科被删除,长谈的哀伤浓度更高。
- 若林恩把「那就复活我们」改成「我会永远陪在你身边」,则主母对林恩的期望从「强者复活」转为「陪伴至死」,她的主母身份更柔情。
- 若林恩主动在主母垂泪时以三位一体之力轻轻镇压她的情绪波动,则她的悲伤被压制,但「她不让他看见软弱」的尊严得到技术保全。
- 若林恩选择在性行为中让主母主导节奏,则她的「让女人身份」更突出,但林恩作为领袖的失控感被缩小。
- 若林恩让银幻在门外偶遇主母,则她得到「主母与林恩有亲密关系」的确认,但她不会外传,未来的副指挥官层级多一层沉默同盟。
- 若林恩决定不让金羽交付发生而改由喵喵叼来一根主母掉落的羽毛,则纪念品来源变成随机,但主母「送给你」的郑重感消失。
- 若林恩主动在主母说「如果你累了就再来这里吧」时回答「我会天天来」,则她的避风港义务被人为加重,但她本人的压力更大。
- 若林恩选择不让长谈涉及「复活死者」的话题而专注当下,则整场对话更轻盈,但林恩「必须变强」的核心驱动力被稀释。
- 若林恩让小丑在殿外偷听,则他得知了主母与林恩的关系,但他不会外传,而是在下一次会议上多看主母一眼。
- 若林恩决定不让主母主动吻他而是他一直不放开,则主母的主动性被压抑,但她的「我不要做负担」的心境更真实。
- 若林恩选择在结束时对主母说一句「我会让所有人活着回来」,则他的决心被绑定在「不死」上,后续任何战斗失败都会让他更崩溃。
- 若林恩让欲望母树在午夜突然撞门而入,则三人同处一室的尴尬画面出现,主母的「圣洁主母」面具破功,但氛围可能更混乱。
- 若林恩主动在主母提到「我们所有人都是」时同时看向左左的方向,则「家人」的范围被扩大,左左与主母之间的关系可能产生微妙张力。
