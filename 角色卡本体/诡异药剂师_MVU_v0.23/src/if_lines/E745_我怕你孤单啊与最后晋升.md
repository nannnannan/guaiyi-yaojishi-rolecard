# E745·我怕你孤单啊与最后晋升·if线

- 若林恩在进入圣所前对主母（自缚天使）再多看一眼，则他会提前捕捉到她指尖那丝已经预备好的决绝，在步入王座时多留一份戒备。
- 若林恩在踏上王座前主动问艾雯一句「你为什么今天不敢看我的眼睛」，则艾雯的谎言会提前半拍出现裂纹，但最终仍会咬牙将锁链扣下。
- 若林恩在锁链自王座升起的第一秒便以黑火反击，则圣所内壁会被烧出一道焦痕，艾雯会被震退吐血，但三叉戟仍会按原计划将他强行钉回王座。
- 若林恩在发觉被算计时不怒吼质问，而是平静地看着艾雯说「这是你的决定吗」，则艾雯在走出圣所大门时会当场跪倒痛哭失声，差点失去主持大局的力气。
- 若林恩在被锁链捆缚的瞬间强行分出一缕黑火缠在艾雯手腕上，则艾雯此后每一次调兵遣将都能感受到他滚烫的脉搏，也在E748忏悔时多一分锥心之痛。
- 若林恩在主母说出「我怕你孤单啊」时隔着圣所大门回应一句「我更怕你们不在」，则主母在王庭阶前绽放赴死时，嘴角会多噙着一抹听见他回答的微笑。
- 若林恩在三叉戟离手反镇自身的刹那，没有强行争夺控制权而是顺势留下一道守护烙印在戟尖，则主母与银色幻想日后握戟迎敌时，手心会多一层免受反噬的暗金护膜。
- 若林恩选择顺从地闭上眼不再挣扎，任由锁链穿入琵琶骨，则艾雯不必动用最酷烈的灵魂禁锢术，林恩在沉眠中的神魂撕裂感会减轻三分。
- 若林恩在被封入王座前最后看了一眼羽毛笔的方向，则羽毛笔在赶往命运之境的途中会突然心口一痛，回头望向圣所紧闭的大门久久无法迈步。
- 若林恩在锁链合拢的瞬间将自己仅存的一点清明化作传音送给外城的船长与银色幻想，则两位刚在天际完成晋升的神王会在出征前收到王最后的嘱托。
- 若林恩在被三叉戟镇压时强行记下锁链上每一枚符文的走向，则他在E757从深层梦境苏醒轰碎锁链时，破封速度会快上整整三息。
- 若林恩在主母立于圣所门外低语时，用王座共鸣轻轻震动地面回应她，则主母会知道自己的孩子听懂了这份沉重如山的母爱，转身走向王宫寝殿时步伐更加从容。
- 若林恩在艾雯宣布「用无数生命与绝望助他完成最后晋升」的残酷计划时，拼尽全力嘶吼出一声「停下」，则圣所穹顶的晶石会应声炸裂，成为他不曾默许这场献祭的铁证。
- 若林恩在天际亮起船长与银色幻想双双晋升神王的璀璨光柱时，分出一缕王座气运注入那两道光柱之中，则两位神王的本源根基会更加稳固，在随后数日的血战中多斩杀数头高阶堕落者。
- 若林恩在被锁死于罪恶王座的最后一瞬，将自己对同伴们的眷恋全部压缩进心脏最深处，则无论外在的黑火如何被绝望催谷暴涨，他心底最核心的人性火种始终未曾熄灭。
- 若林恩在艾雯转身欲走时，用被锁链穿透的手指死死扣住王座扶手直至指骨寸断，则那串滴落在王座台阶上的金色神血会在E748艾雯跪地时直接烫伤她的膝盖。
- 若林恩在沉入黑暗前试图调动黑夜城大阵反锁圣所大门以阻止众人出战，则艾雯不得不提前引爆一枚备用的神王信物强行截断大阵，导致她双鬓在当日便染上霜白。
- 若林恩在感知到主母将她自己的天使本源与圣所外层结界相连时，顺着那道连接逆向送去一缕温养神魂的药力，则主母在E747苏醒时神智会格外澄澈，毫无迟滞地披挂上阵。
- 若林恩在意识被彻底拖入深渊前，死死盯住三叉戟上属于自己的纹章，则那柄神兵在镇压他的同时也会不断悲鸣，直到主母将它拔起迎战魇魔之王才重归铮鸣。
- 若林恩在听见艾雯沙哑着声音说出「这是唯一的办法」时，没有再骂她背叛，而是闭上眼落下一滴滚烫的血泪，则艾雯此生直到灵魂燃尽都再也无法原谅自己。
- 若林恩在被封印的剧痛中仍不忘将一丝守护神念投向幸福之家孤儿院，则夏娃与孩子们在随后数日黑潮压境的恐慌中，夜里依然能做上一场安稳的好梦。
- 若林恩在锁链彻底封死五感前，将外城那两道新晋神王的光辉牢牢印在视网膜上，则他在漫长黑暗的潜意识煎熬中，始终记得还有人正替他撑着这片摇摇欲坠的天空。

- 若林恩在圣所巨门轰然合拢的最后一线光明里，朝着门外所有人的方向轻轻张了张嘴却未发出声，则守在门外的艾雯与主母都会在心底反复描摹他那句未说完的道别。
