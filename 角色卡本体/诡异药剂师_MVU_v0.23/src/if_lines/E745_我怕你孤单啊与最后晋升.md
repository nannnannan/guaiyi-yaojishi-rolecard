# E745·我怕你孤单啊与最后晋升·if线

- 若林恩在艾雯挣开他的手大步离开时追上去抓住他,则艾雯会停下,但他没转身,他肩膀在抖,这是两人最后一次肢体接触。
- 若林恩在喊「我只牺牲我自己一个人」前加一句「你听见了吗大哥」,则艾雯会停下脚步但没回头,他喉咙里滚出「我听见了,弟弟」,这是他最后一次叫林恩「弟弟」。
- 若林恩没有喊而是沉默目送艾雯离开,则事件沿主线推进但林恩心口多一道「未说出的话」。
- 若林恩在主母挥拳袭向艾雯时主动现身挡在中间,则主母的拳头会停在林恩鼻尖一寸处,这是主母唯一一次在林恩面前收手。
- 若林恩在主母一拳把艾雯打倒在地时只是旁观,则主母会连打三拳才停下,艾雯挨打画面会成为林恩在王座上反复回放的「愧疚档案」。
- 若林恩在主母问「你到底隐瞒了什么」之前主动开口「我也在瞒你」,则两位兄弟同时成为「骗子」,主母对信任的定义从此崩塌。
- 若林恩在主母说「你不是伤心于他会死」时主动点头承认,则艾雯会第一次被林恩当面戳穿,主母会直接瘫坐在地。
- 若林恩在主母晕倒时自己伸手扶住她,则主母醒来第一眼看见的是林恩,她眼底阴霾会永久刻入「林恩知情」一行,后续她在 E754 挥剑时心里带着这根刺。
- 若林恩在艾雯说「这是罪啊」时回应「这罪我替你分一半」,则艾雯会被林恩拉到同一立场,他会沉默很久说「不许」,但他内心把这句话刻进「骗子职责」的背面。
- 若林恩在艾雯抱起主母时接过她的身体自己抱,则艾雯会愣住一秒然后松手,后续两人之间形成「共犯交接」,黑夜城的命运从「他瞒我」变成「我们瞒所有人」。
- 若林恩在登临王座前去找银色幻想对她说「我走后黑夜城交给你」,则银色幻想会沉默跪下,这是她唯一一次单膝下跪,后续她在 E754 毁传送门时想起这个跪。
- 若林恩在登临王座前去找船长对他说「喝最后一顿」,则两人喝到一半船长摔碎杯子说「别说什么最后」,后续船长在 E753 守内城时一直在心里接这个话。
- 若林恩在登临王座前去找人偶家交代「丝线不能断」,则人偶家第一次用丝线主动缠住他手腕一下又松开,后续她在 E753 拉船长残躯时想到这一缠。
- 若林恩在登临王座前去找小丑告别,则小丑会把八音盒里第二把钥匙塞给他,这是等价于「小丑在场」的陪伴路径。
- 若林恩在登临王座前去找主母对她说「下辈子还做你儿子」,则主母会呆立很久然后抱住他,后续她在 E754 留守王庭时心里反复抱这一下。
- 若林恩在登临王座前去看睡眠中的纱奈儿并对她说「等我」,则纱奈儿在睡梦中会攥住被角,后续整个 S97 她都梦见这个「等」字。
- 若林恩在登临王座前让左左坐在他肩上一起跨进圣堂,则左左会沉默抱紧他的脖子,后续她在所有「林恩离开」场景里都会重新坐这个位置。
- 若林恩在登临王座前独自在黑夜城最高塔上站了一夜,则他会看见最后一场星空,后续信徒仰望天空时其实都在和他站同一片夜。
- 若林恩在登临王座前把「我怕你孤单啊」这句话录进八音盒里留给艾雯,则艾雯撑不住时会偷听这一句,他的「骗子职责」会在这一句里被反复刺穿。
- 若林恩在坐上王座那一秒回头看了一眼黑夜城全景,则他会看见主母站在最远那座塔上,后续林恩在黑火中闭上眼前最后看到的是她。
- 若林恩决定不让任何同伴来送他登临王座,则圣堂大门外会聚集一整支沉默的队伍,王座黑火从这一刻起多一缕「门外守夜」属性。
- 若林恩在坐上王座瞬间向全域信徒发了一句「等我」,则这一句话会传遍每一个灵魂,后续 E747 噩梦柱落下时亿万信徒心里默念的就是这一句。
- 若林恩在登临前夜亲手给艾雯写了一封只有一句的信「我知道了,大哥」,则艾雯会在接到信后跪地痛哭一夜,后续 E748 坦白时直接把这封信举在林恩面前。
- 若林恩在黑火点燃瞬间主动呼唤织梦名字,则他会听见一缕她的叹息,这一缕叹息成为他整个 S97 在黑火中最稳定的支撑点。
- 若林恩在登临王座前最后见一面小丑并让他永远不要回来,则小丑会拒绝,后续 E751 小丑仍然杀回战场,但他带着「我违抗了王」的印记。
- 若林恩在登上罪恶王座那一秒突然睁开眼最后一次看向艾雯方向,则艾雯会在远处同时抬头,这一秒成为后续所有「兄弟记忆」的最高位帧。
- 若林恩选择不让主母、左左、喵喵任何一人知道登临时点,则主母会冲到圣堂前站三天,左左彻夜不说话,喵喵在王座外守了七天七夜没合眼。
- 若林恩在登临王座前把罪恶王座的真名告诉主母并请她在最后时刻念给他听,则主母会记住这个名字,后续她在 E754 站在阶梯上时心里默念这个名字。
