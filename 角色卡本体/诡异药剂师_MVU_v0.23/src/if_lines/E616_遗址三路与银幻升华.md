# E616·遗址三路与银幻升华·if线

- 若林恩在检阅银色幻想的军队时提前布下一道「欲望压抑」的灵能屏障,则她会在偷袭瞬间察觉异常,亲密度大幅降低。
- 若林恩决定在偷袭银色幻想前赠送她一枚刻有「以M」印记的徽章,则她会当场脸红但会更主动配合,亲密段的成功率更高。
- 若林恩让血枢在巨像开出「山河幻境」前就插入一缕怀疑的灵能,则血枢会立即否决开门,「这不可能」的台词会提前。
- 若林恩在银幻升华时再多给她两年的虚拟时间,则她能再解析出一种战争机器,升华规模更大。
- 若林恩拒绝给银色幻想随意取用机械残骸的权限,改按需分配,则她的升华会被延缓,但「只可以这一次」的警告会更明确。
- 若林恩在山河幻境中让巨像先吸收些微灵能而非血肉精血,则她的血肉之躯会更早地适应「三位一体」的共鸣,锤炼周期缩短。
- 若林恩在结算银幻升华成果时公开说「你是我的骄傲」,则她会当场崩溃,后续的偷袭亲密度大打折扣。
- 若林恩让左左在检阅军队时先投降一次,则她能更放松地面对巨量的机械单位,对「只可以这一次」的期待会更低。
- 若林恩在偷袭银色幻想时另加一层「初诞者之力」的增幅,则她的反抗会更激烈,但屈服的快感更强。
- 若林恩决定在银幻升华后立即举行庆功宴,则她会忍住疲惫好好喝一顿,「只可以这一次」的条件更宽松。
- 若林恩让血枢在山河幻境中透露更多关于「灵魂塑造」的秘密,则巨像的锤炼会更精准,但血枢的吞噬欲望会更克制。
- 若林恩在偷袭银色幻想时突然告白「我只爱她」,则她会当场愣住后温情一笑,「刚才可是一直都在发出」的潜台词变成现实。
- 若林恩把「一月军令」的预警提前告诉银色幻想,则她会提前加速研究,升华后的战力会直接压过两位新半神。
- 若林恩在巨像的山河幻境里加一座半神雕像作为激励,则她的执念会更早地被点燃,突破界限的时刻更激动人心。
- 若林恩决定让银色幻想保留部分升华余力用于后续侦查,则她的战争机器会少建一些,但侦查能力会更精准。
- 若林恩在血枢与巨像的师徒初次见面时插一句「你也是外来者」,则巨像会当场奋起反抗,山河幻境的开课会被延迟数个钟。
- 若林恩在偷袭银色幻想时切换到一脸严肃的表情,则她会因反差而笑场,亲密段的必要性下降。
- 若林恩让血枢在巨像锤炼时加一个小惩罚机制,则她的血肉本能会更小心翼翼,但「绝不可与之同化」的戒律执行更严格。
- 若林恩在升华时向银色幻想承诺「下次带你看真正的战争」,则她会提前把一半精力用于备战,「只可以这一次」的承诺变得空洞。
- 若林恩决定让巨像在山河幻境外先独自尝试一次,则她的失败会更惨烈,但重装上阵时的意志更坚定。
- 若林恩把银色幻想的升华成果写成简报发给整个盟约,则「机械女王」的称号会更响亮,但隐私性更低。
- 若林恩偷袭银色幻想时让左左全程旁观,则她会当场要求加入,「只可以这一次」的范围会扩大到两人。
- 若林恩把「一月军令」延长到三个月,则三路的修炼周期会更合理,但织梦现身的时点会提前。
- 若林恩在银幻升华中让艾雯的灵魂法则也参与解析,则升华后的机械单位会带一丝灵性,战斗力大增。
