# E545·时间逆转与泰坦放逐·if线

- 若林恩让晶莹丝线绷直十字架时不做挣扎而是任自己被锁，则他实际上被钉住，时间逆转窗口从胸前握手变成更艰难的精神唤起。
- 若林恩把生命法则换成鲜血法则硬拉血线，则他能在反噬瞬间多撑一击，但容貌与「鲜血孽灵」气质重合险被识破。
- 若林恩连续空间折跃最终逃入内空间暂避，则「真战场」宣言被自我否定，人偶家无需唤泰坦，战神登台戏被取消。
- 若林恩让左左在钉十字架前先以左手的刀斩断身外一根丝线，则他能短暂保留行动自由度，时间逆转的代价略低。
- 若林恩在人偶家阵列禁咒火海神罚前先以空间法则将火海反弹，则威力转移到施法方，人偶家立刻陷入自伤被动。
- 若林恩胸前握手抓住时光前对左左明说「我要时间回溯」，则她不在事后恍惚，精神协同损耗减少。
- 若林恩让时间逆流只覆盖战场半径五百公里而非全部，则泰坦未退回原位但火海已归天，放逐窗口的形状被改写。
- 若林恩让记忆保留仅针对人偶家与巨像等知情人，则其他根源醒来后不知发生了什么，恐慌的蔓延更慢。
- 若林恩在递上「因为我想让你们记住」台词时主动揭露人偶家布置暗门的具体时点，则人偶家的反驳空间被压缩。
- 若林恩让心灵法则斩丝采用远程切断而非亲临心灵之海，则他保留实体战力，但人偶家有机率提前断线收场。
- 若林恩让傀儡1—4号在脱控后站到自己身后成护卫，则战场力量对比再加一组变化，人偶家的银剑近战更为被动。
- 若林恩在人偶家银剑近战时用力量法则一击轰飞银剑即收手不横刀咽喉，则「收服不杀」的界线更宽，但「披麻戴孝」台词无法出现。
- 若林恩拒绝说出「等我把事儿处理完了我再教你心灵法则」，则人偶家留在原地无法确定未来，败者情绪走更暗一线。
- 若林恩让世代更早坠落根源在时间逆转后的苏醒阶段立下保密誓约，则「被种心灵种子」情报被压下，恐慌由内部消化。
- 若林恩让星球其他不被控根源也目击到人偶家的丝线崩断，则傀儡师手法被全场公见，她后续更难再获信任。
- 若林恩让左左在泰坦砸来前抢先唤醒她的斩神一刀，则她能与林恩的空间裂口形成「推入加引力双击」，放逐的画面更壮观。
- 若林恩不撕空间口而改用更强力的死亡法则将泰坦暂时石化，则放逐改向封印，北海迷路的预期不成立。
- 若林恩让放逐落点不再混乱坐标而是锚定北海某孤岛，则泰坦在三五年内被明确找回的路径存在，「三五年迷路」预期重写。
- 若林恩让「大哥的力量和思维成反比」小声评论被自缚天使与巫神听见，则两人气急的对白加强，「太潦草」剧本更响亮。
- 若林恩在「还有谁不敢上前」句后追加一个具体挑战名额，则泰坦族后辈之外的另一位根源被迫上台，围猎剧本继续延伸。
- 若林恩在泰坦族后辈狂奔唤族长的路径上对后辈轻声说一句「让他自己来」，则后辈在族长面前立场被改写。
- 若林恩在放逐完成时让原子机械画一张潦草的「送到北海」标签贴在裂口，则喜剧效果从口头变成视觉，「太潦草」的指控实质化。
- 若林恩把时间逆转公开给所有黑夜城核心在那一夜密议，则「时间法则」从秘技变为黑夜城知识，后续人偶家与船长的通道更公开。
- 若林恩放逐泰坦后立刻奔赴心灵之海与人偶家深谈，则她在「僵立」的情绪定格被打破，支持线从此前开始。
