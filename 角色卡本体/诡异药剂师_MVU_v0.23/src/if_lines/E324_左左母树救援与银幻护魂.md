# E324·左左母树救援与银幻护魂·if线

- 若左左下水前先咬破自己手指滴一滴血在水潭边,则她激活一道血缘警示,母树嘴唇贴上来瞬间她被拉回半寸、理智之血灌入时间延长一秒。
- 若左左把私藏的精神药剂数量从三瓶减成一瓶灌入,则母树恢复清醒的时间拖后二十分钟,期间欲望波动失控扩大，左左被多舔舐了三十下。
- 若左左发现母树吻上来时不抗拒而是配合半秒再推开,则母树san值仅-15、恢复后羞耻度降低,但她眼神多一层无法解读的执念。
- 若左左在小金库里提前私藏两瓶【理智之血】,则第一瓶灌入后她能立刻再补一瓶巩固,母树欲望完全归零、不发生后面对林恩的怒火发泄。
- 若左左在恳求母树救林恩时改说「如果脑袋打不过小丑诅咒，那就用我的左手去救」,则母树怔住一秒、改以藤蔓直接托着左左投入甬道,救援时间缩短一半。
- 若林恩朝自己太阳窋开枪时改用两根苍白猎魔左轮同时射击,则撕魂效率翻倍、灵魂创伤降至 32%,但概率上弹孔精度偏差一发可能击穿脊椎。
- 若林恩在大叫时改用银色幻想的旧名而非「银色幻想」称呼她,则她的核心反应炉延长 0.3 秒输出,他灵魂稳定期多争取到两秒的呼吸空隙。
- 若林恩在结算落下瞬间命令系统「把时间的魂媒折成一半分给我和银幻」,则道具同步裂成两半、生效范围改变,系统额外奖励一枚【共鸣魂印】。
- 若林恩在意识濒临崩溃时不喝理智之血、改以自身蚀痕吞噬两枚黑颅币强行压制,则他多撑 30 秒但灵魂在 E325 多一条不可修复的永久损伤。
- 若林恩在撕离诅咒的最后一瞬朝甬道口喊一句「左左,别过来」,则左左被母树拽住、避开了瘟疫反扑,她左手的整洁度被保留。
- 若林恩在苏醒瞬间没受左萝鸭子坐的影响、直接翻掌把她拽下水潭,则她被闷了一口自然之泉,不再触发那条「母树没有诅咒的情况下他都涩起来了」吐槽现场。
- 若林恩睁眼时第一时间喊的是「银色幻想」而不是「左左」,则左左嘴上没说什么但背过身默默揪了把自己的左手背,E326 关系问题被她提早抛出。
- 若林恩偷灌自然之泉时一次只灌三瓦罐而非十瓦罐,则母树没有立即察觉,他安全带走少量泉水作为 E325 修复期的备用活水。
- 若林恩在母树用石头砸他眉心瞬间侧身躲过,则石子砸到水潭,母树脸红一瞬,气氛由荒谬转向清凉的尴尬,E326 的对话提前五分钟开始。
- 若林恩在母树说「你还是应该谢谢另外一个人」时立刻拔腿要去看望银幻,则他没听完三人组的胡闹,E325 直接进入严肃机体检查模式。
- 若林恩主动向母树交代自己偷灌泉水的事且当场交出九瓦罐,则她愤怒值-30、反而给了他一片自然之赐的树叶,E333 扎根黑夜城时该树叶被种下成活种根。
- 若林恩苏醒后立刻朝左左伸指检查「这是几」反向做图灵测试,则她炸毛大叫把他再摁回泉水泡十分钟,他额外吞入三口泉水的止痛效果。
- 若林恩在系统结算出现后立刻问「时间的魂媒是否可以分段使用」,则系统提示「一次使用」但他仍把这句话记入笔记本,E334 时他才会回忆起这个限制。
- 若林恩在恬不知耻地凑过去吻左萝前先用左手按在她的小头顶固定,则她的拳头擦过他耳侧而非捣入脸中央,他压力伤害减半但左左后续赌气一小时。
- 若林恩在甬道尽头把银色幻想机体移到泉水前,则她的损坏机体接受泉水浸润三个小时,血肉瘟疫蔓延速度被放缓、E325 的瘟疫剥离工作减半。
