# E664·尘封相册与重归黑夜城·if线

- 若林恩在翻相册到「严师头带第三百次抄书留念」那张时把照片单独抽出来揣进怀里，则法师塔外的苍蓝天空在那一瞬间落了一滴不易察觉的雨，画家在远处第一次对他放下一段执念。
- 若林恩翻相册时不小心碰掉其中一张滑落床底，则他弯腰去捡时第一次发现床板下还有一个更小的暗格，里面可能藏着更深的往日，但都被他主动选择不再打开。
- 若林恩合上相册时指尖轻轻摩挲着封皮三秒再放回，则木箱里某样东西的位置似乎被这种温度重新温过，他下次再来时某样东西的气味会不一样。
- 若林恩在二楼少女闺房里静静坐了半小时什么也不动，则法师塔的一楼摇椅自己摇了三十下，画家在天外某处被迫重新估计她对他的情感投放。
- 若林恩在衣柜前伸手摸了摸其中一件蓝色法师裙又轻轻合上门，则法师塔二层某处多年未曾动过的某物被勾动了一缕真灵，「严师」那道头带下一行小字隐约出现。
- 若林恩顺手把画册中「呲牙笑抱男生脖子比Y」那张塞到法袍内袋当护身符，则他离开苍蓝世界时脚步比进来时更稳，他的「初诞者之力+三位一体」的整合度添一分青涩的火焰。
- 若林恩面对法师塔大吼「你到底把空间神格藏哪了」时用手指指向苍穹外某个方位、字字准确，则画家遥遥主动首次出现在他的感知里递来一段视讯「乖、别逼我」。
- 若林恩离开前在篱笆小院门口朝法师塔方向郑重一拜，则他在拜下去的瞬间获得了一丝从画家身上派生出来的「万物亲和」种子，这枚种子会在 E666 撕开外壁时救他一命。
- 若林恩把床角那只木箱整个搬回系统空间带走，则画家对此并不阻拦反而在他合上门时嘴角浮现笑意，他此行获得了一件意想不到的「她的一部分」，后续 E667 抓神格时她在他眼中更有人性。
- 若林恩临走前用初诞者之力在法师塔外一棵小树上留下一道「林恩到此一游」的时间烙印，则画家遥遥感应到后罕见地失笑出声，「下次来我给你讲一个没人听过的故事」的许诺随之外放。
- 若林恩不需要康斯坦丁巨船接引、自己直接折跃回黑夜城，则他在黑夜城主岛外虚空出现时引发一次小型警报，康斯坦丁的魂火被吓了一跳，跪迎场面依然成立但少一分从容。
- 若林恩抵达黑夜城时不再沉默而是放声宣告「你们的王回来了、跟我走」，则举械齐喝的热烈回应里多一层「他要去哪我就去哪」的决绝，赴汤蹈火的誓言彻底定型。
- 若林恩面对跪迎的军团少有地说出「你们先起来，我不是你们的王，我是你们的人」，则全场的笑与原定的哈哈大笑有微妙的差别，许多人第一次意识到他确实没在演戏。
- 若林恩分发神格时直接说出「这些是给你们保命用的、不是修神位的、神界那次我自去」，则场面先是一静、随后自缚天使第一个哭出声，此后没人再敢提「跟教官一起去」的请战。
- 若林恩在分发神格时单独把一枚适合喵喵的飞在空中落在她额头、当众宣布「这枚归你、不许推三阻四」，则喵喵的尾巴举得老高，小小眼睛发红，林恩在这里立下一道「不能漏下任何一人」的锚点。
- 若林恩对抓住准备讨神格的血族萝莉没有那么用力揍她而改为用袍袖扫扫她的头，则那只血萝第一次在人前没有哭腔、只乖乖把家当地契拿出来献出去，军团后续发展多一个隐藏的「她真的想加入」的信号。
- 若林恩专走访巫神头颅时向他低声说「帮我看着小小和喵喵」，则头颅的骷髅眼眶中魂火跳了一下低声应「老夫这条命早就该还你了」，至此黑夜城的「家人名单」被玩家再次扩编。
- 若林恩当着「您是唯一的王」的拥趸们再一次明确回绝「我不要这个称呼，叫我林恩」，则自缚天使深深看了他一眼后改口为「林大哥」，那个称号从此在军团的私下场合传开。
- 若林恩在走访小小和喵喵时分别送给她们一份来自画廊小院的糖果和一片相册里空白的纸，则两片空白在那一晚同步浮现出「画家」两字的影子，两个孩子在无意识中成为了盟友。
- 若林恩在主母面前承诺「我会回来把左左和巨像全都带回来」并把语调放得极缓，则主母手心那一刻死死抓着他的衣袖说了一句「别把我儿子弄丢了」，林恩自此背负一段他自己立下的母亲般重担。
