# E551·五百根源拉练·if线

- 若林恩在高塔顶把法则轮盘炸向城外根源营地之前先炸一遍中央广场，则集结号被压缩在城区之内，「炮仗是谁放的」的互指更激烈，新入盟根源的敌意更先指向林恩本人而非死亡教会。
- 若林恩在落地问责前先用咒瞳扫一遍荒原上的几百根源小团体，则他对「组织分明、一盘散沙」的判断多一条像素级底稿，分组恶意搭配的精准度被他自己看见。
- 若林恩落地后刻意省略「不想打就和我打，你们选一个」的选项，仅淡淡说「继续罚」，则双方宿敌互殴推迟半刻仍被迫启动，但怨气在十六小时内累积得更厚。
- 若林恩在宿敌互殴全程不下场治愈任何一方，则死亡教会当日大幅减员，惩戒从「打到满意」退化为单方面屠杀，拉练名义崩塌。
- 若林恩只治愈败方而不修复死伤双方现场尸位，则两阵营带着各自的死者名单继续拉练，「下一次起义」的燃料被悄悄加深。
- 若林恩在双方默契暴起指向他时不迎战而是当场解散今日训练，则「玩我们」的怒吼悬空，次日城门不到百人集合，神灵建军整体被推后。
- 若林恩在城外指令里附加「谁跑得最慢今晚单独对我一场」，则速度型根源全员当场抬轿带落后者，一人不过全体罚的口径从第一天起就被击穿。
- 若林恩把跑圈指标从「今天三千五百圈」直接拉到五千圈，则第一日就触发上百根源混战，「撂挑子→军团协作」的曲线被压平。
- 若林恩在搬山规则里允许力量型同时多扛两人份山峰而不计入本人指标，则力量根源渐成本次拉练的隐藏猪脚，速度根源的反叛情绪不再点向协作。
- 若林恩把「一人不过全体罚」改成「最后一名单独罚」，则军团一词逆向退化回各自练各自的，跑圈与搬山两阶段都不再产生「取决最后一名不是第一名」的共识句。
- 若林恩在第三次大起义镇压后临时把罚则加码成「关进心灵之海五百载」，则退盟人数骤增，攻击整场拉练的话语从内部倒灌攻击到他与船长的同盟。
- 若林恩刻意不让速度型根源主动带队，反其道让力量型逐日点名，则「高速列车」画面延后半个月形成，军团节奏完全由力量根源掌握，速度根源反噬明显。
- 若林恩在划分三人一组时刻意把星轨拆出原二次坠落团体但与之配两名理念契合者，则「刻意制造矛盾」的设计被稀释，星轨组的领跑位置更稳。
- 若林恩在分组名册上故意把水火元素之主剔除恶意组合，则「冰火两重天」的赛制气氛组消失，战报节奏整体顺一档，但第二出线组因此失去看点。
- 若林恩在公布「积分前十小组授法则」的同时先把第一梦境布置成极简单的纸关，则前十个有效积分被动稀释，残酷梦境战报的公信力一夜崩塌。
- 若林恩在积分赛中某次梦境准备里悄悄收走主宇宙的标记素材，则「回到主宇宙」的情绪不在梦境里被持续搅动，「你们是一个军团」的口号对老根源们更冷。
- 若林恩在船长巨船分批投入前只送三组梦境小队一手，则三界狂暴梦境侧的血肉扩张不足，积分板倒映的战况更像内部演练而非主宇宙推演。
- 若林恩在积分赛期间拒绝把老者临时跌落那一条计入小组分，则评分显得公正拘谨，「六十七组」后来的高分反而走得更快。
- 若林恩主动邀请艾雯或银色幻想现场督导且不让她们只托文件，则「冷峻教官」人设被稀释一半，黑袍的孤绝地位被改成联合领队。
- 若林恩把「与黑袍共进晚餐／教授法则之道」的奖励口径临时改写为「由船长代授」，则梦境赛后个人唯美主义留痕锐减，本就精瘦的师徒线被进一步淡化。
- 若林恩在船长递上无限页公务文件时当场把薄本丢回去不接，则林恩躲公务的人设未能立住，船长腿色更黑，后续他在梦境教官席的坐席从不稳移到反差人设。
- 若林恩在听完全场蠕动之神问母星的回答后未鼓掌允许暂休，则共同家园执念组的出线址再延一日，「授法则」被推迟，奖赏落地时点改由水火组预先到达。
- 若林恩在第二出线组公布时没有提及「猜拳轮庄」，则战争之王那个颇为滑稽的默契生成法被藏于内部，事后根源们从外场听不到它的运作机理。
- 若林恩利用拉练本身悄悄为自己猎取法则样本，则拉练结束后他的个人境界突破叙事与五百根源建立共同伙伴的集体叙事脱节，主语背离。
- 若林恩判定全场无动于衷时擅自提前抽走全部血腥梦境，则心灵之海积分赛从「你死我活的血火校验」退化为单纯任务式演练，对抗性显著下降。
- 若林恩主动要求从头到尾每日进度向船长简报，则跑圈/搬山/梦境积分赛的全部数据成为船长手中的不可争辩材料，他本人「自决落地」的立意被洗白成另一个人背书。
