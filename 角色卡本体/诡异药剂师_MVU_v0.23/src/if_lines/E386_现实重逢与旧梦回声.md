# E386·现实重逢与旧梦回声·if线

- 若林恩先私下打开木盒把紫裙布偶藏进系统空间，则花园里她见到他时手里空空，她的「我就是梦中的那个女孩」断言多一道证据缺口，两人关系信任被系统以「信物不明」标记。
- 若林恩在会面开场就送她一枚夫妻对戒作为梦中婚礼的信物延伸，则她的答复从「只是朋友」转为「你说这是婚姻吗」，定位当场急速偏离青春期定性。
- 若林恩主动问她「你是不是记得我小时候」，则她望着他半晌不语、最后简单点头并说「我抱着你喝过奶」，「重生」证词成立但只是她梦中察觉的痕迹。
- 若林恩在会面中主动递上一本他正式写就的《梦境日子纪实》，则她按着页序读完一遍再一遍，把它放在胸口微笑说「这是我全部的生活」，信物优先级升级。
- 若林恩反向拒绝承认梦中存在的自己，只以「我是来探望新人的客人」的身份接触，则她的定位无法建立，她转头望向人偶夫人和艾雯并嘟囔「他不认识我了」。
- 若林恩故意维持高冷并仅以「我现在有更重要的工作」回绝，则她默默背身离开一阵，事后再递上一块刻着「他不会来」的字牌以告别。
- 若林恩强行走亲密路线在她面前吻她一下，则她愣一会儿后侧身推开并说「我只是你梦里的孩子」，信任降级且她与他的互动被新生框架重写。
- 若林恩强行让她在众人面前分享梦中生活的每个细节，则她拒绝但暗中拉住他的手告诉他「这只是你和我才知道的事」，她的低调性格被强化。
- 若林恩问她是否要继承血娃娃所在的小队职责以继续留在主城，则她下意识望向艾雯以及人偶家，并后推出她想要一笔「不被利用的自由时间」的请求。
- 若林恩反向资助她去新大陆，把梦中的生活复制到现实，则她带着信物离开并接受，离别后的黑弦月定位变形为「现实远行的她」。
- 若林恩让左左代替他送杯子蛋糕做梦中她最爱的点心，则左左敲开门后出现一次「她不认识我」的惊讶，并因为愤怒道「你不是那个哥哥」。
- 若林恩反向教学她咒瞳使用方法想组建梦境小队，则她被初次强光灼伤一只眼睛，诊疗记录中增加「初次运瞳事故」。
- 若林恩拒绝对她梦中句子「你说让我去未来等你，我来了」做任何识别，则她对他的定位立即降到「陌生人」，她主动走向人偶家以寻求接纳。
- 若林恩在做宽慰阶段向她告白他这一生爱她，则她以惊讶回望并以柔和但坚定的方式拒绝，她说「我只是梦中被你陪伴的孩子，请別把定位再改」。
- 若林恩动员艾雯在场以了解更多黑弦月幼儿时期的秘密，则艾雯轻声说出「她幼时被老人家抽过腿」，黑弦月立刻垂首并出声「请不要再说」。
