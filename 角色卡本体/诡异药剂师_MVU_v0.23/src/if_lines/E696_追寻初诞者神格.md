# E696·追寻初诞者神格·if线

- 若林恩在回应画家化身前先以心声对银色太阳追一句「她可信吗」，则银色太阳当众以古语替那色彩作简短证词，画家在镜像挑明前多停顿一秒，后续情报更受信任。
- 若林恩在画家面前直言问她是不是把自己「当棋子」，则她不会反驳，只在临消散前轻声一笑，林恩恨意栏里多一行小字「她承认了」。
- 若林恩主动把自己斩杀镜面之魇的长矛残迹掷向色彩化身作等价交换，则残迹被色彩当场吃掉，画家报道镜魔与兽王的时限时额外补一句「我也可借这一缕记住你的杀气」。
- 若林恩反向追问「真理神格怎么样处理最有用」，则画家会主动提示真理已经湮灭，但留下一句「你不要再想着复活他」，跳过主宇宙档案里的真理一段。
- 若林恩主动要求自己听完情报后立刻离开战场、不再返回原战区，则追寻本源的时长被压到极短，本源将不得不以更快节奏暴露自己在他视野里，但清剿留守魇的安排只能交给神疆自动执行。
- 若林恩主动提出「先带我去石柱群看一眼那些信标」，则他能在画卷消散前亲眼看一眼七十二柱，会在其中一根上读出「镜」字，但消耗他本源搜索时效的一半。
- 若林恩主动问「如果你真那么强为何不亲自下场」，则画家沉默一拍后首次答「因为这个世界不能再多一个我了」，林恩对她的「只有一个容器」底细有更直观理解。
- 若林恩主动把自己三位一体之力残余反过来涂在神疆表面，则画卷消散前会多扫他一眼并提醒一句「你撑不住了别再逞强」，最后补一句「游到本源去」。
- 若林恩主动要求画家把神界本源的位置写在他体内，则她会拒绝，但会以一缕混乱色彩在他眉心烧出一道「寻源指引」，他在风暴深处能直接感到金色昊阳所在方位。
- 若林恩主动调侃一句「最后这次帮我还是要还吗」，则她会在身形消散瞬间回一句「都在你未来那份账本上」，留下轻微不快。
- 若林恩改为回应「我会考虑」并刻意不立刻朝本源方向前进，则本源的风暴会在他前进路上先行聚合起来、主动现身，但林恩的多余停留会撞上漫游的梦魇余部。
- 若林恩在走向本源深处前主动先用神疆对在场留守梦魇展开大清洗，则他独自踏入风暴带时身后的神王界会被锁得密不透风，但他对本源的寻找被延后整段时间。
- 若林恩主动把匣子残留碎片一并塞进怀里才动身，则金色昊阳第一眼会以「已有画家碎片」的口吻发出更温和的声音，原本老者沧桑与少女青涩的语气转为同辈明亮的语气。
- 若林恩主动用「你作为初诞者神格还记得主宇宙的哪个名字」作问，则本源首次报出自身源于旧世界终末的瞬间，林恩会明白「它既是权柄也是故乡」。
- 若林恩主动问「吞噬你以后我会是什么样子」，则本源坦白回答「你就是主宇宙的私人领域，所有人的呼吸都系在你之手」。
- 若林恩表示「现在无法接受、想保留她作为兵器」，则本源会表态理解，并以大量法则为他凝聚「临时完全调用」十小时，作等价过渡；但吞噬的提议不会再次主动开口。
- 若林恩选择完全不深入追寻本源而返回原战场，触发变形条件：本源不被发现，后续「神王界决战」以林恩「未持本源」形态进行，防线构造全数改写。
- 若林恩主动朝本源那只金色昊阳倾诉紫罗兰大君旧事，则本源在长叹后给他一缕额外的旧世界回忆画面，他会短暂以渡鸦视角掠过旧世界终末的一角。
- 若林恩拒绝本源请求、转身离开，则触发变形条件：本源保持意志另觅他人，林恩失去至高权柄，下一步将面对未强化的魇王大军。
- 若林恩主动对银色太阳吐槽「她居然让我吃她」，则银色太阳会毫不客气地答「谁让你是最后一只渡鸦」，本源长声轻笑搅动风暴一圈。
- 若林恩主动追问为什么「魇会一次次复生」，则本源直接举旧世界例子，给他关于时间战争失败次数的具体轮廓，并借此警告「你也会失败很多次」。
- 若林恩在「请吞噬我」开口前主动说「这样吧——你先带我去外围看一眼战局」，则本源会带他以神王深度远观魇王、因果、兽王的围困，林恩对战局判断更清晰，但消耗他决策时间一刻。
