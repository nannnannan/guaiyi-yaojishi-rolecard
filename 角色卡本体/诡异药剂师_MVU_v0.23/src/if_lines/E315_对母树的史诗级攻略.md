# E315·对母树的史诗级攻略·if线

- 若林恩在踏入树干内部前先把夜医袍换成疫医祭祀款，则母树扫描到仪式感而非入侵者，警戒 -15，但攻略的气场比例下降一档。
- 若林恩主动在攻略前给左左配一段「待会我就要胡说八道了你别打断」，则她应允旁观并开局崇敬 +3，攻略结束后她多评一句「凑脑袋这回真撑住了场面」。
- 若林恩在「你就是想啪我」名场面前主动补一句「当然也是为了救你」，则她的愤怒飙至顶点但同时神魂颤动半秒，攻略进度瞬间+5，事件直奔收束。
- 若林恩把假面恶鬼论换成「我们都是孤独的树」，则母树空洞一拍，攻略进度 +3，但她对他的敌意里新增一条「恶魔会看人心」的可怖评估。
- 若林恩主动在攻略中放下单片眼镜凝视她十分钟不语，则她被长时间凝视逼得先开口，事件由林恩主导改为母树先崩溃。
- 若林恩让左左穿透树干给水潭那边送一朵虚拟花，则她的神性起身反应让攻略进度瞬+2，但被母树记录为「外魔幼体介入」告警，警戒 +5。
- 若林恩在攻略前激活海嗣面具戴在脸上，则她以「处理异类」标准迎战，攻略路径滑向恶堕路线 +10。
- 若林恩主动在攻略时承诺「我愿意把神性分你一半」，则她配合意愿 +20，但林恩此后永久失去一半神性存量，代价以神性池减半结算。
- 若林恩主动让攻略过程被左左广播给智脑，则智脑远程听到林恩的「史诗级攻略」全程，她对叛变可能性的预估上调一档，林恩获得一档抢劫契机。
- 若林恩主动要求「你只能为我一人唱呐」，则她拒绝妥协但以M驯化度 +30，她把「声音的圣洁」视作最后底线。
- 若林恩让左左伸手去碰树干外一条病变流质，则她被剧痛感扫过狂震，她大骂的同时意外给母树构成「我们是同盟」的旁证。
- 若林恩在「我平生最怕背叛」前补一句「所以我曾杀过你一次」，则她惊慌到防御机制疯狂激活，林恩被藤蔓拽倒，攻略进度反而上升 +5。
- 若林恩在攻略时改以讲故事般平静腔调，则她沉静状态拉长，攻略进度 +5，敌意同步 -15，她评估其为「魔头中的温柔刀」。
- 若林恩主动对她许诺「我保护你最后一刻不离弃」，则她几乎立即臣服，林恩承担一份沉重誓言债务，事件衍生成「不可中断的誓言线」。
- 若林恩主动让出一份死星结晶作为信物，则她收入的同时对策上调一档晶磁防御，林恩需用一道运算重启战术才能触及核心。
- 若林恩在三秒倒计时「一」喊出前主动再给一分钟，则她在最后一分钟里主动说出「我接受」，臣服主动度提升一档。
- 若林恩主动用水潭的水漱一口再吐出，则她对他的神性血脉被践踏产生剧烈怒火，事件脱离史诗攻略路线。
- 若林恩主动以树叶结尾作为攻略最终定位，则她反感知后疯狂反抗，林恩魅力类型被划为「生态洁癖」，攻略难度 +20。
- 若林恩让左左在系统空间敲窗唱和，则她与林恩同时开启喜剧对白，母树被这对活宝逗出第一次笑，攻略进度意外 +10。
- 若林恩主动把「你就是想啪我」改成「你就是想嫁我」，则她被瞬间炸穿防御，臣服进度拉满但同时她愤怒值顶峰，事件进入急速收束变形。
