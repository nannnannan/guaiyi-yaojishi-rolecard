# E748·对不起林恩我骗了你·if线

- 若林恩在艾雯独自推开沉重的圣所内门、满身血腥与疲惫地走到罪恶王座前跪下时，没有立刻怒吼而是死死盯住他苍白如纸的脸，则艾雯在开口前便会先呕出一口压抑已久的黑血。
- 若林恩在艾雯跪伏于地、颤声说出「对不起林恩，我骗了你……死的是所有的人」那一刻，拼尽全身力气扯动穿骨锁链，则飞溅出的金色神血会直接滴落在艾雯低垂的额角，滚烫如烙铁。
- 若林恩在听清「死的是所有的人」这句残酷真相后，于锁链与潜意识的囚笼中发出撕心裂肺的「我不愿意」的嘶吼，则整座圣所的石柱都会裂开蛛网般的缝隙，连门外的终焉黑潮都为之一滞。
- 若林恩在被迫承受万族生灵与前线将士战死后的绝望、看着漫天灵魂化作金色光雨汇入罪恶王座时，拒绝闭眼逃避而是强行看清每一道金光生前的面容，则他的神魂会在千刀万剐般的悲恸中淬炼出最纯粹的守护黑火。
- 若林恩在苗苗于命运之境中哭喊着扑向轮回神王之影、拼命拍打质问「为什么要这么对他」时，顺着两人之间的本命契约送去一缕微弱的安抚神念，则哭到力竭的苗苗会在倒地前感受到他掌心的温度。
- 若林恩在艾雯含泪抬起头、坦白从一开始就没有人打算在终焉之战中独活时，在潜意识里朝他怒喊「那谁来陪我」，则艾雯会苦笑着抓起王座台阶上的尘土按在胸口，低语「下辈子换我找你」。
- 若林恩在漫天阵亡者的灵魂金光涌入自己胸膛的瞬间，以王座最高权限将他们的痛苦与恐惧全部剥离并由自己一人吞下，则那些汇入王座的英灵都得以在温暖安宁的微光中沉睡。
- 若林恩在锁链勒入骨髓、试图强行打断这场以众生献祭促成的晋升仪式时，艾雯不得不将自己的本命神格直接按在阵眼上死死顶住，则林恩会清晰感受到兄长正在用最后的生命替他锁紧囚笼。
- 若林恩在潜意识的狂暴挣扎中，恍惚听见前线战死者化作金光前仍在高呼「愿吾王永生」，则他眼角流下的血泪会瞬间被黑火蒸干，从极致的悲愤化作极致的死寂与决绝。
- 若林恩在苗苗于命运之境哭得嗓音沙哑、手指都被轮回神王冰冷的残影震出血痕时，以王座黑火隔空替她裹住伤指，则轮回神王之影会沉默地低下头，任由那个女孩替林恩发泄所有的委屈。
- 若林恩在艾雯跪在王座前将外城一道道防线正在流血的战况毫无保留地坦白时，没有再试图震碎他的心脉，而是用颤抖的声音在心底问了一句「痛吗」，则艾雯原本挺直的脊梁会瞬间佝偻下去。
- 若林恩在无数灵魂金光如百川归海般灌入罪恶王座、强行将他的神格向第三阶段推举时，在每一缕金光上都刻下黑夜城的印记，则这亿万生灵的名字都成为了他神格中不可分割的骨血。
- 若林恩在愤怒嘶吼「我不愿意」的同时，拼命将一丝残存的治愈药力顺着灵魂通道逆向推回前线，则正在城头浴血死战的船长与泰坦等人会在力竭之际突然感到胸口涌起一股滚烫的暖流。
- 若林恩在艾雯磕下最后一个响头、准备留在王座旁燃尽自己最后一分灵魂陪他走完晋升之路时，用尽全力将锁链拽偏一寸指向圣所大门，则艾雯会读懂他「不准死在我看不见的地方」的执念。
- 若林恩在命运之境中的羽毛笔默默站在痛哭的苗苗身后、满头白发在虚空中无风自动时，向她的方向投去一道跨越维度的注视，则羽毛笔会闭上双眼，将织梦留下的最后火种护得更紧。
- 若林恩在感知到连外围星域那些素未谋面的普通士兵在战死时都将最后一缕信念化作金光投向圣所时，终于停止了徒劳的自残抗拒，昂起头任由那场沉重如星海的献祭洗礼全身。
- 若林恩在艾雯因为过度透支灵魂而跪在台阶上剧烈咳嗽、指缝间全是鲜血时，让王座底部的黑火收敛起灼人的锋芒化作温煦的暖意托住他的膝盖，则艾雯会在绝望中露出一丝孩童般的安心。
- 若林恩在听到轮回神王之影面对苗苗的哭打只留下一句「这是他唯一能活下去并战胜终焉的路」时，在王座上冷冷回应「我活下来不是为了当孤魂野鬼」，则他体内的第三阶段雏形会自行演化出重塑万物的生机暗纹。
- 若林恩在灵魂金光最密集的那一刻，突然在万千光点中认出了昔日曾受他救治的一名黑夜城老兵的残魂，则他会分出一缕王座黑火轻轻包裹住那枚光点，送入识海最深处妥善安放。
- 若林恩在艾雯伸出染血的双手握住贯穿他琵琶骨的锁链、以自身血肉为缓冲减轻他晋升时的法则反噬时，不再剧烈挣动锁链以免割裂艾雯的手掌，则两人之间的血顺着锁链彻底融为一处。
- 若林恩在潜意识深处对着那片正在被黑暗吞噬的星空立下血誓「凡今日为我而死者，来日我必向终焉百倍讨还」，则罪恶王座上方会凝聚出一顶由纯粹黑火与金色泪滴交织而成的荆棘王冠。
- 若林恩在苗苗哭倒在羽毛笔怀里、两人隔着命运之境的屏障遥望黑夜城圣所时，让她们手腕上的印记同时亮起三息温暖的金光，则两个女孩会明白无论变成什么样，她们的林恩依然在回应她们。
- 若林恩在完全接纳漫天灵魂金光、踏入第三阶段晋升最痛苦的蜕变期前，深深看了一眼跪在脚边的艾雯，则那一眼包含了愤怒、心疼与最终的宽恕，让艾雯在随后的灵魂燃烧中再无半点遗憾。
