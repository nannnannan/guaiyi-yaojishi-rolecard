# E748·对不起林恩我骗了你·if线

- 若林恩在艾雯开口承认「所有与你相连的灵魂都可能被黑火抽取」之前主动说「我早知道」,则艾雯会在那一刻彻底崩溃跪倒,这是他最后一次以「骗子」自我折磨的瞬间,后续他对林恩所有道歉都化为沉默。
- 若林恩听完后第一反应是抬手给艾雯一拳,则这一拳会成为两人之间唯一一次肢体冲突,艾雯不躲,他挨了这一拳,但他在挨打后眼里反而平静,后续「共谋」从这一拳开始。
- 若林恩听完后没有说话只是沉默,则艾雯会主动再补一句「你骂我吧」,林恩仍不骂,艾雯会第一次在王座前失声痛哭,主母在远处会把这一幕记入心底最疼的位置。
- 若林恩在听懂因果燃烧机制瞬间立刻尝试切断自己与主母的连接以保护她,则主母会第一时间感应到被切,她转身长吼他的名字,这一声会让整个王庭的信徒都听见,但她不会谅解这一刀。
- 若林恩反过来主动加固与主母、左左、喵喵的所有连接,则她们被黑火抽取的速度会加快,但林恩会知道每一滴从他爱的人身上流出的火,后续他在 E749 承受这些火时意识会精准到她们各自的名字。
- 若林恩在听完真相后第一句话是问「织梦当年知道吗」,则艾雯会沉默很久说「她知道」,林恩心里最后一道防线崩落,织梦的名字从此成为他最不敢触碰的刻痕。
- 若林恩主动以黑火把艾雯从因果网络中暂时屏蔽,则艾雯会拒绝,他说「我该是第一条」,林恩首次以王座之力强制推开他,后续 E749 两人各带一道「我亲手烧你/我亲手被你烧」的债。
- 若林恩让主母此时此刻听到真相,则她不会晕倒,她会走到王座前盯着林恩看很久,然后转身离开,背挺得极直,后续她在 E754 留守王庭时的背影对此夜完美对应。
- 若林恩让普通信徒此刻全部得知因果燃烧,则信仰帝国的表面秩序会崩塌又重建,「知情赴死」传统从这一刻成立。
- 若林恩决定让部分高层先知道部分真相,则高层会分裂成撑林恩与暗中切断王座两派,后续 E754 城破时两派会造成不同撤离路径。
- 若林恩在艾雯道歉后只说「闭嘴,继续烧」,则艾雯会听令执行完所有步骤,后续 S97 他再没说一句对不起,他的「骗子职责」从此剥离所有自辩。
- 若林恩主动灌一口烈酒并同时被燃烧,则他会边流血边笑,这一笑会成为 S97 所有同伴记忆中最具画面感的一帧。
- 若林恩在听懂后主动问「那织梦消散时有没有也这样被烧」,则艾雯会点头,这一知情会成为他后续所有「共情」场景的母版。
- 若林恩让艾雯把真相压成一枚金属牌交给他随身佩戴,则林恩身上从此多一块「知情牌」,后续 E754 听到城破时会低头看一眼。
- 若林恩独自在王座上把每一位相关者名字在心里默念一遍,则这份清单会成为 E749 燃烧时的「最后点名」,每个名字烧掉时他都会跟着断一根弦。
- 若林恩把自己对终焉的全部愤怒压成一缕黑火亲手还给艾雯,则艾雯会接下这缕火,后续每一次执行「骗子」工作时都会被这缕火烧一次。
- 若林恩反过来灌给艾雯一缕安慰之火说「我不怪你」,则艾雯会当场瘫倒在王座前,后续他对林恩的歉疚从「罪人」升格为「弟弟的债」。
- 若林恩让喵喵此刻跃上王座坐在他膝上一起听完艾雯的坦白,则喵喵会发出一声极低的呜咽,后续她对艾雯的态度从此改变。
- 若林恩让左左此刻出现并亲耳听到真相,则左左会第一次主动开口叫艾雯一声「大哥」,这一声会让艾雯的泪腺完全失控,后续他在 E749 燃烧时会反复默念这个称呼。
- 若林恩让黑夜城所有医院被告知真相以便选择,则医院会分成「知情燃烧」与「不知情燃烧」两派,两派的死亡表情会被永久记录。
- 若林恩主动把「我怕你孤单啊」这句话再次对艾雯说一次,则艾雯会痛哭失声,这是他接受到的最后一次温柔,后续 S97 每一次痛苦他都会回放这一句。
- 若林恩主动把自己灵魂撕开一小口看那些正在被抽取的连接,则他会亲眼看见亿万条丝线连向圣堂、医院、家族、同伴,这一画面会成为他作为「王」的最终定义。
- 若林恩在得知真相后坚持让艾雯再讲一遍直到林恩听腻,则艾雯会连续讲七次,第七次时林恩第一次伸手打断他,后续他们之间再没有任何语言上的「骗子与被骗」。
- 若林恩把母亲面前的真相也一并摊开,则母亲会第一次在主母与自缚天使面前跪倒在地,后续她在 E750 信仰城守城时每个决定都带着这份重量。
- 若林恩在得知自己将成为「唯一生还者」时突然笑了,则这一笑会让艾雯终生难忘,后续 S97 每一次绝望他都会想起这一笑作为反向鞭策。
