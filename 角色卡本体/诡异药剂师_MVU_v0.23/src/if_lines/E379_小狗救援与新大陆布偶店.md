# E379·小狗救援与新大陆布偶店·if线

- 若林恩在海关收贿那一秒主动记下贿赂金额与省略排查的台账差距，则地下世界善事档案里多一笔「系统性视而不见」的亲眼证据。
- 若林恩在小狗叼着腐朽钥匙串到笼子前那一秒主动鉴定钥匙串上的坠饰，则他发现那是同仓被囚者的草织手链，小狗曾被底层同伴喂养过。
- 若林恩在笼锁咔哒打开瞬间主动在她耳边用心声压一句「别怕」，则疫医气息被历史反弹，但她肩头抖动幅度在那半秒减小，档案里多一条「轻度干预尝试」。
- 若林恩在她被驮跳入海那一秒主动陪她一起落水，则他的视野被水雾糊住、记忆边界将他强制击退回黑堡床边，本轮下潜中断。
- 若林恩在黑皮肤男孩率先撞向水手瞬间主动记录冲撞的角度与力度，则档案里多一份旧世底层暴动力量样本。
- 若林恩在「通往自由的通路」形成瞬间主动清点暴动人数与前后顺位，则档案记下这是一场小规模自发冲撞、不是有组织的暴动。
- 若林恩在她濒临昏迷那一秒主动跟水草场梦景前行，则疫医档案里多一份「濒死舒缓幻景」副本样本。
- 若林恩在雪莉梦中笑着招手那一秒主动测量她脸上岁月的痕迹，则他发现这是投影中的雪莉、不是真实外界的她，深层执念的「重逢幻想」展开空间被锚定。
- 若林恩在小狗驮着她坠入海面那一秒主动测算浪差与时间，则疫医档案里多一条旧世火器射中水生动物样本记录。
- 若林恩在燧发弹斜上方贯穿小狗腹部瞬间主动记录弹道与冲击位置，则弹道学档案里加一条「旧世燧发枪对水面动物」命中公式。
- 若林恩在小狗舔她下巴那一秒主动把这一幕色调与湿度录入记忆，则疫医档案里多一条「离世亲近」触感样本，作为黑弦月深层执念的次级证据。
- 若林恩在她首次口齿清晰说出「会好起来的」那一秒主动记下她的语调与呼吸节奏，则档案里第一次确认她有整段语句能力、此前闭锁不是哑。
- 若林恩在翌日阳光小狗僵硬那一秒主动停下来不打扰她直面死亡，则疫医档案里多一条「片刻停留」的选择记录。
- 若林恩在她低低说「狗狗，太阳升起来了」那一秒主动记录这句话的颤抖幅度，则深层执念的「活着」一项首次在档案里加入「死讯认知后仍坚持说话」的样本。
- 若林恩在她离开垃圾场那一秒主动陪她走完雨夜泥泞的长度，则疫医档案里多一笔「废场纪实」的细节量。
- 若林恩在佝偻老人自我介绍「我年轻时当过一段时间外科医生」瞬间主动辨认他的发音与手部动作细节，则他第一次意识到这位施救者的细节与舞台工匠重合，档案里多一条「疫医旧世同道」线。
- 若林恩在老人拿出修补布偶那一秒主动比对布偶的新旧破口与缝合方向，则他发现裂缝缝合手法具备外科水平，改造者的身份伏笔被锚定。
- 若林恩在她无言沉默凝视老人时主动压一缕疫医气息落到她额前试图窥探她想法，则疫医气息被历史反弹，他听不到她的回应。
- 若林恩在她想问老人自己小狗下落但老人只先说「可能随垃圾清走」那一秒主动记住这个说法的含糊度，则档案里多一条「未直说的救她人意图」。
- 若林恩在她到垃圾场找尸体那一夜主动陪她去找，则他走完整夜的腐臭与断续犬吠，疫医档案里多一页「旧世底层纪实」。
- 若林恩在第七夜那一声错觉犬吠瞬间主动陪她转身，则他也看见那片空野，档案里多一笔「幻听一次」记录。
- 若林恩当场选择结束旧世接触退回现实，则疫医档案里关于小狗的真相与布偶店的修补始末被落定归档，黑弦月深层执念的「绝境温暖」一项首次有完整背景。
