# E391·渡鸦死亡与逼近的注视·if线

- 若林恩在吸收开始前与左左约定每十分钟一次强制唤醒，则他在腐败刚蔓延到耳际时被拉出，记忆侵蚀程度显著降低，但吸收总量只有原计划的三分之一。
- 若林恩在吸收过程中主动以咒瞳扫描尸骸灵魂结构，则他短暂读取到一段与「紫罗兰大君」相关的加密符文，该符文在他意识里留下无法解读的烙印。
- 若林恩在死亡片段播放时反向以心声高呼「我不是你」，则画面剧烈抖动，渡鸦的注视短暂转向他，一股冰冷的溯及力试图穿透他的意识防线。
- 若林恩让左左在吸收期间持续吟唱旧日歌谣以稳定他的精神，则她的歌声与他意识里的渡鸦记忆产生共鸣，他提前进入更深层的记忆区块，风险同步放大。
- 若林恩在吸收到 40% 时主动切断连接以保存实力，则他获得部分启蒙知识但缺失死亡真相，E392 的证据链出现无法弥补的缺口。
- 若林恩在腐败蔓延到颈部时仍未停止，则他的声带受到侵蚀，苏醒后声音变得沙哑，与林恩原声产生明显差异，左左一度认不出是他。
- 若林恩在吸收期间让左左以餐刀在外部刻画倒计时标记，则她每刻一笔都同步感受到他灵魂强度的波动，她的情绪被卷入其中，事后出现短暂的共情眩晕。
- 若林恩在死亡片段结束后反向向尸骸注入一缕自己的记忆，则尸骸微微颤动，一股陌生的情感回流，他短暂体验到渡鸦对某个存在的「眷恋」，情感来源不明。
- 若林恩在吸收结束后拒绝立即检查身体状态并选择继续深入，则他在上升途中突然咳出一口黑色血块，血块中掺着无法辨认的羽毛碎片。
- 若林恩在吸收期间让左左以系统空间隔离他的意识备份，则备份在吸收完成时自动激活，他获得一次「记忆回溯」的机会，但回溯画面带有明显失真。
- 若林恩在腐败出现时以血肉灾变强行修复受损组织，则修复速度与腐败速度持平，他暂时维持清醒但消耗的是未来的自愈潜力，E395 的血气觉醒被延迟。
- 若林恩在吸收期间让左左以初诞者之力包裹他的左手，则他的左手在吸收结束后微微发热，掌心浮现出一道与幻境中左手完全一致的印记，但颜色更淡。
- 若林恩在死亡片段播放时尝试与画面中的巨大眼睛对视，则一股超越认知的威压直接贯穿他的意识，他被强制弹出吸收状态，现实身体同步喷出鼻血。
- 若林恩在吸收结束后拒绝记录吸收比例并选择隐瞒，则左左在事后检查时发现他的灵魂强度读数与预期不符，她对他的信任度首次出现可量化的下降。
- 若林恩在吸收期间让左左以血灵石研磨成粉撒在他的额头，则药粉与他的皮肤接触后迅速蒸发，腐败速度减缓三成，但左左的血灵石存量永久减少。
