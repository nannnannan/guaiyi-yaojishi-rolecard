# E201·白逸失联与首次跨界呼叫·if线

- 若林恩第一次失败之后临时把法阵挪到黑夜城外一处废弃离魂街,则002室自带的位面屏蔽消失,跨界信号一次穿透,但白逸病房的总局坐标反追踪程序在午夜立案。
- 若林恩把巨像之心输出压到七成,则羊皮纸光幕只亮到昏黄一线,白逸在镇静中把大哥的声音当成半梦半醒的幻听,病房监测仅记录一次异样脑波。
- 若林恩不用那颗藏品、改用白逸遗失小拇指的断茬作媒介,则定位系数减半,跨界链路多出十秒静默,白逸手心吊坠反而先于呼叫发烫发亮。
- 若林恩在阵眼处垫一张他亲手模仿白逸笔迹的字条「是大哥」,则白逸越过阈值那一次性听清原话,镇静后被梦魇加上一层「家人来骂」的二次心理回环,第三次抬手直接瘫软。
- 若林恩把主母毛从墨水改作阵眼主插针,则最后一步通讯卡顿消失,白逸接到完整通牒,但法阵烧尽速度快了一倍,没机会补上「明天」两个字。
- 若林恩让左左留在大殿外望风、不进场,则跨界信道不再引出羽毛笔的镜面窥视,002室书架上那面蒙尘旧镜也未被动过,事件以变形(羽毛笔未察觉)收束。
- 若林恩第三次接通前先用羽毛笔遗留的笔记本压住阵沿,则信道被书写咒权罩住,白逸完全没收到警告,主母殿堂的感应阵只记下一段「外部咒权干涉」。
- 若林恩吼话开头直接切入「血肉神教已入侵,明天召唤我」,不带寒暄,则白逸在镇静里只捕捉到这几个关键词,深夜翻床时按响了病房警铃,尹琴窗口提前一晚打开。
- 若林恩改用恶意低嗓厉喝「不允拒接」,则梦魇判定音源非本尊,跨界信道被反向锁回地狱,法阵两侧同时炸壳,左左被震得耳鸣一整晚。
- 若林恩在第三次连线里刻意不报名号只在末尾补一句「就当还我那一颗」,则白逸只收到关键字「还」,梦魇把它标为心理压迫信号,顺带加扎一针,但频道多撑五秒。
- 若林恩用白逸送他的吊坠作为额外媒介,则吊坠在蓝星病房同步发烫发亮,白逸意识到是大哥召唤,硬是扛过两轮注射听见「血肉神教」五个字才昏死。
- 若林恩接入巨像之心二级输出,则信道带宽暴增,他临时多吼出「小呀哒都惦记你」,白逸被代入睹物回路,情绪暴发到连续三针都压不下,事件以变形(白逸情绪熔断)收束。
- 若林恩在阵眼额外嵌一枚逆追踪模组,则他并不只送出警告,还顺势窥见了白逸这段时间废寝忘食的特训画面,事件以变形(警告变斥责)收束,原本准备好的最后通牒在最后一刻变成一句「别再练这种命」。
- 若林恩布阵时顺嘴对主母的一根毛道一声「姐,先容我用一回」,则殿堂那侧悄悄放行,跨界信道全程未被任何梦魇拦截,白逸收到完整警告,事件末尾主母亲自来劈头质问。
- 若林恩临时从怀里摸出一段人声范文装作口令报号「此地宜居业务招投」,则梦魇把那句误识别为推销录音,镇静阈值不上调,白逸全程听完原话却仍起不了床。
- 若林恩让左左代他吼一句对白逸的狠话「你个懒小子被二姐压到现在还不起来」,则左左哭腔式骂法在蓝星病房引爆第二波情绪震,监测系统直接把白逸转送精神监护室,召唤筹备窗口顺延半天。
- 若林恩在法阵外围嵌一层灵能定向偏转镜,则跨界信号绕开蓝星医疗卫生局的监察频段,但波及总局另一侧干员,事件以变形(跨界串频)收束,召唤筹备名单里多出一名意外对象。
- 若林恩掏出随便一块鹅卵石暂代藏品塞进阵眼,则跨界定位穿透蓝星后迷失方向,信号飘到血肉神教外围祭坛,那边一位教徒收到「地狱恶鬼将临」的错误启示。
- 若林恩第二次失败后临时停用巨像之心、改用主母殿堂外头采集的神圣锁链残片作能量源,则法阵被权柄镇压半段,羊皮纸彻底燃尽前只够送出「明天」两个字。
- 若林恩先在殿堂向主母报备一次跨界通讯意图,则主母亲自加持一道静默魔法,跨界信道免被任何地狱外存在察觉,事件以变形(通讯合法化)收束,后续外界关注率清零。
- 若林恩法阵启动前先随手给左左剥一颗糖塞进嘴里,则她被糖卡住,跨界吼话全程只剩她自己咳嗽伴奏,白逸收到的讯号质量下降到只能听见「大哥」两个字。
- 若林恩在第三次接通前临时加设一道紧急切断开关,则在纸阵燃尽前半秒主动压掉信号,事件以变形(呼叫取消)收束,白逸彻夜未醒,召唤窗口被顺延至第三天。
