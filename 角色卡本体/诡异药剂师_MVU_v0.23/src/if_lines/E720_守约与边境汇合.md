# E720·守约与边境汇合·if线

- 若林恩在进入黑瞳前先把酒壶中的酒一饮而尽再踏进黑暗，则他踏入画家世界时神智更松，但落地后会先在苍蓝残垣里留下一个脚印深的焦痕，提前惊动那只巨手。
- 若林恩在看到画家被巨手砸落时第一时间拔刀冲上、不再先听她解释，则他会替她扛下新一轮雷瀑，但失去听到「我在以身饲虎」那段关键说明的机会。
- 若林恩在劈开那道雷瀑后第一句话不是「是我」而是一句低声「笨师傅」，则画家的瞳孔会真正崩溃一秒，苍蓝的体形外泄出大量失控色彩，林恩需多花一刀替她稳住边界。
- 若林恩不扶单片眼镜、不侧面摆出任何疏离姿态，只正面静静看她，则画家会更早读出他不是她记忆里的那个林恩，心理落差集中爆发，对话节奏被压缩一半。
- 若林恩问她「你打算让它吃掉你是不是」而不是旁敲侧击，则她会比主线更早摊牌，后面的「最后一只渡鸦」情报也会顺带着被她说出，林恩情绪余震更深。
- 若林恩在画家说出「很高兴你能赶回来」之后立刻把刀架到自己脖颈反问「你以为我会让你送死」，则她会第一次回头正视他，局面瞬间进入两人意志对峙。
- 若林恩在金色梦境挡下黑潮一击后立刻负伤吐血，则他随后的追问会变得咄咄逼人、不再绕弯，画家会意识到他已经猜到八成，主动把「让祂整个吞掉我」方案说完整。
- 若林恩在她化作苍蓝箭矢冲出去的瞬间没有跟上去、而是咬牙留在原地稳定裂隙，则她将独自进入黑瞳范畴，林恩失去为她挡下第二轮反扑的位置，画家会在最深处受一次本可避免的伤。
- 若林恩紧紧拽住她的手腕不让她再冲，则她将第一次在万年岁月里被物理拦下、愣住，黑瞳的反扑会同时砸在两人身上，林恩必须以常态罪火硬抗完整一记。
- 若林恩在陪她冲入黑瞳范围内瞬间回头看一眼后方远方的边境战线，则他会在那一眼里看到王骑白旗下跪的身影，情绪被压成更沉的一刀。
- 若林恩以心声在冲撞途中对她说「等你把话说完我再决定要不要挡你」，则她会保留一口气继续冲，但接下来她对他摊牌的措辞会从「计划」换成「恳求」。
- 若林恩在黑潮中主动拉住她的脚踝把她往身后拽，则她会借力回身、把前半句话吞回去改成一拳砸在他胸口，借此宣泄那个「早就想好的方法」的怒气。
- 若林恩在最后她贴近黑瞳的瞬间用左手的印记把她暂时标记为「不许擅自死」，则标记会刻入她苍蓝色的手腕，后续即使她成功被吞噬，林恩也能借此连接感应到她被消化的进度。
- 若林恩整个过程中不发一句心声、不喊她名字，则画家会在冲入黑瞳那一刻回头看他一眼，那一眼里第一次带上了「对不起」。
- 若林恩在跟随她时悄悄从系统空间落下一枚信标贴在苍蓝残垣上，则这次的撤离预备路径会被银色幻想未来感应到，为 E724 的撤退预设更多余地。
- 若林恩拒绝听她整个计划、强行把她打晕拽回边境，则灾厄的注意力瞬间聚焦，两人会被一起打入更深的无序深空，事件直转变形。
