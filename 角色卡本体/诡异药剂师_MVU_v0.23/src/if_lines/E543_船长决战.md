# E543·船长决战·if线

- 若林恩选择在黑袍身份下鼓掌但不发言祝贺，则船长看不出真祝贺，讶异与恍然环节缺失，第一回合前张力更紧。
- 若林恩在人群中不换黑袍而以真面目出列，则「黑袍人就是林恩」在决战开始时即公开，船长认输支持线被前置。
- 若林恩不拔刀而改为鞠躬邀请「请主座决断」，则决斗性质由「以命相搏」降为「切磋」，经验压制的强度下降。
- 若林恩第一回合只守不攻，则船长不得不一开始就动用法则，冷兵器经验压制节奏被打乱。
- 若林恩让左左在第一回合即揭竿「凑脑袋让我来」，则冷兵器轮被左左全程代打，技巧比拼的悬殊在左左层面继续。
- 若林恩选择一开始就与船长同走死亡法则而非先斗冷兵器，则经验压制环节被跳过，第二回合的对轰提前爆发。
- 若林恩在死亡对轰中短暂掺杂空间法则折叠幽灵船撞击路径，则他被撞入心灵之海的位移距离缩短，亡灵拖拽环节缺席。
- 若林恩在心灵之海中主动吸引亡灵上自己的意识之门，则精神被消耗的速率上升，反噬格局由「焊死」变为「勉强顶住」。
- 若林恩让左左在死亡法则扩张时只催他占体量而不让他叠精神防御，则心灵之门在船长操控下被部分穿透，落败剧本提前展开。
- 若林恩不用初诞者之力化死亡而靠现有死亡法则硬撑，则体量对拼落于船长下风，第一局即被宣判败北。
- 若林恩在斩神一刀时刻意借左左的法则而非只借身，则那一刀被船长识别为「林恩+左左合体」，巨像不再单独注目左左。
- 若林恩让左左那一刀砍向船长的胸而非左臂，则斩神一刀的目标改向要害，支持的收束点被推向更危险的结算。
- 若林恩让左左脱离自己身体独立对船长展开近身，则「借身不借法则」结构解体，两人组合变成双线夹击。
- 若林恩在船长轰碎初期即停战认输，则「败在上限」的定性无从成立，支持线被改写成礼让。
- 若林恩不允许左左插入「交给我！」的二对一宣言，则断臂一刀无事发生，船长剑刃碎裂仅凭林恩本体。
- 若林恩在裂纹脆响前抢先献初诞者之力修复，则死亡控制权的对撑被外力打破，船长认输的语境从「已达极限」变为「被救济」。
- 若林恩在裂纹出现后选择继续对拼至极限而非停手，则船长半步神格可崩，「认输+支持」线改写为悲剧分支。
- 若林恩让白发青年形态的船长出现在决战现场，则对决的视觉标志是年轻对决年轻，缪斯感被替换为同代对决感。
- 若林恩在「王的道路」对白后多加一句「紫罗兰大君不是终点」，则林恩的目标表述被外扩，船长支持的政治风险上升。
- 若林恩让左左在船长夸奖后持续炫技显摆，则船长对「不输给任何人的存在」的肯定文本被削弱，左左的气场则成形。
- 若林恩让左左先踩他胸脯再让船长赞那一刀，则斩杀肯定带着喜剧杂味，「左左斩神」的威名沾染玩笑纹理。
- 若林恩在「地狱该统一」宣言后追加对人偶家与泰坦的提前提点，则船长临行提醒环节冗余，但后续围猎时两人的反应速度抬升。
- 若林恩选择不告知船长任何后续安排而让其自行演完威慑戏，则船长支持的自觉度更深，但他对林恩真实目标的信任度略降。
- 若林恩让左左爆栗镇压后立刻释放作为谢礼，则左左对林恩的敌意少一笔，识相的「懂事挂件」形象重新立起。
- 若林恩让艾雯半途以心声插入一句「等一个结果」而不只旁观，则他更早读懂决战真意，后续审判时代表知情层的参与度提升。
