# E156·蓝星死界恶鬼与召唤预警·if线

- 若林恩在黑夜城地下大殿接受主母亲吻额头赐予升级版【主母的祝福】后见好就收、乖巧道谢，则他不仅保住道德属性免遭暴打，还获赠主母额外凝聚的一缕神圣护身辉光，事件以不变形收束。
- 若林恩在被主母暴打（抗打击能力+1）后顺势厚着脸皮请教如何主动引导【主母的祝福】压制小丑诅咒，则主母冷哼一声传授了精神壁垒的收束法门，事件以不变形收束但小丑诅咒压制效率提升。
- 若林恩在地下大殿向主母提及自己即将跨界前往蓝星处理信标事务，则主母额外将祝福的持续时间加固，叮嘱他莫要堕了黑夜城威名，事件以不变形收束。
- 若白逸在蓝星超自然总局会议室内感应器失序前提前按下静音键，则会议室只有尹琴的汇报声继续，黑暗世界语系辨认由白逸口头背出而非电子公放，事件以不变形收束。
- 若白逸没能及时按住感应器、任由「笨蛋，射她啊」循环播放，则总局会议室秩序一度中断，事件以变形（感应器持续故障）收束，满室调查员对「那位林恩先生」的冷幽默印象深刻。
- 若白逸在录像播放到红衣高跟鞋画面时主动申请调取超自然总局的旧案卷宗比对，则档案室迅速锁定荒村封锁区的历史异常，事件以不变形收束但调查进度提前。
- 若白逸在尹琴汇报前主动关闭义体语音播报接口，则感应器全程静默、白逸改为低声向局长补充细节，事件以不变形收束。
- 若白逸在会议期间同步放出此前收集的异界环境音频辅助说明，则满室调查员神经紧绷、能级紧迫度被评为「灾难级」，事件以不变形收束。
- 若白逸在会议结束前主动向尹琴提议加强荒村外围的灵能警戒，则总局在部署撤离预案时多加一道封锁网，事件以不变形收束。
- 若白逸在裤裆感应器响起三声「笨蛋」后机智地拍了拍义体谎称是防盗警报，则会议室众人信以为真、尴尬气氛迅速化解，事件以不变形收束。
- 若尹琴在会议结尾主动提醒总局高层「红裙录像切勿外泄至外网」，则总局决定将录像证据列为绝密封存，事件以不变形收束、泄密风险归零。
- 若白逸在会议闭幕后单独向尹琴展示义体感应器的异常共鸣频率，则两人当场确认荒村内必然存在与林恩相关的跨界信标，事件以不变形收束。
