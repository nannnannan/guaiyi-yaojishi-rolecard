# E156·蓝星死界恶鬼与召唤预警·if线

- 若林恩在白逸感应器失序前主动远程把感应器通过咒瞳静音，则会议室只有尹琴的声音继续，黑暗世界语系辨认由白逸口头背出而非电子公放，事件以不变形收束但满室沉默改为满室紧记笔记。
- 若林恩当场远程静音失败，让感应器继续循环「笨蛋，射她啊」，则总局会议室秩序失控当场中断会议，事件以变形（感应器持续故障）收束，满室调查员对「那位林恩先生」印象落到黑色幽默一栏。
- 若林恩在录像播放瞬间主动用咒瞳远程对照红衣高跟鞋与地狱失踪名单，则咒瞳穿透画面被反弹，录像里的红裙恶灵似乎瞥了镜头一眼，事件以变形（恶灵反向察觉）收束，总局临时加密录像副本。
- 若林恩在尹琴汇报前主动让左左抠开义体接口切断感应器供电，则感应器哑火、白逸的指认改为低声汇报，事件以不变形收束但白逸因没及时认出大哥感应系统失落整日。
- 若林恩主动让白逸的义体在会议期间播放利维坦战役现场音作为氛围乐，则满室调查员神经紧绷、录像段被迫快放，事件以不变形收束但能级紧迫度被评为「极高」改「灾难级」。
- 若林恩趁录像暂停那几帧红鞋画面主动用咒瞳抽取残留气息回黑夜城分析，则咒瞳被一股冰冷血雾撞上瞬间失能数秒，事件以变形（跨界气息触发反击）收束，咒瞳当晚进入检修状态。
- 若林恩在总局会议结束前主动以「血衣相关方」名义向尹琴寄一封无署名警告信，则总局在部署撤离预案时多一条「疑似目击者存在」，事件以不变形收束但白逸开始怀疑大哥知道什么没说出来。
- 若林恩主动用远程感应让白逸裤裆感应器停在三声「笨蛋」后自动转口播「谢谢观看」，则会议室有人噗嗤笑出声，尴尬气氛找到出口，事件以不变形收束、白逸的「笨蛋射线」绰号公开化。
- 若林恩在会议结尾主动让左左透过天师耳语提醒「红裙这段不要外漏到新闻」，则总局决定将录像证据只封存不进外网，事件以不变形收束、泄密风险暂时归零。
- 若林恩趁着全城注意力集中在红裙恶鬼时主动指令巨像之脑暗中监测蓝星方向残余波动，则根源数据库多一条「蓝星血肉神教召唤余波」画像，事件以不变形收束但根源跨世界动向被记录。
- 若林恩主动让巨像之脑直接给总局发一条古老传音「此灵出自旧部，不得造次」，则总局在并无证据下采信、部署更谨慎，事件以变形（根源提前介入）收束，后续血衣剧情抽出独立门禁。
- 若林恩主动在总局疏散同时把血肉教徒仪式台词投影到任一派系屏幕上试图勾起内部检举，则一名潜伏教徒表情被打动，事件以不变形收束但内应名单在总局档案室被加急核查。
- 若林恩在事件结束时指派左左一段无意识梦话「红鞋子会有更多鞋」，则左左醒后不解含义、把话讲给艾雯爵士，事件以不变形收束但「更多鞋」一词出现在后续警告标签里。
- 若林恩全程不涉入、任由总局自治，则事件按原走向收束，红衣恶鬼身份保持未知，但总局内部对林恩的人类立场依旧停留在模糊。
- 若林恩主动让左左在会议闭幕时给白逸一张画着高跟鞋的涂鸦便签，则白逸持签询问楚，事件以不变形收束但白逸与尹琴当场开始怀疑红裙的身份线索。
