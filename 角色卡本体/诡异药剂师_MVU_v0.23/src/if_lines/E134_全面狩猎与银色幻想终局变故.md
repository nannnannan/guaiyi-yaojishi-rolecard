# E134·全面狩猎与银色幻想终局变故·if线

- 若林恩在万机集火泰坦前先用血肉瘟疫切断更多舰船控制链，则万机被迫两线作战，泰坦承受的总火力下降
- 若林恩改为只在远端制造瘟疫压制而不投入近战，则万机仍以完整舰队集火泰坦，虚化空间裂痕出现更早
- 若林恩让艾雯爵士继续把战舰干涉进万花筒而非抽手协防，则银色幻想所需的突入窗口由林恩另行补齐
- 若林恩让银发女孩改斩舰桥而非动力系统，则万机指挥权短期紊乱但泰坦承伤上升，转火到林恩队伍概率加大
- 若林恩联合巫神头颅专攻万机弹药链，则舰队齐射节奏被拆，根源合击泰坦的时间窗变短
- 若林恩在万机收归舰群重化机械龙首时发动瘟疫隔离，则龙首成型被推迟，但万机可能改为放弃舰群直接逃入裂隙
- 若林恩把治疗资源优先压给银色幻想而非撤离人员，则舰队缴获结算缩水，银色幻想机体完整度提高
- 若林恩在银色幻想跃下残楼前已对她建立过偏离账本，则她的根源光束落点与台词按账本状态呈现，不照搬原作
- 若林恩以「巨像之脑超维网络」尝试入侵万机终端，则失败被白描呈现，但万机需分神抵御、龙首合击延后一拍
- 若林恩在银色幻想被双斧吞没前发射巨镰折跃抵达，则机体救回窗口成立但林恩自身被泰坦锁为新仇恨目标
- 若林恩让小小用家族协作拦下的一道齐射，则银色幻想意识回传路径受保护更全面，但小小撤离窗口被压缩
- 若林恩允许银色幻想喊出「这次是你输了」的原作台词而不加以干涉，则她接下全部泰坦仇恨、机体进入原始毁弃路径
- 若林恩在万机狂笑化龙首时以血肉瘟疫集中攻击其头颅合击点，则根源合击炸碎难度下降，但裂隙闭合时机提前
- 若林恩决定优先追击万机残部而非保护银色幻想机体，则她机体毁弃按原作节拍走完，意识回传转向长期未证
- 若林恩把战场上的瘟疫库存改为对泰坦封锁用，则银色幻想可少挨一击但万机可能借泰坦怒吼突围
- 若林恩让巨像之脑在泰坦血红巨瞳锁死银影前把他召回诅咒之城废墟，则泰坦人身退场、银色幻想机体保全度上升
- 若林恩借用E133夺到的首舰火力参与齐射，则万机头颅炸碎口径扩大，首舰残骸结算为「损毁」而非「待净化」
- 若林恩在三大根源与君王级合击炸碎万机头颅的同时投放瘟疫通讯包，则万机留下的内部通讯可被部分截获
- 若林恩在「机械……永恒……」念出前已让巫神头颅布下防护结界，则银色幻想躯体毁弃程度下降、丢狙举剑的画面保留
- 若林恩试图强行阻止裂隙闭合以图追击万机，则失败被呈现，根源齐射转向维持裂隙稳定、区域环境撕裂加重
- 若林恩优先回收万机残舰与武器残骸而放弃救援银色幻想，则机械神教长期缴获大幅增加，她的意识回传走向后台
- 若林恩让巫神头颅的远程防护完全罩在银色幻想身上，则主战场舰队缴获减少，机械神教短期撤退反而更完整
- 若林恩主动对银色幻想伸出援手的台词被她拒绝，则剧情仍走原作机体毁弃路径，后续恨意账本按既有偏离值滚动
- 若林恩在变故后立即撤离放弃残骸与追击，则联军伤员存活率最高但机械舰队缴获归零，万机撤离结论成立
- 若林恩把变故节点记账为「发酵中」并保留对银色幻想的未了承诺，则E135起她的意识去向以偏离账本条目驱动
