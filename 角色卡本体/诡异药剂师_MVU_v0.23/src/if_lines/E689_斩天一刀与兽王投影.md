# E689·斩天一刀与兽王投影·if线

- 若林恩在「让我来毁灭你」宣言前先低声复述一次因果在金殿里的那句话，则星寂一拳轰出的同时真理残魂在甬道尽头会突然停顿一拍，金色书页从他膝上跌落，他没有回头，但嘴角第一次有了人类才会有的微小颤动。
- 若林恩没等待兽王的神格吞噬只抢先一戟刺向它龙首胸口，则兽王会提前侧身避开要害，但它肋骨间那一缕刚融进去的神格会被林恩带出的气劲扯碎一角，那缕力量并未被吞噬，而是化作一撩血线溅在林恩左眼睑上。
- 若林恩让左左在启动梦境领域的瞬间同时从神识层面掐断兽王对外联系的因果细线，则它会被强制留在这片神疆领域的「缓冲笼」里，但代价是左左胸口会凭空多出一道横贯半个身子的爪痕，从意识空间里一路贯穿到现实。
- 若林恩在被白骨利爪抵住咽喉瞬间故意不闪不避，任由那一缕邪气贯穿半寸，则他会被一击击飞出去，但獠牙划过他脖颈时他体内那轮银色太阳终于第一次在真正与灾厄法则硬碰硬的场合下主动出手——不是出手解除，而是出手将那道时停反击回兽王。
- 若林恩在展开梦境领域前主动撕掉左肩的衣袖让一缕血线落入金色涟漪，则这个梦境的范围会临时扩大到方圆七百而非数百，兽王的息逃落点会全部被纳入领域边界之上，但它的挣脱力量也会在三息内撕碎这件屏障，他必须以最快速度完成那一记冒险的斩击。
- 若林恩不止以三位一体之力，而是把织梦昏迷前无意识在他指尖留下的那半缕残光也一并融进罪火长刃，则这一刀斩出时会伴随着一声极清极冷的剑鸣，兽王崩碎后原地残渣无法再顺势融入七十二柱中的新柱——它被真正意义上地一次性抹杀。
- 若林恩在斩出那一刀前主动压下脑中浮现的「织梦那一刀便是这般斩出的」念头，完全以直觉出招，则刀锋会在落下前自主调整半寸轨迹，代价是他肩头上空裂开一个深可见骨的伤口，连同他的骨骼都被那一缕刀气挑断几根——这是他没有借助任何人的记忆、只凭自身领悟所必须付出的代价。
- 若林恩在刀锋落下前主动把第三只渡鸦尸体在系统空间里捏碎、把剩余的初诞者之力全部压入刀身，则这一刀不再耗尽他全部的三位一体之力，但他以凡人之躯完成了远超自身位格的一击，他的右手将有三日时间无法握紧任何东西。
- 若林恩没立刻收刀，而是踩着风雨中的金色涟漪走到兽王崩碎的残骸旁，将柄尖刺入毁灭神格彻底摧毁它的灵性，则这枚神王格从此不再有主人，也无法再成为任何一位神王的盾牌——它从瑰宝变成了一颗普通的、蕴含磅礴法则的黑石。
- 若林恩在加冕瞬间把金色梦境领域向四面八方一撒，则它不再只是限制兽王的囚笼，而是第一次以近乎「具象」的形态笼罩了整片神界废墟的中心区域——三息之内，林恩所站立的地方被识别为神王国度的临时交汇点，所有正在赶来的外来者一次减速三成。
- 若林恩在灭掉兽王后没有急着向来路奔逃，而是从地上捡起那只白骨断臂杵在自己肩头当作拐杖，则在 E690 面对真理的冷漠与戒备时，他手里的这只断臂会无声地向对面释放出一股极淡的、诡异的同源气息——真理残魂将第一次对林恩做出正眼打量。
- 若林恩在罪火一斩的威光未散时转身望向金色少年，则金色少年眉心的真理神格会在同一瞬间发出一声不堪重负的哀鸣，这个他一直被蒙在鼓里的存在，第一次当面见到了被剥离的真正「主人」站在一个陌生敌人的身后——他的世界观从此面临崩塌危机。
- 若林恩错过这个落点没在三息内向第七层奔去，而是先回身补刀第六层里那十几位试图复燃的施法者尸体，则真理残魂在 E690 中到达第七层时将多一段路要自行排除脚下的陷阱，林恩的赶到会比他慢上整整七息。
- 若林恩在收刀瞬间主动触碰那枚悬浮神格并反吸一口仍未散尽的黑雾，则他的灵体将第一次强行模拟真理的波动，他能在短时间内以「不被识破」的形态接近第七层——但代价是他往后三日每一次使用三叉戟，都会有一瞬间误以为握在手中的是那根金色神格虚影。
- 若林恩在银色太阳刚要开口的节点先一步掐断它发言，自己抬头望向那方辉煌，则第七层正中央会以肉眼可见的速度从左到右重新染上一层金色，来自于第七层最深处的一道视线里第一次带上了陌生又熟悉的忌惮——他们第一次在没有桥梁的真正意义上，近距离地四目相对。
