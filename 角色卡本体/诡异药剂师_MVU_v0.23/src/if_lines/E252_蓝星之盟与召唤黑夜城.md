# E252·蓝星之盟与召唤黑夜城·if线

- 若林恩在白逸狂奔扑来时不伸单手拎领子而是直接接住抱一下，则白逸当场哭成黄花闺女升级版，五将官目睹后集体调整对这位机械使者的评估、握手时多出三分人情温度。
- 若林恩拒绝白逸的牌位宣言、当场呵斥「把我牌位撤了」，则白逸抹着眼泪回身照办，林恩在白家家祠的「供奉」段落被取消，但白逸心里更认定他是「活着的神」。
- 若林恩朝弥赛亚而不是对她似笑非笑，改成端正鞠躬致谢她的中间人身份，则弥赛亚被这份正经闪了一下、握紧的拳头缓放松，「单独治烧伤」的调戏段落被推迟。
- 若林恩主动避开「帮你治疗烧伤」的暗示、改成承诺「处理完战事再谈」，则弥赛亚用邦邦拳警告他「别爽约」，两人关系由调戏路径改为约束路径。
- 若林恩在摊出局势时先把全球被渗透的政府名单完整投放到屏幕上，则五将官在第一波震撼中就被迫面对自己国家高层的腐坏，结盟谈判的赔罪段落更沉重。
- 若林恩主动要求五将官每位当场「自述被控期间做了什么」再谈结盟，则王正和等人依次诚恳交代、鸣枪仪式前多一段忏悔时长，结盟的合法性加码。
- 若林恩拒绝接军礼、改为请他们「先把面前这支军队收队再谈」，则五将官挫一下后立即照办、林恩的指挥位被默认证得更深，但【蓝星之盟】的官方仪式被推迟到傍晚。
- 若林恩提出「不看军礼、看军纪」、现场点一队被控期间军纪未崩的连队致意，则那支连队被记一笔战前功勋，林恩在军中的非正式威望开始自下而上渗透。
- 若林恩主动提到「等黑夜城大军抵达要按中国军令混编」而不是独立作战，则王正和愣一下、上前一步与他再次握手，【蓝星之盟】附赠一条「军事整合度 +20%」备注。
- 若林恩主动把「等就我们两个人单独在一起」的话缩回去、改为公开商谈烧伤治疗，则弥赛亚白眼翻完仍接受安排，但他的「治疗调戏」表情包在白夜眼里被永久分类。
- 若林恩在鸣枪敬礼瞬间同步用巨像之心回响一声回应，则机体嗡鸣让前排士兵短暂失聪半秒、【蓝星之盟】场面被自动记入各国通讯社头版。
- 若林恩主动邀请夜医团在结盟仪式后立刻为五将官体检，则体检段落提前、被控期间残留的精神细丝被剪除，E253 召唤段夜医到位时间提前一天。
- 若林恩把「我们也是普通人」那句改为「我们也曾普通到被人砍下头颅」，则五将官集体沉默数秒、宋全真上前自报家门，结盟氛围由宣言升格为共同伤痛。
- 若林恩主动蹲下与从装甲车上下来的年轻通讯兵平视、问他「怕不怕」，则那名士兵结巴回答后直接成为林恩阵营内第一个非系统的「人类粉丝」，E253 召唤基地的通讯班主动加班。
- 若林恩拒绝全国直播结盟、只允许内圈记录，则【蓝星之盟】的官方声望 -10，但血肉神教对仪式的反扑准备时间被砍掉，E254 核拦截段的前哨情报更早到。
- 若林恩主动把召唤黑夜城大军的使者卡递给王正和过目，则王正和凝视符纹十秒、缓慢对他说「这是第一次有人把刀柄交到我们手里」，军方联络线好感度封顶。
- 若林恩当场要求白逸把「祖祠牌位」的照片拍下来传给他，则林恩收下后用作回头逗左左的素材，左左看完大笑三分钟，亲密度额外 +2。
- 若林恩主动请弥赛亚在结盟书上同时签下「隐修会代表」落款，则她的手抖一下、然后签得比谁都端正，隐修会与黑夜城的双轨外交正式开档。
