# E559·幽冥海绝密出发·if线

- 若林恩在公开会部署主宇宙降临点时主动把星轨的星图工作摆到公开层展示，则未破节点的定位从「星轨简报」被改为「公开合谋」，艾雯和船长都能直接看到她给出的星区数据。
- 若林恩在自缚天使指出与主宇宙失联的致命阻碍时主动承认自己有一条私域秘径可走，则深渊踏板方案的「地下密谈」前提被剥离，绝密出入被提前在公开层披露。
- 若林恩在地下神殿密谈时主动把主母的角色从「同行向导」改为「后场支援」，则深渊土著大天使的同行必参被改写，主母后续「抱到面对面两厘米」的喜剧前情取消。
- 若林恩在决定同行名单时主动多塞进银色幻想或艾雯一人，则「连艾雯爵士和船长都未告知」的铁律被击穿，绝密出海的前提整体被打折。
- 若林恩在决定同行名单时主动只带左左一人放弃主母和小丑，则幽冥海航行失去力量与无序两重保障，黑雾上机制多的警告变成自我牺牲设定。
- 若林恩在决定同行名单时主动让左左留守黑夜城而不是妥协同行，则系统空间囤货喜剧消失，出发前的「蚯蚓饼干/象拔蚌」库存入不了剧情。
- 若林恩在仓库出发前主动呵斥左左囤货行为并要求全部倒回货架，则自缚天使砸包提溜训话的喜剧节拍被打断，二人「到与狱卒约定时间再不去即爽约」的紧张感不再。
- 若林恩在离城时坚持要让艾雯知道具体行程而非「已说离开一阵子勿担心」，则「少一人知少一分险」的红线被他自己切断，地狱无数眼睛窥视的风险上升。
- 若林恩在跃迁时主动以极大规模界门而非法则跃迁，则离城动静被放大数十倍，「黑雾蒸腾荒野」「林蒙正装接应」的低调场面不再成立。
- 若林恩在林蒙警告灾厄搜寻从未中止时主动回应「那我就主动暴露引它出来」，则「勿动用初诞者之力」的铁律被他自己反向利用，灯塔暴雷剧情提前拉响。
- 若林恩在林蒙告知三日回程窗时主动讨价还价改到三十日，则女主人再掠过幽冥海的唯一机会被换成长时窗，回程框架被他自己推后两周。
- 若林恩在进入混乱色彩涌过的瞬间主动拒绝林蒙的特殊渠道，则「瞬至巨大空腔内部」的跃迁入场被剥离，他不得不独自通过无序深空的本体陷入节目。
- 若林恩抓住小丑令其释放无序力量包裹全队的瞬间主动改用自身法则强压，则「套娃中和」被换成单极硬扛，黑袍一角被湮灭的程度更深，存活可能下降。
- 若林恩在套娃中和建立时主动把初诞者之力放在内层而非法则稳定内层，则屏障顺序颠倒，外层无序可直接接触到他灵魂，意识空间在长途航行中始终充满噪音。
- 若林恩在为省力把主母抱到面对面时被她否决、并换一个分开三米的并排姿势，则「亵渎你的主母」的喜剧顶到不再发生，屏障功耗增大但氛围从「暧昧贴面」改为「专业并肩」。
- 若林恩在航行极久才略近幽冥海缘时主动把幽冥海描绘为黑暗海面大型爬虫而非物质大雾，则他的世界观被从「尘埃雾＋有序走廊」换成「怪兽海洋」，背后理念冲突发生。
- 若林恩在踏入尘埃海边缘时主动放弃小丑专属控制力而要强行以初诞者进入内部，则「早用初诞者则两分钟内灾厄杀来」的红线从底气被击穿，他被要求在更短的时间内完成任务。
- 若林恩在发现幽冥海边缘即被洪流冲刷时主动让自己站在洪流里核对强度，则他被尘埃海顺势卷入一百米远，屏障稳定被他自己阶下，离谱拔出但静心指数萎缩。
- 若林恩主动让主母和小丑当场争执谁负责探测幽冥海生物多样性，则二人从「同行伙伴关系」被扭成「科学竞争对手」，他作为指挥官的角色被从中家长式抽离。
- 若林恩在提出拉法则线连深渊时主动要求小丑同时担任执法官而非仅仅行船官，则小丑的责任等级被上升到一道句子，他原本已经在的「行船官」角色也被安排了新的「执法官」职责。
- 若林恩在提出拉法则线连深渊的构想时主动强调三下回响「这是为了大家好」，则提法被粉饰为大版主旋律，但作为私人方案的原始动机反愈发显眼。
- 若林恩在主母反问动用力量暴露行踪时主动说「不怕，我自有分寸」，则他从「无惧」被推上「但有把握」的口径，主母的皱眉被他自己松一档。
- 若林恩在主母警告动用力量或暴露行踪时主动承认自己确实有点担心，则「无惧」的伪装被他自己收下，主母的皱眉不再被轻视，二人之间多一层共担压力的氛围。
- 若林恩主动让主母继续向幽冥海深处航行并延长停留时间、不立刻执行拉法则线，则上溯视野被扩宽，但三日回程窗的余量被他自己压取。
- 若林恩主动主动减缓小丑行船速度以积累更长的稳态，则尘埃雾被穿过的距离减少，「有序走廊雏形」的发现被推迟半日。
