# E688·毁灭神格与兽王吞噬·if线

- 若林恩在得到织梦腐化诊断的第一刻撕碎另一只渡鸦尸体注入自己体内，则他能在她本源磨损完前多撑三分钟的「人形封印」，但此具尸体在 E689 中将无法再用，他面对兽王时的峰值力量将降低一成。
- 若林恩没把织梦送进三叉戟世界，而是将她背在身后以无形之链系在自己背上继续追击，则她昏迷中会因剧烈震动而呕出带色的血珠，但他在 E689 险境中多出一个可以牺牲自己为她挡攻击的活体护盾。
- 若林恩在起点时主动把一缕初诞者之力沿着织梦心口裂口逆行种植，则她体内的紫黑色腐化会被强行扯出一线尽头，若她在 E689 初诞者之力耗尽前完成逆转一匕首终结，她与他能同时躲过「死肉」而非「堕落」的结局。
- 若林恩看到兽王撕碎渡鸦分身的瞬间立刻折返来追那只龙首怪诞，则第五层因果殿堂外会留下一道他亲手破开的空间裂口——追上时那个因果王座是空的，但他能看到王座扶手上几行刚被摩挲到发亮的旧式中文连笔字，是他们初次相见时她偷偷记下的。
- 若林恩在第三层没听真理残魂的建议直接冲向第六层，而是先拐去第五层一看，则他会与因果神王正面相遇，因果不会动手，只是把一只布满裂纹的金色手炉递给他——里面是他最后一缕未登全盛的神王之力。
- 若林恩没抓握那枚漆黑神格，而是把它从法阵边缘一脚踹向第六层侧墙，则血肉巨人手臂会突然伸长把神格抓入自己身体，融合加速，他必须在三息内同时面对巨人的完整爆发与神格新主真正的降临。
- 若林恩出手打碎毁灭法阵后立刻闪进侧墙的阴影之内，则他会亲眼目睹血肉巨人徒劳抓握融合失败的哀嚎，并在巨人额顶完整的金色龟裂处看到一枚极小的紫罗兰徽记——那是旧世界「他」的部众的标志，而巨人本身，正是某位被亲手剥离自我意志的熟人。
- 若林恩对真理残魂先动身后的最一瞬施以一缕反向律令，则那具半透明身影会在突入大门时被无形之手扳住一步，金色天平两侧第一次显出他体内真正的分裂——理性与恨意在同一个灵魂里，暂时谁也压不倒谁。
- 若林恩在兽王张开血盆大口吞下毁灭神格前主动燃烧自己一缕灵魂之力掷入其咽喉，则兽王消化不良，它腹中会发出一阵闷雷般的碎裂声，那双黑洞洞的眼眶里第一次流过一缕不属于它的、淡淡的金红——那缕人性未被它消化。
- 若林恩让真理残魂在出发前悄悄把几缕真理律令烙入自己的三叉戟柄，则他与真理残魂在这一层分开后，那柄戟第一次获得了在没有任何律令授权的情况下，仅凭接触即可对「虚假」实施强制矫正的能力。
- 若林恩从法阵边缘捡起一块融合了「毁灭—真理」双系法则的碎片收进系统空间，则 E692 中银色太阳将能通过感应感应到这块碎片，首次向他透露七十二柱中最早苏醒者的姓名，而代价是这道碎片被标记后，兽王复活的时间将再提前两息。
- 若林恩在最后一拳星寂前先反手将自己背后的一面血肉污染板放在面前充当肉盾，则那记拳头的轰击面会更大，第七层的结构破坏更重，但他自己不会在第一波法则洪流中被反噬得半跪，体表的伤口仅剩巴掌大一块。
- 若林恩放任魇的眼睛多说几句「工具」的言论，则他得知兽王之外的「另四根正在破封的石柱」早已被神界精锐预先布置在行宫第四层与第七层之间的任一条通路上——他所见的第一波梦魇合围只是诱敌，真正的死亡正沿着他们来时的路爬回来。
- 若林恩把「让我来毁灭你」这句话用金色序纹刻在虚空当中，则第六层坍塌的方向会微微偏上一尺，一道原本会砸向第七层的巨大法则轰击被他提前引向侧面，那位正在冲向第七层的真理残魂在疾驰中额发被掀起——他感知到了这个微小的庇护。
- 若林恩动手时主动让左左从系统空间伸出两指，夹住神格那一瞬间，则左左的本源将被提纯升华一瞬，她的身高永远固定在一米二，但身体的某一处（例如指尖或耳内侧）会第一次同步出现神王金纹——这趟旅程里她第一次真正与他的命运捆绑在了一条线上。
