# E360·堕天使幻境与魔君身份·if线

- 若林恩进入主母意识深处时主动先释放出那缕初诞者黄沙气息作为见面礼，则血月下的城堡视野会为他多让出一条前往魔门前的捷径，第一波恶魔围堵减少一半。
- 若林恩在火刑架前不立刻现身，而是先用灵能波纹扫一遍周围堕天使幻影的频率构成，则他能在记忆里标记出哪些是「真实复刻」哪些是「心障投射」，规避无谓消耗。
- 若林恩在主母低语「不愿一辈子留在这座坟墓」时现身主动接上一句「那就跟我走」，则她金色眸子在火光里抬起来，第一次有外来意识被她真正看见，幻境随之出现一个微弱裂口。
- 若林恩试图打断火箭队射出前主动用巨像网络里借来的克苏鲁深蓝能量抵挡第一波火箭，则深蓝与火焰在血月空中对撞燃烧，城堡外围观恶魔集体后退三步让出空隙。
- 若林恩在主母被锁链钉缚时主动赐名她一个全新代号，则幻影姐妹齐声抹除这个代号再念出旧名，主母本人却在意识深处多听到一次有人试图为她改名。
- 若林恩让左左从掌心探出一根细触手触碰火刑架木柱，则木柱渗出陈旧诅咒流入触手末梢，左左在意识空间呛得捂嘴，但获得「这火刑是心障非真实」的实物证据。
- 若林恩领着主母直接往城堡最顶端塔尖飞升，则天空自觉远离，那条始终摸不到边的穹顶反向压低半寸，他被迫承认单靠高度无法破界。
- 若林恩在主母低声问来者是谁时主动报出林恩二字，则她皱起眉茫然摇头，记忆里那一栏仍空，但听到「恩」字时唇角莫名一动。
- 若林恩承认「我就是那只渡鸦」，则她金色泪光一闪，幻境里所有恶魔攻势同时顿一拍，但她紧接追问「那你为什么不再陪我」，触发一段他无法绕过的解释义务。
- 若林恩不否认渡鸦身份而是反问「如果我告诉你那只渡鸦欠你一封信」，则她陷入长默，血月空中的火焰意外熄了三秒，魔门前浮现一条通往她的近道。
- 若林恩主动从灵能里捏出一枚微型渡鸦羽毛当作信物递过去，则她会盯着那根羽毛看上许久，某段被封印的「渡鸦真容记忆」被慢慢撬出一角。
- 若林恩带主母站在魔门前不推只立，则她下意识跟上却被旧规自动暂停三步，门的对岸传来一句模糊回响，「守门人不得推开」。
- 若林恩试图独自推魔门，则门纹丝不动但门内传出一声悠远叹息，主母听见第一反应是「那是他的声音」，她多年不敢承认的恐惧在这一瞬被按压下来。
- 若林恩在主母面前主动召出紫罗兰大君的魔纹形态，则围攻的堕天使幻影集体兵刃脱手，但主母本人在那一刻反向退三步，金眸里第一次浮现「愤怒与释然并存的泪」。
- 若林恩把魔君形貌仅显一瞬即收，则堕天使幻影的攻势恢复一半，但主母多得到一线确认自己并不孤独的余地，幻境心障松动一格。
- 若林恩在主母哭泣时主动伸手擦她的泪，则她攥住他的手腕不放开，意识海表层随之轻轻一动，现实包裹两人的十二金羽同步晃了一度。
- 若林恩在主母问「如果那只渡鸦看到我走出深渊会不会高兴」时主动答「会」，则她低下头轻轻嗯了一声，黑羽间浮起第三缕金色。
- 若林恩在主母问「如果它真的在火场会怎么救我」时主动抱住她做示范动作，则她僵了三秒后把头靠在他肩上，幻影城堡的火势在那瞬间彻底熄灭。
- 若林恩选择沉默停下幻境接触从意识海退出，则主母主人格的复归被推迟一个未定时长，但暗面反扑也随之暂停，现实恢复时间换得缓冲。
- 若林恩在主母说「不想知道更多猜测」时不追问也不解释，只是坐在她身侧陪着，则她在长默后主动把头放到他膝盖上，黑羽染金速度加倍。
- 若林恩在恶魔守门者嘶吼时主动朝它们挥出一句「退后」，则他体内那根与路西法相连的权柄引发共振，所有恶魔幻影瑟瑟发抖，但他自己也被权柄反噬出一道血丝。
- 若林恩在主母即将完全认出他身份时主动屏蔽那一缕交汇的气息说「先不要想起来」，则她的认知被温柔按下，但现实身体里的金羽染金速度也同步暂停一格。
- 若林恩主动从意识海边缘抓一缕灰色雾塞进她手心说「以后我不会再走」，则她捏紧那团雾，意识表层浮现一缕现实中才能产生的暖意。
- 若林恩在幻境即将消散时主动拉住她的手走向那扇魔门而非走向自己的出口，则她会愣在原地，过往多年坚守的守门教条被一寸一寸反噬崩塌。
