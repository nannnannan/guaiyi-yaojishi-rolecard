# E166·蓝星善后与夜医学徒去向·if线

- 若林恩在白逸抓住触手喊出「战友」的瞬间回一句「你刚才说『战友』两个字，比你前面三个月加起来都值钱」，则白逸首次从「不成器小弟」升格为「被大哥正视过的后辈」，成长线锚点加深。
- 若林恩在骂白逸「拆掉自己的骨头和血肉」时把自己左手当场撕下来、用那根断臂在白逸脸上盖章，则台词杀伤力叠加画面冲击，白逸三观第一次真正动摇。
- 若林恩故意不骂白逸、改用触手拍拍他的背给他顺气，则白逸的悔意没有立刻爆发，反而像被父母纵容的孩子一样更难自处，后续主动谢罪桥段前置。
- 若林恩在裂隙将闭时让左左多拽一把、把白逸也一并拽过裂隙，则白逸被顺路带到黑夜城见世面，「我和我战友一起游历地狱」路径当场打开。
- 若林恩在聚合体袭击左左时不吐它、一口咽到底、当场消化，则警备队追捕名单上首次没有这号怪、左左肚子里多一段「她吃过恶灵聚合体」的隐密档案。
- 若林恩吐聚合体之前先在它体内留一根跟踪触手，则它穿墙逃窜的方向全程向林恩直播，警备队获得实时雷达。
- 若林恩吐完聚合体后顺手把墙上血迹舔舐干净，则画面从「怪诞滑稽」滑向「真·疫医本能」，左左首次主动在他背后退半步。
- 若林恩决定不放它走、当场用触手拧成一团塞进系统空间标「蓝星样本 γ」，则警备队空手而归，总局那边的「恶灵聚合体收容失败」记录被永久挂在档案首页。
- 若林恩把「姑娘，我让你学的是知识，不是姿势」改成「姑娘，进了我的药房可不是脱了衣服就完事」，则荤味翻倍、左左当场从怀里探出小拳头敲他后脑勺。
- 若林恩在尹依决定留下时让她亲手签下一张「自愿不依附」的疫医字据，则归属契约反向锁死，恶堕调教路径在规则层面被永久封档，只剩纯师徒线。
- 若林恩不清澄奴役威胁、让「你是私有玩物」的暗示保留着，则尹依归属感挂在一个半悬的阴影里，后续调教教本可按默认推进。
- 若林恩主动向左左介绍尹依是「新徒弟、你的学妹」，则左左首次以「学姐」身份自居、对尹依的保护本能全面启动，调教路径上多一层学姐审查门槛。
- 若林恩在清点利维坦血肉九十一公斤的代价时故意叹气吐槽「这买卖亏本」，则系统弹出「疫医经济学+1」的恶搞成就，左左气得揪他耳朵。
- 若林恩把那一元硬币与五十一套特战服杂物一并当作「蓝星土特产」分赠给艾雯爵士与左左，则黑夜城住民首次收到「蓝星货币+军品」组合，跨世界外交出现彩蛋。
- 若林恩主动把那把会燃烧的刀扣下来、不让白逸带回，则白逸第一次真正失去了父辈遗物，「战友」二字的重量被真正用实物衡量过。
- 若林恩让左左在「加把劲！献祭给地狱的利维坦血肉要消耗完了！」后再加一句「你再拖拖拉拉我就咬你」，则拽出动作从「救」升级为「主人式催逼」，双生羁绊主动权重写。
- 若林恩决定不向尹依提夜医学徒、直接安排她进黑夜城日常当普通居民，则她从「候选学徒」退到「被保护的游魂」，调教与成长两条线同步关闭。
- 若林恩在骂白逸时把「我会拆掉自己的骨头和血肉」的原话改成第一人称示范——「像我上次为大哥差点当信标那次，你懂个屁」，则白逸首次听懂「大哥」其实是一种「作法」而不是「身份」。
- 若林恩让左左把林恩拽出裂隙的瞬间回头和白逸比了个剪刀手，则画面被白逸永远印在视网膜上，「我大嫂绝对不是人」的认知第一次成型。
- 若林恩决定顺手把白逸拽去检查包扎、把他按在黑夜城的病床上过夜，则蓝星总局第二天发现「白逸失踪」并启动新一轮搜查，跨世界误会再叠加一层。
