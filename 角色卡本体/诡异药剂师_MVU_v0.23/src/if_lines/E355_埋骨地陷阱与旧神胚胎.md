# E355·埋骨地陷阱与旧神胚胎·if线

- 若林恩在踏入白雾前先用灵能朝雾区深扫一圈再前进，则他会提前几分钟发现浓雾边界被刻意拉扯成漏斗形、来客正被雾往预定口袋赶。
- 若林恩朝巨像之脑要求她退在雾外待命、只派他一人深入，则巨像之脑第一次不会同意、她会用巨像之心的共振把他钉在原地不动，对峙被记入她对他的边界共识。
- 若林恩在白雾中主动让克苏鲁之眼透出体表一寸当作探针，则眼睛的跳动会直接指向胚胎方位，但他在事后被这枚眼睛反过来嵌入了一段不属于他的旧神记忆残片。
- 若林恩朝雾里最先出现的那具旧骸伸手要拉近距离，则骸骨表面会瞬间爬出血肉藤蔓把他双臂缠住，巨像之脑从外圈只能冲近一步把他掀离。
- 若林恩在巨像之脑判断为「旧神葬区」时主动开口说「我们撤」，则疫医的提前伏击不会在那一刻启动，但退路本身已被血肉巨鲸从三个方向按住、撤退的另一端变成新的遭遇战。
- 若林恩在血雾扩张瞬间主动朝雾中灌入一缕黄沙，则黄沙只能短暂点亮一条一丈长的空道、三秒过后黄沙被雾完全吞没，他后续要再次使用必须付出双倍的灵能成本。
- 若林恩让左左先跳出自己的身体化作外部肉身作战，则左左首次以独立形态参战、她的咒纹在血雾里烧出一小片净空，但这个动作同时把她从他和巨像之脑的网络里剥离。
- 若林恩选择背起狱卒遗体向血雾中心强突，则封锁会在他突破的路径上被无序湮灭、但他自己每走一步皮肤都会被无序腐蚀出一道新伤口，他这次突破的代价是几十道深可见骨的刻痕。
- 若林恩让巨像之脑负责撕开血雾，他自己专心护住遗体，则巨像的甲胄会在十几秒内被怨念撕得七零八落、她的血肉碎片散落整整一圈，但她的网络意识反而因为剧烈威胁而更活跃。
- 若林恩顺着克苏鲁之眼的指向在雾中偏离主路一头侧向，则他会发现疫医在外围真正集结的预备陷阱，这一条偏路让他提前看到了主围杀圈的后手。
- 若林恩顺着克苏鲁之眼的反应主动深入到胚胎所在位置，则他第一次得见整头由血肉与白骨串联的巨型胚胎、它的第一次尖啸会让他踉跄后退三步。
- 若林恩朝下走近胚胎时主动释放蓝龙一脉的气息做引，则胚胎的膨胀幅度先短暂缩小、但紧接着膨得更大，他第一次意识到这具胚胎对血脉象征的敏感不是温顺、是饥渴。
- 若林恩在残念接触时主动把自己的以M气息掺进灵能，则残念接触瞬间会有一段短暂的混乱，但片刻后那段混乱转化为对他单独的注意力，他被残念首次主动记住。
- 若林恩拒绝用灵能碰残念、只用意念投射慰问，则残念不会反噬他的意识、但他们也不会真正靠过来，那一夜的胚胎和残念都没有明显变化。
- 若林恩主动在胚胎周围以黄沙画一个无瞳法阵而不是直接用灵能，则法阵会缓慢点亮、残念会以更慢的速度靠过来，整个过程要持续数十倍于默认时间但更稳。
- 若林恩在巨像之脑警告「根源级怪物」时反问她「那它能被引导吗」，则她会首次承认「理论上可能、但你得先问它愿不愿意听你的」，把能否催化的判断权交给他自己。
- 若林恩在巨像之脑问及救援主母的判断时，主动说「先把这头胚胎稳住再看主母」，则她会当场记下他对主母救援的优先级排序，作为后续行动里她对他做安排的重要依据。
- 若林恩在巨像之脑追问「这样靠近能撑多久」时主动回答「再看一次」，则她会与他达成一份「只看一次、之后立刻撤离」的口头协议，这份协议在她后续任何越界动作里都会被她自己提醒。
- 若林恩在尖啸缓和的瞬间突然对胚胎唱一句幼时夜医们的摇篮曲，则胚胎的起伏节奏会第一次和那支摇篮曲同步，巨像之脑会首次对他另眼相看。
- 若林恩在撤离埋骨地前主动用一根触手从胚胎表面剥离一枚残片带走，则残片会贴在他掌心持续发热一整夜，那一夜他在梦中第一次听见它没有说出口的「名字」两个字。
