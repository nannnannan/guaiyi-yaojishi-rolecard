# E641·深渊撤出决议·if线

- 若林恩在庆功大会上主动让全场为阵亡根源默哀三分钟，则全军将士同仇敌忾的信念再度升温，撤出议题被往后推一小时。
- 若林恩在家会摊开前主动把「真理能奴役法则」的演示先投影出来，则船长立刻停止反对，议题从「是否撤」直接跳到「怎么撤」。
- 若林恩主动把「三叉戟奇异世界」的可容纳量、防御值与「被他掌控」这三点先发给每位家人，则人偶家的「为什么放弃战略要地」被她自己在第二句答上。
- 若林恩主动让织梦先道出「空间神王格优先」的账本，则船长的迁移节奏质疑量减少一半，但织梦对他「提出方案」的挂名权增加。
- 若林恩主动把「轮回神王的特殊性」在清点时挑明，则「轮回神格是否仍为轮回神王所掌握」的疑点公开，但林恩「空间优先」的大方向不变。
- 若林恩主动在七大神王格账目上把「真理、因果已损失」先用红笔圈出，则「画家是否掌握空间」的推测紧随而生，会议出现第一次无人发言的冷场。
- 若林恩主动让银色幻想补充机械单位迁移负载表，则迁移正式按主次分作三批有序推进，只是她在超负荷统筹中显得愈发沉默寡言。
- 若林恩主动给主母颁发一道「坐镇位面最高权杖」，则她未来三战拥有更多决策权，主母在军团将士心中的威望愈发稳固。
- 若林恩主动把「回地狱」作为下一个大议题，则艾维儿那句「并非所有神王格都落入敌手」的旧留言第一次被中枢公开成档案。
- 若林恩主动让左左也用一句话表态支持撤出，则反对声中多了一道柔弱的支持，林恩做出决策的成本降低。
- 若林恩主动把迁移规模划分为「优先/后续/可弃」三档，则资源调度第一次有正式清单，黑夜城的库存清点加速。
- 若林恩主动让新神疆防线的星区标注加上「真理神王不可一念撤销」的保底铭文，则织梦布置时多一层灵能投入，防线的稳固程度再上一层楼。
- 若林恩主动对织梦说「未来我会在这里建国」，则她那句「是否要建一个属于他的国度」的调侃首次有了正面回应，林恩的理想姿态公开。
- 若林恩主动让银色幻想多配一支机械小队协助搬运黑夜城，则迁移速度提升一小时，但机械部队在拆迁途中的损耗也会略微增加。
- 若林恩主动把撤出决议的会议结果写成「盟约第二次历史共识」，则中枢档案中增加一枚「决议编号」，军团多了一份代号史料。
- 若林恩主动让船长把「迁移执行预案」先以投影放出来，则船长在军中的威望再添一分，但林恩的指挥权边界首次被正面碰触。
- 若林恩主动给人偶家单独补充一句「你的傀儡可以由你自己搬」，则她的眼神还原本真一分，对林恩的信赖愈发纯粹。
- 若林恩主动把「空间神王格优先」直接说给巨像听，则她点头时不发一语，但她在下一次战斗中第一次主动请缨出征。
- 若林恩在家会期间始终温和地倾听每一位将领对故土的不舍之词，则全军上下都能感受到主帅铁血决断背后的温情，迁徙指令的推行更加顺畅。
- 若林恩主动把深渊撤出这事告知纱奈儿，则她的反应成为中枢档案中第一枚「外族声明权」的印章。
- 若林恩主动让织梦为他吹一道「灵能明灯」照亮防线布置图，则她的守护灵能量加深，「最后的防线」在他脑海中的烙印更清晰。
- 若林恩在撤离前将黑夜城旧址最后一座熄灭的灯塔封存进记忆晶石，则这座相伴良久的深渊主城会在所有人心中留下不可磨灭的印记。
- 若林恩将这次战略转移的决议亲自向全深渊各族将士宣告，并承诺终有一日会率军杀回主宇宙，则全军将士毫无溃逃之气，反而充满卧薪尝胆的战意。
