# E243·斩断血肉支配者投影·if线

- 若林恩在苍蓝色流光形成之前先让巨像之心把能源路线设定成"饱和供给残余回路"，则机体的初始速率+15%，但机体的机能破损被提前点燃，事件以变形（能源处置后不利）收束。
- 若林恩在一刀斩落之前先在右臂接一段药剂增强带并把白夜的呼唤声引入耳朵，则他的战意更强、发刀速度+20%，事件以变形（更快斩落）收束，但白夜的提醒令他的思考略乱。
- 若林恩在斩断投影时故意不将机械能量用到100%、留一些以防血肉支配者重构，则投影的重伤度减小但机械机体以能量配置护住自己并免除了直接的损毁，事件以变形（保守斩致非重伤）收束。
- 若林恩让左左在机体左面替他喊出"出击"的一声，则她被震撼+10%，事件以变形（她加入出击）收束，多一个小角色亲身的出场。
- 若林恩把单分子剑的回响波动调成一个全屏太阳，则投影"被刺眼的光芒所慑"导致他的撤退路径预判错误、第一场对战举步维艰，事件以变形（初战诡谲光污染）收束。
- 若林恩在120%负载下让系统警告转成屏幕上"能源耐久10%"而机械机体仍强悍如初，则整场战斗的能源消耗被精确排列，事件以变形（能源耐久残留10%）收束。
- 若林恩在斩击前补充补一句"我打算用巨像之心的真正能力"，则投影听到"巨像之心"三个字的瞬间情绪暴躁、其后续战斗模式变成以反巨像之心为主，事件以变形（投影作了无谓调整）收束。
- 若林恩在斩掉一半投影后将另一半投影通过一刀反向斩落的姿态录屏存档，则他在一劈以后获得另外一战完整的视角材料，事件以变形（额外记录）收束。
- 若林恩让白夜远远观看他120%负载时呼喊"你享受吧"的台词，则白夜的反应从"惊呼"变为"激动咆哮"，事件以变形（白夜介入评论）收束。
- 若林恩让机械机体的双眼变成模拟流星的风景色彩，则他的战斗美学变得更耀眼而美丽，事件以变形（视觉画面改变）收束。"
- 若林恩在出斩前中包含一个额外灾变的新月岭极致束缚，则投影的动作可以被电流禁锢更长的时间，事件以变形（更长禁锢）收束。
- 若林恩从一开始就用"机体信仰"为主独裁自己的决断而非思维所值，则机体每一次发动攻击时他看到的眼费是"究竟在保护谁"的自家对话，事件以变形（机体被精神联结）收束。
