# E585·天堂遗址与血枢残骸·if线

- 若林恩拒绝耗灵识斩出末刀，则入场窗口可能错失或改走更险投影贴脸分支，天堂之战口述仍可立，但灾厄投影的降临时间被进一步压缩。
- 若林恩拒绝靠近残骸或拒开超维链接，则残骸定性与链接确认延后，以太躁动与屏蔽事实仍作已知，但左左的剧痛被无限期悬置。
- 若林恩在口述天堂之战时主动将「入梦者活了下来」补充为「入梦者可能至今仍在」，则三位一体的联想层被向前推进一格，左左在这段中竖起了耳朵。
- 若林恩在连续时间战争护航时主动也开启时间裂隙欲助战，则一瞬间他被来自未来的自己以无形之力反推，「那是我的战争」的信息以冲击波形式打回。
- 若林恩在乌鸦长鸣时主动以同样频率发出一声鸦鸣回应，则时间长河外某种存在予以确认，未来的航道被他用一声叫声点亮一角。
- 若林恩对左左说「你斩出你的全部就行，我来扛后果」，则左左一生最强一刀的边界向更高处推进，她的刀光斩出后他的防护网被波及。
- 若林恩在恒星炸裂垂直坍塌时主动让左左躲入自己怀里并用翅膀遮蔽，则左左紧咬他衣角没有惨叫，她的灾变萝身在这一瞬得到一次极端温暖的验证。
- 若林恩在进入遗址前先以系统空间投影出一份地图并标记坐标，则遗址内部残缺地形的推演先行，但他确认「这里超出任何坐标系」。
- 若林恩在撞到不明悬浮物时先用初诞者之力包裹住自己再靠近，则撞上前的晕眩被削弱，他更早识别出血枢头颅。
- 若林恩在以太出现挣扎征兆时主动以心灵法则压制它，则封印表层被暂时加固，但他的精神力在下一分钟出现断层。
- 若林恩在确认巨像共鸣时主动把这种共鸣反向引导到魔躯细胞，则他的手背浮现与血枢类似的血肉纹路，本体与外来血脉在他皮肤下完成一次无声的对话。
- 若林恩对左左说「如果你痛我们就回去」，则左左摇头把左手掐进他掌心，她的坚持让他确认她需要的不仅仅是他的保护。
- 若林恩在超维链接中主动尝试与血枢的意识光点对话，则没有回音但光点的聚集速度微微变化，血枢记忆层的模糊扰动被他主动确认。
- 若林恩在尝试镇压炼化血肉时放弃炼化改为封印，则血肉被完整保留但活性被锁定，猩红核心的成形前兆被按下暂停。
- 若林恩在离开尸骸区前对血枢最后一次鞠躬，则虚空中的猩红心跳在他背影转身的瞬间难得地平复了一拍。
