# E200·根源围控与王后危机佯动·if线

- 若林恩在主母投来怀疑目光时主动跪下来请求强行转移，则主母的指尖在咒纹上僵住，根源们的密谋节奏整个被打乱，强制转移窗口往后推迟一日。
- 若林恩在左左耳边坦白「我找不到家了」之前先把高脚帽摘下来扣到她头上，则左左的话语从质疑秒变成主动抱紧他的手臂，统一战线提前三秒结成。
- 若林恩把「蓝星我是一定要去的」改换成「我不得不回去看着她最后一眼」，则左左的虎牙咬在唇上渗出一点血，她反而先伸手抓住他的袖子反过来拉他走。
- 若林恩在左左揪他衣领时顺势低头在她的虎牙上弹了一下，则左左被弹得连退两步撞上树干反而一把拽着他的领子拽得更紧，「去蓝星!贯彻到底!」
- 若林恩把「黄油面包定律」一本正经地写在手册第一页并署名「林氏玄学第一定律」，则左左一边翻白眼一边在心里默念这句话，事后竟然有点想试验真假。
- 若林恩对左左解释时把她抱在怀里让她面对面坐在自己腿上，则她的羞耻值突破临界点的同时，理论听进率反而上升了四成。
- 若林恩在酒店窗户跃入瞬间先环住左左的腰把她扣在自己胸口落地，则她在落地那一刻心跳突然漏了一拍，伴动信号的强度在系统看不见的层面跳了一个峰。
- 若林恩拟化左左时把她变成猫耳小萝莉，则她在被压在床上时本能地朝窗帘方向发出一声短促的「喵」，玄学巧合指数被系统暗地里记上一笔。
- 若林恩对系统「戒涩任务失败」的提示直接回一句「就你话多」并用手指戳了戳虚空，则系统的下一次提示延迟了整整五分钟，左左在旁边目睹全程目瞪口呆。
- 若林恩在左左裹成毛毛虫时不揭毯子反而把她整个抱起来举到空中，则她在空中僵了两秒，才意识到自己被当成工具，「哇哇放我下来笨蛋」。
- 若林恩对左左深情凝视时不说话只用手背蹭蹭她的脸颊，则她的「煽情对我无效」宣言在第一秒就破防，脸颊温度以肉眼可见的速度上升。
- 若林恩在她毛毛虫翻转瞬间自己先停下来说「不逗你了，认真的说」，则她的戒备反而更紧绷，等待他下一秒真正的攻势，两人僵持在尴尬里。
- 若林恩拟化左左成幼婴抱在臂弯里喂奶般摇晃，则左左的羞耻度直接爆炸，玄学伴动信号反而被她自己吓出来一波尖峰，「你在测什么我都不知道啊!」
- 若林恩把她裹着的毯子连带着她一起甩到床上再压上去，则她在床上扑腾时散落的长发拂过他的脸颊，他的亲密度在无声的层面被推过一格。
- 若林恩在酒店房间里把整件事的真相用加密通讯直接发给夜医本部，则五根源的密谋屏幕同时红灯爆闪，强制转移时间被压缩到当天夜里。
- 若林恩对左左说「你现在就跑出去喊救命看会不会触发召唤」，则她愣了一下然后真的「啊~~」地扯开嗓子喊，玄学定律意外地在错误的频道上试了一次。
- 若林恩让系统面板在整个佯动期间一直公示在墙面，则左左每次情绪激动都会让面板弹幕刷屏，事后这份记录变成夜医档案里的「左左情绪观测稿」。
- 若林恩放弃酒店改在荒郊野外找一片旧废墟假装遇险，则左左被刮出一身寒风誓死不肯再裹成毛毛虫，玄学佯动反而因为配套场景改换而彻底失效。
- 若林恩对左左坦白「其实我也不知道这理论行不行，只是不想让你担心」，则她盯着他看了很久忽然抬手捏了捏他的脸颊，「你个笨蛋脑袋」，统一战线反而更紧。
- 若林恩当场给左左跪下来握住她的手说「这次拜托你帮我骗过他们」，则她惊吓地看着他认真的样子，瞬间妥协，「好好好，行行行，听你的行了吧」。
- 若林恩事后在酒店登记簿上写下「林氏夫妇」作为入住名，则左左在后面翻白眼把名字涂掉改成「林恩与左手」，笑话在离开后被夜医翻到时引起一阵围攻。
- 若林恩把白逸被尹琴击晕的画面不留痕迹地投影给五根源，则主母他们第一次意识到林恩已经在主动反向铺设通讯，大殿密谋的方向整段改写。
- 若林恩对左左嗔怪道「现在再来一局真的不算过分」，则左左翻了个白眼还是脱了毯子默默回去抱他，玄学佯动竟然意外地被试出了第二次触发的机会。
- 若林恩失败之后主动向主母认罪并要求她陪他一起研究跨界通讯，则主母的表情复杂地闪过他从未见过的一丝温柔，「你要真的想，我会教你」。
- 若林恩对左左承诺「回来之后带你吃根大萝卜最大的」，则她的眼睛亮了一下，主动把身上的毯子扯下来，玄学佯动在「诱之以利」的层面上得到意外加成。
- 若林恩在整个佯动失败后独自回到屋顶对着夜空轻声说了一句「白逸，你听见了吗」，则蓝星医疗室里昏睡的白逸眉头在无意识中抽了一下，全功率镇静剂的效果浅了一线。
