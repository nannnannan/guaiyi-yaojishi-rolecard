# E520·时间战争启动·if线

- 若林恩在时间裂隙中先朝远处小小／老头的残影投一枚定位符而不是只旁观，则未来某条时间线中他能在该时空插上一枚可操作棋子。
- 若林恩选择让左左在清剿污染者时也参战而不是只辅助，则左左首次真正斩污染者，她的刀法成长路径提前。
- 若林恩在「不要干涉历史」的准则上做出例外——主动救下一位本该死在该时空的人，则该人回未来某处出现，蝴蝶效应账开始计。
- 若林恩在54次时间战争完成奖励面板前选择不领取而是继续刷第55次，则他积累更多但错过回会时机，会议厅等他的众人不耐烦。
- 若林恩在完成第54次时选择将奖励换成「回到过去某一点专门观察」，则他获得情报型回返而非战斗型，稿本的成长形态不同。
- 若林恩决定让左左在某次回返时空手而归，则她受挫后独自修行，刀法路径从「伴随」变成「独处磨枪」。
- 若林恩在清剿污染者时主动保留一只活口准备审讯，则该污染者可能被带回现实作为战俘，情报线延展一条。
- 若林恩选择不戴面具而裸脸穿行时间裂隙，则他受到时间乱流的反噬，每次回返后头痛，神王切景那张脸对林恩辨识难度加大。
- 若林恩决定给左左配一柄专属武器而不是公用夜魔刀，则左左的刀路更稳定，但她失去「左手一刀」的标志性。
- 若林恩在魔人协会总部外节点时选择不向小小／老头残影隐匿而是招摇走过，则学徒时代的自己可能察觉一道熟悉身影留下遥远印象。
- 若林恩在会议厅现身时不入场而是站在门外听完全部会议，则他错过「参会认强」的画面，但获得全面听众视角的情报。
- 若林恩选择在银幻调侃时反调侃「智械小姐也想双修吗」，则气氛从微微一笑变成暧昧上扬，银幻「电量+1%」变成「电量+2%」并伴随耳尖泛红。
- 若林恩在会议厅强调时间战争参战时让左左拉出「看到他一直在打」的证据，则左左作证，林恩不需要自证，赢回信任的路径更短。
- 若林恩决定拒绝说明时间战争的存在，则众人只看到他的变强现象，恐怖猜测蔓延，信任轴改写。
- 若林恩在左左摸头「狗头」时不口头叮嘱而是沉默任何情绪，则左左心中多一段「脑袋不笑了」的反思，她后续独立成长加速。
- 若林恩选择在第54次时突然停止时间战争转向专注新躯体适配，则「更久远时间点」权限不兑现，但他的「三位一体完全体」进度提前。
- 若林恩在时间战争过程中尝试让其他家族成员（如主母）同行，则由于她们的时间先天承受力不足被强制遣返，林恩学到「只有我能走这条路」的冷酷边界。
- 若林恩决定把渡鸦尸躯容器机制的原理记录在笔记中交给船长研究，则船长成为这一秘密的知情人之一，合作网扩一环。
- 若林恩在清除污染者时主动尝试活捉渡鸦尸体而不是让其散架，则获得一具可研究的样本，未来某次炼金/召唤时可调用。
- 若林恩选择在会议厅离席后不立刻回房而是去找主母／银幻单独谈话，则「仰头闭眼回屋」的孤独画面被替换，心理状态稳定度上升但孤独感减弱共鸣。
- 若林恩决定让艾雯为他制作一件脑波稳定器辅助时间战争承受，则54次积累的负荷减轻，但欠艾雯一笔人情。
- 若林恩在时间战争间歇时去向小小／泰坦讲述未来预言，则两位非参战者产生别的成长路径，未来战场分布改变。
- 若林恩选择不说明参与者只有「自己+头顶」而是含糊「还有别人」，则众人对情势的想象力放大，恐慌与决心同时上升。
- 若林恩在「奖励回归后发放」退出机制选择上主动锁定「立即发放」，则他在回返前即领取能力，下一次回返时能力值更高。
- 若林恩决定让主母／银幻也尝试时间裂隙行走一次，则她们可能瞬间衰老一秒／机能失调或被时空屏障排斥，林恩确认这是独行路径。
- 若林恩在会议厅被问「为什么要做这个」时选择说「因为我不知道该干什么」，则氛围从坚定变成迷惘，众人对他的信任轴改由「同病相怜」承载。
- 若林恩选择在左左肘击镇压时让左左「这次让她喊一声」，则她可能在那个时点发出一声短促喊叫，被过去自己捕捉到一线回声。
- 若林恩在荒野清污染时遇到一只熟悉但已被污染的过去盟友，则他可选择杀或放，Karma账多一笔「过去也曾是朋友」的债感。
- 若林恩决定让巫神头颅随行观摩时间战争入口，则巫神头颅作为旁观者进行一次精神检测，他可能领悟某些与林恩不同的洞察。
- 若林恩在事件结尾不向艾雯说明坠落神明污染/潜伏可能而是独自调查，则他错失会议厅集智的机会，但形成独立调查线。
