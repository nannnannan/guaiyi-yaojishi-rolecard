# E692·神王的国度与镜面的魇·if线

- 若林恩踏入金色法则风暴时先用一缕梦境护在脚腕上稳定自身，则那股狂暴的力量不至于把他直接掀飞，他能从风暴缝隙里读出地面上铭刻的一行旧式中文连笔：「为未能归返之人留一盏灯。」
- 若林恩收拢意念不去抵抗法则风暴，而是尝试以初诞者之力吸入其中一缕，则这缕被吸收的力量将化作他迄今为止最精纯的护体甲，无论是贴身的衣物还是潜在的神格残余都在体表上烙下一层极浅的金壳。
- 若林恩没躲开那支漆黑长枪而任由它撕开颅骨一表皮，则那位镜面之魇会以一道本可通过换来避免的必死之伤开局，他必须在 E693 起手时以自己的血肉为阶梯爬出这一段血路。
- 若林恩在长枪刺来瞬间反手接住那杆枪身，则那柄神器会顺着手臂隐隐长出第一个倒刺，他从此在 E693 开始与真正的敌人交手时已不需要武器脱手的顾忌，但手腕上每一道青筋都永久记忆了那个被复制的怪物在他身上烙下的第一道侵入式印记。
- 若林恩事先察觉那些疯狂的无序力量可被梦境领域的小模样所吸收，则他能在 E692 起手时通过某种法则伪装，让自己在他踏足之处的法则波动中彻底消失，镜面之魇必须在第一次与他照面时就凭着直觉而非法则追根溯源。
- 若林恩尝试以钟声扰乱这万年无人敢触碰的无规律风暴，则他会听到从那个已经残缺的神界核心的最深处传来一声极轻的回应——通道就在他脚下，只要他踏进去，他将再也无法从另一侧沿着自己记忆中的来路离开。
- 若林恩没有听信银色太阳让他「逃」的催促而是拖着半条命的身躯小心展开梦境领域，则他能在那面镜子最幽暗的角落里多待半刻，但他无法阻止一枚极细小的镜片悄无声息地嵌进他的颈侧——那个被复制出来的影子从此有了自己无比清晰的意识。
- 若林恩在镜面裂缝中第一眼看到的就是他幼年时趴在床边吃糖果的自己，则那道裂缝会在半空凝固下来，他能对视那双原本属于自己、但眼下已被毁去灵识的漆黑眼睛，问出此生最不敢问的问题：「你认不认得我？」
- 若林恩让左左在对抗风暴时伸出双手抱着滚进他前面充当护盾，则那只幼龙在滚动中被一根骨针穿透左侧翅膀，从此她的身高永远不能突破一米二整，但她用一生中全部的血把林恩护出了自己的血脉最后的重量。
- 若林恩让渡鸦分身先在金色风暴外环一遍探路而不是直接进入核心，则它会在折返时把第一道镜面之魇的气息先行带回，林恩立刻意识到那个尾随自己的并非寻常怪物，而是已经开始复刻他气息的「他自己」。
- 若林恩问画家「神格里里长期酝酿的屏障怎样才能越过」，则那个自称本应死在千百年前的古老神格会主动睁开眼，为他指出一条不曾被任何人走过的、可以通往权力核心的捷径，它就藏在他的指纹尽头。
- 若林恩让那只可怜的渡鸦沿原路返回悄悄探路，则在 E693 开头他会拼死折回把自己撕成九百九十六段化骨铺路，林恩能够在那座他曾踏遍的神界入口处为一只没名字的异界使者搭起第一座桥。
- 若林恩用精神链接触碰了一下身后处处受掣的空间界域，则他踏贯那道裂缝时会发现自己的意识被一股前所未有的混乱所包围，同时他意识空间中的一切都会被涌入的这一缕伟大幅度所击垮。
- 若林恩把梦境领域压缩到百米内再贴着自己行进，则金色风暴从他身边掠过时他自身的气息会被这层涟漪屏蔽一拍，镜面之魇第一次失去主动追杀他的方位，但同时也意味着这层领域只能用来遮蔽、不能用来反击。
- 若林恩向那个充满神秘感的神祇追问同样的问题，则他会经历前所未有的自我启示之旅，随后在这个因为过于真实而变得不真实的恍惚中唤醒他的力量——他获得了独一无二的先决条件。
