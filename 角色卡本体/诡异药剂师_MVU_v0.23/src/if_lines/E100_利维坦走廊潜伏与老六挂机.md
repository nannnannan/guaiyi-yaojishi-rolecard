# E100·利维坦走廊潜伏与老六挂机·if线

- 若林恩拉开烟雾弹保险前先朝左侧走廊掷一支镇静药剂，则一侧复制体动作整齐滞一拍，银色幻想起手杀阵偏向那一侧，血肉搜刮样本多一道「被镇静过的疫医残肢」标签。
- 若林恩在催动血肉灾变瞬间把喵喵从怀里抛出落地猫形态自保，则她不随他贴肉壁、不共享恶灵视角，潜入段换成她蹲在远处舔爪监督，「哥哥姐姐加油」场景改写成她瞥过来一眼。
- 若林恩的血肉灾变更彻底压成纯死肉、不留神经虹膜，则监控视野全场归侧墙眼球堆，他失去全局观察位，但憎恶者 3 号落地时不会第一眼往他墙方位向。
- 若林恩保留更小人形态爬行代替眼球贴肉，则警戒名单多一条「小型异物」标记，他被某个走廊深处疫医护士当伤兵拖走，挂机模式被迫中断。
- 若林恩主动贴合走廊顶端菌膜缝隙当壁虎挂机，则脱离常规眼球队列，没人识别他，但利维坦警报模块会把他归类为「未授标监控」单独写入告警日志。
- 若林恩在烟雾中先用左左卷住最近一只疫医复制体拖来充当就地取材，则他能直接侧切一块活体样本塞进系统空间，但那只复制体死亡回响会让墙体附近监控瞳孔集体回望一秒。
- 若林恩把乌鸦面具扣在贴墙的眼球拟形外，则「疫医监控眼球」整体身份多一层诡异符号失真，315 博士远程日志里多一条「该走廊 NA 监控异常」备注。
- 若林恩在银色幻想浴血突杀时主动用心声指挥爱丽丝「把她往内层大门方向引」，则杀入路径偏移，「精神鼓励」场景由他身上剥离到银色幻想孤军推进深处，核弹爆点向后移。
- 若林恩主动让左左从眼球里探出细长触手触碰墙体死气，则她首次直接接触恨意聚合，绑定校准参数 +1，但她一整段挂机期都在意识空间干呕。
- 若林恩用咒瞳反向扫描银色幻想背影队列，则视野被她机体反扫描锁住半秒，恨意在挂机期就先行结算 +10，涩涩度另起一行小字「他敢看我」。
- 若林恩在憎恶者 3 号被推入走廊前就主动朝它的诞生容器掷一支夜医应急血包，则容器封皮破口、混合制剂渗入,3 号诞生时带一缕疫医路径偏移，后续舰上转会组圈定「走廊异常批次」。
- 若林恩在爱丽丝共享恶灵视角瞬间主动多录三秒站位密码，则他垄断该段走廊布局，但作为成本，他眉心多一缕由恨意直接烧进去的灰线。
- 若林恩把精神加油改成恶作剧视讯——指挥爱丽丝/左左/喵喵齐喊「左边那个复制体特别瘦」，则三只疫医复制体被心声撩得分神，银色幻想背后压力骤减，「协助特征」首次录入万机之神副档。
- 若林恩趁混乱多埋六枚手雷并提前拉住银色幻想衣角示意，则她首次没一剑劈开他伸出的左手，默认配合一次回避，核弹爆点偏移形成长廊侧厅安全口。
- 若林恩在核弹触发瞬间主动朝反方向贴墙撤离，则他被气浪掀飞的路径偏到另一侧旁通道，进入 E101 时落点是小队长洛什正面视野。
- 若林恩在飘向内层大门的中途用一根触手勾住走廊末段一颗监控眼球残骸一起带走，则事后他拿到完整疫医监控模组，但同帧银色幻想破门后回头瞥见他被卷走。
- 若林恩被气浪掀飞瞬间主动朝银色幻想破骂一句「机械婊子」，则她在核弹火光里确实渺了一眼，恨意结算在该瞬间 +15，潜台词多一行「他知道我炸了」。
- 若林恩在挂挂机期间当场检索系统商城，订购一套疫医复制体备用零件，则物件平生落在他手边但产生一条「E100 时空差」交付记录，万机之神日志多一行诡异条目。
- 若林恩挂机时反向调用视野释放出一缕以M气息，则贴墙附近疫医复制体体表行为分层紊乱一线，警报通报多一条「该走廊出现以M痕迹」。
- 若林恩施放血肉灾变前主动对左左说「这次挂机我主导，你坐着看」，则她硬生生憋住没顶撞，挂机全场只在林恩意识里咬耳朵，绑定关系在该瞬间多一笔「她被主人打压在心」。
- 若林恩把咒瞳扫描视野压在银色幻想身上全程追踪，则她起手斩杀时被记录进他面板全份姿态，事后他多了一个「机体全解第二版」档案。
- 若林恩决定全程不搜刮血肉素材只挂机静观，则内层大门冲击成立但被系统标记「采集经验 +0」，利维坦感到一段异常秃点在走廊表面浮现。
- 若林恩选择挂机期内主动休止一切思维、放空成纯畸变模型，则破晓 315 博士凯期远程扫描到他时只读到「纯利维坦组织」，他首次被永久标记入疫医档案「非常规走廊组织类型」。
- 若林恩在核弹爆炸那一秒朝自己被炸开的方向主动多释放二重血肉增生，则火舌烧不透他根骨，但他会以胖子状态飘向内层大门，后续现场被发现时疫医复制体以「眼眶内出现异物」警报。
- 若林恩完全拒绝挂机、主动变身疫医护士加入两侧复制体包围圈，则他被编队某小队长按照脚本分配赴死队列，提前进入「疫医掩护身份」路径。
- 若林恩在贴肉挂机期主动朝破晓 315 博士所在的深处隔空传一句心声「你的恨意扰动一条劫机潜入游线」，则博士枯手停顿一秒，315读到的不是悦耳之声，而是林恩的疫医术话。
