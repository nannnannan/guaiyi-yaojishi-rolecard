# E690·承诺与两不相欠·if线

- 若林恩听到银色太阳的忠告后先把手伸向心口确认那枚龙心仍在自己掌中便打断下方进展，则他不会立刻听到后续「因果」二字，但他在 E691 开局的惊愕中足足多了一刻钟的准备时间。
- 若林恩在真理神王现身前就主动解开三叉戟柄上的真理律令烙印放在掌心，则烙印会化作一缕金光钻入真理长袍下摆，那位神王的灵体波动第二次靠近时没有第一次那样冷漠——他第一次获得了一位真正「发过誓」的盟友在法理层面的感知。
- 若林恩没坐下而是立在原地让真理自己决定是否坐起，则那位半透明的神王会起身，负手而立，金色纹路在他脚下铺成一块小圆桌，他自己向林恩伸出手，第一次以对抗者的姿态而不是王者的姿态伸出了邀约。
- 若林恩在真理抛出龙心、说「谁也不欠谁」的那一刻手一松没接，则龙心会继续悬浮半空一刹才真正落入他怀里，那一刹里两人四目相对，真理的冷漠与林恩的复杂第一次在没有攻击意图的情况下被真正看见。
- 若林恩没隐瞒自己曾在第三层的石柱上看到过的那根与他自己一模一样的浮雕，则真理的眼神在那句话落地后会有一瞬碎裂，理性在他身上不是铁板一块，而是可以与恨意并存的另一种形态的痛——但这癫狂只持续了半拍就被新的平静压住。
- 若林恩问真理「若这个世界终将迎来终焉，你这枚龙心是否也会落入那个深渊」，则真理会告诉他：它不会，因为它是用他母亲的最后一点光铸成的，那道光来自另一个遥远的、不属于初诞者的世界——它将带着另一个宇宙的执念活下去。
- 若林恩没直接向真理道破自己对「自由意志本就是骗局」的不认同，而是把这个问题先抛给了在场的所有命运军团残魂，则那些没有真正死亡的英灵第一次以影子般的形态齐声否定了这个结论，真理第一次在千年后听到同样的答案不是一个人说的。
- 若林恩在询问真理之后突然朝着虚空掷出一支疫医信号剂让其炸开化作一片金色雨幕，则雨幕落在真理长袍上时，他身上的金色纹路会有一次不似法则流转的活物般的骚动，那是他第一次在冷冰冰的计算之外，主动接纳了来自另一个人的行为。
- 若林恩在转身前先把那枚契约碎片埋入自己脚底的土地，则金光会从地下无声钻入真理影子里，这不是一份新的誓言，而是一条把他们联系在一起的、在众人视线之外的临时通道，日后一旦林恩真正陷入绝境，这条足下的通道会第一时间为他打开一线生机。
- 若林恩让左左蹲在自己脚边双手按住脚踝一起倾听真理讲述，则左左会在这场对话中第一次真正意义上理解「忠诚」两个字的写法，往后千年她将成为他所有孩子中最先一位学会对真理保持敬畏之人。
- 若林恩没问及兽王破封的经过而是把话题压在那位「已先行归来了」的金色少年身上，则真理会向他揭开那位少年的真实来历：他不是魇王的恶犬，而是他自己亲手在旧世界的一念之差创造的镜像，但从那场大灭绝起，他就再也不是傀儡。
- 若林恩在分别前把织梦仍昏迷的人事告诉真理，则那位金袍神王会在原地停留足有三十息，然后转身朝第七层反方向走，没有再多说一句，但在他路过林恩的一刹那间，林恩突然感受到一股极淡的温度落在自己肩头——是来自真理法则最底层的、不属于他掌控范围内的第一道问候。
- 若林恩清点完龙心后又在第七层废墟前的暗角处找到一把锈迹斑斑的旧战剑插在地上，则剑柄上的紫罗兰徽记已被岁月磨平了花纹，他拔剑收进系统空间，从此三叉戟多了一件可以不用却以精神之力与他共鸣的旧武器。
- 若林恩在银色太阳说「你赌赢了」后主动反问「那你说到底赌赢了什么」，则银色太阳不会答，他把手按在自己胸口那轮银色的太阳上停了很久很久，太阳的光芒第一次泛起一抹极微弱的金色——时间神王自己，也在认真审视那一轮挂在林恩心头的、真正正在升起的神王太阳。
- 若林恩没让过去的同伴在石隙内停留，而是带着他们一同步入神界最底层前先做了一整套的仪式祝福，则 E692 当他真正踏足核心区域时，第一个迎接他的不是那片法则风暴，而是没有人在他身边的一幕永恒空旷。
