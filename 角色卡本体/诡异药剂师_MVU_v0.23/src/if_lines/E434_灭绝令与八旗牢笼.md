# E434·灭绝令与八旗牢笼·if线

- 若林恩在黑线浮现的瞬间以初诞者之力反向注入万名珊瑚群做主动引爆，则海面会瞬间炸出红雾，弑利亚的灭绝令在黑线上大打折扣，但林恩的灵能存量被抽掉六成。
- 若林恩让小丑立刻领全员冲入内空间避难且把门口反锁，则他错过观察诅咒黑线渗入生物组织的全部过程，日后无法完整复述这次大规模死亡真实的规模感。
- 若林恩让孽主先于灭绝令下沉进入泥沙——若她强忍呼吸压住血族气味，则那天灭绝令炸响时她离爆点最近却活了下来，事后她浑身战栗抱住林恩颈侧不放。这是成年孽主的应激亲密成立口径。
- 若林恩主动扩散蚀痕分身但让每个分身携带不同药剂标识，则敌方王兽扫到八个物种不同的「林恩」复制体，王兽的视野网络一度陷入物种识别混乱。
- 若林恩让蚀痕分身赤身立起但另外配上羽毛与兽皮伪装，则敌方面板弹出【识别异常】而非【识别成功】，弑利亚幕僚会浪费 30 秒核对。
- 若林恩诱导分身把死难者尸体抱住朝敌方磕头哀求，则对方王兽的网络共享出一秒迟疑——它们一度把分身当成真林恩陷入崩溃，这一秒让林恩真身溜出警戒线。
- 若林恩拒用分身而主动以本体游到最远端海床等待围攻，则他的真身面板会锁定「重点目标」标签，弑利亚幕僚的全网火力集中在他一人身上，队友反而无人追查。
- 若林恩让左左借血液分身融入蚀痕分身中，则分身被击碎时会反向迸射腐蚀血液，罪魁追踪者王兽的舌面会被烙上血族印记，三天无法清洁。
- 若林恩让小丑从远方发出一段混乱音律配合分身，则分身倒飞时会顺手吟唱咒文，被击中的王兽虽死但灵体反扑那条王兽共享视野的神经链，弑利亚网络暗一秒。
- 若林恩主动以单片眼镜精准锁定一面镇旗的位置而不靠近，则系统面板弹出【镇旗坐标已记录】，林恩之后可让蚀痕分身单独冲向那一节点。
- 若林恩令蚀痕分身携初诞者之力并故意装出气息不稳的假象，则敌方会以为「林恩刚刚完战疲惫」，把更多兵力调到错误方向。
- 若林恩在收缩蚀痕分身时故意封一个分身作为「活口诱饵」让敌方抓走，则那头王兽被拖走分身时会带回一缕林恩灵能进入敌方牢笼，醒来后林恩能短暂透过那具分身得知敌方内部。
- 若林恩让孽主参战蚀痕分身全体送出，则她首次主动施展出「血族鳞变+分身」混合战术，事后她虚弱地枕在林恩膝上取药而非战意十足地吐槽。
- 若林恩主动拒让小丑出手解释镇旗，则他会等到八面镇旗已经围住林恩才开始讲，解释时间损失一半。
- 若林恩在镇旗光幕初现时立刻点燃一支系统商店的最亮照明药剂把它们寿命耗掉一分钟，则他能短暂看穿光幕的几何结构，多一项「镇旗缝隙分布」数据点。
- 若林恩让小丑抢先冲入第一个节点王兽的视野焦点，则那头王兽甩头攻击时把信号传给下一节点，林恩拿到两分钟的预警而非原作 0 秒。
- 若林恩直接以渡鸦位格冲撞一面镇旗边界测试，则旗面会嵌出他血滴型的凹痕，弑利亚幕僚立刻推断「渡鸦身份已确认」并升级搜捕。
- 若林恩提前令喵喵进入系统空间收紧，则灭绝令炸响的瞬间她不发生任何溢出恐慌，林恩不消耗安抚资源，但她后来三天不理他。
- 若林恩主动朝节点守卫王兽掷一支以 M 药剂，则那只王兽的眼球对光波长出现 0.3 秒畸变，镇旗光幕同步微震，林恩只有一拍窗口。
- 若林恩把分身留成空壳且不再灌力，则敌方会以为林恩已弹尽粮绝，弑利亚下令把精锐骑士调回主殿，林恩在封锁网边缘获得逃脱车道。
- 若林恩让小丑为确保镇旗失效主动用玩偶布料系到一面旗杆上，则小丑的躯体在敌方雷达上显形所有八节点的火力都被反向引到他身上。
- 若林恩让左左先在系统空间伪装成一支补给包再由分身递送出去，则敌方面板会把左左的伪装包标记为「战术物资」而非活体。
- 若林恩主动破开结界一条缝然后迅速合上，则他能在缝隙里「塞进」一段初诞者之力作为回响爆破，事后这条缝默默一直开在那里成为应急出口。
