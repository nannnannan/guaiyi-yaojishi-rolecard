# E401·血肉支配者的定位·if线

- 若林恩让夏娃在会议上直接把那段血谷见闻投影到主屏，则全场同步目击破碎小丑、巨大冰冷眼球与捆绑血肉，议论速度加快，但泰坦与根级同伴的警惕等级同步抬升。
- 若林恩只让夏娃一对一口述给艾雯爵士记录，则情报走侧线，黑堡同频识别需要多两小时，但小丑真相的震慑被削弱一档。
- 若林恩让夏娃在贴合交接后反向抹除自身印记再述说见闻，则双向定位窗口关一半，敌方逆向定位通道被那一阵贴合释放的巨量亲近压制。
- 若林恩在会议上直接展示夏娃贴合在他胸口的血红躯壳，则人偶家皱眉质疑「异常久了会同化」，会议走向「人格化的家庭危机评估」。
- 若林恩私下在侧厅对人偶家摊出紫罗兰大君推测，则原作现场反应成立，人偶家震到失语、要独处消化，她留下驰援的可能性大幅提高。
- 若林恩在侧厅对人偶家摊出推测但加注「其实后面是我编的」，则她的震慑被削弱，她仍会陷入思考，但留下的信念度打折。
- 若林恩在侧厅改走另一套「渡鸦在灾难前救火、春日前离开」的悲壮叙述，则人偶家会从他身上闻到「壮绝的逃避者」气息，她留下的决心更强。
- 若林恩拒绝跟人偶家单独谈话，则她会亲自敲林恩房门质问出路，事件走向「人偶家主动上门与师徒对质」。
- 若林恩让小小压住人偶家不许她走，则她会反向要挟「你不放我走我就把黑弦月叫回来」，事件变形为「双向绑架与防御工事」。
- 若林恩让艾雯爵士在会议上暂不动员大部队、只走侦察小队，则血肉剥夺削弱战术退为阶段目标，诅咒反噬压力压低。
- 若林恩让泰坦在会议上带头表态「我与血肉支配者积怨已久」，则诅咒加深的阴影成为主制约，但泰坦被列为正面战力。
- 若林恩提出「优先保护两到三名同伴」但名册不公开，则全场当场投票表决，阵营边缘同伴因此出现分歧。
- 若林恩让巨像之脑以「下水道黏稠事件」作会议开场，则人偶家愣住一拍桌、骂「学徒休想提那件事上来」，气氛反向被拽到严肃级别。
- 若林恩让小小随口问一句「银趴是否推后」，则人偶家当场炸毛，怒道「现在血肉支配者名单都被公布了」，场内肃静。
- 若林恩让巨像之脑在会议上顺手展示林恩胸口被贴合过的血红残留，则左左低头，巨像之脑压迫林恩「说明贴了多久」。
- 若林恩在会议结束前给左左强行灌下农业用药与粉红色改良剂，则左左先反抗后欲睡，林恩被反灌一起迷幻，事件变形为「师徒双迷与醉后走调」。
- 若林恩主动表示愿意被原初庇护，则艾雯爵士赐予庇护，但作为代价「本次必须以魔物状态参战」，议题被一环环拉紧。
- 若林恩要求夏娃在贴合后改口叫「林恩」而不是「爸爸」，则她会回应但语调生硬，她血管抓住他手臂的力度陡增。
- 若林恩让小小对血肉支配者标本发挥「投喂」本能，则小小会扑上去被血肉束缚反卷入定位链，事件变形为「小小被动定位」。
- 若林恩让喵喵在会议上随口一句「我爸爸就是那个爸爸」，则巨像之脑咬牙骂「蠢猫」，但全场瞬间肃静，认同主线被推到「家庭成员公开」。
- 若林恩不走侧厅、直接在人偶家离开前亮出一身被贴合符号，则她能理解徒弟的成因被「私人订制」取代，她在阵营边缘沉默地吞下。
