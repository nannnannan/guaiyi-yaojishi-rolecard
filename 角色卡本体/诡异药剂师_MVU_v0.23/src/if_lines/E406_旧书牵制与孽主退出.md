# E406·旧书牵制与孽主退出·if线

- 若林恩在支配者破界瞬间公开手中旧书，则看到内容的眼球受创，但诅咒无法杀死这个根源，支配者会从书页痕迹反推己方持有渡鸦系遗物。
- 若林恩不亮出旧书，则渡鸦遗物路径不被反推，但失去旧书对眼球的压制。
- 若林恩在旧书牵制窗口让泰坦在另一侧通道迎敌，则骨斧正对从空间涟漪探出的躯体。
- 若林恩唤起往日遗念巨神战姿叠加泰坦，则战力翻倍，但须由林恩主动唤起才生效。
- 若林恩不唤起往日遗念，则泰坦以常态「骨与诅咒复合躯壳」作战，硬碰硬风险被抬高。
- 若林恩让小小继续荒野机动，则她会被血肉剥夺范围牵连。
- 若林恩带小小远离战场寻求医疗，则沿途剩余利维坦会沿途追击。
- 若林恩按条款接受孽主提议——眷族安全、战后清除控制法门——则她可按下指印建立灵魂约束，退出战争。
- 若林恩拒绝签约，则孽主保留自主权但支配者可能察觉她的不忠行为。
- 若林恩用反派腔调自称亵渎对方神明并威胁放录像，则疫医催动战，她被骂「蛊惑人心的垃圾」，但这只是施压话术。
- 若林恩让孽主识破林恩的嘲笑，则她能反向推测敌方的所有支援渠道。
