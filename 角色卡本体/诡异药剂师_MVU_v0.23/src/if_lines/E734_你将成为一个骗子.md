# E734·你将成为一个骗子·if线

- 若林恩在城墙风雪中听完艾雯的必死真相陈述、看着飞雪落满手心释然微笑说出「这不是我一直以来都在选择的路吗」时，把双臂张开拥抱漫天风雪，则艾雯爵士会死死咬住牙关，将这一幕永远铭刻在心底。
- 若林恩在把手放在艾雯肩头、对他竖起大拇指并拜托他「这些事情最好还是先不要让主母她们知道了，特别是主母和智械小姐」时，故意用当年在游魂巷诊所里的轻松语气说话，则艾雯会在林恩转身走入风雪后彻底决堤落泪。
- 若林恩拒绝让艾雯单独承担「骗子」的罪责，坚持在每一道推行狂热救主信仰的帝国密令上同时盖下自己的王印，则两兄弟在每一个不眠之夜都会清楚：这场善意而残酷的欺骗是由他们共同背负的。
- 若林恩在新型帝国最高的欢迎仪式上亲自为艾雯爵士加冕、公布他就是二十多年来在各沦陷星区拯救无数底层生灵的「暗夜独行者」时，高声向全宇宙说一句「他是我的兄长，亦是帝国的脊梁」，则全主宇宙的欢呼声会震动星海，艾雯王下第一人的威望再无任何人能够动摇。
- 若林恩在翻阅艾雯耗时二十余年写就的数百万字《大宪章》手稿时，看到页脚处艾雯在边疆黑雨中留下的斑驳血迹与批注，则他会亲笔在宪章扉页签下「准行」二字，全力支持将各大星球改造成【哨兵星球】【工业星球】【农业星球】【医院星球】的宏大变革。
- 若林恩在艾雯重启两千多年前织梦铸造的【群星防线】并以神疆为其加持时，主动抽调三叉戟中的主宇宙本源协助诸多星球完成大转移变轨，则整座横跨星宇的战争机器会提前半年完成合拢。
- 若林恩在黑夜城最高会议上亲自站出来确认艾雯的话——证实唯有汇聚全宇宙生灵最狂热的救世主信仰才能点燃第三阶段黑火，则原本对造神运动心存疑虑的旧日根源与狱卒首领们会彻底放下芥蒂，全心投入信仰宣传。
- 若林恩在主宇宙最中心的世界视察三座至高圣堂（【宗教】【领袖崇拜】【至高神论】）的落成时，独自走入空旷的圣堂仰望穹顶，则他会提前感受到那即将从亿万星辰汇聚而来的沉重因果。
- 若林恩在圣堂内听完艾雯叮嘱「你必须以绝对碾压的方式辉煌地赢下接下来的每一场战争」、目睹数年来未曾合眼的艾雯不堪重负重重倒地时，第一时间冲上前一把扶住兄长并严令夜医强制他休养，则艾雯紧绷到极限的神经终于得以暂歇。
- 若林恩在守候昏睡的艾雯爵士时，亲手替兄长盖好被子并叮嘱侍从不准任何政务打扰他，则这位背负了整个帝国运转的「骗子」会在梦中难得地安睡三天三夜。
- 若林恩在自缚天使（主母）暂代王庭重任、恍惚地望着他的脸颊轻声问出「真的只是如此吗……那么代价呢？」时，没有丝毫闪躲地迎上她温柔而敏锐的目光，则他必须在心底做好准备，用最温和的笑容去编织那个连主母都要一起欺骗的谎言。
- 若林恩在主母追问代价的那一刻下意识握紧了怀中那支羽毛笔，则羽毛笔会微微散发出一丝暖意，帮他稳住心神，不让自缚天使从他眼中看出半点赴死的端倪。
