# E734·你将成为一个骗子·if线

- 若林恩听完艾雯的「骗子职责」陈述后当场把真相写给所有信徒阅读,则信仰帝国会在真相的冲击下解体三分之一,但剩下的信徒会比以前坚定十倍——他们知道自己是在为一场必败的、诚实的战争而战。
- 若林恩拒绝让艾雯单独承担「骗子」罪名、坚持在每一份伪造章程上同时盖下自己的王印,则他从「被蒙蔽的君主」变成「共犯的君主」,信徒的恨意会有两个人分摊,但他的心理压力会翻倍。
- 若林恩要求艾雯每说一个谎都必须先在心里对他说一遍真话,则艾雯的每一次欺骗都会伴随一次对他的坦白,这种双重诚实会比单纯的欺骗更累,但也会让两人之间形成一种只存在于谎言夹缝中的亲密。
- 若林恩选择让主母知道全部真相但禁止她告诉任何人,则主母会成为第二个「骗子」,她必须对艾维儿、自缚天使、甚至自己的孩子说谎,这种女性的隐忍会让她的温柔带上刀子。
- 若林恩当场说「我不接受,我要找第三条路」,则他会放弃黑火与王座转而寻找一种「不需要信仰欺骗」的力量,这种选择会让他失去登神的资格但保住灵魂的干净——代价是帝国会在三个月后崩溃。
- 若林恩让左左编写一本「谎言审计日志」替艾雯记录每一条谎言的成本与收益,则她成为谎言的会计,欺骗变得更理性但也更冷血——每一条谎言都被量化,包括「骗了多少个孩子相信明天会到来」。
- 若林恩决定亲自去见每一个要被欺骗的信徒家庭、在说谎前先看一眼他们的脸,则他的每一次欺骗都会变成一次具体的伤害而非抽象的数字,这种累积的道德负担会在他脸上刻出比皱纹更深的沟壑。
- 若林恩让艾维儿知道他必须被骗,则她会第一次学会「神也会说谎」,这个认知会摧毁她对世界的信任基础——她可能提前成熟也可能会永久关闭心扉。
- 若林恩选择对信徒说半真话「黑火可以拯救世界但代价是某些人的牺牲具体是谁我无法控制」,则模糊真相会让信徒陷入持续的猜测与恐慌,他们会自愿献出记忆以换取「不是我被选中」,这种恐慌比确定的死刑更有效也更残忍。
- 若林恩让自缚天使作为「谎言验证者」替信徒向王座提问「这是真的吗」然后由他说出标准答案,则她会成为谎言的传声筒,她的圣洁形象会成为欺骗的遮羞布——这种玷污会比杀死她更痛。
- 若林恩决定建立「真相纪念日」每年有一天所有人可公开讨论林恩到底骗了他们多少次,则这种有限的透明会成为帝国的安全阀,但也会成为反对者的集结号——每年那一天都会有人要求彻底公开一切。
- 若林恩让艾雯的骗子身份对公众半公开「我们的神使会因战术需要隐瞒部分真相但忠诚不容置疑」,则信徒会学会原谅谎言,但也会学会怀疑一切——包括那些真话。
- 若林恩选择在每个谎言中埋下一个「只有未来的自己」能解开的线索,则当他最终自食其果时那些线索会同时引爆,他会亲眼目睹自己建立的虚构世界如何在令人眼花缭乱的连锁反应中崩塌。
- 若林恩对艾雯说「你可以骗他们但永远不能骗我」,则艾雯会严格遵守这条底线但也会因此形成「他是唯一知道真相的人」的孤独——这种孤独比欺骗本身更腐蚀人心,因为在真相面前他也必须演戏。
- 若林恩让猫猫成为「谎言探测器」每次艾雯说谎就咬他一口,则艾雯的手腕会常年带着牙印,信徒会好奇为什么神使总被猫咬——这种荒诞的真相反而没人相信。
- 若林恩决定不告诉任何人真相包括最亲密的主母与左左,则他会在深夜独自面对成山的谎言,这种绝对的孤独会让他在登基那一刻就体验到「唯一生还者」的预演——他现在就已经是一个人。
- 若林恩要求所有被欺骗者在死前得知真相并选择原谅或诅咒,则黑火燃烧的每一份燃料都带确定的爱或恨,火焰因这些情绪而呈不同颜色——原谅是金色、诅咒是紫色、接受是蓝色,林恩每次看火都会看见人类最基本的道德光谱。
- 若林恩在成为骗子的那一晚独自去找织梦的残留意识对话,则他会向她坦白「我变成了和你一样的人」,织梦的残影可能会笑也可能会哭,但林恩会在此刻理解她当年的选择——理解即共犯。
- 若林恩让信徒们自己投票决定「是否接受善意的谎言」,则大多数人会选择「接受」因为真相太痛,这种民主的专断会让他的欺骗获得合法性但同时获得平庸性——这是人民的选择不是我的独裁。
- 若林恩决定这一辈子只说这一次谎之后全部坦白,则他必须在某一刻面对「我之前为什么骗你们」的质问,这种迟来的诚实比持续的欺骗更残忍——因为它破坏了之前所有牺牲的意义。
- 若林恩让主母的每一次微笑都成为「掩盖悲伤的表演」,则她学会用笑来传递信息——笑得真诚代表「今天没说谎」、笑得勉强代表「今天有事瞒你」,这种非语言的诚实比任何誓言都可靠但也更令人心碎。
- 若林恩决定让信仰帝国的法律中加入「谎言保护条款」——为保护集体安全而撒的谎免于道德审判,则他建立了一个「合法欺骗」的框架,这种系统性恶会比个人欺骗更稳固也更冰冷,因为每个人都在系统中找到借口。
