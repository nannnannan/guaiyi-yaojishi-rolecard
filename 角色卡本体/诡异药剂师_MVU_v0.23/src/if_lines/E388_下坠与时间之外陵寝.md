# E388·下坠与时间之外陵寝·if线

- 若林恩在穿越结界后主动反向收回黄沙保护层以观察被分解反应，则现场试验以他的小指边缘被无声消解作为代价，规则记录但身体代价显著。
- 若林恩让左左跟随到结界边缘并独自穿越，则她单独留在界外并立刻发出呼救信号，他被隔离但因为她主动观察记录下更多底层异常数据。
- 若林恩先对结界注入他亲手炼制的以M气息测定反应，则结界立刻发出刺耳警报，他被强制排回表层并需要重新规划探索路线。
- 若林恩在下坠期间用咒瞳强行透视底部以便于挑选着陆点，则他读到一阵「请勿窥探」的反弹信息，惩罚式增加一段深层沉滞，路径延长两小时。
- 若林恩不按规则下落而是主动向上回拽以测试回折特性，则他被反吹的结界直接回摔到表层，探索路径完全失败且需要重新申请。
- 若林恩动员左左在他下坠期间另一方位以餐刀刺破结界之壁，则结界反弹使左左餐刀被弹回并擦出她身上一道伤口，她对他的位置更加警觉。
- 若林恩在结界之后首先选择安全着陆并搭建小型探索营地，则他记下整个深渊入口坐标并把它与初诞者之力关联起来，后续探索路径更安全。
- 若林恩让艾雯从黑堡直接降下灵能火线与他同行，则火线在结界边缘即被分解，艾雯的损耗上升，同行者失联。
- 若林恩施放系统手雷在结界内壁试图引爆强行打开通路，则爆炸权能下整个结界陷入一种持续轰鸣状态，他被卡在墙面一会儿且无法通过。
- 若林恩在下坠中途切断与地面的通讯以专心探索，则深入阶段增加一个「孤立点」，外部无法干预，而且救援命令完全没有任何效力。
- 若林恩在下坠过程主动说明初诞者之力并试图教化，则结界以「不接受教化」返回，结界表明它并无任何主观意识只是被动评估。
- 若林恩让左左在结界之后原地跳跃玩耍以测试边界，则她因为边缘反作用力被摔出去并被系统记为「接触性探索」。
- 若林恩以血灵石打磨小通道以加速结界通过速度，则一通道拿在手中立刻熔化，矿材相对硬度有限，路径还是只能被逐点打开。
- 若林恩被结界反弹时拒绝记录反弹形式，则他下一次遭遇还会重复相同错误，信息被强制以「无作战笔记」记录。
- 若林恩反向将结界视为万机之神副手并尝试直接对话，则结界保持完全沉默且对他的解释闪烁，说明它并不属于机械神教。
