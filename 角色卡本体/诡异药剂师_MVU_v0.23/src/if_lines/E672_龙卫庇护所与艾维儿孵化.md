# E672·龙卫庇护所与艾维儿孵化·if线

- 若林恩在甬道里故意触发一处禁制试探庇护所反应，则警报提前响彻、守卫立刻结阵，迎接姿态从严阵以待转为已锁定目标箭弩齐发，孵化段的混乱代价升级。
- 若林恩主动以初诞者之力闪避甬道禁制完美潜过千米，则龙卫澜事后会从他身上嗅到一缕残留的禁制气息，质问「你到底是谁」的台词会提前到孵化之前。
- 若林恩在音音跃入水潭净化瞬间以空间折跃从旁现身，则她惊呼一声却没来得及拉起长袍，全身毛茸茸的狐耳紧贴颈根，庇护所显眼位置永久留一笔「渡鸦不请自来」的传言。
- 若林恩提前把龙蛋递给守卫看，则两名黑袍守卫会立刻触发最高警备状态，引来龙卫澜提前披甲现身，孵化出世改在殿外面而非水潭里。
- 若林恩以空间神格在水龙卷冲向自己时把龙蛋反向抛给音音，则她会下意识抱住、随即脸色一白跌回水潭，孵化时她依旧被「爹」认作见证者。
- 若林恩冲入潭水接龙蛋时不小心抱住音音胸口位置，则她事后会乖巧瞪他一眼又咬牙把头顶蛋壳砸过去，艾维儿目击此景会以一岁神智笑出声。
- 若林恩在水龙卷席卷瞬间主动裸露出初诞者之力威压，则庇护所一切禁制会全部炸裂熄火，但龙卫澜会以「入侵者必是神王」等级的杀意接待。
- 若艾维儿破壳瞬间林恩故意装作不认识她，则她会瘪嘴泪眼汪汪说出「爹你不要女儿了」随后死死抱住他大腿不放，抚养难度+100%。
- 若林恩面对一岁的艾维儿主动用糖果哄她止哭，则她会立刻破涕为笑，糖果哄骗成为后续照顾期的默认安抚手段并被龙卫澜记录为「渡鸦手段之一」。
- 若林恩在艾维儿喊出「爹」的瞬间回应「我不是你爹，我是你师父」，则她会先用一口小龙牙咬他一口再嚷「坏师父骗艾维儿」，但龙卫澜松了口气说出「这样更好」。
- 若林恩在龙卫澜认出紫罗兰大君面孔时改口自称「我只是见过你王的雕像」，则她会沉默良久再启口「请不要侮辱帝国的传承」，效忠意愿彻底关闭。
- 若林恩在卫兵跪拜请安时主动挥手免礼、把艾维儿高高举起，则全庇护所守卫会在她心里刻下一笔「渡鸦对殿下有真挚情谊」，忠诚度隐性+10。
- 若林恩看到卫兵们窃窃私语「和雕塑上一模一样」，主动朝他们一笑，则窃窃私语会瞬间消失，所有卫兵低下头颤栗，庇护所纪律全面崩坏转为肃穆。
- 若林恩在龙卫澜解释「我以为您会是带着您的人杀上神界」之后当场愣住久久不语，则她会敏锐察觉出他隐秘的孤军深入并默默把庇护所兵力替他留出一条撤离通道。
- 若林恩把空间神格威压全开以神王身份与龙卫澜对话，则她会单膝跪地把长枪抵地自请「述职」并把所有护卫权限移交，她的旧世福国情怀彻底引爆。
- 若林恩在孵化当下用初诞者之力替艾维儿修补蛋壳并让她重新睡回去，则她意识会更稳定但艾维儿孵化延后再发生，本事件会转入「龙卫澜拖住林恩」的暂时僵局。
- 若林恩当面以三叉戟指着龙卫澜质问庇护所立场，则她会坚定地以紫荆花卫队的誓词回应「绝不会背叛女主人」，林恩若执意出手她将以死明志。
- 若林恩隐瞒自己从画家那里接过龙蛋的事实，则龙卫澜会在孵化后逼问龙蛋来历，本事件转入「谎言败露」的军衔审查序列。
- 若林恩在音音跃入水潭前主动握住她手腕叮嘱「以后别独自出巡」，则她会泪眼汪汪点头，庇护所对林恩的阵营归属感再上一档。
- 若林恩在水潭残力与龙蛋共鸣之际以空间神格封锁整片溶洞，则被引动的庇护所禁制无法被点爆，一切孵化发生都闷在他的封锁场里，因果定位被强行屏蔽。
- 若林恩在水龙卷扑来瞬间用三叉戟直接把它斩散，则龙蛋会被自己的力量反震脱手坠入溶洞深处，孵化地点随机改写，被迫同时面对敌我对峙。
- 若林恩在龙蛋发热的瞬间把它收入系统空间稳定化，则孵化推迟下一事件，但龙卫澜会立刻警觉到蛋的消失并以武力封锁林恩进入。
- 若林恩以咒瞳反向追踪龙蛋的封印曲线，则能提前看到画家的精魄密码，但解锁瞬间艾维儿模糊意识会主动回应「爹我看到妈妈了」。
- 若林恩面对一岁的艾维儿吼出「我不是你爹！你妈妈是画家！」，则她会震惊的呆住几秒，随后痛苦地全身痉挛，蛋壳崩裂速度会 exponential 加快。
