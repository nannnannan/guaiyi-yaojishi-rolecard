# E708·叛乱与毁灭神王格·if线

- 若叛乱不在第十五天同步发难而是分两批行动，则时间泡只在第一次受创而未被严重破壊，船长的重伤避免，时间加速修练得以保留半年。
- 若银色幻想的原子网络未能第一时间预警，则黑夜城多位半神在睡梦中陨落，人数比原文再翻一倍，神界警戒线崩溃到内环。
- 若船长在时间泡被袭那一刻选择撤退而非死守，则他本人平安，但时间泡当场被拆解，「时间加速时代终结」提前一日成立。
- 若「牧魂者」不是从狱卒集团高位亲至而是遣弟子带药，则船长没有老师的临场判断，「破而后立」方案无人提出，船长只能在黑夜城内部等死。
- 若死亡之神当场用死亡神力为船长续命但不传位，则船长只能作为暂时保住性命的「行尸走肉」，无法迈出比老师更高一层的道路。
- 若银色幻想动用林恩给予的权限时先请示母树与人偶家才发出请求，则林恩因多年未联已彻底失联的可能被推迟发现，三人联席对策也告吹。
- 若林恩远程送来的不是毁灭神王格而是其他神格（如时间或灵的残片），则「死亡是毁灭的子序列」与「比老师更高一层」的判断不成立，船长再无冲击神王的路径。
- 若母树不当众气急喊「林恩你心偏」，则她与林恩之间的旧账不在黑夜城公开暴露，她的隐秘心事得以保留，对林恩回归那一刻的爆发点推迟。
- 若康斯坦丁接受老者「破而后立」的指引但拒绝接受毁灭神格的传承，则他另寻新路，但是否能活下来成悬念，神界少一柱关键战力。
- 若那枚毁灭神王格在撕裂空间那一刻被某黑暗第三方截获，则船长失去唯一救命稻草，三年之后内环战场彻底崩塌，神界陷入更长的不归夜。
- 若林恩退回的神格附带一缕他自己的消息或预言，则黑夜城能提前得知他多年不接讯的真相，银色幻想对他的等待修正为「信心等待」而非「焦虑等待」。
- 若林恩的闭关状态被某位神界特务偷看到一眼外泄，则整个神界对他的现状进行各种猜测与神学化处理，「他是变成神物了」的谣传蔓延。
- 若神界在战争后对内部的腐化排查获得了真正的突破口（一位神通过逆向谜雔法术），则内应集团被逐一清除，下轮的弱点被补足。
- 若林恩从闭关中突然伸出过一只手帮助船长的「破而后立」仪式，则他提前醒来，后续「罪火三阶段」的积淀被打断，命运全面改写。
- 若母树在气完之后冷静反思「我早就应该选择不一样的路」，则她下一次神位冲击会出现「自然与毁灭融合」的新取向，多一位新神形象。
