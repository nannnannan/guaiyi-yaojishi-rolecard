# E786·三位一体之主·if线

- 若林恩在回声响起前主动切断织梦的灵能联系，则三位一体之主的声音只能对她单方面演说，她无法提问，远古记忆变得残缺。
- 若林恩选择让织梦独自承受全部回声而他只在外部接应，则织梦在回声结束后会陷入七日沉睡，梦中她重走永恒燃烧全过程。
- 若林恩主动朝三位一体之主提出一个直接问题——「你为什么制造了我」,则回声会停滞数秒，回答是他在 E787 才稍作消化。
- 若林恩让左左在回声外侧同时观察记录，则左左能在 E787 提供第三视角的二次解读，但她的手指从此无法完全伸直。
- 若林恩放任回声覆盖当前时间而不切断，则他在冬泉谷的短暂消失导致织梦在 E787 着急唤醒他,两人的关系第一次出现「主动寻找」的版本。
- 若林恩主动把自身某段记忆作为与三位一体之主交换的代价，则他能换得多一段远古画面，但那段被换走的记忆会形成他自己再也无法愈合的空洞。
- 若林恩在回声最深处主动点燃黑火而不是熄灭，则三位一体之主第一次正面「看到」未来，祂留下一句话被林恩听见，织梦却没听见。
- 若林恩选择把远古记忆原样吸收而不筛选，则他在 E787 苏醒时会被记忆中的紫罗兰大君、画家与轮回神王影像同时轰击。
- 若林恩主动让三位一体之主知道他是「反复降临的林恩」,则祂会给林恩留下一段特殊的印记，那印记在 E789 截杀时会成为空白实体的诱饵。
- 若林恩在织梦听到关键真相时主动捂住她的耳朵，则她能躲过最直接的伤害但失去完整理解，E788 她会因不懂而提出本可避免的疑问。
- 若林恩放任远古回声穿过自己身体反向注向世界，则他成为回声中继，主宇宙的某座城在那一夜所有居民做同一个被永恒燃烧的梦。
- 若林恩主动问一句「织梦是你的女儿吗」,则三位一体之主会给出模糊回答,织梦在 E787 因此对林恩增加了明显敌意。
- 若林恩选择让回声只传递部分，剩余由他自行探索，则他在 E787 会用一周时间独自重溯回声路径，期间被左左质问为何隐瞒。
- 若林恩主动把喵喵放在回声覆盖区当活体传感器，则喵喵的毛会变成光波三线色，它能感知未来 E794 的三种终局战场。
- 若林恩在回声外侧主动搭建一道反相屏障，则屏障碎片在 E789 截杀中可作为一次性反制，因为他已测得回声频率。
- 若林恩让织梦在回声中第一个提问，则她提出的问题决定了整个回声走向,林恩不得不接受她的优先权。
- 若林恩主动拒绝三位一体之主提供的某些记忆打包，则那些记忆会作为封印残片留在时间长河,E798 终局时他将回到那里取回。
- 若林恩放任回声对当前世界进行反向目击——回声「看到」现在的林恩，则他会在 E790 与空白实体对峙时空白引用回声语，那种语让林恩毛骨悚然。
- 若林恩主动将自己的咒瞳借给织梦去看回声画面，则她看到的版本与他不同,两把咒瞳在 E787 会因解读差异而互斥。
- 若林恩选择在回声结束后立即彻底摧毁路径让三位一体之主无法再联络，则他切断了自己的退路，E794 终战时三位一体之主不再是援手。
