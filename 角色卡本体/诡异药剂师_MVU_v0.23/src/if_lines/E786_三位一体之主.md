# E786·三位一体之主·if线

- 若林恩在远古回声响起前主动切断织梦的灵能联系，则三位一体之主的声音只能单方面回荡，织梦无法提问，远古记忆变得残缺。
- 若林恩选择让织梦独自聆听全部回声而他只在外部护法接应，则织梦在回声结束后会陷入七日沉睡，梦中她将重走一遍旧世界追求永恒的全过程。
- 若林恩主动朝三位一体之主提出一个直接问题——「为什么旧世界的众生连永恒都无法忍受」，则回声会停滞数秒，给出的沉重回答让他在 E787 才彻底消化。
- 若林恩让左左在回声外侧同时观察记录，则左左能在 E787 提供第三视角的二次解读，但她的手指会因记录高维信息而酸痛数日。
- 若林恩放任远古回声覆盖冬泉谷而不提前设防，则他在谷中的短暂失神会导致织梦在 E787 焦急地摇晃唤醒他，两人的关系第一次出现她主动关心他的转变。
- 若林恩主动把自身某段记忆作为与三位一体之主共鸣的引子，则他能换得多一段旧世界黄金乌托邦的画面，但也必须亲身体验一次旧世界众生在永恒中的窒息感。
- 若林恩在回声最深处主动点燃深渊黑火照亮黑暗，则三位一体之主的残影第一次正面「看清」这位未来的破局者，祂留下的一声叹息被林恩听见，织梦却未曾察觉。
- 若林恩选择把远古记忆原样吸收而不加筛选，则他在 E787 苏醒时会被旧世界毁灭、轮回开启与诸神混战的庞大画面同时冲击。
- 若林恩主动向三位一体之主承认自己是「从未来逆流而上的渡鸦」，则祂会给林恩留下一道古老的秩序共鸣，那道共鸣在 E789 截杀时能帮他提前预警黑袍人影的逼近。
- 若林恩在织梦听到「我就是三位一体之主，祂就是我啊」而剧烈动摇时主动握住她的肩膀，则她能更快从身份冲击中稳住心神，不会因自我怀疑而灵能紊乱。
- 若林恩放任远古回声穿过自己身体并映照进【黄金梦境】，则黄金梦境中的渡鸦灵魂们也会在同一夜窥见旧世界永恒燃烧的壮烈景象。
- 若林恩主动问织梦一句「知道自己就是造物主的一部分后，你害怕吗」，则织梦会咬紧嘴唇沉默良久，最终倔强地抬头回答「我就是我，我是织梦」。
- 若林恩选择让回声只传递核心真相而将其余悲剧画面自己扛下，则他在 E787 会独自消化那些旧世界自毁的绝望记忆，期间左左会心疼地替他揉按眉心。
- 若林恩主动在回声覆盖区布下一枚记忆水晶球作为记录载体，则水晶球会染上命运、时间与梦境交织的三色流光，成为他在后续推演终焉弱点的重要参照。
- 若林恩在回声外侧主动搭建一道黑火反相屏障，则屏障碎片在 E789 截杀中可作为一次性防御手段，因为他已借此测得高维法则的震荡频率。
- 若林恩让织梦在回声中第一个向古老的声音发问，则她提出的问题决定了整段远古秘辛的展开方向，林恩也能从中听出她心底最在意的执念。
- 若林恩主动封存三位一体之主传递来的部分过于沉重的记忆残片，则那些残片会留在冬泉谷的冰雪之下，直到 E798 漫天烟火升起时才化作春水消融。
- 若林恩在回声映照出旧世界众生反抗永恒的狂潮时依然保持眼神清明，则三位一体之主会赞许地向他颔首，认可他并非盲目追逐永恒的狂徒。
- 若林恩主动将自己的咒瞳借给织梦去直视回声深处的本源，则她看到的旧世界图景会带上林恩的秩序视角，两人的灵魂共鸣在 E787 更加紧密。
- 若林恩选择在回声结束后立即以黑火抚平冬泉谷的时空涟漪，则第七十二柱黑衣人影无法顺着三位一体之主的苏醒痕迹提前锁定冬泉谷的坐标。
