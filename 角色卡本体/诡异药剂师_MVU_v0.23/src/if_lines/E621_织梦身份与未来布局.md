# E621·织梦身份与未来布局·if线

- 若巨像俯身捡证件夹前先用血肉法则隔绝封面照片,则织梦的注视感应被延迟一息,血枢爆怒的时点顺延,但照片异动仍会发生。
- 若纱奈儿在证件夹落地瞬间被母树紧紧抱在怀里遮盖视线,则她不会第一时间冲回夺包,合照曝光的羞耻感减弱,但织梦的媒介另选他物。
- 若林恩在异变发生前就坐镇病房内,则时停定格会把他一并框入,照片女人的开场白转向林恩,血枢的警告改由林恩心底炸响。
- 若织梦选择不以照片站起而是借纱奈儿的身体开口说话,则小学徒会惊醒尖叫,老者当场昏死,后续师生关系的柔软纽带被替代为恐惧。
- 若血枢在辨认照片瞬间强行切断超维链接保护巨像,则她没看见那张脸,但「我们找到她了」的告警到达林恩耳中时,现场已陷入时停。
- 若母树在照片异动时立刻释放自然魔法包裹病房,则她的绿意会与镜裂同时存在一息,织梦现身画面更妖异,但魔法的抗性更强。
- 若老执事在昏厥前就开口阻止巨像翻包,则证件夹曝光延后,纱奈儿的谎言「十八岁」能多活数小时。
- 若林恩决定直接以初诞者之力撕碎那张照片阻止现身,则织梦的媒介被摧毁,但她的冷笑会借血枢之口传出「没用的」。
- 若照片里女人的目光先落在母树怀中的纱奈儿身上,则「织梦老师」四字会由孩子自己喊出,身份暴露更快。
- 若血枢的警告在照片异动前提前抵达林恩意识,则他能早一息冲入病房,三叉戟落点在照片尚未站起时,但阻止失败。
- 若巨像在察觉血枢惊变时立刻化身巨人保护病房全员,则她的血肉屏障能阻挡镜裂扩散半寸,但织梦的目光会穿透她。
- 若照片女人站起后先对巨像说一句「你长大了」,则师徒初见冲击更强,后续血枢的「本质」话题会更刺耳。
- 若林恩在病房外就感应到灵能波动选择不立即进入,则他能保存战力,织梦对巨像的对峙时间更长。
- 若纱奈儿挣脱母树后立刻抓住照片护在胸前,则照片与她的肌肤接触更深,织梦借她身体的可能性大增。
- 若血枢的警告改为通过巨像的骨血共鸣直接炸响在她心脏,则她会当场呕血,但冲出去救纱奈儿的速度更快。
- 若照片异动时病房里只剩巨像一人,则她与织梦一对一的注视延续更久,「血枢大惊小怪」的台词更刺耳。
- 若母树在异变瞬间把纱奈儿高高举起想带她逃离,则时停定格的画面更荒诞,小女孩悬浮半空的姿态成为永恒的一帧。
- 若林恩在现身前让渡鸦群环绕法师塔形成封锁,则织梦的来路被斩断一线,但她仍会借照片从容起身,只是表情多一分不悦。
- 若老执事醒来后第一件事是把纱奈儿推向巨像求助,则孩子的恐惧会转移为对「萝莉姐姐」的信任,日后她对巨像更依赖。
- 若织梦站起后先放低姿态对巨像微笑,则气氛更诡异,血枢的后续坦白会蒙上一层阴影。
- 若林恩在病房外感应到「三位一体」波动时立刻收剑入鞘以礼相待,则织梦会多看他一眼,但艾雯被挟持的事实不变。
- 若血枢的警告包含「她是我等最强」一句,则巨像的战意会更猛烈,但织梦的压制也更坚决。
