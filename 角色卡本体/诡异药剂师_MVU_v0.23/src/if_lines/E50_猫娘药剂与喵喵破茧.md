# E50·猫娘药剂与喵喵破茧·if线

- 若林恩接过小鱼干直接收进贴胸口袋而非哑然失笑，则喵喵"想变成人"的恳求当场开口，药房那段鬼使神差改写成街道人群里的点头。
- 若林恩掰下一角小鱼干尝了，则坏肚子的预言落空，"分哥哥一半"的仪式被这一角咬掉，炼药动机从安慰换成还嘴馋。
- 若林恩拿到配方后只答"先看材料能不能凑齐"，则当夜的纠结拉长成整宿，炼药房的灯晚半宿点亮，左左在廊下多喵一声催促。
- 若林恩以同剂量逆月昙替换太阳花，则药剂转为冷色银粉，破茧后喵喵发色粉蓝漂移成月白、猫耳边缘挂霜。
- 若林恩手抖多添一份猫咪分泌物，则药剂甜度爆表，喵喵饮后在床榻里昏睡三昼夜才破茧，林恩守门外三日才听见撕裂声。
- 若林恩不偷红茶包、改潜入病院标本库取一段封存根源组织，则成就落空、智力与快乐加成不结算，永久罪恶改记为"擅闯标本库"。
- 若林恩当面跟主母讨要红茶包，则主母愣一瞬丢来一整盒并附一句"送你了别再偷"，成就讽刺文案改写、罪恶那笔落空。
- 若林恩以自身一滴根源血替代根源级材料，则药剂柄上系住他的因果线，破茧后喵喵对他多一段血脉级感应，红茶包原封留在系统空间。
- 若林恩被左左一声"凑脑袋"叫得错手，则药剂滚沸溢出半勺，喵喵饮后破茧只化出上半身猫耳娘、犬尾拖延一日才褪。
- 若喵喵坚持拉林恩的手一起坐在镜前等，则撕犬皮的瞬间他在场，每一声呲啦都攥紧他指节一寸，镜中那眼先撞上他的瞳孔再撞到她自己。
- 若喵喵饮药时出于羞怯要求熄灯，则破茧在黑暗里进行，她摸到的是自己的血肉而非镜像，"不再畏惧自己"改写为"不再畏惧触摸自己"。
- 若喵喵撕到半途疼痛锥心选择暂停，则破茧分两段进行，中间她裹着撕裂犬皮在床角哭一场，第二段撕扯时指节抓痕比上次更深。
- 若喵喵吞药出现排异、犬猫形态间闪回三次才稳定，则每次闪回伴随骨骼错位声，她在镜前跪下三次才终于直腰，新形象挂一层淡虚影。
- 若喵喵破茧中途失控暴走撞翻药架，则林恩破门而入时她把半边犬皮抵在胸前遮掩血肉，破茧暂停待现场收拾净再继续。
- 若喵喵转变后当晚拉住林恩袖口把人请上床陪睡、尾巴缠上他手腕当枕头，则她指尖在他掌心一遍遍描自己刚长出的指甲形状，成年猫娘的撒娇夜直白延伸。
- 若喵喵转变后首次发情期又急又烈、抱着林恩的腰哭求安抚，则成年猫娘的本能写入她的身体时钟，林恩回应路径由玩家声明，未声明前只停在她把滚烫耳朵贴上他胸口。
- 若喵喵拒绝饮药把瓶子摆回原处说"再想想"，则事件向取消方向走，配方留存、茶包因果失效，她以犬耳娘身份继续日常。
- 若主母当夜远程发现红茶包被偷亲自上门，则病院炼药房闯进不速之客，喵喵破茧在主母注视下进行，成就附赠一行"被她看到了"。
- 若林恩炼完药在掌心掂瓶、闪过"要不要先自己尝一滴"的念头，则玩家主权弹窗压下这一步，未声明咽下的前提下瓶子原样揣回衣袋，成就附注"差点变成猫男郎"。
- 若喵喵转变后不肯立刻出门、把猫尾当枕头窝三天，则林恩回朋克酒店的日程被打乱，E51的折跃龟快递先一步送进病院门口。
