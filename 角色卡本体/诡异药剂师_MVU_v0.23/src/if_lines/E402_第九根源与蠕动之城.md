# E402·第九根源与蠕动之城·if线

- 若林恩一句话「不迁城，我们守黑夜城」，则母树根系不介入、夏娃血管不扩张，城市留在原地，敌方情报窗口被拉长但随身迁移体系丧失。
- 若林恩让母树根系介入地基但不整体抬升、改为「分段滑移」，则迁城不引发深坑，隐匿期缩短但工程跨度扩到三倍。
- 若林恩在夏娃血管托举城市时把她的心跳节奏渗透进母树根系，则两者共鸣进入双体联动模式，但迁城后地层留血肉耦合痕迹被敌方侦测到。
- 若林恩让艾雯爵士在迁城前主动把隐匿方案泄给机械神教，则敌方反向锁定板块轨迹，城市迁至离散布局的「无城」阵型变成陷阱。
- 若林恩让人偶家留阵但不补第九根源位置，则议事一席空缺，相关大能决议推迟，盟友边缘开始动摇。
- 若林恩让人偶家以「私定契约」直接代左左完成入盟仪式，则左左会因「被替代」产生隐伤，人偶家与黑弦月关系的伏笔同时被扰动。
- 若林恩让艾雯爵士把隐匿调整为「隐形影子城市」模式，则外部眼线只能追踪到一道暗黑波纹，但居民日常必须避光。
- 若林恩在迁城途中让爱丽丝也迁入黑夜城，则她的环形系带与金发宝石眼随包裹一并转移，幸福之家打包有额外延迟。
- 若林恩让大舌头出运动场召集魅魔防线，则他的下水道贵族营地会被魅魔标记为「偷闲乐窝」，加入战力需要割舍温柔所物。
- 若林恩让大舌头不集合、保持贵族式生活，则灾变来临时他被迫弃家舍护，这种没落反而将他推向战力提升。
- 若林恩让巨像之脑在大舌头召集时主动挖出「舌灵活受魅魔青睐」八卦，则全场笑场，大舌头誓死反驳「本舌头是很严肃的」。
- 若林恩让巨像分体战时暂时集合但不主张完整战姿，则聚合反噬只出一半，战术杀伤力只到中等。
- 若林恩让巨像分体汇总时把左左也拉入集合阵，则她与心脏同步可能产出额外银色幻想识别，但她会很不情愿。
- 若林恩让克苏鲁联络艾泽法拉时主动献上黑水尾巴的唤醒咒，则深海响应可能被打开阻隔，但同时有被另一侧深海生物入侵的风险。
- 若林恩让艾雯爵士提醒边疆红线时掷笔送出深海骨哨，则舰队顺火种航线探测到一片深海阴影，但会惊动深海存在。
- 若林恩在迁移完成时让人偶家接手主监测位置，则她需要以双人姿态监控机械神教动向，精力被牵得很累。
- 若林恩让喵喵负责监测隐身边界，则她会一门心思伏在边界草根处，但敌方侦察读到的只是「一只无法被机械读取的神兽」。
- 若林恩让小小负责迁移后的隐藏侦察，则她的速度会成为新点「快速防线」的核心，但她可能喜欢上这种「到此一游」的生活。
- 若林恩让左左驻守在旧阵地，则她能以防御阵能量重建阻挡，但她那套「城市贵族」的幻想会被现实击穿。
- 若林恩让黑弦月打通黑堡联络时在调度所修一把旧剑，则她能把边栈阵地反向定位到机械神教，但书中提到的「古老修剑者」并不存在。
- 若林恩让艾雯爵士在迁城时刻意推迟她个人的黑暗操纵，则灵能隐匿会被压三刻钟，城市暴露窗口被击穿。
- 若林恩在迁城完成时以「现场近在咫尺」的态势昭告一切盟友，则某些缘浅的盟友会被挤出去，战线被打散。
- 若林恩在迁城完成时将某族盟友姓名钉帖，则该族会被契约束缚定制化，但盟友规则的执行力未必稳定。
- 若林恩让全部迁移成员在迁城完成时同步合影，则这张照片会成为下一个战争前夕的伏笔。
