# E530·私藏品试探与身份逼近·if线

- 若会议把熔物试探预案的投票门槛改为三对三就需重投，则银幻的「不太好」会拖住整场行动，私藏汇总改写成低声小圈子审问而非广场公演。
- 若艾雯把私藏位置的猜测清单上交前先召集一次只有女性根源参加的预审会，则红茶包/恶堕书/清凉集邮册在公开层被提前曝光，男性根源（泰坦）事后才知道这场羞辱。
- 若银幻在广场挥洒黑颅币时不按刻签名日期一颗颗抛洒而是一次性烧整批，则黑袍识破熔物侦察的心理难度抬升，他可能更早出手试图灭火。
- 若银幻不先烧签名硬币、而是从头就倾倒黑颅币宝石书堆一起火，则首轮审问关键破绽被一次性出尽，黑袍「你在戏弄我」表层起手式仍在，但他需要在第一轮就抬刀。
- 若林恩（黑袍）在首轮烧出一枚便主动抓住它，则他失去「什么都没动」的淡定伪装，但也争取了把它抢收回戒指的台阶，银幻对「他在压火」的判断会升级到「他肯定有所藏」。
- 若银幻在亮左左未成年外形的清凉照时不澄清这是机械对象试探，则用幼态性意味抓他的反噬会打偏 tactic 焦点，整场对身份的试探改变性质。
- 若左左在黑袍要被她贴身逼问时突然按住自己的暴走、幻化成纯左手挂回他手臂，则「恶堕的偷窥变态萝莉控」的骂战抓拍失败，黑袍可以立刻栽在「刚才是演戏」让她完美配合。
- 若左左灌农药镇压时主动力度大过山头，让黑袍当场呛出白沫，则他在扒装现场露脸前会有一段真正的狼狈，银幻动手扯黑袍的时机在他脆弱状态中段。
- 若银幻不扯黑袍、改用空间规则直接撕开他的伪装斗篷，则整个扒装行为被裁决为「规则层面的脱衣」而非「物力层面」，他在现场维持高傲的档位可以更高一层。
- 若林恩（黑袍）在被扒光前就主动喝一声「好我认输」，则现场将切到「他主动坐实身份」的体面收束，四角裤暴露改写为「他自己脱到只剩四角裤」，但这句「认输」会被银幻追问后续硬盘动机。
- 若黑袍被扒装时先用左左幻化成口罩线佩戴兜帽层，则银幻的下扯动作只扯到一层左左手型的人身伪装，扒装现场多一段「他的脸是左手捏出来的」误会才暴露真容。
- 若林恩（黑袍）在扒装瞬间把心挂住精灵之眼触发空间折跃试图逃离，则身份坐实流程中断、银幻进入追击链条，E531 审判的物理场景改写为城外荒原。
- 若林恩在私藏里多埋一份自己写给自己的「训练忏悔笔记」，则这份笔记被抓出会成为另一条动机证物，夏娃/巨像原委的口述解释不变，但感情债的深重层在他自己笔下被预先证实。
- 若小小翻出「妈妈和爸爸的牙齿」时主动跑去找主母献上，则主母会被诱导进入现场，她用主母权限直接追问林恩身份，整场试探的道德压力抬升一级。
- 若自缚天使的红茶包曝光时就有巫神头颅现场起哄「这是谁的」，则自缚在会议上立刻跌神位秩序，她主动离开会议、不再主持后续私藏汇总；盘点人换成艾雯。
- 若银幻在动手撕黑袍前先用原子机械把整片广场罩入快门录像模式，则 540 度全视角扒装全程被她留下，但她自己看完画面会直接当机十分钟。
- 若林恩在扒衣序的最后一段强行把四角裤本身也丢出去，则扒装收束时他是真正赤裸站在广场中央，银幻抓袖拉住门板不对外，她对他的信任破口被她自己亲手锁上。
- 若林恩（黑袍）在左左暴走的瞬间主动对左左大声承认「是我错」，则左左的暴走会延迟一秒、并给最终是否反戈这一场中的犹豫留出空隙。
- 若林恩在广场时让羽毛笔作为参与者通过冥想远程看着，则羽毛笔对「他就是那个渡鸦」的共感在当事瞬间会被确认，他失去在羽毛笔面前再隐藏偷窥者名的可能。
- 若银幻在「他有东西要给你看」之前再点一枚火焰扔到他脸上试探，则林恩的火抗会被作为身份旁证之一被记录进她的「必是他」账本。
