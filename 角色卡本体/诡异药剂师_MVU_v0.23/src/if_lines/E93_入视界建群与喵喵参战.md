# E93·入视界建群与喵喵参战·if线

- 若林恩只带爱丽丝参观视界广场、暂不点发入群邀请，则她乖巧牵着的手心没等到那行系统字，主母现身时机由后续触发另行编排，妹妹前缀缺位，家册上她仍只是"夜医寄宿的小女孩"。
- 若林恩给爱丽丝的群前缀改成「义妹」或别的昵称，不用「妹妹」，则名册里那一栏与她日后在夜医、主母嘴里的称呼统一跟进，初恋天使对她身份的第一印象按新前缀重新落笔。
- 若林恩点发邀请前先往群里丢一句「我把亲妹妹拉进来，别吓到」，则初恋天使不再"……"三秒，直接现身回呛，训斥缩成半句，追问小小下落的顺序被她自己抢先截走。
- 若林恩顺手把左左也拽进群，则她(ΩДΩ)的表情从房前延到视界广场，主母训斥对象扩大，三根源截击情报照放，但授权艾雯爵士参战附带一条"看住那孩子"的额外条件。
- 若林恩拉爱丽丝入群时把她按在自己腿上让她看清每一条群公告，则她在他怀里忍着脸红逐字读完，喵喵事后看到成员列表时那一栏的入群时间让她多喵了一声"主人偏心喵"。
- 若林恩听完「小丑拦截」立刻想到体内同名诅咒并当场告诉主母，则主母把"人为拦截"升格为"极有可能针对你"，授权层级上调一档，艾雯爵士带回的咒具清单多一件针对小丑系的应急品。
- 若林恩不追问小小和泰坦的下落，则主母不主动吐截击情报，三根源抵达时间与状态由玩家另行探索，"小丑拦截"这条因果挂起。
- 若林恩先问情报再解释爱丽丝身份，则初恋天使的训斥被压到情报之后落下，三根源截击先行入档，事件因果不变但叙事节奏前后对调。
- 若林恩不连珠炮拜托、只挑两件提，则艾雯爵士只把被点名的找回来，夜魔刀与夜医套装按夜医流程搁置，天使之吻续费链路需要玩家另行启动。
- 若林恩把七本诅咒书说成六本、忘掉一本，则艾雯爵士按六本清单去办，缺位的那本被其他夜医顺路带回或延后出现，钩子从"独缺一本"改写为"哪一本失踪"的悬念。
- 若林恩拜托名单再追加一项备用手术线或咒纹绷带，则艾雯爵士的"我尽量"难度上浮，首次响指扇回卧室的时点提前，第六件事没被应允。
- 若林恩改口要求主母当面续吻而非印唇纸，则艾雯爵士回一句"自己回去印"，白光祝福不立刻落袋，天使之吻续费动作延到后续场景，E94开场前他胸口那道印记是缺的。
- 若林恩接过六本诅咒书不核对清单就把印唇纸拍在胸口，则《看了就会死的书》失踪这条钩子被动延后暴露，白光缭绕落进祝福时他还以为七本齐了，后续在某次清点时才当场炸出来。
- 若林恩当场追问《看了就会死的书》失踪原因，则艾雯爵士承认探查失败并暗示有更深一层的力量在遮蔽，钩子从被动揭示升级成一条由玩家主动追的分支线。
- 若林恩把印唇纸上那行「回来杀了你」折起来收进内袋不贴胸口，则24小时祝福不生效，胸口镜像印记不落，他在E94开场时少一道灵性护盾，左左的紧张感多一层。
- 若林恩把六名疑似疫医的座位号按席位用密语写给艾雯爵士、不当面指，则被点名者不察觉暴露，幽灵模式布置更干净，但他们仍在队列里随灵能跃迁装置就位，破口压到E94开战当口再撕。
- 若林恩点名时存心点错一两个，则艾雯爵士按错位名单布置，真正的内奸漏进阵列，E94开场夜医防线多出原作没有的破口，他事后从面板里看到错位痕迹才补上。
- 若林恩选择暂不点、先把名单收进面板等开战再说，则艾雯爵士不开幽灵模式，上千夜医列队整齐走完，六名内奸以原位进入E94，以另一形式在战场上浮出。
- 若喵喵没能混过跃迁安检被拦在门外，则她改用附身黑猫贴在某一名夜医的披风内衬里折返参战，久别重逢的强吻环节取消，可控猫化展示推迟到她在战场首次出手那一刻。
- 若林恩在喵喵扑上来强吻时稳住身形顺势回吻，则她的猫尾把他整条手臂缠得更紧，爱丽丝的空洞眼神从下颌压到脚尖，左左(ΩДΩ)定格，队内修罗场被记下，后续可捡回再点火。
- 若林恩按住喵喵让她退回黑猫形态、表明此刻不是撒娇场所，则她呲溜一声缩回一只黑猫趴在脚边，可控猫化被压成只切换形态、不演示导弹变猫的军用版，千名夜医没看到最震慑一段。
- 若林恩现场让喵喵演示军用版但限定规模不许真上导弹靶，则滚动演练在阵列前放完，可控猫化的战场价值没在第一线坐实，但艾雯爵士把她归入了"待登记战力"那一栏。
- 若林恩当场把喵喵引荐给艾雯爵士登记为正式随从，则她名字写进夜医序列，E94开场能合法随队折跃不再只是悄悄混入，"喵喵参战"从灰色渠道转成正编，她对林恩的那声"主人"在名册里立得住。
- 若林恩把喵喵、爱丽丝与左左同时安排在自己紧挨的观战位，则三人同框对视的牵引张力抬到E94开战前夜，谁站在他左侧谁站在他右侧都被队内记下，可在三蜂巢压顶时翻出回响。
