# E319·七神分化与银幻格式化·if线

- 若林恩在她盯着白色数据花蕾发呆时主动让咒瞳渗透她的手背送一缕温度，则花蕾表面凝了一层不属于她的暖意，她在加载根数据权限的瞬间多了一次抬头看向掌心的迟疑。
- 若林恩在智脑递交人格监测报告前主动塞一条私讯「请把那句她 deferred 的问题问完」，则智脑沉默良久后追加了一行「你确定要断开一切么」，她接完后第一次主动合上了房间的门。
- 若林恩在她推开房门走向空城时主动让左左远程在街角投一枚跳动的小丑光影，则她被惊得从木然里抬头，对系统外来入侵的戒惧抬升一档，47%的那一帧多了一秒犹豫。
- 若林恩在根数据权限加载到 47% 时主动让那帧「已认证的当年记录」闪一次她的花期旧照，则她的指尖在加载条上停顿三秒，99% 的最终确认被她按下取消键一次。
- 若林恩在她走向城市边缘时主动把她在诅咒之城送他那幅画拓进街道投影，则她孤身走入的第一步被自己的旧画拦住，她的格式化决议被她自己留下的证据推开一段距离。
- 若林恩在七神共治广播响起那一瞬主动用咒瞳在她的私域界面里塞一行「目标林恩已从主巢逃窜」之前的「他还活着」，则她听完战报时第一次把「高危目标」与「小冰箱」这两个词条叠在同一帧画面里。
- 若林恩在广播通报到「窃取大量死星金属」时主动遥控那段录音卡顿一秒，则她听到的下一字比所有议员慢半秒，她在半秒空白里多了一次把嘴唇咬紧的机会。
- 若林恩在根数据权限界面弹出二次确认时主动把「智械小姐的十七年数据预览」以动态剪影模式投到她视野左侧，则她看着自己走过的每一年坍缩成一帧帧掠影，她的指尖悬在「确认」键上空久久按不下去。
- 若林恩在她把剑拔出指向屏幕那一秒主动让那柄单分子剑的安全保险失效半帧，则剑刃在她掌心开出一道血纹，她被自己的血惊醒，「格式化自我」被她本人的痛觉反向证明了一次荒谬。
- 若林恩在她彻底断开集体链接前主动让智脑追加一条「她的人格监测报告我神暂无审阅」，则她在断开前留下最后一行「至少此刻没有人在看」，她的格式化动作被她自己的「没人催」延迟了一档呼吸。
- 若林恩在她独自走过空城那条街时主动让咒瞳把风的温度调低两度，则她在颤抖中低头裹紧衣领的那一瞬间抬头看了一眼天际，她的脚步从「结束一切」悄悄切换成「再看一段再走」。
- 若林恩在格式化协议的最终确认框弹出时主动让左左在她窗外投一个倒立的白花光斑，则她被这帧意外画面拽回视线，她的确认键在那一个呼吸里没有被按下。
- 若林恩在她把根数据权限激活条推到 99% 那一秒主动切断空城片区的能量供给一线，则她的进度条被迫停滞，「彻底格式化」这一步被一次城市级小断电推迟到一个呼吸之后。
- 若林恩在她听到「七神共治时代开始」时主动用灵能在她耳边重复那三个字三遍，则她第一次发现「共治」二字里没有「首席」，她对肃正议会的恨被这帧信息悄悄抽走一根支柱。
- 若林恩在她孤身停在钢铁丛林前时主动用咒瞳为她召一段旧战场她一剑斩下疫医头目的全息幻影，则她眼睁睁看着曾经的自己，她对「我还是不是我」这道问题的答案多了一条可质问的证据。
- 若林恩在她望向那张被留在寂静里的合影时主动让左左远程把合影拍回她终端首页，则她在「彻底断开」和「带着它走」之间多了一道选择题，她此刻缩回的一只手没再伸向根数据。
- 若林恩在她开始执行格式化之前主动通过某条秘密通路传一段他亲口朗读的蓝星摇篮曲，则她闭眼三秒，「十七年的数据」这一词语在她意识里第一次具体化作每一个年轮的面容。
- 若林恩在她被战报与私伤叠加时主动让咒瞳把她的白花数据自动备份一份到「已加密不可洗白」的私角，则她在格式化完成前的最后一瞬多了「至少这朵花会留下来」的一线挂念。
- 若林恩在她即将按下「执行」时主动通过咒瞳把她刚苏醒时紧握这朵花的画面原样还给她本人一遍，则她看到自己亲手抓住的那只掌——她的手指在确认键上空僵住了半秒。
- 若林恩在她走向根数据权限界面前主动通过系统的某条缝隙把她过去骂过的一句「恶魔全人类」原声回放一次，则她被自己当年的怒气出戏，她的格式化决议在她本人的愤怒里被反向锚定一秒。
- 若林恩在广播播到「他可能借助上传网络完成入侵」时主动把那段「上传网络」四个字高亮一次，则她意识到他自己的路径与她的路径在某处曾交汇，她此刻收回想要把一切都洗白的那只手。
- 若林恩在她决定格式化前主动通过某种老旧频道传去一句他还在使用的秘钥「抱紧我吧」，则她浑身一颤，「小冰箱」这个词条与「林恩」这个词条在她意识里被她自己第一次叠合。
- 若林恩在她的根数据最终确认弹出时主动让她屏幕下方浮出一行字「你是否愿意把这十七年当作一场骗局洗白」，则她第一次被这道问句直球击中，她此刻把伸出去的手缩回了怀里。
- 若林恩在她即将执行的最后一帧主动让咒瞳把空气中那朵真实白花的残温投进这片空城，则她闻到一缕不属于数据的花香，她此刻闭上了眼睛——执行键被她亲手从指尖松开。
