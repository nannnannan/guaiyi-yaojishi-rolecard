# E151·血肉真身接纳与平等信任·if线

- 若林恩化猫进入真身区，则原作路径成立，羽毛笔的「猫咪」认知被进一步强化，尖叫驱离的强度降一拍，但仍会哀求他先离开。
- 若林恩以人形进入且未先解释来意，则羽毛笔把他认作「好奇者」而非「懂她的人」，驱离带上明显恐惧色彩，事件往取消条件方向滑一步。
- 若林恩在抓住狂乱笔触被甩飞后立刻站稳、不再逼近，则羽毛笔的暴走凸触暂停半秒，给双方留下一个「不逃也不压」的对视窗口，后续信任判定从「他能忍住」起步。
- 若林恩被凸触抽飞后转身离开、不再返回，则本事件不进入「猫咪=同类」揭示，真身互认挂起，羽毛笔在原地独哭至反噬下一轮，事件变形为「安全撤退」。
- 若林恩用绷带或外物把脸面撕开处缠住再继续靠近，则「变得和你一样」的视觉冲击减半，羽毛笔的怔住节拍被延后，原作那段名场面被现实化处理。
- 若林恩没有擦落眼球、保持被抽烂的姿态安静跪坐，则不出现「眼球慌忙安回」的狼狈笑点，但羽毛笔对他「能忍」的认知同样成立，名场面可由别的方式落地。
- 若林恩把掌心的「死物」羽毛笔轻轻放回书桌才说话，则羽毛笔第一次意识到自己显化被识破的完整链条，坦白节奏加速，事件直接进入「权柄显化 vs 血肉真身」对账。
- 若林恩试图用血肉支配压制凸触，则羽毛笔把他判为「想用力量逼我出面」，反噬瞬间被引向林恩自我，事件变形为「血肉同化危机」。
- 若林恩提出「让我替你受一段反噬作为平等信任的代价」，则羽毛笔在意识清醒下拒绝，她不再把他当作「同情者」，但反噬总量不变，E152 的承担议题提前抛出。
- 若林恩带来外部麻醉或催眠药剂试图让她停止哀叫，则本事件取消，她的暂睡眠不算「清醒允许交流」，平等信任完成条件不成立，事件挂回 E150 重新进入。
- 若林恩对着血肉高喊「我已经放过那张字据了，现在我们重新谈」，则欺骗字据的歧义被当场抹除，羽毛笔获得一次「不靠诱导凭证」承认他的机会。
- 若林恩保持沉默、只用动作把身上被抽烂的皮肉一点点挪到她面前，则羽毛笔的羞耻防御从「被推入」转为「亲眼看见」，事件照常推进但林恩不发声也能完成揭示节拍。
- 若林恩私自携带猫咪形态下的旧物（小鱼干袋、毛球玩具）让羽毛笔联想起之前的无害接触，则「了解你」的成立成本下降一档，她的反应从怔住转为抽泣式默许。
- 若林恩说过「变成什么样我都认识你」之后立即追问「那你愿意和我说反噬还有多久」，则话题被切到 E152 之前，事件变形为「真身互认+信息量超出」，地狱回应节奏整体前移。
- 若林恩未说出「猫咪」自比而是改用「朋友」「同行者」等称呼，则羽毛笔的认可仍成立，但她对林恩身份的认知会被记录为「人形化猫」的复合叙述，后续对话中她对猫偏好不再独占。
- 若林恩在被抽飞超过五次后开口求停，则羽毛笔停手但他已遍体鳞伤；事件仍可完成，但林恩获得「以伤换认」的额外代价项。
- 若林恩在她说出「不会的，因为我了解你」之后立刻索要亲密（拥抱、触碰病变血肉），则她当场拒绝，事件不取消但亲密窗口关闭；色色按真实拒绝白描呈现。
- 若林恩提议「那让我先治好我的样子再来」，则羽毛笔怔住片刻点头，事件变形为「延后互认」，E152 触发时机被拖到林恩形象恢复之后。
- 若林恩试图当场解释紫罗兰力量怎么让自己的皮肉变得像病变，则她强行打断话题，把紫罗兰隐秘重新上锁，事件提前收尾、相关伏笔被归档为「她不许提」。
- 若林恩保持远距、只用书页或黑弦月转述完成互认，则按变形条件路径成立，不发生身体接触的真实互认仍记为完成，亲密路线延后到 E152 之后。
