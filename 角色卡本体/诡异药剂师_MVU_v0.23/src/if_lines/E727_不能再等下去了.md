# E727·不能再等下去了·if线

- 若林恩在黑夜城王庭大厅听完堕天使关于各星域执政官上任与自杀率下降的汇报后，勉励他一句「深渊一脉这几年做得很好」，则这位从旧日追随至今的堕天使会激动地深深俯首，各星域的政令推行效率再提一成。
- 若林恩在正式取消圆桌议会、改建为黑夜城王庭的那天，命人将当年地狱时期那张破旧圆桌的木料封存在王座基座之下，则他在独坐王座时仍能感受到当年巨像、艾雯、主母与泰坦大哥围坐欢笑的余温。
- 若林恩在屏退左右、独坐王座望着垂落的旗帜向紫罗兰大君低语「这会是你曾经想要的吗」时，伸手抚过冰冷的王座扶手，则他会更加深刻地体会到那位初诞者当年孤身背负整个秩序世界时的彻骨寒意。
- 若林恩在十年间的第三场大战面对十七尊魇魔时，主动在万军丛中锁定刚刚复活归来的魇王并将其再度当场格杀，则梦魇大军的攻势会提前瓦解，主宇宙外围的三颗工业星球得以免遭涂炭。
- 若林恩在第五场大战面对二十尊魇魔时，选择独自一人提刀杀入无序深空、直接堵在沉眠的灾厄本体附近释放滔天罪火，则那二十尊魇魔会因投鼠忌器而不敢越雷池一步，但林恩自身的精神消耗也会达到十年来的顶峰。
- 若林恩在十年征战中察觉自己鬓角渐生白发却毫不在意、连镜子都不看一眼，则只有在银色幻想或船长短暂苏醒时，他才会在谈笑间被她们心疼地指出这一缕沧桑。
- 若林恩在银色幻想短暂苏醒的片刻，完全卸下帝王的威严、像当年在地狱里那样坐在她床边讲起这几年的趣事，则智械小姐会在安心的微笑中重新沉入深眠，神王格的融合进度大幅加快。
- 若林恩在二十尊魇魔学会于大梦中集体自爆以加剧他意志负担时，及时收缩大梦范围改为高密度罪火绞杀，则他能减少三成精神反噬，但前线军团需要多顶住半个时辰的梦魇潮冲击。
- 若林恩在王庭大厅闭关强行冲击第三阶段、遭遇罪火失控暴走烧尽全身血肉时，死死咬紧牙关将暴走的火浪全部压在预先布下的禁制之内，则整座黑夜城将毫发无损，而他自己会单膝跪在血泊中大口呕血。
- 若林恩在自缚天使急促冲入大厅搀扶起摇摇欲坠的自己时，勉强笑着摆手说「只是老毛病了，别声张」，则自缚天使会红着眼眶替他擦去血迹，对外严密封锁王在闭关中重伤的消息。
- 若林恩靠在王座边缘向自缚天使坦言「三位一体的补全只是增加本源权重，但在这之外还有无形的东西挡在我面前」时，主动联想到奇异世界里的织梦，则他会立刻决定不再闭门造车，动身前往奇异世界向织梦请教。
- 若林恩在说出「我们已经不能再等了」之后，先将黑夜城未来数月的防务调度全权交托给自缚天使与艾维儿，则在他前往奇异世界陪伴织梦的这段时间里，主宇宙边疆依然固若金汤。
- 若林恩在离开王庭大厅前最后回望一眼那座高高在上的王座，则他会在心中暗自发誓：哪怕前方是刀山火海，他也绝不允许自己在这场末日里倒下。
