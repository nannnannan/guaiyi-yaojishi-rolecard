# E727·不能再等下去了·if线

- 若林恩在进入黑狱门缝前先把三叉戟交给艾维儿保管，则主宇宙防线能在表层战争初期更多一份威慑，但林恩独自深入时失去主宇宙本源的呼应，黑火爆发筹备期被拉长。
- 若林恩选择把意识探入门缝之前先在门口立一座临时祭坛、向她奉上一杯酒，则黑狱的门会迟缓一瞬才闭合，他能多感受到一缕「她还在」的余温，但那瞬间门内的灵魂深渊也记住了他的脸。
- 若林恩在门内灵魂深渊前回头望向门外的蔚蓝天空一眼再踏入，则他会把那一眼作为往后梦境中的清醒锚点，但同时那一眼里他也永远告别了这个主宇宙表层的「人间感」。
- 若林恩在门槛前被一缕清凉从脚底升起时突然想到左左，则他会立刻收住脚、不向前一步，他会先在门外长立一日，让那缕清凉沉到心底。
- 若林恩对门内的巨大苍老声音选择不回应、不被它吸引，则他能以纯粹意志踏入，但与门内某个更古老的存在之间的「未曾倾听」将成为后续合作的永久阻碍。
- 若林恩抬手握紧刀、连呼吸都没乱地面对二十只重建终焉柱的噩梦，则他会以一记纵斩强行贯穿最先成形的一根，但其余噩梦的反扑会立刻锁定他。
- 若林恩选择在第一波噩梦来袭瞬间反向跃回门内、让那些噩梦撞在关上，则他会给自己赢到半个呼吸的准备时间，但黑狱的门会在他眼前永久关闭一缝。
- 若林恩带着对左左的执念把那场混战视作「为她而战」，则他的刀会在某一刻突然激发出一缕从未有过的黑火变体，那一道黑火化出第一次前所未有的形态。
- 若林恩把黑狱中的部分灵魂残片暗自收入系统空间准备带回黑夜城研究，则他会获得研究黑狱本质的第一手材料，但那些残片会时不时在系统空间深处低语。
- 若林恩决定先回援噩梦柱再深入黑狱，则外环会更稳，但他会失去「先入为主」的黑狱印记，将来再入门时要多花一倍精力才能寻到原本那条路径。
- 若林恩在门槛前心事重重地反复踱步、最终没有踏入，则那扇门会缓缓在他面前再次沉入地底，下一次它出现的位置将完全不可预知。
- 若林恩选择把自己的一滴血抹在门缝边缘作为印记，则他将来能从任意位置感应到门的位置，但每次感应都会让他短暂失控、被一丝黑狱意志附身。
- 若林恩带着对未来的恐惧和决绝同时跨入，则他会在门内第一次瞥见自己的死亡景象，但那个景象也包含了一线生机。
- 若林恩主动让自己的罪火被门内黑火短暂吞噬一次以淬炼，则他会受一次真正的濒死体验，但醒来后他对黑火的理解会跨越一个量级。
- 若林恩在门内听见某个声音说「你来晚了」，则他会立刻明白这扇门并不是只为等他才开启，他会从此意识到这世界上还有另一位或几位在走向同样的终点。
- 若林恩进入黑狱时故意留下一缕罪火封在门外、给艾维儿作为警讯，则艾维儿能在异常发生瞬间获得警报，但那缕罪火也将永远无法回收。
- 若林恩在门口给银色幻想的沉睡神格悄悄传一句话「我去门里了，你别跟过来」，则她未来苏醒时会因为这一句话反而立刻挣脱束缚想冲进来，林恩需要为此负责。
