# E588·三位一体白焰·if线

- 若林恩在出体前先对左左交代三句详细看护守则，则左左收下钱袋时不会一边哭一边搜他全身，醒来那一段改成她乖乖蹲在肉身旁边数数。
- 若林恩出体瞬间把一缕心神贴在左左发梢作保险丝，则灵魂暴露灼烧时左左会在现实端感受到一阵阵暖意，事后她红着脸不肯细说。
- 若林恩在灵魂暴露瞬间立刻拔升灵能而非依赖初诞者之力硬扛，则灼烧压力以更猛烈的方式反咬灵能本身，扑火段成为真正的「三质缺一不可」的实证。
- 若林恩拒绝让左左携肉身会合、独自以灵魂态冲向苍白耀阳，则三质同框的画面缺了巨像血气一角，灵识烙印口述的时点改写为灼烧中一道孤影提起。
- 若林恩在扑火前主动告知左左自己将独自入火，则她哭喊摇晃的时间提前、扑火段她递来一缕血气援注，三力归一因她的血气而更稳一线。
- 若林恩在苍白领域叫醒灵识烙印后先问奈奈子下落，则烙印消散前那句「欲见奈奈子未及」被一字一句说完整，林恩肩上多一笔「代问」。
- 若林恩在烙印口述中追问「融合失败而终焉之主诞生」的细节，则烙印用最后残力给出一段模糊的「月之背影」画面，后续事件多一条悬线。
- 若林恩拒不接受烙印消散、强行用灵能将其压制封回魂壁，则烙印不入消散流程，体内多一位时而复苏的「过去自己」，悬念改为定时炸弹。
- 若林恩在映像中刻意多盯紫罗兰大君背影十秒，则映像结束那一刻大君眷恋一瞥与他隔空对上，初诞者之力随之颤一下。
- 若林恩把白发白瞳形态当作对外的定装拒绝散去，则外观「近渡鸦记忆白发人」直接固化，回到左左面前她以一句「装逼」收下整段喜剧。
- 若林恩在内视胸腔熔炉时闭上第二种感官、刻意只看血气一力，则他能临场感受巨像心跳，但会失去对「星环钳制看守」这层警铃的清晰读数。
- 若林恩在左左哭喊时夺钱镇压后补一句「我不会白吞你这三千年」，则左左傲娇脸红情绪峰值被进一步推高，E589 里她点名「媳妇画家、娃艾维儿」的嘴更硬。
- 若林恩公开说出「三位一体」一词给左左听，则左左会私下在系统空间学舌，E590 动员段她脱口而出「三位一体究极合体技」被巫神镇压。
- 若林恩选择不驱白焰只在内视中留存，则外观无白发变化、骨肉爆鸣不显，E589 撤离时屏蔽实证改用一缕若有若无的焰息。
- 若林恩在容量瓶颈显露时立刻停止向熔炉借力，则耀阳仍亮而不熄，离开时遗址多一层「未借力过度」的余裕，E589 弃搬耀阳时他心里负疚更轻。
- 若林恩在离开前回头朝原耀阳深深一拜，则耀阳光芒微微晃动一次，作为外部对照记录「借火有还」。
- 若林恩在灼烧中刻意留住一缕痛苦的知觉不肯过滤，则 E589 撤离时他神魂带伤，屏蔽窗口缩短五秒。
- 若林恩自始至终没召唤以太、没解放巨像血气、纯以灵能加初诞者冲向耀阳，则三质不齐、化焰不立，事件整体走向变形：灼烧升级，魂域改走体魂剥离失控分支。
