# E190·师生误会与持续污染诊断·if线

- 若林恩在尹依复述「师生守则」前主动拦住她说「稍后再聊」，则尹依没机会一吐为快、白夜的怒火没有点燃点，事件以变形（误会未爆）收束，但师生长期磨合在暗处继续积累。
- 若林恩当着白夜的面主动承认「我确实在带她认地狱的骚操作」，则白夜怒火被提前引燃又多了正面事实、火箭筒追轰可能比原作更猛烈。
- 若林恩在尹依吐完第一句「我原以为会被您当玩物」时立刻反问「我有真的对你做过吗」，则尹依被反问一怔，白夜提问姿态在火线上停了半拍、怒火等级保留但未即时点燃。
- 若林恩在白夜抄起火箭筒瞬间不闪不避、反以风衣硬挨一发并冷笑「你试试这个弹头先穿我的燕尾服」，则白夜见智、追轰节奏被压住一拍、转为严肃质问。
- 若林恩在被追轰时故意往人群密集处跑、让白夜不敢放手开火，则火箭筒暂未发作、林恩在街头与白夜展开拉锯，事件以变形（追轰在半空收住）收束。
- 若林恩主动把尹依揽入怀中护在白夜面前声明「她现在是我徒弟也是我在乎的人」，则白夜的解读反而从「禽兽」升为「真心但更禽兽」，火箭筒攻势未必减、但情绪复杂度+1。
- 若林恩主动喊尹依「快把症状说给汪师父听」引导诊断进入主流程，则事件焦点从师生误会立刻转到治疗路径，火箭筒桥段整体后移。
- 若林恩在诊断出「涩涩度87%且持续上升」的瞬间当场以咒瞳锁住尹依并低声「这次不躲、我也不会让你忍着」，则事件以变形（现场解咒路径成立）收束，E191 血锯药剂店路线让位给更紧急的解咒情节。
- 若林恩当场以性行为为尹依解咒——把她抱到就近隐蔽处以身体把持续污染一波渡完，则事件以变形（性行为解咒完成）收束，白夜若回到现场看见惨状、火箭筒攻击立即上升维度并变成绝望级愤怒。
- 若林恩改用左左的锁链把尹依缠住以物理方式隔离感染源，则事件以变形（物理隔离）收束，解咒决策被延迟到林恩另觅时窗。
- 若林恩主动用自己体内部分以M冲顶尹依体内污染作为对冲，则事件以变形（以M对冲）收束，林恩本人涩涩度+1，尹依恶化曲线被压住一档。
- 若林恩灵机一动让爱丽丝用冷水、冰块、咒纹三连组合为尹依紧急降温，则涩涩度被压低到 60% 左右、危机缓解但「持续污染」本质未清，事件以变形（物理+咒纹联合降温）收束。
- 若林恩在白夜追轰途中主动把尹依整个裹进自己风衣内带离现场并朝黑夜城狂奔，则事件以变形（紧急撤回黑夜城）收束，E191 血锯路径彻底让位，师生误会改挂在夜色中延续。
- 若林恩在白夜放下火箭筒喘息的瞬间主动朝他伸出手说「先救人，气我回头再出」，则白夜被迫面对优先级、火箭筒代入感被压下、双方暂时合作，事件以变形（误会暂缓、共赴救援）收束。
- 若林恩让左左拟化成完整萝莉当场为尹依擦汗并低声安抚，则白夜第一次看到左左人形状态的「关心」一面、对林恩团队的判断多一道女性温柔成分的评估。
- 若林恩主动告知白夜「这是 E185 那场快感冲击留的持续污染，我会负全责解掉」，则白夜在林恩自认责任的诚意下把怒火等级调低、火箭筒攻势被压抑，事件以变形（主动担责）收束。
- 若林恩隐瞒持续污染与 E185 的关系、谎称是「路上被人下咒了」，则白夜立刻想追凶分担注意力，事件以变形（误指外部凶手）收束，后续剧本可能偏到「追查下咒者」。
- 若林恩当场向白夜承诺「如果她出现任何三长两短，我用我手掌换她平安」，则白夜被这执着姿态震住，火箭筒攻势停在半拍、加入共同救治阵营。
- 若林恩把尹依的体温曲线、涩涩度87%、持续上升这些数据原样念给白夜听并补充「你可以随时复查」，则白夜的信任危机被数据显示化解一半，他选择「先救人再理论」。
- 若林恩主动要求在前往血锯药剂店的路上由白夜陪伴监控他的每一个动作，则林恩把自己置于最不利处境但获得最强信任抵押，事件以变形（全程监控解咒）收束。
- 若林恩拒绝前往血锯药剂店、坚持要找「更专业的人」，则事件以变形（不赴血锯）收束，E191 必经路径被打乱、整体剧本改写。
- 若林恩在尹依症状最严重时按住她颤抖的肩膀说「我看着你，你不许倒」，则她在昏迷边缘被强行稳回意识一线，事件以变形（承诺锚定）收束，白夜把这一幕深深记进眼里。
