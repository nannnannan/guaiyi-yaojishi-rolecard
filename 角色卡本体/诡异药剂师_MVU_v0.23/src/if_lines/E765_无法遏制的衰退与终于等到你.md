# E765·无法遏制的衰退与终于等到你·if线

- 若林恩在无序大梦的狂暴黑海中主动放弃对抗、任由意识彻底沉入海底，则他在无序演化到极致的瞬间成功逆转出磅礴的金色秩序，完成了如「衔尾蛇」般的闭环。
- 若林恩在极致秩序与极致无序成千上万次的交替轮回中始终守住本心，直至某一次秩序逆转至绝巅、一缕终焉黑火在金色秩序大梦中倏然亮起，则他真正靠自己的力量跨过了第二门槛。
- 若林恩在金色秩序大梦点燃黑火的瞬间当即终止进一步向虚无的演化、欣喜若狂地睁开眼收回大梦，则通讯频道第一时间广播出无需羽毛笔牺牲的喜讯，整个大梦空间回荡着胜利的宣告。
- 若林恩在睁开眼看清眼前的羽毛笔早已红颜褪尽、满头白发、干瘪枯槁如行将就木的老妇人时，则虚空中狂暴的神火扩张瞬间凝固止息，整片时间之外陷入死寂。
- 若林恩在目睹白发枯槁的羽毛笔怀中正紧紧抱着完好无损、甜美沉睡的小女孩左左，并向他露出欣慰微笑说出「太好了……我就知道你肯定能够回来的……所以，我也没有食言哦……」时，则周围的时空力场在情绪剧震下发出沉闷悲怆的轰鸣。
- 若林恩在苏醒瞬间感知到时间之外的恐怖变化——百年前被放逐定格于此的诸神躯体与神格爬满裂纹，连悬浮在羽毛笔头顶庇护她的「时间神格」内里也隐隐出现了磨损与裂纹——则诸神躯体与神格上的崩解裂纹如蛛网般蔓延，清晰证实大衰退的侵蚀法则早已强行渗透进时间之外。
- 若林恩注意到时间之外身后蜿蜒流淌的「时间长河」坚韧超脱、丝毫不受大衰退干涉，则该关键法则抗性参数被客观记录入系统数据链。
- 若林恩通过羽毛笔残存的命运丝线回溯她守望期间的经历，得知她在不断咳血缝补自身断裂法则的绝境中，发现了被初诞者之力吸引漂流而来的冰封左左，则羽毛笔那万道命运断线的因果负荷在回溯中完全展开。
- 若林恩看到羽毛笔当年吃力地将冰封左左拉入怀中、读取林恩曾两次放逐保护左左的命运轨迹后含泪笑着说出「就让我们两个一直等他吧！」的记忆画面，则机体核心因能量过载而发出沉闷的低吼。
- 若林恩看清羽毛笔正是因为用自己仅存的命运丝线将左左层层包裹、替左左抵挡了所有大衰退的恐怖侵袭，才会耗尽神力从命运女神衰老成垂死凡人老妇，则虚空中的秩序屏障在此刻全面震颤共鸣。
- 若林恩在衔尾蛇轮转苦修期间留有一丝潜意识感应外界，则他在某次轮回间隙隐约听到过羽毛笔压抑的咳嗽声，从而拼尽全力将苏醒时间提前了数分。
- 若林恩在刚点燃金色秩序大梦中的那缕终焉黑火时先将其稳固在梦境核心，则这团新生的黑火既具备终焉的毁灭伟力，又完全听命于他的秩序意志。
- 若林恩在收回大梦的刹那第一时间将磨损裂开的时间神格招回体内温养，则神格的裂纹不再继续扩大，保住了后续横渡时间长河的根本。
- 若林恩在看清怀抱左左的苍老羽毛笔时，连呼吸都变得小心翼翼生怕惊扰了她微弱的生机，则这位曾在万军之中杀伐果断的神王此刻手足无措得像个孩子。
- 若林恩在听见羽毛笔说「我也没有食言哦」时强忍住夺眶而出的泪水朝她用力点头，则羽毛笔浑浊苍老的眼眸中亮起了最纯粹的喜悦光芒。
- 若林恩在探查沉睡中左左的状态时发现她体内连一丝一毫的大衰退伤痕都没有留下，则左左周身环绕着羽毛笔以本源神力编织的绝对庇护结界，结界损耗程度显示出倾尽性命的守护优先级。
- 若林恩在时间之外的死寂虚空中半跪在枯槁的羽毛笔面前，则他将全部的敬意与温柔都献给了这位信守诺言陪伴他到最后的命运女神。
- 若林恩察觉羽毛笔体内断裂的命运法则已彻底失去神性光辉、生机垂危，则金色秩序梦境自发狂涌而出、秩序金光全力笼罩其残躯稳固心脉。
- 若林恩在苏醒后对“大衰退连时间神格都能磨损”这一异常现象留下一分警惕，则这为他日后在时间战争中怀疑手中时间神格并非完整原件埋下了伏笔。
- 若林恩在冲向羽毛笔张开双臂的那一刻，将满腔的庆幸、心痛与眷恋尽数化作紧抱她枯瘦身躯的动作，则两人在时间之外迎来了最催人泪下的重逢与告别。
