# E765·无法遏制的衰退与终于等到你·if线

- 若林恩在无序梦境中感到羽毛笔命运线颤抖时主动沿那条线回送一缕黑火，则羽毛笔火焰短暂稳住一拍，但他自己梦境中的护身黑火随之薄一分。
- 若林恩隔着梦境朝左左被冻结的方向轻声唤一句「左左」，则她身外的冰晶多一线由内而外的微光，羽毛笔找到她时定位更准。
- 若林恩主动让王座把羽毛笔命运线的根烙进自己灵魂，则即使羽毛笔本体消散，他未来仍能循着剩下那一线找到左左的未来坐标。
- 若林恩在梦中告诉羽毛笔「先去顾左左，再来顾我」，则羽毛笔把本已所剩无几的力气优先投入固定左左，林恩在梦境里的引路光少一缕。
- 若林恩主动在梦境中点一枚以小小金发为心的火，则羽毛笔在衰退途中被这枚火照到，获得一缕情感层面的燃料。
- 若林恩让王座在羽毛笔找到左左那一刻主动朝左左送一道苏醒信号，则左左在林恩的注视里睁眼一拍，但那一眼会立刻抽走羽毛笔所剩的一口气。
- 若林恩主动从梦境向现实一侧偏出一缕意识，则他能陪伴羽毛笔走完守护的末段，但梦境与现实边界因此薄一层。
- 若林恩把轮回神王留在梦境里的余温让出一份给羽毛笔，则羽毛笔短暂恢复旧日笔锋，却也从林恩身上抽走一份未来唤醒自己的力量。
- 若林恩让王座在羽毛笔前行的路径上先把某些时空裂隙抚平，则羽毛笔走得更顺，但王座深处的某段存档被消耗一格。
- 若林恩在羽毛笔即将消失前主动对它说一句「辛苦你了」，则羽毛笔在最后时刻被允许作为「伙伴」而非「工具」燃尽。
- 若林恩主动把自己梦境中某段关于旧日书店的画面送给羽毛笔作为陪葬，则羽毛笔在消散时多一段可以握住的画面，林恩自己却失去那段回忆的清晰边缘。
- 若林恩让梦境里黑河忽然改道绕开左左所在的冰晶一尺，则左左被洪流冲散的风险暂时退去，但河流改道撞乱了梦境另一端某段画面。
- 若林恩在羽毛笔找到左左时主动把自己的一缕心跳声送过去，则左左在冻结中听见那一份脉搏，她未来能凭这一份脉搏认出林恩。
- 若林恩主动在梦境中种一棵以黑夜城旧院为形的小树，则小树根系成为羽毛笔最后一程的凭依，但树上每一片新叶都从林恩记忆里抽一滴。
- 若林恩让羽毛笔在找到左左之后，先看到她的眼睛再看到她的全身，则羽毛笔首先识别到的是一份仍然活着的意识而非一具待救的躯体，选择路径更稳。
- 若林恩主动要求羽毛笔不要硬撑，把「撑不住也要说实话」作为前提，则羽毛笔开口交代真实的衰退速率，林恩得以精准规划最后的时间。
- 若林恩让王座主动在羽毛笔进入左左冰晶区域时亮起一道远灯，则羽毛笔在黑暗中走过去的那一段不至于踩空，但远灯的光会引来无序注视。
- 若林恩在羽毛笔说「我快要消失了」的时候主动伸手隔空握一下，则那只手成为羽毛笔最后的可确认接触，它在剩余时间里不再恐慌。
- 若林恩主动把左左曾经的旧语作为一种法则刻入梦境底部，则那条法则在羽毛笔引路时会以她的语气发声，帮忙指引方向。
- 若林恩让梦境深处的某一盏旧日临街灯重新亮起，则那盏灯为羽毛笔照亮一段归途，但周围其他画面因电流倾斜而短暂暗一格。
- 若林恩主动从黑火里抽一小缕作为路标埋在羽毛笔必经之路上，则羽毛笔在衰退视野里多一颗不会熄的火点，林恩自己的黑火表层留下一道永久痕。
- 若林恩让自己在梦中某个时间缝隙里和羽毛笔并肩坐一会儿，则羽毛笔在最后任务之前有一段真同伴片刻，但林恩的梦境进度因此慢半天。
- 若林恩主动把左左未来坐标的第一部分告诉羽毛笔而不是只说方向，则羽毛笔可以更早开始布线，但信息提前暴露给无序注视。
- 若林恩选择握住羽毛笔在它最后消散前的那只「笔尾」，则他掌心收到一缕真实的木质，那一缕木质从此在他灵魂里长成一棵极小的纪念树。
