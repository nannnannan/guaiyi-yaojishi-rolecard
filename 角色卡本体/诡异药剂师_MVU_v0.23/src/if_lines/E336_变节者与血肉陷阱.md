# E336·变节者与血肉陷阱·if线

- 若林恩在视界之主讲述旧神过往时插话打断，则变节者承认的引导链条被截断成更模糊的陈述，血肉支配者的怒火无从锚定。
- 若林恩提前把乌鸦面具扣在脸上亮相，则伪装让血肉支配者误以为他另有身份，质问对象从「你为何没疯」错向「你为何替林恩送死」。
- 若林恩在血肉支配者撕约前把和约副本揉碎吞进肚子，则印记永远无法完成签署，违约天谴同时卡住不落。
- 若林恩用往日遗念投影血肉支配者的父亲残影，则对方短暂失神，视野里小女儿的脸代替了叔父的审判，撕约时触手软化数寸。
- 若林恩让小丑的八音盒当场哑火，则 「既定轨迹」失去节拍，血肉支配者撕约动作迟滞半秒，足以让在场所有人看清分裂源。
- 若林恩在黑粉炸开瞬间主动对结界投一支净化试剂，则暗红藤蔓寿命缩短，城内药剂师抢出一丝喘息时间。
- 若林恩选择不目击「我是不是曾经见过你」那句话，直接折返黑夜城，则后续剧情中视界之主的回忆雷区换成独对一座空崖。
- 若林恩用一枚麻醉针射向自己的烙印，则他在被诬陷的夜色里当场昏迷，和约碎片被迫停在他失去意识的手边。
- 若林恩割腕取血浇在担保卷轴上，则自己的体液把自己划成第三方见证者，正式违约天谴变成他做保的烂摊子。
- 若林恩在血肉支配者面前抬头直视他的眼睛三十秒，则两者的仇恨同频共振，叔父今后的每一次攻击都带着一丝照妖镜的错觉。
- 若林恩把猪头屠夫卷进对话，则小丑的既定剧本第一次出现画面外配音，屠夫一锤砸断自己弟弟的台词节拍。
- 若林恩不用林恩这个名号赴会而报渡鸦，则身份假名让血肉支配者试图验证旧神遗骨，转移了他盯人质议题的火力。
- 若林恩在会面现场点燃一缕欲望母树的遗蜕，则灰烟飘散让黑粉活性翻倍，暗红藤蔓瞬间缠住他自己半边衣袖。
- 若林恩放弃担保者的担保，直接向血肉支配者扔出一簇本源火焰，则议还没开始就变成火拼，卷轴烧得比划线还快。
- 若林恩让左左从城外冲进来砸场子，则血腥小手的到场让谈判多出一个擅自炸裂的变量，叔叔恨意暂时转向幼态咒体。
- 若林恩用书面文字伪造另一条担保条款塞进卷轴，则羽毛笔在结界上当场识破他的小三手艺，负责通道的她暴怒封锁全档案。
- 若林恩在自称「我早疯过一次了」之后掉头走，则对方追击的激将法失效，黑粉不再以他为勒索主目标而转向整座城市。
- 若林恩掏出时间魂媒对准血肉支配者，则对方第一次遇见「停在时间外的恶意」，撕约的冲动被冻结在灯火下一瞬。
- 若林恩把会面地点改在欲望母树树冠之上，则肉果香气渗透全场，谈判者多了一层想退又退不得的体温。
- 若林恩拒绝质询叔父真相而直接发难，则小丑主动公布黑粉陷阱讯息，因为他更想让主角失控而不是看清算计。
- 若林恩当场宣布放弃赴约并把代理权出租给视界之主本人，则守护者当场破产，他不得不亲自面对自己耍过的把戏。
- 若林恩在撕约发生时高喊「你们赢了，我滚」，则恐惧指向真正撕裂的不是和约，而是他在城内的安置软弱替身。
- 若林恩向血肉支配者头顶投一支媚药让这些愤怒变成情欲，则触手纠缠的瞬间出现在不该出现的地方，围捕变成欲望失控。
