# E754·黑夜城沦陷·if线

- 若林恩在银色幻想下达「毁掉」命令瞬间主动通过黑火给予她一次支援,则她能在执行这命令时少受一份痛苦,「机械姬王的最后军令」会因此被赋予一层悲壮美感,她的决心会因此被记入王座最高档案。
- 若林恩让主母在阶梯上亲眼目睹银色幻想的命令并通过黑火给予她一个赞许,则这一赞许会被记入「主母的最终认可」,银色幻想的「服从命令」会因此带上最高位正当性。
- 若林恩让人偶家在拿出所有戒指的瞬间通过黑火给她一缕力量以让她的最后一刻更壮观,则人偶家的最终战斗会被定格为「繁荣之美」的最高体现,「人偶家的最后一击」会成为永久艺术。
- 若林恩让船长与人偶家在人偶家伸手与他握手时通过黑火完成一次同步,则他们的联手会带上一种「心灵合一」特质,「毁灭与丝线的最后合一」会成为王座黑火中最美的画面。
- 若林恩让主母在楼梯上挥剑斩腐化者时通过黑火获得一缕王座之力,则主母的剑术会在这一刻达到前所未有的高度,「主母的最后剑道」会成为后世剑术学习者最高位的追求。
- 若林恩让主母在与银色幻想对话时通过黑火给予她一缕关于「王座最后想法」的启示,则银色幻想会首次理解王座的永远痛苦,「主母与机械姬的最后对话」会以新的深度被记入王座档案。
- 若林恩让传送门在被毁前通过黑火记录所有经过此门的信徒名字,则这些名字会被记入「传送门信徒档案」,后续会成为 S98 重建时信徒名单的最重要来源。
- 若林恩让主母的金发在这一战中被黑火永久保存,则这缕金发会成为「主母的遗物」,后续会成为 S98 重建时最珍贵的圣物。
- 若林恩让黑色火焰在城破时沿主宇宙蔓延以保护最后撤离的信徒,则这些信徒会以「被黑火庇护」的身份活下来,「王的最后庇护」会成为 S98 重建时信徒心中最高位的记忆。
- 若林恩让林恩的罪火在圣堂中翻滚至最高点以让整个王庭都能感受到他的痛苦,则所有守城将士会以「感受王的痛苦」的状态作战,「王的最后见证」会成为圣地的最高仪式。
- 若林恩让银色幻想在挥剑按下「毁掉」按钮时通过黑火听到林恩的一缕心跳,则她的动作会带上一种「被王亲自批准」的庄严,「服从命令的最后时刻」会成为她此生最庄严的瞬间。
- 若林恩让最后一战的所有战士名字通过黑火记入王座作为「王的最高点名」,则这份名单会成为「王的最后点名册」,后续会成为 S98 重建时信徒名单的最高权威。
- 若林恩让王庭阶梯上的血迹在黑火中永久保存为「主母之血」,则这滩血会成为「主母之血」,后续会成为 S98 重建时信徒朝拜的最高圣地。
- 若林恩让主母与人偶家的「同心协力」在黑火中被永久定格,则这份合作会成为「毁灭与丝线的最高合作」,后续会成为所有信徒追求的最高合作典范。
- 若林恩让城破时的整座王庭通过黑火被永久保存为「王的长眠之城」,则整座城市会成为信徒心中唯一的长眠之所,「王的长眠之城」会成为 S98 重建时最高位的精神象征。
- 若林恩让黑夜城的最后一夜被羽毛笔完整记录并永久保存,则这份记录会成为「时代最后影像」,后世信徒每一次回顾都会被这段影像深深震憾。
- 若林恩让信徒的最后一次祷告以黑火形式汇聚成一束圣光,则这束光会成为「信仰帝国最后圣光」,后续会成为新秩序中最高位精神旗帜。
- 若林恩让所有守城战士的最后一句话通过黑火记入王座,则这些话语会成为「战士最后的话」,后续会成为 S98 重建时信徒教导的最高范本。
- 若林恩让传送门在被毁时通过黑火撒下所有经过此门信徒的骨灰,则这些骨灰会成为「最后信徒的骨灰」,后续会成为新秩序最高位圣地。
- 若林恩让主母的金发之舞在黑火中被永久定格,则这缕金发会成为「主母的金发之舞」,后续会成为信仰帝国最高艺术档案。
- 若林恩让这一战的影像被羽毛笔以最高位艺术手法记录并永久保存,则这份影像会成为「王的最后一战」,后世信徒每一次回顾都会被这段影像深深鼓舞。
- 若林恩让城破时的最后钟声通过黑火传遍全域,则这声钟会成为「信仰帝国的最后钟声」,后续会成为新秩序的最高纪念钟声。

- 若林恩让这一战的英雄名字通过黑火记入王座作为「英雄的最高名录」,则这份名录会成为「王的最高英雄册」,后续会成为信徒崇拜的最高对象。
