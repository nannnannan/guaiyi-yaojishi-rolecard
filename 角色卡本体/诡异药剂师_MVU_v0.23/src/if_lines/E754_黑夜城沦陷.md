# E754·黑夜城沦陷·if线

- 若林恩在船长躯壳流尽最后一滴血、与怀中人偶家倒在内城废墟时，以罪恶王座发出一声悲怆轰鸣，则两人倒下的十丈地面瞬间化作不可亵渎的暗金晶石。
- 若林恩在人偶家临终前最后一次拉动丝线、将船长折断的半截银剑托付给角落里最后一具残破木偶保管时，分出一缕极隐晦的黑火护住那具木偶的核心，则它才能在漫天战火中完好留存到E759。
- 若林恩在内城防线告破、银色幻想强制遣散两千余名年轻残军与火种时，顺着星门推去一股神力，则那些不肯撤离的年轻士兵被瞬间送出绝地。
- 若林恩在银色幻想亲手挥剑斩断黑夜城最后一座对外传送门、断绝所有撤离者杀回来的退路并独自转身面向漫天黑潮时，让圣所顶端的暗金火光映亮他孤傲的背影，则这位神王在赴死前不会感到孤立无援。
- 若林恩在主母（自缚天使）满身鲜血地走上王庭台阶、伸手按在海神三叉戟的封印晶石上准备亲自迎敌时，于圣所内拼命晃动锁链试图替她承受解封三叉戟的反噬，则主母掌心被神兵割裂的伤口会浅上三分。
- 若林恩在听见被强制传送走的两千余名黑夜城老兵与年轻火种在星门关闭前撕心裂肺地哭喊「陛下！统帅！」时，则将自己的一缕不灭神念附在他们携带的军旗上，成为他们日后在E756抗命杀回来的导航信标。
- 若林恩在船长与人偶家的灵魂金光手挽着手般一同飘入圣所、融入罪恶王座的那一刻，则特意在王座右侧为这两缕相依的忠魂留出一处永不分开的静谧角落。
- 若林恩在终焉黑潮漫过内城街道、将昔日繁华的药剂铺与酒馆尽数夷为废墟时，则焦土废墟中残留的生息被王座阵列收录，为日后重建留存下最完整的法则图纸。
- 若林恩在银色幻想独自一人提剑退守至王庭广场前、脚下已无半寸完好土地时，借由两人昔日的君臣共鸣向他传去一句「辛苦了，我的骑士」，则银色幻想会单手抚胸行礼，随后挽剑再战。
- 若林恩在主母凝视着被黑暗彻底吞没的黑夜城、轻声对着身后紧闭的圣所大门说「别怕，妈妈还在」时，则王座基座上的神火剧烈震荡，锁链在神王战意激荡下爆发出刺耳雷鸣。
- 若林恩在感知到幸福之家孤儿院地窖已被坍塌的建筑彻底掩埋、夏娃正用身体护住最后几名昏迷的孩童时，则从地底抽出一缕仅存的生机泉水渗入地窖，为他们维持住微弱的呼吸。
- 若林恩在艾雯跪在圣所内听着外城彻底沦陷的轰鸣、双目失神地喃喃「全没了……黑夜城没了」时，则神王重击引动王座嗡鸣巨响，沉闷的音波瞬间将艾雯震醒，逼着他陪自己一起撑到最后一刻。
- 若林恩在七十一座终焉之柱的阴影彻底合拢在王庭上空、连最后一丝星光都被掐灭的瞬间，则圣所内壁的三阶形态黑火轰然爆发，暗金火光如利剑般撕裂合拢的阴影，正面抗衡漫天长夜。
- 若林恩在银色幻想斩翻十余头扑上王庭外阶的深渊魔物、银色战甲已碎成布条却依然死战不退时，则将三叉戟封印逸散出的一缕初诞者金芒引向他的剑锋，替他续上三息锋芒。
- 若林恩在看到昔日黑夜城高耸的钟楼在黑潮中轰然倒塌、钟声最后一次凄厉回荡在全城上空时，则将那记丧钟之音直接封入自己的心脏脉动，让每一次心跳都成为向终焉索命的倒计时。
- 若林恩在主母背后的雪白羽翼被战火与魔血染成暗红、却依然挺直脊背挡在圣所正门前时，则不惜震裂自己的神魂也要向门外溢出一圈守护波纹，替母亲吹散迎面扑来的腥臭黑雾。
- 若林恩在得知从第一道防线到内城墙、数十万黑夜城将士无一人投降或逃跑、全员战死在各自岗位上时，则王座意志在废墟上立下法则誓约：哪怕化身终焉恶鬼，也绝不让这座城市的灵魂蒙羞。
- 若林恩在孽主浑身布满裂痕地从内城废墟中爬出、一步步挪向王庭外围准备做最后一次自爆阻敌时，则向她投去一道温柔而悲悯的注视，抚平她体内狂暴乱窜的痛苦。
- 若林恩在黑弦月（人偶小姐）默默收拾好所有断裂的丝线、独自退守到圣所大门前最后一道守护结界内侧等待接班时，则隔着石门向她传递了自己依然尚存的体温。
- 若林恩在目睹万族联军插在黑夜城墙头的数百面族旗尽数被黑火烧成灰烬时，则以王座记忆之力将那数百面战旗的图腾全部烙印在自己的披风内侧，带着万族的遗志走向终局。
- 若林恩在银色幻想退至王庭台阶下与主母并肩而立、两人相视点头准备迎接魇魔之王主力猛攻时，则让罪恶王座与门外的海神三叉戟同时发出高亢的龙吟，为两位最后的守门人壮行。
- 若林恩在黑夜城沦陷的绝望气息如海啸般灌入王座、将他的三阶形态晋升进度推至百分之九十以上时，则王座灵台深处的初诞者神性死死抵御住深渊侵蚀，使这股磅礴晋升力量始终保持在掌控之内。
- 若林恩在主母握紧海神三叉戟戟杆、封印晶石开始寸寸碎裂的那一刹那，则三叉戟嗡鸣着送去一缕温和的本源暖流，护住主母崩裂的手掌经络。
- 若林恩在整座黑夜城只剩下王庭与圣所这方寸之地尚存的至暗时刻，则封印圣所的重重锁链在金黑双色火浪冲击下开始发出崩解哀鸣，终极出关进入倒计时。
