# E408·血肉支配者陨落·if线

- 若林恩在诅咒加深第一波就先命令左左自愿断一臂把断口血肉反哺泰坦骨躯，则泰坦臂膀上嵌着一缕银紫色的骨肉杂纹，他从此挥斧多一道「人形小杂音」，左左事后咬他指节要赔一次深夜陪睡。
- 若林恩把外储原初之力分成两份、一份送入夏娃一线一份分给巨像天使艾雯，则巫神那一路无人庇护、在诅咒反噬中险撑不住，但夏娃后续的「同源倒戈」被按住、她主动为林恩挡下一根旧神残骨。
- 若林恩主动用克苏鲁之眼扫向支配者躯体的「旧神拼接区」并立刻以原初之刃切除，则他的血肉重组速度被短暂锁死、第一次焚烧节奏被推迟十秒，给泰坦获得足够窗口抢进近战。
- 若林恩刻意暴露渡鸦残魂给支配者看见后又收起、反复玩「现身即收」的猫鼠，则支配者整场战斗的视锥盯死残魂、无视泰坦攻势，事后泰坦在战斧背面刻下一行「借假爹引假爹」。
- 若林恩在诅咒加深降落瞬间反其道而行、让外储原初之力只压在自缚天使和艾雯身上、留给泰坦自身吞抗，则泰坦承受整段加深而不死、骨躯上的霉斑扩展到全身三成、但「泰坦被净化」一说从此被锁死。
- 若林恩召唤死亡之主从涟漪中探出手臂、请求把支配者残魂暂存进他的潮湿骷髅体内，则康斯坦丁当场吞下残魂、湮灭度下降半档，E409 里他见到尸体的需求被一并冻结，转而接受罗盘条件。
- 若林恩主动与艾雯声明「你统筹巨像天使，我去试战术试错」，则他孤身面对支配者第一道扑杀、被以M气息恰好锁住内脏，事后他疲劳值升至上限、艾雯会主动给他一夜「爵士特批」的床头打盹权。
- 若林恩提前引爆支配者体内一丝他自己埋入的人形寄生虫、以污染攻污染，则支配者诅咒加深立刻白热化、躯干连环爆裂三段，他临终喊出的「父」字更淡更哀，残躯里不再可复原值班的拼接四肢。
- 若林恩在战后把支配者残躯的头颅用魂砂定格当谈判筹码展示给死亡之主，则他不需完整尸体、仅凭这颗头颅支付 E409 报酬，康斯坦丁对这具头颅的眼神如见初恋。
- 若林恩用拟化拾一片支配者的「父爱哭容」肌肉纤维回头凝在自己胸膛，则他在随后的数十日中只要听到旧神之歌就出现隐约胸腔撕裂声，但渡鸦残魂会以一根细指温柔贴合那片纤维抚慰。
- 若林恩让喵喵以「夜医巡检官」身份在战后亲自登记支配者遗尸，则她顺手偷走一枚口中病变暗核作纪念，暗核入胃很快活化、从此她咳嗽时多一缕低回的男音。
- 若林恩选择不亮渡鸦残魂、只以咒瞳连扫支配者胸口病根，则支配者会以更强姿态重新认识林恩的财力眼界，战后他不死、被艾雯一道灵能锁按入黑堡，E410 起成为黑夜城的半驯囚徒。
- 若林恩让小丑现场直播向万机之神（电信号直连、声音全程静音），则小丑的狂信被315博士冷处理，失控度降半档，但他对林恩心里多一层「主子让我伸出手来的陌生恩赐」的情愫。
- 若林恩主动要求人偶家挤进尸体交付现场与死亡之主并肩，则人偶家第一次正面见到死亡之主的模样、被骷髅眼中蓝焰烧伤灵魂一小块，事后她在 E409 会成为林恩的陪同顾问、不再主战。
- 若林恩让左左以人形替换泰坦骨躯位置正面吸收一次自毁冲波，则泰坦的骨躯免于受损、林恩因此维护前线的「绝佳英雄姿态」，左左会在事后从耳朵尾端扯下两片银白鳞片给他当作礼物象征。
- 若林恩在整个战斗中始终不开咒瞳、只靠面板特征和身形枪位移判断支配者短板，则他被315博士称作「黑靶手之王」，但咒瞳对此失能进行抗议——E410 起他的咒瞳初级增益永久减一档。
- 若林恩在战斗中顺手把支配者的「父爱哭容」嗓音用拟化录成指环戴在小指上，则那枚指环会在他入睡时反复播放这声音，左左整夜在他耳边低语要求把这玩意儿丢进焚尸炉。
- 若林恩主动上呈渡鸦残魂让万机之神过目，则残魂被博士锁进试验台二十四小时，315 把它当成新式标本采样，事后东京方向即刻派来一艘黑银邮轮抵港接走样本。
- 若林恩主动上呈支配者头颅、但留躯体让泰坦、艾雯、巫神各自取走一部分，则全员在场都进账一件「血肉支配者关键战利品」，战后艾雯把这放进奖杯柜当日志脚注。
- 若林恩在支配者最后一刻派小丑临场提醒「他父亲在六千年前的画像中已为他写下最深的情书」，则小丑的那声咳嗽让残躯慢死半秒，给泰坦喘了一口气，也换来了支配者眼中残存的一丝人性眷恋。
- 若林恩在整个事件结算中让面板主动拆分为「击杀」「净化」「君父断绝」三栏，则他的等级提升仅锁定在「击杀」栏、其他两栏挂起、后续 E409 里他的角色界面因此多了三行新增记录。
- 若林恩在支配者倒地后自愿不补刀、转身以血肉灾变同时朝所有人拍了一张「全家福」绘影，则这张绘影被自动存放在黑堡的虚拟档案里，泰坦、艾雯、喵喵都各自拿来做过手机壁纸。
- 若林恩在支配者倒地后主动先检查是否存在未灭残活、咒瞳连扫三秒，则他发现两段神经脉络仍在跪地蠕动——他立刻用原初之力将其彻底焚灭，事后康斯坦丁谈起的时候表示教主残留未死。
