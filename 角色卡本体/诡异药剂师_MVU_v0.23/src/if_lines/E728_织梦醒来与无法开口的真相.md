# E728·织梦醒来与无法开口的真相·if线

- 若林恩在织梦苏醒瞬间立刻把自己的手腕划开喂她一滴血，则她的腐蚀扩散能被暂缓一刻，但那滴血中的初诞者之力会在她体内引发新一轮异变。
- 若林恩没有以三叉戟压制污染、而是先用罪火尝试灼烧腐蚀源，则腐蚀会以更猛烈的形态反扑回来，他需要立刻退开三里才不至于被波及。
- 若林恩在织梦断续说出「信仰、灵魂与因果共同成为燃料」时立刻追问她细节，则她会因为这段记忆被强行唤起而加速裂解，他能多获得三句关键信息但也同时加速她的死亡。
- 若林恩选择沉默地听织梦说话、一句不插，则她能以最平稳的语速把那段残酷的真相讲完，但她讲完的那一刻会立刻闭上眼。
- 若林恩在她情绪失控时大声对她说「我会和你一起扛」，则她会第一次在精神层面放下一些防御，但那也意味着她未来的痛苦会更多分到他身上一份。
- 若林恩没有阻止她独自回到黑狱研究回声区，则她会带回那句「终焉之火与灵魂燃烧之间存在直接联系」的关键结论，但她也因此让污染进入本源最深处。
- 若林恩强行把她拽回来、不让她独自回黑狱，则她会因为被阻止而彻底崩溃，那段「你不是唯一承受者」的呐喊会以更伤人的方式撕开在两人之间。
- 若林恩在她拿起那件能刺穿本源的力量瞬间冲上去夺，则争夺中两人之一必受本源之伤，林恩如果选择自己挨这一下，他将永久失去一部分灵能根脉。
- 若林恩在最后的「无法开口」瞬间向前一步，则她会用最后一份清醒的力气把那段信息以心声形式传入他的梦里，但传完后她的本源立刻坍塌一半。
- 若林恩选择不阻止她、只远远看着她完成那个动作，则她的「切断污染」会以最完整最有效的形态进行，林恩的心里也将永远烙下这一幕。
- 若林恩在她颤抖时默默把手递过去让她握，则她会以最大的力气反握，那个力度会把林恩指骨压出三道红痕，但也让她多坚持了三秒说完最后一句话。
- 若林恩选择告诉银色幻想「织梦腐蚀了」请她以创造法则共担，则银色幻想会被震撼得神格立裂一次，但她能在崩溃中保住织梦身躯的一个核心片段不被完全污染。
- 若林恩独自以金色梦境覆盖织梦整片意识海，则可能让她在临终前陷入一场「回到了她最初的家」的美好幻觉，但林恩的梦境会因此留下一块永远的阴影。
- 若林恩没有给她说「我会去找办法救你」的希望，则她会以更坦然的姿态面对自己的结局，那一份坦然比任何挣扎都更刺骨。
- 若林恩选择不让艾维儿知道她腐蚀的真相，则王女将继续信任织梦的「沉睡说」，但将来真相揭开时，艾维儿对林恩的信任也会出现一道裂纹。
- 若林恩决定独自承受所有真相不告诉任何人，则他从此多了一副「什么都不能说」的枷锁，这副枷锁将一直戴到他自己也撑不住为止。
- 若林恩在她自伤前硬是打断她说「先去找左左，那边还有救」，则她会犹豫一秒、把刀放下，但那也意味着她会以一半的腐蚀状态继续往前走。
