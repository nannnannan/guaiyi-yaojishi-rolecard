# E728·织梦醒来与无法开口的真相·if线

- 若林恩在赶到奇异世界、看见织梦胸腔深可见骨的伤口黑气脉动时，下意识想动用罪火替她焚烧黑气，则他会在出手前一瞬猛然收手——因为他及时反应过来罪火会连同织梦的灵能本源一起吞噬，随即改用初诞者之力温和压制。
- 若林恩在织梦哭诉第二阶段「罪火」必须确保唯一性、挥拳结结实实打在他脸上求他吞掉自己时，非但没有躲闪反而顺势一把将她颤抖的身躯紧紧抱在怀里，则织梦会僵住片刻，那滴生平第一次流下的眼泪会直接滚落在他的肩头。
- 若林恩在织梦捧起他的脸颊、额头抵着他眉心流下第一滴泪并说「到死居然还有一个人在乎你，这已经是我能收到的这辈子最好的礼物了」时，低声回答「只要我还活着，就绝不会拿你当柴薪」，则织梦紧握的双拳会缓缓松开，眼底多出一丝连她自己都害怕的眷恋。
- 若林恩在拒绝吞噬织梦后，毫不犹豫地将镇守黑夜城的主宇宙核心三叉戟直接搬到这座奇异世界，则如浩日般璀璨的主宇宙本源会瞬间将织梦体内的无序侵蚀压制到最低，但也意味着黑夜城本部的防御在短期内必须完全依靠他自身。
- 若林恩在搬来三叉戟后天天像块傻木头一样抱刀蹲守在织梦闺房的地板上寸步不离，则织梦会在气笑之余抓着他的肩膀猛摇，房间里压抑了十余年的死寂气氛被彻底冲淡。
- 若林恩在织梦开玩笑说「你有这闲工夫不如出去帮我宰个魇魔回来」时，当真一言不发地起身要撕裂空间去深空蹲守，则织梦会吓得脸色一变、急忙一把拽住他的衣袖将他拉回来，嗔怒道「你还真去啊，傻子！」
- 若林恩在与织梦探讨第三阶段【黑狱】与先主往事、得知梦境之外现实法则路断且无数勇者皆化作飞灰时，平静地说「那我们就走出一条先主没走完的路」，则织梦会深深看他一眼，下定决心动用本源灵能为他溯本回源。
- 若林恩在被织梦笑着拖到房门边、一脚踹出房门下逐客令时没有立刻离开，而是隔着关上的房门轻声说一句「我就在门外守着你」，则门内正死死捂住胸口剧痛的织梦会咬紧嘴唇，强忍住不发出半点痛呼声。
- 若林恩在织梦布下重重隔绝结界溯源先主传承的几天里，察觉到门内灵能波动有一瞬间的剧烈崩裂与死寂，则他会担忧地叩响房门询问情况，却不知门内的织梦刚刚看清了「踏入第三阶段林恩必死」的终极真相。
- 若林恩在房门外每天徘徊，隔着门板兴奋地向织梦提出「既然现实世界腐蚀你，那我可以让你寄居在我的梦境当中」的新办法时，把耳朵贴在门上倾听，则他只能听到门内一片死寂，却不知道织梦正背靠着大门死死抱住双腿、将头埋进膝盖无声痛哭。
- 若林恩在门外守候时顺手用初诞者之力加固了整座屋子的外围阵法，则三叉戟的浩日光辉会更加柔和地笼罩闺房，但也让门内决心赴死的织梦更加心如刀割。
- 若林恩在第三天清晨依然准时坐在织梦房门外的台阶上擦拭夜魔刀、准备等她出来就带她去看黑夜城的新变化，则这份纯粹的期盼会成为他稍后推开门看见满地鲜血时最残忍的对比。
