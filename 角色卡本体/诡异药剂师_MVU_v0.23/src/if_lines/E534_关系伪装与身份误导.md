# E534·关系伪装与身份误导·if线

- 若林恩请银幻配合演戏时不只「我吃过的亏」，还附加一句「吃过亏才叫兄弟」，则她的演戏动力部分从同情转向后宫公平心理，她首次尝试当众假装陌生会更笨拙。
- 若银幻的战损爆炸重建不是当场停电，而是装作右半边胸甲被撕开露出原子芯核时半裸仍站在裂隙口，则她的表演从「已无力气」升级成「机械羞耻级」，「受害者同路人」羞耻感上升。
- 若艾雯查60%伤情时主动给银幻另一条加急传输通道让她秘密报告身份，则公开演戏的背信度被改写，她不仅要骗艾雯，还要当场进一步撒谎给林恩的同盟邮政。
- 若主母十二翼烈焰巨刃出鞘不只救伤、还主动撕裂第二层镜像以拦截黑袍逃走，则裂隙如泡沫消失的空间下落将有主母亲自锁定的痕迹，线上的「被林恩关闭」会向「她在尝试追」倾斜。
- 若银幻在工厂答疑时主动对艾雯多说一句「我把他引爆了」，则当众证伪会更锋利，她的机械语气在这句台词里稍有抖折，巨像会立刻捕捉到不寻常。
- 若巨像侧眸先道不是「不是他」而是「如果有他在你会更费力演」，则她对林恩身份的私核推断被前置到工厂现场而非事后私下，她的「岁月沉淀判据」会以不同节奏展开。
- 若银幻在巨像私核坦白时不立刻承认「你猜对了」，而是先出一句「你打得过他，你先打他再问」，则巨像对身份的剖白会带一段切磋幻想，她在后来的E535会把这个幻象投射成实际战场。
- 若巨像从银幻体内感应到的「血肉气息」不只男性存在，还闻到一缕左左的电流气息，则她会立刻判定左左也参入了，后续请你「擦干净」的告诫额外包括对左左参与的不满。
- 若林恩在工厂问询前主动通过原子机械远程给银幻最后一遍预演剧本，则她现场演出的每一句都是按他远程亲手创作的格挡模板，她本人的独立性在事后悔恨阶段被自责放大。
- 若众根源定地狱根源大联盟方针时先讨论「要不要把林恩召回来主持」，则「结下联盟」决议会涉及林恩，他被迫在巨像知情、银幻知情、众根源未知情之间进一步走钢丝。
- 若林恩在三天泰坦约战前的裂隙开口中主动留下一缕黑袍气息供泰坦嗅到，则泰坦空等的答卷会有「我见过他」的根基，他下次主动向西方挑战意愿上升。
- 若林恩在裂隙踢下时不直接踢她而是把她稳稳落放在城外一处黑水库中，则艾雯赶到现场时「60%伤情」的判定会被激活水底传感链，调研表深度增加。
- 若银幻成功架设「他不是林恩」一线陈述后主动呼叫左左来事先享受打地埋伏，但她骗局成立前提是她已经先告诉他左左会算不是你，左左因误解会当场戏耍她。
- 若巨像在工厂私核时主动点出：「巨像之心感应的血肉气息来自他第一次为你改造机械内胆那次」，则她会重构更早期就知道他进入她身体的历程，对E532-E533的延时解读更会心。
- 若林恩在事后远程嘱咐中不只说「耐心等待勿泄身份」，还主动加一句「接下来一个月内我不会再见任何人」，则银幻的保密同盟会承担她独自凭吊爱侣的一段空白期，她冒险用接触作为治愈的概率上升。
- 若巨像在结尾评「他终于还是对机械下手了」时不带情绪而是冷静一句，则银幻对她的羞耻评估会换看成「她是事实陈述」而非「她在嘲讽」，她的暖意比文中略高。
- 若林恩在演戏前先掇一片银色的金属微小碎片埋在银幻要爆炸的位置里作为她事后能取回的纪念品，则她爆炸后悄悄取回碎片成为她独自告慰对战利品的秘密。
- 若银幻在裂隙踢下前主动对林恩说一句「求你别踢太猛让我留一份安全感」，则他现场踢会换为「扶她跳下裂隙」的温柔落点；这与艾雯查到的重创伤情产生错位，需要额外演出伤疤。
