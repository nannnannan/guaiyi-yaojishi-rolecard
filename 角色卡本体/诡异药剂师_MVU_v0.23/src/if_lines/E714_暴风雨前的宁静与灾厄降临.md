# E714·暴风雨前的宁静与灾厄降临·if线

- 若林恩在人偶家被梦魇拖向扭曲深渊时，在虚无中吹了一缕截断的狂风（灵能风暴）冲入漆黑海底，则人偶家能抓住这一缕神迹般的援手，即使极度虚弱她也能逆转局势。
- 若林恩在灵能风暴中进一步投入了三叉戟，甚至这一对撞导致金色帷伏的崩溃，则救世行为的核心告别存在的因素，神界内部的新情绪升温。
- 若林恩在那「漫长的战争」中截断了一切与前线的通信，反而是一个致命的失误，因为这将阻断他向未来求救的机会。
- 若林恩在心灵之海震惊的画面中，见到高大恐惧的神像并向那「更高神界」发出求救，则神界内部第一个理解他的存在（继钻石之后）将迅速介入。
- 若林恩在十年战火中提前脱离（例如提前十年开始造神或离开战场），则他的存在会提前成为人类的记忆与希望，而非作为夜医的结束点。
- 若林恩在看到主母与母树针锋相对时，突发奇想以「项链」的谐音与象征意义来测试母树的忠诚并借此传递信息，则会破坏原定的最高权限层级。
- 若林恩在未来回溯中，第一次醒来并非到达天国之战遗址，而是以另一个身份在附近沉睡（例如在第二个门罗之前），则他的复苏影响会与神界人类的衔接更为紧密。
- 若林恩在持续十几年来从未主动干预梦魇的行动（哪怕只是精神引导），则神界内部的诸多怕须无法实际展开来执行历史证明。
- 若林恩在第四年年底收回了他那颗逆戟重生的神格（例如告别了他的一部分身份），则他会失去一定程度的自我保护，在面对未来的生死难题时会更加脆弱。
- 若林恩在缔造神界时决定不设置任何与「七二七」相关的时间之说道，而是以洗礼与禁咒来建立秩序与平衡，则后续的大灾难事件将失去一个明显的参照。
- 若林恩在十年战争结束后从未主动揭示身份背景或是白冥阶段的事宜，而是选择按常例退后一步，则他被神界部分遗老混淆为「黑马城的反叛者」。
- 若林恩在十年的时间里向四位狂犬（魇魔）的领袖提出过一次非战之盟（这原本是不被允许的），则双方可能会避免致命的冲突，但最终的对决仍将如期发生。
- 若林恩在十年的时间里向林恩的人类同胞（包括银色幻想与林蒙）发起过一次强制性的鉴别和信任测试，则最后结论会成为一大神界内部矛盾的导火索。
- 若林恩在持续十年的战争期间，在无意识中向四位魇魔发出了「我已经有巨像人化」的信号（无论是否故意），则四位魇魔可能会误判为「已然有第三方强大的存在」，改变对战术的选择。
