# E619·紫罗兰小队组建·if线

- 若林恩接受自缚天使的全军方案,则作战会议升级,六人小队取消,冬泉谷入境前提失效。
- 若林恩拒绝艾维儿的记忆坐标依赖,改派占卜师占卜紫罗兰方位,则艾维儿的向导权取消,「不容任何人染指故乡」的台词消失。
- 若林恩把星轨替换为另一位更强大的根源,则她的不安戏份转移,但艾雯的命运受影响更小。
- 若林恩决定让巨像也随行但限定其只能作为观察员,则她的战斗戏份被压缩,「血肉修炼」的成果展示减少。
- 若林恩把母树替换为她的近侍,则「母性泛滥」的场景会减少,但对纱奈儿的情感会更温柔。
- 若林恩选择让伊甸代替母树,则「自然女神」的幽默感减弱,但对冬泉谷的认知会更专业。
- 若林恩决定把船长也列入小队,则「黑夜城与军团的运营」会变成无人管理,后续远征风险更大。
- 若林恩让渡鸦作为向导而非艾维儿,则出行方式更隐秘,但紫罗兰的坐标准确性降低。
- 若林恩把深渊第七位面的空间中枢改为自行横渡,则折跃不适会减轻,但时间会更长。
- 若林恩拒绝告诉小队成员真相,则他们的动机变单一,「艾雯被带走」的痛苦不会被公开。
- 若林恩让血枢残魂也随队以保护巨像,则它会因「外来者」的身份在队伍中引发猜忌。
- 若林恩决定在出发前先举行一场家宴,则安積的士气会增加,但一月军令的紧迫感会更强。
- 若林恩把「紫罗兰世界」改名为「紫罗兰现实」,则在远征目标感更强,但对「现实」的质疑会更多。
- 若林恩让母树在队伍中专门负责娱乐,则气氛会更轻松,但「看起来很轻松」的队形会更危险。
- 若林恩把伊甸改为大君长女,则「不容任何人染指故乡」的台词会更刺耳,紫罗兰问题的敏感性更高。
- 若林恩让喵喵也随行,则她的嗅觉能更快锁定织梦的气息,但幼幼的形象会被削弱。
- 若林恩决定把艾维儿调教得更温和,则「战意表态」会更委婉,但紫罗兰的判断会更谨慎。
- 若林恩把艾雯的被带走转化为他的救赎,则小队的动机更悲壮,「三位一体」的意义更深。
- 若林恩拒绝展示任何紫罗兰世界的图像,则小队成员的期待值更高,但现实会更残酷。
- 若林恩让织梦提前得知远征计划,则她会反布陷阱,冬泉谷的定点突袭会更成功。
