# E23·异域同乡与爱丽丝初愈·if线

- 若林恩撞开厨房冷冻库门时节奏放缓、先以夜魔刀撬一道缝倾听内里动静再推门而入，则白逸在食材检索中提前暴露，缝合手术在无恶灵干扰下完成，但爱丽丝的现身被延迟至走廊尽头。
- 若林恩不用「奇变偶不变」对暗号而是直接以圣属性左轮持续压制，则白逸意识在恶灵剥离后仍短暂清醒，平行世界错位通过病史问诊逐条揭露，无异域的家乡成就弹出。
- 若林恩用血肉增生药剂直接灌注白逸胸腔而未先缝合内脏，则触手变异在心脏接驳处提前爆发，剁除位置从腰际移至心口，白逸存活但心肺功能永久减半。
- 若林恩接受爱丽丝「做我的家人」邀请并承诺永久停留古堡，则白逸被释放至走廊自行离去，林恩获得古堡内自由行动权，E24围猎对象转为外部入侵者而非林恩本人。
- 若林恩拒绝爱丽丝但先行击碎走廊两侧烛火制造黑暗，则爱丽丝幻象维持时间缩短，卡梅尔与女主人表层意识恢复窗口提前至白逸手术完成之前。
- 若林恩在冷冻库提前察觉墙壁上的复眼凝视并加快手术，则爱丽丝在白逸缝合完成前现身打断，治疗只进行到内脏装入而未启动恶灵剥离，白逸作为半傀儡状态被带离古堡。
- 若林恩把夜魔刀交给白逸自卫而自己徒手对抗恶灵，则白逸在林恩脑部微创手术期间被恶灵反向操控持刀袭击，触手剁除失败转为林恩后颈被划开，爱丽丝趁乱带走白逸。
- 若林恩用系统空间同时收纳白逸与缝合器械进行移动手术，则手术在古堡地窖完成，爱丽丝的「家人」邀请改为对林恩随身携带的「小房子」产生执念，E24触发地点转为血锯药剂店。
- 若林恩击碎白逸头颅中的病变瘤子后未注意到额叶残留恶灵碎片，则白逸在后续日常中逐渐出现第二人格，碎片在E24围猎高潮时苏醒并反控白逸作为内应。
- 若林恩用枸杞冰糖热茶灌醉白逸使其昏睡后再行手术，则白逸全程无痛但苏醒后产生「被大哥遗弃在黑暗中」的虚假记忆，对林恩的信任度出现隐性裂痕。
- 若林恩在触手变异发生后保留触手未剁除而是尝试驯化，则白逸获得可操控的触手义肢，但每日需承受恶灵低语，爱丽丝现身时触手自动迎合并成为她感知林恩位置的锚点。
- 若林恩向爱丽丝展示自己为白逸缝合的「家人式」关怀，则爱丽丝暂时放弃傀儡化执念，转而要求林恩为她寻找「会疼人的头颅」，E24围猎目标转为古堡内其他住客。
- 若林恩击破爱丽丝幻象后未立即追击而是先稳定白逸生命体征，则爱丽丝本体脱离地窖附身于古堡家具之上，E24围猎转为古堡物品活化袭击模式。
- 若林恩用神圣左轮同时压制白逸与突然现身的爱丽丝，则两股恶灵能量在圣光中对冲爆炸，古堡西侧走廊坍塌，林恩被迫背负白逸从地窖密道撤离，E24入口转移至地下墓穴。
- 若林恩对爱丽丝说出「我可以帮你找真正的家人」并指向白逸，则爱丽丝执念目标从林恩偏移至白逸，白逸被标记为「新哥哥」并在E24中被傀儡夫妇优先猎杀。
- 若林恩接受爱丽丝邀请但附加「白逸必须一起留下」条件，则爱丽丝同意并立即将白逸转化为完整傀儡，林恩目睹全过程且无法阻止，白逸人格被恶灵完全覆盖。
- 若林恩在冷冻库直接剜出白逸心脏进行体外缝合再装回，则白逸心脏在体外暴露期间被恶灵碎片污染，装回后形成定时咒印，E24围猎时心脏爆裂迫使林恩二次开胸。
