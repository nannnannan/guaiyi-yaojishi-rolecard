# E392·界门撤离与血肉飞升图谱·if线

- 若林恩在开启界门前主动以血灵石为六根源同伴各炼制一枚护身符，则护送过程中的力量损耗降低两成，但血灵石存量耗尽，后续探索必须依赖替代资源。
- 若林恩在猪头屠夫斩击到来前主动以棺板迎击而非格挡，则棺板承受冲击后出现一道裂痕，但成功反弹部分刀势，屠夫的动作出现半秒迟滞。
- 若林恩在撤离时拒绝使用空间结晶并选择直接硬抗，则界门在屠夫第二次斩击下出现裂纹，黑堡通过时有三名人偶被震落，伤亡首次出现。
- 若林恩在羽毛笔发出警告时主动以心声回应「相信我」，则她的笔在最后一刻偏转方向时微微一顿，拉拽动作出现 0.5 秒延迟，林恩的衣角被刀风削去一片。
- 若林恩在撤离成功后拒绝检视血肉飞升图谱并选择先安抚黑弦月，则图谱在他怀里持续发热，当晚自动展开并覆盖在他的脸上，抽血过程在睡梦中进行。
- 若林恩在撤离时让左左以触手缠绕他的手腕以确保同步通过界门，则左左在穿越瞬间被空间乱流撕去一小块皮肉，她的触手出现永久性缺口。
- 若林恩在撤离成功后立刻以咒瞳扫描巨像之脑，则他读到她意识深处对「渡鸦」的复杂情绪，包括一丝无法掩饰的敬畏，为 E393 的问询埋下额外伏笔。
- 若林恩在撤离时拒绝让艾雯参与并选择独自开启界门，则界门稳定性下降四成，穿越过程中黑堡底部被空间风暴削去一角，人偶家的领地意识首次出现裂痕。
- 若林恩在撤离成功后主动将棺板与空间结晶一并收入系统空间，则两者在收纳时产生共鸣，系统空间的容积被永久扩大 5%，但品质评级下降一级。
- 若林恩在撤离时让泰坦以本体力量强行撑开界门，则泰坦的触手因过度拉伸而断裂两根，他需要一周时间才能完全再生，战斗力暂时下降。
- 若林恩在撤离成功后拒绝接受任务奖励并选择将图谱转赠给左左，则左左试图阅读时图谱自动燃烧，她只保留了一页焦黑的残片，但残片上隐约可见「血气开发度」字样。
- 若林恩在撤离时主动以初诞者之力覆盖整座黑堡，则他的意识与堡内每一只人偶短暂连接，他同时体验到数十个不同视角的撤离过程，精神负荷逼近极限。
- 若林恩在撤离成功后拒绝向黑夜城居民解释黑堡的来历，则城内谣言四起，有人声称「良医被古堡吞噬」，林恩的公众形象首次出现负面标签。
- 若林恩在撤离时让自缚天使以锁链固定黑堡顶部，则锁链在穿越界门时被空间法则切断，自缚天使的束缚状态得到暂时缓解，但她的诅咒根源未被解除。
- 若林恩在撤离成功后主动以图谱分析左左的身体数据，则图谱显示她的细胞活性与血气开发度均为「未知」，且有一条注释「该样本不属于当前数据库」。
