# E541·心灵之海百年修炼·if线

- 若林恩让船长把时间比说明改为「一小时三百年」，则修炼窗口更激进但迷失风险同步放大，部分根源上船前退缩。
- 若林恩拒绝让船长先行更深而要求并排沉潜，则心灵之海分层探索节奏被改，百年后众人强度更趋一致但船长触底半步的窗口变窄。
- 若林恩在入海前让左左将一份「危险认知自测表」发给每个人，则迷失遣返率显著降低，但百年修行的时长被切碎。
- 若林恩主动保留对巨船的最低限度观察，则认知警报的后端多一双外援眼，月内无人被强制遣返。
- 若林恩让镜像罪孽城的废墟里多留几处补给点，则孽主被打入地下后仍能爬起再战，她的耻辱与斗志同向加深。
- 若林恩踩血萝时不用脚背而用刀柄轻敲，则羞辱度下降、喜剧度下降，但她后续对「战法」的执念更纯。
- 若林恩扯黑巾前先把孽主提溜到黑夜城门外公开身份，则「因材施教跟练」的私密性没了，孽主的撒谎退路被截断。
- 若林恩施放那一道劈开废墟的刀光时刻意收力，则万里鸿沟变为千里，孽主逃脱的逃生欲打折，她更早回头反抗。
- 若林恩在北方联盟结成当日先遣原子机械窃听战场发言，则后续空间切割能做到更精确的「首恶优先」投放。
- 若林恩改用诅咒法则而非空间法则拆解北方联盟，则数十位根源受到精神污染而非抛弃四方，恐慌的风格从「绝望」变为「心寒」。
- 若林恩让切割流放的落点偏向白昼海域，则被放逐的根源更容易重聚，联盟瓦解不彻底，求法中心化节奏放缓。
- 若林恩在切割风暴中当众念出参与联盟的名单，则求法的散兵与名门的分界线更清，巨像的「力量法则示范」号召力更集中。
- 若林恩让巨像第一次熔铸失败而非撑过反噬，则「法则之路可走」的标杆断裂，根源求法中心化延后十日。
- 若林恩在巨像示范之后主动宣布「明日换人」，则十二翼天使的光暗转化提前到次日，求法中心的舆论被双倍放大。
- 若林恩把示范由公开改为只对几位古老根源演示，则求法中心化的范围缩小，黑夜城不成为世界中心而是秘密圣地。
- 若林恩主动通知人偶家示范当天的时刻，则她会强行破静养出场想分一杯法则熔铸的灵感，黑堡出关日程提前。
- 若林恩让十二翼天使的光暗转化在深夜悄然发生，则示范缺乏视觉奇观，「第二位法则掌控者」名号诞生更慢。
- 若林恩在示范日布置银幻的原子机械环绕现场录像，则记录被传播到主宇宙的坠落者网络，求法中心化的名声越过地狱边界。
- 若林恩让示范日后巨像在黑堡门前再向人偶家演一次肉身承载，则人偶家前往心灵之海修行的执念被点燃。
- 若林恩施压让艾雯在入海时把「心灵之海深层不同步」的恐怖说得再重一些，则众根源更愿意在浅海适应两小时再下潜。
- 若林恩让船长在出发前秘密把一颗死亡法则碎片封入巨船船舱，则认知警报在测试失败时能触发一次性微复苏，遣返多一道兜底。
- 若林恩主动预想并替孽主准备一份「法则讲义傻瓜版」，则她在被强制跟练时起步门槛骤降，破防过程被缩短。
- 若林恩让左左当众嘲笑孽主「笨蛋」代替提溜后脖颈，则羞辱由肢体转向语言，血萝对林恩的敌意更内化为不甘。
