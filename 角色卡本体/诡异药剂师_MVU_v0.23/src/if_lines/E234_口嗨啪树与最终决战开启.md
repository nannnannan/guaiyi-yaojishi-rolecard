# E234·口嗨啪树与最终决战开启·if线

- 若林恩在对方招揽时接一句"你出价要诚意点，先交三根巨触抵利息"，则对面阴沉一秒就爆发出笑，"欲望母树可以给你"的反讽筹码换成新角色交易窗口，招揽程序重新走一轮。
- 若林恩口嗨时把腰子的描述换成"她就是这么贱，被我灾变出十几根尾巴还在喊要"，则对面被戳到的痛点更尖锐，怒气+50跳到+80，天空翻滚的血气提前炸开。

- 若林恩只讲到一半的"她是我一个人的树"就被对面轰击打断，则他没把"施肥浇水"的话题讲完，激荡的怨念反而少了一层羞辱，血肉支配者的怒火+50停在+30，剧情在他半话不答之间拉长。
- 若林恩用左左傀儡在远处故意补一句"她才不要和你做了呢"，则对面被"左手也插刀"的恶意叠加，怨恨值连环爆，但他没动咒瞳、反而被激怒到提前发拳，事件以变形（傀儡嘲讽引战）收束。
- 若林恩把对方"隔着大陆攒下来的容器献祭"当作自己做交易筹码直接答应入籍，则对面顿住、整段骗局本来就只是试探，事件以变形（让他瞬间没词）收束，赌骰节奏被推迟。
- 若林恩口嗨前先把弥赛亚拖到现场让他正面对上"徒弟当面叛逆"，则对面第一眼就看见她的动摇，双方的开场嘲讽路径重新洗牌。

- 若林恩在掷骰前先喊出"地下的更深处也许还能挖出利维坦之骨"，则对面刹那犹豫、给林恩留了再掷一轮的窗口，描述路径转入"他提出新知识"而非纯口嗨。
