# E614·外来者绝路·if线

- 若林恩在巨像第一次偷修时以「我在监测你」方式提醒,则她会把偷修改在更隐蔽的灵能风暴边缘,恶化速度未变但被发现时点推迟。
- 若林恩主动向左左承诺「不立左左之墓,改立三位一体之门」,则她的拔刀闹剧收束更快,但「谁都会死的」台词更重。
- 若林恩在巨像把「我没办法修行法则了是吗」捅破时立即回应「是的」,则她会在那一刻放开手不再凝聚,但心底会割开一道无声的缝。
- 若林恩在苍白耀阳下试验前让艾雯也旁观,则两人会在成千上万次失败的实验记录中达成共同悲鸣,「那是责任」台词更具共鸣。
- 若林恩把「我带你走另外一条路」换成「我陪你们死在这条路上」,则三人聚齐时的气氛更低,家规的语气会更沉重。
- 若林恩不摊开三位一体真相而是直接作遗址远征动员,则巨像与艾雯的动机只系「信林恩」一条,师徒起步的情感温度低一档。
- 若林恩决定招募织梦同行远征,则她会在听完证词后静静拒绝,「不,这场戏是你的」,紫罗兰之约的伏笔更早埋下。
- 若林恩在第七天允许巨像彻底失控一次把「如触刀刃」全部吞下,则她会化作一摊血雾由林恩亲手重组,家规提前从「不允许牺牲自己」变成「不允许折断她」。
- 若林恩让喵喵也参加远征筹备,则她会提议以猫族视角解读血枢残魂的记忆,「她也是血肉」一句提前多一层暗线。
- 若林恩在坦白家规前先自陈「我也可能走不下来」,则巨像与艾雯的意识会更早完成精神造血,「绝不允许牺牲自己」的承诺会更坚固。
- 若林恩把「不让你们牺牲自己」改成「不让你们被抹杀」,则家规的语义被推向更高位的死亡红线,后续纱奈儿事件中的裂缝会更明显。
- 若林恩在召集三人时另加一位母树追求者作护道配偶,则母树会心生不快,但远征中她会更认真,母性泛滥的场景被压缩一半。
- 若林恩直接让左左陪同进遗址,则她随行的安全问题会被母树当面提出,「三位一体」的家规会更早在左左身上落地。
- 若林恩决定先把创生殿殿主召来问遗事,则殿主的告白会让「念想……断了」这一刻更沉重,三文明的相遇必然链更早被点破。
- 若林恩把「超越初诞者之力」换成「超越终焉之主」,则全盟约的视角会被抬高到「外来者是不受那个存在管束」的大格,「那是责任」台词从家属之责变为救世之责。
- 若林恩在三人聚齐时先「考一考艾雯的判断」,则他会主动让艾雯复述那段传奇,他自己补漏,艾雯的责任感会更早从「法则之路」转向「三位一体之路」。
- 若林恩召唤渡鸦作为证物,则夜空会出现一片纯白,大君的「我已不相信死亡」台词在渡鸦长鸣中得到回声,「渡鸦新生史」更早铺垫。
- 若林恩选择牺牲自己亲手斩断巨像的最后一根血肉法则残脉,则她会当场崩溃,但绝对无法再有任何法则之念,「三位一体」的代价在林恩身上体现。
- 若林恩在巨像背对蜷起时只说「你受伤你负责」,则她不会当场还口,但下次凝聚法则会更猛,恶化速度变快。
- 若林恩把远征出发日定在军团大反攻之前,则一月军令与远征倒计时双压汇聚,「只有一个月」窗口期会更窄。
- 若林恩在血枢残魂面前掏出「织梦曾见你」一事求证,则血枢会当场确认,三外来者的相遇必然律再确凿,紫罗兰之约的阴影更深。
- 若林恩提出远征只需巨像一人,则艾雯会被留下,后续他在灵能风暴中的失控时点会拖到被遗忘为止,「外来者之兄弟」这一环成为悬置变量。
- 若林恩让渡鸦记录此次远征目标,则夜空会出现「外来者之怒」的图腾,为后续纱奈儿事件埋下更多幻象。
