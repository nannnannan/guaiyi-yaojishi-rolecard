# E15·求援信与小小赴约·if线

- 若林恩只写一封求援信（只给小小或只给血锯），则到场援军只有一方；缺位者一方按原著动机继续按自己节奏行动，事件以「至少一方就位」降级完成。
- 若林恩两封信都不写、改为亲自登门传话或托中间人带话，则失去信件作为物证与情报渠道，小小与血锯的反应分别按其性格重新评估信任度；信件笑话链与系统成就（快乐+10、超勇的自己）不触发。
- 若林恩借虚空折跃兽与腐地龟王之外的召唤物、或雇佣信使、或自己传送送信，则替换送达方式；只要两封信安然抵达对方手中，完成条件等价成立，但送达时机与两方家长反应可能不同步。
- 若林恩在送信前先以占卜/视界/卧底情报确认魔人协会压境规模，则把信件措辞改为更准确的求援；家长与血锯收到的信息可信度提升，旁观判断更冷静，傲娇反应弱化。
- 若林恩在小小抵达前主动出门迎接而非睡到被戳脸，则【超勇的自己】成就与起床枪击事件不触发；小小好感度起点提升幅度降低，由后续接待动作补齐。
- 若林恩接住小小戳脸的触手不开枪而是先开口，则没有弹壳创可贴的喜剧桥段；两人关系从正常客套开局，独角鬼王产生的「猛士钦佩度」是否触发以林恩后续是否做出超出常理的胆气行为判定。
- 若林恩在小小抵达时直接谈魔人协会威胁、把「外卖」点破，则小小理解战斗意图前置，但失去「以为是医生朋友请吃饭」的天然好感加成；战斗降临后小小是否主动保护林恩按已有信任度判定。
- 若林恩布置物理防线（陷阱、药剂、阵列）替代单纯的求援信，则械魔大军压境时先行触发防线剧情，小小的到场对遭遇战位置与烈度产生改写。
- 若林恩在求援对象中额外加入血衣女士、小小、血锯、爱丽丝等已建立关系的角色，则增加对应登场成本；多援军就位时事件后果是「援军超额」而非「医护超载」，需在偏离账本中追记资源消耗。
- 若林恩公开求援（在视界广场或游魂巷频道发帖），则游魂巷居民与敲钟人提前做好撤离准备，械魔军压境时非战斗人员伤亡下降，但小小登场时的「惊讶指数」与林恩的装逼效果都被打折。
- 若血锯在收信前已被林恩用其他方式联络告知平安，则人偶夫人戳破血书漏洞的喜剧桥段不会发生；血锯对林恩调皮的态度更早转化为「不出所料的嫌弃+放心」，立即返回游魂巷的紧迫度下降。
- 若血锯收信当下未被丝线束缚、直接冲出庭院，则可能在被外面血肉傀儡击伤后才返回游魂巷；他到场时自带伤势，不能立刻投入战斗，而林恩需为此就地提供急救。
- 若小小的礼物或饮食需求在信件中被林恩附加（如写明菜色），则她到场时主动期待「说好的大餐」，对械魔大军出现的态度从一开始就是「食材到了」；后续她对林恩的好感增长更偏向「赏味的医生」而非「救场的医生」。
- 若林恩在小小抵达前主动透露独角鬼王在跟踪，则小小会当场折返或「(?ω?)」地对独角鬼王做鬼脸；独角鬼王的钦佩度加成路径切断，但他可能改为对林恩「知道却不动声色」的另一层钦佩。
- 若林恩把小小藏在后院、对外界装作药店无人，则械魔军压境时会更彻底破坏店面；小小登场时的反转冲击更强，但店面损失与「留全尸」任务的紧张度同步上升。
