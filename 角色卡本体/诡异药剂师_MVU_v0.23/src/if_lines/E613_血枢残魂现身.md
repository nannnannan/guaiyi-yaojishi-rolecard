# E613·血枢残魂现身·if线

- 若林恩在启封血滴前先让左左短暂退出系统空间，则她的厌恶预警缺席，但后续她在超维链接外听血枢声音时会再加一层警惕。
- 若林恩用两滴以上的残魂血液完成血枢补全，则它说话的声音更冷、更圆，「那是我的本质」变成高压宣言，吞噬欲望更猛。
- 若林恩在交易里附加「此后永远不得吞噬血肉文明任何一员」的条款，则血枢会拒绝立下死誓，只阴冷地承诺「只要她不主动招惹，我便不侵蚀她」，其贪婪吞噬的本性依然暗藏心底。
- 若林恩不让血枢看巨像的画面而改让他感应，则血枢能更快锁定本质来源，同时认出左左身边的灵魂标记，认出「她也是我的血肉」。
- 若林恩敢在血枢激怒扑击瞬间亲手捏碎它的四肢，则它会尖叫着停止挣扎，告白从一开始更卑微，吞噬愿望被绷得更紧。
- 若林恩在精神领域外向巨像转达血枢的部分告白，则她当晚会多一刻沉默，后续在山河幻境中她会更早认出师生的共同传承。
- 若林恩决定不使用超维链接而直接以灵能渗透血滴，则血枢对他的抗拒会更大，交易条款留有更多漏洞，「重归自己世界」成谎言。
- 若林恩在血枢的证词中拈出「你是被刻意逼上绝路」一句，则它会第一次低下头，「那是一个我无法回忆的地方」。
- 若林恩在与血枢交易时把「将来若你助我而林恩败下，你自由」挂进口号，则血枢会在短暂权衡后冷笑着应下「绝无这种可能」，但最终依然捏着鼻子达成了交易。
- 若林恩决定不动用血滴而用初诞者神血替代，则补全失败，残魂瞬间破碎，排斥机理证词永久不可得，巨像与艾雯的绝路在沉默中拉长。
- 若林恩让左左在超维链接里「陪坐」，则她会在血枢看见巨像时专注打量血枢的反应，认出那层杀戮冲动并记在心中。
- 若林恩在血枢面前主动提及「三大外来者之首那位入梦者」的传闻，则血枢会瞬间陷入忌惮的沉默，对高维灵能者的畏惧溢于言表。
- 若林恩威胁要将血枢这滴残魂直接炼成警示全军的血咒样本，则它会彻底暴怒破防，在极度屈辱中吐露出更多关于古神时代血肉起源的秘辛。
- 若林恩为血枢留下一日的自由畅想时间再放它回封印，则它会列出八个关于自由的场景，每一个都建立在它无用的残忘之上，交易感觉更悲伤。
- 若林恩让艾雯也参加超维链接旁听，则艾雯会亲口问「我与它有何同源」，血枢会给出沧桑一句「你与三大外来者中最类似」。
- 若林恩没有直接用武力威逼血枢，而是以层层设套的盘问试探其底线，则血枢会全程保持最高警惕，不敢轻易流露出吞噬巨像的野心。
- 若林恩让血枢在巨像凝聚「如触刀刃」的瞬间超维观察，则它会在心底点出「她走一步便是尘之伤」，证词更精确但少了一份愤怒。
- 若林恩专门往血枢的精神领域里放入一枚万物希望符，则它会把自由幻想寄托在符上，吞噬冲动换来临时的平静。
- 若林恩提出以血枢一撮灰烬作为巨像的启蒙礼物，则血枢会气急败坏地怒骂他无耻，却又在他的威压下不得不屈服。
- 若林恩让血枢与「念想……断了」当场对话，则「断了」二字会在它残存的意识深处留下一道裂痕，后续山河幻境的师徒关系会带着这层伤可能真正生长。
