# E566·空岛前哨与大小姐归来·if线

- 若林恩开口要世界时主动改口为「把两座空岛推给我就可以」而非「随便塞一两个世界」，则边王算账的冷汗从「统治权让渡」直接跳到「现成空岛让人搬走」，谈成快一半。
- 若林恩在空岛推进巨大空间裂隙时主动让原子机械在四边同时把裂隙缝边伸出稳定锚点，则鲸头推进过程中裂隙边缘不抖，两座空岛入奇异世界时的损率比默认更低。
- 若林恩在左左缩袖害躁时主动朝她竖一下中指而非按原文镇压，则左左右手红瞳圆睁怒骂「你还敢笑我」，主人的讥讽在她心里挂了一笔「他到底在不在乎我」的不平账。
- 若林恩在开中央电脑决议前主动让三位一体机推算「留下电脑」与「带走电脑」双方案的边王心理代价，则他选留下那次向边王说明顺水人情时多了一份从容。
- 若林恩在搬空岛完毕就主动要边王引路去幽冥海源头而非等待战后重建防御，则「在幽冥海源头等候大小姐」的时点提前排整齐，后续艾维儿落鲸背的衔接空间被压缩。
- 若林恩在边王向他介绍幽冥海源头时主动询问「她从这里出没过几次」，则边王的口述带出了几次数百年前她现身过几次的细节，为「大小姐」形象多添一笔地理背景。
- 若林恩在恶鬼面具女子落鲸背时主动先起身踏前一步而非任由对方视线压迫，则那句「你好，闺女」更容易说出口，小丑拍额的动作几乎同步发生，艾维儿目光波动多一瞬。
- 若林恩在剑指肩头时主动让三位一体机锁死剑刃的微小振动数据并记录在面板，则那柄苍银剑刃的派系起源在他面板留痕，他可能后续借此追踪她的师承。
- 若林恩在「你不应该来到这里」出口前先用两指捏住剑尖，则她握剑的手微颤被他的力度牵引中断，那句劝告以更平静的方式出口，情绪温度略降。
- 若林恩在她握剑手微颤时主动伸出左手覆在她右手背上，则她那下意识缩手的反应让剑刃脱手落地，「铿锵」一声替换了原本的剑峙节奏，她凝视他目光多一瞬意外。
- 若林恩答「我知道我是谁」时主动补一句「我不是你父亲，但我带着他的一部分活过来」，则她握剑的手松了一线，但「母亲一直在利用你」的警告被推迟一拍才出口。
- 若林恩在她摘下恶鬼面具那瞬间主动闭眼转过身去，则她在摘面具失神坐下时没有发现他刻意回避的姿态，那句「你是画家的女儿」少了这一瞬眼神交汇的情感验证。
- 若林恩在她质问「你知道我母亲要对你做什么吗」时主动伸手按住她前臂轻轻摇头，则她伤恸「可这不值得」的话被她硬生生咽回一半，后半句化成她凝视他时微微泛红的眼眶。
- 若林恩在她给出警告后主动向她伸出左手而非右手，则左左红瞳圆睁「这手也给她？」的不满是压住声音发出的颤音，但艾维儿读懂了那只「会说话的左手」背后的讯息。
- 若林恩在艾维儿自下游归场落鲸背瞬间已经带领边王撤离现场只剩小队，则她的落点变化为「只剩她与他」，剑指如常但压迫感减小，「母亲一直在利用你」那段得以更私密地展开。
- 若林恩在行宫落座后主动示意左左先退下，则左左炸毛骂「别想支开我」的插科没了，行宫氛围从「镇压左手」与「她还小」的喜剧地面跳到了「继母与女儿」的正经庭上。
