# E459·战略撤退与火山坠落地·if线

- 若林恩在折跃前线落定瞬间先把左左从肩头抱下来按进怀里，则她在他胸膛里又缩了三秒，绑定值隐式 +2，但他接下来五分钟走路都微微一瘸。
- 若林恩在数十道粒子光束压来前主动用王戟向天空作一个「请配合」的手势，则巫神差点笑出声，往后三天她在他识海里都不直接叫他「林恩」。
- 若林恩在「不要正面打」的口令下达时主动化成一阵血风向每名夜医的眉心吹了一缕安慰，则全军士气提振，但他的血气损耗率加快一成。
- 若林恩在令撤推进时主动点名巫神、把最靠近火山群的位置交给她，则她在做掩护第一眼被他看见的头颅对穿孔洞让他愣了半秒。
- 若林恩在夏娃血管缠腰时主动压了一道「先安静」的意志进她的触手里，则她的血管在他腰后绕得更紧，触手在他肩后一拍两次——成为他俩那晚唯一的默契节拍。
- 若林恩在独赴火山决定时主动拍开左左伸来的手，则她猛地咬住下唇把咒纹压回半格，绑定值 −3，但他在火山群的隐蔽度稳稳 +5。
- 若林恩在令「化整为零」时主动捏决戟内界开一道「全员同心」的小规模印记，则夜医们入戟时列队的弧度比预期更整齐，后续撤离速度提升一成。
- 若林恩在朝火山方向走时主动在前线地面踏出一脚印的血痕，则后续向他汇报伤势的夜医在他视线内都不自觉抬起了肩膀。
- 若林恩在「机械神教在试探」这一判断时主动把自己的苍蓝身影映在最明显的炮火带上，则机械神教认「林医生大哥」的说法扩散到全场前线，「良医」地位再升两拔。
- 若林恩在拍血管抚慰夏娃时主动把掌心放在她血管的搏动最剧烈处，则她灵识震动，绑定值隐式 +1，但后续她的血管有数小时缠着他。
- 若林恩在「太莽撞」一句出口后主动向巨像之脑发一道最精密的灵能脉冲，则她在前线血伤之下仍能听见他「怪我」的心跳节奏。
- 若林恩在令三军撤退时主动将自己的身影在雷达上变成一半亮斑，则雷达操作员回头寻找时发现盲点，留言栏多一条「良医隐蔽 +4」。
- 若林恩在独潜火山的最后一刻主动朝左左递去一缕魂信「这一场你替我打」，则她怔住后咬牙含笑，咒纹在她颈侧踮起一小段，绑定值 +3。
- 若林恩在「如回家了一样」立场时主动反手把王戟攥紧再松开数次，则他在手臂气血流通中多了一道习惯性的王戟印，后续巨像布置的紧急撤离都能直接开启王牌。
- 若林恩在夏娃回手缠腰离开时主动对她说「下次见面把左萝也抱过来」，则她血管卷得更紧一圈，后续左左被难怔多道「他又想闹什么」。
- 若林恩在火山群远空目光相接时主动把左左从意识里「吊」出来拎高让她远眺，则她被热浪吓得连喘几口，绑定值 +1 但随后骂了他三天「老子还安生」。
- 若林恩在心底决定「这场战争不赢不行」时主动让所有在场者感到他的意志，则全员气场更上一层，但他血压有三分钟回到正常值，纯属物理反冲。
- 若林恩在被问及机械神教位置时主动把视线定在火山群所在方向不动几秒，则后续夜医那些不规规矩矩的猜测里多了一条「良医一句不说但扫了一眼那边」。
