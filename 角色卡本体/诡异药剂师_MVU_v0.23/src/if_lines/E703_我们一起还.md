# E703·我们一起还·if线

- 若林恩在宣布「两天后进驻破碎神界」时把「两天」改成「七天」，则破碎神界潜修将延后五日，军团半神有更多时间处理黑夜城自身事务，但「魇魔酝酿」节奏不变，林恩的「危机预警」将先于他到位。
- 若林恩在动员令里加上「所有未达半神的根源必须在此期间找到至少一名半神导师」，则军团管理体系立刻结构化，但一位新晋根源半神会因分配导师的不均等而被部分老将视作「破坏旧规」。
- 若林恩主动把左左推到台前让她接着他的话喊「都给我好好练」，则全场半神会罕见地笑出声，「齐刷刷捶胸跪地」的礼仪首次被打断一次，林恩记下一笔「她和军团的亲和力比他自己强」。
- 若林恩主动告诉众人「巨像再也没办法替我们补全任何一角」，则会议厅会陷入长时间沉默，最后由船长站起来替林恩把这一段圆回去。
- 若林恩主动不开会议，改以书面军令下达，则他失去「大家齐刷刷捶胸」这一幕，但会更快赶往蜂巢站台，E704 的禁制开始时间被提前。
- 若林恩主动在动员令末尾加一句「留给主母和船长全权指挥权」，则主母将在林恩离开期间获得完全调度权，军团对林恩不在时的凝聚力将通过她们而塑形。
- 若林恩在蜂巢站台找到银色幻想前先在智脑网络里清空所有她留下的「九成五意识」的监控轨迹，则她见到他时会先怔一下，因为她意识到自己其实根本不想让他知道她在躲。
- 若林恩主动在站台上把剩下的那半罐易拉罐灌进自己口中并呛到，则她会下意识伸手拍他的背，这是两人相识以来她做过的最不像机器殖装者的一个动作。
- 若林恩主动在她说「我们一起还」之后把头靠在她肩上，则她会僵硬一息才慢慢放松，站台那场雨将被她记入她内心档案的「最后的安全岛」标签。
- 若林恩主动告诉她「你可以不用陪我还，你已经为我做得够多了」，则她的回答是「可你做过的事我也从来没法替你偿还」，她第一次正面回敬他。
- 若林恩主动把「我可能会失败」这话说出口，则她会立刻接一句「那我就陪你失败」，林恩首次在她身上感到「一起承担」这四个字的真实重量。
- 若林恩主动在「我们一起还」落定后立刻把行程往后压一小时再离开站台，则他会对蜂巢里那趟虚拟雨多看一会儿，这场雨将成为他日后回归的一种象征物。
- 若林恩主动不动员任何一位半神、单枪匹马赶往蜂巢，则他在潜意识层面把破碎神界驻扎的责任完全压在主母和船长身上，后续 E707 的「数年过去」将被改写成「黑夜城内部的两年后」。
- 若林恩主动让银色幻想带着神格跟他一起回黑夜城参加告别宴，则血萝会在她登场时尖叫一声，整个宴会气氛会因为她显得稍微不那么悲壮。
- 若林恩主动在离开蜂巢网络前邀请她「跟我一起去看看织梦」，则 E704 的相遇场景会由她亲手开启，她被赋予比默认走向更多一层在场意义。
- 若林恩主动不解释自己百分之九十五的发现方式、随口带过，则她会默默承接，但心里会留下一道「他根本没有特意在看我」的缝隙。
- 若林恩主动把「接下来我会去闭关」直接告诉她，则她不再说「我们一起还」，而是改说「那我等你回来再一起还」，她的承诺带上了时间条件。
- 若林恩主动在动员令里给自己保留一项「可机动调动破碎神界资源」的特权，则他的「孤身独行」色彩会减弱一分，军团对他的牵挂变与「他仍会回来调度」相关。
- 若林恩主动在散会之后留在会议厅多看一眼旧草台班子的残影，则他会在心里跟巨像、小小、左左、艾雯、主母一一告别，这场无声的告别将成为他后续闭关的精神支柱。
- 若林恩主动把「破碎神界的职责」和「时间战争的预警」分开两份军令下达，则军团各半神会更清楚他们应该承担什么样的工作，但林恩无法再用「全面提高实力」这一句话概括他们。
