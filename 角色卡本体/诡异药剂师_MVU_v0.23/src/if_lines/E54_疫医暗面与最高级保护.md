# E54·疫医暗面与最高级保护·if线

- 若林恩上发条后没立刻通过视界上报，而是先对森一尸身独立验一遍血肉改造残留，则主母事后从艾雯处得知他已自行查验，林恩拿出第一手数据，"唯一遏制者"的筹码被自己加码一枚。
- 若林恩在艾雯悬浮尸身前主动开口"骨缝里有连续改造的旧痕"，则艾雯睁绿光的第一句从询问帮手改为"你也看出来了？"，尸检权威被林恩分担一半。
- 若黑弦月在林恩授意下保持完全隐身，则艾雯指尖绿光停在林恩身侧三秒后收回，"那个姑娘"的问句不出口，第七人偶的协同作战对主母保密。
- 若林恩让黑弦月显形但只施半礼即再度透明，则艾雯把她记录为"未公开编号的机械幽灵"，为日后人偶庄园交涉埋一道未落档的暗格。
- 若林恩在艾雯问"他们为何盯上你"时抢先自答"我能压制主母体内诅咒"，则艾雯意味深长的拍肩动作省掉，机密披露由林恩反客为主。
- 若林恩不追问、任由艾雯只讲完疫医渊源就收声，则"你是唯一遏制者"被艾雯咽下，林恩对自己在黑夜城的地位继续半盲，事件滑向变形收束。
- 若林恩反问"那主母当年为何不把他们连根拔净"，则艾雯首次在下属面前承认数百年清剿无能为力。
- 若林恩点破疫医与现行夜医理念在救人定义上的分歧，则艾雯把"恰恰相反"改口为"分歧比我们愿意承认的更深"，林恩在理念层被默认为可对话的同侪。
- 若林恩在酒店扭曲收缩前提出保留森一一枚义眼或一段脊柱做样本，则艾雯打响指的动作停顿半秒、默许切割，"独立验尸能力"在主母处备案。
- 若林恩拒绝艾雯携尸一并消散、要求将尸体押入公共停尸房，则现场收尸权易主，四级元勋的身后流程被林恩撬开一道口子。
- 若林恩在地下大厅门口请求同入、亲耳听复命，则"是时候该收网了"与"疫医是我们的暗面"都落入他耳中，暗面推测的首批听众由一人加至两人。
- 若林恩在石阶下止步不听，则推测只停在艾雯与倒吊天使之间，林恩事后只能凭保护配置反推，暗面疑云对他保持封闭。
- 若林恩立刻出声反对、举出外来邪神操纵的可能，则倒吊天使不驳斥任何一方，把"外来主脑"与"内部暗面"两线并行追查，事件以未定性的双轨推进。
- 若林恩顺势附和以森一堕落时间跨度佐证，则倒吊天使首次在石座上睁开第三只眼看了他一眼，把他从被保护对象重新归档为可参与早期研判者。
- 若林恩在艾雯迟疑时主动退后半步闭目示意"我不应听见"，则推测改为主母事后单独转述，且删去"我们的暗面"只留"内部渗透"，信息可见度被林恩自己关小。
- 若林恩向艾雯建议暗中保护只需远程警戒而不贴身尾随，则23号夜行小队将潜伏半径外推五十米，朋克酒店周边的暗哨切换为外围机动盯防。
- 若林恩询问艾雯药剂研发机构内部是否还有森一的同党，则艾雯留下一枚加密传讯符，允许林恩在发现可疑药剂流向时直接越级通报。
- 若林恩要求所有暗中护卫小队在非致命遇袭时不得暴露行踪，则三十一支小队全程隐入黑夜城阴影待命，直到他真正遭遇拔枪威胁时才会现身。
- 若林恩让黑弦月暗中记下艾雯空间跳跃与万花筒修复酒店的灵能波动，则第七人偶的战术数据库新增一条高阶夜医元勋特征记录。
- 若林恩拒绝一切暗中护卫配置、坚称自己与黑弦月足以自保，则最高级保护取消，事件滑向取消方向，艾雯需重新评估林恩的安保方案。
- 若林恩请求艾雯顺带关照血衣女士与小小的街区安全，则外围巡逻网顺势覆盖到药剂店所在街道，暗中保护范围被林恩主动拓宽。
- 若林恩在艾雯消散前追问森一身上血肉遁术的媒介来源，则艾雯透露酒店内死尸与鼠群早被提前种下血印，为防范同类渗透提供了一手判据。
- 若林恩要求凡涉遏制诅咒的研究优先知会他本人，则黑夜城药剂研发机构相关报告日后须抄送他一份，他在学术层面对疫医渗透拿到持续视野。
- 若林恩把森一遗留的血肉样本收进自己系统空间而非全部交由艾雯带走，则面对同类生化袭击他能拿出第一手对照样本，但这一私藏主母处没有备案。
- 若林恩向倒吊天使请愿收网时机由"掌握更多信息"改为"四十八小时内动手"，则主母摇头但补偿他旁听下一次地下大厅议事，林恩首次进入最高决策的外圈。
- 若林恩全程谨言慎行、只在艾雯拍肩时微微颔首致意，则这场酒店现场勘验在心照不宣的默契中收束，夜医高层对这位年轻良医的沉稳评价再抬一档。
