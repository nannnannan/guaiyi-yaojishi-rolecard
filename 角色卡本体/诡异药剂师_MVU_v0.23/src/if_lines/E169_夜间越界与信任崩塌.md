# E169·夜间越界与信任崩塌·if线

- 若林恩在挨完鼻血一拳后真的乖乖躺下不动，则事件以变形（中途停手）收束，安眠数值原封，但次日清晨左左会盯着他的睡脸小声嘀咕「居然真的老实了」，信任余温尚存。
- 若林恩狡辩「做春梦」时被左左拆穿——她贴着巨像之脑耳边说「姐姐，他在撒谎」，则灵能神罚当场引爆，事件以取消收束，他被当胸贯穿一个焦黑的洞。
- 若林恩第一下揉捏时用力不慎把巨像之脑的小背心撕破，则炸裂的布帛声把她彻底惊醒，灵能冲击波在三层被单下炸开，事件以取消（神罚）收束，驯服数值反向 -20。
- 若林恩拟化左左时忘了同步心跳频率、黑发左左的胸口没有一丝起伏，则巨像之脑半梦半醒中抓住的「王后小手」凉得像玉石，她猛地清醒、看见那具没有呼吸的傀儡，灵能神罚+惊叫双重结算。
- 若林恩引导她小手去握「滚烫奇异之物」时被她突然攥紧不松，则昂扬部位被握到血管胀痛、他又不能喊、又不能挣，只能躺着硬吃这一波「梦里的绞杀」，信誉崩塌但恶堕结算按默认 +25。
- 若林恩点烟时被烟灰烫到手指发出很轻的「嘶」声、恰好把左左吵醒一秒，则她迷迷糊糊睁眼看见一根红点悬在半空、看见姐姐光着上身贴在她怀里，「信任崩塌」第一次以目击证人视角被完整记录。
- 若林恩决定不满足于拟化左左、还顺手把巨像之脑也拟化出另一个版本反过来「贴贴」，则两只一模一样的巨像之脑躺在同一张床上彼此搂抱，画面被系统截图生成隐藏成就「双倍的王后」。
- 若林恩在结算数值时发现【驯服】+17【恶堕】+25 的暴涨远超他预期、下意识笑出声，则笑声把左左从拟化里唤醒半秒，她在半梦半醒间看到他脸上的表情——信任崩塌不一定要等清晨。
- 若林恩决定收手之前再多贪一秒、让黑发左左的指尖在巨像之脑锁骨上画一个爱心，则恶堕结算被系统额外标注「画心动作 +1」，但这个动作的痕迹在天亮时被浴巾镜前照见——真正的崩塌导火线。
- 若林恩在褪去小背心时手抖把整件撕成三片、布屑飘落在左左熟睡的脸颊上，则次日左左洗脸时在鼻尖拈起一缕姐姐贴身衣料的棉线，推理链条在她的起床气里启动。
- 若林恩把烟蒂直接戳在巨像之脑床柱子上留下焦黑印记，则清晨左左一眼看见那个印记，推理链从「焦痕 → 烟 → 前辈抽烟 → 他半夜没睡」完整成立，餐刀修罗场如期而至。
- 若林恩在最后横生念头、用咒瞳录下整个夜间过程反复回看，则他给自己留了一份永远删不掉的罪证，【恶堕】数值 +25 之外追加一条「自留证据」心理负担，【道德】 再 -3。
- 若林恩在她贴贴搂抱的瞬间动心，把剧本从「调教结算」改写成「真心相拥」、不再继续，则事件以变形（中途收手但已越界）收束，数值只结算一半，信任崩塌量级也减半。
- 若林恩操控左左的小手主动去牵巨像之脑的手十指相扣、不再做任何更进一步的引导，则这是他在整个夜间唯一无侵略性的动作，恶堕+25 变成 +12，但十指相扣留下的余地比任何数字都值钱。
- 若林恩决定在最得意的时候对着熟睡的两只轻声说「对不起」，则这句话不会被任何人听见、也不会写进系统日志，但这三个字在他自己心里第一次凿了一个洞，后续 E170 早晨他的眼神会不一样。
- 若林恩故意在结算完把那根点过的烟别在左左小拇指缝里、让她醒来时手里夹一根烟蒂，则「信任崩塌」的引爆瞬间被刻意设计成视觉喜剧，但这层恶趣味本身就是最大的越界。
- 若林恩在巨像之脑半梦半醒说出「嘤呜——」时喉头一紧、当场把她的小背心重新拉好并把左左还原、一整夜再不敢动，则事件以变形（心动中止）收束，数值结算定格在恶堕 +0、心理账簿却记一笔「他主动停下」，这一笔在 E170 之后的任何和解剧本里都重过所有成就。
- 若林恩选择在最兴奋的时候把整张床血肉化、把双生与自己裹进同一只血肉卵里睡成一体，则同床剧本跨越成「血肉巢」级别，灵能神罚来不及阻止，但清晨巨像之脑睁眼时会以为自己已经死了——信任崩塌以宗教体验形式完成。
