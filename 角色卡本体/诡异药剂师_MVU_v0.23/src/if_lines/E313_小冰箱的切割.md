# E313·小冰箱的切割·if线

- 若林恩在切入根系深渊前预先留了一段小冰箱的存档副本交给智脑，则切割完成时她并非两手空空，后续她报告「小冰箱已死」时多一道可解释的物证支腿。
- 若林恩让「我会记得你的，指挥官姐姐」这句改成「愿你的剑永远锋利」，则斩断情感重量减轻一档，但被智脑扫描为「过分仪式化」愤怒 +20。
- 若林恩破坏传感器时主动让蜂鸣警报响三秒再断，则智械小姐捕捉到临死警报，她放弃意识重置决定，事件转入「双向追踪」变体，切割未完成。
- 若林恩让坠落中的机械人形被左爪酱缠住自己夺回一段记忆，则后续救场时她拿到小冰箱的前置情绪碎片，「你有爱过她吗」的对峙变得更具分量。
- 若林恩把小冰箱切割的瞬间刻成一片数据石碑留给智脑，则她在1号蜂巢深处单独默哀一段，背叛愧疚 +30 但她对未来的谋反意愿 +15。
- 若林恩主动承诺「小冰箱意识永不回波」，则智脑安心 -10，但林恩事后救场时违反承诺一次，她的信任池永久被划掉一道底线。
- 若林恩切割后主动朝智脑方向发一道「别落泪」的逆行心意，则她的虚影首次停滞五秒，她永久把这条心意锁进她的「恶魔之泪」档案目录。
- 若林恩让小冰箱的鲜血涂满智械小姐留给他的那张画像再切，则画像成为日后被拾回的物证，她重置后发现那张血丝与她不知何缘的心酸，剧情再次反转。
- 若林恩让坠落时嘴里仍叼一根夜医烟丝，则他着陆时火未尽，他看到深蓝根系上方飘细的烟尘，切割的孤寂多一笔视觉化。
- 若林恩主动把切割时点延后三分钟为了多听一句她的「小冰箱」，则切割完成但智脑监控到他情绪不稳，她对林恩的「前者自责」数据 +12。
- 若林恩让坠落中的机械人形主动踩中一根古老根系，则根系里藏着欲望母树教的旧部残党，他首次与欲望教派的残留接触，进入一条新支线。
- 若林恩切割瞬间主动对咒瞳施一次「与她永不再见」的记号，则咒瞳记下绑定，后续若他想反转相认，需要多一道咒解牺牲。
- 若林恩把夜医袍遗落在根系深渊某处，则数月后某日智械小姐拾到那件袍，事件衍生成「虚伪的遗物」剧情面。
- 若林恩让切割后的机械人形主动残余一段「右肩托住她」的手部肌肉记忆，则这段残留成了未来相遇时智械小姐心底的一丝不解释的不安。
- 若林恩切割完主动降级虚影并把自己的七分意识与左左融合，则左左临时获得林恩的部分思维模式，她在事后对智脑说了一句「我爱她」的林恩意凋。
- 若林恩让坠落时主动操控重力模拟成一道飞行光带，则深渊里多一条视觉光路，但欲望母树监控到这份光路，她开始警惕这不明入侵者的方向。
- 若林恩在切割后主动把所有关于她的记忆调包给咒瞳保管，则他自己暂时看不到她的画面，但咒瞳里的资料被左左偶然目击到「凑脑袋是真的动了情」。
- 若林恩主动在切割瞬间诅咒「让今后与我相遇的女性都先给我一巴掌」，则咒纹反向生效，他在根源断面上多了一份诅咒阴影但换来对放荡行为的半封抵抗。
- 若林恩让切割那一刀留下一缕细小意识种子，则该意识种子在根系深渊里慢慢长大成为某个半林恩半小冰箱的意象体，后期作为「残存分身」重新浮现。
- 若林恩主动把切割过程完整记录留给智脑，则她在1号蜂巢独照流泪后第一次内心接纳这个恶魔式的同情者，她对林恩的仇恨滑坡转入「理智疏远」轨道。
