# E790·你到底是谁与唯一活下来的希望·if线

- 若林恩在骨鸦开口唤出「奈奈子」之前便敏锐察觉到未来画家灵魂的颤栗并伸手按住她的肩，则画家不至于当场失态崩解，但看向骨鸦的眼神依旧盛满跨越万古的悲恸。
- 若林恩在看清骨鸦体内翻涌的终焉灾厄时毫不犹豫地挥剑斩向它的咽喉，则骨鸦会在狞笑中任由剑锋刺入，借机引爆早已埋在十万渡鸦血脉中的同源死亡悖论。
- 若林恩在未来画家颤声问出「你是大君？」时主动挡在她与骨鸦之间并厉声喝问「你到底是谁」，则骨鸦会歪着惨白的头骨，用紫罗兰大君的温柔嗓音与黑袍人的冷酷语调同时回答他。
- 若林恩在未来画家燃烧自身神力死死缠住第七十二柱黑衣人影与骨鸦时，回头深深看她一眼并郑重承诺「我不会让你白白等下去」，则画家眼角的蓝色光粒会化作一抹决绝的微笑。
- 若林恩主动用咒瞳直视骨鸦眼眶中跳动的漆黑魂火三秒以读取其底牌，则他会看见紫罗兰大君最初放飞这只渡鸦时的画面，从而明白自己从一开始就是大君留给未来的最后种子。
- 若林恩试图将最后这只骨鸦也强行拉入【黄金梦境】镇压，则骨鸦体内潜藏的灾厄黑雾会瞬间污染梦境边缘，逼得林恩不得不当机立断将其震出体外。
- 若林恩在听到未来画家嘶吼「去未来！冲击时间之末！你是唯一能活下来的希望！」时没有丝毫迟疑，立刻拽起左左转身冲向未来通道，则他能将画家拼死争取到的每一分生机都化作冲刺的速度。
- 若林恩在未来通道入口被悖论风暴撕扯时主动以自身脊背护住怀里的左左，则他后背的骨骼会在风暴中寸寸龟裂，但左左搭建的时间桥得以完整贯通至时代终末。
- 若林恩主动将梦主印记化作一道金色锁链甩向身后追击的第七十二柱黑衣人影，则黑衣人影与未来画家角力的战场会被短暂封印一息，为他争取到跨过时间门槛的最后刹那。
- 若林恩把「你是唯一能活下来的希望」这句话当作沉甸甸的托付刻在心头，则他在冲入未来通道时眼神冷冽如铁，再无半点侥幸与退缩。
- 若林恩在转身离开前将一瓶自己亲手调配的幽魂巷治愈药剂抛向正在燃烧的未来画家，则画家会在漫天黑火中伸手接住药剂瓶，像握住旧日诊所的最后一丝温暖般将其贴在心口。
- 若林恩在撤离紫罗兰旧地的瞬间留下一缕黑火缠住画家掉落的一截蓝色画笔残片并将其卷回袖中，则这截画笔残片会在 E797 成为唤醒大君与奈奈子旧日羁绊的引子之一。
- 若林恩在跨入未来通道的最后一刻向着风雪与黑火交织的战场高喊一声「奈奈子，等我杀穿未来！」，则正在死战的未来画家会爆发出超越极限的灵能，将黑衣人影死死钉在原地数秒。
- 若林恩在骨鸦即将自爆引燃同源悖论的瞬间提前斩断【黄金梦境】与外界的灵能回路，则他虽能保住梦境核心不碎，但十万渡鸦死亡带来的因果反噬仍会如海啸般顺着时间线追尾而来。
- 若林恩主动把一段悖论锁链缠在自己左手腕上硬生生拽入未来通道，则他虽要一路忍受手腕被法则割裂的剧痛，却能借此摸清第七十二柱黑衣人影在时间之末的准确落点。
- 若林恩在冲刺途中与左左合力将两人的黑火融合成一双燃烧的巨翼，则他们突破时间壁障的速度会暴涨一倍，在悖论完全合拢前险之又险地撞开时代终末的大门。
- 若林恩在骨鸦狞笑着说出「你救不了任何人」时冷冷回敬一句「那我就去时间之末把你本尊的头拧下来」，则骨鸦眼中的黑火会剧烈跳动一下，第一次在这个未来渡鸦身上感受到真正的威胁。
- 若林恩放任部分同源悖论的冲击波擦过自身胸膛以换取借力飞跃，则他会在吐出一口黑血的同时借势掠过塌陷的时空断层，一步踏入时代终末的接轨点。
- 若林恩在未来通道内部一面飞驰一面将沿途破碎的渡鸦记忆碎片尽数吸入心口，则他在抵达 E791 时虽已遍体鳞伤，眼底燃烧的黑火却比以往任何时候都要炽烈。
- 若林恩主动用那句「如果我必须杀了你」回应骨鸦的挑衅并挥出斩断过去的一剑，则剑光会在紫罗兰旧地的天空中留下一道经久不散的裂痕，宣告过去篇的挣扎彻底迈向终局决战。
