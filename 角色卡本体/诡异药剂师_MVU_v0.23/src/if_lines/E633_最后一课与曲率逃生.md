# E633·最后一课与曲率逃生·if线
- 若林恩悬浮远望时不发问，只静静凝视色彩洪流，则苍蓝身影的授课仍以无情绪的宣告形式落下，「最后一课不因他的沉默而取消」，但授课语调多一线「已知他不哭」的从容。
- 若林恩主动朝色彩聚成的巨手跪地恳求，则巨手在他眼前松开又聚回，苍蓝声音「你已经走得太远跪地了」一句被混入授课，服从关系首次出现在他对画家的层面。
- 若林恩主动在混乱色彩中挣扎出声说「放开我，我还有事要做」，则苍蓝声音毫无波动答「这就是你要学的乖」，他的挣扎被以更长的句式压制进沉默。
- 若林恩主动对画家大喊「我杀了你母亲」，则苍蓝身影眼睫不动，色彩洪流无波，他第一次确认画家已经远超他能激怒的任何存在。
- 若林恩主动朝苍蓝身影问「你爱过她吗」，则她不答但色彩洪流如呼吸般起伏一波，「爱」对她而言已是听者自行定义的姿态。
- 若林恩主动朝苍蓝身影递出三叉戟当礼物，则她不接，但戟在他手里变重一分，「她让戟更沉」的事实被记录。
- 若林恩在被放逐煽飞瞬间主动喊出「纱奈儿还好吗」，则色彩洪流毫无回应，但纱奈儿在遥远床上的睫毛极轻地颤了一下。
- 若林恩施放全部分身朝苍蓝身影冲去，则分身立刻消失，他再度失去所有分身但无法换回任何答案。
- 若林恩在曲率漂流中主动想象「做个普通人也好」的画面延长一分钟，则满腔怒意的呐喊晚一秒出现，反攻决意被他自己掩埋多一层刻骨铭心。
- 若林恩在走马灯中主动让喵喵、左左、母树、巨像、伊甸、血枢的影子一闪而过，则他苏醒时对那些人的捆绑关系 +1，但他失去对某个重要片段的记忆。
- 若林恩在陨石苏醒后主动先帮织梦疗伤，则她意外拒绝，「我可以自己养」的语气混上一线不易察觉的感谢。
- 若林恩主动对织梦道歉「我害你被盯上了」，则她怔住不知该说什么，后续服从姿势里她第一次给予他道歉。
- 若林恩主动跟织梦讨论「你们入梦者需要神格吗」，则她意外答「我们需要更多的渡鸦，你还需要我们」，两人互补的未来被短暂明示。
- 若林恩主动朝苍蓝身影投掷一根花藤作为「礼物」，则花藤在色彩洪流中燃尽，但燃尽前化作「婚纱」的轮廓一秒，织梦在旁凝视。
- 若林恩施放白烬朝苍蓝身影轰一击，则白烬被吸收消失，她无任何反应，「你还不够格」的水平被她视为理所当然。
- 若林恩主动躲进系统商城并认证至高身份，则系统返回权限不足，入梦者的位格远超他已知。
- 若林恩施放血肉灾变在陨石周边画出壁画缅怀艾维儿，则织梦看到那幅壁画后选择安静地收起。
- 若林恩主动朝遥远天堂世界发出心声「我会为你报仇」，则天堂世界传来一声轻微但清晰的「对不起」。
- 若林恩用心声朝织梦求教「我可以信你吗」，则她怔住长久不答，「信任」对她的含义从此有了重写。
- 若林恩主动问织梦「她（画家）是否恨你」，则她回答「她不恨我,她只恨终焉」，「画家 VS.终焉」的纵深首次被她点明。
- 若林恩主动告诉织梦他想立刻折返去看那条裂隙，则她拒绝，「再看一眼你就会永远留在那里」被她头一次道出。
- 若林恩起身时主动默念一句「艾维儿，走好」，则远方混乱色彩洪流如朝大海送别般起伏一圈再平伏，「她听见了」这一事实被他记住。
- 若林恩主动把自己对画家的认知写成「我不是艾维儿，我是林恩，但我爱她」，则他在宣战时将在某段语音中无意间说出口。
- 若林恩主动让织梦为他切一道灵能碎片保命，则她大意外并拒绝，她的本质缺口已经不能再填。
- 若林恩主动在曲率漂流中假寐两分钟，则满腔怒意的呐喊由他自己先引发，反攻决意更清晰。
