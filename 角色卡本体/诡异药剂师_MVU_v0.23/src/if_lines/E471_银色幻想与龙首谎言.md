# E471·银色幻想与龙首谎言·if线

- 若林恩在协议余波中不伸手戳而是后退一步先道歉，则光宴那记要出未出的拳头会停在半空、缓缓收回，她对他的「压得住」评级首次盖过「油嘴」。
- 若林恩伸手戳向她的瞬间主动让协议一警报声放大到两人都能听见，则她会猛地僵在那里，她第一次被自己体内的协议条文化为一堵真实的墙撞了一次。
- 若林恩在转入下一区块时主动让光宴先行两丈探路，则她进入废弃巢都时被某段残破代码扫到、瞬间记下「这里有非神教活动痕迹」，智械小姐的存在被她先于林恩确认。
- 若林恩在听残破虚影劝银色幻想「靠他」时主动心声插一句「我建议你别」，则银色幻想体内的上传体会在那一瞬皱一下眉、把对方手抓得更紧，她后续的「不靠林恩」宣言会被提前成形。
- 若林恩选择不接近巢都底层夹隙，则银色幻想独自完成维护残破意识、不会与玩家侧产生任何视觉交汇，「等我」那句话只有她自己听见。
- 若林恩用灵能远程扫描银色幻想上传体，则会在扫到她胸口的瞬间被一道反扫描钉回，咒瞳视野在那一秒被她涂白，「她注意到了他」这一事实首次被登记。
- 若林恩在银色幻想吞第一台光宴终端时主动介入帮她拦截报警，则她会回头瞥他一眼、没说话，七神占比上升后她对林恩的「敌对」标签首次出现轻微动态修正。
- 若林恩在银色幻想吞七神个体后想欢呼或大笑，则她会在淡金烈焰光效未散时瞬间把手按在自己的粒子枪上，玩家侧任何过度反应都会触发她的警戒反射。
- 若林恩想趁警报中冲入区域17，则龙首的意志投影像会先于林恩抵达，他和龙首第一次「面对面」将在没有任何遮掩的情况下成立。
- 若林恩在「智械……」那两个字被她吐出时屏住呼吸记下这个音色，则他日后能用音色反向调出她的意识波动，光宴会立刻警惕他留这一手。
- 若林恩在龙首降临请银色幻想交权时主动释放一缕自己的灵能注入她体内作支持，则她会立刻排斥、把那缕灵能推出体外，但心里留下「他敢」这一笔。
- 若林恩在龙首抛出「是我创造了你」时私下心声对光宴说「他在撒谎」，则光宴会立刻承认，并把「父权争夺」这条龙首心理动机首次手动推给玩家。
- 若林恩在龙首威胁灭绝者／拥星者时主动检索这两位七神的当前坐标，则会拉到两条均显示「移动中」的回执，三兄弟集结17的成局被他提前两分钟看见。
- 若林恩主动用咒瞳扫龙首投影，则会触发一道来自源头的反扫描回压，咒瞳初期受创三个数据簇，他对「七神不能被随便看」这件事的体会上调。
- 若林恩在听光宴说「银色幻想也算我女儿的一半」时反问她「另一半是谁」，则她会沉默很久、没回答，某个她目前不愿谈的分支被她自己用沉默盖住。
- 若林恩选择趁乱冲击更高权限、不去17，则后续与银色幻想的会面将由她来定时机，玩家侧在情报和主权上都损失一截。
- 若林恩在去17的路上让左左用上古符文现场涂鸦一枚逆向信标，则该信标会在后续被银色幻想注意，她对「他身边有会写这种东西的人」这一事实留下底账。
- 若林恩在17警报涌入瞬间把光宴的双眼暂时罩住，则她不会在警报高峰被龙首投影的第一缕威压扫到，他对她的这次「捂眼」动作会被她默默记下。
