# E750·最后的信仰之城·if线

- 若林恩在万族残军没有选择逃亡、而是逆向跃迁汇聚至黑夜城这座「最后的信仰之城」时，从圣所内发出一声沉雄的王座共鸣，则那些跨越星海赶来赴死的万族战士会在跃出星门的瞬间热泪盈眶。
- 若林恩在听见万族联军在黑夜城外齐声高呼「我们是来保护神的！」那一刻，被锁在罪恶王座上的身躯猛然震颤，则圣所高塔顶端会冲起一道照亮半个星域的暗金火柱，回应这群凡人与弱族的逆行。
- 若林恩在幸福之家孤儿院内的孽主褪去平日伪装、化作高挑少女模样准备奔赴城墙战场时，透过地脉送去一缕温和的认可神念，则这位曾由罪孽诞生的少女会挺直脊背，以真正黑夜城守护者的姿态握紧武器。
- 若林恩在喵喵于孤儿院门前拉住夏娃的衣角、与孽主一同向夏娃郑重告别时，让一阵带着药草清香的微风拂过院落，则夏娃会强忍住眼泪，替两个即将走向死地的女孩整理好领口。
- 若林恩在万族残军用残破的战舰与血肉之躯在黑夜城外围筑起人形防线时，将自己王座底层的防御法则强行外放百里，则那些由普通凡人驾驶的护卫舰在与深渊魔物撞击时能多撑住两轮齐射。
- 若林恩在孽主踏上黑夜城外城墙、回头最后看了一眼幸福之家孤儿院的屋顶时，在心底默念她的名字，则孽主眼中的凶戾会彻底化作守护的慈悲，在城头杀出一条血路。
- 若林恩在喵喵轻巧地跃上城垛、用她最敏捷的身姿在废墟与火线间传递弹药与药剂时，分出一丝黑火余温护住她的脚踝，则她在漫天碎石与黑雨中穿梭时始终未受重伤。
- 若林恩在感知到曾经受黑夜城庇护的数百个附属种族哪怕只剩最后一艘飞船也毅然撞向终焉之柱时，在王座上闭目将他们的族徽一一记入神魂，则这些弱小种族的荣耀永不会在宇宙历史中湮灭。
- 若林恩在夏娃独自留守幸福之家孤儿院、将所有年幼孩童护在地下掩体并领唱安魂祈祷歌时，让掩体石壁上的荧光药草同时亮起，则孩子们会在柔和的光亮中忘记外面的地动山摇。
- 若林恩在银色幻想与船长看到万族援军逆流而至、高呼着保护神明冲入战团时，借由两位神王的佩剑发出一声清越的剑鸣，则全军士气瞬间攀至巅峰，硬生生将逼近城门的黑潮反推回去数里。
- 若林恩在一名断臂的人类老兵抱着炸药冲向高阶堕落者、口中大喊「别让那些脏东西吵醒吾王」时，以一缕隔空飞至的黑火替他提前引爆敌群核心，则老兵在消散前看到的是整片魔物被黑火吞没的壮丽景象。
- 若林恩在孽主于城墙血战中浑身浴血、却依然死死挡在通往内城平民区的主干道前时，将昔日留在孤儿院的一道祝福印记转移至她眉心，则她每次挥击都会带起净化无序的暗金烈焰。
- 若林恩在万族各教派的祭司们齐聚黑夜城中央广场、不再祈求神明赐福而是燃烧自身寿命为护城大阵充能时，强行分出一成王座本源回流大阵，则这群年迈祭司能多坚持半个时辰才力竭倒下。
- 若林恩在喵喵看到熟悉的老街坊倒在血泊中、强忍着悲痛继续背起伤员往内城医疗帐篷奔跑时，让医疗帐篷内的存量药剂药效翻倍，则被她救下的数十名重伤员得以保住性命。
- 若林恩在整座黑夜城化作宇宙间最后一座孤悬的信仰灯塔、四面八方皆是无穷无尽的终焉黑潮时，将自己的神王威压化作一口无形巨钟笼罩全城，则城内将士的心智始终未被黑暗低语侵蚀分毫。
- 若林恩在夏娃握着防身短剑守在孤儿院地窖入口、发誓就算死也要挡在孩子们前面时，让地窖门外三丈之内的石板自动升起一道黑火暗纹，则零星漏网潜入内城的低阶魔物一触即燃。
- 若林恩在听到万族联军中不同语言的战歌最终汇成同一句「为了黑夜城，为了林恩陛下」时，被锁链穿透的双手死死扣进王座石髓，任由滚烫的血水顺着台阶流向圣所大门。
- 若林恩在孽主与一名扑上城头的魇魔眷属同归于尽般对轰一拳、震得自己半边身躯龟裂时，以神念替她稳住险些溃散的核心，则她还能擦干嘴角黑血，笑着撑到E753与孤儿院孩童并肩的时刻。
- 若林恩在万族残军带来的最后一艘医疗母舰于城外空域被魔柱光束击中、即将坠毁在城区时，猛地催动王座引力将其残骸牵引偏斜至城外荒原，则城内数万平民免遭坠舰波及。
- 若林恩在喵喵趁着战隙跑到圣所外围、隔着高墙朝王座方向磕了一个头便又转身跑回前线时，让圣所檐角的风铃无风自鸣一声，则喵喵会擦干眼泪，带着他的回应继续战斗。
- 若林恩在目睹那些平日里连魔兽都害怕的普通市民主动拿起铁锤与火把走上街垒协助守军时，在心底将「最后的信仰之城」真正的含义定义为「值得神明为之赴死的凡人之城」。
- 若林恩在黑夜城外围防线被黑潮一层层剥落、每一寸土地都浸满万族英烈鲜血之际，将渗入大地的所有战血气机尽数吸入罪恶王座，则他破封之日挥出的每一击都将携带着亿万将士的怒火。
- 若林恩在万族残军用生命为他的最终晋升硬生生抢回最宝贵的一段时间后，于黑暗的圣所内向着四方城墙的方向深深低下头颅，则这位至高神王在成神之路的终点，向全体凡人致以了最高的敬意。
