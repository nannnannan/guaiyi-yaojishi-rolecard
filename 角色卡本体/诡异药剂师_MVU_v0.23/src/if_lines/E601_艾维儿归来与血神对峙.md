# E601·艾维儿归来与血神对峙·if线

- 若林恩的意识体在摁住银幻时多说一句「让艾维儿先回半场再动手」,则王女入场时机延后一拍,血神踏入第三位面多撕开数千公里,军团护卫阵型被迫顶到第三位面边境。
- 若林恩的意识体不以敲额而是以拍肩收住银幻,则她少了那条「主控责备」参数,但小丑看在眼里,后续会议里对她的偏袒指数 +1。
- 若林恩主动把承诺改成「在敌军发起总攻之前双方都不敢动」,则他对两神的判断被别出一层意义,血神听后反而抢先进攻,对峙提前爆点。
- 若林恩的意识体不在银幻额头上敲而下身给她一个有力的拥抱,则银幻系统里「主人回温」一项爆参数,机体修复度小幅再上,小丑远远看着把表情咽回去。
- 若林恩主动对艾维儿提前一句「你妈没杀你爸」,则她飞抵战场前心境已被撼过一次,跟血神对峙时第一次回话里多一丝颤音。
- 若林恩决定让黑剑不是从众人身后而是从第三位面的另一侧爆射,则血神被击退的方向偏离,大军减速禁默的入口位置随之外偏数十公里。
- 若林恩把「不要追,等他们来」改成「追,但只追到走廊口」,则艾维儿独战血神的战线被拉入走廊内,后续大军入场位置被他本人锁得更深,杀敌效率反而下降。
- 若林恩的意识体事先在艾维儿面前露过一次真形,则她迎战血神时不再「等待一个答案」,对话里少一句冷嘲,多一句直接动手。
- 若林恩主动让艾雯爵士在黑剑出手前就化身灵能巨人迎向血神,则爵士独抗规则神半秒,重伤三级,换来艾维儿拔剑时机更稳。
- 若林恩的意识体对战阵发令时多说一句「巨像控住血液」,则巨像不受血神威压干扰,后续战场她的血肉感应更灵,但血神注意到她,把她写进名单。
- 若林恩决定不点破血神身份,由艾维儿口说「自甘堕落」,则他用词被替换,后续军团记忆里多一句「王女斥神」的口号版本。
- 若林恩的意识体沿走廊边境印的锁链编织改为「全程可见」,则大军抵达时直接看见整条银色银色光网,心理压制+1,但远处混乱深空多一线对这条链路的反追踪可能。
- 若林恩让暗影存在的叙旧部分被传到他耳里,则他后续与黑夜之神对阵时心里多一格筹码,但夜神对他的判断里也加上「渡鸦已听到」的防备。
- 若林恩主动让艾维儿在他现身前已把破军切入战场,则血神被双锁时阵型不需要重塑,但林恩本人入场画面失去「神兵天降」张势。
- 若林恩的意识体在对抗血神时以心声多给艾维儿一句「他体内恐惧你的血脉」,则她独战时打得更有攻势,但血神反应对她的恨意结算 +5。
- 若林恩决定让林恩在这段不把建军告诉艾维儿,改由康斯坦丁传达,则她听到时反应是讥讽一句「他父亲不会这样做」,后续父子对比画面被往后挪一篇。
- 若林恩主动让巨像在血神威压下对外释放血液沸腾的画面,则根源军团比默认走向更早理解「神也有定胜负威压」,但他们被威压吓住的瞬间多一秒。
- 若林恩的意识体把「个半小时」的到达时点提前通报为「二十分钟」,则军团护卫阵型更紧,但任何一帧延误都会被艾雯爵士和船长放大追责。
- 若林恩决定不对艾维儿发送「等他们来」,任她独追血神,则她投入走廊深处被血神暗影双锁时深陷一战,后续林恩亲自动手进场血神的第一次正面。
- 若林恩让银幻在这段不撤回深渊而暂驻边境,则她在血神到达画面里多一道记录机体,但后续 E602 机械狂潮出手她手上牌会少半组。
- 若林恩的意识体在与艾维儿灵能通讯时主动安抚她「他不像你父亲」,则她在后续对峙时情绪更稳,但夜神对她的解读少一层可撬动空间。
- 若林恩主动设定黑剑不出手,改由自缚天使与泰坦头颅联手拖延,则边境军团顶住三次冲击付出多人重伤,黑剑的「林恩底牌」印象被转移到泰坦身上。
- 若林恩决定让血神第一次出手时不只撕第三位面空间,而是点杀几名根源,则军团瞬间减员,后续防线建立时反噬支援者名单里，多了几位未到的名字。
- 若林恩的意识体在这段结束时主动追加一句「随时可以变」,则整个「时间,足够的」逻辑被升级为「他随时可来」,NPC反应画面被压缩,但艾维儿心里的另一个疑问被埋下。
