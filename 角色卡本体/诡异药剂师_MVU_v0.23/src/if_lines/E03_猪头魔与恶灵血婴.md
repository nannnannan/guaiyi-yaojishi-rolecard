# E03·猪头魔与恶灵血婴·if线

- 若林恩在猪头魔索要眼球时主动报出更高的价位或附加条件，则猪头魔仍以「拿猎物换」压价，危机值按砍价幅度额外浮动。
- 若林恩没有当面抠出右眼、改用语言镇场或直接展示拾荒婆婆的眼球，则猪头魔的恐惧度下降更慢，san值扣减幅度变低，后续动手概率抬升。
- 若林恩把自抠眼球直接卖给猪头魔并允许其换眼，则林恩右眼需另寻匹配源，系统会另行提示「器官缺失」的临时视野与时限问题。
- 若林恩在安装时故意保留结石血块不刮，则猪头魔短期复明但炎症复发，三日内带刀上门或托人代讨说法。
- 若林恩先用麻药再动刀，则猪头魔的恐惧度成长放缓，「极度惊恐」顾客首位奖励不再由本事件触发。
- 若林恩忘记收锤子或让猪头魔瞥见整套器具，则猪头魔术后连夜搬离游魂巷，猪肉店易主，E06猪肉供应链改道。
- 若林恩主动用脉象点破腹部异常但措辞换成「你肚子里有活物」，则猪头魔跳过暴怒直接下跪救诊，省去宫外孕到性别矫正手术一连串口角。
- 若林恩避开宫外孕话题、只描绘「寄生反噬宿主」画面，则猪头魔出手抓领子这一段被掐掉，「安抚经验」改为「威慑经验」进账。
- 若林恩在唤魔药剂阶段拖延、先做腹部听诊画位，则腹中恶灵有更长时间成型，开腹难度与风险同步上调。
- 若林恩在开腹前拒绝铁镣铐固定、任由猪头魔自由躺卧，则术中挣脱概率极大，剔骨刀可能划到非预期位置引发医疗事故结算。
- 若林恩以「先付定金再上刀」为条件预付订金，则猪头魔会掏空大半钱袋，术后夺门时连「闺女忘带了」都顾不上回头。
- 若林恩在血婴啼哭时立刻用擀面杖敲晕，则血婴提前失去意识，捏脸阶段畏惧度增长更陡，san消耗却更慢。
- 若林恩按系统给出的另三条可选分支走（化魂灯油/喂后院小宝贝/泡试剂收藏），则鬼婴不留在店内，E06塑形与E07母女线断开，转为「标本/灯油/小宝贝好感」支线结。
- 若林恩对系统提示的四条分支置之不理、任由血婴在脸上长囊肿触手不处理，则血婴怨气渗透店面，san与店面卫生度持续扣减，进入变形判定。
- 若烧死鬼上门时林恩暂停捏脸先接诊烧死鬼，则烧死鬼换脸照常结算，但鬼婴扭曲速度加快，「压制怨气」完成度上限被压低。
- 若林恩对烧死鬼亮出未完成捏脸的血婴并叫其观摩，则烧死鬼当场惊恐逃离且绯闻散播得更快，「黑店」名声提前于预定节点扩散。
- 若林恩对血婴额头竖起的第一颗竖瞳不戳爆、任其自然生长，则竖瞳成为可用魔性器官，但畏惧度曲线改走「共生畏惧」，日后压制方式改变。
- 若林恩在捏脸完成后用雕刻刀在自己指上割小口喂血，则血婴认血齿印，初期绑定关系成立，血衣女士后续强募时将其视作半个血裔而非婴灵食物。
- 若血衣女士循骚动于当晚推门强募血婴，则林恩需在「交出血婴抵命债」「以手术服药劳务代替」「掮客式谈判分账」三条路径中现场拆招，结果计入偏离账本。
- 若林恩以店面作为恶灵血婴的庇护所并公开挂牌收容，则游魂巷内同类婴灵/游荡恶灵会陆续上门投医，诊所庇护功能作为常驻服务被加入店面介绍。
- 若林恩在猪头魔复返后将血婴以抚养权名义交还，则母女线断在婴儿期，猪头魔带走血婴但恐惧度未清，猪肉店对林恩长期免肉价。
- 若林恩把恶灵血婴暂存于店里的魔法场（药剂柜/唤魔木盆等任一调制场域），则怨气受场域压制减速，但场域内的药剂品质同时被污染，需事后净化。
