# E452·三叉戟内界与狱卒可能·if线

- 若林恩在踏进浅滩之前先让喵喵在戟门外守候,则她被留在现实一侧作为坐标伴侣,他在内界探索时多一扇可被外界唤醒的窗口,「单向走不到尽头」的解读不变。
- 若林恩主动开口问艾泽法拉「你走过几天没能找到边境」,则她撩起额前长发的动作会拖慢一拍,「很大,远比你想象的要大」的台词被加重。
- 若林恩主动问「这里能看到星星吗」,则她从低潮里抬起眼会客套地笑一笑,她与他之间多一道毫无实际用途的寒暄,但后来的「我神」跪拜没变。
- 若林恩在殖装克苏鲁之瞳淌泪瞬间主动用手指把那滴眼泪接住接到嘴边,则她下意识会对他动手阻拦,「她很敏感」的警告画面被压一拍。
- 若林恩陪伴艾泽法拉一同下跪低声对融合尸躯开口,则她双手交叉于胸的姿势不变,但他与她之间的连线被多添一线「他在我这边」。
- 若林恩在艾雯爵士灵能藤蔓触到尸躯之前递出一支解毒剂,则她灵能韧度稍强,但「她被大量无序拒绝」的画面不变,五彩混乱的颜色仍冲上尸躯。
- 若林恩提议「是不是换一种共振频率她能接收」,则艾雯爵士会沉默几秒再摇头,「我接触不到祂的意识」的凝滞台词被加重一拍。
- 若林恩在康斯坦丁开口前主动问「你活过了多少年」,则他骷髅眼火焰的跳动会拖慢一拍,「祂存世远更古老」的台词里多一缕敬畏。
- 若林恩主动代康斯坦丁说出「狱卒二字」,则他抬手覆尸躯的骷髅骨架会被他多添一线怅然,他「给出一种可能性」的节奏拖长一拍。
- 若林恩在小丑闪烁期间主动压他「你和他们都不一样」,则小丑玩偶被迫先接住那一眼,「我无权窥探」的台词被加重一拍,他被上诉身份没有变。
- 若林恩在开口问「逼出无序会怎样」之前先低声自报一句「我担心她」,则康斯坦丁解释黏连灵魂的语气会缓一拍,他被允许的脆弱显露一份。
- 若林恩自己按住咒瞳反向粗瞄尸躯,则他被系统弹出警告「灵躯已重创」,后续「不许动她」的阻拦会更直接,他被留下的担心多一拍。
- 若林恩对康斯坦丁扔出极端提问「能否把她直接拖出来」,则全场沉默会被他亲自点燃,艾泽法拉坚毅抬头「我神说过她一定会归来」的台词被提前。
- 若林恩在两日停留期间主动提议陪她去浅滩再守一夜,则她被允许多住一天,「再回内界」的时间被延到第三天,但她打出「可信任挚友」牌时画面不变。
- 若林恩主动给康斯坦丁递上一杯小酒再听他重申「赌一赌」,则那道黑斗篷骷髅在风中孤酌的画面被延长一拍,他作为黑夜城盟友的存在感被多添一份。
- 若林恩提议用自已的初诞之力在尸躯周围铺一道护圈,则护圈能立住但无法改变她内在的无序腐蚀,「赌转化」决定不变,但他被默留下的担忧多一拍。
