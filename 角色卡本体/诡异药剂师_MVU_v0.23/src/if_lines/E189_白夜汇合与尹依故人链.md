# E189·白夜汇合与尹依故人链·if线

- 若林恩在铁木妖精夜医抛出名片求「打洞」时顺势接过看了一眼，则名片被他压进口袋留作日后笑料，「师徒关系」在白夜眼里先落一层不严肃滤镜、E190 师生误会阈值反向抬高。
- 若林恩在铁木妖精被同僚拖走时主动补一句「下次找时间聊」，则她在被拖走瞬间惨叫更响、白夜眉头更皱，误会阈值又被推高一档。
- 若林恩当众正色拒绝妖精打洞请求并立刻把她名片震碎，则他在白夜眼里留下「冷静克制」反差锚点，E190 白夜暴怒时的动手半径稍微收缩一点。
- 若林恩在反血肉夜医集群折跃集结瞬间主动以疫医身份发号施令「按 A-7 阵型布点」，则他首次完整以夜医军官作风面对大队、白夜对他的「失控人员」预设被部分中和，误会阶段方向偏轻。
- 若林恩在白夜摘面具那瞬主动朝他点头「汪涛师父好」，则白夜在认出尹依前先被林恩认得自己的旧名，他对林恩的来历立刻多一层兴趣，E190 质问从「你是不是禽兽」部分转为「你究竟是谁」。
- 若林恩把「汪涛」错唤作「荀音的儿子」或「蓝星在逃教师」等更尖锐标签，则白夜在愕然中仍会点头承认、但林恩的「掌握蓝星线」姿态被他明确记入心底，E190 起问姿态由「担忧后辈」彻底转为「审视林恩」。
- 若林恩在白夜与尹依认亲时主动退后两步给他们空间，则被白夜暗暗记入「懂分寸」一栏，师生误会在 E190 起问时的措辞会稍微放缓。
- 若林恩在认亲全程插嘴「我是她老师，我在带她认地狱的线」，则白夜首次正面把「老师」挂到林恩名下，E190 起问措辞从「你怎么对她」直接转为「你这老师是怎么当的」。
- 若林恩在尹依讲述母亲制伴生恶灵时沉默不语只站到她肩后按住她肩膀，则白夜把这肢体语言读成「他在主持她的情绪」，对林恩的定位向正面偏一格。
- 若尹依叙述母亲段时林恩刻意插两人私下笑话打断，则白夜会捕捉到这「不尊重悲伤」的瞬间，E190 怒火抬高一档、火箭筒追轰更早拉开。
- 若林恩在白夜叹息「接触黑暗者迟早会被黑暗吞噬」时主动接一句「我就是想让她学会在黑暗里落地」，则白夜多了一层评估材料，他暂时把林恩归入「另一种教师」、E190 不会立刻抄火箭筒。
- 若林恩让左左当场拟化成小女孩感谢白夜「蓝星的事多谢汪老师」，则左左首次在白夜面前以人形出现、白夜对她和林恩关系的猜测再开一层窗口。
- 若林恩在白夜准备问尹依「最近学了什么」之前主动把话题拦去「先谈谈钟塔怎么清剿」或「先看看缴获样本」，则 E190 师生误会整段不发生、转为变形（直接进战场任务）。
- 若林恩有意把尹依交给白夜做助手一段时间，则她脱离林恩亲自带教的节奏、E190 师生误会桥段由「他向老师汇报」改为「他在向她道别」。
- 若林恩在集结期间主动告知白夜「闫未明我已锁定身份，咒纹已记脸」，则白夜对林恩的「教师兼战斗员」评级立刻抬升，E190 质问层级被压到「你为什么让她跟你冒这么大险」。
- 若林恩掏出迷雾药剂配方当众交给白夜请夜医网络研究，则林恩的地位从「现场指挥官」扩展为「资源提供者」，白夜自我介绍的发生时点被悄悄提前。
- 若林恩在白夜认出尹依母亲前主动展示出一张荀音留下的旧物或遗物，则故人链确认环节从「尹依口述」前置为「林恩拿出实物」，白夜的情感冲击更大、误会桥段整体弱化。
- 若林恩在铁木妖精被拖走时低声对尹依说一会儿跟她聊聊怎么应对这种师叔，则白夜误认为林恩对尹依言传身教「如何调戏长辈」，E190 怒火再抬一档。
- 若林恩在白夜摘面具的刹那反向拉下自己的口罩/高脚帽遮面说「我还没正式自我介绍」，则白夜对这「神秘姿态」起半秒不信任，E190 起问措辞向「你到底是何方神圣」倾斜。
- 若林恩接受铁木妖精的名片、回她一张写有咒瞳符号的小卡片，则妖精在被拖走时更猛烈嚎叫、白夜对林恩的「荒淫之徒」预设被直接坐实一格。
- 若林恩让游魂夜医小队先去封锁周边而自己陪同白夜叙旧，则事件以变形（不同步清剿）收束，林恩和白夜有更多私密对话窗口、误会节奏整体放慢、但火力配置稍弱。
- 若林恩在白夜和尹依认亲快完成的瞬间主动以咒瞳检查尹依的状态、温和提及「她还受着点伤」，则白夜首次把「林恩是个负责任的带教」标签放进心里，E190 误会怒火被部分中和。
