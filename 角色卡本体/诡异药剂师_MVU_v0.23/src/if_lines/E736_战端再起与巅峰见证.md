# E736·战端再起与巅峰见证·if线

- 若林恩把三十噩梦的攻击引导到无人星域而非承受在第一线,则信仰殿损失最小但王座威信大损——信徒会看见他们的神「让星球代他们死」,这种战略性放弃会让参与式信仰根基动摇。
- 若林恩让艾维儿独自拦截最凶的那只噩梦没派任何支援,则她会被打成重伤濒死但也将彻底觉醒,「神界守护者」身份会升级为「神界战神」,但林恩会永远背负「用姐妹当诱饵」的道德污点。
- 若林恩在战斗中当众亲吻主母以调动信徒的参与热情,则这种行为会被解读为「神与王后的定情」并引发大规模模仿,信仰会被简化成浪漫关系,但短期内士气会暴涨。
- 若林恩决定用机械军团的集体意识作为信仰的临时载体让银色幻想成为「代理神」,则他的负担会减半但信徒会产生分裂——信银色幻想派与信林恩派的内斗会让黑火的燃料不纯净。
- 若林恩选择把信仰的全部力量集中在一次反击中击溃三只噩梦,则剩余的二十七只会因同伴之死而狂怒,它们的反击会比原本强五倍,林恩将赢得战役但输掉战争。
- 若林恩让信徒在战斗中直接献祭自己的记忆给黑火而非普通的祈祷,则每场战斗都会制造大量失忆者,帝国虽然胜利但会失去最珍贵的资源——故事与传承。
- 若林恩在战斗中公开承认自己只是「替众生挡刀的凡人」,则参与式信仰的理论基础首次得到证实,信徒会因「神也是凡人」而产生更深的连接,但也会因「神也会死」而恐慌。
- 若林恩用左左作为信仰的「放大器」让所有信徒的祈祷都先经过她的意识筛检,则她会承受数万倍的信息冲击,她会快速精神崩溃但同时也快速升格——她可能成为比林恩更稳定的神。
- 若林恩在战斗关键时刻故意放水让噩梦伤到无辜平民,则「需要拯救」的紧迫感会催生更强烈的参与式信仰,但这种「制造苦难以凝聚信仰」的手段一旦被发现、林恩会被推翻。
- 若林恩与王座火焰进行「对话」询问它「你到底想要什么」,则他首次听到信仰的集体意志而非个体祈求,这种聆听会让他的政策更民主但也会更混乱——十亿种声音同时响起比沉默更可怕。
- 若林恩让三十噩梦的攻击在击中前一刻自己转换成参与式信仰的燃料,则噩梦会反过来「喂养」他,帝国会在战斗中越打越强,但这种反转会让信徒失去对现实的理解——什么是攻击什么是恩赐。
- 若林恩在战前把自己的一部分神格分给各个星域的信徒让他们成为临时的「地方神」,则分散式防御让三十噩梦难以同时突破,但林恩的神格会因此碎片化难以完整回收。
- 若林恩让信仰殿在战斗中变成可移动的堡垒直接开到前线,则它们会成为更易被攻击的目标,但也会让信徒切身感受「神与我们同在」的直接性。
- 若林恩在战斗中故意暴露自己的位置引诱所有噩梦集中攻击他,则他可以一次性承受全部伤害让星域完全无损,但他会重伤到濒死,帝国的存废将在他一个人的生死上摇摆。
- 若林恩在战斗中发明「信仰债」概念信徒可以先借取黑火的力量战后再偿还,则短期内战斗力爆发,但战后会有大量的「信仰破产者」需要清算,这种金融化会让信仰变质。
- 若林恩在战斗中突然宣布「撤销所有神迹让信徒自己战斗」,则完全的自治会让信徒的参与感达到顶点,但也会让帝国失去神迹的加持——纯粹的凡人战争会比混合战争惨烈十倍。
- 若林恩让艾雯在战斗中同时向信徒广播「我们的神正在牺牲」,则这种实时的「牺牲直播」会让参与式信仰变成情感勒索,信徒会因「不忍他不牺牲」而被迫更积极。
- 若林恩与一只噩梦进行「单挑」胜者为王,则这种决斗会让战斗变得简单,但也会让他成为所有噩梦的集中目标——一旦你赢了一只、你就是下一只的首要猎物。
- 若林恩让信徒在战斗中看见信仰物理化成具体的武器——想保护孩子的母亲的手变成盾牌、想复仇的士兵的拳头变成锤子,则具象化会让战斗壮观十倍,但也会让信徒过于依赖「想要」的力量而非「能做」的技能。
- 若林恩在战斗中与主母共同承受王座的重量让她的意识与他并轨,则两人体验到完全相同的痛苦与喜悦,这种共享会让关系进化到前所未有的深度,但也会让林恩的每一次心动都被她同步感知——毫无隐私。
- 若林恩让战斗的每一刻都被信徒的记忆保存成为「集体亲历」,则他们会因共同记忆而团结,但也会有人因承受不了创伤而崩溃——集体创伤后应激是集体记忆的代价。
- 若林恩决定这场战斗为「最后一次大规模战争」之后解散信仰帝国,则这种「以战止战」的承诺会让信徒全力投入——这是为了不用再信仰,但也会让他在胜利后面临巨大的空虚。
- 若林恩让三十噩梦中的一只在被击杀前发出「我们其实也是被创造来服务更高意志」的呐喊,则这种「敌人也有苦衷」的揭示会让信徒的道德产生困惑——我们在杀的是敌对的神还是另一个受害者。
- 若林恩在战斗中让所有信徒都能「请假」暂时离开战斗去陪伴家人,则人性化的安排会让信徒更忠诚,但也会让前线的人手不足——这种仁慈会牺牲一部分效率。
