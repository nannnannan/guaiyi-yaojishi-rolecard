# E736·战端再起与巅峰见证·if线

- 若林恩在三十尊魇魔撕开旧日幽冥海遗留的后门、绕过外围防线直插空虚的神界与黑夜城时，于第一时间轰然震开三大圣堂的青铜巨门，则那如灭世洪水般冲出圣堂覆满星空的猩红罪火，会瞬间稳住神界内濒临崩溃的自缚天使与留守守军。
- 若林恩在一步踏出圣堂巨门、与守候门外的艾雯爵士错身而过的那一瞬，没有回头只是极轻地对兄长说了一句「看好圣堂，我去去就回」，则艾雯爵士会含着热泪与微笑目送他踏入苍穹，在心底默念「我希望能见到你真正屹立在绝巅的那一刻」。
- 若林恩在踏出圣堂的瞬间主动放开三大圣堂的信仰链接，让全主宇宙的亿万信徒同时通过天幕看见他们的王横刀立于星空，则整个帝国的沸腾呐喊声会汇聚成前所未有的声浪，但也意味着稍后战局的每一分凶险都将毫无保留地暴露在众生眼前。
- 若林恩顶着一头苍苍灰发、手握夜魔刀孤身横挡在黑夜城神国之前直面三十尊魇魔时，先以刀鞘重重顿击虚空震散魇魔降临带来的无序威压，则神界初创界域的崩解速度会被强行遏制大半，为黑夜城居民争取到宝贵的撤离时间。
- 若林恩在为首的魇王死寂开口、察觉到他周身罪火减弱且初诞者之力占比已不足两成时，依然面无表情地横刀冷笑「杀你们足够了」，则魇魔群会因忌惮他过往十年的赫赫凶名而不敢立刻轻举妄动。
- 若那尊擅长精神窥探的魇魔冒险将感知探入林恩的心灵之海、骇然看见他捆缚着无数尖啸面孔与漆黑锁链的臃肿怪诞意志映象时，林恩顺势以残存的意志反斩一记精神刀芒，则那尊魇魔虽仍能嘶吼出「他处于力量最低位！趁现在！」，但其自身的精神本源也会当场受创。
- 若林恩在三十尊魇魔听闻他处于力量最低谷、同时面露狰狞准备一拥而上时，提前将自缚天使与黑夜城神国向后方推移万里，则接下来的灭世碰撞余波将不会直接波及黑夜城内的核心家人。
- 若林恩在被三十尊魇魔包围的绝境中，依然分出一丝心神安抚怀中微微震颤的羽毛笔，则他能在万千杂念锁链的撕扯下保持刀势不乱，正面迎向三十尊魔神的狂暴合击。
