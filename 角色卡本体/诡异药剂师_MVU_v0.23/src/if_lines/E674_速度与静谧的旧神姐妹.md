# E674·速度与静谧的旧神姐妹·if线

- 若林恩在龙卫澜讲解神界近况时主动用「腐化神灵怎么解决」逼问细节，则她会罕见地脸红承认她们从不敢硬碰，会让林恩看到她曾经作为紫荆花卫队的屈辱自卑。
- 若林恩在神音介绍自己时直接点评「她速度法则纯度已破半神限制」，则她会自豪地笑出声又一愣，「我们的法则纯度为什么被外人一眼看穿」的疑点会促使她后期主动配合体检。
- 若林恩在默默身后蹲下伸手抚摸她的狐耳，则她不会躲闪反而浑身僵直安静地站着，黑色的眼睛定定看住林恩，「静谧」波动短暂让全队的心声停一拍。
- 若林恩对神音默默这对姐妹直接坦白「你们的来历疑点满满、我不打算现在拆穿」，则龙卫澜会立刻领会不再追问，队伍原本紧绷的信任链条得以延续。
- 若林恩在支援龙卫澜整合小队时主动筛选减员只带四名精锐，则行进速度+2但大量庇护所内部事务失去支援，留给遗民的防守真空大开。
- 若林恩在龙卫澜提起记忆删除计划时主动拒绝「我不会允许你删他们的记忆」，则她会罕见地露出挣扎神色说出「泄密的代价是我们都死」，庇护所协议首次产生公开裂痕。
- 若林恩主动用初诞者之力配合删除知情权人的记忆，则过程会快数倍且林恩能精准控制涉及范围，对遗民的二次伤害归零。
- 若林恩在石碑前用空间神格反向扫描黑骑足迹，则会发现足迹深处有一缕「通往大裂隙的隐藏节奏」，揭示黑骑内部存在的等级制度。
- 若林恩当场以初诞者之力封住小队的所有足迹不留一缕，则黑骑的因果追踪会被彻底搅散，但庇护所内其他知情人将从此失去队伍座标。
- 若林恩对神音提问「你怎么从黑骑围杀里活下来」，则她会愣住随后理所当然地说「我也不知道、我就是动手了」，法则反克能力的未解之谜首次被点破。
- 若林恩当面要求摸摸神音的额头感应法则，则她会顿一下后主动扣住他指尖说「可以试试，但最好别丢开我」，律条共鸣会主动融合进林恩的法则序列。
- 若林恩在城市废墟中停下来主动用感知扫过一群徜徉的「被抹杀灵魂回响」，则能短暂获得其中一缕灵魂的临终记忆片段，第一手第几个大破灭场景得以补足。
- 若林恩主动把庇护所小队以空间阴影形态深度包裹，则他们高速穿越上千公里全程无知无觉，但林恩的初诞者之力消耗暴涨，后续作战序列被迫暂停一格。
- 若林恩在圣堂外围一时兴起以三叉戟直指塔尖试探「腐化气息浓度」，则他会立刻被外层巡逻黑骑锁定，原本偷偷摸摸的窥探升级为折跃突围。
- 若林恩对龙卫澜坦白「羽毛笔是旧世紫罗兰帝国的物件」时把名字完整说出，则她会罕见地周身一颤质问「您与她见过」，本事件会顺势带入更多紫罗兰帝国的内幕。
- 若林恩在羽毛笔发烫时用三叉戟叠加罪火反向引动，则滚烫的笔杆会瞬间炸出橙红裂纹无穷扩散，圣堂外围环境从内向外被「命运」二字短暂烙下。
- 若林恩在庇护所交涉时硬要带上遗民老者同行，则老者会以「我们只会拖累」婉拒又附赠一张他手绘的「命运之神庇护所隐藏入口」手稿，未来若需折返会快数倍。
- 若林恩选择放弃记忆删除引发泄密，则庇护所会在遗民的口舌中把「渡鸦到来」词条快速扩散到魇群的因果追踪网。
- 若林恩看到圣堂外围的滚滚黑雾主动用初诞者之力燃尽残雾，则暴露会在数秒内照出，对地下的因果化身产生直接逼近心理效应，下一事件难度提升。
- 若林恩向神音打听「你姐妹的来历还有谁知道」，则她会不安地低声说出「只有我们两个人」，林恩的「她们并非单纯难民」推断会直接升级为主动搜查的纲领。
- 若林恩在城市废墟主动引动三位一体的白焰烧穿一片死灵回响，则回响的场面会瞬间止息但整片废墟的无序浓度骤升，因果化身的位置会被锁定到几百公里范围内。
- 若林恩在石碑前主动叩拜说出「对不起、我来晚了」，则无形弥漫的「命运」气息会弥漫出来附在他肩头一阵，后期他利用命运神格时会得到额外加成。
- 若林恩独身上路、把龙卫澜一行全部留在庇护所看护王女，则虽然行进更灵活但羽毛笔的反应无人能解读，圣堂的外围窥探将停留在表层。
