# E785·你我皆凡人与偿还眼泪·if线

- 若林恩主动先在织梦面前落泪一次而不是仅展示凡人痛苦，则织梦会因林恩的眼泪先理解「神明亦会流泪」，E785 的转变从她开始而不是结束。
- 若林恩让织梦在凡人城市梦境中附身一位病重老者而不是旁观者，则她亲历衰老与死亡过程，E786 她因此问林恩「死亡降临时你在想什么」。
- 若林恩主动把某位他无法救下的凡人临终场景作为开场，则织梦一开始就被震住，她必须接受「即使是高高在上的神明也无法挽回所有生命」。
- 若林恩选择让织梦先看到他自己昔日不得已斩杀敌人的残酷影像，则织梦会以「你和我们都有罪孽」的眼神望他，这眼神成为她不再将他当成说教者的起点。
- 若林恩放任织梦的灵能先失控一次再让她看到失控的后果，则她目睹自己造成的梦境废墟后主动要求重新理解凡人的悲欢。
- 若林恩主动在冬泉谷的溪流旁用树枝为织梦弹奏一曲《凡人歌》，则织梦会静静听完那句「你我皆凡人，生在人世间」，并在曲终时第一次主动向他讨要歌词。
- 若林恩在织梦看到某位母亲护子的场景时主动告诉她那位母亲的名字与后来的结局，则织梦因此理解每个面孔背后都有完整的人生。
- 若林恩主动在织梦的灵能瓶颈上注入一滴自己的血液作为引信，则瓶颈破裂速度翻倍，但织梦从此与林恩血液共感，他疼痛她知晓。
- 若林恩让她先救助一只在风雪中冻僵的幼鸟再扩展到人类，则织梦的共情曲线更平缓但更深，她在捧起幼鸟时第一次学会收敛神力的锋芒。
- 若林恩主动在她进行凡人观察的同时在另一半梦境里重演自己当年在黑夜城为同伴流泪的往事，则两人从两侧进入共情，在梦境中央相遇。
- 若林恩放任织梦的灵能突破时把冬泉谷部分冻结，则冬泉谷会成为一个晶莹的冰域，E788 林恩告别时看到她站在属于她的冰晶长廊里。
- 若林恩选择以自身的一缕深渊黑火协助织梦刺破心灵瓶颈，则突破速度极快，且她的梦境灵能从此带上一丝黑火的坚韧，在后续直面终焉时更具抗性。
- 若林恩主动告诉她「在未来的黑夜城里你已经陪伴了我很久」，则织梦会以充满审视的眼神打量他三日，第四日她默默接受了这份跨越时空的羁绊。
- 若林恩让左左在凡人城市梦境中亲自出演一个凡人家庭的女儿，则织梦因对左左的熟悉加速共情，但左左扮演结束后需在现实里休息数日。
- 若林恩在织梦担心他的黑火反噬自身时主动让她亲手触碰那团火焰，则她会伸出手帮他把躁动的黑火抚平，从此她对林恩的「火」不是忌惮而是掌心的温度。
- 若林恩主动让她看完一位凡人从生到死的完整一生而不是片段，则织梦的灵能会因为「一次性承担太多悲欢」而短暂震颤，但平复后她看到的众生更加真切。
- 若林恩选择隐瞒未来自己与黑袍大君决战的真实凶险，则织梦在 E787 会从远古回声中自行察觉，并冷着脸责问他为何独自瞒下生死。
- 若林恩让织梦在凡人城市中拥有一个普通药师学徒的身份作为参与者而非旁观者，则她会与城中居民结下未明说的羁绊，E798 那座城里仍流传着她的故事。
- 若林恩主动在她突破瞬间撤去所有屏障让冬泉谷的真实风雪灌入，则她在天地风雪的洗礼中完成蜕变，并在漫天飞雪中接住自己滑落的第一滴眼泪。
- 若林恩在立下「我会还给你的，织梦，我发誓！」的誓言时主动伸出小指与她拉钩，则织梦会怔怔看着他的手指，最终极轻地勾住他的指尖完成这场跨越千年的约定。
