# E443·失却之海净化与导航者覆灭·if线

- 若林恩捏爆渡鸦尸体前先把熔岩巨兽的火焰巨剑方向用上位心声朝外拨偏一寸，则弑利亚被撕天之剑挡下时的控制指令会往空位偏一拍，康斯坦丁巨臂抓剑的窗口延长，攀爬上肩能省一秒。
- 若林恩把缚魂锁链缠上熔岩巨兽剑脊再催发初诞之力，则污染沿剑身剥离时其本体痛苦程度更深，提前长啸反水，弑利亚的决战节奏被迫提前。
- 若林恩跃入失却之海前先用咒瞳反向扫一遍心灵海面的窗口分布，则记忆航海图多一幅冗余底稿，错过心灵船舵的方向时能凭记忆二次定位船长。
- 若林恩叫左左先用心声轰击船长驻留位置，则碧蓝光晕船长抬眼时多一瞬被干扰，灵魂之船没入漆黑寂静处的速度稍慢，灌注窗口可以多停留半秒。
- 若林恩命令喵喵守在现实肉身边缘，则王兽反水涌向己身时有猫形哨卫尖啸示警，一线征兆提前浮现。
- 若林恩跃出灵体之船时绑一条初诞细链拴住船舷，则意志归回能多一线精神坐标，窗口关闭时拉回速度快一拍，不会错过最后的刺戟定位。
- 若林恩把身体贴在王兽集群与弑利亚中间位置再意志归回，则王兽心灵被切断瞬间第一反应是看向自己，归属裁断的接受度更高。
- 若林恩踩稳地面再举戟，则炽烈初诞之力呈十字冲击波扩散而非散漫震荡，少数居外的王兽也会一并被净化光笼罩。
- 若林恩挡下弑利亚刺出的虚无长矛前先抽三叉戟迎击，则无序威能被戟身初诞者之力直接反噬进弑利亚手臂，长矛会被当场熔解一半，但林恩手心承受的反噬会更深。
- 若林恩握住长矛时故意把无序力量多引一点进自身，则裁断「他们是我的了」时身上会多一条由无序镌刻进眉心的细灰线，后序警告标签「他敢接」同时入账。
- 若林恩立刻转头用心声捅破弑利亚「你和我没有任何区别」的诡辩并给王兽下令撕碎她，则她那一整段「自认小丑／以感情操控家人」的话会被王兽怒火直接轰碎，死得更快，但「甚至都没有位列根源」的诛心话不会入画。
- 若林恩故意沉默听完她全部讽刺再下撕碎令，则她会在讽刺最盛时被王兽怒火正面压下，死状更惨，但自己听完后内心多一道「甚至被教你的人反咬」的刻痕。
- 若林恩挥戟断指她抽逃向海面的第一根手指，则她跌落时会下意识再损一只手掌，落海姿态更难看，但多损的这只手不会增加信息。
- 若林恩点破「四个」战死并把第一次围堵时化无序掩护撤退的王兽名字挨个念一遍，则小丑「你还记得？」的瞳孔会震颤更久，忘却机制的当面展开会更慢更渗人。
- 若林恩故意遗忘被概念抹去的名字，则小丑会先替林恩补上四个名字之一，反而更加崩坏，忘却机制第一次当面验证就从最亲近的人身上展开。
- 若林恩捡起欲望母树种子前先滴一滴金色的血进焦炭表层，则入库的种子多一缕初诞者之力残留，母树后续涅盘时可能被这枚血印锚定一次复活窗口。
- 若林恩在捡种前先用心声逼问种子表层是否还存母树的恨意，则系统可多弹一条「残留意念」标签，可提前把可能的母树复仇线挂成隐患。
- 若林恩走近孽主前先用力弹一下她的脑门再以「活着就够」收束，则她哭诉时肩膀耸动的幅度更大，但最后扑进怀里的瞬间比不哭出来更重。
- 若林恩把孽主留在原地不许她跟来集结，则她会抱着毛绒玩具猫在远处角落坐到大战彻底落幕，最后归城时手会死死攥住林恩衣角。
- 若林恩举戟号令王兽前先让熔岩巨兽站出来单膝，则数十王兽紧跟臣服时的队列会先压一截又抬高，集结权柄的观感更霸。
- 若林恩以「跟来」代替「请」号令王兽，则集结时的叩首会更直接、权柄分开海面时的王兽密度更高。
- 若林恩跳上康斯坦丁肩并以全副心声喊话收编队伍前多出一句「我不许你们乱动」，则王兽的热泪臣服会更沉，后续听调时执行度更高。
- 若林恩特别把已净化的王兽拉到旁边私语一句自己身世，则该王兽在出发前会专门绕过来对林恩低首一次，友谊点数更高。
- 若林恩忘掉生命之种入库步骤就启程边境，则康斯坦丁会在出发瞬间按住林恩肩膀提醒，种子仍必须当下回收才能入系统空间。
- 若林恩把举戟集结的命令翻译成王兽各自母语再喊出，则集结整齐度更高，但「我们都听您的」统一呼喊的白描感会削弱。
- 若林恩允许王兽带拐走的战伤王兽一起出发，则庞大队列出海时会有重伤矫正段，节奏放慢但「活着就走」口径扩展一次。
- 若林恩让左左在权柄下达的瞬间用竖瞳对上弑利亚最后残存的心智，则她跌落时第一反应是别过头去，不会留任何「母神」台词，但一线潜心底的恶堕响彻。
- 若林恩把林恩自己的台词改成让王兽直接向王骑叩首，则后续重誓段中「像极大君再世」的观感会更强，但林恩的「他是我的了」归属感会被弱化。
