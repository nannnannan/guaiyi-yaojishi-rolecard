# E25·双面伯爵与心脑之汤·if线

- 若林恩在黑雾扑面时不直上高台而绕外墙寻门，则卡梅尔被迫下高台追击，「假面的卡梅尔」任务地点改写为外墙阶，白逸避开旗杆段落仍被触手另行处理。
- 若林恩首枪不射双眼而打卡梅尔握杖手腕，则权杖脱手，双面切换出现一帧卡顿，左右脸对位台词被打散成残句，但眼球完好、恢复结算照旧。
- 若林恩电锯被挑飞时不接刀锋任屠刀坠下高台，则「我确实玩够了」对白失去支点，林恩改以骨刺残段作第二份药引，结构较轻仍交左左收存。
- 若林恩在殖装龙息之臂前先把白逸从高台放下，则旗杆恐高段落推后或取消，白逸对林恩的登记从「被丢下」改为「被提前安置」。
- 若林恩在聚焦之瞳融头前先以聚光扫过卡梅尔脚背，则卡梅尔临死一瞬多一个未被读出的嘴型，残躯保留部位不变，左左药引登记照旧。
- 若林恩腰斩卡梅尔时不质问女儿形象而只报出「手术结束」，则卡梅尔双面对位同步崩裂而非一闭一睁，第二份药引诅咒活性微降，左左吃时口感清淡一笔。
- 若林恩在龙首熔炼左臂时把左左拉下不让她吃，则焦糖口味登记缺席，左左当场对该战利品归属记异议，E26 起涉及她分到战利品时优先翻这一笔。
- 若林恩在推铁笼木门前先用过往遗念扫过门板，则肢解再现前置到推门之前完成，林恩带着已过画面进入母女切换对话，第一句台词顺位与原著次序对调。
- 若林恩揭穿寄居者身份时不叫玛丽夫人而直呼其生前女巫名，则过往遗念功率上调一档，爱丽丝面板短暂崩解一拍，林恩登记簿「身份」一栏先记下的是那个生前名。
- 若林恩走廊血手穿胸时不反手自贯而改后退拉开三步，则玛丽放弃近战改以古堡墙体渗血合围，交火点从走廊移到楼梯井，林恩不再以胸口豁口换相位松手时机。
- 若林恩反手自贯时不涂恶灵显形药水而改以神圣力量灼烧夜魔刀，则相位松手仍成立，但灼烧反噬落在林恩掌骨上，战后持刀日程顺延数日。
- 若林恩揭地板先壁炉后大厅，则那只仍在流血的小手最后出现在壁炉深处，爱丽丝对林恩的第一笔私人账从「找到我」改写为「挖我出来」。
- 若林恩举碗前先报出「善心一颗、恶脑一颗」的配方原料名，则猪头屠夫承认他识货放松半寸，但半小时窗口与免责一句均不变。
- 若林恩让汤凉下再喝、先与猪头屠夫闲聊古堡库存，则屠夫以「汤凉效用减半」把交换窗口压到二十分钟，心脏弹射冷冻库的倒计时更紧。
- 若林恩舀一瓢汤给左左先尝再自己饮，则左左吞一口即吐并记「这锅不能吃第二口」的预警，心脏期限不变，她对古堡食材的把关自此多一道。
- 若林恩当场提出以卡梅尔骨刺残段加屠刀换心而不饮汤，则成交时心脏交易成立、两份叮声均不落林恩身上；不成交则汤仍是唯一通道，未饮汤对应叮声按系统规则不结算。
- 若林恩当场拒绝一切换心条件，则心脏被猪头屠夫收回汤中，爱丽丝重建媒介缺最后一块，事件按等价路径未成立出局，转入变形通道由其他战斗或代价补出。
- 若林恩饮汤后先把碗扣在石案上再捞心，则契约仍按原约处理，但下次涉及猪头屠夫食材交易时他对林恩的「识时务」记录扣一笔。
- 若林恩把心脏弹射进冷冻库后追加一句「极恶之心我用别的给你」，则任务被登记为「限期+方式自定」，违约底本仍是林恩心脏，好感判定通道由后续履约方式结算。
- 若林恩在母女高频切换时平静说「让爱丽丝本人答我一句」，则寄居者反扑烈度上调，但爱丽丝本体夺回控制权瞬间留一声短喘息，林恩对她的称呼登记从此从「病人」改起。
- 若林恩把卡梅尔残躯药引收入自己的系统储物而非交予左左，则左左记归属异议，后续她吞噬任何新战利品时优先翻这一笔旧账。
- 若林恩现场清点古堡墙体每块藏尸并当面报数，则推冷冻库门之前拼图清单已齐，E26 重建现场不必回头清点，爱丽丝对林恩的私人账本从「数过我的人」这一行起算。
