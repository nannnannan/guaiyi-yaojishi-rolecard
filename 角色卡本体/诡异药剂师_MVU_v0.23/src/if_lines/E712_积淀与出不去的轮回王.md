# E712·积淀与出不去的轮回王·if线

- 若林恩在听到银色幻想「我会继续冲击神位」时主动走上前扶一扶她的肩，则黑夜城众人会立刻读出林恩对她的青睐态度，E713 时她被赋予的机械狂潮战术权重会再高一点。
- 若林恩主动在战后谈判桌上把「败一次就满盘皆输」这句话说出口，则那一句立刻成为黑夜城众人的共同口诀，他本人也自动背上「不能输一次」的担子。
- 若林恩在苍白耀阳即将熄灭的瞬间主动伸手去握住最后一缕余烬，则以太吸纳的速度会被压得更稳，但他自己会在这一秒承受一次极限性灼烧。
- 若林恩主动把罪火常态化的感觉录进系统面板并钉在明显位置，则下一次他再动并保持「火光温润如水」的最低门槛会被档案化，灵能象的提示系统会随时刻意提醒他维持。
- 若林恩主动在时间长河里只打一轮肉搏而不再追加力量档，则轮回神王会留出一记「你还差一段」的眼神不再一巴掌煽飞他，二人的对话空间被让出更大口子。
- 若林恩主动在肉搏被煽飞之后不再喊「再来」，则轮回神王会将手掌放下、第一次以「歇一歇、讲讲道理」的姿态坐到林恩身边的虚空上。
- 若林恩主动问轮回神王「你和我打的时候真的有在用力吗」，则那身影会静静停留一瞬、没有回答，但林恩会从那一瞬读出「他保持了与我无限接近的力量规模」的实感。
- 若林恩主动把「我现在依旧被逻辑所困」这句话记下来贴在心口，则他在下一次 E713 里再次当面对质时会立刻用这句话做开场,把死结从心底再翻一次。
- 若林恩接受轮回神王「把记忆给你」的提议，则他会在接手的瞬间被那段积淀的重量碾成陌生人,这一条 if 线由此陷入终结,不能再继续。
- 若林恩果断拒绝「变成你这种扑克脸」并笑出声,则轮回神王那一直以来扑克脸似的外表会第一次浮现一丝极浅的、类似「不出所料」的认可情绪,尽管他不会让它真正变成表情。
- 若林恩主动问「你能用初诞者之躯入主梦境的中枢吗」,则轮回神王会摇头、平静告诉他「这条路我试过,是死路」,这一段历史首次在二人之间挑明。
- 若林恩主动问「你所谓的『梦境的主人』现在是什么状态」,则局面会首次隐约给出「终焉之主即是造梦者」的反面证明,林恩的对外战略立刻有了真正方向上的一点不同。
- 若林恩把「我出不去的」这四个字反复咀嚼、选择主动再问一句「那以后呢」,则轮回神王会告诉他「时间未到、未来的你和我谈过」,这句话首次落在林恩耳中并重锤一次.
- 若林恩主动提议让轮回神王坐上自己同一战线,则会被用「我与你不是同一阵线」的语气拒绝,但在拒绝这一拍当中,二人之间的关系首次被他自己定义成「独立的、不同的两点」。
- 若林恩主动表示愿意试着去拆开自己身上「外来者的烙印」,则轮回神王会静静摇头、语带描摹地说「不是你想要的」,但林恩内心对烙印的本质将有更深一层的认识.
- 若林恩主动在弥留外部总分地站起来喊出一声「原来如此」,则这一刻「你和他,都是斩掉了记忆的我」的真相在林恩心口落定一次,无形中他将被烙上准备好的印记,后续所有决策都连带这一次心灵翻篇。
- 若林恩主动在灵能象的阴影下说出「请原谅我」之前再多说一句「我会回来」,则灵能象会对这四个字有最深的一次保留,未来他再用灵能象时的道德预感就少了一点下落坡度。
- 若林恩把罪火常态化的姿态用来外放,以威压黑夜城的几个在场主张调停的老派人士,则在 E713 里可选出「罪火柔软如水」的合规实例,「众人重新树立对林恩的希望」将以林恩当众示范这条罪火为核心。
- 若林恩主动在时间长河里暂停一切动作,静听轮回神王慢条斯理翻完一本书,则他会首次感知到那种「打一辈子」只是这位神王的存在方式,而不是彼此对立的比力,这一局二人之间平衡关系被永久确立。
- 若林恩主动把「三位一体是破局关键」这件事改口以「三位一体的更具体拆法是如何」表述,则轮回神王会没有表情地接住他的话,但留出的信息细节将出奇完整。
