# E712·积淀与出不去的轮回王·if线

- 若林恩在白烬罪火触及第三重境界门槛时急于强行破境，则体内尚未完全圆融的三位一体会再度震荡，轮回神王会出手一指按住他的眉心助他稳住心神。
- 若林恩在金色梦境与灵能海洋暴涨至巅峰时主动将一缕梦境之力投射到天堂之战遗址外围，则窥伺外环的梦魇投影会在靠近遗址亿万里前便被无声蒸发。
- 若林恩在轮回神王说出「我已经没什么能教你的了」时没有立刻追问原因，而是郑重向老者行了一个晚辈礼，则轮回神王会罕见地露出一抹欣慰的笑意。
- 若林恩在得知轮回神王「只是一段属于过去的执念、跨入现在就会消散」的真相后，尝试以空间神格与金色梦境为老者构筑容身容器，则轮回神王会摇头拒绝，坦言属于过去的早就该留在过去。
- 若林恩向轮回神王追问「当年你们七位初代神王迎战终焉时，到底差了哪一步」，则老者会指向林恩胸膛，告诉他「差的就是你如今融于一身的这股不属于旧神体系的力量」。
- 若林恩在时间长河中将自己十年积淀出的白烬罪火毫无保留地演示给轮回神王看，则老者眼底会映出久违的亮光，断言这股火焰足以烧穿梦魇的本源。
- 若外环战场上银色幻想与船长在应对梦魇的梦境投影渗透时，提前借助织梦残留的梦境图谱布下防御网，则十年消耗战中被腐化的下位神数量将减少三成。
- 若黑夜城主母在十年拉锯战中期主动轮换前线半神回城休整，则守军的精神紧绷度能得到有效缓解，防线在第十年的承压能力更为坚韧。
- 若林恩在第十年的沉淀尾声提前感知到主宇宙权重的缓慢滑落，则他与轮回神王道别的节奏会更加紧凑，出关前的战意也会瞬间攀升至顶点。
- 若轮回神王在揭示自身执念真相时多叮嘱林恩一句「别把我们也当成你的包袱」，则林恩背负的旧时代沉重因果会轻去一分，心境愈发纯粹通透。
