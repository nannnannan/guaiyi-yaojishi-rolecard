# E398·夏娃降临·if线

- 若林恩在异常冷意扫过黑夜城时立刻集结核心成员到广场，则艾雯爵士与巨像之脑的先遣侦察由玩家直接旁观，地下蔓延的血肉网络被第一手目击。
- 若林恩选择在警报响起时先行唤醒沉睡的喵喵让她感知同源血肉，则喵喵的鼻子可以指出夏娃分裂出的主要血管大致方位，但无法判断主躯位置。
- 若林恩让小小直接进入地下网络探查，则她的触手会在夏娃分裂血管面前被视作威胁，夏娃可能主动攻击小小，事件变形为「误伤与紧急隔离」。
- 若林恩在自缚天使释放神圣火焰前就让她辨认出「旧神气息」，则她会留下辨认余地但火焰强度更大，夏娃的血管在压制下仍保持形态完整。
- 若林恩让艾雯爵士直接用维度空间围困、不通知巨像之脑超维链接测试，则弱基因联系不被察觉，夏娃对巨像之脑的天然敬畏不被激活，晚餐台上巨像之脑对她的警惕不会因为她的一声「爹」而缓和。
- 若林恩在夏娃喊出「爹」之前主动用渡鸦气息笼罩她，则她的认亲音节会被那声呼唤提前触发，全场死寂的程度更深，艾雯爵士的表情僵硬到需要人偶家拍肩唤醒。
- 若林恩在她喊出「爹」之后立刻公布「这是本城的女儿」，则全场镇压力瞬间解除，自缚天使会皱眉追问来历，但后续家庭融入的阻力显著降低。
- 若林恩在众人愣住时悄悄对左左说「这就是本大爷的闺女」，则左左会磨牙说「笨蛋！！哪个正常父亲会让这种事发生在自家门口」，但她的手已经不自觉地伸过去想捏一把那团蠕动之物。
- 若林恩选择不立刻承认关系、先让黑堡那头远程听声音，则黑堡会给出「死亡与怨念比血肉支配者淡薄」的补充判断，但承认时差会让夏娃的血管在几秒里因「不被认可」而狂乱抽搐。
- 若林恩让夏娃的血管突破维度封锁靠近自己，则她的触碰会带来强烈的亲昵与喜悦，但巨像之脑会立刻切换战斗姿态随时压制，艾雯爵士的维度空间需要紧急加固。
- 若林恩在她喊出「爸——」之后直接问她「你愿不愿意留在黑夜城」，则她会立刻发出刺耳而顺从的肯定，但被其他同伴听见的「直接收留」决定会引发关于危险等级的紧急讨论。
- 若林恩让她辨认「邪恶而扭曲的气息」来源时先给她喂一颗糖，则她会因为甜味而平静下来，更容易进入「回忆」状态，但糖水会黏在她血管上需要后续清理。
- 若林恩让喵喵直接跳到她血管堆里打滚，则她会因为「小小个子+温热触感」而停止防御性散落眼球，但对喵喵的初步判断是「这只猫可以吃」，需要玩家及时纠正。
- 若林恩在她扑向自己时张开双臂，则她会瞬间把万千血管缠绕到他腰上，黏糊糊地贴紧，巨像之脑会皱眉说「这不是一个父亲该有的姿势」，但玩家的主动权让她无法抗拒。
- 若林恩选择让她辨认疫医大本营那段「友好性改造」的经历，则她的血管会因「被认定是缔造者手笔」而集体朝玩家方向扭转，事件走向「缔造者身份正式确立」。
- 若林恩不让她辨认疫医经历、只让她辨认当前气息，则她的认亲范围被限定为「缔造者」，但巨像之脑会注意到她对林恩的依恋远超生理范畴。
- 若林恩在地下大殿讨论时让自缚天使详细描述「无数年怨气的积累」，则她的警告级别提高到最高，全员同意需要严格的引导观察期，但林恩的亲密度不受影响。
- 若林恩让她当场展示「无与伦比的分裂性和延展性」，则她的血管可以瞬间覆盖半个广场，但艾雯爵士会要求她立刻收回，控制力测试得到实证。
- 若林恩让小小现场与她打一架测试实力，则小小的触手会在她血管面前显得纤细，但小小的速度能让她追逐一阵，测试结果被记录为「速度压制，杀伤力未知」。
- 若林恩选择不测试她的战斗能力，则她的图鉴面板停留在理论描述，后续家庭成员对她的实际破坏力没有直观概念，信任建立需要更多日常接触。
- 若林恩让她在大殿里直接转化出一小坨血肉样本给巨像之脑检查，则检查结果会提前确认「旧神子嗣/血肉聚合物」标签，但她的「弱基因联系」不会被激活，巨像之脑对她的警惕不减。
- 若林恩在她喊爹之后立刻带她参观黑夜城顶楼俯瞰全城，则她的万千血管会本能地在高处扩散，但玩家的指令能让她收回，她的领域控制本能得到初步确认。
