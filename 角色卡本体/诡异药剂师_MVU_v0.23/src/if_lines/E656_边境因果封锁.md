# E656·边境因果封锁·if线

- 若林恩不指向边境方向折跃，则变形：偏转不显现，他不会识破因果封锁，离开主宇宙的路线仍被锁死。
- 若林恩第一次折跃撞上破碎之眼后坚持留在曲率空间，则他会同时对抗无序风暴与破碎之眼的吞噬，能在夹缝里找到一条活路，但眼中会多一道伤痕。
- 若林恩一开始就改用短距折跃贴近边境，则他会遭遇更密集的意外，但单次意外的烈度会低于长距折跃。
- 若林恩自始至终只用普通空间法则校准航向而不动用法则视角，则他不会识破规则纹路的偏转，他会以为所有偏离都只是巧合。
- 若林恩点住太阳穴让初诞者之力汇聚双瞳再做第三次尝试，则他能立刻看清无形罗网的存在，他对因果封锁的判断会早一拍。
- 若林恩在第七次折跃撞上被污染者大军时不跃开而硬闯，则他能避开被大军咬住，但他要承受一次大规模的横扫暴击。
- 若林恩在第十次折跃被抛回主宇宙中心时不立刻反扑，则他能静下来盘点以往的偏航记录，他能理出一条更可靠的因果轨迹。
- 若林恩在反向指向主宇宙中心作对照时不立刻迈出几次长距折跃，则他能更精细地描出弧线的不对称，因果封锁的证据会更确凿。
- 若林恩任由一次又一次意外把他卷回主宇宙中心，则他会被困在因果罗网里无法脱身，事件以他被困取消收束。
- 若林恩把对因果的怀疑同织梦用心声对照，则他们会立刻认同这是因果神王的手笔，对策成形得更早，但织梦会立刻担心他的安危。
- 若林恩在发现因果封锁存在后立刻转身去寻画家而不继续试图突破，则他能避开因果神王的下一步陷阱，但他会失去找出因果封锁处理方法的窗口。
- 若林恩把每一次偏转的方向都记入星图归档，则他能生成一根反向识别的禁弧，这是因果神王始料未及的侦探工具。
- 若林恩在深陷因果罗网时突然感到某道撕裂，则他可以以意外的目的地作为对因果的最后线索，他能获得足够的时间和设定来追踪因果的源头。
- 若林恩忽略所有的意外并坚定地迈向反向前进，则他能绕过因果的推演防线，让因果推动成为他完整的垫脚石。
- 若林恩在因果之力影响下瞬间蓝染更深，则他能以一个不同的方式窥探因果，他能从因果神王身上偷师他本不该拥有的神力。
