# E655·深渊残骸与主宇宙防线·if线

- 若林恩不借深渊空间机制折跃、改用航行，则本事件取消，主宇宙最新战况改由其他渠道零碎传入。
- 若林恩折跃终点选在陌生星区，则群星不与他共鸣，观测范围大减，敌方三线并进的全局只能靠分段推测。
- 若林恩出曲率裂隙后忘记抹去来路轨迹，则因果神王的追痕会沿尾迹切入，他专心观测的窗口立刻缩短。
- 若林恩观测前先用一缕金色领域罩住识海外侧，则观测时不被打断，但梦境持续抽走初诞者之力，观测时间被压缩。
- 若林恩观测只扫过旧战场星区而忽略边境方向，则他能印证旧战果，但会错过主宇宙边境内移的关键信号。
- 若林恩在观测到某颗星辰被湮灭的瞬间强制切断群星连接，则他能稳住心神，但失去对该星区沦陷速度的精细评估。
- 若林恩在「第二道防线失守」刚露头时就立刻中止观测，则他不会看到「三线并进」的最终结算，对敌方战略的判断会缺一环。
- 若林恩观测时不点亮金色领域护外，则他能更久维持群星连接，但神识窥探会立刻追踪到他方位。
- 若林恩观测到多个星区沦陷后立刻离开主宇宙去寻画家，则他不会看清「成千上万星辰被湮灭」的规模，他带出去的情报比现实更悲观。
- 若林恩在观测中切换锚点到主宇宙中心，则他能绘制核心全域的实时图，但对边境的沦陷一无所知。
- 若林恩把观测时间主动压缩到只观边境不看已沦陷星区，则他能算出边境内移的速度，但失去对旧疆失陷的精细追踪。
- 若林恩观测结束后用心声把结果告诉织梦再做下一步选择，则他能立刻获得织梦的同步建议，对局势的判断更犀利。
- 若林恩在观测中突然把自身位置反向投给织梦以确认锻锚，则织梦会立刻飘到深渊第一位面等他，两人能立刻对论敌方三线并进的实况。
- 若林恩放任群星一直共鸣不关闭连接，则他能持续观望主宇宙的每一座战火，但织梦会因此在极快时间内为他的星链额外付出一线。
- 若林恩在飞往观测地点之前突然止步徘徊观星，则他会缺失观察边境的机会，但他能换一种方法解读边境的异境光明。
