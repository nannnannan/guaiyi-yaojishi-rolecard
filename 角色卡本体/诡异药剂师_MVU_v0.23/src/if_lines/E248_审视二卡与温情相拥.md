# E248·审视二卡与温情相拥·if线

- 若林恩在调出【林恩（1）】旧面板时把"灰（字面意义）"先遮住看再逃避，则他对旧躯体的记忆延长一秒不亲眼面对，事件以变形（逃避凝视）收束。
- 若林恩把这个数值锁住不让左左看见、却依然让她卷着他胸口敲，则她后续抱上来时带着完全不知情的纯粹，事件以变形（秘密保护亲密度）收束。
- 若林恩在左左抱上来时顺势从系统空间拿出一枚从蜀都商贩那里买到的玫瑰，则温情画面被抹上玫瑰花的滤镜，事件以变形（加入玫瑰）收束。
- 若林恩在她问"你不要再不要我了"之后不回答反而是把她轻轻放到肩膀上，则她坐在铁壳肩上比拥抱更自由，画面被重新构图。
- 若林恩在这场拥抱前先主动把手上的咒瞳摘下来丢在地上，则左左看见的是"纯粹的机械林恩"而不是带着警惕的林恩，事件以变形（摘装备坦诚）收束。
- 若林恩在她砸下巴时轻声说"你要是这么喜欢我以后我也不能离开你"，则她被这句话噎住没继续打，事件以变形（承诺保值）收束。
- 若林恩在她没穿衣服被发现时直接脱自己的机械黑袍裹住她，则她在他身体里获得一层额外的温暖，事件以变形（被机械壳保护）收束。
- 若林恩在她追问"那部分血肉留哪儿"时直接回答"留给了它最配得上的主人"，则她愣住几秒、突然明白他在说谁，事件以变形（剧透给她自己）收束。
- 若林恩让白夜远远看见这一幕并用通讯发来"你们两个倒是安静点"，则白夜在远方目睹"机械人与小萝莉"的画面，事件以变形（白夜目击）收束。
- 若林恩把她抱起来时让机械系统的拟化短暂地为她模拟出心跳节奏，则她听到这颗假心跳，情绪被拨到高峰、差点掉泪，事件以变形（机械心跳）收束。
- 若林恩在她抱紧时让巨像之心对这个拥抱反馈一记柔和的震动，则她误以为他的心脏真的在为她跳动，事件以变形（巨像心跳同步）收束。
- 若林恩让这场拥抱结束后主动在她耳边低语"留一点悬念明天再继续"，则她第二天跟着他溜进蜀都的节奏从早就被排定，事件以变形（约好明天）收束。
