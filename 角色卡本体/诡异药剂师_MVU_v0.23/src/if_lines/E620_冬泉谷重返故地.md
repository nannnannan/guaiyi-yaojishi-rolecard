# E620·冬泉谷重返故地·if线

- 若林恩在折跃前为六人分发「初诞者灵药」以提升体质,则他们抵达时的不适感会减轻,但灵能的抗受能力会降低。
- 若林恩决定让左左先行探索紫罗兰世界,则她能更早地发现冬泉谷的现状,但也会错过「织梦」的踪迹。
- 若林恩在折跃时多进行一次空间稳定,则跨越半个主宇宙的代价会增加,但精度和安全性更高。
- 若林恩让母树在抵达时先行窥探冬泉谷,则她能更早地认出纱奈儿,但也会因过度关注而忽略危险。
- 若林恩把「以紫罗兰的运行轨迹」推算失误,则目的地可能会偏移,折跃路径会更长。
- 若林恩决定让羽林军也随队折跃,则他们会因不熟悉而晕眩,但战斗力会更强。
- 若林恩让血枢残魂在抵达时指导巨像的探索,则她会更快地发现「血脉」感应,但也会因血枢的干扰而迷失方向。
- 若林恩在深渊第七位面给羽林军加持「外来者印记」,则他们会以更高的秩序排列,但折跃的代价也会更高。
- 若林恩决定让银色幻想提前在深渊部署军队以应对紫罗兰的变数,则她会耗费更多精力,后续升华的时间会减少。
- 若林恩把「织梦已经知道我们来了」的想法告知小队,则他们会因紧张而行动更快,但失误率会增加。
- 若林恩决定让艾维儿用她的初诞者记忆创造一座桥梁,则队伍能更轻松地跨越紫罗兰世界的障碍,但记忆的消耗会很大。
- 若林恩在折跃时让母树使出自然魔法,则她能更容易地找到冬泉谷的位置,但魔力的消耗也会更大。
- 若林恩让血枢残魂在抵达时保护艾雯的灵魂,则他会更稳固,但艾雯的失控风险会降低。
- 若林恩决定让渡鸦提前在紫罗兰世界侦察,则它能更早地发现冬泉谷的踪迹,但「纱奈儿」的身份会暴露。
- 若林恩在抵达时让巨人本体紫云覆盖紫罗兰世界,则视野会更广阔,但冬泉谷的隐蔽性会降低。
- 若林恩让小队成员在抵达时先休息一段时间适应环境,则他们能更好地调节身体,但时间会拖长。
- 若林恩把「紫罗兰世界」设为「织梦的地盘」,则小队成员会因恐惧而退缩,但后续为艾维儿征讨会更有信心。
- 若林恩决定让血枢残魂在冬泉谷外仿造一座灵能雕像,则它能成为队伍的指引,但血枢的负面影响会更明显。
- 若林恩在折跃时让母树以她的力量创造一群自然精灵护路,则路途会更安全,但自然精灵的生命力会更脆弱。
- 若林恩让左左在抵达时先行寻找「三位一体」的入口,则她能更早地定位织梦,但也会错过与巨像的和解。
