# E345·混乱色彩与古老记忆·if线

- 若林恩在她摘下兜帽时主动伸手按住自己的脸,则她面容与他重叠的那一秒她自己先别开视线,茶杯被搁回桌面时微微溅出一圈茶渍。
- 若林恩听到「我还要利用你」时没有开口,则她眼底那点红色在他沉默里更深了一层,她第一次没有用任何词为自己辩护。
- 若林恩在她道歉时直接反问「道歉有用你早说了」,则她指尖在壶柄上停了两秒,两秒后她的视线挪到窗外翻滚的苍蓝天空,没有答。
- 若林恩问她复活承诺「可以换回几个名字」,则她说出了两个他从未听过的人名,说完之后她的瞳孔里第一次出现不属于剧本的懦弱。
- 若林恩听到「说过要娶我的人」时没有追问,则她那句誓言在茶烟里悬了三分钟才被打破,打破它的是风吹窗棂的第三声响。
- 若林恩反问她「你等的会不会是别人」,则她自己的身体在那一秒出现一次不属于她控制的颤抖,颤抖后她第一次主动承认「我不确定」。
- 若林恩在软禁的几天里沿着直线日走八小时,则第七次折返时篱笆的虚掩方向忽然改了,改后那道门前留着一串不属于他的湿脚印。
- 若林恩尝试用往日遗念回溯这栋院落,则影像在他意识里显出一层陌生画面,画面里有个同他面貌相似的远端身影背对着他在沏茶。
- 若林恩在塔内书架上拿了一本非地狱文字的书翻了两页,则她注意到他的视线,隔天那本书被换成了一个他自己写过的故事。
- 若林恩在月儿兰花园里深夜独自坐,则花香让他短暂回到了一个不属于这场轮回的记忆,记忆里有个蓝发女孩在喊「徒儿」。
- 若林恩把破碎戒指套在自己手指上绕着花园走了一圈,则戒指的内侧在那一圈里多了三道浅浅的刻痕,刻痕的形状是三笔不属于已知文字的符记。
- 若林恩每晚在篱笆前对系统空间大喊左左,则第七天夜里那枚乌鸦臂章突然在他掌心亮起半秒,亮过的臂章里传来一声细若蚊鸣的抽泣。
- 若林恩在软禁期间不吃不喝静坐三天,则她在他房门外留下一杯温热的茶和一块布巾,布巾一角用针脚绣了一朵小小的、半开的白花。
- 若林恩在老人再来时先问「你就是引路者吗」,则黑气在那一瞬出现一次不属于剧本的收缩,收缩里他听见了一个极轻的「对」字。
- 若林恩对老人说「破局之道我已找到」,则老人的拐杖在沙地上敲了三下,敲下的三处土坑在他离开前自行愈合,愈合纹路恰好拼出一个无瞳印记。
- 若林恩对老人回话「她等的人可能就是我,我只是没记得」,则老人沉默片刻后低声回答「那你就替那个被遗忘的人,先把她救赎一次」。
- 若林恩在戒指与桌面刻纹对照时故意遗漏一格,则桌上的花纹在那一秒自行落款一颗不属于这次召唤的旧纹,旧纹方向指向蓝星海底。
- 若林恩在她再次现身时主动问「你能不能告诉我那个人的眼睛是什么颜色」,则她答了一个林恩没听过的色名,那个色名在琥珀和黑之间。
- 若林恩在混乱色彩再度涌现时朝她伸出一只手,则那道色彩在他掌边凝住了三秒,三秒后,塔外的狱卒群整齐跪下了一头。
- 若林恩在软禁期间用血在自己手臂刻一道无瞳小阵,则那阵纹在第七天夜里亮了一次,亮时塔内某个从未展于人前的门锁轻轻动了一寸。
- 若林恩在软禁最后一日对她开口「我至少能答应你不逃」,则她站在窗前的身影顿了一秒,随后她把一双原本不打算给他的银质茶匙放在了桌上。
- 若林恩在戒指纹路与花园中心对齐时跪下来用手贴了贴泥土,则土里渗出一阵不属于这个轮回的暖意,暖意在他掌心写下第一句谜底。
