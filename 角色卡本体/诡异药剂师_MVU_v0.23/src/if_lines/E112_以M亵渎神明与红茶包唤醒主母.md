# E112·以M亵渎神明与红茶包唤醒主母·if线

- 若林恩在巨头咬合期间持续以M灌入堕天使手臂直至对方弓身抽搐，则恶面挣脱力道锐减，利维坦最后一根神经链条提前崩断，自爆节奏被读者观众先一步听出不祥。
- 若林恩只灌一发Max以M便立即松口，则堕天使娇喘未达清醒阈值，恶面仍处浑噩状态，主母善面唤醒难度上升，需另寻信仰心锚。
- 若林恩在第一发以M后立即追加第二发并顺势将堕天使手腕扯向自己胸口，则手指痉挛沿小臂向上蔓延至肩胛，恶面本体在裂隙内发出羞怒低吼。
- 若林恩对着堕天使耳边故意复述她的浑噩呻吟，则恶面羞耻心压过杀意，强行分出一丝意识抵抗以M冲击，主母善面残留意志被牵动。
- 若林恩在自爆前一刻以额头抵住堕天使额头并直接喊"主母"，则双魂共振，金色神光自眉心溢出，堕落镇压力度增强。
- 若林恩在松口时不顺势由利维坦自爆掩护，而是瞬移抱住堕天使腰部向下坠落，则堕天使羽翼本能收拢将二人裹作茧，一同卷入信仰法阵的祷告潮。
- 若林恩在坠落途中改用触手撑开堕天使双翼逐一撕扯，则十二翼翎羽脱落如雨，全城信徒目睹主母受辱，信仰心锚反而被愤怒凝聚得更粗壮。
- 若林恩改喊"主母当年您泡给我的那杯红茶是我一生最耻辱的口粮"，则社死方向调转，善面被自揭黑历史刺得当场失控扑近林恩。
- 若林恩改喊"主母的红茶包被我炼成了解咒药剂"，则善面把"被亵渎的私物"瞬间解读成"被珍藏的体温"，神光中掺入一缕不易察觉的粉色。
- 若林恩只是狂喊"主母我错了"而不点明红茶包，则信徒们一头雾水，信仰法阵共鸣衰减，善面苏醒窗口被拉长。
- 若林恩信仰宣告时刻意沿用315博士的"对母神那种事"口癖，则博士在利维坦血肉内目眦欲裂，临死前最后一丝精神力反向助推主母憎恶投影。
- 若林恩以触手在胸前拓印出一盏红茶茶杯纹路并高喊其名，则社死效果举重若轻，善面被这种不动声色的亵渎气笑，主导权争夺战平添一层人味。
- 若主母善面苏醒瞬间林恩立刻以触手将小小、黑弦月、喵喵、银色幻想护入利维坦残骸，则主母亲眼目睹"信徒以外的人也被他护住"，善面对林恩"守序善良"的判断重新加盖印章。
- 若林恩在主母金色神光扫过瞬间主动闭嘴不再亵渎，则善面羞怒值减半，恶面留下的"死亡名单"必杀令语气减弱一个层级。
- 若林恩在神光扫过后补一句"主母您泡的红茶真的不错"，则善面在金光中嘴角抽动，必杀令改写为"永生永世，不得超离主母视线"。
- 若艾雯爵士在林恩信仰宣告时同步注射自己血液入法阵增幅，则全城祷告增幅三倍，主母善面苏醒更彻底，恶面被压入裂隙最深处。
- 若315博士在自爆前一瞬掏出备用利维坦神经链条把林恩拖入爆炸核心，则二人同坠，主母金色神光必须分出两缕分别救人，恶面获得一丝反扑空隙。
- 若小小加大全力张开嘴却没接住黑弦月，则黑弦月在下坠途中以琴音定住自己身形，落地后与小小之间多一段"你不接我"的别扭对话。
- 若小小在坠落着陆时把林恩整个含在嘴里不放，则信徒们在信仰法阵直播里看到"主母信徒被巨口少女叼走"的画面，主母羞怒值再度+1。
- 若利维坦自爆时林恩主动用巨头肉身挡在堕天使背后，则爆炸冲击波在林恩背脊撕开深深血沟，善面亲眼目睹，神光里掺入一丝不易察觉的颤抖。
- 若林恩在坠落中抓住一片堕天使脱落的黑色翎羽并贴在自己心口，则翎羽与林恩体内积攒的以M产生共鸣，系统提示"信物锚定：主母恶面残存意志追踪开启"。
- 若小小着陆砸出巨坑时坑洞正好对准欲望母树方向，则后续E113巨像红芒爆发路径被地形改写，红芒从坑洞中心照射而出。
