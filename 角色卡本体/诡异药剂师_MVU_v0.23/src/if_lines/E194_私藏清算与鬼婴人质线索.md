# E194·私藏清算与鬼婴人质线索·if线

- 若林恩在大舌头第一次吐出一百多枚骷髅币后就收手不再追问私藏，则那一千两百一十枚隐秘小金库继续埋在地窖底部，事件以变形（小金库未曝光）收束。
- 若林恩改要黑颅币、按新比率折算后让大舌头再吐一轮，则折算加死神价差后实际只多出三十枚，事件以变形（币种替换）收束。
- 若林恩把空药剂瓶改踢进信使嘴里而不是地窖，则信使被当场喝住，供出与眷者的接头坐标，最终教堂位置提前一秒锚定，事件以变形（直接供地）收束。
- 若林恩在「算术不好」辩解那一秒让左左俯身帮大舌头把账重新清点一遍，则主仆共治轨道首次展开，事件以变形（账目共治）收束。
- 若林恩以巨像之心身份正面处决大舌头立威，则他死前喊出最后一份名单，事件以变形（结忠拱手）收束，全场锁具当夜被他旧部解开。
- 若林恩在大舌头呸出那一枚后立刻用咒瞳反读他心声，则「还卖了血锯」这条事实先一步浮出，事件以变形（读心逼供）收束。
- 若林恩在两名血肉队长被血畸藤绞杀前就起步离开现场，则原作藤蔓二次开花场景取消，事件以变形（缺杀另结）收束。
- 若林恩让左左在大舌头耳边不停轻吟咒纹细丝，则他的五感紊乱程度以倍数增强，「小呀哒」关键字被提前叫出，事件以变形（关键字提前）收束。
- 若林恩故意不关心小呀哒的下落直接清理完就走，则大舌头当晚偷偷放一条乌鸦传讯给眷者，事件以变形（鬼子线索被藏）收束，人质营救节拍延后。
- 若林恩在清剿完小金库后不立刻出门而是彻夜点钞，则他的临场反应被现场队员议论一整夜，事件以变形（主人清账怠战）收束。
- 若林恩把大舌头交代的「小呀哒」线索直接转给艾雯爵士大群征求参谋意见，则全家公开围观，事件以变形（全家旁听）收束。
- 若林恩让喵喵同行一同封锁教堂，则这只死灵猫贴着屋顶尖声锐啸，眷者被迫分兵应对猫形耳语，事件以变形（双证官入堂）收束。
- 若林恩用那颗金牙做咒瞳透镜提前扫一遍教堂外围，则血迹气味被精确锁定，事件以变形（侦察入微）收束，眷者战力排布提前曝光。
- 若林恩派左左伪装成信使入教堂和眷者对话，则她在引荐阶段就被识破半句、被迫加一层护配警，事件以变形（假信使暴露一线）收束。
- 若林恩在教堂外围临走前埋一包摄魂花粉，则眷者当晚跟着花粉吸了一口，护卫队形被慢慢麻醉，事件以变形（花粉压制）收束。
- 若林恩让大舌头一同前往教堂当面作证，则眷者看见小宝贝与主人同行，事件以变形（内护法失衡）收束，背叛指数上涨一格。
- 若林恩给大舌头披上一件燕尾服当活体盾牌，则他首次硬挺起脊梁扛了一整段入场步伐，事件以变形（小宝贝翻身）收束。
- 若林恩主动掏出巨像之心面配合巫族咒术在教堂外围锁一圈，则眷者首次目睹根源列席现场，教堂护卫体系被强行压成一团，事件以变形（根源到场）收束。
- 若林恩把私藏的一千两百一十枚骷髅币折算成黑颅币交给白夜做火箭筒配合金，则白夜扛炮上场那一秒，原作「你这气生的有点持久啊」直接放出，事件以变形（根源开场）收束。
- 若林恩进驻夜医大军封锁教堂但不让主炮出场，则眷者认为「被包围的队伍不能忍受」，事件以变形（眷者硬抗）收束，教堂提前出手反抗。
