# E339·错误衔尾与大君复苏·if线

- 若林恩在法阵中心主动接受错误力量灌注，则黄沙在他血管里奔涌，他的左眼率先映出漆黑，系统首次记录【复苏度】但身份栏空白。
- 若林恩用小丑的八音盒作为施术媒介，则音栓被黄沙腐蚀，曲调走调成古老哀歌，小丑第一次因恐惧而跪地。
- 若林恩在号角响起前主动切断与黑弦月的灵魂线，则她的逆转停滞在半途，但小丑无法再用她作为情感杠杆。
- 若林恩把左手按进法阵纹路任由错误力量改写印记，则烙印在他掌心形成一枚反向衔尾，从此他能感知到另一端的波动。
- 若林恩在号角声抵达现场时选择原地坐下闭眼，则狱卒群的征召无法锁定一个「拒绝参与」的目标，战争号角在他身上失效。
- 若林恩用血在黄沙上画出乌鸦臂章的图案，则图案在沙面上自燃，火焰中浮现的不是旧神而是某个被遗忘的名字。
- 若林恩对错误衔尾喊出「我认得你」，则黑蛇在瞳心停顿半秒，那一瞬的迟疑足以让他夺回半秒的身体控制权。
- 若林恩在被灌注时主动回忆左左的笑容，则情感冲击让错误力量的侵蚀出现裂缝，但裂缝中渗出的是更古老的麻木。
- 若林恩把黑弦月的尸体抱在怀里跳入法阵中心，则逆转被强行续写，她的伤口愈合但灵魂回返时带回了不属于她的记忆碎片。
- 若林恩在号角声里朝最近的狱卒掷出一支镇静药剂，则那名狱卒的光幕出现一次闪烁，征召队列出现短暂的空档。
- 若林恩用往日遗念投影出黑弦月生前的最后一笑，则影像在黄沙中凝固，错误力量的侵蚀被「美」的出现短暂迟滞。
- 若林恩在复苏度显示47%时主动对系统说「把数字藏起来」，则界面空白，但他从此无法确认自己正在被哪一股力量占据。
- 若林恩在战场上用牙齿咬破舌尖朝错误衔尾喷血，则黑蛇的轮廓被血色污染，它的侵蚀方向出现一次不属于剧本的偏移。
- 若林恩让左左在系统空间里大声朗读童话，则咒体的声音穿透屏障，他被灌注的记忆洪流中出现了一页不属于轮回的插画。
- 若林恩在号角声里主动朝血肉支配者的位置走去，则他的足迹在黄沙中留下燃烧的印记，每一步都在改写战场的重力。
- 若林恩在错误力量占据身体时主动微笑，则那张面容上的表情让旁观者分不清是臣服还是嘲讽，小丑第一次无法解读他的表情。
- 若林恩用时间魂媒在法阵中心点燃一盏灯，则灯火在黄沙中摇曳，被定格的时间让错误力量的侵蚀出现一次可观测的暂停。
- 若林恩在复苏度34%出现时对系统说「把47%那个人叫出来」，则界面无回应，但他能感受到两股力量在体内形成了某种制衡。
- 若林恩在战场上用主母的黑羽作为笔在沙上写字，则字迹被黄沙吞没，但写下的内容在视界之主的记忆里留下一道灼痕。
- 若林恩在号角声里选择原地躺下装死，则狱卒群的征召无法识别「已死之人」，战争号角在他身上出现一次判定混乱。
- 若林恩在错误力量灌注时主动背诵自己作为药剂师的配方，则理性认知让侵蚀出现一次智商上的迟滞，但配方本身被污染成禁忌知识。
- 若林恩在黑弦月逆转停滞时主动吻她的额头，则她的身体出现一次不属于剧本的颤抖，但灵魂回返的路径被这个吻改写。
- 若林恩在战场上把乌鸦面具戴反，则面具内侧的古老刻痕对准他的眼睛，他第一次看到了面具主人曾经见过的景象。
- 若林恩在号角声里用血画出一个反向的八音盒，则小丑的玩具面容第一次出现近似「愤怒」的表情，但祂无法阻止图案成形。
- 若林恩在复苏度47%时主动对错误衔尾说「你不是我要等的王」，则黑蛇在瞳心收缩，那一句话让侵蚀出现了一次可观测的退缩。
- 若林恩在战场上用仅剩的体力朝黑弦月的方向竖起大拇指，则她的尸体在姐妹怀里微微动了一下，但没有人知道那是肌肉痉挛还是灵魂回应。
- 若林恩在号角声里主动切断与左左的最后连接，则咒体在系统空间里突然安静，她的咒纹在那一刻变成了纯粹的黑色。
- 若林恩在错误力量占据身体时主动朝自己的心脏刺入一支解毒剂，则剧痛让他夺回半秒控制权，但解毒剂本身被错误力量转化为剧毒。
- 若林恩在号角声里对最近的狱卒说「你们的主人也只能这样了吗」，则那名狱卒的光幕出现一次信仰动摇的波动，但波动很快就被抚平。
- 若林恩在复苏度34%出现时对系统说「把47%和34%合并成一个名字」，则界面空白，但他从此能用一个新的代号来称呼体内的两股力量。
