# E547·身份暴露与三招悬停·if线

- 若林恩在齐攻起势黑巾未破时主动自揭身份，则「两个月单机杀遍全地狱」真相由自己口中落地，怒火受控不外溢。
- 若林恩让左左在强弩之末拒绝抢控而非涕泪欲夺，则精神内部戏被弱化，林恩独立硬撑的画面更纯。
- 若林恩在「教你们入门」台词前稍作保留不显化元素系法则脉络，则馈赠的范围减序，勇者门槛变窄。
- 若林恩在逆向显化法则时故意把血肉与生命系展示得模糊，则相关根源的感悟窗口未开，求法中心化的后来路线被裁剪。
- 若林恩让利爪撕黑巾时同时暴露出左臂的左左纹印，则身份暴露附加「左手挂件」画面，神秘感多一层杂味。
- 若林恩让银色幻想在坠落接怀时不化巨龙而是以本体现身，则掩护形态缩小，伤员的坠落速度未必能稳接住。
- 若林恩让接坠由巨像代行，则银幻继续观战席上的空洞模式，后续反噬抢救链条缺少一环紧迫感。
- 若林恩接坠后马上召原子机械把身躯披覆以防被看清脸，则身份暴露的窗口被遮盖回一半，公开审判的准备时间延长。
- 若林恩在昏迷前喃喃「终于回家了」时不吐露出声，则心声留在内部，精神层的「回家」意象外泄不到现场。
- 若林恩在精神层不与神王对峙而直接追问「小心奈奈子」含义，则三招赌约被跳过，命运神的获取路径改写。
- 若林恩在三招赌约中只用初诞者之力一系而不化多重法则，则他受到的排斥反馈更单一，「万物排斥」的恐惧稀释。
- 若林恩在第三招失败时选择不接「再来」而默认认输，则「被世界排斥」的精神体验不再触发，三招赌约以平局收场。
- 若林恩回答初诞者定义时漏掉「无序深空第一缕有序」，则他与神王的「你我他」同魂对话失去基础，赌约破裂。
- 若林恩被问「你是吗？」时不回答「你、我、他都是」而回避，则神王的警告「小心奈奈子」缺位，精神层收束路径变更。
- 若林恩让神王转身时不再远走而是散去化作黑光注入他体内，则他获得一份弱化版命运神之力，同时也继承遗留业障。
- 若林恩在精神层接受神王「故乡嘱」时主动许诺，则他背上无法兑现的精神债，回归现实后的赎罪步伐被加压。
- 若林恩最后警告「小心奈奈子」之前先吐出人偶家名字完整，则后续他对人偶家的态度将被警戒而非合作。
- 若林恩让左左在黑色精神层显形为实体萝莉搀扶他而非只在脑内发声，则他回归现实的路径被同伴实体陪伴。
- 若林恩在回归现实后第一时间自设梦境锁防止自己再度掉入精神层深处，则后续昏迷被切成可控的浅睡，醒转窗口缩短。
- 若林恩让利爪撕黑巾前自己配方修复脸部的伤，则「狂笑狂战」画面更完美，公开冲击的整体强度被削弱。
- 若林恩让见习夜医男孩在身份暴露瞬间没掉铁剑而非当啷落地，则他拔起的剑成为新一段誓约的信物。
- 若林恩在昏迷之后让左左主动抱脸虫咬鼻先于他自己醒，则喜剧的节奏依旧，但「自己终于回家了」的沉稳被打断。
- 若林恩在「你我他同魂三意志」台词后多加一句「但我们不相爱」，则分裂的伤感被强调，神王的悔意深化。
- 若林恩把精神层的法则失控显化为身体物理裂解而非烟雾散逸，则醒来的伤势对外更具说服，公开审判时同情分上升。
- 若林恩在黑巾撕破前主动用死亡法则染黑自己整张脸以遮，则身份暴露时刻延后，他选择暴露的余地更多。
