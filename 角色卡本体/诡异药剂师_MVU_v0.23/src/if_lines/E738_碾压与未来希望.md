# E738·碾压与未来希望·if线

- 若林恩在双手握刀、身后浮现出亿万道与他一同举剑的金色众生虚影时，迎着狂吼「林恩！我要你死！！」的魇王正面挥出第一刀，则整个神界将在这一击的余波中彻底崩解，化作漫天飞舞的绚丽丝带与历史烟花。
- 若林恩在神界大葬的黑暗中心赤裸上身、眼燃黑火踏空而上时，一步一破灭地主动撞入魇魔最密集的战团，则他刀刃上的黑火将在无声无息间烧穿魇魔引以为傲的无序腐化，短短数息之内便将三十尊魇魔屠戮过半。
- 若林恩在如鬼魅般闪现至骇然回首的魇王面前、单手如铁钳般掐住魇王咽喉将其高举半空时，将黑火直接打入魇王的核心本源锁死其全部力量，则这尊不可一世的魇王只能在极度的恐惧中徒劳挣扎。
- 若林恩在掐着魇王咽喉宣告「我会一次次地斩你，我会告诉你永恒带给你的不仅仅是生命，也是宿命，我会一次次杀你，杀到你厌恶这永恒，杀到你每一次见到我，都如蜉蝣见苍天」时声音轻得像耳语，则黑火燃遍全身将魇王烧作飞灰的那一幕，会成为无序深空所有魇魔永恒的梦魇。
- 若林恩在全灭三十尊魇魔、收刀入鞘向全宇宙宣告胜利后，婉拒了前线各大军团归来庆祝的请求而选择留在星空喘息，则他既能避免在万众面前暴露黑火持续燃烧的巨大消耗，又能把最纯粹的胜利喜悦留给全宇宙信徒。
- 若褪去了冰冷机械武装、终于恢复温热血肉之躯的银色幻想（智械小姐）第一个从星空冲来、不顾一切地扑进林恩怀中紧紧抱住他时，林恩也用力回抱住她温软的身躯并轻声说「欢迎回来」，则智械小姐会将脸深深埋在他胸口，十余年沉睡的思念在这一刻尽数融化。
- 若彻底褪去死亡法则负面影响的康斯坦丁船长含笑走上前，林恩对他笑着捶了一下肩膀说「船长，让你久等了」，则这位老船长会爽朗大笑，黑夜城最初的顶梁柱们终于再度齐聚。
- 若林恩在看见自缚天使（主母）、艾雯爵士、洗去往日火辣化作自然精灵模样的欲望母树，以及被巫神特意从地狱带出来的小小全员赶来时，主动蹲下身把欢呼雀跃的小小抱起来转了个圈，则战场上残留的肃杀之气会被家人的欢声笑语彻底冲散。
- 若林恩在拥抱完小小后走到艾雯爵士面前，看着兄长脸上那道利爪疤痕，郑重地说出「谢谢您，艾雯大哥」并露出自织梦死后的第一个真正笑容，则艾雯会眼眶含泪地伸出拳头与他轻轻相碰——「我们一定可以的。」
