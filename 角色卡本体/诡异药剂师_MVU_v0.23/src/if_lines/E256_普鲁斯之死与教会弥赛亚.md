# E256·普鲁斯之死与教会弥赛亚·if线

- 若林恩在普鲁斯刚张开手臂扑向弥赛亚那一秒就从教堂顶梁无声落地，则那记火焰踢落点改在普鲁斯的后背而非脸颊，教徒的鼻梁骨与自尊同时碎成两截。
- 若林恩故意不进场、只在教堂外听完整出丑剧，则弥赛亚必须独自挥剑斩断与三哥十年的纽带，普鲁斯手腕上的血痕再深三寸，她的崩溃从"被迫被救"变成"被迫自救"。
- 若林恩让左左先一步在教堂角落显形，则普鲁斯的痴心妄想被一道咒纹锁住双臂，他在林恩到场前就先吃了左左一记耳光，弥赛亚第一次亲眼看到"主人的左手"在自己之外还能为谁出气。
- 若林恩朝普鲁斯叫嚣"你这样的废物根本不配心疼她"，则那发子弹不只命中额头、同步穿过他背后祭坛上供奉百年的圣像，教徒信仰与帮派情面被一并打碎。
- 若林恩没有对着弥赛亚说教、只是面无表情地把尸体扛上肩，则她的世界观坍塌在静默里完成，没有"善良"台词缓冲，她在整夜失眠里独自得出"他不是恶魔"的结论。
- 若林恩在弥赛亚掩面大哭时俯身用指尖勾出她的一滴眼泪收进玻璃瓶，则那支"恒焰世纪之泪"标签的药剂在他背包里第一次出现，配方又多一条诡异稀有材料。
- 若林恩把大段"什么是善良的人"换成一句硬话"你活下去才有机会继续做错事"，则她的哭声卡在喉头，面具碎裂得干脆利落，重建却相当迅速。
- 若林恩故意把"你以为他们值得"的质问改成一支部落恶灵显形药剂公开播放，则普鲁斯过往的私心作妖画面像电影一样在她眼前重放，世界观坍塌的证据变得铁一般难以反驳。
- 若林恩在递药剂时绕到她背后从脖颈吹了一口气，则她接药的那只手一颤差点摔地，普鲁斯死亡阴影里第一次混进一缕被她死死压住的羞愤。
- 若林恩对尸体处置改成"挂在教堂外示众",则次日隐修会全员得知普鲁斯死讯并指认她与恶魔合谋，弥赛亚在"失去组织"的痛苦中更早接受"阵营选择"教育的下一课。
- 若林恩不亲自处决而是交枪给弥赛亚"你来抉择"，则圣光剑刃在她手里颤了整整一分钟之后终于落下，她拿到的不是"别人的死讯"，而是"自己亲手沾血"的觉醒仪式。
- 若林恩处决时故意喊一句"这一枪是替我自己老子挡的"，则弥赛亚在悲伤里多听出一份诡异的家庭暗示，她开始第一次好奇这位"恶魔"的童年。
- 若林恩不赠药剂，只在离别时手指作创造状，则她的烧伤需由梵蒂冈医术自理，伤愈过程留下一枚暗金色奇纹疤痕，这条疤痕后续成为她被问话的最大破绽。
- 若林恩把那支药剂直接倒一半在掌心、湿哒哒抹在自己手背上给她演示"这样涂"，则弥赛亚得学一个暧昧动作但没有解药，她在午夜面对镜子时第一次理解"他的路"走得有多湿。
- 若林恩在告别时落地前顺手把那几只乌鸦唤回来立在教堂尖顶，则弥赛亚窗外的每一只黑鸟都成为"他派来的眼睛"，她的心理防线被这层持续注视再磨一层。
- 若林恩离开后留字条"撒谎是走向这个世界的第一步——下一句等你想通",则那瓶药剂被她摆在床头军刀旁，她在噩梦惊醒的夜里下意识先摸瓶子再摸军刀。
- 若林恩在处以击毙前一天就把普鲁斯的恶念证据放在她床头，则她第二天看见普鲁斯主动出手时不再错愕，子弹命中自己挚友的感触有整整十二小时的缓冲，她的世界观坍塌延后，但成长的痛更绵长。
- 若林恩要求她在处决后亲手合上普鲁斯尚未瞑目双眼，则她指尖的第一缕"陌生人的冷"成为她的成年礼，"好朋友之间的裂隙"被以同义词"朋友的死亡"重新打开。
- 若林恩把她整夜未眠的崩溃录成音频发回指挥部归档，则她成为事件档案"绝望片段 #001"的原声对象，万机之神在自留档里第一次为人类的哭泣按下保存键。
- 若林恩处理完尸体后在她身边默默站二十分钟一言不发，则二十年的保护壳被无声的陪伴从内膛缓缓熔穿，她主动开口的第一句话不是质问而是道歉。
