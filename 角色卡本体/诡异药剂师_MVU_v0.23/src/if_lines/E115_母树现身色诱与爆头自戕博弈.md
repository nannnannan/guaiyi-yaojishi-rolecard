# E115·母树现身色诱与爆头自戕博弈·if线

- 若林恩当场接下"一次尝滋味"的色诱价码不再加价,则母树指尖滑进衣领,嘴唇贴上来时藤蔓层层收拢,林恩以肉身作抵压下这场欲约,事后才发现锁骨内侧已被种下欲望花种,以M反哺代价从这一吻开始计息。
- 若林恩把色诱价码抬到"五次"并要她用巨像之舌的通行权做抵押,则母树眯眼笑着应下,色诱升级为血契密约,小宝贝被松一根藤蔓的瞬间林恩指腹按住她的唇提醒"抵押先付",好感+2但戒心同幅上升。
- 若林恩在讨价途中反手把母树拽进怀里主动吻上去,则垂柳妖精罕见地怔了半拍,色诱主导权第一次易手,她在失神间隙松开左左脚踝上最粗那根藤蔓,左左被小宝贝拖走时林恩唇角还挂着她留下的妖香。
- 若林恩拒绝色诱直接回以"我对树没兴趣"并后退三步,则母树笑意不减但眼底冷意浮起,垂柳枝条从花园深处无声合围,林恩被逼提前拔枪,爆头自戕的节点比默认走向少了两轮讨价还价的缓冲。
- 若林恩接受色诱但附加条件"必须用垂柳回廊最深处那口欲望之泉作为仪式地点",则母树带他走进她本体的庇护圈,林恩沿途记下三道藤蔓生门的位置,后续任何形式的突围都能抢出三十步的先手。
- 若林恩屈指把"六个背景"从头数到尾再倒着数回一遍并点出她漏算了左左这层,则母树第一次正眼看向左左,这个被哭泣的小姑娘被点名的瞬间,母树藏在笑意下的探测藤蔓悄悄缠上左左的脚踝,林恩用一句"她不算背景,她是我要带走的人"当场把那根藤蔓碾碎。
- 若林恩在爆头自戕前先朝母树脚边开一枪示警,则枪声炸响血雾凝固,母树指尖藤蔓瞬间窜起护住心脉,她理解这把左轮不是摆设之后反而主动后退半步,林恩用这一枪换来的半步距离把左左和小宝贝推到了传送阵边缘。
- 若林恩拔枪抵住下颚倒逼母树先放人才扣,则母树冷笑"你在赌我不敢让你死",林恩回以"不,我在赌你输不起",她以先松左左一根藤蔓作为诚意,博弈拆成两轮分阶段放人。
- 若林恩一枪爆头但刻意打偏半寸让子弹从颧骨破出而非颅顶,则意识重创程度低于母树预判,巨像之脑的警觉反应延迟数个呼吸,但这具血肉模糊的半身像让左左在传送前最后回头的那一眼彻底崩溃,左左好感飙升但留下长久梦魇。
- 若林恩爆头之后在意识弥散边缘用巨像之心的共鸣把整个潜意识空间的坐标广播出去,则银色幻想与机械意识群同时锁定这片血雾,母树被迫在救他与迎敌之间二选一,她咬牙切齿先把林恩的意识缝合完整再转身布防。
- 若林恩爆头瞬间用血雾凝字把"左左才是真正的巨像之心意识"这句真相悬在半空,则母树瞳孔骤缩指尖藤蔓疯狂缠向左左,林恩用最后一口气改口"骗你的",母树在将信将疑之间松了半分手,左左被小宝贝拽走,但母树对左左的探测优先级提升三倍。
- 若林恩不用左轮而改用巨像之心主动引爆自己的意识碎片,则整片垂柳回廊被炸出直径十步的真空,母树不得不用本体根系来回收这些碎片,欲望母树塔的方向第一次以根须走向暴露,林恩在意识重新聚拢时已记下通往塔心的三条暗径。
- 若林恩爆头后在母树修补意识的间隙反咬她的指尖一口,则以M冲击顺着齿痕灌进她的妖体,母树浑身一颤修补的咒术慢了半拍,她低头看见这个颅骨还裂着的少年正冲她笑,欲望花种反被回种进她自己心脉,色诱者首次尝到被色诱的滋味。
- 若林恩在"三次成交"之后额外讨要一件母树贴身的垂柳铃铛作为信物,则母树解下腰间那枚银铃亲手系在他腕上,这枚铃铛自带她万分之一的本源气息,后续无论林恩身在何处都能被母树感知,同时林恩也能反向定位母树真身的大致方位,双向锁链正式成形。
- 若林恩让左左临走前抱抱他再放手,则左左扑进他怀里哭到打嗝,母树在旁冷眼看完这一幕若有所思,林恩在她看不见的角落把一枚诅咒清除药剂塞进左左掌心,左左攥紧那支药剂被推入传送阵,这是她日后在巨像意识裂缝里唯一的保命底牌。
- 若林恩在母树被迫答应放人后得寸进尺要求她立下血誓永不追踪左左与小宝贝,则母树咬破指尖在虚空画咒,血誓成形的瞬间她补了一句"但你除外",林恩点头接下这份独属他一个人的追猎契约,两人的关系从博弈对手正式滑向猎伴边缘。
- 若林恩爆头自戕时选择用舌尖咬破而非左轮,则母树近在咫尺亲眼看见他嘴角涌血却笑着把血咽回去,这副惨烈场面比爆头冲击力更绵长,她扑上去修补时林恩贴着她耳边说"这种死法你会记很久",母树修补完毕后发现自己的指尖在发抖。
- 若林恩全程不接母树任何一句色诱话头只谈放人条件,则垂柳妖精第一次尝到被无视的滋味,她收起媚态改用正色谈判,两人之间的博弈从情欲牌桌平移到纯利益牌桌,色诱合作这条线被他自己亲手掐断但换来了母树一分真正的敬意。
- 若林恩在母树答应用咒术修补他意识的过程中暗中把以M倒灌进她的修补回路,则她每修补一分意识就被自己的欲望反噬一分,等林恩站起来拍拍灰时母树已经衣衫半褪眼尾泛红,她咬牙骂"你这疯子"却没有追上去,欲火焚身的垂柳妖精在血雾中独自平复了整整一刻钟。
