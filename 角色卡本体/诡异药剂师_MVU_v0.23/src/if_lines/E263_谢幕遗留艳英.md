# E263·谢幕遗留艳英·if线

- 若林恩在白发老妪嘶喊「她不能离开」时直接出手制服她，则她怀中善念碎片受外力震荡出现裂纹，小锦碎片补全度被锁定在99%，事件以变形（强行介入碎片）收束。
- 若林恩隔着路口距离用咒瞳扫描她而不踏入她禁区，则她察觉被窥视后立即把火药枪上膛，事件以变形（远距离对峙）收束，火药枪击发的情况下事件卡入警局处理程序。
- 若林恩让林樱先开口询问「老奶奶，您还记得晓晴阿姨吗」，则老妪当场泪崩，根由绕一圈，事件以原作路径收束但林樱首次获得「百年执念见证者」标签。
- 若林恩在老妪掌心握住小锦骸骨瞬间低声说「她等这个拥抱等了一百年」，则她把骸骨又抱紧一寸，事件以原作路径收束且结算画面多一帧温情特写。
- 若林恩在她拉棺离去的背影前默不作声也不递任何东西，则她提灯走下山路时未回头，事件以原作路径收束但「未践行告别」氛围被记录。
- 若林恩当场提出为她伐一口金丝楠木棺椁以表敬意，则她停下回头看他一眼但仍坚持用自己带来的旧棺，事件以原作路径收束且她记下「这个中医懂礼数」。
- 若林恩代替她伸手点起那盏百年灯芯，则她首次接受「林恩之手」帮扶,事件以原作路径收束且她的灯笼在世界书标签追加「由林恩点燃过」。
- 若林恩在她拒绝复活提议时改用「让她以善念形态短暂回人间一日」，则她依旧摇头,「死了就是死了，活了就是活了」原句落地，事件以原作路径收束且该台词成为标签。
- 若林恩在她体内取出善念碎片时用灵能压制她的生命力流逝速度，则她的寿命凭碎片化吸收多延了一日，次日天晴时祁镇上空多了一只晴空布谷，事件以原作路径收束但延期一天。
- 若林恩在她拉棺而去的山脚下提前放置一辆轮椅代步，则她路过时未接受但仍低声说了句「谢谢你，孩子」，事件以原作路径收束且「被婉拒的轮椅」成为世界书道具。
- 若林恩在她背影消失前用往日遗念把她的一生独立播出给血衣看，则血衣亲眼目睹百年守约全程，事件以原作路径收束且血衣对「凡人」重新定义。
- 若林恩在碎片注入小锦眉心时用单分子剑划开自己指尖加一滴精血同流，则小锦沉睡中的手指轻轻颤动一根，事件以原作路径收束且小锦的初次苏醒预兆往前提早晚各几句。
- 若林恩让白夜以最高指令调动魔都殡葬专家协助棺椁运输，则她依旧坚持亲手拉棺，事件以原作路径收束但白夜的「林恩式凡人之礼」认知得到加强。
- 若林恩在她最终消失夜幕的瞬间主动启亮咒瞳目送她走完最后一段路，则他在灵瞳视界里看到她与孙女并肩走完山路，事件以原作路径收束且追加「他替她送终」的精神锚点。
- 若林恩把碎片补全后的瞬间顺手启动【灵能反馈】扫视祁镇全境，则死气消散的画面提前在他咒瞳中呈现，事件以原作路径收束且「天晴」画面由他提前感知。
- 若林恩让林樱现场以纸笔速记艳英口述百年守约全记录，则一份「凡人守约百年全书」被写入系统资料，事件以原作路径收束且该文档成为日后隐修会道德模板。
- 若林恩在她倒地之前主动启动【延寿之术】试救，则她反向摆手「让我以我自己选择的方式走」，事件以原作路径收束且「延寿遭拒」记录成立。
- 若林恩在她黎明的最末一刻陪她躺在山路上看天光初现，则她笑着离开人间，事件以原作路径收束但结算画面多一帧「林恩陪她命运闭环」。
- 若林恩在她睡着的棺椁旁悄悄放下一串岁月流年的佛珠，则次日祁镇山路上多一件清晨被发现的小物件，事件以原作路径收束且该物件成为世界书纪念道具。
