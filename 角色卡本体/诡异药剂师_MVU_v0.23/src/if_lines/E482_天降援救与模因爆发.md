# E482·天降援救与模因爆发·if线

- 若林恩掷咒瞳骰子数字不是3而是6，则泰坦巨躯会完整复现、灭绝者利爪被单手撕碎，但林恩本体三十秒后会陷入无法自主退出的泰坦合体反噬期。
- 若林恩用三叉戟横挡利爪时先用初诞者之力在刃尖镀一层破银，则刃下不只是拆开巨爪、还会在灭绝者前甲上烙一层「不可愈合」的夜医灼痕。
- 若林恩让夏娃拖拥星者进入的不是走廊而是一座现场织成的血管梯形迷宫，则后续「猩红血管＋铁锥」双打击就少了预设舞台，两根源只能临场应变地冲。
- 若林恩让巫神头颅破墙而入时先打向银发少女而不是灭绝者本体，则她会先掐住伪身、再给灭绝者一锥，林恩本体的救援印象在她记忆里被扣掉一拍。
- 若林恩现身银发少女面前时戴上乌鸦面具，则她会认出面具但看不见脸，「他被拉来的瞬间我认不出他」这件事会成为她后续脑中放不下的疙瘩。
- 若林恩把她背出废墟时让她胸前被她自己的装置烧焦的那一片朝上，则她全程能感受到自己那片缺损被风刮、而不是被他手心遮，这一刻她第一次感到自己被允许暴露破绽。
- 若林恩单膝蹲下、手按她胸前施术时多留半秒不撤，则灵能会顺着胸口往数据核里再探一层，他会被这层挖到万机遗产组件的残影，但伪身表情会出现一秒短暂的薄红。
- 若林恩问她「涂鸦你收到了吗」而不是让她自己出示，则她会抬头半秒，先看他眼睛才举起数据绘、两个人的关系在这一秒被她偷偷改了一格。
- 若林恩把她的「英雄救美落空」玩笑接住、改成「我不是英雄，我是来讨recall」，则她会愣一下，然后无表情地告诉林恩「recall找不到我，」——后续启程时林恩记得到她多留了一句真相。
- 若林恩在她给逃生倒计时「快爆炸了」时主动说一声「我数到三十你才爆」，则她会停一秒、然后把倒计时设置延后三十秒陪林恩说话，这三十秒是本事件唯一一次他们俩没有被倒计时压着的对话。
- 若林恩在她说「没有逃生路线」之后对她说「那我把你背出去」，则她会沉默一秒然后回答「我的腿已经不在了，」林恩被这句话迫在爆炸前两秒决定带不带走她的数据核。
- 若林恩不主动问逃生路线、直接把她扛起扔上自己肩膀，则她会在他肩上自言自语地说一句「你怎么跟你当年一样烂」，林恩第一次在这个机械姬身上听到十年前自己的影子。
- 若林恩施放血肉灾变把爆炸范围反向拉出一片区、把她封在自己血肉盾内，则爆炸时本事件所有后果只要他一人吃下，伪身病毒被滤在他体内只感染力他而不再扩散。
- 若林恩在夏娃缠住拥星者的走廊瞬间主动加入她战线、分担一条血管，则夏娃本体的负荷下降一档，她会后续对另一个源起一份「林恩」类别的好感。
- 若林恩让左左在意识空间替他记录银发少女最后的表情，则这段记忆会被永久存档，但左左从此长大后会偶尔在系统空间自己翻出这张表情哭泣。
- 若林恩在爆炸瞬间主动以灵能罩住拥星者的意识源头，则它不会知道病毒激活的真凶是谁、后续围猎巫神与夏娃的人选就被改为林恩一个。
- 若林恩让智脑在网道口放声大喊「伪身」，则整厅的机械调度会瞬间接收到这条错误信号、所有外围增援会被引导向错误坐标，但智脑会被第一次钉入最高等级的数据库。
- 若林恩穿越火焰波时召回所有被波及的碎片在他的系统空间里封存，则他会得到一批「被模因污染过的机械残骸」、是被夜医研究后续研发反伪身的唯一物资。
- 若林恩主动放弃救她、只把万机遗产的部件摘下来带走，则装置会按原序引爆、病毒会以全记录散播，但林恩失去确认伪身意图的唯一窗口。
- 若林恩在爆炸热浪倒灌前最后一个动作是把乌鸦面具塞进她手里，则她爆炸前最后一秒会用这只面具遮住自己的脸、让所有人以为她带着面具引爆，林恩日后看到热浪中会认错面具。
- 若林恩在将军下令「光宴投入数据熔炉」时反向触发中枢预警，则他能提前两小时得知熔炉令，有窗口在学者反对前先拦截将军命令。
- 若林恩在学者对将军说「你无权决定」时用灵能反向把这帧台词录制下来，则他获得一份证明「学者在反对将军」的证据，后续逼学者转向时这是他最有力的筹码。
- 若林恩让光宴看分身侧所见的爆炸过程，则她会立刻被「刚才那个不是我」的事实钉死，「智械小姐故意伪身」这条线在她身上立刻从猜疑升为铁证。
- 若林恩主动把林恩已潜入100%的信息压回去不登记，则中枢对七神的警报会推迟一拍、林恩获得「还没被锁定」的十分钟窗口。
- 若林恩撤离时在回程网道上设一支以M系反探息痕，则后续以太诞生时会以这缕灵能为索引追踪的不是银色幻想而是林恩本人，本事件后果直接换主人。
