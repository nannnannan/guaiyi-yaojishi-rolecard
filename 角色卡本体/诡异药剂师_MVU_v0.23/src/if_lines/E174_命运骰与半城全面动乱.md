# E174·命运骰与半城全面动乱·if线

- 若林恩在六点掷出瞬间主动以M之力充能却不开枪、仍处于最后一刻反向切掉巨像之心供能链，则宿主流血被中止但整体血肉蔓延未停，事件以变形（断能不开枪）收束，半城污染仅靠夜医紧急封锁压制。
- 若林恩在被血肉脉络覆盖后主动以恶灵视角跳离本体只留躯壳，则宿主「本质」离开、诅咒无施受主体，事件以变形（灵魂弃壳）收束，原作自杀复生路径被推翻。
- 若林恩在自杀前选择由左左手代劳开枪，则左左首次成为「救世主役」、心理负担改变，事件以变形（代理开枪）收束，死亡责任链条重新记账。
- 若林恩掷出六点后未启动自杀反制、直接以根源咒纹自封心脏，则宿主在心脏停跳前进入假死态，事件以变形（自封心脏）收束，原作「天使之吻复生」触发条件改写。
- 若林恩在掷出六点前主动封存咒瞳不植入接驳，则命运骰机制未触发、半城动乱全起未发生，事件以取消收束，原作高风险考验被人为剪除。
- 若林恩掷出六点后主动接入咒瞳视野、反查自身命运骰机制内部结构，则他被卷入六点诅咒的确定性漩涡，事件以变形（探头反查）收束，下一次掷点被预设。
- 若林恩在天使之吻复生之后主动不告诉任何根源、独自遭殃咒瞳下一次掷骰，则事件以变形（私密试验）收束，半城动乱的信息无法传至支援部门。
- 若林恩掷出六点后把咒瞳就地埋入地下三尺，则巨像之心共振被地面压制、血肉蔓延仅形成地下污染管网、事件以变形（深埋压制）收束，但地下管网作后期隐患。
- 若林恩掷出六点后不断喊「主母救我」，则主母感应被拉入扰动场，事件以变形（主母介入）收束，六大根源格局首次引入地狱之主。
- 若林恩在自杀开枪前主动为在场夜医五秒钟抢救倒计时，则事件被写进急救记录，事件以变形（公开殉职）收束，修瞳原作的隐秘性首次被打破。
- 若林恩掷出六点后主动把咒瞳收入口袋系上十九道符咒，则巨像之心被强制断连、半城污染不形成，事件以变形（断连压住）收束。
- 若林恩掷出三点平静统计后主动多加一颗石子进咒瞳，则三点结果带噪声干扰变为「部分魔化」，事件以变形（噪点试验）收束，六点与三点之外的噪声版图首次被探查。
- 若林恩在活性意识体叫出「献祭一种养分」时立刻应激提出「贡献我的记忆」，则意识体接收非原始列表的元素，事件以变形（拿记忆行贿）收束，意识体开启个性化索取路线。
- 若林恩在活性意识体钻出眼眶时当场用左左缠住不让其独立移动，则意识体未具成形、事件以变形（抑制独立）收束，四点与二点五点规则无法被记录。
- 若林恩在心脏充红可见时主动举目望向巨像之心，则他被半是祷告半是观察的姿态卷入心脏节奏共鸣，事件以变形（跨物共振）收束。
- 若林恩在掷骰全程故意闭耳不听系统播报，则他不知道自己掷到了多少点，事件以变形（结果未知）收束，六点半城污染被迫其不知情方式继续。
- 若林恩此时主动把咒瞳丢给艾雯，则她从宿主变成暂时持有者，事件以变形（代理掷骰）收束，根源侧首次被牵引到直接承担命运骰风险。
- 若林恩掷出一分时意识体未等数秒就被强行瞄准射杀，则独立意识体尚未说话即殒灭，事件以变形（蝼蚁式毁灭）收束，四点规则完全关闭。
- 若林恩在测试前主动查阅疫医数据库对【虫群孵化所】扫描升级，则六点结果与原作不同、血肉腐化路径改写为「高温虫群」，事件以变形（版本变种）收束。
- 若林恩掷出六点自杀开枪时手部被左左即时攥住、没有命中太阳穴，则宿主血肉仍然蔓延但自杀中断，事件以变形（自杀未遂）收束，天使之吻无法触发、进入另一种重伤态。
- 若林恩在复原眼球钻出眼眶时主动借由系统空间把意识体当场纳入防腐，则事件以变形（隔离意识体）收束，等价交易通道在不信任中被强制关闭。
- 若林恩掷出六点后未治疗持续流血直至休克，则事件以变形（休克被动）收束，天使之吻被强制唤醒但后遗症增加一个等级。
- 若林恩以M之力反作用咒瞳令其钻回眼眶自行修正，则活性意识体未成形，事件以变形（强装归位）收束，规则点解读全部中止。
- 若林恩掷骰测试之前向巨像之心正式征得「借能同意书」，则巨像之心在六点强制触发时不会「强行被借」、反而走借阅合同，事件以变形（征得同意）收束。
- 若林恩在项目结束时主动把全部记录上呈艾雯，则原始所有骰点结果被正式归档，事件以变形（数据公开）收束，地狱更大范围的根源部门开始排查类似魔改殖装。
