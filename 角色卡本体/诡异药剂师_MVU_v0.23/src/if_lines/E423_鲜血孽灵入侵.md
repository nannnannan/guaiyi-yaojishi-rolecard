# E423·鲜血孽灵入侵·if线

- 若林恩初看那只竖瞳瞬间用咒瞳扫溯瞳仁中央裂隙，则他提前半秒读到「非当前时间」标签，向众人预警时语气从警觉翻为肯定。
- 若林恩在孽灵袭来前主动把孽主拽入自己影子帮她起屏蔽，则她第一次与孽灵正面交会时不再「穿过去」，她与另一时间的同位体首次可互相看见对方瞳孔。
- 若林恩故意让蚀痕分身在孽灵面前假装成「玩家真身」诱刀，则污秽匕首真正切进替身血肉的一刹，他的本体现身于孽灵背后完成反包夹。
- 若林恩完全不躲进系统空间、与孽灵面对面拼刀，则对方识别「主角不逃」逻辑链断裂，她的追击节奏短暂中断一拍，「单体威胁顶格」标签首次出现裂纹。
- 若林恩在系统空间被入侵一瞬主动关闭全部空间屏障暴露自身，则孽灵在袭击真身时被林恩用逆沙渗透手背反泡，匕首穿透他但粘住她手腕一秒。
- 若林恩让左左在他进入系统空间瞬间从内部反噬出一根触手外露拉住孽灵脚踝，则她第一次被「点对点的力道」拽停半秒，「无序压制」层次首次破防。
- 若林恩拒绝召小丑心脏介入，则整场缠斗中无人能牵制孽灵狂攻，孽主与小观念各自失守，事件以变形（无援压制）收束，林恩被迫自己承担七次重伤才逃脱。
- 若林恩让小丑心脏主动暴露气息吸引孽灵，则她目标切换逻辑被验证、追杀途中被迫折返，「智能目标选择」适用范围得到首次实锤。
- 若林恩在夺门而出时主动用初诞者之力在殿门口引爆一道沙幕作为人视阻断，则孽灵停顿一秒侦测沙后踪迹，队伍的脱离距离从十米放到四十米。
- 若林恩主动让喵喵以猫形态游走打草惊蛇引开孽灵视线，则她判断「远程干扰来自脱靶小动物」一度修正射向，喵喵吞到一枚紫黑匕首碎片留在囊中证物。
- 若林恩召唤爱丽丝用幸福之家传送阵把自己与马戏团等平台一并拔离现场，则「空间不稳定带离」首次被记录，整个小队到达黑夜城后花园全员甩地。
- 若林恩把左眼咒瞳换成渡鸦之眼看孽灵面部表情变化，则他首次确认「她在找什么具体的东西」、而不只是追杀人，「目标锁定」的判定从杀人降至取样。
- 若林恩在与孽灵眼神偶合时主动眨三下示意自己认得她，则她被这一「被识别」信号打断一个动作拍，系统化「认识」充当了短距离死锁。
- 若林恩拒绝进入系统空间、选择脚踏咒瞳跃上悬浮巨手，则画面镜头翻转成他借机俯视全屋，「弱者逃跑」脚本首次被逆向改写为他权站位。
- 若林恩在逃离前用蚀痕在孽灵背后地面落下三枚「回家」印记，则她下次回地牢时也许会被该印记信号追踪，「反向追」的概念首次被引入。
- 若林恩拒绝使用巨像之锤，纯凭他体型位移多向逃跑，则孽灵把他识别为「无攻击意图者」，报道从刺客升级为「无视者」，她的追击优先级被意外降低。
- 若林恩主动让三日一体机核跳出警报协助分析，则「无序侵蚀分部」统计图首次被以数码形状呈现，他的战术空间被她自己供出来。
- 若林恩在匕首穿通他胸膛近击时主动用初诞者之力把腐蚀部份整个推出体外凉滞，则伤部以肉眼可见速度干净，「无痕回复可能」的实锤被她自己目击。
- 若林恩把喵喵抱怀里在后退中主动吻她一下重获力道，则喵喵作为移动港湾首次被定位，孽灵读识到该画面后进攻意图短暂中断一拍。
- 若林恩在选择逃跑路线时主动把孽主抱上自己肩头，她被迫成为人肉盾牌，则孽灵匕首入下意外停滞一拍，「攻击她」和「不攻击她」的逻辑矩阵首次被她本人选择。
