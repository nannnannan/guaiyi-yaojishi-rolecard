# E715·全面战争·if线

- 若林恩在地獄中僅選擇鎮壓而並不一次性全面入侵遙遠的無序深淵，那麼七千年一次的兵敗禁戰將改寫為低調的長期博弈與憤怒傾斜。
- 若林恩在進入畫家體內的地獄化戰鬥中僅出現一千零八尺而非完全內部吞噬，則他的存在將會被削弱，失去鎮壓災厄的主動權。
- 若林恩的聲線在漫長的地獄戰場上突然再度出現，宣布其身份並發起最後一道指令（這是他自地獄一戰以來的極大例外），則一切後續行動將被重新定義。
- 若林恩在面對巨大衝擊時選擇劇烈地燃燒罪火但並未與周圍的靈魂或神靈進行共享，則他的戰鬥力在沒有任何外力拖動的情況下終將崩潰。
- 若林恩在那一刻用刀鞘接住了巨刃的打擊，同時也將自身的血肉擊碎，則他將會形成一個完美的閉合循环，罪火將會蔓延至他的身體。
- 若林恩在血塗鴉群與出現時，要求自己首先通過踏地而非靜坐，則他的戰鬥有著明確的方向感，而連接複雜的神界內部。
- 若林恩在看到「神界的眾神」舉行哀悼儀式之前，首先以強制手段齊一神界內的权力李靜，則他將會失去一個至關重要的盟友，再次成為孤獨的主宰。
- 若林恩在對「死亡所代表的更高一層」進行不敬而將其釋放，則他將會墮落到一個極端冒險的死地，失去自我。
- 若林恩在現場見面後質疑自身有著不合適的地位（例如他才剛剛從閉关中醒來），則其自我審視的過程將會被中斷，神界的歷史秩序會被擾亂。
- 若林恩在無意識中因害怕面前的神界內混乱而選擇向後退讓而非擊敗眼前的人，則他將會激怒那些他試圖要為神採用代表的權力者。
- 若林恩在那一瞬間突然從潛在的闷燃煉造進化為對抗一个真正活命的敌手（例如朝天勾碎公開的敌意），則他會突然失去所有的控制與平衡，最終走向危險。
- 若林恩在那一瞬間因為過於期待同代神靈的認可而選擇不故作威勢，而是展示出內心的真實情感，則他會失去一部份神靈的軍事威信。
- 若林恩在那一瞬間為了維護那個永不復醒的過往而選擇不擁抱夜閽和哢哢的声音，最後只是用劍與刀鞘對峙，則神界的阴影自動会降臨。
- 若林恩在那一瞬間由於心理過於疲乏而選擇不再進行激烈的肉身格鬥，而是期望用魔力來控制局面（而不是肉身本身），則此舉將失去最關鍵的戰鬥指揮權。
- 若林恩在進入大罪火化神火狀態時，向冷漠無情的神界發出警告而非命令，則神界的重担將因「不夠威儲」而讓步給他，而他成為了神界的至高顧問而非管理者。
