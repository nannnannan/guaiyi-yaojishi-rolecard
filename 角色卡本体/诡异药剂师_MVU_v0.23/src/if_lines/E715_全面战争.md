# E715·全面战争·if线

- 若林恩在天堂之战遗址收刀入鞘、以锁链层层捆缚夜魔刀时多缠绕了一道白烬罪火封印，则待他抵达战场拔刀或挥鞘时，蓄积的锋芒会更加内敛而致命。
- 若林恩在隔空抓回三叉戟的瞬间顺势借主宇宙本源向全宇宙防线传去一道微不可察的法则脉动，则正在绝望中颤栗的众神会隐约感到主心骨尚在。
- 若画家在跃入混乱色彩化作单一苍蓝前朝天堂之战遗址的方向深深看了一眼，则远在遗址的林恩会清晰感应到她那份义无反顾的决绝。
- 若王骑与林蒙在看到女主人化作单一苍蓝迎向灾厄时立刻率领地狱大军死守边境侧翼，则试图绕过画家防线渗透的零散梦魇洪流会被当场截断。
- 若自缚天使在目睹苍蓝碧空与遮天黑暗轰然相撞时高呼全军稳住阵脚，则神界外最后防线的狱卒们会更快从概念级冲撞的法则震荡中回过神来。
- 若魇王在率领七柱魇魔神杀向内环、隔空向林恩发出挑衅时，林恩在遗址中以冷冽的目光遥遥锁定了魇王的气机，则魇王心头会莫名掠过一丝寒意。
- 若艾维儿在七柱魇魔神分头扑向内环的第一时间便主动迎上镜魔的去路，则镜魔将无法分身去干扰破碎神界第四层的战场。
- 若画家在与灾厄正面冲撞的刹那以苍蓝色彩替主宇宙内环多挡下一成余波，则内环诸多生命世界在开战之初的法则崩裂程度会显著减轻。
- 若轮回神王在林恩提戟起身、迈步走向战场前最后告诫那句「九死一生」，而林恩只是平静地回以一笑，则那份历经十年沉淀的从容已彻底成型。
- 若黑夜城内的生灵在三千年前大坠落的恐惧记忆复苏时彼此紧握双手、拒绝向绝望屈服，则汇聚向神疆的信念之火会燃烧得更加纯粹炽烈。
