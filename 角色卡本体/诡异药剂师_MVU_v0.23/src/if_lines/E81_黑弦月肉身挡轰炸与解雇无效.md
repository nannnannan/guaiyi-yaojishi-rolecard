# E81·黑弦月肉身挡轰炸与解雇无效·if线

- 若林恩在弹雨砸落前以咒压推向半空作诱饵，则黑弦月落点偏移，林恩被气流掀翻但未瘫软，挡轰炸仍成立，机体损伤减轻一档。
- 若林恩以咒瞳提前引爆半数导弹，则她接下的仅为残余弹幕、断臂环节缺失，「抱紧我，林恩」与「解雇无效」对白链仍完整成立。
- 若林恩脱口喊出「我的黑弦月」而非「你这个笨蛋」，则她丝线走位短暂紊乱，被一枚重型导弹擦过左腿，突围路线改由左左接应。
- 若林恩在黑弦月背他时主动宣言「契约作废我赔你自由」，则她当面撕毁人偶之誓残页，解雇无效不被念出，事件变形为「契约自裁与共死突围」。
- 若林恩以仅存替死娃娃抵上黑弦月断臂断口作接驳，则断臂在新一波弹幕中被娃娃替身重接、机体损伤降为半残，但替死娃娃本轮清零、E82 死光对撞无余量。
- 若林恩在黑弦月沉默支撑期间以戏谑口吻再度宣告「你被解雇了」，则她补一句「驳回，第二次，驳回，第无数次」，突围完成但「仅一瞬停顿」节拍被改写。
- 若林恩在黑弦月挡下第一波后主动扑向她后背替她接第二波，则两人同受创、林恩昏迷被反抱，「背林恩突围」主语倒置，事件变形但结论固化。
- 若林恩在黑弦月睁眼前最后一瞬主动吻住她以情欲解六咒残压，若玩家声明调教项目，则咒纹与机油同溢、解咒途径成立，突围改写为「边吻边杀出围」。
- 若林恩在宣告解雇后改口「你不被解雇，你自由了」，则黑弦月陷入短暂空白、丝线失控绞碎三具机械人形，突围路线被拉长、存在意义冲突推迟至 E82 死光前。
- 若林恩在黑弦月唤名「林恩」前抢先唤她「黑弦月小姐」，则她首次以名字回应的对位节拍丢失，突围动作不变但所有台词节点重新标注。
- 若林恩在黑弦月背他途中以一手覆上她断臂根部替她承受咒术火花，则林恩右臂灼伤烙印与黑弦月的焦背形成成对伤痕，突围完成但新伤延续至 E82。
- 若林恩改用夜医麻醉针将自己放倒避免挣扎，则她不需死死按住他的手腕，突围路线平稳但「抱紧我，林恩」被夜医睡态吞没、唤名推迟到苏醒。
- 若林恩在黑弦月挡下第一波后大喊「我命令你放下我」，则她一字一顿答「命令驳回，理由：人偶之誓无法单方面终止」，解雇无效被进一步固化为单句驳回模板。
- 若林恩向万机之神开口吸引火力称「她是我抢来的人偶」，则蜂巢狙杀优先级临时把林恩抬至第一目标，黑弦月突围被强行提速。
- 若林恩在被背负途中主动掏枪点射追兵而非任由她杀戮，则紫色华尔兹规模缩小一半、林恩手腕被后座力震脱臼，突围完成但机体损毁降至中度。
- 若左左强行插入代替黑弦月背林恩，则黑弦月改为前锋开路撕碎所有伏击机械，突围链成立但「抱紧我，林恩」错位成「别磨蹭」、情感节拍转入另一支线。
- 若林恩向蜂巢公共频道广播「她是人偶别杀她」，则狙杀列表中她的硬目标位被替换为「不可伤主」，突围火力被分流。
- 若林恩在被背负途中以性为解咒途径对黑弦月的咒纹接缝实施调教，若玩家声明调教项目，则她第一次主动松开一手按住林恩手腕于腰后，突围与调教并行但步速被压低。
- 若林恩在宣告解雇后反悔改口「再续三十天」，则黑弦月答「层级已变，三十天不再成立」，突围继续、契约自居的存在意义被替换为「自由人守诺」。
- 若林恩不让黑弦月背负、强行扶她共走突围，则丝线缠上两人腰保持联结，突围成立但「背林恩」的物理事实被改写为「互相拖拽」、机体损伤再多一档。
- 若林恩在黑弦月保护下提前昏迷错过宣告解雇，则「解雇无效」环节整体缺失，事件变形为「单方面守护与未宣告」，完成条件不达成，E82 预兆改标「黑弦月是否已挡轰炸」差异。
