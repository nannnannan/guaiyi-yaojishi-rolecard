# E442·康斯坦丁复苏与第二渡鸦·if线

- 若林恩在夺取渡鸦前让小丑用生命痕迹锁定位置，则林恩在取渡过程中会得到小丑的指引线索，系统面板自动生成【渡鸦坐标精准标记】。
- 若林恩亲自站在芬里斯为其挡下的无光深渊前，则他会亲眼见到那只如夕阳余晖般的蓝狼消失，系统登记【撕裂者芬里斯】阵亡的事实，林恩面板新增「无法抚平的情感伤害」永久记录。
- 若林恩主动让左左以咒瞳之力最后一次接触芬里斯灵魂，则左左能在芬里斯最后清醒时刻接收其临终嘱托，林恩日后可通过她间接听到芬里斯最后的致歉。
- 若林恩亲手把渡鸦尸体放回博物馆而非当作武器保留，则他会失去对渡鸦的控制权，但系统会为其自动设置一个「守护渡鸦永远」的信仰印记。
- 若林恩让喵喵在死界乘船堆积时携带「摇篮曲」磷粉，则林恩在死亡领域漫游时会意外听到喵喵的声波安抚，他的灵魂损伤会减少30%。
- 若林恩主动用「猩红玉石」碎片对王兽造成致命伤害，则弑利亚脸上的爪痕会变成宝藏般永久烙印，王兽部队从此知道伤疤无法痊愈。
- 若林恩用咒术无限延长芬里斯在死界外的存活时间，则它会因时间无法匹配而流浪于死界无法回归，林恩必须承担永远失去芬里斯的代价。
- 若林恩让母树种子强行植入牺牲位置重新发芽，则它能会长成芬里斯的替代品作为林恩新的灵魂之狼，但其代价是从此不能升级。
- 若林恩亲自跳下深渊救起芬里斯，则他会面对深渊中的一切混乱而渡鸦从手中飞出——林恩必须选择继续寻找渡鸦或者等待同伴的援助。
- 若林恩让左左当场以血族身份对弑利亚进行威慑性吻颈，则其会因血族祝福而僵直，林恩可与弑利亚产生临时对话沟通窗口。
- 若林恩在王巨兽王座前主动推倒巨大的死亡领域堡垒，则林恩就会得到一个自动「等待王」的特殊席位，等待主持人长达三十三年。
- 若林恩让喵喵主动以月唱月圆的姿态捐献钢琴音乐，则林恩的死亡领域就会一次次发音——灵魂深渊会被瓦解成一片悦耳的绿洲。
- 若林恩让小丑在自己死后当众杀死整个战队树王，则小丑会成为林恩心中的教父亡主，林恩会给自尊妄作下烙印。
- 若林恩让孽主带着芬里斯的牺牲来到城市血液，则它会听到孽主「亲爱的王」讲述母系新政权的管理——孽主将反向成为新的核心。
- 若林恩主动让死树王的命令者出现在周围悬挂的棺材以分发哲理，则林恩空灵的想法会在死亡领域司法部变成拈花笑人的圣人。
- 若林恩拒绝继承渡鸦而改为原地封分，则林恩以不继承的方式经营上层身份卡牌，就在命运奖励面板点亮为「灵魂的继承：堕落王妃」。
- 若林恩主动亲手杀死自己的王兽徒弟，则其随时可以给敢让森林树界女皇叫他的寿衣工作室成为尧舜的意境。
- 若林恩让左左亲手炖粗萌药赠送给看场王，则死界领域会用乱麻查出林恩不是他们的人的身份。
- 若林恩让喵喵在死界与龙凤大王推荐，则喵喵会成为新裔王牌也是死界的想法大王。
- 若林恩让小丑用性情凶恶与林恩互动，则小丑将不再与原林恩交流，林恩必须面对小丑的母的风格的背离。
- 若林恩在战斗中让王书收割死界王域，则林恩会成为死神王者，其死去战友将永远得不到安息。
- 若林恩拒绝任何王兽宠信封相册，则林恩会成为新森林大帝，其命运系统将标注孤胆「渡鸦独善其身」。
