# E442·康斯坦丁复苏与第二渡鸦·if线

- 若林恩在左左焦急劝阻他立刻撤离时冷声回应「我向来不喜欢欠别人东西」，则左左会在短暂怔忪后收起劝逃之词，全力配合他将初诞者之力化作漫天金焰。
- 若林恩将沸腾的金色火焰毫无保留地席卷包裹住周围自杀式冲锋的受控王兽群，则金焰在焚烧无序污染的同时强行锁住王兽生机，让这群昔日海王殿旧部在清明中停下自毁。
- 若林恩在金焰净化群兽导致自身灵能再度逼近极限时仍死守城前不退，则地下墓船方向会骤然爆发出一股令整片无尽海战栗的古老死亡威压。
- 若林恩在弑利亚惊疑不定之际侧身让开身后城门通道，则彻底褪去腐朽病变的康斯坦丁会端坐于如山白骨王座之上破海升空，眼眶蓝焰暴涨。
- 若林恩与苏醒的康斯坦丁并肩立于深海战场上空，则船长那句沙哑的「船员们，该干活了」会瞬间唤醒整支深海骑士军团的旧日契约，成千上万名受控骑士当场调转枪头反戈。
- 若林恩在深海骑士军团反戈冲杀时挥戟指向高空黑色光团，则复苏的王兽与亡灵大军会汇成一股不可阻挡的洪流，瞬间将弑利亚的包抄阵线冲得七零八落。
- 若林恩在弑利亚死死盯住他手中暴涨的初诞者金焰时毫不掩饰自身气息，则她会从那股远超单具躯壳的力量量级中猛然醒悟，失声叫破「你找到了第二只渡鸦」。
- 若林恩在弑利亚揭穿第二具渡鸦后冷眼反讽她同样不过是窃取力量的窃贼，则她在暴怒与嫉恨交加下会彻底撕开黑色光团伪装，癫狂自曝「我才是第一只渡鸦」。
- 若林恩在弑利亚自曝「第一只渡鸦」身份并引动更高层无序黑雾反扑时呼唤左左，则左左会毫不犹豫地脱离左手形态，在金光与电弧中化作第二柄缠绕雷霆的三叉戟。
- 若林恩双手分持深海王戟与左左所化的雷霆三叉戟同时掷向天际，则两道毁天灭地的流光会在半空交织成螺旋金芒，一击贯穿再度张开的无序黑雾巨口。
- 若林恩在双戟贯穿黑雾巨口的瞬间引爆其中压缩的毁灭金焰，则弑利亚赖以维系降临的投影通道被当场撕裂重创，她的尖啸声在坍缩的旋涡中戛然而止。
- 若林恩在黑雾巨口崩散后伸手接住重新化回人形的左左，则左左会挂在他手臂上大口喘息却得意晃腿，炫耀自己变成的三叉戟比海王殿原装的那把还要锋利。
- 若林恩在战局初定后转头望向白骨王座上的康斯坦丁，则船长会向他微微颔首致意，深海霸主的威仪与刚刚缔结的生死盟约在这一眼间彻底坐实。
- 若林恩下令让鲛人将军率先收拢战场上重伤脱困的王兽与骑士，则沉眠地外围的惨烈战场得以迅速清理，为紧接着直扑天空之城的总攻腾出整编序列。
