# E195·群发求援与根源法阵曝光·if线

- 若林恩在给艾雯爵士拨号前先压低声音对夜医交代「待会配合演戏别拆台」，则周围夜医齐刷刷摆出悲壮表情，求援录音公开处刑时全员表情管理崩坏。
- 若林恩对白夜的 RPG 不闪不躲反而挺胸硬接，则炮弹在他胸口炸出一团焦烟，白夜愣神掏第二发的手停在半空，事件以白夜主动熄火收束。
- 若林恩让左左张口咬下 RPG 后顺手拍拍她脑袋补一句「乖，吐出来还能用」，则左左黑着脸把弹头吐到他掌心，炮弹被林恩原路还给白夜。
- 若林恩在拨号前先把坐标发往黑夜城让信标先立起来，则信标光柱先于求援电话升起，五根源在大殿里目睹坐标墙提前曝光，后续拨号对象全员起疑。
- 若林恩只对艾雯爵士一人求援并放弃骚扰其余四位，则地下大殿的铭文依旧在刻，但公开处刑环节缩水为艾雯单人吐槽，巨像之脑逃过一劫。
- 若林恩张口第一句不是「弟弟遇到点麻烦」而是正经汇报结界规格与殖装阶位，则艾雯爵士停下来听数据，灵能兵器折跃方案换成定向破障锤而非捆绑包。
- 若林恩对主母的哭惨改为报实数「零伤亡但破不开膜」，则主母在法阵边挑眉反问「那你要神圣殖装做什么」，求援录音多出一句拆台质问。
- 若林恩干脆把面具频段切到公放让白夜亲耳听自己怎么哭穷，则白夜全程死鱼眼陪演，事后在报告里把「几十个同志阵亡」划掉改成「零」。
- 若林恩向巫神开口索要不死系道具而非攻击殖装，则巫神头颅在大殿里咯咯笑出声，手指勾出一条备用咒线作为附赠品塞进折跃包。
- 若林恩跳过泰坦头颅完全不打这一通，则泰坦在大殿委屈地嘟哝「是不是看不起我」，事后抄起一罐自备精粮硬塞进信标里补位。
- 若林恩对巨像之脑改成单刀直入「王后需要你男人一件兵器」，则巨像之脑耳根通红一声不吭地掐断通讯，五秒后单独折跃一只小巧血髓指虎到信标。
- 若林恩在「隔空亲我一下」前先正经道谢三句再补一句调戏，则巨像之脑拳头硬了三次又放下，只回一句「等回来再算」，血色锁链没被艾雯启动。
- 若林恩对巨像之脑改喊「老婆贴贴」而非「脑子贴贴」，则大殿整个死寂延长到十秒，艾雯爵士的锁链都懒得抬，巨像之脑当场死机。
- 若林恩在四通电话之后再多拨一通给小小说「哥哥我想你了」，则小小在大殿里开心举起触手挥挥，巫神瞪向林恩的目光多了三分杀意。
- 若林恩挂断每通电话前都补一句「坐标已发，等见面还」，则五位根源同步掏出坐标记录，大殿法阵边的坐标栏被他自己的名字刷屏。
- 若林恩在拨号途中停下先对左左交代「接下来演技拉满别穿帮」，则左左认真憋着笑全程当背景板，投影仪公放时她的憋笑表情占满整个全息画面。
- 若林恩把坐标直接甩到黑夜城却不说明用途，则大殿法阵边的五位全部停笔抬头发愣，主母第一个反应过来掐出遥感咒去摸现场。
- 若林恩放弃拨号改掏出自己库存的药剂硬怼结界，则三瓶烈性腐蚀剂泼上之后只融开一层薄膜，夜医集火提前两轮开打。
- 若林恩把求援内容换成「借你们一件 Shell 让我进结界做疫医诊断」，则艾雯亲自折跃一副反血肉诊察镜，公开处刑环节整段消失。
- 若林恩在公放现场主动举手认栽并宣布「今晚请全员撸串」，则夜医憋笑爆发，套娃铁箱在被切开前就多了一群围观的举着烤串的身影。
- 若林恩让左左从体内钻出来站在自己身侧全程围观拨号，则左左每听一句就摇一次头，画面变成双簧式处刑。
- 若林恩在巨像之脑暴走冲来游魂巷前先主动折跃自己回大殿门口受死，则她拳头落在他肩膀却停住，血色锁链第一次没有自动跟上。
- 若林恩把套娃铁箱先推给白夜开，则白夜一刀劈开第二层就开始皱眉，套娃怨气当场转移到白夜身上，林恩逃过社死焦点。
- 若林恩在投影仪启动瞬间抢到镜头前喊一句「大家好我是林恩」，则全息画面里他的大脸占满整个大殿，左左现场爆笑跪地捶地。
- 若林恩只用一通电话但要求艾雯一次性积压五件殖装打包折跃，则套娃铁箱层级翻倍，巨像之脑的报复心血被压在最底层。
- 若林恩挂断最后一通电话时朝镜头飞个吻作为收尾，则投影仪回放时全场夜医集体捂眼，白夜当场把面具摘下来揉太阳穴。
