# E96·血肉利维坦突现与战局逆转·if线

- 若林恩听到利维坦长鸣时先把左左压进意识空间遮蔽共鸣，则「王后」身份不被同源血肉唤醒，孢子雨按原节奏倾泻，林恩少了左手被反咬的应激提醒。
- 若林恩直视利维坦超过三秒并硬生生记住一颗瞳孔的形状，则面板多烧出一栏「根源直视烙痕」，护盾对面记忆缺失的艾雯爵士读不出他在默念什么。
- 若林恩把单反视角从天空改压到万机之神断臂伤口，则白逸拿到的是「万机之神受创全记录」而非「根源对峙」，血肉神教在视界网的估价改写。
- 若林恩先把喵喵从肩上解下收进口袋再谈「潜入」，则她竖瞳的恍惚不被同源血肉持续锁定，潜入少一条警报线但多一份林恩对她的瞒。
- 若林恩在「我明白了」之前先把血雨采样一滴收进系统空间，则后续调配针对机械意识封锁的解药少跑一次利维坦取样，但背包多一个会被欲望母树隔空嗅到的引子。
- 若林恩把白逸的单反塞进半残机械先驱残骸充当「目击者」，则影像被万机之神回收到主基地，林恩潜入 footage 被两个根源同时握有，三根源密约时刻筹码反向成立。
- 若林恩不喊「我明白了」而是把猜测写成纸团塞给艾雯爵士，则护盾外没人听见那声，破晓315博士枯手不会被一丝注意力抓住，利维坦对林恩坐标的标记延后一轮孢子节奏。
- 若林恩当场建议「你先升格，我再潜入」，则升格窗口被移到瘟疫全面喷洒之前，艾雯爵士意识上传沾到咒缚孢子，赛博本体多一道无法回滚的血肉沉积。
- 若林恩朝死寂蜂巢掷一支肾上腺素型药剂，则一座蜂巢的瘫痪被一针延迟半秒，意识上传窗口被撑开一线，机械神教对「疫医」的标记多一层「曾救蜂巢」黑账。
- 若林恩在利维坦长鸣峰值抽出夜魔刀斩断一缕披风上的血雾，则血雾与血气共鸣，利维坦把他归为「可承接母体」而非待污染机械，破晓315博士在腔室边缘抬起面具。
- 若林恩把潜入方案压在心底、改向欲望母树借一条藤蔓，则母树在藤蔓接口亲手摸到他的心跳频率，「小弟弟」从戏谑转为实体记录，血肉支配者对他多一次扫视。
- 若林恩拒绝潜入、用「门」跳跃撤退，则战局逆转主线不变，「斩首行动」改由艾雯爵士独自承担，记忆缺失下硬闯主控腔室的代价挂在林恩账上。
- 若林恩朝破晓315博士方向掷一支基因增幅药剂，则药剂在半空被血雨吞没，博士枯手挥落节奏乱一帧，三颗孢子落点偏离孔洞，三架机械战机得以把「主宰坐标」完整回传万机之神。
- 若林恩感到「皮肤融化」错觉时反手打一针镇静剂，则脑海蛆虫噪鸣降低，【利维坦直视】不落进诊断术，但混乱开始前那三秒失去读取博士手势密码的机会。
- 若林恩让左左从左手反卷进自己手腕，则「王后」与「巨像之心宿主」在利维坦血肉视野中重叠出场，体表几颗瞳孔短暂失焦，孢子雨在林恩头顶形成一圈留白。
- 若林恩朝欲望母树喊「你的瘟疫连我也会一起咒」，则母树目光在他身上停一秒，回一句「小弟弟，我没算你」，孢子对护盾亲和度下降一层，「不在名单上」被同步纳入血肉支配者的「林恩档案」。
- 若林恩朝三大蜂巢之一掷一支夜医应急血包，则那只蜂巢断联前收到完整药理配方，意识上传屏蔽时多一道夜医加密签名，林恩在肃正黑名单被追加「药理干扰源」标注。
- 若林恩用拟化把利维坦升空第一帧印在左掌心，则事后可凭烙印反向推演腔室分布，潜入路径缩短一幕，但拟化纹路在掌心持续发痒，靠近血肉神教阵地即复发。
- 若林恩当场主动释放巨像之心一圈共鸣脉冲照向利维坦，则三根源混战节奏空一拍，血肉支配者与万机之神同时捕捉「巨像之心」存活信号，孢子轨迹改道，母树人脸上的笑首次真正变意味深长。
- 若林恩在逆转瞬间只录像不反应、先把喵喵塞进艾雯爵士护盾最内圈，则她不被同源污染拉扯、后续不掉链子，但林恩在「我明白了」那一瞬少一个可对视确认的同伴。
- 若林恩把顺来的单反当场摔在护盾外任血雾吞掉，则「录像证据」不立，白逸那头只由左左口述战况，血衣阵营对这场神战烈度的评估整体下调一级。
- 若林恩朝破晓315博士当面掷一瓶未启封噩梦混合药剂，则枯槁手掌在面具前接住，半秒停顿被母树读进眼里——疫医九字元勋对夜医方的「敬意」首次留下可被质疑的缝。
- 若林恩在血雨罩顶时把血肉增生药剂泼在自己脚边充当诱饵，则孢子先污染地面，护盾外腐蚀链被洗乱，他的真实行动轨迹对机械神教残留探测器与利维坦都变得不对称。
- 若林恩朝利维坦瞳孔集中一侧定向念一句以M静心咒，则以M之力与咒缚权柄在血肉天幕对撞一次，一颗瞳孔反卷、孢子爆射中断三秒，三大蜂巢抢到对「意识上传屏蔽」的第一次反向回传破口。
- 若林恩在录完「我明白了」后立刻把猜测写成私语传给肩上喵喵，则她当场听懂「潜入利维坦」全部暗号，竖瞳恍惚被她自己一爪踩回，潜入之前林恩多一个能替他做决定的小执法者。
