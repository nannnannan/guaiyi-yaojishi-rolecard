# E795·大结局与原初身体·if线

- 若林恩在大君以原初身体出现时主动叫出「你是我最早的那一具壳」而非「你是我敌人」，则大君的攻击迟了半秒，那半秒里他第一次发现自己面对的不是怪物而是某段被抛弃的旧日。
- 若林恩在黄金梦境即将燃尽前主动停下火焰换用一份平凡的心跳而非继续燃烧，则大君的攻势首次未能完全贯穿，他在那一拍里听见自己原本只是一个想过日子的药剂师。
- 若林恩在七十一噩梦被清除后主动留下一只伤得最重的而非让它化烬，则它成为他终焉之战的活证，此后战场每次提及它都会沉默半秒。
- 若林恩在大君承认「你早已不是过去那个人」前主动先说出「我也已经不是」，则这场同源之战的胜败定义从「谁赢」变成了「谁先原谅谁」，结局曲线因此改了。
- 若林恩在三叉戟切开黄金梦境防线的瞬间主动用左手接住其中一根戟尖而非闪避，则他从此左手上多了一道永久的刻痕，但他也从这一道刻痕里第一次读懂了原初自己的疲惫。
- 若林恩把自己的空间法则主动改造成一片花园而非战场，则大君的攻势在这片花园里首次失效，因为毁灭在同类的花园里再无用武之地。
- 若林恩在大君以漫长经验压制他时主动坦白「我没有经历那么久，所以我会累」，则大君的攻势出现一个他从未设防的口子，因为虚伪在这一刻比他更陌生。
- 若林恩让轮回碎片在远处发出的最后回应不是圣言而是一声轻轻的「辛苦了」，则他在这声回应中作战的风格多了份温度，大君偶尔被这份温度击穿防线。
- 若林恩在核心黑火开始反向吞噬双方时主动把自己体内的一缕温暖送进火焰而非抵抗，则火焰的吞噬方向慢慢从「灭他」变成「围住他」，他在火焰中得以喘息。
- 若林恩在大君同源身份完全显现时主动喊「我们是同一根」而非「我们是对立」，则这场战斗第一次有了「是否能共存」的余地，结局边界因此外扩。
- 若林恩在左左外部桥接中看到她正试图送完最后一缕权柄时主动先对她说「你已经够好了」，则她的桥在他这一句话里稳了最后一拍，那一拍足够他把战局推到下个阶段。
- 若林恩在大君用重量把所有攻击压回时主动选择用重量承受而非反推，则他在这场同源角力里第一次没有跌倒，因为承受比进攻更接近他自己。
- 若林恩把黄金梦境里的「同伴记忆」换成「同伴当下」而非过去，则他的攻势中首次带上了真实呼吸的重量，这种重量比任何咒语都能动摇大君原初经验。
- 若林恩在终焉战场空间即将定型时主动划出一条只属于他的不规则路径，则大君从此必须在他的曲线上与他对话，权力就在这一瞬间变成一把双刃剑。
- 若林恩在大君尚未彻底失控前主动抓住他的手而非举拳，则大君首次在这场战争里有了一次不是攻击的体验，他今后即便败北也会记住这一次被握住。
- 若林恩让七十一噩梦的黑影亦被写入他的血液而非只成灰，则他的攻击里从此带上一种得而复失的预感，这种预感比任何采伐都锋利。
- 若林恩在战局最危险时主动自问「如果我赢了他但更糟，那该怎么办」再出击，则他的胜利路径里写入了「善后」这一变数，他赢的也将不再是「灭」而是「换」。
- 若林恩在大君失去心的那一瞬主动把自己心脏的节拍借给他一拍，则大君第一次在这场战里感受到自己的心跳，他今后即便在混乱中也会时不时触到这一拍。
