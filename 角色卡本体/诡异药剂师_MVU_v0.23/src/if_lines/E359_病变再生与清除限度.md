# E359·病变再生与清除限度·if线

- 若林恩在以M冲击堕天使精神时多叠加一层赛博飞升灵能波纹，则她调用暗影的起手式被识别成「数据化信号」，堕天使后续每次施法都会短暂卡顿半秒。
- 若林恩在撕开天使圣象甲胄时主动保留一片银白甲片塞进系统空间，则暗面再生时会在那一位置多出一块与整体格格不入的「劣质补丁」，后续撕甲出手一眼可辨。
- 若林恩在堕天使道出病变再生真相前抢先回应「那就把你整个人一起清」，则她瞳孔瞬间收缩，暗面在这一瞬间把全部诅咒调回防御，再生节奏反而拉慢一拍。
- 若林恩在端出灵魂契约时把签名栏预填「一日为徒终身为子」，则主母意识深渊里泛起一缕难以察觉的颤音，表层堕天使的反抗短暂紊乱一拍。
- 若林恩在诱导暗面出手时不藏杀招故意留一线破绽给她轻取，则她那一击尚未触到他背心，自己反而因为灵力阀门更早滑开被净化之力抢先灌入。
- 若林恩让巨像在压住堕天使时把双足再往她腰后挪半寸，则她一声闷哼泄出，暗面驱动十二翼的反扑提前被压回体内，以M重拳结算多+5。
- 若林恩在病变即将沿七窍溢出瞬间主动用左左从掌心探出细缝做前置引流口，则排出的第一坨黑液被改道牵入预先备好的隔离器皿，回流风险降低三成。
- 若林恩把血肉触手茧改成薄翼形「翅膀形肉棺」而非圆茧，则堕天使在内部仍能微幅扇翼，欲望反噬时翼尖优先贴到他脸颊，定力损耗追加一道外加分。
- 若林恩在结茧前主动朝巨像喊一句「给我闭上眼三十秒」，则巨像老老实实闭眼，但意识网络里多一条「巨像被话痨指挥」的悄悄备注。
- 若林恩在背诵道德经时把「道可道非常道」替换成左左的黑话台词，则系统警报【定力-1】的间隔意外延长一次，但左左在意识空间内气到跳脚。
- 若林恩在堕天使以M余波下扭动磨蹭时主动把下巴搁在她头顶而非推开，则她喉间逸出一声几不可闻的低吟，神性诱惑再上一层，定力-2 同时结算。
- 若林恩在她唇间呢喃索吻之时用一根触手塞住自己耳朵闭眼硬扛，则他眼前能见的诱惑被削减两分，但左左在意识空间尖叫「凑脑袋你别堵我的视线」。
- 若林恩主动提前让克苏鲁之眼踏入警戒位而非等暗面偷袭时再启动，则堕天使察觉外部多一道深蓝凝视，施法念头被打断两次，暗面反扑推后十几秒。
- 若林恩在病变剥落时主动把指尖按到焦炭状病变上反向催熟它，则一小块病变被提前碳化落地，剩余病变再生时这块位置永久留下一个焦斑标记。
- 若林恩偷偷用触手末梢在她锁骨写下「徒弟到过此处」，则堕天使在身体表层浮现一缕隐秘痒意，主母主人格深处被扯了一下，深层唤醒提前半秒触发。
- 若林恩把她拼命引诱的索吻直接用一记「脑瓜崩」打断，则堕天使愣了三秒，暗面诅咒震荡，再生病变进度被卡住一格。
- 若林恩在完成病变排出后不立刻入意识海，反而先拥她原地多静坐十息，则堕天使余波下的欲望再多叠加一层未被化解，他入幻境时意识表层浮现一缕旧时亲密残影。
- 若林恩主动把触手茧扭曲成「兔耳状大蝴蝶结」造型，则堕天使事后清醒过来看到形状第一时间暴走外放黑羽，巨像之脑网络里多一条备注「王后审美崩坏」。
- 若林恩在病变吸纳入容器时主动给容器命名「堕天使限定特调一级病变」，则巨像网络自动记录一条烹饪误识日志，左左在意识空间吐槽吐到干呕。
- 若林恩把精神威能贯穿那扇意识之门时主动叠加一层主母熟悉的初诞者气息，则她在幻境深处第一波反应是认出「那是他」，而不是先筑起防御墙。
- 若林恩在结茧完成瞬间主动朝巨像竖起大拇指，则巨像下意识也竖起一根覆盖整个荒野的巨大拇指，黑堡远端的某个调查夜医通过灵魂丝线看到这一幕后当场僵硬。
- 若林恩在堕天使呼吸最急时主动把鼻尖贴到她额头上而非躲开，则暗面短暂失守，主母主人格的金色在意识深处亮起一整格，幻境入口轮廓更明显。

- 若林恩主动用触手把堕天使的十二道金黑相间翅膀压在自己身下一起入茧，则她瞬间像被安抚的幼鸟，深潜途中精神反扑减少一拍。
