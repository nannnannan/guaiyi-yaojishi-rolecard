# E583·时光横断与灾厄黑瞳·if线

- 若林恩拒绝斩瞳任由竖瞳注视，则竖瞳与腐化加持仍立，气机／投影将至风险升级，横断驱逐线不因拒斩而回退，事件以更危险的暴露分支收束。
- 若林恩试图追入横断后的时间战场，则本事件不写成已掺和成功，艾维儿「非可掺和」判断仍作已知，他被未来护罩不远不近地挡回。
- 若林恩在白发兜帽影拔刀时主动同步拔出自己的夜魔刀预备一击，则银发影与当下他的刀剑共鸣引发双重轨道对撞，横断时光的力量在这一秒被放大。
- 若林恩对白发影宣言「被我杀死的人不需要回来复仇」，则银发影的目光首次转头看了他一眼，未来的自己与当下的自己在意识层面完成一次无声的握手。
- 若林恩在三大扭曲存在突袭时主动把左左抛到艾维儿怀里，则左左炸毛后咬他手臂，但那瞬间未来影的站位因分目出现一条极细的裂缝。
- 若林恩对艾维儿说「你先护着她」，则自缚天使在你的指令中被主母和艾维儿夹在中间，三人三角站位在那段割裂的时空中被加固。
- 若林恩在银发影消失后对残存法则大喊「别走，至少告诉我我是谁」，则没有任何应答，但系统面板在他意识深处亮了一行「你正在成为你」。
- 若林恩对腐化恶魔群释放初诞者之力作威压而非攻击，则蝠翼恶魔畏惧后退半圈，主宇宙级的气息在深渊第七位面首次被公开。
- 若林恩对主母说「把你的力量借给我」，则她的眼泪与金色血一起滚落，十二光翼的共鸣在这一刻被注入他的恶魔之翼，两者不同本源压出新的力量峰值。
- 若林恩在斩瞳时不用夜魔刀而是以手作刃，则刀光被手劈出的效果弱一线但身体的贯通度更强，竖瞳哀鸣时间更长，他指尖多一道被灼伤的竖纹。
- 若林恩斩瞳后直接对天空喊「我在这，你来啊」，则灾厄气机在他的挑衅下短暂凝聚成第二次凝视，艾维儿在下方以狼般的表情盯住他。
- 若林恩不对任何人说「他已经来过了是吗」而是只在心里问，则系统istence静默，这句问话变成只有他一个人知道的悬案。
- 若林恩在自缚天使绝望长啸后主动接住她并堵住她的嘴亲吻，则自缚天使的惊恐在这一秒被反向点燃，她的力量下意识地缠绕到他刚获得的恶魔之翼上。
- 若林恩主动询问系统「竖瞳被斩后灾厄投影到来的最快时间」，则系统弹出猩红倒计时，他知道自己的逃离窗口具体长度。
- 若林恩站在荒原上主动张开双臂等待被他斩碎的竖瞳黑烟缠绕，则灾厄气机在他身上留下一道冰冷的刻痕，之后每一次灾厄凝视都会优先定位到他。
