# E755·最后的绽放·if线

- 若林恩在主母（自缚天使）亲自捏碎王庭外海神三叉戟封印、将神兵高高举起的那一刹那，主动切断三叉戟抽取圣所镇压力量的回路，则主母挥出第一戟时不会受到封印反噬的牵制。
- 若林恩在主母彻底解开自缚枷锁、燃烧全部天使本源在王庭阶前绽放出此生最璀璨夺目的金色神光时，于圣所内仰头望向穹顶，则那抹穿透石壁的温暖金光会照亮他满是血污的脸庞。
- 若林恩在主母手持海神三叉戟独战逼近圣所的魇魔之王、金发在狂暴法则风暴中如烈阳般飞舞时，顺着三叉戟与自己的本命联系强行注入一缕王座黑火，则戟尖迸发的金芒中会多出一道令魇魔胆寒的毁灭黑线。
- 若林恩在银色幻想提着残破长剑留在王庭阶下、以满月银辉与主母的金色神光交相辉映协同死战时，分出一丝神念替两位神王串联起呼吸频率，则两人在绝境中的配合毫无破绽，硬生生挡住魔潮半个时辰。
- 若林恩在主母每挥出一戟便有一片璀璨金羽从她背后剥落化作火雨焚烧魔物时，拼命催动王座引力将其中一片未烧尽的染血金羽隔空吸入圣所缝隙，则他得以留住母亲最后绽放的一缕痕迹。
- 若林恩在感知到主母的生命本源正如决堤江河般飞速流逝、却依然一步不退地死死钉在圣所大门前时，在锁链中发出撕心裂肺的悲吼，则那声悲吼会化作实质的音波替主母震开侧面偷袭的三头高阶魇魔。
- 若林恩在魇魔之王凝聚起足以轰塌整座圣所的漆黑灭世光束射向主母时，强行引爆自己残留在三叉戟内部的一道初诞者底牌，则主母能够借此一戟将那道灭世光束正面劈成两半。
- 若林恩在主母因为过度燃烧神魂而嘴角溢血、却在回头瞥见紧闭的圣所大门时露出一抹温柔至极的微笑时，将那抹微笑死死烙印在自己的灵魂最深处，永生永世不敢遗忘。
- 若林恩在银色幻想为了替主母分担侧翼压力、主动以肉身硬扛一尊终焉魇魔的巨爪而被震飞撞碎石柱时，顺着地脉送去一缕药力护住他的心脉，则这位银发神王还能再次拄剑站起。
- 若林恩在主母绽放出的金色神光将整座沦陷的黑夜城废墟重新照亮如白昼的那一刻，让躲在城内残存掩体中的幸存者们都透过缝隙看见这轮金色的太阳，则绝望中的人们重新找回了活下去的勇气。
- 若林恩在主母以三叉戟画地为牢、在王庭台阶前布下神圣天使绝域将数十尊魇魔死死拦在百步之外时，用自己的王座威压替那道绝域加固基底，则魔潮在主母油尽灯枯前始终未能踏上台阶一步。
- 若林恩在听见主母于漫天金光中轻声呢喃「这就是妈妈能为你做的最后一件事了」时，拼尽全力挣断了身上的第一根次级锁链，鲜血喷涌间将晋升速度推向极限。
- 若林恩在主母的天使羽翼燃烧殆尽、化作漫天金色光点洒落在王庭废墟上时，让那些光点凡触及黑夜城阵亡将士遗骸处皆生出一朵洁白的光花，替满城忠魂整理最后的仪容。
- 若林恩在银色幻想浑身浴血地跃至主母身侧、与她背靠背架起三叉戟与银剑迎战四面八方扑来的魇魔大军时，于识海中向这两位替自己撑起天幕的长辈与挚友深深叩首。
- 若林恩在主母绽放的圣光震散了笼罩圣所上空的无序黑雾、让久违的一缕清风吹入王庭时，深深吸了一口那混杂着母亲神力余温与硝烟的空气，将这份味道化作自己第三阶段神格的底色。
- 若林恩在艾雯跪在圣所内感受着门外主母正在燃烧生命、哭着向林恩磕头说「林恩，快一点，再快一点完成晋升啊」时，不再抗拒王座对绝望的鲸吞，主动张开双臂迎接那场刮骨熬魂的蜕变。
- 若林恩在主母一戟刺穿一尊上前叫嚣的终焉魇魔咽喉、自己握戟的虎口也彻底崩裂露出森森白骨时，顺着戟杆送去一丝温润的生机替她止住颤抖，则她拔戟再战的动作依然优雅如初。
- 若林恩在感知到主母为了不让战斗余波震坏圣所大门、每次硬接魇魔重击都刻意用自己的脊背去卸力时，心如刀绞般在王座上流下金色的血泪，每一滴血泪都化作加速破封的燃料。
- 若林恩在主母最后的绽放将周围十数座终焉之柱的投影灼烧得嗤嗤作响、逼得漫天魇魔一时不敢近身时，将这短暂的寂静化作神魂风暴，一举冲破了第三阶段晋升的倒数第二道关卡。
- 若林恩在银色幻想看着主母气息渐弱、主动横剑挡在她身前高呼「只要黑夜城的骑士还在，休想越过此阶」时，让三叉戟分出一缕金辉缠绕在银色幻想的断剑之上，助他再斩一魔。
- 若林恩在主母燃烧本源的火光映照进幸福之家孤儿院地窖缝隙、让夏娃与孩子们感受到如母亲怀抱般的温暖时，将这份温暖永久封存在孤儿院的地脉之中。
- 若林恩在主母神力即将见底、原本璀璨夺目的金色长发开始从发梢寸寸化作透明光点消散时，拼命伸出被锁链拴住的右手朝圣所大门方向虚抓，仿佛想要抓住母亲正在远去的衣角。
- 若林恩在目睹这位一生自缚、从未为自己活过的天使在生命尽头绽放出超越诸神的光辉时，在心底立誓：待他重塑乾坤之日，定要还她一个无需背负任何枷锁的自由人间。
- 若林恩在主母最后的绽放即将落幕、漫天漆黑恶魔长矛已在黑雾中悄然举起的至暗前夕，将全身黑火压缩至心脏一点，积蓄着随时轰碎整座圣所的终极雷霆。
