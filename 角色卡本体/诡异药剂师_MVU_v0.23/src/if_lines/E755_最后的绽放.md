# E755·最后的绽放·if线

- 若林恩在主母取出三叉戟前从王座隔空按住她手腕一瞬，则三叉戟交接延迟半秒，银色幻想在外墙多扛下一波黑潮，主母对她的对视多一缕确认。
- 若林恩沿王座因果把一缕黑火预先缠上三叉戟柄，则三叉戟在银色幻想手中首次回应时不是金色而是金黑双色，灾厄主人痕迹被主动照亮一次。
- 若林恩把最后一段「我在」沿王座写进主母神性，则主母在承受正面噩梦冲击的瞬间神格不颤，承接时长 +数秒。
- 若林恩通过王座把撤离者中某个已死工匠的记忆压在光幕褶皱里，则那一段光幕在被撕裂时以工匠手艺方式重新缝合，而不是单纯燃烧主母神性。
- 若林恩让王座故意漏出一道假破绽给噩梦侧翼，则噩梦主力短暂被引偏，银色幻想堵口的机械节点得以多布两座。
- 若林恩在机械军团分节点时通过王座给其中一座写入旧疫医师暗号，则那座节点在崩毁前反向释放一枚血气爆破，把扑上来的一段黑潮震退半米。
- 若林恩把主母神性与石柱连接的位置往内城再压半寸，则光幕正面弧度改变，噩梦第一波冲击被打散成两股。
- 若林恩让王座在光幕上翻写一段过去黑夜城守卫的列阵口号，则响应而回的残缺法则在衔接段更早对齐，E756 旧军团回返多一股先头。
- 若林恩隔着王座朝银色幻想送出一句短到不能再短的「顶住」，则她未抬头但持戟的右手紧了一分，三叉戟回应持续。
- 若林恩在王座里拒绝听撤离者的哭声、把听觉锁死在主母呼吸上，则他不会先崩，但主母神力流失曲线被他自己越缠越紧。
- 若林恩主动让王座黑火舔过石柱根部一次，则柱体表面被烧出一道黑纹，从此外界噩梦接触柱体时会被黑火倒咬一口。
- 若林恩把三叉戟交接瞬间大气中逸散的神性碎屑收进王座存档，则他未来能把这一缕交还给新一位承接者，三叉戟认主链不被打断。
- 若林恩先挡下某个试图趁乱穿越撤离通道的漏网魇魔，则撤离队伍尾端不减员，但王座被黑火在那一秒焠得发白，他对主母心声的回应慢一拍。
- 若林恩在主母开口安慰撤离中的某位年幼生还者时替她补一句沉稳的话，则那名年幼儿女在撤离另一端回头望了一眼光幕，E756 多一线「回路信标」。
- 若林恩允许王座把主母写在石柱上的最后一段悄悄话暂时缓存，则他不会当场破防，但那段话被延后到更残酷的时机才放出。
- 若林恩在三叉戟半空时先一步把自己的王权烙印烙上戟身，则灾厄主人痕迹以此为饵愣神一瞬，主母交接多出一口气的余地。
- 若林恩命令王座把某座废弃内城石柱连根拔起掷向侧翼黑潮，则正面压力略减，但内城记忆层随之塌陷一角。
- 若林恩在主母回头望他那一眼时没有别开视线，则主母以周身神力把这一眼钉进他的王座背面，日后他无论逃到哪里都躲不开。
- 若林恩让王座在两座机械节点之间拉一条肉眼看不见的血肉戏法细绳，则噩梦冲断其中一座时另一座会突跳半步，让第一人偶家的残余丝线找到可依附的形状。
- 若林恩直接对王座下令「把我也算进光幕」，则黑火自愿沦为燃料之一，主母第一次以眼神责怪他，但光幕多烧出整整一轮轰炸的厚朴。
- 若林恩让王座主动扭曲噩梦最浓重那一处的因果，则那一段黑潮绕成环状自噬数秒，主母肩膀上得以卸下一击。
- 若林恩在最后光幕即将熄灭一秒前把自己的黑火灌进即将破灭的撤离门，则撤离门尾端生生多撑一粒呼吸，让最后一名老妇人跨出去。
- 若林恩把王座的听觉主动放大到能听见撤离另一端年幼生还者的小声感谢，则他黑火的稳定性短暂上扬，但被回灌的因果残渣随之更多。
- 若林恩提前把自己的一小缕血滴在王座边沿，则未来他在梦中重回到这一日时，能在血的味道里准确找到这一秒。
