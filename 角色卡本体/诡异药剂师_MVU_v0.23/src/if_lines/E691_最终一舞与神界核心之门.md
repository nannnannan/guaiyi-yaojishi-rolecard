# E691·最终一舞与神界核心之门·if线

- 若林恩在金色屏障拦路前先以戟尖顶住那道金光替自己撑开一条缝隙，则屏障会偏一寸，他在另一侧会被真理抬手扣住手腕向后一拽——这位神王第一次亲眼看到自己立下的绝对法则在一个外来者身上出现裂缝。
- 若林恩在真理说「还没被疯狂吞噬」的同一瞬间主动朝第三层方向回望一次，则那位神王会捕捉到这一眼，金色书页在他膝上停顿半拍，但他没有转身，只极轻地说了一句「不要回去」。
- 若林恩让龙心的光束在光幕中央多停一息才轰然洞开，则洞口另一侧不再立即显现神王界的法则风暴，他能在那扇门的成形边缘瞥见那道金色身影正渐行渐远的背影一角，像一道被没收回去的落日。
- 若林恩把第二只渡鸦尸体也预捏一缝、留作门内紧急情况下的备用法则核心，则它不会在三叉戟世界里被分解，而在他踏入 E692 时以最纯粹的状态重新成形为一只金色瞳仁的成年鹰，代价是 E693 起手时他将少一项可押的资源。
- 若林恩没走这道已开之门，而是绕行第七层北墙外自行凿开一条通路，则他能避开正前方因果与金色少年的视线，但抵达核心之地的时间将比常规迟到三息，兽王石柱在那三息内的活化程度会比原轨更深一寸。
- 若林恩在跨入门内的前一瞬把三叉戟尖稳稳地钉入第七层废墟中央，则这柄戟将作为一处「仍在使用中的渡鸦信标」被记入神界档案，他日后再度回到此处，仍能凭借它一次性定位自己过去的一切踪迹。
- 若林恩在看见金色少年与因果的第一时间反手扣住少年的手腕将其一并带入核心之门，则少年眉心的真理神格会同时被吸入这条通路，因果在原地失声喊出他的名字，门对真理残魂的感知从那一刻起，与他手边这位宿敌紧紧纠缠。
- 若林恩让真理残魂在王座殿一战中把自己的半缕灵识系在林恩的戟韧上作监视而非信任，则当真理神格自金色少年眉心离体的瞬间，他能通过戟身白光实见那一幕——真理神王在充满敌意地夺回自己的神格时，眉尾明显颤了一下。
- 若林恩没推门而入，而是选择让这道由龙心所开的入口自行关上，则 E692 的入口从此消失，他必须另找一条未被魇王先知的路径踏入神王界，而真理神格在另一侧也不会再有他所熟悉的人手上的灰烬。
- 若林恩在坠落中把自己背上的布袋抖落朝下，让几缕疫医止血绷带融入金色涟漪，则这道入口在他身后持续残留两重防护——任何企图以非「真理」所披让的法则强势叩击此门的，都会先被一层无形的气墙拦住。
- 若林恩在门内先以梦境领域把整个入口裹住一圈再前进，则他的影子第一次彻底消失在这片神界当中，但镜像之魇在 E692 遭遇他时将无法在复刻阶段读到他完整的面貌，复刻的精度从略微模糊到严重失真。
- 若林恩在金色屏障落下时主动把身边的龙卫澜残存意志顺势推入裂缝一端，则她那缕从未安心休息过的灵识第一次找到一个完整的寄居所，她将在那里注视着下方所有向他倾斜的目光——以血脉、以信仰，或以一场千年未尽的守护。
- 若林恩让自己的影子在门前先停顿一拍，确认右脚腕的金环未被法则乱流扫断，再一步踏入神王界，则他能在门内看到因果那双如烟如雾的眼睛的最后一次睁闭，而她手上的白绫第一次被金色的微尘染出一线微红——这位千百年不曾崩溃的神王，眼泪第一次从面纱下面爬出来。
- 若林恩在坠落过程中尝试用一只早已破损的青铜腰牌护住自己的眉心，则他下一秒将被一束反向涌出的金色激流包裹，他手背上的紫罗兰徽记将亮起一瞬，然后他感到那扇巨大门扉在他身后合上时，轻轻转了半圈，像是一个没有落幕的谢幕。
- 若林恩让左左在他坠落最后一段程牵住他的左手手腕直到最后，则她真正脱手前会把手腕上三根已发硬的指骨留下一段在他手心里——她的身躯在金色涟漪中消散无踪，但他手里最后那一撮发烫的鳞片将永远是她活着的证明。
