# E337·黑夜城围攻与视界战场·if线

- 若林恩在黑色液滴攀入结界前用一瓶【理智之血】泼洒城墙，则藤蔓在接触瞬间集体僵直，病变渗入速率减半，艾雯爵士的迎击得到额外缓冲。
- 若林恩让羽毛笔在血墨折断时改用他的血书写，则字迹勉强成形但每写一笔他指尖就裂开一道新伤，城内警报由红转紫。
- 若林恩在城内开启心灵巨人模式反向吞吸病变，则潮汐被短暂压回，但巨人躯体表面浮起黑斑，艾雯爵士在E338时多一道「被污染」标记。
- 若林恩把月儿兰丢向拥星者的恒星攻击轨迹，则花朵在星核前无声湮灭，但那一瞬的反光让机械军团误判坐标，炮火偏移三公里。
- 若林恩用《看了就会死的书》对准小丑而非血肉支配者，则八音盒的音调第一次走调，祂的踉跄让围猎阵型出现半秒缺口。
- 若林恩在系统空间内连续十次尝试折跃，则每次失败都在坐标上留下一道空间裂痕，蜂巢的追踪算法被误导到其他荒原。
- 若林恩对血肉巨鲸的载员挨个发媚药，则鸟嘴面具下的呼吸声变得粗重，几头巨鲸在半空中失控相撞。
- 若林恩在视界之主触手庇护下主动切断一条触手，则庇护范围缩小但禁锢结界出现数据波动，机械将军的战术地图短暂雪花。
- 若林恩把左左藏进破裙口袋并让她在口袋里小声唱歌，则歌声透过布料渗出，咒体旋律让最近的机械单位动作变得像跳舞。
- 若林恩在回援黑夜城时先朝小丑掷一枚石子，则那只八音盒被击中音栓，诅咒加深的节奏乱了半拍，视界之主多一次移送机会。
- 若林恩在禁锢范围内用往日遗念投影出自己死后的影像，则敌军看到「已死之人仍在移动」的悖论，攻击指令出现逻辑冲突。
- 若林恩把天使之吻涂在箭矢上射向星核，则神圣力量在恒星表面炸开银斑，七神的攻击出现一次美学上的不洁。
- 若林恩在归途上选择不进入系统空间而硬闯机械罗网，则他的身体被炮火削去半边，但血肉再生的画面被全城守军目击，良医传说多一笔「不死」。
- 若林恩在拥星者显化时大喊「我认识你，开拓者」，则星核中的存在第一次迟疑，复仇与旧日功绩在祂意识里短暂交战。
- 若林恩把智脑的救治容器当作盾牌挡在身前，则智脑在数据世界里尖叫「我不是武器」，但攻击确实被透明屏障折射。
- 若林恩在庇护范围边缘用血画出反向召唤法阵，则阵纹未能完成但足以让囚禁他的空间出现一次心跳式的震颤。
- 若林恩让左左在关键时刻从口袋里探出头对小丑做鬼脸，则那张似哭似笑的面容第一次露出近似「困惑」的表情。
- 若林恩在撤离前朝城内方向投掷一支通讯药剂，则药瓶在病变区炸出短暂的安全气泡，三名残余夜医得以冲出包围。
- 若林恩在系统空间内用旧日记忆贿赂银色幻想让她提前调动舰队，则她沉默三秒后回了一句「这是最后一次」，蜂巢坐标偏移支援战场。
- 若林恩在庇护者耳边低声说「你也是我见过的最像人的神」，则视界之主的触手在移送他时多缠了半圈，力度刚好不让他被甩出去。
- 若林恩在围城期间用主母的黑羽作为信标，则大殿方向的病变结晶突然共鸣，一条通往地下的暗道在灰烬中短暂显形。
- 若林恩把乌鸦臂章高举向机械将军，则将军的护甲内侧闪过一道不属于七神阵营的古老刻痕，围攻指令在高层延迟了两秒。
- 若林恩在星核爆炸瞬间用时间魂媒定格自己，则他被冻结在半空，爆炸的冲击波从他身边绕行，但祂的灯油消耗了三分之一。
- 若林恩在系统空间内对左左说「这次换我保护你」，则咒体在口袋里安静了一整夜，她的咒纹第一次没有因恐惧而缩紧。
- 若林恩在回援途中把黑粉样本塞进一只机械信鸽，则信鸽在飞出禁锢范围前被击落，但样本碎片被风带到城外药剂师手中。
- 若林恩在庇护者被啃噬时主动用诅咒清除支援，则银光与诅咒加深正面碰撞，三位一体机、死星结晶与巨像之心同时出现崩坏裂纹。
- 若林恩在最终移送前对视界之主喊「我会把你救回来的」，则守护者的触手在分离时多停留了一秒，那一秒足够让一只远方的黑伞看见坐标。
