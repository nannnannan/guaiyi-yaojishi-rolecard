# E637·天鹰座首战与破碎之眼封印·if线

- 若林恩在贴脸折跃前主动让银色幻想先洒一把诱饵机制造假突破，则敌方大魔误判三秒，突袭近身的惨烈程度再压一档。
- 若林恩在突袭舰队成形时一声「母舰别插手」,则星际堡垒被指令强制节流远程火线，机械单位泛滥依旧但被挡在本队侧翼。
- 若林恩在斩首冲刺中主动先把三叉戟丢与巨像，则巨像第一次站上远征军前台的 C 位，她的身份曝光度被整支深渊军团记下。
- 若林恩在大魔最后一句实话前主动多录三秒口供，则战后会议多一段破碎神界「指挥权在彼端」的原声证词。
- 若林恩在夜幕展开前主动把拱卫根源排成梯队后撤三里，则金色边境张开时他们的反噬 -1，但整支防线的压场气焰 -2。
- 若林恩在闭眼前主动喊一句「左左，这段由你掌控边界」，则她第一次接过军令，金色边境展开时多一双绿色触手向外延展。
- 若林恩在领域张开瞬间主动让现实宇宙晖光透入一寸，则梦境与现实在边境处叠加一枚描金边缘，封印画面的未来观感 +1。
- 若林恩选择不御颚深藏指挥突进，则敌旗舰位置被晚推算半分钟，但本队战损减小三位数。
- 若林恩主动通过系统请示褪梦是否要继续投他，则神王一声不答，但战场上一枚远方的渡鸦长鸣与他重叠。
- 若林恩在边境压到破碎之眼瞬间主动下令「都别掠过去」，则军团退后半步，金色边境的吸收机制唯一一次在他主导下「停火」。
- 若林恩把金色帷幔结尾燃成石雕，则破碎之眼刹那熄灭时多一缕鳞甲，事后调查者发现「渡鸦封印」与「织梦封印」并列共存。
- 若林恩主动把梦境领域的初开示一次为「海碧之海」，则未来的迷雾之海在迷失幕中多了一小段「引子」的立场提示。
- 若林恩在封印完成后主动让银色幻想立刻发出「已告完成」的信号，则深渊中枢那片「胜利」的气氛比之前提前十五分钟到达。
- 若林恩在撤离之前主动把一方支架留在原地，则下一支远征军在打开这条通道时多一个初始据点。
- 若林恩选择撤离时回头多看一眼正在坍塌的破碎之眼，则他目睹「他们在吞噬」的最后一帧，心中多一分「此战是必须」的认知。
- 若林恩主动把战报画成一幅群画让中枢滚动播送，则军团的士气在曲率通道上游再增一档。
- 若林恩在破名首战后主动为巨像与银色幻想题词签名，则她们的名字在天鹰座档案黑牌里留下落笔，二人羁绊各自 +1。
- 若林恩主动让左侧小带下一次带出「七乐镜」，则他的情绪提醒系统获得一枚「这些不再是战术」的提示音。
- 若林恩把战后统计写成「一小时零二分」，则中枢和织梦对他的「闪电战」的名号少用一次「超于预期」的形容。
- 若林恩主动把这次战争视为「暴力的晨曦」，则他的下一战前提案的标签里多一项「暴力手段被历史同意」。
- 若林恩在第一次引爆梦境领域时主动把外放改成内敛，则领域收敛稳定不再溢出，但「金色边境」的规模缩水一半。
- 若林恩主动给拱卫根源戴上截法面具，则边境展开时他不会被黑洞压制，但整支队伍的法术声和 = 0。
