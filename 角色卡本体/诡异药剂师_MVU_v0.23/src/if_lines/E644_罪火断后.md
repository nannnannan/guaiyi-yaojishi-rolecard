# E644·罪火断后·if线

- 若林恩在织梦坚持「由她殿后」时主动让她立一个「三分钟内必回」的口令，则她在被召回时首次有了时间约定，林恩在海内多一枚牵挂计时。
- 若林恩主动在织梦撞入法则巨龙的瞬间把自己的三位一体灌一缕给她，则她的灵能屏障再次撑开 0.3 秒，二档【绯红】的开启被拉慢半拍。
- 若林恩主动在织梦吸噬力量时主动不抵拒，则她吸噬的成功率 +20%，林恩的二位一体强度在此战被多耗一分。
- 若林恩主动在织梦挥出【罪】前主动喊一声「回来」，则她隔空望他半秒，红焰长刀的挥砍路径稍微偏一厘米，金色少年肩膀多一道擦伤而非深可见骨。
- 若林恩主动在织梦化灰前主动伸手跨越天际把她拉回，则她的火焰被瞬间熄灭一部分，但她与林恩之间的灵能联系被缩减一半。
- 若林恩主动在织梦临终一句「你终于学会了冷漠」前先回一句「我不会让你白死」，则她眼中最后的欣慰与他心生挫败感笼罩，感情线闭合度提升。
- 若林恩主动在冲入迷雾之海前回头再看一眼她化灰的位置，则他被金色少年追兵的距离拉近三米，林恩的「学会冷漠」契约首次被自己写下白纸黑字。
- 若林恩主动让喵喵在织梦施展二档时跳上他肩头为他遮目，则林恩没看到「她化灰」的最后一帧，但他首次对喵喵发出一声「别让我看」的请求。
- 若林恩主动把【绯红】的招式名写进自己的系统，则他未来的三位一体档位在他面前打开一格，中枢档案多一笔「教学痕迹」。
- 若林恩主动在织梦断后瞬间主动把自己的一星颜色亮出来作为干扰，则金色少年的注意力被分散半秒，织梦的一刀多劈三米。
- 若林恩主动让银色幻想在奇异世界内立刻发出「织梦遇难」的求救信号，则军团的悲鸣在十分钟内遍布中枢，指挥官的存活度受到降低。
- 若林恩主动在主宇宙边境的迷雾之海入口前把手伸向迷雾，则他的手指尖第一次触到「法则在这里无效」的真实体感，迷雾之海的防线层数首次被他证实。
- 若林恩主动对金色少年大喊一句「下次我会赢你」，则少年嗤笑一声回眸，林恩首次把「下一次战争」的对象明牌化。
- 若林恩主动在织梦消散瞬间主动把她当成「远征队教练」而非临时教官，则林恩心中关于「教官」的定义第一次升级，织梦的军衔由「外援」晋升为「亲内战友」。
- 若林恩主动在奇异世界内向众人说出一句「她是为我而死」，则林恩首次背负「教官命债」，中枢档案中多一行公开的「教练遇难」的辩证记录。
