# E249·血肉灾变与首次涩涩·if线

- 若林恩在左左看到那根"万恶部位"之前先把它用一块护布遮住不给她看，则她的三观不至立刻碎裂，"san-5"结算被替换成"san-3"，事件以变形（含蓄一些）收束。
- 若林恩在拔出它时加上一句血淋淋的解说"这是我父亲血脉的展现"，则她被这突如其来的孝道宣言搞到哭笑不得，san结算再次降低。
- 若林恩在"我真的是为你才做这样的牺牲"表白时顺手从系统空间取出一个黑颅币塞给她作为聘礼，则她一边骂一边收下，事件以变形（送礼OR挨骂）收束。
- 若林恩在她想逃的同一秒让左左傀儡忽然出现在她背后又吓她一跳，则她被双重夹击，但傀儡"左左"只是安静地递了杯水，事件以变形（傀儡感化）收束。
- 若林恩把那根血肉生殖器的灾变等级从"粗壮大肉棒"降到"迷你可人款"，则她吐槽效果反而被削减，"切"的一声替代了原本的剧烈反弹。
- 若林恩在世界之眼站稳之前的某个时刻不再要求"涩涩"而是紧紧抱着她说"只是想碰碰你"，则她原本的纠结被定格为"被疼爱上来的泪"，事件以变形（温情涩涩）收束。
- 若林恩在她抱紧他脖颈时让巨像之心反向反应一次"用力跳动"，则她误以为他对她动心、心甘情愿地被支配，事件以变形（心跳共舞）收束。
- 若林恩在她委屈哭泣时让她的眼泪汇聚成一枚记忆晶体收藏在系统空间，则他后续随时能回看"她第一次为我哭的样子"，事件以变形（储存记忆）收束。
- 若林恩用主母的红茶包在她身上点了一下熏染香气而非任何物理触碰，则她被"神圣的气息"束缚在原地，事件以变形（圣香定身）收束。
- 若林恩让左左在高潮的瞬间看见他机械之躯上贴着一张"她是他妻子"的便利贴，则她被这宣告震慑，事件以变形（宣告存在）收束。
- 若林恩在事后陪她看月亮时告诉她"我不会用这种感觉勒索你做什么"，则她被这温柔打动，事件以变形（涩涩之外有信用）收束，但这层信任被延伸到更多未来的事件发生。
- 若林恩在手上做些花哨功夫、让这个"肉棒"的外形按她上一次喜爱的骑士剑形状进行改造，则她被这奇特的浪漫逗笑，事件以变形（玩具型）收束，道德再扣但快乐+5。
