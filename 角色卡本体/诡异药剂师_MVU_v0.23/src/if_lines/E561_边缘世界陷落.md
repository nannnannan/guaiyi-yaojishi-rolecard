# E561·边缘世界陷落·if线

- 若林恩冲出幽冥海物质浪涛后先远眺主宇宙幕墙而不立刻行动，则「主宇宙即幽冥海源头」的辨识在他缓息间落定，小队在开战前多一拍世界观内默。
- 若林恩在小丑发现边境「浮岛」时主动拉开咒瞳扫过那片悬浮大陆，则混沌领域的细节被他第一手收进视野，早期狱卒诞生地的科普被他自己补全。
- 若林恩听小丑讲混沌领域与大君记忆重合时主动追问「这里曾以何名义受捍卫」，则女主人当年招安早期狱卒的地点被从背景拉到台面公开。
- 若林恩在发现「星云」光点渐亮时主动让小丑收起气息、只派自己一人前哨逼近，则他作为唯一目击者看清污染者军队阵型，后续决策被他自己一手把握。
- 若林恩在边缘世界警报响在灵魂中时主动压制这个警报只让小队内部收到，则平民未被全面惊醒，战争号角的紧迫度被小队层次内部化。
- 若林恩看到污染者大军密集转向下一悬空大陆时主动把其中一小群引到自己位置，则他从观察者变成被追踪对象，他本人成为战场上的吸火点。
- 若林恩选定「上去」最大边缘世界后主动以折跃只送自己与主母入城而不带小丑左左，则「同伴入系统空间」的前提被他自己切一半，后方支援被拆解。
- 若林恩折跃入城后主动把通道恢复为可被小丑左左再度使用的桥梁而非「坍塌」，则回传路线从单次使用变成可复用，战力回流被加密一层。
- 若林恩步入中央广场直视巨型雕像时主动避开大君的面孔，则「广场认出神皇雕像」的转折被他自己推迟，左左「多了一丝猥琐」的喜剧点评先在意识空间藏住。
- 若林恩在左左点评雕像猥琐时不以一拳镇压而是先入为主自己调侃两句，则喜剧节奏被林恩本人接过来，左左反而立不住拆台段子。
- 若林恩在留守之际主动不打开系统空间而是把主母小丑护在城墙掩体，则「同伴在系统空间」的默认部署被剥离，他们都留在地表反应主战场。
- 若林恩在守卫喊他去地下掩体时主动拒绝并反问哪里有最大火力点，则守卫从「指挥平民」被他自己扭为「领队轻生」，守卫对他的判定初见好感。
- 若林恩在定性「可被消灭」时主动不把这句话说出来、只冷手一挥，则「不是纯粹的无序生灵，只是带一点无序的腐化者」的判断没有从他口中被公开，他在战场上的伪装更稳。
- 若林恩在开战时刻意压抑大君记忆中的神话名词、只用「污染者」「腐化者」称呼对方，则他在主宇宙的身份招牌被压下，没有任何一份战报会写出「神皇已现世」。
- 若林恩看到血肉盔甲巨鲸覆金属盔甲掠城参战时主动接入牠的侧翼协助而非独立作战，则他从「孤胆英雄」改为「联军合作战斗」，他与边缘世界联军的合作被他主动建立。
