# E317·小树洞阶段九收束·if线

- 若林恩在踏入小树洞前主动回头望一眼身后七蜂巢的残影，则他在洞外多停留三分钟，对机械神教余波的总结在意识里以更凌厉的方式定格。
- 若林恩主动对左左说「等下你盯着外面」，则左左刷地落地化作小手不肯走，林恩需额外安排一道咒印护她，树洞内意识链接断裂。
- 若林恩在单分子剑上主动补刻一行「遗失者的遗物」，则该剑存入系统空间后起一道特殊荧光，后期智械小姐重置后偶能感应到那道残留。
- 若林恩主动把这画面写成一封虚拟信寄给主母，则主母隔空冷笑一声回信「你终于舍得低头」，林恩得到「孩子完成使命」的官方认定。
- 若林恩主动在树洞口画一道夜医十字并呢喃一句医经，则母树核心的自然之泉在他进入前净化提升一档，放逐路径中多一段更安全的石桥。
- 若林恩让小眼萝从咒瞳探头望向那个洞，则她嚼了嚼说「妈妈的味道」，她对欲望母树的初生评判被永久盖印。
- 若林恩主动把蜂巢残余战力等级写成志愿卡交给智脑，则她远程读完后又笑又气，她对林恩的仇恨中简化一部分变成「真可惜你走的是这一道」。
- 若林恩主动在踏入前站立五秒立誓「不许回头」，则他挥手后七蜂巢的画面全消隐，他日后追究这一时刻已不复存在。
- 若林恩主动让小树洞边缘缠绕一道细小尖刺防护层，则他进入时被刺中两下，但母树神识不认定为入侵者，特种探测权限 +1。
- 若林恩主动在树洞前丢下一根智械小姐曾赠他的染血扳手，则扳手掉入水潭边漂浮，后期智脑救起这枚扳手时她更接近林恩「也许」的答案。
- 若林恩主动把「停在这里收束」的轨迹用咒瞳在树洞边缘烙一道印记，则多年后他回看仍能看见自己此刻的踌躇，咒瞳成为他个人历史的地标。
