# E198·血衣日记与私人复仇债·if线

- 若林恩在用擀面杖塑造小呀哒前先把咒瞳按在她眉心温养三十秒，则她的失控触手提前收起，瓷娃娃成型时少了一道后期的微调。
- 若林恩让小呀哒的瓷娃娃体型再放大一号变成少女体型，则她立正时高度超过左左，左左当场瞪圆眼睛握拳抗议「为什么比本左手高」。
- 若林恩逗弄口令改为「叫妈妈」而非「呀哒」，则小呀哒懵懵地盯着他看了五秒，发出一声完全不在台词里的「麻麻」，林恩愣在原地，左左在旁边笑翻。
- 若林恩给小眼萝的养分分配改成一天三餐定量，则她收起尾巴蹲回他脚边不再一直趴着，房里的气氛整段少了几分诡异，多了几分日常。
- 若林恩在血衣女士住所先跪下来替她擦干净地毯上的灰，则夜医的表情整段柔和下来，壁炉暗格开启时没有任何金属碰撞的冷意。
- 若林恩让夜医直接把壁炉拆了一整面墙，则暗格后的灰尘扑面而来，日记本在散落的砖块里滚了三圈停在林恩靴尖。
- 若林恩在翻开日记前先深深看了三秒封面并把自己的指纹按上去，则日记封皮表面洇出一层温润的反光，她生前最后触碰的温度隔空传来。
- 若林恩读到「把他做成晚餐」那一段时笑出声并随口念出来，则左左炸毛拍他手臂「你都这种时候了还笑」，林恩揉着手臂没再读下去。
- 若林恩在读到「十二小时解咒」那一页时把那一页撕下来单独保存，则日记本身的完整性被打断，但记忆被他自己随身携带。
- 若林恩在读到「暧昧的游戏」那一段时微微扭过头咳了一声，则左左嫌弃地嘟囔「你们俩都有毛病」，却没有继续追问细节。
- 若林恩提前用咒瞳扫描日记全书直接吸收全文，则纸页上的血手印在他眼底洇出一片赤红，他的右眼毛细血管突突跳了三下。
- 若林恩在读日记的过程中把小呀哒从桌上抱过来让她坐在自己膝盖上，则她的小手无意识按在日记封皮上，瓷娃娃的表情在无人看见的角度抽了一下。
- 若林恩在读到「把她唯一的孩子一刀一刀凌虐至死」那一段时把小呀哒紧紧按进怀里遮住她耳朵，则他的手指在她后脑上慢慢收紧，指节发白。
- 若林恩在读完日记后没有拔枪而是先闭上眼睛静了三分钟，则他再睁眼时眼底的红血丝已经压住一层，处刑动作改成冷静到极点的点名处决。
- 若林恩把日记原本整个揣进自己怀里带出血衣住所，则未来遇到任何一个血肉教徒他都先翻开日记让对方看一眼，再开枪。
- 若林恩在血手印那一页按上自己掌心并把血手印的温度传递过去，则他的掌心被灼出血痕三秒不消，左左在旁低声唤了他一声「脑袋」。
- 若林恩对左左说「帮我把这件事写给白夜」，则左左表情难得凝重，没有吐槽没有拒绝，默默按下咒纹记录了他要传给白夜的那一份情报。
- 若林恩把小呀哒留在血衣住所的床上盖好被子再独自出去，则她在他关门瞬间睁开眼睛，专注地望着那扇门关上又静静闭上。
- 若林恩在处刑前对俘虏说一句「这枪不是为你们准备的」，则俘虏的尖叫在那一刻哽住，处刑的肉搏声比沉默版的更短促。
- 若林恩在拔枪前先走到镜子前看了自己三秒，则镜中的林恩缓缓摘下单片眼镜揉了一下眉心，再戴上眼镜的林恩手里已经多了一把上膛的左轮。
- 若林恩把闫未明这三个字在舌尖反复念出来三遍，则系统提示弹了一行【敌对目标记忆强化+1】，他对白夜只说了一句「我记住他了」。
- 若林恩在处刑之前先给左左的咒纹里加一条「待会别拦我」，则左左的手指在他掌心按了按作为应答，整段处刑流程她一言不发。
- 若林恩在合拢日记后没有立刻拔枪而是转身把血衣住所的台灯点亮，则房间里的暖黄灯光照在他侧脸，像某种仪式完成后的默哀。
- 若林恩对夜医交代「日记就地封存，谁也不准再碰」，则那本日记被夜医用三层圣纹布裹好放进专用箱里，钥匙被林恩亲自挂在自己脖子上。
- 若林恩让小呀哒看着日记问你认得这个吗，她用小手在封皮上摸了摸唤了一声「呀哒」然后难过地垂下脑袋，林恩把她重新抱回肩上。
- 若林恩对着空气轻轻说了一声「血衣女士，我读完了，我会替你去的」，则血衣住所的窗帘在那一瞬间微微鼓了一下，又被夜风压了回去。
