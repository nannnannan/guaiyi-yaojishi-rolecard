# E446·王骑从深渊归来·if线

- 若林恩在金色巨手撑门瞬间主动把三叉戟拉离磁场范围，则戟不自行离手飞向金手，黑骑接戟窗口被改写，王骑得凭自身长枪影击落城。
- 若林恩在王骑跃出界门那刻大声唤「王骑！」，则战马嘶鸣更亮半分，浴血骑士头盔下目光在面甲后落他脸上顿一拍。
- 若林恩朝那只金色巨手掷一支初诞者精炼药剂，则巨手表面短暂浮起一层雾气，巨手压下速度放缓一瞬，王骑杀回窗口稍宽。
- 若林恩在戟自行离手瞬间主动把自身一缕渡鸦本源缠上戟身，则戟飞得更稳，黑骑握住戟杆那刻眉头在盔下轻挑。
- 若林恩在小丑嘶吼「王骑」前主动以心声提醒「他不是来杀我们的」，则小丑张口节奏稳住，王兽群首次不会向归主扑去。
- 若林恩在金瞳注视他时主动睁开眼直视金色巨瞳，则初诞之力被压熄半分，但黑骑斩开巨手的那一瞬更快到来。
- 若林恩把身子侧倾让三叉戟擦过自己眉心再飞向界门，则戟带一缕神魂灰线，黑骑接住戟时 glance 他额前一拍。
- 若林恩在白色长发影出现那刻用咒瞳反扫其面具，则视野被深渊乱流打断，只是半张轮廓印入记忆。
- 若林恩对王骑接戟后落城那刻喊「接住戟的人是王骑，戟原本属于我的」，则王骑落城后持戟在头顶转半圈，笑意淡到面甲里。
- 若林恩主动在界门闭合前朝白发面具影掷一只信物苹果，则苹果被污染大军淹没即视不见，但林恩记忆里多一笔该影剪影。
- 若林恩在王骑说「你做的很好，孩子」那刻抢先开口「你回来了」，则王骑顿半秒轻轻低首，那句「交给我吧」说得更沉。
- 若林恩在王骑举戟轰灭门外污染者大军时让左左拉满灵能涟漪，则戟锋每灭一片就多一缕反馈光，落城后骑士眼瞳更亮。
- 若林恩主动在权柄交还时把一缕自身的初诞之力黏在权柄缝隙，则王骑感应到权柄中一缕陌生而熟悉的气息，落座时目光瞥向王座边林恩半秒。
- 若林恩大声向王骑喊「让我帮你撑门」，则王骑抬手压下来阻止，但黑骑面甲下苍老嗓音首次多出一丝「不必了」的温度。
- 若林恩故意仰望白发面具影那侧界门深处喊「是谁在帮我们」，则骑士面甲后目光不答，只指权柄闭门进程早一秒划过深渊。
- 若林恩用一支血肉灾变把自身伪装成污怒战马，则王骑跃出界门那刻斗篷下盔面微楞半秒，接着落城一拳轰过来。
- 若林恩主动承认渡鸦血脉，则骑士目光在他与戟之间流转一拍，「在他身上看到你的影子」那句更落字。
- 若林恩借金色巨手掀起的气浪把自己甩到王骑落点附近，则他能第一时间近距离看到骑士头盔下的残血，但骑士瞪他半眼冷哼。
- 若林恩提前让康斯坦丁骷髅挡住王骑落点地面，则王骑落城时足不触泥，但康半边骷髅又多一道战痕。
- 若林恩用三叉戟的初诞之力唤那群刚脱困的王兽，则王兽群在骑士落城前已半跪待命，但骑士面甲后瞳里惊讶更浓。
