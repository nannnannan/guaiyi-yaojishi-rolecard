# E683·龙卫迁移与幼龙坐标·if线

- 若林恩先把庇护所里几位伤势较重、灵能不稳的遗民单独圈入一处法则定格的小空间再张开五指收人，则三叉戟世界里的震荡波次更低，龙卫澜在跃迁末段的干呕从一次减为一次短促反胃。
- 若林恩典当三只渡鸦之前先检查盒子里是否还有第四条陌生翎羽，则他会发现画家在盒底夹着一张泛黄的坐标残页，残页上的行宫方向与龙卫澜记忆里偏差不到一星位。
- 若林恩没把艾维儿从系统空间提出来，而是直接以精神链接把黑雾画面投给她，则她仍会含着棒棒糖「甜~」一声，但她会先把嘴里的糖捏碎、呆毛竖起，再闭眼感应，锚定线更稳。
- 若林恩在龙卫澜展开记忆时主动以初诞者之力替她承接一半的精神压力，则她的跃迁眩晕减半，但林恩在远望行宫时会持续有小半秒视觉模糊，那个金色少年的转头画面在他视野里多闪了一帧。
- 若林恩把庇护所全部人收进三叉戟世界后顺手把魇群盘旋路径也复刻一份备份，则事后龙卫澜能凭这份备份验证自己是否已被行宫的凝视之眼标记，路径标记上多一行「疑似已波及姐妹」。
- 若艾维儿主动抢话要先感应再讨糖，则她抱起棒棒糖龙吸水的速度会更快，黑雾在她嘴里绕出一个肉眼可见的漩涡，行宫深处锁链的嗡鸣比原先提前一拍回传。
- 若林恩建立思维链接时没有让艾维儿走完整段地下阶梯，而是提前在最重那扇门前切断，则反噬的深度一减，他不会亲眼看到那尊破碎王座，但她会指着最深处说一句「老爸那个东西在看你」。
- 若林恩剥离艾维儿时顺手在湮灭区边缘掷下一支血包，则那片齑粉里会浮起一把被浸透的灰烬，渡鸦分身成形瞬间能从灰烬里抓回一缕极淡的腐化样本。
- 若林恩从系统空间摸出渡鸦尸体时不注入初诞者之力而是改用三位一体之力，则那只复活的渡鸦不再是「与林恩一模一样的脸」，而会化作一只眉心燃着金色瞳仁的成年鸟形，他失去人身伪装但飞行速度倍增。
- 若林恩让渡鸦分身在成形后先在三叉戟世界内走一圈巡看龙卫与遗民，则庇护所众第一次见到这只「渡鸦」会齐齐一震，龙卫澜会默不作声地对它行一个短暂注目礼。
- 若林恩没采用画家的盒子里现成的渡鸦尸体，而是反手去系统商城订一份「无徽渡鸦胚胎」，则交付会立即生成一条「E683 异位交付」记录，渡鸦分身将在 E684 开场时以幼虫形态爬行而不是人形。
- 若林恩在登上破碎山崖前一瞬撕开一小道空间裂口伪装成普通无序塌陷，则行宫的凝视之眼会优先扫向那道伪裂口，被他捕捉到 0.5 秒反向锁定的空余。
- 若林恩在湮灭发生前一刻抓住龙卫澜的手先退到黑雾边线而不是直接传送，则整片齑粉冲击的余波仍会在他衣角烧出两个洞，行宫警报会被完整记录但仍向「未知入侵方向」笼统汇报。
- 若林恩在龙卫澜说出「女主人不显」后主动追加一句「我现在才来接你」，则她会愣住半秒，跃迁中的一行龙卫残魂会在三叉戟世界里同时低头，「女主人未忘」这句话被悄悄写进他们心中。
- 若林恩告诉渡鸦分身不必闹得越大越好、只需精准炸掉行宫西侧舟坞，则渡鸦会被魇群围剿得更慢，但那座被锁死的舟坞里正在检修的一艘噩运方舟将带着半成品的无序引擎一并殉爆。
