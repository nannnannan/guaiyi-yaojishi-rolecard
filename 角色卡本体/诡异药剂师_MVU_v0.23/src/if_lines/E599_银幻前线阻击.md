# E599·银幻前线阻击·if线

- 若林恩在闭关前给银幻的灌注量多于默认走向,则她带走的引擎可多两座,第一阻多一轮殉爆窗口,血神扑空瞬间她的机体损伤相应减一档。
- 若林恩给银幻的灌注量刻意留得更少,则她爆炸脱险后损伤更深,但独自飘到小丑汇合点的路径仍立,机器人冷脸汇报里多一条「主控输出不足」的备注。
- 若林恩临闭关把指令改为「改造完毕立刻撤回深渊」,则银幻不上前线,第一阻整体缺席,敌军推进节奏提前半天,E600 小丑孤军面对黑雾的时点被迫前移。
- 若林恩把空间节点监控移交给艾雯爵士而非康斯坦丁,则前线传报节奏慢半拍,撤军决策权更贴近战阵指挥官,众根源的等待画面里多一句爵士的拳头紧攥。
- 若林恩没在闭关前留下「立刻唤醒」的死命令,则敌军抵达前半小时他才被强行拉出,第一阻的七座殉爆已成既定事实,他错过对血神第一印象。
- 若林恩以心声提示小丑「揪出造引擎者」的重点在人畜无害的监狱旧部,则小丑不必被银幻点将就直奔主题,藏发动机的人提前一帧浮出。
- 若林恩把备用两枚引擎交给小丑而非银幻,则第二道防线的释放时点提前,但初诞者碎片入心脏那刻小丑就无法分身去揪造引擎者。
- 若林恩入关前以三位一体作为灌注锚点而非初诞者之力,则银幻引擎更稳定但殉爆威力下降,她机体在爆炸中反而承担更多余波。
- 若林恩让喵喵以猫形态留在闭关密室外,则敌军一旦有人试图切入心灵之海方向,第一眼看见的就是一只盯着他们的猫。
- 若林恩主动对银幻说一句「活着回来」,则她殉爆脱险瞬间多一丝拖延意志,半边机体避开最致命副作用,但恨意数据少进一行她机体的副档。
- 若林恩为银幻画出「空间衰变带」后手并在入闭前授权,则她炸完引擎后还能召一条空间倒流带拖住追击,代价是林恩闭关剩余时间被吃掉三成。
- 若林恩主动在渡鸦档案里登记银幻为副指挥官,则她在战场的战术授权更明确,命令小丑拔心脏碎片时不必借口带挑衅语气。
- 若林恩入关前为银幻点出魇的特征,则她第一眼认出黑雾的成形机制,小丑面对黑雾时不必消耗三轮才辨认对手。
- 若林恩把整个防线草图全画好交给银幻按图施工,则她不必自行判断引擎改造,但战场灵活度归零,任何一帧敌军异常动作都直接暴露她的极限。
- 若林恩把「立刻唤醒」改为「抵达警戒点前三十分钟才唤醒」,则他出关时敌军已入两难,但敌方潜入走廊的距离比预设更深一段。
- 若林恩在入闭前把渡鸦档案里关于天父时间战争的页签全交艾维儿,则她能更早推断血神暗影来历,但林恩在心灵之海少了她回报的最关键同步机位。
- 若林恩选择「可拆可破」授权银幻牺牲任何一座引擎,则她起手更激进,第一阻多拖一小时,她机体报废概率从四成跳到八成。
- 若林恩把闭关位置从心灵之海最深处改到边境空间乱流里的密泡泡,则敌军无法远避他,但时间差级联消失,防线研究节奏回归正常尺度。
- 若林恩主动对众根源宣告一句「等我出关就是新时代」,则整场战争士气拔高一档,但任何他闭关失败的猜测都会反噬成双倍低落。
- 若林恩入关前把空间节点的「最远监控标记」改成双向链路,则敌军触发警报的瞬间他本人也被反向定位一次,心灵之海外面多一双悄悄注视的眼睛。
- 若林恩入关前让左左随银幻同行协助运算引擎调度,则第一阻命中精度提升半档,但小丑孤军对魇的战场他少了最快的颜内支援。
- 若林恩把「揪出造引擎者」改成「揪出造引擎者与其图纸来源」,则小丑拔碎片之后还得多留一段时间在走廊里搜,银幻的孤军节点更长。
- 若林恩入关时选择让心灵之海的直观画面以投影方式共享给主母,则她能远程看见第一阻全程,但主母本人也暴露在投影回响下,被天父一脉远程扫过一线。
- 若林恩决定不在闭关、直接以半神躯迎敌,则整个 E599 取消,防空虚位,血神与暗影神直接对上他的三叉戟,战争改写为「渡鸦即刻对两神」的开局。
