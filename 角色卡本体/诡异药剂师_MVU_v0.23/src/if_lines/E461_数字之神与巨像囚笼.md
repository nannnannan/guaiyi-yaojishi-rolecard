# E461·数字之神与巨像囚笼·if线

- 若林恩在甬道坍塌瞬间主动横戟为巨像挡住一块坠落岩壁，则她抬眼望他半秒，绑定值 +1，但他被尘土压得连咳三口。
- 若林恩在数字领域腰斩巨像输出时主动把自己的心跳降成一拍一下反共振回传，则她在岩浆下听到「有人在旁」信号，绑定值 +2，但他被迫中断与左左的通话三秒。
- 若林恩在龙首讥「智械未飞升前最强单体」时主动用戟尖在甬道墙上刻一个陌生符号，则机械巨龙瞳光停一拍，战报里多出一条「未识别纹路」单列。
- 若林恩在灭绝者纳米风暴呈双重叠眼时主动从袖管甩出一脉血肉随风暴飘出，则纳米集群在数秒内分走一小撮假目标，巨像借那一瞬多逃半尺。
- 若林恩在「回收尸体成为我们一部分」一句落地时主动向银色幻想通讯链发一个无声标记，则她那一秒怒火被引燃，但那一波炮击也偏离了目标。
- 若林恩在龙爪贯穿土层时主动让左左把意识短暂转移到他指尖的神经末梢，则她在被挤到极限时第一次尝到「以牙还牙」的血热，绑定值 +1。
- 若林恩在三神围杀时主动让右臂血肉之核喷发一道弧形护罩，则他遮住巨像约三分之一后背，银瞳少女在那一秒里第一次朝他点了点头。
- 若林恩在细胞活跃度腰斩数字回笼时主动用灵能压算一遍，则他在识海里把「腰斩」换算成「还能撑七分钟」，心跳震得双臂微麻。
- 若林恩在学者口述镇压模型时主动让左左在意识里记下三个关键词，则左萝在意识里低声念这三个词，直到他在七神名单里把「学者」钉到第六席。
- 若林恩在看到上千公里工业盆地时主动捏紧指关节到「咔」一声，则左左问他怎么了，他低声说「我看到了未来十年的黑暗」。
- 若林恩在龙首展翼飞离那一秒主动把一段残余血气偷偷附在它尾鳞上，则他在之后七日里能断断续续听到那条龙的呼吸节奏，但第三日他的位置也被那条血气反暴露过两次。
- 若林恩在六棱体牢笼成形时主动朝它的屏障投出一道灵能探针，则他三秒内遭数字反弹，但他记下那道屏障的反弹波是一簇带刺的数字。
- 若林恩在左左问「其他的我」时主动用一束温和灵能压住她神经的跳灵感，则她冷静下来判断「我才是自己」，绑定值 +1。
- 若林恩在学者提及「女儿」一词时主动让左萝在意识里画一个问号，则她在后续与左左的对话中第一次主动追问「女儿」对应位置，绑定值 +1。
- 若林恩在空降构想浮现时主动向巨像之脑发一道「我先在火山后方等」的密讯，则她在前线血伤中读到了他的位置，绑定值 +1，但那道密讯穿越纳米网时被吃掉三成字节。
- 若林恩在情感／自毁权限对话公开时主动把左左从意识里请出去静一静，则她隔着意识壁也能听到那一段自毁程序的宣读，绑定值隐式 +2，但她那一晚没睡。
