# E697·神王界决战与最后防线·if线

- 若林恩在壁垒破碎声响起的瞬间立刻把心声中神疆压成贴地藤蔓状，则梦魇登陆路径被提前剖开一层，兽王跟进时前肢被缠住半拍，但他自己的金色虚影无法全力凝聚。
- 若林恩主动对那道裂隙一声高吼「谁第一个冲就先消失」，则魇王本尊不会亲率的第一批梦魇会立刻畏缩一秒，但因果将把这个动作计入他的风险偏好档案。
- 若林恩刻意让神界本源以「未完熔铸」状态先回应魇王一声怒吼，则敌军推测林恩要硬碰，他能在初诞者之力凝成第一个金色虚影前多抢一回回合的突袭窗口，但本源的十分钟空档会被迫提前开始。
- 若林恩主动告诉本源「十分钟太长，五分钟就够」，则本源意志在半信半疑下重设倒计，整场最后防线缩短至五分钟，他要在更短窗口里同时抵挡兽王与因果铁律。
- 若林恩反其道而行主动要求本源「你就死着点吧，不要理我」，则本源不再一路伴随节奏指引，他必须自行判断铁律波动与防线收束，但能在调度上更自由。
- 若林恩朝那扑来的密密麻麻梦魇大军先丢一支「疫医复制体之毒烟」，则前锋集体迟滞三秒、为金色虚影凝聚多留出一秒，但副本损失被记入他名下。
- 若林恩直接迎向兽王白骨之躯先一记三叉戟斩下，则兽王会下意识转身为魇王挡祸，触发魇王提早出手、十分钟空档战术空间缩水。
- 若林恩主动以心声请银色太阳临时为他代偿一部分铁律震荡，则银色太阳会为他转写两层时间壁垒，但代价是他无法在战后第一时间被送回主宇宙时间线。
- 若林恩主动把三位一体之力最后一次凝聚成熟悉的「渡鸦之形」朝因果方向鸣叫，则因果神王会一瞬被这段叫声替代成「渡鸦即林恩本人」的认知，她对自己的出战决心会被动摇一拍。
- 若林恩主动以初诞者之力凝成「一个渡鸦」替代百个金色虚影杀敌，则此渡鸦能在梦魇中撕开整片缺口而战损更小，但那把「曾经的渡鸦」标记会让其后续染出强烈的自我意志。
- 若林恩主动让神界本源把他体内「那一缕画家混乱色彩」剥离出来当作哨兵，则他会失去画家的临时罩护，画家的化身将不能现身于战场，「十分钟空档」期间他独自一人对抗全部敌。
- 若林恩在铁律降下时不展开梦境隔断而硬以神疆顶尖法则设防，则铁律透过初诞者之力会渗透进来，但他的梦境本身不会消耗，后续事件梦境描写全数重写。
- 若林恩主动朝隐藏在他体内的真理残存之力也进行一次「真理重组扫描」，则他会发现真理的最终一击挂在了「银色幻想」身上，但他必须立刻选择是否要让她被动暴露。
- 若林恩主动把投入梦境的最后一丝力量取回用作「传送回家」，则他会以退为进地断掉「神王界防线」并回到黑夜城，「神王界决战」立即收束，但「本源熔铸失败」成立。
- 若林恩在因果神王释放铁律时主动反向把「抵达」改写为「离开」，则他难以实现完美反转，但能将铁律深度锁进主宇宙某一随机陆上区域，临时把魇军前锋诱离林恩视野。
- 若林恩直接对着在梦境之外咆哮的兽王一记重手斩下，则兽王白骨巨躯立刻碎裂万丈，但因果神王会立刻暴动、一次铁律强度直接翻倍，林恩的梦境隔断被击碎提前。
- 若林恩主动对因果一声大喝「你不是真的想要这样，去看看真理怎么死的」，则因果的意识会被短暂唤醒，她在整段铁律期间会怔怔望着他，梦魇的「抵达」效率骤减但 outage 后会迎来更猛烈反扑。
- 若林恩主动提前在战场埋设一枚「有序锁链」装置，则他能在最后一刻用一根极细的神疆锁链像拉铃一样撕裂因果神王的铁律，但装置本身会立刻毁灭并封锁他一次再建防线的能力。
- 若林恩在梦境被压缩到极限时选择「不喊画家，就硬抗」，则他必须以自己的永恒部分燃烧为代价，导致最终战后复原期的某些记忆完全灰化，但「画家召唤点」会以「没有人召唤」的事实落档。
- 若林恩主动让喵喵在梦境之外替他传达「画家，这次让我自己来」，则画家化身收到「林恩求救」的延续但同时多一笔「他还有心情叫猫」的诡异备注。
- 若林恩主动在暴雨中抢身冲到兽王血盆大口之侧强剥一枚白骨残片，则他能取得「兽王本源样本」，但在撕片时被振飞数百公里，落地时金色梦境会瞬间塌掉一半。
- 若林恩主动朝中心祭出自己完整的神王境地，则他能以暴晒自己为代价让所有金色虚影立刻集合重新强化，但存在的痕迹会被主宇宙缓慢磨灭，后续认同感-20。
- 若林恩主动让神界本源守护他进行秘密撤离，则他会离开「神王界决战」全力推进到「重回黑夜城」，但整场事件转为变形，他在major战场彻底缺席。
- 若林恩主动尝试以三位一体将兽王、魇王、因果三人「临时融合」作为一个敌人处理，则三者会被瞬间绑定为一体巨大怪影，但三者的各自技能复合输出使林恩本源立刻再掉两成。
- 若林恩主动在梦境中将所有压力汇成细碎雨点砸向因果神王，则她的铁律出现短暂撕裂窗口，他能让部分梦魇在抵达前失误，但他对因果的看到真心状态会经历一次苦涩震荡。
