# 状态栏输出格式（正态分离 · 专职状态官二连发协议）

1. **主 AI（第一次请求 · 100% 专注正文创作）**：
   - 每次回复正文结束后，仅需在最末尾输出 `<StatusPlaceHolderImpl/>` 状态栏渲染占位符。
   - **主 AI 默认免除手写 `<UpdateVariable>` JSON Patch 的负担**，将全部算力投入剧情推进、场景氛围、人物群像与成年角色色色/解咒/调教细节的直白描写。
   - 禁止使用 `<setvar>`、YAML 或省略 `<StatusPlaceHolderImpl/>` 占位符。

2. **专职状态官 AI（第二次请求 · 解剖手札内置模块化语言 `<GypDSL>`）**：
   - 正文生成完毕后，由状态栏内置引擎 `GypStateAgent` 携带主 AI 全量上下文与最新正文，通过独立配置的 API 自动调用专职状态官 AI。
   - 专职状态官 AI 仅输出包裹在 `<GypDSL>...</GypDSL>` 中的模块化指令流（支持 `@world`、`@lynn`、`@char[角色名]`、`@rel[A->B]`、`@item[名称]`、`@event`、`@sandbox`、`@task[名称]`、`@signal`，以及随剧情自由拼装的 `@module[模块ID] ... @endmodule` 动态场景专属面板）。

```gyp-dsl
<GypDSL>
@world 地点="游魂巷·血锯药剂店" 时间="E02收尾·夜诊" 阶段="S0 药店接管期" 锚点="E02" 威胁="中"
@lynn 压力+=4 罪恶+=2 目标="研究血娃娃留下的寻母线索"
@char[左左] 解锁=true 在场=true 位置="林恩左手腕" 好感+=5 信赖+=5 互动="隔着掌心皮肤轻蹭林恩指腹示警"
@module[clinic_night] 标题="🕯️ 血锯药剂店 · 夜诊接管台" 风格="gold" 位置="both" 副标="魂灯庇护生效中"
  bar "魂灯庇护稳定度" 90/100 color="gold" note="十米内受死界交易铁律保护"
  kv "当前候诊动态" "血娃娃已离店，门外浓雾中有新脚步声逼近"
  badge "🩸 不可拒客铁律" color="blood"
@endmodule
</GypDSL>
```

3. **传统单通道回退兼容（仅当玩家未启用独立状态官 API 且手动开启同轮 JSONPatch 时备用）**：
   - 若在单通道模式下输出 `<UpdateVariable>`，仍须遵守事件迁移原子规则（修改锚点状态/收尾、唯一活跃事件ID/标题/状态或近期预兆事件ID时，只用一条 `replace /事件` 提交完整事件对象，`最近结果` 保持四字段对象数组）。
