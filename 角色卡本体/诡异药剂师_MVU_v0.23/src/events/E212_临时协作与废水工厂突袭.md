# E212·临时协作与废水工厂突袭

- 玩家主权：以下“默认走向”仅作原作因果参考；涉及林恩的对白、主动行动、决定、判断与内心，只有玩家输入已明确声明的部分才能写成事实，未声明部分必须停在可行动节点。色色与亲密由NPC按人设主动或由玩家推进均可，但林恩自身的行动仍由玩家驱动。
- 阶段：S30·蜀都寄生虫追查期
- 地点：蜀都近郊废水处理厂、地下实验间与污水管网入口
- 前置条件：硬前置：E211完成或变形（已取得工厂方位且血娃娃处于安全监管）。任一触发：现场侦察发现停工外观下仍有人活动；或城内神圣警铃连续十三次报告跨界异常。
- 参与者与动机：血娃娃（以现场指认换取公平调查并阻断更大灾害）、血肉教徒首领与守卫（转移成果、毁灭证据并从地下撤离）、被抓来实验的无家者（获救与去污）、猩红高跟鞋中的厉鬼（被当作拖延追击的载体）、左左、18岁的林恩。
- 默认走向：原作因果：清晨的蜀都天主教堂里，戴着老花镜的主教凯文斯看着腰带上那枚金色铃铛急促地震响、冒起浓重黑气，他慢慢摘下眼镜，将祈福的任务交给身边的教士，快步走向钟塔拨通军方专线。"这里是蜀都的天主教堂，根据我们与你们达成的协议，请帮我转接弥赛亚女士，我是隐修会的主教凯文斯，请告诉她，有超过那条界限的诡异，降临了。"钟塔里传来了整整十三声钟鸣，在天主教义里，这个数字代表着不详与魔鬼，普通人却不会觉得钟声与往日有什么不同。几乎在同一瞬间，林恩已经戴着鸟嘴面具立在六层居民楼的天台边缘，血娃娃撑着大伞、抱着洋娃娃轻飘飘地悬浮在他耳朵边，嗅着空气里"细小的触须和蠕动的脑子在滚烫而血红的铁锅里面折磨的诡秘气味"，林恩没好气地纠正她那叫火锅。他把侦测视角推到极限，果然透过工厂外围墙壁看见一个又一个走动的人影，还有他们身上那股只有接触过诡秘和地狱才会具备的微弱恶臭。
  若林恩沿用原作突袭路线，他会几个闪身潜入工厂，首间监控室里，教徒们捧着实验记录本面无表情地旁观：流浪汉被当作宿主，催化剂把幼虫的潜伏期压到一天就能繁衍上百条，虽然催化会快速杀死宿主、无法转化为傀儡，但能在初期大规模扩散。监控画面角落里骤然闪过一个燕尾服少年抬头微笑的脸，"敌袭！！"外面巡逻教徒的脖颈一个接一个诡异旋转一百八十度瘫软倒下，监控屏随之不断黑屏，突袭频率越来越快、目标显然是监控室；短短不到一分钟，监控室外走廊的画面也黑了。咚咚咚——门外响起礼貌的三下敲门声，整间屋子的灯光开始忽明忽暗地抽搐，为首教徒慢慢从怀里摸出一只猩红的高跟鞋，那是养着一只厉鬼的诅咒之物，他把那只鞋重重摁在地面，一滴鲜血啪嗒落下，他自己却捏碎心形吊坠、连人带骨干一起化作血雾当场消失。林恩微笑地推开那扇"咔哒"自开的大门，一地的鲜血里，一只苍白入骨的手正从鞋里伸出来，左左和血娃娃眼睛同时亮起"能吃吗？！""我也饿了！"，那只手僵在半空、以双倍的速度想要缩回鞋里去，被两人一左一右扑上去分食得连渣都不剩。

- 幕后停止点：停在地下人员准备向污水口倾倒剩余容器、被试者仍困在隔间，而玩家尚未决定先封管救人还是追击首领的节点。
- 变形条件：玩家选择与军方、医院或超自然部门联合封锁；或只进行远程断流和证据固定，待专业队伍进入。只要剩余幼虫未继续流入管网、被试者获得救援，即可形成变形结果。
- 完成条件：工厂投放能力被切断；存量容器、实验笔记、监控或活口证言至少保全两类；被试者进入隔离医疗；确认已有约半数容器在更早时段离场或投放，但去向未被虚构补全。
- 取消条件：工厂证据已被彻底焚毁且现场再无人员或幼虫可救；或专业部门完成无遗漏接管，使林恩阵营继续突入只会增加污染与冲突风险。
