# E707·数年过去与新神

- 玩家主权：林恩不出场，本事件为其闭关期间的外部纪实；以下只给条件因果、NPC反应和外部变化。黑夜城与神界的所有选择均归在场的 NPC，不假设林恩的对白或回归。
- 阶段：S94·神位传承与主君归来
- 地点：黑夜城／神界各处／主宇宙边缘世界／主宇宙边疆的无序深空
- 前置条件：E706已形成可承接结果；林恩已在天堂之战遗址苍白耀阳中闭关；神疆以群星为载体持续扩散，清理主宇宙污染的战争已持续两年；黑夜城军团所有根源已成半神并冲击神位。
- 参与者与动机：船长／主母／人偶家／自缚天使／母树／泰坦／银色幻想（各自修行、防御与抉择）；自缚天使（第一个登临至高神位）；人偶家（借心灵之海研究成心灵之神）；母树（舍弃毁灭一面，拥抱过去本源，成自然之神）；泰坦（不告而别，辗转边缘世界孤身与魇血战，最后目击冲入边陲无序深空）；狱卒集团（与黑夜城协防边疆）；被林恩所杀又重降的白骨兽王、魇王、镜魔与「第四个魇魔」。
- 默认走向：这是最坏的时代，也是他们这些成神者最好的时代，大部分神灵已被扫除一空、神位空缺，就像世界伊始，成神的难度大幅减弱。第二个年头，自缚天使依靠林恩留下来的神格，一跃超过所有半神，率先登临至高神位，动乱的世界中第一个新神诞生了。人偶家是第二个成就神位的根源，她通过对心灵之海的研究，一跃位居心灵之神的神位，完成最终升格。紧接着是第三位、第四位。母树在第三个年头时，在主宇宙当中找回了自己曾经支离破碎的家，那一夜的恸哭之后，她整个人似乎都变了很多，尽管心里依然带着满腔的仇恨，但她终究还是找回了曾经被她所丢掉的自己，最终舍弃了毁灭，拥抱自己过去的本源，一跃位居自然的神位。

  时间飞逝，第四个年头，那一日整个神界隆隆颤动，无数消息从主宇宙边缘世界传来，所有人都意识到，这短暂的平静要结束了。无序深空当中出现了数量庞大的魇，甚至比他们在神界战争时期遇到的梦魇还要多得多，以不可阻挡之势迅速消灭了主宇宙的多个边缘世界，对整个主宇宙的边境发动了猛攻。那一日，有人在边缘世界见到了曾经被林恩所杀的庞大的白骨兽王，祂似乎比之前变得更加强大，口中吞吐的无序，宛若一个行走的灾厄，所过之处一个又一个世界被祂吞噬，甚至从最后传回来的影像中，连无序生灵都能被祂吞噬、成为祂力量的一部分。魇王、镜魔重降。神疆只能抵挡得住那些寻藏的魇，在他们的面前，金色的疆域根本无法造成任何阻碍。而更恐怖的是，就在他们身边，竟出现了第四个身影。
