# E710·更高的境界

  利用梦境来创造自己所使用的力量，因为梦境是意志的延续，然后再让梦境照进现实！不，林恩明白，这也许已经是他能讲给他听的、最浅显易懂的一种，但绝对不可能是轮回神王的全部。这一刻林恩再一次感受到了他的恐怖，因为这到底是怎样一种可怕的理论：这也意味着，只要意志尚存，那你的力量就会源源不绝，甚至在某种意义上来说，你本身就已经不需要具备任何的力量，因为你的意志，就是力量。若在旧世界时期他就已掌握这种理论并付诸实施的话，那他绝对会是整个旧世界的天花板，那位大君能战胜他本就是天方夜谭。林恩深吸一口气，不过他很快回神：旧世界时期的他应该还只是掌握了这种理论、没有办法付诸实施，因为创造这个梦境本身最重要的条件，就是以初诞者之力为载体。但尽管如此，他也深感他的可怕。
  可是，该怎么做呢？林恩眉头紧锁。虽然他明白了理论，但想要把理论变成现实，可就又是另外一件事情了。若他闭上眼睛，在那个金色的梦境当中模拟自己的罪火、让它在梦境当中一点点熊熊燃烧，恍惚间他的整个梦境便遍布了猩红的火焰。他慢慢伸出手，试着将它们在手中展现：呼，一缕猩红的火苗在他的手中燃烧而起，越来越大，最后化作一团火球，照亮了时光。但很快他眉头紧皱、摇了摇头：「不对。」这确实是红色的火，但也只是红色的火，和罪火可以说是八竿子打不着的关系。
