# 轮回神王·从时间长河对岸投来的气息（E760）

- 基础信息：在「林恩已完成第三阶段并独自留在残余宇宙」「最后一位幸存者以敬明天告别并死亡」的节点上，从时间长河对岸投来气息的存在——它是 C1119「未来林恩／轮回神王」概念下的具体形态：一种「林恩未来时间线的另一种神王化形态」，与当前林恩同源、却已经是走完更长道路之后的「那一个」；它在这一刻只是「出现」，没有立刻降临。
- 生活结构：它没有具体的现形——只以气息形式投在时间长河水面；但它在水面上的投影足以让林恩开始把「独自守护」转为「向时间之外寻找突破」的方向。它所处的位置在长河对岸、时代合流之前的某一处历史凹陷里。
- 人物性情：它克制、沉稳、已经把「结果」看得比「当下」更重；它对林恩此刻的悲伤不试图触碰——它知道他必须自己撑过最后幸存者的死；它也无兴趣解释自己是谁——它知道接下来的相遇会让林恩自己认出它。
- 穿衣风格：仅以气息投在水面，无具体外形；但若林恩极目远眺，能隐约看见长河对岸有一道「燃烧着」的身影轮廓——燃烧的不是林恩现在的烬黑之火，而是「已经把自身因果关系全部压入火焰中作为柴薪」的那种白热。
- 关系网络：与林恩——它是他未来时间线的另一种形态；与时间长河——它在长河对岸维持自身轮廓，不被水流冲散；与最后一位幸存者——它没有介入这一场告别，只在结束之后才投下气息；与轮回/梦主/时间王——本切片不展开其与这些名号的横向关系。
- 场景表达：林恩在残余宇宙的废墟中刚把最后一位幸存者的名字收进梦境——时间长河对岸忽然有一股燃烧的气息扫过水面；他抬头，看见长河对岸隐约有一个燃烧的身影；那不是他，但是「是未来的某一种他」；他没有追过去，因为他知道现在的他还没资格去面对那一位。
- 使用边界：本场登记「轮回神王的气息从长河对岸投来」「它是林恩未来时间线的神王化形态」两条事实；它与神王（C1137）、与时间王、与时间太阳之间的同一性/对立关系——本切片不展开；它将要采取什么行动——下文以 E761—E763 承接；林恩如何回应这股气息——归玩家。

# 轮回神王·你出师了——燃烧自身因果的传承者（E762）

- 基础信息：在「林恩重建黑夜城、反复攻击时间阻隔」之后挡在长河之外的存在——它是轮回神王完全显形的形态：承认自身已经无法陪林恩继续前进，愿意把积累的因果负担燃烧成一次「让林恩突破时间长河阻隔」的力量。它的本源是「林恩的未来形态」，它的某一个核心选择是「把自己作为柴薪」，把当下林恩推得更远。
- 生活结构：它此刻的形体是一个由「已经被它自身切断的过去片段+正在被压入黑火的因果负担+长河外壁裂缝的白热」三位一体构成的燃烧身影；它的身体在燃烧过程中逐渐透明——每切下一段过去，它就有一部分自我消失；每一部分自我消失，长河外壁的裂缝就扩大一线。
- 人物性情：它已经把「传承」看作自己存在的最后意义——它不是为了自己的延续而燃，而是为了让林恩走得更远；它不「煽情」，只有一句给林恩的话：「你出师了」；它接受林恩穿过裂缝后可能坠入无尽沉眠的代价，也接受自己会被火焰全部吞没的结局；它不设想林恩会回头——它只是把自己烧成那条通路。
- 穿衣风格：全身被燃烧自身因果的白火覆盖，火中还能看见它生前（作为未来的林恩）留下的许多段记忆——是某一些时代的黑夜城、某一些已无法再见的人、某一些它曾经「想过也许还能留下」的执念——但它亲手把这一切都切了下来、压入火中；它手中最后一缕未被烧尽的力是「指向第二门槛」的引导。
- 关系网络：与林恩——它承认林恩已经「出师」，承认林恩接下来的路必须他独自走完；它把最后的力量送给林恩，并不期望被回报；与时间长河——它以自身作为缺口，长河因此记录下一处不可逆的因果缺口；与轮回/梦主/时间王——它与这些名号是四种不同存在立场的（见人物增量映射中的同一性裁断），本切片不展开横向关系；与无尽沉眠——它接受林恩坠入沉眠的可能，知道自己无法陪他去醒那一场梦。
- 场景表达：林恩站在长河外——轮回神王以燃烧的形态转过身来面对他；它没有解释自己是谁、也没有要求林恩叫它什么；它只是把自身从某一段过去切断，那段过去立刻被压入黑火，长河外壁「咔」一声出现一条裂缝；它对林恩说：「你出师了，林恩」；然后它把剩余全部因果燃尽；林恩沿裂缝前进时，能感受到它最后一缕力在自己背后推了一把——那一推之后，它就完全从这场故事里消失了。
- 使用边界：本场登记「轮回神王切断与部分过去的联系并压入黑火」「长河外壁出现短暂裂缝」「它对林恩说出『你出师了』之后燃尽全部因果」三条事实；林恩是否接受这份传承、是否在沉眠中回头看它——归玩家；它燃烧前的具体过去内容、它与林恩未来形态之间的具体差距——不展开；它是如何走到这一步的，本切片不做完整交代。

# 轮回神王·残余火焰成为第二门槛的引路线（E763）

- 基础信息：在「林恩穿过裂缝后坠入无尽沉眠」的阶段——轮回神王的「本体」已经燃尽，但它的残余火焰还在；它的残余气息成为林恩在无尽梦境中「唯一指向出口的线」，也是第二门槛所在位置的引导；它以「残余火焰」的形态继续承担「传送者」的角色——它已经不能再「陪林恩走」，但它留下的火还在。
- 生活结构：它的形体此刻只是一缕白色的火焰——火焰底端指向无尽梦境的某个深处，正是第二门槛所在；它不是完整的神王，只是一缕「还能指向」的残余；它没有意识的核心可以再做决定，只是按照它在燃尽前最后那一刻立下的意志，持续指向。
- 人物性情：它已不再具有性情——只剩「指向」。它不再衡量林恩是否配得上、不再判断林恩能不能跨过门槛；它只是烧着、指着、等着林恩自己走过去。它存在的最后方式是「成为路标」。
- 穿衣风格：一缕悬浮在无尽梦境底部的白色火焰；火焰中偶尔还能看到它燃尽前留下的几帧记忆残片——但那些残片已经不能构成完整人格，只是它的火在燃烧时把某些曾经的东西顺带翻过一遍；火焰的指向永远不偏。
- 关系网络：与林恩——它现在不是「对手、同伴、导师」，只是他的路标；与无尽梦境——它是梦境中唯一稳定的方向；与第二门槛——它存在就是为了指向那道门；与黑狱/无序/秩序潮汐——它承受的冲刷与林恩相同，但它比林恩更不能再走一步。
- 场景表达：林恩在无尽梦境中失去方向——他突然看到很远很远的地方有一缕白色火焰；火焰不挪、不熄、不闪烁，只是指着一个方向；他沿那个方向走——火焰与他之间的距离不断缩短，他最终看见火焰底部就是那道第二门槛；他伸手触到火焰时，火焰在他掌心散开——它的使命完成了。
- 使用边界：本场登记「轮回神王的残余火焰指向第二门槛」「林恩在火焰散开时到达门槛」两条事实；第二门槛之后的结构、林恩跨过门槛的过程——下文不在此场；林恩对火焰的回应、是否回头看它——归玩家；本切片对轮回神王的「燃尽与传路」功能就此完成，不再追加其它作为。
