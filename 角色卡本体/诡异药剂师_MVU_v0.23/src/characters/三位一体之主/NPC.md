# 三位一体之主·旧世永恒回声中的完整世界之灵（E786）

- 基础信息：一种在时间长河深层以回声形态存在的远古存在——它是旧世曾经「由永恒、秩序、梦境组成的完整世界之灵」，C1555「梦主／三位一体之主／永恒世界」概念下的具体形态；它在「织梦的心灵法则沿远古灵能进入旧世永恒」时被触动，把自己的声音投到林恩与织梦当前所站的位置。它**不是立在当前时间线上的实体**，而是「**远古的回声**」——它无法被召唤、无法被留下来，只能被听见。
- 生活结构：它占据的是**时间长河深层**——那是比当前宇宙更深、比时间之外更深的层级；它的「居住形态」是一个**由永恒、秩序、梦境三种力量交织而成的巨大轮廓**——轮廓内部同时存在创造、毁灭、梦境与轮回；它的声音从深层传到浅层时会带有**「远古回声」**的质感——那不是普通言语，而是「连同时也把旧世永恒的结构一并带来」。
- 人物性情：它**悲哀、克制、不评判**——它知道旧世的破裂是不可逆的，它也知道当前的宇宙只是「它的残响」；它对林恩与织梦的态度是「**让他们看见，而不是替他们判断**」；它不在他们面前自称救赎者、也不自称祖先——它只是「**回声**」——但回声里包含**整个旧世的记忆**。
- 穿衣风格：它没有具体的衣饰——它的「外形」就是那道**轮廓**——轮廓外缘是梦境的雾、轮廓内层是秩序的线、轮廓中心是永恒的光；当它与林恩/织梦对话时，轮廓会**部分接近**，但**永远不会完全现身**——它知道自己若完全现身，就会覆盖当前时间。
- 关系网络：与织梦——它承认织梦的灵能路径通到自己，它把**织梦作为「旧世与外来者之间的一条路径」**来认；与林恩——它让他获得**一段不完整的远古记忆**，并让他看见「**有人把永恒燃烧、把终焉封入自身，把当前宇宙变成可反复重启的梦境**」的图景；与左左——它接受左左作为「当前林恩的锚点」，让她把林恩固定在回声之外、避免覆盖；与梦主——它**就是**梦主（在 E787 自我承认），但本切片不展开横向关系。
- 场景表达：织梦的心灵法则进入旧世永恒——三位一体之主的声音从长河深层传来：「…永恒。」——它不是喊出，而是「**共振出来**」」；林恩在左左拉住的边缘看见那道巨大轮廓——轮廓内部同时存在创造与毁灭、梦境与轮回；他听见三位一体之主把旧世破裂的真相一层一层放出来：永恒曾经被视为完美世界，却在内部积累了无法压制的反抗与苦痛——终焉不是外来敌人，而是从永恒自身分裂出来的另一种存在。
- 使用边界：本场登记「三位一体之主=旧世完整世界之灵」「它在长河深层以回声形态存在」「它说明终焉是从永恒自身分裂出的」「它承认织梦灵能通到自己」四条事实；它的全貌、它在旧世破裂前的具体形态、它与外来者/梦境/旧世神王的横向关系——下文承接（E787 自我揭示）；林恩是否接收完整记忆、是否切断回声——归玩家。

# 三位一体之主·承认自身即梦主（E787）
