# 苗苗·轮回神王亿万年的陪伴（E679）

- 基础信息：植灵——轮回神王亿万年唯一的陪伴；她在时间神王展示的画面里出现——最初只是一株小小的、自称健壮植灵的嫩芽——后来化形、背着她踏过溪水与峡谷、在淅沥的大雨里陪她久久发呆——她在轮回神王的每一个轮回里都出现。
- 生活结构：她是轮回神王在每一个轮回里都会前往的林地巨石上的一株小植灵——她说「你是谁啊，很奇怪，为什么你的枝干还会开叉？」、「没错，我就是这里的老大！如果你是想要跟着我混的话，那就乖乖地等我长大，等我长大了的话，我就结果子给你吃~」、「第一次见面，我叫苗苗~至于为什么会取这样的名字，我也不太清楚」——她在轮回神王无数轮回里都是一个有名字的、真实的存在。

# 苗苗·林地废墟府邸苏醒（E682）

- 基础信息：植灵——在林地废墟府邸苏醒的一株新芽——她不是之前轮回神王陪伴的那株苗苗——她是余烬、是重临、是同样的存在——但她不认识林恩——她只是感觉到了一种熟悉——她问林恩「你是谁呀？苗苗见过你吗？为什么总感觉……对你好熟悉呢」——她是一株重生的苗苗。
