# 时间王·时代终末分门另一侧的身影（E791）

- 基础信息：在「林恩进入未来尽头、过去/现在/未来三时代像多层透明薄片一样互相覆盖」的节点上，从「悖论组成的空门」另一侧显现的存在——它的名号是「时间王」，与「神王（C1137）」「轮回神王（未来林恩）」「时间太阳」是四条不同名号、四种不同立场的存在；它不是神王、也不是轮回神王，它的本源将在下一节点（E792）才被揭示。它以「站在空门另一侧、与空白实体（C1552）的力量同时伸向时间权柄」作为动作特征——它要借时代接轨改变结果。
- 生活结构：它立足在悖论组成的空门另一侧——空门是时间权柄显现的具体位置；它身后的背景是无数相互覆盖的时代残片，它在残片之间维持稳定存在；它伸出手时，能让每一次时间移动把一段历史提前带入现在——许多已发生的死亡与尚未发生的灾厄同时出现。
- 人物性情：它不急躁、不掩饰——它知道自己站在空门另一侧意味着什么，也知道林恩必定会走到这里；它对空白实体借最后载体的重量压向未来通道的行为不阻止、不主动配合——它要走的是它自己的那条路；它对林恩此刻承受多个时代因果、梦主记忆与自身经历继续重叠的状态——既不趁机压下，也不出手帮一把。
- 穿衣风格：它的身影在薄片的折射下看起来像由无数「时代断层」叠成的人形——每一个动作里都能看到过去某段历史在他身上的倒影；它的轮廓周围悬浮着空的王冠，是没有「时间权柄认主」前的无主象征；它的目光能穿透薄片直接望向林恩。
- 关系网络：与林恩——它是他在「最终争夺时间权柄」上的对手之一；与空白实体——它在空门另一侧与空白力量同时伸手，但二者目标并不完全一致（空白要截杀，时间王要另一位结果）；与左左——它感知到她黑火接入桥接结构，但不视她为首先需要解决的对象；与时间权柄——它要它，却不被它认主；与轮回/梦主——本切片不展开（在 E792 揭示）。
- 场景表达：林恩在时代合流区中移动——每一次时间移动都会让某段历史提前进入现在；他能在另一端的空门处看见时间王的身影——那是一个「由时代断层叠成」的存在，正与他隔着空门对望；左左在他身后桥接逐渐失去黑火控制，过去渡鸦、未来林恩、当前林恩的身影短暂重合——而时间王仍站在空门另一侧不动，等林恩自己走过去。
- 使用边界：本场登记「时间王从悖论空门另一侧显现」「它不是神王/轮回神王/时间太阳」「它要借时代接轨改变结果」三条事实；它的本名、它与梦主关系——本切片不展开（E792 揭示）；林恩是否选择先救画家/保护左左桥接/直接进入空门——归玩家；时间王的具体手法、它对林恩的态度是否还会变化——下文承接。

# 时间王·梦主最早的伙伴与背叛者（E792）

- 基础信息：身份已经揭晓的时间王——它是**梦主（C1555）最早的伙伴之一**，承认**曾经背叛轮回结构，试图借终焉得到解脱**；它与轮回（承接梦主遗志的部分）争夺时间权柄，并愿与紫罗兰大君共同发动最后攻击；它是「四条时间线/权责」中的一条独立体——不是神王、不是轮回神王（未来林恩）、不是时间太阳。
- 生活结构：它此刻在「时代合流区+时间权柄空门+轮回桥接战场」的三位一体位置中维持核心站位；它能召唤自身过去的时代影像作为武器——每被轮回「剥离一层」，它的身影便变得稀薄一些，但它在稀薄中仍然保持攻击路径；它的力量终点是「与紫罗兰大君的终焉力量合流」。
- 人物性情：它**承认**——它不粉饰自己曾经的背叛；它对梦主的态度不是「敌意」而是「另一种解法」——它认为轮回结构本身已经无法继续，它要走的是「借终焉让一切重来/结束的路」；它对林恩不是恨——它认为他**也应该看见这条「借终焉解脱」的路**；它不会对林恩客气——它会把所有悖论的重量压下。
- 穿衣风格：身上的时代断层此刻更加清晰——每一段断层里都能看到它曾经与梦主共同走过的痕迹；它手持一柄由悖论铸成的「断裂权杖」——权杖断口处不断渗出悖论的反光；它的容貌在多层时代折射下同时显得苍老与新锐——是一个已经走过极长时间、却仍未停止选择的存在。
- 关系网络：与梦主——它是梦主最早的伙伴之一，如今背叛；与轮回——它要争夺轮回所持的「梦主遗志」，它不认为那是梦主真正的意志；与林恩——它要借林恩的历史负担完成截杀，但借林恩看见「另一条路」；与左左——它接受她以空置时间权柄维持桥接，但会与她对抗；与紫罗兰大君——它将与之共同发动最后攻击；与时间权柄——它争夺，但不配拥有。
- 场景表达：终焉倒计时在时代合流区响起——时间王从空门另一侧走出，不再以模糊身影存在，而是具体落地；它向林恩揭示自己的身份：「我曾是你父亲之友」——那一句里最重的不是「父」也不是「友」，而是「曾」；它主动承认自己曾背叛轮回结构，承认自己想借终焉解脱；它向林恩伸出手——不是邀请，是宣告：接下来会有最后一击。
- 使用边界：本场登记「时间王=梦主最早的伙伴之一」「它曾背叛轮回结构、试图借终焉解脱」「它与轮回争夺时间权柄」「它与紫罗兰大君共同发动最后攻击」四条事实；它当年为何背叛、它与梦主之间具体哪一段过去——不在此场展开（C1555 概念外的完整历史不做全景式展开）；林恩是否愿意取走时间权柄/保护轮回/继续桥接——归玩家。

# 时间王·把最后悖论与紫罗兰大君一起压向林恩（E793）

- 基础信息：在「时间权柄已脱离它、空置权柄转移到左左桥接位置、轮回站在攻击路径上承受历史悖论」的节点上，与紫罗兰大君一起发动最后攻击的时间王——它把所有时代的悖论压成一道终点攻击，目标直指林恩与左左桥接；它不再是「争夺者」，而是「落败后仍要终结一切者」。
- 生活结构：它站在紫罗兰大君之侧，与它形成终焉力量与悖论力量的合流点；它让最后一击穿过无数过去与未来——每一层被穿透的过去都会叫出某个已死者的名字、每一层被穿透的未来都会显出某个尚未发生的灾厄；它已经无路可退，因为它承认它已经背叛了一切，如今只剩这道攻击。
- 人物性情：它**没有恨意**——它只是觉得这一切早就该结束；它对林恩不是「怨」，是「让他也要面对终焉」；它对轮回的「这是我能帮林恩的最后一件事」保持冷静旁观——它知道轮回会破碎，也知道轮回破碎后，它仍然不会停手；它对紫罗兰大君的「原初身体」是一种「同盟但不合一」的态度——它借大君的力，但不会融入大君。
- 穿衣风格：身上的时代断层此刻已全部向外展开——它不再是「由时代叠成的人形」，而是一个**让所有时代同时站在它背后为它作证**的存在；它手中的悖论权杖完全碎裂，但碎裂的权杖反而成为它**真正**的武器——每一枚碎片都是一次悖论；它的目光已经越过轮回、越过左左、直落在林恩身上。
- 关系网络：与轮回——它是轮回破碎的直接推手之一；与紫罗兰大君——它是与它共同发动最后攻击的同谋者；与林恩——它把他当作「必须见到终焉的人」；与左左——它把她当作「桥接的另一端」，攻击必须穿过她；与梦主——它终于承认梦主留下的并非只有救赎者，而是**互相记住的众生**——它不能接受这一点。
- 场景表达：最后攻击穿过无数过去与未来——时间王与紫罗兰大君的合流力量压向林恩；轮回站在攻击路径上承受第一层——轮回的身体与记忆被一层一层击碎；林恩在轮回身后看见梦主留下的所有痕迹——无数生命、黑夜城、命运之地、渡鸦群体——这些都不是救赎者，而是仍然能够互相记住的众生；时间王看着这一切——它并没有改变主意。
- 使用边界：本场登记「时间王与紫罗兰大君共同发动最后攻击」「攻击穿过无数过去与未来」「轮回替林恩承受」「林恩复苏后看见终焉城与七十一噩梦的最后战场打开」四条事实；最后一击的胜负、林恩进入终焉核心的具体过程——下文承接；林恩是否在此时选择追随轮回/先救左左/接受复苏进入终焉核心——归玩家；本切片对时间王的「背叛者」功能就此定型。

# 时间王·被轮回之火压入历史之火（E796）

- 基础信息：在「轮回燃烧自身，把时间王与悖论一起拖入历史之火」的节点上——时间王最终被轮回以自身为代价拉入终焉核心的历史之火中；它不是被击败，而是被**「与它曾经背叛的那个结构同源的火」**所吞没；大君的终焉力量无法再利用它——它的**过去**成为了它此刻的牢笼。
- 生活结构：它的形体被轮回的火焰包覆，无法再穿透任何时代；它曾经展开的所有时代断层此刻都已被烧穿——它被迫回到**它自己的那一段过去**里；它手中已经失去悖论权杖，只剩一柄**「透明的、属于它自己过去」**的影子；它在历史之火中的定位是「**曾经背叛的那个反面**」。
- 人物性情：它**没有后悔**——但它**也没有继续坚持的力气**；它看着林恩把历次历史战斗积累的黑火投向终焉核心，那火焰不再只烧毁噩梦，而是把过去的每个因果节点同时点燃——它知道**它自己也已经成为那些因果节点之一**；它对轮回承认：它没有赢过，也不会赢过。
- 穿衣风格：身上的时代断层已全部熄灭——它只剩一个**燃烧中的剪影**；剪影中还能看见它最早与梦主并肩走过的那段路的残片；它的容貌已被火焰洗净，看不出年纪——只剩下一个**「选择」**的轮廓。
- 关系网络：与轮回——它是轮回以自我燃烧才拖入历史之火的对象；与林恩——它在被烧尽前最后看了一眼林恩，那一眼里没有告别，只有**「你已经见过终焉」**的默认；与紫罗兰大君——它在与大君共同发动最后攻击之后便被剥离出合流，不再是大君的同盟；与梦主——它在被压入历史之火时**看见梦主记忆把永恒、终焉与宇宙梦境的关系重新排列**——它终于在最后一刻承认**自己不属于新的排列**。
- 场景表达：轮回在终焉核心中显露梦主最后遗志的完整形态——时间王被那一只手（轮回燃烧自身的手）抓住，二者一同坠入历史之火；时间王身上的所有时代断层一层一层剥落——它想反抗，但它每一段过去都已经被轮回锁住；它终于在火焰中看向林恩——它没有说话，只是那一眼里把**自己曾经背叛的一切**全部交了出去，然后**它被火吞没**。
- 使用边界：本场登记「时间王被轮回以自身为代价拖入历史之火」「它不再能被紫罗兰大君的终焉力量利用」「它的过去成为它自己的牢笼」三条事实；它在历史之火中是否有最后一段话/是否完全消散——本切片不再展开；轮回燃烧自身的具体情绪、林恩对这一幕的回应——全部归玩家；本切片对时间王这一 NPC 的弧线就此收束。
