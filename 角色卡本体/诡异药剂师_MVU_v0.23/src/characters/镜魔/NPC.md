# 镜魔·神王国度里的镜面之魇（E692）

- 基础信息：七十二柱魇魔之一，被时间之末释放、此刻潜伏在神界最底层神王国度的镜面之魇；他代表的是「变化与镜像」——人间百态，人最战胜不了的就是自己——是一种扭曲的概念，与先前降世的白骨兽王（兽性与凶性）属同级但不同质的另一位魇。
- 生活结构：他维持着「全身覆盖着镜面般光滑的晶体、细看又像是从体内长出的刀刃」的形体——没有脸颊、没有面孔、面部是锋利的三角尖盔刃、身后拖着一根长长的尖锐尾巴、手持漆黑长枪、枪身反射着此地浩荡的神芒；他看上去就像一个完全由刀刃与晶体扭曲成的人形怪物。他站在金色风暴中不动，每一片镜面上都倒映出林恩的脸。

- 关系网络：与七十二柱魇魔体系同列，与白骨兽王（已被林恩斩落）是先后降临的两位魇；他对林恩关系的本质是——他是林恩在这一刻「不可战胜的自己」；他对银色太阳的提示置若罔闻，他对林恩的追杀是单方面的镜像追猎。
- 场景表达：林恩刚进入神界最底层那一刻——一把漆黑长枪撕裂重重叠叠的风暴，笔直射向他的头颅；林恩侧身的瞬间，远处金色风暴中浮现那个身影——镜面上的一只与林恩一模一样的眼睛一点点变成浓重的漆黑——林恩明明没有动，镜像却像是有了自己的意志。若林恩折跃遁去，离开刹那他镜面上会出现一道道裂纹，里面汩汩渗出猩红的鲜血与黏浆；裂隙里浮现一只与林恩的眼一模一样的眼睛——像有什么怪物正从这一身晶体与刀刃中诞生。
