# 兽王·从时间之末降临的白骨凶灵（E688）

- 基础信息：从时间之末被解放出来的凶灵——一张宛如龙首的巨大口器、眼眶中流淌滚滚黑气、十几米高的庞大骨架，由无数动物骸骨强行拼凑的扭曲怪诞；魇王一方口中的「兽王」，与曾出现在第三层的那只骨爪同形。
- 生活结构：它此刻并不在行宫之内，而是在行宫之外的虚空游猎——以撕碎林恩放出的渡鸦分身为首次显形：一根锋利尖锐的骨爪刺穿渡鸦、龙首撕碎头颅一口吞入腹中，渡鸦的记忆化作信息隆隆涌入它的体内，无数梦魇在虚空中对它臣服。它望向行宫的方向，眼里是纯粹的暴虐与兽性。
- 人物性情：它的凶性远超此前任何所见——它不与任何人对话，凡是会动、会发光的存在都是它的猎物；它的猎目标首要指向可供吞噬的神格（毁灭神格），其次指向第七层里被锁链缚住的真理本体；它的战斗经验远在林恩之上，像丛林里狩猎的老手。
- 穿衣风格：白骨龙首、漆黑眼眶、十几只手臂、利爪穿刺——像一具由各种掠食者的白骨铸成的怪诞；身躯最深处是层层叠叠的黑气；白色的骨架在无序的虚空中反射着苍冷的光。
- 关系网络：属魇王一方，受七十二柱魇魔的体系节制；与刚夺下毁灭神格控制权的「魇」是协同关系——那只魇公开宣告「兽王大人的投影已降临」；对林恩与真理残魂，它是此刻最大的外部威胁。
- 场景表达：一根骨爪刺穿渡鸦分身、将它撕碎；龙首吞入渡鸦，渡鸦的记忆隆隆涌入；一道波动穿过整个神界疆域、蔓延向无序深空——林恩与真理残魂在这一刻彻底暴露。它像一具白骨铸成的无边噩梦，静静地漂浮在行宫之外的虚空里，黑气从眼眶里汩汩溢出。
- 使用边界：本场登记「时间之末降临」「白骨龙首十几只手臂」「吞渡鸦分身」「首要目标是毁灭神格，其次是第七层真理本体」「战斗经验远在林恩之上」五条事实；它的真身、它在时间之末的具体来源、它与魇王的从属层级不写；它没有对白，只有凶性的显形；「他已彻底暴露」的判断由林恩一方给出。

# 兽王·毁灭神格的吞噬与斩天一刀（E689）

- 基础信息：已经吞下夺自第六层的漆黑毁灭神王格的凶灵——吞下后龙首眉心浮现那枚神格、毁灭法则如闪电自周身闪现、在白骨上铸出尖锐的黑色铠甲，凶芒愈盛；这是一种能把吞下的东西变成自己身体一部分的能力。
- 生活结构：它先撞退林恩、吞下毁灭神格、随即倒挂在走廊对面破损的墙壁上像蜘蛛品味猎物般咀嚼神格；它意识到必须并行处理两件事——一边派一副扭曲的人骨攀爬赶路往第七层吞噬真理本体，一边本体转身正面应战林恩；最终它撕裂空间的速度比先前快上十几倍、骨爪直取咽喉。
- 人物性情：它一被斩中那一记「星寂」的三叉戟——跨越无垠距离把前往第七层的人骨斩杀湮灭——断裂的骨爪肉眼可见地再生、龙首恍如不觉地转向林恩，意识到不打败这只渡鸦就去不了第七层，彻底转换目标。它的位格与实力极其恐怖，即便金色梦境全面展开一时也难以完全限制。
- 穿衣风格：白骨龙首、龙首眉心镶着那枚漆黑的毁灭神王格、周身毁灭法则如闪电在白骨上铸出黑色铠甲；它的体型十几米高、背后还裂开攀爬出一副扭曲的人骨分身。
- 关系网络：与夺下毁灭神格的那只魇——是夺食者与猎物的瞬间逆转，它黑雾里龙首冲出、一口把神格连同魇吞了下去，魇的呼喊连同神格一并被咀嚼声吞没；与真理——它要把他的本体一并吞下；对林恩——它是必须在他消化完神王格之前被解决的对手。
- 场景表达：它沉默地评估、与林恩几乎同时扑向神格；它以远超估计的敏捷避开林恩一击横斩、化身蜘蛛般在建筑残骸上跃迁；它攀附在第六层墙壁、一整副骨骼后背裂开攀爬出分身；林恩撕开空间以「星寂」一拳——旦展开金色梦境、亿万公里长的虚无巨刃携罪火与初诞者之力合斩而下——兽王开始疯狂挣扎，眼眶里的黑气涌动，白骨的龙首中心裂开一道纹路迅速蔓延到全身核心；无声的巨响后，全身燃起罪火，如水中泡沫般化作无数光点，碎在金色大梦里。碎片被林恩在梦境中炼化，最终只剩那枚漆黑的神王格悬浮在金色涟漪中。
- 使用边界：本场登记「毁灭神格被兽王吞噬并黑甲改造」「梦境领域对魇复活的检验」「罪火长刀与初诞者之力合刀」「兽王在金色梦境中被林恩斩碎崩解」四条事实；它是否真死仍作悬置；它的分身那副人骨被「星寂」一击湮灭的事实独立成立；它降临时间之末的具体来历仍不解；林恩的出手、刀时与代价由玩家独占。

- 基础信息：已从被斩落的命运里复生归来——它随魇王、因果三人并肩从世界壁垒的裂隙中显化，吞魇之后身躯暴涨到万丈，已适应林恩空间法则被抵消的手段；它此刻是梦魇大军涌入神界本源所在地的主要先锋之一。
- 生活结构：它先攀附在金色梦境的外围——像窥视的外神，口中喷涌的无序之力化作遮天蔽日的漆黑大海；它用庞大到遮天的体量压着林恩那膨胀到接近千米仍在不断收缩的梦境边界。

- 关系网络：与魇王、因果是此刻强行破界进入神界本源位置的三大魇；它的存在包括压住林恩梦境的一角，与魇王本体的黑巨人、因果的「铁律」是同一面压阵的墙；它也仍是吞噬者的角色——它等待一切可被吞下的资源。

- 生活结构：祂此刻不是任何战术的棋子，而是一个自主的、巨大的、行走的灾难源——在边缘世界，祂自行展开吞噬与扩大；祂身边同行的还有重降的魇王、镜魔，以及第四个身影。

# 兽王·倒于林恩刀下（E718）

- 基础信息：在林恩归来的那一刻，兽王从内环最前线被召往主宇宙核心——它刚感应到魇王他们的印记在无序深空重新激活、意识到主宇宙行动失败，却又立刻被林恩出现在内环最前线；它最终倒于林恩刀下——一刀、未出刀鞘、被当场力劈。
- 生活结构：它此刻不再有任何战术目的——它死了。它到死都不敢相信：曾经的那个拼尽全力才能与他们一战的少年，此时此刻竟是已经到了一个让它们都需要仰望的高度。
- 人物性情：它临死时的不信、临死时被一刀截断的庞大惯性、连同它对自己的骄傲与对林恩曾有的战术估量，一并被那不出鞘的一刀湮灭。
- 穿衣风格：庞大到宛若恒星的白骨身躯；伤口的位置是一道深可横贯躯干的劈痕——汹涌的无序力量在那爆燃的火焰中干燥如柴薪、化作虚无与破灭。
- 关系网络：它和镜魔、人脸蛇身是外围三魔，被地狱四王拦在内环最前线；它在魇王陨落的同一时段内被林恩以一刀力劈；它是「归来的林恩」给主宇宙的第一次公开宣示。
- 场景表达：撕裂的虚空中熊熊燃烧的血色火焰就像地狱里的恐怖光景遍布浩瀚星空——和十几年前相比，那猩红的罪火仿佛达到了一个更高的层次：明明在汹涌地燃烧，却没有对周围的空间与法则造成任何破坏性的摧残，就像介于存在与不存在之间。轰隆隆隆——兽王庞大到宛若恒星的身躯在那火光中隆隆地倾倒。他死了——甚至他到死都不敢相信，曾经的那个拼尽全力才能够与他们一战的少年，此时此刻竟是已经到了一个让他们都需要仰望的高度。艾维儿都一阵阵巨大的恍惚——因为只是一刀：甚至林恩手中的那把刀都没有抽出刀鞘，那个庞然的巨兽便在那烈焰当中被当场力劈。
- 使用边界：本场登记「兽王在林恩归来后被一刀未出鞘力劈而死」「兽王到死不敢相信」「倒于内环前线」三条事实；它是否会再度复生是悬置——这是它第一次被「归来的林恩」斩，不再像神界那一次是「在梦境里被炼化」，但 E 系列未给最终真死判定；他的尸体与后续处置不写。
