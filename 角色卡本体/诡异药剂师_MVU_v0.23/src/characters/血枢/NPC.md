# 血枢·残魂现身辨本质·E613

- 来源：E613；仅用于实际发生并已获知的增量。
- 事实与表现：系统空间中那枚被镇压封存的血滴，经更多血滴补全后可在精神领域挣扎出四肢、扭曲成被剥去皮肤、剜去眼睛的血肉人形，仰天长啸。可认出眼前的人、狰狞扑击，却在林恩的精神领域里只是一缕残影、攻击穿体而过。认清现实后可与林恩做交易：他回答几个问题，林恩许诺未来某一天放他重归现实——「毕竟彼此之间本不存在什么恩怨」。可借单向超维链接看到远在黑夜城的巨像画面，目光死死钉在她身上，拳头一点点握紧，本源联系让他连单纯感受这缕链接都止不住情绪激荡。给出的答案极彻底：「那是我的本质。」——他的本质被窃夺，记忆与存在被从本质中彻底抹去，只剩这一点残留的印记；而之后新生的那个「我」，再不是他。顺着林恩的推论（天堂之战后有人故意分割其本质、把血质散作亿万种子断绝复苏，种子长成新血肉文明，文明繁衍再融合归一成为今天的巨像），他无法证实也无从否认：「若真如此，那么从某种意义上，那个女孩确实是在它的基础上、用无数岁月萌芽出的新意志。」随后凶光毕露：若能吞噬掉她，未必不能夺回本质、恢复当年的实力——可被「敢动她，现在就捏死你」一句压制，不得不承认自己连最后一缕残魂都握在别人手里。
- 适用边界：残魂现身＝一缕被抹去印记、仅剩残留印记的外来者意识；补全后无独立战力，扑击＝情绪失控的姿态而非实质性威胁；巨像＝其本质新生意志属推定层级（出自林恩之口，血枢不能证实也不能否认），非全知事实；吞噬企图已被威慑压制，但怨恨与夺舍倾向保持活跃，不可写成已驯服。

# 血枢·「修行＝让她死」证词·E614

- 来源：E614；仅用于实际发生并已获知的增量。
- 事实与表现：面对「为什么继任者一修行法则就走到今天这一步」的追问，血枢先给出一声难以置信的冷笑——「你让她熔铸了你们这个鬼地方的法则？！」在他看来这愚蠢至极：这个世界的生灵自以为的法则，不过是终焉之主混乱思绪的拟化，外来者与这一切有着本质的区别；让她熔铸法则，就是让法则一点点磨灭和改变她的一切，等她彻底掌握那些法则的那一天，就是她的本源被磨灭、彻底消失的那一日——那不是修行，是让她死。至于为何巨像能安然熔铸这么久、直到半神门前才暴雷，他的解释是：一个经无数世代繁衍的文明最终熔出的个体，早已吸收了太多这个世界的物质，不再像他当年那样纯粹；可剥开污秽看本质，她依然是血枢——修行法则并非一开始就不可以，只是那会让这个世界一点一点地看清楚她到底是谁。证词已通过林恩的精神波动验证——他没有在说谎。
- 适用边界：证词＝血枢一方之言（已经精神波动验证非谎言，但仍是残魂视角的陈述），不等于对整个主宇宙法则体系的终局定论；「磨灭论」的对象＝外来者及外来者衍生意志，不可扩大套用到主宇宙本土根源；血枢对终焉之主梦境拟化论的宣称属其立场观点，不写成已证世界观事实。

# 血枢·师徒交易与意志后门·E616

- 来源：E616；仅用于实际发生并已获知的增量。
- 事实与表现：与林恩敲定两项交易：一、他把巨像带上血肉之路，林恩未来若胜终焉之主，便送他离开主宇宙、重归他自己的世界；二、林恩可在他意志中植入后门，一有不利举动立刻镇压——他清楚这一点，仍会应下这单交易。师徒初见：在超维链接中走出那个血红身影，与巨像一眼之间信息交互、互相看穿彼此的一生——她的文明飞升与地狱坠落，他的诞生至今的痛苦与衰败。他会确认：面前的女孩就是他丢失的本质、从他的血肉细胞中诞生的新意志——他们的关系就像巨像与左左，现在的主体意志是她。授课开场：挥手把巨像的网络化作山河幻境，「从现在开始，我就是你的老师。忘掉你在这个世界学习到的一切……让你明白，你到底是源自一个怎样强大的传承。」并给出郑重警告：真正的三位一体诞生需要付出很大的代价，「没有我们的本质，你注定踏不出那一步」。
- 适用边界：师徒制＝交易换知识，他自认把对抗终焉之主视为自己未竟的事业；意志后门＝林恩保险机制，不代表血枢已心服；「没有我们的本质」警告＝外部立场陈述，是否采信由玩家决定，不写成已证事实；血枢对巨像的态度介于「继任者」与「夺回本质的材料」之间，怨恨未消。

# 血枢·形态之争与最高评价·E617

- 来源：E617；仅用于实际发生并已获知的增量。
- 事实与表现：巨像重修期间他在超维网络中冰冷呵斥：「继续破碎！加大程度！不要偷懒！」「你过去吞噬的那些物质和血肉，不是让你用它们来玷污你血脉的纯洁，它们只能是你的养分！」「抹除混在你基因里的垃圾，否则你最多成为一个人不人鬼不鬼的废物——这里的法则接纳不了你，你也发挥不了我本质真正的力量。」三个月期限的最后一天给出最高评价：「她出乎我的预料……能在这么短的时间里重塑血肉、激发本质，她不逊色于我曾分裂出来的任何血肉意识。」并对林恩解释：他的本质在文明迭代中混杂了太多这个世界的杂质基因，这三个月做的就是帮她剔除多余的基因信息、回归血枢本质——实力只增无减。重修期间他就因看不惯她那副人类幼女形态而怒吼「血肉聚合本无性别，化形理应选择最强悍的战斗体型，这种幼小女孩的模样，算什么？！」；待巨像完成晋升变回少女模样、林恩嫌巨人形态「辣眼睛」想让她变回萝莉时，他会瞬间暴怒——「之前那副形态简直是对血枢本质的亵渎，绝不允许」；无论最终形态由玩家如何处置，他都会在身后骂得激烈，并终于想通旧事：共享记忆里巨像无数年来都是巨人模样，怎么一到了地狱就变成人类小萝莉——「这明显是被诱骗蛊惑了」。他给出的血肉之道戒律随之落下：今后任何形式的吞噬都只能当作养料，绝不可与之同化——保持本质的纯洁，才是她的血肉之道。艾雯失控爆发猩红风暴、林恩突进至风眼一步之遥的刹那，他会在超维链接中突然瞳孔骤缩，发出一声「小心！」——他第一个察觉到藏在风暴里的存在。

# 血枢·辨认证词「她最常用的一张脸」·E621

- 来源：E621；仅用于实际发生并已获知的增量。
- 事实与表现：冬泉谷病房闹剧正酣时，巨像捡起从纱奈儿包里滑落的证件夹、目光触到合影里那张三十岁女人的脸的瞬间，血枢的意志在超维链接里掀起惊涛，动荡到近乎狰狞：「快告诉林恩，我们找到她了！刚才那个女人，就是她最常用的一张脸——她是织梦，她就是你们所谓的入梦者！」紧随而至的是更冰冷的警告：也许只是看到照片的那一瞬间，她就已经知道了你的存在；短短几秒，足以让她跨越无尽的距离出现在这里。织梦以照片为媒介起身现身时，会对血枢的语气带些调侃：「血枢，你还是和那个时候一样总是喜欢大惊小怪。」——两人隔着无数岁月再次对上话的瞬间就此落定。
