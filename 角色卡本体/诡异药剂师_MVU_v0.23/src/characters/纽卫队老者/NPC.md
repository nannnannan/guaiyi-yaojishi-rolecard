# 纽卫队老者·隐蔽村庄的衰老人（E676）

- 基础信息：隐蔽村庄里坐在广场中央、被黑骑一手扼着咽喉举离地面的老人——他是村里「纽卫队」的退伍老兵，曾随探索队深入过靠近中心地带的峡谷、被银色太阳的银光一瞬间衰老到寿命尽头——此刻他靠着残存的力量向林恩一行传递银色太阳与峡谷的线索。
- 生活结构：他本该能勉强活到一千岁——比普通人两百岁长得多——但几年前深入峡谷时他靠得太近，回过神来已经晚了——他一下子衰老到寿命的尽头。从此被迫退出探索队。他是这村庄里少数知道峡谷情形的普通人。
- 人物性情：即使被扼着咽喉举离地面、口中涌血，他仍咒骂黑骑「你们这些怪物，刽子手」，抓着黑骑的臂铠不放——他是这村庄里剩下的、有血性的普通人；他活下来不是因为他能战，而是因为他不甘心死得没有价值。
- 穿衣风格：一身普通村民的旧式长袍——褴褛、洗得发白；他的面容苍老憔悴、皮肤上满布皱纹；他和他的同伴们脚上还沾着村庄里的泥血。
- 关系网络：他与村民是纽卫队老兵与普通村民——他是他们中间的一员；他与林恩一行是见证与证人的关系——他驱动残存的力量、把不久前的记忆渲染成模糊而不稳定的画面、把银色太阳的所在与峡谷的大致范围告诉林恩。
- 场景表达：黑骑举着画卷、画卷上勾勒着一个像银色太阳般悬动的构造体；黑骑沙哑地吐出几个字：「见过——便说——你的机会——」；老者血从口中涌出、咒骂着、抓着黑骑的臂铠不放——另一把隐约传出龙啸的长枪却先一步将黑骑连人带马贯杀在地面；老者瘫坐血泊、问他们是什么人；龙卫澜说他们不会伤害他们——老者驱动残存的力量把记忆渲染成画面——他在林恩递来的地图上指出了那座峡谷的大致范围。
