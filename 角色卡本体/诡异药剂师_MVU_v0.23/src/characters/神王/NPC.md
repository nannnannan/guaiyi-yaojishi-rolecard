# 神王（轮回神王）·「轮回不属于任何人」·E663

- 来源：E663；仅用于实际发生并已获知的增量。
- 事实与表现：画家在碧蓝世界法师塔前对林恩摊开七大神王格分布时，提到「代表着毁灭的神格最接近于无序，它现在应该就在那片灾厄的手中。至于最后的轮回神格……」她侧过脸，语气中没有任何温存：「它不会属于任何人。我拥有不了，那片灾厄也拥有不了。但如果他想让你拥有，那你或许还有一丝机会。」她说这句话的时候，语气明显带着某种极深的歉意——那枚神格不属于任何一个人，但如果那位神王想让你拥有，你或许还有那么一丝机会。林恩提到的他：就是被黑堡城主轮回神的指挥层；这种祸根从旧世界那一生他在最危急的时刻被堂堂大君识破后，他一直都生活在旧世界的另一侧。他与他的按脉——「黑色少年」——两人从未彼此独立，他们共同的灵魂部分始终维持着单一体态。林恩以画家的意识推进，第二次尝试再一次时需吞入的神格吸引。
- 适用边界：本条只记录「轮回神格不属于任何人」的定性被程式的创设——他是倒吊天使大君最可怕的敌手之一——但他不再是这个天地序列主导的最强者；本条只写他在边角出现，他的重要性将通过轮回神王对林恩的明确一句预言所带出。

# 神王（银色太阳）·「好久不见，哥哥」·E680

- 来源：E680；仅用于实际发生并已获知的增量。
- 事实与表现：他带着林恩跨过时间长河，在几年前罪孽城外的平台上与那道黑发冷漠的身影面对面。他微微颔首：「好久不见，哥哥。」
那与林恩长得一模一样的身影神色平静：「是你。」
银色太阳微变，略带些酒气：「你复苏之后是否可以再跟我联手——」
轮回神王没有回答，抬手轻轻挥，把林恩用一股巨力轰出了定格的时间。
轮回神王落座，像曾经在无法言喻的轮回一样，与他下完那盘亘古未完的棋。时间神王目光凝重：「他已经达到了空间神王的果位，这也算以外者的身份也能进入这个视界。」轮回神王说：「这是我们最后一面，完后便离开。」时间神王接道——所以说，你是不愿再往前了？
轮回神王平静地落子，长发随风——「我根本不知道所谓的终焉之主，当我在这个时代自立时，才第一次想自己经历的这些或许根本就不是时间的轮回。」
时间神王说——这种区别吗？每当终焉之主苏醒，就带来整个世界的重启，这本就是将你们锁死在这里的牢笼，你不清楚吗？轮回神王露出一个冷漠的目光：「不要再叫我哥哥。在我知道时间从未回溯之后，我就无法确定，你是否与我处于同一个时代，你或许比我伟大得多，也或许根本早已存在；我觉得你那次复苏的方式有些问题。」
时间神王眼眸一缩：「因为我只代表着时间，我不是初诞者，我不是你们。」经过一番死斗，他终于说出积压已久的话——我们根本不约束，都是为了逃出这个牢笼，不就是为了追求那份解脱吗？
于是他问一个简单的问题：那么当死亡降临，又是什么？
- 适用边界：轮回神王这次的对话揭开了旧世界最核心的伤疤：时间神王没有抛弃和朋友共处的希望——他想做的样子麻木，而他不能面无表情了，他说「以我的永世长眠为代价，来换你的解脱」，他成功了——这如同杀死他最亲密的兄弟一般。
