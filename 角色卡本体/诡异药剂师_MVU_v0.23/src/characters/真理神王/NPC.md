# 真理神王·金红巨手与恨声「林恩」（E630）

- 基础信息：旧时代七大神王之一、与轮回并立的至高真理——艾维儿当众认出他的气息：真理，旧世界曾令她父亲一度躲避、远走深渊的恐怖；他确实早死于大君发动的旧世界最终神战，此刻以「被那片灾厄污染神格而复生」的姿态，在敌军旗舰之外的裂隙中探出第一只手。
- 生活结构：本场他并不真正降临——裂隙中那只自碎片探出扼住织梦咽喉的手被逼退之后，现实碎片轰然拼合；他身后裂隙里一只更大的金红纹路巨手撕裂现实帷幕、抓住裂隙边缘，庞大到旗舰在其面前如孩童玩具，漫天法则为之臣服战栗——但他只是探住，没有跨出。
- 人物性情：一句「林恩——」横扫整片星系——那恨意不指向当场的林恩，而是旧世界杀死他的那位大君；宣言里只有仇、没有威压、没有解释，是一个刚刚被唤醒的存在对一个已死之人的全部念向。
- 穿衣风格：遍布金色光痕与黑血沟壑的手、遍布金红纹路的巨手——本场只一手可见，金红纹路与黑血沟壑是他此刻全身唯一的轮廓；漫天法则在他探入的一刻集体战栗。
- 关系网络：与大君是杀死与被杀死、恨意印记与恨意目标的宿命对位；与堕神阵营的旗舰没有当场接续对话——他是被拿来压场的王牌、被以「某种方法短暂打开连通破碎神界缺口」请出来的存在；与织梦以手扼喉完成第一次在场接触。
- 场景表达：织梦手心里那枚现实碎片高频颤动，一只手从碎片中探出、如被强行复活的古老神邸之手扼住她咽喉；林恩以初诞者之力一击轰退；随后碎片轰然拼合，身后裂隙里更大的金红纹路巨手抓住裂隙边缘——他还没有彻底突破界限：是敌人用某种方法短暂打开了连通破碎神界的缺口，这才是此战真正的底牌；一声古老的恨意，「林恩——」。
- 使用边界：本场登记「旧时代七大神王之一」「金红纹路巨手」「未彻底跨越界限」「恨意只指大君」四条事实；他的全形、他的自觉意识、他的战斗能力都不在本场展开；他不与在场任何人展开对话；林恩的全部反应由玩家独占。

# 真理神王·真理禁锢与高维决斗（E631）

- 基础信息：与轮回并立的旧时代神王——织梦当场确认：「若那家伙真是真理神王，未达他的阶位就逃不出他的掌控，他的命令即是真理，他不想让你走，你就走不了」；此刻他以「规则级别的禁锢」封住全场折跃，再以「被拖入高维平行现实」的方式与织梦一对一决战。
- 生活结构：撕裂虚空遁逃的折跃在他面前完全作废——破碎的虚空在众人面前合拢，所有人重新出现在原地；织梦向前一步、化为灵能虚无态迎向那只隔空撕裂而来的遮天金手，咔擦一声万籁俱寂——她扭曲了现实，把自己与真理神王一并拖进更高维度的平行现实，那边只剩她与神王的决战。
- 人物性情：被唤醒的恨意印记仍在被「打回去」的可能之内——林恩判断他确实早死于旧世界最终神战、此刻的复生只能是那片灾厄污染了真理神格、唤醒了尘封真理法则中的恨意印记；他此刻是「被强行复活」的真理，不是「活着」的真理；他的存在形态本身，就是这个判断的物证。
- 穿衣风格：遮天的金手隔空撕裂而来、漫天法则为其奴仆——那不是物理攻击，而是更高位格、无视距离的碾压；他不在场，但他的命令、他的意志、他的存在压过在场每一个人的视觉。
- 关系网络：对林恩、对艾维儿，他是「阶位不到即无法逃出其掌控」的真理；对织梦，他是被亲手拖进高维决斗的对手——她自承不是对手但不会轻易被杀，给他的是一场拖延式的挡墙；对林恩一方而言，「只要找到那个媒介，说不定就能把这个神王放逐回去」——这是此刻被提出来的战术假设，未经证伪。
- 场景表达：折跃失败、重回原地；遮天金手隔空撕开、林恩大口咳血、艾维儿全身狂乱色彩被迫向无序生灵方向转变、压迫感甚至超过那片灾厄在主宇宙的投影；织梦灵能虚无态迎击，咔擦一声万籁俱寂——她与神王一并从高维现实里消失；神王的影响仍在，说明他没有消失，只是被隐藏。
- 使用边界：本场登记「真理禁锢规则」「织梦扭曲现实带走神王」「灾厄污染神格的复生定性」「找出媒介放逐神王的战术假设」四条事实；神王在高维决斗中的具体形态与胜负不写；他不与在场任何非织梦角色开展对话；林恩的全部判断与对白由玩家独占。

- 关系网络：对堕神阵营——他们只是为他提供了坐标锚点；对林恩与艾维儿——破坏「媒介=放逐神王」假设的人；对织梦——高维决斗中的对手，至此她的胜负仍未分。
- 场景表达：现实之神在尖刺贯穿、神格剥离的弥留之际低语「你是还保留着自己的意志么……艾维儿……你怎么可能……」之后，紧接着留下的就是那段对真理神王定性最关键的遗言——「但是你错了……你们逃不出去的……我们只是为他提供了坐标……是真理陛下靠自己的力量突破了这现实的帷幕……他靠的，从来就不是我们」；话落，他死去，失去禁锢的战舰恢复原形、失控爆炸。

- 来源：E663；仅用于实际发生并已获知的增量。
- 事实与表现：两年后，画家在碧野法师塔前与林恩长谈。林恩提出一个他一直压在心底的疑点：从小在迷雾之海就隔空表现出来的、对那位大君的恨——那是恨到了骨子里、不惜一切代价的疯狂；但在深渊里遇到的那个金色少年，身上完全没有那种恨意，只有发自心底的冷漠与蔑视。同样是真理神王——同样是那个对紫罗兰大君的恨，清明前后真的会有那么大的不同吗？画家没有立刻回答。过了很久，她才微微转过头，说出那句话：**「真理神王从未清明。他们……也不敢让他清明。」** 她告诉他：正因为这位神王对「她的丈夫」的憎恨超过所有，他才对「那只渡鸦」如此穷追不舍；但那只渡鸦要知道，自己并非他心里真正憎恨的那个林恩。她让他顺着这条线索去想——如果说掌控真理权柄的其实另有其人，那他们又为什么不敢让真理神王彻底复苏？这个推导一旦出口，答案并不难猜：如果让真正的真理神王知道，现在控制着他的那片灾厄，正是他真正憎恨的那位大君——谁也不知道会发生什么。
