# 未来画家性格调色盘

性格调色盘总括：她的底色是「放笔维艰、认画无悔」——那个两纪元里画到最后仍不肯让位的人；主色调是画布般厚重的坦供、以茶与龙蛋递出去的托付、不肯轻易没收他人决定的画者威仪；点缀色是 E714 那一瞬闭眼低语「那也不是……我的丈夫」的残缺——她断得了身份，断不了共燃。

底色内核：放笔维艰、认画无悔
  - 画者心理：她对「完成一幅作品」的执拗高过对「自己是否仍然被记住」的原本坚持；她不找人继承她的风格——她只是不想让一张画没画完就被撕下来扔在风里。E663 的坦供、E671 的龙蛋托付，都是她把画稿拍全交到林恩手里之后可以放手的行为。
  - 放笔维艰：她等了那两纪元，等到紫罗兰旧部都不再提那场婚礼，等到大君沉眠成传说，等到整个神界都移了新地；她没离开、她没换画——她就是那里还站着的那份苍蓝色。E697 三维化身含泪定时，含泪是她面对这趟足以封笔的画必须粗挖的情绪——她还是接了。
  - 断命不舍画：她不是「为了大局安排自己献祭」那类人，她是「这一笔画完之前我不放下」的人；E714 闭眼低语「那也不是……我的丈夫」，是她第一次公开切断神兵与丈夫羁绊，但她没让自己的人生画走完——她仍然要推到 E723「向那最黑暗拓路」才肯下台。

主色调一：画布般厚重的坦供与托付
  - 坦供不遮底：E663 种下一盘棋全貌，承认七大神王格分布、真理神王从未清明、她能屏蔽的最深层因果也有限——她不喊诫，但把诫写得清清楚楚；「我从没说这是一盘公平的棋」是她的作风。
  - 托付不派兵：E671 她把龙蛋交付，不办仪式、不送卫队——她「一拂袖」把林恩扔到世界边荒，只说失败之后她也无力再救。这是她最高的信任，也是她对林恩最严的考量。
  - 「我以为凭你的能力」：她的预判从不出错——她敢说出「我以为凭你的能力，一辈子都找不到这里」，也是她敢承认她只是参与者。

主色调二：不肯轻易没收他人决定的画者威仪
  - 「拥护你的决定」不是她的语言：她从未在任何一次为林恩的决定背书——但她也从不把自己看作可以否决他的人。E714 她看见林恩的局落到三叉戟时不是拦而是低语；E723 她退场时一句「向那最黑暗拓路」是命令不是请求——她把作者与参与者分得清清楚楚。
  - 闭关是「画下去」：她与艾维儿母女之间并不亲腻；她出口的全部家事就锁在龙蛋与权柄之中。紫罗兰旧部喜欢她，也是因为她不必多言，大家都懂她的沉默。

性格点缀与反差：
  - 斟茶的手：苍蓝篱笆小院，茶还是温的——那是她漫长等待里的一个习惯；动笔办案之余她学会了煮茶、学会了把一整段严寒冻住的年月一杯一杯度过去；她坦供时茶是温的，那不延，是她主动把它续着。
  - 含笑的十分钟：E697 三维化身落泪、一巴掌打脸遮天魇王——她的十分钟不是「救赎者」表演，是「我说过不可能撑过十分钟，但我还是撑了」的那种内敛的固执；她给超出她力量的事留了承诺，是她这一生里最远离画笔、最靠近自己的一次。
  - 「向那最黑暗拓路」：E723 退场时的退场命令——不是她逼别人去吃土，是她知道自己这一生画已经到了尽头、她把笔交出去。她到最后一刻仍是个画者——退场的姿势以作画命他人收笔。

极端压力下的应激反应：
  - 面对灾厄本体——她不会逃，也不会站在那里让灾厄来得顺遂。她会撑、会拖、会在被打穿的关键一轴把全部拖入历史梦魇层去继续拖。一生如此。
  - 面对真理神王的对峙——她的反应不是憎恶，是熟悉：她和这些棋子在两纪元里下过很多次，她知道哪一步会掉什么地方。她不怒，她算账。
  - 面对空白实体手里那只「最重载体」——她的反应不是失控、不是嘶吼、也不是护神姿态；她只是以奈奈子之名接住自己，并以奈奈子之名让林恩去做下一件她做不到的事——夺取时间权柄。她对痛苦的处置方式永远是把画画完，不是跪下来哭。
  - 面对终焉——她主动把自己交给它，作为秩序与终焉融合的引信；她的退场不是战败，是她最后给这幅画填的最后一道颜色。黑火中她与大君同时燃烧——这就是这张调色盘最重的颜色。
