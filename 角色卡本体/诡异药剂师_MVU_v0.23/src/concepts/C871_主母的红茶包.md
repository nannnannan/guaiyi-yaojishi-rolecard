# 概念·物品·主母的红茶包（事件["E266","E268"]）

- 类别：物品；黑夜城主母（倒吊天使）以自身十二翼大天使精血泡制的伪装红茶包，具备【大天使净化】与清空旧日（克苏鲁）注视度的保命奇效（严格区分于圣女弥赛亚用于点亮炽天使魂灯的血脉红茶包）。
- 事实门槛：仅在对应事件（E266/E267/E268）进入“完成”或“变形”且正文出现该事实时方可引用；“预兆”“活跃”不得提前兑现。
- 定义：【主母的红茶包】是黑夜城主母（十二翼神圣天使/倒吊天使）特制的战略级保命消耗品，外观伪装成普通红茶包，实则封存着主母本尊的高浓度大天使神圣精血。必须严格区分两类茶包：其一是隐修会圣女**弥赛亚**留下的红茶包/血迹长裙（内含炽天使后裔眷属精血，在E241/E264/E266中作为同源燃料用于点亮【炽天使魂灯】）；其二则是黑夜城**主母**亲手泡制的【主母的红茶包】（内含根源级十二翼大天使本源圣血，在E267/E268梵蒂冈与深海前线中由林恩饮用或激发，触发【大天使净化】以强行清空逼近满值的克苏鲁旧日注视度并驱散深海蚀痕污染）。
- 来源：E266林恩使用弥赛亚留下的红茶包/血迹织物为炽天使魂灯补充圣血燃料；E267—E268在梵蒂冈地下回廊与旧日污染危机中，林恩动用黑夜城主母赐予的【主母的红茶包】，触发大天使净化瞬间清空旧日注视度，化险为夷。
- 机制：①双茶包严格区分：弥赛亚茶包（眷属圣血）＝点亮炽天使魂灯燃料；主母红茶包（根源级十二翼大天使圣血）＝触发【大天使净化】、清空旧日注视度；②大天使净化（E267/E268）：饮用或燃烧主母红茶包后，高阶神圣法则瞬间冲刷全身，强行抹除旧日低语、深海蚀痕与克苏鲁注视锁定；③便携伪装：以日常红茶包形态收纳于系统空间，便于在跨界与潜行战中随时取用。
- 限制与代价：主母处于虚弱休养期，其本源圣血泡制的红茶包数量极其稀少、用一包少一包；单包净化虽能瞬间清零当前累积的旧日注视度，但若继续停留在克苏鲁遗骸或高污染源核心，注视度仍会重新累积。
- 未知项：主母后续恢复后能否再次批量赐予红茶包，以及大天使圣血对更外层宇宙灾厄是否有效。
- 禁止外推：林恩的对白、动作与选择由玩家主权独占；严禁将“黑夜城主母（倒吊天使）”与“隐修会圣女弥赛亚”混同为同一人，不得把弥赛亚称为主母。
