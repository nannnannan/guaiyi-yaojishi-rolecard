# 概念·机制·幽灵模式（事件["E271"]）

- 类别：机制；林恩至高机械体（及后续蚀痕海嗣躯）搭载的光学与气息隐匿潜行模式。
- 事实门槛：仅在对应事件（E271/E314）进入“完成”或“变形”且正文出现该事实时方可引用；“预兆”“活跃”不得提前兑现。
- 定义：幽灵模式是林恩的至高机械体（三位一体机）以及后续融合克苏鲁之眼蚀痕的海嗣之躯所具备的高阶潜行功能。启动后，机体表层通过光学迷彩、能量内敛与生命波动屏蔽，将自身视觉轮廓、热源与灵能气息压制到近乎不可察觉的“幽灵”状态。在E271潜入太平洋深海隐修地（天使禁区外围）以及E314潜入欲望母树根系营救智械小姐时，林恩均依靠幽灵模式规避海嗣集群与敌方耳目的锁定。
- 来源：E271林恩驾驶至高机械体开启幽灵模式潜入太平洋最深处的隐修之地侦查；E314林恩以蚀痕海嗣之躯开启幽灵模式潜入欲望母树根系，将孤身寻尸的智械小姐意识上传权限从【否】改回【允许】。
- 机制：①启动：由林恩的至高机械体或蚀痕海嗣躯激活潜行协议；②视觉与光学隐匿：贴合环境折射光线，消除机体物理轮廓；③气息与能量屏蔽：压制机械炉心波动与生命气息外溢，降低水体或空间扰动；④战术用途：专用于深海禁区渗透、高危战场潜行侦查与秘密救援；⑤破隐条件：主动发起高能攻击、近距离接触根源级/旧日级强感知本体或遭受大范围无差别清场冲击时会解除隐匿。
- 限制与代价：幽灵模式仅提供潜行遮蔽而非无敌免伤；面对克苏鲁注视、根源级领域全面扫描或高强度能量碰撞时仍可能暴露；维持高规格隐匿需持续消耗机体能源。
- 未知项：幽灵模式在不同形态机体（如后续高等三位一体容器）上的迭代上限。
- 禁止外推：林恩的对白、动作与选择由玩家主权独占；严禁将幽灵模式误写为“白夜或普通夜医长袍自带的潜行能力”。
