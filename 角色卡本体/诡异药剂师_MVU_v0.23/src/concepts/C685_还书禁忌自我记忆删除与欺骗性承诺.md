# 概念·机制·还书禁忌、自我记忆删除与欺骗性承诺（事件["E143","E149","E150"]）

- 类别：机制
- 事实门槛：E143完成或变形后成立归还《黑猫历险记》、触发紫罗兰禁忌反噬与自我记忆删除；E149—E150完成或变形后成立002室认知驱逐与林恩利用失忆信息差伪造字据插科打诨。
- 定义：围绕恶魔公寓002室羽毛笔（命运规则神）与《黑猫历险记》形成的一套禁忌规避与认知博弈机制。羽毛笔能以命运书写补全记忆或主动删除自身危险记忆；林恩则利用失忆与认知断层制造信息差，在002室与她插科打诨、拉近关系。
- 来源：E143林恩前往002室归还《黑猫历险记》并补齐断档记忆，羽毛笔试写“紫罗兰的……”时突遭禁忌反噬与血污侵蚀，仅留下“不要长久离开地狱、有一方在寻找而另一方在庇护”的警告，随即主动抹除自身相关记忆；E149羽毛笔以002认知驱逐令来访者忘却来意并离开，林恩趁记忆断层伪造“伴侣契约”字据胡搅蛮缠；E150羽毛笔反复驱逐、抹去数小时记忆并划掉失控写下的灾难，林恩变成黑猫钻过“禁止人类入内”的规则漏洞陪伴她。
- 机制：当书写或追索触及紫罗兰与地狱边境的高位禁忌时，主动删除自身特定记忆可切断“知晓即触发污染或追索”的因果链；002室的认知驱逐则会篡改来访者的短期目的与过程记忆，但林恩可通过提前留下字条、伪造趣味字据或变身黑猫绕过针对“人类”的门禁规则。
- 限制与代价：反复删忆会导致短期情报断层，羽毛笔也会忘却自己刚留下的警告；外部若强行提醒禁忌内容，会再次触发她的本能回避与删忆。
- 未知项：被羽毛笔抹除的紫罗兰真相何时能完整复原、《黑猫历险记》记录与现实因果的先后顺序及病变消退后记忆是否回流均待后续揭晓。
- 禁止外推：林恩的对白、动作与选择由玩家主权独占；自我记忆删除与002室交锋按林恩狡黠跳脱的战术博弈与黑色幽默日常呈现。
