# 概念·历史·渡鸦跨文明启蒙传说的新增证据（事件["E121","E125","E155","E389","E391","E393","E394"]）

- 类别：历史／跨文明传说
- 事实门槛：既有巨像渡鸦神话可按早期事实调用；本词条的新增证据只有主母亲自恢复并讲述深渊记忆（E155）后才成立。梦中指引、画像相似和命运占卜均是线索，不足以确认渡鸦真实身份。后续旧日幻象与时间陵寝事件（E273—E275、E389、E391、E393、E394）严格按对应事件完成或变形门控开放。
- 定义：在巨像文明“永夜中带来春天”的古老神话之外，主母文明也保存了一组独立而结构相似的渡鸦记忆：在深渊全面战争和自我信仰危机中，一只只在梦中出现的渡鸦教她依靠自己、保护同伴并跨过成神门槛，战争结束后消失。由此，渡鸦从巨像单一文明图腾升级为可能跨越文明与时空的启蒙现象。
- 来源：E121确认巨像文明以渡鸦象征在永夜和寒冬中带来希望；E125中林恩以“也能做渡鸦”的誓言承担现实救援角色，但只取得象征意义；E155确认主母在深渊诸位面战争中接受梦中渡鸦指引，之后无法再寻得对方，命运占卜结果指向“不属于当时时空”，其画像还与夜医鸟嘴面具高度相似。事件同时把渡鸦列为连接巨像、赛博与主母文明的跨文明谜团。
- 机制：新增证据至少包含四层。其一，出现环境都与永夜、战争、文明危亡或个体失去外部依靠有关；其二，渡鸦传递的是自救、守护同伴与跨越力量门槛，而非要求崇拜或献祭；其三，完成指引后主动消失，不留下可确认的组织；其四，不同时空和文明的叙述存在意象呼应。它们提高“同一启蒙现象”的可能性，却也可能来自相似符号、后世传播或多个承担同一称号的存在。
- 新旧区分：早期词条已经给出巨像神话和林恩的象征誓言；本词条在E155只补主母第一位面经历、梦中教学、占卜异常和面具相似。林恩愿意承担渡鸦职责，不代表他就是历史中的渡鸦；夜医面具相似也不能证明夜医由渡鸦直接创建。
- 限制与代价：主母记忆曾被封印且暗面未灭，个人回忆需要与其他档案互证；命运占卜只能说明时空不匹配，不能给出来源。赛博一侧被确认存在跨文明关联线索，但具体载体与文本在E155尚未展开，不能擅自补全。
- 运行边界：是否认同、否定、调查或承担“渡鸦”称谓由玩家决定，系统不能替玩家预设救世主认同。渡鸦在各文明中主要承载历史指引与启蒙传承，林恩的言行选择由玩家主权独占。
- 未知项：渡鸦是单一实体、群体称号、命运投影还是文化传播结果；其与赛博文明的具体证据、与夜医面具的因果、能否跨越时间、为何选择主母与巨像，以及是否仍存在均未知。
- 禁止外推：林恩的对白、动作与选择由玩家主权独占；禁止违背既有设定将其描写为无消耗或脱离因果律违规生效。
