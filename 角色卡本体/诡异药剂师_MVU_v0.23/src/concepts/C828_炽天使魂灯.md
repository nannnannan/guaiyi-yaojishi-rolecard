# 概念·物品·炽天使魂灯（事件["E255","E265","E584","E592"]）
- 类别：物品；隐修会传承的古老法器——以炽天使血脉之血（弥赛亚精血）为燃料，可驱散诡秘、蒙蔽注视、压制深海污染；灯灭即诡秘动乱。
- 事实门槛：E255隐修会与炽天使关系揭示（神降之日/天启元年/血脉后裔）；E265完成/变形且正文实际出现魂灯（破损）拾取、以弥赛亚红茶包/血迹裙/血迹绷带点灯、灯照范围压制动乱、踏入圣彼得中心广场时方可引用。
- 定义：【炽天使的魂灯】是隐修会内部传承下来的古老法器，只有隐修之地内的侍从方可使用，可以在一定程度上驱散周围的诡秘、蒙蔽某些事物的注视，似乎对深海的污染有着一定的克制效果；但随着魂灯的熄灭，周围的诡秘也会出现更可怕的动乱。E265林恩在梵蒂冈教堂走廊拾到【炽天使的魂灯（破损）】（教士尸骨手骨上挂着），用【弥赛亚的红茶包x1】【沾染弥赛亚血迹的裙子x1】【沾染弥赛亚血迹的绷带x5】作燃料点亮——炽天使血脉精血是燃料；灯燃处蚀痕不敢近、海嗣在外环绕；灯灭或燃料耗尽则外围动乱沸腾。
- 来源：E255弥赛亚揭隐修会来历（两千多年炽天使降临、血脉后裔）；E265教堂走廊发现教士尸骨与破损魂灯，往日遗念揭示教士们曾试图逃出、魂灯压制污染、被海嗣围攻抽干、最后一位教士滴血续火、灯灭消散异变（"快跑！魂灯马上就要熄灭了！"）；林恩翻出收藏的弥赛亚红茶水/血迹裙/血迹绷带点灯，"呼——火苗窜起"；【技能：炽天使魂灯展开——以弥赛亚精血为燃料，驱散诡秘+蒙蔽注视】；魂灯灯照之处触手不敢近，外围蚀痕沸腾更烈；他提灯与血衣踏入圣彼得中心广场。
- 机制：①法器：隐修会侍从专属（驱散诡秘/蒙蔽注视/克制深海污染）；②燃料：炽天使血脉之血（弥赛亚精血——红茶包、血迹裙、血迹绷带皆可为来源）；③点亮：挤入燃料→火苗窜起→展开技能；④场域：灯照范围内蚀痕/触手被压制、不敢靠近；⑤代价：灯灭→外围诡秘全面动乱（教士全灭的教训）；⑥探索：魂灯是后续旧日核心探索的唯一稳定照明。
- 限制与代价：破损魂灯有耐久上限；燃料是炽天使血脉产品（有限、需从弥赛亚遗留物中取）；灯照范围有限、灯外动乱随行为（攻击/深入）加剧；灯灭即死局。
- 未知项：魂灯完整版的效果、能否以其他炽天使血脉（主母级）点灯、灯灭后动乱的极限形态均未知。
