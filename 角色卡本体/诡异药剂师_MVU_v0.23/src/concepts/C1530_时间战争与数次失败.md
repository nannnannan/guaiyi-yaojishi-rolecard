# C1530·时间战争与「失败了无数次」的推断

- 类别：战争／推断句／时间之末本体
- 未知项：「我们已失败无数次」「林恩已多次踏足这类战场」「他重演过去、摆脱钳制」「未来的你和我谈过」仅作推断与暗示出现，未交清；「历史重塑」具体推表几句、主母和孽主的先例如何关联这些时间点；画家「只有容器」与「不同时间点信息不同步」的本点仅是 flash 段语句；「这一次的时间战争」是否最终交清，仍未知。
