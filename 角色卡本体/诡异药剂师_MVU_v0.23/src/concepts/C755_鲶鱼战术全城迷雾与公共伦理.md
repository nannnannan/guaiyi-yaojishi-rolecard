# 鲶鱼战术全城迷雾与封城动员［C755］

- 概念编号：C755
- 所属分类：战术策略与危机控场
- 首次出现事件：E215
- 相关事件：E215、E216

## 定义与机制
“鲶鱼战术”是林恩在蜀都面对潜伏于数百万市民中的寄生兽危机时，故意在广播塔制造全城迷雾与巨型血肉恐怖异象，以“人造外敌恐慌”充当鲶鱼，倒逼蓝星官方机器瞬间进入最高战备封城状态的非常规控场策略。

## 核心规则与表现
1. **破除常规通报困局**：寄生兽通过水源隐秘传播，若按常规渠道层层上报，不仅耗时长久，更会给血肉神教转移和引爆虫群留出充足空当。
2. **恐怖显影倒逼封城**：E215林恩在广播塔顶释放遮天蔽日的迷雾并投射骇人异象，令官方误以为遭遇超自然全面入侵，当即下令全城戒严、封锁交通与水源，客观上完美配合了防扩散需求。
3. **迷雾索敌精准拔点**：在全城静默封锁的掩护下，林恩利用迷雾感知网迅速揪出第二人民医院聚集感染区并完成定点清除（E216—E218）。

## 使用约束
- 鲶鱼战术体现了林恩行事不拘世俗常理、善用恐惧与大势达成救人目的的灰暗行事风格。
