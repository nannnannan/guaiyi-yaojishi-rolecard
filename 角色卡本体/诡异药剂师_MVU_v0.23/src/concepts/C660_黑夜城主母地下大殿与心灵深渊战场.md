# 概念·地点·黑夜城主母地下大殿与心灵深渊战场（事件["E141","E142","E144","E145","E146","E147","E155","E195","E199","E200","E202","E203","E204","E351","E368"]）

- 类别：地点／根源级战场与议事法阵
- 事实门槛：地下大殿有两个必须分开的运行状态。主母失联、甬道黑霜、守卫扭曲、心智污染或堕天使仪式至少两项得到现场确认后，才可调用心灵深渊危机；仪式破碎、善性主人格归返只证明一次全城转化被阻止，不代表暗面人格消失。后续五名根源共同刻画跨世界法阵、讨论保护性转移与隐蔽旁听，必须由E195以后的记录单独确认，不能倒写成旧战场设施原本用途；涉及跨界与转移的选择始终由玩家主权独占。
- 定义：大殿位于黑夜城中央高塔下方，最初是主母长期自缚、封印暗面、会见根源与处理城市事务的地下殿堂。暗面夺取身体时，现实甬道、结界门、大殿法阵与主母意识深处、全城金色节点重叠，形成抽取生命、放大恶意的复合战场；危机之后，此地恢复为根源议事、诊断、封印和跨界工程场所，又被五名根源用于收集表世界信号和准备转移林恩。
- 来源：E141至E142确认主母持续无回应、地下禁令、黑霜、扭曲守卫、十二翼暗面和心灵深渊仪式。E144至E146确认羽毛笔制造命运偏差、金色节点与钟阵回亮、根源同伴牵制、八音盒加深诅咒、主人格从深处夺回身体并击碎仪式；E147与E155确认主母休养、临时保护和暗面仍需长期镇压。E195确认五名根源同处大殿刻画大型法阵；E199至E200确认二百零一个世界信号、五十一个可准备召唤代价的宣称，以及在地狱凝视前实施保护性转移的提案；E202至E204确认主母在殿堂诊断持续污染、隐藏法阵和诱导许可暴露，随后出现五十余世界并发定位与围控冲突。
- 机制：心灵深渊会放大覆盖区恶意与疯狂，使完成转化者服从施术者并抽取全城生命力反哺暗面；破局依赖地下攻坚、城市钟阵、主人格金色节点、根源牵制和外部命运偏差共同作用。战后议事态的法阵则接收外部召唤信号、降低跨界阻力并叠加定位。地下大殿铭刻有初代黑夜城的防御古阵与心灵隔离结界，大殿深处连接主母的私人内空间。
- 限制与代价：最高禁令曾延迟查验，公开双人格真相又会冲击信仰；根源攻坚造成结构损伤，法阵破碎也不能复原全部受害者。跨界工程把多世界坐标引入城市，可能招来追索与信号串扰；大殿防御高度依附主母自身状态。
- 未知项：旧仪式的伤亡与康复名单、暗面与主人格原初关系、八音盒和狱卒权柄来源、路西法之门现状、跨界法阵建造材料与二百零一个信号身份均未知。
- 禁止外推：林恩的对白、动作与选择由玩家主权独占；禁止违背既有设定将其描写为无消耗或脱离因果律违规生效。
