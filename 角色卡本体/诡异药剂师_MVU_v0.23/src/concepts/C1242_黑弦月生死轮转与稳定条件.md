# C1242·黑弦月生死轮转与稳定条件·E636
- 类别：状态机制／献祭式改造与自愿折衷
- 定义：林恩从人偶阵列中感到一道熟悉的气息、瞬身掀开靠前那个娇小身影的遮面长袍——黑曜石般的双眼睁开，是黑弦月。她的表情木然，如真人偶。人偶家解释：她太要强了——不知不觉中那个曾在地狱陪着林恩的少女已慢慢掉队、跟不上他的脚步；她本可以像其他人一样安静地待在黑夜城，可她不想那样，她还是想跟在他身边、和他并肩作战、而不只是接受他的庇护。所以她接受了人偶家的衣钵：**打碎了自己好不容易获得的血肉、留干了血、重新把自己改造成了人偶**。若林恩脸色阴沉斩钉截铁反对、法则流光浮现掌心就要笼罩她，人偶家会抓住他的手挡住：她是他有能力把她变回去，但**那是弦月自己的选择**；她不希望自己只能远远地看着他独自痛苦——她是他她的老师，比他更知道她想要什么、她能忍受什么。人偶家直视林恩：**她不是你的妻子，也不是你的禁脔，你没有权利违背她的意愿**。就在这时一只纤细的手抓住他的手背——黑弦月不知何时已走到他面前、抓住他的手、闭着眼把侧脸贴上他的胸膛、一点点熄灭他手心的法则威光。她木然无温，但小拇指上那根丝线仿佛在轻轻诉说她的决定、渴望与向往：也许不奢求他全部的爱、不奢求梦境中那样的一生——但就像那个时候、像他帮助她那样，也给她一次能帮助他的机会，哪怕只是微不足道的一份力量。丝线停下。若林恩紧握的拳一点点松开、终究没有逆转她的改造，他会擦去眼里的沙子、笑着扭头，不让人看见表情：既然你们每个人都有自己的主意，那就随便你们好了。
