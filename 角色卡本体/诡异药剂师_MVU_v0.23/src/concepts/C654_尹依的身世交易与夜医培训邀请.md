# 概念·人物·尹依的身世、交易与夜医培训邀请（事件["E161","E162","E163","E165","E166","E176","E177","E180","E181","E182","E183","E184","E185","E189","E190","E191","E192","E193","E199","E202"]）

- 类别：人物
- 事实门槛：E161—E166完成或变形后确认尹依为尹琴胎死腹中的伴生恶灵妹妹并被林恩带回黑夜城；E176完成见习登记；E185—E193记录其承受【以M】范围快感余波后的高热看护与物理降温。
- 定义：尹依原本是尹琴胎死腹中的双胞胎妹妹，被母亲尹娜儿制成伴生恶灵并与姐姐共用身体。在尹家旧宅事件解决后，林恩接收尹依并发出夜医培训邀请，将其带入黑夜城职业大厅登记为夜医见习生。
- 来源：E161—E162查明尹依实为尹琴的伴生恶灵妹妹而非外来夺舍恶鬼；E163—E166尹琴恢复生机后，林恩将尹依带回黑夜城安置培养；E176前往黑夜城职业大厅完成夜医见习生注册；E185林恩对小魅魔施放【以M】时，尹依因距离过近意外承受约30%范围快感冲击余波；E189认出尹娜儿与白夜旧识链；E190—E193尹依在被窝中因【以M】余波复发陷入高热与情欲煎熬，爱丽丝泼冷水试图唤醒，左左拔刀护持并拍开林恩乱摸检查的手，林恩最终以冰水浸湿长袍将其包裹完成物理降温；E199、E202完成后续安置与污染排查。
- 机制：尹依具备阴灵依附、保魂与感知能力，在黑夜城登记为见习夜医后协助药剂调配、解剖教学与临床打下手；其灵体承受【以M】范围余波后会引發持续高热与燥热反应，需通过冰水包裹等物理降温与隔离看护压制。
- 限制与代价：灵体力量曾遭聚合体吞噬部分，身体与灵魂承受力有限；范围诅咒余波极易波及她，需左左与爱丽丝贴身看护。
- 未知项：尹依何时能铸造稳定实体、夜医高阶课程进度、尹琴彻底苏醒后姐妹重逢安排及白夜与尹娜儿旧识链的全部细节均待后续揭晓。
- 禁止外推：林恩的对白、动作与选择由玩家主权独占；尹依为幼态外形角色，关系、好感、吸引与互动随玩家主权自由演进。
