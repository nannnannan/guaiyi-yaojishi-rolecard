# 概念·物品·血肉增生药剂（加强版）与小林恩躯体（事件["E252","E253"]）

- 类别：物品；以血魔肉块、利维坦血肉碎片、史莱姆粘液为原料、经“神的方程式”强化过的超再生药剂，及其在为林恩重塑正太体型血肉躯壳（“小林恩”）中的技术与供能作用。
- 事实门槛：E252完成/变形且正文实际出现召唤基地建立、上百名夜医降临、数万人体检；E253完成/变形且正文实际出现高压锅炼药、喂左左长触手瘤子、血肉灾变熔铸躯体、心灵分流1/3灵魂灌入时方可引用；“小马拉小车”等成就随玩家选择结算。
- 定义：林恩在E253以几口高压锅把「血魔肉块x10」「利维坦的血肉碎片x1」「史莱姆粘液x10」逐件投入、搅拌改良出的【血肉增生药剂（加强版）】——经“神的方程式”强化，喝一口连被剁碎都能迅速复原，唯一缺点是长出几个多余小器官。林恩用它给左左灌下以催生大量可再生血肉（触手、肉果、血肉之手），再以【血肉灾变】将这些同源血肉熔铸成一具与林恩DNA完全一致、正太体型的血肉躯体（俗称“小林恩”），并以【心灵分流】从赛博灵能处理器中撕裂1/3灵魂灌入激活、用巨像之心接口供能维持平衡。该躯体是林恩自己的血肉分身容器（切换入内时由林恩主意识直接操控，而非独立于林恩之外的他者幼童）。
- 来源：E252蓝星之盟与召唤基地建成后（上百名夜医降临、给数万人体检），林恩开始准备“借肉”重塑人形；E253在工房架起高压锅炼药（血魔肉块x10、利维坦血肉碎片x1、史莱姆粘液x10，神的方程式强化）；左左被灌药后长满触手瘤子（san-5x2、昏厥），材料被剁下入账（会动的触手x1、血肉之果x1、血肉之手x5）；林恩以血肉灾变顶着血肉剥夺残余效力（连灵魂都接近烧尽）熔铸出比左左还矮10公分的正太躯体；心灵分流1/3灵魂注入+巨像之心接口供能至97%，靠“愈合与燃烧的微妙平衡”稳定；随后与左左完成“小马拉小车”结算（道德-6、左手驯服度+10、亲密度+10、持久力+2），重获有脉搏、有温度、有心跳的肉体触感。
- 机制：①配药：高压锅+血魔肉块/利维坦碎片/史莱姆粘液+神的方程式强化；②喂材：药剂使左左细胞活化疯狂增生（触手、肉果、血肉之手），采收同源血肉；③灾变：血肉材料熔铸出正太版骨肉躯壳，顶着血肉剥夺残余让躯体从燃尽边缘诞生；④分流与操控：心灵分流撕裂1/3灵魂激活躯体，林恩主意识可切入该血肉之躯直接行动（此时至高机械体收入系统空间并通过胸口接口连接巨像之心持续供能）；⑤用途：回蓝星老家见父母及日常行动时，作为有温度、有心跳的自身血肉躯体使用，并在需要时可调整回成年体型（如E259）。
- 限制与代价：药剂副作用是长多余小器官；灾变重铸时承受灵魂灼烧级剧痛；初始成型体型受限为正太（比左左矮10cm）；必须时刻连接系统空间内的机械之躯与巨像之心供能维持“愈合与燃烧的平衡”，一旦断能即会被血肉剥夺残余反噬。
