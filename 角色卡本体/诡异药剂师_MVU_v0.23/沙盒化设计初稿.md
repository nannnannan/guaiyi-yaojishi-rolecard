# 《诡异药剂师》沙盒化设计初稿

**版本**：草稿 v0.1（待哥哥审）
**日期**：2026-10-01
**参照样例卡**：卡 2 光阴长河（长河支流偏离账本）、卡 4 日式中专大乱斗（后台默认路径/可偏离）、卡 5 校园恋爱综漫（时空锚点/调度器）

---

## 一、核心设计原则

1. **主线线性保留**：798 主线事件 E01→E798 保持线性因果链，保证时空连贯性（哥哥决策 B）。
2. **玩家可偏离，但需结果等价**：玩家可跳过某事件，但需以偏离方式补齐该事件的结果（如「用配方调配」代替「去医院救患者」获得解药），保证后续事件因果成立。
3. **偏离记账**：偏离通过「偏离账本」记录（原著走向/玩家改变/预期影响/涉及人物/状态），供后续事件激活时参考。
4. **时空锚点驱动**：玩家偏离主线时，世界流动由「当前时间/当前地点/当前阶段」驱动，而非线性事件顺序。
5. **最小改动**：在现有 MVU Zod schema 上**新增**沙盒变量，不改「事件.锚点状态」「关系」「林恩」等核心变量；不删 798 事件内容（「默认走向」作为后台默认路径保留）。

### 2.1 新增字段（在现有结构基础上）

```yaml

世界:  # 在现有字段基础上新增时空锚点子字段

    #     状态: "发酵中"

# 关系/角色关系/系统/元数据：不动
```

### 2.2 字段说明

- **`世界.当前时间/当前时段/当前地点`**：时空锚点，驱动「玩家偏离主线时，世界怎么流动」。玩家不走主线时，世界流动由「当前时间+当前地点+近期事务」决定，不再依赖线性事件顺序。
- **`世界.时空冻结`**：参照卡 5。开时，`当前时间/当前时段/当前地点` 保持不变（玩家自己控制时间）；关时，按剧情自然流动。
- **`章节管理.时期/阶段`**：大阶段与子阶段（参照卡 4）。用于 EJS 章节/概念分支（如「蓝星篇初期」激活蓝星相关概念，「地狱篇中期」激活地狱相关概念）。
- **`事件.偏离`**：偏离账本（参照卡 2 长河支流）。**只记录玩家对原著走向产生节点性改变的事件**，不记录日常琐事或仅登场露面。
- **`事件.近期事务`**：近期世界动态（5-8 项滚动）。玩家偏离主线时，世界动态由这些事务呈现，替代「按线性事件顺序推进」。

### 2.3 不新增字段（哥哥否决项）

- ❌ 日常药剂坊事件模具（卡 5）：我们卡概念和事件已足够丰富
- ❌ 记忆模板（卡 1）：我们已有其他记忆方式

## 三、798 主线事件改造（后台默认路径 + 可偏离）

参照卡 4 的 Z_Y 章节大纲格式，把每个主线事件 E 从「线性剧本」改造为「后台默认路径 + 可偏离」的五段式。但**不改动现有「默认走向」内容**，而是在事件外部（或系统提示）加偏离通道。

### 3.1 事件结构（五段式，新增加粗部分）

```
事件内容（默认走向）:（现有内容，保留不动，作为「后台默认路径」）

后台推进（新加）:玩家不干预时，原著默认走向（一句话概括：本事件原著走向是什么）
  例（E37）:「林恩去蜀都医院救治患者，获得解药」

可偏离内容（新加）:玩家如何改写本事件（列举允许的偏离方式，保证结果等价）
  例（E37）:
    - 若玩家用系统/配方自行调配出解药，视为结果等价（解药入手），E38 照常推进
    - 若玩家放弃救治患者，解药不入手，E38 无法推进（因果断裂）

原主角偏离反应（新加）:玩家截胡/改变主线时，原作主角/相关 NPC 的反应
  例（E37）:
    - 若玩家用配方调配，医院医生不会认识林恩，后续医院相关剧情按偏离账本调整
    - 若玩家提前离开蜀都，血肉神教在旧城区的活动按近期事务呈现
```

### 3.2 改造方式（最小改动）

**不直接改 798 个事件文件**，而是：
- **后台推进/可偏离/原主角偏离反应**：写进一个统一的「沙盒规则」常驻概念条（或系统提示补充），说明「玩家偏离主线时，按结果等价原则补齐，偏离通过偏离账本记录」。
- **后台默认路径**：现有「默认走向」就是后台默认路径，不需要改动。

这样**不改动 798 个事件文件**，只在「系统层」加偏离规则。

## 四、事件链激活逻辑调整（concept_event_router）

现有 eventSequence 线性推进（找第一个「活跃」事件作为锚点）需要调整，以支持「玩家偏离主线时不卡死」。

### 4.1 激活逻辑调整（核心改动）

**现状（线性推进）**：
```
找 eventSequence 中第一个「活跃」事件作为锚点 → 激活「事件窗口±1」
```

**改为（时空锚点 + 偏离账本驱动）**：
```
1. 先读「世界.当前时间」「世界.当前地点」「章节管理.时期/阶段」
2. 找「当前时空」下应激活的事件（按章节管理的时期/阶段过滤 eventSequence，取当前时期/阶段内第一个「活跃」事件）
3. 激活「事件窗口±1」（保留现有机制，但窗口基于当前时空的事件，而非全局第一个活跃事件）
4. 读「事件.偏离」账本，把偏离影响注入激活的概念/角色（如：医院 NPC 对林恩的认知按偏离账本调整）
```

### 4.2 偏离账本参与激活

激活后续事件时，AI 读「事件.偏离」账本，理解：
- 玩家之前偏离了哪些事件（结果如何补齐的）
- 这些偏离对世界状态的影响（如：医院 NPC 不认识林恩）
- 后续事件的激活是否需要调整（如：后续医院相关事件按偏离账本调整 NPC 反应）

**偏离账本的呈现**：在「默认走向」注入时，附加偏离影响说明（如「由于玩家之前用配方调配解药，医院医生不认识你」）。

### 4.3 玩家想走主线时（spawn point）

玩家想回到主线时，选择一个事件切入（spawn point），然后用现有的「锚点状态」+「事件窗口±1」机制继续推进（线性链保持不变，作为可选玩的原著线）。

## 六、待哥哥确认的设计决策

在动笔前，有几个决策点需要哥哥确认：

### 决策 1：**偏离账本多久自动清理？**

偏离账本记录玩家对原著走向的改变。这些偏离是否需要自动清理？比如：
- **A. 永久保留**：所有偏离都永久保留（账本越来越大，但完整）
- **B. 按状态清理**：「已兑现」的偏离保留一段时间（如 50 个事件后）后清理，「发酵中」的偏离永久保留直到兑现
- **C. 按重要性清理**：只有影响后续事件的偏离保留，无关紧要的偏离自动清理

### 决策 2：**「结果等价」的判定权归谁？**

玩家用「其他方式」获得解药时，谁判定这个方式「足以支撑后续因果」？
- **A. AI 判定**：AI 根据世界观+逻辑判断替代方式是否等价（灵活，但可能误判）
- **B. 预设规则**：在沙盒规则里预设「哪些偏离方式算等价」（如「用配方调配解药=去医院救患者」），AI 按规则判定（可控，但不灵活）
- **C. 玩家声明**：玩家声明替代方式等价即可（最简单，但可能乱来）

### 决策 3：**「时空冻结」默认开启还是关闭？**

卡 5 的时空冻结默认是「关」（时间自然流动）。我们的卡：
- **A. 默认关**：时间自然流动，玩家偏离主线时世界照常流动（推荐，符合沙盒精神）
- **B. 默认开**：时间冻结，玩家自己控制时间（安全，但可能卡死剧情）

### 决策 4：**「章节管理.时期/阶段」怎么划分？**

798 个主线事件怎么划分「时期/阶段」？建议：
- 蓝星篇（E01-E200）
- 地狱篇（E201-E400）
- 机械神教篇（E401-E600）
- 主宇宙篇（E601-E798）

或者按现有 S 阶段（S0-S101）划分。
