2. **98 份全角色深渊图鉴卷宗（28 核心角色 + 66 动态登场 NPC + 4 份特殊卷宗）与机制三等价**
   - **28 名核心角色**：均配备「角色速览 / 基础信息 / 性格调色盘 / 三面性 / 多阶段人设 / 二次解释」六组件立体档案，随事件推进动态解锁阶段人设。
   - **66 名可选动态 NPC**：按事件窗口与关键词双路动态投送，不冗余挤占常驻上下文。
   - **色色解咒三等价与专属调教维度**：严格遵循「以M = 快感冲击（媚药）、性行为 = 解咒途径、恶堕 = 性调教路径」三等价法则；维护好感、信赖、戒备、吸引、关系创伤、恶堕、涩涩度及专属调教维度（情感开发度 / 驯服度 / 崩坏值 / 恨意值）。成年存在按成年口径直白呈现，明确标注为幼童的角色保持纯净亲情守护与童趣互动的中性合规表述。

3. **V1.0「诡秘解剖羊皮卷」双层响应式状态栏**
   - **楼层轻量摘要卡**：每轮回复底部呈现紧凑哥特羊皮卷摘要，集成时期/地点坐标、林恩生理与权柄微章、在场角色速览、当前活跃事件与 `@module` 动态场景专属模块。
   - **全屏四大核心视图（`灵肉场域` / `深渊情缘` / `诡异图鉴` / `沙盒星图`）**：支持一键展开检视林恩生理/药剂/手术台、核心羁绊与调教刻度、98 份深渊人物与设定图鉴、798 事件沙盒星图与偏离账本。
   - **防剧透门控（`spoilerSafe`）与窄屏/移动端自适应**：默认隐藏尚未解锁的人物与未触发事件并提供显影开关；针对窄气泡与手机视口（低至 `375px`）实现 `0px` 水平溢出。

4. **正态分离 · 专职状态官独立 API（`#gyp-agent-console-v023` & `<GypDSL>` v1.0）+ `@module` 动态场景模块**
   - **正态分离二连发引擎**：主 AI 专注正文叙事，回复结束后由内嵌状态官引擎自动审计正文并输出 `<GypDSL>` 指令块，实时编译为 MVU JSON Patch 并驱动状态栏更新（兼容单通道 `<UpdateVariable>` 回退）。
   - **独立 API 与零配置主 API 双模支持**：通过内置 `#gyp-agent-console-v023` 控制台，既可配置自定义 OpenAI 兼容副模型（Base URL / API Key / Model），也可零配置直接复用酒馆主 API（`TavernHelper.generateRaw`）。
   - **`@module` 动态场景专属模块**：状态官可根据当前现场（如怪医外科解剖台、魔药调配、古堡围猎、机械姬调教舱、神疆战局等）动态挂载场景专属交互模块。

5. **沙盒世界观架构与 MVU × 龙血玄黄·数据库双轨协同**
   - **沙盒变量层**：`schema.js` 系统对象完整维护 `偏离`（蝴蝶效应账本）、`近期事务`（滚动时空轨迹）与 `信号`（一次性事件防重锁），支持结果等价判定与变形收束。
   - **双层纪年数据库协同**：原生适配「龙血玄黄·数据库（AutoCardUpdater / shujuku）」，通过 E 锚点世界观层与 `[AMxxxx]` 个人纪事层双轨协同，保障超长线记忆连续。
