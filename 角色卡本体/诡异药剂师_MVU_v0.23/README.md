## 一、V1.0 核心特性总览

1. **全书 798 事件封箱（S0—S101）+ 1,830 条世界书词条 100% 内置**
   - 完整覆盖原著七大时期（游魂巷药店篇 `E001—E032`、黑夜城夜医篇 `E033—E133`、蓝星返乡篇 `E134—E254`、机械神教篇 `E255—E348`、渡鸦真相与地狱扩展篇 `E349—E506`、地狱统一与主宇宙神战篇 `E507—E681`、终焉决战篇 `E682—E798`），止于 **E798** 终焉融合与雪谷婚礼「本书完」。
   - 内置 1,561 项核心概念（含事件门控动态变体与增量演进）、798 份事件素材与 798 份专属 `if线` 分支，依托 `@@preprocessing` 概念/人物事件窗口（`±1`）与酒馆原生关键词双路去重激活。

2. **94 名全角色深渊卷宗（28 核心角色 + 66 动态登场 NPC）与机制三等价**
   - **28 名核心角色**：均配备「角色速览 / 基础信息 / 性格调色盘 / 三面性 / 多阶段人设 / 二次解释」六组件立体档案，随事件推进动态解锁阶段人设。
   - **66 名可选 NPC**：按事件窗口与关键词双路动态投送，不冗余挤占常驻上下文。
   - **色色解咒三等价与专属调教维度**：严格遵循「以M = 快感冲击（媚药）、性行为 = 解咒途径、恶堕 = 性调教路径」三等价法则；维护好感、信赖、戒备、吸引、关系创伤、恶堕、涩涩度及专属调教维度（情感开发度 / 驯服度 / 崩坏值 / 恨意值）。成年存在按成年口径直白呈现，明确标注为幼童的角色保持纯净亲情守护与童趣互动的中性合规表述。

3. **全新 V1.0「诡秘解剖羊皮卷」双层状态栏**
   - **楼层轻量摘要卡**：每轮回复底部呈现紧凑哥特羊皮卷摘要，集成时期/地点坐标、林恩生理与权柄微章、在场角色速览、当前活跃事件与 `@module` 动态场景专属模块。
   - **全屏四视图解剖手札**：支持一键展开「病历与躯壳」「因果解剖图」「深渊人物志」「视界与造物」四大全屏档案页，默认隐藏未接触人物与未触发事件以严防剧透，并提供显影切换开关。

4. **首创「正态分离 · 专职状态官二连发引擎 + GYP-DSL 模块化语言 + 动态场景专属模块（`@module`）」**
   - **正态分离二连发**：主 AI 专注正文叙事，回复结束后由内嵌脚本自动调用「专职状态官 AI」审计正文并输出 `<GypDSL>` 指令块，实时编译为 MVU JSON Patch 并驱动状态栏更新（兼容单通道 `<UpdateVariable>` 回退）。
   - **`@module` 动态场景专属模块**：状态官可根据当前现场（如怪医外科解剖台、魔药调配、古堡围猎、机械姬调教舱、神疆战局等）动态挂载场景专属交互模块。

5. **v0.23 → V1.0 沙盒世界观架构与数据库协同**
   - **沙盒变量层**：`系统.沙盒` 完整维护 `偏离`（蝴蝶效应账本）、`近期事务`（滚动时空轨迹）与 `信号`（一次性事件防重锁），支持结果等价判定与变形收束。
   - **双层纪年数据库协同**：原生适配「龙血玄黄·数据库（AutoCardUpdater）」，通过 E 锚点世界观层与 `[AMxxxx]` 个人纪事层双轨协同，保障超长线记忆连续。

## 二、构建与离线校验

在本目录运行以下命令执行全套构建与离线契约校验：

```bash
npm run build
npm run check
```

生成物为 `dist/诡异药剂师_v0.23.json`（保持工程产物路径稳定，禁止直接手改 `dist/`）。真实 SillyTavern 宿主验收按作者要求暂缓，`host_acceptance.json` 状态保持 `pending`。
