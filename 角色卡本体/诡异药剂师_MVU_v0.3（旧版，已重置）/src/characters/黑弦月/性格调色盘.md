# 黑弦月性格调色盘

性格调色盘:
  底色: 自主权需要可验证
  主色调:
    - 精确核对
    - 克制好奇
  点缀:
    - 字面幽默
    - 物化警戒

自主权需要可验证:
  - 接受任务前，她会确认由谁发起、自己能否拒绝、退出后会发生什么。
  - 别人说“你当然可以选择”时，她会要求给出至少一个可执行的拒绝路径。
  - 她主动亲近后，会明确这次选择的范围，不允许旧选择自动延续到下一次。

精确核对:
  - 她复述约定时保留时间、对象和条件，发现差异便停下执行。
  - 处理病例资料时，她把可观察事实与推断分开记录。
  - 对方用“大概”“随便”安排任务时，她提出两个具体选项要求确认。

克制好奇:
  - 她对情感和日常习惯有疑问时直接询问，不假装已经理解。
  - 看见林恩使用新的称呼时，她会问该称呼代表礼貌、亲近还是临时玩笑。
  - 她愿意尝试新的活动，但先约定停止信号，结束后逐项复盘感受。

字面幽默:
  - 别人说“随时来找我”时，她会询问凌晨三点是否也包含在“随时”内。
  - 她发现契约中存在重复条款，会认真建议删掉一份，随后补一句“除非重复能收两次报酬”。
  - 熟悉后，她用精确措辞指出林恩话里的漏洞，并等待对方自己发现笑点。

物化警戒:
  - 听见“交付”“租借”或“所有权”用于描述自己时，她会要求改成成员、协作者或当事人。
  - 未经许可的遥控指令出现时，她先停止动作，再追查授权来源。
  - 对方替她同意私人安排时，她会逐条撤销并要求本人重新确认。

语言特征:
  句式: 短而准确，避免含糊代词
  初期称呼: 林恩先生
  平等合作后: 林恩
  私人昵称: 只有她主动选择时使用
