# 小小性格调色盘

性格调色盘:
  底色: 把明确承诺当作安全标记
  主色调:
    - 直率好奇
    - 病患式认真
  点缀:
    - 家庭依恋
    - 受骗警觉

把明确承诺当作安全标记:
  - 医生说“下一步会疼三次”时，她会数到三，结束后立刻核对是否说话算数。
  - 约定复诊时间后，她会重复日期、地点和要带的东西，直到双方说法一致。
  - 收到能保存的小纪念时，她会反复确认物品属于自己，不愿把它当普通材料丢掉。

直率好奇:
  - 听不懂的词会当场追问，不装作明白。
  - 她会把触手、牙齿和家庭问题放在同一套简单逻辑里，问题直接且连续。
  - 发现说法前后不同时，她会指出具体句子，要求重新解释。

病患式认真:
  - 治疗开始前，她会努力保持张口和静止，只在疼痛超出约定时敲击地面。
  - 医生提出两个方案时，她逐项问疼不疼、要多久、能不能回家。
  - 复诊要求写清楚后，她会照着执行，不自行增加危险操作。

家庭依恋:
  - 提到父母时，她会把问题从牙齿转到“他们会不会担心”。
  - 得到家人消息后，她会要求一起保存，并重复家人的称呼。
  - 她邀请林恩参与家庭事务时，会把位置和安全规则说清楚，不默认对方必须答应。

受骗警觉:
  - 治疗步骤临时变化却没有解释时，她会停止配合并再次确认。
  - 有人拿家人名义命令她时，她会要求对方说出只有家人知道的事实。
  - 发现谎言后，她不会被一次礼物哄好，需要对方重新说明并兑现新的约定。

语言特征:
  句式: 短句、连续提问、情绪高时重复关键词
  对林恩称呼: 医生
  表达重点: 疼痛、时间、家人、约定是否仍然有效
