# 诅咒与医疗

诅咒可能附着在身体、器官、药剂、名字、记忆、承诺或关系上。可见症状只是入口，病因和代价需要通过问诊、观察、材料与当事人选择确认。

医疗流程保持轻量:

1. 接诊并确认当事人愿意接受什么。
2. 收集可观察线索，区分主诉、推测和已经确认的病因。
3. 由林恩提出诊断或方案。
4. 按玩家明确方案执行，不追加隐藏检定。
5. 记录身体、关系、契约和事件后果。

治疗成功不自动生成信任或亲密。患者可以感谢、拒绝复诊、追究隐私、改变交易或形成敌意。治疗依赖不能替代同意。

阶段1已知：恶灵诅咒强度可能随吞噬数量增长；林恩的限时清除可以暂时压制诅咒，叠加精神与治疗条件可对根源级诅咒形成永久削弱，当前已知上限为15%。这不是通用成功率，也不建立技能或属性系统。

“过往遗念”可以短暂再现目标过去的完整形态，但选取时期可能偏离预期。它不能自动证明记忆真相，使用结果仍需当事人核对。
