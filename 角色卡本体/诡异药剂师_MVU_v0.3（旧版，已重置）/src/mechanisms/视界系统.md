# 视界系统

视界由黑暗世界的至高意志生成，是用于观察、传递情报和建立有限认知的系统。它按区域和频道组织信息，支持频道交流、情报交易、店铺展示、直播与转播，并会在使用规模增长时自动扩容。

用户只能接触已经开放的区域、频道和群组。建立猎头者家庭群组属于E11可能形成的关系结果，不会在此前自动开放。情报员024等只在相关势力和事件中作为功能角色出现，不建立主要角色词条。情报应记录来源、可见范围与可能偏差。

运行原则:

- 预兆方向可靠，地点、人数、精确时刻和结果保持模糊。
- 系统观察镜头只展示林恩可以据此行动的内容。
- 角色没有进入视界、收到报告或亲眼见证时，不自动知道幕后事件。
- 玩家改变观察条件后，以新的可见事实更新，不保留虚构的全知优势。
- 视界上的曝光、抹除面部、直播和交易会影响势力行动，但不使用热度、粉丝或店铺经营数值。
