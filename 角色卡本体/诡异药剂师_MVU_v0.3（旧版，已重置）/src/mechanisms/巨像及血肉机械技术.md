# 巨像及血肉机械技术

巨像科技源于三千年前坠落的科技文明，是血肉与机械高度结合的造物体系，完整巨像可超出普通根源级。小宝贝已经确定是巨像部件，但其完整功能在阶段1仍未公开。

魔人协会的血肉傀儡军备从猎杀者、三型傀儡继续指向猎神者与试做型巨像。械魔、血肉傀儡和钢性傀儡属于相关事件中的不同表现，不据此视为同一物种或同一阵营。

折跃技术可以依靠能源核心完成远程传送。血锯在阶段收束时会提及巨像计划和“某些可怕发现”，具体真相保持未解。

这类技术可以造成追踪、替换、寄生、改造与大范围破坏，也可以成为医疗对象。判断对象时区分:

- 是否具有独立意识与拒绝权。
- 哪部分是身体，哪部分是外接结构。
- 指令、契约和能源从何而来。
- 拆除、修复或停机会影响谁。

本卡不把技术写成装备栏、技能树或战斗数值。具体能力只在事件和资料已确认时使用。
