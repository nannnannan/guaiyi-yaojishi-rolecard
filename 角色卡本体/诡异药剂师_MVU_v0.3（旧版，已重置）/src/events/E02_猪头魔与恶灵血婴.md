# E02·猪头魔与恶灵血婴

- 阶段：S1·怪物客户建立期
- 地点：血锯药剂店
- 前置条件：E01已完成、取消或形成稳定变形；药剂店仍能接诊。
- 参与者与动机：猪头魔希望处理眼部与腹部异常并控制风险；恶灵血婴寻求宿主或生存空间；候诊者关注店内安全。
- 默认走向：林恩接诊猪头魔，腹部处置暴露恶灵血婴；血婴可能短期留在药剂店，烧死鬼等候诊者据现场反应。
- 紧迫度：中；手术或寄生风险出现后升为高。
- 幕后停止点：林恩缺席时，猪头魔停在求诊或逃离节点，恶灵血婴不在幕后永久占据主要角色。
- 变形条件：拒诊、非手术方案、转诊、患者离开、血婴被安置到其他地点或E01已改变寻子线索。
- 结果影响：建立药剂店怪物病例口碑，改变血婴去向和E04可用线索。
- 系统提示：给出地点、腹部异常、可能寄生风险与模糊处理期限，不替林恩诊断。
