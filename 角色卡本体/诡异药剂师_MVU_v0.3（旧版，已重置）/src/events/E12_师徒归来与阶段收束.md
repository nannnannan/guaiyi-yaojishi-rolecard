# E12·血锯和人偶夫人归来、人偶治疗、阵营判定及阶段收束

- 阶段：S4·猎头者家庭与师徒归来期
- 地点：血锯药剂店、人偶庄园或双方实际会合地点
- 前置条件：E11形成结果；血锯与人偶夫人能够归来或以变形方式重新接触林恩；存在需要处理的人偶医疗或阵营分歧。
- 参与者与动机：血锯核对林恩独立看店和协会冲突的后果；人偶夫人为自身与女儿们的血源诅咒寻求治疗；黑弦月尚未正式到货，只能经明确租借进入后续；其他主要角色按既有关系选择立场。
- 默认走向：血锯与人偶夫人归来，说明魔人协会内幕和巨像计划中的可怕发现；林恩可完成对人偶夫人的首次诅咒治疗；血锯说明夜医职业极端风险并进行阵营判断；人偶夫人提出租借第七人偶黑弦月作为后续联系。
- 紧迫度：中；患者恶化或阵营冲突时升为高。
- 幕后停止点：林恩缺席时，归来与会面可以发生，但需要林恩的治疗、决定和关系确认停在可介入节点。
- 变形条件：血锯已提前归来、人偶夫人与药店敌对、治疗已由其他方式完成、庄园结构改变、林恩拒绝阵营判断或拒绝租借。
- 结果影响：更新血锯的师徒判断、人偶夫人首次疗程及女儿解咒委托、巨像计划伏笔、夜医风险、黑弦月租借状态和有效关系边；写入阶段总结。事件结束后不自动生成第149章后的续接、循环或结局。
- 系统提示：报告会合地点、治疗对象、公开阵营分歧和模糊期限；阶段收束不等于游戏结束。
