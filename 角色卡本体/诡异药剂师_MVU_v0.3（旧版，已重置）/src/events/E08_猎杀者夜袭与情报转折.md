# E08·猎杀者夜袭与情报转折

- 阶段：S3·魔人协会冲突期
- 地点：游魂巷、血锯药剂店、凄凉荒野或倒吊塔相关路线
- 前置条件：E07已经暴露足够情报或形成新的敌对因果；魔人协会仍具备派出猎杀者的能力。
- 参与者与动机：猎杀者执行夜袭或继续追踪；情报员024观察、交易和试探林恩；游魂巷居民优先保护自己的门槛；林恩可应对、转移、谈判或反向诊断情报者。
- 默认走向：林恩通过024接触协会情报，并可用头发等诊断材料发现其多种病症、提出治疗邀约和定金试探；024的立场可能偏移，并从视界画面中抹去林恩面部。
- 紧迫度：高；夜色和位置提供模糊期限。
- 幕后停止点：林恩缺席时，夜袭可造成地点损坏和人员受伤，但主要角色停在可介入的受困或失联节点。
- 变形条件：协会已失去目标、024选择不同立场、游魂巷居民改变防线、林恩提前转移或E07没有留下原作情报。
- 结果影响：更新药店与巷道安全、024的情报范围与立场偏移、林恩在视界的暴露程度、猎杀者去向及E09进攻条件。
- 系统提示：报告夜间、受威胁地点、可见人数范围、情报状态和高紧迫度。
