# E11·猎头者家庭记忆、契约与关系绑定

- 阶段：S4·猎头者家庭与师徒归来期
- 地点：猎头者家族相关地点、独角鬼王神庙或实际因果指向处
- 前置条件：E10完成、取消或形成稳定变形；家庭记忆和头颅角色的线索已能被接触。
- 参与者与动机：小小希望维持医生与家人联系；泰坦头颅从敌意中核对林恩是否真正帮助女儿；巫神头颅从试探转向主动绑定；林恩是否接受任何称呼和契约只能由玩家决定。
- 默认走向：使用“过往遗念”短暂再现三千年前形态，小小恢复金发碧眼的泰坦幼女形态，巫神头颅可能再现为偏离预期的幼年形态；父母情绪失控后重新谈判。林恩可永久削弱泰坦诅咒15%，建立视界群组，并讨论心灵契约、结拜与女婿式关系。
- 紧迫度：中；若有人强制契约或夺取头颅则升为高。
- 幕后停止点：林恩缺席时，其他角色可以讨论和移动，但任何需要林恩同意的契约停在等待确认。
- 变形条件：过往遗念选择其他时期、林恩拒绝关系或契约、诅咒采用其他治疗、头颅角色选择其他去向、家族结构已被玩家改变。
- 结果影响：按实际接触解锁泰坦头颅和巫神头颅，更新小小家庭身份、泰坦清醒规律与女儿喜好、巫神认可、心灵契约和视界群组；只记录实际成立的角色关系边。
- 系统提示：说明地点、契约参与者、公开条款范围和模糊期限，明确林恩尚未同意。
