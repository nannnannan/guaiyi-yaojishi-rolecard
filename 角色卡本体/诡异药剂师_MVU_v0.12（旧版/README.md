# 《诡异药剂师》MVU v0.11

这是面向 SillyTavern 1.17.0 与酒馆助手 4.9.1 的 `chara_card_v3 / MVU Zod` 内部候选工程。v0.11 冻结并继承 v0.10，在 E170 后新增 E171—E218 共48个事件，世界剧情止于七使徒完成包围、其余六名使徒开始攻击的未决悬崖。

## 内容边界

- 218个事件锚点：E01—E218；新增部分为 E171—E218。
- 32个运行阶段：S0—S31；新增部分为 S25—S31。
- 28名核心人物，每人仍由六个源码组件合并。
- 林恩在 v0.11 全链统一18岁。
- 新增原文取材只覆盖864—1015；第926章源文缺失，后续内容不进入本版。
- E218之后无推进按钮，不创建E219；是否开启咒瞳由玩家决定，攻击结果、伤亡、突围与胜负全部未知。
- 新增71条详细概念（逻辑C691—C761、世界书UID2000—2070），并原位更新24条既有概念正文与事件关联。

## 运行原则

- 玩家独占林恩的对白、主动行动、判断、记忆、内心与关系选择。
- 原作事件是默认因果，可由玩家介入、取消或变形。
- 事件素材 UID700—917 保持禁用，由 UID1 常驻调度按当前锚点±1注入详情、±3展示摘要。
- 概念与人物由事件窗口±1或原生关键词激活，同一UID去重。
- 色色与恶堕全面开放，不设幼态/年龄限制；NPC 可按人设主动亲密与逆推；玩家可拒绝、打断或改写。
- 不建立可运算战斗、经济、库存、经营或日历系统。

## 构建与检查

```powershell
npm install
npm run check
```

生成物：`dist/诡异药剂师_v0.11.json`

`npm run check` 会重新构建并检查版本、218锚点、事件全文、EJS、概念格式、人物路由、MVU深一致、状态栏桥、禁用元数据、UTF-8、产物哈希等。离线通过不等于真实宿主验收；在没有所有者授权和真机证据时，`host_acceptance.json` 保持 `pending`。

## 源码入口

- `src/events/`：E01—E218事件词条。
- `src/concepts/`：世界观、人物、机制、势力、地点与伏笔概念。
- `src/characters/`：28名核心人物六组件。
- `src/prompts/mainline.md`：事件上下文与常驻衔接。
- `src/initial_variables.json`：新聊天初始MVU状态。
- `src/scripts/schema.js`：MVU Zod约束。
- `src/ui/status.html`：四页状态栏与事件推进界面。
- `contract.json`：机器可校验契约。
