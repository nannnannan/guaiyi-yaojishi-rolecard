# 巨像及血肉机械技术

巨像科技源于三千年前坠落的科技文明，是血肉与机械高度结合的造物体系，完整巨像可超出普通根源级。

## E01至E20可见形态

- 魔人协会的血肉傀儡军备链：猎杀者 → 三型傀儡 → 猎神者 → 试做型巨像。它们有核心驱动、目标优先级与同步解析反制系统，会针对目标特征生成反制措施。
- 钢性傀儡是纯粹机械造物，区别于血肉机械混合体；械魔是机械与血肉结合的高阶执行者。
- 折跃技术依靠能源核心完成远程传送；信使体系（腐地龟王、虚空折跃兽等）可组合改造。
- 小宝贝已确定是巨像部件（血锯保管的舌头），其完整功能与具体部位在E01至E20仍未公开。它感知林恩体内的巨像之心，因此"不杀心脏"。

## 血锯与巨像计划

血锯是魔人协会前元老，参与倒吊塔建造与巨像计划建设，因"某些可怕发现"退出并私藏巨像部件与巨像之心（残缺，黑心#4）。他把心脏殖装进林恩体内，意图成谜。巨像计划完整历史在E12由血锯讲述：三千年前坠落→历代研究→发现战争背景与诅咒风险→老会长禁止→元老分散保管部件→噬心魔重启→试做型巨像012号诞生。

## 判断原则

这类技术可以造成追踪、替换、寄生、改造与大范围破坏，也可以成为医疗对象。判断对象时区分：

- 是否具有独立意识与拒绝权。
- 哪部分是身体，哪部分是外接结构。
- 指令、契约和能源从何而来。
- 拆除、修复或停机会影响谁。
