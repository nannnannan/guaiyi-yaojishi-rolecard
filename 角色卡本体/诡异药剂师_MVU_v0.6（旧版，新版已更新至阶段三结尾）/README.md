# 《诡异药剂师》MVU v0.6

这是面向 SillyTavern 1.17.0 与酒馆助手 4.9.1 的 `chara_card_v3 / MVU Zod` 内部候选工程。v0.6 从 v0.5 独立复制，在不修改 v0.5 accepted-release 的前提下，把内容边界扩到第276章、小总结08至13。

## v0.6内容

- 35个六态事件锚点：保留E01至E20，新增E21至E35；E21至E34含下一事件引入，E35只有阶段3待续钩子，不创建E36。
- 8个宽阶段S0至S7；阶段二新增S5幸福之家、S6寂静镇灾变、S7黑夜城授职与跨界伏笔。
- 17名核心人物，每人6个运行时组件；9名新增人物另有未注册的候选二次解释稿，等待用户逐条确认。
- 93条概念：UID400至451共52条阶段一既有概念按阶段二详写格式完成补充整理，稳定UID、名称、类别、关键词与事件关联保持不变；UID452至492为41条阶段二详写概念。其中32条状态随事件变化的概念采用EJS状态变体（按锚点状态只渲染当前适用变体），其余保持静态。
- 世界书167条；事件完整详情注入当前锚点及前后各1个事件，事件摘要覆盖前后各3个事件，常驻衔接钩子只按锚点状态提供可接续信息。
- UID1常驻调度是事件全文唯一运行时来源；UID300至334保留为构建素材但统一禁用，避免事件名称绿灯形成第二份正文。
- 概念/物品采用事件详情±1窗口强启或酒馆原生关键词绿灯；两路始终指向同一世界书UID，同轮只注入一次。
- 全部概念统一包含事实门槛、定义、来源、机制、限制与代价、未知项和禁止外推；静态概念另含事件演进、当前状态与人物关联，状态变体概念把这三项放入按门控事件从新到旧排列、末块兜底的变体块内。阶段一内容以大总结1与小总结01至07为依据，事件窗口不会自动兑现原作默认结果。
- 人物采用事件详情±1窗口内的出场人物强启或姓名/别名关键词绿灯；两路复用同一人物UID，人物条目内部EJS依据当前事件状态只输出已解锁阶段人设。
- 路由、事件、人物与概念条目全部显式开启`exclude_recursion`和`prevent_recursion`；强启路由先按UID去重，注入正文不得再次递归串灯。
- 34对常驻事件桥；完成/变形可正常推进，取消态由正文按局部依赖判断，状态栏不机械推进。
- 初始变量、Schema、开场initvar与状态栏FALLBACK_STATE保持深一致；事件身份迁移只允许单条`replace /事件`。
- 黑弦月已交割到店但保持封装，阶段二不启用；血衣诅咒未治愈，默认遗忘线由实际回访记忆覆盖。
- 爱丽丝暂时隐去身形不等于消散；卡梅尔夫妇先短暂恢复再于同次出诊复燃；小丑显化体死亡不等于根治，E34天使血只压制15日。

林恩的对白、主动行动、决定、判断、感情与关系接受始终由玩家独占。爱丽丝幼态外观阶段只开放非性关系方向且恶堕恒为0；倒吊天使关系方向开放，但原作之吻、任务或好感不代表玩家同意。其余计划指定人物固定非恋爱。

本卡不建立战斗数值、可运算等级成长、技能树、装备栏、库存、货币、经营结算、回合制或日历/天数系统。

## 维护入口

- `创作规划.yaml`：内容边界与连续性决策，修改前先同步。
- `contract.json`：35事件、17人、93概念与局部依赖的结构契约。
- `manifest.json`、`profile.json`：版本、稳定ID、依赖与构建映射。
- `src/worldbook.json`：167条世界书注册表；所有条目双递归保护。
- `src/events/`：E01至E35事件详情素材；构建时嵌入UID1，独立UID300至334不参与运行时扫描。
- `src/characters/`：17人六组件EJS；`候选二次解释/`不进入运行时。
- `src/concepts/`：93条概念正文（静态或EJS状态变体两种形态）。
- `src/prompts/mainline.md`：事件摘要±3、完整详情±1与34对按状态工作的常驻桥。
- `src/initial_variables.json`、`src/scripts/schema.js`、`src/prompts/mvu_*`、`src/ui/status.html`：MVU整链。
- `tools/build.mjs`、`tools/validate.mjs`：构建与离线验收。
- `tools/sync-v06-state.mjs`、`tools/sync-v06-worldbook.mjs`、`tools/sync-v06-concept-headings.mjs`：受控同步脚本。

不要直接编辑`dist/`。修改源码后重新运行`npm run check`。
