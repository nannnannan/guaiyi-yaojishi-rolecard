# 《诡异药剂师》MVU v0.6 接手指南

## 适用范围与权威顺序

本文件只适用于`诡异药剂师_MVU_v0.6/`。权威顺序为：用户当前要求 → `创作规划.yaml` → `contract.json` → `manifest.json` → `profile.json` → `src/` → `dist/`。不要手改`dist/`，不要修改v0.5及旧版本目录。

## 版本边界

- 内容至第276章，阶段二新增范围为第150至276章、小总结08至13。
- 事件E01至E35；S0至S7；E35是本版终点，不创建E36。
- 17名核心人物各6组件；93条概念；世界书167条。
- v0.6是真机待验的内部候选，不得继承v0.5 accepted-release状态或哈希。

## 创作与安全铁律

- 玩家独占林恩的对白、主动行动、决定、判断、记忆、内心、感情与关系接受。默认走向只供因果推演。
- 爱丽丝隐身不是消散；卡梅尔与女主人先短暂恢复、再于同一次出诊中被玛丽诅咒复燃；两人阶段末意识/生死未知。
- E31只处理本次哭泣小丑显化体；黑白小丑本体仍存，E34天使血只压制15日，后续会再次爆发。
- 猪头屠夫与黑白小丑山巅密谈只供叙事层，不能写入林恩知识。
- 血衣女士默认线为林恩忘记回游魂巷与续治；实际聊天存在回访事实时，以关系关键记忆覆盖默认线，不得自动提醒、判死、原谅或敌对。
- 黑弦月已到店封装，阶段二不得开箱、启动或调用阶段三能力。
- 爱丽丝幼态阶段禁止性化，只开放非性关系方向，恶堕恒为0；倒吊天使开放关系仍需玩家明确接受。

## 事件契约

- 六态固定为未触发、预兆、活跃、变形、完成、取消；只有活跃占唯一活跃槽，变形是稳定终态。
- E21至E34严格保留v0.5事件文件结构；默认走向200至500字。E35只写阶段3钩子。
- E20至E35连续，正式订单是E20→E21桥；不得重复首次介绍夜医、血锯外出决定或屠夫送达传闻。
- 事件完整详情窗口固定为当前锚点±1；当前锚点±3只提供事件摘要。下一事件引入与常驻桥必须按六态输出可接续钩子，不得把未来事件正文当成已经发生。
- UID1是事件全文唯一运行时注入源。UID300至334只作为构建素材保留，必须统一`enabled:false`，不得通过事件ID、标题或剧情宽泛词再次绿灯。
- 完成/变形可按局部前置推进；取消态状态栏只提示“需正文判定局部依赖”，模型依据`contract.required.event_dependencies`与事件替代入口处理。
- 任何锚点状态/收尾、唯一活跃身份或预兆身份变化，只用一条完整`replace /事件`。

## 人物、概念与EJS

- 人物运行时组件顺序固定：角色速览、基础信息、性格调色盘、三面性、多阶段人设、二次解释。
- 9份`候选二次解释/`不得注册进世界书，用户逐条确认后才能替换正式二次解释。
- 人物只通过两路进入提示词：事件详情±1窗口内的出场人物自动强启，或姓名/别名原生关键词绿灯。两路必须复用同一人物UID并先按UID去重；人物条目内部EJS继续保留未登场锁与事件门控，只输出当前已解锁的阶段人设。
- 概念分两种形态：无跨事件状态变化的概念正文保持静态；状态随事件变化的概念采用状态变体EJS。两路激活不变：事件详情±1窗口强启或原生关键词绿灯，事件数组标题、worldbook元数据与关键词注册必须一致，两路复用同一概念UID且同轮只注入一次。传闻与真相、小丑机制与天使血压制保持分条，避免提前泄底。
- 状态变体块按门控事件从新到旧链式`if/else if`排列，只认`完成`/`变形`，末块必为兜底；每个非兜底块含单一门控事件与门控行，事件演进、当前状态必在块内，人物关联静态一次或每块一次。变体门控事件允许超出标题事件数组——窗口决定何时注入，EJS决定注入哪个状态。
- 概念变体EJS只读`getvar("stat_data.事件.锚点状态.EXX.状态", { defaults: "未触发" })`，禁用const/let/await/activewi/getEnabledWorldInfoEntries；首行仍是概念标题行，不加`@@`装饰器，保证路由回退正则与标题同步脚本继续有效。
- UID400至451的阶段一概念已按阶段二详写结构补齐；维护时保留稳定UID、名称、类别、关键词和事件关联。阶段一事实以大总结1与小总结01至07为准，每条都要保留唯一事实门槛及定义、来源、机制、限制与代价、未知项、禁止外推；事件演进、当前状态与人物关联在静态形态中保持不变，在变体形态中只出现在变体块内。
- 含`const/let`的非路由EJS必须`@@private`或独立作用域。路由内部必须对目标UID建立本轮去重集合，不能因同一人物/概念关联多个窗口事件而重复调用强启。
- UID399统一路由只能处理承载该机制条目的本卡世界书；不能因其他已启用世界书复用人物或概念UID而误激活外部条目。
- 新增或修改世界书条目必须显式开启`exclude_recursion`与`prevent_recursion`；被注入正文不得参与递归扫描，也不得继续触发其他世界书条目。

## MVU整链

根字段固定为元数据、世界、林恩、事件、关系、角色关系、系统。任何结构变化同步：

`src/initial_variables.json` → `src/scripts/schema.js` → `src/prompts/first_message.md` initvar → `src/ui/status.html` FALLBACK_STATE → 更新规则/输出格式 → `contract.json` → `tools/validate.mjs`

角色关系边最多48；不建立全矩阵。不创建战斗数值、等级成长、装备、库存、货币、经营或天数系统。
