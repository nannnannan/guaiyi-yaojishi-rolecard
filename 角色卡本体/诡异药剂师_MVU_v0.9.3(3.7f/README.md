# 《诡异药剂师》MVU v0.9

这是面向 SillyTavern 1.17.0 与酒馆助手 4.9.1 的 `chara_card_v3 / MVU Zod` 内部候选工程。v0.9 完整扩写至阶段五末尾：新增 E97–E126 共 30 个六态锚点与 E126 阶段收束终点，全量覆盖 E01–E126（共 126 个事件锚点）。

## v0.9 内容规划

- 126 个事件锚点：覆盖 E01–E126，含下一事件引入与标准六态门控；E126 作为阶段五收束终点。
- 18 个宽阶段 S0–S17：新增 S14 利维坦潜入与疫医夺权期、S15 第一腔室绝杀与主母双魂期、S16 巨像意识空间与母树博弈期、S17 巨像冲击地狱与双生子重塑期。
- 27 名核心人物：162 个 6 组件全量动态 EJS 渲染；支持阶段五的人物事件动态激活与角色弧光演进。
- 215 条深度世界观概念：UID 400–615，按事件状态和原生关键词双路由加载。
- 世界书路由：事件详情±1 强启 / 原生关键词绿灯，同 UID 去重，双递归保护；UID1 唯一事件运行时源；事件素材 UID 700–825。
- 125 对常驻事件桥：涵盖全量 E01 至 E126 推进链。
- 初始变量、Schema、开场 initvar 与状态栏 FALLBACK_STATE 保持深一致；事件身份迁移只允许单条 `replace /事件`。
- 色色口径：以M=快感冲击（媚药）、性行为=解咒途径、恶堕=性调教；遵守色色机制三等价。
- 禁元数据词汇：卡内与世界书正文禁止出现"第X章/小总结/阶段几"等元数据词汇，来源与门控一律用 E 编号。
- 玩家主权绝对独占：林恩的对白、主动行动、决定、判断、记忆与内心始终由玩家独占；默认走向只供因果推演。
