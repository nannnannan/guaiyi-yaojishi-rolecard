# 概念·特殊设定·棒医生称号（事件["E17"]）

- 类别：特殊设定
- 事实门槛：标题中的事件编号只标注关联阶段。只有E17进入“完成”或“变形”，且聊天正文实际让小小使用称呼并形成家长反应时，本条的事件演进与当前状态才成为当前事实；“预兆”“活跃”或“取消”不会自动宣告喜爱、制造女婿误会或取得家族认可。林恩如何回应与定义关系只能由玩家决定。
- 定义：“棒医生”是小小对为她处理牙痛、安装钢牙的林恩使用的亲昵称呼，核心含义来自医患信任和她对治疗者的肯定。称号不是系统授予的战力头衔，也不自动代表恋爱、婚约、家族成员资格或对林恩全部行为的认可。
- 来源：E05若牙科治疗、命名与信任实际成立，小小已经把林恩识别为不会吃掉、能够复诊的医生。E17默认线中，她在大战后把林恩带到泰坦头颅与巫神头颅面前，以乳牙跑风的发音介绍“超级喜欢的棒医生”。
- 事件演进：含糊介绍可能使父母把医患亲近误读为女儿的伴侣关系，根源级注视则形成高压审视。林恩可解释牙医身份、保持沉默、承认其他关系或采用不同回应；只有实际对话形成后，家长态度与E19的家族因果才可更新。
- 机制：称号通过小小的直接称呼传递亲近与信赖，并可作为家长确认“救治者是谁”的关系证据。它不提供数值增益、召唤权限、医疗成功率或根源庇护；家长会根据现场信息独立判断。
- 限制与代价：小小的发音和“喜欢”容易被过度解读，林恩面临泰坦与巫神的根源恶意和追问。称呼可以持续存在，但关系含义会随玩家与小小的真实互动改变，不能用原作默认婚恋方向锁死。
- 当前状态：若E17默认介绍成立，小小仍可称林恩为棒医生，父母已知道其牙医身份并产生审视；是否邀谈、认可、结拜或推进家族绑定须跟随E17、E19正文。未形成介绍时，只保留E05的医患来源。
- 人物关联：小小是称呼使用者；林恩是被称呼的医生；泰坦头颅与巫神头颅是潜在听者和审视者；钢牙与神圣之矛碎片构成称号的治疗背景。
- 未知项：小小对称号的长期含义、父母最初是否准确听清、不同玩家回应将产生何种家族结果均未预设。
- 禁止外推：不得把“超级喜欢”直接写成恋爱同意；不得自动确立女婿、婚约、家族绑定或根源庇护；不得替玩家自报身份、接受邀谈或定义与小小的关系。
