# 概念·物品·四合一超级异常药剂（事件["E105","E108"]）

- 类别：物品
- 事实门槛：仅在对应事件（E105/E108）进入“完成”或“变形”，且聊天正文明确出现该事实时方可引用；“预兆”“活跃”“取消”不得提前兑现。
- 定义：林恩在利维坦绝密实验室现场开炉熬制的灭绝级群体生化下毒药剂。
- 来源：E105全舰强制注射下毒，至E108第一腔室响指引爆全员瘫痪。

- 限制与代价：必须提前将药剂注入受害者体内建立生化潜伏，无法隔空凭空直接产生肉体变态突变。
- 未知项：全舰数千疫医异变猫娘后的激素紊乱周期与后续治疗方案不详。
- 禁止外推：禁止将四合一药剂的引爆写成不可控的自发泄露；禁止无视其猫耳大哔哔的具体异变特征。
