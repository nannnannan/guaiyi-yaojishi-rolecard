# 概念·机制·死灵畸变体与憎恶者3号（事件["E100"]）

- 类别：机制
- 事实门槛：仅在对应事件（E100）进入“完成”或“变形”，且聊天正文明确出现该事实时方可引用；“预兆”“活跃”“取消”不得提前兑现。
- 定义：利维坦生化防御体系中由杀戮死气与入侵者极致仇恨催化孕育的重装怨念怪物。
- 来源：E100走廊战役中315博士通过全舰监控收集银色幻想的杀戮死气与仇恨值定向孵化。
- 机制：躯体由数百名战死疫医的白骨与扭曲血肉死死缠绕熔铸而成，外层附带高阶抗物理与抗等离子自适应护盾，对银色幻想的单分子剑刃与能量光束具备极强的吞噬抵抗力。在利维坦尾部走廊死死缠住银色幻想，后被银色幻想发射的微型战术核弹在千万度高温中瞬间汽化消融。
- 限制与代价：行动相对笨重迟缓，对瞬间爆发的超高温核聚变冲击波缺乏有效防御手段。
- 未知项：利维坦生化孵化池中是否还封存憎恶者4号及以上型号的胚胎不详。
