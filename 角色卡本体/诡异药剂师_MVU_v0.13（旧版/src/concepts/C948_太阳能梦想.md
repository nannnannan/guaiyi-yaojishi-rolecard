# 概念·情感锚点·太阳能梦想（事件["E297"]）

- 类别：情感锚点；「黑雾之上有阳光，站在阳光下就能充电」——小冰箱的执念与机械姬心里刻下的光。（与C945/C946互证：太阳能梦想是拖行剧本的情感顶点。）
- 事实门槛：仅在E297进入"完成"或"变形"且正文实际出现"黑雾上面有什么、阳光、站在阳光下充电、太阳能梦想"等事实时方可引用；"预兆""活跃"不得提前兑现该梦想的实现或破灭。
- 定义：太阳能梦想，是"小冰箱"（林恩伪装人格）在拖行剧本中喊出的执念——"指挥官姐姐——您说黑色雾气的上面——会有什么啊——会有阳光吗——只需要站在阳光下就可以充电——我想那一定是一件很满足的事情吧"。黑暗世界永远被黑雾笼罩（地狱没有阳光），机械体靠能源核心与集体网络供能；"站在阳光下就能充电"因此成为小冰箱对"外面的世界"最朴素、最奢侈的想象——不需要神迹、不需要救赎，只要阳光。这份梦想的杀伤力在于它的天真：它不是对权力的渴望、不是对自由的宣言，只是一个锈迹斑斑的小冰箱对"太阳"的向往——而这恰好击穿了银色幻想的心防。她在孤立个体化（C946）后的拖行剧本里已动摇，太阳能梦想成为压垮理智的最后一根稻草：她终于开口"小冰箱……我现在可以让你加入机械神教了……我会给你……给你一副更好的机体……"——而他不再回应，屏幕上覆着细细的灰尘——他已经死了，早就到了损坏的边缘、连意识上传都做不到。太阳能梦想就此永远悬置：一个连阳光都没见过的机械，把"站在阳光下充电"当成一生的愿望，然后死在了黑雾里。
- 来源：E297拖行剧本荒原仰望——"黑雾上面会有什么啊/会有阳光吗/站在阳光下就可以充电"（太阳能梦想）；随后冰箱死亡、机械姬的咫尺之距（"但你想看的话……我也一定会让你看到的啊……"）。
- 机制：①提出者：小冰箱（林恩伪装人格）；②场景：荒原中央仰望黑雾（拖行剧本后期）；③内容：黑雾之上有阳光、站在阳光下充电、很满足；④效果：银色幻想彻底破防（开口许以入教与机体）；⑤转折：冰箱已死（屏幕覆灰、无法意识上传）；⑥残留：梦想未实现亦未破灭，悬置在黑雾之上。
- 补充事实：梦想之前的拖行细节——"她看它抠出自己的电池想给她充电、在荒原划出大大的标志求援、一次次撕扯她身上的血肉却徒劳无功"；暴风骤雨之夜他突然消失（她被遗弃般煎熬一整夜），雨停时他又出现（"我被闪电劈了几百次之后终于充满了——"，把漏电的电池绑在她身上）；机械救援小队赶到时（机体损毁47%），她的指尖与冰箱"将触未触"——"咫尺之距成了一辈子无法企及的距离"。
- 限制与代价：太阳能梦想属于"黑雾之上"的彼岸（地狱没有阳光，其实现条件未知）；梦想以"死亡"为代价悬置（冰箱已死）；对机械姬而言，这份执念将伴随她的余生（"但你想看的话……我也一定会让你看到的啊……"）。
- 未知项：黑雾之上是否真有阳光、太阳能充电对机械体的可行性、梦想是否会在E298-E301（黑雾重逢）后有兑现窗口，均未解。
- 禁止外推：林恩的对白、动作与选择由玩家主权独占；太阳能梦想原文（"站在阳光下就可以充电"）按原样保留；禁止把梦想写成已实现或已嘲弄的既定桥段，保持其"悬置的光"的质感。
