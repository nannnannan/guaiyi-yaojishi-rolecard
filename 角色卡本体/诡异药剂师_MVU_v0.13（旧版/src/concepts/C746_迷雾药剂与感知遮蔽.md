# 概念·物品／感知机制·迷雾药剂与感知遮蔽（事件["E187","E210","E214","E215","E216"]）

- 类别：物品／感知机制；统合迷雾药剂从局部遮蔽、追击脱离到临时基地警戒与城市搜索网的不同用法，要求分别记录可见度、感知范围、通信影响和公共风险。
- 事实门槛：E187确认迷雾可阻断视觉并遮蔽部分感知；E210显示迷雾能够帮助脱离追击，但专业罗盘仍可能沿异常锁定；E214用低可见度雾层感知停车场入口；E215、E216则把雾扩展到城市应急争议。只有药剂浓度、覆盖区域、持续时间和目标用途被明确，才能判断是遮蔽、感知还是高危显影。
- 定义：迷雾药剂制造可控雾层，基础功能是降低视觉与部分超常感知，进阶使用可把雾内扰动反馈给施术者，形成入口警戒或感染搜索网。它不是绝对隐身，也不必然切断罗盘、神圣铃音、异常气息和跨界定位。高浓度、大范围雾若与血肉显影结合，会从战术物品转化为公共灾害工具。
- 来源：E187的培养区行动提供局部遮蔽样本；E210证明罗盘在持有者自身异常过强时失去常规追踪价值，却仍显示迷雾并非唯一因素。E214的停车场基地说明雾可用于低伤害警戒，E215、E216记录全城雾可能造成通信与交通中断、恐慌、踩踏和封控争议，同时也能提升感染搜索效率。
- 机制：使用前选择模式：撤离遮蔽控制在最小走廊；基地警戒保持低可见度并设置友方通行标识；医疗搜索只覆盖医院、水务和污水节点；城市级覆盖必须另行取得玩家明确选择与公共风险评估。每种模式都要保留急救通信、交通分流、撤回药剂和雾外观察员。雾内感知只报告异常坐标与置信度，不自动判定敌我或感染。
- 限制与代价：雾会同时影响平民、救援者和使用者，可能遮住危险、延迟救护、引发车辆事故并损害公众信任。浓度越高、范围越大，撤回越困难。专业追踪、共享网络和神圣定位可能穿透或绕过遮蔽；把雾当成永久基地屏障会形成单点失效。感知反馈还可能造成信息过载和误报。
- 未知项：不同感官被遮蔽的精确比例、罗盘和金铃穿透阈值、雾对寄生幼虫及患者的生理影响、城市气象对持续时间的改变、低可见度搜索的误报率、长期吸入安全性及多种异常同时存在时反馈如何区分均未知。
- 禁止外推：林恩的对白、动作与选择由玩家主权独占；禁止违背原著设定将其描写为无消耗或脱离因果律违规生效。
