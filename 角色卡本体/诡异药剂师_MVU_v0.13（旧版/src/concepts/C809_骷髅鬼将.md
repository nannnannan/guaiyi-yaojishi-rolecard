# 概念·人物·骷髅鬼将（事件["E259"]）

- 类别：人物；游荡在罪孽城、悬赏"疫医林恩"500万骷髅币的老油条鬼将，E259教学线中短暂出场的陪衬反派。
- 事实门槛：E259完成/变形且正文实际出现骷髅鬼将身份/悬赏信息（游荡的罪孽城老油条、悬赏疫医林恩500万骷髅币）时方可引用；其被斩杀/受挫与否随E259结算。
- 定义：骷髅鬼将是罪孽城（游魂巷背景）一位游荡的老油条鬼将，对"疫医林恩"开出了500万骷髅币的悬赏——他是教学夜的背景威慑，也把林恩在黑暗世界的"名声"落到实处。在E259的贫民区/鬼屋教学中，他作为可遭遇、可提及的陪衬角色存在；是否正面冲突由E259走向决定。这一悬赏同时呼应v0.11既有的"游魂巷居民"生态：骷髅币是黑暗世界硬通货，500万的价位几乎相当于小型雇凶组织的年流水，足见林恩在罪孽城树敌之深。
- 来源：E259林恩带林樱逛街鬼/贫民区时，背景设定提到骷髅鬼将的悬赏（500万骷髅币）；作为"游荡的罪孽城老油条"，他的存在让"教妹妹"这件事始终顶着被追杀的风险。悬赏金额与此前罪孽城过往（夺萃之镰、猪头屠夫、游魂巷黯影等既有设定）互相印证：在黑暗世界，被悬赏者的价值等于其威胁度的报价；E259把它作为教学夜的背景板，既是给林樱上第一堂"黑暗世界社会学"，也让教学夜始终悬着一把刀。
- 机制：①身份：罪孽城游荡鬼将；②悬赏：对疫医林恩开500万骷髅币；③定位：教学夜的可遭遇陪衬（背景威慑）；④纠葛：随时可能因悬赏袭击林恩。
- 补充事实：骷髅鬼将的存在让"教妹妹"这件事始终带刀——林樱第一次直面"哥哥在黑暗世界有多值钱"的社会现实；500万骷髅币的悬赏也反衬出林恩在地狱/黑暗世界恶名昭著的程度，与他在蓝星"救世者"的声名形成双面映照。作为一次性陪衬，其被斩杀与否不决定主线，但他被提起这件事本身已是"游魂巷背景板"的延续（v0.11既有游魂巷生态）。
- 限制与代价：被悬赏意味着教学夜不能久留一隅、须警惕追兵；骷髅鬼将若纠缠会让林樱首次直面别样杀机。
- 补充细节：从剧情功能看，骷髅鬼将更像是"游魂巷生态"的移动路标——他把林恩在罪孽城的旧日仇怨（夺萃之镰、猪头屠夫、游魂巷黯影等既有设定）压缩成一行悬赏文本，让新读者无需翻旧账也能瞬间明白"这个男人的过去有多凶险"；对林樱而言，这也是她第一次意识到"哥哥在另一个世界是被人悬赏的怪物"，与她在蓝星看到的"救世者"形成身份撕裂。作为一次性陪衬，他的存在价值在于"被提及"本身。
- 未知项：骷髅鬼将的战力与数目、悬赏是否被其他恶鬼响应、后续是否再登场均未知。
- 禁止外推：林恩的对白、动作与选择由玩家主权独占；禁止违背原著设定将其描写为无消耗或脱离因果律违规生效。
