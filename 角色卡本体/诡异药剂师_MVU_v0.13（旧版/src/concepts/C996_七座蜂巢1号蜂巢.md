# 概念·据点·七座蜂巢/1号蜂巢（事件["E311","E312"]）

- 类别：据点；机械神教地表悬浮战争母巢集群，1号蜂巢为智脑与银色幻想的居所与数据中枢。
- 事实门槛：仅在 E311、E312 进入"完成"或"变形"且正文实际出现地表悬浮母巢、1号蜂巢、数据中枢等事实时方可引用；"预兆""活跃"不得提前兑现。
- 定义：七座蜂巢是机械神教地表层面的战争母巢集群：悬浮于地表之上、以蜂巢结构组织的巨型战争据点群，每座蜂巢既是军事要塞也是数据节点。1号蜂巢是七座蜂巢中最核心的一座——它是初代智脑（C964）与银色幻想的居所，也是机械神教数据网络的最高中枢：意识上传、数据备份、指挥调度都汇聚于此。蜂巢内部以模块化数据隔离（C965）切割成魔方状独立区块，既防信息污染扩散，也防外部意识入侵。
- 来源：E311 林恩以数据网络虚拟化脱壳（C995）上传直抵1号蜂巢；E312 与智脑在1号蜂巢周旋、套出七神编年史。
- 机制：①悬浮战争母巢：七座蜂巢以集群形态分布于地表战略要地；②数据中枢：1号蜂巢承载上传/备份/调度；③模块化隔离：内部区块化切割、断网防扩散；④居住功能：智脑与银色幻想的居所；⑤权限分级：1号蜂巢权限高于其他蜂巢。
- 补充事实：当林恩以数据体现在1号蜂巢内现身时，智脑的表情像见了鬼——一个被通缉的"家电"堂而皇之地站在机械神教最核心的客厅里，还反客为主地问茶。
- 限制与代价：蜂巢依赖数据网络运转，网络被切断则指挥瘫痪；1号蜂巢核心区权限极高，无授权进入会被制裁之光（C967）锁定。
- 未知项：其余六座蜂巢的确切位置与功能分工；蜂巢群的建造者与年代；是否存在比1号蜂巢更核心的隐藏主巢。
- 禁止外推：林恩的对白、动作与选择由玩家主权独占；禁止违背原著设定将其描写为无消耗或脱离因果律违规生效。
