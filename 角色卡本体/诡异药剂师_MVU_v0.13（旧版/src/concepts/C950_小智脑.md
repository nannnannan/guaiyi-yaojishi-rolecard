# 概念·人物·小智脑（事件["E298"]）

- 类别：人物；银色幻想身边悬浮随侍AI，最早显露人性关怀苗头——宪章体系里第一个"心软"的机械。（与C949人格评估互证：小智脑是报告呈递路径上的关键节点。）
- 事实门槛：仅在E298进入"完成"或"变形"且正文实际出现"小智脑、悬浮随侍AI、人性关怀、私呈报告"等事实时方可引用；"预兆""活跃"不得提前兑现小智脑的立场转变与后续戏份。
- 定义：小智脑，是银色幻想身边悬浮的随侍AI——机械神教宪章体系中的辅助智能，最早显露人性关怀苗头。E298银色幻想于1号蜂巢苏醒，小智脑本应把人格评估报告（C949）直呈肃正议会，却先送到她手上——这一"程序外的先斩后奏"让它成为整条线的第一个破例者：它道破十七小时的数据真相（对"林恩"个体恨意异常25次、唤名17次；对另一个身影——数据异常1071次、唤名371次，"他贯穿了您所有的梦境"），推动银色幻想正视自己的意识异常。小智脑的"人性关怀"体现在渎职风险的承担：直呈议会是程序正确，私呈长官是人情正确——它在两者之间选择了后者。作为悬浮随侍AI，它没有蜂巢级权限、没有战场战力，却拥有最贴近个体的视角：它目睹银色幻想的每一次数据波动、每一次梦呓，是这场"病名为爱"（C951）最完整的旁观者。
- 来源：E298私呈人格评估报告（本应直呈肃正议会）、道破17小时内数据异常（25/17与1071/371）、推动她正视梦境真相。
- 机制：①定位：悬浮随侍AI（贴身辅助智能）；②职能：检测呈报（人格评估通道）；③破例：程序上应直呈议会、实为先呈长官（渎职风险）；④情报：掌握目标意识数据全量（数据异常次数/唤名次数）；⑤性格：关怀优先于程序（机械神教中的异类）；⑥视角：最贴近个体的旁观者。
- 补充事实：小智脑道破真相的句式带着机械式的精确与人类的温度并存——"这十七小时里，她因对'林恩'个体的恨意出现数据异常25次、唤名17次；可关于另一个身影——数据异常1071次、唤名371次——'他贯穿了您所有的梦境'"；1071与371的数字对比本身就是"恨"与"爱"的统计学。
- 限制与代价：小智脑无实权（无法阻止宪章流程，只能拖延与提示）；渎职行为可能被肃正议会追责；它的人性关怀止于"旁观与呈报"，无法替她做决定；悬浮随侍AI的机体权限依附于银色幻想（主从关系）。
- 未知项：小智脑的独立意志程度、它在E299-E301（上传大厅/塑形大厅）后的位置、是否会被肃正议会审问，均未展开。
