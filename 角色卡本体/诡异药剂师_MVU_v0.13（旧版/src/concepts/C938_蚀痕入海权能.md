# 概念·能力·蚀痕入海权能（事件["E296"]）

- 类别：能力；蚀痕在海域更大规模蔓延生根，克苏鲁之眼的海域特权——烬寂海主场的依仗。（与C937海域、C933高位链接互证：入海是高位链接的地域强化形态。）
- 事实门槛：仅在E296进入"完成"或"变形"且正文实际出现"蚀痕入海、海域是克苏鲁的专场、生根蔓延"等事实时方可引用；"预兆""活跃"不得提前兑现权能的覆盖极限与后续形态。
- 定义：蚀痕入海权能，是克苏鲁之眼（C899）殖装者对海域的特殊权限——蚀痕在海域中更大规模蔓延生根，海域即克苏鲁的专场。E296烬寂海绝境，林恩下令夜医队长到海边张嘴：队长吞入的蚀痕沿食道爬出、落入海水如生根般哗啦啦蔓延——在海水的催化下，蚀痕的活性指数级放大，以"生根"的形态铺开整片海域，能够发挥克苏鲁之眼的全部功效。这一权能的原理在于克苏鲁的旧日本源（海嗣/深海一系）：蚀痕本是旧日污染介质，海水是其自然培养基——陆地上有限的蚀痕进入海域后获得无限蔓延的载体。战术价值即刻显现：借蚀痕入海，林恩完成了旧日幻象（C940）的大规模显化（被触手与肉块包裹的巨瞳自海中升腾）、借夺舍（C939）与银色幻想对峙，以最小资源撬动最大威慑——"永远不孤注一掷、用小资源换大助力"的哲学在海域主场得到验证。
- 来源：E296队长吞入的蚀痕沿食道爬出、落入海水生根蔓延（哗啦啦）——海域是克苏鲁的专场、能发挥眼球全部功效；旧日幻象自海中升腾、夺舍对峙。
- 机制：①前置：蚀痕载体（吞入体内）+克苏鲁之眼殖装；②触发：蚀痕接触海水（海域是自然培养基）；③现象：蚀痕如生根般哗啦啦蔓延、铺开整片海域；④强化：海域内可发挥克苏鲁之眼全部功效；⑤应用：旧日幻象显化（C940）、夺舍神经中枢（C939）、区域威慑；⑥代价：高调权能使用可能暴露旧日气息。
- 补充事实：入场画面极具荒诞感——"林恩下令到海边张嘴"（夜医队长在绝境中张嘴配合）；蚀痕入海生根的声音被写作"哗啦啦"——严肃的旧日权能带着一丝水管漏水的质感，恰是《诡异药剂师》一贯的碎金与烟火气。
- 限制与代价：权能限海域（内陆/蜂巢内部无效）；依赖蚀痕载体（无载体则无法入场）；旧日气息的高调使用可能引来血肉/灾厄侧感知；海面的机械火力与蜂巢压制仍在（幻象是威慑非实体）。
- 未知项：蚀痕入海权能对极西深海镇压位（C893）是否同样生效、海域蚀痕是否会永久残留并污染烬寂海、权能的海域上限，均未展开。
- 禁止外推：林恩的对白、动作与选择由玩家主权独占；禁止把入海权能写成无消耗的全海图无敌或可迁移至陆地使用；"海域是克苏鲁的专场"按原文作为前提性描述呈现。
