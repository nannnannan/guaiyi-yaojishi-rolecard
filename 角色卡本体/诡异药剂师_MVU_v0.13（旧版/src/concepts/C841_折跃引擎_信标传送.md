# 概念·机制·折跃引擎·信标传送（事件["E267","E271"]）

- 类别：机制；至高机体超距传送：指定名额（信标21）、强干涉区域失效。
- 事实门槛：仅在对应事件（E267/E271）进入"完成"或"变形"且正文出现该事实时方可引用；"预兆""活跃"不得提前兑现。
- 定义：折跃引擎是至高级机体（机械神教/至高机体系列）搭载的超距传送机制，以"信标传送"为运作形式：指定某处锚定信标后，机体可将自身（或至多信标所承载的限定名额，如信标21名）超距投送过去，无视常规地理距离。传送并非无条件万能——在强干涉区域（旧日领域、根源级封锁、炽天使结界等秩序被扭曲的地带）内，折跃引擎的运作会被压制或直接失效，因为这类区域的规则不允许"被折叠的距离"成立。折跃引擎与传送门（隐修地千年传送门等）是两套体系：前者依赖机械信标与机体自身能源，随叫随到但受干涉区限制；后者依赖固定结构，稳定但不可移动。该机制既是至高级机体的机动力核心，也是其在深海/旧日战场上的主要入场手段，同时暗含其弱点：切掉信标或制造干涉场，即可将至高机体困在战场上。
- 来源：E267至高级机体以信标传送方式抵达战场（信标21名额）；E271深海隐修地一带折跃引擎与干涉区冲突的表现。
- 机制：①锚定：先在某地放置/激活信标（信标可承载名额，如21）；②发动：机体消耗能源折叠路径完成超距投送；③名额制：每次传送携带数量受限，超出部分无法随行；④干涉失效：强干涉区域（旧日/根源/结界）压制折跃，表现为无法锚定、传送中断或落地偏差；⑤能耗：连续折跃消耗机体能源，需第二能源接口等补充。
- 补充事实：信标21的名额暗示传送不是单人神技而是"编制式空投"——至高级机体可作为整支队伍的入场通道。
- 限制与代价：强干涉区是天然克制；信标可被破坏或篡改；传送后的落点精度在干涉边缘会劣化，可能落入包围。
- 未知项：折跃引擎的技术来源、是否所有至高级机体均搭载、能否反向利用干涉区制造"传送陷阱"均未知。
- 禁止外推：林恩对白/动作/选择玩家主权独占；不违背原著。

## 旧日深化（E305、E307）
- 集体跃迁：E305 本尊在死星工厂扑空后线索指向机械工厂、两线并进（「我那边可还有个对象要谈的啊！」）；E307 洗劫成功后以折跃脱身——三分钟窗口结束、单分子剑当空劈落，林恩猛地摸出大镰刀「折跃！」血色烟雾中身影消失。
- 折跃引擎同步锁定追击（E307）：折跃从此不再是安全离场——战争亲卫的折跃引擎同步启动、通过大数据流锁定方位（「目标锁定——追击——」），一道又一道折跃光束骤然划空追向未知落点。敌人的折跃引擎反成林恩的追命锁：至高机体系的传送能力被敌方同款能力对标克制，落点不再由林恩独占。
- 反幽灵干涉（E307）：逃亡途中智脑掐着「反幽灵结界的五秒空档」让他穿越——折跃/传送路径上存在专门的反幽灵干涉封锁（针对幽灵模式等隐匿穿行手段的物理/数据封锁），连折跃都要掐空档避险。折跃引擎的「干涉失效」从强干涉区域（旧日/根源/结界）扩展到机械神教的反幽灵结界，机制闭环：信标传送需要锚定、路径需要无干涉、脱身需要掐空档。
- 本区间定位：E307 后折跃引擎从「入场手段」变成「被锁定追踪的逃亡手段」，与战争亲卫的折跃同步启动互为镜像——至高级机体体系内，折跃既是机动优势也是暴露坐标的弱点。
