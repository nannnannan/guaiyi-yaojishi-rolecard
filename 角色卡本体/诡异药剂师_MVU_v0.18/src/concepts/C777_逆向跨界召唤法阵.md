# 概念·机制·逆向跨界召唤法阵（事件["E231","E240","E242","E340","E343"]）

- 类别：机制
- 事实门槛：对应事件完成或变形且正文实际出现后，才引用其事实；事件中的参考经过不代替玩家选择。

- 既往定义：一种可在蓝星反向打通地狱的门径级大型法阵。原本的逻辑是"以利维坦血肉（地狱根源级血肉）为祭品，向地狱发出召唤波动、请黑夜城/白夜等降临蓝星"——如同倒转的跨界传送门。因其可逆向运转，也能被改造为"把已降临的敌人与整座法阵一起引爆"的灭世级混合炸弹：法阵在能量灌注后变得极不稳定，一旦引爆，能震碎全城玻璃、汽化高楼、夷平城市——因为祭品是根源级的利维坦血肉。
- 既往来源：E231林恩为把血肉支配者逼出，割掌以血为墨、用利维坦血肉碎片反复铭刻假召唤法阵，让血色光束一次次直刺云霄、把波动限制在蓝星内（忌惮羽毛笔的注视警告），用意只在释放"我随时可能从地狱拉来一支军队"的信号；E240左左在蜀都地下以利维坦血肉为祭布设召唤法阵，召唤白夜与其反血肉军团降临；E242白夜被召唤降临后，左左因认定林恩已死而改写法阵、把残余利维坦血肉做成引爆装置要"大家都去死"，最终被机械之躯归来的林恩以超维感应止爆。
- 既往机制：①铭刻：以血/灵力为墨、利维坦血肉为能量核心布置法阵节点；②激活：释放大型跨世界召唤波动（可压限在单一世界内）；③召唤：地狱方响应后白夜等夜医沿裂隙降临；④逆向：法阵可被恶性改写为不稳定的混合炸弹，祭品力量瞬间狂暴宣泄；⑤止爆：以同源力量（超维感应/巨像控制力）从外部遏制引爆，阻止爆炸扩散。
- 既往补充细节：这套法阵的"逆向"本质贯穿三个用途：向地狱发信（E231假召唤）、向蓝星请兵（E240真召唤）、向敌人点火（E242引爆）——同一套技术在不同意志下可以是信号、传送门与炸弹；左左在E242改写运行的那一步，是全书"召唤系统被反用"的最危险示范：她把利维坦血肉从祭品改写成燃料，让"神的恩赐"变成"神的炸药"。
