# 概念·机制·死兆级傀儡与白痴印记（事件["E107","E108"]）

- 类别：机制
- 事实门槛：仅在对应事件（E107/E108）进入“完成”或“变形”，且聊天正文明确出现该事实时方可引用；“预兆”“活跃”“取消”不得提前兑现。
- 定义：利维坦傀儡军团的高阶控制法则与防止反噬的熔断自毁机制。
- 来源：E107林恩在黑弦月指导下接管524具战斗傀儡并在脑干刻印。
- 机制：由死兆级强者尸骸熔铸而成的杀戮傀儡战力凶悍。林恩在黑弦月指导下刻入霸道的“白痴级”傀儡之印，并预设自动熔断机制，一旦遭遇外部黑客强行入侵或即死因果律诅咒，符文会瞬间烧毁替身中枢，确保操控者本体绝不受任何反噬。

- 未知项：利维坦封存的五大死兆傀儡生前所属的具体远古神教派系不详。
- 禁止外推：林恩的对白、动作与选择由玩家主权独占；禁止违背原著设定将其描写为无消耗或脱离因果律违规生效。
