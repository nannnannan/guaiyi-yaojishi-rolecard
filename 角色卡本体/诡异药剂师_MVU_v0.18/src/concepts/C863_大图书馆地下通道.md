# 概念·场景·大图书馆地下通道（事件["E267"]）

- 类别：场景；腐败如海床的图书馆，通往隐修地传送门。
- 事实门槛：仅在对应事件（E267）进入"完成"或"变形"且正文出现该事实时方可引用；"预兆""活跃"不得提前兑现。
- 定义：大图书馆地下通道是圣域大图书馆深处的隐蔽通路。大图书馆本身是一座宏伟的藏书圣殿，但受旧日污染侵蚀后，建筑内部开始"腐败如海床"——走廊生苔、墙面沁出湿气与腥咸、空气弥漫海底腐烂的气息，仿佛整座图书馆正在被深海从内部泡软。就在这片腐化的地下，隐藏着通往隐修地传送门的通道：穿过腐败的地下层，可抵达承载千年传送门的隐修地传送门大殿（E268主场），从而连接到隐修会与天使侧的神圣领域。这条通道因此兼具双重身份：环境上是被旧日污染的腐败地带，功能上却是圣域与隐修地之间的秘密咽喉。行于此地者既要提防腐败环境与可能渗入的污染，又要依赖这条通路完成从圣城到隐修地的关键转移。
- 来源：E267大图书馆地下通道腐败如海床、通往隐修地传送门的描写。
- 机制：①位置：圣域大图书馆地下层；②腐败态：墙体生苔、湿气腥咸、渐变海床质感；③通路：地下层连接隐修地传送门；④咽喉：圣城与隐修地之间的秘密转移通道；⑤隐患：腐败环境与渗入污染同步威胁通行者。
- 补充事实：图书馆的书页并不是怕水——它们是像海带一样在湿气里慢慢舒展卷曲，仿佛整栋楼都在往海底沉。
- 限制与代价：腐败环境消耗通行者精力与净化资源；污染在湿腐地带扩散更快；通道一旦被堵，圣域与隐修地联系即告断裂。
- 未知项：大图书馆的献世藏书是否遗存、通道是否有其他分支、腐败源头是否与圣彼得中心广场蚀痕相连均未知。
