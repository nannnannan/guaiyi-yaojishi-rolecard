# 概念·物品·灵能芯片与赛博文明火种（事件["E98","E99","E120","E351","E362","E363","E364","E367"]）

- 类别：物品
- 事实门槛：仅在对应事件（E98/E99/E120）进入“完成”或“变形”，且聊天正文明确出现该事实时方可引用；“预兆”“活跃”“取消”不得提前兑现。 本版新增事件（E351/E362/E363/E364/E367）按相同门槛生效。
- 定义：赛博飞升者文明最高科技与记忆结晶，艾雯爵士文明记忆与自我认知的最后核心载体。
- 来源：E98艾雯爵士升格为根源级赛博飞升者前夕，将其贴身郑重托付给林恩随身保管。 E351现场找回受损芯片；E362主母确认保存未受暗面污染的备份；E363主母解封并耗时数小时传输原始备份唤醒艾雯，但备份停在十几年前其尚未结识林恩之时；E364艾雯致歉并愿重新建立友谊；E367巨像之脑为其补充记忆映像档案。
- 机制：由高维灵能水晶与超导量子回路熔铸而成的微型芯片，内含赛博文明数万年积累的完整科技树、灵能矩阵算法以及艾雯毕生记忆。由于赛博飞升诅咒会导致使用者随着力量释放加速遗忘过往，该芯片成为艾雯在战场上辨识唯一挚友、维系自我认知的最后锚点，也是万机之神三位一体飞升梦寐以求的关键组件。 艾雯的人格与文明记忆存在多处备份。受灾变侵蚀的现场芯片丢失大量数据；主母保存的早期原始芯片（前任飞升者传承）成功唤醒其意志与灵能，但该离线数据未包含近十余年经历。外部记忆映像能帮助艾雯理解近事背景，但无法直接替代亲身经历与情感认知。
- 限制与代价：无法直接阻止艾雯在战斗过程中即时产生的记忆衰退，仅能作为离线数据备份与物理认知锚点存在。 离线备份存在显著时间代差；压制诅咒只能减缓进一步遗忘，不能自愈已损坏的人格数据；外部资料学习不能等同于亲历记忆归返。
- 未知项：赛博母星毁灭前夕由最高议会录入芯片底层的终极自毁或重启协议参数不详。 芯片残片能否进一步重建，损失的近期数据能否找回，艾雯与林恩的羁绊如何重新积累。
- 禁止外推：林恩的对白、动作与选择由玩家主权独占；禁止违背原著设定将其描写为无消耗或脱离因果律违规生效。 不得把找到受损芯片写成艾雯已恢复；不得把前任飞升者与继承者混为同一现行人格；艾雯未恢复亲历前不得用读档替代失忆状态，不得替林恩做固定回应。
