# 概念·能力·随机诊断术与debuff滚雪球（事件["E228","E229"]）

- 类别：能力；以低代价、可无限释放的随机诊断术对单一目标堆叠精神类病症、令成功率随debuff数量指数级上升的战斗体系。
- 事实门槛：E228中林恩对魇魔极速连发数十次随机诊断术、从十几次失败到十几种精神病症同挂；E229鬼面尖啸者吹散白雾、病症失控推动魇魔投影走向末路。未发生实际成功叠加上病症前，不引用雪球生效。
- 定义：随机诊断术本是一种低代价、随机判定的诊断干涉术，对目标有概率附加一个随机病症。林恩利用其"可无限重复、只要概率非零终究会中"的特性，配合「死缚」保证必定命中、「百分之百未命中」剥夺对方反制，形成滚雪球：每挂上一个精神类病症（精神迟钝/意志衰弱/精神错乱/疯狂/癔想等），双方实力差进一步拉大，后续释放的成功率随之暴涨，直到十几种病症同时啃噬其精神世界、把死兆级恶灵削到接近普通人。
- 来源：E228机械猎场决战，林恩以死缚锁定魇魔真身后，靠精神药剂+暴击药剂增幅自身、白雾+震荡器/抑制器削弱对手，一句"只要概率不是0%，只要出一个病症，就能滚起雪球"，十次、二十次地反复诊断，最终叠加出精神迟钝、意志衰弱、精神错乱、疯狂、癔想等多重病症，逼得魇魔自抓虚体；E229病症在巨像之心灾变中全面发作、配合千台鬼面尖啸者尖啸完成压制。这印证了随机诊断术在"优势在我"型战斗中的降维打法。
- 机制：①先以死缚锁死目标使其无法转移/反制；②以百分之百未命中剥夺其命中与行动力；③以自身buff（精神/暴击药剂）、环境debuff（白雾削弱感知）拉开精神判定差；④无限释放随机诊断术——失败无数次也无代价；⑤一旦首个病症命中，成功概率跳升，继续追加直至数十个病症雪球式叠加；⑥配合机械装置衰减目标反扑。判定轴：心灵怪物血肉强度≈0、宿主全点体质，故肉体判定必胜、精神判定先输后靠buff逆转。
- 限制与代价：需要极高的操作节奏与药剂库存支撑；对心灵型目标最有效、对纯物理敌人收益有限；目标挣脱锁定（如打爆装置）即雪球崩盘；持续释放浪费精神力与价值高昂的药剂；运气极差时可能长期出不了首个病症。
- 未知项：诊断术上限病症种类、对根源级本体是否有效、雪球能否对群体生效均未知。
- 禁止外推：林恩的对白、动作与选择由玩家主权独占；禁止违背原著设定将其描写为无消耗或脱离因果律违规生效。
