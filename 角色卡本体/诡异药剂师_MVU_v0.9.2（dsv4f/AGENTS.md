# 《诡异药剂师》MVU v0.8 接手指南

## 适用范围与权威顺序

本文件只适用于`诡异药剂师_MVU_v0.8/`。权威顺序为：用户当前要求 → `创作规划.yaml` → `contract.json` → `manifest.json` → `profile.json` → `src/` → `dist/`。不要手改`dist/`。v0.7 已 accepted-release 并冻结，不回改；v0.6 及更旧版本目录同样不动。

- 核心人物 27 名 = 24 既有 + 万机之神(UID295，登场锁E77，固定非恋爱) + 巨像之脑(UID296，登场锁E78，恋爱/恶堕开放，只写骨架+不详) + 血肉支配者(UID297，登场锁E96恒锁定，固定非恋爱，只写最低限度)。

- v0.8 为 pending 内部候选；真机验收（所有者另行授权）通过后才可转 accepted-release，不继承 v0.7 的哈希与验收状态。

## 创作与安全铁律

- 玩家独占林恩的对白、主动行动、决定、判断、记忆与内心；默认走向只供因果推演。
- 本书为色色风后宫文：色色与恶堕全面开放，不设幼态/年龄限制；NPC 可按人设主动亲密与逆推；玩家可拒绝、打断或改写。
- **色色直白化**：原文色色暗语/隐喻直接翻译成明语写入，包括性行为过程；不设分级词表。机制三等价：以M=快感冲击（媚药；可唤起性欲；对根源级同样有用）、性行为=解咒途径、恶堕=性调教路径。
- **禁元数据词汇**：角色卡与世界书正文禁止出现"第X章、小总结、大总结、阶段几"等总结/原文词汇，来源与门控一律用 E 编号。
- 关系字段归属：涩涩度=全部恋爱开放角色通用；情感开发度=黑弦月专属；驯服度/崩坏值/恨意值=银色幻想专属；信任度并入信赖；亲情不建字段。
- 固定非恋爱锁0：血锯、白逸、泰坦头颅、巫神头颅、小宝贝、白夜、渡鸦、黑颅、猪头屠夫、哭泣小丑、黑白小丑、艾雯爵士、万机之神、血肉支配者。（渡鸦、黑颅为女性形态仍维持锁；巫神头颅吸引锁0、恶堕开放。）
- 特殊口径：爱丽丝=存世数百年的恶灵、天真完全相信林恩的可爱妹妹，恶堕开放；左左=独立意识，色色开放；小小=根源级泰坦/未婚妻，开放；巨像之脑=恋爱/恶堕开放但未登场。
- 白小凌为配角NPC：并入概念或群像，不建人设、不入关系根，不设色色设计也不设禁令。
- 身份反转门控：左左=巨像之心王后意识仅在 E78 及以后解锁，阶段一二三文本不加暗示；银色幻想为万机之神独女（万机之神之外唯一的机械意识）在 E95 揭晓，E77 段保留"主宰的……"省略。
- 白夜 E83 前失联、E83 经艾雯爵士重新聚拢复联；泰坦/巫神 E83/E93 被八音盒与诡异乐声截击触发狂乱、仅小小独自前往；三根源仍未会合。
- 猪头屠夫/黑白小丑"教育者"定位可写；"穿越幕后推手"只留叙事层，不得写入林恩知识。
- 用户私下剧透（林恩后续与欲望母树有亲密戏、羽毛笔是欲望母树上辈子朋友）只供留白，不得写入卡内任何文件。
- 第 560 章起（阶段五）内容禁止写成已发生；E96 只列封存线程。

## 事件契约

- 六态固定为未触发、预兆、活跃、变形、完成、取消；只有活跃占唯一活跃槽，变形是稳定终态。
- E65–E95 含下一事件引入，默认走向 300–500 字；大锚点 E77（万机之神投影贯穿取心）、E80（直死书与六诅咒同归于尽）、E94（三蜂巢饱和轰炸·母树降临）按幕分段、整条不超 800 字。E96 只写阶段待续钩子。
- 事件完整详情窗口固定为当前锚点±1；当前锚点±3只提供事件摘要。下一事件引入与常驻桥只输出可接续钩子，不得把未来事件正文当成已发生。
- UID1 是事件全文唯一运行时注入源。UID300–334（阶段一二素材）、UID335–363（阶段三素材）、UID364–395（阶段四素材）统一 `enabled:false`，不得通过事件ID、标题或剧情宽泛词再次绿灯。
- 完成/变形可按局部前置推进；取消态状态栏只提示"需正文判定局部依赖"，模型依据 `contract.required.event_dependencies`（E65+ 每事件三字段：hard_all/hard_any/independent_fallback）与替代入口处理。
- 战斗段（E67/E68/E72/E77–E82/E94）只设完成/变形，不设取消；色色/日常段设取消与"拒绝/改道"变形路径，任何性行为不得成为唯一解。
- 任何锚点状态/收尾、唯一活跃身份或预兆身份变化，只用一条完整 `replace /事件`。
- 全卡桥共 95 对（E01→E02 … E95→E96）；E96 无推进按钮；E64→E65 桥前件判断挂 E63（E64 恒未触发不当前件）。

## 人物、概念与EJS

- 人物运行时组件顺序固定：角色速览、基础信息、性格调色盘、三面性、多阶段人设、二次解释。
- 新增3人（万机之神/巨像之脑/血肉支配者）按"未登场锁+事件门控"建立；巨像之脑、血肉支配者只写骨架与"不详"，严禁瞎编。
- 9 份候选二次解释已注册：并入倒吊天使、哭泣小丑、渡鸦、爱丽丝、猪头屠夫、白夜、白逸、黑白小丑、黑颅的官方二次解释组件。
- 人物只通过两路进入提示词：事件详情±1窗口内出场人物自动强启，或姓名/别名原生关键词绿灯。两路复用同一人物UID并先按UID去重；条目内EJS只输出当前已解锁阶段人设。
- 概念分静态与状态变体EJS两种形态；两路激活不变；事件数组、worldbook元数据与关键词注册一致，同一UID同轮只注入一次。传闻与真相、"疫医暗面"等疑云保持分条与"未知项/禁止外推"，不提前泄底。
- 状态变体块按门控事件从新到旧链式 `if/else if` 排列，只认完成/变形，末块必为兜底；E65+ 新变体插链首，末块兜底为"E65+ 均未触发"；事件演进、当前状态必在块内。
- 概念变体EJS只读 `getvar("stat_data.事件.锚点状态.EXX.状态", { defaults: "未触发" })`，禁用 const/let/await/activewi/getEnabledWorldInfoEntries；首行仍是概念标题行，不加装饰器。
- 概念详写、数量不设上限；**删除字数上限、保留下限与结构断言**；来源用 E 编号；"未知项/禁止外推"覆盖全部大揭示；末段统一"后续阶段另有展开，禁止外推"；立项前强制 keywords 差集核查（机制词可入 keys，具体性行为词不入）。
- UID 段：人物 295–297；概念 551 起；事件素材 364–395；428 留空不重排；UID400–492 与 493–550 保持稳定。
- 含 `const/let` 的非路由EJS必须 `@@private` 或独立作用域。路由内部必须对目标UID建立本轮去重集合。
- UID399 统一路由只能处理承载该机制条目的本卡世界书。
- 新增或修改世界书条目必须显式开启 `exclude_recursion` 与 `prevent_recursion`。
- v0.7 既有概念与阶段四事实冲突时，在 v0.8 内用状态变体新块覆盖，不改 v0.7 文本。

## MVU整链

根字段固定为元数据、世界、林恩、事件、关系、角色关系、系统。任何结构变化同步：

`src/initial_variables.json` → `src/scripts/schema.js` → `src/prompts/first_message.md` initvar → `src/ui/status.html` FALLBACK_STATE → 更新规则/输出格式 → `contract.json` → `tools/validate.mjs`

- 锚点状态 96 个（E01–E96）；阶段 S0–S13。
- 关系根 27 人。关系字段扩展：涩涩度（0–100，恋爱开放角色通用，固定非恋爱锁0）；情感开发度（仅黑弦月）；驯服度/崩坏值/恨意值（仅银色幻想）；未用角色恒0且状态栏不渲染。信任度并入信赖；亲情不建字段。
- 林恩新增字段：压力、道德、罪恶、复苏度、替死娃娃剩余、天使之吻状态、根系网络权限、巨像网络权限。六诅咒不进 MVU（纯叙事）；RPG属性/货币/装备库存不进 MVU。
- 角色关系边取消 64 上限，按需建立、不建全矩阵。不创建战斗数值、等级成长、装备、库存、货币、经营或天数系统。
- 初始态：E01 完成、E02 活跃且收尾=true、E03–E96 未触发。
