# 概念·场景·仪式塔（事件["E44","E45"]）

- 类别：场景
- 事实门槛：标题中的事件编号只标注关联阶段。只有对应事件锚点进入“完成”或“变形”，且聊天正文实际形成炸炉炼药、四阶段讲解、法阵追溯或祷文之争结果时，本条的事件演进与当前状态才成为当前事实；“预兆”“活跃”或“取消”不会自动兑现所列走向。玩家偏离时，以聊天中已经发生的事实为准。
- 定义：仪式塔是黑夜城的高塔，城西最大的一座由九字元勋、人工智能艾雯爵士负责。塔内可进行药剂炼制、召唤法阵的炼化、烙印与测试，并可借万花筒般的空间变换进入中世纪图书馆或黑暗虚空；是主母亲授林恩炼制史诗药剂、以及林恩确立专属召唤体系的地点。
- 来源：E44中，主母亲自教导林恩在仪式塔炼制史诗级药剂【自缚天使的怜悯】，林恩连炸199次。E45中，主母让林恩去黑夜城西最大仪式塔找艾雯爵士办专属召唤仪式，艾雯在其中讲解召唤四阶段并追溯无瞳法阵，随后发生祷文之争。
- 机制：仪式塔承载药剂炼制（可由主母以根源级体液/天使圣血为原料、唾液版替代）与召唤法阵的炼化、烙印与成功率测试；召唤体系分四阶段【众生】→【超凡—死兆】→【君王—根源】→【根源之上】，法阵只向下兼容；指定召唤需靶向定位（生辰八字、姓名、特征、爱好），能否召唤取决于力量能级与降临成本。
- 限制与代价：炼制史诗药剂需根源级体液，主母拒给圣血、林恩只得索要唾液版替代（还因索要“姨妈巾”被圣光连炸）；炸炉是常事（抗爆炸能力提高、抗炸成就）；法阵烙印会被虚无意志拒绝，追溯出疑似更大法阵一部分的血色无瞳之眼；祷文美化版成功率不足1%，加入“萝莉控”描述才飙至94%。
- 未知项：无瞳法阵的完整含义与来源、四阶段之上是否还有更高阶、艾雯爵士对无瞳之眼的未明判断均未知。无瞳法阵与“体内的祂”关系属后续剧情，保持未知、不坐实。
- 禁止外推：不得把仪式塔写成林恩专属领地或把未确认的法阵形制当成已掌握；不得坐实无瞳法阵的来源或将其解释为林恩真实身份的铁证；不得虚构艾雯爵士已完成的四阶段法阵之外的旧法阵。
- 事件演进：若E44按炼药线推进，林恩在仪式塔连炸199次、熟练度卡199/200，最终以主母唾液代替天使圣血第200次炼成盗版【自缚天使的怜悯（盗版）】（史诗级-，压制诅咒），获“炼药速度+10、药效+5、药剂制作至高级”，并顺带向主母打探到巨像脑组织情报。若E45按召唤线推进，艾雯讲解四阶段体系、带林恩入黑暗虚空欲烙印专属法阵被拒，逆向追溯出十米血色无瞳之眼法阵；随后祷文之争中左左添“变态而扭曲的萝莉控”，成功率由3%飙至94%，林恩当场被召唤上法阵。
- 当前状态：只有正文实际记录后，炸炉炼药、四阶段讲解、无瞳法阵追溯与祷文94%底本才成立；法阵的后续测试与艾雯的“发现”以聊天事实为准。
- 人物关联：林恩是炼药者与受教者；倒吊天使（主母）亲授并讨血；艾雯爵士（义兄/师长向、非恋爱）负责法阵并留下“发现”伏笔；左左参与祷文之争；仪式塔测试人员校正法阵。
