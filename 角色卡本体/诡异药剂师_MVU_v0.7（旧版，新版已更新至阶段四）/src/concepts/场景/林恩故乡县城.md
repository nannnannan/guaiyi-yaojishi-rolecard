# 概念·场景·林恩故乡县城（事件["E40","E42"]）

- 类别：场景
- 事实门槛：标题中的事件编号只标注关联阶段。只有对应事件锚点进入“完成”或“变形”，且聊天正文实际形成户籍锁定、跳车寻母、车祸或呼喊结果时，本条的事件演进与当前状态才成为当前事实；“预兆”“活跃”或“取消”不会自动兑现所列走向。玩家偏离时，以聊天中已经发生的事实为准。
- 定义：林恩故乡县城位于平行蓝星东北黑龙地区，是林恩记忆中“母亲”生活的北方小城。县城有街道、校车路线与尽头处带院落、栽种盆栽的家，母亲在此与丈夫共同生活，并称家中只有“一个宝贝闺女”。该县城同时关联着平行蓝星上存在的、未下地狱、正常陪伴父母的“林恩”（其户籍被加密为马赛克图像）。
- 来源：E40中，林恩在超自然总局豪华房间触手敲键盘调取户籍资料与卫星定位，锁定北方县城里那张与自己记忆中一致、带皱纹的母亲的脸，并输入“林恩”检索发现全国无匹配、转而翻出平行“林恩”的马赛克加密户籍，决意“远远看一眼”。E42中，火车倒计时将至，林恩跳车、触发车祸，冲至县城街道尽头呼喊母亲。
- 机制：县城通行现代户籍与实名制，母亲影像与平行“林恩”户籍均可经资料库检索锁定；召唤物驻留存在回归倒计时（血娃娃告知无法延长），时间耗尽即被黑暗世界裂隙强行拖回。校车、街道、院落构成林恩最后冲刺的空间。
- 限制与代价：林恩只能“远远看一眼”，回归倒计时（11分03秒）不可逆；他在县城被校车撞飞受伤，与母亲之间隔着百米被锁链强行拖回的距离；母亲视角只觉街巷空空、被丈夫安抚“听错了”。平行“林恩”的户籍加密本身即阻断了直接查明真相。
- 未知项：母亲的家庭全貌、平行“林恩”的真实身份与去向、林樱与林恩的血缘/同位体关系、触碰闪现的内容与机制均未知。
- 禁止外推：不得把县城写成林恩上海故乡；不得坐实平行“林恩”即林樱，也不得坐实“一个宝贝闺女”即指林樱；不得虚构母亲、父亲之外的亲属或情节。
- 事件演进：若E40形成检索结果，林恩锁定母亲影像、发现平行“林恩”加密户籍并起意看一眼。若E42按寻亲线推进，林恩火车上身体闪烁、打破车窗跳车，倒计时剩三分钟时冲入县城被校车撞飞，穿校服、学过护理的林樱制止众人并触碰其侧脸引发异象，林恩与她相望后奔向街道尽头，望见院内修剪盆栽的母亲背影，哭喊“妈妈”时回归倒计时归零，被虚无锁链拖回黑暗世界，距背影百米如咫尺天涯；母亲转身回望只有空街。
- 当前状态：只有正文实际记录后，母亲影像、跳车、车祸、林樱相遇与“妈妈”呼喊才成立；林恩已被拖回黑暗世界，母亲与县城的后续以聊天事实为准，不得自动续写重逢。
- 人物关联：蓝星母亲与父母在此生活；平行“林恩”（加密户籍）悬而未决；林樱是校车急救与触碰异象的关键人物；白逸、血娃娃同行见证跳车；林恩在此完成百米寻母的名场面并重拾归乡信念。
