# 概念·物品·猫娘药剂（事件["E49","E50","E63"]）

- 类别：物品·特殊药剂（配方型，猫咪饮下百分百变猫娘）

- 事实门槛：只有对应事件锚点进入“完成”或“变形”、且聊天正文实际形成该条目的取得、使用或成立结果时，相应内容才成为当前事实；“预兆”“活跃”或“取消”不会自动兑现所列走向。玩家偏离时，以聊天中已经发生的事实为准。

- 定义：猫娘药剂是林恩为喵喵炼制、令"猫咪饮下百分百变猫娘"的特殊药剂。以【猫娘药剂配方】炼制，成品为粉红药剂 x1（另加猫薄荷与蜂蜜调味）。喵喵饮下后，从秋田犬形态（被缝犬皮的猫）撕开犬皮囊、蜕变为蓝发猫耳萝莉，成为正常猫耳娘。

- 来源：
- 配方：E49 照片真相揭晓后，特殊任务结算投放【猫娘药剂配方】（配方含太阳花x1、死亡草x1、猫咪分泌物x2、根源级生物组织x1等；猫咪喝下百分百变猫娘），林恩同时升 26 级。
- 炼制：E50，喵喵请求"变成和妈妈一样的、和医生哥哥一样的人"，林恩在病院炼药房集齐材料炼制；最关键材料"根源级生物组织"是林恩趁第三次为主母压制诅咒时盗取的【主母的红茶包】，投入锅中神圣金光四溢，触发成就"红茶包的正确用法"（永久罪恶+1、智力+5、心灵手巧+1、快乐+5）；再令喵喵"tui一口"分泌物，炼成粉红药剂 x1（炼药经验+1）。

- 机制：
- 变猫娘：猫咪饮下后百分百转化为猫耳娘形态（固定效果，无成功率波动）。
- 蜕皮成长：喵喵饮下后独自撕开那副罪恶的犬皮囊，强忍剧痛直面镜中扭曲血肉，完成从"缝犬皮猫"到"猫耳娘"的心身蜕变。
- 材料绑定：需猫娘药剂配方所列材料，其中"根源级生物组织"一环以主母红茶包替代达成。

- 限制与代价：
- 原料稀缺：核心材料"根源级生物组织"极难获得，林恩靠盗取主母私物【主母的红茶包】才凑齐，属不可复制的旁门获取。
- 成品数量：本事件仅炼成粉红药剂 x1。
- 定向对象：配方针对"猫咪"，对非猫类生物的适用性未说明。

- 人物关联：
- 喵喵：饮药者，由此从"狗耳娘"彻底变为猫耳娘并破茧。
- 林恩：炼制者，盗用主母红茶包完成炼制并触发"红茶包的正确用法"成就。
- 倒吊天使（主母）：红茶包失窃的对象，为配方中最关键的隐藏材料来源。
