# 《诡异药剂师》MVU v0.7 接手指南

## 适用范围与权威顺序

本文件只适用于`诡异药剂师_MVU_v0.7/`。权威顺序为：用户当前要求 → `创作规划.yaml` → `contract.json` → `manifest.json` → `profile.json` → `src/` → `dist/`。不要手改`dist/`，不要修改v0.5、v0.6及旧版本目录。

## 版本边界

- 内容至第431章，阶段三新增范围为第277至431章、小总结14至20。
- 事件E01至E64；S0至S10；E64是本版终点（开放钩子，与后续阶段四融合），不创建E65。
- 24名核心人物各6组件（17名既有+7名新增）；倒吊天使在UID200扩写。
- v0.7是真机待验的内部候选，不得继承v0.6 accepted-release状态或哈希。

## 创作与安全铁律

- 玩家独占林恩的对白、主动行动、决定、判断、记忆与内心；默认走向只供因果推演。
- 本书为色色风后宫文：色色与恶堕等情节全面开放，不设任何幼态/年龄限制；NPC可主动发起亲密与逆推（按人设），越线无需玩家决定；玩家可拒绝、打断或改写。
- 爱丽丝按"存世数百年的恶灵"处理、恶堕开放；左左按独立意识处理、色色开放；小小按根源级泰坦/未婚妻处理、开放。
- 固定非恋爱的角色维持原样：血锯、白逸、泰坦头颅、巫神头颅、小宝贝、白夜、渡鸦、黑颅、猪头屠夫、哭泣小丑、黑白小丑；艾雯爵士为义兄/师长向非恋爱。（注：渡鸦、黑颅为女性形态，但按既有固定非恋爱锁维持，不因性别措辞误开。）
- 白小凌为配角NPC：并入概念或群像，不建人设、不入关系根，不设色色设计也不设禁令。
- 爱丽丝隐身不是消散；卡梅尔与女主人阶段末意识/生死未知；E31只处理哭泣小丑显化体，E34天使血压制15日，阶段三期间自然到期，复发留钩子。
- 猪头屠夫与黑白小丑山巅密谈只供叙事层，不能写入林恩知识。
- 血衣女士默认线为林恩忘记回游魂巷与续治；实际聊天存在回访事实时，以关系关键记忆覆盖默认线。
- 泰坦/巫神/小小E59起驰援在途，全程未抵达，不得写成已会合。
- 白夜E63后完全失联；不得写成已脱困或已回归。
- 用户私下剧透（林恩后续与欲望母树有亲密戏、羽毛笔是欲望母树上辈子朋友）只供留白，**不得写入卡内任何文件**。

## 事件契约

- 六态固定为未触发、预兆、活跃、变形、完成、取消；只有活跃占唯一活跃槽，变形是稳定终态。
- E36至E63含下一事件引入，默认走向300至500字（大锚点E47/E60/E61/E63按幕分段，整条不超800字）。E64只写阶段待续钩子（与后续阶段四融合）。
- 事件完整详情窗口固定为当前锚点±1；当前锚点±3只提供事件摘要。下一事件引入与常驻桥必须按六态输出可接续钩子，不得把未来事件正文当成已经发生。
- UID1是事件全文唯一运行时注入源。UID300至334（阶段一二素材）与UID335至363（阶段三素材）统一`enabled:false`，不得通过事件ID、标题或剧情宽泛词再次绿灯。
- 完成/变形可按局部前置推进；取消态状态栏只提示"需正文判定局部依赖"，模型依据`contract.required.event_dependencies`与事件替代入口处理。
- 任何锚点状态/收尾、唯一活跃身份或预兆身份变化，只用一条完整`replace /事件`。
- 全卡桥共63对（E01→E02至E63→E64）；E64无推进按钮。

## 人物、概念与EJS

- 人物运行时组件顺序固定：角色速览、基础信息、性格调色盘、三面性、多阶段人设、二次解释。
- 新增7人（黑弦月、喵喵、林樱、艾雯爵士、羽毛笔、a01银色幻想、欲望母树）按"未登场锁+事件门控"建立；素材不足处写"不详"，严禁瞎编（羽毛笔、a01、欲望母树后续有大戏份）。
- 9份`候选二次解释/`不得注册进世界书。
- 人物只通过两路进入提示词：事件详情±1窗口内出场人物自动强启，或姓名/别名原生关键词绿灯。两路复用同一人物UID并先按UID去重；条目内EJS只输出当前已解锁阶段人设。
- v0.6的"黑弦月"物品概念条目删除（UID留空不重排），内容并入新人设。
- 概念分静态与状态变体EJS两种形态；两路激活不变；事件数组、worldbook元数据与关键词注册一致，同一UID同轮只注入一次。传闻与真相、"疫医暗面"等疑云保持分条与"未知项/禁止外推"，不提前泄底。
- 状态变体块按门控事件从新到旧链式`if/else if`排列，只认完成/变形，末块必为兜底；事件演进、当前状态必在块内。
- 概念变体EJS只读`getvar("stat_data.事件.锚点状态.EXX.状态", { defaults: "未触发" })`，禁用const/let/await/activewi/getEnabledWorldInfoEntries；首行仍是概念标题行，不加装饰器。
- 阶段三概念详写、数量不设上限；一次性小道具与纯过场角色保留在事件正文，不拆独立概念；"大哔哔"直写为"大鸡巴"。
- UID400至492既有概念保持稳定UID、名称、类别、关键词和事件关联；新增概念从493起。
- 含`const/let`的非路由EJS必须`@@private`或独立作用域。路由内部必须对目标UID建立本轮去重集合。
- UID399统一路由只能处理承载该机制条目的本卡世界书。
- 新增或修改世界书条目必须显式开启`exclude_recursion`与`prevent_recursion`。

## MVU整链

根字段固定为元数据、世界、林恩、事件、关系、角色关系、系统。任何结构变化同步：

`src/initial_variables.json` → `src/scripts/schema.js` → `src/prompts/first_message.md` initvar → `src/ui/status.html` FALLBACK_STATE → 更新规则/输出格式 → `contract.json` → `tools/validate.mjs`

- 锚点状态扩至64个（E01–E64）；阶段扩至S0–S10。
- 关系根24人；恶堕全面开放（女性角色无锁，不再使用`z.literal(0)`）；固定非恋爱角色（含女性形态的渡鸦、黑颅）维持锁。
- 角色关系边最多64；不建立全矩阵。不创建战斗数值、等级成长、装备、库存、货币、经营或天数系统。
