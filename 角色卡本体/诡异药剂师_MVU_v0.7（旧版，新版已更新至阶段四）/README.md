# 《诡异药剂师》MVU v0.7

这是面向 SillyTavern 1.17.0 与酒馆助手 4.9.1 的 `chara_card_v3 / MVU Zod` 内部候选工程。v0.7 从 v0.6 独立复制，在不修改 v0.5/v0.6 的前提下，把内容边界扩到第431章、小总结14至20。

## v0.7内容

- 64个六态事件锚点：保留E01至E35，新增E36至E64；E36至E63含下一事件引入，E64只有阶段4待续钩子（与后续阶段四融合），不创建E65。
- 11个宽阶段S0至S10；阶段三新增S8蓝星与黑夜城、S9成长与人偶线、S10宗教战争与疫医伪装。
- 24名核心人物，每人6个运行时组件；新增7人（黑弦月、喵喵、林樱、艾雯爵士、羽毛笔、a01银色幻想、欲望母树）按"未登场锁+事件门控"建立，素材不足处写"不详"；9名既有角色的候选二次解释稿仍未注册，等待用户逐条确认。
- 150条概念：UID400至492既有概念保持稳定UID、名称、类别、关键词与事件关联（"疫医"UID452按阶段三扩写为E30/E32/E48/E52/E54/E60）；UID493至550为58条阶段三详写概念。其中状态随事件变化的概念采用EJS状态变体（按锚点状态只渲染当前适用变体），其余保持静态。
- 世界书260条；事件完整详情注入当前锚点及前后各1个事件，事件摘要覆盖前后各3个事件，常驻衔接钩子只按锚点状态提供可接续信息。
- UID1常驻调度是事件全文唯一运行时来源；UID300至363（阶段一二与阶段三素材）保留为构建素材但统一禁用，避免事件名称绿灯形成第二份正文。
- 概念/人物采用事件详情±1窗口强启或酒馆原生关键词绿灯；两路始终指向同一世界书UID，同轮只注入一次。
- 全部概念统一包含事实门槛、定义、来源、机制、限制与代价、未知项和禁止外推；静态概念另含事件演进、当前状态与人物关联，状态变体概念把这两项放入按门控事件从新到旧排列、末块兜底的变体块内。事件窗口不会自动兑现原作默认结果。
- 63对常驻事件桥（E01→E02至E63→E64）；完成/变形可正常推进，取消态由正文按局部依赖判断，状态栏不机械推进，E64无推进按钮。
- 初始变量、Schema、开场initvar与状态栏FALLBACK_STATE保持深一致；事件身份迁移只允许单条`replace /事件`。
- 本书为色色风后宫文：女性角色（含左左、小小、爱丽丝）恋爱、吸引与恶堕全面开放，不设幼态/外观限制；固定非恋爱角色维持锁0（血锯、白逸、泰坦头颅、巫神头颅、小宝贝、白夜、渡鸦、黑颅、猪头屠夫、哭泣小丑、黑白小丑、艾雯爵士）。NPC可按人设主动发起亲密与逆推。
- 白小凌为配角NPC，不建人设、不入关系根。爱丽丝隐身不是消散；小丑显化体死亡不等于根治；白夜E63后完全失联；泰坦/巫神/小小驰援在途未抵达；用户私下剧透（欲望母树亲密戏、羽毛笔前世）不写入卡内。

林恩的对白、主动行动、决定、判断、记忆与内心始终由玩家独占；默认走向只供因果推演。

本卡不建立战斗数值、可运算等级成长、技能树、装备栏、库存、货币、经营结算、回合制或日历/天数系统。

## 维护入口

- `创作规划.yaml`：内容边界与连续性决策，修改前先同步。
- `contract.json`：64事件、24人、150概念与局部依赖的结构契约。
- `manifest.json`、`profile.json`：版本、稳定ID、依赖与构建映射。
- `src/worldbook.json`：260条世界书注册表；所有条目双递归保护。
- `src/events/`：E01至E64事件详情素材；构建时嵌入UID1，独立UID300至363不参与运行时扫描。
- `src/characters/`：24人六组件EJS；`候选二次解释/`不进入运行时。
- `src/concepts/`：150条概念正文（静态或EJS状态变体两种形态）。
- `src/prompts/mainline.md`：事件摘要±3、完整详情±1与63对按状态工作的常驻桥。
- `src/initial_variables.json`、`src/scripts/schema.js`、`src/prompts/mvu_*`、`src/ui/status.html`：MVU整链。
- `tools/build.mjs`、`tools/validate.mjs`：构建与离线验收。
- `tools/sync_worldbook_v07.mjs`、`tools/fix_variant_gates.mjs`、`tools/fix_concept_format.mjs`、`tools/merge_deps.mjs` 等：v0.7 迁移与修复脚本（一次性过程记录）。

不要直接编辑`dist/`。修改源码后重新运行`npm run check`。
