# 概念·场景·魂灯营业（事件["E01"]）
- 类别：场景
- 描述：魂灯是血锯药剂店的招牌灯具与庇护机制，以鲜血为燃料、燃烧时发出凄厉惨叫。规则上：魂灯亮起时庇护宅基地，怪物须受邀才可入内；白天可点燃，夜晚熄灭后庇护失效，无法拒绝怪物入店。E01中林恩在老师血锯狂人外出时接手续店，挂起魂灯、点燃猩红火苗完成开业并获系统奖励，确立"魂灯庇护+交易（有钱给钱/没钱等价交换）+进门就得看病"的生存与接诊规则，为E02-E04各路来客铺垫。安全边界：魂灯只决定店内容纳与驱逐的边界，不附加额外驱逐或无敌效果；玩家接诊顺序由自己决定，系统只报告店内状态与当日待办。
- 关联：血锯药剂店、任务系统、血锯狂人、E02/E03/E04来客
