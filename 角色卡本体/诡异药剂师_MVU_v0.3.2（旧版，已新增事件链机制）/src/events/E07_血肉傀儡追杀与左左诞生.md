# E07·血肉傀儡追杀、小宝贝支援与左左诞生

- 阶段：S3·魔人协会冲突期
- 地点：血锯药剂店、游魂巷及追逐经过的相邻区域
- 前置条件：E06形成结果；魔人协会或相关敌对方掌握足以发起追踪的信息；左左尚未诞生。
- 参与者与动机：三型血肉傀儡"地狱行者"执行追杀，目标优先级异常执着于林恩；小宝贝根据照看关系保护栖身处并可能用巨型舌头支援；大量血肉增生药剂造成林恩身体与左手变异，左手变异体由致命威胁转为能够谈判的独立共生意志（左左诞生）。
- 默认走向：血夜推进，追杀逼近药店；小宝贝载林恩返回战场、舔舐腐蚀触手救出被吞噬过半的血衣恶灵；林恩使用血肉增生药剂后出现多重变异（触手、竖眼、脑蛇），左左诞生并与林恩谈判共存。
- 紧迫度：高。
- 幕后停止点：林恩缺席时，追杀停在药店或主要角色仍可获救的危机节点；左左不在没有林恩参与的情况下自动完成诞生。
- 变形条件：追杀来源改变、药店已转移、小宝贝疏离、林恩用其他方式处理危机、左左以不同但合理的医疗或药剂事故诞生。
- 结果影响：按实际接触解锁左左，记录共存条件与后续蜕皮休眠；确认小宝贝能提供巨型舌头支援，并更新药店安全、魔人协会情报与E08条件。
- 系统提示：报告高紧迫度、逼近路线、可确认参与者和模糊到达期限，不替林恩选择药剂或行动。
