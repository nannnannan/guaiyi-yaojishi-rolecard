# E10·噬心魔出击与魔人协会覆灭

- 阶段：S3·魔人协会冲突期
- 地点：魔人协会实际据点、游魂巷或冲突变形后形成的地点
- 前置条件：E09已形成结果；魔人协会仍存在指挥核心或残余冲突；噬心魔能够出击。
- 参与者与动机：噬心魔亲自出击维持协会；小小、泰坦头颅与巫神头颅保护家人与已建立的医生关系；024等情报人物选择去向；林恩可利用视界和既有情报介入。
- 默认走向：噬心魔遭三名猎头者围堵（猎神者傀儡被撕裂分食），林恩可骑乘小小前往倒吊塔，以随机诊断术或明确诊断方案改变关键节点；协会大本营失去组织能力，噬心魔死亡后大脑样本可被回收；协会覆灭、残部流亡。
- 紧迫度：极高。
- 幕后停止点：林恩缺席时，猎头者家族可以推进围堵，协会结构可以崩溃，但噬心魔的最终结果与主要角色不可逆结果停在可通知危机；不得凭"噬心"名称自动改写内心。
- 变形条件：协会已提前解体、噬心魔改变目标、林恩与协会达成新结构、进攻力量被解除或关键因果不存在。
- 结果影响：记录协会为覆灭、残部流亡、变形或取消，结算024、械魔、噬心魔与居民处境，开放S4家庭事件预兆。
- 系统提示：报告冲突中心、组织状态、参与者范围、极高紧迫度和可能收束窗口。

## 下一事件引入（E11·猎头者家庭记忆与契约）
- 触发时机：E10形成结果后，或猎头者家族进入家庭事件时
- 剧情引子：倒吊塔的废墟还在冒烟，小小却不肯走，用触手卷着林恩的袖子，眼睛亮晶晶地看着他。远处，两个巨大的头颅缓缓靠近——小小的父母第一次正眼打量这个骑过他们女儿的医生。泰坦头颅的眼中没有杀意，只有审视；巫神头颅的触手已经在掏录音笔了。
- 预兆写法：写小小不肯走、父母头颅靠近与审视的目光；不写逼婚与契约细节，把E11写入近期预兆。
- 承接因果：协会覆灭让猎头者家族与林恩的因果浮出水面，家庭记忆与契约线就此展开。
