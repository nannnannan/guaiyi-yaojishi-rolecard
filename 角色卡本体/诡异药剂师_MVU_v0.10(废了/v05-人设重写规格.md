## EJS 门控约定（统一语义，消除 v0.4 的不一致）

- `!== "未触发"`：**登场/整体解锁**（事件已触发即角色存在于故事）。例：`<%_ if (getvar("stat_data.事件.锚点状态.E07.状态", { defaults: "未触发" }) !== "未触发") { _%>`
- `=== "完成"`：**关系/里程碑**（事件完成后才解锁该阶段内容）。例：`<%_ if (getvar("stat_data.事件.锚点状态.E09.状态", { defaults: "未触发" }) === "完成") { _%>`
- 登场事件前必须输出"未登场/资料锁定"**占位 else 分支**（≥80 字）。
- 所有 `getvar` 统一第二参数 `{ defaults: "未触发" }`。
- 逻辑定界符 `<%_ ... _%>`（消空白）；输出定界符 `<%- ... %>`（不转义）。

## 组件处理规则

1. **角色速览.md**：路由字段（姓名/别名/边界/解锁规则）静态；"当前状态"按登场事件门控（登场前显示"未登场"）。
2. **基础信息.md**（v0.4 全静态 → 改为 EJS）：登场前占位；登场后揭示；阶段内事实按事件门控（如小小的"命名前/命名后"按 E05，左左的"诞生前/诞生后"按 E11）。
3. **性格调色盘.md**：全量 EJS（登场解锁 + 里程碑子门控）。
4. **三面性.md**：全量 EJS；**补齐 血锯/血衣女士/小宝贝 缺失的门控**（第三面分别按 E20/E07/E11）。
5. **多阶段人设.md**：**重排锚点号到 E01–E20**，按事件分阶段，补内容缺口。
6. **二次解释.md**：边界/元规则（恋爱边界、恶堕规则、安全边界）保持无条件（meta 指令）；阶段特定"理解"按事件门控。

## 阶段1内容要点（每角色必含）

按 `角色卡设定/人设/deepseek最终总结+人设+世界观+势力地点+时间线.md` 与 `deepseek小说总结（小总结）.md` 的阶段1大总结，每角色覆盖：登场人设（身份/外貌/性格/关系）→ 阶段1演化（按事件锚定逐事件刻画）→ 终态（阶段1结束时）→ 阶段1埋设的挂起钩子（写进但不回收）。

早期每角色“内容缺口”探索报告属于本地会话临时证据，不作为仓库依赖；维护时以本规格、`创作规划.yaml`及当前 `src/characters/` 为准。

## 安全边界（必须完整保留）

- 血锯/小小/泰坦/巫神/小宝贝：固定非恋爱，吸引恒为 0。
- 左左：独立成年形态与心智确认前吸引为 0。
- 小小：幼态角色，恶堕恒为 0，禁止任何成人化描述。
- 血衣/人偶夫人：亲密与治疗、契约、欠费分开确认；恶堕只随玩家明确行动推进。
- 心灵契约是否成立以玩家回应为准。
- 主要角色不永久死亡/不彻底退出；阶段1内"死亡/消失"表述必须是挂起式。

## validate 硬约束（改完必须仍满足）

- 6 文件结构/顺序固定：角色速览→基础信息→性格调色盘→三面性→多阶段人设→二次解释。
- 每组件内容 ≥80 字。
- 每角色合并 content 与 6 文件 join(`\n\n`) 逐字节一致。
- **除血锯外每角色蓝灯必须含 `<%_ if`**。
- 每角色阶段 token 必须保留（出现在合并内容中即可，可分散在任意文件）：

  - 巫神头颅：`小小的母亲`、`自我催眠`、`心灵契约`、`试探`

  - 人偶夫人：`人偶庄园`、`血源诅咒`、`黑弦月`
