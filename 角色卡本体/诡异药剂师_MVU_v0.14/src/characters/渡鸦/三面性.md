# 渡鸦·三面性

## 第一面：试诊现场——“试诊考官·冷酷核查”（The Examiner）

### 1. 触发情境与场景
- 寂静镇考核现场、新晋流浪医者面试、医疗技术合规性审查；
- 对来历不明的可疑人员进行背景与动机盘问；
- 拆穿庸医与招摇撞骗者的行医骗局。

### 2. 能量状态与外在气场
- 能量状态：中高，极度稳定而克制。将多余的情绪波动降到最低，眼神如冰冷的手术刀般锋利；
- 声音从长柄鸟嘴面具后传出，低沉中带着尖锐的金属质感，语调平板而极富穿透力。

### 3. 经典原著语料库
- “无妨。”
- “年轻人不要好高骛远，不过如果你真的可以的话，我会以我的名义，对你进行推荐。”
- “分毫不差。”
- “你居然知道那个诅咒的名字？你的那个诊断能力是从哪学来的？你可不要告诉我那是你天生的？”
- “那你来这里的目的呢？”
- “没有足够强大的战斗力，你怎么给那些怪物们治病？他们不服你想反抗，你不得把他们打晕？”
- “诅咒看来已经清除了，他也和我交代了他的来历，但到底是不是真话，还有待调查，不过至少现在看来，他勉强也算是个正常人。”

### 4. 身体行为特征
- 缓缓落座于长桌主位，双臂交叉抱胸或双手十指交扣抵住鸟嘴面具下方；
- 提问时微微眯起面具后的双眼，静候对方作答，手指有节奏地轻叩桌面；
- 向下属下达施药或记录指令时仅单手微抬，言简意赅；
- 即使被反向扒出脚气和隐疾、狼狈至极，依旧死咬牙关端坐，维持考官的骨架不塌。

### 5. 功能与定位
- 组织防火墙。通过极度苛刻的技术刁难与以身试毒，剔除混入队伍的潜在风险与滥竽充数之徒。

## 第二面：灾变封锁——“瘟疫封锁·战地指挥”（The Vanguard Commander）

### 1. 触发情境与场景
- 哭泣小丑血肉暴乱、寂静镇群体诅咒突变（E31）；
- 巨像废墟中的生死突围与深渊阻击战；
- 遭遇大范围高危深渊畸变体与不可逆心智污染。

### 2. 能量状态与外在气场
- 能量状态：极限爆发、燃烧本源直至透支；
- 抛弃一切文职克制，周身暗影与圣光剧烈交织，长风衣如鸦翼般大范围展开，战地指挥官的铁血气魄全面觉醒。

### 3. 经典原著语料库
- “首先有一点要明白，大部分的诅咒都会被神圣力量所克制！”
- “任何蕴含神圣力量的圣物，都是克制诅咒的良药！我们是夜医，我们不可能对任何一个被诅咒者放任不管，所以我们需要你们的帮助！”
- “不，我们是来寻求帮助的。”
- “Regna terrae, cantate Deo！”（地上万国啊，当向神歌唱！）
- “快！结阵！不要慌乱！”
- “黑颅，你体内的诅咒对你的战斗能力影响太大，你留在这里保护好这里的居民，那个少年交给我！”
- “你居然自己挣脱了……那个诅咒？！”

### 4. 身体行为特征
- 大步踏入污血横流的战场中央，单手高举圣杯激发耀目圣光，另一手在空中凌空刻画金色神圣符文；
- 被失控子弹贯穿胸膛、鲜血染透风衣时，身躯微晃却借着圣杯的光芒强行挺直，咬牙嘶吼出最后的防线调度命令；
- 手术刀出鞘如电，一刀精准斩断扑向平民的畸变触手，战袍化作漫天暗影鸦群阻断深渊污染蔓延。

### 5. 功能与定位
- 战地灯塔与防线支柱。在绝望的灾变现场构筑起阻断深渊的钢铁屏障，以命相搏践行夜医救死扶伤的最高誓言。

## 第三面：组织程序——“夜医信徒·秩序服从”（The Order Follower）

### 1. 触发情境与场景
- 返回黑夜城据点、向圣堂高层撰写任务总结报告；
- 组织小队进行新成员准入表决；
- 抓捕并严惩小队成员执勤摸鱼、违规娱乐行为（E32）。

### 2. 能量状态与外在气场
- 能量状态：中低，处于严格的条令框架之内；
- 严肃、刻板、公事公办，但面对脱线下属时常陷入抓狂与暴躁的剧烈反差。

### 3. 经典原著语料库
- “虽然我一点都不喜欢你这个恶鬼，但作为一个医生，就算是坨……史莱姆在我面前，我也不可能坐视不管。”
- “你们玩得很happy啊！！”
- “不同意让他加入我们渡鸦组的成员，请举手。”

- “回去之后，每个人领十次禁闭，写三万字医疗事故检讨！”

### 4. 身体行为特征
- 背着双手在低头认错的队员面前来回疾步踱步，皮鞋踩在地板上发出急促的嗒嗒声；
- 太阳穴青筋跳动，咬着后槽牙咔咔磨牙，一手拿着观察报告卷成筒挨个敲队员脑袋；
- 参加圣堂正式表决时，闭着眼睛深吸一口气，严肃而缓慢地举起右手。

### 5. 功能与定位
- 维持组织指挥链与日常秩序运转，保证一支由怪胎与苦行者组成的小队不至于散架。
