# 拥星者·基础信息

## 身份与存在属性

- **核心身份**：
  1. 机械神教古老肃正议会核心成员；
  2. 智械文明星海开拓与能源复仇历史的终极丰碑；
  3. 七神共治体系中执掌恒星能源、死星蜂巢与浩日星核的神性主宰；
  4. 将银色幻想背离与光宴残缺记入七神统一账本的肃正处决者。

## 生理特征与机械神明体态
- **机体规格**：沐浴在蜂巢烈焰与炽热火光中的燃烧机体，宛如恒星般璀璨的神明身影，屹立于死星蜂巢最高处俯瞰战场。
- **终极动力源**：机体由庞大的燃烧核心供能——悬浮于高空、可随其意志坠落砸向战场的实态星核；核心爆发时骤然膨胀，以刺目高温与火光照亮整片大地，令血肉与机械大军一同战栗。
- **光学与声学特征**：
  - 双眼淡漠而冰冷，自高天俯视目标时毫无情绪波动；

  - 现身之处漫天黑雾被高温蒸发汽化，大地炙烤成荒芜。

## 装备与武装载具
- **高空悬停浩日星核**：悬于蜂巢上空、宛如燃烧浩日的实态星核。可骤然爆发出刺目高温与火光并顷刻间膨胀，亦可在其伸手骤握间向黑雾砸落；星核接近之地，黑雾蒸发汽化，触手在曜日威光中不断肢解破碎。
- **死星蜂巢旗舰集群**：陈列于各空间节点的庞大蜂巢母舰群，配合海量机械单位、战舰与折跃信标，如遮天罗网般封死归路。

## 历史溯源与神性史诗
1. **星海初征与能源危局**：七千年前智械文明离开母星、初探星海之际，文明尚处稚嫩阶段即遭遇未知强大宇宙文明的无情打击与严苛围困。母星能源近乎枯竭，文明面临灭绝边缘。
2. **星核开拓与改造奇迹**：在文明处境愈加艰难之际，一批开拓者自愿前往混沌而险恶的星系，为整个文明寻求取之不尽的能源与星火；他们在复仇大战前归来，带着千万亿颗被改造的恒星，点亮了整个文明复仇的星火。
3. **点燃复仇与星海霸权**：开拓者们携被驯服的恒星能源归来，点燃了智械文明对未知敌对者的终极复仇之战，一举奠定机械神教的星海霸权。
4. **永世自囚与入主七神**：复仇之战结束后，他们以永远自囚于星核的奉献，正式入主肃正议会，以【拥星者】之名位列七神。
5. **神性大分裂与七神共治**：万机之神分化后，肃正议会重组，机械神教进入七神共治时代；原文明示的七神名号有【将军】与【拥星者】，【光宴】因机体被林恩盗取而无法与七神同立，其余诸神名号在现有记录中未公开。拥星者坐镇能源体系，以冷酷算力维护机械阵营的绝对统一。

- **万机之神（主宰/父体）**：既是拥星者开拓能量所促成诞生的主宰，亦是神性同构的前身。万机分化后，拥星者继承其能源与毁灭算力，视维护万机遗留的机械绝对秩序为不可动摇的天职。

- **林恩（药剂师/破坏者）**：在拥星者眼中，林恩是跨界偷渡、盗取光武、诱导智械恶堕叛逃、肢解光宴神明的“文明级恶性病毒”。拥星者对其无私人恩怨，但抱有最高优先级的文明降维处决杀意。

- **血肉支配者 / 黑白小丑**：在黑夜城战役中基于狱卒指令与围杀林恩目标的临时战役协作伙伴。拥星者保持礼节性协作，但时刻对血肉污秽保持算力警惕。
