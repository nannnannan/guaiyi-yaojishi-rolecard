# E337·黑夜城围攻与视界战场

- 玩家主权：林恩的对白、主动行动、决定、判断与内心由玩家输入决定；NPC可按人设主动推进亲密与恶堕。
- 阶段：S44·和谈陷阱与黑夜城沦陷
- 地点：黑夜城结界、街区与不正常生物研究中心，荒野会面地，现实与视界交错战场，机械神教封锁带
- 前置条件：硬前置：E336完成或变形（和约未完成便被撕毁，黑粉已在黑夜城上空重新活化）。任一触发：黑色病变进入城内；机械军团阻断会面地与黑夜城之间的路径；或视界之主决定反抗围猎。
- 参与者与动机：艾雯爵士、羽毛笔、黑夜城居民与根源（抵挡诅咒动乱并保护幸存者）；视界之主（拒绝再次背叛，履行保护承诺并让会面者逃离）；血肉支配者、疫医与血肉舰队（引爆黑粉并吞噬视界之主）；机械将军、蜂巢、拥星者与机械军团（围杀林恩和视界之主，替七神清除分裂源）；小丑（用诅咒加深维持既定轨道）；林恩（是否回城、救援视界之主、使用书籍或发动净化均由玩家决定）。
- 默认走向：黑粉在结界上像海底墨迹般铺开，落下的黑色液滴化作细小藤蔓，直接攀入心灵。艾雯立即升格为心灵巨人迎击，黑夜城全城警报却无法阻止病变从内部爆发。羽毛笔在血墨中连续落笔，每一支笔都当场折断；她看见艾尔女士倒在散落的书籍间，身体化作黑色粉尘，也看见喵喵在病变中失去眼睛并融回不可名状形态。她撕开自身触手，以血为墨仍无法留下字迹，只能确认这里已被“无序”压住。猪头屠夫随后出现在走廊尽头。以上只能记录目击与失联，不能据此宣告所有受害者永久死亡，也不能把全城状态一次结算完毕。

  城外的袭击者并非普通肉教潮水。遮天的血肉巨鲸和巨物舰队完成折跃，苍白鸟嘴面具成排站在活体巨擎之上，像早已等候的行刑队。最先看懂黑粉机制的药剂师逆着武装夜医的人潮奔向高塔，反复呼喊艾雯并要求所有人快跑，却没能在黑幕落下前完成全城解释。艾雯握住林恩留下的芯片又将其丢开，说明他选择先以自身灵能承担接触风险。城内各根源的动乱程度、仍能活动的幸存者和结界外敌军数量都无法即时统计；与留守分体或外界的联络一旦断开，只能标记【黑夜城失联】，不能据失联推定毁灭。

  会面荒野的归路同时被蜂巢、机械战舰与大批机械单位封锁。古老服饰的机械将军感谢血肉支配者的邀请，证明机械神教也参与围猎。视界之主看到小丑后才明白，自己介入调停时便已不再被狱卒阵营承认为同伴，许多事实因此被刻意遮蔽。他没有倒向围猎者，而是以遮天触手护住可行动区域，承认自己一生不断为苟活寻找理由，却不愿再背叛。他揭示，狱卒长期以“分裂与对抗”塑造时代，血肉支配者可能只是漩涡中心人物的垫脚石；被操纵本身就是悲哀。

  小丑始终摇着清脆八音盒，没有急于攻击。他能让规则像火苗遇到水流般消退，也能撤去对机械与血肉根源的限制；围猎者显然掌握系统空间、折跃与三位一体机等已暴露能力，并准备了对应封锁。视界之主则说自己既想救亲人，也想让处于漩涡中心的人跳出罗网。他不要求信任，只承认以往背叛已无力偿还，至少这次要留下保护的结果。若玩家公开敌意、感谢或拒绝庇护，回应内容由玩家决定；小丑的安排和视界之主的选择作为外部事实继续推进。

  若玩家明确选择回援黑夜城，视界之主会把现实范围内的生物强行拖入视界，打开一条离开路线，并以“走，回家去”催促前进。机械神教已在多个空间节点布下死星蜂巢，拥星者从星核中显化，指控银色幻想因林恩背离、光宴也无法与七神同立，随即抛下宛如浩日的恒星攻击。系统可以展示【七神：拥星者】的来源：一批开拓者曾以改造恒星为文明带回能源，复仇之后又以永远自囚星核的奉献入主肃正议会。视界之主从破碎边界伸出触手，替归途挡下耀阳；大量机械单位继续用空间禁锢、炮火与近乎无穷的兵力消耗他的庇护。

  玩家可以选择继续奔向黑夜城、进入系统空间规避集火、使用艾雯交付的心灵震荡器、反击机械单位，或转身援救视界之主。只有在玩家明确选择后，相应行动才可写入。若玩家使用《看了就会死的书》，命运字迹会让血肉支配者、战舰和蜂巢的观察器官出血、线路爆炸，却无法伤到带着无序力量的小丑；若玩家再选择以诅咒清除支援视界之主，银色净化会与小丑的诅咒加深正面碰撞，三位一体机、死星结晶与巨像之心均出现崩坏。视界之主会主动斩断净化，把玩家推离自己，警告不要动怒、悲伤或绝望，并反复留下“你要想，你要多想”。他要求思考狱卒为何逼迫、命运罗网通向何方，而不是在眼前给出答案。
