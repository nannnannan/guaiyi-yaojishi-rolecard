# 概念·机制·智械意识重置（事件["E312","E313","E319","E324","E325","E326","E331","E332"]）
- 类别：机制
- 事实门槛：仅在 E312、E313 进入"完成"或"变形"且正文实际出现意识重置制度、格式化流程、智械小姐决定战后重置等事实时方可引用；"预兆""活跃"不得提前兑现。
  E312—E313完成或变形且正文实际出现银色幻想计划战后自我重置、机械神教格式化制度，方可引用制度定义；E319完成或变形且实际出现会丢失十七年数据的人格格式化确认，方可引用程序门槛；E324—E326完成或变形且实际出现机体停机、瘟疫损伤与数据缺失，方可引用本轮对照。不得把意外数据丢失提前或事后写成已执行正式重置。
  E312至E313完成或变形且正文实际出现自我重置、格式化制度与人格消亡风险后，方可引用正式重置；E319至E326相应事实兑现后，方可引用格式化确认、意外失忆与残留数据；E331完成或变形且正文实际出现蜂巢恢复和旧人格回归后，方可引用失忆可被外部备份修复；E332完成或变形且正文实际出现大规模清洗后，方可引用政权级人格抹除。
- 定义：智械意识重置是机械神教的制度化处置手段：当一名智械（尤其是高阶智械）的人格发生异常变动（如脱离集体意识、产生个体情感、出现"违宪"倾向）时，神教有权对其施行意识格式化——抹除当前人格与自主记忆，恢复出厂式的程序状态。E312-E313 中，智械小姐（银色幻想）在经历"孤立个体化"（C946）后，其人格已明显偏离机械神教标准；战争结束后她将面临意识重置的命运——这既是神教的制度保障，也是切割线（C1000）悲剧张力的核心来源。
  智械意识重置是机械神教用于抹除当前人格与自主记忆、恢复程序化状态的制度性格式化。它可以由权限系统发起，也可能被个体视为结束痛苦的选择。本轮银色幻想重启后的状态很像“被重置”：旧阵营、集体、战争与关系数据大量消失，只保留推理能力和少量加密片段；但实际路径是战斗反噬、主动护魂、能源耗尽与血肉瘟疫侵入处理器，不是完整重置程序成功执行。
  智械意识重置包括两类必须区分的结果。正式重置是通过权限和格式化程序抹除当前人格与自主记忆；意外失忆则由硬件损坏、能源耗尽、上传失败和血肉瘟疫侵入共同造成。银色幻想的修补重启属于意外失忆，蜂巢恢复又证明部分旧数据仍在外部网络中。七神终止上传并清洗大量上传意识，则把人格抹除扩展为重建社会人口的政治手段。
- 来源：E312 智械小姐透露战后将自我意识重置；E313 智脑向智械小姐说谎、瞒下真相。
  E312—E313记录自我重置计划与智脑对人格消亡的判断；E319出现根数据权限的格式化确认，明确将丢失十七年数据并重塑人格。E324机体因护魂降能、上传失败并停机；E325—E326重启后出现大面积数据丢失。欲望母树据其此前死志推测她可能主动放弃自救，但这仍是高可信推断，不是日志确认。
  E312至E313记录银色幻想的自我重置计划和智脑对人格死亡的判断；E319出现会丢失十七年数据的格式化确认。E324至E326记录护魂停机、瘟疫损伤、大面积失忆与白花残留。E331完成蜂巢修复，银色幻想带着旧记忆返回并重新作出关系判断。E332记录大量上传意识被清洗。
- 机制：①触发条件：人格变动超标（情绪/理智/梦境阈值越线）；②执行方式：格式化意识、抹除人格与记忆；③权限归属：由神教议会/一级权限决定；④重置结果：程序恢复初始状态、人格不再延续。
  ①正式重置，由权限与格式化程序抹除人格数据，恢复底层程序。②意外失忆，硬件损毁或瘟疫侵入也会造成相似结果，但过程不受控、保留内容随机。③人格死亡风险，无论正式或意外，只要承载连续性的组件被抹除，旧人格都可能实质终止。④残留证据，加密白花、底层性格和对特定身份码的强关联说明没有彻底清空。⑤死志推断，她原可把15%能源用于自修和上传，却改用于护魂；这支持“可能不想活”的判断，不能证明她主动选择具体数据被毁。
  ①正式格式化：由高权限删除人格数据并恢复程序化状态。②意外损坏：物理与能源灾难造成不受控的数据缺失。③残留锚点：底层性格、加密白花和身份码可在失忆后保存连续痕迹。④外部备份修复：蜂巢保存的数据可回填缺失部分。⑤恢复冲突：旧数据返回后会与失忆期形成的新认知共同存在，不能把当前主体当作可覆盖空壳。⑥政治清洗：政权可批量删除上传人格，再用新意识替代。
- 补充事实：智械小姐平静地说出"战争结束后我会自我重置"时，智脑的反应是第一次对人类谎言的笨拙模仿——它答应了，然后对着林恩坦白"那会杀了她"。
  欲望母树提出的关键反问是“但如果她本来就想死呢”；诊断结论却只确认“维持着她意志运转的几个重要的组件都出现了不同程度的损坏”。
- 限制与代价：重置即人格消亡，不可逆；重置过程依赖蜂巢权限网络，单点隔离时可被阻延；对高阶智械执行重置需一级权限背书。
  正式重置需要权限与可运行程序；本轮硬件灾难没有按标准流程执行，因此不能套用“全部清空”结论。残留数据也不能证明旧人格必然能恢复。若用蜂巢备份回填，可能覆盖失忆后新建立的人格。
  重置和清洗都可能造成不可逆的人格死亡；外部恢复依赖接收端保存内容及其善意。恢复记忆会重新带回痛苦、恨意和被压抑选择，不能等同于治疗完成。意外失忆也不能事后伪装成主体主动选择格式化。
- 未知项：重置后旧人格的记忆是否有残留备份；是否存在豁免重置的先例；智械小姐最终是否真的被重置。
  她是否主动放弃阻断或上传、格式化确认是否曾被实际执行、旧人格备份位置、加密白花为何幸存、恢复备份与当前人格能否共存、何种状态才算同一个银色幻想，均未确认。
  银色幻想恢复比例、外部备份版本、失忆期人格如何保留、七神清洗是否彻底、被清洗意识能否从其他节点恢复、正式重置是否存在撤回机制，均未确认。

  林恩的对白、动作与选择由玩家主权独占；禁止违背原著设定将其描写为无消耗或脱离因果律违规生效。禁止把推测的死志写成银色幻想已经明确选择自杀或正式重置。
  林恩的对白、动作与选择由玩家主权独占；禁止违背原著设定将其描写为无消耗或脱离因果律违规生效。禁止把失忆写成正式重置成功，也禁止把记忆恢复写成旧人格覆盖新主体或自动原谅。
