# 概念·能力·自然神性驾驭力（事件["E316","E318","E320","E324","E328","E333"]）
- 类别：能力
- 事实门槛：仅在 E316 进入"完成"或"变形"且正文实际出现母树臣服、自然神性驾驭力+20%、面板结算等事实时方可引用；"预兆""活跃"不得提前兑现。
  E316完成或变形且正文实际出现自然神性驾驭力加成后，方可引用基础能力；E318至E320只在正文明确写出对应性行为、角色当下反应和随后神性或病变变化时，才引用性行为解咒带来的神性结果；E324完成或变形且自然之泉实际出现后，方可引用物质载体；E328完成或变形且正文实际出现感官共享、根系视角和自然神性反馈后，方可引用当前应用；E333只确认强制冲突后的服从值、两小时内容无人知晓、之后树体葱郁和红花开放，以及母树为界门供能，不得据此新增解咒或亲密养护结算。
- 定义：自然神性驾驭力是 E316 成就【欲望母树的堕落】（C1004）结算新增的永久属性：以欲望母树（C941）臣服为契机的 +20% 永久加成，代表林恩对"自然女神一系"神性权柄的驾驭能力指标。作为新增数值面，它既非传统战力的直接增幅，也非单纯的声望值——它是"驾驭自然神性"这条专属权柄线的量化刻度，暗示自然女神系存在更高的权柄应用（背后的神系与本源未明）。
  自然神性驾驭力表示林恩与欲望母树自然神性之间建立的适配接口。它能够在双方实际开放时延伸感官、短时操作既有根系，并在正文明确写出养护或性行为及随后反馈时获得自然神性结果。它不是完整自然权柄，也不允许凭空创造植物、永久控制母树或无条件调用根源力量。E333只显示树体在未知两小时之后变得葱郁并开满红花，母树随后为迁移界门提供力量；两项事实不能证明开花由性行为、解咒或服从值导致。
- 来源：E316 成就结算：永久自然神性驾驭力+20%；母树契约（C1006）确立。
  E316记录永久加成；E318至E320按正文实际写出的水潭、灵魂交融和神性反馈记录；E324记录自然之泉；E328记录感官扩展至地下数百公里、横向上千公里的根网。E333只确认强制冲突后的服从值、两小时具体内容无人知晓、之后树体状态变化，以及母树与艾雯共同为界门供能。
- 机制：①获取途径：母树臣服成就结算；②数值：+20%（永久）；③属性定位：自然女神系驾驭权柄指标；④关联数值：与驯化度（+20）、全属性（+10）同批结算；⑤使用方向：驾驭自然神性权柄（具体应用未全面展开）。
  ①适配增长：系统结算提高对自然神性的承载与操作。②灵魂接口：双方开放时思想、感官和身体反馈交汇。③根系视角：沿既有根网观察地层、矿脉、地下社会和远端对象。④短时操作：可在母树授权范围内调用根系或力量。⑤解咒反馈：玩家推进并且正文写出对应性行为、角色当下反应和后续变化时，才登记神性或解咒反馈；强制冲突、角色拒绝或未知片段只保留原状。⑥协同供能：母树自然力量可以注入大型界门。⑦状态隔离：服从值、树体葱郁和红花开放分别记录，不互相证明因果。
- 补充事实：面板上这条属性亮起时，林恩盯着看了两秒——前边全是力、敏、智、精这种看腻了的字眼，突然冒出个"自然神性驾驭力"，他只觉得这面板越来越像一本正经的胡说八道。
- 限制与代价：当前仅作能力指标，具体权柄应用尚待开发；过度依赖可能引动自然系神性的不可知回响；与母树的限约条款（C1006）绑定。
  权限共享需要母树实际开放，并会暴露双方感官与思想。自然神性反馈来自母树真实损耗或养护结果，不是无源奖励。开花还可能携带欲孽花粉并造成城市风险。根系视角不能看见不存在或超出根网的信息。
- 未知项：+20% 的上限与后续成长途径；自然神性驾驭力的实际应用场景（治愈/御植/通神？）；自然女神一系的完整神格谱系。
  驾驭力上限、数值换算、能否只读不控、界门供能效率、自然之泉与能力增长关系、开花和结果的关系、离开地狱后的完整权能及母树撤回权限的方法，均未确认。
- 禁止外推：林恩的对白、动作与选择由玩家主权独占；禁止违背原著设定将其描写为无消耗或脱离因果律违规生效。
  林恩的对白、动作与选择由玩家主权独占；禁止违背原著设定将其描写为无消耗或脱离因果律违规生效。禁止补写未知两小时内容，禁止把服从值或开花改写成亲密、解咒或神性结算证明，也不得用它们抹掉强制冲突和未知两小时；临时接口不等于永久控制。
