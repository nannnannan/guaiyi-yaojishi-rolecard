# 概念·势力计划·血肉神教旧日计划（事件["E271"]）

- 类别：势力计划；血肉支配者殖装旧神血肉制造克苏鲁子嗣的计划。
- 事实门槛：仅在对应事件（E271）进入"完成"或"变形"且正文出现该事实时方可引用；"预兆""活跃"不得提前兑现。
- 定义：血肉神教旧日计划是血肉神教（以血肉支配者为核心的邪教势力）的核心野心：将"旧神血肉"——来自旧日神明（克苏鲁）残骸或本体的血肉——殖装到血肉支配者身上，从而"制造克苏鲁的子嗣"。这个计划把血肉神教的信仰从"支配血肉"升级为"孕育神明"：血肉支配者不再满足于操控普通血肉，而是试图以旧神血肉为原料，在自己的身体上殖装出足以承载旧日血脉的结构，使自身或自身体内诞生出克苏鲁的后代——一个拥有旧日神性的新存在。计划一旦成功，意味着旧日血脉将获得一个新的人间容器与延续通道，其威胁远超普通污染扩散。计划涉及旧神血肉的获取、殖装手术、以及"子嗣"的孕育培育三个环节，每一步都伴随巨大的污染与堕化风险，也使其成为多方势力眼中的致命威胁。
- 来源：E271血肉支配者殖装旧神血肉、意图制造克苏鲁子嗣的计划揭露。
- 机制：①获取：收集旧神血肉（克苏鲁残骸/本体组织）；②殖装：将旧神血肉殖装到血肉支配者身体；③融合：血肉支配者本体与旧神血肉融合，向旧日血脉倾斜；④孕育：在殖装基础上培育"克苏鲁子嗣"——携带旧日神性的新存在；⑤扩散：子嗣/殖装体成为旧日意志的新人间通道；⑥威胁面：计划成功将重塑旧日阵营的延续能力。
- 补充事实：血肉神教相信，子嗣不需要长大——它只需要"被生出来"，旧日的意志就能借它重新开口说话。
- 限制与代价：旧神血肉获取极难且携带致命污染；殖装手术失败率与反噬率极高；计划过程会招致圣域、夜医、隐修会等多方围剿；子嗣的诞生可能连计划者自己都无法控制。
- 未知项：旧神血肉的具体来源、子嗣是否具备完整旧日神性、计划是否存在替代方案均未知。
