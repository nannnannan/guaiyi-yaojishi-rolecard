# 概念·能力·灵能化形跨界显化（事件["E303","E332"]）
- 类别：能力
- 事实门槛：仅在 E303 进入"完成"或"变形"且正文实际出现灵能跨数据/现实两界穿行、化形显化、附身化形等事实时方可引用；"预兆""活跃"不得提前兑现。
  E303完成或变形且正文实际出现灵能在数据与现实之间穿行、化形或附身后，方可引用跨界显化；只有E332完成或变形且正文实际出现林恩以数据体转化为灵能形式独立存在、艾雯识别并补充灵能后，方可引用当前扩展。不得把短时稳定写成可长期脱离机体。
- 定义：灵能化形跨界显化是一种绕开蜂巢上传规则的特殊行动方式：灵能作为介于物质与信息之间的特殊能量，可以不受数据世界与现实世界边界的常规约束，在两界之间穿行。持此能力者能以灵能凝出实体化的形象（化形显化），使灵能不再是虚无缥缈的能量流，而具备可感知、可交互、可施力的现实形态；亦可将灵能附着于既有物体或躯体（附身化形），借他人之形行走，规避身份识别。相比"意识上传"需要走蜂巢的通道、注册、审核全套流程，灵能化形跨界显化等于从侧门翻墙：不经过上传通道，也就不受上传规则的查验与限制。这条路径让灵能者在蜂巢数据世界拥有"无痕入境"的特权，也因不落上传记录而难以被常规追踪；代价是灵能消耗巨大，跨界与显化的每一步都在燃烧持能者的精神力储备。
  灵能化形跨界显化是把数据化意识转成灵能形态，使其在信息与现实之间活动并形成可交互外观的能力。它能绕开部分常规上传流程，也能让失去原躯的意识暂时以灵能承载自我。E332显示林恩当前使用海嗣身体并以灵能形式维持数据体，艾雯能够一眼识别这种存在方式，同时警告他尚未达到长期独立存在的程度。
- 来源：E303 灵能者借灵能穿行数据/现实界隔，化形显化与附身化形绕开上传规则。
  E303记录灵能穿越数据与现实界隔、化形和附身。E332中艾雯确认林恩“把数据体转化为灵能的形式独立存在”，并指出长时间保持会迷失，建议以后改造机体，先以罐装载体承载；他随后为林恩补充灵能，使近乎透明的灵魂重新实质化，感官显著恢复。
- 机制：①凝聚灵能，定位跨界坐标（数据世界或现实世界）；②以灵能形态穿行界隔，避开上传通道；③化形显化：将灵能凝成可交互的实体形象；④或附身化形：附着于既有物体/躯体活动；⑤任务完成后散去灵能形态，或寻机撤离；⑥全程不产生上传记录，无法被常规数据追踪。
  ①数据转灵能：把信息态自我转换为心灵力量承载。②化形显现：灵能形成可被现实感知和交互的形体。③临时独立：没有完整机体时维持意识和行动。④高位补能：成熟灵能飞升者可向同类结构灌注灵能，强化实质感与感官。⑤载体回归：长期稳定仍需要合适机体或容器。⑥迷失风险：灵能耗损和自我边界淡化会让主体逐渐失去方向。
- 补充事实：化形显化的形象通常凝练而短暂——灵能躯体并非血肉，被击中时会像烟雾般散开再重聚，战场上活像打不死的幽灵；蜂巢的战警扫描不到它的数据身份，只能对着"不存在的入侵者"干瞪眼。
- 限制与代价：灵能消耗极大，持续显化或反复跨界会快速透支精神力，甚至导致灵能枯竭；附身对象若被破坏，显化者会连带受创；灵能波动本身可被高阶感知捕获，面对顶尖存在时"无痕"只是相对的。
  当前形态依赖持续灵能储备，耗损后身体会透明、蚀痕加重、感官衰退。补能只能恢复储量，不能证明结构永久稳定。跨界与显化会暴露灵能波动，高位存在仍可感知。林恩当前还不到完全脱离载体的层级。
- 未知项：灵能与数据世界底层协议的关系；跨界显化是否存在距离上限；灵能形态能否被永久固化在数据世界。
  最长稳定时间、迷失的具体表现、罐装机体方案、补能频率、跨界距离、灵能与海嗣身体的兼容性及完全体灵能独立存在需要的条件，均未确认。

  林恩的对白、动作与选择由玩家主权独占；禁止违背原著设定将其描写为无消耗或脱离因果律违规生效。禁止把短时独立写成不死、无载体永续、无损穿界或已经完成灵能飞升。
