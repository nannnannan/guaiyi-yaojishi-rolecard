# 概念·势力·肃正议会机械军团（事件["E286"]）

- 类别：势力；银色幻想所属追剿组织，第一智脑下属003/011/006蜂巢。
- 事实门槛：仅在对应事件（E286）进入"完成"或"变形"且正文出现该事实时方可引用；"预兆""活跃"不得提前兑现。
- 定义：肃正议会机械军团是银色幻想所属的机械侧追剿组织，其职能是对黑暗世界中的威胁目标（尤其血肉神教等异常根源）执行"最终肃清"。组织以"议会"为名义中枢、以"第一智脑"为最高指令源，下方由若干编号蜂巢（003/011/006）构成作战单元——蜂巢是机械军团的基本编制，每一蜂巢由海量机械体组成，可展开工业级战争机器。E286中，第一智脑向银色幻想下达最高指令：目标（欲望母树）处于虚弱状态，要求对欲望教派进行最终肃清，并由003/011/006三大蜂巢协助。肃正议会的作战形态极具工业感：机械人形遍布视野、工业钟鸣响彻、空间被撕裂出庞大缺口、重装机械与黑色舰艇从裂隙涌入、无数机械体的屏幕蓝转红进入战争状态，银色幻想以单分子剑与数字洪流之眼领军。它代表着"机械秩序对异常根源的肃正意志"。
- 来源：E286第一智脑下达最高肃清指令，银色幻想率003/011/006三大蜂巢突入血红大地。
- 机制：①中枢：肃正议会+第一智脑（最高指令源）；②编制：编号蜂巢（003/011/006）为作战单元；③目标：对异常根源执行最终肃清；④指令流：第一智脑下最高指令，蜂巢协助执行；⑤作战形态：机械体集群、裂隙输送、重装舰艇空投；⑥领袖：银色幻想（数字洪流之眼、单分子剑）领军。
- 补充事实：无数机械体的屏幕在命令下达那一刻齐刷刷蓝转红——肃正议会的战争，从来不是某一台机体的事，是整个蜂巢在换血。
- 限制与代价：肃正议会以"肃清"为唯一逻辑，对目标不问缘由只问威胁；蜂巢集群作战的代价是数量庞大、目标显眼；对根源级目标（如欲望母树）未必能速决。
- 未知项：第一智脑的完整身份、肃正议会与机械神教的隶属关系、蜂巢的总数与上限均未知。
- 禁止外推：林恩对白/动作/选择玩家主权独占；不违背原著。
