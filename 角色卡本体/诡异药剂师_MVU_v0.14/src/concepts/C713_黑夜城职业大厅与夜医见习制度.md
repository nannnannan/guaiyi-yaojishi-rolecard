# 概念·地点／制度·黑夜城职业大厅与夜医见习制度（事件["E176"]）

- 类别：地点／制度
- 事实门槛：只有当候选人已获得岗位风险、退出方式、替代安置和非从属边界的说明，并在没有债务、救命压力或监护人代替决定的情况下主动选择登记，才能称其进入夜医见习咨询；一张登记表、一次陪同或一句愿意学习都不等于正式录取、雇佣、宣誓效忠或永久留在黑夜城。尹依的年龄、成熟度、语言能力和完整同意能力尚未核实，因此她当前只能获得正规医疗照护、基础自护与可撤回的见习信息，不能被安排危险临床工作。
- 定义：职业大厅是黑夜城承接职业登记、能力初筛、岗位说明和训练分流的公共节点，见习区则把夜医知识从直接上岗拆成观察、基础学习、患者权利、低风险协助和复核录取。它既是地点，也是对“救过谁便拥有谁”的否定性制度：住宿、翻译、医疗、载体稳定与返乡协助必须和职业选择分开，候选人可以只作情报协作者、短期访学者或受保护来客。大厅不自动代表整个夜医体系符合安全标准，现场暴力反而暴露其需要纠偏的机构缺口。
- 来源：E176确认尹依在知晓风险、自主权和替代安置后可以再次表达咨询意愿；她缺乏系统医疗基础，登记只能从见习评估开始。她在大厅目击夜医以群体暴力阻止病人逃离，并把新增伤势重新标记成治疗结果，这一事实被定性为患者权利与机构问责案例，而不是合格教学。她同时在复盘室整理蓝星南方失踪、献祭和红色鞋履等线索，使职业大厅兼具培训入口与受控情报交接功能；血衣女士仅被列作高可信待核对象，不能以情报价值换取尹依入职。
- 机制：合格流程至少包含身份与年龄核查、翻译支持、能力和创伤评估、课程风险说明、独立退出渠道、低风险观察期、双人带教、事件记录与申诉复核。教学资源可包括药剂基础、非暴力麻醉、分诊、感染隔离、患者拒绝权、跨界对象身份核验和紧急联络，但不得用逃离病人练习控制，也不得让见习者替机构隐瞒伤害。候选人可以选择暂停、拒学、改作住宿与自护课程，或要求第三方见证；机构若无法保证这些条件，登记应冻结而非把沉默当同意。林恩的行动与选择由玩家主权独占。系统不能替他给尹依作职业承诺。
- 限制与代价：职业大厅能集中资源，也会放大等级、信仰和救命关系造成的压力。尹依没有实体载体、正式资格、熟练语言或已确认返乡通道，任何塑形、契约、长期留居和临床暴露都需单独审查；培训人员曾出现暴力医疗，说明内部权威不可作为正确性的唯一证据。见习撤回后仍应保留安全住宿、必要治疗和资料副本，不能以停训为由停止照护、追讨费用或限制行动。
- 未知项：大厅具体管理者、课程长度、考核项目、投诉是否独立、夜医资格能否跨世界承认、尹依最终是否登记、其年龄与载体方案、暴力事件受害者的伤情与追责结果、血衣线索是否进入正式救援流程均未确认。也没有证据证明所有夜医都认可同一套患者权利规范。
- 禁止外推：林恩的对白、动作与选择由玩家主权独占；禁止违背原著设定将其描写为无消耗或脱离因果律违规生效。
