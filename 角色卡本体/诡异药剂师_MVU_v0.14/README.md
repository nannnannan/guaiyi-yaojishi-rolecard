# 《诡异药剂师》MVU v0.14

这是面向 SillyTavern 1.17.0 与酒馆助手 4.9.1 的 `chara_card_v3 / MVU Zod` 内部候选工程。v0.14 独立继承 v0.13，在 E317 后新增 E318—E348 共31个事件（阶段十尾段 S41—S45），世界剧情止于 E348 当前版本封口。

## 内容边界

- 348个事件锚点：E01—E348；新增部分为 E318—E348。
- 46个运行阶段：S0—S45；新增部分为 S41—S45。
- 28名核心人物，每人仍由六个源码组件合并；E318—E348重新出场角色追加 EJS 人设增量；拥星者作为高权重 NPC 六组件接入。
- 世界书源码共1003条：348条禁用事件素材、阶段十概念增量、28名核心人物和1名可选NPC。
- 林恩全链统一18岁。
- 新增原文取材覆盖1351—1452章（阶段十尾段）；E349及以后内容不进入本版。
- E348之后无推进按钮，不创建E349；E348之后的自由、未知来客和后续世界留给玩家推演。
- 阶段十概念增量与新增概念按全局台账登记，阶段十当前卡只接入 E318—E348 所需的 25 个新增逻辑概念。

## 运行原则

- 玩家独占林恩的对白、主动行动、判断、记忆、内心与关系选择。
- 原作事件是默认因果，可由玩家介入、取消或变形。
- 事件素材 UID700—1047 保持禁用，由 UID1 常驻调度按当前锚点±1注入详情、±3展示摘要。
- 概念与人物由事件窗口±1或原生关键词激活，同一UID去重。
- 色色与恶堕全面开放，不设幼态/年龄限制；NPC 可按人设主动亲密与逆推；玩家可拒绝、打断或改写。
- 不建立可运算战斗、经济、库存、经营或日历系统。

## 构建与检查

```powershell
npm install
npm run check
```

生成物：`dist/诡异药剂师_v0.14.json`

`npm run check` 会重新构建并检查版本、348锚点、事件全文、EJS、概念格式、核心角色与拥星者 NPC 路由、MVU深一致、状态栏桥、禁用元数据、UTF-8、产物哈希等。离线通过不等于真实宿主验收；在没有所有者授权和真机证据时，`host_acceptance.json` 保持 `pending`。

## 源码入口

- `src/events/`：E01—E348事件词条。
- `src/concepts/`：世界观、人物、机制、势力、地点与伏笔概念。
- `src/characters/`：28名核心人物六组件与拥星者 NPC 六组件。
- `src/prompts/mainline.md`：事件上下文与常驻衔接。
- `src/initial_variables.json`：新聊天初始MVU状态。
- `src/scripts/schema.js`：MVU Zod约束。
- `src/ui/status.html`：四页状态栏与事件推进界面。
- `contract.json`：机器可校验契约。
