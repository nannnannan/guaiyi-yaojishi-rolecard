# 《诡异药剂师》v0.5

这是面向 SillyTavern 1.17.0 与酒馆助手 4.9.1 的 MVU Zod 角色卡工程。v0.5 以 v0.4 事件链为基础，将 8 名主要角色的六组件人设全部重写为 EJS 分阶段渲染，并扩展 52 条事件概念。概念现采用“当前事件 ±3 窗口 OR 酒馆原生绿灯”双路激活，原生绿灯完全继承宿主 user+AI、扫描深度与递归缓冲规则。开场白正文保持原文，内容范围截至第 1–149 章阶段 1。v1.0 以前仅内部使用，不公开发布；卡按开源标准制作，玩家主权优先。

## 本版内容

- 开场白：小说原文摘抄（第1章至第4章）。开场后E01（系统觉醒与开店）完成、E02（血娃娃上门与找妈妈任务）收尾活跃态、E03未触发；玩家推进后E03（猪头魔）才进入预兆。
- 二十个事件锚点：E01 系统觉醒与开店、E02 血娃娃上门与找妈妈任务、E03 猪头魔与恶灵血婴、E04 猎魔人治疗与传说左轮、E05 不眠夜与小小牙科、E06 诅咒清除能力与鬼婴塑形、E07 血衣寻子与鬼婴萌化化解、E08 暴击药剂与视界曝光、E09 血衣鸿门宴与诅咒绑定、E10 视界经营与玥玥治疗、E11 血夜地狱行者与左左诞生、E12 血肉灾变与左手共存、E13 猎杀者夜袭与信使线、E14 瘦长鬼影手术与024诊断、E15 求援信与小小赴约、E16 械魔大军与猎神者、E17 小小介绍棒医生、E18 倒吊塔决战与协会覆灭、E19 猎头者家族绑定、E20 师徒归来与阶段收束。
- 次要支线并入对应事件（血娃娃找妈妈、血婴母女线、024闭环、人偶庄园诅咒、玥玥去向、秃头群体、左轮诅咒、左左蜕皮），不单独建锚点。
- 八名主要角色：左左、血锯、血衣女士、小小、人偶夫人、泰坦头颅、巫神头颅、小宝贝。
- 每人六个源码组件，按事件状态用EJS条件分段呈现阶段人设。
- 52 条事件概念（势力/场景/物品/特殊设定/能力/诅咒）为静态原生绿灯条目：完整标题与专名别称可从 user 或 AI 最近消息触发；ID 399 的 `@@preprocessing` 路由另按当前锚点 ±3 窗口强制激活同一 UID，两路同时命中只注入一次。
- 六类势力、三套世界机制、五处关键地点。
- 事件衔接常驻化：`src/prompts/mainline.md` 收录19对「下一事件引入」剧情引子（EJS门控：前件完成/变形/取消或活跃且收尾为true、后件未触发/预兆时渲染），配合上下文窗口（当前锚点±3摘要）、详情窗口（当前±1完整详情）与状态栏手动「推进」按钮；只有`活跃`占用活跃槽，`变形`是稳定替代结果的终态。事件身份迁移以单条`replace /事件`原子提交，锚点链就绪时禁止原创来客占位。
- 纯事件驱动时间线：不记录天数、星期或具体日期。
- 系统任务+图鉴轻量版；林恩按原文为17岁、等级2。
- 七根MVU结构；四页状态栏（当前状态、人物关系、世界事件、系统）。仅最新楼层可写，历史楼层只读；写入前重读 `latest`，写后同步最新消息并等待聊天落盘。
- 恶堕值=成年女性角色亲密接受度：关系结构保留兼容字段并初始为0；小小为幼态角色，恶堕字段永久锁定0。

血锯、小小、泰坦头颅、巫神头颅和小宝贝固定非恋爱，吸引恒为0。八名主要角色不会永久死亡或彻底退出。

本版不包含战斗数值体系、可运算的等级成长、装备栏、库存、货币经营结算、天数计数或旧聊天迁移。E06原作商城只保留为一次性叙事场景和道具来源。

## 维护入口

- `创作规划.yaml`：需求和内容边界。
- `contract.json`：结构契约与验收条件（20个事件ID）。
- `manifest.json`：稳定ID、版本、文件映射和运行依赖。
- `src/worldbook.json`：世界书注册表（20条事件蓝灯，id 300–319）。
- `src/prompts/opening_source.txt`：开场白原文源（修改开场白须同步此源并保持逐字一致）。
- `src/prompts/first_message.md`：生成的开场白（原文+占位符+initvar块）。
- `src/prompts/mainline.md`：自主世界事件调度与19对常驻即时衔接段（EJS按状态渲染）。
- `src/events/`：二十个事件锚点源码（蓝灯详情，含「下一事件引入」段）。
- `src/characters/`：八名主要角色的六组件 EJS 分阶段源码（本版核心改动）。
- `src/prompts/concept_event_router.md`：不输出提示词的 `@@preprocessing` 事件窗口路由。
- `src/concepts/`：52 条静态概念正文；激活关键词与事件数组维护在 `src/worldbook.json`。
- `src/factions/`、`src/mechanisms/`、`src/locations/`：世界内容。
- `src/initial_variables.json`、`src/scripts/schema.js`、`src/prompts/mvu_*`、`src/ui/status.html`：MVU整链。
- `tools/build.mjs`、`tools/validate.mjs`：构建与离线验证。
- 新增事件请使用 `tavern-cards/event-chain-builder` 技能（脚手架 + 全链路同步片段）。

不要直接编辑`dist/`，应修改源码后重新构建。
