# E02·猪头魔与恶灵血婴

- 阶段：S1·怪物客户建立期
- 地点：血锯药剂店
- 前置条件：E01已完成、取消或形成稳定变形（未处置的寻母线索不阻塞）；药剂店仍能接诊；玩家推进接客或日常后，E02经模糊预兆进入。
- 参与者与动机：猪头魔希望处理眼部与腹部异常并控制风险，自称腹中"有东西在动"；恶灵血婴寻求宿主或生存空间；候诊者（烧死鬼等）关注店内安全。
- 默认走向：林恩接诊猪头魔，腹部处置暴露恶灵血婴；血婴可能短期留在药剂店并塑形，成为后续"鬼婴"；塑形结果影响血衣女士寻子线（E04）与母子线收束。
- 紧迫度：中；手术或寄生风险出现后升为高。
- 幕后停止点：林恩缺席时，猪头魔停在求诊或逃离节点，恶灵血婴不在幕后永久占据主要角色。
- 变形条件：拒诊、非手术方案、转诊、患者离开、血婴被安置到其他地点或E01已改变寻子线索。
- 结果影响：建立药剂店怪物病例口碑，改变血婴去向和E04可用线索。
- 系统提示：给出地点、腹部异常、可能寄生风险与模糊处理期限，不替林恩诊断。

## 下一事件引入（E03·小小夜间牙科）
- 触发时机：E02完成、变形或取消后，或玩家推进过夜、夜间接诊时
- 剧情引子：塑形后的鬼婴安静地睡在篮子里。夜更深了，药剂店的魂灯火焰向内缩了一截。门外忽然传来脚步声——沉重得不像任何活物，每一步都让地板上的灰尘跳起来。低鸣声贴着门缝挤进来，闷闷的，像是巨兽在忍着疼。那影子停在门外，比门框高出太多。
- 预兆写法：写深夜、超出门框的巨大影子、压抑的低鸣与沉重脚步；不写名字与来历，把E03写入近期预兆。
- 承接因果：塑形鬼婴让"药剂店收治怪病"的口碑传得更远，连黑暗里最大的病患也循着魂灯找上门。
