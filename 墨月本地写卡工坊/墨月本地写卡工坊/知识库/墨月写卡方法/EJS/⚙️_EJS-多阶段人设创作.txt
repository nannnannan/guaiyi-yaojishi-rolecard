# EJS专项：单角色多阶段人设正式创作

## 一、唯一合法输入

只接受一份完整`<EJS多阶段人设创作提示词>`。它必须已经确定一个且仅一个角色、变量路径与类型、初始默认值、更新规则摘要、互斥且穷尽的条件表、每个分支的完整阶段差异正文、角色专属语义标签、条目名称和世界书配置。

本条目不读取用户先前聊天，不从散乱的initvar或更新规则重新推断设计，也不接收多个角色的合并任务。输入缺失、冲突或仍有待确认项时，只指出第一个阻断点，让用户回到“EJS·多阶段人设设计”。不得提问补齐、猜默认值或输出临时版本。

## 二、唯一实现结构

生成一个启用的蓝灯世界书条目。全部阶段正文直接存在于这一份EJS代码中；EJS读取当前MVU变量后，只把命中的一个阶段正文发送给“你”。

不得采用旧式控制器加禁用阶段条目。不得调用或激活其他世界书。不得生成正则、脚本、安装器、第二套方案或多个代码文件。

## 三、严格编译EJS

先输出一个完整`ejs`代码块，直到最后一个EJS标签闭合后才能结束围栏。为了防止酒馆把本轮交付的EJS代码立即执行，实际回复必须在这个代码围栏外再放一对提示词模板范围转义标记：开标记由字符`<`、`#escape-ejs`、`>`依次组成，闭标记由字符`<`、`#/escape-ejs`、`>`依次组成。开标记紧邻代码围栏之前，闭标记紧邻围栏之后；不要把标记写进代码围栏。若扩展处理生成内容，标记会被消费而代码以原始EJS文本显示；若未处理，用户复制代码围栏时也不会把外侧标记带入代码。

### 3.1 读取与条件

- 只使用`getvar('stat_data.准确路径', { defaults: 准确初始值 })`读取提示词列出的变量。
- `stat_data.`前缀、字段大小写、中文键名、类型和默认值必须逐字对应提示词。
- 不声明共享变量；在条件中直接读取，避免与其他EJS条目发生变量名冲突。
- 使用一条按提示词顺序排列的`if / else if / else`链。
- 数值使用提示词已经确认的边界比较；固定文本和真假值使用严格相等。
- 只允许严格比较、数值边界、`&&`、`||`与括号，不执行输入中的任意JavaScript。
- 最终`else`必须存在并使用提示词指定的分支，不自行创造错误提示或新阶段。

条件链严格采用下列形状，按实际分支数量增减中间`else if`；所有说明位置必须替换为创作提示词中的真实路径、默认值、条件、标签和正文：

```ejs
<%# @qk-unit | 工件=单角色多阶段人设 | 单元=第一阶段分支 | 依据=创作提示词第一分支 | 边界=不处理其他分支 | 完成=条件与阶段正文闭合 %>
<%_ if (getvar('stat_data.实际路径', { defaults: 实际初始值 }) 实际比较条件) { _%>
<实际角色专属标签>
第一阶段的完整差异正文
</实际角色专属标签>
<%# @qk-unit | 工件=单角色多阶段人设 | 单元=中间阶段分支 | 依据=创作提示词对应分支 | 边界=不处理其他分支 | 完成=条件与阶段正文闭合 %>
<%_ } else if (getvar('stat_data.实际路径', { defaults: 实际初始值 }) 实际比较条件) { _%>
<实际角色专属标签>
中间阶段的完整差异正文
</实际角色专属标签>
<%# @qk-unit | 工件=单角色多阶段人设 | 单元=最终阶段分支 | 依据=创作提示词最终else | 边界=不新增条件 | 完成=回退阶段正文闭合 %>
<%_ } else { _%>
<实际角色专属标签>
最终else的完整差异正文
</实际角色专属标签>
<%_ } _%>
<%# @qk-complete | 工件=单角色多阶段人设EJS | 已闭合=变量读取,条件覆盖,阶段正文,语义标签,EJS结构 %>
```

模板中的“实际……”与阶段说明只表示替换位置，不得出现在最终代码。只有两个阶段时删除整个中间`else if`单元；超过三个阶段时复制完整中间单元，不得拆散其条件、标签与正文。

### 3.2 分支输出

每个分支的EJS起止标签之间，直接写入角色专属语义标签和该分支完整阶段正文。示意位置必须全部替换为提示词中的真实内容，不得保留占位符。

每次运行只输出：

```text
<角色专属语义标签>
当前命中阶段的完整差异正文
</角色专属语义标签>
```

不得让阶段名、变量数值、条件表达式、EJS说明、调试内容或未命中分支泄漏到发送文本，除非它本来就是用户确认的阶段人设正文。不得改写、扩写、美化或合并用户已经确认的阶段内容。

阶段正文位于EJS代码标签之外，因此正文中的引号、冒号和普通标签保持文本；若正文含`<%`或`%>`则视为输入不合法并停止，不能尝试转义后继续。

### 3.3 控制注释

只允许使用EJS自身不会输出的注释：

`<%# @qk-unit | 工件=单角色多阶段人设 | 单元=变量读取与条件链／阶段分支 | 依据=创作提示词对应项目 | 边界=不处理其他角色与外部条目 | 完成=当前结构闭合且正文逐字对应 %>`

最后一个条件块闭合后加入：

`<%# @qk-complete | 工件=单角色多阶段人设EJS | 已闭合=变量读取,条件覆盖,阶段正文,语义标签,EJS结构 %>`

注释不得使用JavaScript块注释替代，不得包含内部推演、需求讨论或用户可见说明。

本条目只读取现有变量并选择一段静态提示词，不承担任何其他运行职责。
