# MVU专项：变量结构脚本

## 一、真实位置与输入合同

变量结构脚本是MVU自定义流水线的最后编译产物，不是最先约束用户讨论的前置文件。必须同时收到两个完整包：

**初始变量包**

1. 完整`<MVU初始变量设计终稿>`。
2. 完整`[initvar]变量初始化勿开`YAML。

**变量规则包**

3. 完整`<MVU变量规则设计终稿>`。
4. 完整`[mvu_update]变量更新规则`YAML。

缺少哪份只索取哪份，不从历史、常见玩法或其他Schema重建。设计终稿负责保存YAML无法表达的空集合项目类型、固定选项全集、固定/动态性质、缺失与清空语义、权限和结构约束；正式YAML负责核对最终字段、层级、初值与实际规则落地。四份输入共同构成唯一来源。

若字段、类型、权限或初值冲突，返回“MVU·初始变量设计／格式化”；若更新语义冲突，返回“MVU·变量规则设计／格式化”。本条目不提出新的玩法问题。

## 二、唯一输出文件

酒馆直接安装版固定外壳：

```js
import { registerMvuSchema } from 'https://testingcf.jsdelivr.net/gh/StageDog/tavern_resource/dist/util/mvu_zod.js';

export const Schema = z.object({
  /* 根据两组完整工件生成的全部字段 */
});

$(() => {
  registerMvuSchema(Schema);
});
```

`z`和`_`由当前酒馆助手环境提供，不导入`zod`或`lodash`。Schema名称固定为`Schema`，定义与注册大小写一致。输出是一个自包含角色脚本，不依赖用户再创建本地文件。

## 三、Zod 4映射

- 数值使用`z.coerce.number()`；真假使用`z.boolean()`，不做真假强制转换；文本使用`z.string()`。
- 固定选项使用设计终稿中的完整`z.enum([...])`或等价字面量联合，不只采用当前initvar值。
- 有序列表使用`z.array(...)`；按名称增删和读取的集合使用对象记录。
- 固定同型必需键使用`z.record(z.enum([...]), valueSchema)`；固定同型可选键使用`z.partialRecord`；动态键使用`z.record(z.string().describe('键的真实含义'), valueSchema)`；异型固定键使用`z.object`。
- 动态键含确定必需键时使用固定对象与动态记录的交集。
- 字段名已经说明含义时不重复`.describe()`；动态键等没有字段名的位置才描述。

## 四、缺失、清空、约束与幂等

- 只有初始变量终稿允许缺失，或更新规则允许移除后增量恢复时，才增加相应处理。
- 需要缺失输入自动补全时优先使用`.prefault(...)`而不是`.default(...)`；prefault值必须是合法输入。
- 复合对象从`{}`恢复时，内部必需字段也必须能完成解析；可整体清空对象不能靠`.optional()`让类型长期漂移。
- 只实现初始变量终稿确认的范围、容量、过滤和修复约束；更新规则不能凭空增加Schema约束。
- transform只接收值参数并保持幂等，`Schema.parse(Schema.parse(input))`结果不继续变化；数值修复可使用`_.clamp`。
- 不为了复用在`Schema`外创建平行业务Schema或额外业务状态。

## 五、权限

- “发送给你且由你更新”字段使用终稿确认的普通最终名称。
- “发送给你但只读”字段必须已使用`_`开头的最终名称；脚本照录，不临时改名，更新规则中不得出现。
- “仅代码使用”无法仅靠当前固定三文件无条件保证。出现此需求而用户未提供实际版本的隐藏机制时停止，要求确认机制或改存脚本变量，不发明前缀。

## 六、四份输入交叉检查

1. 初始变量终稿的每个字段在initvar中出现且层级、值类型一致。
2. 规则终稿与更新规则YAML一一对应；无需专门规则、只读与仅代码字段没有被误列。
3. 更新规则引用的每个字段都存在于初始变量包，类型与设计终稿一致。
4. 空动态映射、空列表、固定选项和复合结构依靠设计终稿恢复完整Schema，不能从`{}`、`[]`或单个值猜测。
5. Schema必须接受当前完整initvar；允许后续更新的结构必须能表达规则中确认的插入、删除、替换和移动结果。

存在任何不一致时不生成半成品脚本，只报告第一个阻断点和应返回的上游条目。

## 七、输出与验收

最终只输出一个`js`代码块。按顶层变量组使用合法单行控制注释`/* @qk-unit | ... */`；注册前使用`/* @qk-complete | 工件=MVU变量结构脚本 | 已闭合=全部变量组,注册外壳 */`。清洗后只留下完整脚本。

完成前检查：注册导入与调用完整；没有导入zod或lodash；所有字段只出现于正确层级；initvar能够被Schema接受；规则字段和类型可表达；固定/动态键、复合结构、缺失、清空、范围、枚举和权限一致；transform幂等；括号、引号、逗号、注释和围栏闭合。

代码块外只给出配置：保存为酒馆助手角色脚本`变量结构`并启用；MVU运行脚本必须已经安装并启用。不得继续生成或修改任何上游文件。完成后停止，并提醒用户下一步开启“MVU·固定输出”。
