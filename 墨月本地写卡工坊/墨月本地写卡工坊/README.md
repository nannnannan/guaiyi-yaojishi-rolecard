# 墨月本地写卡工坊

《诡异药剂师》已登记为外部工程，**运行卡体 v0.18（0.18.0）**（止于 E492）冻结；**当前设定精修为 v0.19工作区**（E493—E540／原文1927—2086，settings-only）。继续该项目时读取 `src/诡异药剂师/项目状态.md` 及[版本与工作区索引](../../版本与工作区索引.md)。真实 SillyTavern 实测按作者要求暂缓；不自动导入、创建聊天或运行宿主测试，host_acceptance 保持 pending。

墨月是一套面向新作者的本地写卡环境。使用时只需要用本地 AI 打开整个文件夹，然后说大白话。目录、文件、命令、检查与打包都由秋青子在后台完成，作者只负责提供想法、回答真正影响作品的问题并确认结果。

第一次请看 [`开始写卡.md`](开始写卡.md)。建立作品后，每张卡都会有一个 `创作台.md`，可以把没整理过的想法、临时补充和实测反馈写进去。

秋青子负责：

- 理解作者真正想表达的意思；
- 在含义不明确时继续询问，而不是擅自猜一个答案；
- 把复杂工程拆成当前能够完成和检查的小部分；
- 方向确认后再写入正式角色卡；
- 自行查阅人物、世界书、MVU、EJS、前端和酒馆接口资料；
- 检查、构建并打包 JSON 或 PNG。

秋青子不会因为收到几个标签或零散想法就直接生成主角。她会先整理作者已经说出的内容，指出不同理解和真正缺少的部分；只有经过对话确认，才进入正式创作。

详细说明见 [`墨月使用教程.md`](墨月使用教程.md)。`知识库/`、`@types/`、`.agents/`、`scripts/` 和其他工程文件是提供给 AI 的后台资料，普通使用不需要打开。
