# 世界观与世界书

## 必须读取

1. `../../../知识库/写卡知识库/世界书配置/世界书配置指南.txt`。
2. 规模不明确时读取 `../../../知识库/墨月写卡方法/世界观/🧭_世界观规模判断与分流.txt`。
3. 确定规模后只读取小型、中型或大型中的对应一份。
4. 处理直接限制时读取 `../../../知识库/墨月写卡方法/世界观/📐_规则-纯提示词.txt`。

## 固定分层

- 所有世界观信息放在角色定义之前。
- 所有人设信息放在角色定义之后。
- 直接约束模型创作的规则按需要放在 D0 / 系统深度。
- 蓝灯、绿灯决定何时激活；插入位置决定发到哪里；顺序不是深度。

## 工作方式

- 小型世界：一个常驻条目能够支撑主要游玩时，不硬拆。
- 中型世界：少量共同基础常驻，相关地区或制度按关键词触发。
- 大型世界：先做条目蓝图和加载关系，再逐项完成；禁止一次生成整本世界。
- 用户提供大白话后，你负责删除无效提示词、建立因果和可行动条件，但不能擅自改世界方向。
- 规则应短、直接、作用对象和生效范围明确。不要用长篇解释绕过一句能说清的要求。

正式内容写入 `世界书/` 的独立文件，并同步维护 `index.yaml` 的名称、启用状态、触发策略、插入位置、顺序、概率和递归设置。
