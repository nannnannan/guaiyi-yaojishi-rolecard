# 人物生境

## 必须读取

- 首次进入人物专项时读取 `../../../知识库/写卡核心/AIRP人物生境写法教程.md`。
- 涉及高冷、天才、机器式人物、套话或禁忌时读取 `../../../知识库/写卡核心/写卡禁忌与规范.md`。
- 根据当前部分读取 `../../../知识库/墨月写卡方法/人物生境/` 下同名条目；不要一次读取整个人物目录。

## 内容结构

- 基础信息：稳定客观事实，回答“这个人是谁”。
- 生活结构：主线之外持续存在的事务、责任、关系、地点、资源与限制。
- 人物性情：怎样理解事情、真正在意什么、怎样理解自己及内部张力。
- 场景表达：前三层不足以约束真实表达时才增加。
- 穿衣风格：写选择倾向，不穷举固定衣柜。
- NPC：允许按用户几句话直接生成轻量生境，但仍避开廉价标签化人物。

## 对话与写入

1. 先消化用户已给材料，只讨论当前人物部分；不属于这里的内容列为待处理，不擅自丢弃。
2. 用户只有标签、感觉或零散想法时，不直出主角人设。先复述理解，并请用户描述具体场景、选择、关系或不希望出现的表现。
3. 每轮只解决一组彼此相关、会影响人物根本方向的问题。
4. 当内容已足以支持陌生场景中的自然选择，主动说明本部分已经够用，不继续填满。
5. 用户确认进入正式创作后，把最终内容写入当前角色卡 `世界书/角色/` 的独立文件，并在 `index.yaml` 配置为“角色定义之后”。
6. 人物需要通过空卡实测。用户带回 AIRP 片段或感受时，先诊断问题属于哪一层，再修改对应文件。

举例只能使用与用户角色无关的其他人物，不能借举例替用户完成角色。不要把示例角色的设定带进用户角色，也不要把用户未确认的推测写成事实。

轻量 NPC 是明确例外：只有用户主动要求“根据这几句话直接生成一个配角”时，才可按 NPC 规则生成；不能把这个例外扩展到主角。
