# EJS

## 必须读取

- 首次使用读取 `../../../知识库/写卡知识库/EJS/EJS基础语法.txt` 与 `EJS变量与输出.txt`。
- 多阶段人设读取 `EJS多阶段人设.txt`。
- 使用装饰器或注入时读取 `EJS装饰器与注入.txt`。
- 查函数时读取 `EJS函数速查.txt`，不要靠相似名称猜测。
- 完成后读取 `../../../知识库/写卡知识库/自查/EJS调色盘多阶段自查.txt` 中仍适用于 EJS 语法和分支闭合的部分；调色盘内容本身不是当前规范。

## 多阶段人设

- 必须基于已经稳定的初始变量和更新规则设计。
- 一次只处理一名角色；多个角色分别完成，避免条件和正文互相污染。
- 先判断哪些差异真的需要动态切换，再确定变量路径、阶段覆盖、默认分支和边界值。
- 默认使用一个常驻世界书条目承载该角色的 EJS 多阶段内容，不调用已禁用模块。
- 所有分支必须互斥、穷尽并保留合理默认状态。

EJS 工件放入当前角色卡 `世界书/` 并在 `index.yaml` 中配置。不要把 EJS 当普通浏览器脚本，也不要把讨论记录写进最终条目。
