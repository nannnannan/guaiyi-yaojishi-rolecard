# 专项路由

根据本轮实际目标，只读取对应 Skill。一个任务可以连续经过多个专项，但同一时刻只让一个专项主导。

| 用户正在做什么 | 读取 Skill |
|---|---|
| 新建角色卡、整理混乱需求、规划大工程、恢复进度 | `.agents/skills/moyu-project/SKILL.md` |
| 主角、配角、生活结构、性情、场景表达、穿衣风格、实测回流 | `.agents/skills/moyu-character/SKILL.md` |
| 世界观、世界书拆分、触发方式、规则提示词 | `.agents/skills/moyu-worldbook/SKILL.md` |
| 第一条消息、开场白、多个开场分支 | `.agents/skills/moyu-opening/SKILL.md` |
| MVU 变量、initvar、更新规则、Zod Schema | `.agents/skills/moyu-mvu/SKILL.md` |
| 状态栏、消息楼层界面、酒馆内嵌 UI | `.agents/skills/moyu-tavern-frontend/SKILL.md` |
| 酒馆后台脚本、事件、变量、世界书操作、AI 请求 | `.agents/skills/moyu-tavern-script/SKILL.md` |
| ST-Prompt-Template、EJS、多阶段人设 | `.agents/skills/moyu-ejs/SKILL.md` |
| 检查、构建、同步、导出 JSON/PNG、交付 | `.agents/skills/moyu-package/SKILL.md` |

如果用户一句话同时包含多个目标，先用 `moyu-project` 排顺序，再进入第一个专项。不要同时加载所有技术知识。
